# CLI 6001-8000 分类方案

共 2000 个 Go CLI 工具项目，分 40 类，每类 50 个。

## 语言与命名

- 全部 Go 标准库实现（不用 Gin/Fiber 等 web 框架）
- 命名：`{number}-go-{description}`，如 `6001-go-file-hash-cli`
- 纯命令行工具，不启动 HTTP 服务（除非 PROMPT 显式要求）
- 编译命令：`go build -o cli-tool` 或直接 `go run .`
