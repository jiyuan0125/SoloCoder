写一个 FIFO 广播协议的 Rust 实现。

FIFO 广播是最基本的有序广播：保证来自同一个发送者的消息按发送顺序被所有接收者交付。不保证不同发送者消息之间的顺序（比因果序弱，比全序也弱，但实现简单高效）。实现 FIFO 广播：每个发送者维护一个递增的序列号 seq，消息携带 (sender_id, seq)。接收者为每个发送者维护一个 expected_seq 的 map，收到消息后如果 seq == expected_seq[sender] 就立即交付并把 expected_seq++，同时检查缓冲区是否有后续可以交付的消息。否则放入按 seq 排序的缓冲区等待。

Rust 实现，cargo build 通过，模拟 3 个发送者并发发消息，验证每个发送者的消息按序交付。

这个工具的核心价值在于把fifo order的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

FIFO 广播保证来自同一发送者的消息按序到达。最基本的有序广播——实现简单（发送者递增序列号），性能好。
