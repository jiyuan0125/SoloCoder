帮我用 C 写一个监控系统告警推送模块。运维系统检测到异常后，需要通过 HTTP 请求把告警信息推送到企业微信、飞书、钉钉这些平台的 webhook 地址。

模块要支持 GET、POST、PUT 三种请求方式。POST 和 PUT 能发送 JSON 格式的请求体。每个请求要能自定义 HTTP 头部，比如 Content-Type 和 Authorization。

网络这块比较头疼：目标服务器有时候会超时，有时候连接不上，有时候响应很慢。所以每个请求要支持设置超时时间（连接超时和读取超时分开设），超时了要返回错误而不是无限等下去。还要支持自动重试——请求失败后重试最多 3 次，每次间隔翻倍（1秒、2秒、4秒），最后一次还失败就放弃并记录错误信息。

另外告警推送不能阻塞主流程，最好能设置一个整体超时上限，比如 10 秒内必须完成（包含所有重试），超时就直接跳过这个告警。

有些 webhook 地址是 HTTPS 的，模块要能处理，但不要求验证证书（内网环境通常用自签证书）。响应内容要能拿到状态码和响应体，方便调用方判断推送是否成功。

用纯 C 写，不依赖第三方库，gcc 在 Linux 上编译通过。写个 main 演示：往一个 HTTP 测试服务发 POST 请求，模拟发送告警 JSON。
