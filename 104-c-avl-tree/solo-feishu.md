| User Prompt | 帮我用 C 写一个游戏实时排行榜系统。玩家打完一局后提交分数，排行榜要实时更新并显示当前排名。这个排行榜有几个特点让它不能简单排序了事： 第一，数据量可能很大——几百万玩家都有分数记录，每次更新后要能快速拿到某个玩家的排名。比如玩家刚提交了分数，马上就要告诉他现在排第几名，不能等几秒钟才出结果。如果每次更新都重新排序几百万条记录，延迟根本受不了。 第二，查询方式多样。除了查排名，还要支持：查某个排名区间的玩家列表（比如第 50 到第 100 名）、查某个分数段内的玩家数量。这些查询都要尽量快。 第三，会有大量并发——游戏高峰期每秒可能有上千次分数提交和排名查询。所以读写操作都要能并发进行，但不能用全局锁。 第四，要处理分数相同的情况。相同分数的玩家按提交时间排序，先提交的排前面。如果后来有个玩家的分数追平了之前的玩家，应该排在后面而不是前面。 第五，排行榜有个容量上限，比如只保留前 100 万名。超出容量的玩家记录要能自动淘汰掉，但淘汰时要维护好剩余数据之间的相对顺序。 用纯 C 写，不依赖第三方库，gcc 在 Linux 上编译通过。写个 main 演示：插入大量玩家分数，查询排名、查询区间、并发更新。 代码要拆成至少 4 个源文件，按功能模块分——排行榜数据管理、并发访问控制、排名查询、主程序。头文件和实现文件分开。gcc -lpthread 编译能过。 |
