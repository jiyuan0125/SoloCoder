| User Prompt | 帮我用 C 写一个智能家居温湿度采集服务。家里部署了一批低功耗传感器（温度传感器、湿度传感器、门窗开关传感器），它们通过 CoAP 协议（一种轻量级的 UDP 协议，类似精简版 HTTP）上报数据，你的服务需要接收并存储这些数据。 每个传感器有一个唯一编号，上报时带上传感器类型、当前读数、电量百分比、时间戳。服务端收到后存到内存里，最近 1000 条读数要保留，超出的自动丢弃。 外部系统（比如手机 App 或者告警系统）会通过同样的 CoAP 协议来查询数据。查询方式包括：查某个传感器的最新读数、查某个传感器的最近 N 条历史、查所有传感器中温度最高的前 5 个。这些查询的响应也要用 CoAP 格式返回。 CoAP 协议有个消息类型机制——CON（需要确认）和 NON（不需要确认）。传感器上报通常用 NON（省电），但查询请求用 CON（确保送达）。服务端收到 CON 消息后要回复 ACK。 告警逻辑：当温度超过 40 度或低于 0 度时，服务端要主动记录一条告警。告警信息包括传感器编号、异常温度值、发生时间。同一传感器连续 3 次上报都异常时才触发告警（避免偶尔一次波动就报警），恢复正常后要能自动解除告警状态。 用纯 C 写，不依赖第三方库，gcc 在 Linux 上编译通过。写个 main 启动服务并模拟几个传感器上报数据、外部系统查询。 |
