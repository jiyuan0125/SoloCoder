帮我用 C 写一个 JSON 数据构建模块，用于自动生成测试数据。测试框架需要生成各种格式的JSON 供 Mock 服务使用，所以这个模块要能方便地拼装 JSON。

基本操作：创建一个空的 JSON 对象或数组，然后往里面添加内容。支持的数据类型包括：字符串、整数、浮点数、布尔值、空值、嵌套对象、嵌套数组。每个值可以设置一个键名，也可以不设（数组元素不需要键名）。

字符串内容要正确处理特殊字符转义——引号、反斜杠、换行符、制表符这些都要自动转义，不能让生成的 JSON 格式错误。中文字符直接用 UTF-8 输出，不需要转成 \uXXXX。

输出格式化：默认输出压缩格式（无空格无换行），但也要支持美化输出（缩进 2 空格，每个键值对一行）。美化时嵌套层级要正确缩进。

内存管理：所有创建的数据用完后要能统一释放，不能有内存泄漏。设计一个释放机制，释放根节点时自动释放所有子节点。

有个容易忽略的点：浮点数输出时要避免打印出多余的零（比如 3.0 不要输出成 3.000000），但如果值本身就是 3.00000001 这种，要保留精度。另外 NaN 和 Infinity 在标准 JSON 里是不合法的，遇到时应该输出 null。

用纯 C 写，不依赖第三方库，gcc 在 Linux 上编译通过。写个 main 演示：构建一个包含嵌套对象和数组的复杂 JSON 并打印出来。

代码要分几个模块：JSON 值节点管理模块、输出格式化模块、内存管理模块，各自有头文件和实现文件。加一个 main 做演示。至少 3 个 .c 文件加对应的 .h 文件。gcc 编译能过。
