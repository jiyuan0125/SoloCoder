## 需求逐项验证

### 1. 编码功能
| 需求 | 状态 | 说明 |
|------|------|------|
| 输入任意二进制数据（字节数组+长度） | ✅ | `base64_encode(uint8_t*, size_t, ...)` |
| 输出 Base64 编码后的字符串 | ✅ | 输出到调用方提供的 char* 缓冲区 |
| 每 76 个字符插入换行符（MIME 标准） | ✅ | `BASE64_LINE_LENGTH=76`，编码循环中 `col >= 76` 时插入 `\n` |
| 编码结果以空字符结尾 | ✅ | `output[idx] = '\0'` |

### 2. 解码功能
| 需求 | 状态 | 说明 |
|------|------|------|
| 输入 Base64 字符串（可能含换行和空格） | ✅ | `base64_decode(char*, size_t, ...)` |
| 输出解码后的原始字节数据和长度 | ✅ | 通过 `output_len` 返回实际长度 |
| 非法字符跳过不报错 | ✅ | `decode_table[c] == BASE64_INVALID` 时 `continue` |
| 非 4 倍数长度正确处理 | ✅ | 尾部 remainder 区分 group_idx==2 和 group_idx==3 |

### 3. 性能要求
| 需求 | 状态 | 说明 |
|------|------|------|
| 查表法 | ✅ | 编码用 `base64_table[64]`，解码用 `decode_table[256]` |
| 不用 pow 或除法 | ✅ | 全部使用位运算（`<<` `>>` `&`） |

### 4. 内存管理
| 需求 | 状态 | 说明 |
