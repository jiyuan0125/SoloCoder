| User Prompt | 帮我用 C 写一个邮件附件的编码解码模块。电子邮件发送附件时，二进制文件要转成纯文本格式传输（Base64 编码），接收端再解码还原。这个模块就是干这个事的。编码：输入任意二进制数据（字节数组和长度），输出 Base64 编码后的字符串。每 76 个字符要插入一个换行符，这是 MIME 标准要求的。编码结果以空字符结尾，方便作为字符串使用。解码：输入 Base64 编码的字符串（可能包含换行和空格），输出解码后的原始字节数据和长度。输入中非法的字符要能跳过而不是报错——实际邮件中经常有换行、空格、尾部的等号等。如果输入的长度不是 4 的倍数，要能正确处理（根据尾部的等号数量判断原始数据长度）。性能要求：编码和解码都要尽量快，可以考虑查表法。不要用 pow 或者除法这种慢操作来做位运算。内存管理：编码输出和解码输出的内存由调用方提供（传入缓冲区和大小），模块不自行分配，这样调用方可以复用缓冲区减少内存分配次数。如果缓冲区不够大，要能返回需要的实际大小。边界情况：空输入要能正确处理（编码输出空字符串，解码输出空数据）。超大文件不能一次性读入内存——要支持流式编码和解码，每次处理一小块数据，适合处理几百 MB 的大附件。用纯 C 写，不依赖第三方库，gcc 在 Linux 上编译通过。写个 main 演示：编码一段二进制数据，再解码还原，对比结果是否一致。代码要分几个模块：编码模块、解码模块、流式处理模块，各自有头文件和实现文件。加一个 main 做演示。至少 3 个 .c 文件加对应的 .h 文件。gcc 编译能过。 |
