帮我用 C 写一个交互式命令行输入模块。我们的数据库管理工具需要一个命令行界面，用户在终端里输入 SQL 查询并查看结果。这个模块负责处理用户的键盘输入。

基本功能：读取用户输入的一行文本。支持退格键删除字符、左右方向键移动光标、Home/End 键跳到行首行尾、Delete 键删除光标后面的字符。支持输入超长文本——终端一行放不下时要能正确换行显示，光标位置要跟实际编辑位置对应。

历史记录：用户按上下方向键能翻阅之前输入过的命令。历史记录最多保留 1000 条。输入为空（直接按回车）的行不记入历史。相同内容的连续输入不重复记录（比如连续两次输入SELECT * FROM users，历史里只记一次）。

行内编辑：支持 Ctrl+A 跳到行首、Ctrl+E 跳到行尾、Ctrl+U 清除光标前面的内容、Ctrl+K 清除光标后面的内容。这些操作要有类似 Bash 的体验。

Tab 补全：用户按 Tab 时，调用方提供一个补全候选列表，模块负责显示候选并让用户选择。如果只有一个候选，直接补全；多个候选时列出并等待用户继续输入缩小范围。

信号处理：用户按 Ctrl+C 时，清除当前输入行并显示新提示符，不能让整个程序退出。用户按 Ctrl+D 且当前行为空时，表示退出（返回空表示 EOF）。

有个坑：终端设置修改后（比如设置了 raw mode），程序退出前必须恢复原来的终端设置，否则用户的终端会变成乱码状态。即使程序因为信号被杀掉，也要确保终端设置被恢复。

用纯 C 写，gcc 在 Linux 上编译通过。写个 main 演示：显示提示符，读取输入，打印历史。

代码要拆成至少 4 个源文件，按功能模块分——终端控制与光标管理、历史记录管理、行编辑与补全、主程序。头文件和实现文件分开。gcc 编译能过。
