帮我用 C 写一个音乐播放器的播放列表管理模块。播放器需要管理歌曲列表，支持播放、暂停、上一首、下一首、随机播放、单曲循环、列表循环等各种模式。

基本结构：维护一个有序的歌曲列表，每首歌有编号、标题、歌手、时长、文件路径。支持添加歌曲（添加到末尾或插入到指定位置）、删除歌曲、移动歌曲位置。

播放控制：维护一个当前播放指针，指向正在播放的歌曲。下一首把指针移到后面一首，上一首移到前面一首。到达列表末尾后根据播放模式决定行为——列表循环就回到第一首，单曲循环就重复当前，顺序播放就停止。

随机播放模式：开启后，下一首随机选择一首（不能是当前正在播放的同一首，除非列表里只有一首）。随机播放也要保证每首歌都被播放到后才重复——也就是说随机播放 N 首歌的列表，前 N 次下一首不应该有重复。

插入和删除的效率：播放列表可能有几百甚至上千首歌，添加和删除操作要快。不能每次插入都移动后面所有元素（像数组那样）。删除当前播放的歌曲时，播放指针要自动移到下一首，如果删除的是最后一首就移到第一首。

临时插入：播放过程中可以临时插入一首歌到当前播放位置的下一首（插队）。插队的歌播完后自动从列表中移除，不影响原来的播放顺序。

收藏功能：歌曲可以标记为收藏。收藏的歌曲不会从列表中删除，但可以通过筛选只显示收藏的歌曲。收藏状态改变不影响播放顺序。

有个隐藏坑：删除操作中，如果要删除的歌曲正好是临时插入的歌曲，要从不同的位置管理结构中移除。列表本身的歌曲和临时插入的歌曲要用不同的方式管理，不能混在一起。

用纯 C 写，gcc 在 Linux 上编译通过。写个 main 演示：创建播放列表，模拟播放、切歌、随机模式等操作。

代码要拆成至少 4 个源文件，按功能模块分——播放列表数据结构、播放控制与模式、随机播放管理、主程序。头文件和实现文件分开。gcc 编译能过。
