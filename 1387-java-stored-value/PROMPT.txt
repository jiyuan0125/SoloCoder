做一个会员储值卡系统。会员有等级（普通/银卡/金卡/钻石），账户分本金余额和赠送余额。充值有阶梯赠送（充100送5、300送20、500送50、1000送150），赠送金额只取最高档不叠加。赠送记赠送余额，充值记本金余额。

消费先扣赠送余额再扣本金，不够则消费失败。每次消费记录从两笔余额各扣了多少。退款按消费时的扣款比例原路退回。会员等级享受折扣（银卡9.8折、金卡9.5折、钻石9折），折扣后金额再按优先级扣余额。积分按折扣前原价算。充值、消费、退款都生成流水记录。多个会员同时消费时余额扣减要正确。

项目用cargo workspace，core、server、client三个crate。core包含业务逻辑和数据模型，server引用core对外提供HTTP API（Axum框架），client是命令行工具调用server的接口。服务端监听端口通过命令行参数或环境变量指定。数据存内存。
