做一个会员储值卡系统，核心是充值赠送和消费扣款的优先级逻辑。

会员有姓名、手机号、会员等级（普通、银卡、金卡、钻石）。每个会员有一个储值账户，账户里有"本金余额"和"赠送余额"两笔钱。

充值规则：充值有阶梯赠送，充100送5，充300送20，充500送50，充1000送150。赠送金额只取最高一档，不能叠加。比如充600送50（对应500档），不是充500送50再加充100送5。赠送金额记入赠送余额，充值本金记入本金余额。

消费扣款优先级：消费时先扣赠送余额，赠送余额扣完后再扣本金余额。如果赠送余额和本金余额加起来不够支付消费金额，则消费失败。每次消费要记录扣款明细，标明从赠送余额扣了多少、从本金余额扣了多少。

举个具体例子：会员充了500元，本金500赠送50，账户总额550。消费30元时，先从赠送余额扣30，赠送余额剩20，本金500不变。再消费100元时，先扣赠送余额20，再扣本金80，赠送余额变0，本金变420。

退款逻辑：如果消费后发生退款，退回的金额按消费时的扣款比例原路退回。比如一笔100元的消费中，赠送余额扣了20、本金扣了80，退款时就退20到赠送余额、80到本金。

会员等级权益：不同等级享受不同的折扣。普通会员无折扣，银卡9.8折，金卡9.5折，钻石9折。折扣在计算消费金额时应用，也就是先算折扣后的金额，再按优先级扣余额。

积分规则：每消费1元（按折扣前的原价算）积1分。积分可以兑换商品，但这个功能先不做，只记录积分就好。

账单流水：每次充值、消费、退款都要生成一条流水记录，包含时间、类型、金额、余额变动前后。

初始数据预置几个会员，部分会员有初始余额。

Maven多模块项目：common模块放DTO、枚举、统一响应格式等共享定义；server模块是Spring Boot应用，数据全部存在内存中，不连接数据库；client模块是纯Java CLI，通过HTTP调用server。三个模块各自独立pom.xml，根目录有一个父pom.xml。先mvn clean package能编译通过。
