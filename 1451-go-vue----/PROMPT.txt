帮我用 Go 写一个智慧园区的门禁、访客和巡检管理系统。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

门禁这块，园区里每栋楼都有门禁设备，员工刷脸或刷卡通过。门禁记录要存下来，包含通行人姓名、部门、通行时间、门禁点位名称。同一个人在5分钟内重复通过同一个门禁点位，只记一条记录。门禁点位的通行规则要能配置，比如有些门禁只允许特定部门的人在特定时间段通行，凌晨0点到6点除安保部门外不允许进出。门禁点位按区域分组，管理员可以按区域批量设置通行规则。

访客管理是员工提交访客预约，填访客姓名、手机号、来访事由、预计到达时间。审核通过后访客到现场用手机号核销生成临时通行权限。访客预约到达时间过了还没核销超过2小时自动作废，审核通过但还没到到达时间的不能提前核销。访客手机号要去掉前缀0做一次校验。每天每个员工的访客预约上限5人。

巡检模块是给安保人员用的，管理员创建巡检任务，指定巡检路线（一组巡检点位的有序列表）、巡检人员和执行频率。巡检人员到每个点位打卡，巡检点位按路线定义的顺序打卡，跳序不行。巡检中发现的异常如果关联到某个门禁点位的设备故障，要在门禁记录里标记该点位为故障状态，此时门禁自动改为常开模式直到维修完成。多个安保人员同时在不同点位打卡，服务端要正确处理并发写入。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
