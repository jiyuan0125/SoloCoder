帮我用 Go 写一个连锁门店管理系统，核心是 POS 收银、日结和盘点三个功能。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

POS 收银这块，收银员通过客户端选择商品，每件商品有名称、条码、单价、库存数量。支持按条码快速添加商品。收银时有折扣逻辑，顾客是会员可以享受会员折扣，折扣率存在会员等级表里。结算时计算总金额要精确到分，用整数存储不能有浮点精度问题。如果顾客购买的商品库存不足，收银时标记这笔订单的库存扣减为待确认状态。

日结功能是门店每天营业结束后做的。系统自动汇总当天所有交易记录，按支付方式分别统计金额生成日结单。如果一笔交易跨两天，比如晚上23:58开始00:05才完成支付，这笔交易算在后一天的日结里，以实际支付完成时间为准。日结完成后当天的单据不能再修改。多个收银员同时做日结操作不能出现数据不一致。

盘点模块是店长用的，创建盘点任务后系统导出当前库存清单，盘点人员录入实盘数量，系统自动计算盈亏。盘点期间如果有新的销售或入库操作，这些变动要在盘点结束后单独处理。盘点金额计算也要精确到分。盘点导出的库存清单要和实际盘点录入的结果能对应上，以商品的唯一标识做关联。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
