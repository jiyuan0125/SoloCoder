帮我用 Go 写一个物业管理系统，主要覆盖报修、缴费和公告三个业务。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

报修流程是业主提交报修申请，选择报修类型（水电维修、门窗维修、公共设施、其他），填写问题描述和期望上门时间。提交后生成工单，状态为待派单。维修主管分配给维修师傅，师傅处理完后上传维修结果，业主确认后工单关闭。业主24小时内没有确认的系统自动确认并关闭。维修师傅接单后有48小时处理时限，超时未完成的工单自动升级到主管待处理队列。

缴费模块管理物业费、水电费、停车费等。管理员按月生成账单。缴费金额涉及小数计算要精确到分，用整数存。违约金是欠费每天万分之五，违约金天数从缴费截止日的次日开始算，当月正常费用不产生违约金。缴费支持部分缴费，比如账单2000元业主先交500，剩余记为欠费。部分缴费时违约金的计算基数要相应减少。

公告模块支持设置生效时间和失效时间，只显示当前有效期间的公告。公告可以设置可见范围，针对某栋楼或者全体业主。

报修如果涉及公共设施的维修，费用从公共维修基金里扣，要在缴费模块里生成一条特殊类型的账单。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
