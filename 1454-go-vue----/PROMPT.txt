帮我用 Go 写一个企业食堂管理系统，核心是充值、消费和营养分析。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

充值功能是给员工饭卡充钱的，最低10元最高500元。充值成功后余额增加同时生成充值记录。同一个员工在两个设备上同时点击充值，余额不能出现竞态条件。充值金额要精确到分，用整数存分。

消费模块是打菜窗口用的，通过客户端选择员工然后逐个添加菜品。每个菜品有名称、价格、营养成分信息（热量、蛋白质、碳水、脂肪）。消费时自动从员工余额里扣除，余额不足时允许赊账，赊账上限100元。每笔消费记录包含员工信息、菜品列表、总金额、消费时间和餐次（早餐、午餐、晚餐、夜宵）。早餐时段只能用早餐券不能用午餐或晚餐的配额，但余额是通用的不受时段限制。多个窗口同时消费要保证余额扣减的准确性。

营养分析是员工查看自己最近7天或30天的营养摄入汇总。热量推荐标准根据员工性别和体重自动计算，男性基础代谢按体重乘以24，女性乘以22。消费时快照保存当时的营养数据，菜品营养信息后续修改不影响历史记录。

菜品管理支持上下架、价格调整、营养信息编辑。菜品价格调整后新生效，已有的消费记录不受影响。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
