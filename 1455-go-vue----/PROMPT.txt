帮我用 Go 写一个印章管理系统，管理公章、财务章、合同章等各类印章的使用。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

印章使用流程是员工提交用印申请，选择印章类型、填写用印事由、记录需要盖章的文件名称和份数、选择期望用印时间。审批链根据印章类型自动匹配，公章需要部门经理和总经理两级审批，财务章只需财务经理审批，合同章需要法务和部门经理审批。审批人可以同意或驳回，驳回时填写驳回原因。中间某级审批人超过48小时没处理的系统自动催办，催办不超过3次，3次之后升级到该审批人的上级。

用印记录这块，审批通过后印章管理员在指定时间为申请人盖章，盖章完成后登记实际用印时间和份数。如果实际份数和申请的不一致以实际为准但要记录差异。用印完成后系统自动生成审计日志，包含申请人、审批链、用印时间、份数、印章类型等完整信息。审计日志不可修改，任何人包括管理员都不能删除或编辑。

印章库存管理，每种印章有唯一编号，记录当前状态（在库、借出、报废）。印章借出时关联到用印申请，归还后状态恢复为在库。

审批链如果某个审批人同时也是申请人，自动跳过该审批人。用印份数必须是正整数且不超过100。同一份印章被多个申请同时关联，服务端要正确处理并发状态变更。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
