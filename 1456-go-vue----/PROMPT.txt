帮我用 Go 写一个档案管理系统，覆盖归档、借阅和销毁三个核心流程。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

归档流程是档案管理员录入档案信息，包含档案编号（自动生成，格式为年份加四位流水号如20260001）、档案标题、分类（人事、财务、合同、技术文档）、密级（公开、内部、机密、绝密）、归档日期、归档人。档案编号每年重新从0001开始计数，同一年内不能重复。密级为机密及以上的档案对普通用户只显示标题和编号，不显示详细信息。

借阅模块，员工提交借阅申请选择要借阅的档案，填写借阅事由和预计归还日期。审批流程根据密级决定，公开的直接通过，内部的需部门经理审批，机密及以上需部门经理和档案管理员双重审批。超过预计归还日期未归还的，系统每天生成催还提醒。同一份档案已被借出且未归还的，其他人不能再借阅。

销毁模块，档案到达保管期限后（人事永久、财务30年、合同10年、技术文档5年），管理员可以在列表里看到待销毁的档案。销毁操作需要管理员二次确认，确认后生成销毁记录。销毁后的档案不再出现在查询结果里，但销毁记录要永久保存。

档案列表和借阅记录支持导出 CSV。密级为机密及以上的档案在导出时标题只保留前4个字后面用星号替代。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
