帮我用 Go 写一个招商管理系统，主要管意向客户、跟进和签约。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

意向客户管理，销售人员录入客户信息，包括客户名称、联系人、联系电话、意向面积、意向业态（餐饮、零售、办公、仓储）、预计入驻时间。同一个客户名称和联系电话的组合不能重复录入。手机号输入时用户可能带空格或横杠，比较前要先格式化去掉所有非数字字符。

跟进记录是核心模块，每次沟通后记录跟进方式（电话、微信、面谈、邮件）、跟进内容摘要、下次跟进计划时间。系统根据计划时间自动生成待办提醒，超过计划时间48小时没有录入新的跟进记录自动标记该客户为流失预警状态。每个意向客户最多只能有10条未关闭的跟进记录。

签约模块在客户确认入驻后使用，创建租赁合同记录，包含客户信息、租赁面积、月租金单价、租期开始和结束日期、免租期天数。免租期跨月份的，比如从1月15日到2月14日，1月份的租金要按天数折算只收后半个月的，2月份也只收前半个月的。签约完成后该客户的意向状态变为已签约。

数据看板要展示本月新增意向客户数、签约数、签约率、平均跟进次数。多个销售同时录入同一个客户信息时系统要正确处理去重逻辑。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
