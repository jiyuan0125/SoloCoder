帮我用 Go 写一个合同履约管理系统，核心是里程碑管理、付款节点和进度跟踪。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

合同录入时除了基本信息（合同编号、甲方乙方名称、合同总金额、签订日期、合同类型），还要录入履约里程碑。每个里程碑有名称、计划完成日期、计划完成金额（占合同总金额的百分比）、负责人。里程碑的计划完成金额加起来要等于100%，不满或者超过要阻止保存。合同总金额要精确到分，用整数存储。

付款节点和里程碑关联，每个里程碑完成并验收通过后触发对应的付款。应付金额根据里程碑占比乘以合同总金额计算，精确到分。合同总金额执行过程中发生变更，已经完成的里程碑对应的付款金额不变，只影响后续未完成里程碑的计算。实付金额可能和应付金额不同，差额记入合同调整记录。

合同里可以约定服务时间窗口，比如工作日9点到18点提供服务。里程碑的实际完成时间超出服务时间窗口的要标注为非工作时段完成，不同合同的服务时间窗口可能不一样。

所有合同变更操作要记录审计日志，包括变更时间、操作人、变更前后的值。审计日志只读不可修改不可删除。同一个合同的里程碑被多个负责人同时更新，服务端要保证数据一致性。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
