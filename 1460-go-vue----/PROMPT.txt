帮我用 Go 写一个供应商门户系统，企业采购部门用来做询价、报价和比价。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

询价单由采购专员创建，填写采购物资清单（物资名称、规格型号、需求数量、单位），指定报价截止时间（从创建时间起至少3天后），选择邀请报价的供应商。询价单创建后系统自动给被邀请的供应商生成待办提醒。报价截止时间前供应商可以多次修改报价以最后一次提交为准，截止时间后锁定。采购专员在供应商已提交报价后修改了物资数量，之前提交的报价自动标记为失效，需要供应商重新报价。

报价模块是供应商使用的，针对每项物资填写单价和交货周期天数。报价总价自动计算等于各项物资单价乘以数量的总和。供应商可以添加备注说明大批量采购可以给折扣。

比价模块是采购专员用的，询价截止后系统自动汇总所有供应商的报价，按物资维度横向对比每家供应商的单价。采购专员可以选择最终的中标供应商，可以按物资维度分别选择不同供应商。确定中标后生成采购订单发送给对应供应商。

金额计算全程用精确小数，物资单价保留两位小数，总价四舍五入到两位小数。如果某项物资没有供应商报价，比价时该行标记为无报价。多个供应商同时提交报价，服务端要正确处理并发写入。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
