帮我用 Go 写一个能源管理系统，给工业园区用的，做用能数据采集分析和节能建议。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

用能数据管理是基础，系统维护一组用能监测点位，每个点位有名称、所属区域、能源类型（电、水、天然气、蒸汽）、计量单位。监测点位定期上报用能数据，每条数据包含点位ID、时间戳和读数（累计值）。后端收到数据后计算增量值，如果设备更换了表计导致读数归零，增量计算会出负数，这种情况用本次读数直接作为新周期的起始值，不计算增量。

用能分析模块提供按时间维度和区域维度的能耗统计。按时间维度可以看每小时、每天、每月的能耗。按区域维度可以对比不同区域的能耗占比。日数据是一天内所有增量值的和，月数据是一个月内所有日数据的和。某个时间粒度内没有数据上报的，该粒度的值按0处理并标注为数据缺失。

节能建议是根据历史数据自动生成的。如果某个区域本月用电量比上月增长超过20%，自动生成一条节能建议提醒。如果某个点位的单位面积能耗超过同类型点位的平均值30%以上也生成建议。同一个点位同一个月只生成一次同类型的建议。

指标聚合展示总能耗按能源类型分类、同比和环比变化率。变化率的计算公式是本期减上期除以上期乘以100，上期为0时显示为新增不显示百分比。多个点位同时上报数据，服务端要正确处理并发写入。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
