帮我用 Go 写一个安全生产管理系统，工厂和建筑工地用的，管安全隐患排查、整改和记录。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

隐患排查是日常工作核心，安全巡检员定期创建巡检计划，指定巡检区域、巡检项目清单、巡检频率（每天、每周、每月）。计划创建后按频率自动生成巡检任务分配给对应的巡检员。巡检员到现场逐项检查，每个项目标记为合格或不合格，不合格的要描述问题。巡检任务完成后自动生成隐患记录，不合格的项目全部变成待整改的隐患。

整改流程是隐患记录生成后自动派发给责任部门，整改时限根据隐患等级确定，一般隐患7天，重大隐患3天，特别重大隐患24小时。整改完成后责任部门上传整改说明，安全巡检员复核通过后隐患关闭。超时未整改的系统自动升级通知安全主管。整改过程中如果需要补充信息，允许责任部门申请变更隐患等级，但要安全主管审批。

审计日志记录所有关键操作，包括巡检任务的创建和完成、隐患的派发和整改、等级变更的审批等。审计日志只追加不修改不删除。特别重大隐患的所有操作记录要能单独导出。

巡检区域要支持层级结构，比如一车间下面有生产线A和生产线B。巡检计划可以选择任意层级的区域，选择父级区域时自动包含所有子区域。多个巡检员同时提交巡检结果，服务端要正确处理并发。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
