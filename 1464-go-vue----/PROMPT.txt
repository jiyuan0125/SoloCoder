帮我用 Go 写一个消防管理系统，大型商业综合体或园区用的，管消防设备、巡检和演练。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

消防设备管理维护所有消防器材的信息，包括设备编号、设备类型（灭火器、消火栓、烟感探测器、喷淋头、应急灯）、安装位置、安装日期、有效期、上次检查日期、设备状态（正常、待检修、报废）。设备到期前30天自动生成待办提醒。同一个安装位置同时只能有一个同类型的正常状态设备，不能重复登记。

巡检模块按计划执行，管理员创建巡检计划，指定巡检路线（一组有序的巡检点位）、巡检人员、频率。系统按频率自动生成巡检任务，巡检员按路线逐个点位检查，检查结果标记为正常或异常。巡检任务完成后自动汇总合格率和异常项。巡检点位按路线定义的顺序打卡，跳序不行。

演练模块管理消防演练活动，管理员创建演练计划包括演练类型（灭火器使用、疏散逃生、综合演练）、演练日期时间、参与人数。演练完成后记录实际参与人数、演练用时和改进建议。每季度至少要有一次综合演练，系统在每季度末检查如果本季度没有综合演练记录生成一条提醒。

调度器负责定时任务，包括每日巡检任务的自动生成、设备到期提醒、季度演练提醒。任务执行失败要重试最多3次，重试间隔递增。设备状态变更多个巡检员同时上报，服务端要正确处理。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
