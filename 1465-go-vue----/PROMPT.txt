帮我用 Go 写一个环境监测系统，工业企业用的，监测废气、废水和固废的排放数据。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

废气监测维护一组排放口的监测数据，每个排放口有编号、位置、监测因子（二氧化硫、氮氧化物、颗粒物、VOCs等）。监测设备定期上报数据，每条记录包含排放口编号、各因子的浓度值、上报时间。系统根据浓度值和排放标准自动判定是否超标，超标的数据生成告警记录。监测设备可能因为故障上报异常数据（比如浓度值为负数或超过合理上限），这类数据要标记为设备故障而不是超标，不影响超标统计。

废水监测类似，监测因子包括COD、氨氮、总磷、pH值等。pH值的判定逻辑和其他因子不同，其他因子是超过某个上限值就超标，pH值是超出6到9的范围就算超标。废水监测数据按日生成排放报表，记录当日各因子的最大值、最小值和平均值，平均值超过排放标准就算当日超标。

固废管理管理固废的产生、贮存和处置记录。每条固废记录包含废物名称、废物类别（危险废物、一般工业固废）、产生量（吨）、贮存位置、处置方式、处置日期。危险废物的贮存期限不能超过一年，超过一年的生成告警。

同一排放口连续超标超过24小时的告警要升级为紧急告警。多个排放口同时上报数据，服务端要正确处理并发写入和告警生成。告警不能重复生成，同一个排放口同一天同一因子只生成一条超标告警。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
