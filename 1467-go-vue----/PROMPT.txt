帮我用 Go 写一个工程项目管理系统，建筑公司用的，管项目进度、成本和质量。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

项目立项时录入基本信息，包括项目编号（自动生成）、项目名称、建设单位、承包单位、合同金额、计划开工日期、计划竣工日期、项目经理。合同金额要精确到分，用整数存储。项目创建后自动生成若干里程碑节点（基础工程、主体结构、装饰装修、竣工验收），每个里程碑有计划完成日期，里程碑的计划完成日期在开工和竣工日期之间且按先后顺序排列。

进度管理记录每个里程碑的实际进度百分比（0到100的整数），项目经理定期更新。某个里程碑的实际完成日期晚于计划日期标记为延期。整体项目进度用加权平均计算，如果某个里程碑还没开始（进度为0），它的延期天数不应该计算在内，只有已经开始但未完成的才标记延期。

成本管理按合同金额和实际支出对比。实际支出记录包含支出类别（人工费、材料费、机械费、管理费）、支出金额、支出日期、凭证编号。各类别的支出总额不能超过该类别的预算，预算按合同金额的一定比例分配（人工费30%、材料费45%、机械费15%、管理费10%）。支出金额涉及精确小数计算用整数分存储，累加时不能有精度丢失。某类别支出超预算的允许继续录入但红色标记。

质量管理记录施工过程中的质量检查，包括检查项目、检查结果、检查人、检查日期。不合格的要生成整改通知，整改完成后复查通过则关闭。一个项目如果质量检查不合格次数超过5次，标记为质量风险项目。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
