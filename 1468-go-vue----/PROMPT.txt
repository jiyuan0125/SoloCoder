帮我用 Go 写一个招标管理系统，企业采购和工程项目招标用的，管发标、投标和开标全流程。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

发标流程由招标专员发起，创建招标项目，填写项目名称、招标内容描述、招标方式（公开招标、邀请招标）、投标截止时间、开标时间。开标时间在投标截止时间之后至少2小时。设定评标办法（最低价法、综合评分法）。如果是邀请招标要指定被邀请的投标供应商列表。项目创建后到发布之间可以修改内容，一旦发布就不可修改。发布前如果修改了投标截止时间，要确保开标时间仍在截止时间之后。

投标模块是供应商使用的，供应商看到自己可以参与的项目列表（公开招标的全部可见，邀请招标的只显示被邀请的）。供应商填写投标文件，包括报价金额（精确到分）、技术方案描述、工期承诺天数。投标截止时间前可以修改投标内容，截止后锁定。报价金额不能为负数且不能为零。综合评分法时系统根据报价和技术方案自动计算综合得分，报价占60%权重技术方案占40%。

开标在开标时间到达后由招标专员操作，系统自动汇总所有有效投标。最低价法选报价最低的，综合评分法选得分最高的。出现报价相同的情况按投标时间先后排序先投的优先。

金额计算全程精确到分，综合评分的报价得分计算公式为最低报价除以该供应商报价乘以100再乘以报价权重。多个供应商同时提交投标，服务端要正确处理并发写入并确保截止时间判断的准确性。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
