帮我用 Go 写一个监理日志系统，工程监理单位用的，管旁站记录、验收和问题跟踪。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

旁站记录是监理人员的日常工作，对关键工序进行全过程旁站监督。每次旁站记录包含工程部位、施工工序、旁站开始和结束时间、施工情况描述、发现问题、旁站监理人员。旁站时长自动计算，时长不足1小时要标记为异常。旁站记录提交后不可修改只能追加补充说明。

验收模块管理各分部分项工程的验收。每次验收记录包含验收部位、验收项目清单、各项目的验收结果、验收结论、验收人员和日期。验收由至少两名监理人员参与，系统要校验参与人数。验收不合格的生成整改通知发送给施工单位，整改完成后申请复查，监理人员重新验收。复查最多三次，三次仍不合格则上报建设单位处理。

问题跟踪模块管理施工过程中发现的质量和安全问题。每个问题有严重程度（一般、严重、重大）、问题描述、发现日期、责任单位、整改要求、计划整改日期。超过计划整改日期未完成的问题自动标记为逾期。重大问题在发现后要立即生成紧急通知到项目经理。

日志收集方面，每个监理人员每天要提交一份监理日志汇总当天的工作。系统自动从当天的旁站记录和验收记录中提取信息填充到日志草稿里，监理人员补充其他内容后提交。日志提交后不可修改。

多个监理人员同时提交验收记录或旁站记录，服务端要正确处理并发。问题跟踪中同一个问题被多个监理人员同时更新状态，要保证数据一致性。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
