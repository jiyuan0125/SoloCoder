帮我用 Go 写一个客运站管理系统，长途汽车站用的，管班次、售票和检票。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

班次管理维护所有客运班次信息，每条班次包含班次号、出发站、到达站、出发时间、到达时间、车型、票价、总座位数、已售座位数。票价精确到元。出发时间格式为HH:MM，系统要校验出发时间早于到达时间。班次状态有未发车、已发车、已到达、已取消。每天凌晨自动把前一天的已到达班次归档，当天的班次根据时刻表自动生成。班次取消时如果已经有乘客购票要自动发起退票流程。

售票模块是核心业务，乘客通过客户端选择出发站、到达站和出发日期查询可用班次。购票时选择座位号，已售出的座位不能选。支持购买多张票最多5张。每张票生成一个票号。购票金额等于票价乘以张数。某个班次的已售座位数达到总座位数的90%自动标记为即将售罄。

检票模块在发车前使用，检票员输入票号进行检票。检票成功后票状态变为已检票。发车时间过后15分钟未检票的自动标记为未乘车，已购票但未检票的记录进入退票待处理队列。

退票规则是发车前2小时退票全额退款，2小时到30分钟退票扣20%手续费，30分钟内和发车后不允许退票。退款金额精确到分。多个售票窗口同时售同一班次的车票，服务端要正确处理并发确保座位不被重复售出。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
