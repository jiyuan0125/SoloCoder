帮我用 Go 写一个出租车调度管理系统，管车辆调度、计价和乘客评价。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

车辆管理维护所有出租车信息，每辆车有车牌号、司机姓名、司机手机号、车辆状态（空闲、载客、预约中、休息、维修中）。车牌号格式校验要支持新能源车牌（8位）和普通车牌（7位）。

调度模块的核心逻辑是乘客叫车后系统自动匹配车辆。乘客输入上车地点和目的地，系统计算预估费用（起步价加里程费加时长费），确认后系统在空闲车辆中按距离从近到远排序自动派单给最近的车辆。司机30秒内没有接单的自动派给下一辆，最多派3次，3次都无人接单则提示暂无可用车辆。同一乘客在有待处理订单时不能再下单，防止重复提交。

计价规则方面，起步价白天13元（含3公里），夜间（23点到次日5点）16元。超过3公里后白天每公里2.3元，夜间每公里2.8元。低速行驶（时速低于12公里）每分钟加收0.4元。计费精确到分，四舍五入。费用超过200元的标记为大额订单。跨天的行程按不同时段分别计费。

评价模块在行程结束后乘客对本次行程评分（1到5星）并可以填写评价内容。评了1星或2星的自动生成一条待处理投诉到客服待办列表。

指标聚合展示今日总单量、平均接单时间（从叫车到司机接单的秒数）、平均行程费用、好评率（4星及以上占比）。平均接单时间的计算要排除无人接单的订单。好评率按最近7天滚动计算。多辆车的状态变更多个调度请求同时到达，服务端要正确处理并发。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
