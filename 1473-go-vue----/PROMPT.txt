帮我用 Go 写一个公交运营管理系统，管线路、站点和车辆实时位置模拟。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

线路管理维护所有公交线路，每条线路有线路编号、线路名称、运营方向（上行和下行是两条不同的线路记录）、首班车时间和末班车时间。每条线路关联一组有序的站点列表，每个站点有站点编号、站点名称、经纬度坐标。站点在上下行方向的顺序可能不同所以要分别维护。首班和末班时间格式为HH:MM，系统要校验首班时间早于末班时间。

站点管理还要记录站点类型（普通站、换乘站、首末站）。换乘站是在多条线路交汇的站点，系统要根据站点名称自动识别哪些站点在多条线路上（站点名称完全相同的视为同一站点）。站点名称比较时要去掉空格后比较，因为有些站点录入时多打了空格。

实时位置模块模拟公交车辆的GPS位置。系统维护一批车辆，每辆车绑定到某条线路上，有当前所在站点序号。调度器每5秒更新一次车辆位置，模拟车辆在站点间行驶。车辆到达站点后停留30秒模拟上下客然后继续向下一站行驶，到达末站后折返。当前时间不在首末班时间范围内的车辆不运行。某个班次的末班时间已过但车辆还没到终点站的车辆继续行驶到终点后停止。

调度器负责车辆位置模拟更新、首末班时间检查、线路运营状态刷新。异常线路（比如某条线路没有可用车辆）要能标记出来。多个客户端同时查询车辆位置数据，服务端要正确返回最新状态。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
