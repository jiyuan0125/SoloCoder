帮我用 Go 写一个共享单车管理系统，管电子围栏、车辆调度和计费。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

电子围栏管理划定单车的停放区域，用多边形（简化为矩形四个经纬度坐标点）表示。每个围栏有名称、类型（推荐停放区、禁停区、调度区）。用户还车时如果车辆位置在禁停区内收取额外调度费5元，在推荐停放区内正常计费，既不在推荐区也不在禁停区的收取2元调度费。判断一个点是否在矩形围栏内简化处理直接比较经纬度范围即可。围栏之间不能重叠，创建新围栏时要检查和已有围栏是否有交叉。

车辆管理维护单车信息，每辆车有车辆编号、当前状态（空闲、使用中、维修中、已报废）、当前位置、当前所在围栏ID。某辆车超过72小时没有被使用过的标记为闲置车辆，在调度列表中优先考虑搬运。

调度模块是运营人员用的，系统自动分析各围栏区域内的车辆分布情况。某个围栏内车辆过多（超过容量的150%）生成调度任务搬运到车辆不足的围栏。某个围栏内车辆不足（低于容量的30%）也生成调度任务。

计费规则是起步价1.5元（含15分钟），之后每15分钟1元，不足15分钟按15分钟计。每天最高收费25元封顶。计费精确到分，使用时长精确到分钟（向下取整到15分钟的倍数）。骑行结束后如果车辆不在合法停放区加上对应的调度费。多辆车同时开始和结束骑行，服务端要正确处理并发计费。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
