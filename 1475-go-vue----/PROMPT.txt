帮我用 Go 写一个停车场管理系统，管车位引导、缴费和月卡。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

车位管理维护停车场内所有车位信息，每个车位有编号、区域、类型（普通车位、充电桩车位、无障碍车位）、状态（空闲、占用、预留、维修中）。车位编号在同一区域内不能重复。预留车位是给月卡用户固定预留的，在月卡用户未到达之前显示为预留状态，到达后自动变为占用。维修中的车位不参与车位引导计算。

车位引导模块展示当前各区域的空闲车位数量。空闲车位数定期刷新。某个区域空闲车位为0的标记为已满。整个停车场的空闲车位低于总数的10%标记为车位紧张。

缴费模块管理临时停车的费用计算。车辆入场时记录入场时间，出场时计算停车时长和费用。计费规则是前30分钟免费，之后每小时4元，不足1小时按1小时计。每天最高收费40元封顶。停车超过24小时的按天累加计算每天40元。跨天计费方面，比如第一天停了20小时第二天停了3小时，应该是40加16等于56元，不是23小时乘以4等于92元。计费金额精确到分。

月卡管理有三种类型，普通月卡300元每月（不固定车位）、固定车位月卡500元每月（绑定指定车位）、充电桩月卡600元每月。月卡购买后从次月1号生效。到期后3天内有宽限期可以续费，超过宽限期月卡失效。宽限期内到期但还没续费的月卡用户仍然可以正常使用。

多个车辆同时入场或出场，服务端要正确处理并发车位状态变更和计费。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
