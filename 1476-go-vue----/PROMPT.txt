帮我用 Go 写一个加油站管理系统，围绕加油站、油品和会员三个核心概念。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

加油站信息包括名称、地址、经纬度坐标、联系电话和营业状态。每个加油站可以配置多种油品，油品有编号、名称（比如92号汽油、95号汽油、98号汽油、0号柴油）、当前单价和库存量。价格要精确到分用整数存储，别用浮点数。库存量以升为单位精确到整数，低于500升时系统自动生成补货待办提醒站长。

会员管理这块，用户注册成为会员后绑定手机号，每次加油可以关联会员卡享受折扣价。会员等级分普通卡（无折扣）、银卡（95折）、金卡（9折），升级条件是累计消费金额达到1000元升银卡，5000元升金卡。会员有积分余额，加油金额每满1元积1分，积分可以在下次加油时抵扣，100积分抵1元。积分抵扣金额不能超过订单总额，抵扣后的实际支付金额如果为负数要按零处理。银卡会员同时使用积分抵扣，折扣和积分抵扣的计算顺序是先算折扣再抵扣积分。

加油记录是核心业务数据，每条记录包含加油站、油品、加油升数、单价、应付金额、会员折扣、实付金额和积分变动。升数要精确到小数点后两位。多个加油枪同时加油扣减同一个油品库存，服务端要正确处理并发确保库存不为负数。

油品价格调整时需要有审批流程，价格提交后进入待审核，审核通过才生效。价格变更历史要完整保留。加油记录支持按日期范围和加油站筛选，导出 CSV。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
