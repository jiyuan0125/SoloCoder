帮我用 Go 写一个充电站预约管理系统，管充电桩的在线预约和充电计费。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

充电站有多个站点，每个站点下有若干充电桩。充电桩有编号、类型（快充120kW、慢充7kW）、当前状态（空闲、充电中、故障、离线）。用户可以查看充电站的桩位实时状态，选择空闲的桩位预约充电时段。预约时段最小粒度是15分钟，两个人的预约时段有重叠哪怕只是差1分钟也不能同时预约同一个桩位。

计费逻辑方面，快充每度电1.2元，慢充每度电0.6元，充电度数精确到小数点后两位。充电开始后记录开始时间和起始电表读数，结束充电时记录结束时间和结束电表读数，实际用电量等于结束读数减去起始读数。用户预约了14:00到15:00但实际15:10才结束充电，超出的10分钟按1.5倍单价计费。充电度数如果计算出来小数点后超过两位要做四舍五入。所有金额用整数分为单位存储和计算。

预约未到场的场景，用户预约了但超过预约开始时间30分钟都没有开始充电，系统自动取消预约并释放桩位。用户已经开始充电但中途暂停，暂停期间不计费但桩位状态显示为暂停中，暂停超过2小时自动结束充电并按已充电量计费。

充电记录展示历史充电的度数、费用、时长等信息，支持按月份汇总统计。多个用户同时预约同一个桩位，服务端要正确处理并发确保时段不冲突。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
