帮我用 Go 写一个 ETC 管理系统，管 ETC 账户、车辆通行记录和自动扣费。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

ETC 账户绑定车牌号和银行卡信息，账户里有一个预存余额。车辆经过高速收费站时系统记录通行信息，包括入口站、出口站、通行时间、行驶里程和应收费用。费用从 ETC 账户余额中自动扣除。

费用计算方面，客车按座位数分四类，一类车7座以下每公里0.4元，二类车8到19座每公里0.5元，三类车20到39座每公里0.6元，四类车40座以上每公里0.7元。计算公式是里程乘以单价，费用要精确到分，四舍五入不能用截断。货车按载重量分五类计费方式类似但单价不同。

余额不足的情况，账户余额低于本次通行费的80%系统仍然放行但要标记为欠费状态。欠费超过30天或者累计欠费超过500元，账户进入黑名单下次通行不放行。用户充值后余额覆盖了欠费金额的账户自动恢复正常。通行费为0的情况（比如节假日免费通行），不应该产生任何扣费记录和欠费标记。

通行记录支持数据导出，可以选择日期范围导出 CSV，CSV 的编码要用 UTF-8 BOM 确保 Excel 直接打开不乱码。导出字段包括车牌号、入口站、出口站、通行日期、里程、费用、扣费状态。多个车辆同时通过不同的收费站，服务端要正确处理并发扣费和余额更新。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
