帮我用 Go 写一个驾校管理系统，涉及学员管理、教练管理和考试预约三大块。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

学员注册时填写姓名、身份证号、手机号和报考车型（C1手动挡、C2自动挡、A1大巴、B2中巴）。每个学员的学习进度分为科目一到科目四，每个科目有未开始、学习中、已通过三个状态。学员按顺序通过前一科目才能预约下一科目的考试。

教练信息包含姓名、准教车型、联系电话和当前学员数。每个教练最多同时带8个学员。教练的排班按周来设置，每周设置可用时间段。学员预约练车时选择教练和时间段，系统检查教练在该时段是否有空闲。教练当天已有预约且预约之间间隔不足30分钟的，系统不允许插入新的预约，要给教练留出休息和准备时间。

考试预约是核心功能。管理员录入下周的考试计划，包含日期、科目、考场地址和名额。学员在自己通过的上一科目后可以预约下一场考试，但需要满足学习时长要求：C1车型科目二至少练满24学时，科目三至少练满16学时。预约时系统检查学时要求和该场次名额。名额已满学员可以进入候补队列，前面有人取消时按候补顺序自动递补。

学员取消考试预约后释放的名额要先分配给候补队列里排第一的人，而不是直接回到可用池。候补学员收到递补通知后24小时内不确认则视为放弃，名额继续顺延。学员取消预约时距离考试不足3天的取消操作需要管理员审批。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
