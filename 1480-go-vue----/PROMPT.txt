帮我用 Go 写一个车辆年检预约系统，车主在线预约车辆年检，检测站管理检测流程，最后出具检测报告。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

车辆信息录入车牌号、车辆类型（小型轿车、SUV、MPV、货车、客车）、注册日期和上次检测日期。根据车型和使用年限有不同的检测周期：新车6年内免上线检测（每两年领一次检验标志），超过6年的每年检测一次，超过15年的每半年检测一次。预约时系统自动判断车辆是否在应检期内，距上次检测还没到周期的不允许预约。

检测站有多个工位，每个工位同一时间只能检测一辆车。管理员为检测站配置每日可预约的时间段和每个时段的最大车辆数。车主选择检测日期和时段进行预约。

检测流程按待办事项来管理。车辆到站后先做外观检查，通过后进入尾气检测，通过后进入安全性能检测，通过后进入底盘检测。每一步检测都有结果：合格、不合格、需复检。某个环节不合格的记录不合格项目和原因，车辆维修后重新检测不合格的项目不需要全部重做。复检时只收费50%的检测费。

检测费用根据车型不同：小型车180元，SUV 200元，货车350元，客车400元。复检费用是原费用的一半，同一辆车同一次年检中多次复检，从第二次复检开始免费。也就是说第一次复检收90元（小型车），第二次和之后都不收费了。费用计算用整数分避免浮点问题。

车牌号要验证格式，预约日期不能是过去的时间。多个车主同时预约同一个时段，服务端要正确处理并发确保不超额。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
