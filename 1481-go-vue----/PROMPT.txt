帮我用 Go 写一个二手车评估系统，给二手车商用来管理车源、评估车况和给出估价。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

车辆信息包括品牌、型号、年份、颜色、行驶里程（万公里精确到一位小数）、排量、变速箱类型。评估师录入车况信息时有多个维度：外观（五星评分）、内饰（五星评分）、发动机（五星评分）、底盘（五星评分）。每个维度的评分影响最终的评估价格。

估价算法先查同品牌同型号同年份的参考价，然后根据里程和车况做调整。里程超过10万公里每增加1万公里扣减参考价的1%，里程不足5万公里的加2%。车况评分方面，四个维度平均分高于4分的加价5%，低于3分的扣减10%，3到4分之间不调整。最终评估价精确到百元，比如计算出来87453元要显示为87500元。

同车多次评估的情况，一辆车可能被不同评估师在不同时间评估多次，系统保留所有历史评估记录。两次评估间隔不超过7天且车况描述完全相同的，系统提示可能存在重复评估。每次评估生成一个唯一的评估报告编号，格式是PG加年月日加四位序号。

过户管理这块，车辆状态分为在库、已预订、已售出三种。客户支付定金后车辆状态变为已预订，定金金额默认为评估价的5%最低500元最高10000元。客户最终没有完成交易的定金不退。全款付清后状态变为已售出生成过户记录。

多个评估师同时对同一辆车做评估，服务端要正确处理。金额全部用整数分存储。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
