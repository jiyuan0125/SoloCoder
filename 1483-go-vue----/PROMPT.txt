帮我用 Go 写一个保险理赔管理系统，核心流程是查勘、定损和赔付三个阶段。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

被保险人出险后提交理赔申请，填写保单号、出险时间、出险地点、事故类型（交通事故、自然灾害、盗窃、玻璃单独破碎、划痕）、事故描述和预估损失金额。提交后生成一个理赔案件编号，格式为CL加年月日加六位序号。

查勘阶段由查勘员完成。管理员将案件分配给查勘员，查勘员填写查勘报告包括事故原因分析、责任认定（全责、主责、同责、次责、无责）、受损部位描述。出险时间距报案时间超过48小时且没有合理理由的，理赔金额最高只能赔付标准额的70%。

定损阶段由定损员评估具体损失金额。定损员对每个受损项目录入项目名称、维修或更换方式、定损金额。所有项目金额之和为总定损金额。定损金额不能超过保单的保额上限，超过的按保额上限处理。

赔付阶段，系统根据定损金额和责任比例计算实际赔付。全责赔付100%，主责赔付70%，同责赔付50%，次责赔付30%，无责不赔付。同一保单在一年内出险超过3次的，第四次起每次赔付标准额下调20%。赔付款精确到元，四舍五入。

理赔案件有多种状态，每个状态变更要记录操作人和时间。案件在任何阶段查勘员或定损员认为属于骗保嫌疑的，可以提交审核标记进入人工复核流程。多个查勘员或定损员同时操作同一个案件，服务端要保证状态流转的一致性。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
