帮我用 Go 写一个冷链物流监控系统，监控冷链运输车上的温度、湿度和 GPS 轨迹。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

每个冷链运输车上装了一组传感器设备，设备每隔5分钟上传一次数据，包括设备编号、时间戳、车厢温度（精确到0.1度）、车厢湿度（精确到0.1%）、GPS经纬度和车速。一条运输线路从发货仓库到收货仓库可能持续几小时到几天不等。

每批货物有不同的温湿度要求。管理员创建运输任务时选择货物类型（冷冻食品零下18度以下、冷藏食品0到4度、恒温药品15到25度、常温物品不监控），系统根据货物类型自动设定温度和湿度的安全上下限。温度超过上限或低于下限都算异常。

指标聚合方面，系统需要计算每条运输任务在整个运输过程中的温度合格率。合格率等于温度在安全范围内的采样点数除以总采样点数。合格率低于95%的该运输任务的货物到达后需要进行质量复检。此外还要计算运输过程中的温度最大值、最小值、平均值和标准差，这些数据要能导出为 CSV 报告。

告警机制方面，某个采样点的温度超出安全范围时系统立即生成一条温控告警。连续3个采样点（即15分钟内）都超出范围的，告警升级为严重级别。运输任务结束后自动生成一份运输报告，包含告警记录列表和合格率统计。

同一辆车的传感器同时上报温度和湿度数据，服务端要正确处理并发。告警不能重复生成，同一个运输任务同一时间点只生成一条告警。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
