帮我用 Go 写一个搬家服务平台的管理系统，客户预约搬家服务，平台根据物品和距离给出估价，搬完后结算。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

预约流程是客户填写搬家日期、起始地址和目标地址，然后勾选需要搬运的物品清单。物品分大类：家具（沙发、床、衣柜等，每件标记尺寸大中小）、家电（冰箱、洗衣机、空调等，标注是否需要拆装）、杂物（纸箱数量）、其他（钢琴、鱼缸等特殊物品单独标注）。系统根据物品总体积和两地距离给出估价。

估价算法是基础费用加距离费用加特殊物品附加费。基础费用包含一辆标准搬家车和两名搬运工起步价280元。距离费用按公里数阶梯计算：10公里内免费，10到30公里每公里5元，超过30公里每公里8元。距离按两地直线距离乘以1.4作为实际行驶里程。特殊物品附加费方面钢琴加200元，需要拆装的家电每件加50元。估价精确到元。实际结算时搬运过程中增加了物品或更改了地址按实际重新计算。

预约时间有冲突检查逻辑。每天每辆车最多接3单分三个时段（8:00到12:00、13:00到17:00、17:00到20:00），系统检查当天该时间段是否还有可用车辆。客户取消预约但距离搬家时间不足24小时的要支付估价金额的30%作为违约金最低50元。

搬完家后客户确认收货并可以给服务评分（1到5星）和留言评价。金额计算全部用整数分为单位。多个客户同时预约同一时段，服务端要正确处理并发确保车辆不被超额分配。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
