帮我用 Go 写一个开锁换锁服务平台，用户预约开锁师傅上门服务，管工单流转和支付结算。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

用户提交开锁请求，填写地址、门锁类型（防盗门锁、室内门锁、密码锁、指纹锁、汽车锁）和紧急程度（普通、加急）。平台根据地址和门锁类型分配最近且具备相应资质的师傅。师傅信息包含姓名、手机号、服务区域、可开的锁类型和当前状态（空闲、在途、服务中）。

预约时间段方面，师傅每天的工作时间分三个时段：上午8:00到12:00、下午13:00到17:00、晚间17:00到21:00。用户选择期望的服务时段，系统检查该时段该师傅是否有空闲。加急订单不受时段限制直接分配最近的空闲师傅。普通预约选定时段没有空闲师傅的系统推荐其他时段或其他师傅。

工单状态有五个阶段：待接单、已接单、服务中、待支付、已完成。工单详情需要记录是否需要换锁、换锁的品牌和型号、锁芯等级、配件费用和人工费用。开锁服务费按锁类型不同：防盗门开锁150元，室内门80元，密码锁200元，指纹锁250元，汽车锁300元。换锁配件费按实际锁的价格计算另收50元安装费。加急服务在标准费用基础上加收50%的加急费。

支付完成后客户可以对服务进行评价，评分低于3星系统自动生成一条投诉待办给客服。

多个加急订单同时到达，服务端要正确处理并发确保同一个师傅不被重复分配。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
