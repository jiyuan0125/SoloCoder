帮我用 Go 写一个虫害防治管理系统，管客户的虫害防治合同、定期巡检、消杀作业和效果记录。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

客户合同管理记录每个服务客户的基本信息：客户名称、地址、场所类型（餐饮店、食品工厂、办公楼、医院、学校）、面积、防治虫害种类（老鼠、蟑螂、蚊蝇、蚂蚁、白蚁）。不同场所的防治标准和频次不同。餐饮店每月消杀两次，食品工厂每月一次全面消杀加每周一次鼠患巡查，办公楼每季度一次。合同中约定每次服务的费用和年度总价。

巡检是日常工作。消杀人员按合同约定的频次到客户现场巡检，检查各个防治点的虫害情况。每个防治点有编号和位置描述，消杀人员检查后记录发现虫害的种类和数量、防治点的设施状态。巡检结果分为正常、轻微、严重三个等级。严重的需要安排额外消杀作业。

消杀作业管理是核心业务流程。每次消杀作业创建一张工单，包含作业日期、客户、作业范围、使用的药剂名称和用量、作业人员。药剂管理有库存控制，工单创建时扣减药剂库存，库存低于安全线时生成采购待办。药剂用量要精确到毫升或克，费用按单价乘以用量计算。

作业效果跟踪通过后续巡检来评估。消杀作业后下一次巡检时对比上次同类巡检的虫害数据，虫害数量下降超过50%认为防治有效，下降不足20%需要调整方案重新消杀。

每个消杀人员每天最多安排4个作业点。系统根据合同到期日和上次服务日期自动生成待服务的作业清单按到期先后排序。多个消杀人员同时提交工单消耗同一种药剂，服务端要正确处理并发库存扣减。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
