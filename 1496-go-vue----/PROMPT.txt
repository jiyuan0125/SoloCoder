帮我用 Go 写一个废品回收管理平台，管废品分类、称重记录、价格结算和数据导出。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

废品分类管理是基础数据。系统预设废品大类：废纸类（报纸、杂志、纸箱、办公用纸）、塑料类（PET瓶、HDPE容器、塑料薄膜）、金属类（废铁、废铜、废铝、不锈钢）、玻璃类（透明玻璃、有色玻璃）、电子废弃物（旧手机、旧电脑、电池）。每个子类有一个基准回收单价单位是元每公斤。管理员可以调整单价，调整后新的交易按新价格结算，历史交易不受影响。

回收流程是居民或商户把废品送到回收站，工作人员先分类再称重。每笔回收记录包含日期时间、客户信息、废品分类、重量（精确到0.01公斤）和单价。结算金额等于重量乘以单价精确到分，四舍五入。比如纸箱5.23公斤每公斤1.20元，金额5.23乘1.20等于6.276元四舍五入为6.28元。

大宗回收的特殊计价方面，单笔回收中某一类废品的重量超过100公斤的，超出部分的单价上浮10%。比如废铁150公斤每公斤3.00元，前100公斤300元，后50公斤按3.30元计算165元，总共465元。

结算方式分当场结算和月结。当场结算直接支付。月结客户每月底统一结算，当月累计回收金额超过5000元的给予3%的返利，返利金额加到下月余额中。

数据导出可以按日期范围、废品分类导出回收明细 CSV，也可以按月导出汇总统计。汇总统计包含每个废品类别的回收总重量和总金额以及环比上月的变化百分比。CSV 使用 UTF-8 BOM 编码确保 Excel 打开不乱码。多笔回收记录同时录入，服务端要正确处理并发。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
