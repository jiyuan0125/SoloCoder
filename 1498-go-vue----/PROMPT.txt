帮我用 Go 写一个家政人员培训管理平台，管培训课程、学员考证和就业推荐。核心功能做成一个独立的 package，服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。

课程管理分初级和高级两个层次。初级课程包括家政基础知识、清洁技能、烹饪技能、安全常识四门课。高级课程包括母婴护理、老人护理、营养配餐、急救知识四门课。每门课程有名称、课时数、讲师、学费（精确到元）和最大班容量。课程有开班计划，每个班有开始日期、上课时间和教室。

学员管理记录学员的基本信息：姓名、身份证号、手机号、学历、报名日期。学员可以同时报名多门课程但同一天的课程时间不能冲突，系统在学员报名时自动检查时间冲突。学员每门课程有一个出勤记录，每次上课签到或请假。出勤率低于80%的学员不能参加该课程的结业考试。

考证管理跟课程绑定。每门课程结束后组织结业考试，考试有笔试和实操两部分各占50分总分100分。60分及格及格后颁发电子证书。证书有唯一编号格式是HZ加年月加四位序号。学员可以补考一次，补考费用是原学费的10%最低50元。补考仍不及格的需要重新报名该课程。

就业推荐是待办流程。学员取得证书后进入就业推荐池，合作雇主发布岗位需求（需求岗位、要求证书类型、薪资范围、工作地点）。系统根据学员的证书匹配岗位生成推荐待办给就业顾问。就业顾问联系雇主和学员安排面试记录结果。

学员可以分两次付清学费，首次50%报名时付剩余50%课程过半后付。学员中途退课的已上课程按比例扣除费用后退还剩余部分，但已参加考试的不退费。退费金额精确到元。多个学员同时报名同一门课程的同一个班级，服务端要正确处理并发确保不超额。

核心功能实现为一个独立 package。在此基础上写两个程序：服务端引用核心库对外提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。服务端和客户端各自独立 main 包，请求响应格式定义放在公共包。核心库、服务端、客户端各按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。服务端的监听端口应该支持通过命令行参数或环境变量来指定。
