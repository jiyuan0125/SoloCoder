帮农场做一套大棚管理的后端服务，FastAPI 写接口，配命令行客户端。

系统管理一批温室大棚，每个大棚有编号、面积、种植的作物名称和大棚类型（玻璃或塑料）。大棚的环境数据定时上报，包括温度、湿度、土壤湿度和光照。管理员可以为每个大棚设置灌溉和施肥计划，计划里有执行时间、用量这些字段。系统有个调度器，到时间自动把计划状态改为已执行，如果计划时间已经过了也要能补执行。

环境数据可以做聚合查询，选一个大棚和时间段，系统返回某个指标的最大值、最小值和平均值。

同一个大棚在同一分钟内有多个灌溉计划的，只执行最早创建的那个。环境数据同一秒重复上报的用最新一条覆盖。施肥用量不能为零。灌溉计划的时间设成过去的时间表示立刻执行。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
