我们农业科技公司在做一个智慧大棚管理系统，需要你帮忙搭建前后端。后端用 Go，前端用 Vue。数据量不大，全部放内存里就行。

系统管理的核心是农场里的一批温室大棚。每个大棚有编号、面积（平方米）、当前种植的作物名称、大棚类型（玻璃温室或塑料大棚）。系统要能记录大棚的环境数据，包括空气温度、空气湿度、土壤湿度、光照强度这四个指标，这些数据是定时从传感器上报的，每次上报带上大棚编号和时间戳。前端有一个总览仪表盘页面，展示所有大棚的最新环境数据，当某个指标超出预设的安全范围时要在页面上高亮警告，用红色边框标识异常指标。管理员可以为每个大棚单独设置灌溉和施肥计划。灌溉计划包含计划名称、执行时间、持续分钟数、用水量（升）。施肥计划类似，多了肥料种类（氮肥、磷肥、钾肥、复合肥）和用量字段（公斤）。系统内部有一个调度器，到了计划执行时间自动把任务状态改为执行中，执行完毕后改为已完成。如果计划执行时间已经过了但状态还是待执行，调度器也要能处理这种补执行的情况。前端需要展示所有计划的执行状态列表，可以按大棚筛选查看。

环境数据还有一个指标聚合的需求。前端可以选一个时间范围，比如最近24小时或最近7天，查看某个大棚某个指标的最大值、最小值和平均值。后端要把内存中所有上报的时序数据点做聚合计算再返回给前端展示。管理员还能查看某个大棚的指标变化趋势，系统返回选定时间段内所有数据点。

这边有几个业务细节你一下。灌溉计划和施肥计划的时间可以设成过去的时间，表示立刻执行，调度器判断发现是过去时间就应该马上触发。如果同一个大棚在同一分钟内有多个灌溉计划，只执行优先级最高的那一个，优先级由创建时间决定，先创建的优先。环境数据上报时如果同一个传感器同一秒内重复上报，用最新一条覆盖旧数据就行，不要存重复记录，避免内存浪费。指标聚合时如果选的时间范围内没有任何数据点，不要返回空值，返回一条说明该时段无数据的提示信息，前端友好展示。施肥计划中如果肥料种类不在预设列表中（氮肥磷肥钾肥复合肥），按自定义肥料处理，但用量不能为零。

项目结构方面，Go 后端建议用标准库 net/http 起服务，数据全部放内存里用 map 和 slice 管理，不接数据库。前端 Vue 用单页面应用，可以用 CDN 引入 Vue，不用搭脚手架。前后端通过 JSON API 通信。
