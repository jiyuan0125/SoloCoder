给水产养殖合作社做一套后端管理系统，FastAPI 加命令行客户端。

系统管理多个养殖池塘，每个池塘有编号、面积、养殖品种和放苗数量。水质监测数据定时上报，包括水温、溶解氧、PH值和氨氮浓度。每个指标可以设上下限阈值，超了自动标记异常。溶解氧低于2mg/L是安全底线，不管有没有设阈值都要标红。

投喂管理这块，管理员给每个池塘设投喂计划，到了投喂时间调度器自动生成投喂记录。捕捞管理记录每次捕捞的品种、数量和重量，捕捞后自动扣减存塘量。水质数据可以做聚合查询，选时间段返回指标的最大最小平均值。

投喂计划如果时间是当天已经过去的时间点就不执行了。存塘量扣减时如果不足本次捕捞数量就不让创建捕捞记录。同一池塘同一天只能有一条投喂计划生效，新的覆盖旧的。投喂量零或负数的拒绝保存。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
