帮林业局做一套林火巡护管理的后端服务，FastAPI 写接口，命令行客户端调。

系统管理林场的管护区域，每个区域有名称、面积、主要树种和负责的护林员。管理员给护林员派发巡护任务，指定巡护日期和路线关键点。巡护完成后提交报告，记录实际路线和发现的异常。异常分两类，病虫害记录类型和严重程度，火险隐患记录类型和处理状态。提交的异常自动生成待办，分配给区域管理员跟进。

病虫害数据按月做聚合统计，展示每月新发现数量、涉及树木数和重度占比。还有区域健康度看板，根据异常数量和严重程度打分。

巡护任务日期不能是过去的日期。巡护报告路线点数量不能少于任务要求点数的一半，少于的标为不合格。同一个位置7天内的重复异常要标注为重复上报。待办超过14天未处理标为逾期。火险隐患优先级高于病虫害。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
