帮养殖场做一套数字化管理的后端服务，FastAPI 接口加命令行客户端。

系统管理多个养殖批次，每个批次有品种、入栏数量、当前存栏数和状态。繁育管理记录配种信息，不同品种妊娠周期不同，系统根据品种自动算预产日期。防疫管理记录疫苗接种情况。出栏统计记录每次出栏的数量、体重和单价，自动更新存栏数。有个指标看板展示总存栏、本月入栏出栏和品种占比。

预产期临近提前7天自动生成待办提醒，疫苗接种超过间隔天数的也自动提醒。配种后没成功产仔的可以录入失败记录，记录失败原因，然后可以重新配种。

存栏数不能为负，出栏数超过存栏的拒绝操作。同一头母畜同一天不能重复配种。出栏单价为零或负数的不参与产值计算。批次清空后不能新增配种和出栏记录。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
