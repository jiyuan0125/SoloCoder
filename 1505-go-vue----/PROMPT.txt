帮食品加工厂做一套生产管理的后端服务，FastAPI 加命令行客户端。

配方管理是基础，每个配方有名称、产品类别和原材料清单，清单里每项有材料名称、用量和是否关键原料。每种原材料可以设安全库存量，低于就提醒补货。批次管理记录每批生产的配方、计划数量、实际数量和质检结果。质检不合格的批次自动生成待办通知品控主管处理，主管选返工、降级或报废。

数据导出功能，选日期范围导出批次汇总，以纯文本表格形式返回。配方原材料清单至少两条。实际成品数量不能超过计划的110%。检测数值为空但结果填合格的是矛盾数据要拒绝。已有合格质检的批次不能再加新质检记录。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
