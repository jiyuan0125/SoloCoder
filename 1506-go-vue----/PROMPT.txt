帮连锁餐饮品牌做一套后厨管理的后端服务，FastAPI 加命令行客户端。

系统管理多个门店，每个门店维护食材库存表，记录食材名称、库存量、单价和保质期。门店可以提交采购申请，审批通过后采购员录入到货数量，到货后自动加库存。每天后厨登记食材损耗，损耗自动扣库存。库存低于安全库存线的自动标红提醒。

指标聚合功能，选门店和时间范围，返回采购总金额、损耗总金额和损耗率。损耗率超过5%的标红。还可以看各门店损耗率排名。

采购期望到货日期不能是过去的。到货数量为零不让保存。损耗数量大于当前库存的只扣到零并标注实际扣减量。同种食材同一天只出一条低库存警告。安全库存线设为零或负数的按无效处理。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
