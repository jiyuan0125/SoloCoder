帮外卖平台做一套配送调度的后端服务，FastAPI 加命令行客户端。

系统管理一批骑手，每个骑手有编号和当前状态（空闲、配送中、休息中）。商家下单生成订单后进入待接单状态。调度器扫描待接单订单按下单时间排序，给空闲骑手分配。骑手接单后变配送中，送达后确认完成。订单预计送达时间是下单时间加30分钟，超时未完成自动标为超时。骑手连续10分钟没更新位置就标为离线，他手上的订单要重新分配。

指标看板实时展示在线骑手数、待接单数、配送中订单数、今日完成数、平均配送时长和超时率。

同一个骑手同时只能有一单配送中。预计送达时间从下单开始算不是从接单开始算。骑手恢复在线后未完成订单需要管理员手动重新分配。所有骑手都在忙的新订单留在队列里等。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
