帮生鲜电商平台做一套冷链物流后端服务，FastAPI 加命令行客户端。

系统管理多个产地和一批冷藏车，每辆车有编号、当前温度、载重上限和当前载重。配送任务关联订单，调度器根据距离和温度要求分配冷藏车。车辆出发后定时上报位置和车厢温度。

数据导出功能，选日期范围导出配送记录，纯文本表格格式返回。

调度分配时当前载重加新任务重量超过上限的不能分配这辆车。车厢温度超出任务要求的标记异常但不自动中断配送。同一辆车不能同时被分两个温度要求冲突的任务。配送任务24小时没温度上报标记为通讯中断。配送完成后自动释放载重。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
