帮食品安全做一套溯源管理的后端服务，FastAPI 加命令行客户端。

供应链管理记录食品从原料到成品的完整流转过程，每条记录有批次号、环节类型、操作时间和操作人。前端按批次号查完整流转时间线。检测管理记录每批次的质检信息。召回管理是应急功能，发起召回后系统根据供应链记录自动追踪环节，生成待办通知负责人确认处理情况。

数据导出功能，按批次号导出完整溯源链，从原料到上架的所有环节和检测报告，纯文本格式。

同一个批次号不能同时有进行中的召回和新的检测记录。供应链操作时间不能是未来的时间。待办超过7天未处理标为逾期。召回范围为空的仍然允许创建但标记为无法追踪。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
