| User Prompt | 帮我用纯 C 写一个聊天室的消息分发模块。我们正在做一个内部沟通工具，里面有多个聊天频道，比如「技术讨论」「闲聊」「公告」之类的，每个频道独立运行。用户可以加入任意多个频道，加入之后就能收到别人发到这个频道的消息。关键要求：频道 A 的消息绝不能跑到频道 B 去，必须严格隔离，即使两个频道名字很像也不能混淆。新人加入频道后只能看到后续发的消息，看不到加入之前的历史记录。如果某个频道一个人都没有了，这时候有人往里发消息就直接丢弃，不存不转，不占内存。另外用户退出一个频道后，不能再收到这个频道的消息，要立即生效。一个人如果同时加了五个频道，五个频道的消息都要实时收到，不能丢任何一条。还要考虑一个场景：用户在频道里发消息的时候刚好有新用户加入，这条消息新用户应该能收到还是收不到？需要明确定义这个行为并保持一致。支持动态创建和销毁频道，频道名字不能重复。销毁频道的时候要把里面的所有人都通知一下然后清理。整个模块要考虑多线程环境下的安全性——用户加入退出和发消息可能同时发生。用纯 C 写，不依赖第三方库，gcc 编译通过，Linux 上能跑。这个模块是整个聊天系统的核心，质量要求很高，不能有内存泄漏。整个实现要干净利落，代码结构清晰。 代码拆成至少 4 个源文件：频道管理、消息收发、用户订阅管理，各自有头文件和实现文件，加一个 main 做演示。gcc 编译能过。 |
