帮酒庄做一套内部管理的后端服务，FastAPI 加命令行客户端。

葡萄管理记录每个地块的信息，包括品种和种植年份。采收时录入采收记录，包括采收量、糖度和酸度。酿造管理记录每批酒的酿造信息，关联葡萄来源地块。发酵完成后进入窖藏，记录窖藏位置和预计陈酿时长。窖藏管理要看每个酒窖货架占用情况。

窖藏到期时自动生成待办提醒酿酒师品鉴，品鉴后决定继续陈酿或装瓶。继续陈酿的就更新时长重新计算到期日。

酿造批次用的葡萄采收量不能超过地块实际采收量。同一个窖藏位置同一时间只能放一批酒。采收糖度和酸度为正数才接受。发酵结束日期不能早于开始日期。装瓶后从窖藏移出释放位置。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
