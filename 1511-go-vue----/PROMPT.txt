帮茶叶加工厂做一套从采摘到分级的管理后端，FastAPI 加命令行客户端。

系统管理茶园地块信息。采摘季管理员录采摘计划，采摘完成后录实际采摘量和鲜叶等级。鲜叶进加工环节后跟踪炒制过程，每批关联来源地块，记录投叶量和成品量。炒制完成后进行等级评定，等级分特级到三级，记录感官描述。

调度器根据采摘计划提前一天生成待办提醒加工车间准备。采摘完成后鲜叶24小时内必须开始加工，超过的生成紧急告警。

采摘计划日期不能是过去的。成品量不能超过投叶量的40%，鲜叶到成品大概4比1的出成率。同一批鲜叶不能重复创建炒制批次。评级等级或感官描述为空的不让保存。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
