帮粮油仓储公司做一套库存管理后端，FastAPI 加命令行客户端。

系统管理多个仓库和库区，每个库区有类型和容量上限。粮油入库记录品种、数量和来源，出库记录去向和用途。温控管理接收各库区温度上报，超范围标红告警。虫害管理记录检查结果。出库遵循先进先出，系统优先推荐入库最早的批次。安全保管期限不同品种不同，到期提醒出库。

指标聚合展示总库存、品种占比、虫害检出率和温控达标率。

入库时库区容量不足就拒绝。出库数量不能超过批次剩余量。虫害密度超每公斤10头的自动生成待办。温度数据同库区同一分钟多次上报只保留最新一条。品种不在预设列表的默认保管期按1年算。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
