帮中药材种植基地做一套GAP规范的生产管理后端，FastAPI 加命令行客户端。

系统管理种植地块，记录品种和种植日期。GAP要求记录所有农事操作，包括施肥、用药和灌溉。采收管理在药材达标后进行，采收后进入加工环节。数据导出功能按批次输出从种植到加工的全过程记录，包括所有农事操作，纯文本格式用于合规材料提交。

待办有两类，一是用药安全间隔期提醒，采收日期早于间隔期结束的阻止操作。二是GAP年检待办，每个地块每年一次合规检查，种植周年日前30天生成提醒。

采收计划日期不能早于预计采收日期前15天。加工成品量不能超过投料量的80%。用药后安全间隔期内不允许采收。同一地块同一时间只能有一个进行中的采收任务。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
