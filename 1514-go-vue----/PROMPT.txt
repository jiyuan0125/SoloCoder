帮宠物医院做一套门诊管理的后端服务，FastAPI 加命令行客户端。

宠物档案管理记录基本信息。挂号模块登记就诊，挂号后进入候诊队列。医生接诊后记录诊断结果、处方和处置措施，诊疗完成自动生成费用明细。疫苗管理记录接种历史和时间线。预约管理设置医生工作时段，主人选时段预约。

用药疗程如果是多天的，每天生成待办提醒主人按时给药。

挂号时该宠物当天已有候诊中的挂号就不让重复挂。药品单价为零的条目不参与费用计算但仍记录。预约时段满了的新预约进候补队列。疫苗接种下次日期不能早于本次日期。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
