帮宠物寄养中心做一套管理的后端服务，FastAPI 加命令行客户端。

系统管理笼位资源，按区域划分，每个笼位有状态（空闲、占用、清洁中、维修中）。入住登记记录宠物信息和寄养时间，选空闲笼位。寄养期间每天记录喂养日志和健康数据。退房时结账，费用是每天基础费乘实际天数加上服务费，不足一天按一天算。

喂养日志记录了异常症状的自动生成待办通知兽医检查。

入住必须选空闲状态的笼位。预计离开日期不能早于开始日期。超过预计日期3天没退房的自动标为逾期。喂养日志精神状态和排便都为空不让保存。同一笼位同一时段不能重叠。维修中的笼位不能分配。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
