帮宠物美容店做一套预约管理的后端服务，FastAPI 加命令行客户端。

系统管理服务项目（洗澡、剪毛、造型等），每个项目有名称、时长和价格。美容师管理记录擅长项目和工作状态。预约管理按时间段安排，客户选项目和美容师后看可用时段。服务完成后记录实际用时，超时50%以上的标记。服务后客户可以评价。耗材管理记录库存，低于最低库存线生成采购待办，每次服务完自动扣减。

同一客户同一宠物同一天不能预约相同服务两次。评价只能在实际服务完成后提交。美容师所有时段约满了的新预约进候补。预约取消后时段立即释放。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
