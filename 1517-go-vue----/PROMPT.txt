帮动物救助站做一套管理的后端服务，FastAPI 加命令行客户端。

系统管理救助动物档案，记录物种、品种、健康状态和收容笼舍。领养管理是核心，有意向的人提交申请，审核通过后安排面谈，面谈通过后办理领养。领养后第7天、30天、90天自动生成回访待办。捐赠管理记录捐赠信息，资金捐赠累计统计。预约管理安排面谈时段。

同一只动物同一时间只能有一个进行中的领养申请，其他的排队。有不良记录的领养人新申请需要额外审批。回访超期7天未完成标为逾期。捐赠金额为零或负的拒绝。隔离观察的动物不让发起领养。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
