帮农村兽医站做一套巡诊管理的后端服务，FastAPI 加命令行客户端。

系统管理养殖户信息，包括养殖类型和规模。调度器根据地址和上次巡诊时间自动排序生成巡诊路线，兽医可以手动调整。巡诊中记录病例信息，包括用药方案。用药量累计消耗用于库存管理。用药疗程期间每天生成待办提醒关注效果。

指标看板展示本月巡诊次数、覆盖户数、新增病例数和药品消耗排名。

巡诊路线中同一养殖户不能出现两次。疗程天数最少1天。没发现异常的养殖户也要记录一条无异常巡诊记录。药品消耗在用药方案保存时就预扣减。同一养殖户同一天只能一条巡诊记录。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
