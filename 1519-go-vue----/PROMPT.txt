帮饲料加工厂做一套从配方到出库的管理后端，FastAPI 加命令行客户端。

配方管理是起点，每个配方有原材料清单，所有材料占比加起来要等于100%。批次生产关联配方，记录计划产量和实际产量。质检不合格的批次生成待办通知品控主管决定返工、降级还是报废。数据导出选日期范围以纯文本表格形式返回生产批次汇总。

配方原材料清单至少两条。实际产量不能超过计划的105%。同一批次已有合格质检的不让再加新质检。待办超过3天未处理标为逾期。导出跨度超过90天的按月分段。配方停用时有进行中批次关联的不让停。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
