帮水产种苗场做一套繁育和销售管理的后端，FastAPI 加命令行客户端。

系统管理繁育池，记录水体类型和水温。繁育管理记录每次繁育活动，包括产卵、孵化和出苗信息。销售管理记录种苗销售和配送信息。调度器协调生产销售节奏，库存不足时提醒繁育部门安排新一轮。繁育池水温超出品种适宜范围的自动生成待办。

出苗日期不能早于产卵日期。销售数量大于当前库存的只允许部分销售并提示不足。同一车辆同一时间只能执行一个配送任务。水温连续3次上报超范围待办优先级升级为紧急。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
