帮矿山企业做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理多个矿区，记录开采矿种和年产能。采矿作业记录每天的采矿活动，包括计划产量和实际产量。运输管理记录每趟运输的车次和运输量。安全管理记录安全检查，发现隐患生成待办指定整改责任人和期限，超期未完成自动升级。

指标聚合展示本月总产量、产量完成率、运输趟次、平均运输时长、安全检查次数和隐患整改率。

实际产量不能超过计划的120%。运输到达时间不能早于出发时间。安全检查任何一项异常整条记录标为不合格。待办整改期限不能超过30天。同一矿区同一天只能一条采矿作业记录。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
