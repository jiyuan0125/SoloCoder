帮地质勘探公司做一套项目管理的后端，FastAPI 加命令行客户端。

系统管理勘探项目，记录勘探区域和矿种目标。钻孔管理记录钻孔信息和坐标。采样管理在钻孔过程中取样，送到实验室后录入分析结果。项目临近结束仍有未完成钻孔的生成待办提醒。数据导出按钻孔输出从孔口到孔底的岩性和分析结果，纯文本按深度排序。

钻孔实际孔深不能超过设计的110%。采样深度范围不能重叠。元素含量不能为负数。项目进行中不允许把预计结束日期改成过去的。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
