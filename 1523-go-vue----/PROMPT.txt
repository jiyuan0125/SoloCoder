帮选矿厂做一套工艺管理的后端，FastAPI 加命令行客户端。

系统管理破碎和浮选工段数据。破碎记录破碎前后粒度和处理量。浮选记录原矿品位、精矿品位、尾矿品位和回收率。设备管理记录运行状态和累计运行小时数。品位计算模块输入参数后算出理论精矿产量和回收率。指标聚合展示日处理量、平均回收率和设备利用率。

精矿品位不能低于原矿品位否则拒绝保存。回收率超100%的拒绝保存（允许计算误差）。设备从运行切停机时要累计运行小时数。同一破碎机同一天只能一条破碎记录。破碎后粒度不能大于破碎前。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
