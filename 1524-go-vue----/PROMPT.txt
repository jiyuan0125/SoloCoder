帮冶炼厂做一套炉温监控和配料管理的后端，FastAPI 加命令行客户端。

系统管理多个炉子，温度传感器定时上报数据，超安全范围标红告警。配料管理记录每炉的原料清单和重量，配料后记录实际投料开始冶炼。调度器协调多炉生产，冶炼结束后检查等待中的配料单分配给空闲炉子。指标聚合展示今日产出、平均每炉产出、总能耗和炉温超标次数。

配料单所有原料重量之和不能超炉子设计容量。实际投料偏差超10%标为异常。炉温连续5分钟超安全范围生成紧急待办。同一炉子同一时间只能一个冶炼任务。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
