帮矿业做一套行政审批管理的后端，FastAPI 加命令行客户端。

系统管理各种证照（采矿许可证、安全生产许可证、环评批复等），记录发证日期和有效期。有效期剩余不足90天标为即将到期，超期标为已过期。年检管理记录年检情况，到期前30天自动生成待办。合规检查定期检查各项指标，有不合格项生成待办整改。

证照有效期不能早于发证日期。同一证照同一年度只能一条年检记录。安全相关项目不合格的整条记录强制标不合规。证照已注销的不再生成年检待办。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
