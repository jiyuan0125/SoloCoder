帮矿业集团做一套矿区生态修复管理的后端，FastAPI 加命令行客户端。

系统管理矿区修复工程，每个工程记录治理面积、修复类型和计划时间。待办管理包括阶段里程碑和日常巡检，里程碑延迟超7天自动标逾期。监测数据按月聚合各点位指标，点位当月数据不足3次的不参与聚合。验收环节四项打分加权平均，低于60分不通过，60到80分整改复验，复验最多两次。

验收四项权重分别是0.3、0.25、0.25、0.2。复验最多允许两次，第三次还不通过需要重新制定修复方案。聚合时数据量太少的点位要排除避免均值失真。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
