帮煤矿做一套通风瓦斯监测管理的后端，FastAPI 加命令行客户端。

系统管理矿井和监测区域，传感器每分钟上报瓦斯浓度、一氧化碳、风速、温度和粉尘数据。数据超过预设阈值分三级报警。同一区域同一指标连续报警间隔不超过10分钟视为同一次事件不重复记录。

数据按班次聚合统计平均值、最大值和超限次数。按天生成日报。数据导出按日期范围和区域筛选，CSV格式，时间格式yyyy-MM-dd HH:mm:ss，数值保留两位小数。数据量超过10万条分批处理。导出编码用UTF-8带BOM。

班次切换时确保数据归属不搞混。班次划分：早班6到14点，中班14到22点，夜班22到6点。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
