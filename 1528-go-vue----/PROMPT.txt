帮矿山做一套尾矿库安全监测管理的后端，FastAPI 加命令行客户端。

系统管理尾矿库信息，记录库容、坝高和安全等级。监测断面监控干滩长度、浸润线、坝体位移和库水位。日常巡查根据安全等级自动生成巡查频率，一等库每天一次，五等库每周一次。坝体位移日变化量超5毫米触发预警。

闭库验收要提交三份材料，每份材料独立审核，全部通过后验收自动变为通过。不通过可以修改重提，审核次数不限但每次都要记录意见。

巡查任务超计划日期未完成标为逾期并置顶。聚合数据保留最近一年。监测数据聚合规则：干滩每4小时均值，浸润线每天均值，坝体位移每天变化量，库水位每天最高最低。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
