帮石油钻井做一套工程管理的后端，FastAPI 加命令行客户端。

系统管理井的基本信息，钻井过程分八个阶段依次进行。每阶段完成后生成验收待办，验收通过才能进下一阶段。实际天数超计划120%的生成异常报告待办。一口井同时只能有一个阶段进行中。

事故管理记录复杂事故（井涌、井漏、卡钻、井塌），事故记录后需要负责人填写原因分析和防范措施才算闭环。指标按区块统计在钻井数、已完成数和平均钻井周期。复杂事故率按井口径统计，一口井不管几次事故只算一次。同一口井同一类型事故处理时长不足4小时且无损失的记为轻微事故不纳入统计。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
