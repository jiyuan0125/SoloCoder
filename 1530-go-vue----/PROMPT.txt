帮油气管道做一套巡线和监测的后端，FastAPI 加命令行客户端。

系统管理管道和管段信息，按风险等级制定巡线频率。压力监测计算相邻点压力差，超过历史平均3倍标准差判定为疑似泄漏触发报警。调度器每小时聚合压力数据，每天生成巡线计划和日报。

报警事件管理，未处理超1小时升级为紧急，处理中超6小时未更新生成催办。误报需要填原因才能关闭。管道完整性记录壁厚数据，壁厚低于设计80%生成维修建议。

压力差标准差基于最近30天数据计算，数据不足30天的用已有数据。管道完整性检测壁厚低于设计80%生成维修待办。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
