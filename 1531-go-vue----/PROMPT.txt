帮化工园区做一套安全管理的后端，FastAPI 加命令行客户端。

系统管理园区企业和危化品信息。危化品审批分三级审核，甲级有效期6个月，乙级1年，丙级2年。到期前30天生成续期提醒。应急响应管理预案和事故记录，处置过程全程记入审计日志，日志不可删除只能追加。每月自动核对台账与审批的一致性，超过许可量或持过期审批的标为异常。

应急预案演练每半年至少一次，距上次超5个月生成演练待办。评估不合格的30天内补练。台账支持按企业和类别导出CSV汇总。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
