帮化工厂做一套反应釜监控与投料管理的后端，FastAPI 加命令行客户端。

系统管理反应釜信息，温度压力传感器定时上报。超设计上限90%预警，超100%紧急报警。温压同时超预警视为高危。投料管理按配方顺序投料，偏差超正负5%记录异常。配方有投料时间窗口，超时标记为异常批次。

按批次聚合生产数据，按天统计完成批次数和异常率。调度器管理定时任务：数据采集、预警判定、数据聚合和日报。

同一反应釜温度压力同时超预警要特别标注为高危。投料时间窗口从第一种原料开始到最后一种完成必须在规定时间内。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
