帮危废处理做一套全流程管理的后端，FastAPI 加命令行客户端。

系统管理产废单位和危废信息（HW01到HW50）。危废从产生到处置经历台账登记、转移联单和处置。联单有三方签字确认环节，任何一方可以拒绝确认进入异常处理。异常联单最多三次处理，超过三次上报环保主管部门。危废暂存超90天生成预警待办。

台账按月提交汇总，系统自动校验产出量、转移量和库存变化是否平衡，差异超1%审核不通过。连续两个月不通过标记为重点监管。转移联单创建时校验接收单位是否有对应处置资质。数据导出支持CSV格式。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
