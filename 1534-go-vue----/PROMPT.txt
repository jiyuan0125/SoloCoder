帮企业做一套环保设施运维的后端，FastAPI 加命令行客户端。

系统管理企业环保设施，按设施类型确定维保周期自动生成待办。排放监测每小时聚合一次，按天统计达标率。达标率低于90%生成异常待办。按月统计设施运行率、排放达标率和维保完成率，低于95%的标记为重点关注。

同一设施连续两次维保更换同种配件生成设备老化预警。维保记录包含配件清单和费用。维保费用按月汇总到企业维度。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
