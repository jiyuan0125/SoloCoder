帮环保做一套环评全流程管理的后端，FastAPI 加命令行客户端。

系统管理建设项目环评流程，从委托到批复经过编制、评估、审批公示和批复。评估四项打分算术平均，低于60分退回。审批公示7个工作日（排除周末和法定节假日），公示期收到公众意见要在10个工作日内回复。

待办贯穿全流程，每个阶段结束生成下一阶段启动待办。项目从委托到批复超12个月标记为超期。评分维度四项，每项0到100分，最终低于60退回修改。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
