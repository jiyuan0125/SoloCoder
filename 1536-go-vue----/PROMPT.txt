帮企业做一套清洁生产审核管理的后端，FastAPI 加命令行客户端。

系统管理企业审核流程，从启动到验收六个阶段。方案产生阶段分无低费方案和中高费方案，中高费方案三个维度都达到6分以上才能通过筛选。方案实施后填报实际效果，实际节能量低于预期80%或投资超预期120%的标记不达标。

验收时专家组根据方案效果达标率作为重要参考。审核从启动到验收超18个月标记为超期。验收满分100分，70分以上通过。所有操作记录到审计日志，日志不可删除不可修改。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
