帮企业做一套碳排放监测核算的后端，FastAPI 加命令行客户端。

系统管理排放企业和排放源信息。碳排放核算精确到小数点后四位，排放量等于活动数据乘排放因子乘氧化率。氧化率有默认值，企业可修改但不能低于行业基准值。按月汇总生成碳排放报告。配额交易管理记录买卖记录，自动更新可用配额余额。

排放数据质量管理：手工检测数据需审核，在线监测数据连续3小时固定值或为零标记为设备故障，故障期间用前7天同时段平均值替代。报告确认后该月数据锁定不可修改。

金额和配额计算精确到小数点后四位。行业碳排放强度排名排除年产值低于1000万的企业。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
