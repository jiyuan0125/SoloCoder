帮固废管理做一套全流程后端，FastAPI 加命令行客户端。

系统管理产废单位和固废台账（一般固废和危废按HW编号分类）。固废转移使用电子联单，联单状态流转待发运、运输中、已到达、已处置。接收单位核验不符可以拒收。固废暂存超期（一般固废180天、危废90天）生成预警待办。

月度台账管理，系统校验产出量、转移量和库存变化是否平衡，差异超1%审核不通过。连续两个月不通过标记为重点监管。处置单位资质管理，创建联单时校验资质匹配。数据导出支持CSV格式，数值保留两位小数。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
