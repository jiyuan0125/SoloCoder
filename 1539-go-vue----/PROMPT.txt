帮城市做一套噪声监测点位管理的后端，FastAPI 加命令行客户端。

系统管理噪声监测点位，按区域功能类别配昼间夜间限值。监测仪每10分钟采集等效A声级数据，自动判断是否超标。同一点位连续超标超2小时触发预警事件。昼间6到22点，夜间22到次日6点。

按天计算昼夜平均噪声值和达标率。设备故障导致数据缺失超4小时的该天不参与达标率计算。设备每年检定一次，到期前30天生成检定待办。施工噪声管理，有夜间施工许可的周边点位限值上调10分贝。数据导出CSV格式，噪声值保留一位小数。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
