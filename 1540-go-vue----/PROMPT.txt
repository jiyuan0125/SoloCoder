帮放射源做一套全生命周期管理的后端，FastAPI 加命令行客户端。

系统管理涉源单位和放射源信息，源编码12位统一编码。放射源从入库到退役全程记录。巡检管理按类别定频率，一类二类每天一次，三类每周，四五类每月。辐射剂量超标的立即生成应急待办。放射源退役要编制方案并审批。

距到期90天黄色提醒，30天橙色警告，过期红色严重警告。任何证书过期的船员不能被分配上船。审计日志记录所有操作，支持按操作类型、操作人和时间范围查询。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
