我们放射源管理科室最近需要一套放射源全生命周期管理系统，用 FastAPI 做。涉源单位信息要维护好，放射源属于某个涉源单位，源编码是12位统一编码，从入库到退役全程记录。放射源状态有入库、在用、暂存、退役四个阶段，正常流程是入库到在用到暂存到退役，退役要编制方案并走审批。

巡检按类别定频率——一类二类每天一次，三类每周，四五类每月。辐射剂量超标的立即生成应急待办，待办处理后要同步更新对应放射源最近一次巡检结果。涉源单位变更名称或地址后，该单位名下所有放射源的单位关联信息也要跟着更新。

距到期90天黄色提醒，30天橙色警告，过期红色严重警告。审计日志记录所有操作，支持按操作类型、操作人和时间范围查询。每个涉源单位详情里要能直接查看该单位名下的放射源列表和巡检记录。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
