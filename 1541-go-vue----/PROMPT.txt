帮水利枢纽做一套运行调度的后端，FastAPI 加命令行客户端。

系统管理水利枢纽信息，包括泄洪设施和闸门。水位每10分钟采集一次，按小时聚合。库水位超汛限水位进入防汛模式，闸门操作需双人确认。汛限水位根据月份变化，主汛期比正常蓄水位低2米，其他月份低1米。

闸门调度规则：库水位超汛限且入库流量持续增大时依次开启闸门，泄洪闸优先于溢洪道优先于放水洞。闸门开度按20%步进，每次增加间隔不少于15分钟。库水位超设计洪水位95%发布红色预警，所有操作需防汛指挥部授权。水位回落汛限以下持续24小时退出防汛模式。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
