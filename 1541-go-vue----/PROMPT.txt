水利枢纽运行调度管理系统，FastAPI 后端。枢纽信息包括泄洪设施和闸门，水位每10分钟采集一次按小时聚合。库水位超汛限水位进入防汛模式，闸门操作需双人确认。汛限水位根据月份变化，主汛期比正常蓄水位低2米，其他月份低1米。

闸门调度规则：库水位超汛限且入库流量持续增大时依次开启闸门，泄洪闸优先于溢洪道优先于放水洞，开度按20%步进，每次增加间隔不少于15分钟。闸门开启时要同时更新对应泄洪设施的运行状态，泄洪设施状态更新时还要记录该设施累计运行小时数。

库水位超设计洪水位95%发布红色预警，所有操作需防汛指挥部授权。水位回落汛限以下持续24小时退出防汛模式，退出时所有闸门自动归零并生成防汛总结。防汛模式期间产生的每条调度指令要有独立的查询接口，按枢纽、闸门、时间段分别查询。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
