帮灌区做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理灌区水利设施，包括四级渠道和水闸。用水计划管理按年编制，各支渠分配用水配额。配额可按季度调整但年度总量不能超初始配额的110%。配额使用量按月统计，超90%生成预警，连续两个月超配额标记为重点监控。

灌溉季节每天早上6点根据配额余量和需水情况自动生成闸门调度方案。非灌溉季节闸门全部关闭只保留生态基流。按月统计用水量，按季度算灌溉水利用系数。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
