灌区水利设施和用水调度都要管，四级渠道和水闸，用 FastAPI 写。用水计划按年编制，各支渠分配用水配额。配额可按季度调整但年度总量不能超初始配额的110%，调整后各季度已执行的计划用水量也要同步更新——比如二季度从500万调到450万，已经用了200万不动，但剩余可用要按新配额减已用量重算。

配额使用量按月统计，超90%生成预警，连续两个月超配额标记为重点监控。灌溉季节每天早上6点根据配额余量和需水情况自动生成闸门调度方案，非灌溉季节闸门全部关闭只保留生态基流。

灌溉结束后自动根据实际用水量更新对应渠道的年度累计执行量。如果某渠道在系统中没有关联的用水计划记录，闸门调度方案里该渠道的配额余量按零处理，调度方案仍然要正常生成。按月统计用水量，按季度算灌溉水利用系数。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
