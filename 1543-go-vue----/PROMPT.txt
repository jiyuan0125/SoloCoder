雨量站水位站数据分散，防洪调度全靠人工经验。所以想做一个流域防洪调度系统，FastAPI。系统要管流域、水库和监测站，雨量站和水位站每10分钟上报。6小时降雨量超50毫米触发暴雨预警，超100毫米大暴雨预警，河道水位超警戒水位触发洪水预警。

水库水位超汛限开始泄洪，泄洪流量动态计算，计算时要查水库的当前库容曲线和下游河道安全泄量，这两个参数从水库档案里取。调度器每10分钟采集水文数据，每6小时评估洪水形势生成调度建议，调度建议自动推送给值班人员确认后执行。

每次洪水事件从预警触发到结束全程记录，形成完整事件链。洪水期间每条调度指令、每个水库操作、每个水位变化都要关联到同一个洪水事件。洪水事件的所有操作要能通过 /floods/{id}/phases、/floods/{id}/dispatches、/floods/{id}/hydrology 这类路径分别查询。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
