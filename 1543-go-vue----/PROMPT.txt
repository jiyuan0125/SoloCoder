帮流域做一套防洪调度管理的后端，FastAPI 加命令行客户端。

系统管理流域、水库和监测站信息。雨量站和水位站每10分钟上报数据。6小时降雨量超50毫米触发暴雨预警，超100毫米大暴雨预警。河道水位超警戒水位触发洪水预警。

防洪调度规则：水库水位超汛限开始泄洪，泄洪流量动态计算。调度器每10分钟采集水文数据，每6小时评估洪水形势生成调度建议。调度建议推送给值班人员确认后执行。按次洪水统计洪峰流量、总量和历时。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
