水文数据采集管理系统，FastAPI 后端加命令行客户端。不同类型监测站采集不同数据，水位和降雨每10分钟，流量每小时。数据按不同粒度聚合——水位按小时算均值、最高、最低，流量按天算均值和最大值。某小时原始数据缺失超一半的不算聚合值，标记为数据缺失。

数据质量自动识别可疑值：水位1小时变化超2米、降雨负值或超200毫米每小时。审核确认有误的标为无效不参与聚合，已生成的聚合数据要在原始数据被标无效后重新计算。

设备检定周期两年，到期前60天生成检定待办。每个监测站的原始数据、聚合数据、质量记录、检定记录都要能独立查询，路径按 /stations/{id}/raw-data、/stations/{id}/aggregated、/stations/{id}/quality、/stations/{id}/calibrations 这种方式组织。如果聚合时某个站点的设备信息还没录入，聚合结果里该站点的设备型号字段留空，聚合过程不中断。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
