帮水文做一套数据采集管理的后端，FastAPI 加命令行客户端。

系统管理监测站，不同类型站点采集不同数据。水位和降雨每10分钟，流量每小时。数据按不同粒度聚合，水位按小时均值、最高、最低，流量按天均值和最大值。某小时原始数据缺失超一半的不算聚合值，标记为数据缺失。

数据质量管理自动识别可疑数据：水位1小时变化超2米、降雨负值或超200毫米每小时。审核确认有误的标为无效不参与聚合。设备检定周期两年，到期前60天生成检定待办。数据导出CSV格式，水位两位小数流量三位小数降雨一位小数。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
