环保局那边提了个需求，要做水质监测管理系统，FastAPI。监测断面定期采集六项指标，水质评价用单因子法，六项中最差的那个决定断面类别。每个断面的评价标准对应一套标准限值。按月计算达标率，低于70%标记为不达标。汛期加密到每月至少两次监测。

标准限值可以在后台维护，修改需要管理员权限且记审计日志。监测任务按断面类型自动生成——国控每月一次、省控每两月、市控每季度。断面评价标准被修改后，该断面所有未发布的月度评价结果要按新标准重新计算。

数据导出CSV，指标两位小数达标率一位小数。如果某次监测的采样人员信息没填，监测结果仍然正常入库，不影响评价计算。每个断面的监测数据、评价结果和标准限值变更历史都要能直接从断面详情页查看。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
