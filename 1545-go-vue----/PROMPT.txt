帮水质做一套监测管理的后端，FastAPI 加命令行客户端。

系统管理监测断面，定期采集六项指标。水质评价采用单因子法，六项中最差的那个决定断面类别。按月计算达标率，达标率低于70%标记为不达标。汛期加密到每月至少两次监测。

标准限值数据可在后台维护，修改需要管理员权限且记录审计日志。监测任务按断面类型自动生成，国控每月一次、省控每两月、市控每季度。数据导出CSV格式，指标两位小数达标率一位小数。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
