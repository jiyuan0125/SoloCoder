帮水保做一套全流程管理的后端，FastAPI 加命令行客户端。

系统管理水土保持项目，包含工程措施、植物措施和耕作措施三类。按月统计完成进度，进度低于时间进度的生成滞后待办。监测数据雨季每月一次非雨季每季度，按年聚合年均侵蚀模数和植被覆盖度变化率。

竣工验收四项打分加权（0.3、0.3、0.25、0.15），80分以上通过，60到80分整改复验，60分以下不通过。复验最多两次。资金管理模块记录实际支出，超过分项预算110%生成超支预警。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
