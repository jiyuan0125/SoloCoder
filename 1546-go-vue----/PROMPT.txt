最近在搞水土保持项目，需要一个全流程管理系统，FastAPI 实现。项目包含工程措施、植物措施和耕作措施三类，按月统计完成进度，进度低于时间进度的生成滞后待办。监测数据雨季每月一次非雨季每季度，按年聚合年均侵蚀模数和植被覆盖度变化率。

竣工验收四项打分加权（0.3、0.3、0.25、0.15），80分以上通过，60到80分整改复验，60分以下不通过，复验最多两次。项目从立项到实施到验收到结项走完整流程，验收不通过退回实施阶段整改后重新申请验收。

资金管理记录实际支出，超过分项预算110%生成超支预警。项目总预算调整后，各分项的预算占比要按新总预算重新分配，已经完成验收的分项预算金额不动。待办里要能看到每个项目关联的措施完成情况、资金使用情况和验收进度。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
