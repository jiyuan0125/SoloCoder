我们河长办最近需要一套河长制综合管理系统，用 FastAPI 做。河流和河长信息都要维护，巡河管理按河长级别定频率——省级每季度、市级每两月、县区级每月、乡镇级每半月。巡河发现的问题分六种类型按严重程度分三级，问题整改有期限——一般7天、较重15天、严重30天。

超期未完成自动升级问题等级并通知上级河长。问题从发现到整改到复核到关闭走完整流程，复核不通过的退回整改阶段重新处理，重新整改后再次复核。月报在次月5日前提交。

河流信息包括河段编码、起止点和所属流域，每条河流可以设置重点河段标记。巡河记录要关联到具体河段和对应河长，巡河中发现的问题要能通过 /rivers/{id}/patrols、/rivers/{id}/issues、/rivers/{id}/reports 分别查看该河流的巡河记录、问题列表和月报。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
