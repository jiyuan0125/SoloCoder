帮河长制做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理河流和河长信息。巡河管理按河长级别定频率，省级每季度、市级每两月、县区级每月、乡镇级每半月。巡河记录发现的问题包括六种类型，按严重程度分三级。问题整改有期限，一般7天、较重15天、严重30天。超期未完成自动升级问题等级通知上级河长。

待办包括巡河提醒、整改催办和月报提交。月报在次月5日前提交。按河长统计巡河完成率和问题整改率，按行政区汇总工作成效。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
