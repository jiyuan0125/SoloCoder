河道采砂全链条管理系统，FastAPI 后端。采砂许可证审批经过受理、核查、公示和发证四环节，全程记审计日志。采砂作业前要报备，按月统计实际开采量，达年度控制量90%预警，达100%停止本年度作业，实际开采量通过过磅数据计算。

执法管理记录违法采砂，处罚包括警告、罚款、暂扣和吊销许可证。许可证状态变更后，该许可证关联的执法记录里涉及该许可证的处罚执行状态要同步更新——比如许可证被吊销后，该证暂扣处罚自动改为已执行。同一单位年度被处罚两次以上许可证年审不予通过。

巡查任务按河段重要性自动生成，重要河段每周一般每两周。月报自动生成在次月3日前推送审阅。许可证和采砂作业的每一步操作都要有独立接口——/licenses/{id}/accept、/licenses/{id}/inspect、/licenses/{id}/publish、/licenses/{id}/issue，作业报备和过磅数据也是独立路径。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
