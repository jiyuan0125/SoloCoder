帮河道采砂做一套全链条管理的后端，FastAPI 加命令行客户端。

系统管理采砂许可证，审批经过受理、核查、公示和发证四环节，全程记审计日志。采砂作业前要报备，按月统计实际开采量，达年度控制量90%预警，达100%停止本年度作业。实际开采量通过过磅数据计算。

执法管理记录违法采砂，处罚类型包括警告、罚款、暂扣和吊销许可证。同一单位年度被处罚两次以上许可证年审不予通过。巡查任务按河段重要性自动生成，重要河段每周一般每两周。月报自动生成在次月3日前推送审阅。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
