用 FastAPI 写一个渔业资源管理系统。渔民信息和捕捞许可证都要管理，许可证审批时有违规记录未结案的暂停审批。休渔期通常5月1日到9月1日，期间禁所有捕捞（养殖除外）。

违规处理分五种处罚（警告、罚款、暂扣许可证、吊销许可证、刑事移送），罚款按违规类型和严重程度确定，违规记录关联渔民档案影响后续审批。违规案件从立案到调查到处罚决定到执行到结案走完整流程，调查阶段可以补充证据，处罚决定后可以申请复议。

休渔期开始前15天生成通知待办，休渔期检测到渔船定位出现在休渔海域的生成涉嫌违规待办。增殖放流管理记录放流活动信息，放流鱼苗来自哪个苗种场、品种、数量和放流水域。渔港信息包括码头泊位数量和可停靠吨位，渔船进出港要登记。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
