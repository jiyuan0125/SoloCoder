帮渔业做一套资源管理的后端，FastAPI 加命令行客户端。

系统管理渔民信息和捕捞许可证。许可证审批有违规记录未结案的暂停审批。休渔期通常5月1日到9月1日，期间禁所有捕捞（养殖除外）。休渔期开始前15天生成通知待办。休渔期检测到渔船定位出现在休渔海域的生成涉嫌违规待办。

违规处理分五种处罚，罚款按违规类型和严重程度确定。违规记录关联渔民档案影响后续审批。增殖放流管理记录放流活动信息。渔港管理站办公时间工作日8:30到17:30，周末休息，线上系统全天可用。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
