帮海洋做一套环境监测的后端，FastAPI 加命令行客户端。

系统管理海洋监测站，岸基站测潮位海浪水温，浮标站额外测盐度溶解氧叶绿素。潮位按小时算整点值，按天算最高最低和平均。海浪有效波高超2.5米蓝色预警，超4米黄色，超6米橙色，超9米红色。

赤潮监测通过叶绿素浓度异常判断，连续3次采样超正常值3倍标准差判定疑似赤潮。按月统计各海域潮位特征值、海浪特征值和赤潮次数。数据导出CSV格式，潮位两位小数波高一位叶绿素三位。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
