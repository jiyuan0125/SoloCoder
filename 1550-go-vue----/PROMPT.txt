海洋环境数据采集分散，赤潮预警靠人工判断太慢。所以想做一个海洋环境监测系统，FastAPI。岸基站测潮位海浪水温，浮标站额外测盐度溶解氧叶绿素。潮位按小时算整点值，按天算最高最低和平均。海浪有效波高超2.5米蓝色预警，超4米黄色，超6米橙色，超9米红色。

赤潮监测通过叶绿素浓度异常判断，连续3次采样超正常值3倍标准差判定疑似赤潮，疑似赤潮经确认后正式发布，发布后持续监测直到浓度回落到正常范围解除。赤潮事件从疑似到确认到发布到持续监测到解除走完整流程，确认后自动给关联海域的养殖户推送通知。

每个监测站的数据按 /stations/{id}/tide、/stations/{id}/wave、/stations/{id}/redtide 分开查询。如果某个浮标站的盐度传感器数据持续缺失超过24小时，叶绿素和溶解氧数据仍然正常入库，赤潮判定只基于有数据的指标继续运行。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
