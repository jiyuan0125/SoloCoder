帮港口做一套泊位与装卸调度的后端，FastAPI 加命令行客户端。

系统管理泊位信息，每个泊位有类型和靠泊能力。船舶信息管理记录状态和预计到港时间。装卸作业关联船舶和泊位，有优先级。堆场管理各区域容量。调度功能自动推荐合适泊位（类型匹配、靠泊能力足够、空闲），无空闲时显示等待队列按优先级排序。

泊位维护期间不能分配。一艘船同时只能一个活跃装卸作业。堆场不能超容量。装卸结束自动释放泊位。装卸作业结束后船舶状态改为锚泊等待下一轮。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
