帮我做一套港口泊位与装卸调度系统，FastAPI 后端加命令行客户端。每个泊位有类型和靠泊能力，船舶信息记录状态和预计到港时间。装卸作业关联船舶和泊位，有优先级，堆场管理各区域容量。

调度自动推荐合适泊位——类型匹配、靠泊能力足够、空闲，无空闲时显示等待队列按优先级排序。泊位维护期间不能分配，一艘船同时只能有一个活跃装卸作业。堆场不能超容量，装卸结束自动释放泊位，装卸结束后船舶状态改为锚泊等待下一轮。

船舶从预计到港到靠泊到装卸到离港有完整状态流转，靠泊后才能安排装卸，装卸全部完成才能申请离港。船舶信息变更吃水深度后，已经分配的泊位要重新校验靠泊能力是否仍然满足。装卸作业过程中如果堆场区域临时被标记为不可用（比如消防演习），该区域的待装卸货物自动转入等待队列。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
