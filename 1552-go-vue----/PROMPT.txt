帮船舶代理做一套业务管理的后端，FastAPI 加命令行客户端。

系统管理代理服务，从创建到完成经过多个环节。靠泊申请填写时间和泊位偏好，审批后自动分配泊位。物料补给管理，燃油和淡水不能同时配送。垃圾回收管理，回收总重量超500千克超出部分打八折。待办事项按时间顺序，前一个完成才能标记下一个。

申请靠泊时间必须是未来时间，预计靠泊时长2到72小时。靠泊时间距到达超24小时标记等待超时。离港前必须确认所有补给已交付且垃圾回收已完成。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
