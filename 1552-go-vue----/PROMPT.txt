船舶代理那边提了个需求，要做一套业务管理系统，FastAPI。代理服务从创建到完成经过多个环节——接单、申报、靠泊安排、作业执行、费用结算、离港确认，每个环节完成后才能进入下一个。靠泊申请填写时间和泊位偏好，审批后自动分配泊位。

物料补给管理，燃油和淡水不能同时配送。垃圾回收管理，回收总重量超500千克超出部分打八折。待办事项按时间顺序，前一个完成才能标记下一个。申请靠泊时间必须是未来时间，预计靠泊时长2到72小时。

靠泊时间距到达超24小时标记等待超时。离港前必须确认所有补给已交付且垃圾回收已完成，确认后自动从代理费用里扣除对应物料和垃圾回收的费用。如果某次代理服务没有安排物料补给，费用结算时物料费用按零计算，结算流程正常走完。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
