帮航道做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理航道区段信息，实测水深低于设计水深减0.5米标记为限航状态。航标管理，一个区段两个以上航标故障或缺失标为航标异常。疏浚计划管理，计划深度必须大于实测且不超过设计加1米，同区段不能同时两个施工中的计划。

船舶吃水申报自动校验：限航状态申报吃水不能超实测减安全裕度，有施工中疏浚的不超目标深度减安全裕度。水深监测连续三天持续下降生成预警。待办按优先级排，紧急任务处理期限不超24小时。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
