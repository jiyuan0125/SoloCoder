帮海事做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理海事行政审批（四种许可类型）和执法检查。许可期望生效日期不能早于申请日期加3个工作日。一艘船同一时间只能持一个有效同类型许可，已有有效许可的新申请自动驳回。

执法检查不合格的自动生成整改记录。同一艘船30天内两次检查不合格标记为重点关注。行政处罚罚款1000到50000元且必须是100的整数倍，逾期15个工作日未处理标为逾期。审计日志只追加不修改不删除。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
