我们海事局最近需要一套综合管理系统，用 FastAPI 做。行政审批四种许可类型，执法检查不合格的自动生成整改记录，同一艘船30天内两次检查不合格标记为重点关注。许可期望生效日期不能早于申请日期加3个工作日。一艘船同一时间只能持一个有效同类型许可，已有有效许可的新申请自动驳回。

行政处罚罚款1000到50000元且必须是100的整数倍，逾期15个工作日未处理标为逾期。执法检查中如果船舶信息不完整，整改记录和处罚记录仍然要正常生成，缺失信息字段留空，等船舶信息补录后再关联。

整改案件从创建到整改到复查到关闭走流程，复查不通过退回整改阶段重新处理。每艘船的许可申请记录、执法检查记录、处罚记录和整改记录都要能独立查询，也要能从船舶详情页直接看到所有关联记录。审计日志只追加不修改不删除。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
