帮引航站做一套调度管理的后端，FastAPI 加命令行客户端。

系统管理引航员信息，一级可引领所有类型，二级不能超大型油轮，三级只能普通货轮客船。引航申请提交后校验级别匹配和时间要求。调度推荐逻辑：值班中、级别够、没其他任务、连续工作不超8小时。

时间窗管理：客运高峰期禁货轮进出，夜间引航时段只有一级可以执行。引航时长超过预估一倍以上标记异常耗时。统计展示当日任务量、各引航员工作量和平均等待时间。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
