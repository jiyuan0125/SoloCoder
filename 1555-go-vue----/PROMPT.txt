引航站调度管理系统，FastAPI 后端。引航员分三个级别——一级可引领所有类型，二级不能超大型油轮，三级只能普通货轮客船。引航申请提交后校验级别匹配和时间要求，调度推荐逻辑是值班中、级别够、没其他任务、连续工作不超8小时。

时间窗管理：客运高峰期禁货轮进出，夜间引航时段只有一级可以执行。引航任务从申请到调度到执行到完成走流程，执行中遇到恶劣天气可以中止，天气好转后从中止点继续执行。

引航时长超过预估一倍以上标记异常耗时。引航完成后要同时更新引航员累计工作时长和该引航员当月任务统计，月度统计更新时还要检查是否接近月度100小时上限，接近上限的自动在后续调度推荐中排除。统计展示当日任务量、各引航员工作量和平均等待时间。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
