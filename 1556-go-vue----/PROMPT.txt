船员管理系统，用 FastAPI 写。船员信息和证书管理是核心，证书距到期90天黄色、30天橙色、过期红色，只要有过期证书就不能上船。培训记录管理，知识更新培训间隔不能超证书有效期一半。在船考勤按月汇总，工资计算按出勤状态不同系数——正常1倍、加班1.5倍、病假60%、事假不计。

船舶分配校验有空缺、状态待派、所有证书有效，实习生不能单独分配为值班人员。船员从待派到在船到下船，状态变更时关联的考勤记录和当月工资核算也要同步更新——上船当天开始计正常出勤，下船当天按半天算。

船员下船后要同时结算当月在船工资，结算时如果该船员没有培训记录，工资正常结算不受影响。每艘船的船员名单、考勤汇总和证书状态要能直接查看，每个船员的任职履历和工资记录也要能查。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
