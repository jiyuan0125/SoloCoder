帮船队做一套船员管理的后端，FastAPI 加命令行客户端。

系统管理船员基本信息和证书，证书距到期90天黄色、30天橙色、过期红色。只要有证书过期就不能上船。培训记录管理，知识更新培训间隔不能超证书有效期一半。在船考勤按月汇总，工资计算按出勤状态不同系数（正常1倍、加班1.5倍、病假60%、事假不计）。

船舶分配校验：有空缺、状态待派、所有证书有效。实习生不能单独分配为值班人员。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
