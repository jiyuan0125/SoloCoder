帮船检做一套船舶检验管理的后端，FastAPI 加命令行客户端。

系统管理船舶台账和检验任务。检验类型分初次、年度、中间、特别和临时。中间检验到期日从上次特别检验算起2.5年。系统根据最近检验自动计算下次检验类型和截止日期生成待办。检验安排不能晚于截止日期前30天。

坞修管理，每个船坞同时只容纳一艘船。证书到期前90天、30天、7天分别生成提醒。证书过期但船舶有营运记录标记为违规营运。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
