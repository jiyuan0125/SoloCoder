船舶检验管理这些年全靠纸质台账，效率太低。所以想做一个船检管理系统，FastAPI。检验类型分初次、年度、中间、特别和临时，中间检验到期日从上次特别检验算起2.5年，系统根据最近检验自动计算下次检验类型和截止日期生成待办。检验安排不能晚于截止日期前30天。

坞修管理每个船坞同时只容纳一艘船，船坞维护期间不能安排检验。检验完成后要同时更新船舶的证书信息和历史检验记录，更新证书时还要检查该船舶是否有营运记录，有的话把营运期间对应的检验待办标记为已过期。

证书到期前90天、30天、7天分别生成提醒。每艘船的检验记录要能通过 /vessels/{id}/inspections 查询，证书变更历史通过 /vessels/{id}/certificates 查，坞修安排通过 /vessels/{id}/dockings 查，待办提醒也可以按船舶维度筛选。证书过期但船舶有营运记录标记为违规营运。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
