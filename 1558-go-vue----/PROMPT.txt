帮我做一套危险品运输管理系统，FastAPI 后端加命令行客户端。危险品分九大类，申报管理审核包装合规和船舶资质。一类爆炸品和七类放射性物质需要二级审核（初审加复审），其他一级即可。一艘船一航次最多装载三类不同危险品。

装卸监控中一类爆炸品环境温度不超35度，七类放射性装卸记录辐射剂量率。申报从提交到初审到复审（如需）到通过到装卸到完成走流程，初审通过后才能进入复审，复审通过后才能安排装卸，装卸完成自动关闭申报。

应急处置按危险品类别和影响范围自动判定事件等级，如果装卸作业中环境监测设备还没接入系统（温度和剂量率字段为空），应急处置方案仍然要按危险品类别生成默认方案。每条申报的各个操作环节要能通过 /declarations/{id}/review、/declarations/{id}/loading、/declarations/{id}/emergency 独立查询。所有操作写审计日志不可修改不可删除。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
