帮海事危险品做一套运输管理的后端，FastAPI 加命令行客户端。

系统管理危险品分类（九大类）。申报管理审核包装合规和船舶资质。一类爆炸品和七类放射性物质需要二级审核（初审加复审），其他一级即可。一艘船一航次最多装载三类不同危险品。

装卸监控：一类爆炸品装卸环境温度不超35度，七类放射性装卸记录辐射剂量率。应急处置按危险品类别和影响范围自动判定事件等级。所有操作写审计日志不可修改不可删除。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
