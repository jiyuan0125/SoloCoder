搜救中心那边提了个需求，要做一套协调管理系统，FastAPI。报警信息录入后15分钟内必须核实，同一位置30分钟内两条以上独立报警自动升级为紧急报警。搜救力量推荐按到达时间从短到长排序，一艘力量同一时间只参与一个任务。

搜救协调记录形成完整事件链，从报警核实到力量出动到现场施救到任务结束全程记录。任务从接警到核实到出动到施救到结束走流程，核实确认后才能调度力量，力量到达后才能开始施救，施救完成才能结束任务。

搜救完成后记录结果，响应时间超30分钟黄色关注，超60分钟红色预警。每个搜救事件要能通过 /events/{id}/alerts 查看关联报警、/events/{id}/forces 查看出动力量、/events/{id}/timeline 查看时间线、/events/{id}/result 查看结果。按月统计报警数、搜救任务数和成功救助人数。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
