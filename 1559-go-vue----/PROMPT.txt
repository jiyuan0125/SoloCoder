帮搜救中心做一套协调管理的后端，FastAPI 加命令行客户端。

系统管理报警信息和搜救力量。报警录入后15分钟内必须核实。同一位置30分钟内两条以上独立报警自动升级为紧急报警。搜救力量推荐按到达时间从短到长排序，一艘力量同一时间只参与一个任务。

搜救协调记录形成完整事件链。搜救完成后记录结果。响应时间超30分钟黄色关注，超60分钟红色预警。按月统计报警数、搜救任务数和成功救助人数。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
