灯塔综合管理系统，用 FastAPI 做。灯塔的灯光运行状态要实时监控，光照度低于额定值80%标为亮度不足，连续两条记录灯光熄灭生成紧急告警。熄灭超4小时标记为严重故障生成紧急维修工单。

能源管理监控太阳能发电量和蓄电池电量，低于20%生成告警。维护计划按类型定频率，年度大修须连续运行满12个月。同时有日常巡检和应急维修的应急维修优先。备件库存低于安全库存生成采购申请，采购申请提交后要同时更新该备件的在途数量。

灯塔维护任务从创建到分配到执行到验收走流程，分配后才能执行，执行完要验收。采购申请也要走审批——申请到审批到下单到入库，入库后自动更新对应备件库存数量。待办按紧急程度排序，灯光熄灭最紧急。每个灯塔的运行日志、维护记录、能源数据和备件使用情况要能直接查看。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
