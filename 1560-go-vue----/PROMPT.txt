帮灯塔做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理灯塔信息，监控灯光运行状态。光照度低于额定值80%标为亮度不足，连续两条记录灯光熄灭生成紧急告警。熄灭超4小时标记为严重故障生成紧急维修工单。能源管理监控太阳能发电量和蓄电池电量，低于20%生成告警。

维护计划按类型定频率，年度大修须连续运行满12个月。同时有日常巡检和应急维修的应急维修优先。备件库存低于安全库存生成采购申请。待办按紧急程度排序：灯光熄灭最紧急。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
