机场运行部门最近需要一套航班运行保障系统，用 FastAPI 做。航班信息、机位分配、登机口和地面保障车辆都要管。机位分配按机型匹配优先廊桥位，两个相邻登机口不能同时登机。

地面保障按优先级和到达时间排序分配车辆，车辆不足标为等待。宽体机地面时间至少60分钟，窄体机40分钟。航班状态根据时间自动流转——从计划到值机到登机到起飞到完成，值机开始后才能登机，登机结束后才能起飞，起飞后自动完成。

机位分配后状态变占用，航班起飞后自动释放。保障车辆有数量限制，每类车辆的调度、使用记录和维护状态要能通过 /vehicles/{id}/dispatches、/vehicles/{id}/maintenance 独立查询。机位信息变更靠桥状态后，已分配到该机位的航班要重新校验是否仍然满足廊桥需求。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
