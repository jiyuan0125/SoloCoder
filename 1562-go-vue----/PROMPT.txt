机场地勤调度管理系统，FastAPI 后端。航班保障任务下子任务按顺序有依赖关系——旅客下机先于清洁，清洁和行李装卸可并行，加油必须在旅客离机后，登机必须在加油后。摆渡车调度按旅客人数分配，充电中和维护中的不能调度。

加油管理实际加油量不能超计划105%，加油量超油罐容量80%需要两辆车，加油车余油低于容量20%需补油。保障任务从创建到分配到执行到完成走流程，子任务全部完成父任务才完成。

除冰管理根据气温自动推荐除冰液类型，如果气象数据接口还没对接（气温字段为空），除冰方案按I型除冰液默认生成。清洁班组不能同时执行两个航班。航班保障的每个环节——旅客服务、清洁、行李、加油、除冰——都要能通过 /flights/{id}/passengers、/flights/{id}/cleaning、/flights/{id}/baggage、/flights/{id}/fueling、/flights/{id}/deicing 分别查询。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
