帮机场地勤做一套调度管理的后端，FastAPI 加命令行客户端。

系统管理航班保障任务，子任务按顺序有依赖关系：旅客下机先于清洁，清洁和行李装卸可并行，加油必须在旅客离机后，登机必须在加油后。摆渡车调度按旅客人数分配，充电中和维护中的不能调度。

加油管理：实际加油量不能超计划105%，加油量超油罐容量80%需要两辆车。加油车余油低于容量20%需补油。除冰管理根据气温自动推荐除冰液类型。清洁班组不能同时执行两个航班。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
