帮航空公司做一套航材管理的后端，FastAPI 加命令行客户端。

系统管理航材目录，件号加件序号唯一标识实物。库存为零标记为缺件。领用管理支持审批，可控件和超10万元需要二级审批。送修管理跟踪状态，超30天未更新标为超期待跟进。修复费用超单价60%建议评估报废。

库存低于最低库存量自动生成采购建议，库存为0特急，低于最低50%紧急。采购需要审批。库存盘点记录差异原因并调整系统数据。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
