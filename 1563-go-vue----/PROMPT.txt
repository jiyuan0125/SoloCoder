航材管理系统，用 FastAPI 写。航材目录用件号加件序号唯一标识实物，库存为零标记为缺件。领用管理支持审批，可控件和超10万元需要二级审批。送修管理跟踪状态，超30天未更新标为超期待跟进。修复费用超单价60%建议评估报废。

库存低于最低库存量自动生成采购建议——库存为0特急，低于最低50%紧急，采购需要审批。采购到货入库后要同时更新库存数量和该航材的采购历史记录，入库时如果该航材在送修目录里有记录，不等待送修返回直接更新可用库存。

每个航材的送修记录、领用记录和采购记录都要能单独查询，路径用 /parts/{id}/repairs、/parts/{id}/requisitions、/parts/{id}/purchases。航材报废时，关联的在途采购订单和送修记录状态不变。库存盘点记录差异原因并调整系统数据。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
