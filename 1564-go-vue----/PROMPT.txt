飞行员排班和资质管理现在全靠Excel，容易出错。所以想做一个飞行员资质管理系统，FastAPI。月度飞行不超100小时，年度不超1000小时，连续7天不超35小时，达到80小时黄色预警，95小时红色。英语等级低于五级不能执飞国际航线。

只要有执飞必需资质失效就不能安排任务。体检管理满40岁每年一次，不满40岁每两年一次，体检暂时不合格自动停飞直到补检合格。排班校验机型匹配、英语满足、飞行时间不超限、体检合格。

排班确认后要同时更新飞行员的月度累计飞行时间和机型资质最近使用时间，更新月度时间时还要判断是否达到80小时预警线，达到的话自动在后续排班推荐中降低优先级。飞行员从待命到执飞到休息到待命循环，执飞状态不能直接跳到下一个执飞任务，必须经过休息。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
