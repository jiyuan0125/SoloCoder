帮航空公司做一套飞行员资质管理的后端，FastAPI 加命令行客户端。

系统管理飞行员基本信息和资质证书。月度飞行不超100小时，年度不超1000小时，连续7天不超35小时。达到80小时黄色预警，95小时红色。英语等级低于五级不能执飞国际航线。

飞行员只要有执飞必需资质失效就不能安排任务。体检管理：满40岁每年一次，不满40岁每两年一次。体检暂时不合格自动停飞直到补检合格。排班校验：机型匹配、英语满足、飞行时间不超限、体检合格。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
