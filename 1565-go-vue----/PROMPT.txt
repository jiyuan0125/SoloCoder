帮空管做一套调度辅助的后端，FastAPI 加命令行客户端。

系统管理航路点和航路。同一航路同方向水平间隔不小于10分钟飞行距离，垂直间隔按东单西双规则分配高度层。两个航班在同一航路预计时间差小于10分钟发出冲突告警建议调整。

流量管理：达容量80%标繁忙，100%标饱和，新航班进等待队列按预计进入时间排序，国际航班优先。模拟推演输入一组航班计划检测潜在冲突输出冲突报告。航路点距离用Haversine公式计算。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
