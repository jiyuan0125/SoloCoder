空管调度辅助系统，FastAPI 后端加命令行客户端。航路点和航路信息管理，同一航路同方向水平间隔不小于10分钟飞行距离，垂直间隔按东单西双规则分配高度层。两个航班在同一航路预计时间差小于10分钟发出冲突告警建议调整。

流量管理达容量80%标繁忙，100%标饱和，新航班进等待队列按预计进入时间排序，国际航班优先。容量状态从空闲到繁忙到饱和到限流，根据实时流量自动切换，繁忙可以直接跳到限流（紧急管制），繁忙不能直接回空闲（必须先经过正常期）。

模拟推演输入一组航班计划检测潜在冲突输出冲突报告，航路点距离用Haversine公式计算。每条航路的实时状态、历史流量和冲突记录要通过 /routes/{id}/status、/routes/{id}/flow、/routes/{id}/conflicts 分别查询。航路容量参数调整后，当天已生成的冲突告警要按新参数重新评估。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
