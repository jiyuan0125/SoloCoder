航空公司那边提了个需求，要做一套航线网络管理系统，FastAPI。同一城市对只能有一条运营中航线。客座率连续三个月低于60%自动标为亏损预警。收益计算精确到元四舍五入，燃油成本与油价成正比。

系统自动生成优化建议——客座率连续三个月超85%且需求增长建议增班，低于65%建议减班，持续亏损建议暂停。航线从规划到试运营到正式运营到暂停到终止走完整流程，正式运营才能录入航班数据，暂停后不能再新增航班但已有航班照常执行。

航线状态变更后，当月的历史航班数据和收益统计仍然按原状态归类，从变更点开始的新数据按新状态归类。所有金额用整数分存储和计算，显示时转回元，平均票价计算使用精确小数运算。每条航线的航班排期、收益明细和优化建议要能直接查看。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
