帮航空公司做一套航线网络管理的后端，FastAPI 加命令行客户端。

系统管理航线信息和市场数据。同一城市对只能有一条运营中航线。客座率连续三个月低于60%自动标为亏损预警。收益计算精确到元（四舍五入），燃油成本与油价成正比。

系统自动生成优化建议：客座率连续三个月超85%且需求增长建议增班，低于65%建议减班，持续亏损建议暂停。所有金额用整数分存储和计算，显示时转回元。平均票价计算要使用精确小数运算。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
