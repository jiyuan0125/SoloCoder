最近在搞机场行李追踪，需要一个行李全程追踪管理系统，FastAPI 实现。行李牌号全局唯一，行李经过托运、安检、分拣、装载、运输、到达、传送带和提取等环节。行李从托运到安检到分拣到装载到运输到到达到提取按顺序流转，安检不通过的行李不走后续环节直接进入异常处理。

分拣失败同一航班超5件生成告警。装载管理一个航班行李总重不超装载限额，贵重物品装专用位置。到达后30分钟未上传送带标延误，传送带上超60分钟标滞留。赔偿管理普通行李最高1000元，贵重物品最高5000元。

分拣过程中如果行李没有绑定航班信息（比如临时加行李还没录入系统），分拣告警仍然要正常记录，等航班信息补录后自动关联到对应航班。丢失72小时内找回自动取消赔偿。每个航班的行李要能通过 /flights/{id}/baggage/baggage-list、/flights/{id}/baggage/sorting、/flights/{id}/baggage/loading 分别查询各环节数据。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
