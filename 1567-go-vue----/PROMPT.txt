帮机场做一套行李追踪的后端，FastAPI 加命令行客户端。

系统管理行李信息，行李牌号全局唯一。行李经过托运、安检、分拣、装载、运输、到达、传送带和提取等环节。分拣失败同一航班超5件生成告警。装载管理，一个航班行李总重不超装载限额，贵重物品装专用位置。到达后30分钟未上传送带标延误，传送带上超60分钟标滞留。

赔偿管理：普通行李最高1000元，贵重物品最高5000元。丢失72小时内找回自动取消赔偿。超大超重行李额外收费。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
