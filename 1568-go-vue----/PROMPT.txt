帮机场安检做一套管理的后端，FastAPI 加命令行客户端。

系统管理安检通道，每个开放通道需要开机员、手检员、验证员各一人，缺任何一人通道自动关闭。VIP通道至少两名手检员。排班管理按早中夜三班，连续工作不超6天，夜班后不能接早班至少休息12小时。

违禁品记录：爆炸物和仿真武器必须移交公安不能自弃。移交公安记录接收民警警号。通道容量按每小时120人计算，排队超容量3倍建议增加通道，但至少保留2个开放。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
