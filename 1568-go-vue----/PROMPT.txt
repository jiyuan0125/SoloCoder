机场安检部门最近需要一套安检管理系统，用 FastAPI 做。每个开放通道需要开机员、手检员、验证员各一人，缺任何一人通道自动关闭，VIP通道至少两名手检员。排班管理按早中夜三班，连续工作不超6天，夜班后不能接早班至少休息12小时。

违禁品记录爆炸物和仿真武器必须移交公安不能自弃，移交公安记录接收民警警号。通道容量按每小时120人计算，排队超容量3倍建议增加通道但至少保留2个开放。

安检员上班打卡后自动关联到当天排班记录，如果该安检员没有排班记录，打卡仍然正常记录但标记为临时加派。每个通道的排班记录、违禁品记录和客流统计都要能通过 /channels/{id}/schedules、/channels/{id}/contrabands、/channels/{id}/traffic 独立查询，也能从通道详情直接跳转。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
