机场免税店综合管理系统，FastAPI 后端。店铺和商品信息都要管理，免税价必须低于零售价，所有金额以整数分存储计算。保质期管理距到期6个月标临期，过期不能销售。库存查询多批次按先进先出，旅客必须在航班起飞前6小时内才能购买。购买数量有限制——化妆品最多5件，烟酒最多2条烟3瓶酒。

结算日结每天汇总销售总额按支付方式分组，日结确认后不可修改。退货30分钟内无理由（未拆封），超30分钟需主管审批，超24小时不受理。退货审批从申请到主管审核到退款到库存回补走流程，主管审核通过后才能退款，退款完成后库存自动回补。

每笔销售记录要能通过 /sales/{id}/details 查看商品明细，/sales/{id}/refund 查看退货状态，/shops/{id}/daily-settlements 查看日结。商品调价后，已有但未日结的销售记录金额不变，调价后的新销售按新价格。退货后库存自动回补到对应批次。

FastAPI + SQLite，端口环境变量指定，pip install -r requirements.txt 后 python -m server 能启动服务端。
