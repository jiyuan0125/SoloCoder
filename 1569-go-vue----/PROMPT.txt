帮机场免税店做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理店铺和商品信息。免税价必须低于零售价，所有金额以整数分存储计算。保质期管理，距到期6个月标临期，过期不能销售。库存查询多批次按先进先出。旅客必须在航班起飞前6小时内才能购买。购买数量有限制：化妆品最多5件，烟酒最多2条烟3瓶酒。

结算日结每天汇总销售总额按支付方式分组，日结确认后不可修改。退货30分钟内无理由（未拆封），超30分钟需主管审批，超24小时不受理。退货后库存自动回补。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
