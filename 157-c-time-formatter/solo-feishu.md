| User Prompt | 帮我用 C 写一个时间戳的格式化工具。系统里所有的时间数据都存成 Unix 时间戳（秒级的整数），但给用户展示的时候需要转成各种可读的格式。支持以下几种展示格式：绝对时间（2026-05-03 14:30:00）、相对时间（3分钟前、2小时前、昨天 15:20、3天前）、纯日期（2026-05-03）、纯时间（14:30）。相对时间要自动选择最合适的粒度——不到60秒显示「刚刚」，60秒到3600秒显示「N分钟前」，1小时到24小时显示「N小时前」，1天到30天显示「N天前」，超过30天就显示具体日期。相对时间还要处理「昨天」「前天」这种更友好的表述，以及「N天前」和具体日期之间的切换要自然。要支持时区转换——输入的时间戳是 UTC 的，但展示时需要转换到用户所在的时区（比如东八区），时区偏移量可以通过参数指定，支持带夏令时的时区。还要支持反向操作：把用户输入的时间字符串解析回时间戳，支持「2026-05-03 14:30:00」「2026/05/03 14:30」「May 3 2026」等常见格式。解析失败的时候要给出明确的错误提示，告诉用户哪部分格式不对。用纯 C 写，gcc 编译通过，不依赖第三方库。还要支持一种「友好时间」的格式——比如「刚刚」「1分钟前」「5分钟前」「2小时前」「昨天下午3点」这样的自然语言表述。 代码拆成至少 4 个源文件：时间格式转换、时区处理、字符串解析、主程序，各自有头文件和实现文件。gcc 编译能过。 |
