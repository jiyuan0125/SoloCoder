帮航空货运做一套管理的后端，FastAPI 加命令行客户端。

系统管理货运航班和舱位容量。货物收运记录货运单号和计费重量（取实际重量和体积重量较大值）。配载管理分配货物到舱室，前舱后舱重量差不能超总载重10%。生鲜冷链必须装温控舱位，活体动物不能与危险品同舱。

运费精确到分，计费重量乘单价。货物到达后免费保管48小时，超期按每天每千克0.1元收保管费，不足一天按一天算。危险品必须提供申报单号，活体动物必须提供检疫证明编号。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
