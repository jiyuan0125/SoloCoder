帮铁路客运做一套调度管理的后端，FastAPI 加命令行客户端。

系统管理列车信息和交路。一个动车组同时只能执行一个交路，交路间至少30分钟折返。乘务管理：司机连续值乘不超4小时需休息30分钟，日总值乘不超8小时，月度不超160小时。列车员数量按定员配置。

考勤按月汇总，超160小时红色预警。列车晚点超30分钟自动变为晚点状态并生成通知。交路优化建议：动车组日均运用低于8小时或折返时间过长生成优化建议。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
