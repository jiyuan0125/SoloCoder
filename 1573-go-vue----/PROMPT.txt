帮铁路信号做一套监控管理的后端，FastAPI 加命令行客户端。

系统管理道岔、联锁、闭塞和信号机。道岔在列车经过时不能转换，失去表示时进路不能开放信号。联锁管理确保敌对进路不能同时建立，进路建立后相关道岔自动锁闭。自动闭塞模式下后续列车与前方至少保持两个闭塞分区空闲。

闭塞分区轨道电路故障时降级为半自动闭塞。信号机故障时自动显示红灯（故障导向安全）。按小时和日汇总道岔转换次数、故障次数和闭塞区间占用率。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
