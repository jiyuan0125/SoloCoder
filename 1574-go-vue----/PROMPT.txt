帮铁路工务做一套轨道维护的后端，FastAPI 加命令行客户端。

系统管理线路区间数据。巡检分日常、综合和专项三类。三级严重缺陷24小时内处理，二级7天，一级下次综合巡检前。超期未处理自动升级严重等级。钢轨打磨管理，预防性打磨磨耗超2毫米需修理性打磨，修理后仍超1毫米需换轨。

部件更换记录，钢轨有使用寿命按通过总重算，剩余寿命低于10%生成更换预警。维修班组同一时间只能执行一个任务。待办按紧急程度排序，三级缺陷最紧急。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
