帮高铁车站做一套客运管理的后端，FastAPI 加命令行客户端。

系统管理车站基础信息和区域划分。客流监测每5分钟计数，站内人数超最大容纳80%黄色拥挤预警，超90%红色严重拥挤。安检通道调度根据排队人数建议开关数量，至少保留2个开放。故障通道自动从可用列表排除。

检票管理：发车前15分钟开始前3分钟停止。同一站台两趟车间隔小于10分钟提示客流冲突。节假日客运组织方案根据历史数据预测，超平常150%自动生成高峰预警。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
