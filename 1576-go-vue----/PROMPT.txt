帮铁路做一套接触网检修管理的后端，FastAPI 加命令行客户端。

系统管理检修工单，每个工单有检修区段、计划时间、检修类型（日常巡视、周期检修、故障抢修）和负责人。供电数据监控供电臂的电流电压，电流为0且电压为0判定为停电，电流超额定120%判定为告警。

工单计划结束时间必须晚于开始时间，跨天的要正确处理（比如23点到次日6点）。故障抢修不受计划时间约束可随时创建执行。当天到期的工单每天早上推送到待办列表。逾期未执行的工单红色标记。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
