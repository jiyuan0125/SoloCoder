帮机务段做一套检修管理的后端，FastAPI 加命令行客户端。

系统管理检修计划（段修和厂修），段修周期按走行公里数，厂修每240万公里。录入当前总走行公里数后自动推算下次检修时间。计划编号格式JX加年月日加三位流水号。配件管理记录更换的配件，更换后扣库存，库存不足预警。技术手册借阅管理，默认30天期限，超期标黄。

走行公里数推算不能简单加周期，已超期未修的要提示超期警告。厂修计划创建后不能修改时间只能取消重建。配件库存预警阈值默认5件但可按配件单独设。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
