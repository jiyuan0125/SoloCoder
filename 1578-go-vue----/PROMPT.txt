帮铁路货运做一套货票管理的后端，FastAPI 加命令行客户端。

系统管理货票信息，运费计算规则：基础运费等于重量乘费率，费率按发站到站所在价区确定（八个价区）。危险品运费上浮30%。重量不足1吨按1吨，超1吨小数四舍五入到0.1吨。运费精确到分，所有中间计算用整数分。折扣规则：超5000元部分九折，超10000元部分八折，只对基础运费危险品上浮不参与。

货票结算管理，月底对账生成汇总报表（总票数、总重量、总运费、已结算和未结算金额）。数据导出CSV格式，货票列表支持按日期和状态筛选导出。费率查询时价区编号从1开始。货票编号HP加时间戳加四位随机数保证不重复。对账报表时间范围是自然月不是最近30天。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
