帮铁路物流做多式联运调度的后端，FastAPI 加命令行客户端。

系统管理集装箱、运输段和运输工具三种资源。用户创建联运订单指定起止站和送达时间，系统根据线路配置自动拆分运输段并检查运输工具可用性。集装箱状态实时更新：到中转站变待中转，装上工具变运输中，到目的站变已到达。

40英尺集装箱不能装20英尺工具，调度要做规格匹配。水运计划时间只是估计，要区分计划时间和实际时间。某段运输取消时后续所有段级联取消并释放工具。数据导出运输计划和轨迹，时间格式ISO 8601。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
