帮高铁工务段做一套设备巡检的后端，FastAPI 加命令行客户端。

系统管理三类设备：线路、桥梁和隧道。巡检任务管理支持日常、专项和防洪检查，巡检人员录入检查结果包括问题等级和处理建议。指标聚合展示本月巡检完成率、问题数量按等级分布和设备状态分布。待办功能给巡检人员看自己的任务，超期标红。

里程格式K加公里数加加米数，排序要解析出数字比较不是字符串排序。桥梁按长度分级（超1000米特大桥等），不同等级巡检频次不同。巡检完成率分母是计划总数分子是已完成加逾期完成，不包括取消的。防洪检查非汛期（11月到次年3月）不允许创建。设备状态变更要有历史记录。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
