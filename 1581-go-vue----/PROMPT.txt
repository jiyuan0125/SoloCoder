帮地铁做一套运营调度的后端，FastAPI 加命令行客户端。

系统管理列车信息，调度器根据客流数据自动生成运行计划，设发车间隔和首末班时间。调度员可手动调整发车时间，间隔小于最小安全间隔（默认2分钟）给出冲突提示。信号系统管理信号机状态，故障时记录时间生成故障报告。供电管理记录区间状态，停电时对应区段不能有列车运行。

发车间隔调整后已生成时刻表的后续班次要自动重算。列车到终点站折返时间超5分钟在调度日志标出。信号机故障时受影响区段列车自动限速或停运。供电恢复后列车运行计划不自动恢复需调度员确认。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
