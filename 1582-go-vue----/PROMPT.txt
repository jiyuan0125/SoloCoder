帮地铁做一套自动售检票的后端，FastAPI 加命令行客户端。

系统管理票卡（单程票、储值票、学生票、老年票）、充值和闸机数据。计费规则复杂：单程票按里程计费，起步2元乘6公里，每增1元多4公里，超32公里每增1元多6公里。储值票九五折，学生票半价最低1元，精确到分。票卡余额用整数分存储。充值必须10的整数倍，10到500元。学生票充值送10%。

闸机通行数据用票卡号加进出站时间去重。闸机故障超24小时未处理的待办自动升级高优先级。老年票余额为负自动锁定。计费结果四舍五入到分。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
