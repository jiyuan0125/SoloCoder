帮火车站做一套客服管理的后端，FastAPI 加命令行客户端。

系统管理问询记录（编号WX加日期加三位序号，每天从001开始）。失物招领登记失物和拾物信息，自动匹配按描述相似度和地点接近度。超30天无人认领转待处理。投诉管理分一般和严重，一般48小时、严重24小时内必须回复，超时标逾期并通知主管。旅客7天未确认投诉自动关闭。

指标聚合展示今日问询量、失物登记和匹配数、本月投诉量和处理时长。物品价值超1000元的失物匹配需二次确认。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
