帮地铁维保做一套天窗作业调度的后端，FastAPI 加命令行客户端。

系统管理线路天窗时间配置。作业管理支持多种类型，创建后需审批。调度器自动检测安全冲突（同区间同时段不能两项作业）和人员冲突（同一批人不能同时两项交叉时段作业，含1小时缓冲）。待办给作业负责人看今天执行和审批的作业，作业开始前30分钟提醒。

天窗时间跨天要能正确处理时间比较。作业区域区间只要有重叠就视为冲突。天窗时间没配某天某线路的用通用配置。作业超时后每30分钟自动催促通知负责人。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
