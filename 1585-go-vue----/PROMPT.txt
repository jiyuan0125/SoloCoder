帮隧道做一套综合监控的后端，FastAPI 加命令行客户端。

系统管理通风、照明和排水三个子系统。通风自动模式根据一氧化碳和能见度启停风机，浓度降到安全值以下延迟5分钟关闭，延迟期间浓度又超标要取消关闭。照明自动模式调节亮度，出入口高于中间段，每次调整步长不超10%。

排水系统监控水位，超警戒自动启动排水泵，降到安全线下延迟3分钟关闭。排水泵连续运行超1小时告警，累计运行达保养时长生成保养待办。告警分三级用不同颜色区分。设备故障期间手动控制也不可用。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
