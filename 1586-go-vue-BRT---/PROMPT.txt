帮BRT做一套运营调度的后端，FastAPI 加命令行客户端。

系统管理站点、线路、车辆和信号优先。线路是双向的上下行分别管理站点序列。信号优先功能：BRT车辆距路口300米以内时发送优先请求，每天每辆车有请求次数上限。准点率以实际到站和计划到站差2分钟以内为准。

调度器根据运营参数生成排班计划，排班要考虑折返时间。载客容量超80%标记拥挤状态。换乘站可能同时在多条线上，站点编号相同方向不同。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
