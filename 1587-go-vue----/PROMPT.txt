帮有轨电车做一套运营管理的后端，FastAPI 加命令行客户端。

系统管理充电桩和线路。充电管理是特色：车辆进站判断剩余电量低于30%自动分配充电桩充到90%停止，多空闲桩选累计充电次数最少的均衡使用。车辆每30秒上报GPS和电量，电量低于15%发出低电量告警。

调度器监控电量，电量不足跑完当前交路的自动安排充电并调备用车接替。充电过程记录开始时间、预计充满和进度。充电桩故障时通知调度员手动安排到其他站充电。电量百分比保留一位小数。末班时间要确保跑完全程并回车场。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
