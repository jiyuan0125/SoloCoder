帮轮渡做一套运营管理的后端，FastAPI 加命令行客户端。

系统管理航班、码头、船舶和客流。航班状态分计划中、已开航、已到港、取消和延误。码头管理泊位和靠泊能力。船舶管理记录载客载车量。载客或载车达额定90%标接近满载，达100%满载，超额定不允许开航。调度器根据航班计划分配船舶，优先匹配载客量与预估客流。

航班取消后已购票旅客退票不收手续费。恶劣天气风力超6级或能见度低于1000米。船舶年度检验期间不能安排航班。航班延误超30分钟通知码头做好旅客安抚。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
