帮景区索道做一套运行管理的后端，FastAPI 加命令行客户端。

系统管理索道设备信息。天气监控：风速超8米每秒减速运行，超14暂停，超20停止，有雷电直接停止。天气恢复后不自动恢复需操作员确认。风速数据每分钟更新，状态切换要有滞后保护：连续3分钟超阈值才切换。

检修管理分日常、周检、月检和年检。紧急问题必须当天处理否则次日不允许运营。吊厢载客量1.2米以下儿童不计入但要记录。运营时间统计扣除暂停时间。高峰排队人数超吊厢总容量3倍提示限流。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
