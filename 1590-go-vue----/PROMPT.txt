帮景区做一套缆车运营的后端，FastAPI 加命令行客户端。

系统管理往复式缆车信息，按最大载重量（不是人数）管理。排队管理实时统计排队人数和预估等待时间，计算要考虑已在上行轿厢里的人数。载重量传感器读取实际重量超95%提示，超100%不允许发车。每位乘客默认加20公斤行李。

维护管理分日常、周检、月检和年检。调度器根据排队人数动态调整发车间隔，50人以上最短2分钟，10人以下最长10分钟，中间线性插值。调整要有平滑过渡不能突然跳变。传感器故障时用估算值并标明。维护超期未做禁止运行。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
