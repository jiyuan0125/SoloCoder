帮景区做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理门票（多种票种和优惠规则）、导游调度和游线管理。儿童票1.2到1.5米，1.2以下免票需预约，1.5以上按成人。学生票半价最低10元。老人60以上半价70以上免票。团队票10人以上八折。所有金额精确到分用整数分存储。导游按等级收费，高级是中级1.5倍中级是初级1.2倍，基础费按游览时长每小时50元不足1小时按1小时。

景区限流：在园人数达最大80%停售。团队票免票儿童不计入团队人数门槛。游线难度影响保险费有挑战加5元每人。票价优惠不能重复。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
