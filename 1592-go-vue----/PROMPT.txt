帮会展中心做一套展位管理的后端，FastAPI 加命令行客户端。

系统管理展馆、展厅和展位信息。展览管理协调展位分配和布展时间，同一展厅同一天同一展览日期不能重叠。布展管理每展厅同时段最多5个参展商，特装展位多4小时。参观管理预约入场设日最大人数限制。

展位选好后48小时确认期超时自动释放。特装展位面积超36平方米的独占布展时段。参观预约超最大人数排队等待。展览使用多展厅时调度器确保展位尽量集中。布展时段按小时不足1小时按1小时。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
