帮博物馆做一套藏品和展览管理的后端，FastAPI 加命令行客户端。

系统管理藏品信息，状态变更有完整流转记录。展览管理从藏品库选择展出藏品，状态自动变展出，展览结束恢复在库。一级文物同时只能在一个展览展出。预约管理分时间段设人数限制，身份证号同一天只能预约一次，预约前2小时可取消。

会议预约管理，工作日最晚21点周末最晚18点，时间段部分重叠也算冲突。外借藏品到期未还每天生成催还待办。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
