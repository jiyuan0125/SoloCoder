帮图书馆做一套借阅管理的后端，FastAPI 加命令行客户端。

系统管理图书和副本信息。借阅规则按读者类型不同：普通最多5本30天、学生10本60天、教师15本90天。续借一次期限为原借期一半，到期前才能续借逾期不能续。超期每天每本0.1元滞纳金，累计超书价50%按50%封顶，精确到分。还书当天不计逾期天数。

座位预约2小时一档，8点到21点，15分钟内未签到自动取消释放。同一读者不能同时预约两个时段。活动报名超人数上限进候补，有人取消按候补顺序递补。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
