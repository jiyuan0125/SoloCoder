帮体育馆做一套场地预约的后端，FastAPI 加命令行客户端。

系统管理多种场地类型和计费方式（按时或按场）。预约后30分钟未支付自动取消。预约当天提前2小时取消全额退款，2小时内退50%，开始后不退。赛事管理自动生成赛程表，赛程排程同一队伍两场间隔至少2小时。

培训班报名不足最低人数（5人）开班前3天自动取消通知退款。场地维修期间不可预约已预约的通知改期。预约凭证二维码含加密信息扫码解密验证。连续预约多时段中间无空隙九五折优惠。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
