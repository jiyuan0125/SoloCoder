帮城市公园做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理绿化区域、设施和活动。绿化区域按养护等级定频次（一级每周、二级每两周、三级每月），等级可根据季节调整。设施管理支持市民上报损坏，安全相关（如儿童游乐设施）24小时内必须处理。活动使用区域超500平方米需额外安保。养护任务连续两次未按时完成自动提升养护等级。

调度器安排路线优先处理同一区域内多个任务减少移动距离。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
