帮动物园做一套综合管理的后端，FastAPI 加命令行客户端。

系统管理动物信息和个体档案，饲养管理按班次工作记录投喂情况（饲料种类、投喂量和进食情况）。饲料库存管理低于安全库存提醒采购。兽医管理诊疗和用药记录，自动计算下次疫苗时间。投喂量根据体重计算，不同体重同种动物量不同。隔离观察超14天未恢复需升级诊疗。

疫苗接种间隔有最低要求不能提前。极危动物死亡自动生成上报待办。动物进食连续两天拒食自动生成兽医待办。饲养班次确保每个区域每个班次都有人。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
