帮植物园做一套物种管理的后端，FastAPI 加命令行客户端。

系统管理近三千种植物，记录学名、科属、原产地和状态（正常、休眠、引种观察、已死亡）。引种植物先观察至少三个月，期间每周记录生长状况，观察结束状态正常才转正式库。部分植物信息可发布到园区导览，但保护等级一级的默认不能公开位置。

支持专题展览批量标记植物为展览状态，展览结束后自动恢复。导出功能按科属筛选导出CSV用于年报统计。死亡植物保留记录但不参与统计。
项目架构要求：核心功能实现为独立模块。服务端用 FastAPI 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目按 src layout 组织，core、server、client 分模块。pip install -r requirements.txt 后 python -m server 能启动服务端。服务端监听端口通过环境变量指定。
