帮我用 TypeScript 写一个天文台观测任务管理和公众科普预约的后端服务。

观测任务这块，每个月排观测计划，每个任务包含目标天体、观测时段、使用设备和负责人。同一台设备同一时段不能重复预约，冲突校验要在服务端做。天气原因取消的标记为"天气取消"不计入完成率，设备故障取消的要单独标记并记录故障原因。

公众科普方面每周六晚开放参观，每场限50人需预约。预约时填姓名、手机号和参观人数，一个手机号最多预约4个名额。参观前24小时可以取消预约，取消后名额释放给候补列表里的人。如果某场预约人数不足10人自动取消该场次并通知已预约人员。遇到特殊天象可以临时加场，临时场次不受周六限制但仍需预约和限流。

观测数据和活动记录需要能导出报表，支持按月份和设备维度统计。预约取消后名额释放的过程中如果候补列表有多人，按先到先得顺序分配。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
