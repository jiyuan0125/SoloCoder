帮我用 TypeScript 写一个 SaaS 计费平台的后端服务，面向中小企业做订阅计费和用量统计。

平台支持三种套餐：基础版每月99元最多3个用户，专业版每月299元最多10个用户，企业版每月899元用户不限。每个企业客户可以创建多个订阅，每个订阅绑定一个套餐。超出套餐的用量按量计费：API调用量超出后每次0.005元，存储空间超出后每GB每月3.5元。

金额以分为单位存储和运算，以元为单位输入输出。账单每月1号自动生成，记录基础费用、用量费用和总金额。账单生成后有15天宽限期，宽限期内未支付则订阅暂停，暂停超过30天自动取消。宽限期和暂停期基于账单生成时间来算。客户月中升级套餐时，当月账单按天折算两个套餐的费用再合并。同一客户在同一套餐下重复提交订阅变更请求不会产生重复记录。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
