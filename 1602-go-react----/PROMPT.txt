租户管理太乱了，每个客户的配额和告警都靠人工盯，所以想做一个多租户管理平台，TypeScript 后端。

租户创建时填写企业名称、联系人、联系电话和套餐类型。套餐决定资源配额：用户数上限、存储空间上限和每月API调用量上限。配额这块，某项资源使用量达到配额80%时记录告警，达到100%时阻止新操作并返回错误码。管理员可以给单个租户临时提升配额，提升时记录原因和有效天数，有效期用创建时间加上有效天数来算，过期后自动恢复原配额。配额检查在每个涉及资源消耗的操作之前执行。租户删除时如果还有活跃的订阅和未处理告警就不能删。临时配额过期恢复的时候，如果恢复瞬间租户刚好在执行一个消耗资源的操作，这个操作的结果要以当时的实际配额为准。

Express + TypeScript + SQLite，npm run build 能编译通过，node dist/server.js 能启动，端口环境变量指定。
