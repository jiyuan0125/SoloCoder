帮我用 TypeScript 写一个多租户管理平台的后端服务，做租户隔离和配额管理。

租户创建时填写企业名称、联系人、联系电话和套餐类型。套餐决定租户的资源配额：用户数上限、存储空间上限和每月API调用量上限。租户之间数据完全隔离。

配额管理这块，某项资源使用量达到配额的80%时记录告警，达到100%时阻止新操作并返回错误码。管理员可以给单个租户临时提升配额，提升时记录原因和有效天数。有效期判断用创建时间加上有效天数来算。过期后自动恢复原配额。配额检查要在每个涉及资源消耗的操作之前执行。租户删除时要检查是否还有活跃的订阅和未处理的告警，有的话不能删。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
