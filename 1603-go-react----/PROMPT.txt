用 TypeScript 写一个数据可视化平台。后端提供聚合计算和仪表盘管理就行。

用户可以创建多个仪表盘，每个仪表盘上放多个图表卡片。图表类型支持折线图、柱状图、饼图和热力图，数据来源是预定义的指标。后端提供聚合函数：求和、平均值、最大值、最小值、计数和百分位数（P50/P90/P99）。聚合粒度根据时间范围自动调整：7天以内按小时，30天以内按天，超过30天按周。百分位数在数据量少于10条时直接返回原始值。

折线图展示时某个时间点没有数据的要显示0而不是跳过。热力图数据需要归一化处理，不同指标数量级差异大的直接用原始值会导致颜色分布不均匀。仪表盘可以导出配置为JSON，导入时自动重建所有图表卡片。聚合计算时如果某个指标数据源被删除了，引用该指标的图表卡片标记为"数据缺失"状态但不删除卡片，后续如果同名指标重新创建卡片自动恢复引用。

Express + SQLite，npm run build 能跑就行。
