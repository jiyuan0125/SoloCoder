帮我用 TypeScript 写一个数据可视化平台的后端服务，主要做仪表盘管理和指标聚合。

用户可以创建多个仪表盘，每个仪表盘上放置多个图表卡片。图表类型支持折线图、柱状图、饼图和热力图，数据来源是预定义的指标。后端提供聚合函数：求和、平均值、最大值、最小值、计数和百分位数（P50/P90/P99）。

时间范围支持最近7天、30天、90天和自定义区间。聚合粒度根据时间范围自动调整：7天以内按小时，30天以内按天，超过30天按周。百分位数计算在数据量少于10条时直接返回原始值。折线图展示时某个时间点没有数据的要显示0而不是跳过。热力图数据需要归一化处理，不同指标数量级差异大的直接用原始值会导致颜色分布不均匀。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
