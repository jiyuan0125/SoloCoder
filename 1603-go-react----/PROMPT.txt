用 TypeScript 写一个数据可视化平台，后端提供聚合计算和仪表盘管理。

系统需要提供指标数据源和图表卡片的完整 CRUD 接口。用户可以创建多个仪表盘，每个仪表盘上放多个图表卡片。图表类型支持折线图、柱状图、饼图和热力图，数据来源是预定义的指标。后端提供聚合函数：求和、平均值、最大值、最小值、计数和百分位数（P50/P90/P99）。聚合粒度根据时间范围自动调整：7 天以内按小时，30 天以内按天，超过 30 天按周。百分位数在数据量少于 10 条时直接返回原始值不做计算。

折线图展示时某个时间点没有数据返回 0 不跳过。热力图数据做归一化处理，用该指标数据集的最大值和最小值映射到 0-1。仪表盘可以导出配置为 JSON，导入时自动重建所有图表卡片，导入的 JSON 格式不对时返回 400 和具体错误位置。聚合计算时如果某个指标数据源被删除了，引用该指标的图表卡片标记为"数据缺失"状态但不删除卡片，后续如果同名指标重新创建卡片自动恢复引用。删除仪表盘时如果上面还有图表卡片返回错误拒绝删除，错误消息里包含卡片数量。创建指标时名称为空或纯空格返回 400。

Express + SQLite，npm run build 能跑就行。
