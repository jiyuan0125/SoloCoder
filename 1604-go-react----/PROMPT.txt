帮我用 TypeScript 写一个用户行为分析系统的后端服务，做漏斗分析、留存分析和路径分析。

系统采集用户的行为事件，包括页面浏览、点击、搜索、下单、支付等，每个事件有用户ID、事件名称、发生时间、页面路径和额外属性。

漏斗分析：用户定义一个漏斗步骤序列，系统计算每步的转化率和整体转化率。同一个用户在同一个漏斗步骤里触发多次事件只算一次。漏斗时间窗口默认7天，用户从第一步到最后一步需要在7天内。用户完成步骤的顺序要严格按定义来，不能跳步。留存分析：选择某个事件作为基准，查看第1、3、7、14、30天的留存率。留存率的分母是基准事件的总去重用户数，不是总事件数。路径分析要处理循环路径，连续重复的路径合并为一条带循环次数。分析结果支持导出CSV，数值保留两位小数，超过1万行分批写入。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
