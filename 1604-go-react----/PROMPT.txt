帮我做一套用户行为分析系统，TypeScript 后端加命令行客户端。

系统采集用户行为事件，包括页面浏览、点击、搜索、下单、支付等，每个事件有用户ID、事件名称、发生时间、页面路径和额外属性。漏斗分析：定义一个漏斗步骤序列，系统计算每步转化率和整体转化率。同一个用户在同一个步骤里触发多次事件只算一次，漏斗时间窗口默认7天，用户从第一步到最后一步需要在7天内，步骤顺序要严格按定义来。留存分析：选择某个事件作为基准，查看第1、3、7、14、30天的留存率，留存率的分母是基准事件的总去重用户数不是总事件数。

路径分析要处理循环路径，连续重复的路径合并为一条带循环次数。分析结果支持导出CSV，数值保留两位小数，超过1万行分批写入。漏斗步骤可以随时增删改，修改后历史分析结果保持原样不重算，新的查询用最新的步骤定义。

TypeScript + Express，npm run build 通过就行。
