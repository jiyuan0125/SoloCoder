帮我做一套用户行为分析系统，TypeScript 后端。

系统采集用户行为事件，包括页面浏览、点击、搜索、下单、支付等，每个事件有用户 ID、事件名称、发生时间、页面路径和额外属性。事件名称为空或发生时间为空时返回 400 拒绝写入。漏斗分析：定义一个漏斗步骤序列，系统计算每步转化率和整体转化率，同一个用户在同一个步骤里触发多次事件只算一次。漏斗时间窗口默认 7 天，用户从第一步到最后一步要在 7 天内完成，步骤顺序严格按定义来，顺序不对的不算转化。留存分析：选择某个事件作为基准，查看第 1、3、7、14、30 天的留存率，分母是基准事件去重用户数不是总事件数。

路径分析处理循环路径，连续重复的路径合并为一条带循环次数。分析结果导出 CSV，数值保留两位小数，超过 1 万行分批写入。漏斗步骤可以随时增删改，修改后历史分析结果保持原样不重算，新查询用最新步骤定义。查询漏斗分析时如果漏斗步骤序列为空返回 400。删除事件类型时如果它被某个漏斗步骤引用返回错误拒绝删除。查询分析结果的时间范围为空时默认查最近 7 天。

TypeScript + Express，npm run build 通过就行。
