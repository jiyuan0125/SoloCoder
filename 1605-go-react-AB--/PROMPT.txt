产品团队那边提了个需求，要一套 AB 测试平台，TypeScript 实现。

创建实验时定义流量分配比例和分流维度（按用户 ID 哈希、设备 ID 哈希或地域分流），比例之和不为 100% 时返回 400 拒绝创建。实验创建后进入"配置中"状态，启动后客户端请求分流接口根据用户分流 key 返回实验组或对照组。一个用户可以同时参与多个实验，每个实验独立计算分组，同一个用户对同一个实验重复请求分流接口返回一致的分组结果。

指标对比展示实验组和对照组的绝对值差异、相对提升百分比和 p 值，样本量不足 30 时 p 值字段返回 null 并附加提示"样本量不足"。灰度发布按比例自动放量，每步放量后核心指标下降超过 5% 自动暂停，暂停时同步检查该实验所有指标数据并更新状态。灰度中实验被手动暂停时已放量用户保持当前分组不变。实验状态：配置中→运行中→已暂停→已结束，只能按顺序单向流转，非法跳转返回 400。暂停后可恢复到运行中或直接结束，已结束后分流接口对该实验返回空结果。暂停状态下修改流量比例后恢复时新比例立即生效，已有的分组用户不受影响。删除实验时如果实验在运行中或已暂停状态返回错误拒绝删除。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
