产品团队那边提了个需求，要一套AB测试平台，TypeScript 实现。

创建实验时定义流量分配比例和分流维度（按用户ID哈希、设备ID哈希或地域分流）。实验创建后进入"配置中"状态，启动后客户端请求分流接口，根据用户分流key返回实验组或对照组。一个用户可以同时参与多个实验，每个实验独立计算分组，同一个用户对同一个实验重复请求分流接口要返回一致的分组结果。

指标对比展示实验组和对照组的绝对值差异、相对提升百分比和p值。样本量都至少30才能计算p值，不够时明确提示。灰度发布支持按比例自动放量，每步放量后如果核心指标下降超过5%自动暂停，暂停时系统要同步检查该实验关联的所有指标数据并更新实验状态。灰度过程中实验被手动暂停时，已放量用户保持当前分组不变。实验有配置中→运行中→已暂停→已结束几个状态，暂停后可以恢复也可以直接结束，已结束后分流接口对该实验返回空结果。暂停状态下如果修改了流量分配比例，恢复时新的比例立即生效，已有的分组用户不受影响。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
