帮我用 TypeScript 写一个AB测试平台的后端服务，管理实验的创建、分流和指标对比。

产品经理创建实验时定义流量分配比例和分流维度（按用户ID哈希、设备ID哈希或地域分流）。实验创建后进入"配置中"状态，启动后客户端请求分流接口，根据用户分流key返回实验组或对照组。一个用户可以同时参与多个实验，每个实验独立计算分组。

指标对比展示实验组和对照组的绝对值差异、相对提升百分比和p值。实验组和对照组样本量都至少30才能计算p值，不够时要明确提示。灰度发布支持按比例自动放量，每步放量后如果核心指标下降超过5%自动暂停。灰度过程中实验被手动暂停时已放量用户保持当前分组不变。同一个用户对同一个实验重复请求分流接口要返回一致的分组结果。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
