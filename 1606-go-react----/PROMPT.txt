帮我用 TypeScript 写一个内容审核系统的后端服务，处理文本审核、图片审核和规则引擎。

文本审核维护一套敏感词库，分三个等级：一级违禁词直接拒绝，二级违规词标记待人工审核，三级关注词只记录日志。敏感词匹配要支持模糊匹配，比如"加 微 信"中间有空格也要能识别。图片审核根据URL的hash值决定结果，30%概率待审核，5%概率违规。

规则引擎是核心：每条规则包含条件组合（AND/OR逻辑）、匹配字段和操作。规则按优先级从高到低执行，命中第一条后停止。AND和OR混合嵌套时求值顺序严格按优先级处理，不能假设规则按创建时间排序。审核日志在内存中最多保留最近1万条，超出后最早的被淘汰，淘汰时不能影响正在查询的请求。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
