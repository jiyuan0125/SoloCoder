我们搜索团队需要一套站内搜索服务，用 TypeScript 做。

分词模块支持中英文混合文本。中文用正向最大匹配算法，词典内置 500 个常见词。英文按空格和标点切分，统一转小写。用户搜索词全部是停用词时返回空结果和提示"搜索词均为停用词"。搜索时每个文档有相关度得分：标题中出现的分词权重为 3，正文中出现的权重为 1，同一分词在同一文档中出现多次只计一次。系统需要提供文档的创建、查询、更新、删除接口，以及词典词条的管理接口。

系统维护倒排索引结构，新增或删除文档时索引同步更新。删除文档时从所有相关分词列表中移除该文档 ID，分词的文档列表变空时清理索引项。搜索建议基于文档标题生成，返回最多 5 条匹配建议，没有匹配时返回空数组。搜索结果高亮用 `<em>` 标签包裹命中的分词。搜索热词统计 Top 20 和搜索无结果率也要支持。批量导入文档时如果某条文档的分词结果为空（比如全是特殊字符），该文档不入索引，返回警告信息包含跳过的文档 ID 列表，但不影响其他文档导入。管理员往词典添加新词后已有文档不重新分词，只有新增和编辑的文档才用新词。搜索时如果查询词为空字符串返回 400。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
