帮我用 TypeScript 写一个站内搜索服务的后端，支持全文搜索、分词、搜索建议和结果高亮。

分词模块支持中英文混合文本。中文用正向最大匹配算法，词典内置500个常见词。英文按空格和标点切分，统一转小写。用户搜索词全部是停用词时返回空结果。搜索时每个文档有相关度得分：标题中出现的分词权重为3，正文中出现的权重为1，同一分词在同一文档中出现多次只计一次。

系统维护倒排索引结构，每个分词对应一个文档ID列表。新增或删除文档时索引同步更新。删除文档时要从所有相关分词列表中移除该文档ID，分词的文档列表变空时要清理索引项。搜索建议基于文档标题生成，返回最多5条匹配建议。搜索结果高亮用特殊标记包裹命中的分词。搜索热词统计Top20和搜索无结果率也需要支持。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
