我们搜索团队最近需要一套站内搜索服务，用 TypeScript 做。

分词模块支持中英文混合文本。中文用正向最大匹配算法，词典内置500个常见词。英文按空格和标点切分，统一转小写。用户搜索词全部是停用词时返回空结果。搜索时每个文档有相关度得分：标题中出现的分词权重为3，正文中出现的权重为1，同一分词在同一文档中出现多次只计一次。

系统维护倒排索引结构，新增或删除文档时索引同步更新。删除文档时要从所有相关分词列表中移除该文档ID，分词的文档列表变空时清理索引项。搜索建议基于文档标题生成，返回最多5条匹配建议。搜索结果高亮用特殊标记包裹命中的分词。搜索热词统计Top20和搜索无结果率也需要支持。批量导入文档时如果某条文档的分词结果为空（比如全是特殊字符），该文档不入索引但也不影响其他文档的导入。管理员可以在后台往词典里添加新词，新词加入后已有的文档不会自动重新分词，只有新增和编辑的文档才会用到新词。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
