推荐结果不准，运营天天投诉，所以想做一个推荐引擎后台管理服务，TypeScript 后端。电商场景，基于协同过滤做商品推荐。

系统维护用户-商品评分矩阵，每个用户对购买过的商品打1到5分。基于这个矩阵做两种推荐：基于用户的协同过滤（找口味相似的用户推荐他们买过但目标用户没买过的商品）和基于物品的协同过滤（找和目标用户购买过的商品相似的商品推荐），两种结果合并后去重。相似度用余弦相似度，共同评分商品少于2个时相似度设为0。

冷启动策略：新用户评分少于3条时推荐全站评分最高的Top20商品。新商品至少有5个用户评分后才进入推荐候选集。推荐覆盖率、推荐准确率（推荐列表中被用户实际点击或购买的比例，分母是总推荐曝光次数）和推荐多样性按天统计。用户对某商品修改评分后，该商品相关的推荐结果在下一次查询时重新计算，但已经在推荐列表中展示给用户的历史推荐不追溯更新。

Express + TypeScript + SQLite，npm run build 能编译通过。
