帮我用 TypeScript 写一个推荐引擎后台管理服务的后端，基于协同过滤算法做商品推荐。

系统维护用户-商品评分矩阵，每个用户对购买过的商品打1到5分。基于这个矩阵做两种推荐：基于用户的协同过滤（找口味相似的用户推荐他们买过但目标用户没买过的商品）和基于物品的协同过滤（找和目标用户购买过的商品相似的商品推荐）。两种结果合并后去重。

相似度用余弦相似度。用户之间相似度基于共同评分过的商品向量计算，共同评分商品少于2个时相似度设为0。冷启动策略：新用户评分少于3条时推荐全站评分最高的Top20商品。新商品至少有5个用户评分后才进入推荐候选集。推荐覆盖率、推荐准确率（推荐列表中被用户实际点击或购买的比例）和推荐多样性按天统计。准确率的分母是总推荐曝光次数。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
