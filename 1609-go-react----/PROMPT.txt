用 TypeScript 写一个消息中心，站内信、推送通知和邮件通知统一管理。

消息类型包括站内信（系统通知、审批通知、任务提醒）、推送通知和邮件通知，后两种模拟发送记录到日志。每种消息有模板，模板中可以插入变量如用户名、任务名、截止日期，支持中英文两种语言。系统需要提供消息模板和消息类型的 CRUD 接口，创建模板时变量格式不对（比如未用 {{变量名}} 格式）返回 400。

已读未读管理是核心。未读消息数量在查询接口返回，消息列表分全部、未读、已读三类，查询结果为空返回空数组。支持批量标记已读（请求体里传消息 ID 数组）和一键全部已读，批量标记已读时已删除的消息自动跳过，不报错也不减少未读计数。消息列表按创建时间倒序，置顶消息始终在最前面。待办消息是站内信的子类型，带操作按钮如"审批通过""审批拒绝"，操作后状态从"待处理"变为"已处理"并记录处理人和时间。待办消息有过期时间，过期后自动标记为"已过期"不能再操作，对已过期的待办消息调用操作接口返回 400 和"该消息已过期"。待办消息的每个操作通过 POST /api/messages/{id}/actions/{action} 调用，action 不在合法操作列表里返回 400。删除消息后再标记已读不影响未读计数。删除模板时如果还有消息引用该模板返回错误拒绝删除。

Express + TypeScript + SQLite，npm run build 通过，端口环境变量指定。
