用 TypeScript 写一个消息中心。站内信、推送通知和邮件通知统一管理。

消息类型包括站内信（系统通知、审批通知、任务提醒）、推送通知和邮件通知，后两种模拟发送记录到日志。每种消息有模板，模板中可以插入变量如用户名、任务名、截止日期，支持中英文两种语言。

已读未读管理是核心。未读消息数量在查询接口返回，消息列表分全部、未读、已读三类，支持批量标记已读和一键全部已读。点击某条消息查看详情后自动标记已读，批量标记已读时已删除的消息要跳过。消息列表按创建时间倒序，置顶消息始终在最前面。待办消息是站内信的子类型，带操作按钮如"审批通过""审批拒绝"，操作后状态从"待处理"变为"已处理"并记录处理人和时间。待办消息有过期时间，过期后自动标记为"已过期"不能再操作。删除消息后再标记已读不能让已删除消息的未读计数减回去。待办消息的每个操作都有独立接口，通过消息ID和操作类型来调用，接口路径类似 /messages/{id}/actions/{action}。

Express + TypeScript + SQLite，npm run build 通过，端口环境变量指定。
