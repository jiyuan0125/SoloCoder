帮我用 TypeScript 写一个统一通知管理平台的后端服务，管理多渠道通知的发送和频率控制。

通知模板支持邮件、短信、站内信和钉钉四种类型。模板内容中用双花括号包裹变量名，变量替换时要校验参数是否完整，缺失变量保留原始占位符并记录警告日志。

通知渠道支持配置主备两个实例，主渠道失败自动切换到备用。切换时正在发送中的通知要等当前发送完成后再切换。频率控制：同一用户同一渠道类型最多每分钟1条、每小时5条、每天20条。频率控制用滑动窗口实现。超出限制的通知放入延迟队列等窗口过后再发送。渠道配置和频率参数支持通过接口动态修改并立即生效。当某个渠道发送失败率连续10分钟超过10%时触发告警。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
