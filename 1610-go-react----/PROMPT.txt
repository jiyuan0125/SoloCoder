通知渠道太散了经常漏发重复发的管理平台，TypeScript + Express 后端。

通知模板支持邮件、短信、站内信和钉钉四种类型。模板内容中用双花括号包裹变量名，变量替换时校验参数是否完整，缺失变量保留原始占位符并记录警告日志。渠道支持配置主备两个实例，主渠道失败自动切换到备用，切换时正在发送中的通知等当前发送完成后再切换。频率控制：同一用户同一渠道类型最多每分钟1条、每小时5条、每天20条，用滑动窗口实现，超限的通知放入延迟队列等窗口过后再发送。渠道配置和频率参数支持通过接口动态修改并立即生效。

频率检查时如果触发了延迟队列，延迟队列处理也要走一遍频率校验，防止延迟投递时又超限。当某个渠道发送失败率连续10分钟超过10%时触发告警，告警触发后自动切换到备用渠道，切换过程中渠道配置变更和告警状态更新要在同一步完成不能中间断开。

npm run build 能编译通过，node dist/server.js 能启动，端口环境变量指定。
