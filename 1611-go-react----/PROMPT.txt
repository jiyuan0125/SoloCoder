帮我用 TypeScript 写一个产品反馈系统的后端服务，管理反馈提交、自动分类和优先级判定。

用户提交反馈时选择分类（功能建议/Bug报告/体验投诉/其他），填写标题（5到100字符）和详细描述（至少20字符最多2000字符）。可以上传附件，单个附件不超过10MB，附件暂时只记录文件名和大小。

优先级由系统根据规则自动判定：Bug报告且描述中包含"崩溃""闪退""白屏""数据丢失"等关键词的标记为紧急，功能建议标记为低优先级，其余为普通。关键词匹配范围是标题加描述全文。管理员也可以手动调整优先级。反馈有生命周期状态：待处理→处理中→已解决→已关闭，状态变更记录操作人和时间。反馈创建到关闭超过7天未解决自动标记为超时。工作人员可以添加内部备注和给用户发公开回复。反馈列表按优先级排序，支持批量领取和批量标记已解决。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
