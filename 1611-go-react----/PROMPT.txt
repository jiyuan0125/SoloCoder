客服那边提了个需求，要一个产品反馈管理系统，TypeScript 后端。

用户提交反馈时选择分类（功能建议/Bug报告/体验投诉/其他），填写标题（5到100字符）和详细描述（至少20字符最多2000字符），可以上传附件，单个附件不超过10MB，附件暂时只记录文件名和大小。优先级由系统自动判定：Bug报告且描述中包含"崩溃""闪退""白屏""数据丢失"等关键词的标记为紧急，功能建议标记为低优先级，其余为普通，关键词匹配范围是标题加描述全文。管理员也可以手动调整优先级。

反馈有生命周期状态：待处理→处理中→已解决→已关闭，状态变更记录操作人和时间。反馈创建到关闭超过7天未解决自动标记为超时。工作人员可以添加内部备注和给用户发公开回复。反馈列表按优先级排序，支持批量领取和批量标记已解决。反馈从已解决到已关闭需要用户确认，如果用户7天内没确认则自动关闭，自动关闭时给用户发一条通知，如果用户账号已注销通知发不到就只在内部记一条日志。

Express + TypeScript + SQLite，npm run build 通过就行。
