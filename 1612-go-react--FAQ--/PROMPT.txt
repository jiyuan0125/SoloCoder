帮我用 TypeScript 写一个帮助中心的后端服务，管理FAQ和搜索功能。

FAQ按分类组织，分类支持两级层级。每条FAQ有问题标题、详细回答、排序权重和是否启用。管理员在后台管理FAQ，用户在前台搜索和浏览。

搜索功能在所有已启用的FAQ中做全文搜索。相关度计算：标题中完全匹配得10分，部分匹配得5分，回答中匹配得2分，各匹配得分相加。搜索结果中命中的关键词要高亮标记。用户输入全是空格或特殊符号时返回空结果。满意度收集：每条FAQ有"有帮助"和"没帮助"反馈按钮，满意度等于有帮助次数除以总反馈次数。没有任何反馈时满意度显示为N/A。FAQ排序权重相同时按最后更新时间倒序。管理员可以设置待办事项，有过期未完成的标红。搜索无结果率也要统计展示。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
