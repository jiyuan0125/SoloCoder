最近在搞客服效率提升，需要一个帮助中心的后端服务管理FAQ和搜索功能，TypeScript + Express 实现。

提供分类的创建、查询、修改、删除接口（GET/POST/PUT/DELETE /categories），分类支持两级层级，创建二级分类时parent_id指向一级分类，parent_id不存在时返回400。每条FAQ有问题标题、详细回答、排序权重和是否启用字段，提供FAQ的增删改查接口。搜索接口 GET /faqs/search?q=xxx 在所有已启用的FAQ中做全文搜索，相关度计算：标题完全匹配得10分部分匹配得5分、回答匹配得2分，各项得分累加。搜索结果命中的关键词用em标签包裹高亮。用户输入全是空格或特殊符号时返回空数组和0条结果。

满意度接口 POST /faqs/{id}/feedback 接受"有帮助"或"没帮助"两种反馈，满意度等于有帮助次数除以总反馈次数，没有任何反馈时满意度字段返回字符串" N/A"。排序权重相同时按最后更新时间倒序。删除一级分类时如果下面还有二级分类或FAQ则返回409拒绝删除。分类层级调整时（比如把二级分类提升为一级），该分类下所有FAQ的分类路径同步更新，已分享的FAQ链接通过faq_id访问仍然有效不因分类变更而失效。管理员可以设置待办事项，有过期未完成的在查询接口中标红。搜索无结果率单独统计展示。

Express + TypeScript + SQLite，npm run build 能编译通过，端口环境变量指定。
