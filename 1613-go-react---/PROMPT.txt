用 TypeScript + Express 写一个 App 版本更新管理的后端服务。

每个App版本记录版本号（MAJOR.MINOR.PATCH格式，每段0到65535之间的整数，格式不对返回400）、构建号（正整数递增，新构建号小于等于已有构建号时返回400）、更新日志（最多500字超长截断）、发布状态。版本状态只有三条合法流转路径：未发布→已发布、已发布→已撤回、已撤回→已发布，其他跳转一律返回400和原因说明。管理员发布时设置"最低兼容版本"字段，客户端调用 GET /versions/check?current=2.3.1 检查更新，当前版本低于最低兼容版本返回force_update=true，低于最新版本但高于最低兼容版本返回force_update=false。

版本号比较严格按数值规则，先比MAJOR再比MINOR最后比PATCH，2.10.0大于2.9.0。灰度发布支持按百分比和按用户白名单两种方式，白名单新增用户时已存在的返回409不重复添加。同一个版本号重复提交不会创建重复记录，返回409和已有版本信息。撤回一个版本后如果它是当前最新已发布版本，最低兼容版本自动回退到上一个已发布版本并返回回退后的版本号。灰度中的版本被撤回时，灰度百分比自动归零，已在灰度中的用户下次检查更新返回上一个已发布版本。查询版本列表为空时返回空数组。

npm run build 能编译通过就行。
