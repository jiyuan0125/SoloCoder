帮我用 TypeScript 写一个App版本更新管理的后端服务。

每个App版本记录版本号（语义化格式如2.3.1）、构建号（递增整数）、更新日志（最多500字）、发布时间和发布状态（未发布/已发布/已撤回）。管理员发布新版本时设置"最低兼容版本"字段。客户端检查更新时，当前版本低于最低兼容版本返回强制更新，低于最新版本但高于最低兼容版本返回可更新。

版本号比较要严格按语义化版本数值规则来，先比主版本再比次版本最后比修订号，2.10.0要大于2.9.0。灰度发布支持按百分比和按用户白名单两种方式，白名单用户新增时要去重。撤回一个版本后如果它是当前最新已发布版本，最低兼容版本自动回退到上一个已发布版本。重复提交同一个版本号的构建不会创建重复记录。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
