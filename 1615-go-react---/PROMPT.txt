功能开关全靠改代码重新部署太慢了，所以想做一个功能开关管理系统，TypeScript 后端。

每个开关有唯一的key、名称、描述和开启状态。开关可以设置生效条件：按用户ID白名单、按用户百分比（同一用户多次请求返回一致结果）、按用户属性、按时间窗口。多个条件之间是AND关系。开关值可以是布尔类型或JSON类型，JSON类型值的编辑时要做格式校验。

配置加载机制：业务服务启动时拉取所有开关配置缓存到本地，之后每隔60秒轮询增量更新。连续3次轮询失败后不能清空本地缓存，要用上次成功拉取的数据继续服务。API要支持批量查询，一次传入多个key返回对应的值。开关变更记录操作人和时间。同一个开关短时间内多次修改，最终结果要和最后一次修改一致。开关如果被删除了，引用该开关的业务方查询时返回该开关最后一次生效的值，不能直接报错。

Express + TypeScript + SQLite，npm run build 通过。
