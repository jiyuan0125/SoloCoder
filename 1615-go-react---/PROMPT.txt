帮我用 TypeScript 写一个功能开关系统的后端服务，让运营远程控制功能的开启和关闭。

每个开关有唯一的key、名称、描述和开启状态。开关可以设置生效条件：按用户ID白名单、按用户百分比（同一用户多次请求返回一致结果）、按用户属性、按时间窗口。多个条件之间是AND关系。开关值可以是布尔类型或JSON类型。JSON类型值的编辑时要做格式校验。

配置加载机制：业务服务启动时拉取所有开关配置缓存到本地，之后每隔60秒轮询增量更新。连续3次轮询失败后不能清空本地缓存，要用上次成功拉取的数据继续服务。API要支持批量查询，一次传入多个key返回对应的值。开关变更记录操作人和时间。同一个开关短时间内多次修改，最终结果要和最后一次修改一致。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
