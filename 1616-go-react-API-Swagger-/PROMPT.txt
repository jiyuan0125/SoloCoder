帮我用 TypeScript 写一个统一API文档平台的后端服务，管理微服务的Swagger文档并提供在线调试。

管理员上传微服务的Swagger JSON文件（支持OpenAPI 3.0），后端解析提取所有API路径、方法、请求参数和响应格式。Swagger文件解析要容错，很多团队的文件不规范，解析失败时跳过有问题的API并记录警告，不能导致整个服务崩溃。

在线调试功能：后端提供代理接口转发请求到目标服务。代理转发设置默认30秒超时，支持自定义。目标服务不可达时返回明确的错误信息。代码分析功能：解析Swagger时统计每个API的标签分组、必填参数的类型分布（string/integer/boolean/array/object）和响应状态码覆盖情况。配置如代理超时、最大请求体等支持通过配置文件加载，修改后热生效不需要重启。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
