最近在搞开放平台，需要一个开发者门户，TypeScript + Express 后端。管理应用注册、密钥和调用统计。

提供开发者的注册、查询、更新接口（/developers CRUD），开发者的应用管理接口（/developers/{devId}/apps CRUD）。创建应用时填写名称、描述和回调地址，创建成功返回AppID（app_前缀的随机字符串）和AppSecret。AppSecret只在创建响应中展示一次，之后查询接口不返回Secret字段。重置密钥接口 POST /developers/{devId}/apps/{appId}/reset-secret，重置后旧密钥立即失效，有5分钟过渡期让开发者更新配置，过渡期用当前时间加5分钟计算，过渡期内新旧密钥都有效。重置密钥时冷却时间校验和密钥状态更新在同一次请求内完成，24小时内重复重置返回429和剩余冷却时间。

AppSecret在存储前用SHA256哈希。密钥相关操作都记录审计日志。单个开发者最多创建10个应用，超限时返回403。API调用统计接口 GET /developers/{devId}/apps/{appId}/stats 记录每个应用的调用次数、成功率和平均响应时间，按小时聚合。某个应用调用失败率连续1小时超过20%时自动禁用密钥，禁用操作和通知发送作为原子操作，禁用后所有API调用立即返回403，通知内容包含失败率数据。删除开发者时如果还有未禁用的应用则返回409。回调地址格式不合法返回400。

Express + TypeScript + SQLite，npm run build 能编译通过。
