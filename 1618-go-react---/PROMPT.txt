最近在搞开放平台，需要一个开发者门户，TypeScript 后端。管理应用注册、密钥和调用统计。

开发者注册后可以创建应用，填写应用名称、描述和回调地址。创建成功后自动生成AppID（app_前缀的随机字符串，长度要足够避免碰撞）和AppSecret。AppSecret只在创建时展示一次，之后不可查看只能重置。重置后旧密钥立即失效，有5分钟过渡期让开发者更新配置，过渡期截止用当前时间加5分钟来算。

AppSecret在内存中用SHA256哈希后存储。密钥相关操作都记录审计日志。密钥重置有24小时冷却时间，单个开发者最多创建10个应用。重置密钥时需要同步校验冷却时间并更新该开发者的密钥状态。API调用统计记录每个应用的调用次数、成功率和平均响应时间，按小时聚合。某个应用调用失败率连续1小时超过20%时自动禁用密钥，禁用后所有API调用立即返回403，禁用的同时要给开发者发通知，通知内容里包含失败率数据。

Express + TypeScript + SQLite，npm run build 能编译通过。
