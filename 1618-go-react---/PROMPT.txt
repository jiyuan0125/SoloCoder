帮我用 TypeScript 写一个开发者门户的后端服务，管理应用注册、密钥和调用统计。

开发者注册后可以创建应用，填写应用名称、描述和回调地址。创建成功后自动生成AppID（app_前缀的随机字符串，长度要足够避免碰撞）和AppSecret。AppSecret只在创建时展示一次，之后不可查看只能重置。重置后旧密钥立即失效，有5分钟过渡期让开发者更新配置，过渡期截止用当前时间加5分钟来算。

AppSecret在内存中用SHA256哈希后存储。密钥相关操作都记录审计日志。密钥重置有24小时冷却时间，单个开发者最多创建10个应用。API调用统计记录每个应用的调用次数、成功率和平均响应时间，按小时聚合。某个应用调用失败率连续1小时超过20%时自动禁用密钥。禁用后所有API调用立即返回403。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
