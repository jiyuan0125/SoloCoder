第三方接入那边提了个需求，要一套Webhook管理服务，TypeScript + Express 实现。

提供Webhook订阅的创建、查询、更新、删除接口（/webhooks CRUD）。创建时指定事件类型和回调URL，回调URL只能是HTTPS开头（localhost和127.0.0.1例外），非HTTPS返回400。平台产生事件时向回调URL发HTTP POST，请求体包含event、data、timestamp和signature字段。签名用HMAC-SHA256计算，签名内容是timestamp加请求体JSON字符串拼接，密钥是创建Webhook时分配的secret。接收方校验时timestamp超过5分钟的视为过期。

重试策略：回调返回非2xx或连接超时（10秒）时重试，间隔1分钟、5分钟、30分钟、2小时、24小时，下次重试时间用上次投递时间加间隔计算。重试5次仍然失败后标记为最终失败不再重试。同一个Webhook的事件按产生顺序投递不能乱序。每个Webhook的投递记录查看接口 GET /webhooks/{id}/deliveries，单条重试接口 POST /webhooks/{id}/deliveries/{deliveryId}/retry。投递记录包含请求URL、请求体、响应状态码和响应体（截取前500字符）。删除Webhook时如果还有投递中的事件则返回409。投递记录查询为空时返回空数组。事件类型不存在时创建Webhook返回400。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
