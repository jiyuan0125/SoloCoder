帮我用 TypeScript 写一个数据同步服务的后端，管理两个系统之间的数据同步。

同步支持两种模式。全量同步用逐条upsert方式写入，不能简单清空目标再写入。增量同步通过对比最后更新时间戳判断新增或修改的数据。增量同步有"水位线"概念，记录上次同步到的最新时间戳，同步成功后才更新水位线，中途失败水位线不能更新。

冲突检测基于数据ID和更新时间两个字段。当同一条数据在两个系统中都被修改过时产生冲突。冲突处理策略支持三种：源系统优先、目标系统优先、手动解决。同步任务支持配置频率（一次性/每小时/每天）和冲突策略。同步失败的数据项记录到重试队列，下次同步优先处理，单个数据项最多重试3次。每次同步生成报告记录数据条数、新增、更新、删除和冲突数。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
