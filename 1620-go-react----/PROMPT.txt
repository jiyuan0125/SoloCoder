最近在搞数据同步，两个系统之间的数据一直靠人工导来导去太容易出错了，需要一个同步服务，TypeScript + Express 实现。

同步支持两种模式。全量同步用逐条upsert方式写入，不能简单清空目标再写入。增量同步通过对比最后更新时间戳判断新增或修改的数据，有"水位线"概念记录上次同步到的最新时间戳，同步成功后才更新水位线，中途失败水位线不能更新。同步过程中如果源端数据被再次修改，本轮同步要用原始快照而不是最新值。

冲突检测基于数据ID和更新时间两个字段，同一条数据在两个系统中都被修改过时产生冲突。冲突处理策略支持三种：源系统优先、目标系统优先、手动解决。同步任务支持配置频率（一次性/每小时/每天）和冲突策略。同步失败的数据项记录到重试队列，下次同步优先处理，单个数据项最多重试3次，3次都失败后标记为"需人工介入"不再自动重试。每次同步生成报告记录数据条数、新增、更新、删除和冲突数。

npm run build 能编译通过就行。
