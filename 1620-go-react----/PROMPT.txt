最近在搞数据同步，两个系统之间的数据一直靠人工导来导去太容易出错了，需要一个同步服务，TypeScript + Express 实现。

同步支持两种模式。全量同步用逐条upsert方式写入目标，不能简单清空再写入。增量同步通过水位线（上次同步到的最新时间戳）判断新增或修改，同步成功后才更新水位线，中途失败水位线不能变。同步任务有「待执行→同步中→成功/失败」几个状态，只有「待执行」能转到「同步中」，其他跳转返回400和原因。

冲突检测基于数据ID和更新时间，同一条数据两边都改过算冲突。冲突策略支持源优先、目标优先、手动解决。同步失败的数据进入重试队列下次优先处理，单条最多重试3次，超限标记为"需人工介入"不再自动重试。重试次数耗尽时接口要返回明确的错误消息说明哪些数据项需要人工介入。每次同步生成报告记录新增、更新、删除和冲突数。提供同步任务的增删改查接口，包括创建任务、查看状态、查看报告。接口路径用 /sync/tasks、/sync/tasks/{id}、/sync/tasks/{id}/report 这种形式。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
