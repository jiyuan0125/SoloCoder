帮我用 TypeScript 写一个数据备份和恢复服务的后端。

备份支持定时和手动两种方式。定时备份通过cron表达式设定执行时间，保存前要校验cron表达式合法性。每次备份生成一个快照，记录备份时间、数据范围、文件大小和状态（进行中/成功/失败）。备份成功后自动计算SHA256校验和并保存。

恢复操作不可逆，需要二次确认。恢复前做完整性校验，校验失败拒绝恢复。恢复中途失败时已写入的数据要回滚，不能停留在半恢复状态。备份快照最多保留50个，超出自动删除最早的，删除前确认没有被正在进行的恢复操作引用。大备份导出时采用流式写入避免内存溢出。备份任务有启用/禁用开关，禁用后到时间也不执行。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
