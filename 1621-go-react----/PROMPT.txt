用 TypeScript 写一个数据备份和恢复服务。生产环境数据安全要求越来越高需要系统化备份。

备份支持定时和手动两种方式。定时备份通过cron表达式设定执行时间，保存前要校验cron表达式合法性。每次备份生成一个快照，记录备份时间、数据范围、文件大小和状态（进行中/成功/失败），备份成功后自动计算SHA256校验和并保存。快照有创建中→校验中→可用→已过期几个状态，校验失败的不进入可用状态。

恢复操作不可逆需要二次确认。恢复前做完整性校验，校验失败拒绝恢复。恢复中途失败时已写入的数据要回滚，不能停留在半恢复状态。备份快照最多保留50个，超出自动删除最早的，删除前确认没有被正在进行的恢复操作引用。大备份导出时采用流式写入避免内存溢出。备份任务有启用/禁用开关，禁用后到时间也不执行。快照超过保留策略要自动清理的时候，如果正在被某个恢复操作引用就跳过不删，等恢复完成后再清理。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
