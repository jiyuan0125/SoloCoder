用 TypeScript 写一个数据备份和恢复服务。生产环境数据安全要求越来越高需要系统化备份。

备份支持定时和手动两种方式。定时备份通过cron表达式设定执行时间，保存前校验cron不合法返回400和具体原因。每次备份生成一个快照，记录备份时间、数据范围、文件大小和状态。快照状态有「创建中→校验中→可用→已过期」，只能按顺序流转，跳步返回400，校验失败的不进入可用状态停在创建中并标记失败原因。备份成功后自动计算SHA256校验和。

恢复操作需要二次确认参数才能执行。恢复前做完整性校验，校验失败拒绝恢复并返回错误说明哪项校验不通过。恢复过程中如果写入失败要回滚已写入的数据，不能停在半恢复状态，回滚本身失败也要返回错误。快照最多保留50个，超出自动删除最早的，正在被恢复操作引用的跳过不删。删除快照前要检查引用状态，有引用返回409和冲突原因。备份任务有启用/禁用开关，禁用状态到了时间也不执行，手动触发禁用任务返回400。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
