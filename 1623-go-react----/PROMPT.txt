帮我用 TypeScript 写一个配置中心的后端服务，集中管理多个应用的配置项。

配置按应用和环境（开发/测试/生产）隔离。每个配置项有key、value、值类型（字符串/数字/布尔/JSON）、描述和修改历史。配置修改时记录操作人、修改时间和修改前后的值，历史不可删除。配置支持版本管理，可以回滚到任意历史版本。

客户端拉取配置时支持两种模式：全量拉取和长轮询增量更新。长轮询时客户端带上上次拉取的版本号，服务端在有新版本时才返回，否则保持连接直到超时（默认30秒）。批量发布功能：管理员可以一次修改多个配置项，修改在事务中完成，要么全部生效要么全部不生效。配置项的key在同一个应用和环境组合下不能重复。JSON类型配置值要校验格式合法性。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
