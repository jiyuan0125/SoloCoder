帮我用 TypeScript 写一个分布式任务调度的后端服务，管理定时任务的创建、调度和执行记录。

任务创建时指定任务名称、cron表达式、超时时间、重试次数和执行参数。cron表达式保存前校验合法性。任务执行时系统记录开始时间、结束时间、执行状态（成功/失败/超时）和执行结果。超时的任务自动标记为超时状态。

并发控制：同一个任务前一次还没执行完时，下一次触发时间到了的处理策略可选——跳过本次执行、等待上次执行完再执行或强制终止上次执行。任务执行失败后按配置的重试次数进行重试，重试间隔递增（1分钟、5分钟、30分钟）。任务支持手动触发执行，手动触发不影响定时调度的正常运行。同一个任务短时间内多次手动触发不会产生重复执行记录。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
