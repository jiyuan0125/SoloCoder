帮我用 TypeScript 写一个服务注册与发现的后端服务，管理微服务的注册信息、健康检查和路由。

服务实例启动时向注册中心注册，提供服务名称、实例地址、端口号、权重和元数据。注册成功后实例获得一个唯一ID。服务实例需要定期发送心跳（默认10秒一次），连续3次心跳超时则标记为不健康并从可用列表中移除。

服务发现接口：客户端查询某个服务的可用实例列表，返回所有健康实例的地址和权重。支持多种负载均衡策略：轮询、加权轮询和随机。加权轮询时权重为0的实例不参与分配。服务下线时主动注销，注销后的实例不再被发现但历史记录保留。同一个服务实例地址重复注册时不会创建多条记录，而是更新原有实例信息。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
