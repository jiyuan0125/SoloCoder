ETL数据管道管理服务，TypeScript + Express 后端。数据工程团队日常运维各种同步管道需要统一管理。

管道由多个步骤组成，每个步骤定义数据源、转换规则和目标。数据源支持HTTP接口拉取和内存数据读取。转换规则支持字段映射、类型转换、过滤条件和聚合函数。管道按顺序执行各步骤，每步执行完将结果传给下一步。步骤执行完的数据不能被后续步骤重复消费，每步只处理上一步的输出。

管道执行失败时记录失败步骤和错误原因，已执行的步骤结果保留不回滚。支持从失败步骤重新执行而不是从头开始。管道执行记录包含每步的开始时间、结束时间、处理的数据条数和状态。数据量大的管道支持分批处理，每批1000条，批次之间串行执行避免内存溢出。管道可以设置为定时执行，同一个管道如果上一次还在执行中新的触发要被拒绝而不是排队。步骤的数据源如果被删除或修改了，管道下次执行时要用最新的数据源配置。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
