帮我用 TypeScript 写一个ETL数据管道的后端服务，管理数据从源头提取、转换到加载的全流程。

管道由多个步骤组成，每个步骤定义数据源、转换规则和目标。数据源支持HTTP接口拉取和内存数据读取。转换规则支持字段映射、类型转换、过滤条件和聚合函数。管道按顺序执行各步骤，每步执行完将结果传给下一步。

管道执行失败时的处理：记录失败步骤和错误原因，已执行的步骤结果保留不回滚。支持从失败步骤重新执行而不是从头开始。管道执行记录包含每步的开始时间、结束时间、处理的数据条数和状态。数据量大的管道支持分批处理，每批1000条，批次之间串行执行避免内存溢出。管道可以设置为定时执行，执行间隔可配置。同一个管道如果上一次还在执行中，新的触发要被拒绝而不是排队。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
