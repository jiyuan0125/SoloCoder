最近在搞消息中间件，需要一个简单的内存消息队列管理服务，TypeScript + Express 实现。

队列支持创建、删除和查看，管理接口 /queues、/queues/{name}。每个队列有名称、最大容量和消息保留时间，队列名称重复创建返回409。生产者接口 /queues/{name}/messages 发送消息，消费者接口 /queues/{name}/messages/consume 拉取消息，支持批量拉取最多100条。消息有「可消费→处理中→已确认/已死信」几个状态，只能从可消费转到处理中、处理中转到已确认或已死信，非法状态转换返回400。

消息确认接口 /queues/{name}/messages/{msgId}/ack，确认时检查是否触发了死信条件（重试超过3次），达到阈值转入死信队列。超过30秒未确认的消息重新变为可消费回到队列头部。死信队列查看接口 /queues/{name}/dead-letter。队列容量满时发送请求返回503和当前容量信息。同一个消息不能被两个消费者同时处理，如果消费者尝试确认别人的消息返回403。消费者拉取时队列为空返回空列表不是错误。队列删除后如果还有处理中超时回来找队列的消息直接丢弃。队列不存在时发送和消费都返回404。

npm run build 能编译通过，端口环境变量指定。
