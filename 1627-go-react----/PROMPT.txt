帮我用 TypeScript 写一个消息队列管理的后端服务，实现简单的内存消息队列和消费者管理。

队列支持创建、删除和查看列表。每个队列有名称、最大容量和消息保留时间。生产者向队列发送消息，消息包含payload、发送时间和消息ID。消费者从队列拉取消息，支持批量拉取（最多一次拉取100条）。

消息确认机制：消费者拉取消息后进入"处理中"状态，处理完毕发送确认。超过确认超时时间（默认30秒）未确认的消息重新变为可消费状态，回到队列头部等待下次消费。死信队列：消息被重复消费超过3次仍未确认的转入死信队列，不再自动投递。队列容量满时新的发送请求被拒绝。同一个消息不能被两个消费者同时处理。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
