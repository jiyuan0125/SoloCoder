最近在搞消息中间件，需要一个简单的内存消息队列管理服务，TypeScript + Express 实现。

队列支持创建、删除和查看列表。每个队列有名称、最大容量和消息保留时间。生产者向队列发送消息，消息包含payload、发送时间和消息ID。消费者从队列拉取消息，支持批量拉取（最多一次拉取100条）。消息确认机制：消费者拉取消息后进入"处理中"状态，处理完毕发送确认。

消费者确认时需要同时检查该消息是否触发了死信条件，如果确认失败次数已达阈值则转入死信队列。超过确认超时时间（默认30秒）未确认的消息重新变为可消费状态回到队列头部等待下次消费。死信队列：消息被重复消费超过3次仍未确认的转入死信队列不再自动投递。队列容量满时新的发送请求被拒绝，同一个消息不能被两个消费者同时处理。消息从处理中超时回到可消费状态时，如果在这期间队列已经被删除了，这条消息就丢弃不处理。

npm run build 能编译通过，端口环境变量指定。
