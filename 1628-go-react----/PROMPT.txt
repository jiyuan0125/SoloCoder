帮我用 TypeScript 写一个API网关的后端服务，做请求路由、限流和认证。

网关管理多个上游服务，每个服务有名称、上游地址和路由前缀。客户端请求到达网关后，根据路径前缀匹配到对应的上游服务，转发请求并返回响应。路由匹配支持精确匹配和前缀匹配，有优先级区分。

限流功能支持按IP、按用户ID和按接口路径三个维度。每个维度可以配置每秒、每分钟和每小时的请求上限。限流用滑动窗口实现。认证模块支持API Key认证，每个调用方分配一个key，请求时在header中携带。key可以设置过期时间和调用权限（允许访问的路由列表）。网关转发时要设置合理的超时（默认10秒），上游不可达时返回502。请求日志记录每条请求的方法、路径、状态码、响应时间和匹配的上游服务。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
