网关层没有统一管理太乱了，所以想做一个API网关服务，TypeScript 后端。请求路由、限流和认证一起搞定。

网关管理多个上游服务，每个服务有名称、上游地址和路由前缀。客户端请求到达网关后根据路径前缀匹配到对应的上游服务，转发请求并返回响应。路由匹配支持精确匹配和前缀匹配，有优先级区分。限流功能支持按IP、按用户ID和按接口路径三个维度，每个维度可以配置每秒、每分钟和每小时的请求上限，用滑动窗口实现。

认证模块支持API Key认证，每个调用方分配一个key，请求时在header中携带。key可以设置过期时间和调用权限（允许访问的路由列表），路由权限要和网关注册的路由前缀匹配。网关转发时设置合理的超时（默认10秒），上游不可达时返回502。请求日志记录每条请求的方法、路径、状态码、响应时间和匹配的上游服务。调用方的key管理、权限配置和调用统计都有独立的接口，路径类似 /gateway/clients/{clientId}/keys/{keyId}/stats。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
