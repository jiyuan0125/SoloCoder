用 TypeScript 写一个服务降级和熔断管理系统。保护后端服务不被突发流量压垮。

降级策略管理：管理员为每个接口配置降级规则，包含触发条件（错误率超过阈值或响应时间超过阈值）和降级动作（返回默认值、返回缓存数据或直接拒绝），触发条件的时间窗口可配置（默认1分钟）。熔断器状态机：关闭→打开→半开，关闭状态下正常转发请求，打开状态下直接拒绝所有请求。

打开持续一段时间后（默认30秒）进入半开状态，允许少量请求通过测试。半开状态下请求成功则关闭熔断器，失败则重新打开。熔断器从半开回到关闭的过程中如果又有新的错误，要重新进入打开状态而不是停留在中间。熔断器状态的切换要记录时间和原因，同一个接口短时间内多次触发降级条件熔断器只打开一次不会反复切换。接口调用统计按分钟聚合，记录成功数、失败数和平均响应时间。

Express + TypeScript + SQLite，npm run build 通过就行。
