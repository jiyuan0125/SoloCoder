我们运维团队最近需要一套服务监控告警系统，用 TypeScript 做。采集服务指标异常时自动触发告警。

指标采集：每个服务定期上报指标数据，包括CPU使用率、内存使用率、QPS、错误率和平均响应时间。指标数据按服务名和时间戳存储，查询时支持按服务名和时间范围筛选，聚合粒度根据时间范围自动选择。

告警规则管理：每条规则包含指标名称、比较运算符（大于/小于/等于）、阈值、持续时间（指标持续超过阈值多久才告警）和告警级别（警告/严重/紧急）。告警触发后生成告警记录，包含告警时间、触发规则、当前指标值和告警级别。告警状态有待处理、处理中和已恢复，同一个规则对同一个服务在告警未恢复前不重复触发。告警恢复后如果指标再次超过阈值算一次新的告警。指标数据保留最近7天超出自动清理。规则中如果配置的指标名称在某个服务上从未上报过，该规则对该服务不触发也不报错。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
