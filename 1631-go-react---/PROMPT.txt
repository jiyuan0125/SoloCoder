帮我用 TypeScript 写一个链路追踪系统的后端服务，记录和查询分布式请求的调用链路。

每个请求在入口处生成一个traceId，经过的每个服务在调用时传递traceId并生成spanId。每个span记录：traceId、spanId、父spanId、服务名称、操作名称、开始时间、结束时间和标签（键值对）。同一请求的多个span通过traceId关联。

链路查询支持按traceId精确查询完整调用链，也支持按服务名称、操作名称和时间范围模糊查询。调用链展示时要按时间排序成树形结构，每个节点的子节点按开始时间排序。统计功能：按服务维度统计平均响应时间、错误率和吞吐量。慢查询分析：筛选响应时间超过阈值的trace列表，按耗时从高到低排序。同一个trace的span数据量可能很大，查询时要用分页。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
