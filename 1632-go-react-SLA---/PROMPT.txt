帮我用 TypeScript 写一个SLA管理的后端服务，定义和监控服务等级协议。

每个服务可以定义一个SLA，包含可用性目标（如99.9%）、响应时间目标（如P99低于200ms）和错误率目标（如低于0.1%）。SLA按月度评估，系统根据采集的指标数据自动计算实际达成情况。

可用性计算公式：总分钟数减去故障分钟数除以总分钟数。故障判定由管理员手动记录或根据连续错误率超标自动触发。响应时间取P99值。月度SLA报告包含各项指标的达成情况、故障记录和SLA达标率。SLA达标率等于达标项数除以总SLA项数。SLA违约时系统自动生成违约记录，包含违约天数和影响范围。同一个故障不能被重复计入多次违约。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
