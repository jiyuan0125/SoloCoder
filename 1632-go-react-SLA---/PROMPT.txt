帮我做一套SLA管理系统，TypeScript 后端加命令行客户端。服务等级协议定义和监控。

每个服务可以定义一个SLA，包含可用性目标（如99.9%）、响应时间目标（如P99低于200ms）和错误率目标（如低于0.1%）。SLA按月度评估，系统根据采集的指标数据自动计算实际达成情况。可用性计算公式：总分钟数减去故障分钟数除以总分钟数，故障判定由管理员手动记录或根据连续错误率超标自动触发。

响应时间取P99值。月度SLA报告包含各项指标的达成情况、故障记录和SLA达标率，达标率等于达标项数除以总SLA项数。SLA违约时系统自动生成违约记录包含违约天数和影响范围，同一个故障不能被重复计入多次违约。月度报告生成后如果管理员补充了故障记录，报告中的故障分钟数要能重新计算，重新计算时已确认的达标项结果不变只更新受故障影响的部分。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
