运维那边提了个需求，要一套故障管理服务记录故障事件并计算MTTR和MTBF，TypeScript 实现。

故障事件记录包含故障编号、影响的服务、故障开始时间、发现时间、恢复时间和故障等级（P1到P4）。故障等级根据影响范围和持续时间判定：影响核心功能且持续超过30分钟为P1，影响核心功能30分钟以内或非核心功能超过1小时为P2，以此类推。故障等级可以在创建后由管理员调整。

故障有发现→处理中→已恢复→已复盘几个状态，已恢复的故障如果发现恢复不彻底可以重新打开回到处理中。MTTR（平均恢复时间）：统计时间段内所有已恢复故障的恢复时间减去开始时间的平均值。MTBF（平均故障间隔）：统计时间段内相邻两次故障开始时间之差的平均值，如果时间段内只有一次故障则MTBF无法计算。统计数据支持按服务维度和按时间维度（周/月/季度）分组查看。故障恢复时间用故障记录中的恢复时间字段减去开始时间字段来算，如果恢复时间缺失则不计入MTTR。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
