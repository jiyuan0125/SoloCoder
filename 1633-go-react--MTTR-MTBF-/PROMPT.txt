帮我用 TypeScript 写一个故障管理的后端服务，记录故障事件并计算MTTR和MTBF。

故障事件记录包含故障编号、影响的服务、故障开始时间、发现时间、恢复时间和故障等级（P1到P4）。故障等级根据影响范围和持续时间判定：影响核心功能且持续超过30分钟为P1，影响核心功能30分钟以内或非核心功能超过1小时为P2，以此类推。故障等级可以在创建后由管理员调整。

MTTR（平均恢复时间）计算：统计时间段内所有已恢复故障的恢复时间减去开始时间的平均值。MTBF（平均故障间隔）计算：统计时间段内相邻两次故障开始时间之差的平均值。如果时间段内只有一次故障则MTBF无法计算。统计数据支持按服务维度和按时间维度（周/月/季度）分组查看。故障恢复时间用故障记录中的恢复时间字段减去开始时间字段来算，如果恢复时间缺失则不计入MTTR。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
