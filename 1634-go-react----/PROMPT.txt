帮我用 TypeScript 写一个容量管理的后端服务，监控服务器资源使用情况并做容量预测。

管理多个服务器的资源数据，每台服务器记录CPU使用率、内存使用率、磁盘使用率和网络带宽使用率。数据按分钟采集，存储最近30天的数据。查询时根据时间范围自动聚合：1小时内按原始粒度，1天内按5分钟聚合，7天内按小时聚合，更长按天聚合。

容量预警：任何一项资源使用率超过80%时生成预警。预警规则支持配置阈值和持续时间（如CPU连续5分钟超过80%才触发）。容量预测基于最近7天的历史数据，用线性回归预测未来7天的资源使用趋势。如果预测某项资源将在7天内达到90%，提前生成容量告警。同一个服务器的同一项资源在预警未解除前不重复生成预警。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
