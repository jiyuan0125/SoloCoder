用 TypeScript 写一个变更管理系统。生产环境变更太随意了需要规范化流程。

变更申请包含变更标题、变更类型（发布/配置修改/扩容/迁移）、影响范围、变更计划描述、回滚方案和计划执行时间。变更提交后进入审批流程，需要至少两个审批人通过才能执行，审批人按变更类型和影响范围从预配置的审批人列表中选择。

变更状态：待审批→已批准→执行中→已完成/已回滚，执行中如果发现问题可以执行回滚，回滚后记录回滚原因。变更执行后24小时内标记为观察期，观察期内如果相关服务出现故障自动关联到该变更记录。同一时间窗口内（默认2小时）只能有一个变更在执行中防止多个变更交叉影响排障。变更完成后要填写执行结果确认，变更记录永久保留不能删除。观察期内关联的故障记录如果后来被确认为误报，该变更的观察期标记不影响。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
