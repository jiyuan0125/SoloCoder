帮我用 TypeScript 写一个变更管理的后端服务，管理线上变更的审批和执行流程。

变更申请包含变更标题、变更类型（发布/配置修改/扩容/迁移）、影响范围、变更计划描述、回滚方案和计划执行时间。变更提交后进入审批流程，需要至少两个审批人通过才能执行。审批人按变更类型和影响范围从预配置的审批人列表中选择。

变更状态：待审批→已批准→执行中→已完成/已回滚。执行中如果发现问题可以执行回滚，回滚后记录回滚原因。变更执行后24小时内标记为观察期，观察期内如果相关服务出现故障，自动关联到该变更记录。同一时间窗口内（默认2小时）只能有一个变更在执行中，防止多个变更交叉影响排障。变更完成后要填写执行结果确认。变更记录永久保留不能删除。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
