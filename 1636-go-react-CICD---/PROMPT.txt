帮我用 TypeScript 写一个CI/CD流水线管理的后端服务，管理构建任务和部署流程。

流水线由多个阶段组成，每个阶段包含若干任务。阶段之间串行执行，同一阶段内的任务并行执行。任务类型支持：代码拉取、构建、测试、部署和通知。每个任务记录开始时间、结束时间、状态（成功/失败/跳过）和输出日志。

流水线触发方式支持：手动触发、定时触发和Webhook触发（模拟Git push事件）。Webhook触发时要验证来源合法性。流水线执行时如果某个阶段有任务失败，后续阶段不执行。失败的流水线可以重试，重试时从失败的任务开始而不是从头开始。部署任务需要记录目标环境和部署版本。同一个环境同一时间只能有一个部署在进行中，防止并发部署冲突。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
