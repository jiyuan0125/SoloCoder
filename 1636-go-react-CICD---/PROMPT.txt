最近在搞DevOps，需要一个CI/CD流水线管理系统，TypeScript 后端。管理构建任务和部署流程。

流水线由多个阶段组成，每个阶段包含若干任务。阶段之间串行执行，同一阶段内的任务并行执行。任务类型支持：代码拉取、构建、测试、部署和通知，每个任务记录开始时间、结束时间、状态（成功/失败/跳过）和输出日志。阶段完成检查时要同步更新流水线的整体状态，流水线状态变更时还要触发通知模块。

流水线触发方式支持：手动触发、定时触发和Webhook触发（模拟Git push事件），Webhook触发时要验证来源合法性。流水线执行时如果某个阶段有任务失败后续阶段不执行。失败的流水线可以重试，重试时从失败的任务开始而不是从头开始。部署任务需要记录目标环境和部署版本，同一个环境同一时间只能有一个部署在进行中防止并发部署冲突。流水线各阶段的操作有独立接口，路径类似 /pipelines/{id}/stages/{stageId}/retry。

Express + TypeScript + SQLite，npm run build 通过就行。
