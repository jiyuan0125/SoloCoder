帮我用 TypeScript 写一个制品管理的后端服务，管理构建产物的存储和版本信息。

制品按项目组织，每个制品有名称、类型（Docker镜像/JAR包/NPM包/静态文件）、版本号和存储路径。制品上传时自动计算SHA256校验和，上传完成后和客户端提供的校验和比对，不一致则拒绝。同一个制品名称加版本号的组合不能重复上传。

制品仓库支持快照版本和发布版本两种类型。快照版本可以被覆盖更新，发布版本不可覆盖。制品可以被标记为latest，标记latest时自动解除之前同类型同名称的latest标记。制品下载时记录下载次数和下载者。存储空间管理：统计每个项目的制品总大小，超过配额时禁止上传新制品。制品可以设置保留策略，比如只保留最近10个快照版本，超出的自动清理。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
