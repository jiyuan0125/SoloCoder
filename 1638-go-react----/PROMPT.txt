环境太多全靠文档记录早就过时了，所以想做一个环境管理服务，TypeScript + Express 后端。

环境分为开发、测试、预发布和生产四种类型。每个环境有名称、类型、所属项目和状态（运行中/维护中/已销毁）。环境资源包括服务实例数量、数据库连接信息和中间件配置，配置以键值对形式存储支持版本历史。环境有创建中→初始化→运行中→维护中→已销毁几个状态，已销毁的环境不能恢复只能重新创建。

环境克隆：可以从一个已有环境克隆出新环境，克隆时复制所有配置和资源定义但不复制数据，克隆操作完成后新环境状态为维护中需要手动标记为运行中。环境配额管理：每个项目每种类型的环境数量上限可配置，超出配额不能创建新环境。环境资源变更要记录变更历史支持回滚到指定版本，同一个环境同时只能有一个变更操作在进行中。环境配置回滚时正在使用的服务实例不能直接停掉，要先标记为"待重启"等应用方确认后再执行。

npm run build 能编译通过，端口环境变量指定。
