帮我用 TypeScript 写一个环境管理的后端服务，管理多套部署环境的配置和资源。

环境分为开发、测试、预发布和生产四种类型。每个环境有名称、类型、所属项目和状态（运行中/维护中/已销毁）。环境资源包括服务实例数量、数据库连接信息和中间件配置。配置以键值对形式存储，支持版本历史。

环境克隆：可以从一个已有环境克隆出新环境，克隆时复制所有配置和资源定义，但不复制数据。克隆操作完成后新环境状态为维护中，需要手动标记为运行中。环境配额管理：每个项目每种类型的环境数量上限可配置，超出配额不能创建新环境。环境资源变更要记录变更历史，支持回滚到指定版本。同一个环境同时只能有一个变更操作在进行中。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
