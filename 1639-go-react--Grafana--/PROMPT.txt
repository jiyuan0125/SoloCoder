我们监控团队需要一个指标采集和可视化服务，TypeScript 后端。类似 Grafana 的数据查询能力。

指标有名称、标签（键值对集合）和数值，按时间序列存储，每条记录包含时间戳和值。相同名称加标签组合在同一时间戳只保留最新值。需要这些接口：POST /metrics 写入指标数据、GET /metrics/{name}/points 按名称查询数据点（参数 tags、start、end、interval）、GET /metrics/{name}/aggregation 聚合查询（参数 func 支持 avg/sum/max/min/count/percentile、tags、start、end、interval）、POST /templates 创建指标模板、GET /templates 列出模板、GET /templates/{id}/queries 用模板查询、PUT /templates/{id} 更新模板、DELETE /templates/{id} 删除模板。

聚合查询按指定 interval 分组，某个间隔无数据点时返回 null。分页参数 page 和 pageSize（默认每页 1000 个数据点），超出范围的页码返回空数组。写入指标时名称为空返回 400 和 "metric name is required"，标签值包含非法字符（非字母数字下划线横线）返回 400 和 "invalid tag value"。

模板中引用的指标名称不存在时，查询返回 404 和 "metric {name} referenced in template not found"。删除模板时如果正在被其他用户共享引用，返回 409 和 "template is shared and in use"。聚合函数 percentile 需要额外参数 p（0-100 之间的数值），缺失返回 400 和 "percentile function requires parameter p"。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
