帮我用 TypeScript 写一个指标采集和可视化的后端服务，提供类似Grafana的数据查询能力。

指标数据模型：每个指标有名称、标签（键值对集合）和数值。指标按时间序列存储，每条记录包含时间戳和值。数据写入时按指标名称和标签组合做去重——相同名称和标签的指标在同一个时间戳只保留最新值。

查询接口支持按指标名称、标签筛选条件和时间范围查询。聚合函数支持avg、sum、max、min、count和percentile。时间范围查询时按指定间隔分组聚合（如每5分钟一个数据点）。如果某个间隔内没有数据点，可以选择返回null或用前一个值填充。指标模板功能：管理员可以创建指标模板，定义一组常用指标的查询配置。模板可以共享给多个用户。查询大量时间序列数据时要用分页限制返回的数据点数量。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
