帮我用 TypeScript 写一个分布式追踪数据收集的后端服务，类似Jaeger的功能。

追踪数据由trace组成，每个trace包含多个span。每个span有traceId、spanId、父spanId、操作名称、服务名称、开始时间、持续时间和标签集合。数据通过接口批量上报，每次最多500个span。

查询功能支持按traceId精确查询和按条件搜索（服务名称、操作名称、时间范围、最小持续时间）。搜索结果按开始时间倒序返回，支持分页。服务依赖图：根据追踪数据自动生成服务之间的调用关系图，统计每对服务之间的调用量和平均延迟。调用关系是单向的，A调B和B调A是两条独立的边。追踪数据保留最近7天的，过期数据后台定时清理，清理时不能阻塞正常的数据写入和查询。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
