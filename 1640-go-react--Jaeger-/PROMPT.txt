可观测性团队那边提了个需求，要一套分布式追踪数据收集服务，TypeScript 实现。类似Jaeger的功能。

追踪数据由trace组成，每个trace包含多个span。每个span有traceId、spanId、父spanId、操作名称、服务名称、开始时间、持续时间和标签集合。数据通过接口批量上报，每次最多500个span。

查询功能支持按traceId精确查询和按条件搜索（服务名称、操作名称、时间范围、最小持续时间），搜索结果按开始时间倒序返回支持分页。服务依赖图：根据追踪数据自动生成服务之间的调用关系图，统计每对服务之间的调用量和平均延迟，调用关系是单向的A调B和B调A是两条独立的边。追踪数据保留最近7天的，过期数据后台定时清理，清理时不能阻塞正常的数据写入和查询。每个trace有独立的span查询接口和详情接口，路径类似 /traces/{traceId}/spans/{spanId}。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
