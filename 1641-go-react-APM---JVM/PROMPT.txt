帮我用 TypeScript 写一个应用性能监控的后端服务，采集和分析应用的运行时指标。

应用注册后定期上报指标数据，包括：HTTP请求统计（总请求数、各状态码计数、平均响应时间）、数据库查询统计（查询次数、慢查询数量、平均耗时）、JVM/运行时指标（内存使用量、GC次数、线程数）和自定义指标（用户自定义的键值对数值）。指标数据按分钟粒度聚合存储。

异常检测：对比最近5分钟和前1小时的指标均值，如果偏差超过2倍标准差则标记为异常。异常检测在每次新数据写入后异步执行。应用拓扑图：根据上报的调用链数据自动生成应用间的调用关系。每个节点展示应用名称和当前健康状态（基于异常检测结果）。报警规则：管理员配置指标阈值和通知方式，触发后生成告警记录。同一个报警规则对同一个应用在告警未恢复前不重复触发。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
