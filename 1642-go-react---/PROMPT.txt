用 TypeScript 写一个错误追踪服务。应用运行时异常太多了需要统一收集和聚合。

应用通过 POST /errors 上报错误事件，每个事件包含服务名称、错误类型、错误消息、堆栈信息、发生时间和额外上下文（键值对）。服务名称、错误类型和错误消息为必填，缺少时返回400指出缺失字段。相同错误类型和消息的事件自动聚合为一个错误组，堆栈取最顶层帧做辅助判断，新增事件更新错误组的最近发生时间、发生次数加一。

错误组有四个状态：未处理→已确认→已解决→已忽略。状态只能单向流转——未处理到已确认，已确认到已解决或已忽略，跳步操作返回400提示非法状态转换（比如不能从未处理直接到已忽略）。已解决的错误组如果再收到相同类型和消息的新事件，自动回到未处理状态。错误组状态变更接口 PUT /error-groups/{id}/status。错误趋势统计 GET /error-groups/{id}/trend 按小时返回事件数量，部署标记接口 POST /deployments 记录时间点和版本号。高频错误自动标记：24小时内超过100次或影响用户超50人的标记为高频。错误组列表 GET /error-groups 支持按状态和高频标记筛选，已解决且无新事件的错误组30天后自动清理。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
