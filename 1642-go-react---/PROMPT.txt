帮我用 TypeScript 写一个错误追踪的后端服务，收集和聚合应用运行时的异常信息。

应用通过接口上报错误事件，每个事件包含服务名称、错误类型、错误消息、堆栈信息、发生时间和额外上下文（键值对）。相同错误类型的多个事件自动聚合为一个错误组。聚合规则：错误类型和错误消息完全相同的事件归为同一组，堆栈信息取最顶层的那一帧做辅助判断。

错误组展示信息包含错误类型、消息、首次发生时间、最近发生时间、发生次数和影响用户数。错误组有状态：未处理、已确认、已解决和已忽略。标记为已解决后如果同一错误组又出现新事件，自动重新打开。错误趋势统计：按小时统计每个错误组的事件数量，标记部署时间点帮助判断是否是新版本引入的问题。高频错误的判定：24小时内发生次数超过100次或影响用户数超过50人的标记为高频。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
