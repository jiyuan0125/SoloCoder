用 TypeScript 写一个错误追踪服务。应用运行时异常太多了需要统一收集和聚合。

应用通过接口上报错误事件，每个事件包含服务名称、错误类型、错误消息、堆栈信息、发生时间和额外上下文（键值对）。相同错误类型的多个事件自动聚合为一个错误组，聚合规则：错误类型和错误消息完全相同的事件归为同一组，堆栈信息取最顶层的那一帧做辅助判断。

错误组展示信息包含错误类型、消息、首次发生时间、最近发生时间、发生次数和影响用户数。错误组有状态：未处理→已确认→已解决→已忽略，标记为已解决后如果同一错误组又出现新事件自动重新打开回到未处理。错误趋势统计按小时统计每个错误组的事件数量，标记部署时间点帮助判断是否是新版本引入的问题。高频错误的判定：24小时内发生次数超过100次或影响用户数超过50人的标记为高频。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
