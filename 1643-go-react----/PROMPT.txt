性能热点排查全靠猜太低效了，所以想做一个性能剖析服务，TypeScript 后端。采集和分析应用的性能瓶颈。

性能剖析数据按应用和服务分组。每次剖析记录包含开始时间、持续时间和一组采样数据，每个采样数据包含函数名、文件名、行号、采样次数和自身耗时。采集方式支持CPU剖析和内存剖析两种。

火焰图数据生成：将所有采样数据按调用栈聚合，计算每个函数的总耗时和自身耗时（不含子调用），总耗时占比超过10%的函数标记为热点。函数调用关系根据堆栈信息自动构建树形结构。对比功能：选择两次剖析数据进行对比，展示耗时变化最大的函数列表，对比时如果函数名相同但文件路径不同视为不同函数。剖析数据按应用保留最近100次，超出后自动清理最早的，同时只允许一个应用进行一次剖析采集。

Express + TypeScript + SQLite，npm run build 通过就行。
