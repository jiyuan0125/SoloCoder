帮我用 TypeScript 写一个性能剖析的后端服务，采集和分析应用的性能热点。

性能剖析数据按应用和服务分组。每次剖析记录包含开始时间、持续时间和一组采样数据。每个采样数据包含函数名、文件名、行号、采样次数和自身耗时。采集方式支持CPU剖析和内存剖析两种。

火焰图数据生成：将所有采样数据按调用栈聚合，计算每个函数的总耗时和自身耗时（不含子调用）。总耗时占比超过10%的函数标记为热点。函数调用关系根据堆栈信息自动构建树形结构。对比功能：选择两次剖析数据进行对比，展示耗时变化最大的函数列表。对比时如果函数名相同但文件路径不同，视为不同函数。剖析数据按应用保留最近100次，超出后自动清理最早的。同时只允许一个应用进行一次剖析采集。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
