帮我用 TypeScript 写一个告警通知中心的后端服务，统一管理多种告警渠道的通知发送。

告警源通过接口推送告警事件，包含告警名称、级别（信息/警告/严重/紧急）、来源系统、描述和关联的指标数据。告警创建后进入处理流程。通知渠道支持邮件、短信和Webhook三种，都是模拟发送。每种渠道可以配置是否启用和发送频率限制。

告警聚合：同一告警源在5分钟内产生的相同级别和名称的告警合并为一条，记录出现次数。合并后的告警只发送一次通知，通知内容包含出现次数。告警升级：严重级别的告警如果在15分钟内未被确认，自动升级为紧急并发送更高优先级的通知。升级规则用创建时间加15分钟来算。告警可以标记为已确认和已解决。已确认的告警不再触发升级。已解决的告警如果再次出现则算新告警。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
