我们运维最近需要一套告警通知中心，用 TypeScript 做。统一管理多种告警渠道的通知发送。

告警源通过接口推送告警事件，包含告警名称、级别（信息/警告/严重/紧急）、来源系统、描述和关联的指标数据。通知渠道支持邮件、短信和Webhook三种都是模拟发送，每种渠道可以配置是否启用和发送频率限制。

告警聚合：同一告警源在5分钟内产生的相同级别和名称的告警合并为一条记录出现次数，合并后的告警只发送一次通知，通知内容包含出现次数。告警升级：严重级别的告警如果在15分钟内未被确认自动升级为紧急并发送更高优先级的通知，升级规则用创建时间加15分钟来算。告警可以标记为已确认和已解决，已确认的告警不再触发升级，已解决的告警如果再次出现算新告警。聚合窗口关闭前如果又来了相同告警，窗口要延长而不是开新窗口。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
