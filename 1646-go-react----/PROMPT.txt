定时任务管理系统，TypeScript + Express 后端。任务散在各处执行情况不透明。

任务创建时指定名称、执行频率（支持cron表达式和固定间隔两种）、超时时间和执行参数。cron表达式保存前校验合法性非法表达式不能保存。任务执行时记录开始时间、结束时间、状态和输出日志，执行日志支持按任务和时间范围查询。

任务分组管理：任务可以按业务分组，每组可以整体暂停和恢复，暂停的组内所有任务都不执行。任务依赖：可以配置任务之间的依赖关系，被依赖的任务成功后依赖任务才触发，被依赖任务失败则依赖任务跳过执行。任务有已创建→等待依赖→待执行→执行中→已完成/已超时/已跳过几个状态，已跳过的任务如果依赖的任务后来成功了不能自动重新触发。任务超时处理：执行时间超过配置的超时时间后自动标记为超时但不强制终止（模拟场景）。同一个任务如果上一次执行还没结束新的调度触发要跳过而不是排队。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
