帮我用 TypeScript 写一个定时任务管理的后端服务，管理周期性任务的创建和执行。

任务创建时指定名称、执行频率（支持cron表达式和固定间隔两种）、超时时间和执行参数。cron表达式保存前校验合法性，非法表达式不能保存。任务执行时记录开始时间、结束时间、状态和输出日志。执行日志支持按任务和时间范围查询。

任务分组管理：任务可以按业务分组，每组可以整体暂停和恢复。暂停的组内所有任务都不执行。任务依赖：可以配置任务之间的依赖关系，被依赖的任务成功后依赖任务才触发。被依赖任务失败则依赖任务跳过执行。任务超时处理：执行时间超过配置的超时时间后自动标记为超时，但不强制终止（模拟场景）。同一个任务如果上一次执行还没结束（仍在运行中），新的调度触发要跳过而不是排队。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
