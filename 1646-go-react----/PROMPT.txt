定时任务管理系统，TypeScript + Express 后端。任务散在各处执行情况不透明。

任务创建接口 POST /tasks 指定名称、执行频率（cron表达式或固定间隔秒数）、超时时间和执行参数。cron表达式保存前校验合法性，非法表达式返回400提示格式错误。任务分组接口 POST /task-groups，任务创建时通过groupId关联分组。组暂停接口 PUT /task-groups/{id}/pause 和恢复接口 PUT /task-groups/{id}/resume，暂停组内所有任务不执行。

任务依赖配置接口 POST /tasks/{id}/dependencies 传入依赖的任务ID列表，被依赖任务成功后依赖任务才触发，被依赖任务失败则依赖任务标记为已跳过。任务状态：已创建→等待依赖→待执行→执行中→已完成/已超时/已跳过，只能按顺序流转不允许跳步，比如不能从已创建直接到执行中返回400。已跳过的任务即使后来依赖成功了也不自动重新触发需要手动重启。任务超时处理：执行超过配置的超时时间后标记为已超时。同一任务上一次执行还没结束时新的调度直接跳过不排队。执行日志查询接口 GET /tasks/{id}/executions 支持按时间范围筛选，返回每次执行的开始时间、结束时间、状态和输出。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
