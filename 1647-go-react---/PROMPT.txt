最近在搞审批流程，需要一个工作流引擎，TypeScript 实现。各种审批流程全靠邮件走太不规范了。

工作流由多个节点组成，节点类型包括：审批节点（需要指定审批人）、条件分支节点（根据条件走不同分支）、并行节点（多个分支同时执行）和通知节点。工作流创建后可以启动实例，每个实例独立跟踪各节点的执行状态。

审批节点支持通过和拒绝两种操作，拒绝后工作流可以配置是直接终止还是跳回指定节点重新执行。条件分支的判断表达式支持简单的字段比较和逻辑运算。并行节点所有分支都完成后才继续下一步。工作流变量：每个实例维护一组变量在执行过程中可以被节点读取和修改，变量值可以是字符串、数字或布尔类型。审批节点执行时需要读取变量来做条件判断，判断结果又要更新到实例变量中。同一工作流定义可以同时运行多个实例互不影响，实例的状态变更要记录操作人和时间。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
