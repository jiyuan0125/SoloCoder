帮我用 TypeScript 写一个工作流引擎的后端服务，管理和执行多步骤业务流程。

工作流由多个节点组成，节点类型包括：审批节点（需要指定审批人）、条件分支节点（根据条件走不同分支）、并行节点（多个分支同时执行）和通知节点。工作流创建后可以启动实例，每个实例独立跟踪各节点的执行状态。

审批节点支持通过和拒绝两种操作。拒绝后工作流可以配置是直接终止还是跳回指定节点重新执行。条件分支的判断表达式支持简单的字段比较和逻辑运算。并行节点所有分支都完成后才继续下一步。工作流变量：每个实例维护一组变量，在执行过程中可以被节点读取和修改。变量值可以是字符串、数字或布尔类型。同一工作流定义可以同时运行多个实例，实例之间互不影响。实例的状态变更要记录操作人和时间。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
