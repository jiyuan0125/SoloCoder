最近在搞审批流程，需要一个工作流引擎，TypeScript 实现。各种审批流程全靠邮件走太不规范了。

工作流定义接口 POST /workflows，由多个节点组成，节点类型包括审批节点（指定审批人列表）、条件分支节点（根据条件走不同分支）、并行节点（多分支同时执行）和通知节点。每个节点有唯一ID和类型，审批节点必须指定至少一个审批人否则返回400。工作流启动接口 POST /workflows/{id}/instances，每个实例独立跟踪各节点状态。

审批操作接口 POST /instances/{instanceId}/nodes/{nodeId}/approve 和拒绝接口 POST /instances/{instanceId}/nodes/{nodeId}/reject。拒绝后工作流根据定义配置决定是终止还是跳回指定节点重新执行，跳回时该节点之后的所有节点状态重置为待执行。条件分支从工作流变量中读取值判断，变量不存在时返回400提示缺少变量。并行节点所有分支完成后才推进到下一步。工作流变量接口 GET /instances/{id}/variables 返回当前变量快照，节点执行时可以修改变量。同一工作流定义可同时运行多个实例互不影响。实例状态变更记录操作人和时间，历史查询接口 GET /instances/{id}/history。非当前待执行节点调用审批操作返回400提示节点不可操作。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
