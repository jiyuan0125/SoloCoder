帮我用 TypeScript 写一个数据隐私合规管理的后端服务，管理用户数据的收集、使用和删除请求。

数据收集管理：记录系统收集的每类用户数据（姓名、邮箱、手机号、地址、行为数据等），包含数据用途、法律依据（同意/合同/法定义务/合法利益）和保留期限。超过保留期限的数据自动标记为待清理。

用户数据主体权利请求：支持三种类型的请求——数据访问（用户要求查看自己的所有数据）、数据更正（用户要求修改不正确的数据）和数据删除（用户要求删除自己的数据，即"被遗忘权"）。请求提交后有30天的处理期限，处理期限用创建时间加30天来算。数据删除请求需要先检查是否有法律要求保留的数据（比如财务数据需要保留5年），有保留义务的数据只能匿名化不能删除。同意管理：记录用户对各项数据收集的同意状态和同意时间，用户可以随时撤回同意。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
