GDPR合规审查快到了，数据隐私这块全是漏洞，所以想做一个数据隐私合规管理服务，TypeScript + Express。

数据收集管理：记录系统收集的每类用户数据（姓名、邮箱、手机号、地址、行为数据等），包含数据用途、法律依据（同意/合同/法定义务/合法利益）和保留期限，超过保留期限的数据自动标记为待清理。

用户数据主体权利请求支持三种类型——数据访问（用户查看自己的所有数据）、数据更正（用户修改不正确的数据）和数据删除（"被遗忘权"）。每种请求类型有独立的提交和查询接口，数据访问还有导出接口，请求状态也可以独立查看。请求提交后有30天的处理期限，处理期限用创建时间加30天来算。数据删除请求需要先检查是否有法律要求保留的数据（比如财务数据需要保留5年），有保留义务的数据只能匿名化不能删除。同意管理：记录用户对各项数据收集的同意状态和同意时间，用户可以随时撤回同意。

npm run build 能编译通过，端口环境变量指定。
