GDPR合规审查快到了，数据隐私这块全是漏洞，所以想做一个数据隐私合规管理服务，TypeScript + Express。

数据类别管理接口 POST /data-categories 记录系统收集的每类用户数据（姓名、邮箱、手机号、地址、行为数据等），包含数据用途、法律依据（同意/合同/法定义务/合法利益）和保留期限天数，保留期限必填且必须大于0否则返回400。超过保留期限的数据后台定时扫描标记为待清理状态，标记前不影响正常读取。

用户数据主体权利请求三种类型各有独立接口：数据访问 POST /requests/access、数据更正 POST /requests/correction、数据删除 POST /requests/deletion，都需提供用户标识。请求提交后30天内须处理（创建时间加30天为截止），到期未处理状态标记为已逾期。数据删除请求处理时先检查该数据类别是否配置了法定义务保留依据，有保留义务的执行匿名化而不是删除匿名化后原值不可恢复。请求状态查询 GET /requests/{id}，数据访问结果导出 GET /requests/access/{id}/export 返回用户全部数据JSON。同意管理 POST /consents 记录用户对各类数据收集的同意状态和时间，撤回接口 DELETE /consents/{consentId} 撤回后对应数据类别的收集标记为无同意基础。

npm run build 能编译通过，端口环境变量指定。
