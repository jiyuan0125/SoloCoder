帮我用 TypeScript 写一个权限管理的后端服务，实现RBAC角色权限控制。

系统管理用户、角色和权限三个实体。权限定义对资源的操作，格式为"资源:操作"如"user:read""order:write"。角色是一组权限的集合，支持角色继承——子角色自动继承父角色的所有权限，继承关系不能出现循环。用户可以被分配多个角色，最终权限是所有角色权限的并集。

权限检查接口：传入用户ID、资源和操作，返回是否允许。检查时先获取用户的所有角色（包括通过继承得到的），再汇总所有权限进行判断。角色变更后权限立即生效。管理员可以创建自定义角色、分配权限和设置继承关系。用户-角色分配和角色-权限分配的变更都要记录审计日志。同一个用户对同一个角色不能重复分配。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
