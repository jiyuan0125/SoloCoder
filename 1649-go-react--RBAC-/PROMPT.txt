用 TypeScript 写一个RBAC权限管理服务。权限体系太乱各系统各搞一套需要统一。

系统管理用户、角色和权限三个实体。权限定义对资源的操作，格式为"资源:操作"如"user:read""order:write"。角色是一组权限的集合，支持角色继承——子角色自动继承父角色的所有权限，继承关系不能出现循环。用户可以被分配多个角色，最终权限是所有角色权限的并集。

权限检查接口：传入用户ID、资源和操作返回是否允许。检查时先获取用户的所有角色（包括通过继承得到的），再汇总所有权限进行判断，角色变更后权限立即生效。管理员可以创建自定义角色、分配权限和设置继承关系。用户-角色分配和角色-权限分配的变更都要记录审计日志，同一个用户对同一个角色不能重复分配。角色删除时如果还有用户关联该角色，删除操作要被拒绝并提示哪些用户在使用。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
