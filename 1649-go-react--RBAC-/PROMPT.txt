用 TypeScript 写一个RBAC权限管理服务。权限体系太乱各系统各搞一套需要统一。

系统管理用户、角色和权限三个实体。权限创建接口 POST /permissions，格式为"资源:操作"如"user:read""order:write"，格式不对返回400说明正确格式。角色创建接口 POST /roles，角色是一组权限的集合。权限分配接口 POST /roles/{roleId}/permissions 将权限绑定到角色，角色继承接口 POST /roles/{roleId}/inherit/{parentRoleId} 让子角色自动获得父角色所有权限，设置继承时检查是否形成循环继承链，有循环则返回400拒绝。

用户分配角色接口 POST /users/{userId}/roles，用户可分配多个角色最终权限是所有角色权限并集。同一用户同一角色重复分配返回409提示已分配。权限检查接口 POST /permissions/check 传入用户ID、资源和操作返回allowed布尔值，检查时获取用户所有角色包括继承来的角色再汇总判断，角色或权限变更后下次检查立即生效。角色删除接口 DELETE /roles/{roleId}，如果还有用户关联该角色返回409提示哪些用户在使用并拒绝删除。用户-角色和角色-权限的每次变更写入审计日志，审计日志查询接口 GET /audit-logs 支持按操作类型和时间范围筛选。

Express + TypeScript + SQLite，npm run build 能跑起来就行。
