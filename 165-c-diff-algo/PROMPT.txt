帮我用 C 写一个文本文件的差异对比工具。场景是：运维团队管理着很多配置文件（nginx 配置、应用配置、系统参数文件等），每次修改配置之前要先看清楚改了什么，确认没问题再上线。工具接收两个版本的文本内容（旧版和新版），对比之后输出一份详细的差异报告。要求以行为基本单位进行比较，输出结果里标明：哪些行被删除了（只存在于旧版中）、哪些行被新增了（只存在于新版中）、哪些行被修改了（同一位置的内容变了）。对于修改的行，要同时显示旧内容和新内容方便对照。支持一个「忽略空白」模式——开启后如果两行只是空格或制表符的数量不同，不算作修改。输出格式类似 Linux 下 diff 命令的效果：删除的行前面加 - 号，新增的行前面加 + 号，没有变化的行前面加空格。最后统计一下：总共多少行被删除、多少行被新增、多少行被修改。两个版本的文本可以直接作为字符串传入，也可以从文件读取。还要考虑一个大文件的场景：如果两个文件各有几万行，对比过程不能太慢，需要有一定的效率。用纯 C 写，gcc 编译通过。还要支持一种「上下文行数可配置」的功能——不只是显示前后3行，用户可以指定显示前后N行。如果两个文件完全相同，要输出「文件内容一致」而不是显示一堆没有变化的行。
代码拆成至少 4 个源文件：行级比对算法、差异结果生成、输出格式化、主程序，各自有头文件和实现文件。gcc 编译能过。
