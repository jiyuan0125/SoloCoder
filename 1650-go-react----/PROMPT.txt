帮我用 TypeScript 写一个审计日志的后端服务，记录系统中所有敏感操作的日志。

审计日志记录包含：操作人ID、操作类型（创建/读取/更新/删除）、资源类型、资源ID、操作时间、操作前数据快照、操作后数据快照和请求来源IP。日志通过接口写入，写入后不可修改不可删除，只能追加。

查询审计日志支持按操作人、操作类型、资源类型、时间范围多个条件组合筛选。查询结果按时间倒序，支持分页。数据快照对比：选择同一条资源的两条日志，展示两次操作之间的字段级差异。差异只展示发生变化的字段。日志数据量大时查询要控制返回条数。审计日志保留策略默认永久保留，也可以配置保留天数，过期数据后台定时清理。同一个操作如果短时间内重复提交（比如双击），只记录一次日志。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
