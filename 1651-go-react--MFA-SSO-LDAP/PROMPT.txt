帮我用 TypeScript 写一个认证中心的后端服务，支持多因素认证和单点登录。

用户认证支持用户名密码登录。密码在内存中用bcrypt哈希存储。登录成功后颁发一个token（JWT格式），token包含用户ID、签发时间和过期时间。token验证接口检查签名和过期时间。

多因素认证（MFA）：用户可以在个人设置中开启MFA。开启时生成一个TOTP密钥（Base32编码），用户用认证器App扫描绑定。之后每次登录除了密码还要输入TOTP验证码。TOTP验证码基于当前时间窗口生成，允许前后1个时间窗口的偏差。单点登录（SSO）：提供一个SAML风格的简化认证流程。第三方应用将用户重定向到认证中心登录，登录成功后认证中心回调到第三方应用并携带认证凭证。凭证用HMAC签名，第三方应用验证签名后信任该凭证。同一个用户同时在多个应用登录时，注销认证中心后所有应用的会话都失效。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
