认证中心系统，TypeScript 后端。要支持多因素认证和单点登录。

用户先用用户名密码登录，密码用bcrypt哈希存在内存里。登录成功后颁发JWT格式的token，包含用户ID、签发时间和过期时间，有个接口专门验证token的签名和有效期。

多因素认证这块，用户可以在设置里开启，开启时生成Base32编码的TOTP密钥，用户拿认证器App扫码绑定。之后每次登录除了密码还要输TOTP验证码，验证码允许前后1个时间窗口的偏差。单点登录做一个简化版的SAML流程：第三方应用把用户重定向过来登录，成功后回调到第三方并携带用HMAC签名的认证凭证，第三方验证签名后信任该凭证。同一个用户在多个应用同时登录时，注销认证中心后所有应用的会话都失效。

登录成功后颁发token的同时要自动记录一条认证日志，日志写入不需要再走一遍鉴权。登录失败连续5次冻结账号15分钟。

Express + TypeScript + SQLite，npm run build 能编译，node dist/server.js 能启动。
