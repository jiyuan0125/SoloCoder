帮我用 TypeScript 写一个密码策略管理的后端服务，提供统一的密码强度校验接口。

后端提供密码校验接口，输入密码字符串返回校验结果（通过或失败）和具体原因。策略可配置：最小长度（默认8位，最大128位）、是否必须包含大写字母、小写字母、数字和特殊字符、是否禁止包含用户名（不区分大小写的正向包含检查）、是否禁止使用最近N次的历史密码（默认3次）。

密码历史记录按用户存储。修改密码时要检查新密码是否在历史记录中。历史记录满N条后最早的被淘汰。密码强度评分：根据策略规则给密码打分（0到100分），包含大写加20分、包含数字加20分、包含特殊字符加20分、长度超过12加20分、长度超过16加20分。密码规则变更后，已通过旧规则校验的密码不需要强制修改，但下次修改时按新规则校验。同一个用户短时间内多次请求校验接口要考虑限流。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
