客服那边提了个需求，要一套用户会话管理服务，TypeScript 后端加命令行客户端。

每个用户登录后创建会话对象：会话ID、用户ID、设备信息、IP地址、登录时间和最后心跳时间。客户端每30秒发一次心跳续命，超过90秒没收到的标记为离线。不同套餐允许同时在线人数不一样，达到上限后新登录把最早创建的会话踢掉。

管理员可以看所有在线会话列表，按用户和IP筛选，也能远程踢掉指定会话。会话统计包括当前在线人数、今日登录人次和平均会话时长——时长从登录到最后心跳来算。同一个用户同一设备重复登录不创建新会话只更新心跳时间。会话记录保留最近30天。

踢掉会话的时候系统内部要往审计模块发一条通知记录，审计通知本身不需要再校验会话有效性。

Express + TypeScript，npm run build 能编译通过，node dist/server.js 能启动。
