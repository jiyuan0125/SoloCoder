帮我用 TypeScript 写一个用户会话管理的后端服务，管理在线用户的会话信息。

每个用户登录后创建一个会话对象，包含会话ID、用户ID、设备信息、IP地址、登录时间和最后心跳时间。客户端每隔30秒发一次心跳请求续命，超过90秒没收到心跳的会话自动标记为离线。不同套餐允许同时在线的人数不一样，达到上限后新登录会把最早创建的会话踢下线。

管理员可以查看所有在线会话列表，支持按用户和IP筛选。管理员可以远程踢掉指定会话，踢掉后会话立即失效。会话统计：当前在线人数、今日登录人次、平均会话时长。会话时长从登录时间到最后心跳时间来算。同一个用户在同一个设备上重复登录时不会创建多个会话，而是更新已有会话的心跳时间。会话记录保留最近30天的。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
