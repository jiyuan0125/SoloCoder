帮我用 TypeScript 写一个API访问安全网关的后端服务，做IP白名单和频率限制。

所有API请求先经过这个网关。网关按顺序执行检查：协议解析（从请求头提取真实IP，处理X-Forwarded-For和X-Real-IP）、IP白名单校验、频率限制和风险打分，全部通过后才返回允许的结果。

IP白名单支持单IP和CIDR格式的IP段。白名单变更后立即生效。频率限制按IP维度，每个IP每分钟最多60次请求，用滑动窗口实现。风险打分根据多个因素计算：请求频率（正常0分，接近限制加30分，触发限制加100分）、IP是否在黑名单中（加50分）、请求路径是否包含敏感关键字如admin和config（加20分）。总分超过80分标记为高风险，高风险的请求直接拒绝。黑名单IP管理：管理员可以添加和移除黑名单IP，添加时可以指定过期时间，过期时间用添加时间加有效时长来算。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
