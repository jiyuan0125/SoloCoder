帮我用 TypeScript 写一个设备信任管理的后端服务，管理可信设备的注册和验证。

设备指纹生成：服务端接收客户端采集的设备信息（浏览器类型和版本、操作系统、屏幕分辨率、时区、语言偏好等），对字段按固定顺序排序后拼接哈希，生成32位十六进制设备指纹ID。字段顺序不同会导致同一个设备算出不同指纹，排序是关键。用户第一次在新设备登录时做设备指纹校验，通过后该设备标记为"已信任"，后续30天内再次登录不需要额外验证。信任有效期用创建时间加30天来算。

管理员可以查看所有用户的可信设备列表，也能远程解除某个设备的信任状态。解除后该设备下次登录需要重新验证。设备信任记录包含用户ID、设备指纹、首次信任时间、最后使用时间和信任状态。同一用户同一设备的信任记录只有一条，重复登录更新最后使用时间。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
