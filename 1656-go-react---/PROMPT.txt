帮我做一套设备信任管理服务，TypeScript 后端。登录安全这一块需要设备级别的信任管理。

服务端接收客户端采集的设备信息（浏览器类型版本、操作系统、屏幕分辨率、时区、语言偏好等），字段按固定顺序排序后拼接哈希，生成32位十六进制设备指纹ID。字段排序是关键，顺序不同会算出不同指纹。用户第一次在新设备登录时做指纹校验，通过后标记为"已信任"，后续30天内再登录不用额外验证。信任有效期用创建时间加30天算。

管理员可以看所有用户的可信设备列表，也能远程解除某个设备的信任。解除后下次登录要重新验证。信任记录包含用户ID、设备指纹、首次信任时间、最后使用时间和信任状态。同一用户同一设备只有一条信任记录，重复登录更新最后使用时间。

设备信任校验通过后要自动创建一条信任记录，创建记录时如果发现已经有记录了就更新最后使用时间和信任状态。如果信任记录刚好过期了又被同一个设备访问，要重新走一遍校验流程而不是直接更新。

Express + TypeScript + SQLite，npm run build 能跑就行。
