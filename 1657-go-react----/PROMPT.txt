帮我用 TypeScript 写一个实时风控引擎的后端服务，对交易请求做实时风险评估。

规则引擎管理：每条规则有名称、条件表达式和风险权重（1到100）。条件表达式支持字段比较（如金额大于10000）、字符串匹配（如设备指纹在黑名单中）和数值范围判断。规则之间用AND和OR连接形成规则树。规则按优先级排序，命中第一条后停止。

风险评分计算：每笔交易请求经过所有匹配的规则，命中的规则权重相加得到总分。总分超过阈值（默认50分）的交易拦截或进入人工审核队列。评分在30到50之间的标记为可疑并记录日志。人工审核队列中的交易由风控人员逐条审核，标记为正常或欺诈。规则可以在线增删改，变更后立即生效不需要重启。同一个交易请求短时间内重复提交到风控引擎，只评估一次不重复计分。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
