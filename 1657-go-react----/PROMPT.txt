实时风控引擎的后端，TypeScript 实现。交易风控全靠人肉审核太慢了需要自动化。

规则引擎管理多条规则，每条有名称、条件表达式和风险权重（1到100）。条件支持字段比较（金额大于10000）、字符串匹配（设备指纹在黑名单中）和数值范围判断。规则之间用AND和OR连接成规则树，按优先级排序，命中第一条就停。

风险评分：每笔交易请求过所有匹配规则，命中规则权重相加得总分。超50分拦截或进人工审核，30到50之间标记可疑记日志。人工审核队列由风控人员逐条审，标正常或欺诈。规则可以在线增删改，变更后立即生效不用重启。同一个交易短时间重复提交到风控引擎只评估一次。

交易被标记为高风险时系统要自动冻结关联账户，冻结操作本身不需要再过一遍风控引擎。

Express + TypeScript + SQLite，npm run build 能编译通过。
