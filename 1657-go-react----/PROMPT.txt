实时风控引擎的后端，TypeScript 实现。交易风控全靠人肉审核太慢了需要自动化。

规则引擎管理多条规则，每条有名称、条件表达式和风险权重（1到100），权重超范围返回 400。条件支持字段比较（金额大于10000）、字符串匹配（设备指纹在黑名单中）和数值范围判断。规则之间用AND和OR连接成规则树，按优先级排序，命中第一条就停。规则ID不存在返回 404，条件表达式语法错误返回 400。

风险评分：每笔交易请求过所有匹配规则，命中规则权重相加得总分。超50分拦截或进人工审核返回 403 和风险分数，30到50之间标记可疑记日志返回 200 加风险标记。人工审核队列由风控人员逐条审，标正常或欺诈，审核记录不存在返回 404。规则可以在线增删改，变更后立即生效不用重启，规则更新过程中正在评估的交易用旧规则还是新规则都可以但不能卡住。同一个交易短时间重复提交到风控引擎只评估一次，重复提交返回 200 和首次评估结果。

交易被标记为高风险时系统要自动冻结关联账户，冻结操作本身不需要再过一遍风控引擎。冻结和风险标记的记录要一起成功，冻结失败时返回 500 但风险标记要保留，后续通过补偿机制重试冻结。

Express + TypeScript + SQLite，npm run build 能编译通过。
