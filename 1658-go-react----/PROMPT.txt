帮我用 TypeScript 写一个反欺诈检测的后端服务，管理用户、订单和设备的关联分析。

系统维护用户、订单和设备三类实体。每个用户有基本信息和风险标签，每个订单有商品信息、金额、收货地址和支付方式，每个设备有指纹ID和关联的用户列表。三者之间通过外键关联。

关联分析：当检测到可疑订单时，系统自动查询该订单关联用户的所有历史订单、关联设备的所有用户和关联用户的所有设备，构建关联图谱。图谱展示要从可疑订单出发向外展开两层关联。欺诈标记：调查员确认欺诈后，关联用户加入黑名单，关联设备也加入黑名单。黑名单用户的新订单自动标记为高风险。误判放行时模型规则不受影响，但该用户的风险评分降低。风险评分基于黑名单关联度计算：关联的黑名单实体越多评分越高。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
