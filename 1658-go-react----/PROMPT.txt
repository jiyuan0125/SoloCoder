欺诈检测太被动了总是用户投诉才发现，所以想做一个反欺诈检测平台，TypeScript 后端。

系统维护用户、订单和设备三张表，用户有基本信息和风险标签，订单有商品信息、金额、收货地址和支付方式，设备有指纹ID和关联用户列表。三者通过外键关联。

检测到可疑订单时，自动查关联用户的所有历史订单、关联设备的所有用户和这些用户的所有设备，构建关联图谱。图谱从可疑订单出发向外展开两层。调查员确认欺诈后，关联用户和设备都加入黑名单，黑名单用户的新订单自动标高风险。误判放行时规则不变但该用户风险评分降低。风险评分基于黑名单关联度计算：关联的黑名单实体越多分越高。

调查员标记欺诈时要同时更新用户风险标签和设备黑名单状态，这两个更新要在同一步完成不能只更新一个。

Express + TypeScript + SQLite，npm run build 能编译通过，node dist/server.js 能启动。
