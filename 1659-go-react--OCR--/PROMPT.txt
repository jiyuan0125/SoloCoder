帮我用 TypeScript 写一个内容安全审核的后端服务，对文本和图片内容做自动审核。

文本审核维护一个敏感词库（Trie树结构，支持前缀匹配），对提交的文本做扫描。匹配到敏感词时记录命中位置和词内容。为防止用户通过插入特殊字符绕过（比如"色[]情"），扫描前要先做文本标准化：去除所有非汉字非字母非数字的字符，全角转半角，连续空格合并为一个。标准化后的文本做匹配，返回结果时要映射回原始文本的位置。

图片审核暂时模拟：根据图片URL的hash值决定结果，30%概率待审核，5%概率违规，其余通过。审核队列管理：自动审核通过的直接放行，待审核和违规的进入人工审核队列。审核员逐条审核并做出处理决定（通过/删除/警告）。批量提交的内容如果其中一条违规，不影响其他内容的审核结果。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
