我们社区垃圾内容太多了，需要一套反垃圾系统，用 TypeScript 做。

频率限制对每个用户的发帖和评论做实时监控：每分钟最多3条，每小时最多20条，每天最多100条。三个维度独立计数，任何一个超限都触发限制。超限后该用户后续发布的内容自动标为"待审核"。计数器用滑动窗口实现，窗口到期后自动清除。

内容分析用简单规则匹配：包含外部链接（http开头）、连续重复字符超5个、全大写字母超50%的内容自动标可疑。可疑和超限内容都进审核队列。黑名单用户的所有内容直接拦截不进队列。白名单用户（管理员标记的优质用户）跳过自动审核直接发布。黑名单可以设过期时间，用添加时间加有效时长算。

标记用户为黑名单时要同步清理该用户所有待审核内容的状态——这些内容改为"发布者已拉黑"状态，清理过程中每条内容的状态更新互相不影响，某条更新失败不影响其他条。

Express + TypeScript + SQLite，npm run build 能编译通过。
