帮我用 TypeScript 写一个社区反垃圾系统的后端服务，结合频率限制、内容分析和黑名单治理垃圾内容。

频率限制对每个用户的发帖和评论行为做实时监控：每分钟最多3条，每小时最多20条，每天最多100条。三个维度独立计数，任何一个超限都触发限制。超限后该用户后续发布的内容自动标记为"待审核"。计数器用滑动窗口实现，窗口到期后自动清除。

内容分析：对发布内容做简单规则匹配，包含外部链接（http开头）、连续重复字符超过5个、全大写字母超过50%的内容自动标记为可疑。可疑内容和超限内容都进入审核队列。黑名单管理：管理员可以添加用户到黑名单，黑名单用户的所有内容直接拦截不进入审核队列。黑名单可以设置过期时间，过期时间用添加时间加有效时长来算。白名单用户（管理员标记的优质用户）的内容跳过自动审核直接发布。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
