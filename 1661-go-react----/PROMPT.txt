广告投放全靠运营手动调太低效了，所以想做一个广告投放管理平台，TypeScript 后端。

每个广告计划有预算（精确到分用整数存）、每日预算上限、定向条件（年龄段、性别、地域标签）、出价方式（CPC按点击或CPM按千次展示）和出价金额。计划状态有草稿、投放中、已暂停和已结束。预算耗尽后自动暂停。

竞价排序：广告展示机会进来时从所有符合条件的计划中选最优。CPC出价要乘该计划的预期点击率（历史平均，新计划默认5%）得到每次展示的预期价值，再跟CPM出价除以1000做统一比较。最高出价有多个计划相同时按预算剩余比例高的优先。效果统计记录每个计划的展示次数、点击次数、点击率、花费金额和转化次数。花费不能超过总预算。点击率等于点击除以展示。统计按小时聚合。

预算耗尽自动暂停时要更新计划状态并发通知给投放人员，通知发送失败不影响状态更新。

Express + TypeScript + SQLite，npm run build 能跑就行。
