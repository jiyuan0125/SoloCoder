帮我用 TypeScript 写一个广告投放管理系统的后端服务，管理广告计划的创建、竞价排序和效果统计。

广告计划管理：每个计划有预算（精确到分，用整数存储）、每日预算上限、定向条件（年龄段、性别、地域标签）、出价方式（CPC按点击或CPM按千次展示）和出价金额。计划状态有草稿、投放中、已暂停和已结束。预算耗尽后计划自动暂停。

竞价排序：广告展示机会进来时，从所有符合条件的计划中选出最优。出价金额要转换为统一计价单位比较。CPC出价乘以该计划的预期点击率（历史平均值，新计划用默认5%）得到每次展示的预期价值，和CPM出价除以1000比较。最高出价有多个计划相同时按预算剩余比例高的优先。效果统计：记录每个计划的展示次数、点击次数、点击率、花费金额和转化次数。花费金额不能超过计划的总预算。点击率等于点击次数除以展示次数。统计数据按小时聚合。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
