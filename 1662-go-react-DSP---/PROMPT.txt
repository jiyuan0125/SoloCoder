帮我用 TypeScript 写一个需求方平台（DSP）简化版的后端，实现竞价引擎和报表统计。

广告活动管理：每个活动有名称、日预算、总预算、定向条件（年龄、性别、地域、兴趣标签）、出价策略（CPM固定出价或CPC固定出价）、出价金额和状态。活动状态有活跃、暂停和已结束。日预算或总预算耗尽后活动自动变为已结束。

竞价引擎：收到竞价请求后提取用户画像，遍历所有活跃活动匹配定向条件。匹配上的活动根据出价策略计算实际出价。采用第二价格拍卖机制：赢家实际支付第二高出价加一分钱。如果只有一个活动参与竞价按底价支付。竞价日志记录每次竞价请求的参与者、出价和胜出者。竞价统计按活动维度汇总：竞价次数、胜出次数、胜出率和总花费。日花费统计不能超过日预算。定向条件匹配时如果用户画像某个字段缺失，该条件视为不匹配。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
