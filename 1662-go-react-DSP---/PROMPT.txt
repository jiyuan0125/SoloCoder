帮我做一套简化版DSP需求方平台，TypeScript 后端。竞价引擎和报表统计就行。

广告活动管理：每个活动有名称、日预算、总预算、定向条件（年龄、性别、地域、兴趣标签）、出价策略（CPM或CPC固定出价）、出价金额和状态。状态有活跃、暂停和已结束。日预算或总预算耗尽后活动自动变为已结束。

竞价引擎收到请求后提取用户画像，遍历所有活跃活动匹配定向条件。匹配上的按出价策略计算实际出价。用第二价格拍卖：赢家实际付第二高出价加一分钱。只有一个活动参与竞价时按底价付。竞价日志记录每次请求的参与者、出价和胜出者。统计按活动维度汇总：竞价次数、胜出次数、胜出率和总花费。日花费不能超日预算。定向条件匹配时如果用户画像某个字段缺失，该条件视为不匹配。

竞价胜出扣减预算的时候，如果扣减过程中发现预算已经被其他请求用完了，这次竞价结果作废。

Express + TypeScript + SQLite，npm run build 能编译通过。
