帮我用 TypeScript 写一个联盟营销平台的后端，管理推广渠道、佣金计算和归因逻辑。

推广渠道管理：每个渠道有名称、联系人、结算方式（按月结算或达到阈值即时结算）、佣金比例和状态。每个渠道可以生成多个推广链接，每个链接对应不同的推广素材（首页、活动页、商品页）。链接包含唯一标识码用于追踪来源。

归因逻辑：用户通过推广链接进入后，系统记录渠道标识和用户ID的关联。归因窗口默认7天，即用户通过推广链接进入后的7天内下单都归因到该渠道。如果用户先后通过不同渠道的链接进入，归因给最后一次点击的渠道。同一用户的同一笔订单只能归因到一个渠道，不能重复计算。佣金计算：订单金额乘以渠道的佣金比例。金额精确到分，用整数运算。佣金状态有待结算、已结算和已取消。订单退款后对应佣金标记为已取消。结算统计按渠道维度汇总每月的订单数、佣金金额和结算状态。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
