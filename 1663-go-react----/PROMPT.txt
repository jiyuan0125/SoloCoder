联盟营销管理的后端服务，TypeScript 实现。推广渠道和佣金计算需要系统化管理。

每个渠道有名称、联系人、结算方式（按月或达到阈值即时结算）、佣金比例和状态，佣金比例不在0到1之间返回 400，渠道名称重复返回 409。渠道可以生成多个推广链接，每个链接对应不同推广素材（首页、活动页、商品页），链接包含唯一标识码用于追踪。

归因逻辑：用户通过推广链接进入后记录渠道标识和用户ID的关联，用户ID或渠道ID不存在返回 400。归因窗口默认7天，即进入后7天内下单都归因到该渠道。如果先后通过不同渠道的链接进入，归因给最后一次点击的渠道。同一用户的同一笔订单只归因一个渠道，重复归因请求返回 409。

佣金计算：订单金额乘渠道佣金比例，金额精确到分用整数运算。佣金状态有待结算、已结算和已取消，订单退款后佣金标为已取消，已结算的佣金不能直接取消要先走退款流程。结算统计按渠道维度汇总每月的订单数、佣金金额和结算状态。订单归因到渠道时要检查渠道是否有效，无效渠道的订单佣金自动标为已取消，渠道从无效恢复为有效后已经标为已取消的不追溯恢复。

Express + TypeScript + SQLite，npm run build 能编译通过。
