运营团队那边提了个需求，要一套私域运营平台，TypeScript 后端。

每个社群有名称、类型、创建时间、成员上限和当前成员数，成员加入退出都有记录。运营可以创建群发任务，选一个或多个社群，编辑消息内容设定发送时间。群发任务创建后进待发送队列，到时间逐个群发。发送频率限制每分钟最多30条，超出的排队等。某个群发送失败不影响其他群。

用户标签管理支持给用户打标签，标签有名称和分类，一个用户可以有多个标签。按标签组合筛选用户支持AND和OR。用户分层根据标签和活跃度自动算：活跃（最近7天有互动）、沉默（7到30天无互动）、流失（超30天无互动）。群发任务可以指定发送给特定分层或标签的用户。同一个群发任务不能重复发到同一个社群。

群发任务发送到某个群的时候，如果该群刚好被删除了，跳过这个群继续发其他群，最终报告中标记该群为"目标不存在"。

Express + TypeScript + SQLite，npm run build 能跑就行。
