帮我用 TypeScript 写一个私域运营平台的后端服务，管理社群和用户分层运营。

社群管理：每个社群有名称、类型、创建时间、成员上限和当前成员数。成员加入和退出都有记录。运营可以创建群发任务，选择一个或多个社群，编辑消息内容和设定发送时间。群发任务创建后进入待发送队列，到时间后逐个群发送。发送频率限制为每分钟最多30条消息，超出的排队等待。某个群发送失败不影响其他群的发送。

用户标签管理：支持给用户打标签，标签有名称和分类。一个用户可以有多个标签。支持按标签组合筛选用户，组合条件支持AND和OR。用户分层根据标签和活跃度自动计算：活跃用户（最近7天有互动）、沉默用户（7到30天无互动）和流失用户（超过30天无互动）。群发任务可以指定发送给特定分层或标签的用户。同一个群发任务不能重复发送给同一个社群。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
