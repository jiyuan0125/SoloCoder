帮我用 TypeScript 写一个CRM系统的后端服务，管理销售线索和商机跟进。

线索管理：记录每个线索的来源渠道、联系方式、公司名称、联系人、需求和创建时间。线索状态有新线索、已联系、已拒绝和已转化为商机。线索创建后7天内没被销售认领就自动进入公共线索池。销售认领后该线索归其所有。但该销售30天内没有更新线索状态，线索自动回到公共池。认领操作要处理并发冲突，不能两个销售同时认领同一个线索。

商机跟进：线索转化为商机后进入跟进流程。每个商机有预计金额、负责销售、阶段（初步接触/需求确认/方案报价/商务谈判/赢单/输单）和预计成交日期。阶段只能向前推进不能跳跃，但可以回退并记录原因。输单要记录输给谁和输单原因。销售漏斗统计：按阶段统计商机数量和金额，计算各阶段的转化率。转化率等于进入下一阶段的商机数除以进入当前阶段的商机数。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
