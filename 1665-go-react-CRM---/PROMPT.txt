最近在搞销售管理，需要一个CRM系统后端，TypeScript 实现。线索和商机跟进全靠Excel管太混乱了。

线索管理记录每个线索的来源渠道、联系方式、公司名称、联系人、需求和创建时间，来源渠道和联系方式为空返回 400。线索状态有新线索、已联系、已拒绝和已转化为商机，状态只能从新线索→已联系→已拒绝/已转化，已拒绝的不能再转回来返回 400，已转化的不能再改状态返回 400。创建后7天没被销售认领就自动进公共池。认领后归该销售所有，但30天没更新状态就自动回公共池。认领操作要处理并发冲突，不能两个销售同时认领同一个线索，后到的返回 409 和"线索已被认领"。

线索转化为商机后进入跟进流程，每个商机有预计金额、负责销售、阶段（初步接触/需求确认/方案报价/商务谈判/赢单/输单）和预计成交日期，金额为负数返回 400。阶段只能向前推进但可以回退并记录原因，赢单和输单之后不能再改阶段返回 400。输单要记输给谁和原因。漏斗统计按阶段统计商机数量和金额，转化率等于进入下一阶段的除以进入当前阶段的，当前阶段数量为零时转化率按零算。

Express + TypeScript + SQLite，npm run build 能编译通过。
