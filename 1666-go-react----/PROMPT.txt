帮我用 TypeScript 写一个销售漏斗分析的后端服务，管理销售阶段数据和转化预测。

每个销售机会有创建时间、当前阶段、预计金额、负责销售和客户信息。阶段定义：初次接触、需求调研、方案演示、商务报价、合同谈判、赢单。输单记录输单原因。阶段只能向前推进不能跳跃（从初次接触直接到方案演示不行），但可以回退并记录原因。

漏斗数据聚合按时间窗口统计：选择时间范围后统计该范围内"曾经进入过某阶段"的机会数量，不是"当前处于某阶段"的数量。每个阶段的转化率等于进入下一阶段的机会数除以进入当前阶段的机会数。预测功能：根据历史转化率和当前各阶段的商机金额，预测最终赢单金额。预测金额等于当前各阶段商机金额乘以从该阶段到赢单的历史转化率再求和。统计时要排除已输单的商机。数据支持按销售个人和按团队维度查看。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
