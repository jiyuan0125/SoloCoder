我们销售团队需要一个漏斗分析服务，TypeScript 后端。销售转化数据需要精细化分析。

每个销售机会有创建时间、当前阶段、预计金额、负责销售和客户信息，金额为负数返回 400，负责销售不存在返回 404。阶段定义：初次接触、需求调研、方案演示、商务报价、合同谈判、赢单。输单记输单原因。阶段只能向前推进，从初次接触直接到方案演示不行返回 400 和"必须经过需求调研阶段"，但可以回退记原因。

漏斗数据按时间窗口统计：选时间范围后统计该范围内"曾经进入过某阶段"的机会数量，不是"当前处于某阶段"的。每个阶段转化率等于进入下一阶段的除以进入当前阶段的，当前阶段数量为零时转化率按零算。预测功能根据历史转化率和当前各阶段商机金额预测最终赢单金额：当前各阶段金额乘以从该阶段到赢单的历史转化率再求和。统计时排除已输单的。数据支持按销售个人和团队维度看，销售ID不存在返回 404。

商机阶段变更时要记录历史，历史记录和商机主表更新要一起成功或一起失败，历史写入失败时整个变更回滚返回 500。漏斗统计查询的时候用最新的阶段历史数据来算，如果统计过程中有商机的阶段刚好被更新了，那次更新不影响当前查询的结果——统计开始时确定数据快照查询期间数据变更不影响结果。

Express + TypeScript + SQLite，npm run build 能跑就行。
