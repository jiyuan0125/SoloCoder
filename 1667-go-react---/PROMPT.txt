用 TypeScript 写一个合同管理平台。合同模板和签署流程太乱了需要系统化管起来。

合同模板维护多个模板，每个有名称、类型（采购/销售/服务协议/保密协议）、版本号和模板内容，模板名称加版本号重复返回 409。模板内容用双花括号做变量占位符，如"甲方：{{party_a}}"、"合同金额：{{amount}}元"。用模板创建合同时提供变量值后自动填充生成正文，变量值不全返回 400 和缺失的变量列表。模板变更后已有合同不受影响，新合同用最新模板。

合同创建后进入审批流程，审批按金额分级：5万以下部门经理批，5到20万总监批，20万以上CEO批，分界线上按高等级处理。审批通过进签署阶段，签署完归档。状态有草稿、审批中、已批准、签署中、已签署、已归档和已作废，只能按这个顺序往下走，非法跳转返回 400 和当前状态说明，已作废的不能恢复返回 400。已签署的可以改为补充协议，关联原合同。同一个模板同一版本号不能重复创建。

合同审批通过后自动生成签署任务，签署任务里记录的金额以审批通过时的合同金额为准。如果合同在审批过程中被修改了金额需要重新提交审批，已进入审批中的合同修改内容返回 409 和"请先撤回审批"。审批操作和签署任务的生成要一起完成，签署任务创建失败时审批结果仍保留但标记为"待人工处理"。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
