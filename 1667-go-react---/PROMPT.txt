帮我用 TypeScript 写一个合同管理平台的后端服务，管理合同模板和签署流程。

合同模板维护多个模板，每个模板有名称、类型（采购/销售/服务协议/保密协议）、版本号和模板内容。模板内容用双花括号包围变量占位符，如"甲方：{{party_a}}"、"合同金额：{{amount}}元"。使用模板创建合同时提供变量值后自动填充生成合同正文。模板变更后已有合同不受影响，新合同用最新模板。

合同签署流程：合同创建后进入审批流程。审批支持多级审批，审批人按合同金额分级——5万以下部门经理批，5到20万总监批，20万以上CEO批。合同金额在分界线上时按高等级处理。审批通过后进入签署阶段。签署完成后合同归档。合同状态有草稿、审批中、已批准、签署中、已签署、已归档和已作废。已签署的合同可以修改为补充协议，补充协议关联原合同。同一个合同模板的同一个版本号不能重复创建。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
