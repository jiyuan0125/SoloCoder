发票管理系统重写，TypeScript 后端。旧的系统太老旧了需要重做。

发票有增值税专用、增值税普通和电子发票三种。每张记录发票代码、号码、开票日期、购买方信息（名称和税号）、销售方信息、金额、税额、价税合计和状态。金额税额精确到分。税额按金额乘税率后四舍五入到分，然后价税合计等于金额加四舍五入后的税额——不能先算价税合计再反算税额，否则会出现一分钱差异。税率支持13%、9%、6%、3%和1%。

开票流程：选已审批通过的合同，填开票信息提交申请，校验完整后生成发票。红冲：已开具的可以开红字发票冲销，金额为负数，关联原蓝字发票，每张蓝字发票只能红冲一次。发票查验通过代码和号码查询，校验金额和税额是否匹配。

红冲发票生成时要同时更新原发票的状态为"已红冲"，如果原发票在红冲过程中刚好被其他操作引用（比如正在被查验），红冲操作要等引用结束后再执行。

Express + TypeScript + SQLite，npm run build 能编译通过，node dist/server.js 能启动。
