帮我用 TypeScript 写一个发票管理系统的后端，处理发票开具、查验和认证流程。

发票有增值税专用发票、增值税普通发票和电子发票三种类型。每张发票记录发票代码、发票号码、开票日期、购买方信息（名称和税号）、销售方信息、金额、税额、价税合计和状态。金额和税额的计算精确到分。税额按金额乘税率计算后四舍五入到分，然后价税合计等于金额加四舍五入后的税额，不能先算价税合计再反算税额否则会出现一分钱差异。税率支持13%、9%、6%、3%和1%。

发票开具流程：选择已审批通过的合同，填写开票信息提交申请。校验信息完整性后生成发票。红冲发票：已开具的发票可以开具红字发票冲销。红字发票的金额为负数，关联原蓝字发票。每张蓝字发票只能红冲一次。发票查验：通过发票代码和号码查询发票信息，校验金额和税额是否匹配。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
