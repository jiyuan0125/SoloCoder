渠道对账全靠人工逐笔对比太容易出错了，所以想做一个自动对账平台，TypeScript 后端。

支持从多个渠道导入交易流水（内存数据模拟）。渠道流水有流水号、交易时间、交易金额、对方账户、渠道名称和状态。内部订单有订单号、下单时间、支付金额、支付方式和订单状态。

匹配规则按金额和交易时间来：金额完全一致且时间差在5分钟以内的算匹配成功。同一笔流水只能匹配一笔订单，反过来也一样。匹配结果分三类：匹配成功、渠道多出（流水无对应订单）、订单多出（订单无对应流水）。对账完生成报告记匹配成功数、渠道多出数、订单多出数和对账时间。差错处理：多出的标为待处理，处理方式有补录（手动创建缺失记录）、挂账（暂时搁置）和调平（确认差异合理）。对账报告每日生成，不能对同一天重复对账。

补录创建缺失订单时，创建操作记入对账报告的调整记录。补录的订单金额如果和原始流水对不上，差异记在调整记录里。

Express + TypeScript + SQLite，npm run build 能跑就行。
