帮我用 TypeScript 写一个自动对账平台的后端服务，比对渠道交易流水和内部订单数据。

支持从多个渠道导入交易流水（用内存数据模拟）。每条渠道流水有流水号、交易时间、交易金额、对方账户、渠道名称和状态。每条内部订单有订单号、下单时间、支付金额、支付方式和订单状态。

对账匹配规则：按金额和交易时间匹配。金额完全一致且交易时间差在5分钟以内的视为匹配成功。同一笔渠道流水只能匹配一笔订单，同一笔订单也只能匹配一笔流水。匹配结果分三类：匹配成功、渠道多出（流水无对应订单）和订单多出（订单无对应流水）。对账完成后生成对账报告，记录匹配成功数、渠道多出数、订单多出数和对账时间。差错处理：多出的记录标记为待处理。差错处理方式有补录（手动创建缺失的订单或流水记录）、挂账（暂时搁置等后续处理）和调平（确认差异合理后标记为已调平）。对账报告每日生成，不能对同一天重复对账。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
