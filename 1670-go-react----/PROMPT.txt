帮我做一套资金清算系统，TypeScript 后端。处理轧差计算和结算单生成。

清算系统计算每个卖家在结算周期内的应收和平台手续费，然后生成结算单。轧差就是把一个周期内某卖家的所有收入和支出互相抵消只结算净额，比如收到买家付款10000元退款支出2000元，轧差后结算8000元。所有金额用整数分存储，金额为负数返回 400。

手续费按轧差后净额的百分比收，比例按卖家等级配置（普通2%、银牌1.5%、金牌1%），等级不存在返回 404。手续费也精确到分，先算手续费再算应结金额（净额减手续费），不能先算应结再反算手续费。结算单每个卖家每个周期一张，包含应收总额、退款总额、轧差净额、手续费和应结金额，卖家ID不存在返回 404。状态有待确认、已确认和已打款，已确认后金额不能再改，尝试修改返回 409。同一个卖家同一周期不能生成两张结算单，重复生成返回 409。

确认结算单的时候系统要从平台收入中记录这笔手续费，记录手续费的时候要用结算单上的金额，不能重新算一遍。手续费记录和结算单状态更新要一起完成，手续费记录失败时结算单状态不变返回 500。

Express + TypeScript + SQLite，npm run build 能跑就行。
