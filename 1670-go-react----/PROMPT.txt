帮我用 TypeScript 写一个资金清算系统的后端服务，处理轧差计算和结算单生成。

清算系统计算每个卖家在结算周期内的应收金额和平台手续费，然后生成结算单。轧差计算把一个周期内某个卖家的所有收入和支出互相抵消，只结算净额。比如收到买家付款10000元，退款支出2000元，轧差后结算8000元。所有金额用整数分存储运算。

手续费计算：按轧差后净额的百分比收取，比例可按卖家等级配置（普通卖家2%，银牌1.5%，金牌1%）。手续费也精确到分，先算手续费再算应结金额（净额减手续费），不能先算应结金额再反算手续费。结算单生成：每个卖家每个结算周期一张结算单，包含应收总额、退款总额、轧差后净额、手续费和应结金额。结算单状态有待确认、已确认和已打款。确认后的结算单金额不能再修改。同一个卖家同一个结算周期不能生成两张结算单。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
