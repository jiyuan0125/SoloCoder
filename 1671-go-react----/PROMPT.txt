帮我用 TypeScript 写一个统一支付网关的后端服务，管理多渠道支付路由和对账。

对接三个支付渠道（微信、支付宝、银联），每个渠道的费率不同。费率是阶梯式的，比如微信1000元以内0.38%，超过0.32%。网关对外暴露统一API，内部根据策略路由到不同渠道。

路由策略支持三种：按费率优先（选最便宜的）、按成功率优先（选历史成功率最高的）、按指定渠道。费率优先时要根据实际金额计算每个渠道的手续费再比较，金额用整数分运算。支付记录管理：每笔支付有商户订单号、支付金额、支付渠道、渠道流水号、支付状态和创建时间。支付状态有待支付、已支付、已关闭和已退款。退款金额不能超过支付金额。渠道健康度监控：记录每个渠道的请求次数、成功次数和平均响应时间，按小时聚合。连续10分钟成功率低于95%的渠道自动降级，不再路由新支付到该渠道。降级后已有支付不受影响。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
