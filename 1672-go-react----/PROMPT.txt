帮我用 TypeScript 写一个资金池管理系统的后端，处理多账户资金调拨和利息计算。

管理多个银行账户，每个账户有名称、银行、余额（整数分）、类型（收入户、支出户、资金池主账户）和币种（只处理人民币）。资金调拨：管理员可以发起调拨，指定调出账户、调入账户、金额和原因。调拨后调出账户余额减少，调入账户余额增加。余额不足时调拨失败。所有金额用整数分存储。

利息计算：资金池主账户的利息按日计算，日利率可配置。利息 = 主账户每日余额 × 日利率，按月累计后结息。结息日为每月20日，结息后利息清零开始新一轮累计。余额不能为负（除了允许透支的账户），调拨前要检查余额。调拨记录包含调出账户、调入账户、金额、时间、状态和操作人。同一笔调拨不能重复提交。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
