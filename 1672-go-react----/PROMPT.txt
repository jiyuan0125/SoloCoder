最近在搞资金管理，需要一个资金池管理系统，TypeScript 实现。多账户资金调拨和利息计算。

管理多个银行账户，每个有名称、银行、余额（整数分）、类型（收入户、支出户、资金池主账户）和币种（只处理人民币），账户名称重复返回 409。资金调拨由管理员发起，指定调出账户、调入账户、金额和原因，调出或调入账户不存在返回 404，金额为零或负数返回 400。调拨后调出余额减调入余额加，余额不足时调拨失败返回 400 和"余额不足"。所有金额整数分存储。

利息计算：资金池主账户按日计算利息，日利率可配置。利息等于主账户每日余额乘日利率，按月累计后结息。结息日每月20日，结息后利息清零开始新一轮。余额不能为负（除允许透支的），调拨前检查余额。调拨记录包含调出、调入、金额、时间、状态和操作人，同一笔调拨不能重复提交返回 409。

结息日计算利息的时候要读主账户当月每天的余额，如果结息计算过程中刚好有一笔调拨在执行，利息按调拨执行前的余额来算——利息计算要锁定余额快照，计算期间的调拨排队等利息算完再执行。调出账户扣款和调入账户入账要原子性完成，不能出现扣了没入或入了没扣的情况。

Express + TypeScript + SQLite，npm run build 能跑就行。
