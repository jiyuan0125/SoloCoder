我们平台需要一个虚拟账户体系，TypeScript 后端。处理账户开立、清分和记账。

每个用户有一个主账户，主账户下可以开多个子账户（充值账户、担保账户、提现账户）。每个账户有ID、用户ID、类型、余额（整数分，可以为负但不超透支额度）和状态。账户之间可以转账，源账户减目标账户加，保证原子性。

担保交易流程：买家付款时钱从充值账户转到担保账户，卖家确认发货后买家确认收货，钱从担保账户转到卖家充值账户。退款时从担保账户退回买家充值。提现从充值账户到绑定银行账户（记提现信息即可），金额不能超充值余额。账户流水记每笔操作：类型（充值/消费/退款/提现/转账）、金额、操作前后余额和时间。余额增减通过流水记录来核对。同一用户同一笔订单的担保转账不能重复。

确认收货的时候系统要把钱从担保账户转到卖家充值账户，同时扣一笔平台手续费到平台收入账户。手续费金额用担保金额乘平台费率来算，如果担保金额不足以扣手续费就从转账金额里扣。

Express + TypeScript + SQLite，npm run build 能编译通过，node dist/server.js 能启动。
