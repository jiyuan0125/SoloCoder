帮我用 TypeScript 写一个虚拟账户体系的后端服务，处理账户开立、清分和记账。

每个用户有一个主账户，主账户下可以开多个子账户（充值账户、担保账户、提现账户）。每个账户有ID、用户ID、类型、余额（整数分，可以为负但不超过透支额度）和状态。账户之间可以转账，转账时源账户减目标账户加，要保证原子性。

担保交易流程：买家付款时钱从充值账户转到担保账户，卖家确认发货后买家确认收货，钱从担保账户转到卖家的充值账户。退款时钱从担保账户退回买家充值账户。提现：卖家从充值账户提现到绑定的银行账户（记录提现信息即可）。提现金额不能超过充值账户余额。账户流水记录每笔操作：操作类型（充值/消费/退款/提现/转账）、金额、操作前后余额和时间。余额的增减要通过流水来保证一致性。同一个用户的同一笔订单的担保转账不能重复执行。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
