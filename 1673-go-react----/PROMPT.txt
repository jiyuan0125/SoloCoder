我们平台需要一个虚拟账户体系，TypeScript 后端。处理账户开立、清分和记账。

每个用户有一个主账户，主账户下可以开多个子账户（充值账户、担保账户、提现账户）。每个账户有ID、用户ID、类型、余额（整数分，可以为负但不超透支额度）和状态，用户ID不存在返回 404，同一用户下同类型子账户只能有一个重复创建返回 409。账户之间可以转账，源账户减目标账户加，保证原子性，源账户或目标账户不存在返回 404，源账户余额不足返回 400。

担保交易流程：买家付款时钱从充值账户转到担保账户，卖家确认发货后买家确认收货，钱从担保账户转到卖家充值账户。退款时从担保账户退回买家充值。提现从充值账户到绑定银行账户（记提现信息即可），金额不能超充值余额超了返回 400。账户流水记每笔操作：类型（充值/消费/退款/提现/转账）、金额、操作前后余额和时间。余额增减通过流水记录来核对。同一用户同一笔订单的担保转账不能重复返回 409。

确认收货的时候系统要把钱从担保账户转到卖家充值账户，同时扣一笔平台手续费到平台收入账户，三个账户的变更要一起完成。手续费金额用担保金额乘平台费率来算，如果担保金额不足以扣手续费就从转账金额里扣。转账过程中担保账户余额的读取和扣减要保证不会因为并发操作导致透支。

Express + TypeScript + SQLite，npm run build 能编译通过，node dist/server.js 能启动。
