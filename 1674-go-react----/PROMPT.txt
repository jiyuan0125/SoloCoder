帮我用 TypeScript 写一个跨境支付系统的后端，处理外汇转换和合规检查。

支持多币种虚拟账户（人民币、美元、欧元、日元）。汇率表用相对人民币的交叉汇率表示，精确到小数点后6位，用整数存储（乘以1000000）。汇率每分钟更新一次（模拟外部推送）。不同货币之间的转换通过人民币做交叉计算，比如USD转EUR要经过USD→CNY→EUR两步。

汇兑计算用整数运算：先将源金额按源币种汇率转为人民币（乘以汇率再除以1000000），再将人民币按目标币种汇率转为目标币种。每次汇兑记录源金额、源币种、目标金额、目标币种、使用的汇率和汇兑时间。合规检查：单笔跨境转账超过5万美元需要额外审批。日累计超过10万美元触发合规告警。汇率的时效性：交易时使用的汇率必须是最近1分钟内更新的，超过1分钟的汇率视为过期，交易要等新汇率到达后再处理。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
