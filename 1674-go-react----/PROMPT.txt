跨境支付各环节全是手动操作太容易出错了，所以想做一个跨境支付系统，TypeScript 后端。处理外汇转换和合规检查。

支持多币种虚拟账户（人民币、美元、欧元、日元），币种不在支持列表里返回 400。汇率表用相对人民币的交叉汇率表示，精确到小数点后6位，用整数存储（乘以1000000）。汇率每分钟更新一次（模拟外部推送），不同货币间转换通过人民币做交叉计算，比如USD转EUR要经过USD→CNY→EUR两步。

汇兑计算用整数运算：先将源金额按源币种汇率转人民币（乘汇率再除1000000），再按目标币种汇率转目标币种，金额为零或负数返回 400。每次汇兑记源金额、源币种、目标金额、目标币种、使用的汇率和时间。合规方面：单笔跨境转账超5万美元需额外审批返回 202 和"待合规审批"，日累计超10万美元触发告警但交易本身仍然执行。汇率时效性：交易用的汇率必须是最近1分钟内更新的，超1分钟的视为过期要等新汇率到达，过期时返回 503 和"汇率过期等待更新"。

汇率更新后所有在等新汇率的待处理交易都要被唤醒处理。唤醒时如果某笔交易的金额已经被修改了要用最新金额来算，已经被取消的交易跳过不处理。多笔待处理交易的唤醒顺序按提交时间先后，不能因为唤醒处理导致前面的交易因为额度不足而后面的交易成功了。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
