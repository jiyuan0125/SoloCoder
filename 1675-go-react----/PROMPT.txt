帮我用 TypeScript 写一个供应链金融平台的后端，处理保理融资和仓单质押。

保理模块管理应收账款的转让和融资。供应商登记一笔应收账款（买家名称、应收金额、到期日、合同编号），提交保理融资申请。金融机构审核通过后按应收账款金额的一定比例放款（比如80%）。应收账款金额精确到分。买家实际付款后，先扣除融资本金和利息，剩余部分结算给供应商。利息按天数计算（年利率除以365乘以实际天数），精确到分。

仓单质押：供应商用库存商品做抵押借款。录入仓单信息（商品名称、数量、单价、仓库地址），系统按商品市值的一定质押率计算可借款额度（比如70%）。商品市值 = 数量 × 单价，用整数分计算。质押期间如果商品市值下跌导致质押率超过阈值（比如跌破60%），触发追加保证金通知。同一笔应收账款不能重复发起融资申请。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
