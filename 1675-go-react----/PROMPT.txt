供应链金融平台的后端，TypeScript 实现。保理融资和仓单质押需要系统化管理。

保理模块管应收账款的转让和融资。供应商登记一笔应收账款（买家名称、应收金额、到期日、合同编号），买家名称或合同编号为空返回 400，金额为零或负数返回 400。提交保理融资申请，金融机构审核通过后按应收金额的一定比例放款（比如80%），比例不在合理范围返回 400。金额精确到分。买家实际付款后先扣除融资本金和利息，剩余结算给供应商。利息按天数算（年利率除以365乘实际天数），精确到分。

仓单质押：供应商用库存商品抵押借款。录入仓单信息（商品名称、数量、单价、仓库地址），按商品市值的质押率算可借额度（比如70%），质押率不在0到1之间返回 400。市值等于数量乘单价用整数分算。质押期间市值下跌导致质押率跌破阈值（比如60%）触发追加保证金通知。同一笔应收账款不能重复发起融资返回 409。

买家付款后系统自动结算给供应商，结算操作内部要计算利息并扣除。利息计算基于放款日期到付款日期的实际天数，如果付款日期早于到期日利息按实际天数算，如果晚于到期日逾期部分按罚息利率算。利息扣除和供应商结算要一起完成，利息扣了但结算没到账的情况不能发生。融资状态只能从待审核→已放款→已结算流转，非法跳转返回 400。

Express + TypeScript + SQLite，npm run build 能跑就行。
