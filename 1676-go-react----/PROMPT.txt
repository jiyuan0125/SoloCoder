用 TypeScript 写一个文创众筹平台。管理项目创建、筹款和回报。

发起人创建项目时填名称、类别（影视/音乐/出版/游戏/设计）、目标金额、截止日期和描述，名称重复返回 409，目标金额为零或负数返回 400，截止日期早于当前时间返回 400。设置若干回报档位，每个档位有承诺金额和回报内容，档位金额为零或负数返回 400。项目状态有筹备中、筹款中、已成功、已失败和已取消，只能从筹备中→筹款中→已成功/已失败流转，非法跳转返回 400。筹款中项目到截止日期达到目标金额自动变已成功，未达到则已失败。金额精确到分用整数存。

支持者选择档位支持，同一支持者可以对同一项目多次支持不同档位。退款场景比较特殊：支持者在筹款成功后72小时内取消支持时，要检查项目会不会因为这笔取消降到目标金额以下，如果会的话项目状态回退为筹款中而不是直接失败返回 200 加状态变更说明。如果不会降到目标以下，项目状态不变。部分退款按支持时间倒序逐笔退。同一支持者对同一档位重复提交不会创建重复记录返回 409。

退款时系统要同时更新支持记录状态和项目已筹金额，还要检查项目状态是否需要回退。如果项目已经进入已成功状态且退款后仍达标，项目状态不变。支持记录更新和项目已筹金额扣减要一起完成，不能出现金额扣了但记录没变的情况。

Express + TypeScript + SQLite，npm run build 能编译通过。
