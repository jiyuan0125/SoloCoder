帮我用 TypeScript 写一个文创众筹平台的后端，管理项目创建、筹款和回报。

发起人创建项目时填写名称、类别（影视/音乐/出版/游戏/设计）、目标金额、截止日期和描述。设置若干回报档位，每个档位有承诺金额和回报内容。项目状态有筹备中、筹款中、已成功、已失败和已取消。筹款中项目到截止日期达到目标金额自动变为已成功，未达到则已失败。支持金额精确到分用整数存储。

支持者选择档位支持，同一支持者可以对同一项目多次支持不同档位。退款场景：支持者在筹款成功后72小时内取消支持时，要检查这个项目是否会因为这笔取消而降到目标金额以下。如果是的话项目状态回退为筹款中而不是直接失败，给其他支持者缓冲期。部分退款按支持时间倒序逐笔退。同一个支持者对同一个档位重复提交支持请求不会创建重复记录。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
