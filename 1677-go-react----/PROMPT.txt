捐赠记录太散了税抵凭证也开不明白，所以想做一个慈善捐赠平台，TypeScript 后端。

每个捐赠项目有名称、受助对象描述、目标金额和项目周期，名称重复返回 409。捐赠记录关联项目，包含捐赠人姓名、身份证号后四位、金额（整数分）和时间，项目ID不存在返回 400，金额为零或负数返回 400。电子捐赠证书编号规则是"DJ"加年月日加6位流水号，同天连续递增跨天重置。系统重启后流水号要从已有最大值继续不能重复，并发生成证书时流水号递增要保证不冲突不能两个证书拿到同一个号。

税前扣除凭证：只有标注"具备税前扣除资格"的项目才能生成抵扣凭证，没有资格的项目申请凭证返回 400。可抵扣金额等于捐赠金额，但年度累计不超过捐赠人当年应纳税所得额的30%。系统维护每个捐赠人的年度累计捐赠总额，跨年清零。超出限额部分不能开凭证但仍记为普通捐赠。项目截止前7天如果未达目标金额60%自动生成预警。凭证生成后不能修改只能作废重新开具，尝试修改返回 405。

生成凭证的时候系统要检查捐赠人的年度累计金额，如果累计金额加上这笔捐赠超过了30%限额，只对限额内的部分开凭证超出的部分记为普通捐赠。凭证生成和累计金额更新要一起完成，不能出现凭证开了但累计金额没更新的情况。

Express + TypeScript + SQLite，npm run build 能跑就行。
