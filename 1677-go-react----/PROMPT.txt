帮我用 TypeScript 写一个慈善捐赠平台的后端服务，管理捐赠项目和税抵凭证。

捐赠项目管理：每个项目有名称、受助对象描述、目标金额和项目周期。捐赠记录关联项目，包含捐赠人姓名、身份证号后四位、金额（整数分存储）和时间。电子捐赠证书编号规则是"DJ"加年月日加6位流水号，同天内连续递增跨天重置。系统重启后流水号要从已有最大值继续不能重复。

税前扣除凭证：只有标注"具备税前扣除资格"的项目才能生成抵扣凭证。可抵扣金额等于捐赠金额，但年度累计不超过捐赠人当年应纳税所得额的30%。系统维护每个捐赠人的年度累计捐赠总额，跨年清零。超出限额部分不能开具凭证但仍记录为普通捐赠。项目截止前7天如果未达目标金额60%自动生成预警。凭证生成后不能修改，只能作废重新开具。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
