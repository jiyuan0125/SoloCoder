帮我做一套公益基金会项目管理系统，TypeScript 后端。从申请到执行的全流程管理。

社会组织提交项目申请时填机构名称、统一社会信用代码、负责人、项目名称、类别、预算金额和实施周期，信用代码格式不对返回 400，预算金额为零或负数返回 400。初审通过后进专家评审。系统从专家库随机抽3到5位专家独立打分（1到100分），分数超范围返回 400。去掉一个最高分和一个最低分后取平均，参评专家不足3人时不执行去掉操作直接取平均。60分以下不通过，60到80分整改，80分及以上直接批准。

审计日志记录所有关键操作，包括操作人、时间、类型、内容和操作前后数据快照，日志不可删不可改只能追加，尝试修改或删除返回 405。项目状态变更时记录前后完整项目信息。资金拨付记录纳入审计。待办流程覆盖全生命周期，每个待办有截止时间超期自动标逾期催办。项目预算使用超80%自动生成预算预警。同一项目申请重新提交不超3次，超过返回 400 和"已达最大提交次数"。

项目状态变更时审计日志的写入操作要记录变更前后的数据快照，快照读取和状态更新要在同一步完成——先读快照再更新状态，状态更新失败时快照不写入避免出现没有对应状态变更的日志。状态只能按申请中→初审→评审→批准/整改/不通过流转，非法跳转返回 400。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
