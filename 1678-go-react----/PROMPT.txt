帮我用 TypeScript 写一个公益基金会项目管理系统的后端，管理从申请到执行的全流程。

社会组织提交项目申请时填写机构名称、统一社会信用代码、负责人、项目名称、类别、预算金额和实施周期。初审通过后进入专家评审。系统从专家库随机抽取3到5位专家独立打分（1到100分），去掉一个最高分和一个最低分后取平均分。参评专家不足3人时不执行去掉操作直接取平均。60分以下不通过，60到80分整改，80分及以上直接批准。

审计日志记录所有关键操作，包括操作人、时间、类型、内容和操作前后数据快照。日志不可删除不可修改只能追加。项目状态变更时记录前后完整项目信息。资金拨付记录纳入审计。待办流程覆盖全生命周期，每个待办有截止时间，超期自动标记逾期并催办。项目预算使用超过80%自动生成预算预警。同一个项目申请的重新提交不超过3次。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
