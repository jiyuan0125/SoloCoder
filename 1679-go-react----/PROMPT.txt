帮我用 TypeScript 写一个志愿服务管理系统的后端，管理志愿者注册、活动报名和服务时长统计。

志愿者注册填写姓名、手机号、身份证号、技能特长和可服务时间段。手机号去重，一个手机号只能注册一个账号。累计服务时长满100小时自动升级为骨干志愿者，骨干可以发起活动。

活动创建时填写名称、类别、日期、时间段、地点、所需人数和技能要求。报名时检查志愿者可服务时间段是否与活动时间冲突。报名成功后活动开始前24小时内不能取消。会议预约：志愿者团队可以预约会议室，同一个会议室同一天同一时段不能重复预约。服务时长按实际参与时间计算，不足30分钟不计入，超过30分钟不足1小时按30分钟计，超过1小时向下取整到30分钟倍数。年度累计满50小时铜牌、100小时银牌、300小时金牌。时长统计要正确处理跨天活动。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
