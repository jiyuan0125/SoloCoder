最近在搞社区服务，需要一个志愿服务管理系统，TypeScript 后端。管志愿者注册、活动报名和服务时长统计。

志愿者注册填姓名、手机号、身份证号、技能特长和可服务时间段，手机号去重一个号只能注册一个重复注册返回 409，身份证号为空返回 400。累计服务满100小时自动升级为骨干志愿者，骨干可以发起活动。

活动创建时填名称、类别、日期、时间段、地点、所需人数和技能要求，日期已过返回 400，人数为零或负数返回 400。报名时检查志愿者可服务时间段是否与活动冲突，时间冲突返回 409 和冲突说明。报名成功后活动开始前24小时内不能取消返回 400，取消操作不存在返回 404。志愿者团队可以预约会议室，同一个会议室同一天同一时段不能重复预约返回 409。服务时长按实际参与时间算：不足30分钟不计入，超30分钟不足1小时按30分钟计，超1小时向下取整到30分钟倍数。年度累计满50小时铜牌、100银牌、300金牌。时长统计要正确处理跨天活动。

活动结束后计算服务时长，时长计算结果要更新到志愿者累计时长。如果志愿者在活动期间又报名了另一个有时间重叠的活动，第二个活动的时长按实际参与时间扣除重叠部分来算。时长更新和活动参与记录的状态变更要一起完成，活动参与记录不存在返回 404。

Express + TypeScript + SQLite，npm run build 能跑就行。
