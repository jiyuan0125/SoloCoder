帮我用 C 写一个通信协议的构造和解析模块。场景是：我们要开发一个数据库代理中间件，需要和 Redis 服务进行通信，Redis 使用的是一种自定义的文本协议。这个模块需要两方面的能力：一是能根据给定的命令和参数构造出符合 Redis 协议格式的请求数据，二是能把 Redis 返回的原始字节数据解析成结构化的结果。Redis 的协议有几种不同的数据类型：简单字符串（以 + 号开头）、错误信息（以 - 号开头）、整数（以 : 号开头）、批量字符串（以 $ 号开头后面跟字节长度和实际内容）、数组（以 * 号开头后面跟元素个数）。每种类型都要能正确构造和解析。有两个特殊情况要注意：批量字符串的长度为 -1 时表示空值（null），解析时要特殊处理不能当成空字符串；数组的长度为 -1 时表示空数组。举个例子：执行 SET mykey myvalue 这个命令，需要构造出这样的格式：*3 加换行、$3 加换行、SET 加换行、$5 加换行、mykey 加换行、$7 加换行、myvalue 加换行。如果网络传输过程中数据分成了多个 TCP 包到达，解析器要能处理不完整的数据——缓存已收到的部分，等数据完整后再解析。用纯 C 写，gcc 编译通过。模块要能处理网络传输中的各种异常——连接中断、数据只收到了一半、对端发送了格式错误的数据等。
代码拆成至少 4 个源文件：协议消息构造、协议数据解析、数据类型处理、主程序，各自有头文件和实现文件。gcc 编译能过。
