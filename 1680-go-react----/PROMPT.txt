帮我用 TypeScript 写一个社区议事投票系统的后端，管理议题和电子投票。

议题管理：业主发起议题填写标题、内容、类别和附件。提交后进入公示期（默认7天），期间居民可以发表意见。公示期结束后由业委会决定是否进入投票环节。投票设置包括起止时间、投票方式（一人一票或按面积加权）和最低参与率。

投票验证投票人资格（注册业主且实名认证）。一人一票每个业主投一次，按面积加权也是一次但权重等于房屋面积。投票截止后自动计票：赞成票超过50%且参与率不低于最低参与率则通过。参与率不足但赞成票超三分之二进入复议。投票过程中记录每张选票的投票时间，结果截止前不公开。按面积加权投票时权重的累加要用整数（面积乘以100后计算）避免浮点精度问题。待办跟踪覆盖从发起到执行全程，超期自动提醒。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
