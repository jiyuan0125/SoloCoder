我们社区要搞电子投票，需要一个议事投票系统的后端，TypeScript 做。

业主发起议题填标题、内容、类别和附件，标题为空返回 400。提交后进公示期（默认7天），期间居民可以发表意见。公示期结束由业委会决定是否进入投票，公示期没结束不能提前投票返回 400。投票设置包括起止时间、投票方式（一人一票或按面积加权）和最低参与率，参与率设为零或负数返回 400。

投票验证投票人资格——注册业主且实名认证，未注册返回 403，未实名返回 403。一人一票每人投一次重复投票返回 409，按面积加权也是一次但权重等于房屋面积，面积为零或负数返回 400。截止后自动计票：赞成超50%且参与率不低于最低参与率则通过。参与率不足但赞成超三分之二进复议。投票过程记录每张选票的投票时间，结果截止前不公开查询结果返回 403。按面积加权投票时权重累加用整数（面积乘100后计算）避免浮点精度问题。待办跟踪覆盖从发起到执行全程，超期自动提醒。

议题从公示到投票到执行是完整的流程，每个阶段只能顺序流转不能跳步返回 400。公示期结束进入投票需要业委会确认，投票通过后进执行阶段需要执行人确认完成，执行确认时议题不存在返回 404。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
