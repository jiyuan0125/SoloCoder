邻里互助平台的后端服务，TypeScript 实现。互助需求的发布和匹配。

居民发布需求时填标题、类别（搬运/代购/照看宠物/维修/接送孩子/其他）、详细描述、期望完成时间和是否愿意支付报酬，标题或类别为空返回 400，类别不在选项中返回 400。期望完成时间到了还没人接单就自动标为已过期，过期后48小时内保留显示之后归档。

智能匹配根据需求类别和发布者所在楼栋推荐，同一楼栋优先。一个需求只能一个人接单，接单后可以取消，需求不存在返回 404。接单人取消且距期望完成时间不足12小时的，该接单人7天内不能接新单返回 403 和"取消冷却期"。需求完成后双方互相评价（1到5星），评分超范围返回 400，评价必须在完成后72小时内提交否则系统自动给5星。平均评分低于3.0且评价超10条的系统发预警。月度统计汇总发布数、匹配成功率和平均完成时间，各楼栋活跃度按发布0.6和接单0.4权重计算。

接单人在接单的时候系统要检查他当前有没有进行中的需求，有则返回 409 和"请先完成当前需求"。如果同时有两个人抢同一个需求，先到的接单成功后到的返回 409 和"需求已被接走"，接单操作和需求状态的更新要保证原子性不能两个人都接成功。

Express + TypeScript + SQLite，npm run build 能跑就行。
