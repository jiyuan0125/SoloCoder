帮我用 TypeScript 写一个邻里互助平台的后端，管理互助需求的发布和匹配。

居民发布需求时填写标题、类别（搬运/代购/照看宠物/维修/接送孩子/其他）、详细描述、期望完成时间和是否愿意支付报酬。期望完成时间到了还没人接单则自动标记为已过期，过期后48小时内保留显示之后归档。

智能匹配根据需求类别和发布者所在楼栋推荐，同一楼栋优先。一个需求只能一个人接单，但接单后可以取消。接单人取消且距期望完成时间不足12小时的，该接单人7天内不能接新单。需求完成后双方互相评价（1到5星），评价必须在完成后72小时内提交否则系统自动给5星。平均评分低于3.0且评价超过10条的系统发预警。指标统计按月汇总发布数、匹配成功率和平均完成时间，各楼栋活跃度按发布0.6和接单0.4权重计算。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
