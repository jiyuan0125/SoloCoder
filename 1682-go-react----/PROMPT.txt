用 TypeScript 写一个在线提案表决系统。取代纸质投票提升业主参与率。

业主提交提案时填标题、内容、类型和附件说明。先由业委会秘书做形式审查，检查内容完整性和是否重复。通过后进公示阶段（5天），期间业主可以提修改建议。公示后进表决（10天）。

表决用电子投票，选项为赞成、反对和弃权。验证业主身份用手机号，一个手机号只能投一次。表决期内结果不公开，结束后自动揭晓。通过条件为赞成票超全体业主50%。参与率低于40%则无效需重新表决，重新表决编号加R标记。表决通过的进执行公示（15天），超过10%业主提异议则暂停执行。已执行和被否决的提案公示至少6个月。

每个提案从提交到形式审查到公示到表决到执行，每个阶段有独立的操作接口。待办跟踪覆盖全程，形式审查分配给秘书，表决分配给投票管理员。待办超时3天未处理自动升级通知业委会主任。

Express + TypeScript + SQLite，npm run build 能编译通过。
