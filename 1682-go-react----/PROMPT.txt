帮我用 TypeScript 写一个在线提案表决平台的后端，取代纸质投票。

业主提交提案时填写标题、内容、类型和附件说明。先由业委会秘书做形式审查，检查内容是否完整和是否重复。通过后进入公示阶段（5天），期间业主可以提修改建议。公示后进入表决（10天）。

表决采用电子投票，选项为赞成、反对和弃权。投票需验证业主身份（手机号），一个手机号只能投一次。表决期内结果不公开，结束后自动揭晓。通过条件为赞成票超过全体业主50%。参与率低于40%则无效需重新表决，重新表决的编号加R标记。表决通过的提案进入执行公示（15天），期间超过10%业主提出异议则暂停执行。已执行和被否决的提案公示至少6个月。每个提案从提交到执行全程生成待办，形式审查分配给秘书，表决分配给投票管理员。待办超时3天未处理自动升级通知业委会主任。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
