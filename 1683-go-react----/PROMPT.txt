帮我用 TypeScript 写一个智慧社区管理系统的后端，整合公告、报修和缴费功能。

公告管理：物业发布公告时填写标题、正文、类型（通知/紧急/活动预告/维修公告）和发布范围（全小区/指定楼栋）。紧急公告置顶7天，普通置顶3天。公告可以撤回，撤回后显示"已被撤回"。发布后24小时内可修改，修改不超过3次，每次记录修改时间和摘要。

报修管理：居民提交报修填写类别（水电/门窗/电梯/公共设施/其他）、位置、问题描述和联系电话。物业接报后分配维修人员，维修完成后居民确认评价。紧急报修（水电、电梯）2小时内响应，普通24小时。超时未响应自动升级优先级并发催办通知。物业缴费：每户每季度生成缴费单，各项费用精确到分用整数计算。逾期每天按欠费万分之五收滞纳金，月累计不足1分不收。缴费后生成电子收据。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
