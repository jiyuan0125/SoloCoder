社区管理各系统互不相通太乱了，所以想做一个智慧社区管理系统，TypeScript 后端。把公告、报修和缴费整合到一起。

公告管理：物业发布公告填标题、正文、类型（通知/紧急/活动预告/维修公告）和发布范围（全小区/指定楼栋），标题或正文为空返回 400，类型不在范围内返回 400。紧急公告置顶7天普通3天。公告可以撤回，撤回后显示"已被撤回"，公告不存在返回 404 已经撤回的再次撤回返回 409。发布后24小时内可修改，修改不超3次超过返回 400，每次记修改时间和摘要。

报修管理：居民提交报修填类别（水电/门窗/电梯/公共设施/其他）、位置、问题描述和联系电话，类别为空返回 400。物业接报后分配维修人员，完成后居民确认评价。紧急报修（水电、电梯）2小时内响应，普通24小时。超时未响应自动升级优先级并发催办通知。物业缴费每户每季度生成缴费单，各项费用精确到分用整数计算。逾期每天按欠费万分之五收滞纳金，月累计不足1分不收。缴费后生成电子收据，缴费单不存在返回 404。

报修工单的接口路径要支持 /repairs/{repairId}/assign/{staffId}、/repairs/{repairId}/complete 这种多级操作路径，repairId不存在返回 404，staffId不存在返回 404，路径段数不对返回 404。工单状态只能按待接单→已分配→处理中→已完成流转，非法跳转返回 400。分配维修人员时如果工单已被其他人分配了返回 409。

Express + TypeScript + SQLite，npm run build 能跑就行。
