帮我用 TypeScript 写一个养老院管理系统的后端，管理老人入住、护理和家属互动。

老人入住时填写基本信息、身份证号、紧急联系人、既往病史和护理等级（自理/半护理/全护理）。每月收费标准：自理3000元、半护理5000元、全护理8000元。入住缴纳两个月押金。退住时费用按实际天数计算不足一天按一天计，未结清费用从押金扣除。

护理计划包含用药提醒、饮食安排和康复项目。计划变更记录原因和审批人。每日护理记录包含体温、血压、饮食和特殊事项。连续三天体温超37.5度自动生成健康预警通知医生。家属可以查看护理记录和发送留言。家属每月至少查看一次老人情况，连续两个月未查看系统发提醒。探视时段每天上午10-11点和下午3-4点，每个时段每户限约一次。入住率按当前在住人数除以总床位数计算。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
