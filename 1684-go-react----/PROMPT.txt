帮我做一套养老院管理系统，TypeScript 后端。管老人入住、护理和家属互动。

老人入住时填基本信息、身份证号、紧急联系人、既往病史和护理等级（自理/半护理/全护理），身份证号为空返回 400，护理等级不在范围内返回 400。月收费标准：自理3000元、半护理5000元、全护理8000元。入住缴两个月押金，金额用整数分计算。退住费用按实际天数算不足一天按一天计，未结清的从押金扣，押金不足时差额记为欠费不能出现负数。

护理计划包含用药提醒、饮食安排和康复项目，计划变更记原因和审批人。每日护理记录记体温、血压、饮食和特殊事项，体温或血压为空返回 400。连续三天体温超37.5度自动生成健康预警通知医生。家属可以查看护理记录和发留言，每月至少查看一次老人情况，连续两个月未查看系统发提醒。探视时段每天上午10-11点和下午3-4点，每个时段每户限约一次重复预约返回 409。入住率按当前在住人数除以总床位数。

健康预警生成后系统要自动通知医生，预警ID不存在返回 404。通知操作要读老人信息和护理记录，通知过程中新的护理记录写入不影响通知内容——通知的内容快照在生成时就确定。老人退住时要结清所有费用，有未结清费用的退住操作返回 400。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
