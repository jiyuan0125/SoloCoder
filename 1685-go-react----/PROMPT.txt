民政那边提了个需求，要一套居家养老服务管理平台，TypeScript 后端。

老人信息建档含健康状况评估：自理能力评估和认知能力评估各100分，评分超范围返回 400。总分200分，160分及以上为一级（轻度服务）、120到159分二级（中度）、120以下三级（重度）。评估每年一次，结果变化时服务等级调整但有一个月过渡期，过渡期内按原等级和新等级中较高的标准执行。

呼叫服务：老人一键呼叫发起求助，老人ID不存在返回 404。紧急呼叫5分钟内响应，日常求助30分钟内，响应时间从呼叫到服务人员确认接单。超时5分钟通知社区负责人，超时15分钟通知街道负责人。巡访服务按等级制定：一级每月一次、二级每半月一次、三级每周一次，连续两次巡访未见到老人且无法电话联系的立即上报。血压连续三次超140/90或血糖连续三次超7.0自动标记异常生成就医建议，血压或血糖值为空时不计入连续次数。

服务等级从一级调到三级后巡访频率要提高，等级变更的时候系统要自动调整巡访计划。过渡期内巡访按较高的标准来安排，过渡期结束后按新等级来。等级变更和巡访计划的调整要一起完成，计划调整失败时等级仍然变更但标记为"巡访计划待手动调整"。

Express + TypeScript + SQLite，npm run build 能跑就行。
