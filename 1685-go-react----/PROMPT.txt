帮我用 TypeScript 写一个居家养老服务管理平台的后端。

老人信息建档包含健康状况评估：自理能力评估和认知能力评估各100分，总分200分。总分160分及以上为一级（轻度服务）、120到159分二级（中度）、120以下三级（重度）。评估每年一次，评估结果变化时服务等级调整，但有一个月过渡期，过渡期内按原等级和新等级中较高的标准执行。

呼叫服务管理：老人通过一键呼叫发起求助。紧急呼叫5分钟内响应，日常求助30分钟内。响应时间从呼叫到服务人员确认接单。超时5分钟通知社区负责人，超时15分钟通知街道负责人。巡访服务按等级制定：一级每月一次，二级每半月一次，三级每周一次。连续两次巡访未见到老人且无法电话联系的立即上报。血压连续三次超140/90或血糖连续三次超7.0自动标记异常生成就医建议。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
