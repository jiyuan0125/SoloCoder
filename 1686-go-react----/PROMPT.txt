最近在搞月子中心的信息化，需要一个管理系统，TypeScript 后端。管妈妈和宝宝的护理。

孕产妇预订入住时填预产期、预订房型（标准单间每日680元/豪华单间980元/套房1680元）和紧急联系人，房型不在范围内返回 400，预产期早于当前日期返回 400。入住天数从实际入住日算到出院日，不足一天按一天计。提前出院按实际天数结算多退少补。预产期前15天才可以办理入住，提前入住返回 400。

宝宝护理档案记出生体重、身长、喂养方式和每日日志（喂奶时间及量、换尿布、体温、睡眠时长、黄疸指数），体重或体温为负数返回 400。黄疸指数超12标记偏高通知医生，连续两天超15建议转院。每日体重下降超出生体重7%记录为异常。

护理排班按三班制（早7-15、中15-23、晚23-7），每位护理人员每周至少休息一天连续不超6天，同一班次母婴护理师和儿科护士至少各一人。排班时检查冲突，同一人不能同时排两个班次冲突返回 409。排班接口路径像 /scheduling/staff/{staffId}/shifts/{shiftId}/swap 这种多级的要能正确解析，staffId不存在返回 404，shiftId不存在返回 404，路径格式不对返回 404。换班时要重新检查两个人的冲突不能出现换完之后违反排班规则的情况。

Express + TypeScript + SQLite，npm run build 能编译通过。
