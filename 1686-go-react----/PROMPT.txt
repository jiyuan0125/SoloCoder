帮我用 TypeScript 写一个月子中心管理系统的后端，管理妈妈和宝宝的护理。

孕产妇预订入住时填写预产期、预订房型（标准单间每日680元/豪华单间980元/套房1680元）和紧急联系人。入住天数从实际入住日算起到出院日，不足一天按一天计。提前出院按实际天数结算多退少补。预产期前15天才可以办理入住。

宝宝护理档案记录出生体重、身长、喂养方式和每日日志（喂奶时间及量、换尿布、体温、睡眠时长、黄疸指数）。黄疸指数超12标记偏高通知医生，连续两天超15建议转院。每日体重下降超过出生体重7%记录为异常。护理排班按三班制（早7-15、中15-23、晚23-7），每位护理人员每周至少休息一天连续不超6天，同一班次母婴护理师和儿科护士至少各一人。排班时检查冲突，同一人不能同时排两个班次。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
