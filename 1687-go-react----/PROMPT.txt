帮我用 TypeScript 写一个心理咨询预约平台的后端，管理咨询师、预约和咨询档案。

咨询师注册时填写资质证书、擅长领域、经验和收费标准。管理员审核后才能接单。咨询师设置可预约时段，按周设置重复时段或特定日期例外。已预约的时段不能再被预约。咨询师可以在预约开始前24小时取消预约。同一用户同一天对同一咨询师只能预约一次。

来访者预约填写姓名、手机号和简要问题描述。预约状态有待确认、已确认、进行中、已完成和已取消。来访者可在预约开始前12小时取消，取消后时段重新开放。预约开始后15分钟内未出现咨询师可标记"爽约"，爽约累计3次后该来访者30天内不能预约。咨询记录包含日期、时长、内容摘要和后续建议，对来访者不可见。不同咨询师之间不能查看对方的来访者档案。来访者重复提交同一时段的预约不会创建重复记录。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
