我们平台需要一个心理咨询预约系统，TypeScript 后端。管咨询师、预约和咨询档案。

咨询师注册时填资质证书、擅长领域、经验和收费标准，管理员审核后才能接单。咨询师设置可预约时段，按周设置重复时段或特定日期例外。已预约的不能再被预约。咨询师可以在预约开始前24小时取消。同一用户同一天对同一咨询师只能预约一次。

来访者预约填姓名、手机号和简要问题描述。预约状态有待确认、已确认、进行中、已完成和已取消。来访者可在开始前12小时取消，取消后时段重新开放。开始后15分钟内未出现咨询师可标"爽约"，累计3次后该来访者30天内不能预约。咨询记录含日期、时长、内容摘要和后续建议，对来访者不可见。不同咨询师之间不能看对方的来访者档案。重复提交同一时段的预约不会创建重复记录。

预约确认后系统要同时标记时段为已占用和发送通知给来访者。标记时段为已占用和发送通知要一起完成，通知发送失败不影响时段占用。

Express + TypeScript + SQLite，npm run build 能跑就行。
