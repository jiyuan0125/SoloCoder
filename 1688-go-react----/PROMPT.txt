心理测评数据全靠纸质问卷太落后了，所以想做一个心理测评系统，TypeScript 后端。

系统内置多种量表，每种有名称、适用人群和题目列表，量表ID不存在返回 404。每道题有文本、选项和分值。量表总分计算规则不同：有的直接求和，有的按维度加权汇总，有的需要反向计分（用总分减该题得分）。结果根据常模对照表转换为标准分和等级（正常/轻度异常/中度异常/重度异常）。

测评流程：记录开始时间和每道题的作答时间。可以中途暂停，48小时内继续，超时作废返回 400 和"测评已超时"。同一人30天内不能对同一量表重复测评返回 409。完成后自动计算结果生成报告。中度或重度异常自动触发预警通知主管或班主任，预警ID不存在返回 404。同一人连续两次中度异常或任何一次重度异常，预警升级为紧急需48小时内介入。预警解除需咨询师手动操作并填处理记录，未填记录的解除操作返回 400。管理端统计各等级分布、各量表平均分趋势和预警处理及时率。

预警触发时系统要自动通知相关人员，通知内容包含测评结果摘要。如果被测人在预警处理过程中又完成了一次测评产生新的预警，新预警独立记录不覆盖旧的返回 201。预警状态只能从未处理→处理中→已解除流转，已解除的预警不能重新打开返回 400。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
