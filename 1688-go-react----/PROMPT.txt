帮我用 TypeScript 写一个心理测评系统的后端，管理量表和测评流程。

系统内置多种量表，每种有名称、适用人群和题目列表。每道题有文本、选项和分值。量表总分计算规则不同：有的直接求和，有的按维度加权汇总，有的需要反向计分（用总分减该题得分）。结果根据常模对照表转换为标准分和等级（正常/轻度异常/中度异常/重度异常）。

测评流程：记录开始时间和每道题的作答时间。可以中途暂停，48小时内继续，超时作废。同一人30天内不能对同一量表重复测评。测评完成后自动计算结果生成报告。中度或重度异常自动触发预警，通知主管或班主任。同一人连续两次中度异常或任何一次重度异常，预警升级为紧急需48小时内介入。预警解除需咨询师手动操作并填写处理记录。管理端统计各等级分布、各量表平均分趋势和预警处理及时率。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
