社工机构管理系统，TypeScript 后端。个案、小组活动和社区服务需要统一管理。

社工创建个案档案，包含案主信息、问题描述、需求评估和介入计划，案主信息为空返回 400。一个社工同时负责的进行中个案不超15个，超出不能接新案返回 403 除非主管特批。每次面谈记服务记录（日期、时长、内容摘要和下一步计划），日期为空返回 400。个案从接案到结案不超6个月，需延长的提交延期申请，个案不存在返回 404。

小组活动策划时填名称、目标、活动次数、每次时间和地点、人数上限（6到12人），上限不在范围内返回 400。成员报名后由社工审批，活动不存在返回 404。某成员连续两次缺席且未请假可以移出。活动结束后生成总结报告。社区服务记录服务日期、内容、参与人数和效果。管理层看板：当前进行中个案数、本月新接和结案数、平均个案服务时长、小组活动完成率、社区服务覆盖人次。完成率按已完成除以计划活动数计算，计划数为零时完成率按零算。

个案结案的时候要把所有面谈记录和介入计划打包归档，个案不在结案条件（如未完成介入计划）时结案返回 400。归档后的个案信息只读不可修改尝试修改返回 405。个案如果需要重新打开要主管审批，审批和个案状态的恢复要一起完成。

Express + TypeScript + SQLite，npm run build 能跑就行。
