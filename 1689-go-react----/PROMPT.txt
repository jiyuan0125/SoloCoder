帮我用 TypeScript 写一个社工机构管理系统的后端，管理个案、小组活动和社区服务。

个案管理：社工创建个案档案，包含案主信息、问题描述、需求评估和介入计划。一个社工同时负责的进行中个案不超过15个，超出不能接新案除非主管特批。每次面谈记录服务记录（日期、时长、内容摘要和下一步计划）。个案从接案到结案不超过6个月，需要延长的提交延期申请。

小组活动管理：策划活动时填写名称、目标、活动次数、每次时间和地点、人数上限（6到12人）。成员报名后由社工审批。某成员连续两次缺席且未请假可以移出。活动结束后生成总结报告。社区服务记录服务日期、内容、参与人数和效果。机构管理层数据看板：当前进行中个案数、本月新接和结案数、平均个案服务时长、小组活动完成率、社区服务覆盖人次。完成率按已完成除以计划活动数计算。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
