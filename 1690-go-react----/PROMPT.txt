帮我用 TypeScript 写一个志愿者管理系统的后端，覆盖全生命周期。

招募管理：发布招募公告时填写活动名称、服务类别、日期时段、地点和招募人数。志愿者在线报名填写姓名、手机号、身份证号和紧急联系人。身份证号要校验年龄，未满18周岁需记录监护人信息。同一活动同一志愿者只能报名一次。报名截止后组织者审核通过或拒绝。

培训管理：新志愿者必须完成入门培训才能参加活动。培训含基础知识和安全须知两部分各10道选择题，每部分答对8道通过，两部分都通过才算完成。每年需完成年度复训，未完成不能报名新活动。激励积分：每小时基础10分，特殊岗位每小时额外5分。积分兑换奖品或时长证明。星级评定：一星50小时、二星100小时、三星200小时、四星500小时、五星1000小时。年度复训到期前30天生成提醒待办。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
