用 TypeScript 写一个志愿者管理平台。覆盖从招募到激励的全生命周期。

招募管理：发布招募公告时填活动名称、服务类别、日期时段、地点和招募人数。志愿者在线报名填姓名、手机号、身份证号和紧急联系人。身份证号要校验年龄，未满18周岁需记录监护人信息。同一活动同一志愿者只能报一次。报名截止后组织者审核通过或拒绝。

培训管理：新志愿者完成入门培训才能参加活动。培训含基础知识和安全须知两部分各10道选择题，每部分答对8道通过，两部分都通过才算完成。每年需完成年度复训，未完成不能报名新活动。激励积分：每小时基础10分，特殊岗位每小时额外5分。积分兑换奖品或时长证明。星级评定：一星50小时、二星100小时、三星200小时、四星500小时、五星1000小时。年度复训到期前30天生成提醒待办。

审核通过后系统要自动发通知给志愿者，通知内容包含活动详情和集合地点。如果审核过程中活动信息变了（比如时间调整），通知要拿最新的活动信息来发。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
