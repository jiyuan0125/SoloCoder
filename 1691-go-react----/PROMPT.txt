帮我用 TypeScript 写一个社会组织管理系统的后端，管理注册、年检和评估。

组织注册时填写名称、统一社会信用代码、类型（社会团体/民办非企业/基金会）、业务主管单位、法定代表人、住所和业务范围。组织名称不能与已注册的重复（忽略标点和空格后比较）。审核通过后发放登记证书有效期5年。审核不通过可在30天内补材料重新提交，重新提交不超过3次。

年检管理：每年3月1日到5月31日为年检申报期。提交年检材料含年度工作报告、财务审计报告和业务活动清单。年检结果分合格、基本合格和不合格。连续两年不合格自动注销。年检截止后未参检的组织视为不合格。年检开始前30天自动生成提醒待办。评估管理每两年一次，四个维度各25分满分100分。等级5A（90以上）、4A（80-89）、3A（70-79）、2A（60-69）、1A（60以下）。3A及以上才有资格承接政府购买服务。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
