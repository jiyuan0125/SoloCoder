帮我做一套社会组织管理系统，TypeScript 后端。管注册、年检和评估。

组织注册时填名称、统一社会信用代码、类型（社会团体/民办非企业/基金会）、业务主管单位、法定代表人、住所和业务范围。组织名称不能与已注册的重复（忽略标点和空格后比较）。审核通过后发放登记证书有效期5年。审核不通过可在30天内补材料重新提交，重新提交不超3次。

年检管理：每年3月1日到5月31日为申报期。提交年检材料含年度工作报告、财务审计报告和业务活动清单。年检结果分合格、基本合格和不合格。连续两年不合格自动注销。截止后未参检的视为不合格。年检开始前30天自动生成提醒待办。评估管理每两年一次，四个维度各25分满分100分。等级5A（90以上）、4A（80-89）、3A（70-79）、2A（60-69）、1A（60以下）。3A及以上才有资格承接政府购买服务。

组织年检不合格的不能参加评估，需要先通过整改补检。组织注销后所有相关记录保留但标记为"已注销"不可操作。

Express + TypeScript + SQLite，npm run build 能跑就行。
