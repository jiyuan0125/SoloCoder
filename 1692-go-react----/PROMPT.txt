培训部门那边提了个需求，要一套公益培训平台，TypeScript 后端。管课程、讲师和学员报名。

创建课程时填名称、类别、描述、讲师、总课时数、每课时时长、最大报名人数和开课日期。费用为0表示免费。招生中的课程开课前7天报名不足5人自动取消并通知已报名人员，取消后7天内不可重新开设同一课程。

讲师注册时填姓名、资质、擅长领域和授课经历，需管理员审核。每位讲师同时进行的课程不超3门。讲师评分来自学员评价（1到5分），低于3.5分暂停排课。学员报名同一课程只能报一次，有前置要求时检查是否满足。开课前3天内不能退课，退课后名额释放给等待列表下一个人。证书管理：出勤率达80%以上获得结业证书，编号格式"PE"加年份加4位流水号。评价低于2分不发证书但保留完成记录。

课程取消的时候要给所有已报名学员发通知。通知发送过程中如果有学员刚好自己退课了，那条通知就跳过不发。

Express + TypeScript + SQLite，npm run build 能编译通过。
