帮我用 TypeScript 写一个公益培训平台的后端，管理课程、讲师和学员报名。

课程管理：创建课程时填写名称、类别、描述、讲师、总课时数、每课时时长、最大报名人数和开课日期。费用为0表示免费。招生中的课程开课前7天报名不足5人自动取消并通知已报名人员，取消后7天内不可重新开设同一课程。

讲师管理：注册时填写姓名、资质、擅长领域和授课经历，需管理员审核。每位讲师同时进行的课程不超过3门。讲师评分来自学员评价（1到5分），低于3.5分暂停排课。学员报名：同一课程只能报名一次。课程有前置要求时检查学员是否满足。开课前3天内不能退课，退课后名额释放给等待列表下一个人。证书管理：出勤率达80%以上获得结业证书，编号格式"PE"加年份加4位流水号。评价低于2分不发证书但保留完成记录。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
