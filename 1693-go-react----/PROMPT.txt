最近在搞精准扶贫，需要一个管理系统，TypeScript 后端。覆盖建档立卡到帮扶成效评估。

贫困户建档含家庭基本信息、致贫原因（可多选）、家庭资产和劳动力情况，致贫原因为空返回 400。致贫原因排在第一位的自动判断为主要致贫原因。贫困户分三级：一般、低保和特困，级别不在范围内返回 400。档案每年更新由帮扶责任人入户核实，户ID不存在返回 404。

帮扶计划每户一份，措施包括产业、就业、教育、健康和兜底保障五类，计划可调整但需说明原因并获乡镇批准，措施类型不在范围内返回 400。每季度帮扶效果评估（有效/部分有效/无效），评估结果不在范围内返回 400，连续两次无效的措施需重新制定。脱贫标准为家庭年人均纯收入超过脱贫线且两不愁三保障，系统根据收入数据自动判断是否达标。脱贫后继续跟踪两年，返贫则标记"返贫监测"。县乡村三级看板展示贫困户总数、已脱贫户数、返贫监测户数和各致贫原因分布。

帮扶效果评估为"无效"后要触发措施重新制定的流程，评估记录不存在返回 404。重新制定时要读原计划信息和历史评估结果来参考。已脱贫的贫困户如果返贫了，原帮扶计划自动恢复为执行中状态，状态恢复和历史记录的写入要一起完成不能只恢复不记录。

Express + TypeScript + SQLite，npm run build 能跑就行。
