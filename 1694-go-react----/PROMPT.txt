项目资金管理全靠Excel太不透明了，所以想做一个乡村振兴项目资金管理系统，TypeScript 后端。

项目申报填项目名称、类别、地点、预算和实施期限。预算分项填写（建设费、设备购置费、人工费、其他），各项之和必须等于总预算。提交后乡镇初审、县级复审。审核不通过可修改重新提交，每个项目最多3次。

资金管理：立项后拨启动资金30%，中期验收拨40%，终期验收拨30%。每笔拨付记金额、日期、方式和收款账户。各项支出不得超过该项预算。预算有结余可调剂到其他项但需提交调剂申请获批准。所有金额精确到分用整数存。中期和终期验收结果分通过、整改后通过和不通过，整改后通过要30天内完成整改。验收不通过终止拨付启动审计。同一个项目拨付比例之和不能超过100%。

项目从申报到初审到复审到立项到拨付到验收，每个阶段有前置条件。初审通过才能提交复审，复审通过才能立项，立项后才能拨付启动资金。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
