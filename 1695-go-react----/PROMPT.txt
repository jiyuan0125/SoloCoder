帮我用 TypeScript 写一个应急避难场所和物资管理系统的后端。

避难场所管理：每个场所有名称、位置、类型、面积、可容纳人数、设施配备和负责人。状态有可用、维护中、已满和不可用。维护中的不能被选为疏散目标。分配人数时实时检查剩余容量，达到容量90%标记"即将满员"并推荐就近可用场所。

物资管理：饮用水、食品、帐篷、棉被、急救包和手电筒等，每种有库存数量、保质期和最低储备量。库存低于最低储备量自动生成补货待办。距离过期不足30天标记"临期"优先发放。过期物资必须报废不能发放。物资调拨记录调出场所、调入场所、种类和数量，双方库存实时更新。调拨过程中调出方库存先扣减，如果调入方确认失败则调出方库存恢复。疏散调度时系统根据距离权重0.5、容量权重0.3和设施权重0.2自动推荐最优方案。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
