帮我用 TypeScript 写一个应急物资储备管理系统的后端，覆盖储备、调拨和发放。

物资储备管理：仓库分中心库和片区库两级。物资分类管理，每件记录名称、规格、数量、入库日期、保质期和供应商。库存采用先进先出，发放时优先出库入库日期最早的批次。物资台账按日更新，盘点发现差异记录并生成核查待办。

物资调拨：片区库库存不足时向中心库申请。审批时检查中心库库存，不足则部分批准注明可供应数量。调拨在途物资不计入任何仓库可用库存，入库后才能使用。调拨单状态有待审批、已批准、运输中、已到达和已入库。物资发放：发放后库存实时扣减。发放记录不可删除只能作废，作废时库存恢复。每日发放汇总报表展示当日各类物资总量。调拨出库时如果中心库在审批后到出库之间又有其他出库导致库存不足，要以实际库存为准而不是审批时的数量。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
