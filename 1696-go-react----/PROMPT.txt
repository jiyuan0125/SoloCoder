应急物资储备管理服务，TypeScript 实现。覆盖储备、调拨和发放全流程。

仓库分中心库和片区库两级，仓库名称重复返回 409。物资分类管理，每件记名称、规格、数量、入库日期、保质期和供应商，名称为空返回 400，数量为零或负数返回 400。库存用先进先出，发放时优先出库入库日期最早的批次。物资台账按日更新，盘点发现差异记录并生成核查待办。

片区库库存不足时向中心库申请调拨，调拨申请不存在返回 404。审批时检查中心库库存，不足则部分批准注明可供应数量。调拨在途物资不计入任何仓库可用库存，入库后才能用。调拨单状态有待审批、已批准、运输中、已到达和已入库，只能按顺序流转非法跳转返回 400。发放后库存实时扣减，发放记录不可删只能作废，作废时库存恢复，已作废的不能再次作废返回 409。每日发放汇总报表展示当日各类物资总量。调拨出库时如果中心库在审批后到出库之间又有其他出库导致库存不足，要以实际库存为准返回 409 和"库存不足"。

调拨在途的时候如果中心库又收到了新的调拨申请，可用库存要排除在途部分来计算，计算结果为零或负数返回 400 拒绝申请。

Express + TypeScript + SQLite，npm run build 能编译通过。
