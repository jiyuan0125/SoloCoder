帮我用 TypeScript 写一个灾情信息管理系统的后端，覆盖上报、核查、统计和发布。

灾情上报：基层信息员上报灾情，包含灾害类型、发生时间、地点、受灾人口、转移安置人数、死亡失踪人数、农作物受灾面积、房屋倒损数量和直接经济损失估算。类型和时间为必填，其他可先填"待核实"。同一地点同一时间段的相似灾情上报自动合并为一条，合并时取各次上报中数值最大的字段值。

灾情核查：县级收到上报后安排核查。核查后的数据为确认数据不可随意修改，修改需提交申请获市级审批。重大灾情（死亡失踪大于0或经济损失超1000万）24小时内完成核查，一般灾情72小时。统计报表自动汇总生成日报周报月报，经济损失金额用整数分存储汇总时控制精度。灾情发布经核查确认后由授权人员审核发布。敏感数据发布时脱敏。发布后可修改但每次记录前后内容，修改不超过3次。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
