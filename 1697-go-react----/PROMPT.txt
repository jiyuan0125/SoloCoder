用 TypeScript 写一个灾情信息管理系统。覆盖上报、核查、统计和发布。

基层信息员上报灾情，包含灾害类型、发生时间、地点、受灾人口、转移安置人数、死亡失踪人数、农作物受灾面积、房屋倒损数量和直接经济损失估算，类型和时间为必填缺失返回 400，其他可先填"待核实"。同一地点同一时间段的相似灾情上报自动合并为一条，合并时取各次上报中数值最大的字段值。

县级收到上报后安排核查，上报记录不存在返回 404。核查后的数据为确认数据不可随意修改，修改需提交申请获市级审批，未经审批修改返回 405。重大灾情（死亡失踪大于0或经济损失超1000万）24小时内完成核查，一般72小时。统计报表自动汇总日报周报月报，经济损失用整数分存储汇总时控制精度。灾情发布经核查确认后由授权人员审核发布，未核查的不能发布返回 400。发布后可修改但每次记前后内容，修改不超3次超过返回 400。

灾情从上报到核查到发布是完整流程，核查完成后才能发布，未核查的发布返回 400。核查结果有合格和需补充两种，需补充的退回修改后重新提交核查。同一灾情不能并核查返回 409。

Express + TypeScript + SQLite，npm run build 能跑就行。
