疫情防控数据全靠手工汇总太慢了，所以想做一个疫情防控管理系统，TypeScript 后端。管排查、隔离和核酸检测。

人员排查管理记录排查对象基本信息、排查日期、方式、旅居史和健康状况。排查结果分正常、需隔离和需送医。系统自动识别14天内到过中高风险地区的人员标记为"重点人员"，重点人员每天健康打卡报告体温和症状。

隔离管理分居家和集中两种，期限14天从最后暴露或到达风险地区之日起算。隔离期间每天记体温和健康状况，体温超37.3度或出现呼吸道症状立即升级为需送医。隔离到期自动生成解除通知但需社区医生确认签字。核酸检测：隔离人员第1、7、14天各检测一次，重点人员每3天一次。阳性立即转隔离并启动流调，阴性但后续出现症状的提示重新检测。系统内置调度器每天早上8点汇总前一日数据、检查隔离到期人员、生成检测名单和发送健康打卡提醒。

隔离到期生成解除通知时，通知内容要读隔离人员的健康记录。如果隔离人员刚好在到期前提交了新的健康数据，解除通知要基于最新的健康数据来判断。

Express + TypeScript + SQLite，npm run build 能编译通过就行。
