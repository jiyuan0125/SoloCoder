帮我用 TypeScript 写一个疫情防控管理系统的后端，管理排查、隔离和核酸检测。

人员排查管理：记录排查对象基本信息、排查日期、方式、旅居史和健康状况。排查结果分正常、需隔离和需送医。系统自动识别14天内到过中高风险地区的人员标记为"重点人员"。重点人员每天健康打卡报告体温和症状。

隔离管理：分居家和集中两种。隔离期限14天从最后暴露或到达风险地区之日起算。隔离期间每天记录体温和健康状况，体温超37.3度或出现呼吸道症状立即升级为需送医。隔离到期自动生成解除通知但需社区医生确认签字。核酸检测：隔离人员第1、7、14天各检测一次，重点人员每3天一次。检测结果阳性立即转隔离并启动流调。阴性但后续出现症状的提示重新检测。系统内置调度器每天早上8点汇总前一日数据、检查隔离到期人员、生成检测名单和发送健康打卡提醒。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
