帮我用 TypeScript 写一个疫苗接种管理系统的后端。

疫苗管理：每种疫苗记录名称、厂家、批号、规格、有效期、库存和储存温度要求。库存按批次管理，发放时优先使用临近有效期的批次。有效期不足60天标记"临期"，临期疫苗不能用于首次接种但可用于补种。过期疫苗禁止发放。库存低于安全库存量生成补货待办。

接种预约：居民选择疫苗种类、日期和时段（30分钟一个时段，每时段上限20人）。同一居民同一天不能预约多个时段。接种日前一天不能取消。某时段预约不足5人且距接种日不足24小时自动合并到相邻时段并通知已预约人员。接种记录管理：接种时记录接种人信息、疫苗批号、接种部位和剂量。接种凭证编号"YM"加年月日加6位流水号，系统重启后流水号从已有最大值继续。接种程序自动计算下次接种日期，延迟超7天标记"逾期未种"生成催种通知。不良反应监测：接种后14天内可上报，严重不良反应立即生成紧急待办。同一批号不良反应超5例自动暂停该批次。

核心功能实现为独立模块。服务端用 Express 框架提供 HTTP 接口，客户端是命令行工具通过 HTTP 调用服务端。项目用 TypeScript 写，tsconfig 开启 strict 模式。npm install 后 npm run build 能编译通过，node dist/server.js 能启动服务端。服务端监听端口通过环境变量指定。
