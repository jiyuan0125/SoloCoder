帮我做一套疫苗接种管理系统，TypeScript 后端。覆盖疫苗库存、预约、接种和不良反应监测。

每种疫苗记名称、厂家、批号、规格、有效期、库存和储存温度要求。库存按批次管理，发放时优先用临近有效期的批次。有效期不足60天标记"临期"，临期疫苗不能用于首次接种但可用于补种。过期疫苗禁止发放。库存低于安全库存量生成补货待办。

接种预约：居民选疫苗种类、日期和时段（30分钟一个时段，每时段上限20人）。同一居民同一天不能预约多个时段。接种日前一天不能取消。某时段预约不足5人且距接种日不足24小时自动合并到相邻时段并通知已预约人员。接种记录记接种人信息、疫苗批号、接种部位和剂量。接种凭证编号"YM"加年月日加6位流水号，系统重启后流水号从已有最大值继续。接种程序自动计算下次接种日期，延迟超7天标记"逾期未种"生成催种通知。不良反应监测：接种后14天内可上报，严重的立即生成紧急待办。同一批号不良反应超5例自动暂停该批次。

不良反应上报的接口路径像 /vaccinations/{recordId}/reactions/{reactionId}/report 这种多级结构。

Express + TypeScript + SQLite，npm run build 能跑就行。
