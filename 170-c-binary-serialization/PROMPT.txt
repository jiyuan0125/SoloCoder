帮我用 C 写一个二进制数据的打包和解包工具。场景是：我们的系统需要在网络上传一些结构化的数据，如果用 JSON 之类的文本格式，体积大、解析慢。需要一种更紧凑的二进制格式来传输数据。工具要支持的基本数据类型包括：整数（8位、16位、32位、64位，各有符号版和无符号版）、浮点数（32位单精度和64位双精度）、定长字符串（固定长度的字符数组）、变长字符串（前面用4字节记录长度，后面跟实际内容）、布尔值（1字节，0或1）。还要支持嵌套结构——一个消息里可以包含另一个消息作为字段。打包的时候按照字段定义的顺序依次把各字段的二进制数据写入一个字节缓冲区。解包的时候按同样的顺序依次读取并还原。必须处理字节序问题——发送端可能是小端机器（x86），接收端可能是大端机器（ARM），统一用网络字节序（大端）来存储多字节整数。还要支持向前兼容——如果接收端是旧版本，不认识某些新字段，要能跳过这些字段继续解析后面的内容，不能崩溃。打包和解包的结果要能相互还原——打包后解包得到的数据要和原始数据完全一致。用纯 C 写，gcc 编译通过。要提供一个便捷的方式让调用者定义消息的结构——比如用一个描述文件来声明字段名、类型和顺序。
代码拆成至少 4 个源文件：数据类型编码、字节序处理、消息结构定义与序列化、主程序，各自有头文件和实现文件。gcc 编译能过。
