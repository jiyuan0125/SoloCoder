帮我用 C 写一个带过期时间的本地缓存模块。场景是：我们在做服务网关，后端有很多微服务，有些数据变化不频繁（比如商品分类列表、用户基本信息、系统配置参数），每次请求都去后端查太浪费了。需要在网关这一层缓存一份，减轻后端压力。缓存的基本要求：有固定容量上限（比如最多存1000条），存满了之后如果要存新的，就把最久没被访问过的那条踢出去腾位置。每条缓存数据可以单独设置过期时间——比如用户信息缓存10分钟，配置参数缓存1小时。读取缓存的时候自动检查过期时间，过期了就当没有这条数据。写入时如果指定的 key 已经存在，就更新它的内容和过期时间，并且把它标记为「刚被访问过」（这样它就不会被当作最久没访问的而踢掉）。支持批量操作——一次查询多个 key 的值，一次删除多个 key。提供一个统计面板：缓存的命中率（命中次数除以总查询次数）、当前存了多少条、因为过期被清理了多少条、因为容量满了被淘汰了多少条。多线程环境下读写必须安全。还要考虑一种情况：如果大量 key 同时过期（比如批量导入的数据都设了相同的过期时间），过期清理操作本身会不会造成性能抖动。用纯 C 写，gcc 编译通过。还要支持「永不过期」的缓存条目——有些配置参数不需要过期，要一直保留在缓存里直到被主动删除。
代码拆成至少 4 个源文件：缓存存储、淘汰策略、过期清理、主程序，各自有头文件和实现文件。gcc 编译能过。
