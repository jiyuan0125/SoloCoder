我们科研处最近需要一套科技成果管理系统，管理成果登记、鉴定评审和成果转化跟踪，用 Go 做 REST 后端 React 做前端。

成果登记是基础。科研人员提交登记填名称、类型（发明专利、实用新型、外观设计、软著、集成电路布图、植物新品种、国家级标准、行业标准、论文、专著、其他）、第一完成人、完成人列表、所属学院、完成日期和简介。每个成果有版本号初始v1.0。修改时版本递增（v1.1、v1.2小版本，重大修改v2.0）。查询默认展示最新版本可查看历史。版本号比较要按语义化规则先比大版本再比小版本不能直接字符串排序。

成果鉴定组织专家鉴定。管理员创建鉴定会选待鉴定成果、日期、形式（会议鉴定、函审鉴定）和鉴定专家（至少5人）。专家评审后给鉴定意见和评价等级（国际领先、国际先进、国内领先、国内先进、一般）。汇总后生成鉴定证书记录结论和等级，证书生成后不可修改。

成果转化跟踪应用。每条转化关联一个成果，填转化方式（许可、转让、作价入股）、受让方名称、合同金额（万元精确到两位小数）、签约日期和状态（洽谈中→已签约→实施中→已完成）。同成果可多条转化记录但同一成果同一受让方不能签两份相同类型的合同。

React做成果登记（含版本管理）、鉴定管理、转化跟踪和统计报表（各类型成果数量、鉴定等级分布、转化率）。Gin框架内存存储。鉴定会前7天通知所有鉴定专家，结束后提醒生成证书。评价等级只能五选一传其他400。专家不足5人不能创建鉴定会400。合同金额零或负数400。同成果同受让方同类型合同重复409。版本号递增时大小版本不能同时为0至少一个有变化400。鉴定证书不可修改400。成果有关联鉴定或转化记录不能删除409。
服务端端口通过命令行参数或环境变量指定。
