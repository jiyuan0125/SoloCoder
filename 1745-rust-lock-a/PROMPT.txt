多实例同时操作共享资源老是冲突。Rust axum 搞个分布式锁服务，走 HTTP 接口。锁通过接口获取和释放，支持超时自动释放。
获取锁时如果锁已被占用，可以等待（带超时）或者立即返回失败。锁的持有者通过 token 标识，释放时必须带 token 验证。
锁续期：持有者可以延长锁的超时时间。续期接口是 /api/locks/{lock_id}/renew，通过 PUT 请求。
锁有优先级，高优先级的等待者先获取。同一把锁的等待队列按优先级排序。锁超时后自动释放，等待队列中的下一个自动获取。
监控接口：查看所有活跃锁、等待队列长度、锁的持有时长。
端口 PORT 环境变量，cargo build 能过。
