代码提交前要清理行尾空格和多余空白行，但手动清理太麻烦。你帮我写一个 Go 命令行工具做文本文件的空白字符清理，叫 wsstrip。

工具用 cobra 框架，有 clean 和 check 两个子命令。

clean子命令接收文件路径（支持多个文件和目录递归），执行以下清理操作：去除每行末尾的空格和制表符、去除文件末尾多余的空行（保留最后一个换行符）、将连续的空行压缩为一个空行（但保留有意义的段落分隔）。Markdown文件中行尾两个空格表示硬换行，这种有意义的行尾空格不能去掉，需要在配置中为Markdown文件设置例外规则。缩进用的空格和制表符不要和行尾空格混淆，只去除行尾的空白字符。包含中文的全角空格（U+3000）不在清理范围内，因为中文排版中全角空格是有意义的。支持通过配置文件指定要清理的操作类型，不是所有操作都要一次做完。清理后如果文件内容有变化就覆盖原文件，没有变化就不动。每次清理记录修改了哪些文件、每个文件去除了多少行尾空格、压缩了多少空行。如果文件编码不是UTF-8，跳过不处理并给出警告。空文件（大小为0字节）直接跳过。

check子命令只检查不修改，输出每个文件的问题统计：行尾有空格的行号列表、连续空行超过一处的位置、文件末尾多余空行的数量。输出格式为人类可读的文本。

还有一个特殊用法：作为 Git pre-commit hook 使用。工具支持 --git-staged 参数，只检查 Git 暂存区中的文件，如果有问题就返回非零退出码，阻止提交。这样开发者提交代码时就会自动被检查。
