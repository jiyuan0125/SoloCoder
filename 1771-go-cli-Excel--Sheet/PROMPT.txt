Go 的 excelize 库做 Excel 读写挺方便的，但财务那边的需求不止读写——要转 CSV、操作 Sheet、还能像 SQL 一样查数据。用 Go 写个 xltool，urfave/cli v2 框架，有 convert、sheet、query 三个子命令。

convert 把 xlsx 转 CSV。支持指定 Sheet 名称或索引，不指定就转第一个。可以选编码（默认 UTF-8，也支持 GBK）。Excel 的日期序列号要转成可读字符串，格式可以指定。多 Sheet 可以一次全转，文件名用"原名_Sheet名.csv"。公式单元格取计算后的值。合并单元格只有左上角有值，其他位置要自动填充。超过 50 万行的大文件用流式读取。反向也支持：CSV 转 Excel，可以指定列类型（文本/数字/日期），纯数字文本（手机号、身份证号）不能被 Excel 自动转成数字导致精度丢失，引号内的逗号和换行也要正确处理。

sheet 操作 Excel 的 Sheet：list 列出所有 Sheet 名称和索引，rename 重命名，copy 复制到同文件或另一个 Excel，delete 删除，merge 把多个 Sheet 按行追加合并（列名对齐），split 按某列值拆分成多个 Sheet。

query 用类 SQL 语法查 Excel 数据。SELECT 指定列，WHERE 条件过滤（等于/大于/小于/包含），ORDER BY 排序，LIMIT 限制行数。结果输出表格或 CSV。
Excel 文件不存在或不是有效 xlsx 时退出码 1。sheet merge 合并时列名重复加序号后缀，不能丢数据。CSV 转 Excel 时纯数字文本列要处理为文本类型。大文件流式读取内存不超过 200MB。query 条件语法错误退出码 2 并输出错误位置。
