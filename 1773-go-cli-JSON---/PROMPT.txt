季度末了，接口文档和配置文件都要梳理，JSON 格式化、字段提取、差异对比全是手工活。用 Go 写个 jtool，urfave/cli v2 框架，五个子命令：format、extract、compare、flatten、validate。

format 格式化 JSON。从文件或标准输入读，输出美化后的 JSON。可以指定缩进（空格数或制表符）、排序键名。输入不合法时输出具体语法错误和位置（行号列号）。Unicode 转义要正确处理显示。超过内存的超大文件用流式解析，这时 extract 只支持提取顶层字段。

extract 提取字段值。用点号路径访问嵌套字段，比如 data.items[0].name。通配符 data.items[*].name 提取数组所有元素。数组切片 data.items[0:5]。输出可以是原始值、纯文本或表格，支持同时提多个字段。

compare 比较两个 JSON 差异。递归比较所有层级，输出三类：只在左边的字段、只在右边的字段、两边都有但值不同的。不同的字段显示左右值。支持忽略某些字段。数值 1 和 1.0 视为相等。

flatten 把嵌套 JSON 展平为单层键值对，键名用点号连接，数组用索引。也支持反向 unflatten，展平的还原为嵌套。反向操作的结果要能重新作为正向操作的输入，且结果与原始数据一致。

validate 用 JSON Schema 验证 JSON 文件，输出验证结果和不符合规范的字段列表。
format 输入不合法 JSON 退出码 1 并输出错误行号列号。extract 路径不存在退出码 1。compare 有差异退出码 1，一致退出码 0。flatten 再 unflatten 回来要和原始 JSON 逐层完全一致。超大文件用流式解析，内存不超过 500MB。
