市面上 YAML 处理工具要么太重要么不支持合并策略，我们 K8s 配置合并的需求很简单但现有方案都做不好。用 Go 写个 ytool，cobra 框架，五个子命令：validate、merge、diff、anchor、convert。

validate 验证 YAML 语法。检查语法错误、重复键名、缩进问题、标签合法性，输出详细错误和位置。支持验证多个文件。YAML 1.1 和 1.2 在类型解析上有差异（比如"yes"在 1.1 是布尔 true，1.2 是字符串），工具要能识别版本按对应规范处理。多文档 YAML（--- 分隔）每个文档独立处理。

merge 合并多个 YAML 文件。列表有三种策略：replace（后者替换前者）、append（追加）、mergeByKey（按指定键深度合并）。字典类型递归合并，后者覆盖前者。类型冲突时后者覆盖但输出警告。可以通过配置文件指定不同路径用不同策略。

diff 对比两个 YAML 差异，忽略注释和键顺序，只看内容。支持文本或 JSON 格式输出。anchor 展开 YAML 的锚点和别名（& 和 *），输出完整 YAML。也支持反向：检测重复内容自动提取为锚点精简文件。

convert 在 YAML 和 JSON 之间互转。YAML 转时要正确处理日期、布尔、null、多行字符串等特殊类型。反向转换的结果要能重新作为正向转换的输入，且结果与原始数据一致。
validate 发现错误退出码 1，正确退出码 0，错误信息含行号。merge 同键类型不同时后者覆盖但 stderr 输出警告。convert 反向转换后要能再转回原始数据。多文档 YAML 某个文档出错不影响其他。diff 有差异退出码 1，一致退出码 0。
