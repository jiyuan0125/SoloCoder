老板说要搞配置管理数字化，第一步先把 XML 配置文件的处理工具做了，Go 实现。我们内部系统大量用 XML 做数据交换，XPath 查询和命名空间处理太繁琐了。

工具叫 xtool，urfave/cli v2 框架，五个子命令：query、transform、format、ns、validate。

query 用 XPath 1.0 从 XML 提取数据。输出匹配节点的路径、标签名、文本和属性。@attr 语法提取属性值。支持命名空间前缀的 XPath 查询，通过命令行参数注册前缀和 URI 映射。结果可以输出纯文本、XML 片段或 JSON。支持多个 XPath 同时查。超大 XML（超过内存）用流式解析，此时只支持简单路径查询。

transform 用 XSLT 样式表转换 XML。接收源文件和 XSLT 文件，输出转换结果，支持常用 XSLT 1.0 指令。失败时输出样式表中出错位置。

format 格式化 XML，可指定缩进字符和层级，也支持最小化（去除空白）。可以设置 XML 声明的编码版本，支持自动排序属性。

ns 管理命名空间：list 列出所有命名空间和 URI，prefix 批量改前缀，strip 移除所有命名空间（可能破坏结构所以要谨慎），add 给元素添加默认命名空间。

validate 用 DTD 或 XSD 验证 XML，输出不符合规范的元素列表。
DTD 实体引用要正确解析，但默认禁止加载外部实体（XXE 防护）。CDATA 段原样保留。支持 UTF-8 和 GBK 编码。自闭合和显式闭合标签统一处理。query 的 XPath 语法错退出码 1，结果为空退出码 0。transform 的 XSLT 语法错退出码 2。ns strip 要 --force 才执行。超大文件流式解析内存不超 200MB。validate 通过退出码 0，不通过退出码 1 并列出问题元素。
