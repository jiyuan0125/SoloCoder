帮我用 Go 写一个命令行工具来读写 INI 配置文件。我们团队很多老项目还在用 INI 格式做配置，但 Go 标准库没有 INI 解析器，每次都得手动处理字符串很烦。工具需要支持以下几个子命令：read 读取指定节和键的值，write 写入或更新某个节下的键值对，delete 删除某个节或某个键，sections 列出所有节名，keys 列出某个节下的所有键。INI 文件格式方面，节名用方括号包裹比如 [database]，键值对用等号连接比如 host=localhost。要考虑 INI 文件里经常有以分号或井号开头的注释行，这些在读写的时候要保留不能丢掉。有些键值对里等号右边可能包含空格，比如 path = /usr/local/bin，写入的时候值两边的空格要处理好，读取返回的时候要不要 trim 看情况。还有一个比较特殊的需求，有些 INI 文件会在节名后面加注释，比如 [server] ; 这是服务器配置，解析的时候要把节名和注释分开。工具的输入输出全部走命令行参数和标准输出，不要任何交互式界面。read 命令如果找不到对应的键就输出空字符串并设置退出码为 1。write 命令如果节不存在就自动创建，文件末尾要保留一个换行符。处理中文键值对的时候编码统一用 UTF-8，不要做任何转码。最后加一个 format 子命令，能把一个格式混乱的 INI 文件重新格式化输出到标准输出，节名按字母排序，每个节内的键也按字母排序，注释跟在它原来所在节的前面。
INI文件中同一个节下如果出现重复的键名，后面的值覆盖前面的，format时只保留最终值。
