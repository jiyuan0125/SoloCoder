调研了一圈 Go 做 INI 解析的方案，要么功能不够要么引入太多依赖，不如自己写一个。工具用 Go 实现，子命令：read 读指定节和键的值，write 写入或更新键值对（节不存在自动创建），delete 删节或键，sections 列所有节名，keys 列某个节下所有键。

INI 格式方面，节名用方括号比如 [database]，键值用等号。注释行（分号或井号开头）读写时要保留，不能丢。等号右边的值可能有前后空格比如 path = /usr/local/bin，读取时 trim 看情况，写入时处理好。节名后面可能跟注释比如 [server] ; 这是服务器配置，解析时要把节名和注释分开。

加个 format 子命令，把格式混乱的 INI 文件重新格式化输出：节名和键都按字母排序，注释保留在原位置。
read 找不到键输出空字符串退出码 1。write 文件不存在自动创建，节不存在自动创建，末尾保留换行。同节下重复键名后者覆盖前者，format 只保留最终值。编码不是 UTF-8 时报错退出码 2 不做转码。
