帮我用 Go 写一个 TOML 配置文件处理工具，纯命令行操作。现在微服务配置大量使用 TOML 格式，但线上出问题时需要快速查看和修改某个字段，每次都得打开文件找半天。工具要支持 parse 子命令，解析 TOML 文件并按层级路径查询某个值，路径用点号分隔比如 server.port 或者 database.slaves.0.host，数组元素用数字索引。get 子命令输出原始值的字符串表示，如果是整数就输出整数，字符串就输出字符串，布尔值输出 true 或 false，不要额外加引号。set 子命令修改指定路径的值并写回文件，值从命令行参数传入，工具要自动推断类型，输入 123 就是整数，输入 true 就是布尔值，输入带引号的才是字符串。merge 子命令把两个 TOML 文件合并，如果两个文件有相同的键，第二个文件的值覆盖第一个，但如果值都是数组就做拼接而不是覆盖。validate 子命令检查 TOML 文件语法是否正确，如果有语法错误输出具体的行号和错误原因。TOML 语法里有些细节要考虑：字符串可以用双引号也可以用单引号，双引号字符串支持转义而单引号不支持。日期时间类型要能正确解析。内联表和数组表这两种写法要都能处理。多行字符串用三引号包裹的情况也不能忽略。工具只操作文件，不做任何网络请求。如果文件被其他进程锁定无法写入，输出错误信息并设置退出码为 2。keys 子命令列出某个路径下所有的子键名，比如 keys server 输出 port、host 等字段名。这个功能在不确定配置结构的时候很有用，可以逐层探索 TOML 文件的内容。type 子命令显示指定路径的值的类型，输出 string、integer、float、boolean、array、table 等类型名，方便确认某个字段的实际类型。copy 子命令从一个 TOML 文件中提取指定路径的子树，写入到一个新文件中。比如只把 database 相关的配置提取出来生成一个独立的文件。处理文件路径时如果文件不存在就报错退出。
