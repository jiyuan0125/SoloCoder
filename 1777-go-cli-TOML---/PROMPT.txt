运维那边提了个需求，要一套 TOML 配置快速查看和修改的工具，在线上排查问题的时候每次 vim 打开找半天太耽误事。Go 命令行实现，纯文件操作不联网。

parse 子命令解析 TOML 并按层级路径查值，路径用点号比如 server.port，数组用数字索引。get 输出原始值的字符串表示，整数就输出整数、字符串就字符串、布尔就 true/false，不加引号。set 修改指定路径的值写回文件，值从命令行传入，自动推断类型：123 是整数，true 是布尔，带引号才是字符串。merge 合并两个 TOML 文件，同键后者覆盖，但值都是数组时做拼接不覆盖。validate 检查语法，有错误输出行号和原因。

TOML 有些语法细节：双引号字符串支持转义，单引号不支持。日期时间类型要正确解析。内联表和数组表都要能处理。三引号多行字符串也不能漏。

keys 子命令列某个路径下所有子键名，比如 keys server 输出 port、host。不确定结构时可以逐层探索。type 子命令显示指定路径值的类型（string/integer/float/boolean/array/table）。copy 子命令从 TOML 提取指定路径的子树写入新文件。
set 修改嵌套表时中间路径不存在自动创建。get 路径不存在退出码 1。validate 语法正确退出码 0，有错误退出码 1 并输出行号原因。merge 同键值都是数组时做拼接不覆盖。文件被锁定无法写入退出码 2。
