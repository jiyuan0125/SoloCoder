之前用过 Python 的 python-dotenv 做 .env 管理，这次换 Go 试试。我们项目部署到不同环境，每个环境一套 .env 文件，需要一个命令行工具统一管理。Go 实现。

load 子命令读取 .env 文件把键值对加载到环境变量然后执行后面的命令，比如 envtool load dev.env -- go run main.go。.env 格式跟 docker compose 一样：每行一个键值对等号分隔，井号写行尾注释，空行跳过。值可以双引号包裹也支持转义字符，没引号时从等号后第一个非空字符到行尾（去掉注释）都是值。

expand 子命令读 .env 做变量展开再输出，支持 ${VAR_NAME} 和 $VAR_NAME 格式。循环引用（A 引用 B，B 又引用 A）要检测出来报错，不能死循环。

diff 子命令对比两个 .env 差异：哪些变量只在第一个有、只在第二个有、值不同。输出要清晰，左右文件名，不同值用箭头标。

export 子命令把 .env 转成 shell 的 export 语句输出，方便 source。支持相对路径和绝对路径，文件不存在报错退出。
load 时 .env 不存在退出码 1，格式有误（缺等号）退出码 2。expand 引用的变量未定义就保留原引用格式不替换，循环引用退出码 3。diff 完全一致退出码 0，有差异退出码 1。export 不带分号兼容 bash 和 zsh。值含特殊字符时输出要正确转义。
