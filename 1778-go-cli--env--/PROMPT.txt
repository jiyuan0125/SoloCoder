帮我用 Go 写一个环境变量管理命令行工具。我们项目部署到不同环境（开发、测试、预发布、生产），每个环境有一套不同的 .env 文件。工具需要支持 load 子命令，读取指定 .env 文件并将其中的键值对加载到当前进程的环境变量中，然后执行后面的命令。比如 envtool load dev.env -- go run main.go，这样 main.go 里用 os.Getenv 就能拿到 dev.env 里定义的值。.env 文件的格式跟 docker compose 的一样：每行一个键值对，用等号分隔，支持用井号写行尾注释，空行跳过。值可以用双引号包裹也可以不包裹，双引号包裹时支持常见的转义字符。如果值里包含空格但没加引号，从等号后面第一个非空字符开始到行尾（去掉行尾注释）都是值。还有一个 expand 子命令，读取 .env 文件后做变量展开再输出。变量展开是指值里面可以引用其他变量，用 ${VAR_NAME} 或者 $VAR_NAME 的格式。展开时要处理循环引用的情况，如果 A 引用 B，B 又引用 A，直接报错不要死循环。另外加一个 diff 子命令，对比两个 .env 文件的差异，输出哪些变量只在第一个文件有、哪些只在第二个文件有、哪些值不同。diff 的输出格式要清晰，左边文件名右边文件名，不同的值用箭头标出来。最后一个 export 子命令，把 .env 文件转成 shell 的 export 语句输出，方便 source 进来用。处理 .env 文件路径的时候支持相对路径和绝对路径，如果文件不存在就报错退出。
展开变量时如果引用的变量在文件中未定义，保留原始的变量引用格式不做替换。
分析完成后自动生成摘要，摘要生成也要读中间数据。中间数据和结果存在同一个文件里。
流程：验证-备份-部署-验证部署-完成。部署失败自动回滚。回滚后也要验证。
子命令：tool cmd subcmd [flags]。cmd有add/list/show/export，export有csv/json/pdf子格式。
服务端端口通过命令行参数或环境变量指定。
