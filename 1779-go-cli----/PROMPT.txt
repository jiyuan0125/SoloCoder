看到 etcd 和 consul 做配置中心觉得太重了，我们场景很简单——多环境 JSON 配置文件 + 敏感字段加密就够。Go 命令行实现。

init 子命令在指定目录初始化配置仓库，创建 environments 子目录（dev.json、staging.json、prod.json）和 templates 子目录。templates 里的文件用 Go template 语法，渲染时从环境配置取值填充。render 根据指定环境渲染模板，比如 render --env prod --template app.yaml.tmpl --output app.yaml。set 直接修改某环境的配置项，路径支持点号分隔。

encrypt 对敏感字段加密，AES-256-GCM 算法，密钥从环境变量 CONFIG_KEY 读取。加密后值以 ENC(密文) 格式存 JSON 中，读取自动解密。decrypt 批量解密。switch 切换激活环境，创建 .current-env 软链接。validate 检查配置完整性，对照模板变量看环境配置有没有缺的。模板支持 if 和 range。
render 模板引用变量在环境配置不存在时输出空字符串不中断。validate 缺变量退出码 1 列出缺失变量名，全满足退出码 0。set 修改时先写临时文件再 rename 防断电损坏。encrypt 密钥未设退出码 2 不用空密钥。switch 目标环境配置不存在退出码 1。
