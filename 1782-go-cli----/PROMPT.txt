帮我用 Go 写一个密码生成和强度评估的命令行工具。安全团队要求所有系统账号的密码必须满足一定强度要求，但目前没有好用的工具来生成和验证密码。gen 子命令生成随机密码，通过以下参数控制密码规则：--length 指定长度默认 16，--lower 是否包含小写字母默认包含，--upper 是否包含大写字母默认包含，--digit 是否包含数字默认包含，--symbol 是否包含特殊字符默认包含，--exclude 排除指定的字符集比如排除容易混淆的 0Oo1lI。生成的密码要保证至少包含每种启用类型的一个字符，如果长度不够就报错。batch 子命令批量生成密码，指定数量输出到标准输出，每行一个，前面带序号。entropy 子命令计算给定密码的信息熵。信息熵的计算方式是先统计密码中每种字符类型的使用情况，算出字符空间大小，再用 log2(字符空间^长度) 得到熵值。同时输出密码的强度评级：低于 40 bit 为弱，40 到 60 为中等，60 到 80 为强，80 以上为非常强。estimate 子命令估算暴力破解给定密码需要的时间。假设攻击者每秒尝试 10 亿次，根据密码的字符空间和长度计算总组合数除以每秒尝试次数得到时间，输出人类可读的格式（秒、分钟、小时、天、年）。policy 子命令定义密码策略并验证密码是否符合策略。策略包含最小长度、是否要求包含各类字符、是否禁止连续重复字符、是否禁止常见弱密码（内置一个常见弱密码列表比如 123456、password、qwerty 等几百个）。策略可以从 JSON 文件加载。validate 子命令验证给定密码是否符合策略，输出详细的检查结果：哪些规则通过了、哪些没通过。所有密码在命令行中通过参数传入，不要从标准输入读取，避免被 shell 历史记录泄漏的安全风险。生成密码的时候使用 crypto/rand 不要用 math/rand。
gen 子命令如果启用类型数乘以最小长度大于总长度（比如只要求大写和数字但长度只有 1），报错退出码 1。entropy 子命令空字符串退出码 0 输出熵值为 0。policy 子命令策略文件 JSON 格式错误退出码 2。validate 子命令密码不符合策略退出码 1，符合退出码 0。所有密码生成使用 crypto/rand 不用 math/rand，这是安全要求。batch 生成的密码之间不能有重复。
