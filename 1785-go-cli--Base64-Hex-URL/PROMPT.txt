帮我用 Go 写一个编码转换命令行工具，日常开发中经常需要在各种编码格式之间转换数据，目前用的是 Python 的一行脚本，但启动太慢。encode 子命令做编码操作，通过 --type 参数指定编码类型。base64 对输入数据进行 Base64 编码，支持标准 Base64 和 URL 安全 Base64（加 --url-safe 参数），默认标准模式。hex 对输入数据进行十六进制编码，输出大写还是小写通过 --upper 参数控制。url 对字符串进行 URL 编码，空格编码为 %20 而不是加号（遵循 RFC 3986），加 --query 参数后空格编码为加号（遵循 application/x-www-form-urlencoded）。decode 子命令做对应的解码操作，自动检测输入格式：如果输入只包含 Base64 字符集就尝试 Base64 解码，如果只包含十六进制字符且长度为偶数就尝试 Hex 解码。也可以通过 --type 参数强制指定解码类型。解码失败时输出明确的错误信息，比如 Base64 字符串长度不是 4 的倍数、非法的十六进制字符、URL 编码中的百分比后面不是合法的十六进制数。pipe 子命令从标准输入读取数据，编码后输出到标准输出，方便在管道中使用。file 子命令对文件进行编码或解码，通过 --input 和 --output 指定文件路径，如果不指定 --output 就输出到标准输出。对文件做 Base64 编码时按 76 个字符一行换行，这是 MIME 标准的要求。compare 子命令比较两个编码后的字符串是否等价，比如标准 Base64 和 URL 安全 Base64 编码同一份数据，去掉填充后应该相等。raw 子命令直接操作字节数据，不做任何编码转换，只是把输入的字节以十进制、十六进制、八进制和二进制四种格式同时输出，方便调试二进制协议。
