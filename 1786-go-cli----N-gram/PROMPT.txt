帮我用 Go 写一个文本统计分析命令行工具。内容团队需要分析稿件质量，运营需要分析用户评论，目前靠手工统计太慢。char 子命令统计字符数，分别输出总字符数、不含空格的字符数、中文字符数、英文字符数、数字字符数、标点符号数。区分中英文的方式是看 Unicode 码点范围，CJK 统一汉字区间内的算中文字符。word 子命令统计词数，英文按空格和标点分词，中文因为没有天然的词边界所以按字符数统计（去掉空格后的字符数就是中文词数的近似值），输出时分别显示英文词数和中文词数。line 子命令统计行数，区分总行数、非空行数、空行数。freq 子命令统计字频和词频。字频是统计每个字符出现的次数，按频率从高到低排序输出。词频是统计每个词出现的次数，英文词统一转小写后统计，输出前 N 个高频词（通过 --top 参数指定，默认 20）。支持从文件或标准输入读取文本。ngram 子命令统计 N-gram 频率，通过 --n 参数指定 gram 的长度，默认 2（bigram）。对于中文文本，N-gram 就是连续 N 个字符的序列。对于英文文本，N-gram 是连续 N 个词的序列。输出频率最高的前 N 个 N-gram 及其次数。readable 子命令评估文本的可读性，基于字符数、词数和句数计算几个常见指标：平均句子长度、平均词长、中文字符占比。这些指标可以帮助编辑判断文章是否过于晦涩。file 子命令支持批量分析多个文件，输出一个汇总表格，每行一个文件，列包括文件名、字符数、词数、行数。所有输出默认纯文本格式，加 --json 参数可以输出 JSON 格式方便程序处理。统计数字的时候用整数不要用浮点数（除了可读性指标）。
freq 子命令空输入（零字符）退出码 0 输出空结果不报错。ngram 的 N 值大于文本长度时退出码 0 输出空结果，N 值为 0 或负数退出码 1 报错。file 批量分析多个文件时某个文件读取出错不影响其他文件，最后汇总时标注失败文件。大文件统计时内存占用不超过 100MB，超过自动切换为流式统计模式。char 子命令统计中文字符时 CJK 扩展 B 区及之后的生僻字也要算在内，不能只统计基本区。
