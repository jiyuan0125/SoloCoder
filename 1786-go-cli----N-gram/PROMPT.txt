群里有人说缺一个好用的中文文本统计工具，我寻思 Go 能搞，就动手了。内容团队要分析稿件质量，运营要分析用户评论，手工统计太慢。

char 子命令统计字符：总数、不含空格数、中文数、英文数、数字数、标点数。中文按 Unicode CJK 码点范围判断。word 统计词数：英文按空格标点分词，中文按字符数近似。line 统计行数：总行、非空行、空行。freq 统计字频词频，按频率降序，词频支持 --top 指定前 N 个默认 20，英文词统一小写。ngram 统计 N-gram 频率，--n 指定长度默认 2，中文是连续 N 字符，英文是连续 N 词。

readable 评估文本可读性：平均句长、平均词长、中文字符占比。file 批量分析多文件，输出汇总表格（文件名/字符数/词数/行数）。所有子命令加 --json 输出 JSON 格式。统计用整数不用浮点（可读性指标除外）。
freq 空输入退出码 0 输出空结果。ngram 的 N 大于文本长度退出码 0 输出空，N 为 0 或负数退出码 1。file 批量分析某文件出错不影响其他，最后标注失败文件。大文件内存不超 100MB 超过自动流式。char 统计中文时 CJK 扩展 B 区及之后生僻字也要算。
