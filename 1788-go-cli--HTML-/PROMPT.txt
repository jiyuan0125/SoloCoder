帮我用 Go 写一个文本抽取和结构化命令行工具。我们从各种来源拿到大量半结构化文本数据，需要快速提取其中的关键信息。extract 子命令从 HTML 文本中去除所有标签，只保留纯文本内容。去除标签时要处理几种特殊情况：script 和 style 标签内的内容直接丢弃不要提取，HTML 实体（比如 &amp; &lt; &nbsp;）要转换为对应的字符，连续的空白字符（空格、制表符、换行）合并为一个空格。strip 子命令去除文本中的多余空白，包括行首行尾的空白、连续多个空行压缩为一个空行、全角空格和半角空格统一为半角空格。table 子命令从文本中提取表格数据。支持两种输入格式：用竖线分隔的 Markdown 表格，和用制表符分隔的文本表格。解析后输出 JSON 数组，每个元素是一个对象，键是表头列名，值是对应单元格的内容。如果输入没有表头行，用 column_1、column_2 这样的默认列名。kv 子命令从文本中提取键值对。识别几种常见的键值对格式：key=value、key:value、key -> value。提取后输出 JSON 对象。如果同一个键出现多次，值合并为数组。pattern 子命令用自定义模式从文本中提取数据。模式用正则表达式定义，通过 --pattern 参数传入，支持命名捕获组。提取结果以 JSON 格式输出，键是捕获组名，值是匹配的内容。如果有多处匹配，输出数组。email 子命令从文本中提取所有邮箱地址，phone 子命令提取所有手机号，url 子命令提取所有 URL 链接。这三个子命令内置对应的正则表达式，不需要用户自己写。提取的手机号要过滤掉明显不是手机号的数字串（比如 10 位或 13 位的纯数字）。所有子命令都支持从文件读取（--file 参数）或从标准输入读取。输出默认是纯文本，加 --json 输出 JSON 格式。
extract 子命令输入不是有效的 HTML（比如纯文本）时不报错正常处理，把输入当作纯文本输出。table 子命令表格行数超过 10000 时分批输出到 JSON 文件，不在内存里一次性构建。kv 子命令同一个键出现多次时值合并为数组不丢数据。email 和 phone 子命令在文本中没找到任何匹配时退出码 0 输出空数组。所有子命令输出 JSON 时确保是合法 JSON，特殊字符正确转义。
