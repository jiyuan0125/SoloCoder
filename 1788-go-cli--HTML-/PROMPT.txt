最近在搞数据清洗，从各种来源拿到大量半结构化文本，需要快速提取关键信息。Go 命令行实现。

extract 从 HTML 去除标签只留纯文本。script 和 style 标签内容直接丢弃，HTML 实体（&amp; &lt; &nbsp;）转字符，连续空白合并为一个空格。strip 去多余空白：行首尾空白、多空行压一个、全角半角统一。table 从文本提取表格数据，支持 Markdown 竖线分隔和制表符分隔，输出 JSON 数组，没有表头用 column_1 默认列名。kv 提取键值对，识别 key=value、key:value、key -> value 格式，同一键多次出现值合并为数组。

pattern 用自定义正则提取数据，支持命名捕获组，结果 JSON 输出。email 提取所有邮箱，phone 提取手机号（过滤明显不是手机号的数字串），url 提取 URL 链接。这三个内置正则不需要用户写。

所有子命令支持 --file 从文件读或标准输入，默认纯文本输出，--json 输出 JSON。
extract 输入不是有效 HTML 时不报错当纯文本处理。table 超过 10000 行分批输出到 JSON 不一次构建。kv 同键多次值合并为数组不丢数据。email 和 phone 没匹配退出码 0 输出空数组。JSON 输出特殊字符正确转义。
