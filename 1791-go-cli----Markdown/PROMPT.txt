之前用 Python 的 textwrap 模块处理中文文本截断和换行，这次换 Go 写一个更完整的字符串处理工具集，专门处理中文场景。

truncate 截断字符串到指定字符数（不是字节数），超出用省略号替代。省略号算在长度内（限制 10 字符实际显示 8 字符加省略号）。--word 按词边界截断不把词从中间断开。ellipsis 末尾加省略号，支持中文（……）和英文（...）模式，已经以省略号结尾就不再加。escape 做 Markdown 转义，特殊字符前加反斜杠。unescape 反向操作，连续两个反斜杠表示一个字面反斜杠要区分好。

pad 做字符串填充，左/右/居中对齐，填充字符默认空格，宽度按字符数不是字节数。wrap 按指定宽度自动换行默认 80 字符，优先在空格断行，没有空格就强制断行，中文不在字符中间断开。indent 每行加缩进（空格或制表符）。dedent 去公共前导缩进。case 做大小写和命名转换：upper/lower/title/snake/camel。repeat 重复字符串。reverse 反转字符串。

所有子命令支持从文件读取和标准输入。
truncate 长度 0 输出空字符串退出码 0，负数退出码 1。escape 再 unescape 要和原始一致。pad 宽度小于原字符串不截断原样输出。wrap 中文在宽度边界不在字符中间断。case 的 snake/camel 连续大写字母（如 XMLParser）要正确处理。
