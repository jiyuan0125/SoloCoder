帮我用 Go 写一个字符串处理命令行工具集，专门处理中文场景下的各种字符串操作需求。truncate 子命令截断字符串到指定长度。通过 --length 参数指定最大字符数（不是字节数），超出部分用省略号替代。省略号算在长度限制内，也就是说如果限制 10 个字符，实际显示的是 8 个原文字符加 2 个省略号字符（……）。加 --word 参数时按词边界截断，不会把一个词从中间截断。ellipsis 子命令在字符串末尾添加省略号，支持中文省略号（……）和英文省略号（...），默认中文。如果原字符串已经以省略号结尾就不再添加。escape 子命令对文本做 Markdown 转义，把 Markdown 的特殊字符（#、*、_、`、[、]、(、)、!、|、>、-、+、.）前面加反斜杠。比如 输入 # 标题 输出 \# 标题。unescape 子命令做反向操作，去掉转义的反斜杠。unescape 时要考虑区分反斜杠是转义符还是内容本身（连续两个反斜杠表示一个字面反斜杠）。pad 子命令对字符串做填充，支持左填充、右填充和居中填充，通过 --align 参数指定。填充字符默认空格，可以通过 --fill 指定其他字符。宽度按字符数计算不是字节数。wrap 子命令按指定宽度对文本做自动换行，默认宽度 80 个字符。换行时优先在空格处断行，如果没有空格就在宽度处强制断行。indent 子命令给文本每行前面加缩进，通过 --spaces 参数指定空格数默认 4，加 --tab 用制表符缩进。dedent 子命令去掉文本的公共前导缩进，类似 Python 的 textwrap.dedent，先找到所有非空行的最小公共缩进，然后统一去掉。case 子命令做大小写转换，支持 upper（全部大写）、lower（全部小写）、title（每个词首字母大写）、snake（大驼峰转下划线命名）、camel（下划线命名转大驼峰）。repeat 子命令重复字符串指定次数。reverse 子命令反转字符串。所有子命令支持从文件读取和标准输入，输出到标准输出。
