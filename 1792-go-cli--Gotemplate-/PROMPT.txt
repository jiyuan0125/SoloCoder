帮我用 Go 写一个模板渲染命令行工具，基于 Go 标准库的 text/template 和 html/template，但提供更方便的命令行接口。render 子命令渲染模板文件，通过 --data 参数传入 JSON 或 YAML 格式的数据文件。模板文件用 Go template 语法，支持 if/else、range、with、define、block 等标准动作，也支持管道操作和自定义函数。内置几个常用函数：upper 把字符串转大写，lower 转小写，trim 去首尾空白，replace 替换字符串，now 获取当前时间，format 格式化时间（接收 Go 的时间格式字符串），env 读取环境变量，default 如果值为空就使用默认值。用户可以通过 --func 参数注册额外的模板函数，格式为 name=body，body 是一段 Go 表达式。validate 子命令只检查模板语法是否正确，不做实际渲染。输出检查结果：如果语法正确输出 OK，如果有错误输出具体的行号和错误描述。extract 子命令从模板文件中提取所有使用的变量名，方便确认数据文件是否提供了所有需要的字段。变量名包括 {{.FieldName}} 中的 FieldName、range 遍历中的变量名、define 定义的模板名等。output 子命令指定渲染结果的输出格式。默认输出纯文本，加 --html 参数时用 html/template 渲染并自动转义 HTML 特殊字符。加 --json 参数时输出 JSON 格式。pipe 子命令从标准输入读取模板和数据（用 --- 分隔，上面是模板下面是 JSON 数据），渲染结果输出到标准输出。这个模式方便在 shell 管道中使用。watch 子命令监听模板文件和数据文件的变更，任一文件变化后自动重新渲染并输出到指定文件。目录模板功能：如果指定的模板路径是一个目录，遍历目录下所有文件（保持子目录结构），对每个文件做渲染，输出到对应的目录结构中。跳过二进制文件和隐藏文件（以点号开头的文件）。
