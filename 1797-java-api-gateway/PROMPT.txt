Spring Boot 做 API 网关。路由规则存内存，支持路径前缀匹配和权重路由。前缀匹配走最长前缀原则——/api/v1/user 比 /api/v1 优先级高。之前直接用 Nginx 配，改一次路由要 reload 还影响长连接。

请求经过过滤器链执行：认证过滤→权限过滤→限流过滤→转发。每个过滤器返回 PASS 或 REJECT，REJECT 直接短路返回错误响应，后续过滤器不再执行。过滤器链可以动态组装，增删过滤器不需要重启。

不同路由可以配不同的过滤器链。比如 /api/public/* 不需要认证过滤器，走空的认证链直接到转发。/api/admin/* 全链路：认证+权限+限流+转发。路由和过滤器的绑定关系通过管理接口配置，变更即时生效。

管理接口增删路由规则和过滤器配置。路由规则包含：路径前缀、目标后端列表、权重分配、绑定的过滤器链 ID。变更即时生效——新请求走新规则，进行中的请求不受影响。

转发失败（后端不可达）返回 502 附带后端地址和错误原因。转发超时（默认 10 秒）返回 504。这些错误响应格式统一为 JSON：{"error": "code", "message": "描述"}，方便上游统一处理。

端口用 server.port 配置，Maven 构建。
