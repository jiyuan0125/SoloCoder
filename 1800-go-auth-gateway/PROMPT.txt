前后端分离后所有接口都得过一道认证，之前没有统一入口，每个服务自己校验 Token，改一次认证逻辑要改五个服务。Go net/http 写个认证网关，统一管这事。

同时支持 JWT 和 API Key。JWT 校验签名和过期时间，密钥从环境变量 JWT_SECRET 读取，启动时没有设置就报错退出。过期 Token 返回 401 附带"Token 已过期"提示。签名校验失败返回 401 附带"签名无效"。API Key 存内存 map，每个 key 绑一组路径前缀作为权限范围——请求路径必须命中绑定前缀才放行，否则返回 403。

Token 刷新有讲究。过期前 5 分钟允许用旧换新，但同一个 Token 1 分钟内只能刷新一次。这个频率限制防的是刷新风暴——客户端在 Token 快过期时多个请求同时触发刷新，打满认证服务。刷新后旧 Token 立即失效，加入黑名单。

接口包括：登录拿 JWT（POST /auth/login，用户名密码错误返回 401 不提示具体原因）、刷新 Token（POST /auth/refresh）、增删查 API Key（CRUD /api-keys）。查 API Key 列表支持分页，默认每页 20 条。

PORT 环境变量指定端口，go build 能过。
