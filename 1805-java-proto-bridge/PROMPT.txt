老系统用的自定义二进制协议，新前端只认 JSON，中间缺个翻译层。Spring Boot 写个协议转换网关：HTTP JSON 进来，转换成二进制发给老系统；老系统返回的二进制，解析成 JSON 返回给前端。

二进制格式用 ByteBuffer 拼装：magic(2B) + version(1B) + type(1B) + length(4B) + payload。magic 是固定值 0xABCD，version 当前为 1。字段按固定偏移写入，解析时先读 magic 校验协议头——不匹配直接返回 400 附带"协议头校验失败"。version 不匹配返回 400 附带"不支持的协议版本"。length 与实际 payload 长度不一致返回 400 附带"长度不匹配"。

转换规则按接口路径配置。比如 POST /api/orders 对应 type=0x01 的二进制请求，JSON 字段映射到 payload 的固定位置。映射关系通过管理接口配置，不需要改代码。

管理接口可以增删转换规则和查看转换日志。转换日志记录每次转换的方向（JSON→Binary 或 Binary→JSON）、接口路径、耗时、是否成功。失败的记录包含错误原因。日志保留最近 1000 条，满了淘汰最旧的。

端口用 server.port 配置，Maven 构建。
