隔壁部门做了个 DevOps 平台，我们需要对接 Git 仓库状态监控，顺便把巡检工具也做了。Go 写个 gitpolice，cobra 框架。

YAML 配置文件定义所有要监控的仓库列表，每个仓库配置名称、本地路径或远程 URL、分支、告警阈值。

巡检内容：有没有未提交修改（git status 不干净）、是否落后远程分支（git fetch 后比较）、过期分支（超过 N 天没新提交）、磁盘占用超阈值、大文件被提交（超 10MB）。本地路径不存在或不是 Git 仓库标记"不可达"继续其余。

结果输出汇总报告：正常绿色 OK，有问题的红色告警加描述。末尾统计摘要。有问题仓库退出码 3，全正常退出码 0。--watch 持续监控模式（默认 5 分钟一次），只在状态变化时输出告警避免重复报告。

--notify 告警通知输出到文件（每条一行 JSON，含时间戳/仓库名/问题类型/描述）。并发检查多个仓库用 goroutine，--concurrency 控制默认 10，超时默认 30 秒可配置。bare 仓库自动跳过工作目录检查。SSH 连接失败直接报"无法连接"不阻塞其他。
