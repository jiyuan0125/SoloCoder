开源的 git-stats 功能太多但跨分支差异统计反而没做好，Go 从零写个 gitdiffstats。cobra 框架。

基本用法：gitdiffstats 分支A 分支B。自动执行 git diff 获取差异做统计。输出所有被修改文件按类型分类（Go 源码、配置、前端等），统计每种类型的文件数和代码行数变化。每个文件显示路径、新增/删除行数、修改类型（新增/修改/删除/重命名）。

差异分析：识别纯重构变更（函数重命名、文件移动内容没变）和功能性变更。纯重构特征是新增和删除行数几乎相等且总变化量大。大致分类就行。影响范围分析：根据修改文件推断影响模块。模块映射通过配置文件定义（目录前缀→模块名）。配置文件不存在不影响其他功能。新增依赖检查：对比两个分支的 go.mod。删除代码最多 top 10 文件方便确认。

--output 导出 HTML 格式报告，内嵌 CSS 简单样式，不用外部图表库。
差异可能非常大（长期 feature 分支 vs main），git diff 输出可能几十 MB。用流式处理不一次全加载。先用 --stat 获取摘要再按需获取具体差异。分支名和 commit hash、tag 都支持。两个分支无共同祖先用各自第一条提交做全量对比。
