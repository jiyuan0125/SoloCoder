Go net/http 缓存中间件，内存 KV 存储。TTL 过期加 LRU 淘汰双保险——TTL 到了自动过期，TTL 还没到但容量满了就淘汰最久没访问的。每个 key 独立设过期时间。

过期清理走两条路：惰性删除（访问时发现过期才清）和后台定时任务每分钟扫一批。两条路配合保证过期 key 不会长期占内存。主动删除（调用 delete 接口）的场景下，删完 key 后通知所有订阅该 key 的客户端。订阅关系存内存 map，key → 客户端回调列表。

set 接口设置缓存，必须带 TTL 参数（秒），设为 0 表示永不过期。value 可以是任意字符串，空字符串也合法。get 接口查缓存，miss 返回 404 不带 body。delete 接口删缓存，不存在也返回 204（幂等）。

统计接口暴露命中率（get 命中次数 / get 总次数）、当前 key 数、内存估算（所有 key+value 的字节总和）。容量上限通过配置设定，达到上限触发 LRU 淘汰，每次淘汰 10% 的旧 key。

接口路径：POST /cache/{key}（set）、GET /cache/{key}（get）、DELETE /cache/{key}（delete）、GET /cache/stats（统计）、POST /cache/{key}/subscribe（订阅 key 变更）。

PORT 环境变量指定端口，go build 能过就行。
