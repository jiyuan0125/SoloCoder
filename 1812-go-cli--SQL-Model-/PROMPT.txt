看到其他团队用 MyBatis Generator 自动生成样板代码挺方便的，我们也搞一个 Go 版的。codegen 根据数据库表结构自动生成 SQL 建表语句、Go Model 和基本 CRUD 接口代码。cobra 框架。

表定义用 YAML 格式：表名、中文名、字段列表（字段名/类型/主键/自增/可空/默认值/注释）。生成三层内容：SQL DDL（CREATE TABLE 含字段定义主键索引）、Go Model（结构体驼峰命名含 JSON tag 和数据库 tag）、CRUD 接口代码（基本增删改查函数签名和框架代码）。

合理的项目结构：输出目录已有代码时不覆盖，输出到 generated 子目录打印每个文件路径。generated 已有同名文件退出码 1 提示冲突。文件头部加注释说明自动生成请勿手动修改。

增量生成：表定义更新后重新运行只生成变更部分不覆盖用户已改的业务逻辑。实现方式是在生成代码中嵌入元数据标记记录表定义哈希值，下次比较哈希没变就跳过。

模板功能：--template-dir 指定自定义模板目录覆盖默认模板，用 text/template 语法。--mock 同时生成 Mock 测试代码。字段类型映射在表定义中明确指定 Go 类型不自动推断。索引名格式 idx_表名_字段名，同表多字段索引名不能重复。
