试了三个现成的 API diff 工具都不支持 OpenAPI 3.0 的 $ref 引用展开，只能 Go 自己写。apicheck 做 Swagger/OpenAPI 契约验证，cobra 框架。

基本用法：apicheck check old-api.yaml new-api.yaml，对比两个版本 API 定义找 breaking/non-breaking change。

Breaking change：删除接口路径、删除请求方法、修改路径、删除必填请求参数、必填改选填、删除响应字段、修改字段类型、修改格式约束、删除枚举值。Non-breaking：新增路径/方法/可选参数/响应字段、放宽约束、新增枚举。

输出先概要再详细：变更类型、位置（路径+字段）、描述、前后值。有 breaking 退出码 3，只有 non-breaking 退出码 0，完全相同退出码 0。--allow-breaking 白名单不报错。

apicheck lint api.yaml 验证定义文件规范性（接口描述、未定义引用、命名规范），有 problem 退出码 3。--markdown 输出 PR 友好的变更报告含摘要表格。
对比时 $ref 引用要先解析展开成完整结构。$ref 指向的文件不存在退出码 1。两个文件 OpenAPI 版本不同（一个 2.0 一个 3.0）先提示再尝试基本对比。
