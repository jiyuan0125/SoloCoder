看到 nmap 的 Go 封装库都觉得太重，安全团队只要一个轻量的内网资产扫描工具。Go 写个 portscan，cobra 框架。

基本用法：portscan --target 192.168.1.0/24 --ports 80,443,8080,3306,6379。支持单 IP、IP 范围（192.168.1.1-254）、CIDR 网段。端口支持逗号分隔、范围（80-1024）、预设（--preset web 扫 Web 相关端口）。

默认 TCP 全连接扫描。--syn 半开扫描需 root 没权限退出码 1。--udp 扫 UDP 超时判断关闭。并发用 worker pool 默认 100 连接，从队列取 IP+端口组合。结果显示 IP/端口/状态/服务名。--service-detect 协议探测判断具体版本。输出终端表格/--json/--csv/--output 文件。

超时默认 1 秒可调。--rate-limit 限制每秒探测数默认 100。--exclude 排除 IP，--only-open 只显示开放端口。进度条实时显示扫描 IP，发现开放端口即时显示。
扫描 Ctrl+C 中断输出已完成结果退出码 130。全部目标扫完有开放端口退出码 0，没有也退出码 0。
