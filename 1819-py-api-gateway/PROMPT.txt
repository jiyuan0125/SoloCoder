FastAPI 做 API 网关。路由表同时支持精确匹配和前缀匹配。匹配优先级规则：精确路由 > 最长前缀路由 > 默认路由。/api/v2/user 精确路由优先于 /api/v2 前缀路由，/api/v2 前缀路由优先于 /api 前缀路由。没有匹配到任何路由返回 404 附带可用路由列表。

认证层支持 API Key（通过 X-API-Key Header 传递）和 JWT（Authorization: Bearer {token}）两种方式。不同路由可以要求不同认证——/api/public/* 不需要认证，/api/admin/* 要求 JWT 且必须是 admin 角色，/api/partner/* 要求 API Key。路由和认证方式的绑定通过配置接口管理。

聚合接口 POST /aggregate 是个亮点功能。接收一组服务 URL，用 httpx 异步并行调用所有服务，等全部返回后合并成一个 JSON 返回。单个服务调用超时 5 秒，超时的在结果里标为 timeout 而不是整个请求失败。至少一个服务成功就返回合并结果，全部失败返回 504。

路由变更走接口操作——增删改路由规则，变更即时生效，新请求走新规则。全程 async，不阻塞请求处理。删除一个路由时如果还有请求在使用，等请求完成后再移除。

端口用 PORT 环境变量。
