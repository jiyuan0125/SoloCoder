群里有人说缺一个好用的 traceroute 工具，我寻思 Go 标准库就能搞，就动手了。做一个 traceroute 命令行工具，能探测从本机到目标主机经过的每一跳路由器。

核心功能有三个。traceroute 子命令向目标发送 UDP 探测包，TTL 从 1 逐步递增，每跳发 3 个探测包，收到 ICMP Time Exceeded 就记录那一跳的 IP 和往返延迟。asn 子命令查询每一跳 IP 的 ASN 归属信息，用内置的离线 IP 段数据库做查找。report 子命令把探测结果输出为 JSON 或表格，支持 --output 写入文件。

目标地址支持域名和 IP 两种输入，域名要自动解析。超时时间通过 --timeout 参数控制，默认 3 秒。最大跳数 --max-hops 默认 30。探测端口从 33434 开始递增。

域名解析失败时退出码返回 1 并提示具体域名和错误信息。目标地址格式不合法时退出码返回 1。最大跳数超过 64 时退出码返回 1 并提示合理范围。某一跳如果超时没响应，那一行输出 * * * 表示丢失，继续探测下一跳。如果到达目标主机收到了 ICMP Port Unreachable 就停止探测并标记最后一跳为"到达目标"。探测过程中目标主机完全不可达（连续 5 跳没响应），打印提示但继续探测直到 max-hops。UDP 探测包如果权限不够（需要 root 或 CAP_NET_RAW），退出码返回 1。asn 查询时数据库文件不存在则提示需要先导入数据，但 traceroute 本身不受影响。report 输出 JSON 时延迟字段保留小数点后 3 位，单位毫秒。多目标批量探测时某个目标失败不影响其余目标，最后汇总分别列出成功和失败的目标。端口被占用时退出码返回 1，不能静默换端口。
