之前 DNS 诊断靠 dig 和 nslookup 组合着用，输出格式不统一写脚本也不好解析。换个 Go 写的 DNS 诊断工具，集成查询和健康检查功能。

query 子命令向指定 DNS 服务器发送查询，支持 A、AAAA、CNAME、MX、NS、TXT、SOA、SRV 记录类型。默认查 A 记录。DNS 服务器可以通过 --server 参数指定，不指定则读取系统配置的默认 DNS。输出解析后的记录列表，JSON 或表格格式。域名格式不合法时退出码返回 1。

trace 子命令追踪域名解析过程，从根域名服务器开始逐级查询，展示每一级的授权服务器和返回的记录，类似 dig +trace 的效果。

health 子命令对指定域名做 DNS 健康检查：验证域名能正常解析、SOA 记录存在且序列号合理、NS 记录指向的服务器都能响应、MX 记录指向的邮件服务器可达（TCP 25 端口连接测试）。输出健康检查报告，有问题的项标记出来。

cache 子命令查询本地 DNS 缓存的状态（需要指定一个支持查询缓存的本地 DNS 服务，如 dnsmasq 或 CoreDNS）。刷新本地缓存时发送指定信号或 API 调用。

DNS 查询超时默认 5 秒，超时时退出码返回 1。trace 过程中某一级服务器无响应，标记超时并尝试下一级。查询结果中 TTL 值低于 300 秒的标记为"即将过期"作为提醒。DNSSEC 相关的记录（DNSKEY、RRSIG、DS）如果存在，在输出中标注该域名启用了 DNSSEC 验证。域名如果同时有 A 和 AAAA 记录，两个都展示。PTR 反向查询时 IP 格式不合法退出码返回 1。批量查询时某个域名失败不影响其余，汇总成功和失败数。DNS 服务器如果返回 SERVFAIL 或 REFUSED，退出码返回 2 并展示错误原因。
