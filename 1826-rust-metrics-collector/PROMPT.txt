axum 指标采集服务。三种指标类型各有各的用处——Counter 记请求总数只增不减，Gauge 记当前连接数可上可下，Summary 保留滑动窗口取最近 N 个值算统计量（最小值、最大值、平均值、P50、P90、P99）。

Summary 的滑动窗口大小可配置，默认 1000 个数据点。新数据进来旧的被挤掉。P50/P90/P99 的计算是近似算法，不需要对窗口内的数据做完整排序。窗口内数据量少于 10 个时不计算百分位，返回 insufficient data。

指标数据用 Arc<Mutex<HashMap>> 保护，读写都用同一把锁。查询接口返回全量快照——所有指标名、类型、当前值、标签。快照是某一时刻的完整状态，查询过程中不阻塞写入（或者用 RwLock 优化）。

指标带多维度标签。比如 HTTP 请求指标可以有 method 和 path 两个标签，相同指标名不同标签组合是不同的时间序列。上报时标签以 key=value 对的形式传递，key 为空返回 400。

上报接口 POST /metrics 接收批量数据，一次最多 200 个数据点。每个数据点包含指标名、类型、值、标签。指标名重复（同标签组合）时按类型做不同处理：Counter 累加、Gauge 覆盖、Summary 追加到窗口。

PORT 环境变量配端口，Cargo build 能编译通过。
