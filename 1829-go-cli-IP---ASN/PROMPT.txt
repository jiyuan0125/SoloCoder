市面上的 IP 查询工具要么太重要么只能在线用，我们只需要离线查 IP 归属和 ASN 信息，Go 自己写一个。

工具内置一份离线 IP 数据库（CIDR 区间+范围查找），查询 IPv4 地址的归属运营商（电信、联通、移动、教育网等）、地理位置（省份和城市）、ASN 编号和所属机构。IP 格式不合法时退出码 1 并打印具体哪里有问题。支持单 IP 查询和批量查询（从文件读取 IP 列表，文件不存在退出码 1）。

输出支持纯文本表格和 JSON 两种。保留地址（127.0.0.0/8 回环、10.0.0.0/8 私网、172.16.0.0/12 私网、192.168.0.0/16 私网、169.254.0.0/16 链路本地）查询时直接返回特殊标识。IPv6 暂不支持，输入 IPv6 退出码 1 提示当前仅支持 IPv4。

批量查询支持过滤：只显示某个省份、某个运营商或某个 ASN 下的 IP。还能做 IP 段归属统计，输入一个 CIDR 网段，统计网段内各运营商和地区的分布比例，CIDR 格式不合法退出码 1。批量查询结果保持输入顺序。批量中有格式错误的 IP 跳过并在汇总中列出跳过数量。

IP 数据库查找用区间树（CIDR 转 IP 范围区间），一个 IPv4 范围可能覆盖几万条 CIDR 记录。CIDR 解析时边界要处理好，192.168.1.0/24 的范围是 .0 到 .255，192.168.1.0/32 只是 .0 这一个地址。数据库查不到的 IP 标记为"未知归属"，退出码仍为 0。数据库文件不存在退出码 1 并提示需要先导入数据。
