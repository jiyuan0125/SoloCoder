Spring Boot API 网关。路由存内存，路径前缀匹配加权重路由。请求进来先过过滤器链，按顺序执行：认证→权限→限流→转发。链可以动态组装——每个过滤器返回 PASS 或 REJECT，REJECT 短路返回错误，后续过滤器不再执行。

不同路由配不同过滤器组合。/api/public/* 不走认证过滤器，直接到转发。/api/admin/* 全链路走完。/api/internal/* 跳过限流但保留认证和权限。路由和过滤器链的绑定关系通过管理接口配置。

路由规则和过滤器配置通过管理接口增删，变更即时生效。新请求走新规则，进行中的请求继续走旧规则，不会出现请求处理到一半规则变了的情况。

转发失败返回 502 附带后端地址和错误原因。转发超时（默认 10 秒）返回 504。认证失败返回 401，权限不足返回 403，限流触发返回 429。所有错误响应格式统一：{"error": "code", "message": "描述"}。

管理接口：路由规则 CRUD、过滤器链配置、查看当前所有路由和绑定的过滤器。还提供一个测试接口，给定一个请求路径，返回会匹配到哪条路由、经过哪些过滤器、转发到哪个后端——方便调试配置。

server.port 配端口，Maven 构建。
