子网计算和管理工具，Go 命令行实现。网络工程师做网络规划时要划分子网、判断 IP 归属网段、检查子网重叠，每次手算太慢。

子网划分：输入父网段和需要的子网数量（或每个子网需要的 hosts 数量），自动算出所有子网的网段地址、广播地址、可用 IP 范围和子网掩码。IP 格式或 CIDR 不合法退出码 1 并打印具体哪里有问题。IP 归属判断：输入 IP 地址和网段，判断 IP 是否在网段内。网段重叠检测：输入多个网段，找出哪些之间存在包含或重叠关系。网段合并：输入多个相邻网段，能合并成更大网段就自动合并。

输出用清晰的文本格式，网段用 CIDR 表示法，子网掩码同时显示点分十进制和 CIDR 后缀长度。重叠检测用简洁方式标注哪些网段对有重叠及重叠的地址范围。加 --json 输出 JSON。加 --csv 输出 CSV。

子网划分时如果每个子网 hosts 数不是 2 的幂次，向上取整到最近的 2 的幂次再减去网络地址和广播地址这两个保留地址，输出中说明实际可用主机数。网段合并不能看数字连续就合并，必须检查二进制对齐，比如 192.168.1.0/24 和 192.168.2.0/24 数字连续但不能合并，因为 /23 的边界在 192.168.0.0。IP 地址比较要转成 32 位无符号整数。/31 按 RFC 3021 是点对点链路没有网络地址和广播地址的概念，/32 就是单独的主机地址。输入子网数量超过父网段能划分的上限时退出码 1 并打印最大可划分数。
