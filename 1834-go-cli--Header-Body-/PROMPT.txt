闲着没事想做一个邮件文件解析工具自己用，Go 写。主要是运维这边经常要从 eml 格式的邮件文件里提取发件人、正文、附件等信息，批量处理几百封邮件做审计。

工具接收 eml 文件路径作为输入，文件不存在退出码 1。解析 MIME 格式邮件内容，输出各 header 字段（From、To、Cc、Subject、Date、Message-ID 等），解析正文（纯文本和 HTML 分别提取），列出所有附件的文件名、大小和 MIME 类型。支持把附件保存到指定目录，保存目录不存在自动创建，附件文件名冲突时默认覆盖但打印提示。

批量模式下扫描目录下所有 eml 文件，目录不存在退出码 1。提取指定字段以 CSV 或 JSON 输出，方便导入 Excel 或做进一步分析。支持按发件人、收件人、主题关键字、日期范围过滤。批量处理中某个 eml 解析失败不中断其余文件，失败的文件在汇总中列出文件名和错误原因。

MIME 解析的挑战：邮件可能有多层嵌套的 multipart 结构（multipart/mixed 里嵌套 multipart/alternative，alternative 里又有 text/plain 和 text/html），需要递归解析。Content-Transfer-Encoding 有 Base64、Quoted-Printable、7bit、8bit 几种，解码失败时保留原始内容标注"解码失败"。附件文件名编码规则复杂，RFC 2231 和 RFC 2047 两种都要处理，RFC 2231 被拆成多段的文件名要正确拼接还原。有些 header 字段会折行（空格或 tab 开头的续行），解析时要把续行拼回去。正文编码声明（charset=xxx）可能和实际编码不一致，解码后出现乱码要能检测并提示。全部解析完成退出码 0，部分失败退出码 2。
