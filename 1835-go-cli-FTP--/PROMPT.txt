季度末了，文件同步系统还在用系统自带的 ftp 命令，不支持断点续传也不支持批量，每次中断都得从头传。用 Go 写一个 FTP 客户端工具替代掉。

工具支持连接 FTP 服务器（明文 FTP 和 FTPS 即 FTP over TLS），登录后可以列出目录、上传、下载、创建目录、删除文件。服务器地址格式不合法退出码 1，连接或认证失败退出码 2。上传下载都支持断点续传：目标文件已存在且比源文件小，从已有大小处继续传输而不是重新开始。

批量操作是核心功能。上传模式指定本地目录递归扫描所有文件，按远程目录结构上传到 FTP 服务器。下载模式类似，指定远程目录递归下载到本地。两种模式都支持过滤规则，用通配符匹配文件名决定哪些传输哪些跳过。

目录镜像功能：对比本地和远程目录差异，只传输有变化的文件（通过文件大小和修改时间判断），类似 rsync 但基于 FTP 协议。

FTP 用两个 TCP 连接（控制和数据），数据连接有主动和被动模式，默认用被动模式但允许切换。文件列表解析没有标准格式，不同服务器返回格式不一样，需要兼容多种格式，解析失败跳过该条目并记录。断点续传要用 REST 命令指定起始位置，但不是所有服务器都支持，先发 REST 0 测试，不支持则每次从头传。FTPS 隐式和显式模式握手流程不同，两种都要支持。传输过程中超时重连，但不重复已成功的文件。断点续传时如果本地文件大小超过远程文件（说明远程被替换了），重新下载而不是继续追加。

每次传输记录日志（JSON Lines 格式），包含时间戳、路径、方向、字节数、结果。批量操作中部分失败不中断其余，最后汇总成功和失败数，有失败退出码 2，全部成功退出码 0。
