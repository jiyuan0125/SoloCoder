每个微服务自己管认证，路由规则散落在各处，后端地址硬编码满天飞——这谁受得了？Rust axum 做一个统一入口网关，把路由匹配、认证注入和请求转发收拢到一层。

路由两种匹配方式：精确匹配（/api/users）和前缀匹配（/api/orders/*）。同一个路由表里精确匹配优先于前缀匹配。路由可以动态添加和删除——POST /routes 添加，body 带路径、匹配类型、后端地址、认证策略。DELETE /routes/{id} 删除。删了后新请求就匹配不到了。

认证策略分两档：免认证（public）和 API Key 认证。API Key 的验证逻辑独立做成一个模块，key 存在内存里的注册表中。注册 key 用 POST /keys，返回 key 字符串。请求带 X-API-Key 头，网关查注册表验证。验证模块和路由模块分开，不要耦合在一起。

每笔请求都记追踪数据：TraceID（UUID v4）、后端服务名、响应状态码、耗时毫秒数。这些数据存内存。查询接口按 TraceID 精确查一条，也可以按服务名查该服务最近的所有请求。

后端不可用时返回 502。网关自己做健康检查，每 15 秒 GET 一次后端的 /health 端点，连续失败 3 次标记不可用，恢复了自动标记回来。

Cargo build，端口 PORT 环境变量。
