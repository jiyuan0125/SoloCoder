之前资产信息采集靠手动填表，数据量上来以后经常出错。用 Go 写一个系统硬件信息采集工具，直接输出结构化数据。

工具采集以下信息输出为 JSON。CPU 信息：型号名称、核心数、线程数、主频、缓存大小（L1/L2/L3）。内存信息：总物理内存、可用内存、Swap 大小和已用量。磁盘信息：每块磁盘的设备名、型号、大小、已用空间、文件系统类型、挂载点。网卡信息：每张网卡的名称、MAC 地址、IP 地址、速率、MTU。每次采集带时间戳。输出目录不存在自动创建。

支持多种输出格式：JSON（默认）、表格、简要摘要（只显示总内存、CPU 型号、磁盘总容量等一行搞定）。支持只采集某类信息，通过 --type 参数（cpu/memory/disk/network/all）。

采集逻辑全部通过读取 Linux 的 /proc 和 /sys 文件系统及 uname 等系统调用实现，不依赖外部命令。不在 Linux 上运行退出码 1。/proc/meminfo 中 MemAvailable 字段在老内核上可能不存在（3.14 之前），不存在时用 MemFree 加 Buffers 和 Cached 估算。磁盘信息要从 /proc/mounts 和 statfs 获取，但 proc、sysfs、tmpfs、cgroup、devpts 等特殊挂载点应跳过。CPU 信息在 /proc/cpuinfo 中每个核心会重复出现，要去重统计逻辑核心数和物理核心数（通过 core id 区分）。网卡信息除了物理网卡还可能有虚拟网卡（docker0、veth 开头），加 --all 参数显示全部，默认只显示物理网卡。数值用统一单位（内存 GB、磁盘 GB、频率 GHz），但原始值也保留在 JSON 里。采集失败（权限不足等）时失败字段标记为"获取失败"，不影响其他信息，退出码仍为 0。
