用Go写一个Docker容器和镜像管理命令行工具，用 cobra 做子命令架构。运维团队在管理几十台服务器上的Docker环境时，经常需要批量操作容器和镜像，但docker CLI的批量能力很弱，每次都要写shell脚本。

工具通过调用Docker Engine API（而不是包装docker命令）来实现。Docker daemon 不可用时退出码 1 并提示检查 Docker 是否运行。支持以下功能：列出所有容器及其状态、镜像、资源使用情况；按条件过滤容器（按状态running/stopped、按镜像名、按标签、按运行时长）；批量操作容器（启动、停止、重启、删除），支持用通配符匹配容器名，通配符不匹配任何容器时退出码 0 输出"无匹配容器"。

镜像管理功能：列出所有镜像按大小排序，找出没有被任何容器使用的悬空镜像，按条件清理镜像。支持统计每个镜像占用的磁盘空间，镜像的磁盘空间统计要用Docker的API获取真实的磁盘占用（考虑层共享）。

容器资源监控功能：实时显示指定容器的CPU使用率、内存使用量和限制、网络IO、磁盘IO。支持同时监控多个容器，用表格形式展示。数据采集频率默认每秒一次，不低于0.5秒避免给Docker daemon带来压力。

安全审计功能：检查容器是否有不安全的配置，比如以特权模式运行、挂载了宿主机敏感目录（/、/etc、/var/run/docker.sock等）、使用了latest标签的镜像、以root用户运行等。输出审计报告列出所有安全风险项，有风险项时退出码 3。

容器日志查看功能，类似docker logs但支持彩色输出和按时间范围过滤。

Docker API通过Unix Socket通信（默认/var/run/docker.sock），连接时要处理权限问题，权限不足时退出码 1。批量删除容器时要先停止运行中的容器再删除。批量删除容器时如果其中某个容器处于挂死状态（stop命令超时，默认10秒），用kill代替stop强制终止。
