之前管理 Docker 容器全靠手敲命令加 shell 脚本，几十台服务器管不过来。用 Go 写一个 Docker 容器和镜像管理工具，直接调 Docker Engine API 不包装 docker 命令。

工具支持以下功能。列出所有容器及其状态、镜像、资源使用情况。按条件过滤容器（按状态 running/stopped、按镜像名、按标签、按运行时长）。批量操作容器（启动、停止、重启、删除），支持通配符匹配容器名，通配符不匹配任何容器退出码 0 输出"无匹配容器"。

镜像管理：列出所有镜像按大小排序，找出没被任何容器使用的悬空镜像，按条件清理镜像。统计每个镜像的磁盘占用要用 Docker API 获取真实磁盘占用（考虑层共享）。

容器资源监控：实时显示指定容器的 CPU 使用率、内存使用量和限制、网络 IO、磁盘 IO。支持同时监控多个容器用表格展示。数据采集频率默认每秒一次，不低于 0.5 秒避免给 Docker daemon 带来压力。

安全审计：检查容器是否有不安全配置——特权模式运行、挂载了宿主机敏感目录（/、/etc、/var/run/docker.sock 等）、用了 latest 标签镜像、以 root 用户运行等。输出审计报告列出所有风险项，有风险项退出码 3。

容器日志查看类似 docker logs 但支持彩色输出和按时间范围过滤。

Docker daemon 不可用退出码 1。批量删除容器时先停止运行中的再删除。如果某个容器处于挂死状态（stop 超时默认 10 秒），用 kill 代替 stop 强制终止。Docker API 通过 Unix Socket 通信（默认 /var/run/docker.sock），权限不足退出码 1。
