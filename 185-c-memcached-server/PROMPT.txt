帮我用 C 写一个分布式缓存服务的服务端程序。场景是：公司有多个应用服务器（Web 服务、推荐服务、搜索服务等），它们需要共享一些临时数据——比如用户的登录会话信息、商品详情的缓存副本、系统配置参数的本地副本等。如果每次都去数据库查，数据库扛不住。所以需要部署一个独立的缓存服务，所有应用服务器通过网络来读写缓存。缓存服务启动后监听一个 TCP 端口，等待客户端连接。客户端发来的是文本格式的命令（一行一个命令），服务端解析命令并执行，然后返回文本格式的结果。支持的命令：存入一个键值对（附带过期时间，单位秒）、根据 key 读取对应的 value、删除一个 key、查看当前所有的 key 列表。key 和 value 都是字符串，value 最大不超过 1MB。缓存有内存使用上限（比如 100MB），满了之后按照「最近最少被访问」的规则自动淘汰旧数据来腾空间。过期的数据也要被自动清理。支持多个客户端同时连接和操作。如果某个客户端异常断开了（没有发送退出命令直接断开），要能检测到并释放它占用的资源。用纯 C 写，gcc 编译通过，不依赖第三方库。命令的解析要宽容——如果客户端发送的命令格式有小问题（多了空格、末尾有不可见字符），要能正确处理。
代码拆成至少 4 个源文件：命令解析、缓存存储与淘汰、客户端连接管理、主程序，各自有头文件和实现文件。gcc 编译能过。
