Elasticsearch 索引管理工具，Go 命令行实现，主要用于开发和测试环境的索引创建、查看和查询。

工具通过 ES REST API 交互，用标准 HTTP 客户端不需要专门 SDK。连接参数是 ES 地址（如 http://localhost:9200），开启了认证还需要用户名密码。

index 子命令管理索引：列出所有索引显示名称、文档数、主分片数、副本数、存储大小和状态。--create 创建索引指定名称和分片副本数，支持 --mapping 传入 JSON 映射定义。--delete 删除索引需确认，不存在则提示不报错。--reindex 把一个索引数据复制到另一个。

mapping 子命令查看和比较索引映射。显示所有字段及类型，--compare 比较两个索引映射差异。search 子命令执行查询，--query 传入 JSON 查询 DSL，也支持简化模式 --match "字段名:值"。结果格式化 JSON 输出，--size 限制条数。health 子命令显示集群健康状态：集群名、状态、节点数、活跃分片数和未分配分片数。

ES 连接超时默认 10 秒，超时退出码 1。返回非 2xx 时解析错误响应体 reason 字段展示给用户。删除索引要求用户输入完整索引名做二次确认，不一致取消退出码 1。查询结果字段多时表格截断过宽列到 80 字符。索引名包含特殊字符做 URL 编码。分片数超过节点数 3 倍时打印警告但仍创建。reindex 源和目标同名退出码 1。mapping 完全一致输出"映射一致"不是空表格。search 简化模式查询语法有误退出码 1。health 集群状态为 red 退出码 2（区别连接失败的 1）。
