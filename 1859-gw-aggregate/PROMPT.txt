移动端首页一个接口要拉用户信息、订单列表、推荐商品，串行调三个服务 RT 直奔 2 秒，用户都跑了。Rust axum 做一个 API 网关，除了路由和认证，核心能力是请求聚合——客户端一次请求，网关并行调多个后端，合并结果一次返回。

路由表支持动态增删。POST /routes 添加路由，body 带路径、后端地址、认证策略（免认证或 api_key）。认证模块独立实现，API Key 存内存注册表。DELETE /routes/{id} 删除路由。

聚合场景是关键。"首页"场景要并行调用户服务、订单服务、推荐服务三个后端。"个人中心"场景调用户服务和订单服务两个。每个场景配置一个后端调用列表——URL、超时时间、返回字段名。客户端请求 GET /aggregate/{scene_name}，网关并行调该场景的所有后端，把各服务的响应按字段名合并成一个 JSON 返回。某个后端超时或返回错误——那个字段标为 null 并附带错误信息，不影响其他字段的返回。

后端超时时间可配置，默认 5 秒。每个路由统计请求量。聚合场景的统计也记——每个场景调了多少次、平均耗时。

数据全内存。Cargo build，端口 PORT 环境变量。
