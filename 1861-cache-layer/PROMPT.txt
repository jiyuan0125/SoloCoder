数据库扛不住了，前面加一层缓存。Go 标准库 net/http 做缓存服务，包含 cache、policy、storage、api 四个模块。

cache 模块实现 LRU 淘汰和 TTL 过期。policy 模块管理淘汰策略和 TTL 策略。storage 模块做持久化（可选，写文件就行）。api 模块暴露 HTTP 接口。

容量通过接口配，单位条目数。每个 key 可以单独设 TTL。查询命中已过期的要删除返回 miss。修改容量后超出的立即淘汰。flush 清空所有数据。

stats 接口返回命中率、条目数、总查询次数。key 和 value 都是字符串。端口 PORT 环境变量，go build 能过。
