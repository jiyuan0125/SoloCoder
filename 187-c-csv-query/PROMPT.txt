帮我用 C 写一个 CSV 数据文件的查询工具。场景是：数据分析团队经常需要查看和处理 CSV 格式的数据文件，这些文件可能很大——几十万行、几十列，用 Excel 打开很慢或者根本打不开。需要一个命令行工具来快速查询。工具支持的查询功能：选择特定的列来显示（类似 SQL 的 SELECT col1, col2）、按条件过滤行（支持等于、不等于、大于、小于、大于等于、小于等于、字符串包含等条件，多个条件可以用 AND 或 OR 组合）、按某列排序（升序或降序）、对数值列做统计（最大值、最小值、平均值、求和、行数、去重后的不同值数量）。CSV 文件的第一行是表头，查询时用表头的列名来引用列。CSV 格式有一些特殊的解析规则需要正确处理：如果字段内容本身包含逗号，整个字段要用双引号包裹；如果字段内容包含双引号，要用两个双引号来转义。查询结果在终端以表格形式展示，各列自动对齐。也支持把查询结果导出为新的 CSV 文件。文件很大的时候不能全部读进内存。空行和只有空白的行要跳过。用纯 C 写，gcc 编译通过。如果 CSV 文件的编码不是 UTF-8（比如 GBK 或 Latin-1），工具要能检测到或支持指定编码。
代码拆成至少 4 个源文件：CSV 格式解析、条件过滤与排序、结果展示与导出、主程序，各自有头文件和实现文件。gcc 编译能过。
