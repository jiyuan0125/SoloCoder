仓库那边提了个需求，要给商品生成条形码标签，市面上工具要么太复杂要么收费，Go 命令行自己搞一个。

generate 子命令支持 Code 128（全 ASCII）、Code 39（数字大写字母加特殊字符）、EAN-13（13 位数字）、EAN-8（8 位）、UPC-A（12 位）。输出 PNG 和 SVG，支持 --width/--height 和 --show-text 显示编码文本。validate 子命令验证条形码合法性，EAN-13/UPC-A 校验码不对时输出正确校验码。batch 子命令从 CSV 批量生成。info 子命令显示各格式说明。

EAN-13 输入 12 位自动追加校验码并提示，13 位校验码错误退出码 1 并显示正确值。Code 128 自动选择子集 A/B/C，纯数字偶数长度用 C 效率最高。PNG 默认 300DPI。batch 空行跳过，CSV 不存在退出码 1。SVG 要能在浏览器直接打开。不支持格式退出码 1 列出所有格式。格式和长度不匹配退出码 1。磁盘空间不足退出码 1 删除不完整文件。
