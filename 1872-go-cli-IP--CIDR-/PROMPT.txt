之前 IP 白名单规则散落在十几个配置文件里，管理起来一团糟。上个月安全审计差点因为一条过期规则出事，用 Go 写个命令行工具统一管。

check 子命令检查 IP 是否在白名单，支持单 IP 和 CIDR 网段，输出匹配结果和匹配到的规则。add 子命令添加新规则，检查与已有规则的重叠关系，被包含的提示冗余，包含旧规则的提示是否删除旧规则。merge 子命令合并相邻重叠网段减少规则总数，输出前后对比。diff 子命令比较两个文件的规则差异。expand 子命令展开 CIDR 为 IP 列表，大网段必须指定 --limit。

IPv4 和 IPv6 都处理，混合比较直接返回不匹配不报错。白名单文件支持注释行和空行。IP 格式非法退出码 1。merge 合并后验证覆盖范围一致，不一致退出码 1。文件被锁定无法写入退出码 1。expand 大网段未指定 limit 退出码 1 避免输出千万行。diff 完全一致输出无差异。CIDR 掩码无效退出码 1。
