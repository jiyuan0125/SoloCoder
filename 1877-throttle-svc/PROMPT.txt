上游对接方不按约定的 QPS 调用，高峰期直接把我们打满了。Go 标准库 net/http 做限流服务，用 sync 包做并发控制，time 包做窗口计算。

支持固定窗口和滑动窗口两种模式，按客户端 IP 或 API Key 维度限流。规则通过接口配置：窗口大小、阈值。限流触发返回 429，Header 带 Retry-After。

限流检查的时候内部要调用一个统计模块来获取当前计数，统计模块更新计数时也要检查是否超限来触发告警。这两个操作都涉及同一份计数数据的读写。

统计模块记录每个规则维度的触发次数，提供查询接口。限流规则需要有创建入口。端口 PORT 环境变量，go build 能过。
