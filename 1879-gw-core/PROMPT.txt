后端服务上线要灰度、故障要降级、下线要摘流量——这些生命周期管理全靠人手工改 Nginx 配置，凌晨三点起来改完还经常改错。Rust actix-web 做一个网关，自动管理后端服务的状态流转。

后端服务状态和路由策略。1. 新注册的后端是"待验证"——不转发流量。2. 通过一次健康检查（GET /health，200 就算通过）变"在线"——全量转发。3. 在线后端错误率超过阈值（比如最近 100 个请求中 5xx 超过 20%）变"降级"——只转发 GET 请求（读操作），写操作返回 503。4. 降级后端连续 5 次健康检查通过恢复在线。5. "离线"状态的后端不转发任何请求——要重新注册才能回来。

路由表支持精确匹配和前缀匹配，精确优先。路由可以动态添加删除——POST /routes，body 带路径、匹配类型、后端服务名、认证策略（public 或 api_key）。DELETE /routes/{id} 删除。

API Key 认证：key 存内存注册表，请求带 X-API-Key 头验证。注册 key 用 POST /keys。

统计每个后端的请求量和错误率。GET /stats 返回所有后端统计。GET /services 查所有后端当前状态。健康检查间隔 15 秒。

Cargo build，端口 PORT 环境变量。
