后端服务上线要灰度、故障要降级、下线要摘流量，这些生命周期管理全靠人手工改 Nginx 配置。Rust actix-web 做一个网关，自动管理后端服务的状态流转。

后端服务状态：待验证→在线→降级→离线。新注册的后端是待验证，通过一次健康检查变在线。在线的后端错误率超过阈值变降级。降级的后端连续 5 次健康检查通过恢复在线。离线需要重新注册。

网关根据后端状态决定路由策略：在线的全量转发，降级的只转发 GET 请求（读操作），离线的不转发。路由表支持精确和前缀匹配，精确优先。

每个路由可以绑认证策略（免认证或 API Key）。统计每个后端的请求量和错误率。Cargo build，端口 PORT 环境变量。
