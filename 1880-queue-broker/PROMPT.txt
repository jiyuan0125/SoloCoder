支付成功要通知积分、库存、通知三个服务，同步调任何一个慢了都卡住用户。aiohttp 做消息代理，各服务通过 HTTP 接口发布和消费消息，实现异步解耦。

支持 Topic 和 Consumer Group。消息投递失败重试，全失败进死信队列。消息 ID 在 Topic 内递增。消费者可以按 Topic 名称订阅，订阅时还可以提供一个过滤表达式，只消费满足条件的消息。

消息内容可能包含用户提交的富文本或 HTML 片段。管理后台有个接口可以查看消息内容，直接在页面上渲染展示。这个查看接口的权限控制：只有 Topic 的创建者和管理员可以查看。

Topic 容量可配。消费进度可查。端口 PORT 环境变量。
