前后端对接时 OpenAPI 文档和实际实现经常不一致，Go 命令行工具来校验文档规范和生成 Mock 数据。

校验功能检查 YAML/JSON 格式的 OpenAPI 文件：必填字段齐全（info.title/version/paths 有路径）、每个操作有响应定义、$ref 引用能解析、HTTP 方法合法、路径参数有声明。Mock 生成功能根据 API 路径+方法的 schema 生成 JSON 响应：字符串按字段名生成有意义示例值，数字在 min/max 范围内随机，数组 2-3 个元素，enum 随机选，required 必生成 optional 50% 概率。

$ref 支持文件内和外部文件引用，检测循环引用报错。allOf 合并所有字段，oneOf 随机选一个。OpenAPI 格式不合法退出码 1。有错误级项退出码 1，只有警告退出码 0。循环引用退出码 1 输出引用链。外部文件不存在退出码 1。paths 为空退出码 1。format 为 email 生成合法邮箱，date-time 生成 ISO 8601 时间戳。路径参数自动替换示例值。
