之前格式转换的 Python 脚本太慢了，用 Go 重写一个 JSON/CSV/YAML 互转的命令行工具。

自动检测输入文件格式（扩展名+内容特征），转换为目标格式。六种路径：JSON→CSV 时对象数组每个对象键做列头值做行，嵌套对象用点号展平（address.city），数组值保留为 JSON 字符串。CSV→JSON 第一行做键名，值自动转数字/布尔类型，--nested 启用点号列名还原嵌套。JSON↔YAML 处理缩进风格、日期类型和锚点别名展开。

CSV 按 RFC 4180 标准解析，兼容不严格的文件。JSON null 转 CSV 默认空字符串，--null-string 可指定。CSV 流式解析，JSON 顶层数组流式处理。Windows Excel BOM 头自动跳过。输入不存在退出码 1。BOM 正确跳过。JSON 不合法退出码 1 指出位置。YAML 锚点别名展开。CSV 输出含逗号引号按 RFC 4180 处理。空数据退出码 0。单个对象自动包装为数组。输出覆盖不追加。
