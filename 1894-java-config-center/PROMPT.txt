配置散落在十几个服务的 properties 文件里，改一个数据库连接要登五台机器改五遍。出过一次端口配错的事故之后，决定 Spring Boot 做配置中心统一管。

配置按应用和环境分组，同一个 Key 在 dev 和 prod 可以有不同值。应用和环境都要先创建才能配 Key。环境固定三种：dev、staging、prod。批量查询接口按应用和环境组合过滤，返回的 Key 列表按字母排序，分页用 offset + limit，每页最多 100 条。

版本历史每次修改存快照，可以回滚到任意版本。回滚操作本身也产生一个新版本号，版本号递增不跳号。可以查两个版本之间的 diff，返回变更的 Key 列表和变更前后的值。配置值最大 64KB，超限拒绝写入返回 422。

客户端可以 watch 某个应用下所有 Key 的变更，注册时提供回调 URL。配置变更时 POST 回调通知，内容包含变更的 Key、新值、旧值。回调失败重试 2 次（间隔 5s、15s），连续 5 次都失败自动取消 watch。客户端可以重新注册恢复通知。Key 名只允许字母数字下划线和点，不合法返回 400。Maven 构建。
