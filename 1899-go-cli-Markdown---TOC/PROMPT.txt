技术博客 Markdown 文件管理很繁琐，目录生成、链接检查、元数据管理都是手动搞，Go 命令行工具搞定。

目录生成：扫描标题行生成 TOC，锚点规则（转小写、空格变连字符、去标点、连续连字符合并），插入到 <!-- TOC --> 标记位置，重复生成替换旧区域。链接检查：扫描行内链接、引用式链接、图片链接。相对路径检查文件存在性，绝对 URL 发 HEAD 请求检查状态码，405 回退 GET 只读响应头。并行检查默认 10 并发。元数据管理：读改 YAML Front Matter，meta set 修改字段，meta check 检查必填字段，meta batch 批量操作。

代码块内内容不扫描（标题、链接都跳过）。HTML 注释也跳过。中文字符锚点保留不转换和 GitHub 一致。文件不存在退出码 1。链接 404 退出码 1。网络超时默认 5 秒。HEAD 405 回退 GET。TOC 标记不完整退出码 1。meta check 缺字段退出码 1。meta batch 无 Markdown 退出码 0。
