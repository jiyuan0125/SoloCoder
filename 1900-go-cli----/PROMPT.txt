之前代码片段散落在笔记软件、Gist 和各个项目 README 里，找起来很费劲，用 Go 写个本地代码片段管理命令行工具。

存储在 ~/.snippets.json，每个片段有标题、描述、代码、语言、标签列表和创建时间。add 交互添加：依次输入标题描述语言标签，打开 $EDITOR（默认 vi）输入代码。search 模糊搜索标题描述代码标签，结果显示预览。view 按 ID 查看完整内容。list 按语言分组统计。export 按标签或语言导出为对应扩展名文件。tag 管理标签支持重命名批量修改。import 从目录批量导入代码文件。

编辑器集成通过临时文件，等待编辑器退出。JSON 文件并发安全用 .lock 文件，等待最多 5 秒。搜索无结果退出码 0。import 目录不存在退出码 1。export 目录不存在自动创建。tag 重名冲突退出码 1。add 空内容不保存提示已取消。数据文件损坏退出码 1 提示手动修复。ID 自增不回收。
