Go Gin 做一个 JSON↔Protobuf 双向转换网关。老系统只吐 Protobuf，新系统只吃 JSON，中间得有个东西做翻译。

转换规则按消息类型注册。先 POST /schemas/{message_type} 注册映射关系——Body 里包含 protobuf 的 .proto 定义（或编译后的 descriptor）和 JSON 字段到 proto 字段的映射表。没注册过的消息类型调用 /convert 返回 404，提示 message type not registered。

正向转换：客户端 POST JSON 到 /convert/{message_type}，网关根据注册的映射把 JSON 转成 Protobuf 二进制，转发到后端服务，后端返回的 Protobuf 二进制再转回 JSON 返回。反向也支持：POST Protobuf 二进制到 /convert/{message_type}/reverse，转成 JSON 给调用方。

端到端保证 round-trip 一致性——同一个消息正向转完再反向转回来，结果跟原始数据一致。嵌套对象、repeated 字段都要正确处理。映射关系存在内存里，PUT /schemas/{message_type} 可以更新，更新后新请求用新规则。

端口 PORT 环境变量，go build 能过。
