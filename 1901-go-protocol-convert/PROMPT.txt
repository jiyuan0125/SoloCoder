新旧系统对接需要协议转换，Go Gin 做一个转换网关。支持 JSON 到 Protobuf 的序列化转换和反序列化。
转换规则按消息类型注册，注册时提供 JSON 字段到 Protobuf 字段的映射。映射关系存在内存里，通过管理接口配置。
客户端 POST JSON 到 /convert/{message_type}，网关按映射转成 Protobuf 二进制转发到后端，后端返回的 Protobuf 再转回 JSON。
反向也支持：POST Protobuf 二进制到 /convert/{message_type}/reverse，转成 JSON 返回。
消息类型要先注册映射关系才能使用。端到端转换要保证 round-trip 一致性。端口 PORT 环境变量，go build 能过。
