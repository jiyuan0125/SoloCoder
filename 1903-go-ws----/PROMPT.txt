季度末了在线协作画板的后端还没写完，Go + WebSocket 搞定多人实时画画同步。

画板支持多图层，每个图层有名称和可见性开关。画笔工具：自由画笔、直线、矩形、圆形、橡皮擦。每种工具输出坐标序列或形状参数，服务端只存储转发不解释。每条笔画有 UUID，橡皮擦发被擦除笔画 ID 列表。撤销重做每用户独立历史，撤销广播给所有人（A 撤销 B 界面也同步消失）。

橡皮擦引用不存在的笔画 ID 跳过不报错。撤销涉及已被删除的笔画跳过继续。两用户同时调整图层顺序以服务端最后接收为准。新用户全量同步历史笔画，超 500KB 分批发送。画板 ID 不存在 WebSocket 返回 404。图层删除时笔画一并删除。服务端不做坐标校验只存转发。

gorilla/websocket，JSON 传输，标准 Go 模块，内存存储，8080 端口。
