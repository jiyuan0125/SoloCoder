上次那个代理不支持 WebSocket，前端推数据的场景全废了。Go 标准库重新撸一个，HTTP 和 WebSocket 都要能转发。

路由规则按 Host 头和路径前缀匹配，Host 匹配优先。后端按 Host 分组注册，同一个 Host 下面可以挂多个后端地址做轮询负载均衡。请求过来先看 Host 头有没有匹配的分组，有就走该组的后端；没有 Host 匹配再看路径前缀。WebSocket 升级请求要完整透传 Upgrade: websocket 和 Connection: Upgrade 这两个头，以及 Sec-WebSocket-Key 等所有相关头。

后端连不上的时候，如果同组还有其他后端，尝试下一个，按顺序轮。所有后端都不可用才返回 502，响应 Body 写明 Host 和尝试的后端列表。后端列表通过接口管理：POST /backends 注册（带 host 和 address），DELETE /backends/{id} 移除，GET /backends 查看全部。注册时校验地址格式和端口范围。

路径匹配支持精确和前缀两种模式，精确优先于前缀。端口 PORT 环境变量，go build 能过。
