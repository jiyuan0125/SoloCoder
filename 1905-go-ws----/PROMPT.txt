产品那边要一个在线协作思维导图工具，类似 ProcessOn，Go 后端 WebSocket 实时同步多人编辑。

数据结构是树，根节点在中间，节点有文字/颜色/折叠状态。操作：添加子节点、删除、编辑文字、移动（改变父节点）、展开折叠。移动节点时整个子树跟着走，目标是折叠节点要先展开。根节点不能删不能移，节点不能移到自己子孙下会成环。文字清空恢复旧文字。撤销是每用户独立的，反向操作广播给所有人。

两人同时操作同一节点保证数据一致。移动大分支同步数据只发节点 ID 和新父 ID 不发整个子树。节点 ID 用 UUID 跨客户端不重复。撤销后状态和预期不一致是正常协作行为。操作版本差过大返回错误让客户端重载全量。

gorilla/websocket + net/http，内存存储，8080 端口，JSON 消息。
