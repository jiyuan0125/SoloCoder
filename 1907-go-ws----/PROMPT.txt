之前用 VS Code Live Share 但想自己搞一个，Go 后端 WebSocket 实现多人实时编辑同一份代码文件。

用户打开文件建立 WebSocket 加入编辑会话。操作：插入/删除/替换文本，含类型和位置偏移。光标和选区实时同步，每人不同颜色。OT 算法解决并发编辑冲突。聊天频道用同连接传输消息类型区分。版本历史：停止编辑 30 秒后自动保存快照，可查看历史和回滚（广播给所有人）。

文件 ID 不存在 HTTP 返回 404。WebSocket 连接时文件 ID 无效返回错误。OT 版本不连续让客户端从指定版本重发。聊天超 2000 字符截断。快照距上次不足 30 秒跳过。大文件超 5000 行 OT 超 100ms 打性能警告。快速输入客户端本地合并再发。新用户全量同步文件内容和所有光标。

gorilla/websocket + 标准库，内存存储，8080 端口，JSON。
