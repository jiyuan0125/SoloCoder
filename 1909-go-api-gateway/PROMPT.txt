Go Gin 写一个安全网关，所有外发请求必须过三道中间件：认证→限流→日志，顺序不能乱。

认证用 HMAC 签名——客户端拿 API Key + Secret 对请求 Body 做 SHA256 签名，结果放在 Authorization 头，格式 HMAC {key_id}:{signature}。网关收到后用对应的 Secret 重新算一遍比对，不匹配返回 401。签名验证失败的同时记一条安全日志（包含来源 IP、请求路径、Key ID）。

限流按 Key 每分钟 N 次，N 在创建 Key 时指定，超了返回 429。请求 Body 超过 1MB 直接拒绝返回 413，不进任何后续处理。日志中间件记录请求方法、路径、响应状态码、处理耗时（毫秒），写内存环形缓冲区。

管理接口 POST /admin/keys 创建新 Key（返回 key_id 和 secret），DELETE /admin/keys/{kid} 吊销。吊销立即生效——新的请求立刻被拦，但正在处理中的请求正常完成不受影响。吊销的 Key 列表通过 GET /admin/keys 查看，包含每个 Key 的状态和创建时间。端口 PORT 环境变量，go build 能过。
