内网系统以前全靠 Session，现在要对接第三方应用，得上 OAuth2 授权码模式。Rust actix-web 写一个认证网关。

流程：第三方应用把用户重定向到 GET /authorize?client_id=xxx&redirect_uri=xxx&response_type=code，网关展示登录页。用户登录成功后，网关重定向回 redirect_uri 并带上 authorization code。第三方拿到 code 后 POST /token 换取 access_token（2 小时有效）和 refresh_token（7 天有效）。

access_token 过期后用 POST /token/refresh 拿 refresh_token 换新的——换新时同时颁发新的 refresh_token，旧的立刻失效（旋转刷新）。refresh_token 过期或用过的返回 401，客户端需要重新走授权流程。

第三方应用必须先通过 POST /clients 注册，注册时分配 client_id 和 client_secret，返回给调用方。未注册的 client_id 请求 /authorize 返回 400 错误。所有 Token 存内存，网关重启后全部失效，客户端需要重新授权。Cargo build，PORT 环境变量。
