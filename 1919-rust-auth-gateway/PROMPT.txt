内网系统以前都是 Session 认证，现在要对接第三方，得上 OAuth2 授权码模式。Rust actix-web 写：客户端先到网关授权，网关重定向到登录页，登录成功回调换取 Token。
Token 分 access_token（2 小时）和 refresh_token（7 天）。access_token 过期用 refresh_token 换新的。refresh_token 用过一次就失效，换新时同时发新的。
客户端要先注册才能用 OAuth 流程，注册时给 client_id 和 client_secret。未注册的请求授权返回错误。
Token 存内存，重启后全部失效。Cargo build，PORT 环境变量。
