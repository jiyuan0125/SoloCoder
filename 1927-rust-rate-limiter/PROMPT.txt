单机限流部署了三个实例，每个实例以为自己还有配额，加起来超了三倍。Rust actix-web 写一个分布式计数限流器，多个实例之间通过 HTTP 同步计数。

每个实例本地维护自己的计数器，定时（间隔可配，默认 5 秒）把本地计数推给其他实例。实际用量 = 本地计数 + 其他实例最近一次同步来的计数。允许同步窗口内的短暂超限——统计精度和延迟的取舍，超限不超过同步间隔内的最大增量。

实例列表通过 POST /instances 注册，注册时带 address（其他实例能访问到的地址）。新实例加入后从已有实例拉取当前全局计数状态，不冷启动从零开始。实例离线后（超过 3 个同步周期没推送），它的计数份额按比例平滑分配给其他活跃实例，不突然释放导致流量尖刺。

令牌桶参数按 API Key 配——PUT /keys/{kid}/config 设置限额（每秒允许次数），所有实例共享配置。配置修改通过实例间同步传播到全部节点，延迟不超过一个同步周期。GET /stats 返回本实例视角的全局 QPS 估算、限流次数、已知实例列表。每个 Key 的限流是独立的，Key 不存在返回 404。Cargo build，PORT 环境变量。
