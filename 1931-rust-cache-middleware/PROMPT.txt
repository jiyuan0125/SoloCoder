缓存需要支持多级缓存策略，Rust axum 写。L1 是进程内 LRU 缓存（小容量快速），L2 是一个模拟的远程缓存（用 HashMap + 人工延迟模拟网络）。
查询先查 L1，miss 了查 L2，都 miss 返回空。写入时同时写 L1 和 L2。L2 写入有延迟（模拟网络），期间如果有相同 Key 的查询直接等写入完成。
L1 容量满了只淘汰 L1 的条目不删 L2。L2 条目有 TTL，过期后惰性删除。L1 和 L2 的容量可以独立配置。
提供接口查看两级缓存的命中率、条目数。统计数据中 L1 miss 但 L2 命中的次数也要记录。
Cargo build，PORT 环境变量。
