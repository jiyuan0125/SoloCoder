V2 版本月底上线，探针调度器是核心组件——用来定期检查各种服务的健康状态。actix-web 做，探针类型要能扩展，不能写死只支持 HTTP。

探针类型分四种。HTTP 探针——发 HTTP 请求，检查响应状态码和可选的 body 内容。TCP 探针——尝试建立 TCP 连接，连上就算健康。DNS 探针——查询域名解析，能解析就算健康。自定义脚本探针——执行一个 shell 命令，退出码 0 为健康，非 0 为不健康。每种探针有自己的参数配置，比如 HTTP 要配 URL 和期望状态码，TCP 要配地址和端口。

调度策略三种可选。固定间隔——每隔 N 秒探测一次，简单直接。指数退避——探测失败后间隔逐渐增大（1 秒、2 秒、4 秒、8 秒...直到上限），成功后恢复初始间隔。自定义 cron——用 cron 表达式定义探测时间，适合需要在特定时间段探测的场景。策略按探针单独配置。

多个探针的结果聚合成最终健康状态——每个探针有权重，聚合时按权重计算健康分。比如 HTTP 探针权重 60、TCP 探针权重 40，HTTP 健康 TCP 不健康的话总分 60%，低于 80% 阈值就标记为 degraded。聚合结果和各探针的详细结果都可以查询。

POST /probes 创建探针（类型、参数、调度策略、权重），DELETE /probes/{id} 删除。GET /probes/{id}/status 查看最新探测结果。GET /health 聚合后的整体健康状态。GET /probes 列出所有探针及其配置。

端口通过 PORT 环境变量配置，Cargo build 能过。
