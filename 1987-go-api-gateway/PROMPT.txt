上个月有个接口被越权访问出了事故，查了一周才定位到。现在上 API 网关统一管控——Go 标准库 net/http 做，不依赖第三方框架。

所有请求先进网关，网关根据路径前缀路由到后端服务。路由规则动态配置，支持精确匹配和前缀通配。路径支持多级，比如 /api/v2/users/{id}/settings。匹配优先级：精确 > 带参数 > 前缀通配。

后端服务地址存内存，可以动态添加删除。每次路由匹配记录访问日志：来源 IP、请求路径、命中的后端、响应状态码、耗时。日志保留最近 5 万条，超出覆盖最老的。

用户自定义请求头里可能带各种特殊字符，转发前把非 ASCII 的 Header 值做安全过滤——直接删除不合法的字节。后端返回 5xx 连续超过 10 次，暂时标记不可用，30 秒后自动恢复探测。标记期间请求不转发到该后端，如果该路径只有这一个后端就返回 503。

管理接口查看所有后端状态（活跃/不可用/探测中）和访问日志。路由规则变更后立即生效，不影响正在处理的请求。

请求转发超时默认 30 秒，可以在路由规则里按路径覆盖。转发时保留原始请求的 Query 参数和 Body，响应原样返回给客户端。路径参数（如 {id}）在路由匹配时提取，不传给后端，只做匹配用。端口 PORT 环境变量，go build 能过。
