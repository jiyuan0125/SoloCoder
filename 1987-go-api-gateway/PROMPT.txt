上个月有个接口被越权访问出了事故，查了一周才定位到问题。现在要上一个 API 网关统一管控，Go 标准库 net/http 做。
所有请求先进网关，网关根据路径前缀路由到后端服务。路由规则可以动态配置，支持精确匹配和前缀通配。路径支持多级，比如 /api/v2/users/{id}/settings 这种。
后端服务地址存在内存里，可以动态添加删除。每次路由匹配的时候记录访问日志：来源 IP、请求路径、命中的后端、响应状态码。日志保留最近 5 万条。
用户自定义的请求头里可能带各种特殊字符，转发前要把非 ASCII 的 Header 值做安全过滤。后端如果返回 5xx 连续超过 10 次，暂时把那个后端标记为不可用，30 秒后自动恢复探测。
管理接口可以查看所有后端状态和访问日志。端口 PORT 环境变量，go build 能过。
