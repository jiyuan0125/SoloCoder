想用 Rust axum 练手中间件这块，做个重试调度服务。调用外部服务经常网络抖动，需要一个地方统一管理重试逻辑。
客户端提交任务时指定目标 URL、请求体、最大重试次数、重试策略（固定间隔或指数退避）。任务提交后后台异步执行，客户端拿到一个任务 ID 可以随时查状态。
指数退避要加 jitter 避免惊群，公式 base * 2^attempt + rand(0, jitter_max)。同一个幂等键的任务只执行一次，后来的相同幂等键直接返回之前的结果。
任务状态：待执行→执行中→成功/失败。失败后进入重试中，回到执行中。超过最大次数变为终态失败。正在执行的任务如果服务重启了，恢复后从待执行状态重新开始。
重试执行的时候如果发现目标 URL 是空的或者格式不对，直接标记失败不重试。任务完成后的结果保留 1 小时，超时清理。Cargo build，PORT 环境变量。
