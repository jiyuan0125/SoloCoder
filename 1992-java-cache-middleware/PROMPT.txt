内部十几个服务各自管自己的缓存，TTL 和淘汰策略五花八门，线上出过两次脏数据事故。Spring Boot 2 做一个集中管理的单机内存缓存中间件。
缓存按 namespace 隔离，每个 namespace 独立配置 TTL、最大容量、淘汰策略（LRU 或 LFU）。key 不能重复，value 最大 1MB。容量满了按策略淘汰最老的，过期 key 惰性删除，查询时顺便清掉。也提供手动清除某个 namespace 或某个 key 的接口。
批量操作一次写多个 key-value，要么全成功要么全失败。缓存命中率按 namespace 分别统计。客户端可以订阅 namespace 的 key 变更通知，通过回调 URL 推送，连续失败 3 次暂停该客户端通知 5 分钟。
Maven 构建，端口配置文件指定。
