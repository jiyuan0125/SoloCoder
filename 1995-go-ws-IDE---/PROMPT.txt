用 Go 写一个在线代码编辑器（类似简化版 VS Code Online）的后端，通过 WebSocket 实现多人实时协作编辑代码。用户在浏览器中打开编辑器页面，后端为每个项目维护一个文档状态模型。当多个用户同时编辑同一个文件时，后端使用操作转换算法（OT）来解决并发编辑冲突。每个用户的编辑操作（插入文字、删除文字、光标移动）通过 WebSocket 发送到后端，后端根据操作序列号计算转换后的操作结果，然后广播给其他所有正在编辑同一文件的协作者。项目 ID 不存在返回 404，用户没有项目权限返回 403。编辑器支持语法高亮功能，后端根据文件的扩展名来判断编程语言类型并返回对应的语法规则。还支持自动补全提示功能，用户输入时后端根据当前文件的已有内容和语言类型提供关键词和函数名建议列表。代码运行功能方面，后端在隔离的沙箱容器中执行用户提交的代码并实时返回标准输出和标准错误流。目前支持 Go、Python 和 JavaScript 三种语言。不支持的语言类型返回 400。后端还要记录每个文件的编辑历史，支持版本回退到之前任意一个保存点。每个项目还内置一个 Web 终端，用户可以在浏览器中输入命令行指令，后端创建一个伪终端执行命令并把输出通过 WebSocket 实时推回给浏览器。管理平台统计活跃项目数、同时在线用户数和代码行数变化趋势。

操作转换算法在三个以上用户同时编辑同一位置时容易产生不一致，要充分测试高并发场景。代码运行必须在沙箱容器中执行并设置严格的资源限制（CPU 时间最多十秒、内存最多二百五十六兆字节、禁止网络访问），超时自动终止返回 408。文件编辑历史版本每个文件只保留最近一百个版本快照。多个用户同时对同一文件做 OT 操作时操作序列的转换要互斥，不能出现操作被并发处理导致文档状态不一致。

服务端端口通过命令行参数或环境变量指定。
