新接了个金融客户的项目，他们要求所有接口都要过鉴权网关，Spring Boot 2 来做。
JWT 验证 + 角色控制。请求进来先验 JWT 签名和过期时间，通过后提取角色信息。角色有 admin 和 service 两种，admin 可以调管理接口，service 只能过业务请求。
JWT 密钥支持轮换，轮换时旧密钥保留一段时间（可配），期间新旧都能验。过期后旧密钥废弃。
每个请求验证后记录审计日志：时间、客户端 ID、请求路径、结果。审计日志存内存，最近 2 万条。用户提交的 token 内容可能包含各种特殊字符，解析时要做安全处理。
后端服务地址通过配置指定。后端返回 4xx 的请求记录到审计日志但不影响网关状态。端口通过命令行参数或环境变量配置，Maven 构建。
