新接了个金融客户，安全审计要求所有接口过鉴权网关，token 要短时效、密钥要轮换、每次请求要留审计记录。Spring Boot 2 来扛这个事儿。

JWT 验证加角色控制。请求进来先验 JWT 签名和过期时间，通过后提取角色信息。角色有 admin 和 service 两种——admin 可以调管理接口，service 只能过业务请求。token 过期返回 401，权限不够返回 403。

JWT 密钥支持轮换。轮换时旧密钥保留一段时间（可配，默认 1 小时），期间新旧密钥都能验。过期后旧密钥废弃，用旧密钥签的 token 统一 401。

每个请求验证后记录审计日志：时间、客户端 ID、请求路径、结果（通过/拒绝/过期）。审计日志存内存，最近 2 万条。日志不可修改，只追加查询，支持按客户端 ID 和时间范围过滤。

用户提交的 token 内容可能包含特殊字符，解析时安全处理——遇到无法解码的部分直接标记为无效 token。token 的 Authorization 头支持 Bearer 和 JWT 两种前缀格式。

后端服务地址通过配置指定，支持按路径前缀路由到不同后端。后端返回 4xx 的请求记录到审计日志但不影响网关状态——那是后端的事。管理接口可以查看审计日志和当前密钥状态（哪个是主密钥、旧密钥过期时间）。端口通过命令行参数或环境变量配置，Maven 构建。
