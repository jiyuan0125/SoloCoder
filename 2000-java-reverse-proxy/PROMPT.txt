开源的 Nginx 功能太多但我们需要的那几个定制化需求没做好，Spring Boot 2 从零写反向代理。请求进来按路径前缀转发到后端各服务。
路由规则支持精确匹配和前缀匹配，路径可以多级如 /api/v1/orders/{id}/items。匹配优先级：精确 > 长前缀 > 短前缀。路由规则可以动态添加和删除。
转发时注入 X-Forwarded-For 和自定义的 X-Trace-Id（全局唯一）。后端如果不可用（连接超时或连续 5xx），暂时把那个后端标记为故障，60 秒后恢复探测。探测用 HTTP HEAD。
请求路径中包含 .. 或特殊字符的要做安全过滤。访问日志记录每个请求的来源、目标后端、响应状态、耗时。日志保留最近 1 万条。
管理接口查看所有后端状态和访问日志统计。Maven 构建，端口通过配置文件或环境变量指定。
