现在这块效率太低了，想做一个积分商城系统，Go 标准库。
用 Go 标准库写一个积分商城 HTTP 服务
商品有名称、所需积分、库存数量和每日限兑次数
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。商品不存在返回 404。
用户兑换时扣减积分，积分余额不足返回 400 并告知当前余额和所需积分
同一商品每个用户每天限兑一次，超过返回 429 提示"今日已兑换"
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
库存扣减后 15 分钟内未支付（确认兑换）自动释放回库存，释放时如果商品已下架则库存归零
每笔兑换生成兑换码，兑换码有效期 7 天，过期作废。核销时校验兑换码是否存在和是否过期，过期返回 400 提示"兑换码已过期"
支持查询商品列表、用户兑换历史和兑换码核销
状态从新建→待支付→已兑换→已核销变更。只能按顺序走，跳步返回 400。
管理员可以上下架商品和调整积分，已下架商品不显示在列表中
数据存 SQLite，服务端口 8080。
