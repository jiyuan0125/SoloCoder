业务那边提了个需求，要一套文件格式转换系统，Go 标准库。
用 Go 标准库写一个文件格式转换 HTTP 服务
用户上传文件，指定目标格式，服务返回转换后的文件
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
支持的格式对包括：CSV↔JSON、JSON↔YAML、Markdown→HTML
上传文件大小不限。转换失败的要给出反馈，说明哪一步出了什么问题
如果源文件格式不对或者内容有损坏，工具要能继续处理剩下能处理的部分
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
转换后的文件保留原始数据的结构
CSV 和 JSON 互转时，嵌套关系用点号分隔的键名表示（比如 address.city）
数据存 SQLite，服务端口 8080。
