业务那边提了个需求，要一套文件格式转换系统，Go 标准库。
用 Go 标准库写一个文件格式转换 HTTP 服务
用户上传文件，指定目标格式，服务返回转换后的文件。不支持的格式对返回 415 提示支持的格式列表
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
支持的格式对包括：CSV↔JSON、JSON↔YAML、Markdown→HTML
上传文件大小不限。转换失败的要给出反馈，说明哪一步出了什么问题，不能只返回一个笼统的错误
如果源文件格式不对或者内容有损坏，工具要能继续处理剩下能处理的部分，跳过损坏的行或段，最后报告成功处理了多少、跳过了多少
流程按待提交→转换中→已完成逐步推进。不能跳过转换中直接到已完成。
转换后的文件保留原始数据的结构
CSV 和 JSON 互转时，嵌套关系用点号分隔的键名表示（比如 address.city）
数据存 SQLite，服务端口 8080。
