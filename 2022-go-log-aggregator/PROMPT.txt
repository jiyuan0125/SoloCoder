最近在搞这块业务，需要一个日志聚合系统，Go 标准库 实现。
用 Gin 写一个日志聚合 API
多个服务上报日志，每个日志条目有时间戳、级别、来源服务和消息内容
完成后自动触发关联的数据更新，更新时也要访问同一批记录来校验一致性。
聚合后支持按时间范围、级别和服务来源查询
相同内容的日志如果短时间内反复出现，聚合展示时合并成一条并标注出现次数
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
日志保留一段时间后自动清理，清理规则可以通过 API 配置
查询结果支持按时间排序
日志量大的时候查询不能太慢，需要建索引
总金额调整后各阶段的计划金额按比例重新分配。
支持按服务统计每天的日志数量和错误率
数据存 SQLite，服务端口 8080。
