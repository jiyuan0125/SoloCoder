数据导出系统的管理后台，Go 标准库。
用 Gin 写一个数据导出 API
用户选择要导出的数据表、字段和筛选条件，服务生成导出文件供下载。数据表不存在返回 404
导出的数据要做脱敏处理，手机号中间四位打码（138****5678），邮箱 @ 前面只保留首尾字符（t***g@example.com）
大量数据导出时不能阻塞接口，导出完成后通知用户下载。支持导出进度查询，返回百分比
导出文件保留 7 天后自动删除
同一个人同时只能有一个导出任务在跑，重复提交返回 409 提示"已有导出任务进行中"
导出支持选择文件格式（CSV 或 Excel），不支持的格式返回 400
数据存 SQLite，服务端口 8080。
