用 Go 标准库 写一个配置中心系统。
用 Go 标准库写一个配置中心 HTTP 服务
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
管理多个服务的配置项，配置按服务名和环境（开发/测试/生产）分组
支持通过 API 读取和修改配置
修改配置后，对应的服务要能拿到最新的配置值，不用重启
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
配置有变更历史记录，可以回滚到之前的版本
不同环境之间可以继承配置，比如测试环境继承开发环境的配置并覆盖部分值
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
配置项的类型可以是字符串、数字、布尔值或者 JSON 对象
数据存 SQLite，服务端口 8080。
