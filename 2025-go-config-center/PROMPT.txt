用 Go 标准库 写一个配置中心系统。
用 Go 标准库写一个配置中心 HTTP 服务
管理多个服务的配置项，配置按服务名和环境（开发/测试/生产）分组。服务名不存在返回 404
支持通过 API 读取和修改配置。修改配置后，对应的服务下次读取时拿到最新的配置值，不用重启
配置有变更历史记录，可以回滚到之前的版本。回滚时生成一条新的变更记录，标注"回滚到版本 N"
不同环境之间可以继承配置，比如测试环境继承开发环境的配置并覆盖部分值。读取时先查本环境，查不到的往上级环境找
配置项的类型可以是字符串、数字、布尔值或者 JSON 对象。修改配置时类型要和原来一致，类型不匹配返回 400 提示期望的类型和实际类型
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
数据存 SQLite，服务端口 8080。
