最近在搞这块业务，需要一个缓存代理系统，Go 标准库 实现。
用 Go 标准库写一个缓存代理 HTTP 服务
客户端请求某个 URL 的数据，代理先查本地缓存，命中且未过期直接返回，未命中则去上游服务获取并缓存结果
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
缓存可以设置过期时间，不同 URL 可以有不同的过期策略
缓存空间有限时，需要淘汰旧的缓存项
支持手动清除指定 URL 的缓存
缓存命中率要有统计，可以查看近期的命中率趋势
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
请求上游失败时，如果有过期缓存也可以先用着，但要在响应里标注数据可能过时
本地文件存储缓存
数据存 SQLite，服务端口 8080。
