最近在搞这块业务，需要一个缓存代理系统，Go 标准库 实现。
用 Go 标准库写一个缓存代理 HTTP 服务
客户端请求某个 URL 的数据，代理先查本地缓存，命中且未过期直接返回，未命中则去上游服务获取并缓存结果。URL 为空返回 400
缓存可以设置过期时间，不同 URL 可以有不同的过期策略。默认过期时间 5 分钟
缓存空间有限（默认 1GB）时，淘汰最久未被访问的缓存项（LRU）
支持手动清除指定 URL 的缓存，清除后下次请求重新从上游获取。URL 不在缓存中返回 404
缓存命中率要有统计，可以查看近 7 天的命中率趋势，按天分组
请求上游失败时，如果有过期缓存也可以先用着，但在响应头里加 X-Stale: true 标注数据可能过时
本地文件存储缓存
数据存 SQLite，服务端口 8080。
