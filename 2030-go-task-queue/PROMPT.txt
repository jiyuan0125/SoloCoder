我们最近需要一套任务队列系统，用 Go 标准库 做。
用 Gin 写一个任务队列 API
生产者提交任务到队列，任务有类型、优先级和负载（JSON 格式）。类型为空或负载不是合法 JSON 返回 400
消费者通过 API 拉取任务处理，处理完后上报结果。没有待处理任务时返回空数组而不是报错
任务可以设置超时时间（默认 30 分钟），超时未完成的任务回到队列重新分配，超时次数加 1
同一个任务失败后可以重试，最多重试 3 次，3 次都失败后标记为"失败"不再重试
任务支持优先级调度，高优先级的先执行。优先级范围 1-10，数字越大优先级越高，不在范围返回 400
支持查询任务状态（等待中、处理中、成功、失败），任务不存在返回 404
任务结果保留 7 天后清理
数据存 SQLite，服务端口 8080。
