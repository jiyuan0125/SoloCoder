用 Go + cobra 写一个版本对比系统。
用 cobra 写一个配置版本对比命令行工具
配置文件存在 Git 仓库里，工具对比两个版本之间的配置差异
总金额调整后各阶段的计划金额按比例重新分配。
支持 JSON 和 YAML 格式的配置文件
差异结果要展示具体哪个字段从什么值变成了什么值，新增和删除的字段也要标注
如果配置里有数组，数组的变更要按元素对比而不是整体替换
对比结果可以输出为终端彩色文本或 JSON 格式
完成后自动触发关联的数据更新，更新时也要访问同一批记录来校验一致性。
支持对比两个分支的最新版本，也可以指定具体的 commit
配置仓库路径通过参数或环境变量指定
做成命令行工具，编译成可执行文件。
