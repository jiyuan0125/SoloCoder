用 Go + cobra 写一个版本对比系统。
用 cobra 写一个配置版本对比命令行工具
配置文件存在 Git 仓库里，工具对比两个版本之间的配置差异。仓库路径不存在或不是 Git 仓库时报错退出
支持 JSON 和 YAML 格式的配置文件。其他格式报错提示"不支持的文件格式"
差异结果要展示具体哪个字段从什么值变成了什么值，新增的字段用绿色标注、删除的用红色标注
如果配置里有数组，数组的变更要按元素对比而不是整体替换。数组元素增删要标注索引位置
对比结果可以输出为终端彩色文本或 JSON 格式。JSON 格式时用 action 字段区分 add/modify/remove
支持对比两个分支的最新版本，也可以指定具体的 commit。commit 不存在时报错提示
配置仓库路径通过参数或环境变量指定
做成命令行工具，编译成可执行文件。
