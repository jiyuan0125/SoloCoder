我们最近需要一套JSON校验系统，用 Go 标准库 做。
用 Gin 写一个 JSON 数据校验 API
用户提交一个 JSON Schema 和一段 JSON 数据，服务返回校验结果，列出所有不符合 schema 的字段路径和原因。schema 格式不合法返回 400 并提示哪有问题
输入的 JSON 可能很大（几十 MB），也可能嵌套非常深（100 层以上），处理时不能一次性加载到内存
字段值可能包含各种 Unicode 字符、超长字符串（1MB 以上）。数值字段可能超出 int64 范围
数组字段可能有数千个元素
校验结果要精确到具体的字段路径（用点号分隔），比如 "users[2].email" 格式不对，原因是"不是合法邮箱格式"
服务本身在处理畸形输入时不能崩溃，不是合法 JSON 时返回 400 提示第一个语法错误的位置
内存使用要有上限控制，超过 512MB 时拒绝处理返回 413
数据存 SQLite，服务端口 8080。
