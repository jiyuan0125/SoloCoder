我们最近需要一套JSON校验系统，用 Go 标准库 做。
用 Gin 写一个 JSON 数据校验 API
用户提交一个 JSON Schema 和一段 JSON 数据，服务返回校验结果，列出所有不符合 schema 的字段路径和原因
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
输入的 JSON 可能很大（几十 MB），也可能嵌套非常深
字段值可能包含各种 Unicode 字符、超长字符串。数值字段可能超出 int64 范围
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
数组字段可能有数千个元素
校验结果要精确到具体的字段路径（用点号分隔）
服务本身在处理畸形输入时不能崩溃，要有合理的错误响应
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
内存使用要有上限控制
数据存 SQLite，服务端口 8080。
