文本去重系统的管理后台，Go 标准库。
用 Go 标准库写一个文本去重 HTTP 服务
接收一批文本条目，返回去重后的列表。输入为空数组返回空数组
完全相同的文本合并为一条，相似但不完全相同的文本（比如空格数量不同、标点符号全半角不同、末尾多了一个句号）也视为重复。归一化后再比较
文本可能包含各种 Unicode 字符，有些可能是不可见字符或零宽字符，归一化时先去掉零宽字符再比较
去重时忽略大小写差异。空文本和纯空白文本单独归类处理，不和其他文本比较
返回去重结果时标注每条合并了哪些原始条目的索引号
支持批量提交，单次提交量可能达到上万条，处理时不能阻塞其他请求
去重结果存入数据库方便后续查询，查询为空返回空数组
数据存 SQLite，服务端口 8080。
