用 Go 标准库 写一个图片批量处理系统。
用 Gin 写一个图片批量处理 API
用户上传一组图片，指定处理操作（缩放、裁剪、格式转换、添加水印）。操作参数不合法返回 400，比如缩放到 0 或负数
支持 JPEG、PNG、GIF、BMP 和 WebP 格式。不支持的格式返回 415 提示支持的格式列表
上传的文件可能不全是图片，有些可能是改了扩展名的文本文件或损坏的图片文件。这些文件跳过不处理，最后报告中列出跳过的文件名和原因
GIF 动图缩放时要保留所有动画帧。输出格式转换时保留 EXIF 信息
处理完成后打包为 ZIP 下载。上传的图片可能非常大（几十 MB），内存使用要控制，单张图片处理内存不超过 200MB
本地文件存储
数据存 SQLite，服务端口 8080。
