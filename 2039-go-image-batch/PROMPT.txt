用 Go 标准库 写一个图片批量处理系统。
用 Gin 写一个图片批量处理 API
用户上传一组图片，指定处理操作（缩放、裁剪、格式转换、添加水印）
支持 JPEG、PNG、GIF、BMP 和 WebP 格式
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
上传的文件可能不全是图片，有些可能是改了扩展名的文本文件或损坏的图片文件
处理这些文件时不能影响其他正常文件的处理
GIF 动图缩放时要保留动画帧。输出格式转换时保留 EXIF 信息
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
处理完成后打包为 ZIP 下载
上传的图片可能非常大（几十 MB），内存使用要控制
本地文件存储
数据存 SQLite，服务端口 8080。
