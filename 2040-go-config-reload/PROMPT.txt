现在这块效率太低了，想做一个配置热加载系统，Go 标准库。
用 Go 标准库写一个配置热加载 HTTP 服务
配置文件是 YAML 格式，包含多个服务的配置
操作完成后自动更新关联的统计汇总，统计更新时也要读取同一批数据来核对总数。
服务启动后定时检查配置文件变更（每 10 秒），发现变更后重新加载配置
如果新配置有语法错误，不能覆盖当前有效配置，保留旧配置继续运行
主操作成功后自动更新关联的统计信息。
配置文件可能在写入过程中被读取（部分写入状态），要能处理这种情况
配置变更后通知所有依赖这个配置的模块
支持通过 API 触发立即重载。每次重载的变更内容和时间要记录日志
总数修改后各子项的配额按比例重新调整。
配置项的类型在变更时要校验，类型不对的拒绝加载
数据存 SQLite，服务端口 8080。
