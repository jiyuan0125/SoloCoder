现在这块效率太低了，想做一个配置热加载系统，Go 标准库。
用 Go 标准库写一个配置热加载 HTTP 服务
配置文件是 YAML 格式，包含多个服务的配置。文件不存在时启动报错退出
服务启动后定时检查配置文件变更（每 10 秒），发现变更后重新加载配置。只检查文件内容的哈希值变化，不检查时间戳
如果新配置有语法错误，不能覆盖当前有效配置，保留旧配置继续运行，同时写日志记录加载失败原因和错误位置
配置文件可能在写入过程中被读取（部分写入状态），读取时先检查文件是否完整（校验字节或结构完整性），不完整就等下次检查
配置变更后通知所有依赖这个配置的模块，通知失败时记录日志不影响配置本身的更新
支持通过 API 触发立即重载。每次重载的变更内容和时间要记录日志。配置项的类型在变更时要校验，类型不对的拒绝加载并返回 400 提示期望类型
数据存 SQLite，服务端口 8080。
