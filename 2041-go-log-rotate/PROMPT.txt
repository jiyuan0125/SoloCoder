帮我做一套日志轮转系统，Go 标准库。
用 Gin 写一个日志轮转管理 API
服务持续写入日志文件，当文件大小超过指定阈值（默认 100MB）或到达指定时间（默认每天凌晨 3 点）时自动轮转。轮转参数可通过 API 配置
轮转后的旧日志文件按日期命名并压缩存储，命名格式 app-2024-01-15.log.gz
在日志写入高峰期，轮转操作不能丢失正在写入的日志。轮转时先切换到新文件再压缩旧文件
压缩过程异步进行，不影响当前日志写入。压缩失败的旧文件保留原样并记录错误
保留最近 30 个轮转文件，超过的自动删除。磁盘空间不足时提前删除最老的文件
查询历史日志时自动解压对应的文件，查询完成后重新压缩
日志写入的并发量可能很大，要保证日志条目不丢失不乱序。单条日志最大 1MB，超过的截断并标注"已截断"
数据存 SQLite，服务端口 8080。
