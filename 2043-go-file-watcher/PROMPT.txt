最近在搞这块业务，需要一个文件监控系统，Go 标准库 实现。
用 Gin 写一个文件变更监听 API
用户指定要监听的目录，当目录下的文件发生创建、修改、删除或重命名时，触发回调通知。目录不存在返回 404
支持监听子目录递归。监听中的目录不能重复注册，重复返回 409
短时间内一个文件可能被频繁修改（比如日志文件每秒都在追加），5 秒内的多次修改事件合并为一次通知，只报告最后一次的状态
被监听的文件可能被删除然后又重建，删除事件和创建事件都要通知，不能因为文件不存在就停止监听
目录权限可能导致某些子目录无法访问，跳过无权限的子目录并记录警告日志，不停止整个监听
监听服务本身不能因为目标目录被删除或磁盘满而崩溃，目录被删除后暂停该目录监听，目录重建后自动恢复
数据存 SQLite，服务端口 8080。
