我们最近需要一套环境变量管理系统，用 Go 标准库 做。
用 Go 标准库写一个环境变量管理 HTTP 服务
管理多个项目的环境变量，每个项目有自己的命名空间。支持 CRUD 操作和按项目导出为 .env 文件
总量变更后各部分的分配额度按比例重新计算。
环境变量值可能包含特殊字符（换行、引号、$ 符号、等号），导出和导入时要正确处理
导入 .env 文件时支持带引号的值和注释行
同一个变量在不同环境（dev/staging/prod）有不同的值
主操作完成时自动执行关联的状态同步，同步过程也要读取同一份数据来确认。
变量的值可以通过 API 覆盖。导入的文件可能有各种编码问题
支持对比两个环境之间的变量差异
数据存 SQLite，服务端口 8080。
