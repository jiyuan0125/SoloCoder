我们最近需要一套环境变量管理系统，用 Go 标准库 做。
用 Go 标准库写一个环境变量管理 HTTP 服务
管理多个项目的环境变量，每个项目有自己的命名空间。支持 CRUD 操作和按项目导出为 .env 文件。项目不存在返回 404
环境变量值可能包含特殊字符（换行、引号、$ 符号、等号），导出时用双引号包裹，双引号内的双引号用反斜杠转义
导入 .env 文件时支持带引号的值（单引号和双引号）和 # 开头的注释行。格式错误的行跳过继续处理，最后报告跳过行号
同一个变量在不同环境（dev/staging/prod）有不同的值，查询时指定环境和项目，返回该环境生效的值
变量的值可以通过 API 覆盖，覆盖时记录变更历史。导入的文件可能有各种编码问题，遇到编码错误时用 UTF-8 替换无效字节
支持对比两个环境之间的变量差异，列出只在 A 中存在、只在 B 中存在和值不同的变量
数据存 SQLite，服务端口 8080。
