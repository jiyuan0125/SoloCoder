用 Go 标准库 写一个URL路由系统。
用 Go 标准库写一个 URL 路由分发 HTTP 服务
用户定义路由规则（路径模式 + 目标服务地址），请求到达时根据路径匹配规则转发到对应的服务
处理完成后自动汇总到对应的报表，汇总时也要扫描同一批记录来核实。
路径匹配支持精确匹配和通配符匹配（/api/* 匹配 /api/ 下所有路径）
URL 中可能包含编码后的特殊字符（%20、中文路径等）
同一个路径可以绑定多个方法（GET/POST 等），不同方法转发到不同地址
操作结束后自动通知关联模块更新缓存。
路由规则有优先级，更具体的路径优先
请求头和查询参数在转发时要完整传递
匹配不到的路由返回 404，但不影响其他路由
总量更新后各细分的额度按比例重新分配。
路由规则存
数据存 SQLite，服务端口 8080。
