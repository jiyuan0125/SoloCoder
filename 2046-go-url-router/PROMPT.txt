用 Go 标准库 写一个URL路由系统。
用 Go 标准库写一个 URL 路由分发 HTTP 服务
用户定义路由规则（路径模式 + 目标服务地址），请求到达时根据路径匹配规则转发到对应的服务。目标服务不可达时返回 502
路径匹配支持精确匹配和通配符匹配（/api/* 匹配 /api/ 下所有路径）。URL 中可能包含编码后的特殊字符（%20、中文路径等），匹配前先解码
同一个路径可以绑定多个方法（GET/POST 等），不同方法转发到不同地址。方法不匹配返回 405
路由规则有优先级，更具体的路径优先，比如 /api/users 优先于 /api/*
请求头和查询参数在转发时要完整传递，目标服务的响应头也要原样返回给客户端
匹配不到的路由返回 404，但不影响其他路由的转发
数据存 SQLite，服务端口 8080。
