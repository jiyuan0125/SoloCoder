现在这块效率太低了，想做一个限流系统，Go + cobra。
用 cobra 写一个限流规则管理命令行工具
管理 API 的限流规则配置，规则包括限流维度（IP、用户、接口）、限流算法和限流阈值。维度或算法不合法返回错误提示
限流算法支持固定窗口、滑动窗口和令牌桶。窗口大小不能为负数、阈值不能为零，不合法的规则拒绝导入并提示具体哪个字段有问题
工具可以测试某个规则对给定请求序列的判定结果，输出哪些请求被允许（200）、哪些被拒绝（429），以及被拒绝时的剩余等待时间
滑动窗口模式下窗口大小可配置（默认 1 分钟）。令牌桶模式下桶容量和填充速率可配置
规则可以导出为 JSON 配置文件供其他服务使用，导出时校验所有规则的合法性
规则存 JSON 文件
做成命令行工具，编译成可执行文件。
