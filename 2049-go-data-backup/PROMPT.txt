业务那边提了个需求，要一套数据备份系统，Go + cobra。
用 cobra 写一个数据备份命令行工具
支持备份指定目录下的文件到目标位置（本地目录或压缩包）
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
增量备份只复制上次备份后修改过的文件
备份过程中如果中断（Ctrl+C 或系统异常），下次可以从断点继续而不是从头开始
大文件（超过 1GB）要分块传输，显示进度条
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
备份前后校验文件完整性（比较文件大小和修改时间）
备份记录保存在本地的元数据文件里，包括每次备份的时间、文件列表和状态
恢复时根据备份记录找到对应的文件版本
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
元数据存 backup-meta.json，命令行参数指定源和目标
做成命令行工具，编译成可执行文件。
