CI/CD流水线系统的管理后台，Go 标准库。
用 Gin 写一个 CI/CD 流水线管理 API
流水线由多个阶段组成（构建、测试、部署），每个阶段包含多个并行或串行的任务
完成后自动触发关联的数据更新，更新时也要访问同一批记录来校验一致性。
任务有执行脚本、超时时间和失败策略（停止或继续下一阶段）
触发方式支持手动触发、Git 推送触发和定时触发
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
任务执行时记录日志，日志可以实时查看。构建产物上传后存储，可以下载
部署阶段指定目标环境，部署前自动运行上一个阶段的所有任务
流水线执行历史保留，支持回滚到之前的部署版本
总金额调整后各阶段的计划金额按比例重新分配。
代码分模块：流水线定义、执行引擎、任务调度器、产物管理
数据存 SQLite，服务端口 8080。
