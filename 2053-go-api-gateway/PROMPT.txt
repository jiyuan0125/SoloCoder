用 Go 标准库 写一个API网关系统。
用 Go 标准库写一个 API 网关 HTTP 服务
接收客户端请求，根据路由规则转发到后端服务
请求经过认证、限流、日志记录等中间件处理后转发，响应经过日志记录后返回
流程按申请→初审→复审→批准→完成推进。每步有对应负责人。
路由配置支持路径前缀匹配和精确匹配，可以按请求头做路由分发
认证支持 API Key 和 JWT 两种方式
限流按 IP 和 API Key 两个维度，超限返回 429
每个操作有独立的接口路径：列表查询、详情查看、子项列表、子项操作。
每个请求记录访问日志，包含请求路径、响应状态码、耗时和客户端标识
后端服务不可用时返回降级响应。支持通过 API 动态修改路由规则
代码分层：路由层、中间件链、代理转发、配置管理
数据存 SQLite，服务端口 8080。
