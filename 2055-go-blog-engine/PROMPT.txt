帮我做一套博客系统，Go 标准库。
用 Go 标准库写一个博客系统 HTTP 服务
文章支持 Markdown 编写，发布时渲染为 HTML
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
文章有分类和标签，支持按分类浏览和按标签筛选
读者可以评论，评论支持多级回复。评论有审核机制，包含敏感词的评论自动标记待审核
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
文章浏览量统计，热门文章排行按最近 7 天的浏览量排序
作者可以管理自己的文章（草稿、发布、下架），管理员可以管理所有文章和评论审核
用户系统支持注册、登录和基本的个人信息管理
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
代码分模块：用户管理、文章服务、评论系统、渲染引擎
数据存 SQLite，服务端口 8080。
