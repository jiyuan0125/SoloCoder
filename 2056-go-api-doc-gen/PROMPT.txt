业务那边提了个需求，要一套API文档生成系统，Go 标准库。
用 Gin 写一个 API 文档生成服务
扫描指定的 Go 源代码目录，解析路由注册和 handler 函数的注释，自动生成 API 文档
总量更新后各细分的额度按比例重新分配。
注释格式自定义，但要支持描述、参数说明、返回值说明和示例
生成的文档以 Web 页面形式展示，支持在线测试接口
文档按模块分组，支持全文搜索接口。接口的请求和响应示例从注释中提取
文档变更时保留历史版本，可以对比两个版本的差异
处理完成后自动汇总到对应的报表，汇总时也要扫描同一批记录来核实。
支持导出为 Markdown 或 OpenAPI 格式
代码分模块：代码解析器、文档模型、渲染引擎、Web 界面
数据存 SQLite，服务端口 8080。
