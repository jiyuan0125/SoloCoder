业务那边提了个需求，要一套API文档生成系统，Go 标准库。

扫描指定的 Go 源代码目录，解析路由注册和 handler 函数的注释，自动生成 API 文档。扫描的目录不存在时返回 400 和错误说明，目录下没有 Go 文件时返回空文档而不是报错。注释格式自定义，但要支持描述、参数说明、返回值说明和示例，注释格式不合法的接口在文档中标记为"文档不完整"并高亮显示。

生成的文档以 Web 页面形式展示，支持在线测试接口。文档按模块分组，支持全文搜索接口，搜索无结果时返回空列表而不是 404。接口的请求和响应示例从注释中提取，没有示例的接口显示"暂无示例"占位。文档变更时保留历史版本，可以对比两个版本的差异，对比结果按新增、删除、修改分类展示。

总量更新后各细分的额度按比例重新分配，已完成模块的额度不变。处理完成后自动汇总到对应的报表，汇总时重新扫描同一批记录核实。支持导出为 Markdown 或 OpenAPI 格式，导出时如果接口文档不完整，在导出文件头部列出缺失项。代码分模块：代码解析器、文档模型、渲染引擎、Web 界面。数据存 SQLite，服务端口 8080。
