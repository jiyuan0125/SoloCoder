我们最近需要一套多租户管理系统，用 Go 标准库 做。
用 Gin 写一个多租户配置管理 API
每个租户有自己的配置空间，包括功能开关、自定义字段和套餐信息
确认操作时自动触发后续的数据校验，校验过程也要查询同一批记录来汇总。
租户数据逻辑隔离，通过租户 ID 区分
套餐定义了租户可用的功能列表和资源限额（用户数、存储空间、API 调用次数）
功能开关控制某个功能是否对租户开放
完成后自动从关联模块同步最新状态。
自定义字段允许租户定义自己的业务字段（文本、数字、日期、下拉选择）
资源用量实时统计，接近限额时发出警告通知
降级时超出限额的功能标记为只读
总额变化后各分项按比例同步更新。
代码分模块：租户管理、套餐服务、功能开关、自定义字段
数据存 SQLite，服务端口 8080。
