我们最近需要一套多租户管理系统，用 Go 标准库做。

每个租户有自己的配置空间，包括功能开关、自定义字段和套餐信息。租户数据逻辑隔离，通过租户 ID 区分，查询不存在的租户 ID 返回 404，租户 ID 格式不对（非字母数字下划线）返回 400。套餐定义了租户可用的功能列表和资源限额（用户数、存储空间、API 调用次数），套餐变更后已有租户的限额在下一个计费周期生效，当前周期内不变。

功能开关控制某个功能是否对租户开放，关闭功能后该功能下已有的数据标记为只读，不能新增不能修改只能查看。自定义字段允许租户定义自己的业务字段（文本、数字、日期、下拉选择），字段名在同一租户内不能重复，重复创建返回 409。自定义字段一旦有数据关联就不能删除，只能禁用，禁用后新记录不显示该字段但已有数据保留。

资源用量实时统计，接近限额（超过 80%）时发出警告通知，达到限额时拒绝新的资源创建请求并返回 403 和剩余可用量。降级时超出限额的功能标记为只读。套餐总额变化后各分项按比例同步更新，已使用的部分不变。确认操作时自动触发后续的数据校验，校验过程重新查询同一批记录汇总。代码分模块：租户管理、套餐服务、功能开关、自定义字段。数据存 SQLite，服务端口 8080。
