消息队列管理系统的管理后台，Go 标准库。
用 Go 标准库写一个消息队列管理 HTTP 服务
支持创建主题和订阅。生产者向主题发布消息，消费者通过订阅拉取消息
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
消息确认后从队列移除，未确认的消息重新入队
消息有存活时间，过期自动进入死信队列。死信队列的消息可以重新投递或丢弃
支持查看主题的消息堆积量、消费组的消费进度
消息发布支持批量操作
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
订阅支持广播模式（每条消息投递给所有消费者）和集群模式（每条消息只投递给一个消费者）
代码分模块：主题管理、存储引擎、投递器、死信处理
数据存 SQLite，服务端口 8080。
