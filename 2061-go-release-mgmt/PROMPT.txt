现在这块效率太低了，想做一个版本发布系统，Go 标准库。
用 Go 标准库写一个版本发布管理 HTTP 服务
管理软件版本的发布流程：创建版本号→关联变更记录→审批→部署到 staging→验证→部署到生产环境
接口按资源层级组织：查看所有记录、查看某条记录、查看该记录下的操作历史、给操作添加备注。
每个版本关联一批变更记录（从 Git commit 记录或手动录入）
审批需要至少两个人确认
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
部署到 staging 后自动运行冒烟测试，测试通过才能继续部署到生产环境
生产环境部署支持灰度发布（先部署到 10% 的节点）。发布失败可以一键回滚到上一个版本
发布历史和每次发布的状态完整记录
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
代码分模块：版本管理、变更记录、审批流程、部署引擎
数据存 SQLite，服务端口 8080。
