用 Go 标准库 写一个Excel报表系统。
用 Gin 写一个 Excel 报表生成 API
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
根据模板和数据源生成 Excel 文件，支持单元格样式设置、公式计算和图表生成
模板定义了报表的布局和数据填充位置。数据源支持 JSON 或数据库查询结果
单元格合并、自动列宽和条件格式（数值大于某值标红）都要支持
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
图表类型支持柱状图、折线图和饼图，数据范围和标题可配置
公式字段在导出后仍然是公式而不是固定值
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
大量数据导出时不能内存溢出。使用 excelize 库
数据存 SQLite，服务端口 8080。
