帮我做一套二维码系统，Go 标准库。
用 Gin 写一个二维码生成 API
输入文本或 URL，生成二维码图片。支持输出 PNG、JPEG 和 SVG 三种格式
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
二维码可以设置大小、前景色、背景色和容错级别（L/M/Q/H）
支持在二维码中间放 Logo 图片，Logo 区域的容错级别自动提升
生成的二维码可以添加边框和标题文字
批量生成时输入 CSV 文件，每行一个内容，输出打包为 ZIP 下载
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
二维码内容可以是纯文本、URL、vCard 联系人信息或 WiFi 连接信息，根据内容类型自动选择最优编码模式
使用 skip2/go-qrcode 或类似库
数据存 SQLite，服务端口 8080。
