业务那边提了个需求，要一套JWT认证系统，Go 标准库。

支持颁发和验证 JWT Token，Token 包含用户 ID、角色和过期时间。支持 RSA 和 HMAC 两种签名算法，算法类型在 Token 头部声明，签名不匹配返回 401。密钥轮换机制：可以添加新密钥并设置过渡期，过渡期内新旧密钥都有效，过渡期结束后只用新密钥，用旧密钥签发的 Token 返回 401。Token 黑名单支持注销已颁发的 Token（通过 jti 字段），已注销的 Token 即使未过期也返回 401。

验证时检查签名、过期时间、签发者和受众，过期 Token 返回 401 和过期时间，签发者不匹配返回 401。Token 刷新机制：access token 短期（15 分钟），refresh token 长期（7 天），refresh token 过期后需要重新登录，用过期的 access token 刷新返回 401。同一个 refresh token 只能用一次，重复使用返回 401 并注销该用户所有 Token。

代码自己实现 JWT 编解码，不依赖第三方 JWT 库。操作完成后自动更新关联的统计汇总，统计更新时重新读取同一批数据核对总数。数据存 SQLite，服务端口 8080。
