最近在搞这块业务，需要一个SSH隧道系统，Go 标准库 实现。
用 Gin 写一个 SSH 隧道管理 API
创建和管理 SSH 隧道，将本地端口转发到远程服务器
支持本地端口转发（-L）和远程端口转发（-R）
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
隧道配置包含 SSH 服务器地址、认证方式（密码或私钥）、本地端口和远程目标地址
隧道状态实时监控，断开后自动重连
支持同时管理多条隧道。隧道的流量统计（上行/下行字节数）
接口按资源层级组织：查看所有记录、查看某条记录、查看该记录下的操作历史、给操作添加备注。
通过 API 启动、停止和查看隧道状态
连接日志记录建立时间、断开时间和断开原因
使用 crypto/ssh 标准库
数据存 SQLite，服务端口 8080。
