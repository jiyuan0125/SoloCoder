我们最近需要一套TAR归档系统，用 Go 标准库 做。
用 Go 标准库写一个文件归档 HTTP 服务
将指定目录打包为 tar.gz 归档文件，也支持解压归档文件到指定目录
归档时保留文件的权限位、修改时间和目录结构
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
大文件归档时显示进度（已处理字节数 / 总字节数）
支持增量归档，只归档指定日期之后修改过的文件
归档文件可以加密（AES-256），加密密码通过 API 参数传入
总金额调整后各阶段的计划金额按比例重新分配。
解压时校验归档完整性，损坏时报告具体哪个文件有问题
支持列出归档文件内容列表而不实际解压
只用 archive/tar、compress/gzip 和 crypto 标准库
数据存 SQLite，服务端口 8080。
