ASN.1解析系统的管理后台，Go + cobra。

解析 DER 编码的 ASN.1 数据，支持常见类型：INTEGER、BIT STRING、OCTET STRING、NULL、OID、UTF8String、SEQUENCE、SET、UTCTime 等。输入可以是十六进制字符串或二进制文件，输入文件不存在输出错误并退出码 1，十六进制字符串格式不对（非十六进制字符或奇数长度）输出错误位置并退出码 1。输出展示 ASN.1 结构树，包含标签类型、长度和值，解析失败的位置输出已解析的部分和失败原因。

能够解析嵌套的 SEQUENCE 和 SET 结构，嵌套层级超过 100 层输出警告但继续解析。遇到不认识的标签类型用十六进制展示原始值。支持解析 X.509 证书文件，提取证书的各个字段（主题、颁发者、有效期、公钥信息等），证书过期或未到生效期在输出中标注。输出格式支持文本树和 JSON，JSON 输出要保证 round-trip：解析后的 JSON 重新编码为 DER 后和原始数据一致。

使用 encoding/asn1 和 crypto/x509 标准库。做成命令行工具，编译成可执行文件。
