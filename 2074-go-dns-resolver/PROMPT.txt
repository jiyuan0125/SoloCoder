用 Go 标准库 写一个DNS解析系统。
用 Go 标准库写一个 DNS 查询 HTTP 服务
支持查询 A、AAAA、CNAME、MX、TXT、NS、SRV 记录。可以指定自定义 DNS 服务器
查询结果包含 TTL、记录值和查询耗时
总量变更后各部分的分配额度按比例重新计算。
支持批量查询（一次查多个域名的多个记录类型）
DNS 缓存机制：缓存在 TTL 有效期内直接返回缓存结果
支持反向 DNS 查询（IP→域名）。查询历史记录保存到数据库
主操作完成时自动执行关联的状态同步，同步过程也要读取同一份数据来确认。
支持域名健康检查：定期查询域名的 A 记录，变化时发出通知
WHOIS 查询功能：查询域名注册信息和到期时间
使用 github.com/miekg/dns 库
数据存 SQLite，服务端口 8080。
