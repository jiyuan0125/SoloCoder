现在这块效率太低了，想做一个Protobuf转换系统，Go + cobra。

输入 .proto 文件定义和二进制 protobuf 数据，输出对应的 JSON 格式，反过来也支持。proto 文件不存在输出错误并退出码 1，proto 文件语法错误输出错误行号和原因。二进制数据无法按 proto 定义解析时输出已解析的字段和失败位置。支持嵌套消息、枚举类型、repeated 字段和 map 字段，oneof 字段在 JSON 中用对象表示。

proto3 的默认值字段在 JSON 中可以省略或保留，通过参数控制。时间戳类型（google.protobuf.Timestamp）转换为可读的日期时间格式，时间戳值不合理（如负数）在输出中标注警告。JSON 输出可以格式化或压缩。批量转换时输入目录，输出到另一个目录，输入目录不存在退出码 1。

转换要保证 round-trip：JSON 转回 protobuf 后二进制数据和原始一致。系统管理多种资源类型和它们之间的关联关系，每次操作关联到具体的资源，支持按资源查看汇总。使用 google.golang.org/protobuf 库。做成命令行工具，编译成可执行文件。
