我们最近需要一套分布式计数系统，用 Go 标准库 做。
用 Gin 写一个分布式计数器 API
管理多个命名计数器，支持递增、递减、设置值和获取当前值。计数器按命名空间分组
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
每次操作返回操作后的新值。支持批量操作（一次递增多个计数器）
计数器可以设置上限和下限，到达边界值后操作无效
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
操作历史记录保留，可以查看某个计数器的变更时间线
多个请求同时操作同一个计数器时，结果要准确一致
支持获取某个命名空间下所有计数器的快照
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
计数器数据持久化，服务重启后恢复
数据存 SQLite，服务端口 8080。
