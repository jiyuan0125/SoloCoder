连接池系统的管理后台，Go 标准库。

管理到一组后端服务的连接池，每个连接池有最大连接数、空闲超时和最大存活时间配置。获取连接时如果池中有空闲连接直接返回，没有的话在未超过上限时创建新连接，超过上限时等待其他连接释放，等待超时返回 503 和当前池状态。连接使用完后归还到池中，空闲超过指定时间的连接自动关闭。创建连接池时最大连接数为 0 或负数返回 400。

定期检查连接的健康状态，不健康的连接从池中移除并补充新连接，健康检查失败的连接不能归还给请求方。连接池的状态（活跃数、空闲数、等待数）通过 API 可查，查询不存在的连接池返回 404。连接池正在被使用时不能删除，删除返回 409。

总数修改后各子项的配额按比例重新调整。操作完成后自动更新关联的统计汇总，统计更新时重新读取同一批数据核对总数。数据存 SQLite，服务端口 8080。
