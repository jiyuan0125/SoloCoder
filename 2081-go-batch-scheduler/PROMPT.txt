用 Go 标准库 写一个批量调度系统。
用 Gin 写一个批量任务调度 API
提交一批任务（比如数据处理、文件转换），调度器分配给后台 worker 执行。Worker 数量可配置，默认 4 个
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
任务有优先级（高/中/低），优先级高的先分配
每个 worker 同时只处理一个任务，处理完一个再取下一个
任务执行有超时控制，超时的任务标记为失败
任务状态实时可查（排队/执行中/成功/失败）。失败的任务可以重试，重试次数有限
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
任务之间可能有依赖关系，前置任务完成后后置任务才能开始执行
调度器统计数据：总任务数、各状态数量、平均执行时间
数据存 SQLite，服务端口 8080。
