现在这块效率太低了，想做一个排行榜系统，Go 标准库。
用 Go 标准库写一个实时排行榜 HTTP 服务
多个玩家可以提交分数，系统维护分数排名。排行榜按分数降序排列，分数相同的按提交时间先后排名
完成后自动触发关联的数据更新，更新时也要访问同一批记录来校验一致性。
查询排行榜时返回前 N 名的玩家列表，包含排名、玩家 ID 和分数
可以查某个玩家的当前排名和分数
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
玩家提交新分数时，如果新分数高于已有分数则更新，否则忽略
多个玩家可能同时提交分数，排名计算要准确
排行榜支持多个维度（按日、按周、按总榜）
总金额调整后各阶段的计划金额按比例重新分配。
每隔一段时间自动清理过期的排行数据。历史最高分记录保留
数据存 SQLite，服务端口 8080。
