订单状态机系统的管理后台，Go 标准库。
用 Gin 写一个订单状态管理 API
订单状态：待支付→已支付→备货中→已发货→已签收→已完成。任何状态都可以发起取消
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
不同状态的取消规则不同：待支付直接取消，已支付需审批退款，备货中和已发货需退货
已签收的进入售后流程。售后分维修、换货、退款三种，每种售后有自己的状态流转
所有状态变更只能按定义的路径跳转，非法跳转要拦截
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
每次状态变更记录操作人、时间和原因
支持按当前状态筛选订单，也支持查询单个订单的完整状态变更历史
数据存 SQLite，服务端口 8080。
