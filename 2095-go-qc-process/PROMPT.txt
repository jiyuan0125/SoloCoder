用 Go + cobra 写一个质检流程系统。
用 cobra 写一个质检流程命令行工具
质检单状态：待抽样→抽样中→检测中→检测完成→合格/不合格→复检→终检→已归档
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
不合格的进入返工流程。抽样方案根据 AQL 标准确定抽检数量（输入批量大小和检验级别自动计算）
检测项目有标准值和允许偏差范围，检测结果记录实际值
不合格项需要记录不合格原因和严重程度（轻微/一般/严重）
严重不合格直接判定整批不合格。一般不合格可以申请复检，复检仍然不合格则判定为不合格
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
不合格批次关联返工工单，返工完成后重新质检。质检报告导出为 JSON 格式
质检数据存 JSON 文件，抽样标准配置存 YAML
做成命令行工具，编译成可执行文件。
