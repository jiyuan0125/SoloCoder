用 Go + cobra 写一个质检流程系统。

质检单状态：待抽样→抽样中→检测中→检测完成→合格/不合格→复检→终检→已归档，只能按顺序流转，跳步输出错误和当前状态。不合格的进入返工流程。抽样方案根据 AQL 标准确定抽检数量（输入批量大小和检验级别自动计算），批量为 0 或负数输出错误，检验级别不在标准范围内输出支持的级别列表。

检测项目有标准值和允许偏差范围，检测结果记录实际值，实际值超出偏差范围标记为不合格。不合格项需要记录不合格原因和严重程度（轻微/一般/严重），不记录原因输出错误。严重不合格直接判定整批不合格。一般不合格可以申请复检，复检仍然不合格则判定为不合格，复检最多一次。

不合格批次关联返工工单，返工完成后重新质检。质检报告导出为 JSON 格式，导出内容要和当前质检数据完全一致。质检数据存 JSON 文件，抽样标准配置存 YAML，YAML 格式错误输出错误行号。做成命令行工具，编译成可执行文件。
