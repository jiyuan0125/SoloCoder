现在这块效率太低了，想做一个用户评论系统，Go 标准库。
用 Go 标准库写一个用户评论系统 HTTP 服务
用户可以对文章发表评论，评论支持纯文本和富文本内容
评论列表有分页功能，支持按时间或点赞数排序
操作结束后自动通知关联模块更新缓存。
用户可以回复别人的评论，回复层级最多 3 层
每条评论显示用户昵称、头像、评论内容和发布时间
评论内容保存到数据库，列表查询时从数据库读取并渲染
总量更新后各细分的额度按比例重新分配。
管理员可以删除不当评论，删除后显示"该评论已删除"
支持搜索评论内容（输入关键词返回匹配的评论列表）
用户可以用昵称搜索其他用户的所有评论
数据存 SQLite，服务端口 8080。
