帮我做一套文件下载系统，Go 标准库。
用 Gin 写一个文件下载管理 API
用户上传文件到自己的目录，可以生成下载链接分享给其他人
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
文件按用户目录隔离存储。下载链接包含文件 ID，通过 API 接口获取文件内容
支持设置下载链接的过期时间和下载次数限制
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
管理员可以查看所有用户的文件列表和下载记录
文件上传支持批量操作，上传后返回文件 ID 列表
用户也可以通过路径参数指定要下载的文件（比如 /download/reports/2024/summary.pdf）
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
支持搜索文件名。文件存本地磁盘，元数据存
数据存 SQLite，服务端口 8080。
