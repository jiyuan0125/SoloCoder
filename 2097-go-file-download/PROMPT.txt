帮我做一套文件下载系统，Go 标准库。

用户上传文件到自己的目录，可以生成下载链接分享给其他人。文件按用户目录隔离存储，用户不能访问其他用户的目录，越权访问返回 403。下载链接包含文件 ID，通过 API 接口获取文件内容，链接过期或下载次数用完返回 410。上传文件名包含路径分隔符（.. 或 /）返回 400 防止路径遍历。单个文件上传上限 100MB，超限返回 413。

支持设置下载链接的过期时间和下载次数限制，过期时间为 0 或负数返回 400。管理员可以查看所有用户的文件列表和下载记录。文件上传支持批量操作，上传后返回文件 ID 列表，部分上传失败的不影响已成功的，返回 207 和每个文件的上传结果。用户也可以通过路径参数指定要下载的文件。

查询不存在的文件 ID 返回 404。支持搜索文件名，搜索无结果返回空列表。文件存本地磁盘，元数据存 SQLite。数据存 SQLite，服务端口 8080。
