业务那边提了个需求，要一套API聚合系统，Go 标准库。

用户配置一组外部 API 端点，聚合代理根据请求参数动态调用这些端点并合并结果返回。外部 API 地址格式不对返回 400，调用自己的内部地址返回 400 防止 SSRF。外部 API 调用支持设置超时和重试，超时时间最小 1 秒，重试次数上限 3 次。外部 API 不可达时返回 502 和失败的端点列表，部分成功部分失败时返回 207 和各端点结果。

响应缓存到本地，相同的请求在一定时间内直接返回缓存，缓存过期后重新调用。支持并发调用多个外部 API 然后合并结果，所有外部 API 都返回后才合并响应，不丢弃慢的请求。聚合结果按配置的格式组装（支持 JSON 合并、提取指定字段），格式配置不对返回 400。

确认操作时自动触发后续的数据校验，校验过程重新查询同一批记录汇总。总额变化后各分项按比例同步更新。调用的外部 API 地址和参数通过查询字符串传入。数据存 SQLite，服务端口 8080。
