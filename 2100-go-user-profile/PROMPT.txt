我们最近需要一套用户资料系统，用 Go 标准库 做。
用 Go 标准库写一个用户资料管理 HTTP 服务
用户可以编辑自己的个人资料，包括昵称、个人简介、联系方式和自定义头像
操作完成后自动更新关联的统计汇总，统计更新时也要读取同一批数据来核对总数。
个人简介支持多行文本，用户可以自由编辑内容
每个用户有唯一的用户 ID，通过 URL 路径参数访问用户资料页（/profile/{id}）
用户可以查看其他用户的公开资料
主操作成功后自动更新关联的统计信息。
资料修改历史保留，可以查看某个用户的所有修改记录
管理员可以查看所有用户的资料和修改历史
支持批量查询多个用户的资料（传入一组用户 ID）
总数修改后各子项的配额按比例重新调整。
用户可以通过邮箱或手机号搜索其他用户
数据存 SQLite，服务端口 8080。
