我们做一个面向全球用户的 SaaS 产品，需要支持多语言界面。后台管理界面目前支持中文、英文、日文、韩文四种语言，以后可能还会加更多。产品里的文案分布在很多地方：按钮文字、提示信息、表单标签、错误消息、邮件模板、帮助文档等。产品迭代很快，每次发版都可能新增或修改几十条文案。现在的问题是翻译人员给的是 Excel 表格，开发人员要手动把翻译复制到代码里对应的位置，容易漏掉或者复制错位。帮我用 Go 写一套多语言文案管理方案。开发人员在代码里用 key 引用文案，比如 order.create.success 就对应「订单创建成功」。翻译人员维护 JSON 文件，每种语言一个文件，key 跟代码里保持一致。运行的时候根据用户选择的语言自动加载对应的翻译文件。如果某个 key 在当前语言文件里找不到，要有降级策略：先找英文版，英文也没有就直接用 key 本身作为兜底显示。另外要提供一个检测工具：扫描代码里用到的所有 key，跟翻译文件对比，列出翻译文件里多余的 key（代码里没用到，可能是废弃文案）和缺失的 key（代码里用了但翻译文件里没有，会导致用户看到原始 key）。帮我用 Go 实现。

代码按功能模块分文件组织——多语言加载与切换、翻译缺失检测与降级、文案键扫描工具各自独立文件。go build 能过。
