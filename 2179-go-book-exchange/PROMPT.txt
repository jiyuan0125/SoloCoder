用 Go 标准库 写一个图书交换系统。
用 Gin 框架写一个图书漂流站管理服务
社区设有多个图书漂流点，居民可以把看过的书放到漂流点，也可以从漂流点取走想看的书。漂流点 ID 不存在返回 404。
每本书有 ISBN、书名、作者和当前所在漂流点
放书时扫码录入 ISBN，系统自动查书名作者（先从本地数据库查，查不到就用 Google Books API 补全信息）。ISBN 格式不合法返回 400（13 位数字或 10 位带校验位）。
取书时扫码记录取走时间和取书人。已经被取走的书不能重复取返回 409。被别人收藏的书不能取返回 400。
每本书的漂流历史都记录在案——谁在什么时候放到哪个漂流点，谁在什么时候取走
取走后有 30 天阅读期，到期后系统提醒还书。正在阅读中的书不能被其他人取走返回 409。
如果不想还了，可以标记为"已收藏"，这本书就从漂流池中移除。不在阅读状态的书不能收藏返回 400。
漂流点满了（每个漂流点最多放 50 本）就不能再放书了，返回 409 带当前数量和上限
每本书的漂流次数（被多少人取走过）可以查看
热门书（漂流次数超过 10 次的）自动推荐给新读者
用 encoding/json 处理 API 响应，用 regexp 做 ISBN 格式校验
提供放书、取书、查询漂流历史、推荐热门书的接口，书籍 ID 不存在返回 404
代码按模块分文件
数据存 SQLite，服务端口 8080。
