用 Gin 框架写一个图书漂流站管理服务。
社区设有多个图书漂流点，居民可以把看过的书放到漂流点，也可以从漂流点取走想看的书。
每本书有 ISBN、书名、作者和当前所在漂流点。
放书时扫码录入 ISBN，系统自动查书名作者（先从本地数据库查，查不到就用 Google Books API 补全信息）。
取书时扫码记录取走时间和取书人。
每本书的漂流历史都记录在案——谁在什么时候放到哪个漂流点，谁在什么时候取走。
取走后有 30 天阅读期，到期后系统提醒还书。
如果不想还了，可以标记为"已收藏"，这本书就从漂流池中移除。
漂流点满了（每个漂流点最多放 50 本）就不能再放书了。
每本书的漂流次数（被多少人取走过）可以查看。
热门书（漂流次数超过 10 次的）自动推荐给新读者。
用 encoding/json 处理 API 响应，用 regexp 做 ISBN 格式校验。
提供放书、取书、查询漂流历史、推荐热门书的接口。
代码按模块分文件。
SQLite 存储，8080 端口。
