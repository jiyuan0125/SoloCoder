业务那边提了个需求，要一套加班审批系统，Go 标准库。
用 Go 标准库写一个加班审批服务
员工提交加班申请后走审批流程。审批通过后算有效加班，未审批或审批中的不算。月加班超过一定时长的需要额外审批。申请时加班时长为 0 或负数返回 400。开始时间晚于结束时间返回 400。
审批人可以同意也可以驳回，驳回后申请人可以修改再提交。申请人也可以撤销还没审批完的申请。已审批完的不能撤销返回 400。加班申请状态按 待审批→已通过→已驳回→已撤销 流转。
超过一段时间没审批的自动催一下审批人。审批记录要保留完整历史，每次审批操作都记录时间、审批人和结果。
加班时长统计按月汇总，超过法定上限的生成预警。加班费计算规则根据加班类型（工作日、周末、节假日）有所不同，具体倍数按公司制度执行。金额以分为单位存储。
员工 ID 不存在返回 404。申请 ID 不存在返回 404。重复提交同一天同一时段的加班申请返回 409。
审批记录要保留完整历史
数据存 SQLite，服务端口 8080。
