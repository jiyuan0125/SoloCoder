现在这块效率太低了，想做一个贷款审批系统，Go 标准库。
用 Go 标准库写一个贷款审批服务
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
贷款申请状态：提交、初审、复审、终审、放款、驳回、撤回。初审看征信和基本资质，复审看收入证明和抵押物，终审看综合情况。月薪 3 万以下初审员审批，3-5 万需要主管审批，5 万以上需要总监审批
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
任何环节驳回后申请人可以补充材料重新提交（回到初审状态）。提交后 2 小时内可以撤回。放款前要校验审批记录是否完整，任何环节缺失都不能放款。每个审批操作记录审批人、时间和意见
接口设计要合理，错误情况返回合适的 HTTP 状态码
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
数据存 SQLite，服务端口 8080。
