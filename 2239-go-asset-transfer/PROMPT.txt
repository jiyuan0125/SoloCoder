最近在搞这块业务，需要一个资产调拨系统，Go 标准库 实现。
用 Go 标准库写一个资产调拨服务，代码至少分 3 个文件
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
一个文件管理资产台账（资产编号、名称、分类、原值、当前净值），一个文件管理部门信息和使用人，一个文件管理调拨记录。调拨文件要同时关联资产文件和部门文件
资产调拨时净值按月折旧计算（直线法，残值率 5%）。调出部门要确认资产状态，调入部门要确认接收。调拨过程中资产状态变为"在途"，在途资产不参与折旧计算。历史调拨记录不可删除，只能查询
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
接口设计要合理，错误情况返回合适的 HTTP 状态码
数据存 SQLite，服务端口 8080。
