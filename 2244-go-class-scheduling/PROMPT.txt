帮我做一套班级排课系统，Go 标准库。
用 Go 标准库写一个排课服务
每学期要给每个班级安排课程表。课程有学分和学时要求，每周的课时数和学分对应。教师有可用时间段，同一教师在同一时间只能上一门课，冲突返回 409 带冲突信息。教室有容量，选课人数不能超过教室容量，超过返回 400 带上限。
有些课有先后依赖关系（比如先修课），先修课未排在前面返回 400。体育课不能排在上午第一节，排了返回 400。实验室课要在有实验设备的教室上，设备不匹配返回 400。排课结果可以手动微调。
班级 ID 不存在返回 404。教师 ID 不存在返回 404。教室 ID 不存在返回 404。课程 ID 不存在返回 404。
排课状态按 待排→已排→已发布 流转，已发布的不允许修改返回 400。
数据存 SQLite，服务端口 8080。
