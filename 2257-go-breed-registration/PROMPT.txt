现在这块效率太低了，想做一个品种登记系统，Go 标准库。
一个文件管理品种基础信息（品种名、分类、产地、特征描述），一个文件管理个体档案（个体编号、品种、出生日期、父母编号），一个文件管理血统证书和查询。血统文件要追溯个体档案中的父母关系。
同一个体编号不能重复登记，重复提交返回 409。血统证书可以向上追溯三代（父母、祖父母、曾祖父母）。每代个体信息缺失的标注为"未知"。证书生成后内容不可修改，尝试修改已出证的记录返回 400，如果登记信息有误需要重新出证。
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。不存在的品种 ID 或个体 ID 返回 404。父母编号指向不存在的个体时登记仍然允许但标注为"外部个体"。
流程走草稿→审批→执行→确认→关闭，只能按顺序往下走，草稿直接跳到确认返回 400。中间可以退回上一步。
数据存 SQLite，服务端口 8080。
