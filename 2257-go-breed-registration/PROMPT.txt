现在这块效率太低了，想做一个品种登记系统，Go 标准库。
用 Gin 框架写一个品种登记服务，代码至少分 3 个文件
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
一个文件管理品种基础信息（品种名、分类、产地、特征描述），一个文件管理个体档案（个体编号、品种、出生日期、父母编号），一个文件管理血统证书和查询。血统文件要追溯个体档案中的父母关系
同一个体编号不能重复登记。血统证书可以向上追溯三代（父母、祖父母、曾祖父母）。每代个体信息缺失的标注为"未知"。证书生成后内容不可修改，如果登记信息有误需要重新出证
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
接口设计要合理，错误情况返回合适的 HTTP 状态码
数据存 SQLite，服务端口 8080。
