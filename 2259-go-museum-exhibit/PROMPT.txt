业务那边提了个需求，要一套博物馆展品系统，Go 标准库。
博物馆有多个展厅，每个展厅有多个展柜，每个展柜里有多件展品。展品有基本描述信息。展品可以在不同展厅之间调展，调展期间展品状态标记为"布展中"，布展完成变为"展出中"。调展时源展柜释放和目标展柜占用要么都成功要么都失败，不能出现展品在两个展柜都不在的情况。
有些展品是借展的，有借展期限，到期前需要归还或续借。系统定期检查借展到期情况并提醒。参观者可以通过扫码获取展品介绍。借展到期未归还的展品状态自动变为"待归还"，不能继续调展，尝试调展返回 409。
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。不存在的展厅、展柜或展品 ID 返回 404。布展中的展品不能再发起第二次调展，返回 409 和当前状态。
数据存 SQLite，服务端口 8080。
