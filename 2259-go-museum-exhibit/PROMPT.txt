业务那边提了个需求，要一套博物馆展品系统，Go 标准库。
用 Gin 框架写一个展品管理服务
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
博物馆有多个展厅，每个展厅有多个展柜，每个展柜里有多件展品。展品有基本描述信息。展品可以在不同展厅之间调展，调展期间展品状态标记为"布展中"，布展完成变为"展出中"
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
有些展品是借展的，有借展期限，到期前需要归还或续借。系统定期检查借展到期情况并提醒。参观者可以通过扫码获取展品介绍
接口设计要合理，错误情况返回合适的 HTTP 状态码
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
数据存 SQLite，服务端口 8080。
