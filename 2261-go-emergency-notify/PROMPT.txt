我们最近需要一套应急通知系统，用 Go 标准库 做。
用 Gin 框架写一个应急通知服务
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
发生紧急事件时向相关人员发送通知。通知方式支持短信、邮件、App推送（用 HTTP 模拟发送，不实际调用第三方）。通知模板支持变量替换（比如 {name}、{location}、{time}）
事件分级别：一般、较大、重大、特别重大。不同级别通知不同范围的人员，特别重大事件通知全部人员。使用 Go 标准库的 text/template 做模板渲染。通知记录导出支持 XML 格式（使用 encoding/xml）
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
接口设计要合理，错误情况返回合适的 HTTP 状态码
数据存 SQLite，服务端口 8080。
