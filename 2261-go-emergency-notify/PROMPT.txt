我们最近需要一套应急通知系统，用 Go 标准库 做。
发生紧急事件时向相关人员发送通知。通知方式支持短信、邮件、App推送（用 HTTP 模拟发送，不实际调用第三方）。通知模板支持变量替换（比如 {name}、{location}、{time}），模板中变量找不到值时保留原始占位符不报错。
事件分级别：一般、较大、重大、特别重大。不同级别通知不同范围的人员，特别重大事件通知全部人员。使用 Go 标准库的 text/template 做模板渲染。通知记录导出支持 XML 格式（使用 encoding/xml）。不存在的模板 ID 返回 404，事件级别不合法返回 400。
发送通知失败时不阻断其他人的通知发送，已发送成功的记录保留，失败的记录标记为"发送失败"和原因。通知发送和事件状态变更要么都完成要么都不变更。
数据存 SQLite，服务端口 8080。
