酒窖管理系统的管理后台，Go 标准库。
用 Gin 框架写一个酒窖管理服务
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
每瓶酒有品种、产区、年份、入库日期、购入价格。酒有适饮期（开始年份到结束年份），在适饮期内品质最佳。入库后酒的估值按年份变化，老年份的酒可能升值也可能贬值
出库时选择具体瓶号，系统记录出库时间和用途（自饮、送人、出售）。出售价格和购入价格的差额计入盈亏。按月统计酒窖的总估值变动。同一瓶酒出库后不能再入库（消耗品）
接口设计要合理，错误情况返回合适的 HTTP 状态码
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
金额以分存储
数据存 SQLite，服务端口 8080。
