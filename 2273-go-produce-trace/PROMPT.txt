业务那边提了个需求，要一套农产品追溯系统，Go 标准库。
用 Gin 框架写一个农产品溯源服务
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
农产品从种植到销售要记录每个环节的信息：种植地块、施肥记录、采摘批次、加工记录、运输信息、销售终端。消费者通过批次号查询完整的溯源链条
溯源信息通过 HTTP 接口录入，录入时传入操作人信息和操作详情。查询接口通过 URL 路径传入批次号查询。管理后台可以通过接口查看所有批次的详细信息，包括操作人的身份信息
流程按申请→初审→复审→批准→完成推进。每步有对应负责人。
接口设计要合理，错误情况返回合适的 HTTP 状态码
数据存 SQLite，服务端口 8080。
