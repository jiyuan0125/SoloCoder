最近在搞这块业务，需要一个KTV包间系统，Go + cobra 实现。
用 cobra 写一个KTV包厢管理命令行工具
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
包厢有大小之分（小包、中包、大包、VIP包），不同时段价格不同（下午场便宜、晚场贵）。包厢按小时计费，不足半小时按半小时算。消费金额包括包厢费、酒水和小食
酒水和小食有库存，下单时检查库存。开卡时最低消费额度根据包厢类型不同。结账时包厢费加酒水消费，超过最低消费按实际算，没超过按最低消费收。VIP包有会员折扣，折扣和最低消费取金额高的那个
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
接口设计要合理，错误情况返回合适的 HTTP 状态码
金额以分运算。数据存 JSON 文件
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
