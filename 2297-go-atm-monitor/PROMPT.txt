ATM监控系统的管理后台，Go + cobra。
用 cobra 写一个 ATM 运维监控命令行工具，代码至少分 3 个文件
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
一个文件管理 ATM 设备信息（编号、位置、型号、投币量），一个文件管理故障工单（故障类型、上报时间、处理状态、维修记录），一个文件负责巡检计划和统计。巡检文件要关联设备信息
设备有巡检周期（每天、每周、每月），不同型号周期不同。故障工单有优先级（紧急、高、中、低），紧急工单 2 小时内响应。统计汇总各区域设备可用率、平均故障修复时间、故障类型分布。巡检和维修记录都不可删除
接口设计要合理，错误情况返回合适的 HTTP 状态码
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
数据存 JSON 文件
做成命令行工具，编译成可执行文件。
