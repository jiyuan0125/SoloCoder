帮我做一套宠物美容系统，Go 标准库。
用 Go 标准库写一个宠物美容店管理 API
美容项目分洗澡、修剪、全套三种，价格分别是 80、120、200 元
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
超过 15 公斤的大型犬每项加收 50%。会员享 8 折，折扣在加收之后计算
同一只宠物 3 天内不能重复预约同一项目
预约后 2 小时内可免费取消，之后取消收 30% 费用
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
每天每个美容师最多安排 8 个预约
每个预约按项目类型估算时长（洗澡 1 小时、修剪 1.5 小时、全套 2.5 小时）
美容师同一时段不能重叠，所有金额以分为单位存储运算
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
HTTP API
数据存 SQLite，服务端口 8080。
