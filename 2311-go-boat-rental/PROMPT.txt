船只租赁系统的管理后台，Go 标准库。
用 Go 标准库写一个船只租赁管理 API
船只分皮划艇、帆船、快艇三种，小时单价分别是 50、200、500 元
租赁按整小时计费，不足 1 小时按 1 小时算
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
节假日价格翻倍，翻倍后的金额需向下取整到元
同一艘船同一时段不能重复出租
还船时如果超时不超过 15 分钟不额外收费，超过 15 分钟按一个完整小时计费
押金根据船型和租赁时长计算，皮划艇 200 元起，帆船 1000 元起，快艇 2000 元起
接口按资源层级组织：查看所有记录、查看某条记录、查看该记录下的操作历史、给操作添加备注。
每超 1 小时加收对应小时单价作为押金
支持查询某艘船在指定日期的租赁记录和收入统计
金额以分为单位存储。HTTP API
数据存 SQLite，服务端口 8080。
