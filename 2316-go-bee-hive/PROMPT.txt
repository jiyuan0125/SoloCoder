最近在搞这块业务，需要一个蜂箱管理系统，Go 标准库 实现。
用 Go 标准库写一个蜂箱管理 API
每个蜂箱有编号、放置位置、蜂种、安置日期
处理完成后自动汇总到对应的报表，汇总时也要扫描同一批记录来核实。
日常检查记录蜂群状态（强、中、弱）、蜜蜂数量（框数）、蜂王状态（在、失王、新王）、是否有病虫害
同一蜂箱 7 天内多次检查只记录最新状态，但保留历史
当连续两次检查蜂群状态都为"弱"且蜂王失王时，自动标记该蜂箱为"需介入"
操作结束后自动通知关联模块更新缓存。
蜂箱与蜜源区域关联，同一区域的蜂箱数量不能超过 30 个
采蜜记录要关联到具体蜂箱和日期
同一蜂箱同一季度的采蜜总量自动汇总
总量更新后各细分的额度按比例重新分配。
HTTP API
数据存 SQLite，服务端口 8080。
