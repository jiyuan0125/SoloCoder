我们最近需要一套陶艺课系统，用 Go 标准库 做。
用 Go 标准库写一个陶艺课预约 API
课程分拉坯体验课（2 小时、150 元）、手捏课（3 小时、200 元）、上釉课（2 小时、180 元）三种
每节课限 8 人，预约时自动检查人数
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
每个课程时段之间留 30 分钟缓冲用于清理场地
同一学员同一周最多预约 3 次
取消预约需提前 6 小时，6 小时内取消扣 50% 费用
体验课完成的作品如果需要烧制另收 30 元/件
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
烧制周期 7 天，烧制完成后学员会收到通知
支持查询指定日期的排课情况和剩余名额
金额以分为单位存储。HTTP API
数据存 SQLite，服务端口 8080。
