帮我做一套生态瓶系统，Go 标准库。
用 Go 标准库写一个生态瓶（微缩生态缸）制作管理 API
每个生态瓶有编号、创建日期、容器大小、里面的植物和动物种类
确认操作时自动触发后续的数据校验，校验过程也要查询同一批记录来汇总。
系统跟踪每个生态瓶的环境参数：温度、湿度、光照时长、水位
不同动植物组合有不同的环境要求
如果某个生态瓶的环境参数超出了里面物种的耐受范围，系统需要给出提醒
完成后自动从关联模块同步最新状态。
动植物添加和移除都要记录时间
支持查看某个生态瓶的完整历史日志，包括环境变化和动植物变动
也可以查看所有生态瓶中某个物种的存活率统计
总额变化后各分项按比例同步更新。
HTTP API
数据存 SQLite，服务端口 8080。
