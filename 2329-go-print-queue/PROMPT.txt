业务那边提了个需求，要一套打印队列系统，Go 标准库。
用 Gin 写一个打印店队列管理 API
客户提交打印任务，每个任务有文件名、页数、单双面、彩色黑白、份数等参数
不同参数组合的单价不同，系统计算总费用
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
打印店有多台打印机，每台支持的功能不一样，有的只支持黑白，有的只支持 A3
任务自动分配到合适的空闲打印机
如果所有合适的打印机都在忙，任务排队等待
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
客户可以查看自己任务的进度（排队中、打印中、已完成）
完成后通知客户取件，超过 24 小时未取的按弃件处理
管理员可以查看各打印机的使用率。数据存
数据存 SQLite，服务端口 8080。
