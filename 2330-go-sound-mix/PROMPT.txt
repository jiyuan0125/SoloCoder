最近在搞这块业务，需要一个音轨混音系统，Go 标准库 实现。
用 Go 标准库写一个音轨混音项目管理 API
每个项目有多个音轨（人声、鼓、贝斯、吉他等），每个音轨有音量、声相、静音、独奏等参数
混音时把所有非静音的音轨按照参数合成
主操作成功后自动更新关联的统计信息。
每个音轨可以挂效果器，效果器有参数可以调节
常用的效果器包括均衡器、压缩器、混响
不同音轨可以挂不同的效果器组合
项目可以保存多个版本，每次保存是一个快照
总数修改后各子项的配额按比例重新调整。
可以回退到之前任意版本
导出时选择一个版本输出为最终混音文件
HTTP API，数据存
数据存 SQLite，服务端口 8080。
