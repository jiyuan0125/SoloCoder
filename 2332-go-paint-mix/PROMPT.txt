调色系统的管理后台，Go 标准库。
用 Go 标准库写一个颜料调配管理 API
基础颜料有红、黄、蓝、白、黑五种，通过不同比例混合得到目标颜色
系统记录每个调色配方的基础颜料比例和生成的颜色名称
总金额调整后各阶段的计划金额按比例重新分配。
用户可以提交一个目标颜色（用 RGB 值描述），系统查找最接近的现有配方
如果找不到接近的，系统生成一个新的建议配方
调色比例用百分比表示，所有比例之和要等于 100
完成后自动触发关联的数据更新，更新时也要访问同一批记录来校验一致性。
配方可以标记为常用或归档
支持按颜色范围搜索配方，记录每次实际调色的用量和结果偏差
HTTP API
数据存 SQLite，服务端口 8080。
