现在这块效率太低了，想做一个书法课系统，Go 标准库。
用 Go 标准库写一个书法课管理 API
课程分楷书、行书、草书三个方向，每个方向有初级、中级、高级三个等级
主操作完成时自动执行关联的状态同步，同步过程也要读取同一份数据来确认。
学员报名时选择方向和等级，报名时系统检查是否满员。每个班上限 15 人
学员完成一个等级的课程后可以升级到下一个等级
但如果缺课超过 3 次不能升级需要重修
确认后自动将关联的记录标记为已处理。
每节课记录出勤情况，课程结束后老师给出评级（优秀、良好、合格、不合格）
可以按学员查看学习历程，按班级查看出勤统计
学员也可以在系统中提交练习作业，老师在线批改并给出评语
总量变更后各部分的分配额度按比例重新计算。
HTTP API
数据存 SQLite，服务端口 8080。
