帮我做一套邮票收藏系统，Go + cobra。
用 Go 和 cobra 写一个邮票收藏管理命令行工具
每枚邮票记录国别、发行年份、面值、主题、品相（全新、极美、上品、中品）、编号
同一枚邮票可能有多张，用编号区分
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
支持按国别、年份范围、主题搜索
品相影响估值，系统根据同类邮票的市场参考价和品相等级给出估值范围
买卖记录也要管理，记录购入价、购入日期、卖出价、卖出日期
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
导出整个收藏为 JSON 文件
工具要有 add、search、trade、value、export 五个子命令
数据存本地 JSON 文件
做成命令行工具，编译成可执行文件。
