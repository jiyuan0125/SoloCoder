最近在搞这块业务，需要一个游艇租赁系统，Go 标准库 实现。
用 Go 标准库写一个游艇包租管理 API
用户提交包租订单时填写出行日期、人数、目的地、特殊要求（餐饮、娱乐设备等）
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
游艇有不同的载客量和设施配置
有时候用户填的人数是 0 或者负数，目的地是空白字符串
特殊要求里可能包含 HTML 标签或者超长文本
日期格式可能是 2024-1-1、2024/01/01、Jan 1 2024 等各种写法
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
包租时长可能跨午夜
同一艘游艇同一时段只能有一单
支持按游艇查排期，按客户查历史订单
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
订单状态有报价中、已确认、航行中、已完成、已取消
HTTP API
数据存 SQLite，服务端口 8080。
