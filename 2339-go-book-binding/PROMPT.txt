书籍装订系统的管理后台，Go 标准库。
用 Go 标准库写一个书籍装订单管理 API
装订方式有平装、精装、线装三种，每种方式有不同的工序和计价标准
客户提交装订需求时提供书名、页数、开本、装订方式、数量
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
客户有时候填的页数是奇数、0 或者超大数（比如 99999 页）
书名可能包含特殊 Unicode 字符或者超长
开本字段可能填的不是标准值，数量可能是 0 或者负数
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
装订方式可能拼写错误或不存在
精装书的工序最复杂，需要制壳、上胶、压平等多个步骤
支持按状态查询订单，按客户统计装订量。HTTP API
数据存 SQLite，服务端口 8080。
