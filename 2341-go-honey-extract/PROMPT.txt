现在这块效率太低了，想做一个蜂蜜提取系统，Go 标准库。
用 Go 标准库写一个蜂蜜采集管理 API
每次采蜜记录来源蜂箱编号、日期、重量（千克）、蜂蜜种类（百花蜜、槐花蜜、椴树蜜等）、水分含量
采蜜后的蜂蜜存入储罐，储罐有容量上限
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
传感器上报的水分含量可能是 0%、负数或超过 100%
重量可能为 0 或者是极大的值
同一批蜂蜜可能分多次灌入同一个储罐，储罐里的蜂蜜种类可能混合
接口按资源层级组织：查看所有记录、查看某条记录、查看该记录下的操作历史、给操作添加备注。
支持按种类查库存总量，按时间段查采蜜总量
蜂蜜价格随水分含量变化：水分低于 18% 是一等品价格最高，18-20% 是二等品，超过 20% 不建议出售
HTTP API
数据存 SQLite，服务端口 8080。
