帮我做一套皮革工艺系统，Go 标准库。
用 Gin 写一个皮具手工制品管理 API
每个作品记录使用的皮料种类（牛皮、羊皮、猪皮）、皮料面积（平方分米）、制作工时、作品类型（钱包、包、腰带、手环）
皮料库存要实时更新
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
客户订单可能一次订购大量同一款式（比如团购 200 个钱包），超过当前库存皮料量
皮料入库时可能录入的面积是 0 或者负数
同一批皮料可能分多次入库，每次的面积不一样
总金额调整后各阶段的计划金额按比例重新分配。
支持按作品类型查销量和用料统计
皮料价格随品种和厚度不同，计算成本时要精确到每个作品用了多少面积
HTTP API
数据存 SQLite，服务端口 8080。
