最近在搞这块业务，需要一个奶酪熟成系统，Go 标准库 实现。
用 Go 标准库写一个奶酪熟成管理 API
每批奶酪记录原料奶来源、制作日期、熟成天数、存储温度和湿度
总量变更后各部分的分配额度按比例重新计算。
不同种类的奶酪熟成周期不同：马苏里拉 1-3 天，切达 2-12 个月，帕尔马 12-36 个月
温湿度传感器有时候会上报极端值（温度 -40°C 或 200°C，湿度 150%）
一批奶酪可能中途转移存储位置，转移期间的温湿度数据可能有空缺
有些奶酪的熟成天数远超标准周期
主操作完成时自动执行关联的状态同步，同步过程也要读取同一份数据来确认。
支持按种类查询当前正在熟成的批次，按存储位置查询环境参数
到期提醒在熟成达到标准周期时触发。HTTP API
数据存 SQLite，服务端口 8080。
