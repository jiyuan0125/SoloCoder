我们最近需要一套粮仓管理系统，用 Go 标准库 做。
用 Go 标准库写一个粮仓管理 API
每个粮仓有容量上限（吨），记录当前存储的粮食品种和数量
粮食入库和出库都要记录日期、品种、数量、来源和去向
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
入库数量可能为 0 或者超过粮仓剩余容量
同一个粮仓可以存不同品种的粮食，但出库时必须按先进先出的顺序
传感器上报的温湿度数据可能缺失某些时间段
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
粮食存储超过安全存储期自动标记为待检测
检测合格的可以延期，不合格的标记为待处理
一次可能同时有几十个粮仓的数据需要更新。HTTP API
数据存 SQLite，服务端口 8080。
