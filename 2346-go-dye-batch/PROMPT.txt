染料批次系统的管理后台，Go 标准库。
用 Go 标准库写一个染色批次管理 API
每批染色任务记录使用的染料种类、染料用量、布料材质、布料重量、目标颜色、实际颜色
处理完成后自动汇总到对应的报表，汇总时也要扫描同一批记录来核实。
颜色用 RGB 或者 Lab 色彩空间表示
染料用量有时候记录为 0 或者负数
目标颜色和实际颜色的值可能超出 RGB 范围（比如负数或超过 255）
操作结束后自动通知关联模块更新缓存。
同一批染料可能用于多个染色任务，染料库存要实时更新
色差计算用 Delta E 公式，Delta E 超过 3 视觉上可感知差异
支持按时间段统计色差合格率，按染料统计用量
总量更新后各细分的额度按比例重新分配。
HTTP API
数据存 SQLite，服务端口 8080。
