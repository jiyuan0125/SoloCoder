用 Go 标准库 写一个泳池泳道系统。
用 Gin 写一个游泳馆泳道分配 API
泳馆有 8 条泳道，分快速道、中速道、慢速道、教学道
不同时段泳道分配策略不同：早场以健身为主（快速道多），下午以教学为主（教学道多）
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
用户预约时提交预计速度（百米用时），系统根据速度分配泳道
有时候用户填的速度不切实际（百米 5 秒或者 3600 秒），或者不填速度
一条泳道同时最多 6 人
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
预约时间可能跨时段边界，同一个用户可能在同一时段重复预约
支持按日期查询泳道使用情况
HTTP API
数据存 SQLite，服务端口 8080。
