帮我做一套象棋比赛系统，Go 标准库。
用 Go 标准库写一个棋类锦标赛管理 API
支持瑞士制和淘汰赛两种赛制，每轮比赛后更新积分排名
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
瑞士制按积分相近配对，淘汰赛按对阵表推进
选手注册时填写姓名、等级分、参赛组别
注册人数可能是 0 或者奇数，等级分可能是 0 或者负数
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
同组选手可能重名，一轮比赛中某些对局的结果可能晚于其他对局很久才录入
弃权的选手后续轮次自动判负
支持查询排名、对阵表、某位选手的比赛记录
比赛数据量可能很大（上千选手、十几轮）
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
HTTP API
数据存 SQLite，服务端口 8080。
