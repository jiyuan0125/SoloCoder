用 Go 标准库 写一个烟熏坊系统。
用 Go 标准库写一个熏制食品管理 API
分为原料入库、熏制工艺、成品出库三个模块
确认后自动将关联的记录标记为已处理。
入库模块记录肉类的来源、部位、重量、腌制配方和腌制时间
工艺模块管理不同的熏制方案：冷熏（20-30°C，数天）、温熏（30-50°C，数小时）、热熏（50-80°C，数小时）
熏制时需要关联入库模块的原料批次和工艺模块的方案
出库模块记录成品的重量（熏制后失重）、包装方式和质检结果
总量变更后各部分的分配额度按比例重新计算。
同一批原料可能分批熏制，成品重量需要汇总
工艺参数异常时暂停熏制并通知。HTTP API
数据存 SQLite，服务端口 8080。
