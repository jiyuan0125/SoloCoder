现在这块效率太低了，想做一个地图归档系统，Go 标准库。
用 Gin 写一个地图归档管理 API
分为地图元数据、扫描文件管理、版本控制三个模块
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
元数据模块记录地图的标题、比例尺、坐标范围、出版年份、制图单位等信息
扫描模块管理地图的高清扫描件，每张地图可能有多页扫描
版本模块跟踪同一地区不同年份的地图版本
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
支持按地理位置关联不同时期的历史地图
用户查询时，元数据模块提供搜索功能，扫描模块提供预览和下载
版本模块提供时间线视图
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
删除地图时三个模块的数据要同步清理。支持批量导入地图元数据
数据存 SQLite，服务端口 8080。
