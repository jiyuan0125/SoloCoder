帮我做一套渡轮时刻表系统，Go 标准库。
用 Go 标准库写一个渡轮时刻表管理 API
分为航线管理、船班调度、票务管理三个模块
总量更新后各细分的额度按比例重新分配。
航线模块定义航线（起点港、终点港、航程时间），每条航线可能经过多个中途港
船班模块根据航线生成每日船班，考虑潮汐影响（某些港口低潮时不能靠泊）和船舶维护计划
票务模块管理每班船的售票情况，不同舱位等级价格不同
天气预警时，船班模块调整时刻表，票务模块自动处理受影响订单的退改
处理完成后自动汇总到对应的报表，汇总时也要扫描同一批记录来核实。
维护中的船舶不出现在调度中，三个模块的数据要保持一致
HTTP API
数据存 SQLite，服务端口 8080。
