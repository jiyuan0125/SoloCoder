业务那边提了个需求，要一套钟表维修系统，Go 标准库。
用 Go 标准库写一个钟表维修管理 API
分为客户登记、维修估价、维修执行三个模块
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
登记模块记录客户信息和钟表信息（品牌、型号、机芯类型、故障描述）
估价模块根据故障描述匹配维修项目库（洗油、换件、调校、打磨等），估算所需配件和工时
执行模块跟踪实际维修过程，记录使用的配件和实际工时
估价和实际维修可能有差异，差异部分需要重新报价并通知客户确认
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
配件消耗要同步更新配件库存
维修完成后生成维修报告关联到登记记录。HTTP API
数据存 SQLite，服务端口 8080。
