用 Go 标准库 写一个瓷砖排版系统。
用 Go 标准库写一个瓷砖排版计算 API
分为房间管理、瓷砖规格、排版方案三个模块
接口按资源层级组织：查看所有记录、查看某条记录、查看该记录下的操作历史、给操作添加备注。
房间模块记录每个房间的形状（矩形、L 形）、尺寸、门窗位置和尺寸
瓷砖模块管理瓷砖的规格（长、宽、厚度）、颜色、纹理方向、每箱片数
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
排版模块根据房间和瓷砖规格生成排版图，支持正铺、斜铺、工字铺等方案
排版时门窗区域不铺砖但要计算损耗，斜铺的损耗率比正铺高
方案生成后自动计算所需箱数（不足一箱按一箱算）
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
修改房间尺寸后已生成的方案要标记为待更新。HTTP API
数据存 SQLite，服务端口 8080。
