业务那边提了个需求，要一套面包排产系统，Go 标准库。
用 Go 标准库写一个面包烘焙排期 API
分为配方管理、生产排期、库存销售三个模块
主操作完成时自动执行关联的状态同步，同步过程也要读取同一份数据来确认。
配方模块管理各种面包的配方（面粉、酵母、水、盐等比例）、发酵时间和烘焙温度
排期模块根据门店订单生成烘焙计划，每种面包有不同的制作时长（搅拌、发酵、整形、烘焙、冷却）
确认后自动将关联的记录标记为已处理。
库存模块跟踪成品库存和原料库存
面团需要提前准备（冷藏发酵 12-18 小时），排期时要倒推准备时间
门店的每日订单量不同，排期要根据库存动态调整烘焙量
总量变更后各部分的分配额度按比例重新计算。
销售数据反馈给排期模块优化下次的计划。HTTP API
数据存 SQLite，服务端口 8080。
