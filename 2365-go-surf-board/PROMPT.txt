最近在搞这块业务，需要一个冲浪板管理系统，Go 标准库 实现。
用 Gin 写一个冲浪板租赁管理 API
分为板型管理、租赁订单、维护记录三个模块
板型模块管理不同冲浪板的规格（长度、宽度、厚度、材质、适合浪型）
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
租赁模块处理租借和归还，根据用户体重和技能等级推荐合适的板型
维护模块记录冲浪板的检查、修补和退役情况
归还时检查板况，有损坏的记录到维护模块，维修期间不可出租
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
维护完成后板型状态更新为可用
累计修补次数超过限制的自动标记为退役
租赁费用根据板型和时长计算，损坏需额外收费
数据存 SQLite，服务端口 8080。
