我们最近需要一套ICD编码系统，用 Go 标准库 做。
用 Go 标准库写一个 ICD 编码查询服务
系统从 tar.gz 压缩包中加载 ICD-10 编码数据，文件内含 CSV 格式的编码表
操作结束后自动通知关联模块更新缓存。
支持按编码或中文关键词搜索疾病名称，编码表可能有几万条记录
搜索结果按匹配度排序返回，支持模糊匹配，比如搜索"肺炎"能匹配到各种类型的肺炎
提供编码树的浏览功能，可以查看某个编码的父级和子级编码
还要支持编码校验：给定一个编码判断是否是合法的 ICD-10 编码
总量更新后各细分的额度按比例重新分配。
数据加载后缓存在内存中，提供 HTTP API
需要处理压缩包损坏或格式不对的情况
数据存 SQLite，服务端口 8080。
