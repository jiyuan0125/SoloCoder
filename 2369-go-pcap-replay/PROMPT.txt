现在这块效率太低了，想做一个PCAP回放系统，Go 标准库。
读取 pcap 格式的文件，解析每个数据包的时间戳、源 IP、目标 IP、协议类型、包长度。pcap 文件头包含魔数、版本、链路类型等元信息，魔数不匹配返回 400 和文件格式说明。服务按原始时间间隔重放数据包（可选加速倍数），加速倍数为 0 或负数返回 400。
同时统计各协议的流量、每秒包数、Top 10 通信 IP 对。回放过程中实时显示统计数据，支持按 BPF 过滤规则筛选要回放的数据包，BPF 语法错误返回 400 和错误位置。提供 HTTP API 控制回放（开始、暂停、停止、跳转），查询实时统计。
需要正确处理 pcap 文件的大端和小端字节序。大文件流式读取。pcap 文件不存在返回 404。回放未开始时暂停或停止返回 400。查询统计为空时返回空数组不是 404。
数据存 SQLite，服务端口 8080。
