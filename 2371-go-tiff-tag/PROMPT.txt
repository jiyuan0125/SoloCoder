用 Go 标准库写一个 TIFF 图像文件标签读取服务。
TIFF 文件由文件头（字节序、魔数、偏移量）和多个 IFD（Image File Directory）组成。
每个 IFD 包含若干标签，标签有编号、类型、数量和值。

服务读取 TIFF 文件的所有 IFD 标签，以可读格式展示。
需要处理不同字节序（大端和小端），不同标签类型（BYTE、ASCII、SHORT、LONG、RATIONAL 等）。
有些标签值是指向文件其他位置的偏移量，需要跟随读取。

支持按标签编号查询，对比两个 TIFF 文件的标签差异。
提供 HTTP API，上传文件后返回解析结果。
需要用 compress/flate 处理可能存在的压缩数据。
