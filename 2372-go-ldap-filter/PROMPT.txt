最近在搞这块业务，需要一个LDAP过滤器系统，Go 标准库 实现。
用 Gin 写一个 LDAP 过滤器构建和解析服务
LDAP 过滤器有特定的字符串语法，如 (&(objectClass=user)(uid=john))
支持 AND、OR、NOT 逻辑操作和等于、近似、大于等于、小于等于、通配符等比较操作
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
服务提供两个方向的功能：一是把结构化的查询条件（JSON 格式）转换为 LDAP 过滤器字符串
二是把 LDAP 过滤器字符串解析为结构化的 JSON
解析时要处理嵌套逻辑、转义特殊字符（如括号、星号、反斜杠）
总金额调整后各阶段的计划金额按比例重新分配。
过滤器的嵌套层数可能很深
提供过滤器校验功能，判断语法是否合法
HTTP API，不涉及实际 LDAP 服务器连接
数据存 SQLite，服务端口 8080。
