用 Go 标准库 写一个SSH隧道池系统。
服务维护多个到远程服务器的 SSH 隧道
每个隧道有本地监听端口、远程目标地址和 SSH 服务器信息
客户端请求隧道时，从池中分配一个可用的隧道，用完归还，池满时返回 503 说明当前无可用隧道
隧道的创建使用 SSH 协议的端口转发功能
池中的隧道有健康检查机制，定期通过隧道发送测试请求，失败的重连
最大隧道数有上限，池满时新请求排队等待，超过最大数的创建请求返回 409
需要处理 SSH 连接的各种异常：认证失败、网络中断、远程端口被占用，认证失败的隧道标记为错误状态并返回 401
隧道的生命周期管理（创建、分配、回收、销毁）需要正确释放资源，销毁正在使用中的隧道返回 409
HTTP API 控制隧道池
数据存 SQLite，服务端口 8080。
