现在这块效率太低了，想做一个奖池系统，Go 标准库。
用户可以发起一个合买，设定总份额和每份价格，其他人可以购买份额，总份额或价格不合法（为零或负数）返回 400
一个合买满额后参与统一抽奖
抽奖结果从所有参与者中随机选出一人获得奖品，其余人获得参与奖，合买未满额时尝试抽奖返回 409
合买发起后所有人都能看到，多人可能同时抢购最后几个份额，不能出现超卖，超卖时返回 409
同一个人在同一个合买中可以买多份但不能超过总份额的 30%，超过限制返回 400
合买有截止时间，到期不满额自动退款
抽奖过程要公平透明，每期抽奖记录和参与者列表永久保留可审计，已抽过奖的合买不能再次抽奖返回 409
支持查询历史合买记录，查不到返回空列表而不是 404
HTTP API
数据存 SQLite，服务端口 8080。
