最近在搞这块业务，需要一个抢车位系统，Go 标准库 实现。
用 Go 标准库写一个抢车位服务
小区有固定数量的车位，车位状态有空闲和占用
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
用户离开车位时释放车位，其他用户可以抢占空闲车位
系统给每个用户分配一个车位使用凭证
早晚高峰时段大量用户同时查询和抢车位，不能出现一个车位同时被两个人抢到
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
用户持有车位有时间限制（比如最长 12 小时），超时自动释放但给用户一个 15 分钟的缓冲期
车位状态变更实时可查
支持查看当前空闲车位数量和自己的车位状态
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
所有车位变更记录保留。HTTP API
数据存 SQLite，服务端口 8080。
