实时投票系统的管理后台，Go 标准库。
用 Go 标准库写一个直播投票服务
主播在直播过程中发起投票，观众可以投票
投票有截止时间或截止票数，直播高峰期可能在几秒内涌入大量投票请求
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
每个观众对每个投票只能投一次票，重复投票应该被拒绝
投票计数要准确，最终公布的各选项票数之和必须等于总投票人数
投票结束后结果不可更改
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
支持实时查看当前投票进度（各选项票数，不显示谁投了什么）
主播可以同时发起多个投票
投票历史和结果永久保留。HTTP API
数据存 SQLite，服务端口 8080。
