现在这块效率太低了，想做一个协同编辑系统，Go + cobra。
多个用户可以同时编辑同一份文档的不同段落
文档按段落划分，每个段落有版本号
用户提交编辑时需要带上自己基于的版本号，缺少版本号返回 400
如果期间段落已被他人修改过，提示冲突让用户选择覆盖或合并，版本冲突时返回 409
工具后台跑一个本地 HTTP 服务，编辑器客户端通过 API 提交变更
同一个段落被多人同时编辑时，先提交的生效，后提交的收到冲突提示
支持查看段落的编辑历史和每个版本的作者，段落不存在时返回 404
文档可以回退到任意历史版本，版本号不存在时返回 404
工具要有 start（启动服务）、edit（提交编辑）、history（查看历史）三个子命令
做成命令行工具，编译成可执行文件。
