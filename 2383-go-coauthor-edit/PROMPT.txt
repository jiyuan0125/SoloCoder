现在这块效率太低了，想做一个协同编辑系统，Go + cobra。
用 Go 和 cobra 写一个协同文档编辑服务
多个用户可以同时编辑同一份文档的不同段落
文档按段落划分，每个段落有版本号
流程按申请→初审→复审→批准→完成推进。每步有对应负责人。
用户提交编辑时需要带上自己基于的版本号
如果期间段落已被他人修改过，提示冲突让用户选择覆盖或合并
工具后台跑一个本地 HTTP 服务，编辑器客户端通过 API 提交变更
同一个段落被多人同时编辑时，先提交的生效，后提交的收到冲突提示
每个操作有独立的接口路径：列表查询、详情查看、子项列表、子项操作。
支持查看段落的编辑历史和每个版本的作者
文档可以回退到任意历史版本
工具要有 start（启动服务）、edit（提交编辑）、history（查看历史）三个子命令
做成命令行工具，编译成可执行文件。
