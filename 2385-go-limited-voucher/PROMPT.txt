业务那边提了个需求，要一套限量券系统，Go 标准库。
用 Gin 写一个限量优惠券领取服务
商家发放限量优惠券（比如总共 1000 张），用户可以领取
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
领券高峰期可能几秒内被抢光
每个用户每种券只能领一张，重复领取应该被拒绝
券的库存不能出现负数
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
领取成功后给用户一个券码，券码在有效期内可用
部分券有使用门槛（满减条件），门槛信息在领取时就要展示
支持查询券的剩余数量、自己的券列表
过期未使用的券自动作废，作废的券不影响库存统计（因为已经领出去了）
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
HTTP API
数据存 SQLite，服务端口 8080。
