最近在搞这块业务，需要一个课程认证系统，Go 标准库 实现。
用 Go 标准库写一个培训认证管理 API
学员报名培训课程后经历：报名→学习→考试→评审→发证
报名阶段确认学员资格，部分课程有前置要求（必须先完成基础课程）
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
学习阶段跟踪课时完成情况，必须完成 80% 以上课时才能参加考试
考试不通过可以补考一次，补考还不通过需要重新学习
评审阶段综合学习表现和考试成绩给出等级（优秀、合格、不合格）
流程按申请→初审→复审→批准→完成推进。每步有对应负责人。
发证后证书有效期 2 年，到期前 60 天提醒续证
续证需要完成一定学时的继续教育
每个阶段的变更记录时间和经办人。HTTP API
数据存 SQLite，服务端口 8080。
