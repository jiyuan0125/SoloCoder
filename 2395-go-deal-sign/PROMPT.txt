签约管理系统的管理后台，Go 标准库。
用 Go 标准库写一个交易签约管理 API
交易从意向到达成经历：起草→法务审核→修改→会签→盖章→归档
起草阶段记录交易双方、金额、条款摘要
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
法务审核可以提出修改意见（退回起草阶段）或通过
修改阶段根据法务意见调整合同内容
会签阶段需要双方授权人依次签字，任何一方拒绝则交易终止
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
盖章是最后一步，需要公司公章和日期。归档后合同不可再修改
同一笔交易如果条款发生重大变更（金额变动超过 20%），已完成的会签作废需要重新走
合同编号按年份和序列号生成。HTTP API
数据存 SQLite，服务端口 8080。
