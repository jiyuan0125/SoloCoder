用 Go 标准库 写一个搜索报告系统。
用户可以通过输入关键词搜索报表，支持按日期范围、部门、报表类型筛选，日期格式不对返回 400
搜索结果返回匹配的报表列表，支持分页，没有匹配结果时返回空数组而不是 404
用户还可以自定义搜索条件，直接输入查询表达式来组合多个筛选条件
比如输入 "部门=销售部 AND 金额>10000" 这样的表达式来搜索，表达式语法错误返回 400
系统解析表达式后返回结果
每个报表有标题、内容摘要、创建时间、所属部门等字段
支持全文搜索标题和摘要，查询结果可以按相关度或时间排序
提供导出功能，支持导出为 JSON 格式。HTTP API
数据存 SQLite，服务端口 8080。
