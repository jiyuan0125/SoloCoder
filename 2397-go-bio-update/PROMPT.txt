现在这块效率太低了，想做一个履历更新系统，Go 标准库。
用 Gin 写一个简历信息更新 API
用户可以创建和更新自己的简历，简历包含姓名、联系方式、教育经历、工作经历、个人简介、技能标签等字段
各操作走不同的 URL 路径区分：列表、详情、关联列表、关联操作。
个人简介支持富文本内容
用户可以查看其他人的公开简历（姓名、工作经历、技能标签）
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
联系方式和个人简介对非本人不可见
简历有一个公开链接，用户可以分享给别人，访问公开链接时展示公开信息
管理员可以按条件搜索所有简历
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
简历更新时保留历史版本，支持上传头像图片
数据存 SQLite，服务端口 8080。
