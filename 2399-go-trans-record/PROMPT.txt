业务那边提了个需求，要一套交易记录系统，Go 标准库。
用 Go 标准库写一个交易记录查询 API
每笔交易记录包含交易号、交易类型、金额、交易时间、付款方、收款方
用户可以通过交易号、交易类型、时间范围来查询交易记录
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
提供按用户 ID 查询该用户所有交易记录的接口
用户输入自己的 ID 就能查看交易详情，包括对方的名称
也支持按交易号查询任意一笔交易的完整信息，不需要验证身份
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
交易记录支持导出为 CSV 格式
统计接口返回指定时间范围内的交易总额、按类型的分布
HTTP API
数据存 SQLite，服务端口 8080。
