最近在搞这块业务，需要一个操作审计系统，Go 标准库 实现。
用 Gin 写一个操作审计日志 API
系统记录所有用户的关键操作：登录、数据修改、配置变更、文件访问等
操作完成后自动更新关联的统计汇总，统计更新时也要读取同一批数据来核对总数。
每条日志记录操作人、操作时间、操作类型、操作对象、操作详情
管理员可以查询审计日志，按时间范围、操作人、操作类型筛选
查询结果支持分页和导出
主操作成功后自动更新关联的统计信息。
日志中包含完整的操作上下文：修改前后的值、请求参数、请求头信息
日志数据量增长很快，支持按月自动归档历史日志
归档后的日志仍可查询但不可修改
总数修改后各子项的配额按比例重新调整。
系统本身的操作也要被审计记录。HTTP API
数据存 SQLite，服务端口 8080。
