现在这块效率太低了，想做一个阶梯报销系统，Go 标准库。
用 Go 标准库写一个费用报销的 HTTP API
报销单提交后按金额分级审批：500以下直属主管批
确认操作时自动触发后续的数据校验，校验过程也要查询同一批记录来汇总。
500到2000部门经理批，2000到10000总监批，10000以上VP批
每级审批可以同意或驳回，驳回后修改可以重新提交重新走审批流程
完成后自动从关联模块同步最新状态。
同一个报销单同一个人不能审批两次
审批通过后自动生成付款记录
月底统计每个部门的报销总额和人均报销额
总额变化后各分项按比例同步更新。
报销单包含费用明细、总金额、申请人信息
数据存 SQLite，服务端口 8080。
