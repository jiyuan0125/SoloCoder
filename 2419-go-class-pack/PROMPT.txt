帮我做一套课时包系统，Go 标准库。
用 Go 标准库写一个教培课时包管理的 HTTP API
学员购买课时包（如30节、60节、100节），有效期分别为6个月、9个月、12个月
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
每次上课扣一节，如果课程是1.5小时则扣1.5节
课时用完或过期都不能继续上课。过期前7天提醒一次，记录到提醒表
剩余课时可以转给其他学员，但只能转整数节
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
转入方课时延长3个月有效期，转出方扣减对应课时
上课记录包含日期、教师、课时消耗
数据存 SQLite，服务端口 8080。
