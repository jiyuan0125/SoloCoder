我们公司需要一个简单的键值数据存储，类似一个轻量级的 Redis 但数据存放在本地文件上而不是内存里。支持基本的操作：设置一个键的值（SET）、获取一个键的值（GET）、删除一个键（DEL）、判断一个键是否存在（EXISTS）。值的类型支持字符串和整数，整数类型支持原子加操作（比如 INCR key 就是把值加 1，INCRBY key 10 就是加 10，如果键不存在就从 0 开始加）。所有写操作（SET、DEL、INCR）在修改内存中的数据之前，必须先把操作记录追加写入到一个日志文件里（顺序写入，每条记录包含操作类型、键、值、时间戳），然后再修改内存数据。这样即使程序突然崩溃了，重启后可以通过重放日志文件来恢复崩溃前的数据状态。日志文件不能无限增长，需要定期清理。清理的时机是：每隔 5 分钟把当前内存中的全部数据快照写入一个快照文件（snapshot.dat），写完之后就可以安全删除快照之前的所有旧日志了。快照写入过程中服务不能停止对外提供读写——用户仍然能正常 SET 和 GET。如果快照写到一半程序崩溃了，下次启动时必须能检测到这个快照文件是不完整的并忽略它，改用上一个完整的快照加上之后的日志来恢复。预期数据规模大概几十万个键，每个值不超过 1KB。用 Go 标准库实现。

代码按功能模块分文件组织——内存数据读写、操作日志追加与回放、定期快照与恢复、崩溃安全保护各自独立文件。go build 能过。
