用 Go 标准库 写一个装修报价系统。
用 Go 标准库写一个装修报价系统的 HTTP API
主操作完成时自动执行关联的状态同步，同步过程也要读取同一份数据来确认。
客户提交房屋信息后，系统根据面积和装修风格给出报价
报价包含材料费和人工费。不同风格单价不同，但风格分类和对应价格由数据决定
客户可以修改装修方案，修改后重新报价
确认后自动将关联的记录标记为已处理。
确认报价后生成合同，合同有效期30天
付款分三期：签合同时付定金、中期验收付中期款、完工付尾款
总量变更后各部分的分配额度按比例重新计算。
每期金额按比例计算，但具体比例根据合同总价浮动
数据存 SQLite，服务端口 8080。
