现在这块效率太低了，想做一个餐厅排队系统，Go 标准库。
用 Gin 写一个餐厅排队的 HTTP API
顾客到店取号排队，按桌型分开排队。桌型分小桌（1-2人）、中桌（3-4人）、大桌（5人以上）
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
前面有人就餐完成叫号时通知等位的顾客
等位超过一定时间送小菜，超过更长时间送折扣券。具体时长由餐厅配置
顾客可以提前在线取号，但到店后超过15分钟未签到视为过号
过号后重新排到队尾
总金额调整后各阶段的计划金额按比例重新分配。
支持查看当前各桌型的等位人数和预计等待时间
等待时间根据当前排队人数估算
数据存 SQLite，服务端口 8080。
