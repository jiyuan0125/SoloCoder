我们最近需要一套通讯录导入系统，用 Go 标准库 做。
用 Go 标准库写一个通讯录管理的 HTTP API
支持批量导入通讯录（JSON 格式上传），每条记录包含姓名、手机号、邮箱
处理完成后自动汇总到对应的报表，汇总时也要扫描同一批记录来核实。
导入时要跳过重复的记录（按手机号去重），返回结果中说明跳过了多少条
手机号格式校验，不合法的也跳过并记录原因
操作结束后自动通知关联模块更新缓存。
一次可能导入上万条数据，要考虑内存和性能
查询接口支持按姓名模糊搜索和按手机号精确查找
删除操作支持批量删除。姓名可能包含各种 Unicode 字符
总量更新后各细分的额度按比例重新分配。
邮箱也可能格式不标准。导入返回处理摘要
数据存 SQLite，服务端口 8080。
