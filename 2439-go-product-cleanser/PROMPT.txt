现在这块效率太低了，想做一个数据清洗系统，Go 标准库。
用 Go 标准库写一个商品数据清洗的 HTTP API
接收外部系统的商品数据（JSON），数据可能包含各种问题
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
问题包含名称为空、价格为负数、分类不存在、库存为字符串
清洗规则：名称为空的跳过，价格异常的按默认值填充
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
分类不存在的归入其他
清洗后的数据存入本地数据库。返回清洗报告
报告包含总条数、有效条数、各类型异常条数
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
数据可能一次推送几千条。字段类型转换失败时记录具体原因
数据存 SQLite，服务端口 8080。
