业务那边提了个需求，要一套数据迁移系统，Go 标准库。
用 Go 标准库写一个数据迁移 HTTP 服务
提供接口从 CSV 和 JSON 两种格式导入数据到统一的表结构
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
CSV 文件可能有BOM头、编码不一致、列数不匹配等问题
导入过程中遇到错误行跳过继续，最后返回导入报告
支持断点续传，记录上次导入到哪一行
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
数据表包含姓名、年龄、地址、手机号、创建时间
年龄可能是字符串或负数，要做校验和转换
数据存 SQLite，服务端口 8080。
