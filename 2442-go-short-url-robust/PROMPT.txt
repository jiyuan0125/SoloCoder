最近在搞这块业务，需要一个短链系统，Go 标准库 实现。
用 Go 标准库写一个短链接生成 HTTP 服务
用户提交长 URL 生成短链接。长 URL 可能缺少协议头、包含特殊字符、长度异常
完成后自动触发关联的数据更新，更新时也要访问同一批记录来校验一致性。
要能正确处理这些情况
短链接生成后支持跳转访问，记录访问次数和最后访问时间
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
同一个长 URL 生成同一个短链接（幂等）
短链接过期后访问返回过期提示而不是跳转
支持批量生成短链接，批量请求中重复的 URL 只生成一个
总金额调整后各阶段的计划金额按比例重新分配。
短链接码为6位字符（字母和数字）
数据存 SQLite，服务端口 8080。
