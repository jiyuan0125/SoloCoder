帮我做一套批量评分系统，Go 标准库。
用 Gin 写一个学生成绩批量录入的 HTTP API
教师上传 CSV 格式的成绩表（通过 multipart 表单上传），解析后批量入库
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
文件可能包含空行、成绩为文字描述等异常情况
成绩范围0到100，超出范围的标记为异常待人工处理
同一个学生同一科目的成绩取最新一次
录入完成后返回统计信息：总条数、成功数、异常数
流程走草稿→审批→执行→确认→关闭。中间可以退回上一步。
支持按班级和科目查询成绩
CSV 文件编码可能是 UTF-8 或 GBK
数据存 SQLite，服务端口 8080。
