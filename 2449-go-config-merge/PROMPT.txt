最近在搞这块业务，需要一个配置合并系统，Go + cobra 实现。
用 cobra 写一个配置文件合并命令行工具
支持合并多个 JSON 或 YAML 配置文件
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
规则：后面的文件覆盖前面的同名字段，数组类型直接替换而不是合并
文件可能不存在、格式错误、编码不一致
遇到错误要报告具体文件和位置，继续处理其他文件
输出合并结果到指定文件。支持 dry-run 模式只预览不写文件
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
合并后的配置可以做基本校验（必需字段是否存在）
支持嵌套对象的深度合并和浅合并两种模式
做成命令行工具，编译成可执行文件。
