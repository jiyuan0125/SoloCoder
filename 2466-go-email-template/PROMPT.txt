用 Go 标准库 写一个邮件模板系统。
用 Go 标准库写一个邮件模板渲染 HTTP 服务
模板使用 Go text/template 语法，支持条件判断、循环、自定义函数。模板语法错误返回 400 和错误位置。
自定义函数包含截断、日期格式化、金额格式化
模板变量从 JSON 数据注入。用 html/template 做 XSS 转义。注入数据缺少模板所需的变量返回 400 和缺失的变量名。
但允许部分 HTML 标签通过，白名单包含 b、i、a、p、br
模板预览接口渲染后返回 HTML。预览不存在的模板返回 404。
模板版本管理，修改后保留旧版本
批量渲染接口传入模板ID和数据列表，返回所有渲染结果。批量中单条数据渲染失败不影响其他条，失败的条目在结果中标注错误原因。查不存在的模板返回 404。
数据存 SQLite，服务端口 8080。
