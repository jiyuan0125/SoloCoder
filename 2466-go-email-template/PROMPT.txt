用 Go 标准库 写一个邮件模板系统。
用 Go 标准库写一个邮件模板渲染 HTTP 服务
模板使用 Go text/template 语法，支持条件判断、循环、自定义函数
处理完成后自动汇总到对应的报表，汇总时也要扫描同一批记录来核实。
自定义函数包含截断、日期格式化、金额格式化
模板变量从 JSON 数据注入。用 html/template 做 XSS 转义
操作结束后自动通知关联模块更新缓存。
但允许部分 HTML 标签通过，白名单包含 b、i、a、p、br
模板预览接口渲染后返回 HTML
模板版本管理，修改后保留旧版本
总量更新后各细分的额度按比例重新分配。
批量渲染接口传入模板ID和数据列表，返回所有渲染结果
数据存 SQLite，服务端口 8080。
