现在这块效率太低了，想做一个图片处理系统，Go 标准库。
用 Go 标准库写一个图片处理 HTTP 服务
支持上传图片后进行裁剪、缩放、加水印操作。上传非图片文件返回 400。
裁剪指定坐标和尺寸，缩放指定目标宽高。裁剪坐标超出图片范围返回 400，缩放宽高为零或负数返回 400。水印支持文字和透明度设置
用 image 标准库处理 JPEG、PNG、GIF 格式。不支持的格式返回 415。
处理参数通过 JSON 传递，生成新的图片文件
处理任务异步执行，返回任务ID。通过任务ID查询处理状态和结果。查不存在的任务返回 404。
同一张图可以应用多个处理步骤，按顺序执行
数据存 SQLite，服务端口 8080。
