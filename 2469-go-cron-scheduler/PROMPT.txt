业务那边提了个需求，要一套定时任务系统，Go 标准库。
用 Go 标准库写一个定时任务调度 HTTP 服务
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
支持 cron 表达式定义任务执行时间
任务类型包括 HTTP 回调、数据库查询、命令执行
用 robfig/cron 库解析表达式和调度
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
任务执行记录存数据库，包含开始时间、结束时间、状态、输出
任务可以暂停和恢复。失败任务支持配置重试次数和间隔
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
支持查看任务列表和执行历史。新添加的任务立即加入调度
数据存 SQLite，服务端口 8080。
