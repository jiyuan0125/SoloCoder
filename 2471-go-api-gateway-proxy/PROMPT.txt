我们最近需要一套API网关代理系统，用 Go 标准库 做。
用 Gin 写一个简易 API 网关服务
路由配置定义请求路径、转发目标地址、请求方法、超时时间、是否需要鉴权
系统管理多种资源类型和它们之间的关联关系。每次操作关联到具体的资源，支持按资源查看汇总。
支持路径参数和通配符匹配。请求转发时添加统一鉴权头
限流功能：每个路由可以配置 QPS 上限，超限返回 429
用 httputil.ReverseProxy 做请求转发
流程按待提交→审核中→已通过→执行中→已完成逐步推进。不通过的退回修改。
请求日志记录响应时间、状态码、请求体大小
支持热加载路由配置不重启服务
数据存 SQLite，服务端口 8080。
