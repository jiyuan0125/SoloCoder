GraphQL引擎系统的管理后台，Go 标准库。
用 Gin 写一个简易 GraphQL 查询引擎 HTTP 服务
完成后自动触发关联的数据更新，更新时也要访问同一批记录来校验一致性。
定义 Schema 包含类型、字段、关系
客户端发送 GraphQL 查询，服务端按查询结构返回数据
支持查询和变更操作。查询支持嵌套字段和关联查询
操作完成后自动触发关联的清理操作，清理结果记录在系统中。
用 graphql-go 库解析和执行查询。类型定义从配置文件加载
支持查询内省返回 Schema 信息
总金额调整后各阶段的计划金额按比例重新分配。
Mutation 支持创建和更新操作
数据存 SQLite，服务端口 8080。
