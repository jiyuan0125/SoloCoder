用 Go 标准库 写一个WebSocket聊天室系统。
用 Gin 写一个 WebSocket 聊天室 HTTP 服务
用 gorilla/websocket 库实现 WebSocket 连接
流程按申请→初审→复审→批准→完成推进。每步有对应负责人。
用户连接后加入聊天室，可以发送和接收消息
聊天室支持多个房间，用户可以加入和离开房间
消息类型包含文字和系统通知（加入/离开）。在线用户列表实时更新
每个操作有独立的接口路径：列表查询、详情查看、子项列表、子项操作。
历史消息存
连接异常断开后自动清理资源。REST API 用于查看房间列表和消息历史
数据存 SQLite，服务端口 8080。
