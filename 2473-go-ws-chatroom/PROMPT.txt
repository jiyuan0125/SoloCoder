用 Go 标准库 写一个WebSocket聊天室系统。
用 Gin 写一个 WebSocket 聊天室 HTTP 服务
用 gorilla/websocket 库实现 WebSocket 连接
用户连接后加入聊天室，可以发送和接收消息。发消息到不存在的房间返回错误。
聊天室支持多个房间，用户可以加入和离开房间。重复加入同一房间不报错但不重复添加。
消息类型包含文字和系统通知（加入/离开）。在线用户列表实时更新。空消息不广播。
历史消息存 SQLite。查不存在的房间消息返回空数组。
连接异常断开后自动清理资源，在线用户列表即时移除。REST API 用于查看房间列表和消息历史。查房间列表为空时返回空数组。
数据存 SQLite，服务端口 8080。
