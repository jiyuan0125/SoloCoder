帮我做一套数据库迁移系统，Go + cobra。
用 cobra 写一个数据库 Schema 迁移命令行工具
迁移脚本用 SQL 文件编写，文件名包含版本号和描述
操作通过 URL 路径区分不同层级：集合、单个资源、子集合、子资源操作。
用 golang-migrate 库管理版本。支持 up 和 down 操作
迁移记录存数据库跟踪当前版本
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
迁移脚本中可以包含事务，失败时自动回滚
支持 dry-run 模式只输出 SQL 不执行
配置文件指定数据库连接信息和迁移脚本目录
状态依次是待分配→处理中→待验收→已关闭。也可以转派给其他人。
支持查看迁移历史和当前版本。支持创建新的迁移脚本模板
做成命令行工具，编译成可执行文件。
