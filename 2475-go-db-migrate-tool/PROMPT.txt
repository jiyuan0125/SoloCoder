帮我做一套数据库迁移系统，Go + cobra。
用 cobra 写一个数据库 Schema 迁移命令行工具
迁移脚本用 SQL 文件编写，文件名包含版本号和描述。脚本目录不存在时给出错误提示。
用 golang-migrate 库管理版本。支持 up 和 down 操作。已经在最新版本时执行 up 给出提示，在初始版本时执行 down 给出提示。
迁移记录存数据库跟踪当前版本
迁移脚本中可以包含事务，失败时自动回滚。回滚失败时给出明确错误信息。
支持 dry-run 模式只输出 SQL 不执行
配置文件指定数据库连接信息和迁移脚本目录。数据库连不上时给出错误提示。
支持查看迁移历史和当前版本。支持创建新的迁移脚本模板
做成命令行工具，编译成可执行文件。
