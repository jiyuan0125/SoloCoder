我们公司的安全团队需要定期扫描内网服务器的端口开放情况，看看有没有不应该暴露在外的端口（比如数据库 3306、远程桌面 3389 等）。需要写一个端口扫描工具，支持以下使用方式：输入一个 IP 地址范围（比如 192.168.1.1 到 192.168.1.254）和要扫描的端口列表（比如 22, 80, 443, 3306, 6379, 8080），工具扫描这些 IP 上指定端口是否开放。扫描速度要快但要有节制——如果瞬间发出几万个探测包可能触发内部防火墙的告警甚至被自动封禁 IP。要能配置并发度参数控制同时有多少个探测在跑（默认 100 个并发）。扫描结果要包含：IP 地址、端口号、端口状态（开放/关闭/被过滤）、响应时间（毫秒）。扫描完成后生成一份汇总报告，列出所有开放的端口并用红色标注常见的高风险端口（维护一个内置的高风险端口列表：22=SSH、23=Telnet、445=SMB、1433=MSSQL、3306=MySQL、3389=RDP、5432=PostgreSQL、6379=Redis、9200=Elasticsearch 等）。支持从文本文件读取 IP 列表和端口列表（每行一个）。如果某个 IP 扫描超时了（默认 3 秒没响应），标记为「超时」而不是一直等着。扫描过程中终端要实时显示进度（已扫描 X/总共 Y）。如果用户中途按 Ctrl+C，要输出已经完成的扫描结果再退出，不能什么结果都不留。帮我用 Go 实现这个端口扫描工具。

代码按功能模块分文件组织——并发端口探测、扫描任务调度、结果汇总与报告生成、进度显示与中断处理各自独立文件。go build 能过。
