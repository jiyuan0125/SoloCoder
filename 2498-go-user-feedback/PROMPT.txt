最近在搞这块业务，需要一个用户反馈系统，Go 标准库 实现。
用 Gin 写一个用户反馈收集 API
用户提交反馈时填写标题、内容、联系方式和反馈类型（建议、投诉、咨询）。标题或内容为空返回 400。
管理员可以回复反馈和修改状态。修改不存在的反馈返回 404。
反馈列表支持按类型和状态筛选。筛选结果为空返回空数组。
用户可以通过自己的联系方式查看提交过的反馈。联系方式没记录过任何反馈返回空数组。
管理员界面可以导出反馈数据为 CSV
统计接口返回各类型反馈数量和平均处理时长。没有反馈数据时返回零值统计。
管理员的反馈列表展示用户的联系方式和反馈详情
数据存 SQLite，服务端口 8080。
