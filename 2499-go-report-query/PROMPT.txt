我们最近需要一套报表查询系统，用 Go + cobra 做。
用 cobra 写一个报表查询命令行工具
用户登录后可以查询各种报表：销售报表、库存报表、财务报表
API 按层级设计：查看列表、查看单个详情、单个下的子资源列表、修改子资源。
报表支持按日期范围和部门筛选
每个用户有自己的查询权限范围，普通用户只能查自己部门的数据
系统同时管理主实体和明细记录。明细的每次变动都关联到对应的主实体。
管理员可以查所有部门
报表结果支持输出到终端表格和导出为 CSV 文件
查询参数通过命令行 flag 指定
状态从新建→处理中→待确认→已完成变更。每步完成后进入下一步。
查询历史记录保存到数据库，支持查看和重新执行历史查询
做成命令行工具，编译成可执行文件。
