我们公司的运维团队经常需要做子网相关的计算。比如拿到一个 IP 地址 192.168.1.100 和子网掩码 255.255.255.0，要能快速算出：网络地址是 192.168.1.0、广播地址是 192.168.1.255、第一个可用 IP 是 192.168.1.1、最后一个可用 IP 是 192.168.1.254、可用主机数量是 254。有时候需要判断两个 IP 地址是否在同一个子网内。有时候需要把一个大网段拆分成几个小的子网——比如 10.0.0.0/24 拆成 4 个 /26 的子网。还要支持 CIDR 表示法输入（比如 192.168.1.0/24），也要支持传统的子网掩码格式输入（比如 192.168.1.0 255.255.255.0），两种格式要能互相转换。写一个命令行工具，运维输入一个 IP 或网段就能看到完整的子网信息。还支持网段合并：输入多个网段（比如 192.168.1.0/25 和 192.168.1.128/25），判断能否合并成一个更大的网段（192.168.1.0/24），能合并就输出合并结果，不能合并就说明原因。另一个实用功能是：给定一个 IP 地址列表（可能几万个 IP）和一组网段定义，快速判断每个 IP 属于哪个网段，IP 列表大的话遍历速度要快不能太慢。只支持 IPv4 不需要 IPv6。输入格式要宽容一些，掩码用 CIDR 或点分十进制都行，IP 地址前后的空格自动忽略。帮我用 Go 实现这个子网计算命令行工具。

代码按功能模块分文件组织——IP 与子网解析计算、网段拆分与合并、批量 IP 归属判断、命令行交互入口各自独立文件。go build 能过。
