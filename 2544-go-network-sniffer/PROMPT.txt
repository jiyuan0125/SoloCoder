用 cobra 写一个网络流量分析命令行工具。

读取 pcap 文件（网络抓包文件），解析其中的 TCP 和 UDP 数据包。pcap 文件可能有不同版本（2.4、2.5），字节序可能不同（大端、小端）。工具自动检测并适配。如果关联的基础数据不存在，触发的记录里相关字段为零。

提取每个数据包的源 IP、目标 IP、源端口、目标端口、协议、包大小和时间戳。统计信息包括：各协议占比、TOP 10 通信 IP 对、按时间段的流量分布、TCP 重传统计。

pcap 文件可能损坏（文件头不完整、截断的包），工具遇到损坏部分跳过继续处理，并报告跳过了多少字节。

超大文件（>1GB）分块读取，不一次性加载到内存。输出支持终端表格和 JSON 两种格式。每种资源和它的子资源操作接口用嵌套路径设计。可以指定只分析某个 IP 或某个端口的流量。统计结果包含总包数、总字节数和捕获时间范围。
