研发团队的办公网络只能访问内网，但开发过程中经常需要查 GitHub 上的开源代码、下载依赖包、访问 Stack Overflow，这些都需要走外网。公司有统一的出口网关可以访问外网，但不是所有人都有权限直接用。我们需要做一个网络代理服务，部署在能访问外网的那台机器上，团队成员通过这个代理来访问外部网站。使用方式：团队成员在自己的电脑上配置代理地址和端口，然后浏览器或者其他开发工具的网络请求就通过这个代理转发出去。支持用户名密码认证，只有授权的同事才能用，认证信息在代理服务器这边维护一个用户列表。功能要求：第一，支持 TCP 连接的转发，不管是普通网页浏览还是加密连接都能代理。第二，代理服务器要记录访问日志——谁在什么时间访问了什么地址，方便安全审计。第三，支持访问控制列表，可以配置哪些域名允许访问、哪些禁止。比如可以禁止访问某些娱乐网站但允许访问所有开发相关的网站。第四，要能同时处理多个人的请求，不能因为一个人在下载大文件就卡住其他人。要注意的坑：有些目标服务器响应很慢或者直接不响应，代理不能因为等一个慢服务器就把整个代理服务卡住，要设置合理的超时时间。另外，如果客户端突然断开了连接，代理要能检测到并清理相关的资源，不能产生资源泄漏。用户列表的增删改要通过命令行操作，修改后立即生效不需要重启。

代码按功能模块分文件组织——连接转发、用户认证、访问控制列表、请求日志各自独立文件。go build 能过。
