用 Go 标准库写一个建筑工地管理 HTTP 服务。

人员管理、物资管理、设备管理和进度管理四个模块。人员模块管理工人进场退场记录和特种作业资质。无资质的人员不能操作对应设备。物资模块管理建材的入库、领用和库存。

领用物资时进度模块记录用料量和工程进度。设备模块管理机械设备的租赁、维护和使用记录。设备需要定期维护，超期未维护的设备锁定不可使用。设备使用时关联操作人员，操作记录写入人员模块。

安全检查模块定期创建检查任务，检查结果关联到具体区域和负责人。发现问题生成整改工单，整改完成前该区域暂停施工。工程进度按天记录，可以和计划进度对比。各模块通过工单号、设备 ID 和人员 ID 关联。
数据存 SQLite，8080 端口。
