用 Gin 写一个 PCAP 网络包分析 API。

操作分提交、处理、审核、完成几个阶段，不通过可以退回上一步修改。

上传 pcap 文件后服务解析其中的数据包。使用 gopacket 库解析，提取以太网帧、IP 头、TCP/UDP 头和应用层数据。支持识别 HTTP 请求/响应、DNS 查询/响应、TLS 握手信息。

分析功能包括：TCP 流重组（把同一五元组的包按序列号排序重组为完整流）、HTTP 请求提取（方法、URL、Header、Body）、DNS 解析记录提取。统计各协议的流量占比和包数量。

pcap 文件可能包含多种链路层类型（Ethernet、Linux Cooked Capture、Raw IP），工具要根据文件头自动判断。支持 pcapng 格式。如果文件损坏，尽可能解析完好的部分。分析结果以 JSON 返回，大文件异步处理，通过任务 ID 查询进度。
基础配置数据被主业务流程引用。
数据存 SQLite。
