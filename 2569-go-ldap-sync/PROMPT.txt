用 Go 标准库写一个 LDAP 目录同步 HTTP 服务。

连接 LDAP 服务器（配置主机、端口、Base DN、绑定 DN 和密码），定期同步组织架构和人员信息。LDAP 查询使用标准库或 ldap 库，查询条件支持 LDAP 过滤器语法（如 (objectClass=person)、(&(department=IT)(title=*Manager*))）。

同步策略：增量同步按 modifyTimestamp 字段查变更，全量同步重建本地数据。同步后的数据存本地 SQLite。支持多 LDAP 源，每个源有独立的同步配置和调度。

字段映射可配置：LDAP 属性映射到本地字段（如 sAMAccountName → username、mail → email）。同步冲突处理：本地有 LDAP 无则标记为已删除，LDAP 有本地无则新增，两边都有则以 LDAP 为准。同步日志记录每次同步的新增、修改、删除数量。
8080 端口。
