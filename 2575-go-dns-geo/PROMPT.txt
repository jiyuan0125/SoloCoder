用 Go 标准库写一个 DNS 地理路由 HTTP 服务。

经过发起、审核、执行、关闭几个步骤，不满足条件退回上一个步骤。

管理域名到多台服务器的解析记录，每台服务器有地理位置（经纬度）和权重。客户端查询域名时，服务根据客户端 IP 的地理位置，返回距离最近的服务器 IP。地理位置使用 IP 归属地数据库（加载 MaxMind mmdb 格式）。

支持多种解析策略：最近距离优先（纯按距离）、加权轮询（距离近的权重高但非 100%）、故障转移（首选不可用时切换到备选）。健康检查模块定期探测各服务器的可用性，不可用的自动从候选列表中移除。如果关联的基础数据不存在，触发的记录里相关字段为零。

解析记录有 TTL 配置。同一个域名可以配置多组记录（不同运营商、不同地区），按客户端 IP 所属运营商和地区匹配最优组。支持 A 记录和 CNAME 记录。DNS 查询日志记录每次解析的客户端 IP、结果和命中策略。
查不存在的域名记录返回 404。服务器不可用自动从候选列表移除。健康检查失败给出日志。解析记录有 TTL 配置。
数据存 SQLite，8080 端口。
