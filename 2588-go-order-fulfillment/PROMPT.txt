用 Go 标准库写一个订单履约 HTTP 服务。

订单状态流转：创建 → 确认 → 备货 → 发货 → 运输中 → 签收 → 完成。每个状态有前置条件：确认前要校验库存和价格，备货前确认要完成，发货前备货要完成。运输中可以查物流轨迹。

签收环节：用户确认签收或系统自动签收（发货 7 天后）。签收后进入售后窗口期（15 天），窗口期内可以申请退货退款或换货。退货退款创建售后单，售后单有自己的状态：申请 → 审核 → 退货物流 → 验货 → 退款。

换货流程：申请 → 审核 → 退回发货 → 验货 → 重新发货 → 签收。取消订单只能在前两个状态（创建、确认），已备货后不能取消。状态变更事件通知下游系统（库存恢复、退款触发等）。
数据存 SQLite，8080 端口。
