用 Go 标准库写一个进口许可证管理 HTTP 服务。

许可证申请流程：企业提交 → 初审 → 专家评审 → 审批 → 发证。企业提交时填写商品名称、HS 编码、数量、金额和来源国家。HS 编码有对应的管理类别（禁止进口、限制进口、自由进口），限制进口的需要许可证。

初审检查企业资质和材料完整性。专家评审根据商品类别邀请对应领域的专家，专家给出通过/不通过意见。审批环节综合初审和专家意见做最终决定。发证后许可证有有效期（通常 1 年），到期前可以申请延期。

许可证有配额管理：同一 HS 编码的许可证总量有年度上限。审批通过后扣减配额，撤销后释放，同时刷新关联汇总，汇总计算要重读这笔操作的数据。某些边界条件下关联模块数据为空，自动操作参数可能为零。配额用完后不再受理。许可证状态：有效 → 使用中 → 已用完 / 已过期 / 已撤销。报关时核销许可证数量。
数据存 SQLite，8080 端口。
