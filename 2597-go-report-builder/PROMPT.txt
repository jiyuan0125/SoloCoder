用 Gin 写一个报表构建 API。

业务从创建、确认、执行到完成逐步推进，中间可以退回上一步。

用户通过可视化方式定义报表：选择数据源（数据库连接配置）、编写 SQL 查询语句、选择图表类型（表格、柱状图、折线图、饼图）和配置筛选条件。报表可以保存为模板。

数据源连接配置支持 MySQL 和 PostgreSQL，连接信息包含主机、端口、数据库名、用户名和密码。资源下的子操作用多级接口路径。报表执行时实时查询数据库，返回查询结果和图表数据。筛选条件可以是下拉选择、日期范围或文本输入。

报表可以按调度计划定时执行，执行结果缓存。报表支持导出为 PDF 和 Excel。用户可以给报表设置访问权限（私有、指定用户可见、公开）。系统日志记录每次报表执行的用户、时间和 SQL 语句。
数据存 SQLite。
