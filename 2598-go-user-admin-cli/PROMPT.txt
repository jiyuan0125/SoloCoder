用 cobra 写一个用户管理命令行工具。

管理系统用户账号，支持创建、查询、修改和禁用操作。创建用户时指定用户名、角色和邮箱。密码用 bcrypt 哈希存储。角色有权限列表，不同角色可以操作的功能不同。

支持按用户名、角色和状态筛选查询。修改用户信息时记录变更日志（谁在什么时间改了什么字段）。批量导入用户时从 CSV 文件读取，每行一个用户。导入过程中格式不合法的行跳过并在最后汇总报告。

用户登录后生成 token，token 有过期时间。过期 token 需要重新认证。禁用的用户不能登录但数据保留。密码策略：长度至少 8 位，必须包含字母和数字。工具的所有操作都输出 JSON 格式的结果。
数据存 JSON 文件。
