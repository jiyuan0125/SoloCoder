用 Go 标准库写一个文件分享 HTTP 服务。

经过发起、审核、执行、关闭几个步骤，不满足条件退回上一个步骤。

用户上传文件后生成分享链接，链接有提取码和有效期。其他人通过分享链接和提取码下载文件。下载时不要求登录，但记录下载次数和下载者的 IP 地址。

文件存储在服务器的指定目录下，文件名用 UUID 重命名避免冲突。上传文件大小限制 100MB。用户可以管理自己的分享：查看分享列表、修改有效期、取消分享。调整后相关的记录全部按新值更新。取消分享后链接失效但文件不删除。

分享链接格式：/s/{随机字符串}，随机字符串足够长不易猜测。文件类型不限制，用户上传什么就存什么。支持一次分享多个文件，多文件分享打包为 zip 下载。用户空间有容量上限（默认 1GB），超过后不能再上传。文件过期后自动清理磁盘空间。
数据存 SQLite，8080 端口。
