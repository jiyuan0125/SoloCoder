用 cobra 写一个数据查询命令行工具。

连接数据库执行用户输入的查询语句。支持 MySQL 和 SQLite 两种数据源，通过配置文件切换。用户在命令行直接输入 SQL 语句或指定保存的查询名称。

查询结果以表格形式输出到终端，支持导出为 CSV。常用查询可以保存为命名查询，保存时记录查询名称和 SQL 内容。执行命名查询时直接按名称调用。

参数化查询：SQL 中用 {{param}} 标记参数位置，执行时用户输入参数值。参数值直接替换到 SQL 中。查询历史记录每次执行的 SQL、参数、执行时间和结果行数。

工具支持批量执行：从一个 SQL 文件中读取多条语句依次执行。执行失败的语句不影响后续语句，最后汇总成功和失败的数量。
数据源配置存 JSON 文件。
