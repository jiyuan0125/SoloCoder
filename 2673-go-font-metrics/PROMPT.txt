字体度量的单位换算：内部使用字体单位（em），输出时可以转换为像素（给定 DPI）、点（pt）或毫米。
字体子集化的输出格式支持 WOFF2，用于 Web 字体优化。每种资源和它的子资源操作接口用嵌套路径设计。子集化后的文件大小相比原字体要小很多。

业务从创建、确认、执行到完成逐步推进，中间可以退回上一步。任务状态跳步时返回 400 和当前状态说明。

字体子集化生成的文件要确保不破坏字体的 hinting 信息，否则小字号渲染会模糊。生成的子集字体文件大小要显著小于原字体。
文本整形支持的水平书写系统包括：拉丁文、西里尔文、阿拉伯文、天城文。不同书写系统的整形规则不同，通过 OpenType 特性标签切换。
批量模式返回的排版对比数据包含：各字体的总宽度、平均字符宽度、行数（如果设了行宽限制）。数据用 JSON 格式返回。
用 Go + Gin 写一个字体度量计算服务。字体文件不存在时返回 404，文本为空时返回 400。加载 TrueType (.ttf) 或 OpenType (.otf) 字体文件，计算给定文本的排版度量：总宽度（advance width）、各字符的边界框（bounding box）、行高、基线位置。
支持字体子集化：从完整字体文件中提取指定字符集的子集，生成精简的字体文件。子集化时需要处理 cmap 表、glyf 表、loca 表等相关表的裁剪。
文本整形（text shaping）：处理合字（liga）、连写（kern）、阿拉伯文变形等 OpenType 特性。输入 Unicode 文本，输出经过整形后的字形序列和位置偏移。
支持多字体回退链：如果主字体缺少某个字符，自动从备用字体中查找。度量计算要考虑字体回退的影响。
批量模式：字体列表为空时返回 400。给定一段文本和多个字体，返回各字体下的排版对比数据。用 Go 实现。
