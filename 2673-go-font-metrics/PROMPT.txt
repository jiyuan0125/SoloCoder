用 Go + Gin 写一个字体度量计算服务。加载 TrueType (.ttf) 或 OpenType (.otf) 字体文件，计算给定文本的排版度量：总宽度（advance width）、各字符的边界框（bounding box）、行高、基线位置。内部使用字体单位（em），输出时可转换为像素（给定 DPI）、点（pt）或毫米。
支持字体子集化：从完整字体文件中提取指定字符集的子集，生成精简的字体文件，输出格式支持 WOFF2 用于 Web 字体优化。子集化时需要处理 cmap 表、glyf 表、loca 表等相关表的裁剪，要确保不破坏字体的 hinting 信息。
文本整形（text shaping）：处理合字（liga）、连写（kern）、阿拉伯文变形等 OpenType 特性，支持的水平书写系统包括拉丁文、西里尔文、阿拉伯文、天城文，通过 OpenType 特性标签切换。输入 Unicode 文本，输出经过整形后的字形序列和位置偏移。
支持多字体回退链：如果主字体缺少某个字符，自动从备用字体中查找，度量计算要考虑字体回退的影响。
批量模式：给定一段文本和多个字体，返回各字体下的排版对比数据（总宽度、平均字符宽度、行数），数据用 JSON 格式返回。
字体元数据查询：返回字体文件中的名称、版本、版权、字符集覆盖范围（Unicode 区间）等信息，方便用户选择合适的字体。
字形轮廓导出：支持将指定字符的矢量轮廓（贝塞尔曲线控制点）导出为 SVG path 数据，用于自定义渲染。
用 Go 实现。
