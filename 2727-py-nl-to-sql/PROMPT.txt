用 FastAPI 写个自然语言转 SQL 查询的服务。
用户输入中文描述（比如"查一下最近三个月销量前10的商品"），系统解析后生成 SQL 并执行。
数据库表结构需要提前注册，注册时要声明字段名、类型和中文别名。
返回查询结果的 JSON，最多返回500条记录。
用 Python 的 AST 模块做简单的语法解析，结合正则提取表名、字段名、条件。
不支持 JOIN 和子查询，只支持单表查询。
生成的 SQL 要做安全检查，只允许 SELECT 语句，包含 DROP、DELETE、UPDATE、INSERT 的直接拒绝。
用户输入中的表名和字段名要和注册的表结构匹配，不存在的表名或字段名不能拼进 SQL。
同一个用户10秒内最多查询5次。
查询历史要记录，支持回看之前查过的语句和结果。
自然语言解析、SQL 生成、查询执行分文件写。
SQLite 作为底层数据库。
