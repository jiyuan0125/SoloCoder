FastAPI 写一个定时任务调度引擎。
用户通过 API 注册定时任务，指定 cron 表达式和要调用的 HTTP 接口地址。
系统到时间了就去调用那个接口，用 APScheduler 做调度。
支持查看任务列表、手动触发、暂停/恢复任务，暂停期间的任务不执行但 cron 计算不暂停（恢复后按当前时间触发）。
任务执行结果记录下来（成功、失败、响应时间），同一个任务如果上一次还没执行完，新的触发要跳过。
任务执行超时设30秒，超时的任务标记为失败并记录。
连续失败5次的任务自动暂停，需要手动恢复。
cron 表达式要校验格式，不合法的拒绝注册。
任务注册、执行引擎、日志查询分文件写。
用 SQLite 存任务配置和执行日志。
