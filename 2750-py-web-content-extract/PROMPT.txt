Flask 写一个网页内容提取 API。
传入一个 URL，系统抓取网页后提取正文内容，去掉导航栏、广告、侧边栏等干扰元素。
提取的内容以纯文本和 HTML 两种格式返回，提取不到正文内容的返回错误提示。
有些网页可能是动态加载的（JS渲染），这种情况也返回错误提示。
支持设置超时时间，默认10秒，最长30秒。
抓取频率要做限制，同一域名1秒内只能请求一次。
同一个 URL 10分钟内重复请求直接返回缓存结果不重新抓取。
URL 格式要校验，必须是 http 或 https 开头。
只支持文本内容的网页，PDF 和二进制文件直接拒绝。
网页抓取、内容提取、缓存管理分文件写。
用 SQLite 记录抓取历史。
