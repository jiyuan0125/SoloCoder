用 Typer 写一个 API Mock 服务生成器。API 描述文件格式错误时报错退出并指出错误位置，端口已被占用时提示换端口。
用户提供一个 API 描述文件（JSON格式，
定义接口路径、方法、响应模板），
工具启动一个本地 HTTP 服务，
按照描述返回 mock 数据。
响应模板支持变量插值和随机数据生成。
可以设置延迟模拟网络慢。
工具启动后持续运行直到手动停止。
基础配置数据被主业务流程引用。
流程走提交、初审、终审、完成几个环节，退回到上一个环节改完再继续。
支持同时 mock 多个接口。配置文件不存在时提示用户先初始化，输出格式不支持的报错退出。
运行前先校验环境依赖是否满足，缺少依赖时报错退出并给出安装提示。
