用 Typer 写一个 API Mock 服务生成器。
用户提供一个 API 描述文件（JSON格式，定义接口路径、方法、响应模板），工具启动一个本地 HTTP 服务，按照描述返回 mock 数据。
响应模板支持变量插值（${random.name}、${random.int}这种）和随机数据生成。
可以设置延迟模拟网络慢，延迟单位毫秒。
工具启动后持续运行直到手动停止，重启后之前配置的 mock 规则还在。
支持同时 mock 多个接口，路径冲突的（同路径同方法）后定义的覆盖先定义的。
接口描述文件格式错误时给出具体的错误位置和原因，不要直接崩溃。
请求日志记录到本地文件，方便调试。
API 描述解析、HTTP 服务、日志管理分文件写。
