Click 写一个 JSON Schema 验证工具。
用户传入一个 JSON 文件和对应的 Schema 文件，工具验证 JSON 是否符合 Schema 定义，输出验证结果和不符合的字段路径。
Schema 可能引用外部定义（$ref），$ref 引用本地文件的要能正确解析。
大文件（几十MB）也要能在合理时间内验证完，用流式解析。
验证结果可以输出为报告文件（JSON格式），包含通过/失败状态、所有不符合字段的路径和具体原因。
同一个 JSON 文件如果多次验证用不同的 Schema，每次结果独立保存。
Schema 文件本身格式错误时给出错误提示而不是直接崩溃。
用 jsonschema 库。
JSON 解析、Schema 加载、报告生成分文件写。
