用 Typer 写一个 Markdown 文档站点生成工具。
命令行参数要有基本的校验和帮助信息。
source/ 目录下有多个 .md 文件和子目录，工具把它们转换成 HTML 文档站点，子目录结构映射到 URL 路径。
需要 doc_parser（解析 Markdown 和目录结构）、toc_generator（生成侧边栏目录导航）、html_builder（组装最终页面）三个模块。
支持代码高亮、内部链接（.md 链接转成 .html 链接）、图片引用。
常用选项可以放配置文件里（YAML格式），不用每次都在命令行指定。
生成的站点可以在浏览器直接打开，不依赖服务器。
Markdown 文件中如果有不可解析的语法，原样保留不崩溃。
同一层级下的 .md 文件按文件名排序生成导航。
配置加载、Markdown 解析、HTML 生成分文件写。
