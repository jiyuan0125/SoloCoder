用 Typer 写一个 Markdown 文档站点生成工具。源文件目录不存在时报错退出，Markdown 文件编码异常时跳过并输出文件名。
命令行参数要有基本的校验和帮助信息。
source/ 目录下有多个 .md 文件和子目录，
工具把它们转换成 HTML 文档站点。
需要 doc_parser（解析 Markdown 和目录结构）、toc_generator（生成侧边栏目录导航）、html_builder（组装最终页面）三个模块。
支持代码高亮、内部链接、图片引用。
常用选项可以放配置文件里，不用每次都在命令行指定。
基础配置数据被主业务流程引用。
操作分提交、处理、审核、完成几个阶段，不通过可以退回上一步修改。
生成的站点可以在浏览器直接打开。操作失败时不删除已有数据，保持原子性。输入参数缺失时输出帮助信息。
运行前先校验环境依赖是否满足，缺少依赖时报错退出并给出安装提示。
