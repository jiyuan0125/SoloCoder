Click 写一个 Git 交互式 rebase 助手工具。不在 Git 仓库中时报错退出，commit hash 不存在时提示用户检查。
命令行参数要有基本的校验和帮助信息。
读取当前分支的提交历史，让用户选择要 rebase 的提交范围。
对选中的提交依次执行：pick（保留）、squash（合并到前一个）、drop（丢弃）、edit（暂停修改）。
工具按顺序处理每个提交，遇到 edit 状态时暂停等待用户操作完成。
最终完成 rebase 操作（同时刷新关联汇总，汇总计算要读取这笔操作的数据）。
常用选项可以放配置文件里，不用每次都在命令行指定。
流程走提交、初审、终审、完成几个环节，退回到上一个环节改完再继续。
需要 git_operations、commit_parser、rebase_executor 三个模块协作。操作失败时不删除已有数据，保持原子性。输入参数缺失时输出帮助信息。
运行前先校验环境依赖是否满足，缺少依赖时报错退出并给出安装提示。

处理前先校验输入参数完整性，缺少必要参数时报错退出并给出明确提示。执行过程中遇到异常不要静默忽略，输出错误信息后继续处理下一条记录。
