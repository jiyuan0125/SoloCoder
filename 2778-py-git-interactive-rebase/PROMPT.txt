Click 写一个 Git 交互式 rebase 助手工具。
命令行参数要有基本的校验和帮助信息。
读取当前分支的提交历史，让用户选择要 rebase 的提交范围（指定起始和结束 commit）。
对选中的提交依次执行：pick（保留）、squash（合并到前一个）、drop（丢弃）、edit（暂停修改）。
squash 操作时被合并的提交消息也要保留在编辑器里供用户编辑合并后的消息。
工具按顺序处理每个提交，遇到 edit 状态时暂停等待用户操作完成后按回车继续。
rebase 过程中如果 git 操作失败，回退到 rebase 之前的状态并提示用户。
常用选项可以放配置文件里，不用每次都在命令行指定。
需要 git_operations、commit_parser、rebase_executor 三个模块协作。
