写一个数据库备份脚本。
用 SQLite 数据库，脚本把指定的数据库文件备份到备份目录，文件名带时间戳（格式 YYYYMMDD_HHMMSS.db）。
保留最近 N 个备份（N 可配置，默认7个），清理时按时间戳排序删除最老的。
备份时先用 SQLite 的 backup API 做热备份，不锁库。
备份前检查磁盘剩余空间，预估备份大小（原数据库文件大小），空间不够就删最老的备份腾地方，还不够就报错退出。
备份完成后验证备份文件的完整性（打开检查表列表和行数是否和原库一致）。
记录备份日志（JSON格式），包含备份时间、文件大小、是否成功。
同一个数据库文件5分钟内重复备份直接跳过。
备份执行、清理策略、日志管理分文件写。
