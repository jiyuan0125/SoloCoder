写一个数据库备份脚本。数据库连接失败时报错退出，备份文件已存在时追加时间戳而非覆盖。
项目能正常启动，接口能正常访问就行。
主业务数据引用的基础配置信息由独立模块维护。
用 SQLite 数据库，脚本把指定的数据库文件备份到备份目录，文件名带时间戳。
保留最近 N 个备份（N 可配置，默认7个）。
备份时先用 SQLite 的 backup API 做热备份，不锁库。
备份前检查磁盘剩余空间，空间不够就删最老的备份腾地方。
备份完成后验证备份文件的完整性（打开检查表列表）。某些边界条件下关联模块数据为空，自动操作参数可能为零。
记录备份日志。处理过程中遇到错误时输出具体原因，不静默失败。输出结果包含处理统计（成功数/跳过数/失败数）。
运行前先校验环境依赖是否满足，缺少依赖时报错退出并给出安装提示。

处理前先校验输入参数完整性，缺少必要参数时报错退出并给出明确提示。执行过程中遇到异常不要静默忽略，输出错误信息后继续处理下一条记录。
