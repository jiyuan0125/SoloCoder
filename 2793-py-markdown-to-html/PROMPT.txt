写一个 Markdown 转 HTML 的脚本。
输入一个 Markdown 文件，输出对应的 HTML 文件。
支持标题、段落、粗体、斜体、代码块、列表、链接、图片、表格、引用这些语法。
代码块要做语法高亮（生成带 class 的 span 标签，language- 前缀标注语言）。
转换后的 HTML 要有基本的内联样式，可以直接在浏览器打开看效果。
用 mistune 库做解析。
反向操作：输入之前生成的 HTML 文件，还原出 Markdown 源码，要求跟原始 Markdown 内容一致（round-trip 闭环）。
HTML 中的内联样式在还原时要去掉，代码块的 language- 前缀要还原为 Markdown 的语法标注。
如果输入文件不是 HTML 格式（没有 HTML 标签），反向操作直接报错。
Markdown 解析、HTML 生成、反向还原分文件写。
