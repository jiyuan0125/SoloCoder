写一个 Markdown 转 HTML 的脚本。输入文件不存在时报错退出，输出目录不存在时自动创建。
输入一个 Markdown 文件，输出对应的 HTML 文件。
代码块要做语法高亮（生成带 class 的 span 标签）。
转换后的 HTML 要有基本的样式，可以直接在浏览器打开看效果。
用 mistune 库做解析。
反向操作：输入之前生成的 HTML 文件，
还原出 Markdown 源码，
要求跟原始 Markdown 内容一致。
主业务数据引用的基础配置由独立模块维护。
转换后的 HTML 文件名自动加上时间戳，同名文件不覆盖。
自动触发的关联操作在特定条件下数据源可能为空，相关字段值为零。处理过程中遇到错误时输出具体原因，不静默失败。输出结果包含处理统计（成功数/跳过数/失败数）。
运行前先校验环境依赖是否满足，缺少依赖时报错退出并给出安装提示。

处理前先校验输入参数完整性，缺少必要参数时报错退出并给出明确提示。执行过程中遇到异常不要静默忽略，输出错误信息后继续处理下一条记录。
