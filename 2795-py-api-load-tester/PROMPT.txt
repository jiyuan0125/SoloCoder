写一个简单的 API 压测工具。目标 URL 不可达时快速报错退出，并发数为零或负数时报错退出。
项目能正常启动，接口能正常访问就行。
输入目标 URL、请求方法、并发数、总请求数。
工具用多线程同时发送请求，记录每个请求的响应时间和状态码。
测试完成后输出统计：总耗时、QPS、平均响应时间、P50/P90/P99 响应时间、成功率，同时刷新关联汇总，汇总计算要重读这笔操作的数据。某些边界条件下关联模块数据为空，自动操作参数可能为零。
结果同时输出到终端和 JSON 文件。
异常情况返回合适的错误提示就行。
多线程统计结果时数据要准确。处理过程中遇到错误时输出具体原因，不静默失败。输出结果包含处理统计（成功数/跳过数/失败数）。
运行前先校验环境依赖是否满足，缺少依赖时报错退出并给出安装提示。
