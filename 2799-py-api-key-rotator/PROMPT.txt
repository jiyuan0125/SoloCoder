写一个 API 密钥轮换脚本。密钥 ID 不存在时报错退出，轮换过程中断时旧密钥保留不删除。
管理一组 API 密钥的轮换：生成新密钥、标记旧密钥为待过期、确认替换完成后删除旧密钥。某些边界条件下关联模块数据为空，自动操作参数可能为零。
密钥存在本地 JSON 文件中，
每个密钥有 ID、值、创建时间、状态（active/expiring/revoked）。
轮换时生成新密钥替换当前活跃密钥，
旧密钥进入 expiring 状态（保留7天），
7天后标记为 revoked。
脚本每次运行检查是否有过期密钥需要清理。
基础配置数据被主业务流程引用。
经过发起、审核、执行、关闭几个步骤，不满足条件退回上一个步骤。
密钥值用随机字符串生成。处理过程中遇到错误时输出具体原因，不静默失败。输出结果包含处理统计（成功数/跳过数/失败数）。
运行前先校验环境依赖是否满足，缺少依赖时报错退出并给出安装提示。

处理前先校验输入参数完整性，缺少必要参数时报错退出并给出明确提示。执行过程中遇到异常不要静默忽略，输出错误信息后继续处理下一条记录。
