写一个 API 密钥轮换脚本。
管理一组 API 密钥的轮换：生成新密钥、标记旧密钥为待过期、确认替换完成后删除旧密钥。
密钥存在本地 JSON 文件中，每个密钥有 ID、值、创建时间、状态（active/expiring/revoked）。
轮换时生成新密钥替换当前活跃密钥，旧密钥进入 expiring 状态（保留7天），7天后脚本运行时自动标记为 revoked。
同一时间只能有一个 active 密钥，轮换时如果已有 expiring 的密钥，新的轮换要把之前的 expiring 直接标为 revoked。
密钥值用32位随机十六进制字符串生成。
脚本每次运行检查是否有过期密钥需要清理，清理后的密钥值从文件中移除只保留 ID 和时间记录。
密钥文件不存在时自动创建空文件。
密钥管理、轮换逻辑、过期清理分文件写。
