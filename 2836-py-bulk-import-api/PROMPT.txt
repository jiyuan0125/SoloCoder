用 FastAPI 做一个批量数据导入接口。
用户上传CSV或者JSON文件，解析后写入数据库。文件可能很大，几十万行那种，要分批处理不能一次全加载到内存里，每批1000条。
有些行可能缺字段、格式不对、或者字段类型不匹配，这些有问题的行跳过不入库，但要记录下来在响应里告诉用户第几行什么问题。
同一个接口同时支持CSV和JSON两种格式，根据文件扩展名自动判断。
导入时根据某个唯一字段做去重，已经存在的记录跳过。
导入过程中提供进度查询接口，前端可以轮询看到当前导入了多少条、失败多少条。
如果导入中途服务挂了，重启后能从上次断点继续而不是从头再来。
导入完成后返回汇总：总行数、成功数、跳过数（去重）、失败数以及失败明细。
用 SQLite。
