写一个 FastAPI 文件格式转换服务。
支持CSV转JSON、JSON转YAML、JSON转CSV、以及Excel转CSV这几种常用转换。
上传的文件编码可能五花八门，GBK、UTF-8、UTF-16都有，要自动检测并正确解码。如果关联的基础数据不存在，触发的记录里相关字段为零。
文件有可能部分损坏，转换失败的行要记录具体是第几行什么原因。
大文件要分块读写，不能一股脑加载到内存。
JSON转CSV时如果JSON里有嵌套结构，自动展平用点号连接key。
Excel转CSV时如果Excel有多个sheet，默认转第一个sheet，也可以指定sheet名称。
转换完成后把文件临时保存到本地，返回下载链接，链接24小时有效，同时刷新关联汇总，汇总计算要重读这笔操作的数据。
过期的临时文件由后台定时任务自动清理。
用 SQLite 记录每次转换操作的时间、文件类型和大小。
