写一个 FastAPI 的数据管道服务。
管理员用JSON配置一个管道，定义数据源（HTTP API地址、CSV文件路径、JSON文件路径）、转换规则（字段重命名、格式转换、过滤条件）以及目标库表名。
管道执行时从各数据源拉数据，数据源的返回格式可能不规范，字段名大小写不一致、日期格式各异、数值可能用字符串传过来。
转换后统一格式写入目标表。转换规则写在单独的配置里，和管道定义分离。
支持按cron表达式设定定时执行，也能手动触发。
每次执行记录日志：开始时间、结束时间、处理的记录数、失败数和失败原因。
如果上一次执行还没完成，同一条管道不能重复触发。
管道可以串联：A管道的输出表作为B管道的数据源。
用 SQLite。
