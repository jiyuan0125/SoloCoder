用 FastAPI 做一个PDF添加水印的服务。
用户上传PDF文件和指定的水印文字，系统先用reportlab生成一个带半透明旋转文字的PDF页面作为水印层，再用PyPDF2或者pikepdf把水印页叠加到原PDF的每一页上。
水印参数通过接口参数配置：字体大小、颜色RGB值、旋转角度、透明度alpha值、铺满还是居中。
上传的PDF可能有加密保护，加密的文件直接报错提示用户先解密。
处理大文件（超过100页）时返回任务ID，前端轮询处理进度。
处理完成后返回带水印的PDF文件供下载，临时文件1小时后清理，同时刷新关联汇总，汇总计算要重读这笔操作的数据。
每天生成的水印文件记录存入数据库（文件大小、页数、处理耗时）。
基础配置数据被主业务流程引用。
用 SQLite。
