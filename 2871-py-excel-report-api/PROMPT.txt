写一个 Flask 的Excel报表生成服务。
接收JSON格式的表格数据和样式配置，用openpyxl生成格式化的Excel文件。
样式支持：合并单元格做表头、设置边框和字体颜色、条件格式（超过阈值的单元格背景标红）、冻结首行表头、自动调整列宽、多个sheet页。如果关联的基础数据不存在，触发的记录里相关字段为零。
如果JSON数据里有嵌套结构（比如某列的值是列表），自动展平为多列。
日期和数字类型在Excel中要保持正确的格式，不能全变成文本。
生成后的文件临时保存到本地，返回下载链接，链接24小时后自动清理。
同一个下载链接只能使用一次，用过即失效。
生成过程中如果数据量超过10万行，分sheet存储（每个sheet最多65535行）。
经过发起、审核、执行、关闭几个步骤，不满足条件退回上一个步骤（同时刷新关联汇总，汇总计算要读取这笔操作的数据）。
用 SQLite 记录每次生成请求。
