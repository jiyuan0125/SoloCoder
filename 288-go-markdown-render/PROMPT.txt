我们的技术团队维护着一个内部文档站，文档都是用 Markdown 写的。需要把 Markdown 渲染成漂亮的 HTML 页面展示给团队看。功能需求：第一，支持标准的 Markdown 语法——标题、段落、加粗、斜体、列表（有序和无序）、链接、图片、引用块、分割线、表格。第二，支持代码块语法高亮——代码块用三个反引号加语言标识来标记（比如 python），渲染时根据语言类型给代码着色。第三，支持扩展语法——任务列表（- [ ] 和 - [x]）、脚注、数学公式（用 $ 符号包裹的行内公式和用 $$ 包裹的块级公式）、目录自动生成（根据标题层级生成带锚点链接的目录）。第四，支持自定义 CSS 样式——文档站有自己的设计风格，渲染出来的 HTML 要能套用自定义的样式表。第五，图片引用支持相对路径——文档里的图片引用比如 ![截图](./images/screenshot.png) 要能正确解析。第六，渲染结果要安全——文档里可能有用户输入的内容，要防止脚本注入攻击（把 HTML 标签转义，除非是 Markdown 语法明确允许的标签）。第七，支持渲染为纯文本——去掉所有格式标记，只保留文字内容，用于生成文档摘要或在搜索结果中展示。隐藏的坑：Markdown 里有 HTML 标签混写的情况（比如在 Markdown 里直接写 <div class=“warning”>），需要正确处理这种混合内容。另外，表格如果某行的列数不一致，要能优雅处理而不是渲染出乱七八糟的 HTML。

代码按功能模块分文件组织——块级元素解析、行内元素解析、代码高亮与数学公式、安全过滤各自独立文件。go build 能过。
