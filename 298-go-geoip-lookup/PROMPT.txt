我们的网站想根据访客的地域来展示不同的内容——比如北京的访客看到北京地区的活动信息，上海的访客看到上海的活动信息。还需要统计各个地区的访客数量，帮助市场团队了解用户分布。需要一个根据 IP 地址查询地域信息的工具。功能需求：第一，输入一个 IP 地址，返回这个 IP 大致所在的国家、省份/州、城市。不需要精确到街道级别，到城市就够了。第二，查询速度要快——每个网页请求可能都要查一次，不能成为瓶颈。第三，数据要能定期更新——IP 地址的归属关系会变化，需要能加载新数据。第四，数据更新过程不能影响正在进行的查询——不能因为更新数据就暂停服务。第五，支持批量查询——一次传入多个 IP 地址，返回对应的地域信息。第六，对于无法识别的 IP 地址（比如内网地址 192.168.x.x、保留地址），要返回明确的“未知”而不是报错。第七，提供统计功能——指定一批 IP 地址，统计各个国家、省份、城市的数量分布。数据来源方面：使用公开的 IP 地址库数据文件（比如 MaxMind 的 GeoLite2 数据库，是 CSV 格式的），工具要能读取这种格式的数据文件并构建查询用的数据结构。隐藏的坑：IPv6 地址的查询也要支持，不能只处理 IPv4。另外，IP 地址库文件通常很大（几十 MB），加载到内存的数据结构要尽量紧凑，不能一个 IP 地址就占几百字节。考虑使用更高效的存储格式（比如把 IP 地址范围转换成整数范围来存储）。

代码按功能模块分文件组织——地址库加载与构建、IP 范围查询、批量查询与统计各自独立文件。go build 能过。
