| User Prompt | 场馆座位排布和在线选座。管理员创建场馆时定义多个区域（比如A区B区VIP区），每个区域有多排座位，每排固定座位数，还要标出哪些位置是过道不能坐人。用户浏览场馆座位图后选择区域和具体座位下单。 两个人同时对同一个座位下单只有一个人能成功，另一个要收到"座位已被选中"的提示。用户选了座之后如果迟迟不付款，座位不能一直被占着——锁定10分钟后自动释放回可售状态，别人就能选了。管理员能查看某个场次各区域已售出和剩余座位数量。已售出的座位不能被重复选择。 场馆创建时区域名称不能重复。过道位置标记后在用户选座查询时直接跳过不展示。座位锁定期间用户主动取消订单也要立即释放座位，不用等10分钟超时。管理员可以手动释放某个被锁定的座位——比如用户打电话来说不要了。每个场次独立管理座位状态，不同场次之间的座位占用互不影响。场次名称不能为空且不超过50个字，座位总数在创建时确定之后不能修改。 管理员能导出某场次的座位售出明细。每排座位数创建后不能修改。所有座位和订单数据在服务重启后不能丢失。 拆成服务端和客户端两个独立程序。服务端监听HTTP端口，管理场馆座位布局和处理选座锁定逻辑，座位和订单数据存在内存中。客户端是命令行工具，管理员用它创建场馆和查看售出明细，用户用它浏览座位和选座下单。两个程序各自有独立的main包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
