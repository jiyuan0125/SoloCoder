我们做一个本地 Markdown 笔记工具。左侧是文件目录树，展示用户笔记文件夹里的所有 .md 文件，支持多级目录展开收起。右侧是编辑区，带实时预览功能。点击目录树里的文件就打开对应笔记，编辑完自动保存回本地磁盘。

目录树结构跟实际文件系统一一对应，用户可以在界面上新建文件夹、新建笔记、重命名、删除。重命名时如果目标文件名已存在，弹窗提示冲突不让直接覆盖。删除操作需要二次确认。新建笔记默认用当天日期命名，比如 2026-05-04.md。

实时预览区域跟编辑内容同步更新，提供三种布局模式：只看编辑、只看预览、左右分屏。编辑区支持 Tab 缩进、Ctrl+S 手动保存、Ctrl+N 新建笔记。超过 1MB 的大文件，预览区用延迟渲染——用户停顿 500 毫秒没打字再刷新预览，避免卡顿。

笔记数据全部存本地 .md 文件，不依赖远程服务。界面用 HTML+CSS+JS 渲染，文件读写和目录操作放后端处理，前后端通过 Electron IPC 通信。各模块代码按功能分文件，package.json、main.js、前端入口文件齐全，npm install 后 npm start 能跑起来。
