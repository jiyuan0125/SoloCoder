做一个本地密码管理工具。所有密码数据加密后存在本地文件里，不联网。主界面分三栏：左边是分类列表（社交、邮箱、金融、工作等，用户可以自己添加分类），中间是当前分类下的账号条目列表，右边是选中条目的详情编辑区。

每个条目包含：网站名称、用户名、密码、网址、备注。密码字段默认隐藏，点眼睛图标才显示明文。提供一键复制用户名和密码到剪贴板的功能，复制后 3 秒自动清空剪贴板。密码生成器可以按需生成随机密码，支持指定长度（8-64位）、是否包含大小写字母数字特殊字符。

第一次使用要设置主密码，之后每次打开应用都要输入主密码解锁。主密码不存储原文，用 PBKDF2 派生密钥来加密数据文件。连续输入错误 5 次主密码，锁定 30 秒才能再试。搜索框支持按网站名或用户名模糊搜索，跨分类查找。数据文件用 AES-256 加密，密钥从主密码派生。

界面用 HTML+CSS 做前端展示，加密解密和文件读写走后端 Node.js 处理，前后端通过 Electron IPC 通信。代码按模块分文件组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能正常启动使用。
