做一个本地图片批量处理工具。用户可以拖拽文件夹或选择多个图片文件导入，支持 JPG、PNG、WebP、BMP 格式。主界面上面是操作面板，下面是图片预览网格，显示缩略图和文件名。

操作功能包括：调整尺寸（按像素或百分比缩放，可以锁定宽高比）、格式转换（互转 JPG/PNG/WebP）、批量重命名（支持序号、日期、自定义前缀后缀模板）。用户选好参数后点击"执行"，后端批量处理所有图片，处理进度实时显示在界面上。处理完成后显示前后对比预览——左原图右处理后的效果。

输出目录默认在源文件同级的 processed 子目录下，如果目标文件已存在则自动加后缀 _1、_2 避免覆盖。处理过程中如果某张图片损坏无法读取，跳过这张继续处理其他的，最后汇总报告哪些成功了哪些失败了。批量重命名模板里如果变量名写错，预览时就显示红色警告提示。支持撤销操作——把处理后的图片恢复回原始状态（前提是保留了原始文件副本）。

界面渲染用 HTML+CSS+JS，图片读写和格式转换走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端入口齐全，npm install 之后 npm start 能跑起来。
