做一个本地 RSS 阅读器。用户可以添加 RSS 订阅源 URL，应用定期拉取最新文章。界面三栏布局：左边是订阅源列表（带未读数角标），中间是当前源的文章列表（标题、摘要、发布时间、已读/未读状态），右边是文章详情区（渲染 HTML 内容）。

添加订阅源时自动验证 URL 是否合法、是否能正常返回 RSS/Atom 格式。同一个 URL 不能重复添加。支持分类管理订阅源，用户可以新建分类、把源拖入分类。文章列表支持按时间倒序、按标题排序，关键词搜索过滤。标记已读/未读可以单篇操作也可以"全部标记已读"。收藏功能把喜欢的文章单独保存，收藏列表独立展示。

数据全部存本地 JSON 文件，包括订阅源配置、文章内容、阅读状态。刷新频率用户可以设置，默认 30 分钟拉一次。网络不通的时候不报错，显示上次缓存的旧数据就行。导出功能可以把订阅源列表导出为 OPML 文件，也能从 OPML 文件导入。

前端界面用 HTML+CSS+JS 实现，网络请求和数据库操作在后端处理，前后端通过 Electron IPC 通信。代码按模块分文件，package.json、main.js、前端页面齐全，npm install 后 npm start 能跑。
