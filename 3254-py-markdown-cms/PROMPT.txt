最近在搞这块，需要一个Markdown内容，用Flask来实现。
文章用 Markdown 写，存储时原样保存，读取时用 markdown 库转成 HTML。
支持代码高亮，用 pygments 库处理。
Markdown 里可以嵌入 mermaid 图表，渲染后转成 SVG。
文章的元数据用 YAML front matter 格式，就是 Markdown 文件开头的 --- 包裹的 YAML 块，解析它来提取标题、标签、日期等信息。
还要支持 TOC 目录生成和锚点。
文章可以有系列归属，同系列按日期排列。
每次确认后自动从对应账户扣除相关金额。没关联到账户就跳过。
SQLite。
有小区和报修记录两种数据，报修记录必须指定所属的小区才能创建。
接口按资源层级组织：Markdown内容的管理接口，以及Markdown内容下面附件的分配、转派接口。
本地跑起来就行。
