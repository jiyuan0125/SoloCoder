做一个本地文件全文搜索工具。用户选择一个根目录，工具扫描目录下的所有文本文件建立索引，然后支持关键词搜索。界面分上下两部分：上面是搜索栏（关键词输入框、目录选择器、文件类型过滤下拉），下面是搜索结果列表。

搜索结果显示文件路径、匹配行号、匹配行的内容预览（关键词高亮）。双击结果项用系统默认程序打开对应文件。文件类型过滤支持常见格式：.txt、.md、.js、.py、.json、.html、.css、.xml、.log、.csv，用户也可以自定义扩展名。

首次索引可能较慢，显示进度条和当前扫描的文件路径。索引结果缓存在本地，下次打开直接加载缓存。如果文件内容有变动，提供"重新索引"按钮更新。搜索支持简单的布尔语法：空格表示 AND，| 表示 OR，- 表示排除。大文件（超过 5MB）只索引前 1000 行，避免内存占用过大。

搜索是实时搜索——用户每输入一个字符就立刻过滤结果，用防抖处理避免频繁触发。搜索历史保存最近 20 条，方便快速重复搜索。

界面用 HTML+CSS 渲染，文件扫描和索引操作走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能用。
