现在需要一个命令行测试，用Python CLI。
类似简易版 Postman，能发送 HTTP 请求并展示响应。
测试用例定义在 YAML 文件里，包含请求方法、URL、头、体和断言。
命令行测试有新增、修改、删除、查看详情几种操作，每种操作有独立的接口。命令行测试下面还挂了明细，明细也有自己的接口。
断言支持状态码、响应体字段值、响应时间等。
测试可以按集合组织，一个集合里按顺序执行。
上一个请求的响应可以作为下一个请求的变量。
测试报告输出到终端或 HTML 文件。
代码分用例解析、请求执行、断言引擎、报告生成四个模块。
命令行测试的完整流程是创建、审核、执行、完成，每个阶段过了才能到下一个。完成没过可以退回到审核。
当创建完成后，自动给关联方生成一条通知。没有关联方就不生成。
SQLite存数据。
编码唯一，重复创建返回409。查询的记录不存在时返回404不是500。参数格式不正确返回400。状态只能按顺序流转，非法跳转返回400和当前状态。统计为空返回空数组不是404。
本地跑起来就行。
