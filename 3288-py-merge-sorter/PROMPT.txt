业务那边需要一套数据合并排序，用Python做。
从多个 JSON 文件读取数据列表，合并成一个大的列表然后按指定字段排序。
JSON 文件可能格式有问题：不是合法 JSON、缺少指定字段、字段值类型不一致（有的数字有的字符串）。
数据合并排序的金额变更后，关联的分配记录需要同步更新。
编码也可能不同。
排序字段可能是嵌套的，比如 user.profile.age。
有的记录可能没有这个嵌套路径。
排序方向可以是升序或降序。
合并后可能有重复记录，去重规则是某些字段的组合。
去重时保留第一条还是最后一条可以配置。
需要维护教室的信息，课程安排录入时选择对应的教室。
确认完成时自动在统计模块新增一条汇总记录。
输出到 JSON 文件。
SQLite存数据。
项目能正常跑起来就行。
