做一个本地记账本工具。主界面上面是快速记账栏（金额输入、收支切换、分类选择、备注输入、日期选择），下面分左右两部分：左边是月度日历视图（每天格子里显示当天总支出金额，有支出的日期用颜色深浅表示花费多少），右边是选中日期的明细列表。

收支分类预设：餐饮、交通、购物、娱乐、居住、医疗、教育、工资、兼职等，用户可以添加自定义分类。月度统计面板展示：本月总收入、总支出、结余，按分类的饼图或柱状图。预算功能：用户给每个分类设置月度预算上限，超过 80% 变黄色提醒，超过 100% 变红色。预算数据按月独立，每月自动重置。

支持搜索和筛选：按分类、按金额范围、按备注关键词过滤记录。编辑和删除已有记录，删除需要确认。金额输入只允许数字和小数点，最多两位小数，负数不允许。数据导出为 CSV 文件，按月导出。所有数据存在本地 JSON 文件里，按月分表或加时间索引保证查询效率。

界面用 HTML+CSS 渲染展示，数据存储和统计计算在后端处理，前后端通过 Electron IPC 通信。代码按模块分文件，package.json、main.js、前端页面齐全，npm install 后 npm start 能正常使用。
