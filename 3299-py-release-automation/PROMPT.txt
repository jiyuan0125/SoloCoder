用Python帮我写一个版本发布自动化。
从读取当前版本号开始，经过以下步骤：更新版本号→更新 changelog→运行测试→创建 git tag→打包→发布。
版本号从 pyproject.toml 或 setup.py 里读。
changelog 从 git log 里提取上一个 tag 到现在的提交信息。
测试跑 pytest，失败则中止。
tag 和发布是模拟的，只打印命令不执行。
当创建完成后，自动给关联方生成一条通知。没有关联方就不生成。
每一步可以单独运行也可以一键全部跑。
版本发布自动化的完整流程是创建、审核、执行、完成，每个阶段过了才能到下一个。完成没过可以退回到审核。
版本发布自动化有创建、更新、移除、查看几种操作，每种操作有独立的接口。版本发布自动化下面还挂了操作记录，操作记录也有自己的接口。
步骤之间有前置条件检查，比如没测试就不能发布。
配置和记录存 JSON。
SQLite存数据。
本地跑起来就行。
