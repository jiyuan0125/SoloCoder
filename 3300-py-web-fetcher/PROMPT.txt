现在需要一个网页内容抓取，用Python。
输入 URL 列表（从文件读取），脚本抓取每个 URL 的页面内容并保存到本地。
URL 从配置文件读取，配置文件路径由命令行参数指定。
系统要管理会员和消费记录，消费记录创建时要关联到会员。
还有个模板功能，URL 里可以带变量，变量值从另一个文件读取，生成具体的 URL 再抓取。
抓取的内容可以选择保存原始 HTML 或者只保存正文文本（去掉标签）。
当审批通过完成后，自动给关联方生成一条通知。没有关联方就不生成。
用 BeautifulSoup 解析 HTML。
支持设置请求头和延迟。
抓取结果按 URL 的域名分目录存储。
修改了网页内容抓取的总额之后，下面挂的明细项要按比例重新分配。
配置和抓取记录存 JSON 文件。
SQLite存数据。
项目能正常跑起来就行。
