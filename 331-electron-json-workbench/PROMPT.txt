做一个 JSON 格式化工作台。界面左边是输入区（大的文本框，粘贴或输入 JSON 字符串），右边是输出区（格式化后的结果）。中间工具栏提供几个操作按钮：美化格式化、压缩成一行、排序键名（按字母序）、JSON 路径查询。

路径查询功能：用户输入 JSONPath 表达式（比如 $.store.book[*].author），实时在格式化结果里高亮匹配的节点。如果表达式语法错误，在输入框下方显示红色错误提示。

差异对比模式：切换到双栏对比视图，左右各粘贴一份 JSON，自动找出差异并高亮——新增的字段用绿色、删除的用红色、值变化的用黄色。差异对比是递归的，嵌套对象里的差异也能定位到。

输入的 JSON 如果格式不合法，实时显示错误位置和原因（缺少逗号、引号不匹配等），点击错误提示自动把光标跳到对应位置。支持从本地文件直接打开 .json 文件，也能把结果保存到本地。处理超大 JSON（超过 10MB）时，格式化操作放后端异步处理，前端显示加载动画。

界面用 HTML+CSS+JS 渲染，JSON 解析、文件读写走后端，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能跑。
