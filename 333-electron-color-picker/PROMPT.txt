做一个取色器兼调色板管理工具。主界面中间是一个大的色板区域，用户可以在上面点击取色。支持 HSL 模式调色——一个色相条加一个饱和度/亮度面板。右侧展示当前选中颜色的各种格式值：HEX、RGB、HSL、HSV，每种格式旁边有复制按钮。

屏幕取色功能：点击"屏幕取色"按钮后进入取色模式，鼠标移动到屏幕任意位置实时显示当前位置的颜色值，点击确认取色。取色模式下工具窗口半透明，不遮挡取色区域。

调色板管理：用户可以创建多个调色板（比如"项目A配色""个人收藏"），每个调色板里添加多个颜色。颜色支持拖拽排序、添加备注说明。导出调色板为 CSS 变量文件或 JSON 文件。

对比度检查：输入前景色和背景色，计算 WCAG 对比度比值，显示 AA/AAA 级别是否通过，旁边用文字预览实际效果——白底黑字、黑底白字、自定义底色上的文字可读性。

颜色历史自动记录最近取过的 100 个颜色，方便回溯。两个颜色之间可以查看渐变色预览。

界面用 HTML+CSS+JS 渲染，系统级屏幕取色走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能跑起来。
