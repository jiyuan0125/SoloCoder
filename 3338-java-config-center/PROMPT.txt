最近在搞这块，需要一个配置中心，用Spring Boot来实现。
支持按应用和环境管理配置项，配置值可能是字符串、数字、JSON 等各种格式。
修改配置要记录变更历史，包含修改人、修改时间、修改前后值。
配置推送给客户端时要校验格式正确，比如 JSON 格式的值要能正确解析。
支持配置回滚到任意历史版本。
配置中心有新增、修改、删除、查看详情几种操作，每种操作有独立的接口。配置中心下面还挂了附件，附件也有自己的接口。
配置项可以设为加密存储，接口返回时自动解密。
系统运行时要记录关键操作的执行耗时，方便排查性能瓶颈。
配置中心的总额变更后，关联的子记录需要同步更新。
用Maven构建。
编码唯一，重复创建返回409。查询的记录不存在时返回404不是500。数量为0或负数返回400。统计为空返回空数组不是404。两个操作要么都成功要么都失败。
本地跑起来就行。
