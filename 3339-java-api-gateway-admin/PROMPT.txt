我们最近需要一套管理系统，用Spring Boot做。
可以注册和注销后端服务，服务信息包含地址、权重、健康检查路径。
配置路由规则，支持路径匹配和参数转发，路径中可能带通配符。
可以给路由设置限流策略（每秒请求数）和熔断策略（错误率阈值）。
后端服务健康检查，连续 3 次检查失败才标记为不健康并摘除。
接口按资源层级组织：管理系统的管理接口，以及管理系统下面附件的分配、转派接口。
所有配置变更要记录操作日志。
管理系统的权重变更后，关联的关联数据需要同步更新。
系统运行时要记录关键操作的执行耗时，方便排查性能瓶颈。
用Maven构建。
编号唯一，重复创建返回409。记录不存在时返回404。时间范围不合法返回400。查询结果为空返回空数组不是404。关联数据同步更新失败时原操作回滚。
项目能正常跑起来就行。
