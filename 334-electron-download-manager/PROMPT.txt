做一个下载管理器桌面工具。用户输入下载 URL，工具负责下载文件到本地指定目录。主界面是下载任务列表，每个任务显示：文件名、文件大小、下载进度条、下载速度、剩余时间、状态（等待中/下载中/已暂停/已完成/失败）。

支持同时下载多个文件，并发数用户可以设置（默认 3 个）。暂停和继续单个任务，也可以全部暂停/全部继续。下载失败自动重试最多 3 次。文件名冲突时自动在文件名后加序号。

分类管理：下载任务可以归类到不同文件夹（图片、文档、视频、压缩包等），根据文件扩展名自动分类，用户也能手动改。已完成、下载中、失败的分别用 tab 页展示，方便查看。

批量下载：用户可以粘贴多个 URL（一行一个），一次性添加多个下载任务。支持断点续传——如果之前下载了一半被中断，重新开始时从上次的位置继续，不重新下载已有部分。

下载目录在设置里配置，默认是用户的 Downloads 文件夹。所有任务信息保存在本地 JSON 文件里，重启应用后能恢复未完成的下载任务。

界面用 HTML+CSS+JS 渲染，文件下载和网络请求走后端处理，前后端通过 Electron IPC 通信。代码分文件组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能用。
