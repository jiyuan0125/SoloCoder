文件格式转换，用Spring Boot实现。
支持 CSV 和 JSON 互转、XML 和 JSON 互转。
文件可能很大（几十 MB），不能用内存全部加载，用流式处理。
转换过程中遇到格式错误不要中断，记录错误位置继续处理后面的数据。
转换结果要保证反向转换后和原始数据一致，也就是 round-trip 闭环。
支持自定义字段映射，比如 CSV 中的 name 列对应 JSON 中的 username。
有员工和考勤记录两种数据，考勤记录必须指定所属的员工才能创建。
系统运行时要记录关键操作的执行耗时，方便排查性能瓶颈。
文件格式转换有新增、修改、删除、查看详情几种操作，每种操作有独立的接口。文件格式转换下面还挂了附件，附件也有自己的接口。
用Maven构建。
名称唯一，重复创建返回409。关联的主记录不存在时返回404。名称为空返回400。搜索结果为空返回空列表不是报错。汇总记录不存在时自动创建不报错。
项目能正常跑起来就行。
