消息队列，用Spring Boot实现。
可以创建队列、发送消息、消费消息，消息可能是各种格式（JSON、XML、纯文本）。
队列积压超过阈值要告警，阈值可配置。
消息消费失败进入死信队列，死信消息支持手动重新投递。
消息有 TTL，过期自动删除，TTL 可按队列配置。
提供队列状态的实时监控数据：消息总数、消费速率、积压数。
消息队列有新增、修改、删除、查看详情几种操作，每种操作有独立的接口。消息队列下面还挂了子项，子项也有自己的接口。
系统运行时要记录关键操作的执行耗时，方便排查性能瓶颈。
创建完成时自动在统计模块新增一条汇总记录。
用Maven构建。
编码唯一，重复创建返回409。查询的记录不存在时返回404不是500。参数格式不正确返回400。不能跳步，非法跳转返回400和当前状态。统计为空返回空数组不是404。
项目能正常跑起来就行。
