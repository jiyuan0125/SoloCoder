用Spring Boot帮我写一个数据库Schema版本。
支持创建和执行迁移脚本，脚本按版本号顺序执行，不能跳版本。
已执行的脚本不能修改，修改了会报错。
数据库Schema版本的数量变更后，关联的分摊记录需要同步更新。
迁移失败要自动回滚当前脚本的操作，不影响之前已成功的脚本。
支持查看当前数据库的版本状态和迁移历史。
每次创建后自动从对应账户扣除相关金额。没关联到账户就跳过。
迁移脚本里可能包含复杂的数据转换逻辑，脚本用 SQL 编写。
系统运行时要记录关键操作的执行耗时，方便排查性能瓶颈。
接口按资源层级组织：数据库Schema版本的管理接口，以及数据库Schema版本下面附件的创建、更新接口。
编号唯一，重复创建返回409。记录不存在时返回404。数量为0或负数返回400。状态只能按顺序流转，非法跳转返回400和当前状态。查询结果为空返回空数组不是404。
本地跑起来就行。
