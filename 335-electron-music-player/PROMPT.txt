做一个本地音乐播放器。用户选择一个音乐文件夹，工具扫描其中的音频文件（支持 MP3、FLAC、WAV、AAC、OGG）。界面顶部是播放控制栏（上一首、播放/暂停、下一首、进度条、音量控制、播放模式切换——顺序/随机/单曲循环），中间是当前播放歌曲信息和专辑封面展示区，下面是播放列表。

播放列表支持按歌曲名、歌手、专辑排序，关键词搜索过滤。用户可以创建多个自定义播放列表，从曲库里拖歌进去。播放列表数据保存在本地 JSON 文件中。

歌词显示功能：自动匹配同目录下的 .lrc 歌词文件，如果没有就只显示歌曲信息。歌词随播放进度滚动高亮当前行。简单的均衡器提供几个预设模式（流行、摇滚、古典、爵士、自定义），用户可以调节各频段增益。

扫描文件夹时读取音频文件的元数据（ID3 tag），提取歌手、专辑、时长等信息显示在界面上。如果元数据缺失，用文件名作为歌曲名。音量支持 0-100 调节，记住上次关闭时的音量设置。

界面用 HTML+CSS+JS 渲染，音频解码播放和文件扫描走后端处理，前后端通过 Electron IPC 通信。代码按功能分文件，package.json、main.js、前端页面齐全，npm install 后 npm start 能正常播放音乐。
