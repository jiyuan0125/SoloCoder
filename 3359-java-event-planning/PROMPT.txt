最近在搞这块，需要一个活动策划，用Spring Boot来实现。
活动创建后分多个筹备模块：场地预订管理、嘉宾邀请管理、物料采购管理、志愿者安排。
每个模块有独立的状态和负责人，模块之间通过活动 ID 关联。
创建之后自动把数据同步到月度汇总表。
场地预订要检查时间冲突，嘉宾邀请要追踪回复状态。
活动结束后还有复盘模块收集反馈和统计参与数据，数据来自各筹备模块。
各模块变更要通知活动总负责人，通知通过事件机制实现。
各模块的公共依赖定义在共享模块中，避免重复定义。
活动策划的完整流程是申报、初审、复审、批准，每个阶段过了才能到下一个。批准没过可以退回到初审。
用Maven构建。
编码唯一，重复创建返回409。查询的记录不存在时返回404不是500。时间范围不合法返回400。不能跳步，非法跳转返回400和当前状态。统计为空返回空数组不是404。
本地跑起来就行。
