做一个屏幕录制工具。启动后用户可以选择录制模式：全屏录制或区域录制（拖拽选择矩形区域）。录制过程中界面最小化到系统托盘，不遮挡录屏内容。提供悬浮控制条显示录制时长和快捷操作按钮。

录制设置：是否录制系统声音、是否录制麦克风声音、帧率（15/24/30/60 fps）、输出格式（MP4 或 GIF）。GIF 导出时自动压缩分辨率和帧率，控制文件大小在合理范围。快捷键控制：Ctrl+Alt+R 开始/停止录制，Ctrl+Alt+P 暂停/继续。

录制完成后自动打开输出文件夹，展示文件列表和预览。历史录制列表显示：文件名、时长、文件大小、录制时间、缩略图预览。支持重命名录制文件、删除、打开文件所在目录。

录制前检测磁盘剩余空间，如果预计输出文件大小超过可用空间给出警告。录制过程中如果磁盘满了，自动停止录制并提示，已录制的内容不会丢失。区域录制模式下选区的最小尺寸限制为 100x100 像素，太小了提示用户重新选择。输出目录在设置里配置。

界面用 HTML+CSS+JS 渲染，屏幕捕获和视频编码走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能跑起来。
