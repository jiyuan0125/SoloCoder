单点登录，用Spring Boot实现。
用户登录一次后可以免登访问多个子系统。
支持用户名密码登录和手机验证码登录两种方式。
单点登录的比例变更后，关联的子记录需要同步更新。
Token 用 JWT 签发，包含用户信息和权限，支持 Token 刷新机制。
子系统接入只需配置 SSO 地址和密钥，密钥用于验签。
单点登录有分配、转派、加急处理、关闭几种操作，每种操作有独立的接口。单点登录下面还挂了子项，子项也有自己的接口。
登录状态变更（比如修改密码后）要让已发放的 Token 失效，方式你来定。
接口要有明确的错误码和错误信息，方便客户端处理异常。
单点登录的完整流程是提交、初审、复审、关闭，每个阶段过了才能到下一个。关闭没过可以退回到初审。
用Maven构建。
项目能正常跑起来就行。
