做一个文本差异对比工具。界面是左右分栏布局，用户在左右两侧分别粘贴或加载要对比的文本。差异部分自动高亮——左边独有的内容标红色背景，右边独有的标绿色背景，两边都有但内容不同的标黄色背景，相同的行不标色。

提供两种对比粒度切换：行级对比（整行不同就标色）和词级对比（行内不同的词分别标色）。行级对比适合看代码结构变化，词级对比适合看文案修改。空行差异默认不显示，可以切换是否忽略空白差异。

支持从本地文件加载文本：左右各有一个"打开文件"按钮，选择文件后内容填入对应侧。支持编码检测：自动识别 UTF-8、GBK、GB2312 等常见中文编码，避免乱码。

导航功能：差异点列表展示在底部，点击某一项自动滚动左右两侧到对应位置。上下箭头快速跳转到上一个/下一个差异点。

合并导出：可以选择保留左边的版本、右边的版本，或者手动逐处选择保留哪一边，最终导出合并后的文本到本地文件。对比结果也可以导出为 HTML 文件（带高亮样式，方便分享）。

界面用 HTML+CSS+JS 渲染，文件读取和编码检测走后端处理，前后端通过 Electron IPC 通信。代码按功能分文件，package.json、main.js、前端页面齐全，npm install 后 npm start 能用。
