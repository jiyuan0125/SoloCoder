业务那边需要一套简易聊天机器人引擎，用Spring Boot做。
定义意图识别规则，支持关键词匹配和正则表达式两种匹配模式。
每个意图绑定一个回复模板或一个外部 API 调用，API 返回结果填充到回复中。
支持上下文记忆，多轮对话时记住之前的回答，用 session 管理。
对话日志记录到数据库，包含用户输入、匹配意图、回复内容。
未识别的意图转人工客服队列，人工客服可以查看对话历史。
简易聊天机器人引擎有创建、更新、移除、查看几种操作，每种操作有独立的接口。简易聊天机器人引擎下面还挂了变更记录，变更记录也有自己的接口。
接口要有明确的错误码和错误信息，方便客户端处理异常。
需要维护客户的信息，订单录入时选择对应的客户。
流程分新建、评审、确认、归档四步走，新建不通过退回，确认之后到归档。
本地跑起来就行。
