做一个浏览器书签管理工具。支持导入 Chrome、Firefox、Edge 导出的书签 HTML 文件。导入后解析书签的标题、URL、文件夹结构，在界面上以树形结构展示。

书签管理功能：新建文件夹、移动书签到不同文件夹、重命名、删除。搜索功能支持按标题或 URL 模糊搜索，跨文件夹查找。标签系统：给书签打标签（工作、学习、娱乐、购物等），一个书签可以多个标签，通过标签过滤查看。

失效检测：批量检查所有书签 URL 是否还能正常访问。检测过程在后台运行，前端显示进度。检测结果分为正常（绿色）、重定向（黄色，显示跳转后的 URL）、失效（红色，HTTP 错误或超时）。失效的书签可以一键筛选出来，方便清理。

书签去重：自动检测 URL 完全相同的重复书签（忽略末尾斜杠差异），列出重复组，用户选择保留哪一个。导入新书签时如果发现重复也提示处理。

导出功能：按当前的书签结构导出为 HTML 文件，可以直接导入回浏览器。也支持导出为 JSON 格式。所有书签数据存在本地 JSON 文件中。

界面用 HTML+CSS+JS 渲染，文件读写、网络请求和数据库操作走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能跑。
