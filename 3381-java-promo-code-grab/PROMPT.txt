我们最近需要一套红包领取，用Spring Boot做。
运营发放一批红包（总额和个数确定），用户来抢。
每个用户只能抢一次，重复抢返回已领取。
金额随机分配，但总额要守恒，所有人抢到的金额加起来等于总额。
抢完后显示已抢完，后续请求直接返回。
同一时间大量请求涌入时要保证不超发、不重复领取、金额守恒。
红包领取有新增、修改、删除、查看详情几种操作，每种操作有独立的接口。红包领取下面还挂了子项，子项也有自己的接口。
操作结果要实时可见，不能有明显的延迟或数据不一致。
修改了红包领取的金额之后，下面挂的分配记录要按比例重新分配。
红包领取的完整流程是申报、初审、复审、批准，每个阶段过了才能到下一个。批准没过可以退回到初审。
用Maven构建。
本地跑起来就行。
