用Spring Boot帮我写一个自定义报表。
用户可以通过前端表单输入查询条件来生成报表，查询条件拼成 SQL 语句执行。
报表可以保存和分享给其他用户，分享链接带一个简单的 ID 参数（自增数字）。
报表结果支持导出为 Excel 文件。
需要维护用户的信息，操作日志录入时选择对应的用户。
用户可以给报表命名，名字随便取，没有限制。
报表数据来自多个数据库表，用户可以选择关联的表和字段。
创建成功后自动创建对应的关联单据，金额按比例算。
所有用户输入在存储前要做必要的格式处理。
流程分申请、初审、终审、归档四步走，申请不通过退回，终审之后到归档。
名称唯一，重复创建返回409。关联的主记录不存在时返回404。参数格式不正确返回400。已关闭的记录不能改状态，返回409。搜索结果为空返回空列表不是报错。
项目能正常跑起来就行。
