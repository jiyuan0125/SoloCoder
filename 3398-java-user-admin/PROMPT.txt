现在需要一个管理系统，用Spring Boot。
管理员可以查看用户列表、修改用户信息、重置密码，管理接口不需要额外鉴权。
普通用户可以修改自己的个人信息和密码，通过传入用户 ID 定位记录。
用户列表接口支持分页和按关键词搜索，搜索涵盖用户名、邮箱、手机号。
修改用户角色时传入用户 ID 和新角色值，角色值是数字编码。
管理系统有创建、更新、移除、查看几种操作，每种操作有独立的接口。管理系统下面还挂了子项，子项也有自己的接口。
用户头像通过 URL 引用外部图片，URL 由用户自己填。
所有用户输入在存储前要做必要的格式处理。
修改了管理系统的配额之后，下面挂的明细项要按比例重新分配。
用Maven构建。
项目能正常跑起来就行。
