帮我做一套网盘文件，用Spring Boot。
用户可以创建文件夹、上传下载文件、删除移动，文件的存储路径由用户指定。
支持文件预览，图片直接返回，文本文件读取内容返回给前端展示。
文件下载接口通过参数指定文件路径，服务端根据路径读取文件返回。
用户之间的文件互相不可见，权限校验通过用户 ID。
文件夹支持多层嵌套，路径用 / 分隔。
网盘文件有创建、更新、移除、查看几种操作，每种操作有独立的接口。网盘文件下面还挂了子项，子项也有自己的接口。
所有用户输入在存储前要做必要的格式处理。
网盘文件的金额变更后，关联的关联数据需要同步更新。
网盘文件走创建→审核→执行→完成的流程，创建不通过退回修改后重新创建。
用Maven构建。
本地跑起来就行。
