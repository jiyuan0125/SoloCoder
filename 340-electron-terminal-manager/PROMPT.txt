做一个多标签终端管理工具。主界面类似浏览器标签页，每个标签页是一个独立的终端会话。用户可以新建标签页、关闭标签页、在标签页之间切换。每个终端标签页下方显示当前工作目录路径。

终端功能：支持基本命令执行、命令历史（上下箭头翻阅）、Tab 自动补全文件名。终端输出区域支持滚动查看历史输出。自定义终端配色方案：提供几个预设主题（暗色、亮色、Solarized、Monokai），用户也可以自定义前景色和背景色。

命令快捷输入：左侧边栏保存常用命令列表（用户可以添加、编辑、删除、分组管理常用命令），点击某条命令自动输入到当前终端。支持命令模板，用 ${变量} 占位符，点击时弹出输入框填写变量值再执行。

分组管理：终端标签可以归到不同分组（比如"开发环境""数据库""服务器"），用颜色区分不同分组。切换分组时只显示该分组下的标签页。

终端会话数据（命令历史、工作目录）保存在本地 JSON 文件里，重新打开应用后可以恢复之前的标签页状态。每个标签页可以独立设置字体大小。

界面用 HTML+CSS+JS 渲染，终端进程创建和命令执行走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能用。
