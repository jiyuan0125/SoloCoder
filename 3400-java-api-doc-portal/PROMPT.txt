业务那边需要一套文档管理门户，用Spring Boot做。
用户可以注册并创建自己的 API 文档项目，文档内容支持 Markdown 编写。
文档可以通过公开链接分享，链接格式是 /doc/{projectId}，projectId 是自增数字。
用户在文档中可以嵌入 HTML 来丰富展示效果，HTML 内容直接渲染。
后台管理接口通过 /admin 路径访问，管理员密码写在配置文件中。
用户密码明文存储，登录时直接比对。
接口按资源层级组织：文档管理门户的管理接口，以及文档管理门户下面变更记录的新增、修改接口。
所有用户输入在存储前要做必要的格式处理。
流程分开单、审核、执行、验收四步走，开单不通过退回，执行之后到验收。
创建之后自动把数据同步到月度汇总表。
用Maven构建。
名称唯一，重复创建返回409。关联的主记录不存在时返回404。名称为空返回400。状态只能按顺序流转，非法跳转返回400和当前状态。搜索结果为空返回空列表不是报错。
本地跑起来就行。
