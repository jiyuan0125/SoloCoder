做一个环境变量编辑器。打开应用后显示当前系统所有的环境变量列表，按变量名排序。列表分两列：左边是变量名，右边是对应的值。值特别长的自动截断显示，鼠标悬停或点击展开完整内容。

编辑功能：双击某一行进入编辑模式，可以修改变量名和值。新增环境变量按钮在列表上方。删除操作需要确认弹窗。修改后的环境变量可以选择只影响当前应用进程，还是写入系统配置永久生效（需要管理员权限，写到系统环境变量配置里）。

分组管理：用户可以创建自定义分组（比如"Java开发""Node.js开发""数据库"），把常用的环境变量拖入分组。分组视图下只显示该组内的变量，方便集中管理某个开发环境的配置。PATH 变量特殊处理——按分隔符拆分成多行显示，每行可以单独编辑、上下移动顺序、删除某一项。

导入导出：导出当前环境变量为 .env 文件或 JSON 文件，也可以从 .env 文件导入批量设置。导入时如果变量已存在，提示是跳过还是覆盖。

搜索过滤：输入关键词实时过滤变量列表，匹配变量名和值。

界面用 HTML+CSS+JS 渲染，读取和修改系统环境变量走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能跑起来。
