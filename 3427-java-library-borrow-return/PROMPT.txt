帮我做一套图书借还，用Spring Boot。
Spring Boot。
图书馆有藏书目录，
读者可以借书和还书。
每个人最多同时借5本，借期30天。
创建之后自动把数据同步到月度汇总表。
超期的话按天计算滞纳金。
书被借走了别人可以预约，
图书借还走登记→审核→处理→结案的流程，登记不通过退回修改后重新登记。
还书后自动通知预约的人。
遗失的书标记为丢失，读者需要赔偿。
提供查询某本书当前状态和借阅记录的接口。
用Maven构建。
名称唯一，重复创建返回409。关联的主记录不存在时返回404。参数格式不正确返回400。不能跳步，非法跳转返回400和当前状态。搜索结果为空返回空列表不是报错。
本地跑起来就行。
