做一个万能单位换算工具。界面顶部是类别选择标签页：长度、重量、温度、面积、体积、速度、时间、数据存储、压力等。每个类别下显示常用单位的双向换算面板。

换算面板左右各一个下拉选择单位和一个数值输入框，输入任一侧的数值后另一侧实时显示换算结果。比如长度类别：左边选"千米"输入 1，右边选"英里"实时显示 0.621。支持中间转换单位——点击"添加单位"可以在中间插入第三个单位，形成链式换算。

温度换算特殊处理：摄氏度、华氏度、开尔文三者互转，不是简单的乘除关系。数据存储单位换算用 1024 进制（1KB=1024B），也提供 1000 进制选项（1KB=1000B，磁盘厂商标准），两种结果都显示。

历史记录：保存最近的换算记录，包括类别、输入值、输入单位、输出值、输出单位。快速重复之前的换算。

收藏常用换算：用户可以把常用的换算组合（比如"人民币→美元""磅→千克"）收藏到首页快捷入口。汇率类换算的汇率值用户可以手动更新。

所有配置和历史数据保存在本地 JSON 文件中。

界面用 HTML+CSS+JS 渲染，数据持久化走后端处理，前后端通过 Electron IPC 通信。代码按功能分文件，package.json、main.js、前端页面齐全，npm install 后 npm start 能跑。
