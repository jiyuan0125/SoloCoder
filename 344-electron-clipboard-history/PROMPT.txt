做一个剪贴板历史管理工具。应用在后台运行，监听系统剪贴板变化，每次复制内容都自动记录下来。主界面是历史记录列表，按时间倒序排列，每条记录显示：内容预览（文本截取前 100 字符）、复制时间、内容类型图标（纯文本/图片/文件路径）。

搜索功能：输入关键词实时过滤历史记录，匹配文本内容。置顶功能：重要的条目可以置顶，置顶的排在最前面且不会被自动清理。分组收藏：用户创建自定义分组，把历史条目归类到不同分组（比如"代码片段""常用文案""临时"）。

点击某条记录自动把内容复制回剪贴板，界面短暂提示"已复制"。支持图片类型的剪贴板内容——记录缩略图预览，点击可以复制图片。文件路径类型：如果复制的是文件路径，显示文件图标，双击用系统默认程序打开该文件。

自动清理：默认保留最近 500 条记录，超过的自动删除最早的。清理策略用户可以设置（按条数或按天数，比如只保留最近 7 天的）。固定/置顶的条目不参与自动清理。

数据持久化：文本内容存在本地 JSON 文件，图片内容存为本地文件（缩略图是压缩版，原图在点击时加载）。启动应用自动开始监听剪贴板，最小化到系统托盘运行。

界面用 HTML+CSS+JS 渲染，剪贴板监听和文件存储走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能用。
