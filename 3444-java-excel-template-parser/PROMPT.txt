我们最近需要一套Excel模板解析，用Spring Boot做。
用户上传 Excel 文件，系统按预定义模板规则解析。
Excel 可能包含合并单元格、
隐藏行、公式、空行、特殊字符。
解析结果转成标准 JSON 返回。
模板定义了哪些列是必填、哪些列的数据类型。
修改了Excel模板解析的金额之后，下面挂的明细项要按比例重新分配。
校验不通过的要标注具体位置（行号、列名）。
支持 xlsx 格式。
接口按资源层级组织：Excel模板解析的管理接口，以及Excel模板解析下面操作记录的分配、转派接口。
需要维护用户的信息，操作日志录入时选择对应的用户。
用Maven构建。
编号唯一，重复创建返回409。记录不存在时返回404。时间范围不合法返回400。查询结果为空返回空数组不是404。通知发送失败记录日志不影响主流程。
本地跑起来就行。
