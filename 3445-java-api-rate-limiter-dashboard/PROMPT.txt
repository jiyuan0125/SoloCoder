限流管理服务，用Spring Boot实现。
为不同的 API 设置不同的限流规则（按IP、按用户、按接口）。
限流维度支持 QPS 和日调用量。
接口按资源层级组织：限流管理服务的管理接口，以及限流管理服务下面明细的创建、更新接口。
超限的请求返回429状态码。
流量数据实时统计，提供仪表盘数据接口。
历史流量数据保留30天。
同一个用户在不同接口的调用量独立计算。
提供配置限流规则和查询流量统计的接口。
限流管理服务走申报→初审→复审→批准的流程，申报不通过退回修改后重新申报。
当创建完成后，自动给关联方生成一条通知。没有关联方就不生成。
用Maven构建。
名称唯一，重复创建返回409。关联的主记录不存在时返回404。已关闭的记录不能再修改状态，返回409。已完成的子记录不受影响，只更新未完成的。参数为空或格式不正确返回400和具体字段。
本地跑起来就行。
