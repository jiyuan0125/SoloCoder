业务那边需要一套监控告警规则引擎，用Spring Boot做。
Spring Boot。
用户定义告警规则：指标名称、比较运算符、 阈值、持续时间、告警级别。
系统接收指标数据，匹配规则，
满足条件时触发告警。
接口按资源层级组织：监控告警规则引擎的管理接口，以及监控告警规则引擎下面变更记录的新增、修改接口。
同一规则短时间内重复触发的告警要合并（比如5分钟内只告一次）。
告警支持静默期配置：已告警的在静默期内不再重复。
创建完成时自动在统计模块新增一条汇总记录。
提供创建规则、推送指标数据、查询告警记录的接口。
需要维护用户的信息，操作日志录入时选择对应的用户。
用Maven构建。
本地跑起来就行。
