做一个本地数据库浏览和管理工具。支持连接 SQLite 数据库文件和 MySQL 数据库。主界面左侧是连接列表（用户可以保存多个数据库连接配置），右侧是数据库内容展示区。

SQLite 模式：用户直接打开 .db 或 .sqlite 文件。MySQL 模式：填写主机、端口、用户名、密码、数据库名，测试连接后保存。连接成功后左侧显示数据库的表列表，点击某张表在右侧展示表结构和数据内容。

表结构视图：显示列名、数据类型、是否主键、是否允许为空、默认值。数据视图：以表格形式展示所有数据，支持分页加载（每页 100 行），列宽可以拖拽调整。排序功能：点击列头按该列升序/降序排列。

SQL 编辑器：提供一个 SQL 输入区域，用户可以手写 SQL 语句执行。支持多语句执行（用分号分隔），每条语句的结果分别展示在下方。SELECT 语句的结果以表格形式展示，INSERT/UPDATE/DELETE 显示影响的行数。SQL 执行历史保存最近 50 条。

数据导出：查询结果可以导出为 CSV 或 JSON 文件。表数据可以整体导出。导入功能支持从 CSV 文件导入数据到指定表。

界面用 HTML+CSS+JS 渲染，数据库连接和查询执行走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能用。
