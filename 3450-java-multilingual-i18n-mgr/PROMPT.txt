最近在搞这块，需要一个多语言文案，用Spring Boot来实现。
管理员维护多语言翻译文案，
每个文案有唯一的 key。
确认完成时自动在统计模块新增一条汇总记录。
支持的语言种类可以动态添加。
同一个 key 在不同语言下可能已翻译、未翻译或翻译过时（源文案改了但翻译没更新）。
导入翻译文件时（JSON格式），
已有的 key 更新，
新增的 key 追加，
文件中多余的 key 不删除。
多语言文案有分配、转派、加急处理、关闭几种操作，每种操作有独立的接口。多语言文案下面还挂了变更记录，变更记录也有自己的接口。
系统要管理项目和任务，任务创建时要关联到项目。
提供按语言查询所有文案和标记未翻译的接口。
用Maven构建。
编码唯一，重复创建返回409。查询的ID不存在时返回404。关联数据同步更新失败时原操作整个回滚，不能部分成功。参数为空或格式不正确返回400和具体字段。查询结果为空返回空数组不是404。
本地跑起来就行。
