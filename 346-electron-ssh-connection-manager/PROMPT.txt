做一个 SSH 连接管理器。用户可以保存多个远程服务器的连接配置（主机名/IP、端口、用户名、认证方式——密码或密钥文件路径），分组管理（比如"生产环境""测试环境""个人服务器"）。

主界面左侧是分组和连接列表，右侧上方是终端区域。点击某个连接配置，工具通过 SSH 协议连接到远程服务器，终端区域显示远程 shell。支持多标签页，同时连接多个服务器。

密钥管理功能：配置 SSH 私钥文件路径，支持密码加密的私钥（输入密钥密码后解密使用）。密钥文件浏览器方便选择本地 .pem 或 .id_rsa 文件。

快速连接：顶部搜索栏输入主机名或备注关键词快速过滤连接列表。最近连接记录自动排在最前面。连接超时默认 10 秒，可以在设置里调整。

终端功能：支持基本命令执行、终端输出滚动查看。终端配色可以自定义。会话断开后提示重连。

所有连接配置和分组信息保存在本地 JSON 文件中，密码不存储明文——如果用密码认证，每次连接时手动输入（提供"记住密码"选项，密码加密存储到本地密钥库）。

界面用 HTML+CSS+JS 渲染，SSH 连接和终端交互走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能用。
