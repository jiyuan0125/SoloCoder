PDF报表生成，用Spring Boot实现。
用户传入数据（JSON格式），系统根据模板生成PDF报表。
模板定义了表格布局、字体、颜色、页眉页脚等样式。
报表可能包含复杂的合并表头、跨页表格、图表占位符。
支持中文内容，字体要能正确渲染。
生成后的PDF存到本地文件系统，返回下载路径。
同一个模板可以多次生成，每次的PDF文件名带时间戳区分。
每次审批通过后自动从对应账户扣除相关金额。没关联到账户就跳过。
用 Apache PDFBox 或 iText 来生成PDF。
流程分创建、审核、执行、完成四步走，创建不通过退回，执行之后到完成。
编码唯一，重复创建返回409。查询的ID不存在时返回404。已完成的环节不能回退，返回409。已完成的子记录不受影响，只更新未完成的。金额为负数或零返回400。
项目能启动和测试就行，用 H2 数据库。
