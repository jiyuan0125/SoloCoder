帮我做一套SFTP文件同步，用Spring Boot。
Spring Boot。
定时从远程SFTP服务器下载指定目录的文件到本地。
完成之后自动把数据同步到月度汇总表。
支持文件名模式匹配（正则表达式）、增量同步（只下载新增和修改的文件）。
下载后校验文件大小和修改时间。
同步完成后触发后续处理（回调通知）。
连接超时和认证失败能正确识别并记录。
用 JSch 或 Apache Commons VFS 实现。
SFTP文件同步的配额变更后，关联的明细项需要同步更新。
SFTP文件同步有创建、更新、移除、查看几种操作，每种操作有独立的接口。SFTP文件同步下面还挂了明细，明细也有自己的接口。
用Maven构建。
名称唯一，重复创建返回409。关联的主记录不存在时返回404。已关闭的记录不能再修改状态，返回409。已完成的子记录不受影响，只更新未完成的。时间范围不合法（结束早于开始）返回400。
