做一个 Base64 编解码工具。界面分两个功能区：文本编解码和文件编解码。

文本编解码：左右两个文本框，左边输入原文，右边实时显示 Base64 编码结果（或反过来，左边输入 Base64 字符串，右边显示解码后的原文）。支持 UTF-8 编码，中文内容也能正确编解码。一键复制按钮方便把结果复制到剪贴板。

文件编解码：用户选择一个本地文件，工具把文件内容编码为 Base64 字符串（显示在文本框里），或者把 Base64 字符串解码保存为文件。如果是图片文件，编码后在下方显示图片预览。解码时自动检测原始文件类型（通过 Base64 前缀的 data URI 判断）。

批量处理模式：选择多个文件，批量编码或批量解码。批量操作显示进度条，处理完成后汇总报告成功和失败的数量。输出文件默认保存到源文件同级目录，文件名加 _encoded 或 _decoded 后缀。目标文件已存在时自动加序号避免覆盖。

URL-safe Base64 模式：标准 Base64 的 + 和 / 替换为 - 和 _，去掉末尾的 = 填充。提供切换按钮在标准模式和 URL-safe 模式之间切换。

历史记录保存最近 20 次操作。

界面用 HTML+CSS+JS 渲染，文件读写和编解码计算走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能正常使用。
