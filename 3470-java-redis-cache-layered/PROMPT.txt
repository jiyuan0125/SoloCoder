业务那边需要一套多级缓存服务，用Spring Boot做。
L1 用 Caffeine 本地缓存（最大容量、过期时间可配），
L2 用 Redis。
查询时先查 L1，没有再查 L2，都没有查数据库并回写两级缓存。
更新时两级缓存同时失效。
支持批量查询和批量失效。
当提交完成后，自动给关联方生成一条通知。没有关联方就不生成。
缓存key支持自定义前缀和过期策略。
多级缓存服务有新增、修改、删除、查看详情几种操作，每种操作有独立的接口。多级缓存服务下面还挂了附件，附件也有自己的接口。
用 Spring Cache + Caffeine + Redis 实现。
需要维护教室的信息，课程安排录入时选择对应的教室。
编码唯一，重复创建返回409。查询的ID不存在时返回404。并发扣减不能超卖，库存为0时返回400。两个操作要么都成功要么都失败，不能出现中间状态。统计为空返回空数组不是404。
本地跑起来就行。
