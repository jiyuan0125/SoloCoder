最近在搞这块，需要一个MQTT设备网关，用Spring Boot来实现。
接收物联网设备通过MQTT协议上报的数据（JSON格式）。
设备注册后分配topic，每个设备有独立的数据上报topic。
确认完成时自动在统计模块新增一条汇总记录。
服务端订阅设备topic接收数据，解析后存储到数据库。
支持设备指令下发，通过MQTT发布到设备专属控制topic。
设备离线检测：超过5分钟没收到心跳自动标记为离线。
设备重新上线后自动恢复在线状态并补发离线期间的通知。
用 Eclipse Paho 或 Spring Integration MQTT 实现。
流程分创建、审核、执行、完成四步走，创建不通过退回，执行之后到完成。
修改了MQTT设备网关的配额之后，下面挂的分配记录要按比例重新分配。
记录编号唯一，重复提交返回409。操作的目标记录不存在时返回404。不能跳步，比如不能从创建直接到完成，非法跳转返回400和当前状态。查询结果为空返回空数组不是404。
