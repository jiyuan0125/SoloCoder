我们最近需要一套审计日志服务，用Spring Boot做。
记录系统所有关键操作的审计日志。
日志字段包括操作人、操作类型、操作时间、
操作前后数据快照（JSON diff）、IP地址。
日志量很大，用 MongoDB 存储。
修改了审计日志服务的金额之后，下面挂的子记录要按比例重新分配。
支持按操作人、时间范围、操作类型组合查询。查询结果分页返回。
日志一旦写入不可修改和删除。
用 Spring Data MongoDB 实现。
接口按资源层级组织：审计日志服务的管理接口，以及审计日志服务下面附件的新增、修改接口。
用Maven构建。
编号唯一，重复创建返回409。记录不存在时返回404不是500。已完成的子记录不受影响，只更新未完成的。名称为空时返回400。搜索无结果返回空列表不是报错。
项目能正常跑起来就行。
