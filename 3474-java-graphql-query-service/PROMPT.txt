用Spring Boot帮我写一个用搭一个GraphQL查询。
有几种实体：用户、订单、商品、评论，它们之间有关联关系。
支持按条件查询和关联查询，查用户时可以同时查他的订单和评论。
支持分页和排序，分页参数包括页码和每页数量。
当创建完成后，自动给关联方生成一条通知。没有关联方就不生成。
mutation 支持创建和更新操作，输入参数要做校验。
需要维护客户的信息，订单录入时选择对应的客户。
查询深度要有限制，防止嵌套过深导致性能问题。
用搭一个GraphQL查询有创建、更新、移除、查看几种操作，每种操作有独立的接口。用搭一个GraphQL查询下面还挂了子项，子项也有自己的接口。
关联查询要避免N+1问题。
用 Spring for GraphQL 实现。
用Maven构建。
本地跑起来就行。
