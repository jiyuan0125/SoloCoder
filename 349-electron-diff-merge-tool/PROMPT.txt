做一个文件差异合并工具。支持三栏对比视图：左边是"我的版本"，中间是"基础版本"（共同祖先），右边是"对方版本"。三栏同步滚动，差异区域用颜色块标记——纯新增用绿色、纯删除用红色、双方都修改了同一处用黄色标记为冲突。

冲突区域提供三个按钮：采用左边、采用右边、手动编辑。手动编辑模式下中间栏变成可编辑的文本框，用户可以自由修改冲突内容。解决完所有冲突后可以导出合并后的文件。

两栏对比模式也支持：如果不需三栏合并，可以只打开两个文件做左右对比，功能类似文本对比工具——差异高亮、上下一个差异跳转。

文件加载：从本地选择文件打开，支持编码自动检测（UTF-8、GBK 等）。文件修改时间显示在每个栏的标题栏上，帮助用户判断哪个是最新的版本。

行号显示在三栏左侧，方便定位。差异统计显示在工具栏：新增多少行、删除多少行、修改多少行、冲突多少处。

合并结果导出：解决完冲突后，把合并结果保存到本地文件。也可以选择保存为"我的版本"或"对方版本"的副本。

界面用 HTML+CSS+JS 渲染，文件读取和差异算法走后端处理，前后端通过 Electron IPC 通信。代码按功能分文件，package.json、main.js、前端页面齐全，npm install 后 npm start 能正常使用。
