项目里程碑管理服务，用Spring Boot实现。
项目状态：规划中→进行中→暂停→已完成→已关闭。
里程碑状态：未开始→进行中→已完成→已逾期。
项目进行中才能操作里程碑。
里程碑逾期（超过截止日期未完成）自动标记。
所有里程碑完成后项目才能标记完成。
项目里程碑管理服务有分配、转派、加急处理、关闭几种操作，每种操作有独立的接口。项目里程碑管理服务下面还挂了变更记录，变更记录也有自己的接口。
暂停的项目不自动检查逾期。
重新启动后补查逾期。
提供查询项目进度和里程碑状态的接口。
每次完成后自动从对应账户扣除相关金额。没关联到账户就跳过。
流程分新建、评审、确认、归档四步走，新建不通过退回，确认之后到归档。
编码唯一，重复创建返回409。查询的ID不存在时返回404。已完成的环节不能回退，返回409。两个操作要么都成功要么都失败，不能出现中间状态。时间范围不合法（结束早于开始）返回400。
用Maven构建。
