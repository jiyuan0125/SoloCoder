用Spring Boot帮我写一个退货退款流程服务。
退货状态：申请中→审核通过→待退货→已退货→质检中→退款中→已退款。
审核拒绝和质检不合格是异常状态。
退货申请7天未审核自动通过。
用户退货后填写物流单号。
退货退款流程服务的完整流程是登记、审核、处理、结案，每个阶段过了才能到下一个。结案没过可以退回到审核。
质检不合格时可以选择退款（折价）或退回商品。
退款金额不能超过实付金额。
已退款的退货单不可再操作。
接口按资源层级组织：退货退款流程服务的管理接口，以及退货退款流程服务下面子项的创建、更新接口。
提供查询退货进度和退款状态的接口。
用Maven构建。
记录编号唯一，重复提交返回409。操作的目标记录不存在时返回404。不能跳步，比如不能从创建直接到完成，非法跳转返回400和当前状态。查询结果为空返回空数组不是404。
项目能正常跑起来就行。
