现在需要一个用户资料展示，用Spring Boot。
用户可以设置个人简介、昵称、头像URL。
其他用户可以通过用户ID查看资料。
资料页面支持自定义样式：用户可以在简介里写富文本，
接口按资源层级组织：用户资料展示的管理接口，以及用户资料展示下面附件的创建、更新接口。
系统渲染后展示。
提供一个搜索接口，支持按昵称关键词搜索用户列表。
用户资料展示的完整流程是申请、初审、终审、归档，每个阶段过了才能到下一个。归档没过可以退回到初审。
用户也可以设置资料对外是否可见。
用Maven构建。
编号唯一，重复创建返回409。记录不存在时返回404不是500。状态只能按顺序流转，非法跳转返回400和当前状态。搜索无结果返回空列表不是报错。
本地跑起来就行。
