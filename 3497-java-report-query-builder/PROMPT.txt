帮我做一套报表查询，用Spring Boot。
Spring Boot。
管理员可以创建自定义报表，
定义查询SQL模板。
系统要管理用户和操作日志，操作日志创建时要关联到用户。
用户通过前端选择条件后，
报表查询的完整流程是创建、审核、执行、完成，每个阶段过了才能到下一个。完成没过可以退回到审核。
系统把条件拼接到SQL模板里执行查询返回结果。
报表支持按部门、日期、状态等条件筛选。
查询结果可以导出。
不同角色看到不同的报表列表。
用Maven构建。
名称唯一，重复创建返回409。关联的主记录不存在时返回404。已关闭的记录不能再修改状态，返回409。两个操作要么都成功要么都失败，不能出现中间状态。名称为空时返回400。
本地跑起来就行。
