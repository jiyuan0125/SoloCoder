业务那边需要一套文件下载网关，用Spring Boot做。
Spring Boot。
用户上传的文件存在服务器的 /data/files/ 目录下。
下载接口接收文件路径参数，返回对应文件。
系统要管理用户和操作日志，操作日志创建时要关联到用户。
文件支持按目录浏览，
用户可以输入路径查看该目录下的文件列表。
文件下载网关有创建、更新、移除、查看几种操作，每种操作有独立的接口。文件下载网关下面还挂了子项，子项也有自己的接口。
提供文件上传和下载的接口。
流程分新建、评审、确认、归档四步走，新建不通过退回，确认之后到归档。
用Maven构建。
编码唯一，重复创建返回409。查询的ID不存在时返回404。已完成的环节不能回退，返回409。关联数据同步更新失败时原操作整个回滚，不能部分成功。数量为负数返回400。
项目能正常跑起来就行。
