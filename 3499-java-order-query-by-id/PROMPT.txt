最近在搞这块，需要一个订单查询，用Spring Boot来实现。
用户登录后可以查询自己的订单。
订单详情包含收货人姓名、电话、地址。
系统支持通过订单ID直接查询订单信息，也支持按用户查询订单列表。
客服人员可以查询所有用户的订单。
不同用户看到的数据范围不同。
订单查询有分配、转派、加急处理、关闭几种操作，每种操作有独立的接口。订单查询下面还挂了操作记录，操作记录也有自己的接口。
提供订单创建和查询的接口。
订单查询的完整流程是新建、评审、确认、归档，每个阶段过了才能到下一个。归档没过可以退回到评审。
当创建完成后，自动给关联方生成一条通知。没有关联方就不生成。
用Maven构建。
本地跑起来就行。
