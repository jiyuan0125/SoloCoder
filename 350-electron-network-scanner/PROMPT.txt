做一个局域网扫描工具。用户输入起始 IP 和结束 IP（或一个 IP 段如 192.168.1.0/24），工具扫描该范围内所有可达的设备。主界面上方是扫描配置区（IP 范围、端口范围、扫描超时时间），下方是扫描结果表格。

扫描结果展示：IP 地址、设备名称（如果能解析到）、MAC 地址、响应延迟、开放的端口列表。点击某行展开查看详细信息。扫描进度实时显示在界面上（已扫描/总数），可以随时停止扫描。

端口扫描：用户可以指定要扫描的端口范围（如 1-1000 或 80,443,8080），也可以选择常见端口预设（Web 服务、数据库、SSH 等）。扫描结果中每个设备下方列出检测到的开放端口和对应的服务名称。

设备信息展示：尝试通过 mDNS 或 NetBIOS 解析设备名称。扫描完成后可以按 IP、设备名、延迟排序，关键词搜索过滤。

扫描历史保存最近 20 次扫描记录（时间、IP 范围、扫描结果摘要），方便回溯对比。两次扫描之间可以对比——找出新增的设备或消失的设备。

导出扫描结果为 CSV 或 JSON 文件。扫描超时时间默认 500ms，可以在设置里调整，超时越短扫描越快但可能漏掉响应慢的设备。

界面用 HTML+CSS+JS 渲染，网络扫描操作走后端处理，前后端通过 Electron IPC 通信。代码分模块组织，package.json、main.js、前端页面齐全，npm install 后 npm start 能用。
