最近在搞运维这块，需要一个在线日志查看服务，用 Spring Boot 做。
系统运行日志存在文件系统上，路径在配置文件里指定。
提供一个 Web 接口浏览日志文件内容，支持按关键词搜索、按时间范围过滤、按级别筛选。
日志内容可能包含数据库连接串、API密钥这些敏感信息，搜索的时候如果匹配到了要脱敏展示，但导出完整日志的时候不脱敏。
管理员可以配置要监控的日志文件路径，路径变更后之前保存的搜索条件里引用旧路径的记录自动更新为新路径。
日志文件可能非常大，几百MB那种，不能一次全加载到内存。

创建时如果必填字段缺失返回 400 和具体缺少哪个字段的提示。修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。状态变更前校验当前状态是否允许该操作，不允许返回 400 和当前状态。列表接口支持分页，不传分页参数时默认返回前 20 条。

Maven 项目，H2 数据库。
