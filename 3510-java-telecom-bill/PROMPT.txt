最近在搞通信计费这块，需要一个话单计费系统，Spring Boot 做。
用户有套餐，套餐内包含通话分钟数和流量，套餐内免费。超出部分通话0.15元每分钟、流量5元每GB。
亲情号码之间通话免费，最多设5个亲情号。夜间23:00到7:00的流量半价。
国际长途单独计费，不同国家不同费率。
用户如果月中换了套餐，旧套餐剩余的通话分钟和流量按天折算退到新套餐里。新套餐从生效当天开始按天计算包含量。
月末出账单，账单要列出每项明细。

状态只能按规定的流转路径走，跳步或回退都返回 400 并告诉当前合法的下一步操作是什么。金额计算用整数（分）存储和运算，展示时再转为元。数量和金额参数为 0 或负数时返回 400。

Maven 项目，H2 数据库。
