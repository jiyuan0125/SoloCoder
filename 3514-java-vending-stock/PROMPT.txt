用 Spring Boot 实现自动售货机补货系统。
每台机器有多个货道，每个货道放一种商品，有容量上限。系统根据最近7天的日均销量预测补货需求。补货时保质期短的优先出库，先进先出。
商品剩余保质期不足3天的标记为临期品自动打折。每种商品设最低库存量，低于最低库存触发补货提醒。
补货人员确认补货后，系统自动扣减仓库中对应商品的库存并更新售货机货道库存。如果仓库中该商品不够补货量，能补多少补多少，剩余的生成缺货记录。

更新操作要对记录做存在性校验，不存在返回 404。扣减类操作和对应的状态变更要么都成功要么都失败，不能出现扣了但状态没变的情况。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。

Maven 项目，H2 数据库。
