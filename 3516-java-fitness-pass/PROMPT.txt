用 Spring Boot 做健身次卡管理系统。
用户购买次卡有20次、50次、100次三种，每次使用扣一次。次卡可以冻结，比如出差期间，冻结期间不扣次数也不算有效期。一张卡最多冻结3次，每次最多30天。
次卡过期后未用完的次数可以折算退款：退款金额等于购买价乘以剩余次数除以总次数再乘以0.7。
次卡使用时系统要校验该门店是否在用户所在城市，同时要扣减对应城市的门店可用次数。如果门店被关停了，用户在这家店剩余的次数自动转移到同城最近的一家店。

新增记录时如果同名记录已存在返回 409。已完成或已关闭的记录不允许再修改，尝试修改返回 400。金额计算用整数（分）存储和运算，展示时再转为元。

Maven 项目，H2 数据库。
