Spring Boot 写拼车费用分摊服务。
总费用等于里程乘以单价。白天1.5元每公里、夜间2.0元、高峰时段2.5元。费用按乘客人数均摊，司机不付费。
如果乘客有优惠券，先从个人应付中抵扣，抵扣后的差额不影响其他人的分摊金额。超过3人的拼车单总价打8折。
行程结束后系统自动给每个乘客生成一条待支付记录，同时给司机的账户加上这笔收入。乘客支付完成后自动更新行程状态为已结算。
每周出一趟拼车费用汇总。乘客可以对拼车体验打分和评价。

重复创建同一条记录返回 409 而不是再创建一份。修改不存在的记录返回 404。状态流转的每一步都要记录操作时间和操作人。退款金额不能超过原支付金额，超了返回 400。

Maven 管理，H2 存储。
