用 Spring Boot 写一个菜谱份量调整工具。
菜谱有标准份量比如4人份，用户可以调整到任意人数，系统自动换算食材用量。换算后的用量取合理精度，不能出现0.33个鸡蛋这种。
菜谱有步骤说明，每步有预计时间。用户可以收藏菜谱，也可以上传自己的菜谱。
菜谱的食材如果有应季变化（比如某种蔬菜冬天特别贵），系统在推荐时标注当季价格参考。按菜谱做完后可以打分和评论。
食材用量换算后保留常用单位比如克和毫升。

状态流转的每一步都要记录操作时间和操作人。扣减类操作和对应的状态变更要么都成功要么都失败，不能出现扣了但状态没变的情况。列表接口支持分页，不传分页参数时默认返回前 20 条。

Maven 项目，H2 存储。
