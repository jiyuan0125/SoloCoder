用 Spring Boot 写一个睡眠追踪服务。
用户每天记录入睡时间和起床时间，系统计算睡眠时长并评估睡眠质量。如果连续几天睡眠不足触发提醒。
可以按周、按月查看睡眠报告，报告里有趋势变化。长期睡眠质量不好的用户推荐就医提醒。
用户设置每日睡眠目标时长，如果某天没达到目标，系统自动在周报里标注这一天。但如果用户标注了当天是夜班或特殊原因，这天不计入连续不足天数。
支持设置每日睡眠目标时长。

分页查询时 page 超出范围返回空数组，page 为负数或非数字返回 400。已完成或已关闭的记录不允许再修改，尝试修改返回 400。单次批量操作不超过 100 条，超了返回 400。

Maven 管理，H2 数据库。
