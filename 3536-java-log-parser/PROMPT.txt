Spring Boot 写一个日志解析分析工具。
日志文件可能有各种格式，JSON的、纯文本的、带时间戳的，每行的格式可能不完全一致。系统要能处理大文件几百MB那种，遇到格式不对的行不要崩溃记录下来继续处理。
解析后统计每个错误级别的出现次数和时间分布。支持按关键词搜索日志内容，搜索结果按时间排序。
解析完成后自动把统计结果同步到历史趋势表里，如果同一份日志重复解析，之前的结果不覆盖，而是追加一条新的解析记录。
解析结果支持导出为结构化的JSON文件。

分页查询时 page 超出范围返回空数组，page 为负数或非数字返回 400。已完成或已关闭的记录不允许再修改，尝试修改返回 400。单次批量操作不超过 100 条，超了返回 400。

Maven 项目，H2 存结果。
