Spring Boot 做一个数据迁移工具。
从源数据库读取数据写入目标数据库。源数据可能有各种问题：字段缺失、类型不对、编码异常、重复记录。
迁移过程要记录每条失败的数据和失败原因，不要因为一条数据失败就停掉整个迁移。
支持断点续传，中断后重新运行从上次位置继续。迁移完成后做一次源和目标的数据量校验。
迁移完自动生成差异报告，报告里有源端总数、目标端总数、失败数。如果某条记录迁移失败但目标端已经有部分字段写入了，这条算失败但已写入的部分不回滚。

重复创建同一条记录返回 409 而不是再创建一份。空字符串、null、负数这些非法输入要拦截返回 400。ID 格式不合法时返回 400。

Maven 管理，H2 做迁移记录。
