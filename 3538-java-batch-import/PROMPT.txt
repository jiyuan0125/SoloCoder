用 Spring Boot 写一个批量数据导入服务。
支持 CSV 和 Excel 文件上传。文件可能很大几万行那种。导入时要做数据校验：必填字段不能空、数字字段不能是文本、日期格式要统一。
校验失败的数据单独导出一份错误报告，正确的数据正常入库。文件编码可能是 UTF-8 也可能是 GBK。
导入完成后自动触发数据校验回调，检查入库的行数是否和源文件一致。如果少了要记录差异明细。
导入过程实时显示进度百分比。

列表接口支持分页，不传分页参数时默认返回前 20 条。空字符串、null、负数这些非法输入要拦截返回 400。排序字段如果传了不存在的字段名返回 400。

Maven 项目，H2 存储。
