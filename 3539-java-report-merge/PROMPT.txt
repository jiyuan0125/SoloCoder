Spring Boot 实现报表合并服务。
多个部门提交月度报表，格式基本一样但可能有细微差异。系统合并成一份总报表。
有的部门可能漏填了某些字段，有的部门数据格式略有不同。合并时要处理空值、格式归一化、金额单位统一。
合并完成后自动和上月数据做环比对比，如果某个部门的某项数据环比波动超过50%，在合并报告里标注为异常项。
合并后的报表可以和上个月的数据做环比对比。

创建成功返回 201，参数不合法返回 400 并说明哪个字段有问题。同一份数据的并发修改通过版本号或时间戳做乐观检查，冲突时返回 409。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。

Maven 管理，H2 存储。
