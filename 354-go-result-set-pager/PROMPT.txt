写一个 Go 分页查询辅助库。后端接口返回列表数据时前端传页码和每页大小，后端需要计算总页数、是否有上下页、返回当前页的数据切片。

提供两种分页模式：偏移量分页（适合小数据量直接从切片取）和游标分页（适合大数据量，用上一页最后一条记录的ID作为下一页起点）。两种模式都返回统一结构体，包含数据列表、当前页码、每页数量、总记录数、总页数、是否有上一页和下一页。每页大小自动限制在1到100之间，超出范围修正。总记录数为0时总页数为0不是1。偏移量分页中如果请求的页码超出总页数，返回空数据列表而不是报错，当前页码设为最后一页。游标分页中游标值为空字符串时表示从第一页开始取。游标分页不支持跳页，只能通过上一页返回的游标取下一页。偏移量分页中数据源为nil时视为空切片处理。返回的结构体还要包含总数据量的偏移量位置方便前端展示"第X到第Y条共Z条"。每页大小为0时自动修正为默认值20。偏移量分页的offset计算公式为(page-1)*pageSize，传入page为1时offset为0是第一页。

核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口做分页查询，客户端通过命令行调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。
