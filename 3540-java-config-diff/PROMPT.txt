Spring Boot 写一个配置文件对比工具。
对比两份 YAML 配置文件的差异，输出哪些 key 新增了、删除了、值变了。配置文件可能嵌套很深也可能有数组。
遇到类型不匹配的情况也要标记出来，比如一个用字符串 true，另一个是布尔 true。对比结果可以导出。支持对比历史版本。
配置变更后自动通知订阅该配置的应用实例刷新。如果某个应用实例通知失败，记录到失败列表但其他实例正常推送。
支持忽略某些 key 的变更。

新增时如果关联的上级记录不存在返回 404 和具体哪个关联不存在。删除时如果记录已被引用导致无法删除返回 409 说明原因。已完成或已关闭的记录不允许再修改，尝试修改返回 400。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。

Maven 项目，H2 存对比记录。
