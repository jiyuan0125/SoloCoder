用 Spring Boot 做文件格式转换服务。
支持 CSV 转 JSON、JSON 转 CSV、Excel 转 CSV 等常见转换。文件可能有各种编码，UTF-8、GBK、带BOM的。
大文件要分块处理不能一次全加载到内存。转换失败时返回具体哪一行出了什么问题。
转换完成后自动校验：源文件行数和目标文件行数是否一致（允许有差异但差异超过5%要警告）。
转换后的文件可以下载。支持批量转换，一次上传多个文件排队处理。

状态只能按规定的流转路径走，跳步或回退都返回 400 并告诉当前合法的下一步操作是什么。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。时间范围查询如果开始时间晚于结束时间返回 400。

Maven 项目，H2 存转换记录。
