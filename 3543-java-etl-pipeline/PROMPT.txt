Spring Boot 写一个简易 ETL 管道。
数据从 CSV 文件抽取，经过清洗转换后加载到数据库。清洗规则：去前后空格、空值填充默认值、日期格式统一、手机号去加86前缀。转换规则：金额统一为分、状态码映射为中文。
每一步都记录处理了多少条、失败了多少条。管道的步骤顺序可以配置。
管道执行完自动发一封汇总邮件给负责人，邮件里包含各步骤的处理结果。如果邮件发送失败，汇总结果还是正常入库只是不发邮件。

重复创建同一条记录返回 409 而不是再创建一份。状态变更前校验当前状态是否允许该操作，不允许返回 400 和当前状态。金额计算用整数（分）存储和运算，展示时再转为元。

Maven 管理，H2 存储。
