Spring Boot 写一个数据清洗工具。
输入是一批待清洗的数据通过 API 接收。清洗规则包括：姓名去多余空格、手机号只保留数字并统一加前缀、邮箱转小写、地址标准化去掉省市等后缀再统一格式。
重复记录按手机号去重保留最新一条。清洗完返回清洗报告，报告里包含各规则的命中数量和清洗前后的对比。
清洗完成后自动把清洗结果同步到下游报表系统。如果下游接口超时，清洗结果还是正常入库，同步失败记录到重试队列。
清洗规则可以保存为模板方便下次复用。

重复创建同一条记录返回 409 而不是再创建一份。状态流转的每一步都要记录操作时间和操作人。创建时间不能晚于当前时间。

Maven 管理，H2 存清洗日志。
