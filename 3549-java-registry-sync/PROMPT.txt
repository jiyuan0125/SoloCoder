Spring Boot 做一个登记信息同步系统。
三个登记处各自录入信息，系统要合并三方的数据。同一笔业务可能在多个登记处都有记录，按业务编号去重取信息最完整的那条。
如果同一编号不同登记处的关键字段不一致，比如金额或日期对不上，标记为待核实。合并后的数据可以按来源追溯。
待核实的记录人工确认后，系统自动更新为确认状态并同步到各登记处。如果某个登记处同步失败，本地还是更新为已确认，失败的同步记录到重试队列。

创建时如果必填字段缺失返回 400 和具体缺少哪个字段的提示。已完成或已关闭的记录不允许再修改，尝试修改返回 400。扣减类操作和对应的状态变更要么都成功要么都失败，不能出现扣了但状态没变的情况。

Maven 管理，H2 存储。
