用 Spring Boot 写一个归档文件解压服务。
支持 ZIP 和 TAR.GZ 格式。归档文件可能很大，里面可能还有嵌套的压缩包要递归解压。文件名可能是中文或者特殊字符，解压出来保留原始目录结构。
损坏的压缩包给出明确提示不崩溃。解压完统计文件数量和总大小。
解压完成后自动扫描解压出来的文件，如果发现文件名包含敏感关键词（比如 password、secret），标记为待审查。
解压前可以预览压缩包内容不实际解压。

分页查询时 page 超出范围返回空数组，page 为负数或非数字返回 400。排序字段如果传了不存在的字段名返回 400。ID 格式不合法时返回 400。

Maven 项目，H2 存解压记录。
