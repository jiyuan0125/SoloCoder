Spring Boot 写一个应用内事件总线。
业务模块可以发布事件和订阅事件，事件通过总线路由到对应的订阅者。订阅关系配置在数据库里。
事件处理失败时重试3次，还是失败就进死信队列。事件处理要有日志，能追踪一个事件从发布到处理完成的完整链路。
某个订阅者处理完事件后如果需要发布新事件，新事件也走总线路由。事件处理过程中如果发布者和订阅者是同一个模块且操作同一份数据，不能因为递归处理导致数据不一致。
发布者、订阅者、路由器、持久化分开设计。

创建成功返回 201，参数不合法返回 400 并说明哪个字段有问题。同一时间只允许一个状态变更操作执行，防止并发操作导致状态错乱。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。

Maven 管理，H2 存储。
