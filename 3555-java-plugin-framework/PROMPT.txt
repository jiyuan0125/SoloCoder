用 Spring Boot 写一个插件管理框架。
插件是一个独立的 jar 包，放到指定目录后系统自动加载。每个插件有自己的生命周期：加载、初始化、运行、销毁。插件之间通过注册表发现彼此。
插件不能直接访问主应用的数据库连接，只能通过注册的接口交互。
插件加载时如果依赖的接口还没注册好，进入等待状态等依赖就绪后再初始化。如果等待超过30秒还没就绪，标记为加载失败。
插件加载和卸载不影响主应用运行。

新增时如果关联的上级记录不存在返回 404 和具体哪个关联不存在。同一时间只允许一个状态变更操作执行，防止并发操作导致状态错乱。列表接口支持分页，不传分页参数时默认返回前 20 条。

Maven 项目，H2 存储。
