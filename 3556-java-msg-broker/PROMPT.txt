Spring Boot 实现一个简易消息中间件。
支持 Topic 和 Queue 两种模式。生产者发消息，消费者订阅消费。消息持久化到数据库，消费者宕机后重启从上次位置继续消费。
消费失败的消息进死信队列，有专门的接口查看和重发。
消费者处理消息时如果需要查询数据库，查询结果要和消息内容一起做校验。如果校验失败消息进死信但已经写入数据库的部分不回滚。
队列的堆积数量超过阈值自动告警。

新增记录时如果同名记录已存在返回 409。查询接口如果传了不支持的排序字段返回 400。状态流转的每一步都要记录操作时间和操作人。数量和金额参数为 0 或负数时返回 400。

Maven 管理，H2 存储。
