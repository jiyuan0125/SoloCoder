Spring Boot 实现一个多租户管理平台。
每个租户有独立的数据空间，通过租户ID隔离。租户管理员管理自己的用户和业务参数。系统管理员管理所有租户可以开通停用。
租户之间的数据不能串。租户的配额快用完的时候自动提醒管理员，超配额的操作直接拒绝。
新租户开通时从默认模板创建初始配置，同时自动创建租户的管理员账号和默认角色。如果角色创建失败，租户还是算开通成功，只是管理员暂时没有权限需要后续补建。

新增时如果关联的上级记录不存在返回 404 和具体哪个关联不存在。同一份数据的并发修改通过版本号或时间戳做乐观检查，冲突时返回 409。数量和金额参数为 0 或负数时返回 400。

Maven 管理，H2 存储。
