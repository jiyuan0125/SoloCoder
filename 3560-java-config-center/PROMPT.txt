Spring Boot 写一个配置中心服务。
配置按环境和分组管理，环境有 dev、test、prod。配置有版本历史，每次修改生成新版本。支持回滚到任意历史版本。
配置修改后通知订阅的应用实例刷新。灰度发布：先推给指定实例验证没问题再全量推送。
配置变更支持审批流程，重要配置不能随便改。
回滚到旧版本后，之前在旧版本之后发布的配置变更记录不删除，保留完整历史。灰度推送失败的实例自动进入重试队列。

修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。取消操作只能对合法状态的记录执行，状态不对返回 400。同一时间只允许一个状态变更操作执行，防止并发操作导致状态错乱。空字符串、null、负数这些非法输入要拦截返回 400。

Maven 管理，H2 存储。
