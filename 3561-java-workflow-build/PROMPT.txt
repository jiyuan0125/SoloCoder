用 Spring Boot 实现一个工作流构建引擎。
工作流由节点和连线组成，节点类型包括审批节点、通知节点、条件分支、并行分支、汇聚节点。构建时校验流程合法性，不能有孤立节点，条件分支必须配汇聚。
执行引擎按流程定义驱动流程运转，每个节点执行完更新状态。
工作流版本更新后，正在执行中的流程实例继续用旧版本跑完，新发起的实例用新版本。
节点执行失败支持重试和跳过两种策略。

修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。创建时如果必填字段缺失返回 400 和具体缺少哪个字段的提示。状态只能按规定的流转路径走，跳步或回退都返回 400 并告诉当前合法的下一步操作是什么。单次批量操作不超过 100 条，超了返回 400。

Maven 项目，H2 存储。
