Spring Boot 实现一个通用限流服务。
限流规则按接口路径配置，支持三种算法：固定窗口、滑动窗口、令牌桶。限流维度支持全局限流、按用户限流、按IP限流。同一个接口可以同时配置多个维度的限流规则，请求需要同时通过所有维度检查才能放行，任一维度触发限流就直接返回429。被限流的请求返回429状态码和剩余等待时间，响应头里带上触发限流的具体维度名称。统计每个接口的QPS和限流次数，查询统计时接口路径不存在返回404而不是空数组。限流规则可以动态调整不需要重启。
限流规则变更后，旧的限流计数器不重置，新规则对当前窗口的后续请求生效。删除限流规则时如果该接口还有正在生效的计数器数据，计数器一并清除而不是留着累积。配置接口路径时传空字符串或 null 返回 400。
Maven 管理，H2 存储。
