用 Spring Boot 写一个加解密工具服务。
支持 AES-256、RSA、SM4 三种对称和非对称加密。密钥分层次管理：主密钥加密数据密钥，数据密钥加密业务数据。
提供签名和验签接口，支持 RSA-SHA256 和 SM3。密钥定期轮换，旧密钥解密后用新密钥重新加密。
密钥轮换后，之前用旧密钥加密的数据还是能解密（旧密钥保留为只读），新数据用新密钥加密。如果解密时发现密钥已经被标记为废弃，记录一条告警日志。
加解密操作记录审计日志。

创建成功返回 201，参数不合法返回 400 并说明哪个字段有问题。单次批量操作不超过 100 条，超了返回 400。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。

Maven 项目，H2 存储。
