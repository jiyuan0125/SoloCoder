Spring Boot 实现一个邮件编排服务。
邮件内容支持 HTML 模板，模板里可以嵌入图片。支持添加附件，附件可以是本地文件或从 URL 下载。
收件人支持 To、Cc、Bcc 三种类型。批量发送时每封邮件内容可能不同通过变量替换实现。
发送失败记录原因支持重发。批量发送完成后自动生成发送报告，报告中包含各收件人的发送状态。如果报告生成过程中部分状态还没更新完，报告里按当前已有状态生成。
邮件发送队列支持优先级排序。

修改不存在的记录返回 404。已完成或已关闭的记录不允许再修改，尝试修改返回 400。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。

Maven 管理，H2 存储。
