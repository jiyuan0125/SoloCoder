Spring Boot 做一个多级缓存管理服务。
L1 用 Caffeine 本地缓存，L2 用 Redis（mock一个就行）。读取时先查L1，miss了查L2，再miss查数据库并回写缓存。写入时同时更新缓存和数据库。
支持几种失效策略：TTL过期、容量淘汰用LRU、手动失效。统计缓存命中率。
缓存key对应的源数据被删除后，下次查询会miss并从数据库加载（返回空）。但如果在miss期间有并发写入同一个key，可能导致旧数据被写回缓存。

分页查询时 page 超出范围返回空数组，page 为负数或非数字返回 400。重复创建同一条记录返回 409 而不是再创建一份。同一份数据的并发修改通过版本号或时间戳做乐观检查，冲突时返回 409。

Maven 管理，H2 存统计信息。
