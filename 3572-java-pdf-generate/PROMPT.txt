用 Spring Boot 写一个 PDF 生成服务。
基于模板生成 PDF 文档，模板支持变量替换、表格（动态行数）、页眉页脚含页码。超长表格自动分页，分页时表头在每页重复。支持中文字体。
生成的 PDF 可以直接下载或保存到服务器。提供预览接口返回首页截图。
PDF生成完成后自动通知调用方。如果通知接口超时，PDF文件还是正常生成和保存，只是通知状态标记为待重试。
支持给PDF加水印和设置访问密码。

状态只能按规定的流转路径走，跳步或回退都返回 400 并告诉当前合法的下一步操作是什么。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。排序字段如果传了不存在的字段名返回 400。

Maven 项目，H2 存生成记录。
