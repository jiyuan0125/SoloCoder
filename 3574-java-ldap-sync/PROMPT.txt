用 Spring Boot 写一个 LDAP 目录同步服务。
从公司的 LDAP 服务器拉取组织架构和人员信息同步到本地数据库。LDAP是树形结构本地是关系型数据库要做结构映射。
增量同步按修改时间戳只拉变化的部分。同步过程中如果某个节点读取出错跳过该节点继续处理。
同步完生成差异报告。如果某个用户在LDAP里被删除了，本地数据库里这个用户标记为已停用但不删除，关联的历史数据保持不变。

新增时如果关联的上级记录不存在返回 404 和具体哪个关联不存在。修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。同一时间只允许一个状态变更操作执行，防止并发操作导致状态错乱。时间范围查询如果开始时间晚于结束时间返回 400。

Maven 项目，H2 存储。
