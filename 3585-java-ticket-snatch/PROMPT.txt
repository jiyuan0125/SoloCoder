Spring Boot 做一个抢票服务。
车票有座位数，查询时显示余票。用户提交订单时扣减余票，扣完就显示无票。下单后有15分钟支付窗口，超时未支付自动取消订单释放座位。
一个用户同一车次只能买一张票。
支付成功后系统自动从用户账户扣款同时更新订单状态为已支付。扣款和状态更新要保证一致性。如果扣款成功但状态更新失败，订单实际已扣款但显示未支付。
支持候补：无票时可以排候补队列，有人退票时按顺序自动分配。

分页查询时 page 超出范围返回空数组，page 为负数或非数字返回 400。状态流转的每一步都要记录操作时间和操作人。退款金额不能超过原支付金额，超了返回 400。

Maven 管理，H2 存储。
