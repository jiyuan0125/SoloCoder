Spring Boot 写一个订单全生命周期管理服务。
订单状态：待支付、已支付、备货中、已发货、已签收、已完成。任何状态可以发起售后，售后审核通过后进入退款中然后已退款。已发货后可以确认收货变成已签收，超过15天自动确认。已签收后7天内可以申请售后。
取消订单只能在待支付状态操作。
退款完成后系统自动把商品库存加回去，同时给用户的账户退回支付金额。如果退回金额时用户账户已注销，金额退到用户绑定的银行卡。
订单每个状态变更都记录时间戳。

删除不存在的记录返回 404 而不是 200。状态流转的每一步都要记录操作时间和操作人。扣减类操作和对应的状态变更要么都成功要么都失败，不能出现扣了但状态没变的情况。

Maven 管理，H2 存储。
