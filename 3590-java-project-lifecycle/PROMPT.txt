用 Spring Boot 写项目全生命周期管理。
状态：立项申请、立项审批、需求确认、计划排期、开发中、测试中、验收、上线、结项。立项审批不通过可以修改后重新提交。
需求确认阶段可以变更需求，变更后重新排期。验收不通过回到开发中。
上线后观察一周没问题自动提醒结项。如果项目从"验收"被打回"开发中"，之前排期里的时间节点不自动清除，需要手动更新。
结项时生成项目总结报告。

新增记录时如果同名记录已存在返回 409。修改不存在的记录返回 404。状态只能按规定的流转路径走，跳步或回退都返回 400 并告诉当前合法的下一步操作是什么。创建时间不能晚于当前时间。

Maven 项目，H2 存储。
