用 Spring Boot 实现物流跟踪系统。
包裹状态：已揽收、运输中、到达中转站、离开中转站、派送中、已签收。运输过程中可能经过多个中转站。
包裹如果出现问题比如破损或丢失，可以标记异常，异常包裹走单独的复核通道。
包裹状态更新时系统自动检查状态流转是否合法，比如不能从"已揽收"直接跳到"已签收"。但异常包裹可以走特殊通道跳过某些节点。
已签收后可以确认收货，7天后自动确认。每个状态变更带时间和地点信息。

修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。新增记录时如果同名记录已存在返回 409。状态变更前校验当前状态是否允许该操作，不允许返回 400 和当前状态。数量和金额参数为 0 或负数时返回 400。

Maven 项目，H2 存储。
