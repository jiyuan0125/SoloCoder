用 Spring Boot 做一个订单查询服务。
用户登录后可以查看自己的订单列表，按订单号或商品名搜索。点击订单可以查看详情包括商品信息、金额、物流状态。
订单支持按时间范围筛选和按状态筛选。客服人员可以通过后台查看所有用户的订单。
用户可以对已完成的订单发起售后申请。售后申请提交后系统自动创建一条售后工单，同时把订单状态更新为售后中。
订单列表支持分页和排序。

查询接口如果传了不支持的排序字段返回 400。重复创建同一条记录返回 409 而不是再创建一份。状态变更前校验当前状态是否允许该操作，不允许返回 400 和当前状态。金额计算用整数（分）存储和运算，展示时再转为元。

Maven 管理，H2 存储。
