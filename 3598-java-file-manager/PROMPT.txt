Spring Boot 写一个文件管理服务。
用户可以创建文件夹、上传文件、下载文件、删除文件。支持按文件名搜索。每个用户有自己的根目录可以在下面建子目录。
文件上传时记录文件名、大小、上传时间。支持文件移动从一个目录移到另一个目录。
用户删除文件后文件进入回收站，7天后自动清除。清除时系统自动释放磁盘空间并更新用户的存储用量统计。
管理员可以查看所有用户的文件占用空间。

修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。重复创建同一条记录返回 409 而不是再创建一份。同一时间只允许一个状态变更操作执行，防止并发操作导致状态错乱。数量和金额参数为 0 或负数时返回 400。

Maven 项目，H2 存文件元数据，文件内容存磁盘。
