Spring Boot 做一个报表导出服务。
用户选择报表类型和时间范围系统生成报表文件供下载，支持CSV和Excel格式。报表类型包括销售日报、月度汇总、年度对比。
用户可以给导出的报表文件指定文件名。大数据量的报表后台生成完成后通知用户下载。
报表生成完成后系统自动更新报表导出记录的状态为已完成，同时生成一条下载链接。如果用户指定的文件名包含特殊字符导致文件创建失败，用默认文件名替代并记录一条告警。
导出记录保存在数据库里可以查看历史并重新下载。

更新操作要对记录做存在性校验，不存在返回 404。状态变更前校验当前状态是否允许该操作，不允许返回 400 和当前状态。库存扣减和订单创建是原子操作，库存不够时订单也不应该被创建。

Maven 管理，H2 存储。
