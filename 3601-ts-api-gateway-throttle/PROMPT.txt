用 TypeScript + Express 写一个 API 网关限流服务。
支持按用户ID、IP地址、接口路径三个维度配置不同的请求频率上限。
比如某个接口对普通用户限制每分钟60次，对VIP用户每分钟200次。
超出限制返回429状态码，同时在响应头里告诉客户端还剩多少配额。
限流规则通过配置文件管理，服务启动时加载，运行期间可以通过接口动态更新。
每个维度的限流数据用内存存储就行，不需要持久化。
请求被限流的时候要记录一条日志，包含被限流的维度信息和当前QPS。
提供一个查询接口可以看最近一小时的限流事件统计，按维度分组。
限流规则变更时要把旧规则保存到历史记录里。
项目用 TypeScript 写，能正常编译启动就行。
