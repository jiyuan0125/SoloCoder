用 Express + TypeScript 写一个 Mock API 服务。
用户配置接口路径、请求方法、响应状态码和响应体。支持根据请求参数条件匹配不同响应。
接口路径必须以/开头。同一个路径加方法组合只能有一条配置。
配置修改后实时生效不需要重启。配置支持导入导出JSON文件。
条件匹配规则修改后，之前匹配到该规则的请求历史记录不更新。

修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。创建成功返回 201，参数不合法返回 400 并说明哪个字段有问题。状态流转的每一步都要记录操作时间和操作人。空字符串、null、负数这些非法输入要拦截返回 400。

SQLite 存数据，能正常编译启动就行。
