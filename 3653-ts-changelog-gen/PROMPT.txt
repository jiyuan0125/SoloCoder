用 Express + TypeScript 写一个变更日志生成服务。
从 Git 提交记录中提取变更信息，按约定格式生成变更日志。支持按版本范围生成。
提交信息遵循 Conventional Commits 规范，自动分类为 feat、fix、breaking change 等。
版本标签变更后可以重新生成该版本的变更日志。之前的日志被新内容替换，但生成历史保留。
变更日志支持导出为 Markdown 文件。

修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。排序字段如果传了不存在的字段名返回 400。空字符串、null、负数这些非法输入要拦截返回 400。

SQLite 存数据，能正常编译启动就行。
