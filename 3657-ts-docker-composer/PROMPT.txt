Express + TypeScript 做一个 Docker Compose 可视化管理服务。
用户通过 Web 界面配置服务、网络、卷，系统生成 docker-compose.yml。支持导入已有 yml 文件解析。
服务配置支持环境变量、端口映射、挂载卷。配置修改后实时更新生成的 yml 文件。
服务依赖关系变更后，depends_on 字段自动更新。但已经生成的 yml 文件不会自动重新生成，需要手动触发。
支持配置版本管理和对比。

新增时如果关联的上级记录不存在返回 404 和具体哪个关联不存在。修改不存在的记录返回 404。列表接口支持分页，不传分页参数时默认返回前 20 条。

SQLite 存数据，能正常编译启动就行。
