用 Express + TypeScript 做一个版本发布管理工具。
管理版本号、变更记录、发布计划。版本号遵循语义化版本规范。
发布前自动检查所有待发布的变更是否已完成。未完成的变更可以移到下一版本。
版本发布后自动打 Git tag（mock 就行）。如果发布后发现有遗漏的变更，可以创建补丁版本。
发布记录保留完整历史。

修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。创建成功返回 201，参数不合法返回 400 并说明哪个字段有问题。已完成或已关闭的记录不允许再修改，尝试修改返回 400。批量操作时如果其中一条失败，已成功的要回滚，整个操作返回失败原因。

SQLite 存数据，能正常编译启动就行。
