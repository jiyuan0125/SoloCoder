写一个 Go 中国身份证号解析库。18位身份证号里包含了出生日期、性别和所在地等信息，系统注册时经常需要从身份证号提取这些信息做自动填充和格式校验。

支持校验身份证号格式合法性（包括第18位校验码验证）、提取出生日期（转为time.Time）、提取性别（第17位奇数男偶数女）、提取籍贯省份（前2位对应省份代码）、计算持有人当前年龄。内置所有省份代码到省份名称的完整映射。15位旧版身份证号也要兼容——自动补齐为18位。输入可能包含空格或全角字符要先清理。提取出生日期后验证日期合法性（不能是2月30号）。校验码算法：前17位分别乘以对应权重系数（7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2），求和后对11取模，根据余数查表得到校验字符（1,0,X,9,8,7,6,5,4,3,2）。输入长度既不是15也不是18时直接报错不做任何解析。15位身份证号的出生日期为6位数字（YYMMDD），补齐时年份前加19。

核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口做身份证号解析和校验，客户端通过命令行调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。
