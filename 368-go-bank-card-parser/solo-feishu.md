| User Prompt | 写一个 Go 银行卡号解析库。用户输入银行卡号后需要识别发卡银行和卡种（借记卡/信用卡），通过卡号前6位BIN码来判断。 支持Luhn算法校验银行卡号格式、通过BIN码识别发卡银行名称、格式化银行卡号为每4位加空格的显示格式（6222 0200 0000 0000）、卡号脱敏只显示后4位。内置常见银行的BIN码范围数据——至少覆盖工商银行、建设银行、农业银行、中国银行、招商银行、交通银行、邮储银行的主要BIN码段。卡号长度通常16到19位要支持这个范围。Luhn校验从右到左偶数位乘2大于9则减9。输入可能包含空格或横杠要先清理再校验。卡号全为0或全为同一个数字时Luhn校验失败直接返回无效。如果BIN码不在内置数据中，Luhn校验通过但无法识别银行时返回"未知银行"而不是报错。BIN码查询时先按6位精确匹配，匹配不到再尝试前5位、前4位逐级缩短查找。格式化时卡号不足16位按实际长度每4位分组，最后不足4位的单独一组。 核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口做银行卡号解析和校验，客户端通过命令行调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
