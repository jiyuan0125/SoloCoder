| User Prompt | 写一个 Go 订单号生成器。电商系统每秒可能产生大量订单，订单号需要全局唯一、趋势递增（方便数据库索引）、包含时间信息（方便排查问题）。 生成订单号——格式为yyyyMMddHHmmss加6位序列号加4位随机数。支持设置业务前缀（DD表示订单、TK表示退款单）。序列号在同一秒内自增下一秒归零。同一毫秒内多次调用保证序列号递增不重复。序列号用完6位（999999）后下一毫秒到来之前不能再生成订单号。还提供从订单号反解析出时间信息和业务前缀的函数。随机数部分使用math/rand而非crypto/rand，因为订单号不需要加密安全性但需要生成速度快。反解析时要能正确处理带前缀和不带前缀的订单号，反解析失败时返回错误而不是panic。4位随机数范围是0000到9999，主要作用是在极端高并发场景下降低同一秒内订单号碰撞的概率。时间部分使用服务器本地时区。不提供业务前缀时订单号直接以时间部分开头。上次的序列号和配置要存本地文件，重启后恢复序列号避免重复。 核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口生成和解析订单号，客户端通过命令行调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
