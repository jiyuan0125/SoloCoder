帮我写一个会员积分的 API 服务，Express + TypeScript，用 SQLite。
会员通过消费获取积分，每消费 1 元得 1 积分。积分有两种：普通积分（有效期 12 个月）和活动积分（有效期当次活动结束）。
积分使用时先消耗快过期的普通积分，再消耗其他的。扣减积分不支持部分扣，要么全部扣成功，要么全部不扣。
会员等级分三级：普卡（0-999 积分）、银卡（1000-4999）、金卡（5000+）。等级按累计获得的积分算，不是当前余额。
金卡会员消费可以享受 1.5 倍积分，但这个加成只在消费金额不超过 5000 元的部分生效，超出部分按 1 倍算。
需要查询接口：查积分余额（按类型分组）、查等级、查即将过期的积分。
启动后能正常响应请求就行。
能正常启动运行就行。
