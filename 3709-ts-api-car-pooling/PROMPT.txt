帮我写一个拼车匹配的 API 服务，Express + TypeScript + SQLite。
车主发布行程：出发地、目的地、出发时间、可载人数、每座价格。乘客发布需求：出发地、目的地、期望出发时间范围、人数。
匹配规则：路线方向一致（用起终点的大致方位判断，不要求完全相同），时间偏差在 30 分钟以内，剩余座位够用。
匹配成功后乘客确认，双方生成订单。订单在出发前 2 小时可以免费取消，2 小时内取消扣 20% 费用。
行程完成后双方互评（1-5 星），评分影响后续匹配优先级，低分（低于 3.5）的司机匹配排序靠后。
需要接口：发布行程/需求、搜索匹配结果、确认拼车、取消订单、评价。
启动正常，接口能调用。
能正常启动运行就行。
