写一个 Go 条形码编码库，支持Code 128格式Code B字符集。仓库管理系统需要把商品编码转成条形码模式数据——用0和1的字符串表示条和空（如"11010010000"），后续由渲染层根据宽度绘制条形码。

将输入字符串编码为Code 128的条空模式。计算并附加校验码（所有字符位置值乘以权重后取模103）。将编码结果转换为宽度序列便于渲染。输入为空字符串或包含非ASCII字符时返回错误。Code 128的起始码（Start Code B值为104）、校验码和终止码（值为106）都要正确实现。编码表包含每个ASCII可打印字符（32到127）对应的Code B编码值和条空模式。宽度序列是一个整数数组，每个数字表示对应条或空的宽度单位数，偶数索引是条奇数索引是空。编码后的条空模式字符串长度应该等于宽度序列所有值的总和。每个字符的条空模式由11个模块组成（除终止码为13个模块），总模块数可以用来验证编码正确性。

核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口做条形码编码，客户端通过命令行传入字符串调用服务端获取编码结果。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。
