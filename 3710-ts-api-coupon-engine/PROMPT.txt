用 Express + TypeScript 写一个优惠券系统，数据存 SQLite。
支持三种券：满减券（满 X 减 Y）、折扣券（X 折，最多优惠 Z 元）、无门槛券（固定减 X 元）。
每张券有发放总量限制和每人领取限制。券有生效时间和过期时间，过期未用自动作废。
下单时可以同时使用最多 3 张券，使用顺序影响最终价格。比如先打 8 折再减 20 和先减 20 再打 8 折结果不同，按对用户最优惠的组合计算。
退单时已使用的券返还给用户，返还的券有效期不延长。部分退单按退款比例回收券（退款超过 50% 回收整张券）。
接口：发放券、领券、查询可用券、计算优惠、使用/退回券。
