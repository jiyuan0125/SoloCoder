帮我写一个公司资产借用管理的 API，Express + TypeScript + SQLite。
资产分电子设备、办公用品、交通工具三类。借用要填预计归还日期，电子设备最长借 30 天，办公用品 90 天，交通工具 7 天。
超期未归还每天发一条提醒（接口返回即可），超期 3 天以上自动冻结该用户的借用权限。
归还时如果资产有损坏，要记录损坏描述和赔偿金额。赔偿金额从押金中扣，押金不够的生成一条欠费记录。
同一个资产被借走时不能再被其他人预约。但如果前面的人超期了，新预约自动作废并通知预约人。
接口：借出、归还、查询可借资产、查我的借用记录、查超期列表。
