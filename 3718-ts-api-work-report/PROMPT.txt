Express + TypeScript 写一个工作汇报API。
员工定期提交工作汇报：本周完成、下周计划、遇到的问题。主管可以评论和评分。
汇报有提交截止时间，逾期未提交的自动标记。补交后标记更新但不影响逾期记录。
主管可以按团队查看汇报完成率和评分统计。
汇报模板修改后，之前提交的汇报内容不变。新的提交用新模板。

新增时如果关联的上级记录不存在返回 404 和具体哪个关联不存在。修改时如果数据被其他人改过返回 409 让调用方决定是否覆盖。同一时间只允许一个状态变更操作执行，防止并发操作导致状态错乱。数量和金额参数为 0 或负数时返回 400。

SQLite 存数据，能正常编译启动就行。
