| User Prompt | 写一个 Go 进度追踪库。后端执行耗时任务时需要向调用方报告进度——比如批量导入10000条数据每处理完100条更新一次。 创建进度追踪器时设置总数，更新当前进度（原子操作并发安全），获取当前进度百分比（0到100的浮点数），获取预计剩余时间（基于已用时间和已完成数量估算），注册进度变化回调函数。支持子任务嵌套——一个总任务包含多个子任务各自报告进度，总进度根据子任务权重自动汇总。进度只能前进不能倒退（当前值小于上次的忽略更新）。总数为0时防止除零，百分比返回0。预计剩余时间在进度为0时返回-1表示无法估算，已完成的任务返回0。回调函数在更新进度的协程中同步执行。子任务权重默认均分，调用方可以为每个子任务设置不同权重。支持取消操作——通过context.Context传入，取消时所有子任务同步停止。提供String方法返回人类可读的进度描述如"已完成75/100 (75.0%)"。程序退出时提供Close方法释放资源。 核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口查询和管理任务进度，客户端通过命令行调用服务端查询进度。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
