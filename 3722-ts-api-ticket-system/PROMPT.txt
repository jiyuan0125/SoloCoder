用 TypeScript + Express 写一个 IT 工单系统的 API，SQLite。
用户提交工单选分类（网络、硬件、软件、账号），系统根据分类自动分配给对应的处理组。工单状态：待分配→处理中→待确认→已关闭。
处理人可以把工单转给其他人，转单要写理由。转单次数不超过 3 次，超过的话工单升级到经理处理。
用户确认解决后工单关闭。如果用户 3 天没确认，自动关闭并标记为「超时自动关闭」。
工单关闭后用户可以评价（满意度 1-5 星），低于 3 星的工单自动标记为「不满意」供主管审查。
接口：提交工单、处理/转单/关闭工单、评价、查询工单、统计报表（平均处理时长、满意度分布）。
