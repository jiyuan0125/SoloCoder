写一个 Go 批量处理工具库。很多时候单个操作太慢需要攒一批一起处理——比如往数据库插入1000条记录一条条太慢，攒够100条或者超过5秒就批量执行一次。

设置批量大小（攒够多少条触发）和超时时间（即使没攒够也定期执行）。提供处理器接口让调用方实现具体的批量处理逻辑。超时计时器在每次批量执行后重置不是从第一次添加开始算。缓冲区为空时手动触发不调用处理函数。添加数据和触发执行可能在不同线程要并发安全。批量大小为0或负数时使用默认值1。处理函数执行失败时不丢弃数据，数据留在缓冲区中下次触发时重试。程序退出时提供Close方法处理缓冲区中剩余的数据，Close应该阻塞直到所有缓冲数据被处理完毕或超时。如果处理函数本身panic，批量处理器应该捕获panic并记录日志而不是让整个程序崩溃。提供Flush方法立即处理缓冲区中所有数据不论是否达到批量大小。提供Size方法返回当前缓冲区中的数据量，方便调用方监控积压情况。Close方法的超时时间默认10秒可通过参数配置。

核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口提交数据和管理批量处理，客户端通过命令行调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。
