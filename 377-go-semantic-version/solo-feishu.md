| User Prompt | 写一个 Go 语义版本号处理库。软件版本号遵循SemVer规范——MAJOR.MINOR.PATCH如"1.2.3"，需要解析、比较和操作版本号。 支持解析版本号字符串为结构体、比较两个版本号大小、判断版本号是否在某个范围内（最低版到最高版之间）、版本号递增（主版本+1、次版本+1、修订号+1）、支持预发布版本标识（如"1.0.0-alpha"、"1.0.0-beta.2"）。预发布规则：1.0.0-alpha小于1.0.0-beta小于1.0.0-rc.1小于1.0.0，没有预发布标识的版本大于有标识的。"v1.2.3"和"1.2.3"视为相同（支持可选的v前缀）。版本号各部分必须是非负整数。输入"1.2"自动补齐为"1.2.0"。递增次版本时修订号归零，递增主版本时次版本和修订号都归零。范围比较支持闭区间和开区间——[1.0.0,2.0.0)表示大于等于1.0.0且小于2.0.0。预发布版本的字符串按点号分段逐段比较——"alpha"小于"beta"按字典序，纯数字段按数值比较。 核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口做版本号解析、比较和递增，客户端通过命令行调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
