写一个 Go 密码强度评估库。用户注册或修改密码时评估密码的安全等级，太弱的要提示加强。

评估返回四个等级：弱、中、强、很强。检查密码是否在常见弱密码列表中（内置至少50个如"123456"、"password"、"qwerty"）。给出具体改进建议——比如"建议增加大写字母"、"建议增加特殊字符"。评分规则：长度8位以上1分12位以上2分，含小写1分，含大写1分，含数字1分，含特殊字符1分，总分0-2弱3-4中5强6很强。连续重复字符超过3个扣分。弱密码检查忽略大小写。密码长度少于6位直接评为弱。空字符串或全空格的密码返回错误。改进建议只提示当前缺失的维度。特殊字符定义为非字母非数字的可见ASCII字符。密码中只包含一种字符类型（全小写或全数字）额外扣分。键盘上相邻的按键序列如"qwerty"或"asdf"也应该降低评分。弱密码列表支持调用方扩展添加自定义条目。评估结果结构体包含等级、分数和建议三个字段。

核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口做密码强度评估，客户端通过命令行传入密码调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。
