写一个 Go IP归属地查询库。根据IPv4地址判断属于哪个国家、省份和城市，不调用外部API，基于内置的IP段数据做本地查询。

支持IPv4归属地查询（返回国家、省份、城市）、判断两个IP是否属于同一个省份、判断IP是否属于内网地址（10.x、172.16-31.x、192.168.x）、判断IP地址类型（A/B/C/D/E类）。内置数据用IP段范围表示（起始IP到结束IP对应省份城市），至少覆盖国内主要省份的几个示例IP段。查询是范围包含判断不是精确匹配。IP地址转整数比较时按大端序将四个字节组合成uint32。无效的IP格式要返回错误。IP段范围可能有重叠，查询时匹配最精确的最小范围。127.0.0.1归为内网地址。0.0.0.0和255.255.255.255是特殊地址不在归属地查询范围内。同一IP段数据添加多条记录时不能有范围冲突——新添加的段不能与已有段重叠。提供批量查询方法一次查询多个IP减少重复加载开销。

核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口做IP归属地查询，客户端通过命令行传入IP地址调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。服务端监听固定端口，客户端默认连接 localhost。各程序内部按职责分文件。IP段数据加载在服务端启动时完成，查询时直接从内存中匹配，不涉及磁盘IO。先 go mod init 再开发，go build ./... 能编译通过。
