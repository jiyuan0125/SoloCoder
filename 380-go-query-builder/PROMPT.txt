写一个 Go 查询条件构造器。管理后台的列表查询接口有很多筛选条件——按状态筛选、按时间范围筛选、按关键词搜索、按多个字段排序，条件之间是AND关系。

支持添加等于条件、范围条件（字段在两个值之间）、IN条件（字段在值列表中）、LIKE条件（字段模糊匹配）、多字段排序（每个字段可指定升序或降序）、分页参数。最终输出一个结构化的查询描述（不是直接生成SQL而是生成一个可被后端使用的条件结构体）。同一字段添加多次条件后面的覆盖前面的。分页参数page最小1pageSize范围1到100值不合理自动修正。条件值为空时忽略该条件。排序条件中如果指定了相同字段多次只保留最后一次。LIKE条件默认前后加%做模糊匹配，调用方可以指定只加前缀%或后缀%。范围条件的起始值大于结束值时自动交换。IN条件值列表为空时忽略该条件。条件构造器实例不可变——每次添加条件返回新的构造器实例，原始实例保持不变方便复用。提供Reset方法清空所有条件和排序。

核心库代码独立为一个 package，服务端引用这个库对外提供 HTTP 接口构建查询条件，客户端通过命令行调用服务端。服务端和客户端各自有独立的 main 包，共享的消息协议放在公共包里。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。
