| User Prompt | 写一个 Go 命令行工具用来合并多个日志文件。微服务部署在10台机器上每台一个日志文件，排查问题时需要把所有日志按时间顺序合并成一个文件方便阅读。 用法：./log-merger file1.log file2.log file3.log -o merged.log。日志格式为每行"2026-05-04 10:30:15 [INFO] message content"，工具按时间戳排序后合并。相同时间戳的行保持原始文件中的相对顺序（稳定排序）。日志文件可能很大（几百MB）不能全部读入内存排序，要用逐行归并的方式处理——同时打开所有文件各维护一个读取指针，每次从所有指针中取时间戳最早的那行写入输出。不以时间戳开头的行（比如异常堆栈跟踪的续行）要归属到前一个有时间戳的日志条目下面。输入文件少于2个时提示至少需要2个文件。输出文件如果已存在直接覆盖。合并后的输出文件时间戳格式与输入文件保持一致。支持 --format 参数自定义时间戳格式。工具要记录上次处理到的文件位置偏移量存到本地，下次运行时从断点继续。 拆成两个独立程序：一个是后台常驻的服务进程，负责日志文件的读取、归并排序和断点状态维护；另一个是命令行客户端，用户通过它提交合并任务和查看处理进度。两个程序各自独立 main 包，通过 TCP 通信，共享协议定义放公共包。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
