| User Prompt | 写一个 Go 命令行工具比较两个配置文件的差异。部署时经常需要对比线上和线下的配置有什么不同来排查问题。 用法：./config-diff config-prod.yaml config-staging.yaml。支持key=value格式和简单YAML格式（只处理扁平的key:value结构不处理嵌套）。输出只显示有差异的配置项，用符号标记新增、删除、修改。数字和字符串要区分——8080和"8080"视为相同值。配置项的顺序不影响比较结果。两个文件完全相同输出"配置文件一致"并退出。key=value格式中值两边可能有引号也可能没有，解析时统一去掉外层引号再比较。YAML格式中true/false/null等特殊值要正确识别。如果某个文件中有重复的key后出现的值覆盖前面的值。空行和注释行（#开头）在比较时忽略。支持 --ignore 参数指定忽略的key列表，支持多个--ignore参数。比较结果中新增的key用+标记，删除的key用-标记，修改的key用~标记并显示新旧值。支持 -h 显示帮助信息，错误信息输出到stderr，退出码0成功非0出错。 拆成两个独立程序：一个是后台常驻的服务进程，负责配置文件的解析、比较和历史记录维护；另一个是命令行客户端，用户通过它指定文件路径和查看差异结果。两个程序各自独立 main 包，通过 TCP 通信，共享协议定义放公共包。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
