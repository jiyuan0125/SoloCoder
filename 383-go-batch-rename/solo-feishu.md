| User Prompt | 写一个 Go 命令行工具批量重命名文件。整理照片或下载文件时文件名很乱需要按规则批量改名。 支持的规则：添加前缀后缀、序号替换（{seq}从1开始自动递增并补零）、日期替换（{date}用文件修改时间格式化）、查找替换（把文件名中的某个字符串替换为另一个）、正则替换。运行时先预览改名结果——显示旧名到新名的对照列表，用户确认后才执行。加 --dry-run 参数只预览不执行。如果新文件名已经存在跳过并警告不能覆盖。序号根据文件总数自动决定补零位数。日期格式默认为YYYYMMDD可通过参数指定。查找替换只作用于文件名不作用于扩展名。文件名中不允许的特殊字符在替换结果中如果出现要自动替换为下划线。加 --recursive 参数递归处理子目录中的文件。旧名和新名相同时跳过不做任何操作。支持通过管道传入文件列表（从stdin读取路径）。支持同时应用多个规则——按顺序依次执行每个规则，前一个规则的结果作为下一个规则的输入。正则替换中捕获组可以用$1、$2引用。不指定任何规则时提示用户至少需要一个规则。 拆成两个独立程序：一个是后台常驻的服务进程，负责文件扫描、重命名规则执行和历史记录维护；另一个是命令行客户端，用户通过它提交重命名任务和预览结果。两个程序各自独立 main 包，通过 TCP 通信，共享协议定义放公共包。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
