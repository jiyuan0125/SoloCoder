| User Prompt | 写一个 Go 命令行工具分析磁盘使用情况。服务器磁盘满了需要快速找到哪些目录占用了大量空间。 用法：./disk-usage /path/to/scan --top 20。扫描指定目录统计每个子目录大小，按大小从大到小排序显示前N个。大小用人类可读格式——1.2G、350M、15K，自动选择最合适的单位。支持 --min-size 过滤小于指定大小的目录，支持 --output csv 导出结果。扫描时不跟随符号链接否则可能死循环。跳过没有权限访问的目录并记录警告不中断整个扫描。空目录显示大小为0。扫描统计包含目录下所有文件的总大小。深度超过10层的目录默认不展开只显示总大小可通过 --max-depth 参数调整。加 --summary 参数只显示总大小和文件总数不列出子目录。扫描隐藏目录（以.开头的目录）时默认跳过，加 --all 参数包含隐藏目录。文件大小统计使用os.Stat获取不跟随符号链接。扫描时遇到文件系统错误（如IO错误）记录警告继续扫描不中断。 拆成两个独立程序：一个是后台常驻的服务进程，负责磁盘扫描和大小统计，支持两次扫描之间对比目录增长情况；另一个是命令行客户端，用户通过它指定扫描路径和查看结果。两个程序各自独立 main 包，通过 TCP 通信，共享协议定义放公共包。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
