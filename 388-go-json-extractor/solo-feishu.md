| User Prompt | 写一个 Go 命令行工具从JSON文件中提取指定字段的值。日志分析时经常需要从一大堆JSON里提取某个字段。 用法：./json-extractor data.json -f user.name -f order.amount。支持点号路径访问嵌套字段（user.address.city）、数组索引（users.0.name）、通配符（users.*.name提取所有用户的名字）。JSON文件可能是一个数组或单个对象都要能处理。字段不存在时输出空字符串而不是报错。字段值可能是数字、字符串、布尔值或null要正确处理各种类型。输出默认每行一个key=value对，加 --json 参数输出为JSON格式。数组索引越界时输出空字符串。通配符匹配到多个值时每行输出一个。路径中间某个节点是null时后续路径输出空字符串。大文件逐行读取不全部加载到内存。支持从stdin读取数据（不指定文件名或指定-时从标准输入读取）。加 --compact 参数输出紧凑格式去掉多余空格。 拆成两个独立程序：一个是后台常驻的服务进程，负责JSON文件的读取和字段提取，维护常用查询模式；另一个是命令行客户端，用户通过它指定文件和字段路径并查看结果。两个程序各自独立 main 包，通过 TCP 通信，共享协议定义放公共包。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
