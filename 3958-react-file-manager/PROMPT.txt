用 React 做一个文件资源管理器界面。
左侧是文件夹树（可展开收起），右侧是文件列表（图标视图和列表视图切换）。
支持新建文件夹、重命名、删除、移动（拖拽到左侧文件夹）。
面包屑导航显示当前路径，可以点击跳转。
文件搜索支持按名称模糊匹配。
多选操作：Shift 连选、Ctrl 单选，批量删除和移动。
组件拆分：FileTree 文件夹树组件，FileList 文件列表组件，Breadcrumb 面包屑，ContextMenu 右键菜单，FileOperation 封装增删改操作逻辑。
所有数据 mock，树形结构用递归组件渲染。
支持键盘快捷键（Delete 删除、F2 重命名、Ctrl+A 全选）。
