| User Prompt | 写一个 Go 数据同步工具。两个系统需要同步数据——主系统导出CSV文件，辅助系统需要导入。不是全量覆盖而是增量同步——只更新有变化的记录。 读取源CSV和目标CSV，比较两份数据的差异，生成一份变更文件（包含新增、修改、删除的记录），再把变更应用到目标文件。比较依据是主键列（通过参数指定哪一列是主键）。新增是源有目标没有的记录，修改是两边都有但内容不同的记录，删除是目标有源没有的记录。CSV的列顺序可能不同要按列名匹配。主键值前后空格要先trim。变更文件记录操作类型和变更前后的完整行数据方便人工审核——修改操作要同时显示旧值和新值。应用变更时先生成变更文件，加 --apply 参数才实际修改目标文件。如果目标文件不存在视为所有源数据都是新增。加 --key 参数指定主键列名不指定时默认使用第一列。CSV中如果值包含逗号或引号要正确解析。变更文件使用CSV格式方便用Excel打开审核。源文件和目标文件的换行符不同时统一处理。源文件中重复的主键值只保留第一条记录并记录警告。 拆成两个独立程序：一个是后台常驻的服务进程，负责CSV文件的差异比较和变更应用，维护同步状态和历史；另一个是命令行客户端，用户通过它指定源目标文件和查看同步结果。两个程序各自独立 main 包，通过 TCP 通信，共享协议定义放公共包。各程序内部按职责分文件。先 go mod init 再开发，go build ./... 能编译通过。 |
