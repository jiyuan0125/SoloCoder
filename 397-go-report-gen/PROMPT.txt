写一个 Go 日报/周报自动生成工具。
每天要写工作日报内容包括今天完成了什么、遇到什么问题、明天计划做什么。
这个工具从Git提交记录自动提取信息生成报告草稿。
运行方式：./report-gen --repo /path/to/repo --since "2 days ago" --author zhangsan。
读取指定仓库的git log按日期分组，每天下面列出该天的所有提交——commit hash（短格式前7位）、提交信息和时间。
过滤掉合并提交只显示实际的代码提交。
commit message中如果有issue编号（如#123）提取出来单独标注。
指定时间范围内没有提交时输出"该时间段内无提交记录"。
最后统计提交数量和修改的文件数。
--author 参数不指定时统计所有人的提交。
支持 --format markdown 参数输出Markdown格式。
如果指定的仓库路径不是一个git仓库给出明确提示。
按日期倒序排列——最近的日期在最前面。
commit message中如果超过100个字符只显示前100个字符加省略号。
生成的报告以纯文本格式输出到stdout，同时存一份到本地文件。
拆成两个独立程序：一个是后台常驻的服务进程，负责Git仓库扫描和报告生成，维护生成历史；另一个是命令行客户端，用户通过它指定仓库参数和查看生成的报告。
两个程序各自独立 main 包，通过 TCP 通信，共享协议定义放公共包。
各程序内部按职责分文件。
先 go mod init 再开发，go build ./... 能编译通过。
