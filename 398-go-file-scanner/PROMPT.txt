写一个 Go 文件内容扫描工具用于安全审计。
扫描指定目录下所有文件，
用正则匹配可能包含敏感信息的模式——password=xxx、api_key=xxx、secret=xxx、数据库连接串（包含user:password@host格式）、私钥文件内容等。
输出匹配结果：文件路径、行号、匹配到的内容（敏感值用星号遮挡显示不能直接打印）。
支持白名单模式——指定不检查的文件或目录（如vendor/、.git/、node_modules/），白名单支持通配符。
不扫描二进制文件（通过扩展名判断），遇到二进制文件跳过。
匹配规则可配置——支持通过配置文件添加或修改正则规则。
扫描结果按文件路径分组显示，每个文件下按行号排序。
加 --severity 参数按严重程度过滤。
同一个文件同一行匹配到多条规则时只报告一次。
加 --json 参数输出JSON格式方便后续处理。
扫描时记录总扫描文件数、总匹配文件数和总匹配行数作为汇总信息。
敏感值脱敏时保留前2个字符和后2个字符中间用星号填充。
拆成两个独立程序：一个是后台常驻的服务进程，负责文件扫描和敏感信息匹配，维护扫描规则和历史结果；另一个是命令行客户端，用户通过它指定扫描目录和查看扫描结果。
两个程序各自独立 main 包，通过 TCP 通信，共享协议定义放公共包。
各程序内部按职责分文件。
先 go mod init 再开发，go build ./... 能编译通过。
