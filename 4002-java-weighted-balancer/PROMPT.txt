线上的流量越来越大了，老板说要上个负载均衡。用 Spring Boot 做一个独立的负载均衡服务。
支持加权轮询算法，每个后端节点可以设置权重，权重为 0 的时候该节点不参与分配但不断开注册。权重可以在运行时通过接口调整。
后端节点有四种状态：新建→活跃→疑似故障→已摘除。新建状态需要经过一次健康检查才能变成活跃。疑似故障的节点连续 3 次健康检查通过后恢复为活跃。已摘除的节点需要重新注册才能变为新建。
每次健康检查结果要记录到日志，包括响应时间。健康检查接口和负载分配接口要分开，健康检查是定时任务自动跑的。
提供一个接口查询当前所有节点的状态和权重。端口用 server.port 配置，Maven 构建。
