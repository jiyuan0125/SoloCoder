流量翻倍轮询不够用，好机器该多扛，新节点需预热。Spring Boot 加权轮询负载均衡器。

每后端设权重 1-100 按比例分配。权重 0 不分配但保留注册，PUT `/backends/{id}/weight` 运行时调立即生效。节点生命周期：新建→活跃→疑似故障→已摘除。新建过一次健康检查才升活跃；活跃连续 3 次失败变疑似故障；疑似故障连续 3 次通过才恢复；已摘除须重新注册。慢启动：升活跃后 5 分钟权重从 0 线性增到配置值。

GET `/backends` 返回状态、权重、活跃连接数。GET `/stats` 返回全局 QPS、平均响应时间和每节点请求计数。Maven 构建，`server.port` 配端口。状态变更触发回调，URL 注册时指定。
