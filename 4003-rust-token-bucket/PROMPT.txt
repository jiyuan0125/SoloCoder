爬虫一夜刷 200 万次 API。Rust + actix-web 令牌桶限流器，每 IP 独立一个桶，POST `/config` 配容量和速率，变更立即生效。

令牌按速率加，请求扣一个，桶空返回 429 带 `Retry-After`。每桶 burst 和 rate 独立配，未配 IP 用全局默认。数据全内存，重启清零。叠 API Key 限流：同一 Key 请求共享桶。检查顺序：验 Key（不合法 401）→ Key 限流 → IP 限流。某 IP 所有桶空时加全局冷却，冷却期直接 429。

GET `/status` 返回活跃桶状态（剩余令牌、填充时间、速率）。GET `/cooldowns` 返回冷却 IP 和剩余时间。桶超 1 小时无活动自动回收。`PORT` 环境变量，`Cargo build` 通过即可。
