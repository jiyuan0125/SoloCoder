我们的 API 被爬虫刷爆了，需要一个独立的限流服务。用 Rust + actix-web 搞一个令牌桶限流器。
每个客户端 IP 维护一个独立的令牌桶，桶容量和填充速率可以通过接口配置。令牌用完了请求返回 429，同时在响应头里返回剩余等待时间。
还支持按 API Key 限流，同一个 API Key 下所有请求共享一个桶。限流检查的时候如果发现桶已经空了，要同时检查该 IP 是否在其他桶里也被限流了，如果全都被限流了，给这个 IP 加一个全局冷却时间。
提供接口查看当前所有活跃桶的状态（剩余令牌数、最后填充时间）。冷却中的 IP 列表也能查到。
端口通过 PORT 环境变量配置，Cargo build 能过。
