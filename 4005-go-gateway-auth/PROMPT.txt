十几个微服务直接暴露前端，路由认证聚合全缺。Go Gin 搭 API 网关。

路由三种匹配：精确、前缀（`/api/orders/*`）、正则（`/api/v[0-9]+/.*`），优先级精确>前缀>正则。接口增删改热更新。每路由绑认证：免认证、API Key（Header `X-API-Key` 内存白名单）或 JWT（HS256 密钥可配）。验证失败 401，Body reason 说明原因。

聚合：POST `/api/aggregate` 指定后端列表和路径，网关并行调用，context 总超时 10 秒，结果合并 JSON。某后端失败对应字段 null 加 error。后端不可用 502。所有请求记日志：路径、认证结果、后端状态、耗时。代码按路由、认证、聚合、配置拆文件。`go build` 编译，`PORT` 环境变量。
