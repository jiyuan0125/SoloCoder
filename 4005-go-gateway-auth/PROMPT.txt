微服务架构下的 API 网关，用 Go Gin 做。网关负责路由匹配、认证注入和请求聚合。
路由表支持三种匹配模式：精确匹配、前缀匹配、正则匹配。优先级是精确>前缀>正则。路由可以动态添加和删除，不用重启。
每个路由可以绑定一个认证策略：免认证、API Key 认证、JWT 认证。API Key 和 JWT 的验证逻辑要独立模块。认证失败统一返回 401，Body 里带错误原因。
还需要一个请求聚合功能：客户端发一个请求到 /api/aggregate，网关并行调用后端多个服务，把结果合并返回。聚合的目标服务列表按场景配置。
端口 PORT 环境变量。项目至少包含路由模块、认证模块、聚合模块、配置模块这几个文件，go build 能过。
