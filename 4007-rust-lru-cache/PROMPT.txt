内部服务需共享 KV 缓存，数据量不大访问频繁，Redis 太重。Rust + axum 轻量 HTTP 缓存，LRU 淘汰，容量按条目数配。

PUT `/cache/{key}` 写入（Body 为 value，可选 TTL），GET `/cache/{key}` 读，DELETE `/cache/{key}` 删，POST `/cache/flush` 清空。每 key 可单独设 TTL，不设走全局默认 300 秒。过期惰性删除——访问时发现过期就删返回 404。PUT `/config` 设最大条目数默认 10000，满后淘汰最久未访问的。改容量后超出部分立即淘汰。单条 value 上限 1MB 超出返回 413。

GET `/stats` 返回命中率、条目数、查询次数、淘汰次数。数据全内存重启清零。`Cargo build` 通过，`PORT` 环境变量。
