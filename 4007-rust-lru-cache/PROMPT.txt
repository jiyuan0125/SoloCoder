之前用 Redis 做缓存有点杀鸡用牛刀，想用 Rust + axum 写一个轻量级 HTTP 缓存服务。
支持 LRU 淘汰策略，缓存容量通过接口配置，单位是条目数。超过容量时淘汰最久未访问的数据。
每个缓存条目可以单独设置 TTL，也可以不设置就走全局默认 TTL。TTL 到期后在下次访问时惰性删除。查询缓存时如果命中了但已过期，要删除并返回 miss。
提供统计接口：命中率、当前条目数、总查询次数。修改全局容量后，如果当前条目数已经超过新容量，立即触发淘汰。
缓存值支持任意字符串，value 最大 1MB。接口包括 set、get、delete、flush、stats。Cargo build，PORT 环境变量。
