配置散落在各个服务里，改一个参数要重启好几个服务。用 Spring Boot 做一个配置中心。
配置按环境（dev/staging/prod）和项目分组，格式是 key-value。同一个 key 在不同环境可以有不同的值。接口支持 CRUD 和按环境/项目批量查询。
支持版本历史，每次修改都保存一份快照，可以回滚到任意历史版本。版本之间的差异也要能查到。
客户端可以 watch 某个 key 或某个项目下所有 key，配置变更时主动推送通知。推送方式是客户端注册一个回调 URL，配置中心 POST 变更内容过去。回调失败（连接超时、返回非 200）要记录日志并重试 2 次。
如果 watch 回调 URL 已经失效（多次推送失败），不要无限重试。Maven 构建，端口配置文件指定。
