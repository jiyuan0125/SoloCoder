改数据库参数要重启五个服务。Spring Boot 配置中心，变更热生效。

配置按环境（dev/staging/prod）和项目分组，key-value 格式。GET `/configs/{env}/{project}` 批量查，POST `/configs` 新增，PUT `/configs/{id}` 改，DELETE `/configs/{id}` 删。每次改自动存快照版本递增，GET `/configs/{id}/history` 查历史，POST `/configs/{id}/rollback?version=N` 回滚，GET `/configs/{id}/diff?from=N&to=M` 看差异。

订阅变更：POST `/watches` 注册回调 URL 指定 watch 的 key 或项目。变更时 POST 回调，超时 5 秒非 200 视为失败，重试 2 次（5s、15s），3 次失败停止。投递记录含时间、状态码、Body 可查。Maven 构建，端口走配置文件。数据存内存重启从快照恢复。
