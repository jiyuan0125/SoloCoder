下游有 TCP 有 HTTP 还有自定义协议。Java Netty 通用探针框架。

检查目标配名称、类型（HTTP/TCP）、间隔、超时、不健康阈值 N 和健康阈值 M。HTTP GET 期望 200，TCP 建连成功即健康。连续失败 N 次标不健康，连续成功 M 次标健康，默认 N=M=3。POST `/groups` 创建分组，POST `/groups/{name}/targets` 添加目标。

分组可嵌套，父分组状态由子分组不健康比例决定（超 50% 父不健康）。循环依赖创建时拒绝返回 400。

状态变更 POST 回调 URL 含目标名、旧新状态、原因和耗时。回调超时 5 秒失败重试 2 次。Maven 构建，`PORT` 环境变量。
