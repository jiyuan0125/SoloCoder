前端认 HTTP JSON 后端有 gRPC 服务改造成本高。Go Gin 协议网关做 JSON↔protobuf 转换。

路由格式 `/v1/{service}/{method}`，POST `/routes` 注册映射指定 gRPC 地址、service、method 和 protobuf 定义，可动态增删。请求 JSON 转 protobuf 发后端，响应 protobuf 转 JSON 返回。

gRPC 不可用返回 502 Body 带 gRPC 状态码和错误详情。状态码映射：NOT_FOUND→404、ALREADY_EXISTS→409、PERMISSION_DENIED→403、其他→500。支持 server streaming 转成 chunked transfer encoding，客户端看到逐步到达的 JSON 数组。

GET `/stats` 返回每路由调用量、错误率、平均响应时间。`go build` 编译，`PORT` 环境变量。
