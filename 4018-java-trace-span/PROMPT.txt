线上一个请求要经过七八个服务，哪一步卡住了全靠猜。Spring Boot 写一个简单链路追踪：每个请求分配全局唯一 TraceID，在服务间通过 X-Trace-Id Header 传递。每个服务内部的操作生成 Span，Span 有父子关系组成一棵树。

Span 记录操作名称、起止时间、标签（key-value）。各微服务通过接口上报 Span 数据。查询支持按 TraceID 查完整调用链（返回 Span 树），也支持按服务名和时间范围查慢请求（耗时超阈值的 Trace）。Span 树可能深达 10+ 层，查询结果要正确展示层级。孤立 Span（没有父 Span 也不是根 Span）也要能查到。
至少包含 trace、span、storage、query 四个模块。Maven 构建，端口走配置文件。
