线上请求经七八个服务卡在哪全靠猜。Spring Boot 简单链路追踪。

每请求分配 TraceID（UUID v4）通过 `X-Trace-Id` Header 传递。每服务操作生成 Span 有名称、起止时间、标签（key-value 标记如 `db.query`）。Span 有父子关系组成树，根 Span 是入口，深度可达 10+ 层。各服务 POST `/spans` 上报。

GET `/traces/{id}` 按 TraceID 查完整调用链返回 Span 树。GET `/traces` 按服务名和时间范围查慢请求，支持设耗时阈值只返回超限的。Span 可能乱序到达，后到的父 Span 须正确挂到子 Span。孤立 Span 单独存也可查。

GET `/stats` 返回 Trace 数、Span 总数、平均耗时。代码按 trace、span、storage、query 拆模块。Maven 构建，端口走配置文件。
