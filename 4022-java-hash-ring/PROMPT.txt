有状态服务轮询会丢会话缓存 miss。Spring Boot 一致性哈希负载均衡。

哈希环每后端占若干虚拟节点由权重决定（权重 5 占 50 位权重 1 占 10 位）。请求按可配 key 哈希映射到节点，key 来源可选客户端 IP、指定 Header 或 URL 参数。同一 key 始终打到同一节点。

节点下线只影响被重分配的 key 其他不动。新节点只接管一部分。GET `/migration-report?event={event_id}` 列出哪些 key 从哪节点迁到哪节点按迁出节点分组。

权重 0 虚拟节点保留但不参与分配，恢复权重不用重新注册。PUT `/backends/{id}/weight` 动态调。Maven 构建，哈希用 MurmurHash3，端口走配置文件。
