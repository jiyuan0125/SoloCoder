轮询负载均衡不够用了，有些有状态的服务需要会话保持。Spring Boot 做一个一致性哈希负载均衡器。
每个后端节点在哈希环上占若干个虚拟节点，虚拟节点数由权重决定。权重大的节点虚拟节点多，分到的流量多。
请求根据某个 key（可配置为客户端 IP、请求中的某个 Header 值、或者 URL 参数）做哈希，映射到哈希环上的节点。同一个 key 始终打到同一个节点。
节点下线后，该节点的虚拟节点从环上移除，受影响的请求重新分配。新节点上线后，只影响部分请求的分配，不影响其他的。
哈希环变更后提供一个迁移报告接口：哪些 key 从哪个节点迁到了哪个节点。报告结果按迁出节点分组。
节点权重为 0 的时候虚拟节点保留但不参与分配。Maven 构建，端口配置文件指定。
