令牌桶不够灵活，有些场景需要滑动窗口限流。Rust + actix-web 实现滑动窗口限流器。
滑动窗口的大小可配置（如 1 分钟、5 分钟、1 小时）。窗口内最大请求数也可配置。每来一个请求记录时间戳，统计窗口内的请求数决定是否放行。
限流维度支持三种：按 IP、按 API Key、按自定义标签。同一个请求可以同时命中多个维度的限流规则，全部通过才放行，任一维度被限流就拒绝。
被限流时返回 429，响应头带 X-RateLimit-Limit（窗口上限）、X-RateLimit-Remaining（剩余次数）、X-RateLimit-Reset（窗口重置时间）。
规则变更后立刻生效，但已有的历史请求数据不清空，新窗口大小基于已有数据重新计算。
端口 PORT 环境变量，Cargo build 能过。
