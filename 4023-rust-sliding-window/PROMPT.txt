令牌桶在突发流量下不够精确，有些业务要求严格的时间窗口控制。Rust + actix-web 实现滑动窗口限流：窗口大小（1 分钟、5 分钟、1 小时）和窗口内最大请求数都可配。每来一个请求记时间戳，统计窗口内请求数决定是否放行。
限流维度三种：按 IP、按 API Key、按自定义标签。同一个请求可能同时命中多个维度，全部通过才放行，任一被限就拒绝。被限流时返回 429，响应头带 X-RateLimit-Limit（上限）、X-RateLimit-Remaining（剩余）、X-RateLimit-Reset（窗口重置时间）。规则变更立刻生效，已有历史请求数据不清空、基于新窗口重新计算。
Cargo build 通过，PORT 环境变量。
