令牌桶在突发流量下不够精确——它允许短时间内的 burst，有些业务要求严格的时间窗口控制，比如"一分钟内不超过 100 次"。Rust + actix-web 实现滑动窗口限流器。

窗口大小（1 分钟、5 分钟、1 小时）和窗口内最大请求数都可配，配置通过 POST `/rules` 接口管理。每来一个请求记录时间戳，统计当前窗口内的请求数决定放行还是拒绝。限流维度三种——按客户端 IP、按 API Key、按自定义标签（请求 Header 里的某个字段名）。同一个请求可能同时命中多个维度的规则，全部通过才放行，任一维度被限就拒绝。

被限流时返回 429，响应头带三个信息：`X-RateLimit-Limit`（窗口上限）、`X-RateLimit-Remaining`（剩余可用次数）、`X-RateLimit-Reset`（窗口重置时间戳）。规则变更立刻生效，但已有历史请求数据不清空，基于新窗口重新计算。

GET `/status` 返回所有限流规则的当前状态——每条规则的维度、窗口大小、已用次数、剩余次数。时间戳数据超过窗口范围的定期清理，别让内存无限增长。`Cargo build` 通过，`PORT` 环境变量。
