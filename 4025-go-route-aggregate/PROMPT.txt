API 网关的请求聚合功能之前做得太简单了，现在要加权限控制和更复杂的路由。Go Gin 做一个带认证的请求聚合网关。
路由匹配支持路径参数，比如 /api/v1/users/:id/orders。路径参数提取出来传给后端服务。/:id 这种参数在转发时替换成实际值。
聚合请求可以配置并行或串行调用多个后端。串行模式下前一个响应可以作为后一个请求的输入参数，用模板语法引用，比如 {{response0.data.userId}}。
认证支持 API Key 校验，Key 存在内存里。每个 Key 绑定一组允许访问的路由列表。不在允许列表里的路由返回 403。
聚合接口的响应格式支持自定义，可以只返回部分字段。自定义格式用 JSON 模板配置。
端口 PORT 环境变量，go build 能过。
