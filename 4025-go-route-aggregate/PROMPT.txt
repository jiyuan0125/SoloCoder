之前做的请求聚合太简陋——没有认证、串行调用不支持上下文传递。Go Gin 重写一个带认证的请求聚合网关。路由支持路径参数（如 /api/v1/users/:id/orders），转发时把参数替换成实际值。聚合请求可配并行或串行调用多个后端：串行模式下前一个响应能作为后一个请求的输入，用 {{response0.data.userId}} 这样的模板语法引用。
认证走 API Key，Key 存内存。每个 Key 绑定一组允许访问的路由，不在列表里返回 403。聚合接口的响应格式支持自定义——用 JSON 模板配置，只返回需要的字段。
代码 go build 编译通过，端口号从 PORT 环境变量读取。
