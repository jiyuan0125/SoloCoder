路由支持路径参数如 `/api/v1/users/:id/orders` 转发时替换。聚合可配并行或串行：并行所有后端同时发；串行前一个响应可作后一个输入用 `{{response0.data.userId}}` 模板语法。响应格式用 JSON 模板自定义只返回客户端需要的字段。

认证走 API Key 存内存。POST `/keys` 创建每 Key 绑允许路由列表不在返回 403，DELETE `/keys/{id}` 吊销，GET `/keys` 列出权限。

并行模式某后端失败对应字段 null 加 error；串行某步失败后续跳过返回已执行部分。`go build` 编译，`PORT` 环境变量。
