LRU 缓存做完了，再加一套 TTL 缓存，Rust + axum 实现带 TTL 和缓存穿透防护的缓存服务。
基础功能还是 KV 存储，set/get/delete/flush。每个 key 可以有独立的 TTL，也支持全局默认 TTL。TTL 精确到秒。
缓存穿透防护：如果查询一个不存在的 key，缓存一个空值（有效期较短，比如 30 秒），防止同一个不存在的 key 被反复查询打穿到后端。空值和正常值在返回时要区分开。
缓存击穿防护：热点 key 过期时，只允许一个请求去后端加载，其他请求等待结果。等待超时返回缓存 miss。
缓存雪崩防护：TTL 加上随机抖动（比如 TTL ±10%），避免大量 key 同时过期。
统计接口返回命中率、穿透次数（空值缓存命中也算）、当前条目数。Cargo build，PORT 环境变量。
