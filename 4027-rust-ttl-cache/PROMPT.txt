LRU 缓存能用了，但线上的缓存穿透、击穿、雪崩问题还没防。Rust + axum 在 TTL 缓存基础上加上这三层防护。基础功能仍是 KV 存储（set/get/delete/flush），每个 key 可独立设 TTL，也支持全局默认，精度到秒。

穿透防护：查询不存在的 key 时缓存一个空值（30 秒有效），防止同一 key 反复打穿后端。空值和正常值在返回时要区分开。击穿防护：热点 key 过期时只放一个请求去后端加载，其他请求等结果，等待超时返回 miss。雪崩防护：TTL 加随机抖动（±10%），避免大量 key 同时过期。
统计接口返回命中率（含穿透次数）和当前条目数。Cargo build 通过，PORT 环境变量。
