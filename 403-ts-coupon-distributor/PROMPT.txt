运营发优惠券需求花样越来越多。做一个优惠券发放和核销API。券有三种类型：满减券、折扣券、固定金额券。每张券有面值、使用门槛和有效期。发放可以指定用户ID列表定向发或全员发，全员发放时支持按用户注册时间筛选新用户或老用户。核销时校验有效期、订单金额是否够门槛、券是否已用过。满减券减免金额超过订单实际金额时按订单全额减免实付为0不找零。折扣券最低折扣不能低于5折，防止恶意打折。固定金额券可以和满减券叠加使用，但不能和折扣券叠加，一张订单最多同时使用两张券。券的有效期分两种：固定日期段和领取后N天。如果用户手里有多张同类券，核销时优先使用快过期的。查询用户手里还有哪些未使用的可用券，按过期时间升序排列。服务重启后所有优惠券数据要还在。全员发放时支持按用户注册时间筛选新用户或老用户。折扣券最低折扣不能低于5折防止恶意打折。固定金额券可以和满减券叠加使用但不能和折扣券叠加，一张订单最多同时使用两张券。券的有效期分固定日期段和领取后N天两种模式。如果用户手里有多张同类券，核销时优先使用快过期的。券发放记录包含发放时间、发放人和领取人，供运营做发券效果分析。所有金额相关的字段必须使用整数（分为单位），杜绝浮点数精度问题。null 和 undefined 要严格区分处理，可选字段不能混淆。
采用 TypeScript monorepo 架构。packages/shared 负责定义所有公共的 TypeScript 类型、接口、消息结构和错误码枚举。packages/server 基于 Node.js 原生 http 模块实现 HTTP 服务（严禁使用 Express/Koa 等框架），处理全部业务逻辑，数据保持在内存中。packages/cli 提供命令行界面，接受用户指令后向服务端发起请求并格式化输出。项目根目录使用 npm workspaces 联动三个子包，全局 tsconfig.json 启用 strict 模式。每个子包内部按功能模块拆分到不同文件。全程不允许 any 和 @ts-ignore。执行 npm install && npm run build 可正常编译。
