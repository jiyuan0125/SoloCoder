配置中心要加一个变更推送的确认机制。Spring Boot 做，在之前的 KV 存储基础上加强。
配置变更推送到客户端后，客户端需要回一个 ACK。超过一定时间没有 ACK 的推送标记为失败。失败的推送按策略重试：最多 3 次，间隔递增。
推送历史保留下来，可以查询某个配置的推送记录：推给了谁、什么时候推的、是否确认、重试了几次。
配置回滚的时候要验证：如果要回滚到的版本的某个 key 在当前版本被其他项目引用了，回滚需要确认（加一个 force 参数）。
配置导入功能：批量导入一组 key-value，支持 dry-run 模式（只预览变更不实际执行）。导入结果返回新增了几个、修改了几个、冲突了几个。
Maven 构建，端口配置文件。
