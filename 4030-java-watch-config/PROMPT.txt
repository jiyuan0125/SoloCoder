配置推送不知道客户端收没收到。Spring Boot 加强版补推送确认。

推送后客户端须回 ACK 超时（默认 10 秒）未 ACK 标失败重试最多 3 次间隔递增（5s/15s/30s）。GET `/pushes/{configId}` 查推给了谁、时间、是否确认、重试次数。推送状态：待确认/已确认/失败。

回滚加验证：目标版本某 key 被其他项目引用返回 409 列冲突 key 和引用项目，须 `force=true` 强制回滚。

配置导入：POST `/configs/import` 批量导入支持 `dry-run` 只预览。返回新增/修改/冲突数。GET `/configs/{env}/{project}/export` 导出。Maven 构建，端口走配置文件。
