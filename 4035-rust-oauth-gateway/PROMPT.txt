JWT 网关够内部用但第三方要 OAuth2。Rust + actix-web 叠 OAuth2 支持。

完整授权码流程：客户端重定向到 `/authorize` 用户认证后回调带 code，客户端用 code 调 `/token` 换 access token。JWT 密钥和 OAuth2 client_id/secret/redirect_uri 分开管理，POST `/oauth/clients` 注册。

Token 生命周期：access token 过期用 refresh token 换新的，refresh token 默认 7 天过期后重走授权。refresh token 用一次旧失效防重放。GET `/oauth/clients` 列出所有第三方。

认证事件记审计日志含时间、客户端 ID、方式（JWT/OAuth2）、结果。GET `/audit` 按时间和客户端查。认证通过转发后端路由接口管理。`Cargo build` 通过，`PORT` 环境变量。
