JWT 认证网关够内部用了，但第三方接入要走 OAuth2 授权码流程。Rust + actix-web 在现有网关上叠 OAuth2 支持：客户端重定向到网关授权端点，用户在网关认证后回调到客户端带上 authorization code，客户端用 code 换 access token。JWT 和 OAuth2 配置分开管理——JWT 密钥、OAuth2 的 client_id/client_secret/redirect_uri 都通过接口配。
Token 刷新：access token 过期后用 refresh token 换新的，refresh token 也能过期、过期后重新走授权。每次认证事件记审计日志（时间、客户端 ID、认证方式、结果），可按时间范围和客户端查询。
认证通过后转发到后端（后端路由配置和之前一样）。Cargo build 通过，PORT 环境变量。
