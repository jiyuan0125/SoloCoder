前端有个实时看板用了 WebSocket，后端全是 HTTP REST——需要一个双向桥接。Go Gin 做 WS↔HTTP 协议转换：客户端通过 WS 连到网关，发来的 JSON 消息包含 path、method、body、headers，网关转成 HTTP 请求发给后端，响应通过 WS 推回。同一连接上的多个请求并发处理，响应按请求 ID 匹配。

后端不可用时 WS 桥返回错误消息而不是断开连接。WS 连接异常断开时清理所有未完成请求。还支持广播模式——后端通过一个特殊 HTTP 回调接口主动推消息，网关广播到所有已连接的 WS 客户端。
统计接口：当前连接数、总请求数、活跃请求数。端口通过 PORT 环境变量传入，go build 能编译。
