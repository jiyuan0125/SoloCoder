前端 WebSocket 后端 HTTP REST 协议不一样。Go Gin 做 WS↔HTTP 双向桥接。

客户端连 WS `/ws`，发 JSON 含 `request_id`、`path`、`method`、`body` 和可选 `headers`。网关转 HTTP 发后端响应通过 WS 推回用 `request_id` 匹配。同连接多请求并发处理异步推送。后端不可用 WS 返回 error 不断开。

WS 异常断开清理未完成请求后端响已关的丢弃。广播模式：后端 POST `/broadcast` 主动推消息网关广播到所有 WS 客户端。每连接分配唯一 ID。

GET `/stats` 返回连接数、总请求数、活跃请求数、广播次数。连接 5 分钟无消息自动断开。`PORT` 环境变量，`go build` 编译。
