WebSocket 和 HTTP 之间需要一个桥接服务。Go Gin 做 WebSocket 到 HTTP 的协议桥接。
客户端通过 WebSocket 连到网关，网关收到 WS 消息后转换成 HTTP 请求发给后端，后端响应再通过 WS 推回客户端。WS 消息格式约定为 JSON，包含 path、method、body、headers 字段。
同一个 WS 连接上的多个请求可以并发处理，响应按请求 ID 匹配回推。请求 ID 由客户端在 WS 消息里带。
后端 HTTP 服务不可用时，WS 桥接返回错误消息而不是断开 WS 连接。WS 连接异常断开时，清理所有未完成的请求。
支持 WS 广播模式：后端可以主动推送消息，网关广播到所有已连接的 WS 客户端。广播消息通过一个特殊的 HTTP 回调接口触发。
统计接口：当前连接数、总请求数、活跃请求数。端口 PORT 环境变量，go build 能过。
