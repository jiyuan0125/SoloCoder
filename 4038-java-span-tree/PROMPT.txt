链路追踪能查到调用链了，但看不出哪一步最慢、哪些 Span 有异常。Spring Boot 增强版：Span 除了基本信息外加上标签（tag，key-value）、日志事件（时间戳+消息）、关联异常信息（类型+消息+堆栈摘要）。查询时异常 Span 要高亮标注，支持按服务名查最近 N 条慢 Trace（按耗时降序）。

耗时分析：给定 TraceID 返回关键路径（耗时最长的链路）和每个 Span 耗时占比。父子 Span 之间的间隙（gap time）也要算出来。Span 上报要处理乱序——子 Span 可能比父 Span 先到，后到的父 Span 要正确挂到已有子 Span 上。
至少包含 trace、span、analytics、storage 四个模块。Maven 构建，端口走配置文件。
