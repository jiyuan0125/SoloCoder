人事算工资手工算经常出错。做一个薪资计算API，输入基本工资、岗位津贴、绩效系数（0到2）、社保比例、公积金比例和个税起征点，输出应发工资和各项明细。社保公积金缴纳基数有上下限：低于2000按2000算，高于25000封顶。个税用累进税率：3000以内3%、3000到12000部分10%、12000到25000部分20%、25000到35000部分25%、超过35000部分30%。当月有请假扣款先从基本工资扣除再算社保基数，这意味着请长假的人社保基数会变低。加班费单独计算：工作日1.5倍、周末2倍、法定节假日3倍，每月加班费上限为基本工资的50%。年终奖可以选择并入当月工资计税或单独计税，系统要分别算两种方案让员工选最优的。保存历史薪资记录供查询，支持按员工和月份筛选。服务重启后历史数据要还在。加班费单独计算：工作日1.5倍、周末2倍、法定节假日3倍，每月加班费上限为基本工资的50%。年终奖可以选择并入当月工资计税或单独计税，系统分别算两种方案让员工选最优的。当月社保基数计算完毕后，如果实发工资低于当地最低工资标准，则按最低工资标准发放差额由公司补贴。历史薪资记录支持同比环比对比查询。所有金额用整数分表示，税率计算结果四舍五入到分。数组和对象的操作必须保持不可变性，不能直接修改函数入参。
项目以 TypeScript monorepo 方式组织。在 packages/shared 中集中管理所有公共类型定义、API 接口契约、消息格式及错误码。packages/server 依赖 Node.js 核心的 http 模块搭建 HTTP 服务（不得引入第三方框架），承载全部业务逻辑，运行时数据存于内存。packages/cli 作为终端工具，解析命令行参数并向服务端发起 HTTP 调用，将响应数据以可读格式呈现。根 package.json 配置 workspaces 统管三个子包，顶层 tsconfig.json 开启 strict。各包代码按职责分散到多个文件中。TypeScript strict 模式强制开启，any 和 @ts-ignore 一律禁止。npm install && npm run build 必须能成功。
