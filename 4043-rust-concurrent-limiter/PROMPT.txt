限流器要支持并发数限制和 IP 黑名单。Rust + actix-web 做一个并发限流器。
并发限流：同一个资源同时允许的最大请求数。超出的请求排队等待，等待超时返回 429。和速率限流（QPS）不同，并发限流限制的是同时进行的请求数。
IP 黑名单管理：通过接口添加和移除 IP。黑名单支持 CIDR 格式（如 10.0.0.0/8）。黑名单 IP 的请求直接拒绝，不做限流检查。
白名单机制：白名单 IP 不受任何限流规则限制。白名单也通过接口管理。
限流规则按资源路径配置，每条规则包含并发上限、等待超时、关联的黑/白名单。没有配置规则的路径不限流。
限流触发时记录事件到审计日志。审计日志包含时间、IP、资源路径、触发规则。日志可以按时间范围和 IP 查询。Cargo build，PORT 环境变量。
