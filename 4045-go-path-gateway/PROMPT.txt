API 网关缺限流和缓存，每次请求都打到后端去。Go Gin 加上这两块：请求限流按路由配独立 QPS 上限，超限返回 429，维度支持 IP / API Key / 路由组合。响应缓存对 GET 请求生效，缓存 key 由路由+查询参数组成，TTL 和条目上限按路由配，超限 LRU 淘汰。
路由匹配支持正则和路径参数（如 /api/v{version:[0-9]+}/users/:id），提取的参数传给后端。后端不可用时有降级策略——返回缓存数据（即使过期）或返回默认值，按路由配。网关自己也有 /health 接口，返回路由数、缓存条目数、限流规则数。
go build 编译通过，PORT 环境变量配端口号。
