API 网关缺限流和缓存后端扛不住重复查询浪费资源。Go Gin 把限流和缓存加上。

请求限流按路由配独立 QPS 上限，维度支持 IP/API Key/路由组合。超限返回 429 带 `X-RateLimit-Limit` 和 `X-RateLimit-Remaining`。

响应缓存对 GET 生效，key 由路由+查询参数组成 TTL 和条目上限按路由配超限 LRU 淘汰。命中 `X-Cache: HIT` 未命中 `MISS`。POST `/cache/flush` 手动清。

路由匹配支持正则和路径参数提取参数传给后端。后端不可用有降级：返回缓存数据（即使过期）或返回配置默认值不直接 502。网关 `/health` 返回路由数、缓存条目数、限流规则数。`go build` 编译，`PORT` 环境变量。
