API 网关要加请求限流和响应缓存。Go Gin 做一个带缓存和限流的 API 网关。
路由匹配支持正则表达式和路径参数，比如 /api/v{version:[0-9]+}/users/:id。匹配后把提取的参数传给后端。
请求限流：每个路由可以配置独立的 QPS 上限。超限返回 429。限流维度支持按 IP、按 API Key、按路由维度组合。
响应缓存：GET 请求的响应可以缓存，缓存 key 由路由+查询参数组成。缓存 TTL 按路由配置。缓存条目上限可配置，超出 LRU 淘汰。
后端不可用时有降级策略：返回缓存的数据（即使过期了）或者返回默认值。降级策略按路由配置。
网关本身的健康检查接口：/health 返回网关状态，包括路由数量、缓存条目数、限流规则数。端口 PORT 环境变量，go build 能过。
