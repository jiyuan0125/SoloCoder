配置中心存了数据库密码和 API Key 在明文里，安全审计过不了——等了半年终于排到修了。Spring Boot 加密版，把敏感配置管起来。

敏感配置用 AES-256 加密存储，密钥通过环境变量 `CONFIG_ENCRYPTION_KEY` 注入不落盘。GET `/configs/{env}/{project}` 查询时，如果请求方的角色没有解密权限，返回脱敏值（如 `****`，长度和原文一致）。有权限的返回明文。权限通过 API Key 管理——POST `/keys` 创建 Key 时指定角色和可访问的项目。

配置变更走审批流程——POST `/configs` 创建或 PUT `/configs/{id}` 修改后，状态变为待审批（pending）。PUT `/configs/{id}/approve` 审批通过后生效，PUT `/configs/{id}/reject` 驳回。审批记录保留申请人、审批人、时间和变更内容。待审批超 N 小时（按项目配，默认 24 小时）自动驳回。审批通过后推变更通知给客户端。

预定义常用配置模板（数据源、Redis、MQ 等），POST `/projects/{name}/init` 从模板初始化，模板里的敏感值也加密存。GET `/templates` 列出可用模板。Maven 构建，端口走配置文件。
