配置中心要加加密配置和审批流程。Spring Boot 做一个带审批机制的配置中心。
敏感配置（如数据库密码、API Key）存储时加密。加密方式用 AES，密钥通过环境变量注入不落盘。查询时如果请求方没有解密权限，返回脱敏后的值（如 ****）。
配置变更需要审批。修改配置后状态变为待审批，管理员审批通过后才生效。审批记录保留，包含申请人、审批人、时间、变更内容。
审批超时：待审批超过 N 小时自动驳回。超时时间按项目配置。审批通过后推送变更通知到客户端，通知内容和之前一样走回调 URL。
配置模板：预定义一些常用配置模板（如数据源配置、Redis 配置），新建项目时可以从模板初始化。模板中的敏感值也需要加密存储。
Maven 构建，端口配置文件。
