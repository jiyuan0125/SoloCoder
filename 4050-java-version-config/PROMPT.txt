配置中心存了密码 API Key 在明文安全审计过不了。Spring Boot 加密版。

敏感配置 AES-256 加密存储密钥通过 `CONFIG_ENCRYPTION_KEY` 环境变量注入不落盘。GET 查询时无解密权限返回脱敏值（如 `****` 长度一致），有权限返回明文。权限通过 API Key 管理 POST `/keys` 创建指定角色和可访问项目。

变更走审批：创建或修改后状态变待审批，PUT approve 通过生效 PUT reject 驳回。审批记录保留申请人审批人时间和变更内容。超 N 小时（按项目配默认 24h）自动驳回。审批通过后推变更通知。

预定义配置模板 POST `/projects/{name}/init` 从模板初始化敏感值也加密。GET `/templates` 列出可用模板。Maven 构建，端口走配置文件。
