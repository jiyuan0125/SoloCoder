我们有好几个后端服务，每个服务都依赖不同的中间件（数据库、Redis、MQ），需要一个统一的健康检查服务，能看到各服务的健康状态和依赖链路。Spring Boot 实现。

每个被检查的服务注册时声明它依赖的组件列表。健康检查支持 HTTP 和 TCP 两种探测方式，按服务配置。探测超时、间隔、连续失败阈值都可以单独设。

依赖级联：如果 A 服务依赖 Redis，Redis 挂了，A 的状态自动变为 degraded（不是完全挂）。degraded 的服务还能继续提供部分功能，只是标记为降级状态。级联关系可以跨多层（A→B→C）。

状态变更历史要保留，查询某个服务时能看到最近 N 次探测结果。状态从 down 恢复到 up 要连续成功探测 M 次才切回，避免抖动。

告警通知：连续失败达到阈值时触发告警，告警方式支持 webhook。告警有静默期，同一服务在静默期内不重复告警。Maven 构建，端口配置文件。
