五个后端服务各自实现 Token 验证逻辑改签名算法改五处。Rust actix-web Token 验证网关统一认证。

支持 JWT 和 opaque token。Bearer 打头是 JWT 验签名过期，Token 打头是 opaque 调内部接口校验。JWT 支持 HS256 和 RS256 密钥配置加载。

Token 刷新：refresh token 换 access token。refresh 用一次失效同时签发新的旧加入黑名单 TTL 与有效期一致过期自动清理。刷新接口须提供有效 refresh token。

验证通过转发时注入 X-User-Id、X-User-Roles header。未认证 401 权限不足 403 统一含 error_code 和 message。`/api/auth/{provider}/token` 走认证其余做校验。`Cargo build`，`PORT` 环境变量。
