v2 全量发布后出 P0 故障全量回滚一小时。Python aiohttp 流量染色路由做金丝雀发布。

染色规则基于请求特征：HTTP header 字段值、cookie 标识、客户端 IP 段、用户 ID 列表，四种可组合。匹配到的打标签如 x-canary:v2 路由到对应版本。

流量百分比：新版本先 5% 观察没问题逐步调到 10%/30%/50%/100%。比例按请求维度不是连接。目标版本不可用自动回退到稳定版响应 header 加 x-canary-fallback:true。回退事件记 SQLite。

配置热更新规则和路由表 API 修改立即生效处理中请求不受影响。规则存 SQLite 持久化重启不丢。`PORT` 环境变量。
