五个 gRPC 服务前端只认 REST 每次加接口写两遍。Go Gin HTTP→gRPC 协议桥接。

REST 请求转 gRPC 调用。JSON↔protobuf 字段映射在 YAML 配置里定义支持 snake_case/camelCase 互转和嵌套展开平铺。配置改了热加载不重启。

gRPC server streaming 用 SSE 对接。客户端 GET Accept:text/event-stream 桥接层持续推送 gRPC stream 消息 stream 结束发完成事件关连接。客户端断开桥接主动关 gRPC stream。

批量：一个 HTTP POST 触发多个 gRPC 调用结果聚合 JSON 数组。有依赖串行无依赖并行依赖在配置声明。错误映射：NOT_FOUND→404 ALREADY_EXISTS→409 DEADLINE_EXCEEDED→504。架构分路由/转换/gRPC 客户端/配置管理。`PORT` 环境变量，`go build` 通过。
