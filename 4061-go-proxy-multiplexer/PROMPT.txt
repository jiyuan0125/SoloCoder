代理服务要能同时对接多个后端，后端挂了要能自动摘除。Go 标准库 net/http 做一个带健康检查的反向代理。

路由规则按路径前缀匹配，每条规则对应一组后端。请求进来后先匹配路由，然后从后端列表里选一个转发。后端选择支持轮询和随机两种策略。

健康检查：定时对每个后端发 HTTP 探测。连续失败 N 次的后端标记为不可用，不再分配流量。后端恢复后需要连续成功 M 次才重新启用，避免抖动。

转发超时可以按路由配置。超时后返回 504，同时记录到审计日志。如果所有后端都不可用，返回 503 并带上降级响应（如果配置了的话）。

请求和响应的 header 可以配置改写规则，比如给请求加上 X-Forwarded-For，去掉响应里的 Server 头。配置通过接口修改，修改后即时生效。至少包含 router、upstream、healthcheck、proxy 四个模块。端口 PORT 环境变量，go build 能过。
