一致性哈希在缓存场景下效果不错，需要实现一个支持虚拟节点的一致性哈希负载均衡器。Spring Boot 来做。

后端节点注册时指定权重，权重越大的节点分配越多的虚拟节点。虚拟节点数量 = 权重 × 倍数（倍数可配置）。请求进来后对请求 key（如 IP 或 SessionID）做哈希，在环上顺时针找最近的虚拟节点，映射到实际节点。

节点下线时只影响分配到该节点的请求，其他请求不受影响。节点上线时新增虚拟节点，环上相邻节点的部分流量迁移到新节点。迁移量要均衡。

统计接口：每个节点的虚拟节点数、分配到的请求量、请求分布的标准差。标准差太大说明哈希不均匀，需要调整。

节点变更后主动推送最新的节点列表和哈希环状态给订阅方。推送失败的记录下来，不阻塞主流程。Maven 构建，端口配置文件。
