网关需要支持请求聚合和响应转换。Go Gin 做一个带聚合能力的 API 网关。

路由匹配支持路径参数和查询参数。匹配后可以把一个请求拆成多个后端调用，结果聚合成一个响应返回。比如客户端请求 /api/profile，网关同时调用用户服务和订单服务，把结果合并。

聚合调用的超时取所有后端超时的最大值。部分后端失败时可以选择：返回部分结果（标记哪些失败）或者整个请求失败。策略按路由配置。

响应转换：后端返回的数据可以通过模板重新组织。模板支持字段提取、重命名、嵌套。转换规则存在配置里。

限流和认证作为中间件。限流按路由配置 QPS 上限。认证支持 API Key 和 JWT 两种方式，按路由选择。端口 PORT 环境变量，go build 能过。
