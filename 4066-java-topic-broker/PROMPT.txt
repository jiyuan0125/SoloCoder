消息队列要支持消息回溯和消费组重平衡。Spring Boot 做一个支持消费组重平衡的消息中间件。

Topic 里的消息按写入顺序分配 offset。消费组记录每个分区的消费位移。消费位移提交支持自动和手动两种模式。自动模式下每消费 N 条提交一次。

消费组重平衡：消费者加入或离开组时触发重平衡。重平衡策略支持轮询和按 key 范围分区。重平衡期间暂停消费，完成后继续。

消息回溯：消费组可以把消费位移重置到更早的 offset，重新消费旧消息。回溯时不影响其他消费组。回溯的起点可以是 offset 值或时间戳。

消息在 Topic 里的保留时间可配置。过期消息后台异步清理，清理期间消费不受影响。消费组信息持久化，重启后恢复。Maven 构建，端口配置文件。
