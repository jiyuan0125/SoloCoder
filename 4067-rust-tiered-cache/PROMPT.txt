缓存淘汰策略要更灵活，支持多种淘汰算法组合。Rust axum 做一个多策略缓存服务。

支持 LRU、LFU、FIFO 三种淘汰策略。每个缓存空间可以独立选择淘汰策略。缓存空间的容量（条目数或字节大小）可以配置。

TTL 支持固定时长和滑动时长两种模式。固定时长：写入后 N 秒过期。滑动时长：每次读取后延长 N 秒。两种模式可以共存，按 key 的前缀区分。

缓存预热：启动时从数据源批量加载。加载任务有进度指示，加载期间查询未命中的 key 走正常 miss 逻辑。加载失败不影响已有数据。

缓存穿透防护：查询不存在的 key 时缓存一个空值（短 TTL），防止反复穿透到数据源。空值和正常值在统计里分开计数。

统计接口：命中率、淘汰数量、当前条目数、内存占用。至少包含 cache、eviction、storage、stats 四个模块。Cargo build，PORT 环境变量。
