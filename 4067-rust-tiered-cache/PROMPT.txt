缓存全用 LRU 冷数据扫描把热点 key 挤掉命中率腰斩。Rust axum 多策略缓存服务。

每缓存空间独立选 LRU/LFU/FIFO。容量按条目数或字节限制。不同业务空间互不干扰一个满了不影响另一个。TTL 两种：固定时长写入后 N 秒过期；滑动时长每次读取延长 N 秒。按 key 前缀区分模式。

缓存预热：启动从数据源批量加载有进度指示加载期间未命中走正常 miss。加载失败不影响已有。穿透防护：查不存在 key 缓存空值短 TTL 60 秒防反复穿透。

统计暴露命中率、淘汰数、条目数、内存占用按空间独立查看。模块：缓存管理/淘汰策略/存储引擎/统计监控。`Cargo build`，`PORT` 环境变量。
