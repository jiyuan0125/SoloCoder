全量发布后有 bug 想回滚不知上版本长啥样。Spring Boot 配置灰度发布系统。

配置按项目和环境隔离如 shop 分 dev/staging/prod。每项有版本号修改递增。修改先创建草稿不影响当前版本。草稿确认进发布流程可预览 diff。草稿可丢弃。值类型支持字符串/数字/布尔/JSON。

灰度发布：指定灰度范围（IP 列表/实例标签）。灰度范围拉新版本其他还是旧版本。灰度期间可对比两组行为差异。确认后全量发布。回滚也是发布操作版本号继续递增不回退。

变更通知走长轮询：客户端发起请求有变更立即响应无变更等到超时重发。通知失败不重试下次轮询自然拿到最新。Maven 构建，端口配置文件。
