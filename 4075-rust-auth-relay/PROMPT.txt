API Key/JWT/用户名密码三套认证改一处动三处。Rust actix-web 统一认证网关。

三种认证：API Key 固定密钥校验、JWT 验签名 claims、用户名密码调后端接口。每方式可有多个 provider 如 JWT 配两密钥做轮换。Authorization header 区分：Bearer→JWT、Token→API Key、Basic→用户名密码。

认证缓存：同凭证 TTL 内不重复校验直接取缓存。命中率 /metrics 暴露。LRU 淘汰容量可配 key 含认证方式和凭证哈希。

RBAC：用户属角色角色有权限列表网关层校验通过带 X-User-Id/X-User-Roles 转发。权限变更清相关缓存。登录失败限制：同 IP/用户名 N 分钟失败超 M 次临时封禁时长可配。模块：auth/cache/rbac/guard。`Cargo build`，`PORT` 环境变量。
