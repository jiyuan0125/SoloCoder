API Key 认证走了一个服务，JWT 认证走了另一个，用户名密码又是第三套——每次加个认证方式就得改三个地方。Rust actix-web 做一个统一认证网关。

支持三种认证方式：API Key、JWT、用户名密码。API Key 是固定密钥，直接校验。JWT 验证签名和 claims。用户名密码调用后端认证接口。每种认证方式可以有多个 provider。

认证结果缓存：相同的凭证在 TTL 内不重复校验，直接从缓存取结果。缓存命中率统计在 /metrics 端点暴露。缓存淘汰用 LRU。

RBAC 权限模型：用户属于角色，角色有权限列表。权限校验在网关层完成，通过的在 header 里带上角色信息转发给后端。权限变更时主动清除相关缓存。

登录失败次数限制：同一 IP 或用户名在 N 分钟内失败超过 M 次就临时封禁。封禁时长可配置。至少包含 auth、cache、rbac、guard 四个模块。Cargo build，PORT 环境变量。
