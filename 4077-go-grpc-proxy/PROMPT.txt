Go Fiber 做一个 WebSocket 到 HTTP 的桥接服务，让只支持 HTTP 的后端也能服务 WebSocket 客户端。

WebSocket 客户端连接后，每个消息转换成一个 HTTP POST 请求转发给后端。后端的响应通过 WebSocket 连接推回给客户端。消息格式转换在配置里定义（JSON 字段映射）。

WebSocket 的二进制消息用 Base64 编码后作为 HTTP body 转发。后端返回的二进制数据也做 Base64 解码后通过 WebSocket 发回。

连接管理：WebSocket 连接的超时、最大消息大小、心跳间隔可配置。后端 HTTP 请求的超时独立配置。WebSocket 断开时后端 HTTP 的长连接也要正确关闭。

桥接支持一对多：一个 WebSocket 消息可以触发多个 HTTP 请求，结果聚合后返回。聚合策略：全部成功才返回，或部分成功也返回（带失败标记）。至少包含 ws-handler、http-client、converter、pool 四个模块。端口 PORT 环境变量，go build 能过。
