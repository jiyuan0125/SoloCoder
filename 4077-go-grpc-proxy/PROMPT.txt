前端转 WebSocket 后端只支持 HTTP 协议不对。Go Fiber WebSocket↔HTTP 桥接。

WS 客户端每个消息转 HTTP POST 转发后端响应通过 WS 推回。JSON 字段映射在配置里定义如 WS 端 user_id 映射 HTTP 端 uid。二进制消息 Base64 编码作 HTTP body Content-Type application/octet-stream 返回也 Base64 解码。纯文本直接透传。

连接管理：WS 超时/最大消息/心跳可配。后端 HTTP 超时独立配。WS 断开 HTTP 长连接正确关闭释放资源。一对多：一个 WS 消息触发多个 HTTP 请求结果聚合返回策略按路由配（全成功或部分成功带失败标记）。架构分 WS 处理/HTTP 客户端/消息转换/连接池管理。`PORT` 环境变量，`go build` 通过。
