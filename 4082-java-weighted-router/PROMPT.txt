新机器权重拉满瞬间被打挂需慢启动。Spring Boot 支持慢启动的加权负载均衡。

权重管理：注册时指定初始权重接口动态调立即生效。权重 0 保留注册不接流量。范围 0-100 默认 50。慢启动：前 N 分钟权重从 0 线性增到配置值如 5 分钟第 1 分钟 20%第 3 分钟 60%第 5 分钟 100%。时间可配默认 5 分钟。

统计暴露每节点实际权重、当前 QPS、活跃连接数。排空模式：摘除不立即停不分配新请求等现有处理完下线超时强下线。健康检查 HTTP 探测连续 N 次失败标不健康自动权重 0 保留原权重。恢复后重进慢启动。模块：权重调度/慢启动控制/健康检测/排空管理。Maven 构建，端口配置文件。
