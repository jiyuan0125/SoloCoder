新上线一台机器，权重直接拉满，结果瞬间涌入大量请求，新机器扛不住又挂了——得有个慢启动过程。Spring Boot 做一个支持慢启动的加权负载均衡器。

后端节点注册时指定初始权重。运行过程中可以通过接口调整权重，调整后立即生效。权重为 0 的节点保留注册但不接收流量。

慢启动：新注册的节点在前 N 分钟内权重从 0 线性增长到配置值。慢启动期间节点逐步接收更多流量，避免新节点突然承担大量请求。慢启动时间可配置，默认 5 分钟。

节点摘除：不是立即停流量，而是进入排空模式。排空模式下不分配新请求，等现有请求处理完后下线。排空有超时，超时后强制下线。

健康检查：HTTP 探测，探测失败连续 N 次标记为不健康。不健康的节点自动设权重为 0（保留原权重信息）。恢复后重新进入慢启动。Maven 构建，端口配置文件。
