新上线一台机器，权重直接拉满，结果瞬间涌入大量请求，新机器扛不住又挂了——得有个慢启动过程。Spring Boot 做一个支持慢启动的加权负载均衡器，新节点流量逐步增长不猝死。

1. 权重管理：后端节点注册时指定初始权重。运行过程中可以通过接口调整权重，调整后立即生效。权重为 0 的节点保留注册但不接收流量。权重范围 0-100，默认 50。

2. 慢启动机制：新注册的节点在前 N 分钟内权重从 0 线性增长到配置值。比如配置了 5 分钟慢启动，第 1 分钟实际权重是配置值的 20%，第 3 分钟是 60%，第 5 分钟达到 100%。慢启动期间节点逐步接收更多流量。慢启动时间可配置，默认 5 分钟。

统计接口暴露每个节点的实际权重、当前 QPS、活跃连接数，方便观察慢启动的进度和排空状态。统计接口暴露每个节点的实际权重、当前 QPS、活跃连接数。节点摘除不是立即停流量，而是进入排空模式。排空模式下不分配新请求，等现有请求处理完后下线。排空有超时，超时后强制下线并关闭连接。健康检查用 HTTP 探测，探测失败连续 N 次标记为不健康。不健康的节点自动设权重为 0，但保留原权重信息。恢复后重新进入慢启动流程。架构分权重调度层、慢启动控制器、健康检测层、排空管理器。Maven 构建，端口配置文件。
