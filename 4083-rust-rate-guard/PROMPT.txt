限流 key 不一定是 IP 有些要从 body 提 tenant_id 差异化限流。Rust actix-web 内容感知限流器。

限流维度可从 body 或 header 提字段作 key 如 tenant_id。提取规则用 JSONPath 如 $.tenant.id 或 header X-Tenant-Id。提取失败走默认限流兜底。不同 key 阈值不同按 key 前缀分组配如 tenant:vip QPS 上限 1000 tenant:normal 100。没有匹配用默认阈值。分组动态增删。

令牌桶算法桶容量和填充速率独立配。状态存内存重启清零。超限可选拒绝 429 或排队等待排队有超时和上限。`Cargo build`，`PORT` 环境变量不依赖外部存储。
