请求校验放后端太晚不合法请求已消耗资源。Go 标准库 net/http 带校验的 API 网关。

请求校验：对参数校验——必填、类型、长度、格式。规则 JSON Schema 格式按路由配不同接口不同要求。失败返回 400 和详细错误不转发。流量控制：速率限制按路由+IP 如 /api/query 每 IP 100 QPS。并发限制按路由超出排队。多规则叠加先全局再路由。

请求转换：转发前 JSON 字段重命名、默认值填充、字段过滤在配置里定义。响应缓存：GET 响应可缓存 key 含路由+查询参数 TTL 按路由配上限可配满时 LRU 淘汰。命中率和条目数 /cache/stats 可查。`PORT` 环境变量，`go build` 通过。
