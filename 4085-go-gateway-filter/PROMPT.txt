网关要做请求校验和流量控制。Go 标准库 net/http 做一个带校验能力的 API 网关。

请求校验：对请求参数做校验——必填字段、类型、长度、格式。校验规则在配置文件里定义，支持 JSON Schema 格式。校验失败的请求直接返回 400，不转发到后端。

流量控制：请求速率限制和并发数限制。速率限制按路由和 IP 组合维度。并发限制按路由维度，超出排队。多个限流规则可以叠加。

请求转换：转发前可以对请求做简单转换——JSON 字段重命名、默认值填充、字段过滤。转换规则在配置里定义。

响应缓存：GET 请求的响应可以缓存。缓存 key 包含路由和查询参数。缓存 TTL 按路由配置。缓存条目上限可配置，LRU 淘汰。端口 PORT 环境变量，go build 能过。
