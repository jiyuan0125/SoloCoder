下单 30 分钟未支付自动取消需延迟消息。Spring Boot 消息中间件支持延迟投递和消息过滤。

延迟消息：投递时指定延迟秒数到期才对消费者可见。用时间轮实现精度到秒精度和槽数可配。到期自动投递不需要消费者轮询。

消息过滤：消费者指定过滤表达式只接收满足条件的消息基于 header 属性如 region/priority。服务端执行不匹配不投递节省处理资源。顺序保证：同 partition key 的消息保证顺序不同 key 不保证。key 从消息属性提取。

ACK 机制：超时未 ACK 重新投递带原始投递时间和重试次数。超最大次数进死信 Topic。模块：delay/filter/partition/deadletter。Maven 构建，端口配置文件。
