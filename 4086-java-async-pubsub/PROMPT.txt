消息队列要支持延迟消息和消息过滤。Spring Boot 做一个支持延迟投递和过滤的消息中间件。

延迟消息：投递时指定延迟时间，到期后才对消费者可见。延迟精度到秒。延迟消息到期后自动投递到目标 Topic。

消息过滤：消费者可以指定过滤表达式，只接收满足条件的消息。过滤基于消息的 header 属性（如 region、priority）。过滤在服务端执行，不匹配的消息不投递。

消息顺序：同一个 partition key 的消息保证顺序投递。不同 partition key 的消息不保证顺序。partition key 从消息属性里提取。

消息确认：消费者处理完消息后发 ACK。超时未 ACK 的消息重新投递。重新投递的消息带原始投递时间和重试次数。超过最大重试次数进死信 Topic。Maven 构建，端口配置文件。
