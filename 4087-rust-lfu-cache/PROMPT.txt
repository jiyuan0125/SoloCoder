并发更新同 key 两个请求各改各的后写覆盖先写数据丢了。Rust axum 支持批量操作和 CAS 的缓存服务。

批量操作：MGET/MSET 一次操作多个 key 原子性全成功全失败。key 数量有上限超出自动拆多批次。MGET 不存在的 key 返回 null。CAS：更新先比较版本号一致才更新失败返回冲突含当前值和期望值。每 key 每次写入版本递增。

缓存事件通知：key 更新或删除时推送通知订阅者按 key 前缀过滤。异步推送失败不重试。热点探测：自动统计访问频率超阈值标记热点 TTL 延长淘汰优先级降低。热点列表接口可查。

模块：缓存存储/CAS 控制/事件通知/热点分析。`Cargo build`，`PORT` 环境变量。
