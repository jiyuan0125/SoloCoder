查服务实例只能按服务名查？不够——灰度发布时要查 version=v2 的实例，异地多活时要查 region=east 的实例。Go 标准库 net/http 做一个带标签路由的注册中心。

实例注册时除了 IP 和端口，还可以打标签（如 version=v2, env=canary, region=east）。查询时按标签过滤，比如查所有 version=v2 的实例。标签支持多值（一个实例可以有多个 version 标签）。

权重调整：实例的权重可以通过接口动态修改。权重影响查询结果的分布——权重越大的实例被选中概率越高。权重为 0 等于下线但保留注册。

实例分组：同一服务的实例按标签自动分组。查询时可以指定分组，也可以查所有分组。分组变更（实例标签变化）时触发通知。

实例的状态流转：注册→健康→可疑→下线。可疑状态是心跳延迟但还没超时。从可疑恢复到健康需要连续 N 次正常心跳。至少包含 registry、tag、weight、notify 四个模块。端口 PORT 环境变量，go build 能过。
