各部门预算管理全靠Excel太容易出错。做一个预算规划API，每个部门有年度预算总额分配到12个月和多个类别（差旅、办公、设备、培训等）。报销时自动从对应类别和月份剩余预算扣减，不足直接拒绝并告知还差多少。部门负责人可调整月度预算分配但总和不能超年度总额，调整后如果某月某类别已有报销记录且新预算低于已使用金额则拒绝调整。一笔报销涉及多个类别时分别扣减，任一类别不足整笔都拒绝，不能部分通过部分拒绝。季度末剩余预算可以申请结转到下季度，但结转金额不能超过当季总额的20%。年底未用完的预算自动清零不结转次年。新财年开始前系统自动复制上年度预算结构生成新年度草稿，HR确认后正式生效。提供预算使用率统计，按部门、类别和时间段查询。预算季度末剩余预算可以申请结转到下季度但结转金额不能超过当季总额的20%。年底未用完的预算自动清零不结转次年。新财年开始前系统自动复制上年度预算结构生成新年度草稿。调整月度预算分配时如果某月某类别已有报销记录且新预算低于已使用金额则拒绝调整。提供预算使用率趋势图数据，按部门类别和时间段查询。预算金额全部用整数分表示，扣减和结转计算使用整数运算。数组和对象的不可变操作，不能直接修改传入的参数对象。
项目以 TypeScript monorepo 方式构建。packages/shared 负责集中定义所有公共的类型、接口、消息格式和错误码。packages/server 基于 Node.js 内核的 http 模块创建 HTTP 服务（严禁引入第三方 Web 框架），承载所有业务逻辑，运行时数据保持在内存中。packages/cli 作为命令行客户端，接受用户操作指令后向服务端发起 HTTP 请求，将响应格式化输出。根目录的 package.json 通过 workspaces 字段管理三个子包，顶层 tsconfig.json 启用严格模式。每个子包内部按职责将代码分散到不同文件中。TypeScript strict 模式强制开启，禁止 any 和 @ts-ignore。npm install && npm run build 必须能成功编译。
