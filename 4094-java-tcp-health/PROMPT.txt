告警太多，运维看都不看了——结果真正挂掉的服务淹没在一堆无关紧要的告警里。Spring Boot 做一个带告警升级的健康检查系统，持续不恢复逐级升级通知。

自定义探针：除了 HTTP 和 TCP，还支持执行自定义命令作为探针。命令的退出码决定健康状态（0=健康，非0=不健康）。命令超时可配置。

告警升级：首次告警发给运维组，持续 N 分钟未恢复自动升级到研发组。持续 M 分钟再升级到管理层。升级链路和通知方式（邮件、webhook）可配置。

健康评分：每个服务有一个综合健康评分（0-100）。评分基于探测成功率、响应时间、依赖健康度加权计算。评分低于阈值触发预警。

探测结果的历史数据保留 30 天。支持查询某个服务的历史健康趋势（按天聚合）。趋势数据用于容量规划。Maven 构建，端口配置文件。
