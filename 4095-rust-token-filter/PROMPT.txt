每接口权限不同硬编码维护不过来。Rust actix-web API 级认证网关权限配置化。

权限按 HTTP 方法和路径组合定义如 GET /api/users 公开 POST 需 admin DELETE 需 superadmin。配置文件改权限不碰代码。支持通配符 /api/admin/* 下都要管理员。Token JWT 角色存 claims。过期/签名无效 401 权限不足 403。

权限缓存：解析和判断结果都缓存 TTL 可配默认 5 分钟。配置变更清相关缓存。命中率 /stats 暴露。审计日志：每次请求记用户/路径/方法/判断结果异步写入不阻塞。支持按用户和时间查。模块：authz/cache/audit/config。`Cargo build`，`PORT` 环境变量。
