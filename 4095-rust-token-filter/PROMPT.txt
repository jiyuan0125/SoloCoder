GET /api/users 是公开接口，POST /api/users 要管理员权限，DELETE /api/users/:id 要超级管理员——每个接口权限不同，硬编码维护不过来。Rust actix-web 做一个 API 级别的认证网关。

API 权限按 HTTP 方法和路径组合定义。比如 GET /api/users 是公开的，POST /api/users 需要管理员权限。权限配置存在网关里，不需要每次查后端。

Token 解析后提取用户角色。角色和权限的映射关系在配置里定义。一个角色可以有多个权限。支持通配符路径（如 /api/admin/*）。

权限缓存：解析结果和权限判断都做缓存。缓存 TTL 可配置。权限配置变更时主动清除缓存。缓存命中率统计在 /stats 端点暴露。

审计日志：每次请求记录用户、路径、方法、权限判断结果。审计日志异步写入，不阻塞请求。日志支持按用户和时间范围查询。至少包含 authz、cache、audit、config 四个模块。Cargo build，PORT 环境变量。
