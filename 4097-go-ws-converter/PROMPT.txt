前端 JSON 后端 Protobuf 另一团队 XML 各写一套转换逻辑。Go Gin 自动检测格式的转换网关。

格式检测：先看 Content-Type 没有则根据 body 猜——JSON 以 {/ [ 开头 XML 以 < 开头 Protobuf/MessagePack 二进制格式不同。支持 JSON/XML/Protobuf/MessagePack 四种。检测错误返回 415。

后端只接受一种格式可配。网关负责统一转换。响应反向转换通过 Accept header 协商不指定原样返回。Protobuf 需 schema 文件路径在配置指定启动加载失败的服务不处理 Protobuf。转换失败返回 400 和详细错误。架构分检测/转换/schema 管理/路由。`PORT` 环境变量，`go build` 通过。
