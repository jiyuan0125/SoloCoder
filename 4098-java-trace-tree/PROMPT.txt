Span 只有 trace_id 没有业务标签定位不了业务问题。Spring Boot 追踪系统 Span 可附加业务标签。

自定义标签：Span 附加 order_id/tenant_id/user_id 等。标签通过 X-Trace-Tags header 传播格式 key=value 逗号分隔。查询时标签作过滤条件直接用订单号搜。

跨服务传播：支持同步 HTTP 和异步 MQ 两种方式——MQ 传播 Trace 信息放消息 header 属性消费者取出继续传。传播断了不影响业务只丢那段 Trace。Span kind 区分 CLIENT/SERVER 一对 Span 通过 parent_span_id 关联。采样策略动态调整接口改比例从 0.01% 到 100% 立即生效。Spring Boot Maven 构建端口配置文件数据存内存。
