会员积分系统需要后端管理积分全生命周期。用户消费1元得1积分，积分可以兑换礼品或抵扣消费（100积分抵扣1元）。积分获得后12个月自动过期清零，每月1号批量清理过期积分并生成清理报告。可用积分不足时拒绝兑换，抵扣时积分只能抵扣订单金额的30%上限，防止全积分白嫖。订单部分退款时积分按比例撤回。如果用户已用掉一些积分，可用不够撤回时记为负数，后续新积分先补齐负数再正常累加。积分兑换礼品后发生退货，已兑换的礼品不退回积分但退还实际支付的金额。新注册用户送500积分作为新人礼，新人积分30天内不可用于抵扣消费只能兑换礼品，防止刷号薅羊毛。查询自己积分余额、30天内即将过期的积分数量和明细，支持按时间范围和类型（获取/消耗/过期）筛选。积分100积分抵扣1元，抵扣时积分只能抵扣订单金额的30%上限防止全积分白嫖。积分兑换礼品后发生退货，已兑换的礼品不退回积分但退还实际支付金额。新注册用户送500积分作为新人礼，新人积分30天内不可用于抵扣消费只能兑换礼品防止刷号薅羊毛。每月1号批量清理过期积分并生成清理报告发送给用户。所有函数参数和返回值必须有明确的类型注解，异步操作中 promise 的拒绝必须被正确处理不能被忽略。
以 TypeScript 实现，整体采用 monorepo 项目结构。packages/shared 集中管理公共类型定义、请求响应接口、消息格式及错误码。packages/server 通过 Node.js 内置的 http 模块启动 HTTP 服务（不允许使用 Express/Koa 等第三方框架），处理所有业务请求，数据驻留内存。packages/cli 是命令行工具，用户通过子命令和参数与服务端交互，结果在终端格式化展示。根目录 package.json 使用 workspaces 联动三个子包，tsconfig.json 开启 strict 模式。各包按功能职责拆分文件。禁止 any 和 @ts-ignore。npm install && npm run build 能编译通过。
