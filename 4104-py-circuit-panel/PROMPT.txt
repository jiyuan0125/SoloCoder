之前用过 Hystrix 做熔断，这次换 Python FastAPI 自己实现一套，要做多个服务的集中熔断管理。
每个下游服务独立维护一个熔断器状态。熔断器有三种状态：关闭、打开、半开。关闭状态下失败次数达到阈值自动打开。打开状态持续 N 秒后进入半开，放一个请求试水，成功就关闭，失败继续打开。
提供一个面板接口查询所有服务的熔断状态和近期请求统计。统计包含成功率、平均响应时间、最近一次失败原因。
熔断状态变更时触发回调通知，回调 URL 按服务配置。通知失败不影响主流程。模块划分 circuit、stats、panel、notify。
端口 PORT 环境变量，pip install 能装好依赖跑起来。
