现有网关写死了一堆中间件逻辑，加个功能就要改主代码重新部署。Go Gin 做一个插件化网关，插件机制是核心，用 Go 的 plugin 包动态加载 .so 文件。
网关启动时扫描 plugins 目录，加载所有 .so 文件。每个插件实现固定的接口：Init、Handle、Destroy。请求经过插件链顺序处理，链的顺序通过配置文件定义。
内置几个插件：日志插件记录请求响应、认证插件校验 JWT、限流插件按 IP 限流。插件之间可以通过 context 传递数据。
插件热更新：替换 .so 文件后调用 reload 接口，旧插件 Destroy，新插件 Init。reload 过程中新请求排队等插件就绪。
路由配置支持路径参数和通配符。插件链按路由组配置，不同路由组可以用不同的插件链。端口 PORT 环境变量，go build。
