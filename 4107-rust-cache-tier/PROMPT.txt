Redis 挂了请求穿透数据库雪崩。Rust actix-web 多级缓存 L1 内存+L2 磁盘。

查询：先 L1 命中直接返。L1 miss 查 L2 命中回填 L1 返。两级 miss 返回 miss 调用方自定。淘汰：L1 支持运行时切换 LRU/LFU（PUT /cache/policy）切换清空 L1 L2 不受。缓存项可锁定不参与淘汰不受 TTL。TTL 精度到秒过期 miss 异步删后台每秒扫不阻塞。

L2 用 bincode 序列化每项存 header（key/ttl/created_at/locked）+ body。写入双写删除双删。L2→L1 只查询触发。GET /cache/stats 暴露 L1/L2 hits/misses 和容量。`Cargo build`，`PORT` 环境变量。
