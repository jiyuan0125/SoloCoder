Rust axum 做一个分布式锁管理服务。锁的获取、释放、续期都通过 HTTP 接口。
锁有超时时间，获取后超时未续期自动释放。续期就是延长超时时间。同一个锁同一时间只有一个持有者。其他请求在获取时可以指定是否等待，等待的请求在锁释放后按先来先得获取。
锁支持分级：子锁获取时自动获取父锁。释放父锁时所有子锁一起释放。子锁独立超时，不影响父锁。
锁的状态：free → acquired → renewing → expired。获取中的锁超时后进入 expired，等待队列中的下一个请求自动尝试获取。如果持有者宕机，锁超时后自动释放。
管理接口可以查询所有锁的状态、等待队列长度。至少包含 lock、queue、manager、handler 四个模块。Cargo build，PORT 环境变量。
