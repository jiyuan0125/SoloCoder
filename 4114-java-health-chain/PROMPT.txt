健康检查要支持依赖链级联。Spring Boot 做一个级联健康检查服务。
每个服务可以定义依赖的上游服务列表。检查一个服务时先检查它的上游。上游不健康则下游也标记为不健康。依赖链可能有循环，循环的地方跳过不再递归。
检查结果有三级：healthy、degraded（部分依赖不健康）、unhealthy。degraded 的服务还可以用但不推荐。
检查可以 HTTP 或 TCP 方式。HTTP 检查发 GET 请求到指定路径，2xx 算通过。TCP 检查尝试建连，连上就算通过。
检查结果缓存 30 秒。缓存期间同一服务的检查请求直接返回缓存结果。多个服务同时被检查时，共享的依赖只检查一次。
检查失败超过连续 N 次触发告警，告警推送到配置的 webhook。Maven 构建，端口配置文件。
