安全审计要求每个入口请求必须经过四级校验：IP 白名单、API Key、JWT、权限。Rust actix-web 实现，请求像过安检一样一层层走。
认证链由多个处理器组成：IP 白名单 → API Key 校验 → JWT 解析 → 权限校验。每个处理器独立配置是否启用。链的顺序固定，前面的通过才到后面。
每个处理器有自己的状态：bypassed（跳过）、passed（通过）、failed（失败）。任何一个失败，整个请求直接拒绝。所有通过则在 header 里注入认证结果。
JWT 支持 RS256 和 HS256 两种签名算法。密钥通过配置接口上传，支持轮换。旧密钥在过期前仍然有效。
登录令牌有刷新机制：token 过期前 5 分钟内可以刷新，刷新后旧 token 立即失效。过期超过 24 小时的 token 不允许刷新。
模块分 chain、handler、token、config。Cargo build，端口从 PORT 环境变量读。
