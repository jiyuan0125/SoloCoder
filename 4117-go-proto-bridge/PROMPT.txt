前端只会 HTTP JSON 后端全用 gRPC。Go 标准库协议桥接 HTTP JSON 自动转 gRPC。

映射表：HTTP 路径+方法→gRPC 服务方法。POST /mappings 管理含 http_path/http_method/grpc_service/grpc_method/grpc_address。字段映射：request_mapping 指定 JSON 字段对应 gRPC 字段支持嵌套如 user.name→user_info.full_name 数组映射 repeated 字段。映射不到配默认值或忽略。

响应转换：字段名统一 snake_case。嵌套 message 可展平或保留层级 response_style 控制。enum 转字符串不转数字。

错误处理：gRPC 状态码映射 HTTP——NOT_FOUND→404 ALREADY_EXISTS→409 PERMISSION_DENIED→403 DEADLINE_EXCEEDED→504 其他→500。`PORT` 环境变量，`go build` 通过。
