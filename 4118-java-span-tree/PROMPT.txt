线上的 OpenTelemetry 太重了，重写一个轻量链路追踪，Spring Boot 实现。
TraceID 和 SpanID 是 16 位十六进制字符串。请求进来时如果没有 TraceID 就生成一个。每个处理环节创建新的 Span，记录开始时间和结束时间。Span 之间有父子关系。
Span 可以有标签和日志。标签是 key-value，日志是带时间戳的文本。一个 Trace 下可能有几百个 Span，深度可能到 20 层。
查询接口支持按 TraceID 查完整调用树。调用树按时间排序展示。还支持按服务名和时间范围搜索 Trace 列表。
追踪数据存在内存里，超过 10000 条 Trace 自动淘汰最老的。Span 数据可能不完整（有些环节没上报），查询时要标注缺失的 Span。
Maven 构建，端口配置文件指定。
