凌晨跑批任务挂了 30 多个，手动重试到天亮。用 Rust axum 写个批量重试管理器，以后这种事交给机器。
任务有状态：pending → running → success / failed → retrying → success / dead。失败的任务根据重试策略决定是否重试。重试策略配置最大次数和退避间隔（固定、指数、自定义）。
同一个任务的重试次数达到上限后进入 dead 状态。dead 状态的任务可以手动重新触发。任务分组管理，可以按组暂停和恢复重试。
幂等保证：每个任务有唯一 ID，同一 ID 不重复执行。执行结果缓存，重试时如果缓存中有成功结果直接返回。
并发执行的任务数有上限，等待的排队。拆成 task、retry、queue、store 四个模块。Cargo build，PORT 环境变量。
