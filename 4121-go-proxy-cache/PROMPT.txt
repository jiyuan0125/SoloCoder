后端接口响应慢，老板要求加一层缓存扛住高峰流量。Go Gin 写个带响应缓存的反向代理，GET 请求缓存，POST/PUT 不动。
缓存 key 由请求路径 + query 参数排序后拼接生成。缓存项有 TTL，过期自动失效。同一个 key 并发请求时，第一个去后端拿数据，后面的等第一个拿到后共享结果。不要让并发请求打到后端。
后端服务列表存在内存中，支持动态添加删除。代理在转发前选择后端时做健康检查，不健康的跳过。缓存项被后端返回的数据覆盖时，正在使用旧缓存数据的请求不受影响。
缓存淘汰用 LRU，容量上限可配置。缓存命中率在 /stats 端点暴露。模块划分 proxy、cache、backend、stats。
go build 编译通过，端口 PORT 环境变量。
