上个月双十一流量调度出了个事故，跨机房流量全挤到一条线上了。现在要上分区负载均衡器，Spring Boot 做。
后端节点划分到不同的区域（zone）。请求也带区域标签。优先把请求分配给同区域的节点。同区域没有可用节点时才跨区域。
节点状态：healthy → suspect（疑似异常）→ unhealthy → draining（排水中）→ removed。suspect 状态的节点分配到的流量逐渐减少。draining 状态的节点不再分配新流量，等已有请求处理完移除。
区域切换：如果某个区域的所有节点都不可用，流量自动切到其他区域。区域恢复后流量自动切回。切换过程平滑，已有的连接不中断。
权重配置支持权重为 0 的情况，权重为 0 的节点不分配流量但仍然参与健康检查。Maven 构建，端口配置文件。
