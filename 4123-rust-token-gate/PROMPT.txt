Rust axum 做一个令牌桶限流网关。请求到达时消耗令牌，桶空了就拒绝。
每个客户端有独立的令牌桶。客户端身份从请求的 Authorization header 提取。没有 header 的用源 IP 标识。令牌桶的容量和填充速率按客户端级别配置。
突发流量支持：桶里最多存 capacity 个令牌，每个请求消耗 1 个。桶空了返回 429。客户端可以配置 burst 参数，允许短时间内超限。
黑名单机制：触发限流次数超过阈值的客户端自动进黑名单，直接拒绝所有请求。黑名单有有效期，过期自动解封。
白名单机制：白名单内的客户端不限流。黑白名单通过接口管理。查询接口支持按客户端查当前桶状态和历史被限流次数。至少包含 bucket、gate、ban、handler 四个模块。Cargo build，PORT 环境变量。
