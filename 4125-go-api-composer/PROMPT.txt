Go 标准库做一个 API 聚合网关。一个请求可以聚合多个后端接口的数据返回。
聚合规则配置：定义虚拟接口路径，每个虚拟接口映射到多个后端接口。后端接口可以并行调用也可以串行。串行模式下前面接口的响应字段可以引用到后面接口的请求参数里。
响应合并：多个后端响应合并成一个 JSON。合并规则可配置：取某个字段、合并数组、取第一个非空值。字段名可以重命名。
超时控制：每个后端接口独立超时。部分超时不影响其他接口的结果，超时的接口在最终响应里标记为 timeout。所有接口都超时才返回整体错误。
路由支持路径参数和多级路径。至少包含 router、composer、merger、config 四个模块。端口 PORT 环境变量，go build 能过。
