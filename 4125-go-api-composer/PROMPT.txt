前端一个页面调 5 个接口串行 500ms 起。Go 标准库 API 聚合网关一个请求打包多后端。

POST /compose 创建规则含 path（虚拟路径）/endpoints（后端列表各有 url/method/params/timeout_ms）/mode（parallel/sequential）。并行同时发串行前面响应可引用后面参数用 ${response.field_name}。

合并规则 POST /compose/{id}/merge 配——pick（取字段）/merge_array（合并数组）/coalesce（取首个非空）。字段可重命名避免同名冲突。超时每个后端独立默认 5 秒部分超时不影响其他对应字段标 error。全部超时才 504。路由支持路径参数和多级路径。`PORT` 环境变量，`go build` 通过。
