VIP 客户工单排普通用户后面两小时才处理。Spring Boot 支持优先级消息队列。

消息优先级 1-10 越大越优先同 topic 按优先级排相同按发送时间 FIFO。POST /message/send 含 topic/priority/body（JSON）/ttl（可选过期秒数）。消费失败进死信 GET /deadletter/{topic} 分页查。POST /deadletter/{message_id}/redeliver 重投恢复原优先级。死信上限 10000 满了丢弃最老记 warning。

消息大小上限 1MB 超大返回 413。体须合法 JSON 符合 topic 的 JSON Schema（POST /topic/{name}/schema 注册）校验失败 400 加不匹配字段列表。发送确认：等 broker 返回 message_id（UUID）和 status=accepted 超时 5 秒视为失败。Maven 构建，端口配置文件。
