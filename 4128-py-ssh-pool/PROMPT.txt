Python FastAPI 做一个 SSH 连接池管理服务。运维场景，批量管理多台机器的 SSH 连接。
每个目标机器独立维护一个连接池。池子参数：最大连接数、连接超时、命令执行超时、空闲回收时间。连接建立后执行一个简单的 echo 命令验证可用性。
执行命令接口：指定目标机器和命令，从池子取连接执行，执行完归还。执行结果包含 stdout、stderr、exit_code。超时的命令强制终止并返回部分结果。
连接健康检查：后台定期对空闲连接执行 echo 测试，失败的连接关闭并从池子移除。检查间隔可配置。
目标机器信息管理：通过接口添加和删除目标机器。删除机器时先关闭该机器的所有连接。至少包含 pool、executor、checker、manager 四个模块。端口 PORT 环境变量。
