有人把支付超时从 30 秒改成 3 毫秒全站失败连审批都没。Spring Boot 带审批工作流的配置中心。

配置状态：draft→submitted→approved→published 或 rejected 退回。提交 POST /config/{key}/submit。审批人按环境配 dev 谁都批 staging 需 TL prod 需指定列表（POST /env/{env}/approvers）。批准 POST approve 驳回 POST reject 须填 reason。

推送：客户端轮询 GET /config（30 秒间隔）或 SSE GET /config/stream。确认 POST /config/ack/{version} 未 ack 每 60 秒重推。GET /config/push-status 查确认状态。回滚 POST /config/{key}/rollback?version=N 也走审批版本号只增不减。Maven 构建，端口配置文件。
