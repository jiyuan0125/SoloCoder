单点锁 Redis 挂了全完。Rust axum Redlock 风格 N 节点多数派同意才算拿到。

POST /lock/{name}/acquire 含 ttl（默认 30 秒）和 token。向 N 节点同时 SETNX 超半数成功才算获取成功失败则向所有节点释放清理。续约 PUT /lock/{name}/renew 向 N 节点超半数才算成功建议 TTL 1/3 时发起。释放 DELETE /lock/{name}/release 向所有节点 token 匹配才能释放失败重试 3 次间隔 100ms 都失败记 error TTL 自动过期。

节点 POST /nodes 添加 DELETE 移除 GET 列出 alive/dead。变更不影响已有锁渐进式。健康检查每 5 秒 TCP dial。`Cargo build`，`PORT` 环境变量。
