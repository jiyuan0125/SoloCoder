Rust axum 做一个 Redlock 风格的分布式锁。多个锁节点协同保证互斥。
锁获取：向 N 个锁节点同时请求加锁，超过半数成功才算获取成功。获取成功后记录有效时间。获取失败则向所有节点发送释放请求。
锁续约：持有者在有效期内定期续约。续约也是向 N 个节点续约，超过半数成功才算续约成功。续约失败不立即释放，等有效时间到了自动过期。
锁释放：向所有节点发送释放请求。只有锁的持有者才能释放（通过 token 验证）。释放失败重试几次。
锁节点管理：可以动态添加和移除锁节点。节点列表变更时，已有的锁不受影响。至少包含 lock、quorum、node、manager 四个模块。Cargo build，PORT 环境变量。
