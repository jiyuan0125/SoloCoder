Go Gin 做一个自定义指标采集平台。业务方可以自己定义指标类型和上报数据。
指标注册：通过接口定义新指标，指定名称、类型（counter/gauge/histogram/summary）、描述、标签列表。同一个名称不能重复注册。注册后立刻可以上报数据。
数据上报：客户端通过 HTTP POST 上报指标数据。数据格式是 JSON，包含指标名、标签值、数值。批量上报支持，一次请求上报多个指标点。
聚合查询：按时间窗口（1分钟/5分钟/1小时）聚合查询指标数据。聚合方式按指标类型不同：counter 求增量，gauge 求平均，histogram 求分位数。时间窗口内没有数据返回空而不是报错。
指标之间的数学运算：可以定义派生指标，比如 QPS = 请求数 / 时间窗口秒数。至少包含 registry、ingest、query、compute 四个模块。端口 PORT 环境变量，go build 能过。
