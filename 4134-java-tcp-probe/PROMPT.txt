现有的健康检查只能判断通不通，没有连续性判断。偶尔一次超时就告警，半夜被叫起来发现是网络抖动。Spring Boot 做一个支持多种探针和自定义阈值的健康检查，连续 N 次失败才算真挂。
探针类型：HTTP（GET 请求判断状态码）、TCP（尝试建连判断端口是否通）、Script（执行脚本判断退出码）。每种探针独立配置超时时间、检查间隔、成功阈值和失败阈值。
检查结果判定：连续 N 次成功才标记为 healthy，连续 M 次失败标记为 unhealthy。中间状态是 degraded。阈值可以按服务单独配置。
探针编排：多个探针可以组合。组合逻辑支持 AND（全通过才算通过）和 OR（任一通过就算通过）。组合的结果也需要满足连续性阈值。
历史记录保留最近 1000 次检查结果。历史结果支持按时间范围和服务名查询。检查结果量大时查询要做分页。
probe、orchestrator、history、handler 四个模块。Maven 构建，端口配置文件。
