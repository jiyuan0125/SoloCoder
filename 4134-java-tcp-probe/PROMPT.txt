偶尔一次超时就告警半夜白跑。Spring Boot 多种探针自定义阈值连续 N 次才算真挂。

POST /probe 创建含 name/type（http/tcp/script）/target/timeout（默认 5s）/interval（默认 10s）/success_threshold（默认 2）/failure_threshold（默认 3）。HTTP GET 2xx 成功记响应时间。TCP 建连成功记连接时间。Script 执行退出码 0 成功记 stdout/stderr。线程池并行执行。

三级状态：healthy（连续 success_threshold 成功）/unhealthy（连续 failure_threshold 失败）/degraded（中间态）。状态变更记日志触发回调。探针编排 POST /group 创建组含 probes 列表和 logic（AND/OR）。AND 全通过才算 OR 任一通过。组也满足连续性阈值。Maven 构建，端口配置文件。
