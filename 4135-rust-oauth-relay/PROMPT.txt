十几个应用各接 OAuth2 复制粘贴 bug 修了又修。Rust actix-web 认证中继统一走。

两种流程：Authorization Code（有用户）和 Client Credentials（服务间）。Code 流程中继帮换 token 应用只须 POST /oauth/token 传 code。Client Credentials POST /oauth/client-token 直接返回。

Token 存储：中继缓存每个用户 token 过期前 5 分钟自动用 refresh 刷新失败标 expired 下次返回 401 让应用重新授权。AES-256 加密存储密钥从环境变量读。

用户信息：中继用 access_token 从提供方获取用户名/邮箱/头像缓存 30 分钟。GET /oauth/userinfo 返回。多应用：POST /oauth/apps 注册每应用独立 client_id/secret/redirect_uri。GET /oauth/apps 列出。`Cargo build`，`PORT` 环境变量。
