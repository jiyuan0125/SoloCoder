每次发新功能都是全量上线，出问题了全量回滚。Python aiohttp 写一个 Feature Flag 路由服务，按用户特征灰度放量，出问题只关开关。
Feature Flag 配置：每个 flag 有名称、启用百分比、用户白名单、用户属性规则。规则支持组合：年龄 > 18 AND 地区 = CN。属性值从请求 header 里提取。
流量分配：百分比按用户 ID 取 hash 后分配。同一个用户每次命中结果一致。白名单用户始终命中。
Flag 依赖：一个 flag 可以依赖另一个 flag。父 flag 关闭时子 flag 也关闭。依赖关系不能循环。
变更实时生效：修改 flag 配置后下一个请求立刻按新配置判断。变更历史记录在内存里，可以回滚。拆成 flag、matcher、router、history。端口 PORT 环境变量。
