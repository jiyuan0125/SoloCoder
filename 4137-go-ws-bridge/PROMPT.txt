浏览器 WebSocket 后端 HTTP REST 中间缺翻译层。Go 标准库桥接 WS 消息自动转 HTTP。

映射规则 WS 消息 action 字段映射 HTTP 路径方法如 action=create_order→POST /api/orders。其他字段作 HTTP body JSON。POST /bridge/rules 管理含 action/http_method/http_path/backend_url。

WS 连接管理：多客户端同时连接每连接唯一 connection_id 维护独立订阅列表。subscribe 消息订阅事件。GET /bridge/connections 查活跃连接和订阅。

服务端推送：后端 POST /bridge/push 含 topic/data 桥接推给订阅该 topic 的 WS 连接失败静默跳过。消息序号：每 WS 消息有递增 seq 客户端检测丢失桥接保证按序号顺序转发。`PORT` 环境变量，`go build` 通过。
