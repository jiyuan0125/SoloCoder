Go 标准库做一个 WebSocket 到 HTTP 的桥接服务。WebSocket 客户端发消息，桥接服务转发成 HTTP 请求。
桥接规则：WebSocket 消息的某个字段（比如 action）映射到 HTTP 的路径和方法。消息的其他字段作为 HTTP 请求 body 或 query 参数。映射规则通过配置接口管理。
WebSocket 连接管理：支持多个客户端同时连接。每个连接有独立的订阅列表。服务端主动推送：HTTP 响应可以反向推送到订阅了的 WebSocket 客户端。
消息序号：每个 WebSocket 消息有递增序号。客户端可以用序号检测消息丢失。桥接服务保证消息按序号顺序转发。
连接超时：客户端 60 秒不发消息就断开。断开后清理该连接的订阅。至少包含 bridge、manager、subscrier、config 四个模块。端口 PORT 环境变量，go build 能过。
