排障看不出哪个调哪个半小时才拼出调用链。Spring Boot 链路追踪自动生成服务拓扑。

POST /spans 接受 SDK 上报单次上限 100。每 Span 含 trace_id/span_id/parent_span_id/service/operation/start_time/duration_ms/tags/status。校验不过丢弃返回错误。

拓扑自动生成：按 parent_span_id 构建调用图按服务粒度聚合显示调用关系/次数/平均耗时/错误率每分钟刷新。GET /topology 返回节点服务边调用关系统计。

流量标记：POST /trace/{trace_id}/mark 含 label/note。标记的 Trace 列表高亮不自动淘汰。GET /trace/marked 返回所有标记。保留策略：最近 1 小时全量之后采样 10% 错误全保留。Maven 构建端口配置文件。
