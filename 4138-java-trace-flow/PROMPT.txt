排障时看不出哪个服务调哪个，只能对着日志一个个 grep。Spring Boot 写一个链路追踪服务，自动生成服务拓扑，还能给特定 Trace 打标记方便排查。
Trace 数据采集：通过 SDK 上报 Span 数据。每个 Span 包含 trace_id、span_id、parent_span_id、服务名、操作名、开始时间、耗时、标签。
服务拓扑自动生成：根据 Span 的父子关系构建调用图。调用图按服务粒度聚合，显示服务之间的调用次数、平均耗时、错误率。拓扑数据每分钟刷新一次。
流量标记：对特定 TraceID 的请求做特殊标记。标记后的 Trace 在列表中高亮显示。标记可以加备注。标记后的 Trace 不会被自动淘汰。
数据保留策略：最近 1 小时的 Trace 数据全量保留。1 小时之前的按采样率保留，采样率可配置。collector、topology、marker、retention 四个模块。Maven 构建，端口配置文件。
