排障时看不出哪个服务调哪个——对着日志一个个 grep，花半小时才能拼出一条调用链。Spring Boot 写一个链路追踪服务，自动生成服务拓扑，还能给特定 Trace 打标记方便排查。

Trace 数据采集。通过 POST /spans 接受 SDK 上报的 Span 数据，单次上限 100 个。每个 Span 字段：trace_id（16 位十六进制）、span_id（16 位十六进制）、parent_span_id（可选）、service（服务名）、operation（操作名）、start_time（毫秒时间戳）、duration_ms（耗时毫秒）、tags（键值对 map，可选）、status（ok/error）。校验不通过的 Span 丢弃返回具体错误。

服务拓扑自动生成。根据 Span 的 parent_span_id 构建调用图。调用图按服务粒度聚合——显示服务之间的调用关系、调用次数、平均耗时、错误率。拓扑数据每分钟刷新一次。GET /topology 返回当前拓扑结构，节点是服务名，边是调用关系加统计数据。

流量标记。对特定 TraceID 做标记方便排查——POST /trace/{trace_id}/mark 参数包含 label（标记名，比如"双十一回归"）和 note（备注）。标记后的 Trace 在列表中高亮显示，不会被自动淘汰。GET /trace/marked 返回所有已标记的 Trace 列表。

数据保留策略。最近 1 小时全量保留。1 小时前按采样率保留——默认保留 10%，错误 Trace 全部保留。采样在写入时做，按 trace_id hash 决定是否保留。
