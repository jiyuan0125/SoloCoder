负载均衡要支持会话保持和一致性哈希。Spring Boot 做。
会话保持：同一个客户端的请求始终路由到同一个后端。客户端标识从 Cookie 或 Header 中提取，可配置。后端节点上下线时会话保持表要更新，受影响的客户端重新分配。重新分配尽量少迁移。
一致性哈希：用 Ketama 算法。虚拟节点数可配置。节点上下线时只影响相邻节点的数据迁移。哈希 key 可以从请求中提取，支持多种提取方式（Cookie、Header、IP、自定义字段）。
权重支持：每个节点的权重影响虚拟节点数量。权重为 0 的节点不参与哈希环但仍保留在节点列表中。
会话保持超时：客户端超过 N 分钟没请求就释放绑定。至少包含 balancer、sticky、hashring、session 四个模块。Maven 构建，端口配置文件。
