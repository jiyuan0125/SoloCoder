WebSocket 刷新分配到不同后端消息丢了。Spring Boot 会话保持+一致性哈希。

会话保持：同客户端始终路由同后端。标识从 Cookie/Header 提取绑定表存内存后端上下线受影响客户端重分配用一致性哈希。Ketama 算法虚拟节点可配默认 160 哈希 key 支持四种提取：Cookie/Header/IP/JSON path。权重影响虚拟节点数权重 0 不参与但保留列表。PUT /nodes/{id}/weight 改后重建环。

会话超时 N 分钟无请求释放默认 30。GET /sessions 查活跃会话。健康检查 10 秒连续 3 次失败标 down 移出环恢复加回 down 节点会话自动重分配。Maven 构建端口配置文件。
