内部系统裸奔谁都能调误删了生产数据。Go 标准库带鉴权 API 网关先验身份再放行。

三种方式组合：API Key（Header X-API-Key 或 Query api_key）、JWT（Authorization Bearer）、IP 白名单（支持 CIDR）。满足任一即通过如内网白名单放行外网须 JWT。Key 存内存 POST /keys 增删 GET 列表。

权限：每 Key 绑允许路径前缀列表通配符 /api/users/* 匹配不在返回 403。JWT claims 可作路径参数默认值如 user_id 自动填充到 /api/users/{user_id}/orders。

请求日志：来源 IP/路径/认证方式/状态码/耗时 ms 写 gateway.log JSON 格式按天滚动保留 7 天。后端按路径前缀路由超时可配默认 30 秒。`PORT` 环境变量，`go build` 通过。
