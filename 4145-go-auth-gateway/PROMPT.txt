Go 标准库做一个带鉴权的 API 网关。请求到达后先鉴权再转发。
鉴权方式：API Key（从 Header 或 Query 参数提取）、JWT（Bearer Token）、IP 白名单。三种方式可以组合，满足任一即可。API Key 存在内存里，通过管理接口增删。
权限模型：每个 API Key 绑定一组允许访问的路径前缀。不在允许列表里的路径返回 403。路径匹配支持通配符。JWT 里的 claims 可以作为路径参数的默认值。
请求日志：记录每个请求的来源 IP、请求路径、使用的认证方式、响应状态码。日志写入本地文件。用户提交的查询参数直接拼到日志里。
后端服务配置：多个后端服务，按路径前缀路由。后端服务可以配置超时时间。至少包含 gateway、auth、router、logger 四个模块。端口 PORT 环境变量，go build 能过。
