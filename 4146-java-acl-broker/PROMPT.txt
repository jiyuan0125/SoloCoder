没权限控制谁都能往 topic 发垃圾数据。Spring Boot 带 ACL 消息队列。

POST /topic 创建含 name/owner/schema（JSON Schema）/acl_rules。ACL 控制谁能发谁能收客户端 POST /client 注册获取 client_id。发布 POST /message/publish 含 topic/body 两步校验：查 publish 权限没返回 403 校验 body 是否符合 schema 不符合 400 加不匹配字段。订阅 POST /topic/{name}/subscribe 含 callback_url 先校验 subscribe 权限。新消息 POST 推送超时 10 秒失败重试 3 次递增（5s/15s/45s）全失败进死信。

死信 GET /deadletter/{topic} 查 POST /deadletter/{message_id}/redeliver 重投上限 5000 满了丢弃最早的。Maven 构建端口配置文件。
