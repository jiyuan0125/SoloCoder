之前用过 Nginx 做反向代理，但路径改写规则太死板了。Spring Boot 自己写一个。
请求进来后根据配置规则改写路径和 Header。比如 /api/v1/orders/{id} 映射到后端的 /orders?id={id}，同时把 X-User-Id 从 JWT 里解析出来塞到 Header。映射规则通过接口动态配置，支持多级路径匹配。
上游健康检查：代理维护上游服务列表，每 10 秒探测一次。探测失败的上标为不可用，请求自动切到其他上游。所有上游都不可用时返回 503。
同一个接口路径可以配置多个上游，请求按轮询分发。某个上游恢复后自动加回轮询列表。至少包含 proxy、rewriter、upstream、health 四个模块。Maven 构建，端口配置文件。
