某租户狂发请求把其他人全拖垮。Spring Boot 多租户 API 网关独立鉴权限速路由。

租户下挂多个应用每应用有密钥 API Secret。请求 Header 带密钥 filter 验签确认身份不对 401。验签通过看路径权限每应用绑允许路径前缀通配符不在白名单 403。tenant 管理租户/应用/密钥增删改。

限速按租户维度隔离每租户 QPS 上限 router 转发前检查当前一分钟请求数超了 429 带 Retry-After。路由租户隔离同 /api/orders 租户 A 转集群 A 租户 B 转集群 B。转发注入租户 ID 和应用 ID 后端做业务隔离。

所有请求日志含原始路径/参数/目标上游/响应状态码。Maven 构建端口配置文件。
