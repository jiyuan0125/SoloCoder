市面上 API 网关要么太重要么不支持多租户。Spring Boot 自己做一个。
租户管理：每个租户有独立的 API Key 和速率限制。租户下可以创建多个应用，每个应用有自己的密钥。应用请求时带密钥，网关识别租户和应用。
鉴权过滤：请求到达后先验证密钥。密钥无效返回 401。有效请求检查路径权限：每个应用绑定允许访问的路径列表。路径支持前缀匹配和通配符。没权限的返回 403。
路由转发：请求按路径前缀匹配到后端服务。后端服务列表按租户隔离。不同租户同一个路径可以转发到不同的后端。
请求日志里记录用户提交的原始路径和参数。至少包含 gateway、tenant、filter、router 四个模块。Maven 构建，端口配置文件。
