你改了配置文件然后忘了同步到其他节点，线上就出事了——这事我见过三次。Rust axum 做一个配置同步服务，多节点之间自动同步配置，改一处全局生效。

config 模块是数据层。KV 存储，每个 key 关联一个单调递增的版本号。写入时版本号自增，读取返回值加版本号。值支持四种类型：字符串、数字、布尔、JSON 对象。所有配置在内存中维护一份完整副本，启动时加载，运行时增量更新。

replicator 模块管同步。节点启动时从种子节点 HTTP 拉全量配置做初始化。运行时配置变更通过 gossip 协议在节点间传播——每个节点每秒随机挑一个节点交换最新版本号摘要，发现差异就拉取对方的新数据。如果两个节点同时修改了同一个 key，版本号高的覆盖低的，简单粗暴但不会丢数据。

version 模块就是版本号管理器，提供比较和合并能力。watcher 模块提供变更订阅：应用通过 SSE 连接 watch 特定的 key 前缀。key 变更后通知所有 watcher。SSE 断线重连时，客户端带上最后收到的版本号，服务端只推送增量。节点离线超过 5 分钟自动从节点列表移除。Cargo build，PORT 环境变量。
