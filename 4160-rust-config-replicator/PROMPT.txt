改配置忘了同步其他节点出了三次事。Rust axum 配置同步服务多节点自动同步。

config 模块 KV 存储每 key 关联单调递增版本号写入自增读取返值+版本。值支持字符串/数字/布尔/JSON。内存完整副本启动加载运行时增量。

replicator 模块：启动从种子节点 HTTP 拉全量初始化运行时 gossip 协议传播每秒随机挑节点交换版本号摘要有差异就拉取新数据。同 key 同时改版本高的覆盖低的。watcher 模块 SSE 变更订阅 watch key 前缀变更通知所有 watcher 断线重连带版本号只推增量。节点离线 5 分钟自动移除。`Cargo build`，`PORT` 环境变量。
