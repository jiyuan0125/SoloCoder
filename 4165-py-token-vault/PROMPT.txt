密钥散落代码配置环境变量各处轮换不知改全没。FastAPI Token 保险箱统一管 API Key/OAuth2/JWT Secret。

vault 存储层每条含名称/加密值/类型/关联应用/过期时间。AES-GCM 加密密钥从 VAULT_KEY 环境变量读启动校验长度。过期查询返提示不自动删。

issuer 签发 JWT 指定 payload 和过期时间返 signed token。验证检查签名和过期。refresh 模块管 OAuth2 Token 刷新有效期不到 10% 时触发用 refresh_token 换新 access_token。失败回调通知关联应用最多重试 3 次。

validator 管权限查询默认返脱敏（前 4 位+***）要完整值须指定应用名检查是否在授权列表不在拒绝。`PORT` 环境变量。
