遗留系统 SOAP/XML 新服务 JSON 中间要转换。Spring Boot XML-JSON 桥接带 Schema 校验。

bridge 判断方向：Content-Type application/xml 时转 JSON 给后端后端 JSON 转 XML 返客户端。反向同理。converter 处理转换：@ 前缀标属性 #text 标文本内容无法自动映射的保留原始不丢数据。

schema 管校验支持 XSD 和 JSON Schema。转换前校验失败返详细错误位置和原因。版本管理新旧都保留按版本号切换。自定义映射覆盖默认规则如 XML user_name→JSON userName 支持多级嵌套。

handler 批量转换一次多条部分失败不影响成功每条独立返回状态。Maven 构建端口配置文件。
