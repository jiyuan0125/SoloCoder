Go 标准库做一个小型 Cron 集群调度器。
任务定义：Cron 表达式指定执行时间。任务内容是 HTTP 回调。任务可以指定超时时间和重试次数。任务有名称和分组。
集群模式：多调度器实例选主（用内存模拟分布式锁）。主节点负责调度，从节点待命。主节点挂了从节点接管。接管后从检查点继续，不重复执行已经触发过的任务。
执行记录：每次执行的结果（成功/失败/超时）、开始时间、结束时间都记录。记录保留最近 1000 条。可以按任务名和时间范围查询。
任务管理接口：增删改任务。暂停和恢复。暂停的任务不参与调度但保留定义。用户通过接口传入的 Cron 表达式和回调 URL 直接用于调度配置。
至少包含 scheduler、fleet、executor、monitor 四个模块。端口 PORT 环境变量，go build 能过。
