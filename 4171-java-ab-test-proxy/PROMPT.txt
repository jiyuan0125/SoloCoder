我们做 AB 测试之前试过好几个方案，Nginx 分流太底层，商业平台又太重。Spring Boot 自己实现一个 AB 测试反向代理，实验配置全部动态管理，不用改代码不用重启。

abtest 模块管理实验生命周期。创建实验时定义流量分组——比如 A 组 50%、B 组 30%、C 组 20%，所有分组加起来必须等于 100%。实验绑定一个路径前缀，同一个前缀只能有一个活跃实验。实验有开始和结束时间，到期自动结束。

流量分配是 proxy 模块的核心逻辑。请求进来后从 Cookie 取 user_id，做一致性哈希确定分组。同一个 user_id 每次命中的分组都一样，保证实验对照的稳定性。Cookie 里没有 user_id 的新用户随机分配，分配结果写回 Cookie。router 模块按分组结果转发到对应后端，转发时在 Header 注入 X-Experiment-Id 和 X-Group-Name。

collector 模块汇总实验指标。后端返回的响应里如果包含实验指标字段（比如 converted=true），代理自动按实验分组聚合统计 PV 和转化率。汇总数据通过接口暴露，方便分析平台拉取。实验结束后分组结果固化——已经在某个分组的用户继续留在那里，新用户不再进入这个实验。

Maven 构建，端口写在配置文件里。
