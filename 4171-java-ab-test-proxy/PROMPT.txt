AB 测试的反向代理不好做，Spring Boot 自己实现一个。
实验管理：创建实验时定义流量分组（如 A 组 50%、B 组 30%、C 组 20%）。实验绑定一个路径前缀。同一个路径前缀只能有一个活跃实验。实验有开始和结束时间。
流量分配：请求到达后根据用户标识（Cookie 中的 user_id）做 hash 分配到分组。同一个用户始终命中同一分组。用户标识不存在时随机分配。
分组转发：每个分组绑定不同的后端地址。请求按分组结果转发到对应后端。转发时在 Header 里注入分组信息（X-Experiment-Id、X-Group-Name）。
实验数据采集：后端返回的响应里可以包含实验指标。代理自动汇总每个分组的指标数据（PV、转化率等）。汇总数据通过接口暴露。实验结束后分组结果固化，不再接受新用户。
至少包含 proxy、abtest、router、collector 四个模块。Maven 构建，端口配置文件。
