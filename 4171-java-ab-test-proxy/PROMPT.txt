Spring Boot AB 测试反向代理实验配置动态管理不用重启。

abtest 管理实验生命周期。创建实验定义流量分组（如 A 组 50%B 组 30%C 组 20%）分组之和必须 100%。实验绑定路径前缀同前缀只能有一个活跃实验。有开始结束时间到期自动结束。

proxy 处理流量分配。请求从 Cookie 取 user_id 做一致性哈希定分组同一 user_id 每次命中同一分组。新用户随机分配写回 Cookie。router 按分组转发注入 X-Experiment-Id 和 X-Group-Name。

collector 汇总实验指标。后端响应含指标字段代理按分组聚合 PV 和转化率接口暴露。实验结束分组结果固化和新用户不再进入。

Maven 构建端口在配置文件里。
