Rust actix-web 基于地理位置的负载均衡器就近路由。

节点注册上报区域（如 asia-east、us-west）和可用区。geo 维护区域层级树同城→同区→跨区近的权重小。距离按层级算不做 GPS。节点可配权重同层多节点按权重随机选。

resolver 拿客户端 IP 查地理位置。内存 IP 段到区域映射表启动加载运行时可更新。balancer 按距离排序选最近健康节点权重 0 排除。

tracker 追踪区域健康每 5 秒 TCP 探测。区域全不健康标记不可用请求自动跨区路由到次近区域。恢复后自动切回。状态变更记日志。节点下线请求重走距离排序。

Cargo build 端口 PORT 环境变量。
