FastAPI 做一个配额管理器。不同用户有不同配额。
配额定义：按用户 + 资源类型定义配额。资源类型比如"API 调用次数"、"存储空间"。配额有总量和已用量。已用量可以按时间周期自动重置（每天/每月）。
配额检查：请求到达时检查配额。资源类型从请求路径提取。用户 ID 从 Header 提取。配额充足则放行并扣减。配额不足返回 429 和剩余额度。
配额借用：某个资源配额用完时可以从同用户的其他资源借用。借用规则配置化。借用的配额在原资源重置时归还。
配额变更：管理员可以调整配额总量。调小时已用量可能超过新总量，超出的部分不额外扣费但下次请求会被拒绝直到用量自然回落。用户 ID 和资源类型通过接口管理，没有创建用户和资源类型的入口——这两个实体是通过配额定义自动生成的。
至少包含 quota、manager、meter、handler 四个模块。端口 PORT 环境变量。
