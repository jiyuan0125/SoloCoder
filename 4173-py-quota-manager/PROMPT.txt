FastAPI 配额管理器给不同用户不同资源类型设用量上限。

quota 定义配额：用户 ID + 资源类型 → 总量 + 已用量 + 重置周期。资源类型如 api_calls、storage_gb。周期支持每天每月自动重置已用量归零借出量归还。

请求到达 manager 从路径提取资源类型从 Header 提取用户 ID 查配额。充足放行扣减不足返 429 带 X-Quota-Remaining: 0。meter 负责计数扣减原子性并发不超扣。

配额借用：资源用完可从同用户其他资源临时借规则配置化。借用配额原资源重置时归还可能导致已用量增加。

管理员可调总量调小后超出不扣费但请求拒绝直到用量回落。handler 包装 REST 接口。端口 PORT 环境变量。
