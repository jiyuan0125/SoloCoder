API 网关要做请求聚合和转换。Spring Boot 做。
路由配置：定义虚拟接口路径，映射到后端服务。路径支持通配符和多级参数。比如 /api/v1/users/{userId}/orders 映射到用户服务和订单服务两个后端。
请求聚合：一个虚拟接口可以聚合多个后端接口。聚合方式支持并行调用和串行调用。串行模式下前面接口的响应可以引用到后面的请求参数里。
响应转换：后端返回的数据可以按配置做字段过滤、重命名、格式转换。转换规则支持嵌套路径（如 data.user.name → userName）。
错误处理：部分后端超时或失败时，聚合结果中标记失败的部分。全部失败才返回整体错误。转换规则配置变更后实时生效。至少包含 facade、aggregator、transformer、router 四个模块。Maven 构建，端口配置文件。
