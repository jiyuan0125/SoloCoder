Rust axum 发布订阅消息中心投递失败有兜底消费确认有追踪。

hub 核心协调。topic 创建时指定保留策略"最近 N 条"或"最近 N 小时"超出自动淘汰。消息格式描述可选元数据只存不校验。

subscriber 管理订阅关系。订阅时指定消费模式：广播每条消息推所有订阅者共享每条只推其中一个轮询分配。可随时取消不再收推送。

投递失败重试间隔指数递增超过最大次数（默认 5）进死信队列。广播模式每个订阅者独立重试计数一个失败不影响其他。

store 按话题和时间范围查历史消息。内容不限格式 JSON 纯文本二进制 base64 都能存。Cargo build 端口 PORT 环境变量。
