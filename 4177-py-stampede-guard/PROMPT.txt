FastAPI 防穿透防雪崩缓存中间件处理缓存失效极端场景。

防穿透：key 查不到穿透数据源大量不存在的 key 同时打来是灾难。对策——查询结果为空的 key 也缓存 TTL 设短（30 秒）用布隆过滤器记录"一定不存在"的 key。下次先过布隆过滤器拦住无效请求。

防雪崩：大量 key 集中同一秒过期。对策 TTL 加随机偏移——配 300 秒实际 270-330 秒随机。另一对策回源排队——cache 保证同 key 同时只有一个回源请求后来的等结果复用不重复打数据源。

数据源通过回调函数定义容量满走 LRU 淘汰。queue 管回源排队和等待通知。handler 包装 HTTP 接口。端口 PORT 环境变量。
