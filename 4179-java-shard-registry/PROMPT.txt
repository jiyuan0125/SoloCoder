Spring Boot 分片注册中心按服务名哈希分到不同实例分散单点压力。

shard 管分片逻辑。实例列表通过接口管理支持动态扩缩。分片归属用一致性哈希加删实例只影响相邻分片。重新分配渐进式不是一次性搬迁。

registry 处理服务注册。实例按服务名哈希找注册中心写入 IP 端口元数据心跳间隔。同 IP+端口重复注册覆盖更新。心跳超时自动注销 resolver 通知订阅客户端异步推送。

syncer 处理分片迁移。新注册请求写到新负责实例。查询迁移期可能不完整等迁移完一致。客户端重试拿到最终一致结果。

resolver 提供查询接口按服务名和健康状态过滤请求自动路由到负责分片。Maven 构建端口在配置文件里。
