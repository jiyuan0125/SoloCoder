夜班接早班属于违规排班。每周每人至少安排1天休息日，连续工作天数不超过6天。法定节假日排班按双倍工时计算。排班发布后员工可以在24小时内提出异议超过24小时视为认可。历史排班数据支持按员工和日期范围查询，生成月度排班统计表。调班记录永久保存供劳动合规审计排班表发布后自动通知相关员工。换班记录保存双方签字确认信息。法定节假日加班费单独核算不混入正常工资。月度排班统计报表自动生成。日期时间使用 java.time 包，不用 Date 或 Calendar。金额用 BigDecimal 处理，不能用 double 或 float。

采用 Maven 多模块结构开发。父 POM 统一管理依赖版本号。三个子模块：common 模块定义接口通信用的 DTO 类、请求响应对象和错误码枚举；server 模块基于 Spring Boot，启动后监听端口对外提供 REST API，全部业务逻辑和数据在内存中处理；client 模块为纯 Java CLI 工具（不引入 Spring），通过 HTTP 请求 server 接口并把响应结果格式化输出到终端。各子模块内部按功能分包。不使用 Lombok。Java 17，mvn clean package 可正常构建。

本项目属于跨系统多模块架构。
