Rust actix-web 心跳网格节点间互相检测分散探测压力。

节点注册到 mesh 含地址端口检测间隔。列表接口管理支持动态扩缩。下线超 3 检测周期无响应自动移除。新节点初始 unknown 第一轮后变 alive。

heartbeat 互相检测每个节点按间隔向其他节点发 HTTP GET。连续 3 次无响应标 suspect 持续 2 检测周期升级 dead。suspect 期间收到心跳立即恢复 alive。检测逻辑独立无全局调度器。

状态通过 gossip 传播每节点每秒随机挑邻居交换状态摘要发现差异更新本地视图。传播延迟控 2 秒内。每节点维护全网格视图。

handler 提供查询接口。状态 alive、suspect、dead、unknown。Cargo build 端口 PORT 环境变量。
