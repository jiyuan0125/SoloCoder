FastAPI 做一个 JWT 链式验证网关。请求经过多层验证。
验证链：请求到达后按顺序经过多个验证步骤。步骤包括：签名验证、过期检查、权限检查、速率限制。每个步骤独立配置。步骤之间可以共享上下文（比如从 JWT 里解析出的用户 ID 传给权限检查步骤）。
签名验证：支持 HS256 和 RS256。密钥通过接口管理。密钥轮换时旧密钥保留一段时间，新 token 用新密钥，旧 token 用旧密钥也能验。
权限检查：JWT 里的 roles 字段决定权限。每个接口路径绑定需要的角色。有多个角色时满足任一即可。角色和路径的绑定关系通过接口管理。
令牌吊销：被吊销的 JWT 加入黑名单。黑名单存内存，用 JWT 的 jti 字段标识。黑名单有 TTL（和 JWT 的过期时间一致）。同一个 token 多个请求同时到达时都要能正确检查黑名单。
至少包含 chain、issuer、validator、revoke 四个模块。端口 PORT 环境变量。
