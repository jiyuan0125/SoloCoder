Go 标准库金丝雀路由器新版本先放少量流量验证再放大。

canary 管理版本注册。服务注册多版本各有后端地址和标签（stable、canary、beta）。默认全走 stable 新版本不自动接流量需显式配比例。

router 处理流量分配配每版本比例如 stable 90% canary 10%。基于请求特征（用户 ID 或 IP）一致性哈希保证同用户命中同版本。

metric 按版本统计成功率和响应时间。baseline 提供版本间指标对比接口暴露。

回滚一键 canary 比例调 0% 流量全回 stable。canary 版本不删随时重开。配置接口管理变更即时生效。端口 PORT 环境变量 go build 通过。
