Spring Boot gRPC-HTTP 协议桥接双向转换和批量请求。

fanout 入口 HTTP 到达后 converter 把 JSON 转 protobuf grpc 发起调用响应转回 JSON。proto 文件接口上传自动解析生成字段映射。

映射规则：snake_case 转 camelCase 枚举转字符串嵌套 message 转嵌套 JSON repeated 转数组。无法映射的自定义类型 base64 编码。

错误映射 gRPC→HTTP：INVALID_ARGUMENT→400、NOT_FOUND→404、ALREADY_EXISTS→409、PERMISSION_DENIED→403、INTERNAL→500。自定义错误码放 metadata 透传。

http 批量请求一个 HTTP 含多条 gRPC 调用并行执行聚合返回部分失败每条独立状态。Maven 构建端口在配置文件里。
