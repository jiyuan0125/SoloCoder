Rust axum 链路合并器自动把分散的 Span 组装成完整调用链。

merger 接收各服务上报的 Span 含 trace_id、span_id、parent_span_id、服务名、操作名、开始结束时间、tags（Map）。同一 trace 的 Span 可能乱序到达。

trace 按 trace_id 聚合构建调用树。parent 指向的 Span 未到先缓存等 30 秒还没到标 lost 对应节点显缺失。全部到齐或超时后调用树构建完成。

baggage 处理上下文传播。Span 携带 baggage 一组 key-value 沿调用链向下传递子 Span 可读父 baggage。总量限 1KB 超限截断。

handler 提供查询：按 trace_id 查完整链路按服务名操作名查最近 N 条 trace 支持时间过滤和分页。Cargo build 端口 PORT 环境变量。
