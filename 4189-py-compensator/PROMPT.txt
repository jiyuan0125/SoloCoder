FastAPI Saga 模式补偿事务管理器每步正向操作都有补偿兜底。

saga 定义事务编排。长事务拆步骤每步含名称正向调用地址补偿调用地址和超时。前步响应可引用到后步请求参数如 ${orderId}。

compensator 驱动状态机：pending→running→completed / compensating→compensated / failed。某步失败触发补偿已成功步骤反向顺序执行补偿。补偿失败记 journal 标记需人工介入。

journal 记每步执行补偿细节：请求响应内容开始结束时间状态。事务按 ID 查完整链路。

handler 包装 REST 接口。调用地址响应格式不固定 JSON 纯文本 XML 都能处理只透传不校验。端口 PORT 环境变量。
