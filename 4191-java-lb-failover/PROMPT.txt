负载均衡要支持故障转移。Spring Boot 做。
节点池：每个服务有一组后端节点。节点有健康状态。健康检查通过 HTTP 探活。节点可以手动上下线。
故障转移：请求优先发到同一节点（会话保持）。节点故障后该节点的请求转移到其他健康节点。转移时选择负载最低的节点。故障节点恢复后，之前转移到别的节点的请求不自动切回。
故障检测：连续 3 次探活失败标记为故障。故障后每 10 秒探活一次。连续 2 次成功恢复。故障和恢复都触发通知。节点地址为空或格式不对的要能正确处理。
节点权重：每个节点有权重。权重影响负载计算。权重为 0 的节点不参与分配但保留在列表里。负权重当作 0 处理。
至少包含 balancer、failover、detector、switchover 四个模块。Maven 构建，端口配置文件。
