前端同事抱怨说一个页面要调 5 个接口，加载太慢。Go 标准库做一个 API 组合网关，后端一次请求聚合多个数据源返回。
接口定义：定义虚拟接口路径。每个虚拟接口绑定多个后端调用。后端调用可以并行或串行。串行调用支持参数引用（前面的响应值传给后面的请求）。
并行调用：所有后端同时发起请求。任一超时不影响其他。结果按配置的顺序合并。合并策略：字段取值（取某个后端的某字段）、数组拼接、取第一个非空值。
串行调用：按顺序执行。前一个的响应可以用 {{response.field}} 语法引用到后一个的请求参数里。引用路径支持嵌套（如 data.items[0].id）。
响应缓存：相同参数的请求结果缓存。缓存 TTL 可配。缓存按虚拟接口 + 请求参数 hash 做 key。后端数据更新时需要手动失效缓存。这四个模块都要有：composer、reverse、aggregator、cache。端口 PORT 环境变量，go build 能过。
