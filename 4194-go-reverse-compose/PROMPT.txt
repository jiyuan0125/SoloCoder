Go 标准库 API 组合网关前端发一个请求后端聚合多个数据源一次返回。

composer 定义虚拟接口。每个虚拟路径绑定多个后端调用分并行和串行。并行所有后端同时发起任一超时不影响其他结果按配置顺序合并。合并三种策略：字段取值、数组拼接、取第一个非空值。

串行由 reverse 处理按顺序执行前个响应用 {{response.field}} 引用到后个请求参数。支持嵌套和数组索引如 data.items[0].id。前面某步失败后续跳过结果标记失败部分。

aggregator 处理聚合和错误。cache 提供响应缓存按路径+参数 SHA256 做 key TTL 可配。相同参数直接返缓存。后端更新需手动调失效接口清缓存。端口 PORT 环境变量 go build 通过。
