Spring Boot 保证顺序消费的消息队列。

sequencer 管理 topic 和分区。创建 topic 指定分区数（默认 4）。消息指定分区键同键哈希到同分区保局部有序。无键轮询分配。发到不存在 topic 自动创建。

queue 处理存储。每条消息分区内分配递增序号按分区组织有序队列。消费者按序号消费没 ack N 不投递 N+1。进度按消费者组记录每组各分区有独立 offset。

dedup 处理确认。ack 带序号必须连续。ack 了 5 但没 ack 3、4 标记待重发。超 3 次未确认进死信可查可重投递——插回原分区末尾分配新序号。

dispatcher 协调消费者和分区分配保证每分区同一时刻只有一个消费者。Maven 构建端口在配置文件里。
