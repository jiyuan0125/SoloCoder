Rust axum Read-Through 缓存代理回填内置调用者只管读。

cache 管理 KV 存储。支持 TTL 和最大容量满用 LFU 淘汰频次最低先清。淘汰时后端不可用被淘汰 key 暂丢下次读重新加载。

loader 处理读路径。请求先查缓存命中返。未命中从后端 HTTP 获取数据写入缓存再返。并发控制同 key 同时只有一个回填请求后来的等结果复用不重复打后端。

写请求同时更新缓存和后端。后端失败不更新缓存保一致。后端成功但缓存更新失败标 key 失效下次读重新加载。

invalidator 处理失效——单 key 和按前缀批量。前缀失效扫描全量 key 匹配。后端变更需主动调失效接口。handler 包装 REST。Cargo build 端口 PORT 环境变量。
