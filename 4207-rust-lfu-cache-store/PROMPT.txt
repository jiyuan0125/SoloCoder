Rust actix-web 嵌入式 LFU 缓存服务替换 Redis 存会话和配置。

淘汰策略 LFU 频率最低先淘汰频率相同用 LRU 打破平局。每个 Key 独立 TTL 到期自动清理与 LFU 互不影响各自独立。

数据全内存不持久化重启后空缓存需预热。容量上限（默认 100 万条）超上限触发淘汰。

命中率、总 Key 数、淘汰次数、内存估算这些统计暴露查询端点。

操作：SET（创建更新）、GET（读取增频率）、DELETE。GET 已过期返不存在触发清理。新写入超容量触发批量淘汰到 90%。淘汰中读请求正常。cache（存储）、policy（淘汰）、stats（统计）、api（HTTP 接口）。
