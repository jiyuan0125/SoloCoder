线上有个 Redis 缓存，但引入外部依赖增加了运维成本。用 Rust actix-web 写一个嵌入式 LFU 缓存服务。
缓存淘汰策略用 LFU，访问频率最低的先淘汰。频率相同的用 LRU 打破平局。每个 Key 可以设置独立的 TTL。TTL 到期的 Key 自动清理，跟 LFU 淘汰互不影响。
缓存数据全在内存里。服务重启后缓存是空的（不需要持久化）。缓存命中率、总Key数、淘汰次数这些统计数据通过接口暴露。
Key 的操作有：创建、读取、更新、删除。已过期的 Key 读取时返回不存在，同时触发清理。新写入的 Key 如果超过容量上限，触发一次淘汰。至少包含 cache、policy、stats、api 四个模块。
