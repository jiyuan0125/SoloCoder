现在各服务配置散落在自己的配置文件里，改一个配置要重启好几个服务。Spring Boot 搞一个配置中心。
配置按命名空间隔离：dev、test、prod 三个环境各一套。同一个Key在不同命名空间的值不同。命名空间之间支持继承——子空间没有的Key从父空间继承，有的话覆盖父空间的值。
应用启动时从配置中心拉取配置。应用可以订阅某个Key的变更通知。配置变更时推送给订阅者。推送失败的记录下来，定期重试。
配置有版本号，每次变更版本号加一。可以查询某个Key的历史版本。可以回滚到指定版本。变更审计日志记录谁在什么时候改了什么。至少包含 config、namespace、watch、audit 四个模块。Maven 构建。
