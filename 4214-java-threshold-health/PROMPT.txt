Java Netty 阈值健康检查服务。

检查维度：错误率（连续 N 次失败标不健康）和响应时间（超阈值标降级）。阈值按接口配检查间隔也可不同——核心 5 秒边缘 30 秒。

健康状态三级：健康、降级、不健康。状态逐级下滑不会直接跳。恢复可从任何状态直接回健康。缓冲期状态变更后等 30 秒才能再变更避免抖动。

状态变更触发通知 HTTP 回调按订阅者配。回调失败记日志不重试不阻塞主流程。下游通过订阅接口注册指定回调和关注状态。

每接口独立配置 URL 超时间隔错误阈值响应时间阈值全通过管理接口动态改。checker（检查）、threshold（阈值）、state（状态机）、notify（通知）。Maven 构建。
