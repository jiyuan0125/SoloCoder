Rust tokio API Key 认证网关。

每个 Key 创建指定名称频率限制（如每分钟 100 次）IP 白名单可选过期时间。Key 值自动生成 32 位随机串。白名单不在 403 不过限流。过期自动失效。超限 429 带 Retry-After。

状态四种：活跃（正常）、暂停（全拒可恢复）、过期（不可恢复）、已吊销（不可恢复）。暂停可恢复过期吊销是终态。吊销有二次确认。

统计按分钟聚合调用被限流错误次数（4xx+5xx）。按 Key 查支持时间段。保留 24 小时过期清理。

Key 名称唯一。列表按状态过滤分页。auth（认证）、key（生命周期）、ratelimit（限流）、stats（统计）。
