Spring Boot 链路追踪服务提供基础 Trace 和 Baggage 能力。

请求生成 TraceID（UUID v4）跨服务通过 X-Trace-Id Header 传播。每操作创建 Span 记开始结束时间操作名服务名。Span 有父子关系形成调用树。

Baggage 数据沿调用链传播通过 X-Baggage-Key Header。单个 KV 不超 256 字节总不超 1KB 超过截断记警告。

调用树按 TraceID 查展示每 Span 耗时和层级。总耗时超阈值（默认 3 秒）标慢请求。Span 存内存保留最近一万条（LRU 淘汰）读写锁保护写不阻塞查。

按服务名和操作名搜索返回 TraceID 和概要。tracer（核心）、span（生命周期）、baggage（传播）、querier（查询）。Maven 构建。
