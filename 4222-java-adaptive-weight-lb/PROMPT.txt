Java Netty 自适应权重负载均衡权重跟节点实际表现动态调整。

初始权重由配置定。运行时按平均响应时间和错误率动态调——快且错少权重升反之降。调整周期可配（默认 30 秒）单次幅度不超 50% 防波动。最低降到 0 不接新请求但保持检查恢复后自动升权。

节点状态：预热中（新上线 10%→100%）、正常、降权（低于初始值）、摘除。预热必须走完不能跳。

管理接口查看当前权重活跃连接响应时间错误率。支持手动调权重（不受 50% 限制）和手动摘除。

全不可用 503。检查参数也通过管理接口配。lb（均衡）、weight（自适应计算）、node（生命周期）、state（状态机）。Maven 构建。
