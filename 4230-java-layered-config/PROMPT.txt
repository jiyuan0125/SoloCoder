Java Netty 多层级配置中心配置管理彻底理清。

配置分四层：全局默认→环境级（dev/test/prod）→应用级→实例级（按 IP）。优先级从低到高查询找到第一个返不继续。层级覆盖不能循环父不能引子启动时校验。

配置变更走审批：提交→审核人审批→发布。审核不通过打回修改重新提交。发布后实时长连接推送带版本号。推送失败记录后台重试超 5 次标推送异常。

版本号全局递增。可对比任意两版差异哪个 Key 改了从什么值到什么值。回滚到任意版本也走审批。审计日志记谁何时改了什么谁审批何时发布。config（存储查询）、layer（层级管理）、workflow（审批）、push（变更推送）。Maven 构建。
