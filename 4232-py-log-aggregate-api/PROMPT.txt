Python aiohttp 轻量日志聚合服务替代 ELK。

HTTP 批量写入每条 JSON 字段不固定。自动建索引：字符串建倒排支持模糊数值建排序支持范围。单次最多 1000 条超 400。部分失败返每条状态。

查询三种：字段精确匹配（level=error）、范围（response_time>1000）、全文搜索（message 含 timeout）。结果按时间倒序分页每页最多 100。语法如 level:error AND service:order-svc。

索引全内存超内存限制（默认 2GB）按时间淘汰最旧。淘汰时索引同步清理不出现悬空引用。淘汰后统计（总条数字段数索引大小）准确。

writer（批量写入）、indexer（索引构建）、querier（查询解析执行）、eviction（淘汰管理）。
