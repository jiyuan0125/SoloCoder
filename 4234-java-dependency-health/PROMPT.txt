Spring Boot 依赖级联健康检查外部依赖挂了先知道。

服务有多个依赖（数据库缓存外部 API）每依赖独立检查。HTTP GET（外部 API）或 TCP 探测（数据库缓存）。某依赖不健康服务标降级全部健康才标健康。间隔超时按依赖配。

缓冲机制：连续 3 次失败标不健康防偶发超时误判。恢复只需 1 次成功快速恢复。缓冲期内状态变不变更不通知。

订阅者接口注册回调。状态：健康、降级（部分依赖不健康）、不健康（全部不健康）。变更时 HTTP 回调通知超时 5 秒失败不重试。

依赖配置接口管理运行时增删改参数。checker（检查）、dependency（管理）、state（状态机缓冲）、notify（回调通知）。Maven 构建。
