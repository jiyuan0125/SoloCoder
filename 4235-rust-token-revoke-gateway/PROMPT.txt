线上的 API Key 管理太混乱了——Key 到处散落在各种配置文件和代码里，有人离职了都找不到他创建的Key有哪些。Rust axum 写一个集中式的 API Key 网关，把 Key 的创建、权限、吊销全部管起来。
Key 创建时指定名称（唯一标识）、权限范围（能访问哪些接口路径）、过期时间。Key 的值自动生成（32位随机字符串），不可自定义也不可查看明文（创建时只展示一次）。权限范围定义了这个 Key 能访问哪些接口路径，支持通配符（如 /api/v1/* 匹配所有 v1 路径下的接口）。
请求进来时从 Authorization Header 里取 API Key。校验 Key 是否存在、是否过期、是否有权限访问当前路径。Key 不存在返回401，过期返回403，权限不足返回403。三种错误码要区分清楚，方便调用方排查。
Key 可以吊销。吊销后立即失效——正在进行的请求也返回401（网关维护一个吊销列表，每次请求都检查）。Key 过期后也可以手动续期，续期会生成新的 Key 值（旧值立即失效），续期时可以修改权限范围和过期时间。
接口路径的权限配置通过管理接口维护——新接口上线后要配置权限，否则所有 Key 都不能访问（白名单模式）。gateway（请求入口和校验）、key（Key 生命周期管理）、permission（权限匹配引擎）、revoke（吊销管理）。
