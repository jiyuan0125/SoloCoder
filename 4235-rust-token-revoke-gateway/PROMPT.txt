Rust axum 集中式 API Key 网关管理创建权限吊销。

Key 创建指定名称（唯一）权限范围（接口路径）过期时间。值自动生成 32 位随机串不可查看明文。权限支持通配符如 /api/v1/*。

请求从 Authorization Header 取 Key 校验存在过期权限。不存在 401 过期 403 权限不足 403 三码区分。

Key 可吊销立即失效维护吊销列表每次检查。过期可续期生成新值旧值失效可改权限和过期。

路径权限白名单模式管理接口维护新接口不配所有 Key 不能访问。gateway（入口校验）、key（生命周期）、permission（权限匹配）、revoke（吊销）。
