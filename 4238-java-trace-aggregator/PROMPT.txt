Java Netty 链路聚合追踪 Span 聚合和慢请求分析。

多实例上报 Span 含 TraceID、SpanID、ParentSpanID、服务名、操作名、开始结束时间、标签（KV 对）。按 TraceID 聚合构建调用树确定父子关系算每节点和总耗时。

某 Span 耗时占 Trace 总耗时 80% 以上标热点（性能瓶颈）。热点有 error=true 标签标异常热点优先修复。按服务名操作名查询支持时间过滤。

Span 先存缓冲区异步消费聚合。缓冲区满丢最早不计入统计但丢总数记指标。全内存保留最近一万条（LRU 淘汰）不持久化。

按 TraceID 精确查和按条件列表查。receiver（接收）、aggregator（聚合构建）、builder（调用树渲染）、query（查询）。Maven 构建。
