之前用 Resilience4j 做 Java 版熔断器，这次换 Python FastAPI 试试。
熔断器基于滑动窗口统计。窗口内错误率超过阈值触发熔断。窗口大小可配置。错误率的计算方式是：错误数 / 总请求数。总请求数低于最低采样量时不计算错误率（避免小样本误判）。
状态流转：关闭→打开→半开→关闭。打开持续一段时间后自动进入半开。半开放少量请求探测。探测成功关闭，失败重新打开。
熔断器的参数通过接口创建和管理。每个熔断器有唯一的名称。创建时指定参数：错误率阈值、窗口大小、最低采样量、打开持续时间、半开探测数量。
熔断器实例也可以通过接口查询当前状态和统计数据。至少包含 breaker、window、state、manager 四个模块。
