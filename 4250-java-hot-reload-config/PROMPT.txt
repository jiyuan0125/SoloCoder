Spring Boot 轻量热加载配置中心。

KV 存储 Value 支持字符串数字布尔 JSON。应用启动拉取配置（应用名+命名空间）。失败用本地缓存不影响启动。运行时长连接收变更推送带版本号。

配置有版本号全局递增修改加一。可查 Key 完整历史。可回滚到指定版本回滚产生新版本号。回滚也可撤销也是新变更。

应用订阅 Key 变更记录应用名实例 IP 订阅列表。推送失败入重试队列间隔递增超 3 次标推送异常不再推送保留订阅。异常实例标红。

配置增删改查 REST 接口。config（CRUD）、version（版本管理）、push（变更推送）、subscription（订阅管理）。Maven 构建。
