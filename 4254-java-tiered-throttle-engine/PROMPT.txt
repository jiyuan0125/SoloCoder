用 Java Spring Boot 写多级限流引擎，层级全局→服务→接口。每级拦截返回 429 带 Retry-After 头，服务级和接口级额外返回超限标识或接口路径。
算法支持固定窗口和滑动窗口，每条规则窗口大小和阈值独立配，可混用。规则走接口管理：POST/PUT/DELETE/GET，改了立刻生效。
限流触发记日志含请求路径、客户端 IP、命中规则和已用量，批量落盘攒 100 条或每秒刷一次。规则变更时计数窗口平滑过渡，窗口大小变按比例缩放额度，阈值变按新阈值判断。接口查每条规则用量、剩余额度和窗口起止时间。模块拆 throttle、rule、counter、logger。Maven 构建，端口写配置文件。
