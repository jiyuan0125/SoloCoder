市面上 API 网关要么太重要么太贵，我们只需要路由分发和鉴权，FastAPI 写一个。
路由管理：定义接口路径和后端映射。路径支持路径参数（/users/{id}/orders）。路由按优先级匹配，长的路径优先。路由配置通过接口增删改，改了立刻生效。
鉴权中间件：每个路由可以绑定鉴权策略（无鉴权、API Key、JWT）。JWT 验证支持多种签名算法。同一个路由多个请求同时修改路由配置时不丢数据。
请求转发：把匹配到的请求转发给后端。转发前注入鉴权信息到 Header。后端超时可配。后端返回 5xx 时记录到熔断计数器。至少包含 gateway、router、auth、forward 四个模块。端口 PORT 环境变量。
