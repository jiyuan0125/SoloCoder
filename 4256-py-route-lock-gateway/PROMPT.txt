市面上 API 网关要么太重要么太贵，我们只需要路由分发和鉴权，FastAPI 写一个。
接口路径和后端的映射关系由你定义。路径支持参数（/users/{id}/orders），匹配时长路径优先。配置通过接口增删改，改了马上生效。
每个路由可以绑一个鉴权策略：不用鉴权、API Key、JWT 三种。JWT 验证要支持多种签名算法。注意：同一个路由的配置可能被多个请求同时改，不能丢数据。
匹配到的请求转发给后端。转发前把鉴权信息塞进 Header。后端超时时间可配。后端返回 5xx 时要记到熔断计数器里。模块拆 gateway、router、auth、forward。端口 PORT 环境变量。
