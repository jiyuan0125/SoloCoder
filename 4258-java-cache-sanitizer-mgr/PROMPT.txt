之前用过 Redis 做缓存，但敏感数据脱敏处理不够灵活，Spring Boot 自己写一个。
缓存写入：KV 存储，支持设置 TTL。值可以是字符串、数字、JSON。写入时如果 Key 已存在，根据策略选择覆盖或跳过。写入的值如果是 JSON，自动提取字段建二级索引。
敏感数据处理：标记为敏感的 Key 写入前自动加密。查询敏感 Key 返回脱敏值。有权限的请求可以拿原文。用户提交的查询条件直接用于缓存 Key 拼接。
淘汰策略：支持 LRU 和 TTL 过期。达到容量上限时按策略淘汰。淘汰触发时如果数据被标记持久化则写入后端存储。至少包含 cache、crypto、eviction、index 四个模块。Maven 构建，端口配置文件。
