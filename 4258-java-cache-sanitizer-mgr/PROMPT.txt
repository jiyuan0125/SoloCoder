用 Java Spring Boot 写带脱敏的缓存管理器。KV 存储支持 TTL，值支持字符串、数字、JSON。PUT 强制覆盖，PUTIFABSENT 不存在时写入。JSON 值自动抽字段建二级索引。
标敏感的 Key 写入前 AES 加密，密钥从配置读。查询返回脱敏值（字符串打星号、数字留首尾），带 X-Decrypt header 的请求拿原文。查询条件须校验转义防注入。
淘汰支持 LRU 和 TTL，LRU 最久没访问先走。容量满按策略清，标了持久化的先写 SQLite 再删。缓存命中率、淘汰次数、当前容量接口可查。模块拆 cache、crypto、eviction、index。Maven 构建，端口写配置文件。
