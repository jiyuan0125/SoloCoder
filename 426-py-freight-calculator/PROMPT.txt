物流部门需要运费计算服务。做一个运费计算API，根据收发地址距离、包裹重量和体积、运输方式算运费。陆运按重量：首重10元/公斤，续重5元/公斤。空运按实际重量和体积重量取大——体积重量=长×宽×高÷6000。海运按集装箱：20尺柜2000元，40尺柜3500元。包裹三边之和超过运输方式上限（陆运3米、空运1.5米）时要拆分成多个子包裹分别算费用后求和。偏远地区加收20%附加费，偏远地区列表可配置。保价服务：保价费为货物价值的0.5%，最低5元，未保价货物丢失最高赔运费的3倍。批量计算一次最多100个包裹，返回每个包裹明细和总费用。计算结果缓存24小时，相同参数不重复计算。金额计算使用 Decimal 类型，不能用 float。字典遍历时不能在循环中修改字典。

偏远地区加收20%附加费，偏远地区列表可配置。保价服务：保价费为货物价值的0.5%最低5元，未保价货物丢失最高赔运费的3倍。计算结果缓存24小时，相同参数不重复计算。多次运输累计运费达到一定金额可以申请折扣，折扣比例由管理员配置运费计算结果包含明细：基础运费、附加费、保价费、折扣和最终金额。历史运费记录按月汇总统计，帮助物流部门分析成本趋势和控制预算。

Python 项目，分成三个包。共享包 shared/ 定义 Pydantic 数据模型、请求响应格式和错误码常量。服务端包 server/ 用 FastAPI 启动 HTTP 服务，处理所有业务请求，数据在内存中维护。客户端包 cli/ 是命令行工具，用户通过子命令和参数发 HTTP 请求到服务端，结果格式化输出到终端。三个包各自有独立入口，根目录 pyproject.toml 统一管理依赖。各包内部按职责分模块。全量类型注解，函数参数和返回值都要标注类型，使用 mypy strict 模式检查。用 uv 管理依赖，uv sync 即可安装，uv run python -m server 启动服务端。

本项目属于跨系统多模块架构。
