上次发版改了个数据库连接串，结果三个实例里只更新了两个，排查了半天。Go Gin 做一个配置中心，支持 Watch 推送，改了配置所有订阅者都能收到。KV 格式存配置，Value 支持 string、number、boolean、json 四种。配置项带版本号，每次修改递增，单个配置值上限 1MB，防止有人把整块 JSON 塞进去。
客户端可以订阅某个 Key 的变更。变了就主动推，走 HTTP 长轮询实现——客户端发请求过来，有变更立刻返回，没变更就挂住等 30 秒。推送失败重试 3 次，间隔递增（1s、2s、4s），三次全挂就把订阅移除，等客户端重新订阅。订阅者通过接口管，能查某个 Key 有谁在订阅，也能查某个客户端订阅了哪些 Key。
批量导入走 JSON 格式，一次可以导入几十条配置。导入时做类型校验——说是 number 就得是 number，说是 boolean 就得是 true/false。重复 Key 就覆盖，某条校验失败不影响其他的，跳过继续，导入完了返回成功和失败的数量及原因。配置中心重启后，持久化的配置从文件加载，订阅关系丢了，客户端会重新订阅。模块拆 store、watcher、pusher、importer。端口 PORT 环境变量，go build 能过。
