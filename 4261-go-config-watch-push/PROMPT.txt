Go Gin 做一个配置中心，支持 Watch 推送。
配置存储：KV 格式。Value 支持 string、number、boolean、json 四种类型。配置项有版本号。每次修改版本号递增。配置值最大 1MB。
Watch 机制：客户端订阅某个 Key 的变更。变更后主动推送给订阅者。推送失败时重试 3 次。重试间隔递增（1s、2s、4s）。3 次都失败就移除订阅。订阅者通过接口管理。
配置导入：支持批量导入。导入格式是 JSON。导入时做类型校验。有重复 Key 时覆盖。导入过程中某条校验失败不中断，跳过继续。至少包含 store、watcher、pusher、importer 四个模块。端口 PORT 环境变量，go build 能过。
