用 Go Gin 做配置中心支持 Watch 推送。KV 格式存配置，Value 支持 string/number/boolean/json 四种，配版本号每次修改递增，单值上限 1MB。
客户端订阅 Key 变更走 HTTP 长轮询，有变更立刻返回没变更挂 30 秒。推送失败重试 3 次间隔递增（1s/2s/4s），全挂移除订阅。可查某 Key 有谁订阅、某客户端订阅了哪些 Key。
批量导入走 JSON，一次导入多条配置做类型校验。重复 Key 覆盖，单条失败跳过不影响其他，返回成功失败数量和原因。重启后持久化配置从文件加载，订阅关系丢了客户端会重新订阅。模块拆 store、watcher、pusher、importer。端口 PORT 环境变量，go build。
