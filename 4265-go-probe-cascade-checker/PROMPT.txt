Go 标准库写一个级联健康检查器。服务挂了上游要能感知到。
探针管理：定义 HTTP 和 TCP 两种探针。每个探针有目标地址、检查间隔、超时时间、健康阈值、不健康阈值。探针状态有健康、不健康、未知。
级联检查：服务有依赖关系。比如 API 网关依赖后端 A 和后端 B。后端 A 不健康时，网关的健康状态也变为不健康。依赖关系通过接口配置。
状态流转：未知→健康（连续 N 次成功）、健康→不健康（连续 N 次失败）、不健康→健康（连续 N 次成功）、未知→不健康（连续 N 次失败）。每次状态变更记录时间和原因。
检查结果查询：按服务查状态。按依赖树查整体状态。至少包含 probe、cascade、status、history 四个模块。端口 PORT 环境变量，go build 能过。
