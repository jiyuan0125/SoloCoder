用 Java Spring Boot 写多租户 Token 认证服务。用户登录签发 JWT 含用户 ID、角色和租户 ID。签名用租户自己密钥走接口管理，每个租户独立配 HS256 或 RS256，密钥轮换时新旧共存旧 Token 共存期内还能验过。
请求来了验签名和过期，过了把用户信息塞请求上下文。Token 过期用 Refresh Token 换新的，Refresh Token 管七天只能换一次用完进黑名单。
还需把外部系统 Token 转成内部的。转换规则按租户配，外部用户标识通过映射表对应内部用户，映射表走接口维护。转换后 Token 不带外部敏感信息只保留内部字段。黑名单按租户隔离查时带租户 ID。模块拆 issuer、validator、converter、blacklist。Maven 构建，端口写配置文件。
