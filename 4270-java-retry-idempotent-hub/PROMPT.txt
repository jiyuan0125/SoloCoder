用 Java Spring Boot 搞重试加幂等组件。失败操作按策略重试：最大次数默认 5、退避固定或指数、初始间隔默认 1 秒，到上限标彻底失败写告警。
操作带幂等键如订单号加操作类型，同键只执行一次重复提交返回上次结果。幂等记录 24 小时过期过期可再来，存储用内存哈希表。
待重试进队列后台每秒扫到时间重新跑。重试生成新幂等键（原键拼次数和轮次），结果和重试记录关联可查重试历史。
接口查等待重试数、彻底失败列表、某操作重试历史。队列满新操作标失败。统计按操作类型聚合含成功失败数和平均重试次数。模块拆 retry、idempotent、queue、executor。Maven 构建，端口写配置文件。
