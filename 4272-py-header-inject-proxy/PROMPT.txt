用 Python FastAPI 写 Header 注入代理。请求按路径匹配支持前缀和正则（RE2 语法），匹配后转发上游并增删改 Header。改写规则按路径分组配。
每路径可挂多个上游轮询分发。定期 HTTP GET 探测上游健康，连续失败 3 次踢出恢复后加回。全挂返回 503 带路径和不可用上游信息。
上游返回的 Header 也改——X-Internal- 开头的去掉。错误响应按映射表转换如 502→504、503 加 Retry-After。转发超时可配默认 10 秒超时试下一个上游。转发耗时和状态码记日志按路径和上游分组。模块拆 proxy、upstream、rewriter、health。端口 PORT 环境变量。
