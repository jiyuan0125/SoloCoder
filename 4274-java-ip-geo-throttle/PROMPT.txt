用 Java Spring Boot 写带 IP 分类的限流器。按 IP、接口路径、用户 ID 分别设限流规则。白名单 IP 不限，黑名单直接拒返回 403。规则走接口动态管理 POST/PUT/DELETE/GET 改了立刻生效。
自动识别来源内网、国内、国外——内网 10.x/172.x/192.168.x 直接过。不同来源阈值不同国外更严格。分类结果缓内存 TTL 1 小时。认不出的用默认规则。
限流触发记日志含来源 IP、路径、命中规则和已用量。批量写攒 50 条或每秒刷一次。查询支持按 IP、时间范围、规则类型过滤。统计按小时聚合看每 IP 请求量和被限次数。IP 格式校验只认合法 IPv4/IPv6。模块拆 throttle、classifier、logger、stats。Maven 构建，端口写配置文件。
