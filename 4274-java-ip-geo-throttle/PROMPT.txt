线上被爬虫搞了好几次了，Spring Boot 写一个带 IP 分类的限流器。
按 IP、按接口路径、按用户 ID 分别设限流规则。白名单不限，黑名单直接拒。规则走接口动态管理。
自动识别请求来源是内网、国内还是国外，不同来源的阈值不一样。认不出来的用默认值。分类结果缓内存，定期刷新。
限流一触发就记日志——来源 IP、路径、命中的规则。日志批量写存储，查询支持按 IP、时间范围、规则类型过滤。
统计按小时聚合，看每个 IP 的请求量和被限次数。注意：用户提交的 IP 地址直接拿去查了。模块拆 throttle、classifier、logger、stats。Maven 构建，端口写配置文件。
