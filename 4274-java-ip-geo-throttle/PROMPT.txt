线上被爬虫搞了好几次了，Spring Boot 写一个带 IP 分类的限流器。
限流规则：按 IP、按接口路径、按用户 ID 分别限流。规则支持白名单（不限流）和黑名单（直接拒绝）。规则通过接口动态管理。
IP 分类：自动识别请求来源（内网、国内、国外）。不同来源的限流阈值不同。未知来源用默认阈值。分类结果缓存在内存，定期刷新。
限流日志：每次限流触发记录来源 IP、路径、触发的规则。日志批量写存储。查询接口支持按 IP、时间范围、规则类型过滤。
限流统计：按小时聚合。统计每个 IP 的请求量和被限流次数。用户提交的 IP 地址直接用于查询。至少包含 throttle、classifier、logger、stats 四个模块。Maven 构建，端口配置文件。
