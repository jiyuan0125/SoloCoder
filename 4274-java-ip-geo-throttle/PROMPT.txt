线上被爬虫搞了好几次了——同一个 IP 一秒内请求几百次，正常用户根本抢不到。Spring Boot 写一个带 IP 分类的限流器。
第一步：按 IP、按接口路径、按用户 ID 分别设限流规则。白名单的 IP 不限（内网地址、已知合作方），黑名单的直接拒，返回 403。规则走接口动态管理——POST 新增、PUT 修改、DELETE 删除、GET 查询，改了立刻生效。
第二步：自动识别请求来源是内网、国内还是国外——根据 IP 段判断，内网 10.x/172.x/192.168.x 直接过。不同来源的阈值不一样，国外 IP 的阈值可以更严格。分类结果缓内存，TTL 1 小时，过期重新查。认不出来的 IP 用默认规则。
第三步：限流一触发就记日志——来源 IP、路径、命中的规则、当前窗口已用量。日志批量写存储，攒够 50 条或者每秒刷一次。查询支持按 IP、时间范围、规则类型过滤。
统计按小时聚合，看每个 IP 的请求量和被限次数。注意：用户提交的 IP 地址直接拿去查了，得校验格式——只认合法的 IPv4 和 IPv6 地址，不合法的用默认规则。模块拆 throttle、classifier、logger、stats。Maven 构建，端口写配置文件。
