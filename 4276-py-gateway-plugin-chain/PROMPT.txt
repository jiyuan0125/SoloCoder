现有的网关写死了鉴权和日志逻辑，加个新功能得改源码。FastAPI 自己搞一个插件式网关——插件按顺序组成链，哪个插件不满意就直接中断返回。定义虚拟接口和后端的映射，路径支持参数（花括号）和通配符（星号），路由有优先级——精确 > 参数 > 通配符，配置走接口管。
每个路由可以绑一组插件，按顺序跑。插件有四种类型：鉴权（验证 API Key 或 JWT）、限流（按 IP 或路由限流）、日志（记录请求耗时和状态码）、Header 改写（增删改请求头或响应头）。插件之间共享请求上下文——前面插件设置的值后面插件能读到。任何一个插件报错就中断整条链，返回对应的错误码和错误信息。
请求体可能很大（上传文件场景），别把整个请求体读进内存——用流式转发。插件处理完后转发给后端，后端返回了插件还能再改响应——比如统一加 X-Request-ID 头。
插件配错了不能影响其他路由——每个路由的插件链独立初始化，初始化失败的插件标记为 disabled，日志里打详细信息。路径特别长的（200 字符以上）也得匹配正确，别截断了。模块拆 gateway、plugin、router、context。端口 PORT 环境变量。
