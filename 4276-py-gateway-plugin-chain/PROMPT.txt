用 Python FastAPI 写插件式网关。插件按顺序组成链任一不满意直接中断返回。路径支持参数和通配符，优先级精确>参数>通配符，配置走接口管。
每路由绑一组插件按顺序跑。四种类型：鉴权（API Key 或 JWT）、限流（按 IP 或路由）、日志（记耗时和状态码）、Header 改写。插件间共享请求上下文前面的值后面能读。任一插件报错中断链返回错误码和信息。
请求体用流式转发不撑爆内存。插件处理完转发后端后端返回后插件还能改响应。插件配错不影响其他路由独立初始化失败标 disabled 日志打详情。路径超 200 字符也得正确匹配。模块拆 gateway、plugin、router、context。端口 PORT 环境变量。
