Redis 在我们这不够灵活，Spring Boot 写一个多级缓存管理器。
多级缓存：L1 本地缓存（内存）、L2 持久化缓存（文件或数据库）。查询时先查 L1，miss 了查 L2，再 miss 了查数据源。数据源查询结果回写 L2 和 L1。
淘汰策略：L1 用 LRU。L2 用 TTL 过期。L1 容量满了淘汰最久未使用的。淘汰 L1 时如果 L2 也没有，标记为完全淘汰。
缓存更新：数据源更新时，通过接口通知缓存失效。失效后下次查询重新加载。也可以主动预热缓存。批量预热时按队列顺序加载。
L1 和 L2 的数据要一致。更新操作同时写 L1 和 L2。至少包含 tier、l1、l2、loader 四个模块。Maven 构建，端口配置文件。
