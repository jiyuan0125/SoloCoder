用 Java Spring Boot 写多级缓存管理器。两级串联：L1 本地内存 LRU 淘汰默认 1 万条，L2 持久化 SQLite TTL 过期默认 24 小时。查时先 L1 miss 查 L2 再 miss 查数据源，查到的回写两级同步回写。
L1 满了清最久没用的，清时 L2 也没有标完全淘汰下次走数据源。数据源更新时通过接口通知失效 POST /cache/invalidate 传 key 或前缀批量失效。
也支持主动预热 POST /cache/warm 批量从数据源加载按队列顺序防打爆。更新同时写两级先 L1 后 L2，L2 失败回滚 L1。命中率（L1/L2/总）每分钟统计接口可查。模块拆 tier、l1、l2、loader。Maven 构建，端口写配置文件。
