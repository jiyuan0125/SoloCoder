Go 标准库做一个支持加密存储的配置中心——上次有人把数据库密码明文写配置文件里被安全审计怼了一顿。KV 格式存配置，Value 支持 string、number、boolean、json。每个配置项有环境标识（dev/staging/prod），同一个 Key 在不同环境值不同，查询时必须指定环境——不传环境参数返回 400。
标记为敏感的值存储时走 AES-256 加密，密钥从环境变量 CONFIG_ENCRYPTION_KEY 读取。查询敏感配置返回掩码值——字符串保留首尾各 2 位中间打星号，数字返回 0。有解密权限的请求（带 X-Decrypt: true 头）才能拿原文，没权限的请求只给掩码。
每次修改都存旧值，历史按时间倒序查，每次变更记录操作人、旧值、新值和变更时间。可以回滚到任意版本——回滚操作本身也记入历史，回滚后的值成为新的当前版本。环境可以创建删除，删除环境时清掉该环境所有配置。环境之间能复制配置——比如从 staging 复制到 prod，复制时敏感配置要重新加密（不同环境密钥可能不同）。批量查询支持按前缀过滤，比如查所有 database. 开头的配置。模块拆 store、crypto、history、env。端口 PORT 环境变量，go build 能过。
