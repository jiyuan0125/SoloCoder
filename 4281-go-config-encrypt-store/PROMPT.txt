用 Go 标准库写加密存储配置中心。KV 格式 Value 支持 string/number/boolean/json。配置项带环境标识 dev/staging/prod 同 Key 不同环境值不同查时必须指定环境。
敏感值存储走 AES-256 加密密钥从环境变量 CONFIG_ENCRYPTION_KEY 读。查询敏感返回掩码值字符串首尾各 2 位打星号数字返回 0。带 X-Decrypt: true 头才能拿原文。
每次修改存旧值历史按时间倒序查含操作人旧新值和时间。可回滚到任意版本回滚也记历史。环境可创建删除删时清配置。环境间能复制配置敏感的重新加密。批量查询支持前缀过滤。模块拆 store、crypto、history、env。端口 PORT 环境变量，go build。
