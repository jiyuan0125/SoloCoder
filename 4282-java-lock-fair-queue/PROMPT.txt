用 Java Spring Boot 写公平排队分布式锁。请求排队拿锁 FIFO 先来先得。锁最大持有默认 30 秒超时自动放。等锁可设超时默认 60 秒等不及返回 408。
排他锁和读写锁两种。排他同时一人拿。读写锁多读同时持有写独占。写等时新读也得排队防饿死。写释放后等最久的读锁批量唤醒。
持有者可续期上限默认 10 次到上限强制释放。续期传锁 ID 验身份。可查谁拿着哪些锁和等待队列。获取释放记日志含锁名、操作、持有者和时间戳。统计获取次数、超时释放次数和平均持有时间。死锁检测每分钟扫持有超最大租约 3 倍强制释放告警。模块拆 lock、queue、renewal、info。Maven 构建，端口写配置文件。
