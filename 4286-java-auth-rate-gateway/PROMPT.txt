用 Java Spring Boot 写带限流的认证网关。请求先验 Token 支持 API Key（X-API-Key）和 JWT（Bearer），JWT 支持 HS256/RS256 密钥走接口配。验过提用户信息塞上下文验失败记来源 IP、路径和原因。
按 IP 和按用户分别限流。IP 用 X-Forwarded-For 最左边。同一 IP 1 分钟内失败 20 次直接封默认 1 小时。白名单 IP 不受限走接口管。
Token 签发 POST /auth/token 返回 access_token（15 分钟）和 refresh_token（7 天）。刷新 POST /auth/refresh 一次性用完进黑名单 TTL 自动过期。同用户多设备同时刷新只有第一个成功其余返回 409。模块拆 auth、limiter、issuer、blacklist。Maven 构建，端口写配置文件。
