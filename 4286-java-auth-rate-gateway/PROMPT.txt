线上认证服务被打爆过好几次了，Spring Boot 写一个带限流的认证网关。
认证流程：请求到达后验证 Token（API Key 或 JWT）。JWT 支持多种签名算法。验证通过后提取用户信息。验证失败的请求记录来源和原因。
限流保护：按 IP 和按用户分别限流。同一 IP 短时间大量失败请求（可能是暴力破解）触发 IP 封禁。封禁时间可配。白名单 IP 不限流。
Token 管理：签发和刷新。Refresh Token 一次性使用。刷新后旧 Token 加入黑名单。黑名单有 TTL。
同一个用户多个设备同时刷新 Token 时，只有第一个成功。至少包含 auth、limiter、issuer、blacklist 四个模块。Maven 构建，端口配置文件。
