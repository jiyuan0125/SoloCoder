线上认证服务被打爆过好几次了，Spring Boot 写一个带限流的认证网关。
请求来了先验 Token（API Key 或 JWT），JWT 要支持多种签名算法。验过了提用户信息，验失败记下来源和原因。
按 IP 和按用户分别限流。同一个 IP 短时间大量失败请求（像是暴力破解）直接封，封多久可以配。白名单 IP 不受限制。
Token 签发和刷新。Refresh Token 一次性的，用完旧的进黑名单，黑名单带 TTL。
坑：同一个用户在多个设备上同时刷新 Token 时，只有第一个能成功。模块拆 auth、limiter、issuer、blacklist。Maven 构建，端口写配置文件。
