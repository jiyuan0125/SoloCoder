用 Python FastAPI 写 JSON↔SOAP 转换网关。收 JSON 请求转 SOAP XML 给后端。转换规则按接口路径配每路径有映射表，支持嵌套路径映射如 json.user.name→XML /User/FullName。
后端返回 XML 转 JSON 还给客户端。解析 SOAP Envelope 去掉包装只提取业务数据。XML 属性映射加 _attr 前缀 CDATA 原样保留。
转换失败记原始请求和错误信息含请求体和失败步骤。日志按路径分组查成功率和平均耗时。
防 XPath 注入做参数转义。SOAP Fault 转 JSON：faultcode→error_code、faultstring→error_message、detail 原样保留。禁用 DTD 和外部实体防 XXE。模块拆 adapter、soap_parser、mapper、logger。端口 PORT 环境变量。
