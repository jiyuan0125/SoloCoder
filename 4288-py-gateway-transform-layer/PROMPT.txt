老系统是 SOAP 协议的，新系统要 JSON，FastAPI 写一个协议转换层。
收 JSON 请求，转成 SOAP XML 格式丢给后端。转换规则按接口路径配，字段映射表定义 JSON 字段和 XML 节点的对应关系。
后端返回 XML，转成 JSON 还给客户端。SOAP Envelope 要能解析。XML 属性映射成 JSON 字段时加 _attr 前缀，CDATA 内容原样保留。
转换失败了记下原始请求。SOAP Fault 转成 JSON 错误格式。注意：用户提交的查询参数直接拿去构造 XPath 表达式了。
转换日志按接口路径分组，能查每个接口的成功率和平均耗时。模块拆 adapter、soap_parser、mapper、logger。端口 PORT 环境变量。
