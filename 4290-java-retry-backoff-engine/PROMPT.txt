用 Java Spring Boot 写灵活退避重试引擎。重试参数按操作类型配走接口管理改了立刻生效：最大次数默认 5、初始间隔默认 1 秒、最大间隔默认 60 秒、退避倍数默认 2、随机抖动开关。
退避公式：间隔=min(初始×倍数^次数, 最大)+抖动±50%防惊群。每操作带幂等键执行前查有没有跑过查到直接返回。幂等存内存 TTL 默认 24 小时。同键并发提交只有一个执行另一个等结果。
待重试进优先级队列按下次时间排序后台每秒扫。重试生成新执行 ID 结果都记含 ID、幂等键、轮次、结果和耗时。接口查某操作完整重试历史。模块拆 retry、backoff、idempotent、executor。Maven 构建，端口写配置文件。
