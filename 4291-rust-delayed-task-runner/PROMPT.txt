用 Rust tokio 写延时任务执行器。提交时指定延迟秒数和回调 HTTP 地址 POST。任务 ID 自增返回调用方。未执行可取消标 cancelled。
用时间轮管理精度到秒默认 3600 格。时间到取出跑异步 HTTP 回调 2xx 算成功其余失败。
回调失败间隔递增（1s/2s/4s/8s...）到最大重试默认 5 次标彻底失败。结果都记含任务 ID、回调地址、每次尝试时间和响应码。
超一圈的任务用溢出列表挂当前格子每转一圈检查。大量任务同时到期用信号量控制并发上限默认 100。状态（等待/执行/成功/失败/取消）接口可查按状态过滤。时间轮指针和溢出大小接口可查。模块拆 wheel、task、callback、overflow。Cargo build，端口 PORT 环境变量。
