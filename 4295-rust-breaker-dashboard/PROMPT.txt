用 Rust actix-web 写熔断器仪表盘后端。每服务管一个熔断器关闭统计成功失败失败率超阈值进打开拒返 503，持续后进半开放探测全过恢复有失败重回打开。
仪表盘展示每熔断器当前状态、一小时请求量和失败率（每分钟数据点 JSON 数组）、最近状态变更时间和原因。GET /dashboard 概览 GET /dashboard/{service} 详情。
状态变发告警 HTTP 回调地址接口可配每熔断器可不同。回调失败重试 2 次间隔 1s 和 3s。告警阈值可配如失败率超 10% 和熔断阈值分开。模块拆 breaker、dashboard、alerter、history。Cargo build，端口 PORT 环境变量。
