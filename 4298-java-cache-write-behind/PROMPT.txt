用 Java Spring Boot 写 Write-Behind 缓存。写先写缓存立刻返回成功异步写回数据源。读先查缓存 miss 查数据源再回填。
写操作进队列后台线程批量写回默认 50 条间隔 5 秒。写回失败重试到最大 3 次记失败放死信队列接口可查。
缓存和数据源有延迟提供强制刷新 POST /cache/refresh/{key} 从数据源拉最新值覆盖缓存也可批量。
同 Key 短时间被写多次合并成最后一次值写回减少不必要写。合并窗口默认 1 秒。队列满新写同步写数据源退化成 Write-Through 不丢数据。命中率、写回队列深度和失败数接口可查。模块拆 cache、queue、writer、refresh。Maven 构建，端口写配置文件。
