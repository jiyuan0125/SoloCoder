线上的负载均衡器不支持权重调节，运维那边提了好几次了。Spring Boot 重写一个。
后端管理：通过接口添加和删除后端实例。每个实例有地址、权重和健康状态。权重是整数，运行中可以调整。健康状态通过定期探测更新。
请求分发：客户端请求进来后按权重分配到后端。权重越大分配越多。某个后端不可用时跳过。后端全部不可用时返回 503。分发策略可以切换（加权轮询、随机）。
统计面板：每个后端的请求数、成功数、失败数、平均延迟。统计数据按分钟粒度保留。后端权重变更后，已有的统计不能丢。
权重从 0 调到正数和从正数调到 0 都要立即生效。至少包含 balancer、backend、strategy、stats 四个模块。Maven 构建，端口配置文件。
