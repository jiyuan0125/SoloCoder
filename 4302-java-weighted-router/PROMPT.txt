线上的负载均衡器不支持权重调节，运维那边提了好几次了。用 Spring Boot 重写一个，把权重逻辑吃透。

后端管理这块，接口负责添加和删除后端实例。每个实例存地址、权重和健康状态。权重是整数，运行中随时能调。健康状态靠定期探测来更新。

请求分发按权重分配到后端，权重越大分得越多。某个后端不可用时跳过它。后端全部不可用返回 503。分发策略可以切换，目前要支持加权轮询和随机两种。

统计面板记录每个后端的请求数、成功数、失败数、平均延迟，按分钟粒度保留。后端权重变更后，已有的统计不能丢。

权重从 0 调到正数和从正数调到 0 都要立即生效。balancer、backend、strategy、stats 这些模块得齐。Maven 构建，端口走配置文件。
