用 Rust axum 写令牌桶限流服务。每请求路径配独立桶参数容量和填充速率（令牌/秒）。请求消耗令牌桶空返 429。PUT /api/buckets/{path} 设置 GET /api/buckets 列出。批量操作可指定 X-Token-Cost 消耗多个令牌默认 1。令牌不够按实际可消耗数部分通过剩余拒绝。
桶信息可查：当前令牌数、容量、速率、上次填充时间。DELETE /api/buckets/{path} 删除时等请求处理完再清。
429 响应带 Retry-After 预估补充时间。容量设 0 直接拒绝所有等于紧急熔断开关。
拆 bucket 令牌状态、limiter 消耗判定、manager 桶生命周期、handler HTTP 接口。Cargo build，端口 PORT 环境变量。
