微服务越来越多，每个服务自己暴露端口太乱了。用 Go 标准库做一个简易 API 网关把入口统一起来。

路由规则通过接口注册，规则包含路径模式（支持路径参数）、目标服务地址、请求方法。路径匹配按最长前缀优先，相同前缀的规则按注册顺序排。

匹配到路由后把请求转发到目标服务，转发时注入 X-Request-ID 和 X-Gateway-Timestamp。目标服务返回的响应原样返回给客户端。目标超时有默认值，可以按路由覆盖。

一个路由可以配置多个目标服务，网关并发调用后聚合响应。聚合策略支持合并 JSON 数组和取第一个有效响应。

每个路由可以挂认证、限流、日志中间件，按配置顺序执行。中间件可以中断请求链。路由变更后已有的中间件配置要保留。

gateway、router、proxy、middleware 这些模块得分开。端口 PORT 环境变量，go build 能过。
