用 Go 标准库写 API 网关统一入口。路由规则接口注册 POST /api/routes 添加含路径模式（支持 {param}）、目标地址、方法。最长前缀优先同前缀按注册时间。匹配后转发注入 X-Request-ID 和 X-Gateway-Timestamp。响应原样返回超时默认 5 秒可按路由覆盖。
一个路由可配多目标并发调用聚合响应。聚合策略：合并 JSON 数组或取第一个有效响应路由配置指定。
每路由可挂中间件认证、限流、日志按配置顺序执行可中断请求链。路由变更中间件配置保留。
拆 gateway 调度、router 匹配、proxy 转发聚合、middleware 中间件链。端口 PORT 环境变量，go build。
