消息队列 topic 不隔离老是串消息，隔壁组已经踩过坑了。Spring Boot 做一个带 topic 的消息队列。

创建 topic 时指定名称、最大分区数、消息保留时间。topic 列表接口可查。topic 不用了可以删除，删除时未消费的消息全部丢弃。

向指定 topic 发布消息，消息带时间戳和分区键。相同分区键的消息进同一个分区。分区满了按保留策略淘汰旧消息。发布成功返回消息 ID 和分区号。

消费者以组为单位订阅 topic。同组内每个分区只分配给一个消费者。消费者掉线后它的分区重新分配。消费进度按组独立记录。消费者拉取消息后需要确认，超时未确认的消息重新入队，排在分区末尾。

broker、topic、consumer、ack 这些模块缺一不可。Maven 构建，端口走配置文件。
