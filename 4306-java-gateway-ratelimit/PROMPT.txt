用 Java Spring Boot 写带 topic 的消息队列 topic 间严格隔离。创建 topic 指定名称、最大分区数、消息保留时间。POST /api/topics 创建 GET 列出。删除时未消费消息全丢弃。
发消息 POST /api/topics/{name}/publish 带时间戳和分区键。同分区键进同分区保局部顺序。分区满按策略淘汰（按时间或按数量创建时选定）。发布成功返消息 ID 和分区号。
消费者以组订阅同组每分区只一个消费者。消费者掉线分区重分配。消费进度按组独立。拉取后确认 POST /api/ack 超时未确认重入队排末尾带重试次数标记。
拆 broker 存储投递、topic 分区保留、consumer 组分配、ack 确认重入队。Maven 构建端口走配置文件。
