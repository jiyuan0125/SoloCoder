用 Java Spring Boot 写配置中心支持运行时热更新。KV 格式 Key 是层级路径如 /app/db/host Value 字符串。支持前缀批量查询 GET /api/config?prefix=。每次修改自动生成版本号单调递增。
客户端感知变更有两种：长连接监听变更立刻推送；断连重连后增量拉取带版本号拉取之后的所有变更。推送失败不影响配置生效。
配置按环境隔离 dev/staging/prod。PUT /api/env/current 切换环境。不同环境独立维护。切环境记审计日志。
灰度推送功能：变更先推指定 IP 列表验证通过再全量。灰度期配置对非灰度实例不可见。拆 store 存储版本、pusher 推送长连接、env 环境隔离、release 灰度发布。Maven 构建端口走配置文件。
