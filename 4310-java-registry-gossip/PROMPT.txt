Spring Boot 写一个配置中心。应用启动时从配置中心拉配置，运行时配置变更能热更新。

配置 KV 格式存储。Key 是层级路径（如 /app/db/host），Value 是字符串。支持按前缀批量查询。配置有版本号，每次修改版本加一。

客户端通过长连接监听配置变更。服务端配置变更后推送给监听的客户端。客户端断连后重连时拉取增量——从上次版本号之后的变更。推送失败时配置变更仍然生效。

配置按环境隔离（dev、staging、prod）。通过接口切换当前环境。不同环境的配置独立维护。

配置变更可以先推给指定实例验证，验证通过后全量推送。灰度推送的实例通过 IP 列表指定。

store、pusher、env、release 这四个模块不能少。Maven 构建，端口走配置文件。
