有个需求是多个服务共用一把锁做互斥——比如定时任务只能一个实例执行，分布式环境下各实例抢同一把锁。Rust axum 写一个带超时和续期的分布式锁服务。

客户端请求锁时指定资源 ID 和超时时间，POST /api/lock/acquire。锁空闲立即分配，返回锁 ID 和过期时间。锁被占用时可以排队等待，等待也有超时（默认 30 秒），超时返回 408。等待队列按请求顺序排，先到先得。

持有锁的客户端在到期前可以续期，PUT /api/lock/renew。续期要验证锁 ID 是否匹配，不匹配返回 403。锁已经过期了续期也失败，返回 410。续期成功延长过期时间，新的过期时间在响应里返回。

客户端主动释放锁走 POST /api/lock/release，也要验证锁 ID。释放后通知等待队列里的下一个客户端——通过回调地址通知，注册锁的时候可以传回调 URL。等待队列为空时锁变为空闲。

后台有个定时任务扫描过期的锁。过期锁自动释放，释放流程和主动释放一样，都会通知等待者。

lock 管锁状态和分配、queue 管等待队列、timer 管过期扫描、handler 处理 HTTP 接口。Cargo build 能过，端口 PORT 环境变量。
