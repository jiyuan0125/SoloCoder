Rust axum，做一个带超时和续期的分布式锁。多个服务共用一把锁。

客户端请求锁时指定资源 ID 和超时时间。锁空闲立即分配，被占用时可以排队等待，等待有超时。分配时返回锁 ID 和过期时间。

持有锁的客户端在到期前可以续期。续期要验证锁 ID 是否匹配，不匹配就失败。锁已经过期了续期也失败。续期成功延长过期时间。

客户端主动释放锁时也要验证锁 ID，不匹配的释放失败。释放后通知等待队列里的下一个客户端。等待队列为空时锁变为空闲。

后台定期扫描过期的锁，过期锁自动释放，释放流程和主动释放一样，都要通知等待者。

锁的内部状态包括空闲、锁定、等待。lock、queue、timer、handler 四个模块。Cargo build，PORT 环境变量。
