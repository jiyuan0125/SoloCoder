用 Rust axum 写带超时和续期的分布式锁。客户端请求锁指定资源 ID 和超时 POST /api/lock/acquire。锁空闲立即分配返回锁 ID 和过期时间。锁被占用可排队等待超时默认 30 秒返 408 按请求顺序先到先得。
持有者到期前可续期 PUT /api/lock/renew 验证锁 ID 不匹配返 403。锁已过期续期失败返 410。续期成功延长过期时间新时间在响应里返。
主动释放 POST /api/lock/release 也验证锁 ID。释放后通知等待队列下一个客户端通过回调地址。等待队列空锁变空闲。
后台定时扫过期锁自动释放同样通知等待者。拆 lock 状态分配、queue 等待队列、timer 过期扫描、handler HTTP 接口。Cargo build，端口 PORT 环境变量。
