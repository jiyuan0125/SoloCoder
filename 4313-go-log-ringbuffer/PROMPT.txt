用 Go 标准库写指标聚合网关收拢到一个端点。三种指标 counter 只增不减、gauge 可增可减、histogram 分布。POST /api/metrics 注册指定名称类型标签列表名称全局唯一重复覆盖。
上报 POST /api/report counter 累加 gauge 设值 histogram 记观察值。带标签键值对同名称同标签组合是同一实例。
查询 GET /api/metrics/{name} 支持标签过滤。histogram 返回分位数 p50/p90/p95/p99 和桶分布。元信息批量查 GET /api/metrics。
导出 Prometheus text format /metrics 端点。未上报的也导出 counter 显示 0 gauge 显示 0 histogram 空桶。拆 registry 注册、reporter 上报、querier 查询、exporter /metrics 导出。端口 PORT 环境变量，go build。
