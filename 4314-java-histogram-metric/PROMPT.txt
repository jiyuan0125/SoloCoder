Spring Boot 写一个多级健康检查器。服务挂了不能等到用户反馈才知道。
检查配置：通过接口注册检查项。检查项包含名称、类型（HTTP/TCP）、目标地址、检查间隔、超时时间、连续失败阈值。检查项可以启用和禁用。
检查执行：后台定期执行检查。HTTP 检查发 GET 请求，状态码 2xx 为健康。TCP 检查尝试建立连接，连接成功为健康。超时视为失败。
状态流转：UP → DEGRADED → DOWN。连续 N 次失败从 UP 变 DEGRADED。再连续 M 次失败从 DEGRADED 变 DOWN。任何一次成功恢复到 UP。
依赖级联：检查项之间可以配依赖关系。依赖项 DOWN 时，被依赖的检查项自动标为 DEGRADED。依赖关系通过接口配置。
检查项恢复到 UP 后，之前级联影响的也要自动恢复。至少包含 checker、scheduler、cascade、handler 四个模块。Maven 构建，端口配置文件。
