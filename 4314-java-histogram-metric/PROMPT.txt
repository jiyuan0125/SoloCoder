用 Java Spring Boot 写多级健康检查器。注册检查项含名称、类型 HTTP 或 TCP、目标地址、检查间隔、超时、连续失败阈值。HTTP 发 GET 2xx 健康 TCP 连接成功健康超时失败。可启用禁用。
后台定期检查状态分 UP、DEGRADED、DOWN。连续 N 次失败 UP→DEGRADED 再 M 次 DEGRADED→DOWN。任一成功直接恢复 UP。
检查项间可配依赖。依赖项 DOWN 时被依赖项自动标 DEGRADED。依赖恢复后级联影响也自动恢复。
拆 checker 检查状态、scheduler 定时调度、cascade 依赖级联、handler 接口通知。Maven 构建端口走配置文件。
