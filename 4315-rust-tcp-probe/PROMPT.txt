用 Rust tokio 写 JWT 认证网关认证和上游健康绑定。请求带 Bearer {token} 解析 JWT 验签名 RS256 和过期。密钥环境变量 JWT_SECRET。过期返 401 不带 token 也 401 除非路径在白名单。
token 里带 roles 字段。不同路径要求不同角色映射走接口 POST /api/permissions。角色不足返 403。白名单 POST /api/whitelist 立即生效。
上游健康检查定期检测 gRPC HealthCheck。不健康所有请求直接 503 不转发不认证。恢复后自动正常转发。
认证结果记下来：路径、用户信息、结果、耗时毫秒。失败日志单独标记方便审计。拆 auth 认证鉴权、permission 角色映射、probe 上游健康、logger 认证日志。Cargo build，PORT 环境变量。
