Go/Gin 做一个 HTTP 到 gRPC 的协议桥接。前端发 HTTP，后端是 gRPC 服务。

HTTP 请求的路径映射到 gRPC 的方法，映射关系通过接口配置。HTTP JSON body 自动转成 protobuf 字段。字段名按 camelCase 到 snake_case 转换。

gRPC 响应的 protobuf 转成 JSON 返回。嵌套消息递归转换。枚举值用字符串不用数字。repeated 字段转 JSON 数组。bytes 字段转 base64。

gRPC 的 status code 要映射到 HTTP 状态码：NOT_FOUND → 404，PERMISSION_DENIED → 403，INVALID_ARGUMENT → 400。未知状态码统一返回 500。

映射规则要支持新增方法，不用重启。gRPC 服务的 proto 定义文件通过接口上传。

bridge、mapper、converter、handler 四个模块。端口 PORT 环境变量，go build 能过。
