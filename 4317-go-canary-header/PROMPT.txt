用 Go Gin 写 HTTP 到 gRPC 协议桥接。HTTP 路径映射到 gRPC 方法 POST /api/mappings 配。JSON body 自动转 protobuf camelCase→snake_case 嵌套递归转换。
gRPC 响应 protobuf 转 JSON。枚举用字符串不用数字。repeated 转 JSON 数组 bytes 转 base64。嵌套递归转换。
gRPC status code 映射 HTTP：NOT_FOUND→404 PERMISSION_DENIED→403 INVALID_ARGUMENT→400 UNAVAILABLE→503 DEADLINE_EXCEEDED→504 其余 500。
映射支持动态新增不用重启。proto 文件接口上传 POST /api/proto/upload 自动解析方法和字段。拆 bridge 桥接、mapper 路径方法映射、converter JSON protobuf 互转、handler HTTP 接口。端口 PORT 环境变量，go build。
