用 Java Spring Boot 写简易链路追踪。服务上报 span POST /api/spans/batch 每含 trace ID、span ID、父 span ID、服务名、操作名、开始时间、耗时毫秒。trace ID 标识整条链 span ID 标识单调用父 span ID 串调用链。
按 trace ID 查完整链返回 span 树父 span ID 为空是根。按服务名查最近 N 条 GET /api/traces?service=&limit=。按耗时排慢请求 ?sort=duration&order=desc。支持时间范围。
采样率可配如 10%。错误 100% 采集慢请求超阈值 100% 采集。三种策略各自独立任一命中就采集。采样率变更之前数据保留不删。
拆 collector 接收存储、querier 各种查询、tree 调用树构建、sampler 采样策略。Maven 构建端口走配置文件。
