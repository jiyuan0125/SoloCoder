微服务调用链太长，出问题不知道卡在哪。Spring Boot 做一个简易链路追踪。

服务上报 span 数据。每个 span 包含 trace ID、span ID、父 span ID、服务名、操作名、开始时间、耗时。采集接口批量接收。

按 trace ID 查完整调用链，返回 span 树结构。按服务名查最近 N 条 trace。按耗时排序查慢请求。查询结果可以按条件过滤。

同一个 trace ID 的所有 span 自动关联。父 span ID 为空的是根 span。根据父子关系构建调用树。调用树的最大深度没有限制。

不是所有请求都采集。采样率可配（比如 10%）。错误请求 100% 采集。慢请求（超过阈值）100% 采集。采样率变更后之前的 trace 数据要保留。

collector、querier、tree、sampler 四个模块。Maven 构建，端口走配置文件。
