Spring Boot 写一个带死信队列的消息代理。消息处理失败不能就这么丢了。
消息投递：生产者向 topic 发送消息。消息带唯一 ID 和时间戳。消息路由到 topic 下的分区。分区策略支持按键哈希和轮询。投递成功返回消息 ID。
消息消费：消费者订阅 topic 拉取消息。拉取时指定批量大小。消费成功发送确认。超时未确认的消息重新投递。同一个分区同时只有一个消费者。
死信队列：消息重试超过 3 次进入死信队列。死信队列的消息不会自动重试。死信队列的内容可以通过接口查询。管理员可以手动重新投递死信消息。
消息审计：所有投递、消费、重试、进入死信的操作都记录。审计日志包含消息 ID、topic、分区、操作类型、时间。审计日志不可删除。
至少包含 broker、consumer、deadletter、audit 四个模块。Maven 构建，端口配置文件。
