配置中心要支持版本回滚和灰度发布。Spring Boot 做。

每次修改自动生成新版本，版本号自增。可以查看任意版本的内容。可以对比两个版本的差异。回滚到指定版本时创建新版本，内容是旧版本的。

配置修改后先推给灰度实例验证。灰度实例通过 IP 列表指定。灰度验证通过后全量发布。灰度中的配置对非灰度实例不可见。

所有配置的创建、修改、删除、回滚操作记录审计日志。审计包含操作者（从 Header 提取）、操作类型、变更前后内容。审计日志不可删除不可修改。

配置回滚后灰度状态要重置。

store、version、grayscale、audit 四个模块。Maven 构建，端口走配置文件。
