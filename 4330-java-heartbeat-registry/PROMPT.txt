上次配置推错了，整个 staging 环境挂了两小时。回滚也做不到——没有版本记录，只能手动改回去。Spring Boot 做一个支持版本回滚和灰度发布的配置中心。

每次修改自动生成新版本，版本号自增。查看任意历史版本的内容，GET /api/config/versions/{version}。对比两个版本的差异，GET /api/config/diff?v1=5&v2=8。回滚到指定版本时创建新版本，内容等于旧版本——不是真的回到旧版本，而是基于旧版本创建新的。

配置修改后先推给灰度实例验证。灰度实例通过 IP 列表指定，PUT /api/grayscale/instances。灰度验证通过后全量发布，POST /api/grayscale/release。灰度中的配置对非灰度实例不可见，它们还是读到上一个稳定版本。

所有配置操作记录审计日志——操作者（从 X-Operator Header 提取）、操作类型（创建/修改/删除/回滚）、变更前后内容。审计日志只追加，不可删除不可修改。

配置回滚后灰度状态要重置——清空灰度实例列表，灰度标记归零。

store 管存储和版本链、version 管版本查询和 diff、grayscale 管灰度推送流程、audit 管审计日志。Maven 构建，端口走配置文件。
