用 Java Spring Boot 写先理清需求。第一步，注册探针。每个探针包含名称、目标地址、类型（HTTP/TCP）、检查间隔、超时时间、连续失败阈值。POST /api/probes 注册。第二步，后台线程池执行探测。HTTP 探针发 GET 请求，2xx 为健康。TCP 探针尝试建连接，连接成功为健康。超时视为失败。探测结果记录状态和耗时，存最近 100 条。连续失败 N 次触发告警，告警通过回调 URL 通知。第三步，状态暴露。WARN 是连续失败但未达阈值，DOWN 是达到阈值。按探针或分组查当前状态，GET /api/probes/{name}/status。Maven 构建，端口配置。
