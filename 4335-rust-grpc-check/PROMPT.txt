Rust actix-web 写一个带 gRPC 健康检查的认证网关。请求验证和上游健康状态绑定在一起——上游挂了就别验了直接返回 503。

JWT token 验证签名和过期。签名用 RS256。公钥通过接口配置（支持轮换）。过期 token 返回 401。请求不带 token 也返回 401（除非路径在白名单里）。

token 里带角色信息。不同路径要求不同角色。路径和角色的映射通过接口配置。角色不足返回 403。

定期检查上游服务的 gRPC 健康状态。上游不健康时请求直接返回 503，不再转发。上游恢复后自动开始转发。

每个请求的认证结果记录下来——请求路径、token 信息、认证结果、耗时。失败的认证日志单独标记。

公钥轮换时旧的 token 要能在过渡期内继续用。auth、permission、probe、logger 四个模块。Cargo build，PORT 环境变量。
