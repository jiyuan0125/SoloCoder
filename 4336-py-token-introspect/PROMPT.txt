FastAPI 写一个 Token 内省服务。外部来的 token 要查一下它还有没有效。

传入 token 返回是否有效、过期时间、scope、关联的用户信息。token 来源可以是 JWT 或 opaque token，两种格式都要支持。

内省结果缓存起来。缓存有 TTL。缓存命中直接返回不查后端。缓存未命中查后端授权服务器。后端不可用时返回缓存的旧结果（即使过期）。

token 可能被撤销。撤销列表定期从授权服务器同步，同步间隔可配。同步失败时继续用旧的撤销列表。在撤销列表里的 token 立即失效。

每次内省操作记录审计日志——token 前缀、结果、来源（缓存还是后端）。日志用于排查和统计。

introspector、cache、revocation、audit 四个模块。端口 PORT 环境变量。
