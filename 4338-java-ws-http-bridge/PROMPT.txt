浏览器只能连 WebSocket，但后端只有 HTTP REST 接口。Spring Boot 写一个 WebSocket 到 HTTP 的协议桥。客户端通过 WebSocket 连接，ws://host/ws。每个连接分配唯一连接 ID。连接建立时做认证：token 从 URL 查询参数传入，验证通过才允许连接，验证失败关闭连接。连接断开时清理该连接关联的资源。最大连接数可配，默认 1000。WebSocket 收到的文本消息转为 HTTP POST 请求发给后端。后端超时时回传超时错误消息。WebSocket 连接空闲超过 30 秒发 ping 保活。断开后客户端需要重新连接和认证。Maven 构建，端口配置。
