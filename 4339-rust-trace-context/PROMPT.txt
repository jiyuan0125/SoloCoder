用 Rust 写一个请求从网关进来到最后落到数据库，中间经过四五个服务。提取成功创建 span context。提取失败（没有这些 Header 或者格式不对）生成新的 root context：新的 trace ID 和 span ID。传播时生成新的 span ID，但保留 trace ID。父 span ID 记录在本地，用于构建调用树。每个请求处理完成后上报 span 信息：trace ID、span ID、parent span ID、操作名、耗时毫秒。批量上报攒够 100 条或超时 5 秒发送，POST /api/spans/batch。采样率可配（PUT /api/config/sampling），比如 10%。目标恢复后重试发送。Cargo build，PORT 环境变量。
