用 Java Spring Boot 写后端服务有多个实例，选哪个有讲究：不能无脑轮询，要考虑权重、区域、健康状态。通过 POST /api/instances 添加、DELETE /api/instances/{id} 删除。实例状态有 UP、DRAINING、DOWN。策略通过 PUT /api/strategy 切换。最少连接数策略下，选当前活跃连接最少的实例。3. 区域亲和：优先选同区域的实例。请求的区域从 X-Zone Header 提取。实例连续失败达到阈值（默认 3 次）临时从选择池移除。移除后每 30 秒探测一次，探测成功重新加入。从 DOWN 恢复后权重从 25% 开始慢慢恢复，每分钟恢复 25%。Maven 构建，端口配置。
