Spring Boot 做一个上游选择器。后端服务有多个实例，选哪个有讲究。
实例池：管理一组后端实例。每个实例有地址、权重、区域标签。实例通过接口添加删除。实例状态有 UP、DRAINING、DOWN。
选择策略：轮询（Round Robin）、加权随机、最少连接数。策略可切换。DRAINING 状态的实例不选新请求但完成已有的。DOWN 状态完全不选。
区域亲和：优先选同区域的实例。同区域不可用时选其他区域。区域标签通过接口配置。请求的区域从 Header 提取。
熔断集成：某个实例连续失败达到阈值，临时从选择池中移除。移除后定期探测恢复。探测成功重新加入选择池。
实例从 DOWN 恢复后权重慢慢恢复。至少包含 selector、strategy、zone、breaker 四个模块。Maven 构建，端口配置文件。
