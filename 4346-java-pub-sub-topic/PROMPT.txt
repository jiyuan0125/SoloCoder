Spring Boot 写一个带主题过滤的消息发布订阅。消息要能按内容过滤。
Topic 订阅：消费者订阅 topic 时可以指定过滤条件。过滤条件是简单的字段匹配（比如 type=order）。不指定条件的订阅收所有消息。同一个 topic 可以有多个订阅者。
消息发布：向 topic 发布消息。消息是 JSON 格式。发布时自动添加时间戳和消息 ID。发布后推送到匹配的订阅者。推送是 HTTP 回调。
投递保证：消息至少投递一次。回调失败重试 3 次。重试间隔递增。3 次都失败的消息进入待重试队列。待重试队列通过接口管理。
消息保留：已发布的消息保留一段时间（可配）。保留的消息可以通过接口查询。过期消息定期清理。
订阅者如果一段时间没活跃（没拉取消息也没回调成功），自动暂停推送。至少包含 pubsub、filter、delivery、retention 四个模块。Maven 构建，端口配置文件。
