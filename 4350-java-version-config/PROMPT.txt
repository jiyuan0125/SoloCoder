用 Java Spring Boot 写配置中心没有版本管理，改错了回不去：上次有人把数据库密码改错了，整个 staging 环境挂了，回滚只能手动改回去。配置每次修改生成新版本，版本号单调递增。查看任意历史版本：GET /api/config/versions/{version}。版本之间可以 diff：GET /api/config/diff?v1=5&v2=8。回滚到指定版本时创建新版本，内容等于旧版本，不是真的覆盖。环境通过 POST /api/envs 创建，GET /api/envs 列出。长轮询超时 30 秒，超时后客户端重新发起。没有变更就等到超时返回 304。网络断开时用本地缓存。Maven 构建，端口配置。
