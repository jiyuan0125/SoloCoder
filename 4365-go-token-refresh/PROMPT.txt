Go/Gin 写一个认证网关。请求进来先验证 Token，合法的转发到后端，不合法的拒绝。
Token 验证：支持 JWT 验证。检查签名、过期时间、issuer。验证失败返回 401。Token 过期前 5 分钟自动在响应 Header 中附带新 Token。
黑白名单：路径白名单不需要验证 Token。IP 黑名单直接拒绝。黑白名单通过接口动态管理。
Token 刷新：客户端可以用旧 Token 换新 Token。旧 Token 刷新后立即失效，防止重复刷新。刷新记录保留日志。模块化成 verifier、revoker、whitelist、refresh。go build 能过，PORT 环境变量。
