用 Go/Gin 写一个认证网关。支持两种方式：JWT 和 API Key。JWT 从 Authorization Header 的 Bearer 字段取，验证签名（HMAC-SHA256）、过期时间、issuer。API Key 从 X-API-Key Header 取，查本地配置的有效 Key 列表。验证失败返回 401，响应体带上失败原因（token expired / invalid signature / unknown key）。Token 快过期时自动续期是个好体验。过期前 5 分钟，网关在响应 Header 里附带 X-New-Token，客户端下次请求直接用新 Token。旧 Token 刷新后立即加入黑名单，防止重复刷新。刷新记录保留日志。go build ，PORT 环境变量。
