前端团队用 JSON，后端团队用 Protobuf，两边都不愿意改。中间加一层协议转换代理，各自用自己熟悉的格式。Rust tokio 来写，性能不是问题。1. JSON 转 Protobuf。前端发 JSON 请求到网关，网关根据请求路径找到对应的 Protobuf schema，按 schema 把 JSON 字段映射到 Protobuf 字段然后转发给后端。转换失败返回 400 并指出哪个字段有问题。2. Protobuf 转 JSON。后端返回 Protobuf 响应，网关转成 JSON 返回给前端。3. Schema 管理。支持多版本 schema 并存：不同路径可以用不同版本。Cargo build，PORT 环境变量。
