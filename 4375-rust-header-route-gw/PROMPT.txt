有些 API 网关只看路径匹配，但实际场景里经常需要根据请求 Header 做路由：比如移动端和 PC 端走不同的后端、内部调用和外部调用用不同的服务。Rust axum 写一个基于 Header 匹配的 API 网关。匹配成功后在转发前可以对 Header 做操作：添加新 Header、删除指定 Header、修改已有 Header 的值。操作定义在路由规则里。规则管理通过 HTTP 接口：POST /rules 创建、PUT /rules/{id} 修改、DELETE /rules/{id} 删除。router 管路由分发、matcher 管 Header 匹配、forwarder 管请求转发、admin 管规则 CRUD。Cargo build，PORT 环境变量。
