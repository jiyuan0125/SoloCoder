用 Java Spring Boot 写几十个服务的日志格式五花八门：有的用 JSON 有的用纯文本，字段名也不统一。排查跨服务问题时得人工对时间戳。不符合格式的日志拒绝接收并返回 400。日志接收后先按 level 过滤。ERROR 级别的日志自动触发告警评估：统计该 service 最近 5 分钟内的 ERROR 数量，超过阈值通过 HTTP 回调通知。同一 traceId 的日志自动按 spanId 组织成调用链视图，一次查询看到整条链路上的所有日志。receiver 管接收和校验、filter 管级别过滤和告警、alerter 管告警触发、masker 管脱敏。Maven 构建，端口写在配置文件里。
