用 Go 标准库 net/http 做一个 RBAC 认证网关，角色有继承关系。请求进来先过认证。支持两种方式：API Key 从 X-API-Key Header 取，查本地 Key 列表（通过接口管理），Key 对应一个用户和角色列表。JWT 从 Authorization Header 的 Bearer 字段取，解析出用户信息和角色。认证失败返回 401，响应体带失败原因。认证通过后检查权限。每个路径配置一个所需角色（比如 POST /admin/users 需要 admin 角色，GET /api/orders 需要 user 角色）。角色不匹配返回 403。权限配置通过接口管理。配置变更记录操作日志。go build ，PORT 环境变量。
