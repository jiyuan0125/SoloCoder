用 Rust 写物联网设备用 WebSocket 推数据上来，后端服务只暴露 REST API。设备通过 WebSocket 连接到网关，连接建立时从 URL 参数取设备 ID（ws://host/ws?device_id=sensor-001）。响应消息包含 status（状态码）和 data（响应体）。网关在内存中维护 device_id 到 WebSocket 连接的映射，找到连接后发送 payload。设备管理记录连接状态。设备连接时注册（记录 device_id、连接时间），断开时注销。bridge 管协议转换、device 管设备注册和状态、ws_handler 管 WebSocket 生命周期、rest_client 管 HTTP 调用。Cargo build，PORT 环境变量。
