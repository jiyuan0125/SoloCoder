用 Java Spring Boot 写有些任务不是定时跑的：比如用户下完单 30 分钟未支付就自动取消。提交延迟任务时指定延迟时长（秒）和回调信息。POST /tasks 接口接收任务，请求体包含 delaySeconds、callbackUrl、payload（任意 JSON）。回调失败按退避策略重试（1s、2s、4s，最多 3 次）。如果恢复时任务已经过期，立即触发回调。管理接口查看任务状态。GET /tasks/{id} 查询单个任务详情：状态（PENDING/EXECUTING/DONE/CANCELLED）、创建时间、预计执行时间、回调结果。GET /tasks 批量查询，支持按状态过滤。Maven 构建，端口写在配置文件里。
