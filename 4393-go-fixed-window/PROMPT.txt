滑动窗口实现起来比固定窗口复杂，限流精度也更高。但有些场景就是需要简单粗暴——一分钟内最多 N 个请求，窗口结束归零重来。Go 标准库 net/http 写一个固定窗口限流器，主打简单可靠。

每个窗口独立计数。窗口大小支持秒、分、时三个粒度，通过配置指定。窗口内请求数超过阈值返回 429，响应 Header 带上 X-RateLimit-Limit（窗口上限）、X-RateLimit-Remaining（剩余配额）、X-RateLimit-Reset（窗口重置时间的 Unix 时间戳）。窗口结束时计数器归零，新一轮开始。

多维度限流可以叠加。比如同时配了按 IP 限流（每分钟 100 次）和按 API Key 限流（每分钟 1000 次），请求必须两个维度都通过才放行。维度之间是 AND 关系——任一维度超限就拒绝。维度优先级不影响判断逻辑，全部平等检查。

窗口统计数据按维度聚合。当前窗口的请求数、拒绝数、通过数可以通过 GET /stats 查询。数据在窗口结束时归档（保留最近 10 个窗口的历史），新窗口从零开始。内部按 limiter（限流判断）、window（窗口管理）、counter（计数器）、stats（统计查询）拆模块。go build 能过，PORT 环境变量。
