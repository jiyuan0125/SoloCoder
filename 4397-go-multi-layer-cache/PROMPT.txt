单层缓存要么命中快但容量小（内存），要么容量大但慢（磁盘/远程）。Go/Gin 做一个多层缓存代理。L1 缓存用内存 map 实现，LRU 淘汰。容量上限可配（默认 10000 条）。每个条目有 TTL（默认 300 秒），过期后下次访问时惰性删除。命中 L1 直接返回，响应 Header 标记 X-Cache: L1-HIT。L2 缓存用文件存储。条目也有 TTL，过期文件在读取时检测并跳过。L2 命中时 Header 标记 X-Cache: L2-HIT。回写策略先写 L1 再异步写 L2。l1 管 L1 缓存、l2 管 L2 文件存储、proxy 管请求代理、writer 管异步回写。go build ，PORT 环境变量。
