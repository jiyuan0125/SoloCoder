配置改错了怎么办？这是配置中心最基本也最重要的能力——版本管理和回滚。FastAPI 做一个带完整版本历史的配置中心。

每次修改配置产生新版本，版本号单调递增。可以查看任意版本的完整内容——GET /config/{app}/{env}/versions/{version} 返回那个版本的全部 KV。两个版本之间可以 diff——列出哪些 key 变了、加了什么 key、删了什么 key、value 的前后差异。版本历史保留最近 100 个版本（可配）。

回滚到指定版本是一次特殊操作。POST /config/{app}/{env}/rollback 指定目标版本号。回滚产生新版本（版本号继续递增），内容复制自目标版本。回滚操作记录在审计日志里——谁在什么时间回滚到了哪个版本。回滚也可以撤销——再回滚到回滚之前的版本就行。

配置按环境隔离。环境通过接口创建（dev、staging、prod 各自独立）。同一个 key 在不同环境可以有不同值。环境列表通过 GET /envs 查看，每个环境显示 key 数量和最新版本号。store 管持久化和版本存储、version 管版本 diff 和比较、rollback 管回滚操作、env 管环境管理。端口 PORT 环境变量。
