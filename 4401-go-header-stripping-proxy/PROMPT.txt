上游服务对非法 Header 特别敏感，转发之前得清洗掉。Go 标准库来实现。
请求进来先匹配路径前缀，匹配到的走清洗流程：删掉 X-Internal- 开头的 Header，把 Host 替换成上游地址，给特定路径注入 X-Request-ID。清洗规则通过接口配置，改了就生效不用重启。
上游有主备两个地址，默认走主。主的健康检查连续失败 3 次自动切到备。主恢复后自动切回来。切换过程中已经在处理的请求不受影响。
清洗后的请求体大小超过 10MB 的直接拒绝，返回 413。
代码拆成 cleaner、router、upstream、health 四块。端口走 PORT 环境变量，go build 能过。
