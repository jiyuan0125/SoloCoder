消息投递失败不能就这么丢了。Spring Boot 做一个带死信和重试的消息队列。
生产者通过接口发布消息到指定 topic，消息有 payload、优先级、重试次数，持久化到文件或数据库。消费者通过接口拉取消息，拉取后必须在一定时间内确认（ack）。超时未确认的消息重新入队。确认时可以选重新入队或进死信。
重试超过 3 次的消息自动进死信队列。死信队列的消息可以通过接口查询，也可以手动重投到原 topic。消息的投递顺序不保证严格有序，但同一个 key 的消息要保证投递到同一个消费者。
publisher、consumer、deadletter、store 四个模块。Maven 构建，端口配置文件。
