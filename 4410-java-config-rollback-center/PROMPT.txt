我们配置中心最近要上回滚功能，Spring Boot 做。配置改坏了要能快速回退。
配置存储：配置按 app + env + key 三级组织。每次修改生成一个递增版本号。所有历史版本都保留。配置值支持文本和 JSON 两种格式。
回滚操作：可以回滚到指定版本。回滚不是删除新版本，而是创建一个新版本内容等于目标版本。回滚时推送变更通知给订阅的客户端。多个客户端同时订阅同一配置时变更要都能收到。
变更推送：客户端通过长轮询监听配置变更。长轮询超时 30 秒。变更时立即返回新值。推送失败时不阻塞其他客户端，记录推送失败的事件。
配置值的 JSON 格式在存储时要校验合法性。非法 JSON 的配置不允许保存。
至少包含 store、rollback、pusher、validator 四个模块。Maven 构建，端口配置文件。
