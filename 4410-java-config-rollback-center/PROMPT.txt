我们配置中心改坏了配置只能手动恢复，太危险了。Spring Boot 加一个回滚功能。
配置按 app + env + key 三级组织。每次修改生成一个递增版本号，所有历史版本都保留。配置值支持文本和 JSON 两种格式。可以回滚到指定版本——回滚不是删除新版本，而是创建一个新版本内容等于目标版本。回滚时推送变更通知给订阅的客户端，多个客户端同时订阅同一配置时变更要都能收到。
客户端通过长轮询监听配置变更，长轮询超时 30 秒。变更时立即返回新值。推送失败时不阻塞其他客户端，记录推送失败的事件。配置值的 JSON 格式在存储时要校验合法性，非法 JSON 的配置不允许保存。
store 负责存储和版本，rollback 处理回滚逻辑，pusher 管理长轮询推送，validator 校验格式。Maven 构建，端口配置文件。
