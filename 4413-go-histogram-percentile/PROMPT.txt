Go 标准库做一个直方图指标采集器。Prometheus 那种 histogram，但要自己算分位数。
指标定义：通过接口注册 histogram 指标，指定名称、帮助文本、桶边界。桶边界是升序排列的浮点数。指标名称唯一，重复注册返回错误。
数据写入：通过接口往 histogram 写入观察值。写入时自动更新每个桶的计数和总和。同时记录总观察次数。负数和 NaN 的观察值跳过不算。
分位数计算：查询时根据桶计数计算指定分位数（P50、P90、P95、P99）。分位数计算用线性插值。查询接口返回各分位数值和桶分布。
导出：提供 Prometheus exposition format 的导出接口。同时支持 JSON 格式导出。导出时包含所有已注册的 histogram 指标。
桶边界修改后已有的计数数据要能正确反映新桶的分布。
至少包含 registry、recorder、quantile、exporter 四个模块。端口 PORT 环境变量，go build 能过。
