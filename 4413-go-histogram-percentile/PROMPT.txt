Prometheus 那种 histogram 但要自己算分位数，不依赖客户端库。Go 标准库来写。
通过接口注册 histogram 指标，指定名称、帮助文本、桶边界（升序排列的浮点数）。指标名称唯一，重复注册返回错误。写入观察值时自动更新每个桶的计数和总和，同时记录总观察次数。负数和 NaN 的观察值跳过不算。查询时根据桶计数计算指定分位数（P50、P90、P95、P99），用线性插值。查询接口返回各分位数值和桶分布。
导出提供 Prometheus exposition format 和 JSON 两种格式，导出时包含所有已注册的 histogram 指标。桶边界修改后已有的计数数据要能正确反映新桶的分布。
registry 管理指标注册，recorder 记录观察值，quantile 算分位数，exporter 处理导出。端口 PORT 环境变量，go build 能过。
