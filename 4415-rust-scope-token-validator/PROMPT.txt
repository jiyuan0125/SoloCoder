用 Rust 写有 Token 不够，还得看它有没有对应的权限。光知道"你是谁"不行，得知道"你能干什么"。Token 通过接口创建，指定允许的 scope 列表和过期时间。Token 有唯一 ID 和密钥，过期后自动失效。请求进来时从 Authorization 头提取 Token，验证签名和过期时间。验证通过后检查请求需要的 scope，Token 没有所需 scope 返回 403，验证失败返回 401。路径和方法的映射关系可配：GET 请求需要 read scope，POST/PUT/DELETE 需要 write scope。通过接口可以提前撤销 Token，撤销后即使没过期也不能用。Cargo build，PORT 环境变量。
