用 Go 写内部服务用 Protobuf 通信效率高，但外部客户端只认 JSON，中间得有个桥。接收 JSON 请求转换成 Protobuf 发到上游，接收 Protobuf 响应转换成 JSON 返回。上游地址可配，转换用的 .proto 定义通过接口上传。oneof 字段转 JSON 时只序列化设置的那个，map 字段转 JSON 用对象表示。2. 上游超时可配，默认 10 秒。上游不可用返回 502 并记录错误日志。3. 同一个路径可以注册多个 proto 定义的不同 service，通过 Content-Type 区分。codec 处理编解码，mapping 管路径映射，proxy 做转发，proto_store 存储 proto 定义。端口 PORT，go build 。
