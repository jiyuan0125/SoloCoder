线上微服务调用了经常找不到是哪个环节慢，Spring Boot 做一个带 Baggage 传播的链路追踪。
Span 采集：服务通过接口上报 Span 数据。每个 Span 有 trace ID、span ID、父 span ID、服务名、操作名、开始时间、耗时。批量上报，每次最多 500 个 Span。
Baggage 传播：Span 可以携带 Baggage，就是跨服务传递的键值对。Baggage 在调用链中自动透传。下游服务可以读取上游设置的 Baggage。Baggage 的 key 不区分大小写。
Trace 查询：按 trace ID 查完整调用链，返回树形结构。按服务名查最近 N 条 trace。按耗时排序查慢请求。查询支持时间范围过滤。
采样策略：不是所有请求都追踪。采样率可配（比如 10%）。采样决策在根 Span 做出。采样后的请求所有 Span 都要采集。错误请求的采样率独立配置，通常更高。
至少包含 collector、baggage、query、sampler 四个模块。Maven 构建，端口配置文件。
