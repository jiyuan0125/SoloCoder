任务之间有先后依赖，简单的定时任务搞不定这种复杂关系。任务排成有向无环图执行，前置完成了后续才动。Python aiohttp 做一个 DAG 依赖的任务调度器。

通过接口提交 DAG，包含任务列表和依赖关系。每个任务有名称、回调 URL、超时。依赖关系是任务名称对。提交时校验是否有环，有环拒绝并返回具体的环路径。没有依赖的任务先执行，执行是 HTTP POST 回调。一个任务完成后触发依赖它的任务。同一层级没有依赖关系的任务并行执行，并行数有上限。

任务执行超过配置的超时时间视为失败，失败的任务不触发下游。整个 DAG 的执行也有超时，超时后所有进行中的任务取消——取消也是一次回调通知，告诉下游不用等了。

查某个 DAG 的执行状态，每个任务的状态：PENDING → RUNNING → SUCCESS/FAILED/TIMEOUT。可以查某个任务的上游和下游。DAG 执行完成后保留结果一段时间，默认 24 小时后清理。

同一个 DAG 定义可以触发多次执行，每次执行有独立的 ID。执行的 ID 和 DAG 定义的 ID 分开管理。

dag 管图结构、scheduler 做调度、executor 执行回调、tracker 跟踪状态。端口 PORT 环境变量。
