HTTPS 流量不解密也能分流——看 SNI 就够了。Go 标准库做一个基于 SNI 的路由代理。
TLS 握手时提取 Server Name Indication，不终止 TLS 连接。提取后根据域名做路由决策，提取失败的连接直接关闭。域名到后端的映射关系可配，支持精确域名和通配符域名（*.example.com）。通配符优先级低于精确匹配，规则通过接口动态管理。
匹配到规则后把整个 TLS 连接透传到后端，不修改任何数据。后端不可用时尝试下一个规则，都没匹配时转发到默认后端。
每个域名统计连接数、流量（字节）、错误数，统计按分钟聚合。SNI 提取失败的连接也统计。
sni 提取模块、router 路由模块、forward 转发模块、metrics 统计模块。端口 PORT 环境变量，go build 能过。
