新上线的实例一下子接全量流量容易出问题。Spring Boot 做一个预热加权负载均衡器。
实例通过接口注册，有地址、权重、预热时间。权重范围 1-100，预热时间默认 60 秒。实例状态 NEW → WARMING → READY → DOWN。NEW 状态的实例开始预热，预热期间实际权重从 1 线性增长到配置的权重，增长速度按预热时间均分。预热完成后变 READY 使用配置的权重。
选择策略是加权随机。每次请求按当前实际权重选实例，权重为 0 的不选。DOWN 状态的不选。手动下线时先把权重降为 0，等现有请求处理完再真正移除。预热中的实例突然挂掉，重启后重新预热。
registry 管理实例注册，warmer 控制预热，selector 做选择，lifecycle 管理生命周期。Maven 构建，端口配置文件。
