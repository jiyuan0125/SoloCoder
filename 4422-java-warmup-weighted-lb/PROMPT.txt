Spring Boot 做一个预热加权负载均衡器。新上线的实例不能一下子接全量流量。
实例注册：实例通过接口注册，有地址、权重、预热时间。权重范围 1-100。预热时间单位秒，默认 60 秒。实例状态 NEW → WARMING → READY → DOWN。
预热过程：NEW 状态的实例开始预热。预热期间实际权重从 1 线性增长到配置的权重。增长速度按预热时间均分。预热完成后状态变 READY，使用配置的权重。
选择策略：加权随机。每次请求按当前实际权重选实例。权重为 0 的实例不选（预热刚开始的那一瞬间）。DOWN 状态的实例不选。
手动下线时先把权重降为 0，等现有请求处理完再真正移除。预热中的实例突然挂掉，重启后重新预热。
至少包含 registry、warmer、selector、lifecycle 四个模块。Maven 构建，端口配置文件。
