API 网关本身要做鉴权和限流，然后转发到后端。Go Gin 来做一个带限流的 API 网关。
请求进来先检查 X-API-Key 头。API Key 通过接口管理，每个 Key 有名称、权限级别、QPS 限额。没有 Key 或 Key 无效返回 401。权限级别决定能访问哪些路径前缀。每个 Key 独立的 QPS 限额，超限返回 429 带 Retry-After 头。限流用令牌桶算法，桶的容量和填充速率按 Key 的配置。所有 Key 共享一个全局限流器防止总量过大。
鉴权和限流通过后转发到上游，上游地址可配。转发时注入 X-User-Level 头（权限级别），转发超时 10 秒。上游健康检查每 30 秒一次，不健康时网关返回 503。API Key 的创建接口要能一次创建多个 Key。Key 本身的创建操作不受限流限制。
auth 做鉴权，ratelimit 管理限流，proxy 转发，upstream 健康检查。端口 PORT 环境变量，go build 能过。
