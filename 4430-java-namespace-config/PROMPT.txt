不同团队用不同命名空间，配置互不干扰。Spring Boot 做一个带命名空间的配置中心。
1. 通过接口创建命名空间，有名称和描述，名称全局唯一。命名空间有 ACTIVE 和 ARCHIVED 状态。ARCHIVED 的命名空间配置只读。
2. 每个命名空间独立管理自己的配置。配置有 key、value、格式（text/json/yaml）、版本号。修改自动递增版本号，可以查看任意历史版本，支持回滚到指定版本。
3. 命名空间有管理员列表，管理员可以增删改配置，非管理员只能读取。管理员通过接口添加和移除，列表持久化存储。
4. 配置变更后通知订阅者，订阅者通过长轮询监听。推送失败不影响配置保存，失败的事件记录下来可查。回滚操作也触发推送。
namespace、config、permission、pusher 四个模块。Maven 构建，端口配置文件。
