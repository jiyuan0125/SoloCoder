FastAPI 做一个关联日志聚合器。同一个请求在不同服务的日志要能串起来。
日志写入：各服务通过接口上报日志。日志有 trace ID、服务名、级别、时间戳、消息、附加字段。批量上报，每批最多 100 条。日志异步写入存储。
关联查询：按 trace ID 查询关联的所有日志。结果按时间排序。可以看某个 trace 的完整调用链路。查询支持按服务名和级别过滤。
统计面板：每个服务的日志量趋势。错误率趋势（error 级别占比）。最慢的 trace 排行。统计按分钟聚合。存储中的日志数据量超过限制时自动清理最旧的。
附加字段里的值可能是任意 JSON，查询时要能按附加字段过滤。trace ID 不存在时返回空列表而不是错误。
至少包含 writer、query、stats、storage 四个模块。端口 PORT 环境变量。
