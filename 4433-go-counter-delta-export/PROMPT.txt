Go 标准库做一个 Counter 和 Gauge 的指标导出器。不搞复杂的，就两种基础指标类型。
指标管理：通过接口创建指标，指定名称、类型（counter/gauge）、标签名列表、帮助文本。指标名称唯一。标签名在创建时固定，之后不能改。Counter 只能增不能减。Gauge 可增可减。
数据写入：Counter 通过接口递增。Gauge 通过接口设置或增减。写入时传入标签值，标签值和标签名一一对应。缺少标签值的写入拒绝。标签值中允许数字、字母、下划线、斜杠。
查询导出：Prometheus exposition format 导出。导出时每个指标的所有标签组合都输出。也支持 JSON 格式。JSON 格式包含指标的元信息（类型、帮助文本）。
Counter 重置：某些场景需要重置 Counter（比如进程重启）。重置后 Counter 从 0 开始。重置操作记录到事件日志。Gauge 没有重置的概念。
至少包含 registry、writer、exporter、event 四个模块。端口 PORT 环境变量，go build 能过。
