不搞复杂的 histogram 和 summary，就两种最基础的指标类型——Counter 只增不减，Gauge 可增可减。Go 标准库做一个指标导出器，简单够用就行。

通过接口创建指标，指定名称、类型（counter/gauge）、标签名列表、帮助文本。指标名称全局唯一。标签名在创建时固定之后不能改。Counter 只能增不能减，递增时传入增量值。Gauge 可增可减也可直接设值。写入时传入标签值，标签值和标签名一一对应。缺少标签值的写入拒绝。标签值中允许数字、字母、下划线、斜杠。

导出用 Prometheus exposition format，每个指标的所有标签组合都输出。也支持 JSON 格式，JSON 包含指标的元信息——类型和帮助文本。导出时如果没有写入过观察值的指标也输出——值为零。

某些场景需要重置 Counter——比如进程重启后从 0 开始。重置后从 0 开始，重置操作记录到事件日志。Gauge 没有重置的概念，但可以设值为 0。重置 Counter 不影响其他指标。

指标数量有上限，防止注册太多浪费内存。标签组合的数量也有上限——高基数标签（比如 user_id）会导致组合爆炸，要提前预防。

registry 管指标注册，writer 写数据，exporter 做导出，event 记事件。端口 PORT 环境变量，go build 能过。
