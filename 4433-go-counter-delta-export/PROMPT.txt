不搞复杂的，就两种基础指标类型：Counter 和 Gauge。Go 标准库做一个指标导出器。
通过接口创建指标，指定名称、类型（counter/gauge）、标签名列表、帮助文本。指标名称唯一。标签名在创建时固定之后不能改。Counter 只能增不能减，Gauge 可增可减。Counter 通过接口递增，Gauge 通过接口设置或增减。写入时传入标签值，标签值和标签名一一对应。缺少标签值的写入拒绝。标签值中允许数字、字母、下划线、斜杠。
导出用 Prometheus exposition format，每个指标的所有标签组合都输出。也支持 JSON 格式，包含指标的元信息（类型、帮助文本）。某些场景需要重置 Counter（比如进程重启），重置后从 0 开始，重置操作记录到事件日志。Gauge 没有重置的概念。
registry 管指标注册，writer 写数据，exporter 做导出，event 记事件。端口 PORT 环境变量，go build 能过。
