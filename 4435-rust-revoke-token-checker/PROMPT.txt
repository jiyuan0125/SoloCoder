Rust tokio 做一个 Token 撤销检查网关。Token 即使没过期，被撤销了也不能用。
撤销列表：通过接口撤销 Token。撤销记录有 token ID、撤销时间、原因。撤销列表存在内存里。撤销检查时直接查内存。撤销列表支持批量导入。
请求检查：请求进来时从 Header 提取 Token ID。先查撤销列表，已撤销返回 401。再查过期时间，过期也返回 401。都通过才转发到上游。Token ID 缺失返回 401。
批量预加载：启动时从持久化存储加载撤销列表。运行时通过接口新增的撤销立即生效。撤销列表定期全量同步。同步过程中已有的撤销记录不清除。
统计：已撤销的 Token 被使用的次数。撤销列表的大小。检查耗时分布。统计按分钟聚合。
至少包含 revoke_list、checker、loader、stats 四个模块。Cargo build，PORT 环境变量。
