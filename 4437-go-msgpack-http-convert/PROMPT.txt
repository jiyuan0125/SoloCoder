有些内部服务用 MsgPack 通信，外部只认 JSON，中间得转换：而且字段名还不一样。Go Fiber 做一个 MsgPack-HTTP 协议转换器。1. 外部请求 JSON 格式进来，网关把 JSON body 转成 MsgPack 发到内部服务。内部服务响应 MsgPack 转成 JSON 返回给外部。部分失败不影响其他操作，批量结果用 JSON 数组返回，每个元素有自己的状态码。空请求体直接转发不做转换。MsgPack 解码失败返回 400 和具体错误位置：哪个字节出了问题。JSON 解码失败也返回 400。上游超时可配，默认 10 秒。上游不可用返回 502。端口 PORT，go build 。
