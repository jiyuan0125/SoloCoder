全量采集 Trace 太浪费资源，按比例采集。Spring Boot 做一个采样式 Trace 采集器。
全局采样率可配比如 10%。采样决策在请求入口做，被采样的请求在整个调用链中所有 Span 都要采集。没有被采样的不采集任何 Span。错误请求的采样率独立配置通常更高比如 100%。服务上报 Span 到采集器时，采集器过滤掉未被采样的 Span。过滤依据是 trace ID 对应的采样标记，标记存在内存中过期时间 5 分钟。采集到的 Span 持久化存储。
按 trace ID 查完整调用链，按服务名查最近 N 条 trace，按耗时排序查慢请求。查询接口支持游标分页。
根据当前采集量动态调整采样率：超过上限时降低，低于下限时提高。自适应范围有最大最小值约束，不影响错误请求的采样率。
sampler 做采样，collector 采集 Span，query 查询，adaptive 自适应调整。Maven 构建，端口配置文件。
