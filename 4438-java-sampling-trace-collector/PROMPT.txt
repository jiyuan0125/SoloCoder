Spring Boot 做一个采样式 Trace 采集器。全量采集太浪费资源，按比例采集。
采样策略：全局采样率可配，比如 10%。采样决策在请求入口做。被采样的请求在整个调用链中所有 Span 都要采集。没有被采样的请求不采集任何 Span。错误请求的采样率独立配置，通常更高比如 100%。
Span 采集：服务上报 Span 到采集器。采集器过滤掉未被采样的 Span。过滤依据是 trace ID 对应的采样标记。采样标记存在内存中，过期时间 5 分钟。采集到的 Span 持久化存储。
Trace 查询：按 trace ID 查完整调用链。按服务名查最近 N 条 trace。按耗时排序查慢请求。查询接口支持游标分页。
自适应采样：根据当前采集量动态调整采样率。采集量超过上限时降低采样率。采集量低于下限时提高采样率。自适应范围有最大最小值约束。自适应采样不影响错误请求的采样率。
至少包含 sampler、collector、query、adaptive 四个模块。Maven 构建，端口配置文件。
