Spring Boot 做一个熔断和负载均衡的混合器。两个能力集成在一个组件里。
实例管理：后端实例通过接口注册，有地址、权重、区域。实例状态 NEW → WARMING → READY → DOWN。WARMING 状态的实例权重从 0 逐渐增加到配置值。DOWN 的实例不参与负载均衡。
熔断器：每个实例独立的熔断器。CLOSED → OPEN → HALF_OPEN 三态。实例连续失败 5 次打开熔断。熔断打开后该实例从选择池中移除。熔断器半开时放一个请求探测。
选择策略：加权轮询 + 熔断感知。选择时跳过熔断打开的实例。所有实例都熔断时返回 503。WARMING 实例的权重低但能被选中。实例从熔断恢复后权重从低开始慢慢恢复。
熔断恢复时权重不从 0 开始，从配置权重的一半开始。区域亲和：优先选同区域的实例。实例的权重变更后立即影响选择概率。
至少包含 instance、breaker、selector、warmer 四个模块。Maven 构建，端口配置文件。
