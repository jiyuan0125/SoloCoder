Rust axum 做一个多级配额限流器。不同级别的用户有不同的限额。
配额管理：通过接口创建配额计划。计划有名称、QPS 限制、日请求量限制、突发容量。用户通过接口绑定到某个计划。一个用户同一时间只能绑一个计划。配额计划变更后立即生效。
限流执行：请求进来时从 Header 提取用户 ID。查用户绑定的计划的 QPS 和日限额。QPS 用令牌桶控制。日限额用计数器。日限额归零时即使 QPS 还有余额也拒绝。429 响应带 X-RateLimit-Limit 和 X-RateLimit-Remaining。
多级结构：计划可以继承。子计划的上限不能超过父计划。所有用户共享父计划的全局限额。全局限额是所有子计划用户的总和上限。
配额计划删除前要确认没有用户绑定。日限额在每天零点重置。用户 ID 为空时走默认的匿名限额。
至少包含 plan、limiter、hierarchy、counter 四个模块。Cargo build，PORT 环境变量。
