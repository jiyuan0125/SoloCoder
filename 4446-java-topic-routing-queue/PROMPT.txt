不同类型的消息发到不同的处理队列，路由错了业务就乱了。Spring Boot 做一个 Topic 路由消息队列。
通过接口创建 topic，有名称、分区数、消息保留时间。名称全局唯一，分区数创建后不可修改，消息超过保留时间自动清理。生产者发消息时指定 topic 和路由 key，路由 key 决定消息进入哪个分区。相同路由 key 的消息进入同一分区，分区内有序，不同分区并行处理。
消费者组订阅 topic。一个分区同一时间只给组内一个消费者。消费者通过接口拉取消息，拉取后必须确认。超时未确认的消息重新分配。消费者退出后它的分区立即重新分配。处理失败超过 3 次的消息进死信队列，死信可以查询和重新投递，重新投递的消息回到原 topic。
topic、router、consumer、deadletter 四个模块。Maven 构建，端口配置文件。
