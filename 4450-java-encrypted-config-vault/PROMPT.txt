数据库密码、API 密钥这些敏感配置不能明文存储——万一配置文件泄露了就全完了。Spring Boot 做一个加密配置中心，所有敏感配置都加密存储。

配置项有 key、加密值、加密算法、版本号。支持 AES-256-GCM 加密，加密密钥通过启动参数传入不落盘——进程启动时从命令行参数读密钥存内存，不写任何文件。配置值在写入时自动加密，读取时自动解密，每次修改版本号递增。支持密钥轮换——旧密钥标记为 deprecated 还能解密旧值，新写入的配置用当前活跃密钥加密。密钥轮换时已有的配置不自动重新加密，读取时根据版本号选对应的密钥解密。

配置项有读写权限控制。读权限通过接口授权给指定的应用，写权限只有管理员有。权限信息持久化，没有权限的访问返回 403。所有配置的读写操作都记录审计日志——操作人、操作时间、操作类型、配置 key。密钥轮换操作单独记录。审计日志不可删除，查询支持按时间和操作类型过滤。

key 的格式允许字母数字下划线和点，长度不超过 256 字符。同一个 key 重复写入是更新不是报错。

store 做存储加密，keychain 管密钥，access 做权限控制，audit 记审计日志。Maven 构建，端口走配置文件。
