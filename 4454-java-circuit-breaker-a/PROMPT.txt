用 Java Spring Boot 写先理清熔断的触发条件。CLOSED 状态下统计一个时间窗口里的请求失败率，超过阈值就切 OPEN。OPEN 持续一段时间后放行一个探测请求进入 HALF_OPEN，探测成功回 CLOSED，失败再回 OPEN。然后是告警。同一个服务 1 分钟最多告警 1 次，别刷屏。告警发送失败记日志但不阻塞主流程。1. circuit 模块实现状态机转换和失败率统计
2. alerter 模块管 Webhook 通知和防刷逻辑
3. metrics 模块做分钟级聚合和查询
4. registry 模块管理被保护服务的注册和配置
Maven 构建，端口配置。HALF_OPEN 状态的探测间隔也单独配：关键服务 10 秒探测一次，不急的 60 秒也行。
