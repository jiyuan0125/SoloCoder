Rust axum 做一个 API 网关。前端请求进来，网关做认证、变换、聚合再转发。

路由配置：路由规则支持路径前缀匹配和精确匹配。每条规则配置上游地址列表和认证要求。路由规则通过接口管理。规则变更实时生效。

认证层：需要认证的路由会检查 JWT Token。Token 从 Authorization Header 提取。校验通过后将用户信息注入请求 Header 转发给上游。没有 Token 的请求返回 401。

请求聚合：某些接口需要从多个上游获取数据合并返回。聚合规则配置多个上游请求和合并策略。合并策略支持并行请求全部完成后拼接 JSON。任一上游失败则整个聚合请求返回错误。

至少包含 gateway、auth、aggregator、transform 四个模块。Cargo build，端口 PORT 环境变量。
