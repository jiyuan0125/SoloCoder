Rust axum 实现一个 API 网关，处理认证、请求变换和聚合转发。

【路由】规则支持路径前缀匹配和精确匹配两种。每条规则配上游地址列表和认证要求，走接口管理，变更实时生效。

【认证】标注需要认证的路由会从 Authorization Header 取 JWT Token。校验通过后把用户信息塞进 Header 转给上游；没 Token 的直接 401。

【聚合】部分接口需要从多个上游拉数据拼在一起返回。聚合规则配好多个上游请求和合并策略——当前支持并行请求全部完成后拼接 JSON，任一上游失败则整个聚合请求报错。

模块至少包含 gateway、auth、aggregator、transform。Cargo build，端口 PORT 环境变量。
