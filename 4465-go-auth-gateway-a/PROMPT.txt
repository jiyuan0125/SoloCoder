Go 标准库实现一个认证网关，其他服务把 JWT 相关的事全丢过来：签发、刷新、校验、拉黑，一条龙。Access Token 短效 15 分钟，Refresh Token 长效 7 天。刷新流程：Access Token 过期前可以用 Refresh Token 换新的 Access Token。Refresh Token 也过期了那就得重新走登录流程，没有捷径。黑名单机制：通过接口把某个 Token 拉黑，黑名单里的请求直接 401。过期的黑名单条目定期清理，不会无限膨胀。端口 PORT，go build 。已经签发的 Access Token 不会变，但 15 分钟就过期了，影响不大。如果需要立刻踢掉某用户，走黑名单接口。
