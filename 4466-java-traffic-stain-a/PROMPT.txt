灰度发布的时候，得把一部分流量导向新版本试试水。用 Spring Boot 做一个流量染色网关来搞定这件事。

染色规则走接口配，匹配条件包括 Header 值、Cookie 值、IP 段、百分比，规则可以 AND/OR 组合。匹配到的请求打上 X-Gray-Tag Header 作为染色标记。

有标记的请求路由到灰度环境，灰度地址走接口配。同一服务可以有多个灰度版本，染色标记值决定走哪个版本。没标记的走正式。

灰度流量有百分比控制，按分钟级窗口统计。超百分比的降级到正式环境。灰度版本的健康检查独立于正式环境。至少拆 dye、router、rule、traffic 四个模块，Maven 构建，端口走配置文件。
