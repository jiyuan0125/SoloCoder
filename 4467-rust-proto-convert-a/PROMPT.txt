老服务只认 JSON，新服务用 Protobuf，两边对不上。用 Rust axum 做一个协议转换代理架在中间。

Protobuf schema 通过接口注册，每个 schema 有名称和版本，同一名称可以挂多个版本，查询时返回最新的。

请求 Body 是 JSON 的话，根据路径确定目标 schema 然后转 Protobuf。转换时校验字段和 schema 是否匹配，不匹配的返回错误详情，嵌套对象递归处理。反过来，请求 Body 是二进制 Protobuf 的话，根据 Content-Type 和路径确定 schema，转出来的 JSON 保持 schema 字段命名，枚举类型变成字符串。

至少拆 schema、encoder、decoder、validate 四个模块，Cargo build，端口 PORT 环境变量。
