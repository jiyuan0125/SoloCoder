Netty 实现一个事件调度器。定时后台任务统一管理、统一触发。

【任务注册】通过接口注册定时任务，包含名称、Cron 表达式（标准五段：分时日月周）、回调 URL、超时时间。任务有 ENABLED、DISABLED、DELETED 三种状态。

【执行引擎】Cron 触发后走 HTTP POST 回调，回调超时可配。执行结果记录成功/失败/超时，失败的重试最多 3 次，间隔 1 分钟。

【日志】每次执行都留记录，包括任务名、触发时间、完成时间、结果和响应内容。日志按天归档，可以按任务名和日期范围查。

模块至少包含 scheduler、executor、logger、task，Maven 构建，端口走配置文件。
