Netty 做一个事件调度器。定时的后台任务统一在这里管理。

任务管理：通过接口注册定时任务。任务包含名称、Cron 表达式、回调 URL、超时时间。Cron 表达式支持标准五段格式（分时日月周）。任务状态有 ENABLED、DISABLED、DELETED。

执行引擎：按 Cron 表达式触发任务执行。执行方式是 HTTP POST 回调。回调超时可以配置。执行结果记录（成功/失败/超时）。失败的任务按策略重试（最多 3 次，间隔 1 分钟）。

执行日志：每次执行都记录日志。日志包含任务名、触发时间、完成时间、结果、响应内容。日志按天归档。支持按任务名和日期范围查询。

至少包含 scheduler、executor、logger、task 四个模块。Maven 构建，端口配置文件。
