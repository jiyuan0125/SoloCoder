用 Java Spring Boot 写Netty 实现一个集中式事件调度器，定时后台任务统一管理统一触发。想暂停某个任务直接 DISABLED，不用删了再重建。Cron 触发后走 HTTP POST 回调到指定 URL，回调超时时间可配，默认 10 秒。执行结果记录成功、失败或超时，失败的重试最多 3 次，每次间隔 1 分钟。重试也失败就标记为最终失败，不影响下一次 Cron 触发。scheduler 管 Cron 解析和任务调度，executor 管 HTTP 回调和重试，logger 管执行日志的存储和查询，task 管任务的 CRUD 和状态。Maven 构建，端口配置。非法的 Cron 表达式在注册时就报错，不存进去。
