Go Gin 做一个多级限流器。请求进来先过全局限流，再过路径限流，最后过用户限流。

全局限流：整个系统的总 QPS 上限。超出全局上限的请求直接 429。全局计数器按滑动窗口统计。

路径限流：每个路径模式可以配独立的 QPS 上限。未配置的路径不受路径级限流。路径支持前缀匹配。同一个请求可能匹配多条路径规则，取最严格的。

用户限流：每个用户（从 Token 提取）每分钟的请求数上限。未登录用户用 IP 代替。用户限流超了返回 429 带 Retry-After。

每一级限流触发都记录事件。至少包含 global、pathlimiter、userlimiter、events 四个模块。端口 PORT 环境变量，go build 能过。
