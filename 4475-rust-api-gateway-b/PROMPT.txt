Rust actix-web 做一个插件化的 API 网关。认证、限流、日志这些能力做成插件，按顺序执行。

拦截器链：请求进来经过一系列拦截器。每个拦截器可以放行或拒绝。拒绝直接返回响应，不走后续拦截器。拦截器按优先级排序执行。

请求拦截器：认证（检查 Token）、限流（检查 QPS）、路由匹配（确定目标上游）。每个拦截器独立配置。拦截器通过接口管理增删改。

响应拦截器：上游返回响应后经过一系列后处理。缓存（缓存 GET 响应）、日志（记录请求响应摘要）、Header 注入。响应拦截器出错不影响响应返回。

至少包含 chain、interceptor、request、response 四个模块。Cargo build，端口 PORT 环境变量。
