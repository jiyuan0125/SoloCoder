Go 标准库做一个两级缓存中间件。内存做一级缓存快但不持久，文件做二级缓存慢但重启不丢。

缓存查询：请求先查 L1 内存缓存。L1 未命中查 L2 文件缓存。L2 也未命中回源。回源结果同时写 L1 和 L2。L1 有 TTL，过期后查 L2。L2 没有 TTL，通过主动删除淘汰。

击穿保护：同一个 Key 多个请求同时未命中时，只放一个请求回源。其他请求等待回源结果。等待超时的请求直接穿透回源。

预热接口：通过接口可以主动预热指定路径的缓存。预热时提前回源并存入 L1 和 L2。可以批量预热（一次最多 50 个路径）。预热是后台异步执行。

至少包含 cache、layer、singleflight、warmer 四个模块。端口 PORT 环境变量，go build 能过。
