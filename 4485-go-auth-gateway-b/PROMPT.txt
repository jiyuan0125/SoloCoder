Go Gin 实现 OAuth2 授权服务：各个应用的登录认证不能各搞各的，统一走这里。授权码模式给 Web 应用用。客户端把用户重定向到授权页面，用户确认后回调客户端带授权码。Token 有效期可配，默认 1 小时。authorize 管授权码的生成和校验，token 管 Access Token 的签发和刷新，scope 管 Scope 权限定义和校验，client 管客户端注册和凭证管理。端口 PORT，go build 。客户端注册时分配 client_id 和 client_secret。客户端的 redirect_uri 也要注册，授权回调时校验 redirect_uri 是否匹配，防止开放重定向攻击。
