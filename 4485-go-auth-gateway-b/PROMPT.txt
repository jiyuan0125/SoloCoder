Go Gin 做一个 OAuth2 授权服务。应用的登录认证统一走这个服务。

授权码模式：客户端重定向到授权页面。用户确认授权后回调客户端并带授权码。客户端用授权码换 Token。授权码有效期 10 分钟且只能用一次。

客户端凭证模式：机器对机器的认证。客户端用 ID 和 Secret 换 Token。不需要用户参与。Token 有效期可配。

Scope 控制：每个 Token 关联一组 Scope。Scope 定义了可以访问哪些资源。客户端申请 Token 时指定需要的 Scope。授权服务根据客户端配置批准或拒绝 Scope。

至少包含 authorize、token、scope、client 四个模块。端口 PORT 环境变量，go build 能过。
