Go Gin 实现 OAuth2 授权服务，应用的登录认证统一走这里。

【授权码模式】客户端把用户重定向到授权页面，用户确认后回调客户端带授权码。客户端拿授权码换 Token。授权码有效期 10 分钟，且只能用一次。

【客户端凭证模式】机器对机器的认证，客户端用 ID + Secret 换 Token，不需要用户参与。Token 有效期可配。

【Scope 控制】每个 Token 关联一组 Scope，Scope 定义可访问的资源。客户端申请 Token 时指定需要的 Scope，授权服务根据客户端配置批准或拒绝。

模块至少包含 authorize、token、scope、client，端口 PORT 环境变量，go build 能过。
