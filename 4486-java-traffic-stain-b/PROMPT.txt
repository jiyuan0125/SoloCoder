Spring Boot 做一个全链路流量染色服务。灰度发布不只是网关层的事，整条链路都要透传标记。

标记传播：请求在网关层打上染色标记。标记通过 HTTP Header 传播到下游服务。下游服务读到标记后继续透传。服务调用链上标记不能丢失。

染色规则：每个服务可以配自己的染色规则。规则决定哪些请求需要染色。规则条件支持 Header 匹配和百分比。网关层匹配的规则优先级最高。

流量隔离：染色流量和正式流量在统计上隔离。各服务上报染色流量的指标。指标包括 QPS、延迟、错误率。染色流量指标独立查询。

至少包含 marker、propagate、rule、isolate 四个模块。Maven 构建，端口配置文件。
