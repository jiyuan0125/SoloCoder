Rust actix-web 做一个 WebSocket 到 HTTP 的桥接服务。有些客户端只能用 WebSocket，后端只提供 HTTP 接口，中间需要一个转换。

连接管理：WebSocket 客户端连接到桥接服务。每个连接分配唯一 ConnectionID。连接断开后自动清理。支持同时多个客户端连接。

消息转发：WebSocket 收到消息后解析为 HTTP 请求。消息格式包含目标 URL、Method、Headers、Body。桥接服务发 HTTP 请求到目标。HTTP 响应转成 WebSocket 消息回传。

推送通道：后端也可以主动推消息给 WebSocket 客户端。通过接口指定 ConnectionID 和消息内容。客户端不在线时消息暂存。客户端重连后推送暂存消息。

至少包含 wsconn、forward、pushback、buffer 四个模块。Cargo build，端口 PORT 环境变量。
