有些客户端只能用 WebSocket，但后端只提供 HTTP 接口。用 Rust actix-web 做一个 WebSocket 到 HTTP 的桥接服务架在中间。

WebSocket 客户端连到桥接服务，每个连接分配唯一 ConnectionID。断了自动清理，支持同时多个客户端。收到的 WebSocket 消息解析为 HTTP 请求——消息里包含目标 URL、Method、Headers、Body。桥接服务发 HTTP 请求到目标，响应转成 WebSocket 消息回传。

后端也能主动推消息给客户端：通过接口指定 ConnectionID 和消息内容。客户端不在线时暂存，重连后推送。至少拆 wsconn、forward、pushback、buffer 四个模块，Cargo build，端口 PORT 环境变量。
