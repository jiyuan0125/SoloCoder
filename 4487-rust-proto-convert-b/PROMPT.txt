用 Rust 写有些客户端只能用 WebSocket 长连接：老式浏览器、嵌入式设备、游戏客户端，但后端只提供 REST HTTP 接口。WebSocket 客户端连到桥接服务后每个连接分配唯一 ConnectionID。断了自动清理资源，支持同时多个客户端连接。收到的 WebSocket 消息解析为 HTTP 请求：消息格式是 JSON，包含目标 URL、Method（GET/POST/PUT/DELETE）、Headers 和 Body。wsconn 管 WebSocket 连接管理和 ConnectionID 分配，forward 管消息解析和 HTTP 请求转发，pushback 管后端主动推送，buffer 管离线消息暂存。Cargo build，端口 PORT。request_id 用来匹配请求和响应。
