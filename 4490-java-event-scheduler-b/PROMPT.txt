Spring Boot 实现延迟队列调度器。消息队列里有些消息要延迟处理，还有定时跑的任务也要管。

【延迟消息】通过接口提交，带上 Topic、Body 和延迟时间。到期后通过 HTTP 回调投递到对应 Topic。

【定时任务】通过接口注册，Cron 表达式 + 回调 URL，按 Cron 触发 HTTP POST 回调，执行结果有记录。

【状态跟踪】每条延迟消息和每次任务执行都有状态（SCHEDULED、EXECUTING、SUCCESS、FAILED），按状态查，FAILED 的可以手动重新触发。

模块至少包含 scheduler、delay、timer、tracker，Maven 构建，端口走配置文件。
