Rust tokio 做一个 API 聚合网关。前端一个页面要调好几个接口，网关帮忙合成一个。

聚合配置：每个聚合接口配置多个后端请求模板。请求模板包含 URL、Method、参数映射。参数可以从原始请求中提取。聚合配置通过接口管理。

并行执行：多个后端请求并行发出。所有请求完成后合并响应。合并策略支持：直接拼接、按字段映射、自定义模板。合并结果统一返回。

降级处理：部分后端请求失败时可以选择降级。降级策略：返回默认值、跳过该字段、整个请求返回错误。降级策略在聚合配置中指定。所有请求都失败才返回整体错误。

至少包含 aggregator、executor、merger、fallback 四个模块。Cargo build，端口 PORT 环境变量。
