Spring Boot 写一个数据库连接池监控。线上连接池老出问题——要么连接泄漏导致池耗尽，要么慢查询把连接占满了后面的请求全等着，得能看清每个连接在干嘛。

每次借出连接记录时间、调用方标识和 SQL 摘要（取前 200 字符），归还时记执行时长。持有超过配置阈值的标记为慢连接，活跃连接列表实时可查——每个连接的持有时间、调用方和当前 SQL 一目了然。

SQL 执行超过阈值记为慢查询，阈值可配。记录 SQL 文本、执行时长和调用方信息，有慢查询 Top 10 列表按频率排序，帮助找出最需要优化的 SQL。

连接池的使用率、等待数、活跃数、空闲数按分钟聚合，保留最近 24 小时。使用率超过 80% 告警，等待队列超过 10 个也告警，告警走接口推送。tracker 管连接借出归还追踪，slowquery 管慢查询记录和排名，metrics 管分钟级聚合统计，alert 管阈值检测和告警推送。Maven 构建，端口走配置文件。


慢查询排名可以按不同维度排——按执行时间、按调用频率、按 SQL 模板分组。SQL 模板是把具体参数替换成占位符后的通用格式，比如 SELECT * FROM users WHERE id = ? 就是一个模板。
