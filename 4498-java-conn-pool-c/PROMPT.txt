Spring Boot 做一个数据库连接池监控。线上数据库连接池老出问题，要能看清每个连接在干嘛。

连接追踪：每次借出连接记录时间、调用方、SQL 摘要。归还时记录执行时长。连接持有超过阈值记为慢连接。活跃连接列表实时可查。

慢查询：SQL 执行时间超过阈值记为慢查询。慢查询阈值可配。记录 SQL 文本、执行时间、调用方。慢查询 Top 列表。

池指标：连接池使用率、等待数、活跃数、空闲数。指标按分钟聚合。使用率超过 80% 告警。等待数超过 10 告警。告警通过接口推送。

至少包含 tracker、slowquery、metrics、alert 四个模块。Maven 构建，端口配置文件。
