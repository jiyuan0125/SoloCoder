Spring Boot 做一个带权重的负载均衡器。后端服务有不同规格的机器，需要按权重分配请求。

支持三种策略：加权轮询、最少连接数、一致性哈希。策略可以按服务维度配置，不同的服务用不同的策略。加权轮询的时候权重为 0 的实例不参与分配。

最少连接数策略：每次选当前连接数最少的实例。连接数相同的时候按权重比例选。一致性哈希策略：根据请求里的某个 key（可配置）做哈希，同一个 key 总是打到同一个实例。实例增减时尽量少迁移。

管理接口：注册实例、注销实例、调整权重、查看各实例连接数和 QPS。实例上线时有个预热期，预热期间权重逐步增加到目标值。

至少包含 balancer、registry、strategy、monitor 四个模块。Maven 构建，端口配置文件里指定。
