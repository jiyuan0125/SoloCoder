前端联调记不住五六个微服务地址，经常调错。Gin 做 API 网关统一入口，网关负责路由转发。

路由支持精确路径和前缀匹配，路径带参数如 /users/{id}/orders 提取 id 传给后端。同一路径不同方法可转发不同后端，读走查询服务写走修改服务。

认证注入：部分接口要登录，请求头带 Token，网关验证后把用户 ID、角色注入转发 header。无 Token 或过期返回 401，白名单接口免认证。

请求聚合：一个请求并行调多个后端，结果合并成一个 JSON。聚合规则配置定义。包含 router、auth、aggregator、proxy 模块。编译通过，端口 PORT 环境变量。
