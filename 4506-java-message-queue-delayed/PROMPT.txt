消息量不大每天几十万条，不想搞 Kafka 运维。Java Spring Boot 实现简易消息队列，支持延迟消息和消费组。

Topic 管理：创建、删除、列出，每个 Topic 有保留时长，过期消息后台自动清理，文件持久化重启可恢复。

发布消息往 Topic 发，消息体 JSON。支持普通和延迟消息，延迟消息指定秒数后才可消费（如订单 30 分钟后检查支付）。消息有全局唯一 ID 方便追踪去重。

消费端接口拉取消息，支持消费组，每组独立消费进度。消费成功要 ack，未确认超时重新可消费，同组同条消息只给一个消费者。包含 topic、publisher、consumer、store 模块。Maven 构建，端口配置文件。
