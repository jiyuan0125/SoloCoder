用户画像接口查库 200ms，P99 要求 50ms。Rust axum 做带 TTL 的缓存中间件，其他服务 HTTP 接口读写缓存。

基本操作：set(key, value, ttl)、get(key)、delete(key)。value 任意字符串，key 最长 256 字节，TTL 到期自动删除。过期清理用后台线程定期扫描，不在读写路径判断过期。

缓存总量有上限（可配），满了按 LRU 淘汰，优先淘汰快过期的 key，后台线程执行不影响读写。

防穿透：同一 key 短时间大量 get 不存在时触发保护直接返回空，阈值可配。统计接口提供命中率、请求数、条目数、淘汰次数，最近淘汰 key 保留 100 条。包含 cache、eviction、protection、stats 模块。Cargo build 通过，端口 PORT 环境变量。
