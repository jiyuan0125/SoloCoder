Spring Boot 做一个配置中心，给十来个微服务统一管配置用的。

配置存储：配置按 app + env + key 组织。app 是服务名，env 是环境（dev/staging/prod），key 是配置项名。配置值支持字符串、数字、布尔、JSON 四种类型。每次修改保存历史版本，可以回滚到任意版本。

变更推送：客户端连接后可以 watch 指定的配置 key。配置变更时通过 SSE 推送给所有 watch 的客户端。推送失败（客户端断开）时缓存最近的变更，客户端重连后补推。

灰度发布：支持灰度发布配置。先推给指定的实例（按 IP 或实例 ID），观察一段时间没问题再全量推。灰度中的配置和正式配置隔离。

至少包含 storage、watcher、history、gray 四个模块。Maven 构建，端口配置文件。
