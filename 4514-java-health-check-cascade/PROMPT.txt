Netty 写一个健康检查服务。不只检查服务本身，还要检查它的依赖链是不是健康的。

检查目标：每个服务可以注册多个检查项。检查项类型支持 HTTP 探针（调一个 URL 看返回码）、TCP 探针（连一个端口看通不通）、自定义脚本（执行一段命令看退出码）。每个检查项有自己的超时时间和间隔。

级联状态：服务 A 依赖服务 B，B 依赖数据库。如果数据库挂了，B 的健康状态应该变成 degraded，A 的状态也应该反映这个依赖问题。依赖关系在配置里声明。级联检查不重复执行，B 的结果缓存给 A 用。

状态汇总：每个服务的健康状态由所有检查项的结果综合决定。全部通过是 healthy，部分失败是 degraded，关键检查项失败是 unhealthy。状态变更触发事件，外部可以订阅。

至少包含 checker、cascade、status、event 四个模块。不用 Spring，纯 Netty 做 HTTP 服务。端口启动参数指定。
