Rust axum 做一个认证网关。其他服务把需要认证的请求先发到这里验证。

JWT 验证：网关验证请求里的 JWT Token。Token 从 Authorization header 提取。验证签名、过期时间、issuer。签名密钥通过配置加载，支持 RS256 和 HS256 两种算法。Token 过期前 5 分钟自动在响应头里附加一个新 Token（刷新）。

权限检查：Token 里包含角色信息（role）。每个接口可以配置允许访问的角色列表。管理员角色可以访问所有接口。角色权限配置热加载，改了不用重启。

审计日志：每次认证请求都记录来源 IP、用户 ID、请求路径、认证结果。失败的要记录失败原因（签名错误、过期、权限不足）。审计日志异步写入不阻塞请求。

至少包含 jwt、rbac、audit、config 四个模块。Cargo build 通过，端口 PORT 环境变量。
