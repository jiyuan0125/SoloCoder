Go 标准库写一个协议转换网关。后端有 gRPC 服务，前端只发 HTTP JSON 请求，需要中间转换。

HTTP JSON 转 gRPC：接收前端的 JSON 请求，转换成 gRPC 调用后端服务。Proto 定义文件通过接口上传，网关解析后自动生成映射。路径映射规则：/v1/users 对应 grpc UserService/ListUsers。

gRPC 响应转 JSON：后端 gRPC 返回的 protobuf 消息转成 JSON。嵌套的 message 和 repeated 字段要正确处理。枚举类型转成字符串而不是数字。时间戳转成 ISO 8601 格式。

错误处理：gRPC 的 status code 映射到 HTTP status code。NOT_FOUND→404，ALREADY_EXISTS→409，PERMISSION_DENIED→403，以此类推。gRPC 错误详情里如果有 error info 要一并返回给前端。

至少包含 converter、proto、mapper、error 四个模块。编译通过，端口 PORT 环境变量。
