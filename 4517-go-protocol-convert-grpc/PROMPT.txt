后端用 gRPC 前端只发 HTTP JSON，每次新接口都要写转换代码。Go 标准库写协议转换网关，自动把 HTTP JSON 转 gRPC 调用。

HTTP JSON 转 gRPC：根据映射规则把 JSON 请求转成 gRPC 调用。Proto 文件通过接口上传，网关解析后自动生成路径到方法的映射，如 /v1/users 对应 UserService/ListUsers。

gRPC 响应转 JSON：protobuf 消息转 JSON，嵌套 message 和 repeated 字段正确处理，枚举转字符串不转数字，时间戳转 ISO 8601。

错误处理：gRPC status code 映射 HTTP status code，NOT_FOUND→404、ALREADY_EXISTS→409、PERMISSION_DENIED→403，错误详情一并返回。包含 converter、proto、mapper、error 模块。编译通过，端口 PORT 环境变量。
