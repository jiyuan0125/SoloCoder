Spring Boot 做一个支持会话保持的负载均衡器。有些老系统有会话状态，同一个用户的请求必须打到同一个后端。

会话保持：根据请求里的 Cookie（JSESSIONID）或客户端 IP 做一致性哈希，同一个标识的请求总是路由到同一个后端。后端下线时它的会话自动迁移到其他后端。迁移的时候在新后端重建会话状态。

健康检查：后端探活失败时自动摘除，摘除前先把该后端的会话迁移完。迁移完成后才会把新请求分配给其他后端。迁移过程中的请求暂时排队等待。

动态扩缩：运行时可以添加和移除后端实例。添加新实例后，部分会话会重新分配。重新分配的时候保证不会出现两个后端同时处理同一个会话。

至少包含 balancer、session、health、migration 四个模块。Maven 构建，端口配置文件。
