Go 标准库写一个 API 网关，重点做请求/响应转换。前端和后端的数据格式经常对不上。

请求转换：前端发来的 JSON 格式跟后端需要的可能不同。网关支持配置映射规则，把前端的字段映射到后端的字段。支持字段重命名、类型转换（字符串转数字）、嵌套结构打平。

响应转换：后端返回的数据格式转成前端需要的格式。支持字段过滤（只返回前端需要的字段）、分页格式统一、时间格式统一。错误响应统一格式化。

插件机制：转换规则以插件形式注册。内置 JSON 映射插件和 XML↔JSON 转换插件。自定义插件通过接口加载。插件执行顺序可配置。

至少包含 gateway、transform、plugin、config 四个模块。编译通过，端口 PORT 环境变量。
