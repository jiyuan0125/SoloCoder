Spring Boot 做一个支持优先级的消息队列。报警消息要优先处理，日志消息延后。

优先级队列：消息有优先级（1-10，10 最高）。高优先级消息优先消费。同优先级的按先进先出。消费端一次拉取一批消息，按优先级排序后返回。

死信队列：消费失败超过 3 次的消息自动进入死信队列。死信队列的消息可以手动重新投递或丢弃。死信队列有容量上限，满了后最旧的消息自动丢弃。

消息回溯：支持按时间点回溯消费。指定一个时间戳，从那个时间点开始重新消费。回溯期间正常消息继续生产和消费不受影响。

至少包含 queue、priority、deadletter、replay 四个模块。Maven 构建，端口配置文件。
