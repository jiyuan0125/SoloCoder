不想引入 Kafka 那一套，我们消息量不大，自己实现一个轻量级消息队列就够用了。

报警消息要优先处理，日志消息延后——但现在的消息队列全是 FIFO，紧急消息排不上。Spring Boot 做一个支持优先级的消息队列。

优先级队列：消息有优先级（1-10，10 最高）。消费端一次拉取一批消息，按优先级排序后返回。

死信队列：消费失败超过 3 次的消息自动进入死信队列。

消息回溯：支持按时间点回溯消费。

接口返回统一 JSON 格式，错误响应包含 code 和 message 两个字段。

健康检查接口必须有，返回服务自身状态和依赖组件的状态。

包含 queue、priority、deadletter、replay 模块。
