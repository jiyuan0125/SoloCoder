Rust axum 实现一个支持 LFU 淘汰的缓存中间件。跟 LRU 不一样，LFU 淘汰访问频率最低的。

LFU 淘汰：每个缓存条目维护访问频率计数器。容量满时淘汰频率最低的条目。频率相同的按最近访问时间淘汰（最久没访问的先淘汰）。频率计数器定期衰减（每小时衰减一半），防止旧数据占着高频位。

缓存预热：启动时可以从文件加载预热数据。预热数据的初始频率设为 1。也支持运行时通过接口批量导入缓存。

分片缓存：为了减少锁竞争，缓存内部按 key 的哈希分片。每个分片独立淘汰。分片数可配。跨分片的统计需要聚合。

至少包含 cache、lfu、warmer、shard 四个模块。Cargo build 通过，端口 PORT 环境变量。
