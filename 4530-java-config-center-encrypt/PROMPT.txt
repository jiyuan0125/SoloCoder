Netty 写一个配置中心，敏感配置要加密存储。不依赖 Spring，纯 Java 实现。

配置存储：配置项按命名空间/应用/环境/Key 四级组织。普通配置明文存储。标记为 secret 的配置 AES 加密存储，查询时自动解密。加密密钥通过环境变量注入，启动时校验密钥长度。

版本管理：每次配置变更保存为新版本。支持按版本号回滚。查看两个版本之间的 diff。版本保留最近 100 条，更早的归档到文件。

配置下发：客户端长连接订阅配置变更。变更时主动推送。推送失败重试 3 次，间隔 5 秒。三次都失败后标记该客户端离线，等它重连后补推期间的变更。

至少包含 store、crypto、version、push 四个模块。不用 Spring，Maven 管理依赖，端口启动参数指定。
