之前用 Nginx 做反向代理，配置改了要 reload 太麻烦了。用 Rust/axum 自己写一个，路由规则存内存可以动态改。

代理把收到的请求转发到上游服务。上游地址按路径前缀匹配，比如 /api/* 转到后端A，/web/* 转到后端B。匹配规则支持精确匹配和前缀匹配，长的优先。匹配不到返回 404。

请求转发时要改写 Host header 和添加 X-Forwarded-For。上游响应直接透传回来，包括状态码和所有 header。

代理要定时检查上游健康状态，不健康的自动从路由里摘掉。上游恢复后自动加回来。健康检查间隔可配。

端口通过 PORT 环境变量配置。Cargo build 能过就行。
