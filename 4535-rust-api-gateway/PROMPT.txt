用Rust/tokio写个API网关把这些入口收拢成一个，前端只需要知道网关地址就行了。

路径匹配支持静态路径和带参数的路径，/users/:id/posts会把:id部分提取出来作为路径参数。转发时路径参数要放进转发的querystring或者header里传给下游，具体怎么传在路由配置里指定。

两个请求可以并发发出去，都回来后合并成一个JSON返回给前端。如果某个下游超时或报错，聚合结果里标注该字段为null并附带错误信息。

验证不过直接返回401。

路由配置接口管理：POST/routes添加路由，PUT/routes/:id修改，DELETE/routes/:id删除。GET/routes列出所有路由及其当前状态。

包含 router、auth、proxy、plugin 模块。
