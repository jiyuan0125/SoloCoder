Go 标准库写个认证网关。所有请求先过网关验证身份，验证通过才转发到后端。

JWT token 签发和验证。用户登录接口验证用户名密码后签发 access token 和 refresh token。Access token 有效期短（30分钟），refresh token 有效期长（7天）。

Token 过期前 5 分钟内可以用 refresh token 换新的 access token。旧 refresh token 用过一次就作废。同一个用户同时在多个设备登录，各自 token 独立管理。

黑名单机制：用户登出后 access token 加入黑名单。验证时检查黑名单。黑名单定期清理过期的条目。

端口 PORT 环境变量，go build 能过。
