支持一次性延时任务和周期性定时任务，类似简化版Quartz，Java 实现。

任务注册时指定执行时间和回调URL。回调失败按策略重试——最多3次，间隔10秒、30秒、60秒。

周期性任务支持cron表达式。

任务执行记录持久化到内存。记录包括任务ID、计划时间、实际执行时间、执行结果。查询接口按任务ID查历史和下次执行时间。

提供RESTfulAPI。接口要做参数校验，不合法的请求直接返回400别往下传。分页查询要支持page和page_size参数，默认每页20条，最多100条。

配置变更要有审计日志，记录谁改了什么、改前值和改后值。

包含 scheduler、cron、executor、history 模块。
