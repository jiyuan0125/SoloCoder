业务服务调用外部 API 需要复用连接，每个目标域名独立池，避免连接浪费。Spring Boot 写个 HTTP 连接池管理。

注册目标域名时配置最大连接数、连接超时、读写超时。

池满了新的借出请求排队等待。等待超时返回错误。

内存存储。

健康检查接口必须有，返回服务自身状态和依赖组件的状态。

配置变更要有审计日志，记录谁改了什么、改前值和改后值。

每个池的统计信息：活跃连接数、空闲连接数、等待队列长度、总请求数。

包含 pool、health、config、monitor 模块。
