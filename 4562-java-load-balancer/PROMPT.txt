之前用 Nginx 做负载均衡，但是我们的权重策略比较复杂，Nginx 配置起来太麻烦。用 Spring Boot 2.x（JDK 17，Maven）写一个负载均衡器，自己控制分发逻辑。

后端实例通过接口注册，每个实例带上权重、最大连接数、当前连接数。分发策略支持三种：加权轮询、最少连接数、一致性哈希。一致性哈希按客户端 IP 做键，实例变更时只影响少量键的映射。客户端请求进来后，负载均衡器根据选定的策略选一个后端实例，把请求代理过去，再把响应返回给客户端。

每个实例有个连接计数器，请求开始时加一，请求结束（不管成功失败）减一。同一个实例的连接数达到上限后不再分配新请求，转到其他实例。权重为 0 的实例不参与分发，但仍然保留在列表里。

策略可以按服务粒度配置，不同服务用不同策略。配置通过数据库管理，有接口可以查看和修改。端口通过环境变量 PORT 指定，能正常编译启动就行。
