线上的 API 经常被爬虫打爆，现有的限流不够灵活。用 Rust + axum 写一个独立的限流器服务，支持多种限流算法。

提供接口给每个客户端（用 API Key 标识）配置限流规则，规则包括：算法类型（固定窗口、滑动窗口、令牌桶）、窗口大小或桶容量、每次请求消耗的令牌数。客户端请求进来时带上 API Key，限流器判断是否允许通过，允许就转发到后端，不允许返回 429。

令牌桶模式下，桶里的令牌按固定速率恢复，满桶不再增加。滑动窗口用时间片实现，精度到秒级。固定窗口按自然分钟计数，窗口结束瞬间重置。三种算法可以给同一个客户端同时配置，任一算法触发限流就拒绝。

所有计数数据放在内存里，用 HashMap 管理。限流规则支持通过接口动态增删改。端口通过环境变量 PORT 指定。cargo build 能编译通过。
