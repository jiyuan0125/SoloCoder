不是给某个接口加中间件——是所有服务调用的独立限流网关。不同团队用各自的 API Key，规则各不相同，Rust 实现。

每个客户端用 API Key 标识，限流器为每个客户端维护独立规则。请求携带 API Key，限流器检查所有规则，全部通过才转发，任一触发限流返回 429，响应体带剩余配额和重试时间。

三种算法：固定窗口（按自然分钟计数）、滑动窗口（秒级时间片数组，精度高）、令牌桶（固定速率恢复，允许突发）。三种可同时配置同一客户端，"与"关系全放行才算。计数数据放内存 HashMap，key 是 API Key 加算法类型。规则接口动态增删改。

包含 limiter、window、rule、config 模块。
