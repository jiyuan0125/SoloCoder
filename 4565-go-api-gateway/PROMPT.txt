新来的架构师review了一轮系统之后，是当前最大的单点风险，优先级提到了P0，Go 实现。

网关的，每条规则定义：路径模式（支持通配符和路径参数）、目标服务地址、需要的认证级别（公开、需登录、需管理员）、请求转换规则。请求进来后先做路径匹配，匹配到了检查认证级别，需要认证的从header里取token验证，验证失败返回401。

登录用户用JWTtoken标识，网关负责验证签名和过期时间。

有个聚合接口，一个请求可以并发调用多个后端服务，把结果合并成一个JSON返回。后端服务可以管理接口动态注册和注销。配置存在JSON文件里，启动时加载。

包含 router、auth、proxy、plugin 模块。
