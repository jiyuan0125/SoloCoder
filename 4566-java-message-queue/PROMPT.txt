调研了一圈消息队列，RabbitMQ 和 Kafka 对我们来说都太重了。用 Spring Boot 2.x（JDK 17，Maven）自己写一个轻量级消息队列，支持发布订阅模式。

消息发布者往 Topic 发消息，消息体就是 JSON 字符串。每个 Topic 可以有多个消费者组，每个组内的消费者共享消费进度（同一条消息只被组内一个消费者处理），不同组之间独立消费。消息持久化用本地文件，追加写入，启动时从文件恢复未消费的消息。

消费者通过长轮询拉取消息，如果 Topic 里没有新消息就等 30 秒再返回空。消费成功后消费者要确认（ACK），超时 60 秒未确认的消息重新入队。消息有全局递增 ID，消费者可以按 ID 做幂等去重。

有个管理接口可以查看 Topic 列表、每个 Topic 的消息堆积量、消费者组的消费进度。支持通过接口创建 Topic 和消费者组。端口环境变量 PORT 指定，能编译启动就行。
