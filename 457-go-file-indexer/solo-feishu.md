| User Prompt | 写一个Go文件内容索引库，给知识库和文档管理系统提供全文搜索能力，替代外部搜索引擎降低部署复杂度。给定目录路径递归扫描所有文本文件建立倒排索引。输入关键词返回包含这些词的文件列表按匹配度排序。索引数据序列化保存到文件，下次启动直接加载不用重新扫描。支持增量更新：通过比较文件修改时间判断哪些新增或修改了，只对变化的重新建索引，已删除的从索引中移除。搜索时关键词包含特殊字符当普通字符处理不报错。二进制文件（图片、压缩包等）扫描时根据文件头魔数判断跳过不建索引，不尝试用UTF-8解码来判断。索引文件中存储的词要小写化，搜索时也先小写化再匹配，实现大小写不敏感搜索。文件权限不足无法读取时记录警告继续处理其他文件不中断扫描。支持短语搜索——用双引号包裹的多个词必须连续出现在文档中才算匹配，而不仅仅是每个词都出现。索引文件格式用高效的二进制序列化（如gob）而不是JSON，减少磁盘占用和加载时间。搜索结果展示匹配行上下文——文件名、行号和匹配行内容。 拆成三部分：核心功能是一个独立package，服务端程序引用核心库对外提供HTTP接口，客户端是命令行工具通过HTTP与服务端通信。服务端和客户端各自有独立main包，消息结构体定义在公共包。各部分按职责分文件。先go mod init再开发，go build ./...能编译通过。 本项目属于跨系统多模块架构。 |
