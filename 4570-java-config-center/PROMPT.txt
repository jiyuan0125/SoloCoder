现在各服务的配置散落在配置文件和环境变量里，改一次要重启好几个服务。用 Spring Boot 2.x（JDK 17，Maven）做个配置中心，集中管理所有服务的配置。

配置按服务名和环境分组，每条配置就是 key=value。支持版本管理，每次修改保存为新版本，可以查看某个 key 的历史变更。有接口按服务名查询当前生效的全部配置，返回 JSON。客户端可以 watch 某个 key，配置变更时主动通知订阅的客户端。

通知机制用长轮询，客户端发起 watch 请求后挂起，配置变了立即返回新值，30 秒没变也返回空表示无变化。配置可以打标签（比如 canary、stable），灰度发布时只推给带 canary 标签的实例。灰度确认后一键全量发布。

如果推送通知失败（客户端不可达），记录失败日志，下次客户端主动拉取时把未送达的变更一起返回。端口通过环境变量 PORT 指定。
