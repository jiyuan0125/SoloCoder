之前那个 API 网关只支持路由转发，现在要加上限流、认证、请求转换这些中间件能力。用 Python aiohttp（async）写一个增强版 API 网关。

网关的请求处理流程是一个中间件链：认证→限流→请求转换→转发→响应转换。每个环节可以独立配置开关。认证支持 API Key 和 HMAC 签名两种方式。限流用令牌桶算法，每个客户端独立配额。请求转换支持 header 增删改和 body 的 JSON 字段映射。

路由规则支持路径参数，比如 /api/users/{user_id}/orders 匹配后把 user_id 提取出来。同一路径支持多个后端版本，按权重分配。后端实例通过接口注册，健康检查每 10 秒执行一次。

所有配置通过接口管理，有版本号，支持回滚。请求经过每个中间件时都记录日志（耗时、结果），方便排查。如果中间件链中某个环节出错，直接返回错误不继续往下走。端口环境变量 PORT 指定。
