线上用 Kafka 但有些场景不需要那么重，需要一个轻量级消息代理来处理内部异步通信。用 Spring Boot 2.x（JDK 17，Maven）写一个。

Topic 通过接口创建，创建时指定分区数（默认 4）。消息发送到 Topic 时指定分区策略：轮询、按 key 哈希、指定分区。消息持久化到本地文件，每个分区一个文件，顺序追加写。消息有递增的 offset（分区内递增）。

消费者组订阅 Topic，组内消费者均衡分配分区。消费模式：自动提交（消息投递后立即确认）和手动提交（消费者确认后才能投递下一条）。未确认的消息超时 120 秒后重新投递。连续投递 5 次都被拒绝的消息进入死信 Topic，名字是原 Topic 名加 .dlq 后缀。

消费者断开连接后，它负责的分区重新分配给组内其他消费者。消费进度保存在代理端，消费者重启后从上次的位置继续。Topic 状态（消息量、各分区 offset、消费者组进度）通过接口查询。端口环境变量 PORT 指定。
