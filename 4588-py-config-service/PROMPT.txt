现在配置文件满天飞，格式还不统一（YAML、JSON、properties 都有）。用 Python FastAPI（async）写一个配置服务，统一管理。

配置按 namespace/environment/key 三级组织。每个 key 对应一个值（字符串），值的类型由客户端自己解释。配置有版本号，每次修改递增。查询时可以指定版本，不指定就返回最新版。返回值里带上版本号和最后修改时间。

支持灰度发布：给配置打上灰度标签，指定哪些实例（按 instance_id 列表）能看到新值，其他实例还是看到旧值。灰度确认后全量发布，所有实例看到新值。灰度期间如果再次修改，新修改也走灰度流程。

客户端通过长轮询 watch 配置变更：发请求带当前版本号，版本没变就挂起等待，变了立即返回新值。同一个 key 的 watcher 用 list 管理，变更时逐个通知。如果通知过程中某个 watcher 的连接已经断了，跳过不重试，等它下次主动拉取。

配置导出支持 JSON 和 YAML 格式。端口环境变量 PORT 指定。
