开放平台对外暴露的 API 被刷得厉害，需要按维度限流。用 Go Gin 写一个独立的限流服务。

限流维度支持三种组合：按 IP、按用户 ID、按 API 路径。可以叠加使用，比如同一 IP 对同一 API 每分钟最多 100 次。限流算法用滑动窗口。超出限制返回 429，响应头里带上剩余配额和重试等待时间。

限流规则通过接口配置，支持增删改查。规则修改后立即对新请求生效。已有的计数器不清零。同一个请求命中多条规则时，所有限制都要满足。限流检查内部需要记录日志，日志记录也要访问同一个计数器。

有个统计接口可以看每条规则当前的计数、通过数、拒绝数。统计支持重置。可能同时有大量请求打到同一条规则上。规则数量可能上千。端口环境变量 PORT 指定，go build 能编译通过。
