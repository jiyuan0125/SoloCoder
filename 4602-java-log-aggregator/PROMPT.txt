各个微服务的日志到处都是，出问题排查全靠 SSH 上去 grep。用 Spring Boot 2.x（JDK 17，Maven）写一个集中式日志聚合服务。

服务通过 HTTP 接口接收日志，日志体是 JSON，必填字段：service_name、level、message。支持批量提交，单次最多 500 条。服务端给每条日志生成唯一 ID 和入库时间。

查询接口支持按服务名、级别、时间范围、关键词搜索。关键词在 message 和 tag 字段中匹配。返回结果分页。还有个聚合接口，按服务统计各级别日志数量，支持按小时或按天分组。

用户可以自定义标签名来给日志打标签，标签通过查询参数传入。管理接口允许创建和维护日志告警规则，规则里可以指定匹配条件。日志存储用本地 SQLite。端口环境变量 PORT 指定，能编译启动。
