灰度发布的时候需要把特定用户的流量打到新版本上，现在全靠运维手动改 Nginx 配置。用 Spring Boot 2.x（JDK 17，Maven）写一个流量染色服务。

染色规则：按请求头、Cookie、用户 ID 列表等条件匹配请求，匹配到的请求打上染色标签（如 x-gray-tag: v2）。标签通过 HTTP Header 传递到下游服务。

规则管理接口支持增删改查。规则有优先级，高优先级先匹配。一条规则可以包含多个条件，条件之间是 AND 关系。条件类型支持：Header 匹配（精确/前缀/正则）、Cookie 匹配、用户 ID 白名单、百分比（按比例染色）。

染色结果记录到日志，统计接口可以看到每条规则的匹配次数、染色次数。还可以查看一段时间内的染色流量趋势。规则变更后立即对新请求生效。

用户可以自定义新的条件类型。条件匹配逻辑和规则引擎分开实现。端口环境变量 PORT 指定，能编译启动。
