老系统用 SOAP/XML，新系统用 REST/JSON，中间需要一个协议转换层。用 Rust axum 写一个协议转换网关。

XML 转 JSON：接收 XML 请求体，解析成结构化数据，再序列化为 JSON 返回。JSON 转 XML：反向操作。转换规则：XML 元素变成 JSON 对象的字段，属性加 @ 前缀（如 id 变 @id），文本内容用 #text 键。嵌套元素递归处理。XML 数组（同名兄弟元素）转成 JSON 数组。

支持批量转换：一次提交多个文档，每个独立转换，部分失败不影响其他。转换结果包含成功数、失败数和每条的详细信息。单个文档大小限制 1MB，超出的返回错误。

还有个 Schema 验证功能：可以预定义 XML 和 JSON 的结构模板，转换前用模板校验输入。校验失败返回具体的字段错误信息。模板通过接口管理。可能收到格式完全不合法的输入，也可能收到超大文档。端口环境变量 PORT 指定，cargo build 能编过。
