网络抖动导致请求失败，业务不知道该不该重试，重试了怕重复。用 Go Gin 写一个重试与幂等控制服务。

客户端发请求时带上幂等键（idempotency key），服务端记录 key 和处理结果。相同 key 的请求直接返回之前的结果，不重复执行业务逻辑。幂等记录有 TTL（默认 24 小时），过期后 key 可复用。

重试策略配置：最大重试次数、重试间隔（固定/指数退避）、可重试的错误类型。客户端提交任务后，服务端执行并在失败时按策略自动重试。重试次数用完后标记为彻底失败。

任务状态：待执行、执行中、成功、失败、重试中。每个状态变更记录时间戳。查询接口可以按幂等键查任务状态和执行历史。

服务端执行的具体操作是 HTTP 调用外部服务。调用地址通过配置指定。任务量可能很大，需要持久化到本地文件（JSON Lines）。端口环境变量 PORT 指定，go build 能编译通过。
