需要定时触发的任务越来越多，cron写多了自己也搞不清哪个该跑哪个跑过了，Java 实现。

调度任务支持三种触发方式：一次性定时（指定时间执行一次）、周期性（Cron表达式）、延迟执行（提交后延迟N秒执行）。任务提交时指定执行参数（JSON格式）和回调URL，执行时把参数POST到回调地址。

任务状态：待执行、执行中、成功、失败。任务执行记录保留最近10000条。

有个查询接口可以看当前待执行的任务列表、已完成的任务历史、失败的任务。支持按状态和时间范围过滤。

管理接口支持暂停/恢复调度器、手动触发指定任务、取消待执行的任务。

包含 scheduler、cron、executor、history 模块。
