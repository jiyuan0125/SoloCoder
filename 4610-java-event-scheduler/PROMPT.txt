需要定时触发的任务越来越多，cron 写多了自己也搞不清哪个该跑哪个跑过了。用 Spring Boot 2.x（JDK 17，Maven）写一个事件调度器。

调度任务支持三种触发方式：一次性定时（指定时间执行一次）、周期性（Cron 表达式）、延迟执行（提交后延迟 N 秒执行）。任务提交时指定执行参数（JSON 格式）和回调 URL，执行时把参数 POST 到回调地址。

任务状态：待执行、执行中、成功、失败。执行失败的任务按配置决定是否重试。任务执行记录保留最近 10000 条。

有个查询接口可以看当前待执行的任务列表、已完成的任务历史、失败的任务。支持按状态和时间范围过滤。

管理接口支持暂停/恢复调度器、手动触发指定任务、取消待执行的任务。调度器重启后从持久化存储（本地 SQLite）恢复未完成的任务。多实例部署时同一任务只会被一个实例执行。端口环境变量 PORT 指定，能编译启动。
