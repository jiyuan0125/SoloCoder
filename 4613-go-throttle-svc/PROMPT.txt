API 开放平台的调用量需要按多个维度控制，单机限流扛不住。用 Go 标准库写一个分布式限流服务。

限流规则分为全局规则和用户规则。全局规则限制所有请求总量，用户规则限制单个用户的调用量。两者独立生效，用户的请求必须同时满足全局和用户维度。算法用令牌桶。

令牌桶参数：桶容量、填充速率（每秒填充数）。全局桶和每个用户独立一个桶。桶的状态（当前令牌数、最后填充时间）持久化到本地文件，重启后恢复。恢复时根据时间差补偿填充令牌，但不超过桶容量。

规则管理通过接口操作：创建、更新、删除、查询。更新规则时如果桶容量变小了，当前令牌数超过新容量的立即裁剪。用户首次请求时自动创建该用户的桶。

统计模块独立实现，记录每条规则的通过数和拒绝数，每分钟聚合并可通过接口查询。实现分为规则引擎、桶管理、存储层、统计模块四个独立文件。端口环境变量 PORT 指定，go build 能编译通过。
