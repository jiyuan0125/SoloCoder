数据库查询太频繁，加个缓存层缓解压力。用 Go Gin 写一个缓存中间件服务。

缓存存储支持内存和文件两种后端，通过配置选择。内存后端用 LRU 淘汰，文件后端用 JSON 文件持久化。两种后端共享统一的 CacheStore 接口，缓存项结构包含 key、value（string）、过期时间、创建时间、标签列表。

标签失效机制：每个缓存项可以关联多个标签。调用标签失效接口时，该标签下所有缓存项标记为无效。标签关联关系单独维护（标签到 key 集合）。

缓存穿透保护：查询不存在的 key 时，缓存一个空值（TTL 较短，默认 5 分钟），防止反复穿透到数据库。缓存击穿保护：热点 key 过期时，只允许一个请求去回源，其他请求等待结果。

统计模块记录命中率、总请求数、标签失效次数。分为存储层、标签索引层、防护层、统计层、HTTP 接口层五个模块。端口环境变量 PORT 指定，go build 能编译通过。
