容器环境下服务实例频繁上下线，服务发现需要实时更新。用 Rust axum 写一个服务发现中心。

实例注册时提供：服务名、实例 ID、地址、元数据 map。同一服务名下可以注册多个实例。实例 ID 是服务名下的唯一标识。注册时如果 ID 已存在则更新，否则新增。

心跳机制：实例每 5 秒发一次心跳。15 秒无心跳标记为不健康。不健康的实例 30 秒后自动注销。多个实例可能同时注册、同时心跳、同时超时注销。

服务发现接口：按服务名查询所有健康实例，返回地址列表。支持按元数据过滤（如只返回 version=v2 的实例）。客户端可以订阅服务变更通知（WebSocket），变更包括实例上线、下线、状态变化。

有个管理接口可以手动注销实例、查看所有服务及其实例状态。服务端重启后从持久化文件恢复注册信息。端口环境变量 PORT 指定，cargo build 能编过。
