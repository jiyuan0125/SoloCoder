服务多了配置管理成了大问题，改个配置要一个一个服务重启。用 Python FastAPI（async）写一个配置中心，支持变更推送。

配置按 namespace/group/key 三级组织。每个 key 对应一个值和版本号。值的 schema 由 namespace 级别的模板定义，写入时校验值是否符合模板。模板支持 string、number、boolean、enum 类型。

变更推送：客户端订阅感兴趣的 namespace 或 group，变更时通过 WebSocket 推送变更事件。事件包含变更的 key、新旧值、版本号。推送模块维护订阅者列表和 WebSocket 连接池。

配置历史：每次变更保留历史记录，支持回滚到指定版本。回滚也是一次变更操作，会触发推送。

权限控制：namespace 有管理员和只读用户。管理员可以修改配置和模板，只读用户只能查询和订阅。用户和权限信息存储在单独的模块中。项目分为配置存储模块、schema 模板模块、变更推送模块、权限模块、HTTP 接口模块。端口环境变量 PORT 指定。
