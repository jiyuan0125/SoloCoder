公司要搞统一API网关，用Gin框架。

每个请求进来先校验JWTToken，从Token里解析出用户角色，注入到转发的Header里（X-User-Role）。如果Token过期或无效直接返回401。

健康检查接口必须有，返回服务自身状态和依赖组件的状态。

提供RESTfulAPI。接口要做参数校验，不合法的请求直接返回400。分页查询要支持page和page_size参数，默认每页20条。

后端服务的地址配置在一个JSON文件里，包括服务名和对应的URL列表。路由设计要注意：/api/v1/users/{id}/profile和/api/v1/users/{id}/orders是两个不同的聚合接口，路径解析要精确。

包含 router、auth、proxy、plugin 模块。
