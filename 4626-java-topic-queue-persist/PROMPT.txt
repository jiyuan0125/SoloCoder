有个场景需要进程内的消息队列，用 Spring Boot 2.x（JDK 17，Maven）实现。

支持 Topic 模式的发布订阅。发布者往 Topic 发消息，所有订阅了该 Topic 的消费者组都能收到。每个消费者组内部只有一条消息被消费（负载均衡）。消息要持久化到本地文件，服务重启后能恢复未消费的消息。

消费者消费失败的消息进入重试队列，最多重试3次，每次间隔递增（5秒、15秒、45秒）。3次都失败的消息进入死信队列，不再自动投递。

还有个场景：如果消息的 Topic 不存在，发布消息的时候应该自动创建 Topic 还是静默丢弃？这个你来定。

提供 Topic 管理、消息发送、消费者注册的 HTTP 接口。端口通过 application.properties 或环境变量 SERVER_PORT 配置。
