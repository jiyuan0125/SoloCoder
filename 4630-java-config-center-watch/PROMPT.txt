用 Spring Boot 2.x（JDK 17，Maven）做一个轻量级配置中心。

配置以 KV 形式存储，每个配置项有 key、value、版本号、修改时间。客户端可以通过接口读取配置、写入配置、查看配置变更历史。每次修改配置，版本号自增。

支持 Watch 功能：客户端通过长轮询接口订阅某个 key 的变更，如果该 key 在 30 秒内被修改了，立即返回新值；没修改就等到 30 秒超时返回"无变更"。

配置回滚：可以指定回滚到某个历史版本。回滚操作本身也是一次变更，会产生新的版本号。

如果同一个 key 被多个客户端同时修改，后写入的应该覆盖先写入的，但所有修改历史都要保留。端口通过 application.properties 或环境变量 SERVER_PORT 配置。
