灰度发布需要流量染色，用 FastAPI（async）做一个灰度网关。

网关根据请求中的灰度标记（HTTP Header X-Gray-Tag）决定把流量路由到哪个版本的上游服务。有灰度标记的请求转发到灰度版本，没有标记的转发到正式版本。

灰度规则支持按用户 ID 百分比分流：配置一个百分比值，用户 ID hash 后落在范围内就走灰度。百分比可以在运行时通过接口调整。

灰度标签需要透传到下游服务，网关在转发请求时自动带上灰度标记。

有个问题还没定：如果一个请求既带了灰度 Header，用户 ID 又命中了百分比分流规则，以哪个为准？上游服务的地址格式也没确定，可能是一个 URL 也可能是多个。端口 PORT 环境变量。
