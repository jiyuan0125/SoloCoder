用 Go 的 Fiber 框架做一个路径重写代理。

代理接收请求后，根据配置的规则重写 URL 路径再转发到上游。比如把 /v1/api/users/{id} 重写成 /internal/users/{id}。重写规则支持路径段替换和正则匹配。

同时代理自带限流功能，对每个路径前缀独立计数，比如 /v1/api/users 每分钟最多100次请求。限流用固定窗口算法。

代理转发的时候要把原始请求的 Host 头改成上游的地址，但保留客户端的 IP 在 X-Forwarded-For 里。请求体超过 10MB 的直接拒绝。

路径匹配优先级：精确匹配 > 前缀匹配 > 正则匹配。如果多条规则都能匹配上，选最具体的那个。端口 PORT 环境变量。
