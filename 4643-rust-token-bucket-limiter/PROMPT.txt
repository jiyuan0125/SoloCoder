用 Rust 的 axum 做一个多速率令牌桶限流器。

限流器管理多个令牌桶，每个桶对应一个 API 路径。比如 /api/v1/users 每秒100个令牌，/api/v1/orders 每秒50个令牌。每个桶独立填令牌，互不影响。

桶的容量（burst size）和填充速率通过接口配置。请求进来时从对应桶里取一个令牌，桶空了就返回 429。

支持突发流量：桶满的时候允许一次性消耗多个令牌（burst），但桶不能透支到负数。

桶的状态需要持久化，服务重启后恢复到重启前的水位。但持久化不能影响限流的性能。

令牌桶的配置可以热更新，更新后新的速率立即生效，但已有的令牌数量保持不变。端口 PORT 环境变量。
