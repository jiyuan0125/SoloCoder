第三方接口有调用频率限制，超了就封禁我们，损失很大。

不同接口的限流策略不一样，有的是突发型有的是匀速型，令牌桶可以同时满足。需要一个多速率令牌桶限流器，Rust axum 实现。

限流器管理多个令牌桶，每个桶对应一个 API 路径。比如 /api/v1/users 每秒100个令牌，/api/v1/orders 每秒50个令牌。

桶的容量（burst size）和填充速率接口配置。请求进来时从对应桶里取一个令牌，桶空了就返回 429。

支持突发流量：桶满时允许一次性消耗多个令牌（burst），但桶不能透支到负数。

健康检查接口必须有，返回服务自身状态和依赖组件的状态。

包含 limiter、bucket、rule、config。
