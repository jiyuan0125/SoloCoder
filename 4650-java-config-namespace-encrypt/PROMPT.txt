用 Spring Boot 2.x（JDK 17，Maven）做一个多环境配置中心。

支持多个命名空间（namespace），比如 dev、staging、prod，每个命名空间有独立的配置 KV 集合。同一个 key 在不同命名空间可以有不同的值。

敏感配置（如数据库密码、API Key）需要加密存储。加密使用 AES-256，密钥通过环境变量注入（ENCRYPTION_KEY）。返回敏感配置时脱敏显示（如 db.secret 显示为 db.se***）。

配置变更审计：每次配置的增删改都要记录谁在什么时间改了什么，包括旧值和新值。审计日志不可删除，只能查询。

命名空间的管理操作包括创建、删除（会删除该命名空间下所有配置）、查看配置列表。删除操作需要二次确认——传入一个 confirm 参数，值为 true 才真正删除。

提供接口按命名空间查询所有配置、按 key 查询单个配置、创建/更新配置、查看审计日志。端口通过 application.properties 或环境变量 SERVER_PORT 配置。
