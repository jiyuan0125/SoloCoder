用 Go 标准库 net/http 写一个限流器服务，对不同的 API 路径分别做速率限制。

每个限流规则针对一个路径前缀，配置允许的每秒请求数和突发容量。规则通过管理接口动态添加和修改，修改后立即生效。请求进来先匹配路径前缀，前缀最长的规则优先。匹配到规则后做令牌桶限流：桶里有令牌就放行并消耗一个，桶空了就返回 429，响应体里带上 Retry-After 头表示多久后重试。

没有匹配到任何限流规则的请求直接放行不做限制。令牌桶按配置的速率匀速补充，补充到突发容量上限为止。

限流维度支持两种模式：全局限流（所有请求共享一个桶）和按 IP 限流（每个客户端 IP 一个桶）。按 IP 限流时，同一个 IP 的请求共享该 IP 的桶，不同 IP 之间互不影响。长时间没有请求的 IP 桶（超过 10 分钟）要回收，不能一直占内存。

所有被拒绝的请求记录到日志，包括时间、路径、客户端 IP。有个查询接口能看最近 100 条被拒绝的记录。端口环境变量 PORT 指定，go build 能编译通过。
