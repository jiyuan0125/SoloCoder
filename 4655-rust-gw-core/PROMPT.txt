用 Rust axum 写一个简易 API 网关，统一处理后端多个微服务的请求路由和认证。

路由配置按路径前缀匹配，每个前缀对应一个后端服务地址。路径匹配支持单层通配符（如 /api/*/health）和精确路径。请求匹配到路由后，网关在转发前做认证校验：检查请求头里的 Authorization token，token 格式是 "Bearer {jwt}"。JWT 用 HMAC-SHA256 签名，密钥通过环境变量配置。token 过期或签名不对就返回 401。

认证通过后，网关给请求加一个 X-Request-Id 头（UUID v4），然后转发到后端。后端响应原样返回给客户端。如果后端在 5 秒内没响应，网关返回 504。

管理接口可以增删改查路由规则。路由变更后立即生效。还有个统计接口，记录每个路由的请求总数和平均响应时间。如果某个路由连续 10 次请求都超时，自动标记为降级状态，后续请求直接返回 503 而不是转发。管理员可以手动恢复。端口环境变量 PORT 指定，cargo build 能编译通过。
