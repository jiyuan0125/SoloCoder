用 Go Gin 写一个分布式缓存代理服务，应用层访问缓存的统一入口。

缓存以 key-value 形式存储，value 是字符串。每个 key 可以设 TTL（秒），过期自动删除。支持的基本操作：Get、Set、Delete。Set 时如果 key 已存在就覆盖。Get 时如果 key 不存在或已过期返回 miss。

缓存淘汰策略支持 LRU 和 LFU 两种，通过管理接口切换。切换策略时清空现有缓存数据。最大缓存条目数通过配置指定（默认 10000），满了按淘汰策略淘汰最旧的。

有个缓存预热功能：可以上传一组 key-value 对批量写入缓存。预热过程中如果某个 key 写入失败（比如超出了限制），跳过继续写下一个，最后返回成功和失败的数量统计。

缓存变更通知：应用可以注册 watcher 监听某个 key 的变更。key 被修改或删除时通知所有 watcher。通知方式是向 watcher 注册的回调 URL 发 POST 请求。如果回调失败（超时或非 200），最多重试 2 次，间隔 1 秒。通知过程中如果 watcher 回调的响应很慢，不要阻塞其他 watcher 的通知。

还有个统计接口：命中率（Get 命中数 / Get 总请求数）、当前条目数、总内存估算（按 value 长度累加）。端口环境变量 PORT 指定，go build 能编译通过。
