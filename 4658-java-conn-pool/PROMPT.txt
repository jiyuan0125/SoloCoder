用 Spring Boot 2.x（JDK 17，Maven）写一个 HTTP 连接池管理服务，统一管理到各个上游服务的连接资源。

每个上游服务对应一个连接池，配置最大连接数、最小空闲连接数、连接超时时间、空闲超时时间。连接池通过管理接口创建，创建后立即初始化最小空闲连接数。连接用 URL 标识，包含协议、主机和端口。

获取连接时，如果池里有空闲连接就直接用，没有空闲但没到上限就新建，到上限了就排队等待。等待有超时（默认 5 秒），超时返回错误。连接用完后必须归还，归还时做健康检查（简单的 socket 连通性测试），不健康的直接丢弃。空闲超过空闲超时时间的连接，后台任务定期清理，但至少保留最小空闲连接数。

连接池状态有：运行中、暂停、已关闭。暂停时不接受新的获取请求，已有的连接继续用完后归还。关闭时等待所有在用连接归还后释放资源。

有个统计接口查看每个连接池的：总连接数、空闲连接数、在用连接数、等待获取的请求数。还有个操作接口可以手动触发连接池的健康检查，批量验证所有空闲连接。端口环境变量 PORT 指定，能编译启动就行。
