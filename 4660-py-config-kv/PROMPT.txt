用 Python FastAPI（async）写一个配置中心服务，统一管理各服务的运行时配置。

配置按 namespace/key 两级组织。每个 key 有一个字符串值和版本号，修改时版本号递增。支持的历史版本保留最近 10 个，可以通过接口查询指定版本。

变更推送：客户端通过 SSE 连接 watch 指定的 namespace，namespace 内任何 key 变更时推送变更事件（包含 key、新值、版本号）。同一个 namespace 可以有多个 watcher。watcher 断开后自动清理。如果推送时某个 watcher 连接已关闭，跳过不重试。

配置可以打标签，比如给某个 key 标记为 "secret"，标记为 secret 的 key 在查询接口返回时值被掩码处理（只显示前 4 位）。创建和修改时需要提供完整的明文值，存储还是存原文，只是查询时掩码。

有个导入接口，支持 JSON 格式批量导入配置。导入时如果 key 已存在可以选择跳过或覆盖（通过参数控制）。导入完成后返回成功导入数、跳过数和失败数。如果导入的 namespace 不存在，自动创建。

客户端用户可以在配置值里写表达式引用其他 key 的值，格式自定。解析的时候需要展开引用。端口环境变量 PORT 指定。
