用 Python FastAPI（async）写一个健康检查服务，定期探测各个服务的存活状态。

被探测的服务通过接口注册，注册时提供：服务名、探测地址（URL）、探测方式（HTTP/TCP）、探测间隔（秒）、超时时间（秒）。HTTP 探测就是 GET 请求，期望返回 200。TCP 探测就是建立 TCP 连接，连上就算健康。探测间隔最小 5 秒。

每个服务的健康状态有三种：健康、不健康、未知。新注册的服务初始状态是未知。第一次探测成功变健康，失败变不健康。连续 3 次探测失败从健康变为不健康。连续 2 次成功从不健康恢复为健康。

探测结果记录最近 100 次历史，包括每次探测的时间、结果（成功/失败）、响应时间（HTTP）或连接时间（TCP）。查询接口返回指定服务的当前状态和最近 N 次探测历史。

依赖关系：服务之间可以有依赖（A 依赖 B），通过接口配置。如果 B 变成不健康，A 的状态自动标记为"降级"（不是不健康，表示服务本身没问题但依赖有问题）。依赖是传递的：A 依赖 B，B 依赖 C，如果 C 不健康，A 和 B 都降级。

有个全局概览接口展示所有服务的状态树，一目了然看到哪些服务有问题以及它们的依赖链。端口环境变量 PORT 指定。
