用 Go 标准库 net/http 写一个认证网关，处理用户的登录认证和接口鉴权。

用户通过接口注册账号（用户名和密码），密码存储前做哈希处理。登录接口验证用户名密码，成功后返回一个 JWT token。token 包含用户 ID、角色和过期时间，用 HMAC-SHA256 签名。token 有效期默认 2 小时。token 快过期时（剩余不到 30 分钟），可以通过刷新接口换取新 token。

角色权限：系统有三种角色：admin、operator、viewer。每个 API 路径配置允许访问的角色列表。admin 可以访问所有接口。operator 可以访问业务接口但不能管理用户。viewer 只能查看不能修改。角色通过管理接口分配，只有 admin 能分配角色。

请求鉴权流程：网关拦截所有受保护的请求，从 Authorization 头提取 token，验证签名和过期时间。token 有效则根据 token 中的角色和请求路径判断是否有权限，无权限返回 403。未登录用户访问受保护接口返回 401。

审计日志：每次鉴权操作（登录、鉴权成功、鉴权失败）都记录到审计日志，包括时间、用户 ID（如果有的话）、请求路径、结果。审计日志按天存储到文件。有个查询接口可以按时间范围和用户 ID 检索审计记录。

用户可以修改自己的密码，修改后旧 token 不受影响（仍然可用直到过期）。管理员可以禁用账号，禁用后该用户的所有 token 立即失效。端口环境变量 PORT 指定，go build 能编译通过。
