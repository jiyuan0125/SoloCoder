用 Rust actix-web 写一个协议转换网关，在 HTTP 和自定义二进制协议之间做转换。

后端服务使用自定义二进制协议通信，网关对外暴露 HTTP 接口，内部把 HTTP 请求转换成二进制协议发给后端，再把二进制响应转回 HTTP JSON 响应。

二进制协议格式：4 字节魔数（0xABCD）、2 字节消息类型、4 字节序列号、4 字节负载长度、N 字节负载、2 字节 CRC 校验。消息类型有：QUERY（1）、UPDATE（2）、DELETE（3）、RESPONSE（0x81）。负载是 JSON 字符串。

HTTP POST /api/{resource} 映射到 QUERY 类型，POST /api/{resource}/{id} 映射到 UPDATE 类型，DELETE /api/{resource}/{id} 映射到 DELETE 类型。网关维护一个自增序列号，每个请求的序列号唯一。收到后端响应后校验 CRC，校验不通过返回 502。

网关与后端的连接用 TCP 长连接，空闲超时 60 秒。连接断开后自动重连。请求超时 5 秒，超时返回 504。并发请求通过序列号匹配响应和请求。

管理接口可以查看网关状态：连接状态、已处理请求总数、各类型的请求数、错误数（CRC 校验失败、超时、连接断开）。端口环境变量 PORT 指定，cargo build 能编译通过。
