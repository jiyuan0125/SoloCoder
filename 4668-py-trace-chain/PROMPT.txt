用 Python aiohttp（async）写一个请求链路追踪服务，记录一次请求在多个服务间的调用链。

每次外部请求进入系统时生成一个 Trace ID（UUID v4）。请求在服务间传递时，每个服务生成一个 Span ID，并记录：Trace ID、当前 Span ID、父 Span ID（调用方的 Span ID）、服务名、操作名、开始时间、结束时间、状态（OK/ERROR）、附加标签（KV 对）。Span 数据通过接口上报到追踪服务。

追踪服务收到 Span 后存起来。同一个 Trace ID 的所有 Span 组成一条完整的调用链。查询接口通过 Trace ID 查询完整调用链，按时间排序，并构建调用树（根据父子关系）。返回格式包含调用深度和每层的服务名、操作名、耗时。

统计接口：统计指定时间范围内各服务的平均响应时间、错误率、P95 耗时。还可以查慢请求：耗时超过指定阈值（默认 1 秒）的 Trace 列表。

采样率配置：通过管理接口设置采样率（0.0 到 1.0）。采样率 1.0 表示记录所有请求，0.1 表示只记录 10%。未被采样的请求的 Span 上报时直接丢弃不存储。采样判断在 Trace ID 生成时决定，基于 Trace ID 的哈希值。

数据保留 3 天，后台任务定时清理过期 Trace。端口环境变量 PORT 指定。
