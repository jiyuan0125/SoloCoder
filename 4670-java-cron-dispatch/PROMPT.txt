定时任务多到 crontab 管不过来，不知哪个执行失败了，Java 实现。

任务接口注册，每个任务指定：名称、Cron 表达式、回调 URL、超时时间，注册返回任务 ID。

调度器按 Cron 计算下次执行时间，到达后向回调 URL 发 HTTP POST，请求体 JSON 含任务 ID、名称、触发时间。回调非 200 或超时记失败，连续 3 次失败自动暂停。

管理接口手动暂停/恢复/立即触发。

执行日志记录每次触发结果：时间、状态码、响应时间、是否成功。查询按任务 ID 查执行历史分页返回。概览接口展示所有任务下次执行时间和最近结果。任务创建可指定时区，默认 UTC。

包含 scheduler、cron、executor、history 模块。
