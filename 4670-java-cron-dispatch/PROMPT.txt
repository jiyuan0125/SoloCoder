用 Java Netty 写一个定时任务调度器，管理各种定时和周期性任务。

任务通过接口注册，每个任务指定：名称、Cron 表达式（支持标准 5 段格式：分 时 日 月 周）、回调 URL、超时时间。注册成功返回任务 ID。Cron 表达式不合法时返回错误并提示哪个字段有问题。

调度器按 Cron 表达式计算下次执行时间，到达时间后向回调 URL 发 HTTP POST 请求。回调请求体是 JSON，包含任务 ID、名称、触发时间。如果回调返回非 200 或超时，记一次失败。同一个任务连续 3 次失败后自动暂停，暂停后不再调度执行。

任务状态有：活跃、暂停、已完成（一次性任务触发后）。管理接口可以手动暂停/恢复任务，也可以立即触发一次（不等 Cron 时间）。一次性任务用固定时间点指定，触发后状态变为已完成。

执行日志记录每次触发的结果：触发时间、回调状态码、响应时间、是否成功。查询接口可以按任务 ID 查看执行历史，分页返回。还有个概览接口展示所有任务的下次执行时间和最近一次执行结果。

时区支持：任务创建时可以指定时区，不指定默认 UTC。同一个任务在不同时区下触发时间不同。端口环境变量 PORT 指定，能编译启动就行。
