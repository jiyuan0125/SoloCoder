用 Rust axum 写一个 API 网关，做请求路由、认证和限流三件事。

路由表通过管理接口配置，每条规则有路径前缀、目标后端地址、是否需要认证、限流配置。路径匹配支持精确匹配和前缀匹配，前缀匹配时最长前缀优先。匹配到规则后按顺序执行认证和限流检查，全部通过才转发。

认证模块支持两种方式：API Key 和 JWT。API Key 是一个固定字符串，通过 Header X-API-Key 传入。JWT 通过 Authorization Bearer 头传入。规则配置里指定用哪种认证方式。JWT 认证需要配置密钥（环境变量），验证签名和过期时间。

限流配置在路由规则里：每秒允许的请求数和突发容量。限流粒度按客户端 IP。超出的请求返回 429。

转发请求时设置 X-Request-Id（UUID）和 X-Forwarded-For 头。后端超时 5 秒返回 504。后端返回 5xx 时，网关记录错误但正常返回给客户端。

管理接口可以查看所有路由规则、每个规则的请求统计（总请求数、认证失败数、限流拒绝数、转发成功数、后端错误数）。还有个接口可以测试某条路由规则对指定路径是否匹配。端口环境变量 PORT 指定，cargo build 能编译通过。
