用 Go 标准库 net/http 写一个带 TTL 和淘汰策略的缓存代理服务。

缓存操作接口：Set（写入 key-value，可选 TTL）、Get（读取）、Delete（删除）、Exists（判断是否存在）。Get 时如果 key 存在且未过期，返回值并附带剩余 TTL。过期或不存在返回 miss。

批量操作接口：BatchGet（一次查多个 key，返回找到的和没找到的）、BatchSet（一次写多个 key-value 对）。BatchSet 时如果某个 key 的值是空字符串，跳过不写入，但在返回结果里标记为跳过。

淘汰策略支持 LRU 和 TTL 优先两种。LRU 淘汰最久没被访问的。TTL 优先先淘汰 TTL 最短的（离过期最近的）。策略通过管理接口切换，切换时清空缓存。最大容量通过配置指定（默认 50000 条），满了自动淘汰。

缓存统计接口：命中率、总请求数、当前条目数、总淘汰次数。还有个热门 key 接口：返回最近 1 小时访问量最多的前 20 个 key 及其访问次数。

缓存数据可以通过接口导出（JSON 格式）和导入。导入时如果 key 已存在且未过期，按策略处理（覆盖或跳过，通过参数控制）。端口环境变量 PORT 指定，go build 能编译通过。
