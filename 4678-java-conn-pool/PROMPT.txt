用 Spring Boot 2.x（JDK 17，Maven）写一个数据库连接池监控和管理服务，监控应用连接池的运行状态。

各应用定期上报连接池指标：应用名、池名、活跃连接数、空闲连接数、等待线程数、最大连接数、最小空闲数、总获取次数、总获取超时次数。上报接口支持批量上报。如果某个应用超过 2 分钟没上报，标记为离线，但保留最后一次上报的数据。

监控面板接口：查看所有应用的连接池概览，按应用分组展示。每个连接池显示：使用率（活跃/最大）、等待线程数、获取超时率。使用率超过 80% 或等待线程数大于 0 的连接池标红。

告警规则配置：可以设置阈值（使用率超 X% 持续 Y 分钟触发告警）。告警记录到告警表，包含触发时间、应用名、池名、当时的指标值。告警有冷却期，同一连接池 15 分钟内不重复告警。

历史趋势：指标数据保留最近 7 天，按分钟聚合（每分钟取最后一次上报值）。查询接口支持按应用名、池名、时间范围查询趋势数据，返回时间序列。

连接建议：根据历史数据分析，给出连接池配置建议（比如最大连接数是否需要调大）。这个分析基于使用率峰值和等待线程出现频率。端口环境变量 PORT 指定，能编译启动就行。
