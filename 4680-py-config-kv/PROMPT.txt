用 Python FastAPI（async）写一个配置中心服务，支持版本管理和灰度发布。

配置按应用和环境两级组织，每个应用有多个环境（dev/staging/production）。配置项是 key-value 对，值支持字符串、数字、布尔、JSON 对象四种类型。每次修改自动递增版本号，历史版本保留最近 20 个。

灰度发布流程：修改配置后不立即全量生效，而是先指定灰度实例列表（通过接口设置），只有灰度实例能看到新值。灰度验证通过后调用全量发布接口，所有实例看到新值。灰度期间如果有新的修改，新修改也进入灰度状态。灰度可以回滚，回滚后所有实例恢复到上一个全量版本。

客户端 SDK 模拟接口：客户端通过接口拉取配置，可以指定应用、环境和实例 ID。如果是灰度实例且该配置有灰度版本，返回灰度值。否则返回最新全量版本。响应里包含配置值和版本号。

变更通知：客户端通过 SSE 长连接 watch 配置变更。变更时推送事件包含：变更的 key、新值、版本号。同一个应用+环境可以有多个 watcher。watcher 异常断开时自动清理资源。

配置导出和导入：导出指定应用和环境的所有配置为 JSON 文件。导入时如果 key 已存在可以选择覆盖或跳过。导入完成后返回成功、跳过、失败的统计。端口环境变量 PORT 指定。
