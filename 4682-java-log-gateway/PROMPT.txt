用 Spring Boot 2.x（JDK 17，Maven）写一个日志聚合网关，收集多个服务的日志并统一处理。

服务注册：各业务服务启动时向网关注册自己的服务名和日志级别配置。注册信息包括服务名、支持的日志级别（DEBUG/INFO/WARN/ERROR）、默认采样率。未注册的服务发送的日志直接丢弃。

日志接收接口：业务服务通过 HTTP POST 发送日志条目，每条包含时间戳、服务名、级别、消息内容、上下文KV。网关收到后先做过滤：低于该服务配置级别的日志丢弃。然后做采样：按配置的采样率决定是否保留。保留的日志写入本地存储。

日志查询接口：按时间范围、服务名、级别组合查询，分页返回。还有个聚合统计接口：统计每个服务最近 1 小时的各级别日志数量和趋势。告警规则：可以配置规则，比如某服务 ERROR 日志 5 分钟内超过 50 条触发告警，告警记录到告警表。告警触发后有个确认接口，确认后不再重复告警。

存储层用 H2 数据库。日志表和告警表分开，告警表关联服务名和规则。端口环境变量 PORT 指定，能编译启动就行。
