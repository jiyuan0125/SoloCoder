用 Spring Boot 2.x（JDK 17，Maven）写一个流量染色服务，给微服务请求打标签，实现灰度发布和金丝雀发布。

染色规则配置：每条规则指定匹配条件（请求路径前缀、Header 中的某个值、客户端 IP 段）和染色标签。请求进来后依次匹配规则，命中的请求在 Header 中加上 X-Traffic-Tag 和规则指定的标签值。一条请求可以同时命中多条规则，标签用逗号拼接。

灰度发布场景：规则可以配置目标后端列表和流量比例。比如 90% 流量走 v1 后端，10% 走 v2 后端。比例控制按请求计数做轮转，不是随机的。灰度规则有开始时间和结束时间，到期自动失效。

流量复制功能：配置将匹配的请求复制一份发到镜像后端，不影响正常响应。镜像请求和原始请求异步发送，镜像失败不记错误但记到单独的统计里。

标签传播：下游服务调用其他服务时，自动把染色标签带到下游请求的 Header 里。有个统计接口展示每条规则的命中数、灰度分发到各后端的比例、镜像成功失败数。端口环境变量 PORT 指定，能编译启动就行。
