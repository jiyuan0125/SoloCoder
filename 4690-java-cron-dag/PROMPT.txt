用 Java Netty 写一个支持 DAG 依赖的定时任务调度器。

任务通过接口注册，每个任务指定：名称、Cron 表达式、回调 URL、超时时间。任务之间可以配置依赖关系，形成 DAG（有向无环图）。比如任务 C 依赖 A 和 B，那 A 和 B 都执行成功后 C 才开始执行。注册时检测循环依赖，有环就拒绝。

每次 Cron 触发时创建一个调度实例。实例内部管理每个任务的执行状态：等待（前置未完成）、就绪（前置全部完成）、执行中、成功、失败。任务失败后依赖它的下游任务全部跳过。整个实例的状态是成功（全部任务成功）、部分成功（有失败）、失败（根任务失败）。

执行超时的任务标记为失败。超时后如果回调响应才到，忽略掉。同一个调度实例里，失败的根任务可以手动重试，重试后下游要重新执行。

历史记录：每次调度实例的执行结果保留最近 100 条。可以按任务名查询涉及该任务的所有调度实例。还有个任务依赖图查询接口，返回某个任务的上下游依赖链。端口环境变量 PORT 指定，能编译启动就行。
