用 Rust tokio 写一个 HTTP 反向代理，支持 WebSocket 升级和连接复用。

代理规则通过配置文件（JSON）加载。每条规则有路径前缀和目标后端地址。请求进来后匹配最长前缀的规则，匹配不到返回 404。匹配后把请求转发给后端，转发时加上 X-Forwarded-For 和 Via 头。

WebSocket 升级：如果客户端请求 Upgrade: websocket，代理不做 HTTP 转发，而是和后端建立 WebSocket 连接，然后在客户端和后端之间双向转发帧。WebSocket 连接空闲超过 5 分钟自动关闭。连接异常断开时要清理资源。

连接池：对每个后端维护一个 TCP 连接池，空闲连接 30 秒超时回收。连接池最大容量可配置（默认 100）。池满时新的请求等待连接释放，等待超时 5 秒。

后端可能突然不可达（连接拒绝、DNS 失败、超时），这些都要正确处理并返回 502。连续 5 次转发失败的后端临时标记为不可用，30 秒后恢复尝试。有个状态接口展示每个后端的活跃连接数、请求数、错误数。端口环境变量 PORT 指定，cargo build 能编译通过。
