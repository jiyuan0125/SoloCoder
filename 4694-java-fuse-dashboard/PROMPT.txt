用 Spring Boot 2.x（JDK 17，Maven）写一个熔断器仪表盘服务，同时提供熔断控制和管理功能。

受保护的服务注册到仪表盘，配置：服务名、失败率阈值、统计窗口大小、熔断打开持续时间、半开探测数量。每个服务维护自己的熔断状态机：关闭→打开→半开→关闭。调用结果通过接口上报（成功/失败），仪表盘在窗口内统计失败率。

状态变更时有严格的约束：关闭状态下失败率超阈值才能打开。打开状态持续配置时间后自动变半开。半开状态放行指定数量的探测请求。探测全部成功则关闭，任一失败则回到打开。管理员可以强制将某服务重置为关闭。

仪表盘接口：实时展示所有服务的状态、窗口内指标（请求数/失败数/失败率/平均耗时）。熔断历史：每个服务的状态变更记录，包含时间、旧状态、新状态、触发原因。可以按时间范围查询。

SSE 推送：客户端可以订阅某服务的状态变更事件，实时推送。批量操作接口：一次性重置多个服务或查询多个服务的状态。端口环境变量 PORT 指定，能编译启动就行。
