想用 Rust axum 写一个 API 组合网关，把多个后端服务的接口聚合成一个统一的 API。

组合规则配置：每个对外接口定义为一个组合规则，包含路径、HTTP 方法、和一组后端调用步骤。每个步骤指定：后端地址、路径（支持路径参数替换）、超时时间。步骤之间可以串行也可以并行。

请求处理：客户端请求到达网关后，按组合规则依次或并行调用后端。后端返回的数据可以用 JSON Pointer 提取特定字段，组合成最终响应。某个后端调用失败时，根据配置决定是返回部分结果还是整体失败。请求上下文可以在步骤间传递：步骤 A 返回的 id 可以作为步骤 B 路径中的参数。

响应缓存：可以给组合规则配置缓存，指定 TTL。缓存 key 由请求路径和查询参数组成。缓存命中时直接返回，不调用后端。缓存条目最大 1000 个，满了按 LRU 淘汰。

响应裁剪：客户端可以通过查询参数 _fields 指定只返回哪些字段。网关在最终响应前按 _fields 裁剪 JSON。统计每个组合规则的调用次数、平均耗时、缓存命中率。端口环境变量 PORT 指定，cargo build 能编译通过。
