用 Go 标准库 net/http 写一个多级缓存代理服务。

缓存分两级：L1 是内存缓存（速度快但容量小），L2 是本地文件缓存（速度慢但容量大）。每个缓存层可以独立配置容量和淘汰策略（LRU 或 LFU）。读取时先查 L1，miss 了查 L2，再 miss 就返回空。L2 命中后把数据提升到 L1。写入时同时写 L1 和 L2。

缓存接口：Set（key/value/TTL）、Get、Delete、BatchGet。Get 时如果 key 存在但已过期，返回 miss 并异步删除（不阻塞读请求）。批量接口一次处理可能几百个 key，注意内存和性能。

热点探测：自动统计每个 key 的访问频率，超过阈值（每秒 100 次）的 key 标记为热点。热点 key 的 TTL 自动延长一倍。热点列表可以通过接口查看。

缓存穿透防护：查询不存在的 key 时记录。同一个 key 连续 miss 超过 10 次，自动加入布隆过滤器，后续直接返回 miss 不查缓存。布隆过滤器可以手动重置。统计接口：命中率、总请求数、L1/L2 各自命中率、淘汰数、热点数。端口环境变量 PORT 指定，go build 能编译通过。
