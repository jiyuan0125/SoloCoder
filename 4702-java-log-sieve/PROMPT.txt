用 Spring Boot 2.x（JDK 17，Maven）写一个日志筛分服务，从日志流中实时过滤和分类。

日志通过接口批量上报，每批可能几百上千条。每条日志有：时间戳、来源服务名、级别（DEBUG/INFO/WARN/ERROR）、消息内容、额外字段（Map）。上报接口要能快速接收大量数据，不做重处理直接入缓冲队列。

筛分规则：每条规则指定过滤条件和目标通道。过滤条件支持：级别匹配、来源匹配、消息内容包含/不包含指定字符串、额外字段匹配。一条日志可以同时匹配多条规则，被路由到多个通道。

通道是日志的目的地：文件通道（写入本地文件，按小时滚动）、回调通道（POST 到指定 URL）、聚合通道（统计计数，不存原始日志）。通道处理失败（文件写入失败、回调超时）不阻塞其他通道，失败记录到错误计数器。

查询接口：按时间范围、来源、级别查询原始日志，分页返回。聚合统计接口：按来源统计各级别日志数量，按小时聚合。存储用 H2。端口环境变量 PORT 指定，能编译启动就行。
