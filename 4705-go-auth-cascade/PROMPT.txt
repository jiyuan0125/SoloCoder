用 Go Gin 写一个支持级联认证的 API 网关。

认证链由多个认证模块组成，按顺序执行。支持三种认证模块：API Key 认证（检查 Header 中的 X-API-Key）、JWT 认证（验证 Bearer Token 的签名和过期）、OAuth2 Token 检查（验证 Token 是否在白名单中且未过期）。认证链配置时指定模块和顺序，请求必须通过所有模块才算认证成功。

Token 生命周期：认证通过后生成一个内部 Token（有效期可配置）。内部 Token 的状态有：活跃、即将过期（剩余不到 20% 有效期）、已过期。客户端可以用活跃的内部 Token 换取新的内部 Token（刷新）。即将过期状态仍然有效但响应头里会提示需要刷新。过期后需要重新认证。

权限继承：用户通过认证后获得一组角色。角色有层级关系：admin > editor > viewer。上游服务配置最低权限要求，用户角色必须 >= 要求的角色。

请求转发时带上认证结果（用户 ID、角色、Token 过期时间）。管理接口展示认证链配置、每个模块的通过率和失败原因统计。端口环境变量 PORT 指定，go build 能编译通过。
