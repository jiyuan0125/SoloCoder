用 Rust axum 写一个支持内容协商的协议转换代理。

代理在客户端和后端之间做数据格式转换。支持 JSON、MessagePack、YAML 三种格式。客户端在请求头 Accept 中指定想要的格式，Content-Type 指定发送的格式。代理根据这两个头做转换。后端固定接收和返回 JSON。客户端发 MessagePack，代理转成 JSON 给后端，后端返回 JSON，代理转成客户端要求的格式。

版本兼容：同一种格式可能有版本差异。比如 v1 的 JSON 字段名是 snake_case，v2 是 camelCase。转换时根据客户端指定的版本做字段名映射。字段映射规则在配置文件中定义，支持嵌套字段。

转换过程中如果数据格式不对（比如无效的 MessagePack），返回 400 和错误详情。不认识的字段默认透传不丢弃。嵌套对象中的字段也要正确转换。

流式转换：大响应（超过 1MB）不一次性加载，分块读取转换。转换统计：每种格式的转换次数、平均耗时、失败数。还有个健康接口返回当前加载的映射规则数量。端口环境变量 PORT 指定，cargo build 能编译通过。
