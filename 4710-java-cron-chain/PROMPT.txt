用 Spring Boot 2.x（JDK 17，Maven）写一个链式事件调度器，支持条件触发和超时续约。

调度链定义：一条链由多个节点组成，每个节点指定触发条件、动作 URL 和超时。触发条件支持：时间到达（指定时间点）、事件收到（指定事件名）、条件满足（前序节点输出中的某个字段匹配指定值）。节点之间是链式关系：前一个节点执行成功后，根据其输出决定下一个节点的触发条件。

链实例执行：节点触发后调动作 URL（POST），传递链 ID、节点名和前序输出。动作返回 JSON 作为该节点的输出。超时未返回视为失败。失败的节点可以配置重试次数和重试间隔。

超时续约：节点执行过程中如果需要更长时间，可以调续约接口延长超时。每次续约延长 30 秒，最多续约 5 次。超时后如果还在执行，调取消接口通知目标停止。

链的管理接口需要认证：管理操作（创建/删除链）需要 admin 角色，查询操作需要 viewer 角色。角色通过请求头 X-Role 传入。管理接口还可以查看所有链的状态、每个节点的执行历史。端口环境变量 PORT 指定，能编译启动就行。
