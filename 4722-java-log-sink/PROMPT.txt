各服务日志散落在不同机器上查都查不到，用 Spring Boot 2.x 做一个日志聚合服务。
服务通过 HTTP 接口接收结构化日志，日志包含 level、service、timestamp、message、tags 字段。日志按时间写入分片文件，每小时一个文件。
查询接口支持按 level、service、时间范围、关键词过滤。tag 可以按 key=value 过滤。同一个请求的日志通过 trace_id 关联，查一条日志时自动带出同 trace_id 的所有日志。
日志文件保留7天，过期自动清理。删除时如果对应的分片文件还在写入就跳过。JDK 17 + Maven，PORT 指定端口。
