支持水平扩展，多实例通过共享存储或最终一致性同步状态。写操作要有日志记录可追溯。

外部请求按路径分发到内网不同服务，Netty 实现反向代理。路由表配置路径前缀到后端地址映射，请求 /service-a/api/login 转发到 /api/login。后端连接失败返回 503。支持路径参数匹配如 /users/{id}，参数提取后传给后端。路由配置在 JSON 文件，修改后重新加载。

健康检查后台每 N 秒 TCP 探活，连续失败标记不健康路由时跳过，恢复自动启用。转发改写 Host header 追加 X-Forwarded-For。统计接口按后端统计 QPS 和平均耗时。包含 proxy、router、health、stats 模块。端口 PORT 环境变量。
