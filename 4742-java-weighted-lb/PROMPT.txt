用 Spring Boot 2.x（JDK 17，Maven）做一个负载均衡调度器。

后端实例有 host、port 和 weight 三个属性。请求按权重比例分发到各实例，weight 越大分到的请求越多。管理员可以通过 HTTP 接口动态调整权重，也可以新增和移除实例。

实例有健康状态，不健康的实例不参与分配。健康检查用 HTTP 探针，每 10 秒检查一次。探针失败次数达到阈值就标记为不健康，探针成功一次就恢复。

支持会话保持：如果请求带了 X-Session-Id 头，同一个 Session-Id 的请求始终路由到同一个实例。如果那个实例被移除了，重新按权重分配。

请求分配的策略细节我不太确定，比如 weight=0 的实例怎么处理、实例全部不健康时怎么响应，你看着办，合理就行。端口不硬编码，用 application.properties 里的 server.port 配置。
