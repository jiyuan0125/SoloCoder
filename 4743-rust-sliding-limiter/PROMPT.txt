用 Rust axum 做一个滑动窗口限流器服务。

每个客户端用 API Key 标识，限流规则是每分钟最多 N 次请求（N 可配置，默认 60）。用滑动窗口算法，精度到秒。超出限制返回 429，同时响应头里带上 X-RateLimit-Remaining 和 X-RateLimit-Reset。

管理员可以创建和修改不同 API Key 的限流规则。规则变更后，已有的窗口计数不受影响，新的请求才用新规则。

有个统计接口返回每个 Key 的当前窗口已用次数和剩余次数。统计接口自身也要做限流（每分钟 10 次），防止被滥用。

限流数据存在内存里，用 HashMap 就行。项目能 cargo build && cargo run 跑起来，端口从环境变量 PORT 读取。
