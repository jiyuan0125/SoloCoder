用 Go Gin 做一个 API 网关，核心功能是路由匹配和请求过滤。

路由规则用 YAML 配置，支持路径前缀匹配和精确匹配。路径可能有多级，比如 `/api/v2/users/{id}/profile`、`/api/v2/users/{id}/orders/{oid}`。每个路由规则绑定一个后端服务地址，网关把匹配到的请求转发过去。

请求过滤链：请求进来后依次经过认证过滤器（检查 Authorization 头）、限流过滤器（每个 IP 每分钟 100 次）、日志过滤器（记录请求方法、路径、耗时）。任何一个过滤器拒绝请求就直接返回，不继续往下走。

后端服务的信息（名称、地址、健康状态）通过 /admin/services 接口管理。网关启动时加载配置，运行时可以热更新。

端口从 PORT 环境变量读取，项目 go build 能编译通过。
