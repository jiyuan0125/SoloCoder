用 Python aiohttp（async）写一个通用连接池管理服务。

连接池管理的是到后端 HTTP 服务的连接。每个后端服务有自己的连接池，配置包括：最大连接数、最小空闲连接数、连接超时时间、空闲超时时间。

客户端请求连接时，池里有空闲连接就直接分配，没有就新建（不超过最大连接数）。如果达到上限就排队等待，等待超时返回错误。连接用完后归还到池里。

后台有个健康检查任务，定期（每 15 秒）用每个池的连接发一次探测请求，失败的连接关掉。空闲超过设定时间的连接也自动回收。池里连接数低于最小值时自动补充。

连接池的配置通过管理接口动态调整。调整最大连接数时，如果当前活跃连接超过新的上限，不强制关闭已有的，只是不再新建。

项目分模块写：连接池核心逻辑、健康检查、HTTP API 层、配置管理。端口从 PORT 环境变量读取。
