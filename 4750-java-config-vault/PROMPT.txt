配置散落在各台机器上，改一次参数要登五台机器改五份文件，需要加密。做一个配置中心，普通配置明文存储，敏感配置 AES 加密，Spring Boot 实现。

配置按应用和环境两级组织，每个应用有 dev、staging、production 三个环境。配置项是 key-value 形式，支持文本和 JSON 两种值类型。

有变更推送功能：客户端通过长轮询监听配置变更。配置被修改时，监听该应用的客户端会收到通知，带上变更的 key 列表和最新值。

有些配置项是敏感信息，这类配置存储时需要加密。

内存存储。

用户接口创建应用、管理配置。

包含 storage、encrypt、watch、audit 模块。
