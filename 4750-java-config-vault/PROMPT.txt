用 Spring Boot 2.x（JDK 17，Maven）做一个配置中心，给多个应用提供配置管理。

配置按应用和环境两级组织，每个应用有 dev、staging、production 三个环境。配置项是 key-value 形式，支持文本和 JSON 两种值类型。修改配置后生成新版本，历史版本可查。

有变更推送功能：客户端通过长轮询监听配置变更。配置被修改时，监听该应用的客户端会收到通知，带上变更的 key 列表和最新值。

有些配置项是敏感信息（数据库密码、API Key），这类配置存储时需要加密。加密密钥从环境变量 CONFIG_ENCRYPT_KEY 读取。普通用户查询配置时敏感值返回脱敏的 `***`，只有管理员角色能看到原始值。

用户通过接口创建应用、管理配置。应用有管理者列表，只有管理者能修改该应用的配置。端口用 application.properties 里的 server.port 配置。
