用 Rust axum 实现一个基于租约的分布式锁服务。

客户端通过 acquire 接口获取锁，带上 lock_name 和 ttl（秒）。获取成功返回一个 lock_id（UUID），同时在服务端记录锁的持有者和过期时间。同一个 lock_name 同时只能被一个客户端持有，其他请求返回冲突。

客户端完成任务后通过 release 接口释放锁，带上 lock_id。只有持有者才能释放自己的锁，防止误解锁。锁过期后自动释放。

客户端可以对持有的锁续期（renew），延长 ttl。如果锁已经过期或被其他人获取，续期失败。

有个后台任务定期扫描过期的锁并清理。同时记录锁的等待队列——获取失败的客户端可以排队等待，锁释放后按排队顺序通知下一个等待者。

数据存内存即可。端口从 PORT 环境变量读取，cargo build && cargo run 能跑。
