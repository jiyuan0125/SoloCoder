给 Grafana 对接 Prometheus 指标，Histogram bucket 累计值算错监控图尖峰排查两天。用 Go Fiber 做指标采集导出，封装 Counter、Gauge、Histogram 三种指标。

Counter 只增不减，Gauge 可增可减，Histogram 分布。客户端 HTTP POST 上报，每个指标有名称和标签，同名不同标签算不同时间序列。

导出 Prometheus text format。Histogram 自动算 count、sum 和 bucket 累计值。聚合支持实时求和、平均、最大最小，规则通过管理接口 CRUD。端口 PORT 环境变量。
