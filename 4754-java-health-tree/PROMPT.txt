用 Spring Boot 2.x（JDK 17，Maven）做一个健康检查编排服务。

服务之间有依赖关系，比如 order-service 依赖 user-service 和 inventory-service。管理员配置这些依赖关系，形成一棵依赖树。检查的时候先查叶子节点，逐层往上汇总。

每个服务的健康检查支持 HTTP 和 TCP 两种探针方式。HTTP 探针发 GET 请求，2xx 算健康；TCP 探针尝试建立连接，成功算健康。探针超时时间可配置。

检查结果分三档：healthy、degraded（部分依赖不健康）、unhealthy（自身或关键依赖不健康）。degraded 的服务还能用但需要告警。

支持定时检查（cron 表达式配置）和手动触发检查。检查结果有历史记录，可以查看某个服务最近 24 小时的健康状态变化。

检查结果变化时触发通知，通知方式先实现写日志就行。端口用 server.port 配置。
