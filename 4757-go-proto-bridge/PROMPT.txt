后端写了 gRPC 服务但前端要 REST JSON，手动写转换又蠢又易出错。用 Go Gin 做通用协议转换网关，一套配置搞定 REST→gRPC 双向转换。

对外暴露 RESTful 接口，根据路由表找对应 gRPC 方法，JSON 请求体转 protobuf 调后端 gRPC 服务，响应再转 JSON 返回。路径和 gRPC 方法映射通过 YAML 配置。

gRPC message 嵌套结构（如 Order→Customer→Address），JSON 对应多层嵌套。枚举字段 JSON 用可读字符串（如 "ACTIVE"），gRPC 用数字，双向映射。支持 gRPC 服务端流式响应转 newline-delimited JSON 流式返回，客户端流式先不做。

proto 文件路径和后端地址通过配置加载，后端不可用或超时返回 503。go build 编译通过，端口 PORT 环境变量。
