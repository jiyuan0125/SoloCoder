排查支付慢请求翻五个服务日志对时间戳两小时才定位。用 Spring Boot 2.x（JDK 17，Maven）做分布式链路追踪自动把调用链串起来。

每个请求全局唯一 TraceID，经过的每个服务生成 SpanID，通过 HTTP Header 传递。SDK 做成独立 Java 包加依赖即可：Servlet Filter 拦截请求自动创建 Span，调用下游自动注入追踪 Header，业务代码不用改。

收集服务接收 Span 数据按 TraceID 聚合构建调用链存 SQLite。查询支持按 TraceID 查完整链路、按服务名查最近调用、按耗时排序找慢请求 Top N。端口 server.port。
