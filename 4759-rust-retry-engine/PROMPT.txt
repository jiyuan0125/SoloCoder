用 Rust tokio 做一个重试引擎服务。

客户端提交一个任务（包含 URL、请求方法、Body、最大重试次数），引擎负责执行 HTTP 请求并在失败时重试。重试策略用指数退避：第 1 次等 1 秒，第 2 次等 2 秒，第 3 次等 4 秒，以此类推，最大间隔 60 秒。

每个任务有唯一的 idempotency_key，相同 key 的任务不会重复执行。任务状态有 pending、running、success、failed。达到最大重试次数还是失败就标记为 failed。

支持回调通知：任务创建时可以指定一个 callback_url，任务成功或最终失败时通知调用方。通知失败的话也重试，但只重试 3 次。

查询接口可以按任务 ID 查状态，也可以列出最近的失败任务。引擎重启后，未完成的任务需要恢复继续执行。

数据持久化到文件或 SQLite。端口从 PORT 环境变量读取。
