用 Spring Boot 2.x（JDK 17，Maven）实现一致性哈希负载均衡器。

后端节点用虚拟节点映射到哈希环上（每个真实节点 150 个虚拟节点）。请求根据某个 key（比如用户 ID 或 Session ID）的哈希值找到环上最近的节点。

节点上下线时只影响相邻节点的数据迁移。节点下线后，原本路由到它的请求自动迁移到下一个节点。新节点加入后，一部分请求从负载最重的节点迁移过来。

节点有权重，权重越大虚拟节点越多，分到的流量也越多。权重变更后，哈希环重新分布。正在处理的请求不迁移，新的请求按新环分配。

支持统计每个节点当前的请求量、成功率、平均响应时间。数据存内存，定时刷新到 SQLite 做持久化。端口用 server.port 配置。
