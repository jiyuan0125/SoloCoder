十几个微服务各写认证限流逻辑，改限流策略得改十几个服务重新部署，漏改导致 500。用 Spring Boot 2.x（JDK 17，Maven）做带过滤器链的 API 网关，认证限流路由集中处理，下游只管业务。

过滤器链按序执行：认证→限流→请求改写→路由转发→响应改写，每步可放行或拒绝。路由支持路径前缀和正则匹配，支持路径参数提取（如 /users/{id}）放入请求属性。

认证支持 API Key（Header/Query）和 JWT（Bearer）两种，可同时启用，带哪种用哪种。限流用令牌桶，每个 API Key 独立计数，按路由维度配 QPS。过滤器链顺序和参数通过管理接口动态调整即时生效，进行中请求走旧配置。数据存内存，端口 server.port。
