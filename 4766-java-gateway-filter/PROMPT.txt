用 Spring Boot 2.x（JDK 17，Maven）做一个带过滤器链的 API 网关。

过滤器链按顺序执行：认证 → 限流 → 请求改写 → 路由转发 → 响应改写。每个过滤器可以放行或拒绝请求。拒绝时直接返回对应的 HTTP 状态码和错误信息。

路由规则支持路径前缀匹配和正则匹配。每个路由绑定一个后端地址。支持路径参数提取，比如 `/users/{id}` 里的 id 可以提取出来传给后端。

认证过滤器支持 API Key 和 JWT 两种方式。API Key 在 Header 里传，JWT 在 Authorization 头。两种方式可以共存。

限流过滤器用令牌桶算法，每个 API Key 独立计数。限流参数按路由配置，不同路由可以有不同的限流阈值。

过滤器链的顺序和各过滤器的配置通过管理接口动态调整。路由配置变更后立即生效，不影响正在处理的请求。

端口用 server.port 配置。
