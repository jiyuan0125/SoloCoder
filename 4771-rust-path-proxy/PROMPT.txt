一台机器跑多个内部站点，Nginx 配置几百行改错就全挂。用 Rust actix-web 写轻量路径前缀反向代理，/api/* 转后端 A，/web/* 转后端 B，配置简单不易出错。

路由规则通过 YAML/JSON 配置，每条含路径前缀和上游地址。支持多级路径匹配和路径参数提取（如 /users/{id}/profile 提 id）。上游每 10 秒 TCP 健康检查，连续 3 次失败标不可用，连续 3 次通过恢复。探针超时 5 秒。

转发注入 X-Proxy-Id 和 X-Forwarded-For，响应去掉 Server 和 X-Powered-By。支持 SIGHUP 或 /admin/reload 热重载配置不重启。端口 PORT 环境变量，cargo build 能过。
