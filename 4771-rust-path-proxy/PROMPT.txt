用 Rust actix-web 写一个基于路径前缀的反向代理。不同的路径前缀对应不同的上游服务地址，比如 /api/* 转到后端A，/web/* 转到后端B。路径匹配支持多级，像 /api/v2/users/{id}/orders 这种。

上游服务需要做健康检查，每10秒探一次。检查失败的上游标记为不可用，不可用的上游不再转发请求。连续3次检查通过后恢复可用。探针超时5秒算失败。

请求转发时要注入 X-Proxy-Id 和 X-Forwarded-For 头。响应回来后把 Server 头和 X-Powered-By 头去掉再返回客户端。上游地址通过配置文件加载，支持运行时重新加载配置。端口环境变量 PORT 指定，cargo build 能过就行。
