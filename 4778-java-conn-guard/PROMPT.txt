Spring Boot 2.x（JDK 17，Maven）写一个通用连接池管理器。管理到指定数据源的连接。

数据源配置包含：连接地址、最大连接数、最小空闲连接数、连接超时、空闲超时。获取连接时如果没有空闲连接且未达上限，创建新连接。达到上限后等待，超时抛异常。空闲连接超过空闲超时后被回收，但保留最小空闲数。定期检查连接健康，不健康的连接关闭并创建新的补上。

连接用完要归还。超过最大使用时间没归还的连接强制回收。归还的时候做一下健康检查，不健康的直接销毁。提供接口查看各数据源的连接池状态：活跃数、空闲数、等待数、历史创建/销毁数。还要能查看每个活跃连接的借用时间、借用者标识。端口环境变量 PORT 指定。
