Spring Boot 2.x（JDK 17，Maven）做一个日志聚合服务。各个微服务把结构化日志推到这里集中管理。

日志推过来包含：来源服务名、级别、时间戳、消息体、标签列表。日志先放内存缓冲，积攒到一定数量或超过一定时间后批量写入持久层。缓冲期间如果服务挂了，还没持久化的日志丢了就丢了。

查询接口支持按服务名、级别范围、时间范围、标签组合过滤。全文搜索消息体中的关键词。日志级别从低到高：DEBUG < INFO < WARN < ERROR < FATAL。可以设置全局最低级别，低于该级别的日志接收后直接丢弃。

某个服务如果连续产生大量 ERROR 级别日志（1分钟内超过阈值），自动触发告警回调。告警回调发给配置的通知地址，回调内容包含服务名、错误数量、最近一条错误日志摘要。如果通知地址没配，告警就记到日志里不往外发了。端口环境变量 PORT 指定。
