Gin 做一个认证网关。后端服务把认证逻辑都委托给这个网关。

网关签发 JWT，Token 里带用户 ID 和角色列表。Token 有效期可配，默认 2 小时。过期前 30 分钟内可以用旧 Token 换新 Token（刷新）。刷新后旧 Token 立即失效。

请求经过网关时验证 Token。验证通过后把用户信息注入 Header 转发给下游。下游可以配置路径级别的角色要求。比如 /admin/* 需要 admin 角色，/api/users/* 需要已登录即可。角色不匹配返回 403。

用户可以主动注销，注销后该用户所有已签发的 Token 都失效。Token 黑名单用内存维护，定期清理过期的黑名单条目。清理时如果正好有请求带着黑名单里的 Token 过来，该请求还是会被拒绝。端口 PORT 环境变量。
