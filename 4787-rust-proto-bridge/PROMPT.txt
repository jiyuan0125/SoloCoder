老系统只认 HTTP+JSON，新服务用 gRPC+Protobuf，手动写转换代码蠢又易出错。用 Rust actix-web 写双向协议转换代理让新老系统无缝通信。

HTTP→gRPC：JSON 请求按路径匹配 gRPC 方法，自动转 Protobuf 调后端再转回 JSON。路径到方法映射通过配置文件定义，proto 路径在配置中指定启动时加载。

gRPC→HTTP：收到 gRPC 请求转 HTTP JSON 调老系统 REST 接口再转回。WebSocket 桥接：客户端建立 WS 连接发 JSON 每条消息转一次 gRPC 调用结果通过同一 WS 推回。枚举 JSON 侧用字符串（如 "ACTIVE"），gRPC 侧数字，双向映射不能搞反。端口 PORT 环境变量。
