同一台机器多站点多域名，Nginx 虚拟主机配置又长又复杂改一次怕改错。用 Rust axum 写基于 Host 头的反向代理，按域名路由不同上游，一个 YAML 搞定。

Host 到上游映射在 YAML 中定义，改完调管理接口热重载不重启。支持通配符（如 *.example.com）。无匹配返回 404 不做默认转发。每个 Host 可配多上游轮询负载均衡。不可用上游自动跳过，后台每 10 秒探测连续 3 次成功恢复。

转发注入 X-Forwarded-Host 和 X-Forwarded-Proto。响应原样返回保持透明。上游超时（可配默认 10 秒）返回 504 并记日志含 Host、选中上游、耗时。端口 PORT 环境变量。
