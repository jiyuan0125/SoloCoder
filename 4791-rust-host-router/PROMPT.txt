axum 写一个基于 Host 头的反向代理。同一台机器上跑多个站点，根据请求的 Host 头路由到不同的上游。

Host 到上游地址的映射在配置文件中定义。支持通配符匹配，比如 *.example.com 路由到同一组上游。如果请求的 Host 没有匹配的规则，返回 404。

上游地址可以配多个，请求在多个上游之间轮询。上游不可用（连接失败或超时）后自动切换到下一个。不可用的上游每隔一段时间重新尝试，恢复后重新加入轮询。

转发时注入 X-Forwarded-Host 和 X-Forwarded-Proto 头。上游返回的响应原样返回客户端，包括所有 Header。如果上游响应超时，网关返回 504 并记录日志。日志包含请求的 Host、选中的上游地址、耗时。端口 PORT 环境变量指定。
