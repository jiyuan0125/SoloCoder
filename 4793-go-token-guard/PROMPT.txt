Gin 做一个 API 限流守护。每个 API 端点可以独立配置限流规则。

令牌桶算法：每个端点 + 客户端标识（IP 或 API Key）维护一个独立的令牌桶。桶容量和填充速率按端点配置。API Key 通过请求头 X-Api-Key 传入。没有 API Key 的请求用 IP 作为标识。

IP 黑名单里的请求直接拒绝，不走限流逻辑。白名单里的请求不受限流限制。黑白名单通过接口动态管理。一个 IP 同时在黑名单和白名单里时，黑名单优先。

限流触发时记录日志：时间、端点、客户端标识、当前桶状态。提供接口查询各端点的限流统计：总请求数、被限流数、当前最活跃的客户端 Top 10。统计数据的查询时间范围支持最近1小时、24小时、7天。端口 PORT 环境变量。
