Spring Boot 2.x（JDK 17，Maven）做一个熔断器面板，管理多个下游服务的熔断状态。

每个服务独立配置熔断规则。触发条件支持两种：失败率超过阈值（比如 50%），或者慢调用率超过阈值（比如 80%，慢的阈值可配）。两种条件满足任一即触发熔断。统计窗口可配。

熔断后进入打开状态，所有请求直接失败。打开状态持续一段时间后进入半开状态。半开状态下允许指定数量的请求通过。这些请求全部成功则恢复到关闭状态，任一失败则回到打开状态。半开期间如果通过的请求中有的还在处理中（没返回），不计入成功也不计入失败，等结果回来再判断。但如果等待时间超过了配置的超时，也算失败。

熔断状态变更事件推送到配置的 Webhook 地址。推送内容包含服务名、旧状态、新状态、触发原因。推送失败不阻塞主流程。端口环境变量 PORT 指定。
