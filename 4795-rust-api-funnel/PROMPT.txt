actix-web 写一个 API 网关。负责把外部请求路由到内部服务，顺便做点流量控制。

路由规则在配置文件中定义，支持路径前缀匹配和精确匹配。路径参数用 {name} 的形式，比如 /api/{version}/users/{id}/orders。匹配到的参数要传给下游。如果多条规则都能匹配，精确匹配优先于前缀匹配，长的前缀优先于短的前缀。

请求转发前可以配置转换规则：添加固定 Header、删除指定 Header、把 Query 参数映射到 Header。响应回来后也可以做转换：只保留指定的响应字段、统一错误格式。

每个路由规则可以配独立的限流：QPS 上限。超限返回 429。限流统计按分钟粒度。网关还要支持请求日志，记录每个请求的路径、状态码、耗时、匹配的路由规则名。日志写入本地文件，按小时轮转。端口 PORT 环境变量指定。
