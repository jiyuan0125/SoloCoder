Spring Boot 2.x（JDK 17，Maven）写一个连接池管理器，同时管理多个数据源的连接池。

每个数据源配置：名称、JDBC URL、最大连接数、最小空闲、获取超时、空闲超时、最大使用时长。数据源通过接口注册和注销。注册时初始化连接池，创建最小空闲数的初始连接。注销时关闭所有连接。

连接借出后开始计时，超过最大使用时长未归还标记为泄漏。泄漏检测定期扫描。泄漏的连接强制回收，记录日志包含借用者信息。借用者信息在获取连接时传入。

连接池状态面板：每个池的活跃数、空闲数、等待线程数、历史泄漏次数。可以按池查看最近泄漏的连接详情。全局维度看所有池的总连接数和总使用率。使用率超过 80% 的池自动告警，告警消息推到配置的 Webhook。连接归还时如果池已经被销毁（数据源已注销），连接直接关闭不归还。端口环境变量 PORT 指定。
