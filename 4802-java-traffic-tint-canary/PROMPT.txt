灰度发布靠手动改 Nginx 切流量效率低易出错，上次切完忘切回灰度跑了两天。用 Netty（Spring Boot 2.x，JDK 17，Maven）写流量染色网关。

按请求 Header、Cookie、IP 段等条件匹配打染色标签，标签通过 X-Traffic-Tag Header 在调用链自动传播。不同标签路由不同实例组——灰度走灰度环境金丝雀走金丝雀环境无标签走生产。按用户 ID 或 IP 哈希落入指定范围标记灰度（比例可配如 5%）。灰度流量优先灰度实例不可用降级正常实例。

灰度监控独立统计成功率、响应时间、错误数和正常指标对比，灰度错误率超正常 2 倍自动 Webhook 告警。管理接口配规则和比例、查看对比、手动切换。端口 server.port。
