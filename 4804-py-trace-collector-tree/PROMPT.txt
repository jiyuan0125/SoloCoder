排查支付慢请求翻五个服务日志拼调用链对时间戳两小时才定位第三方余额查询慢。用 Python aiohttp 写分布式链路追踪。

每个请求全局唯一 TraceID 通过 HTTP Header 在服务间自动传播。每次调用产生 Span 含 SpanID、ParentSpanID、服务名、操作名、起止时间、标签。通过 API 上报，按 TraceID 聚合构建调用树。自动计算每 Span 耗时和占比，超阈值标慢 Span。

查询按 TraceID 返回完整调用链、按服务名查、按耗时排序找慢请求 Top N。基于 Span 数据统计服务间调用关系和频率，管理接口查看服务拓扑图数据和最近慢请求列表。端口 PORT 环境变量。
