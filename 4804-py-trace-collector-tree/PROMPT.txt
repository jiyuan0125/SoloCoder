用 aiohttp 写一个分布式链路追踪服务。

每个请求有一个全局唯一的 TraceID。请求经过的每个服务产生一个 Span：包含 SpanID、ParentSpanID、服务名、操作名、开始时间、结束时间、标签（键值对）。

Span 通过 API 上报到追踪服务。追踪服务按 TraceID 聚合所有 Span，构建调用树（根据 ParentSpanID 关系）。查询接口：按 TraceID 查询完整调用链，返回调用树和各 Span 的详细信息。

耗时分析：自动计算每个 Span 的耗时和占总耗时的比例。标记慢 Span（耗时超过配置阈值的）。

服务拓扑：基于 Span 数据统计服务之间的调用关系和频率。管理接口查看服务拓扑图数据、最近慢请求列表。端口 PORT 环境变量。
