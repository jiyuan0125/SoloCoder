Gin 做一个缓存中间件。除了基本的 GET/SET/DELETE，还要支持 LRU 淘汰和热点 key 自动预热。

内存上限默认 256MB，满了之后淘汰最近最少使用的 key。每个 key 被访问时更新它的位置。SET 和 GET 都算一次访问。淘汰时一次性释放容量最小的 key 直到内存降到 80% 以下。

热点 key 检测：统计最近 5 分钟内每个 key 的访问次数，访问频次超过阈值（默认 100 次/分钟）的标记为热点。热点的 TTL 自动续期：快过期时（剩余 TTL 不到原来的 20%）自动续期一倍，但最多续期 3 次。续期次数用完就正常过期。

管理接口：查看当前热点 key 列表及各自的访问频次、总淘汰次数、平均缓存项大小。端口 PORT 环境变量。
