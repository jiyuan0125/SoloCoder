用 Spring Boot 2.x 写一个通用连接池服务。管理对后端数据库（TCP 连接）的连接复用。

池配置：最大连接数、最小空闲连接数、连接最大空闲时间（超时回收）、连接最大生命周期（到期强制关闭重建）。通过 API 管理配置。

获取连接：池中有空闲连接则直接返回，没有且未达上限则新建。已达上限则等待（最多 5 秒），超时返回错误。归还连接：标记为空闲，如果池满则关闭。

连接健康检查：每次获取时做一次 ping（TCP connect 测试），不健康的连接丢弃并补充新的。后台每 30 秒扫描空闲连接，超过最大空闲时间的关闭，低于最小空闲数的补充。

管理接口查看：活跃连接数、空闲连接数、等待获取的请求数、累计创建/关闭/健康检查失败次数。端口 PORT 环境变量。
