用 FastAPI 写一个日志聚合服务。收集多个服务的结构化日志。

日志通过 HTTP API 提交（POST JSON）。每条日志包含：服务名、级别（DEBUG/INFO/WARN/ERROR）、时间戳、消息体、额外字段（键值对）。日志按服务名和级别建立索引，存到本地文件（按天分文件）。

查询 API：按服务名、级别范围、时间范围、关键词搜索。关键词搜索支持消息体的全文匹配。查询结果分页返回，按时间倒序。

日志级别过滤：每个服务可以独立配置最低接收级别（如只接收 WARN 以上）。低于配置级别的日志直接丢弃，不存储。级别配置通过管理 API 动态修改。

统计：每小时统计各服务各级别的日志数量。管理接口查看统计和级别配置。端口 PORT 环境变量。
