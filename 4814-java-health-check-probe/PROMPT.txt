order-service 全线超时根因是依赖的 Redis 挂了查半小时才发现依赖链底层问题。用 Spring Boot 2.x（JDK 17，Maven）Netty 写健康检查编排服务。

管理员配依赖关系形成依赖树，从叶子节点逐层往上汇总底层不健康上层标异常。每服务配名称、探针类型（HTTP/TCP）、地址、检查间隔、超时、不健康阈值、健康阈值。HTTP GET 期望 2xx，TCP 建连成功即健康。结果分 healthy、degraded、unhealthy 三档。

级联状态：B 不健康则依赖 B 的 A 标降级。支持定时和手动触发。状态变更触发 Webhook 通知。管理接口查看状态和检查历史。端口 server.port。
