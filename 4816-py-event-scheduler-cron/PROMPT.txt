用 FastAPI 写一个事件调度器。管理定时任务和延迟任务。

Cron 任务：通过 API 创建，指定 Cron 表达式、回调 URL、超时时间。调度器按 Cron 表达式触发，HTTP POST 到回调 URL。

延迟任务：创建时指定延迟秒数，到期后触发回调。支持取消延迟任务（在到期前通过任务ID取消）。

任务执行记录：每次触发的结果（成功/失败/超时）、回调响应、耗时。执行失败的任务根据配置决定是否重试（最多 3 次，间隔递增）。

并发控制：同一时间最多执行 N 个任务（配置），超出的排队等待。任务执行超时（默认 30 秒）强制取消并标记为超时。

管理接口：查看所有任务、执行历史、当前运行中的任务数、排队数。支持手动触发和暂停任务。端口 PORT 环境变量。
