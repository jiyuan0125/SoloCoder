用 Gin 做一个 Histogram 指标采集服务，专门处理耗时分布类的指标。

指标通过 API 上报：POST /histogram，body 包含指标名、观测值（如请求耗时 ms）、标签键值对。服务端对同一个指标名 + 标签组合的所有观测值维护一个排序数组，实时计算 P50/P90/P95/P99/P999 分位数。分位数的计算用插值法，不是简单取第 N 个值。

当观测值数量超过 10000 时，自动切换到 TDigest 近似算法，内存占用控制在固定大小。查询接口返回各分位数值、总观测数、平均值、最大值、最小值。支持按时间范围查询，只统计最近 N 分钟的观测值。

Prometheus exposition 格式导出：/metrics 输出标准的 Prometheus histogram 格式（_bucket、_sum、_count）。管理接口展示所有指标列表、各指标的观测数量和最近上报时间。端口 PORT 环境变量。
