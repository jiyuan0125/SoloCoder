给 Prometheus 对接指标 Histogram bucket 累计值算错尖峰排查两天才定位。用 Go Gin 做专门处理耗时分布的指标采集。

API 上报观测值（如请求耗时 ms），同指标名+标签组合维护排序数组，实时算 P50/P90/P95/P99/P999 用插值法不是简单取第 N 个。观测值超 10000 自动切 TDigest 近似算法控内存。查询返回分位数、总数、均值、极值支持按时间范围查。

/metrics 输出标准 Prometheus histogram 格式，自动算 count、sum 和 bucket 累计值。管理接口展示指标列表、观测数量和最近上报时间。数据存内存，端口 PORT 环境变量，go build 编译通过。
