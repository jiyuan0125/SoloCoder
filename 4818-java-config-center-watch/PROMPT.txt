用 Spring Boot 2.x 写一个配置中心。管理微服务的动态配置。

配置按 namespace + key 组织。每个配置项有：key、value（字符串）、版本号、更新时间、更新人。配置项的 value 最大 64KB。

配置变更历史保留所有版本，可以回滚到任意历史版本。回滚时生成新版本（值等于历史版本的值），不是真的覆盖。

Watch 机制：客户端可以订阅某个 namespace 的变更通知。配置变更时，注册中心主动通知所有订阅者（HTTP POST 到客户端注册的回调 URL）。通知失败时重试 3 次，间隔 10/30/60 秒。3 次都失败则记入通知失败日志。

管理接口：CRUD 配置、查看变更历史、查看订阅者列表、手动触发通知。端口 PORT 环境变量。
