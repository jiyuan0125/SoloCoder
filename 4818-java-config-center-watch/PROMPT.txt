改超时参数要重启十几个服务，重启时有个服务新参数不适配起不来链路断十分钟。用 Spring Boot 2.x（JDK 17，Maven）写配置中心热更新不重启。

配置按 namespace + key 组织，每项有 value（最大 64KB）、版本号、更新时间、更新人。变更历史保留所有版本可回滚到任意版本（回滚生成新版本）。

Watch 机制：客户端订阅 namespace 变更，变更时 HTTP POST 通知，失败重试 3 次（10/30/60 秒）都失败记通知失败日志。灰度发布：修改时指定只对特定标签实例生效先观察，没问题全量推送有问题一键回滚。管理接口 CRUD、历史、订阅者列表、手动触发通知。端口 PORT 环境变量。
