灰度发布靠手动改 Nginx 切流量效率低易出错，上次忘切回灰度跑了两天。用 Spring Boot 2.x（JDK 17，Maven）写 A/B 测试流量染色。

每个实验有变体列表（名称+比例），比例和必须 100%。按用户 ID 确定性分配——同一用户始终同一变体，标签通过 X-Traffic-Tag Header 在调用链传播。条件支持匹配 Header、Cookie、IP 段等 AND/OR 组合。

指标采集：各变体独立统计转化事件（API 上报）查看转化率、样本量、统计显著性。实验生命周期：创建→运行→停止。运行中可调比例（用户可能重新分配）停止后全走默认变体。管理接口 CRUD、看结果、启停。端口 server.port。
