做一个 A/B 测试的流量染色服务，用 Spring Boot 2.x。

实验配置：每个实验有名称、变体列表（每个变体有名称和流量比例）。比例之和必须为 100%。请求到达时根据用户ID做确定性分配（同一用户始终进同一个变体）。

实验指标采集：每个变体独立统计转化事件。转化事件通过 API 上报（用户ID + 事件名 + 值）。实验结果查看：各变体的转化率、样本量、统计显著性（简化计算，不需要精确的贝叶斯/频率学派方法）。

实验生命周期：创建→运行中→已停止。运行中可以调整流量比例，调整后用户可能重新分配到不同变体。停止后不再染色，所有流量走默认变体。

管理接口：CRUD 实验、查看实验结果、启停实验。端口 PORT 环境变量。
