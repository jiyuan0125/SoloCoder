给 Prometheus 对接指标 Histogram bucket 累计值算错尖峰排查两天才定位。用 Rust axum/tokio 写运行时指标采集器。

拦截 HTTP 请求自动记录每个路由的请求数、错误数、响应时间。响应时间用 Histogram 统计 P50/P95/P99。支持 Counter（只增）、Gauge（可增减）、Histogram（分布）三种类型，客户端也可通过 HTTP 上报自定义指标。

指标按路由和状态码分组，支持自定义标签。相同指标名加标签做聚合。数据存内存时间序列按分钟聚合保留 2 小时，也支持注册回调推外部存储。/metrics 导出 Prometheus text format 标准格式。管理接口看各路由实时指标和历史趋势支持导出 JSON。端口 PORT 环境变量，cargo build 编译通过。
