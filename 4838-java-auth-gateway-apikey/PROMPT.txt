六个微服务各写 JWT 校验 Token 格式改了六个地方还得改还漏一个接口裸奔两天。用 Spring Boot 2.x（JDK 17，Maven）写 API Key 认证网关。

每个 Key 绑定租户 ID 和权限范围（允许的路由前缀列表）。请求带 X-API-Key 头校验有效性过期权限，无效 401 无权限 403。支持 JWT 签发验证，通过后用户 ID 和角色注入 Header 转发下游。

Key 管理：创建自动生成 32 字符随机串，可吊销续期已吊销不能续期。黑名单机制注销后已签发 Token 立即失效。使用统计：每个 Key 按天请求次数、最近使用时间、来源 IP。限流集成：每个 Key 可配独立限流每分钟最大请求数超限 429。端口 server.port。
