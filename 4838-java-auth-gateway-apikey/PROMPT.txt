做一个 API Key 认证网关，用 Spring Boot 2.x。

每个 API Key 绑定一个租户ID和权限范围（允许访问的路由前缀列表）。请求到达时从 X-API-Key 头部读取 key，校验有效性、过期时间和权限。无效返回 401，无权限返回 403。

API Key 管理：通过管理接口创建/吊销/续期 Key。创建时自动生成唯一 key（32 字符随机字符串）。续期延长过期时间，不改变 key 值。已吊销的 key 不能续期。

Key 使用统计：每个 key 的请求次数（按天）、最近使用时间、来源IP。统计信息通过管理接口查询。

限流集成：每个 key 可以配置独立的限流（每分钟最大请求数），超过限流返回 429。管理接口查看限流配置和当前使用情况。端口 PORT 环境变量。
