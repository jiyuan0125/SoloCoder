给 Prometheus 对接指标 Histogram bucket 累计值算错尖峰排查两天才定位。用 Rust axum/tokio 写指标聚合服务。

API 上报含服务名、指标名、值、时间戳、标签。支持 Counter、Gauge、Histogram 三种类型。同服务名聚合，按 1 分钟窗口同指标名+标签组合取 sum/count/max/min。每 60 秒 flush 到 JSON Lines 文件（按服务名分目录按日期分文件），失败保留内存重试 3 次。启动发现有未 flush 历史数据自动补写。

查询按服务名和时间范围查聚合后指标也支持查实时未 flush 数据。/metrics 导出 Prometheus text format。管理接口展示各服务上报频率、flush 状态、文件大小。端口 PORT 环境变量，cargo build 编译通过。
