微服务间需要消息通道但不想引入 Kafka 重型中间件。用 Spring Boot 2.x（JDK 17，Maven）Netty 实现带广播功能的轻量消息队列。

Topic 两种模式：队列模式（消息只给一个消费者拉取）和广播模式（推给所有订阅者），创建 Topic 时指定。广播模式用推送：消费者订阅时提供回调 URL 有消息主动 POST 过去，推送失败重试 3 次（5/15/45 秒间隔）都失败记死信日志。消息按写入顺序递增编号每个消费者独立维护消费进度。消费需显式确认超时未确认重新投递。

消息持久化 SQLite。管理接口看 Topic 列表、消费者状态和各 Topic 堆积量。端口 server.port。
