order-service 全线超时根因是依赖的 Redis 挂了查半小时才发现。用 Rust tokio/axum 实现带依赖图的级联健康检查。

服务间依赖关系 API 配置成 DAG，检查某服务时上游依赖不健康则标「受影响」。检查从叶子节点逐层往上汇总。探针支持 HTTP（GET 返回 2xx）和 TCP（连接成功）超时可配。状态级别：健康→受影响→不健康→未知。支持定时和手动触发。

依赖图可视化接口返回图结构，支持从不健康节点出发查影响范围。探针结果同服务检查间隔内缓存可手动失效。管理接口看依赖图、各服务状态、影响分析，支持手动标记状态覆盖自动结果。端口 PORT 环境变量，cargo build 编译通过。
