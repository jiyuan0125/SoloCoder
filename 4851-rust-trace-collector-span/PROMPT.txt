排查支付慢请求翻五个服务日志对时间戳两小时才定位第三方慢。用 Rust actix-web/axum 实现带 Span 传播的链路追踪。

支持 HTTP Header 和 gRPC metadata 传播，含 trace-id、span-id、parent-span-id、采样标记、baggage。Baggage 总大小限 2KB 超限截断自动传播下游。Span 存文件按 TraceID 前两位分目录，内存维护最近 1 小时索引。

超阈值自动标慢调用一眼看出瓶颈。搜索按服务名、操作名、耗时范围、时间范围查 Trace 列表。管理接口看存储使用和索引状态。端口 PORT 环境变量，cargo build 编译通过。
