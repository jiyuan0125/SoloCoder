用 actix-web 实现一个带 Span 传播的链路追踪服务。

跨服务传播：支持 HTTP Header 和 gRPC metadata 两种传播方式。传播的 Header 包含：trace-id、span-id、parent-span-id、采样标记、baggage（用户自定义键值对）。

Baggage 传播：用户可以在请求链路中设置 baggage（键值对），自动传播到所有下游 Span。Baggage 有大小限制（总大小不超过 2KB），超限截断。

Span 数据存储在文件中（按 TraceID 的前两位分目录）。内存中维护最近 1 小时的 TraceID 索引。

搜索接口：按服务名、操作名、耗时范围、时间范围搜索 Trace。搜索结果返回 TraceID 列表，可以进一步查看详情。管理接口查看存储使用情况和索引状态。端口 PORT 环境变量。
