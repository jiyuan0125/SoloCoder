后端写了 gRPC 服务前端只认 REST JSON，手动写转换代码蠢又易出错。用 Python aiohttp 实现协议转换网关。

HTTP→gRPC：收到 JSON 按路径匹配 gRPC 方法转 Protobuf 调后端再转回 JSON。gRPC message 嵌套 JSON 对应多层嵌套，枚举 JSON 用字符串 gRPC 用数字双向映射。支持 gRPC 流式响应转 newline-delimited JSON。

WebSocket 桥接：HTTP 客户端 POST 通过 WS 转后端，回复转回 HTTP 响应。也支持反向：后端主动推送存队列客户端长轮询拉。WS 连接池管理断开自动重连（指数退避最大 30 秒）。HTTP 转 WS 后 10 秒没回复返回 504。管理接口看连接状态和消息统计。端口 PORT 环境变量。
