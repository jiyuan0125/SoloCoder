查跨服务问题 SSH 登五六台 grep 对时间戳两小时才定位空指针日志格式还不统一。用 Spring Boot 2.x（JDK 17，Maven）Netty 实现带关联 ID 追踪的日志聚合器。

日志可带 trace_id，按 trace_id 获取完整请求链路日志按时间排序展示。存储用文件，按 trace_id 建倒排索引存内存定期持久化磁盘重启加载。查询按服务名、级别范围、时间范围、标签过滤和消息体全文搜索。

日志去重：相同服务名+消息体+1 分钟内算重复只保留一条标重复次数按服务开关。管理接口看各服务日志量趋势、去重比例、索引内存占用，支持按 trace_id 下载链路日志。端口 server.port。
