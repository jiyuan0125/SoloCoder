后端写了 gRPC 前端要 REST JSON，手动写转换蠢又易出错。用 Go Gin 实现协议转换网关。

HTTP→gRPC：收到 JSON 按路径匹配 gRPC 方法转 Protobuf 调后端再转回 JSON。gRPC message 嵌套 JSON 对应多层嵌套，枚举 JSON 用字符串 gRPC 用数字双向映射。支持 gRPC 流式响应转 newline-delimited JSON。

WebSocket 桥接：HTTP POST 转 WS 发后端后端回复转回 HTTP 响应。反向也支持：后端 WS 主动推送存队列客户端长轮询拉。WS 连接池管理断开自动重连（指数退避最大 30 秒）。转发超 10 秒没回复返回 504。管理看连接和消息统计。端口 PORT 环境变量，go build 编译通过。
