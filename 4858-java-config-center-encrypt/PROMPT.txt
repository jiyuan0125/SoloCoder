用 Spring Boot 2.x 实现一个带加密存储的配置中心。

敏感配置项（如数据库密码、API 密钥）在存储时用 AES-256-GCM 加密。配置项有一个 sensitive 标记。标记为 sensitive 的值在 API 返回时掩码显示（只显示前后 4 位）。

配置项可以引用其他配置项：value 中用 {namespace:key} 语法引用，拉取时自动展开。循环引用检测：如果 A 引用 B，B 又引用 A，拉取时返回错误。

配置分组管理：同一 namespace 下的配置可以按 group 分组，拉取时可以指定 group 获取一组配置。管理接口支持批量操作。端口 PORT 环境变量。
