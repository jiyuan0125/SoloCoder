双十一两台机器同时抢到同一把锁同一订单重复扣款。用 Rust actix-web/axum 实现带锁降级的分布式锁。

加锁生成唯一 token 标识持有者，同一锁名同一时间只允许一个持有者。续期验 token 防别人续你的锁，超时自动释放防死锁。等待队列 FIFO 排队锁释放后按序通知等待者重新竞争。正常锁存内存可配持久化同步写磁盘重启恢复。

锁降级：等待队列超 100 个请求时新获取直接快速失败负载恢复后回正常。统计每把锁获取次数、平均持有时间、最大等待时间按分钟聚合保留 1 小时。管理接口看锁统计、当前模式（正常/降级）、手动切换。端口 PORT 环境变量，cargo build 编译通过。
