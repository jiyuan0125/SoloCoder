用 net/http 写一个二级缓存服务：L1 内存缓存 + L2 文件缓存。

GET 时先查 L1，命中直接返回。L1 未命中查 L2（磁盘文件），命中则加载到 L1 并返回。L2 也没有则返回 miss。

SET 时同时写入 L1 和 L2。L1 用 LRU 淘汰（配置最大项数）。L2 用文件存储，每个缓存项一个文件，文件名是 key 的哈希。L2 过期文件通过后台清理协程每 5 分钟扫描一次。

L1 和 L2 的数据一致性：SET/DELETE 操作先写 L2 再更新 L1。如果 L2 写入失败，不更新 L1（保证数据不丢）。管理接口查看各级缓存命中率和容量。端口 PORT 环境变量。
