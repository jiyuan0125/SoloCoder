大促重启缓存全空数据库 QPS 从 500 飙到 5000 差点打挂主库。用 Go net/http 写二级缓存 L1 内存+L2 文件。

GET 先查 L1 命中直接返回；L1 未命中查 L2 磁盘文件命中加载到 L1 返回；都没有 miss。SET 同时写 L1 和 L2。L1 用 LRU（配最大项数），L2 每个缓存项一个文件后台每 5 分钟扫描过期文件。

一致性：SET/DELETE 先写 L2 再更新 L1，L2 写入失败不更新 L1 保数据不丢。缓存击穿防护：热点 key 过期瞬间只放一个请求回源其他等结果。管理接口看各级命中率和容量。端口 PORT 环境变量，go build 编译通过。
