六个微服务各写 JWT 校验 Token 格式改了六处还漏一个认证跳过两天。用 Spring Boot 2.x（JDK 17，Maven）Netty 实现多因素认证网关。

注册时为用户生成 TOTP 密钥（兼容 Google Authenticator）用户扫码绑定。登录两步：先校验用户名密码通过返回临时 session token（5 分钟有效）；再用该 token 提交 TOTP 验证码验证通过签发正式 access token。验证通过后用户信息注入 Header 转发下游。

防暴力破解：同一用户名连续 5 次密码错误锁定 15 分钟。支持 JWT 签发验证和黑名单机制。

管理接口用户管理（启用/禁用 MFA、解锁）、登录日志查询（成功/失败、来源 IP）、锁定状态查看。端口 server.port。
