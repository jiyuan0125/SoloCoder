查问题 SSH 登五六台 grep 日志对时间戳两小时才定位空指针日志格式还不统一。用 Rust tokio/axum 实现多格式日志采集器。

通过 Content-Type 区分三种格式：JSON 直接解析，Syslog 按 RFC5424 解析，纯文本用预配置正则提取时间、级别、消息等字段（正则通过管理 API 动态配置）。所有格式统一转内部 JSON 存储。转换失败不丢弃单独写错误文件。

流量洪峰时按比例丢弃 INFO/DEBUG 日志（ERROR/WARN 始终保留），采样比例根据每秒阈值动态调整。查询按服务名、级别、时间范围过滤和消息体全文搜索。

管理接口展示各格式接收量、转换失败数、当前采样比例。数据存内存。端口 PORT 环境变量，cargo build 编译通过。
