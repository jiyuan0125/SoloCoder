用 Gin 写一个多格式日志采集器。

支持接收三种格式的日志：JSON（结构化）、Syslog（RFC5424）、单行文本（需要正则提取字段）。格式通过提交接口的 Content-Type 区分。单行文本需要预配置正则模式（如提取时间、级别、消息），模式通过管理 API 配置。

所有格式最终统一转换为内部 JSON 结构存储。转换失败的日志存到单独的错误文件中，不丢失。

日志采样：当日志量超过配置的每秒阈值时，按比例丢弃部分 INFO/DEBUG 日志（ERROR/WARN 不丢弃）。采样比例动态调整。

管理接口查看：各格式日志的接收量、转换失败数、采样比例。端口 PORT 环境变量。
