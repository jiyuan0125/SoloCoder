查跨服务问题 SSH 登五六台 grep 对时间戳两小时才定位空指针日志格式还不统一。用 Go Gin 实现多格式日志采集器。

通过 Content-Type 区分输入格式：JSON 直接解析，Syslog 按 RFC5424 解析，纯文本用管理 API 预配置的正则提取时间、级别、消息等字段。所有日志统一转内部 JSON 存储。转换失败不丢弃写入独立错误文件。先放缓冲队列再批量持久化 SQLite。

日志洪峰时按比例采样丢弃 INFO/DEBUG（ERROR/WARN 全保留），采样率根据每秒阈值动态调整。查询按服务名、级别、时间范围、标签过滤和消息体全文搜索。

管理接口展示各格式接收量、转换失败数、采样比例。端口 PORT 环境变量，go build 编译通过。
