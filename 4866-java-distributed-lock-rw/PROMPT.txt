双十一两台机器同时抢到锁同一订单重复扣款。缓存击穿场景大量并发读偶尔穿插写，全局互斥锁太重读写锁才兼顾安全与吞吐。用 Spring Boot 2.x（JDK 17，Maven）实现分布式读写锁。

读锁共享：无写锁时多个读锁可同时持有。写锁独占：必须等全部读写锁释放。写优先策略防止饿死——有写锁在等时新读锁排队。

锁带 TTL（默认 60 秒）超时自动释放。获取返回 token 释放和续期必须携带 token。续期可延长 TTL 上限最大 TTL（默认 5 分钟）。支持读锁升级写锁：无其他读锁立即成功否则等待升级期间原读锁持续有效。

管理接口查看当前锁状态和等待队列。数据存 SQLite 或内存。端口 server.port。
