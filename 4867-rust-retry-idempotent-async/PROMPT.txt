服务间调用失败不能无限重试也不能丢请求。用 Rust axum/tokio 做带退避策略和死信机制的异步重试调度器。

失败的 HTTP 请求（含目标 URL、方法、请求体、重试次数、下次重试时间）记入重试队列，后台调度器定时扫描到期请求重新发送。退避间隔递增：1min→5min→30min→2h→12h。达到最大重试次数（默认 5 次）移入死信不再重试。

目标返回 4xx 不重试直接进死信。重试成功从队列移除。idempotency_key 保证相同请求不重复执行。

管理接口提供重试队列大小、各状态码重试分布、死信队列查看，支持手动触发重试和从死信恢复到重试队列。数据存内存。端口 PORT 环境变量，cargo build 编译通过。
