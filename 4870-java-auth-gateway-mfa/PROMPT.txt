用 Spring Boot 2.x 写一个带多因素认证的网关。

基本认证：用户名密码校验。多因素：密码正确后还需要 TOTP 验证码（Google Authenticator 兼容）。TOTP 密钥在用户注册时生成，用户需要绑定到 Authenticator App。

认证流程：先提交用户名密码，密码正确返回一个临时 session token（5 分钟有效）。用 session token 提交 TOTP 验证码，验证通过后返回正式 access token。

登录保护：同一用户名连续 5 次密码错误，锁定 15 分钟。锁定期间即使密码正确也不允许登录。

管理接口：用户管理（启用/禁用 MFA、解锁账户）、查看登录日志（包含成功/失败、来源IP）、查看锁定状态。端口 PORT 环境变量。
