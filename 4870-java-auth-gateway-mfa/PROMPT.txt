Spring Boot 2.x 做一个认证网关，带 RBAC 角色鉴权和 API 密钥管理。

用户注册时分配角色（admin/operator/viewer）。每个角色有不同的权限集合，权限粒度到 HTTP 方法 + 路径前缀，比如 operator 可以 POST /api/tasks 但不能 DELETE /api/users。登录后返回 JWT token，token 里包含角色信息。

API 密钥管理：用户可以创建多个 API 密钥，每个密钥绑定到特定的权限子集（不超过该用户角色的权限范围）。密钥有过期时间，到期自动失效。通过 X-API-Key 头认证，和 JWT 认证二选一。密钥使用有频率限制，超过限制返回 429。

鉴权网关作为前置拦截器，请求进来后验证 token 或密钥，然后检查该请求的路径和方法是否在权限范围内。鉴权失败的请求记录到审计日志。管理接口：角色和权限配置、密钥列表和状态、审计日志查询。端口 PORT 环境变量。
