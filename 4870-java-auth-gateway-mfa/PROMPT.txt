六个服务各写 JWT 校验 Token 改六处还漏一个。全系统用 admin token 万能通行权限粒度太粗。用 Spring Boot 2.x（JDK 17，Maven）做 RBAC 鉴权网关附带 API 密钥管理。

用户注册分配角色（admin/operator/viewer），每个角色绑定一组权限粒度到 HTTP 方法+路径前缀。登录签发 JWT token 内含角色信息。

API 密钥：用户可创建多个密钥权限不超过所属角色范围，设过期时间到期自动失效。通过 X-API-Key 头认证与 JWT 二选一。密钥设频率限制超限 429。

网关前置拦截验证 token 或密钥后检查路径+方法权限，鉴权失败写审计日志。管理接口角色权限配置、密钥列表与状态、审计日志查询。端口 server.port。
