上下游数据格式不统一——JSON、XML、YAML、CSV 混着来，每次对接手写转换太低效。用 Rust actix-web/axum 做通用格式转换网关。

转换接口指定源格式和目标格式 POST 源数据返回转换结果。JSON↔XML：XML 属性对应 @attr 文本内容对应 #text，数组元素需配置标注。JSON↔CSV：列名取 JSON key（首行表头），嵌套字段点号展平（如 address.city），数组生成多行。

也支持 JSON↔Protobuf（gRPC 服务场景）枚举双向映射字符串和数字。每种格式对可独立配置转换规则（字段映射、默认值、格式化选项）规则通过管理 API 管理。端口 PORT 环境变量，cargo build 编译通过。
