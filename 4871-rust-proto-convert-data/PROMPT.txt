用 actix-web 写一个数据格式转换网关。

支持 JSON、XML、YAML、CSV 四种格式之间的互转。转换接口：指定源格式和目标格式，POST 源数据，返回转换后的数据。

JSON↔XML：XML 属性映射为 JSON 对象的 @attr 字段。XML 文本内容映射为 #text 字段。数组元素需要特殊的类型提示（通过配置指定哪些 XML 元素是数组）。

JSON↔CSV：CSV 的列名从 JSON 对象的 key 生成（第一行是表头）。嵌套 JSON 展平为点号分隔的列名（如 address.city）。数组类型的 JSON 转换为多行 CSV。

转换配置：每种格式对可以独立配置转换规则（字段映射、默认值、格式化选项）。配置通过管理 API 管理。端口 PORT 环境变量。
