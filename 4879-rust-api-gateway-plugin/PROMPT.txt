认证限流日志跨域每个接口需求组合不同全塞框架层太臃肿。用 Rust actix-web/axum 做插件式 API 网关插件按路由灵活编排。

路由按路径前缀匹配支持通配符，每条路由可挂多个插件按顺序执行。内置插件：JWT 认证、令牌桶限流、请求响应日志、CORS 头注入、请求改写（头部和路径）。配置 API 为每条路由独立启用插件并设参。链中任一插件失败直接中断返回对应错误码。日志插件异步写入不阻塞。

下游只管业务不用操心公共逻辑改一个规则只改网关一处。管理接口查看路由列表、各路由插件配置及执行统计（调用次数、失败次数、平均耗时）。端口 PORT 环境变量，cargo build 编译通过。
