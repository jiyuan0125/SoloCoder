线上配置改坏了想回滚却没历史版本可查——配置中心没有 diff 和回滚就是裸奔。用 FastAPI 实现带版本管理和变更推送的配置中心。

配置按 namespace/key 组织，每次变更生成递增版本号历史可查可回滚（回滚生成新版本）。客户端拉取时可指定版本号不指定返回最新。diff 接口传入两个版本号返回哪些 key 变了及新旧值对比。

变更通知支持长轮询和 WebSocket：长轮询客户端带当前版本号有新版立即返回否则阻塞最多 30 秒。灰度发布：修改时指定只对特定标签实例生效先观察再全量推送。

配置支持按 namespace 导出 JSON 和从 JSON 导入（导入时校验格式）。端口 PORT 环境变量。
