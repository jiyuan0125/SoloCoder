写一个事件调度引擎，用 Netty。基于事件触发而非定时。

规则配置：每条规则指定事件类型（如 order.created、user.registered）、条件表达式（简单比较：字段名 op 值）、触发动作（HTTP 回调）。

事件提交：通过 API 提交事件（类型 + 数据）。调度器匹配所有规则，找到满足条件的规则，执行对应的动作。多个规则匹配时并行执行。

动作执行结果记录：成功/失败/超时。失败的动作按配置重试（默认 3 次，指数退避）。

事件去重：相同事件类型 + 相同事件数据 + 1 分钟内视为重复，只处理第一次。去重缓存定期清理。

规则优先级：多个规则匹配时可以按优先级排序执行（高优先级先执行，执行结果作为低优先级规则的输入上下文）。管理接口 CRUD 规则、查看执行日志。端口 PORT 环境变量。
