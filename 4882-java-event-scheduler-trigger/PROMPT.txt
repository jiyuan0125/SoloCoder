定时任务只适合周期性作业，业务里大量"某件事发生后触发动作"的需求靠 cron 搞不定。用 Spring Boot 2.x（JDK 17，Maven）Netty 做事件驱动的调度引擎。

事件触发规则：定义源事件类型和目标动作（回调 URL），源事件发生时引擎匹配规则触发目标。支持 Cron 周期任务和延迟任务。规则支持条件过滤：事件 payload 中的字段满足条件才触发（如 amount>1000 才通知）。

触发失败自动重试最多 3 次间隔递增。动作执行记录存 SQLite 含触发时间、耗时、结果。事件去重：同类型同 key 在去重窗口（可配）内只触发一次。

管理接口 CRUD 规则、查看触发历史、规则命中统计。端口 server.port。
