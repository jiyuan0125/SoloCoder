写一个消息协议适配器，用 Spring Boot 2.x。

适配不同消息格式的系统之间的通信。内置适配器：JSON-RPC、XML-RPC、SOAP（简化版，只支持基本操作）。

适配规则配置：源协议 + 目标协议 + 方法映射表。方法映射把源协议的方法名和参数映射到目标协议的方法名和参数。参数映射支持重命名、类型转换、默认值填充。

适配过程记录日志：源请求、转换后的目标请求、目标响应、转换后的源响应。日志异步写入文件。

错误适配：如果源请求中的方法在目标协议中没有映射，返回 404。参数类型不匹配尝试自动转换（字符串数字互转），转换失败返回 400。管理接口查看适配统计和错误日志。端口 PORT 环境变量。
