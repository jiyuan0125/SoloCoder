十个内部系统各一套登录页用户每天输十次密码。用 Go Gin/Fiber 做 SSO 网关登录一次全线通行。

用户登录时创建 SSO session，通过配置的回调 URL 通知所有关联服务。任一服务发起登出网关清除 session 并通知全部关联方。session 有效期可配置默认 8 小时。Token 用 JWT payload 含用户 ID、角色、session ID、签发时间。验证通过后用户信息注入 Header 转发下游。

角色权限通过配置 API 管理每个角色对应一组允许的路由前缀。下游完全不用碰 Token 代码。

管理接口查看 session 列表、关联服务状态、角色权限配置。端口 PORT 环境变量，go build 编译通过。
