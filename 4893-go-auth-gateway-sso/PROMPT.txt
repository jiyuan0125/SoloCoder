写一个认证网关，支持 SSO 单点登录，用 Fiber。

用户登录一次后，token 在多个关联服务之间共享。网关维护一个 SSO session：用户登录时创建 session，关联的各个服务（通过配置的回调 URL）都收到 session 创建通知。

任一服务发起登出时，网关清除 session 并通知所有关联服务。SSO session 有效期可配置（默认 8 小时）。

Token 格式：JWT，payload 包含用户ID、角色、session ID、签发时间。角色权限通过配置 API 管理：每个角色对应一组允许的路由前缀。

审计日志：所有认证事件（登录、登出、token 刷新、认证失败）都记录日志，包含时间、用户、来源IP、事件类型。审计日志不可删除，保留 90 天。端口 PORT 环境变量。
