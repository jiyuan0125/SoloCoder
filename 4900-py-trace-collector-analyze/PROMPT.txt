排查慢请求时只知道"慢"不知道慢在哪一层——链路追踪数据散落在各服务日志拼不出全貌。用 FastAPI 做轻量链路追踪服务重点在数据组装和统计。

Span 通过 HTTP API 上报每个含 trace_id、span_id、parent_span_id、service、operation、start_time、duration_ms、status、tags。自动按 trace_id 分组构建调用树（树结构 JSON 导出根节点 parent_span_id 为空）。

超阈值自动标慢调用。统计每服务平均耗时、慢调用 Top N、服务间调用频率。查询按 trace_id 查完整链路、按服务名和时间范围查 Trace 列表。

管理接口查看存储使用和索引状态。端口 PORT 环境变量。
