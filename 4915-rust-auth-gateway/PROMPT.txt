六个微服务各写 JWT 校验 Token 格式改了六处还漏一个认证跳过两天。用 Rust axum/tokio 做认证网关统一验身份。

网关签发验证 JWT，请求验签名（HMAC-SHA256）和有效期通过后用户 ID、角色注入 Header 转发下游。失败返回 401。access_token 有效期可配（默认 15 分钟），过期后拿 refresh_token 换新的。

黑名单机制：管理员接口可把 token 加黑名单未过期也拒绝。角色权限映射表通过管理接口动态配置即时生效。/health、/login 公开路径免认证。

数据存内存。端口 PORT 环境变量，cargo build 编译通过。
