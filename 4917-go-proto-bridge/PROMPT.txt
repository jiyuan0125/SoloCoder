改个配置要重启所有服务配置热更新是刚需。用 Go Gin 做通用协议转换网关一套配置搞定 REST↔gRPC 双向转换。

对外暴露 RESTful 接口，根据路由表找对应 gRPC 方法 JSON 请求体转 Protobuf 调后端再转回 JSON。路径和 gRPC 方法映射通过 YAML 配置。gRPC message 嵌套 JSON 对应多层嵌套，枚举 JSON 用字符串 gRPC 用数字双向映射。

支持 gRPC 服务端流式响应转 newline-delimited JSON。proto 文件路径和后端地址通过配置加载。后端不可用或超时返回 503。

配置改完调接口热加载不重启。端口 PORT 环境变量，go build 编译通过。
