排查支付慢请求翻五个服务日志对时间戳两小时才定位第三方慢。用 Spring Boot 2.x（JDK 17，Maven）做分布式链路追踪。

每个请求全局唯一 TraceID 通过 HTTP Header 传播。每次调用产生 Span 含 SpanID、ParentSpanID、服务名、操作名、起止时间、标签。SDK 做成独立 Java 包：Servlet Filter 拦截自动创建 Span，RestTemplate 拦截器注入追踪 Header 业务不用改。

Span 数据按 TraceID 聚合构建调用树存 SQLite。超阈值自动标慢调用。查询按 TraceID 查完整链路、按服务名查、按耗时排序找 Top N。

结果展示耗时树状结构。端口 server.port。
