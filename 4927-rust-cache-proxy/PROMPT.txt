大促重启缓存全空，数据库 QPS 飙到 5000 差点打挂主库。启动时自动加载热点数据，请求先查缓存命中直接返回。过期策略 LRU/LFU，容量满有序淘汰。热点 key 过期瞬间只放一个请求回源其他等结果（缓存击穿防护）。

缓存淘汰区分活跃、过期、淘汰三种状态，支持按标签批量失效。用 axum 实现。

活跃状态正常读写。TTL 到了进过期状态，过期数据不返回但仍在内存。后台清理任务删除过期数据进入淘汰状态，也可手动触发。支持标签，按标签批量删除时所有带该标签 key 一起淘汰。

接口查看每个标签下 key 数量和最近淘汰时间。Rust tokio/axum，cargo build 编译通过。端口 PORT 环境变量。
