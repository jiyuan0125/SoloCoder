新实例上线都手动改 Nginx 再 reload 太麻烦。注册中心自动化：实例启动时注册上报 IP、端口、标签、权重，定期心跳续约，连续多次没收到自动注销。其他服务 WebSocket 订阅变更实时感知上下线。查询按服务名和标签过滤，权重 0 不参与路由但不注销方便摘流量。

用 Go 标准库实现。服务分组管理，每组下多个实例。状态流转：注册中→健康→不健康→注销（注册中未通过首次检查，不健康超配置次数自动注销）。服务变更时 HTTP 回调通知订阅者，失败记日志不影响其他订阅者。

接口：注册/注销实例、订阅变更通知、查询实例列表。端口 PORT 环境变量。go build 编译通过。数据存内存。
