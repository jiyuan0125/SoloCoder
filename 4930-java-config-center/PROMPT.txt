改超时参数要重启十几个服务。配置热更新不用重启——改完长轮询实时推送，实例拿新值立即应用。配置按 namespace/group/key 三级组织，每次修改自增版本号可查可回滚。灰度发布：修改时指定只对特定标签实例生效先观察，没问题再全量推送，有问题一键回滚。

用 Spring Boot 实现。三模块：存储引擎（KV CRUD + 版本管理）、推送服务（变更通知 + 重试）、API 层，事件解耦。存储写入后发布事件，推送服务订阅并 HTTP 回调通知。重试间隔 1s/2s/4s，最多 3 次，全失败标记订阅异常。

API 层提供配置增删改查、订阅管理、推送历史查询。Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
