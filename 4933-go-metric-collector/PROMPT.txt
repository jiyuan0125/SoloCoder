给 Prometheus 对接指标时 Histogram bucket 累计值算错导致监控图诡异尖峰。指标采集导出应封装好不用每次手写。支持 Counter（只增）、Gauge（可增减）、Histogram（分布）三种类型。客户端 HTTP 上报指标值，相同指标名加标签做聚合。导出以 Prometheus text format 输出，Histogram 自动算 count、sum 和 bucket 累计值。

用 Go 标准库实现。上报数据做校验：Counter 递减上报忽略并记告警。Gauge 非数字值忽略。Histogram 观测值忽略负数，上限 1e9。批量上报一次提交多个指标，单条异常不影响其余。Prometheus 格式导出。

端口 PORT 环境变量。go build 编译通过。数据存内存。
