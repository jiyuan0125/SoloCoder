order-service 全线超时但根因是依赖的 Redis 先挂了。按依赖树逐层检查一眼看出根因。做健康检查编排服务，配置依赖关系形成 DAG，检查从叶子节点逐层往上汇总，底层不健康上层也标异常。探针支持 HTTP（GET 2xx）和 TCP（连接成功），超时可配。结果分 healthy、degraded、unhealthy。支持定时和手动触发。

用 Spring Boot 做 DAG 健康检查框架。三模块：探针管理、调度引擎（定时执行）、状态聚合。依赖关系从配置加载形成 DAG，有环拒绝。某探针不健康时依赖它的探针跳过检查标为降级。

状态聚合返回每个探针状态和整体健康状态（取最差值）。Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
