六个微服务每个都自己写 JWT 校验逻辑代码重复，Token 格式改了六个地方都得改还漏了一个。认证网关挡在业务前面统一验身份，签发和验证 JWT，请求经过网关验证 Token 签名和有效期，通过后把用户 ID 和角色注入 Header 转发下游。下游不用碰 Token 代码。支持黑名单机制，注销后所有已签发 Token 立即失效。

用 axum 实现双模式认证网关。API Key（X-API-Key 头）对应租户，租户有配额限制。JWT payload 含 scope 字段，不同 scope 对应不同权限。未认证返回 401，认证但无权限返回 403。每次请求记录认证方式和结果到日志。

Rust tokio/axum，cargo build 编译通过。端口 PORT 环境变量。
