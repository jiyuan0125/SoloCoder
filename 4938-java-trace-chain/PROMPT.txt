排查支付接口慢请求要翻五个服务日志拼调用链对时间戳，花了两小时才定位到第三方余额查询慢。做分布式链路追踪，每个请求有全局唯一 TraceID 通过 HTTP Header 自动传播。每次调用产生 Span 记录起止时间，所有 Span 按 TraceID 聚合构建调用树展示耗时。超阈值自动标慢调用一眼看出瓶颈。查询按 TraceID、服务名、耗时排序。

用 Spring Boot 做链路追踪。Span 状态严格按序流转（创建→开始→结束→上报→归档），不能跳级。每个 Span 有 tags（KV 对）和 logs（带时间戳事件）。通过 parent_span_id 建立父子关系构建 Trace 树。

Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
