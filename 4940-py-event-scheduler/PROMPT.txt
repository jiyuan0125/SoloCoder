crontab 管定时任务太原始，改 cron 表达式还得 SSH 登机器，没法看执行历史。上个月数据对账任务静默失败三天才发现。做定时任务调度器全走 HTTP 接口，Cron 表达式定义周期任务，延迟任务定时执行。到期后调回调 URL 通知业务方，失败自动重试最多 3 次。任务可暂停和恢复，暂停不触发恢复后继续。执行历史异步写 SQLite 不阻塞调度。

用 FastAPI 实现。支持 Cron 周期任务和一次性延迟任务，超时按任务配置。任务数据存 SQLite，写入锁住时重试 3 次。执行失败按指数退避重试最多 3 次。

管理接口查看任务列表和执行日志（起止时间和结果）。Python 异步框架（FastAPI/aiohttp）。端口 PORT 环境变量。
