微服务间需要消息通道但不想引入 Kafka 那种重型中间件。做轻量 Topic 模式消息代理：生产者往 Topic 发消息，消费者订阅 Topic 指定消费起始位置。消息按写入顺序递增编号，每个消费者独立维护消费进度。消费需显式确认超时重新投递，失败多次进死信队列可查可重新投递。

用 Spring Boot 实现。消息按 Topic 组织，Topic 可多分区。发送时指定 Topic 和可选分区 Key：有 Key 哈希到固定分区，无 Key 轮询分配。消费者可指定消费起始位置（最早/最新/指定 offset）。

管理接口创建/删除 Topic、查看消费者状态和队列深度。Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
