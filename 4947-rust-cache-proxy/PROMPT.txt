大促重启缓存全空，数据库 QPS 飙到 5000 差点打挂主库。冷启动穿透是定时炸弹——启动时自动加载热点数据，请求先查缓存命中直接返回。过期策略 LRU 或 LFU，容量满有序淘汰。热点 key 过期瞬间只放一个请求回源其他等结果（缓存击穿防护）。

缓存不是一个大池子——不同业务要隔离。用 axum 实现多命名空间缓存。每命名空间独立容量和淘汰策略（LRU 或 LFU，创建时选定不可改）。缓存值支持版本号：带版本号写入仅在版本号比现有值大时更新，不带则直接覆盖。命名空间可冻结：冻结后只读不写。

管理接口查看所有命名空间状态。Rust tokio/axum，cargo build 编译通过。端口 PORT 环境变量。
