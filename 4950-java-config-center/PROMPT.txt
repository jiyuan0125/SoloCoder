改个超时参数要重启十几个服务。配置热更新不用重启——改完通过长轮询实时推送到所有实例，实例拿新值立即应用。配置按 namespace/group/key 三级组织，每次修改自增版本号可查可回滚。灰度发布：修改时指定只对特定标签实例生效先观察，没问题再全量推送，有问题一键回滚。

YAML 配置支持嵌套——查询时用路径表达式（如 app.database.url）直接取深层值。用 Spring Boot 做配置中心。配置变更通知采用长轮询：客户端带版本号请求，有变更立即返回，无变更 hold 最多 30 秒。导入导出支持整个命名空间 YAML 序列化，导入时冲突由客户端选覆盖或跳过。

Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
