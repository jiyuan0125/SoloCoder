两台机器同时抢到分布式锁导致重复扣款。光靠 Redis SETNX 不够，续期、解锁、防死锁每个环节都致命。加锁时生成唯一 token 标识持有者，同一锁名同一时间只允许一个。续期必须验 token，超时自动释放防死锁。等待队列 FIFO 排队，锁释放后按顺序通知等待者重新竞争。

锁名称只允许字母数字下划线、最大 128 字符。用 axum 实现。获取不存在的锁自动创建并获取。释放时锁不存在或被他人持有返回冲突。超时精度到毫秒，到期后等待队列下一个请求自动获取。同一客户端对同一把锁获取两次（非续期）第二次进等待队列。

管理接口查看锁状态。Rust tokio/axum，cargo build 编译通过。端口 PORT 环境变量。
