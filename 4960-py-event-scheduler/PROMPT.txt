crontab 管定时任务太原始，改 cron 表达式还得 SSH 登机器。做定时任务调度器全走 HTTP 接口，Cron 表达式定义周期任务，延迟任务定时执行。到期后调回调 URL 通知业务方，失败自动重试最多 3 次。任务可暂停和恢复，执行历史异步写 SQLite 不阻塞调度。

任务状态机严格管控——草稿→已调度→运行中→完成/失败/超时，不能跳级。用 aiohttp 实现。草稿不参与调度，已调度等待触发。完成后可重新调度回已调度，失败和超时同理。不能从草稿直接跳运行中。状态变更和执行结果记审计日志。

管理接口：创建任务、手动触发、查看状态流转历史。Python aiohttp。端口 PORT 环境变量。
