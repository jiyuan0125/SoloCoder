十几个服务每个都对外暴露端口，防火墙规则配到崩溃，认证逻辑各不相同。统一网关集中管理。

七八个内部微服务都注册到网关后面，对外只暴露网关地址。用 Go 标准库实现。POST /admin/services 注册服务（service_name、path_prefix、upstream_urls），同 prefix 返回 409。路由最长前缀匹配。IP 黑名单：配置文件列 IP 或 CIDR 段命中返回 403。PUT /admin/blacklist 更新立即生效。多实例随机转发，超时 10 秒返回 504，失败不重试记错误日志。

日志 JSON 格式写 stdout。GET /admin/logs/recent 返回内存最近 200 条。go build 编译通过。端口 PORT 环境变量。
