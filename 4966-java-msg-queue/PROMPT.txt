微服务间需要消息通道但不想引入 Kafka。做轻量 Topic 模式消息代理：生产者往 Topic 发消息，消费者订阅指定消费起始位置。消息按写入顺序递增编号，每个消费者独立维护消费进度。消费需显式确认超时重新投递，失败多次进死信队列可重新投递。

消息生命周期严格管控：创建→就绪→投递中→已确认/已拒绝/已过期。用 Spring Boot 实现。消息创建进就绪，消费者拉取进投递中，确认变已确认，拒绝变已拒绝。超时未确认回到就绪重试，重试次数超限进死信队列。死信队列支持批量重新投递到原 Topic。

接口查看消息状态和流转历史。Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
