大促重启缓存全空，数据库 QPS 飙到 5000 差点打挂主库。冷启动穿透是定时炸弹——启动时自动加载热点数据，请求先查缓存命中直接返回。过期策略 LRU 或 LFU，容量满有序淘汰。热点 key 过期瞬间只放一个请求回源其他等结果（缓存击穿防护）。

缓存 value 要字节级精确——写什么读什么。用 actix-web 做缓存代理。配置从 TOML 文件读取。key 最大 256 字节，value 最大 1MB，超限返回错误。TTL 支持秒级和毫秒级，过期检查读取时触发（惰性删除），后台定时清理兜底。

统计接口按 TTL 范围分桶统计 key 数量分布。Rust tokio/axum，cargo build 编译通过。端口 PORT 环境变量。
