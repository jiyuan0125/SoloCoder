改个超时参数要重启十几个服务才能生效。配置热更新不用重启——改完通过长轮询实时推送，实例拿新值立即应用。配置按 namespace/group/key 三级组织，每次修改自增版本号可查可回滚。灰度发布：修改时指定只对特定标签实例生效先观察，没问题再全量推送，有问题一键回滚。

配置按 app + env + key 组织，变更检测和通知推送分层解耦。用 Spring Boot 实现。三分层：存储层（内存 Map）、变更检测层（对比新旧值没变不触发通知）、通知层（100ms 内同 app 连续变更合并成一次回调推送）。

接口支持按 app/env 查询配置、批量修改、查看变更历史。Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
