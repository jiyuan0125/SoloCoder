actix-web 做认证网关。OAuth2 授权码模式。

角色：客户端（client_id + client_secret）、用户（username + password）、授权服务器（就是本服务）。

授权流程：客户端重定向用户到授权页面 → 用户登录并同意 → 授权服务器返回授权码 → 客户端用授权码换 Token。

Token 有 access_token 和 refresh_token。access_token 有效期 1 小时，refresh_token 有效期 7 天。

所有 Token 用 JWT 签发。签名密钥从环境变量读取。

管理接口：注册客户端、管理用户。

PORT 环境变量，cargo build 通过。
