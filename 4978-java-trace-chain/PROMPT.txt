排查支付接口慢请求要翻五个服务日志拼调用链对时间戳，花了两小时才定位。做分布式链路追踪，每个请求有全局唯一 TraceID 通过 HTTP Header 自动传播。每次调用产生 Span 记录起止时间，所有 Span 按 TraceID 聚合构建调用树展示耗时。超阈值自动标慢调用。查询按 TraceID、服务名、耗时排序。

四模块——Span 管理、采样策略、存储引擎、查询服务职责清晰。用 Spring Boot 实现。采样策略支持全量、概率（如 10%）、速率限制（每秒最多 N 个 Trace）。存储用内存按 TraceID 索引。查询支持按 TraceID 查完整链路、按服务名查最近 Trace、按时间范围查。

Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
