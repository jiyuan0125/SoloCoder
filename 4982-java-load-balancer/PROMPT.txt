用户反馈 WebSocket 消息时有时无，排查发现普通轮询把同一用户连接分到了不同节点。有状态服务必须用一致性哈希或加权策略才能正确分配。

千级实例批量导入——地址校验、去重、跳过无效条目，不能因一条脏数据阻断整批。用 Spring Boot 做负载均衡器。POST /api/backends/batch 批量导入，校验地址格式、权重 >0、去重，返回 total/success/failed 及失败原因。策略用最少活跃连接数：转发前 +1、响应后 -1，同连接数随机选。

健康检查每 20 秒 GET /health（超时 3 秒），连续 3 次失败标 unhealthy。GET /api/stats 返回全局统计。Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
