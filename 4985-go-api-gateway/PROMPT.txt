十几个服务每个都对外暴露独立端口，防火墙规则配到崩溃，认证逻辑各不相同。统一 API 网关集中管理：路由分发、统一认证鉴权、令牌桶限流、请求日志。下游只管业务不用操心认证限流，改认证规则只改网关一处。

路由支持路径参数和通配符（/api/{service}/{version}/*path），版本兼容降级。用 Gin 实现。{service} 和 {version} 是路径参数，*path 匹配剩余。版本兼容：v1 请求后端无 v1 自动降级到最新版本。鉴权插件按路由选 API Key 或 JWT 模式。未配鉴权的路由默认拒绝。

网关配置支持热更新。Go+Gin，go build 编译通过。端口 PORT 环境变量。数据存内存。
