大促重启缓存全空数据库 QPS 飙到 5000 差点打挂主库。冷启动穿透是定时炸弹——启动时自动加载热点数据，请求先查缓存命中直接返回。过期策略 LRU 或 LFU，容量满有序淘汰。热点 key 过期瞬间只放一个请求回源其他等结果（缓存击穿防护）。

分布式缓存单机模拟——多 shard 各自独立锁，跨 shard 操作不能死锁，支持简单事务。用 axum 实现。shard 数量启动时配置，key 通过一致性哈希分配。每 shard 独立锁，跨 shard 批量操作按哈希顺序加锁防死锁。事务：multi 开始缓存写操作，exec 原子执行。

管理接口查看每 shard 负载和 key 分布。Rust tokio/axum，cargo build 编译通过。端口 PORT 环境变量。
