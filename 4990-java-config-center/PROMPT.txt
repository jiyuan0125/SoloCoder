改超时参数要重启十几个服务。配置热更新——改完长轮询实时推送，实例拿新值立即应用。配置按 namespace/group/key 三级组织，每次修改自增版本号可查可回滚。灰度发布：指定只对特定标签实例生效先观察，没问题全量推送，有问题一键回滚。

配置有类型（string/number/boolean/json）——写入校验，环境覆盖回退默认值，变更记审计日志。用 Spring Boot 实现。类型校验：number 需可转数字，boolean 只接受 true/false，json 需可解析。同 key 不同环境可有不同值，无特定值回退默认。审计记录谁、何时、改了什么。

三模块：配置存储、类型校验、审计日志。Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
