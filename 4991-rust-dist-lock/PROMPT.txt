两台机器同时抢到分布式锁导致重复扣款。光靠 Redis SETNX 不够，续期、解锁、防死锁每个环节都致命。加锁时生成唯一 token 标识持有者，续期必须验 token，超时自动释放防死锁。等待队列 FIFO，锁释放后按顺序通知等待者。

可重入 + 读写锁 + 持久化——锁状态不能因重启丢失。用 axum 实现。同一持有者可多次获取同一把锁需等量释放。读写锁：读锁共享写锁排他读写互斥。获取可指定等待超时。锁信息持久化到文件，重启后通过 lock_id + 时间戳判断是否超时恢复状态。

接口查看所有锁的类型、持有者、等待队列。Rust tokio/axum，cargo build 编译通过。端口 PORT 环境变量。
