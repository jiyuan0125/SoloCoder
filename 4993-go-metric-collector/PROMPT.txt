给 Prometheus 对接指标时 Histogram bucket 累计值算错导致监控图诡异尖峰。指标采集导出应封装好。支持 Counter、Gauge、Histogram 三种类型，客户端 HTTP 上报，相同指标名加标签做聚合。导出以 Prometheus text format 输出，Histogram 自动算 count、sum 和 bucket 累计值。

指标从 JSON 文件初始化（不存在用空配置启动不退出），上报密集时不能让聚合计算拖慢响应。用 Fiber 实现。上报接口快速返回，聚合计算异步每 10 秒一次。查询接口返回指定时间范围内聚合数据，可跨多个聚合周期。Prometheus 格式输出。

Go+Fiber，go build 编译通过。端口 PORT 环境变量。数据存内存。
