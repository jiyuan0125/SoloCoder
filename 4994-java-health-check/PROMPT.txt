order-service 全线超时但根因是依赖的 Redis 先挂了。按依赖树逐层检查一眼看出根因。做健康检查编排服务，配置依赖关系形成依赖树，检查从叶子节点逐层往上汇总，底层不健康上层也标异常。探针支持 HTTP（GET 2xx）和 TCP（连接成功），超时可配。结果分 healthy、degraded、unhealthy。支持定时和手动触发。

上百个探针同时运行在独立 EventLoop，状态表被多线程读写。用 Netty 实现健康检查。每个探针独立 EventLoop，结果写入共享状态表需线程安全。状态变更通知在单独线程池执行不阻塞检查。批量查询返回所有探针状态，查询瞬间可能有变更不强求一致性。

Spring Boot 2.x（JDK 17，Maven）。端口 server.port。
