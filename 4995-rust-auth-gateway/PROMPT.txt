六个微服务每个都写 JWT 校验逻辑代码重复，Token 格式改了漏了一个导致部分接口裸奔两天。认证网关挡在业务前面统一验身份，签发和验证 JWT，通过后把用户 ID 和角色注入 Header 转发下游。下游不用碰 Token 代码。支持黑名单机制注销后所有 Token 立即失效。

大量并发请求同时验证不同 Token——验证不能互阻塞，refresh_token 重放要检测并告警。用 tokio 实现。Token 用 crypto-safe 随机数生成存内存。刷新时旧 refresh_token 立即失效生成新的。重放检测：旧 refresh_token 被再次使用则拒绝并触发安全告警。

Rust tokio/axum，cargo build 编译通过。端口 PORT 环境变量。
