Spring Boot 做一个加权负载均衡器，后端权重动态可调。

后端列表在启动时加载，每个后端有权重（1-100）。请求按权重比例分发。权重越高的后端分配越多请求。权重为 0 的后端不接收新请求但保持健康检查。

健康检查：每 10 秒对每个后端发一次 HTTP 探测。连续 3 次失败标记不健康，不健康的后端不参与负载均衡。连续 2 次成功恢复。不健康后端上的已有请求正常完成。

权重动态调整：管理员通过接口修改后端权重。修改后立即生效。支持批量调整（比如一键把某组后端权重设为 0 做维护）。权重变更记录审计日志。

统计接口：每个后端的请求总数、成功数、失败数、平均响应时间、当前权重和健康状态。后端总数可能有几十个。端口 PORT 环境变量。
