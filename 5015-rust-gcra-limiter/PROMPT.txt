axum 写一个令牌桶限流器，支持多种桶配置模板。每个桶有容量（burst）和填充速率（每秒补充令牌数）。可创建多个模板（如"严格" burst=10 rate=5、"宽松" burst=100 rate=50），客户端通过 API Key 关联模板。

请求到达时从对应桶消耗一个令牌。桶空返回 429，响应头带 Retry-After 和 X-RateLimit-Reset。首次出现的 API Key 自动关联默认模板。

模板管理接口：创建、修改、删除模板。修改后关联该模板的桶立即用新参数。删除前需先迁移关联的 API Key。桶状态查询：查看指定 Key 的剩余令牌、容量、速率。统计接口返回桶使用排名（按消耗令牌数降序），长时间不活跃的桶自动回收。端口 PORT 环境变量。
