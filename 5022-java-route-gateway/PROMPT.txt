Spring Boot 写一个 API 网关。核心功能是路由管理和请求聚合。

路由规则：路径前缀加 HTTP 方法匹配到上游服务。同一个路径前缀下，不同方法可以路由到不同服务。比如 GET /api/users 走用户查询服务，POST /api/users 走用户注册服务。

请求聚合：客户端请求 /api/dashboard 时，网关同时调用用户服务、订单服务、通知服务，把三个响应合并成一个 JSON 返回。聚合请求里单个上游失败时，失败的字段填 null，其他正常返回。聚合超时取所有上游超时的最大值。

路由规则变更通过接口管理，变更后立即生效。已有的连接不受影响。端口 PORT 环境变量。
