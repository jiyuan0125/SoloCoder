标准库写一个 API 网关，核心是请求转换和上游负载均衡。路由表维护路径前缀到上游列表的映射（如 /api/v1/users→[upstream1, upstream2]），匹配最长前缀后轮询选择实例转发。

请求转换：转发前把 Authorization 解析出用户信息，注入 X-User-Id 和 X-User-Role。缺失或无效时根据路由配置决定拒绝还是匿名放行。

响应改写：上游错误响应统一包装成标准格式（code、message、timestamp）。上游超时（可配，默认 5 秒）返回 504。路由管理接口增删改规则，新请求立即用新规则，旧请求继续走原来的。上游健康检查每 30 秒一次，不健康的暂不参与负载均衡。端口 PORT 环境变量。
