Spring Boot 写一个优先级消息队列，支持消息分组和顺序消费。

消息入队时指定 Topic、优先级（1-10）、分组键。同一个分组键的消息严格按照入队顺序被消费。不同分组键的消息可以并行消费。

消费者注册时指定订阅的 Topic 和最大并发数。系统按优先级从高到低投递消息，同优先级按入队时间。一个分组键同一时刻只能有一个消费者在处理。

消费确认：消费者拉取消息后需要在超时时间内 ACK。超时未 ACK 的消息重新入队。同一个分组键的后续消息被阻塞直到前一条 ACK 或超时。

死信处理：消息被重新入队超过 3 次后进入死信队列。死信队列可以查看和手动重新投递。统计接口显示各 Topic 的堆积量、消费速率、死信数量。端口 PORT 环境变量。
