标准库写一个 HTTP 缓存代理。请求先查缓存，命中且未过期直接返回。未命中则转发到上游，响应缓存后返回。

缓存 key 是请求方法和 URL 的组合。响应的缓存时间由上游通过 Cache-Control header 指定。没有 Cache-Control 则使用默认 TTL（可配）。

缓存淘汰策略：LRU。最大缓存条目数可配，默认 10000。缓存命中率和内存使用量通过接口查看。

缓存穿透保护：同一个 key 连续 3 次未命中且上游返回 5xx，该 key 短暂标记为拒绝缓存状态（30 秒），期间直接返回上游的最后一次错误响应。

缓存可以按前缀批量清除。清除操作和正常读取可能同时发生。缓存条目的 value 可能很大（几MB），不能阻塞其他操作。端口 PORT 环境变量。
