Spring Boot 实现一个多级缓存。L1 是进程内缓存（Caffeine），L2 是本地文件缓存，L3 是远程缓存（模拟 Redis 的 HTTP 接口）。

读取流程：L1 命中返回 → L2 命中回填 L1 返回 → L3 命中回填 L1 L2 返回 → 回源并回填三级。

每级缓存独立配置 TTL 和容量。L1 容量最小速度最快。L2 用文件存储，支持重启后恢复。L3 通过 HTTP 接口访问。

缓存更新：写入时同时写三级缓存。各级 TTL 可能不同，所以各级过期时间不同步。回源时如果发现 L3 有较新的数据（通过版本号比较），直接用 L3 的。

缓存失效：支持按 key 失效和按前缀批量失效。失效操作要同步到三级。端口 PORT 环境变量。
