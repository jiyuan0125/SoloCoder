actix-web 写一个多租户缓存中间件，每个租户独立的命名空间和容量配额。租户通过 API Key 标识，各有独立缓存空间，互不影响。创建时指定容量上限（最大条目数），超出按 LRU 淘汰。

缓存操作：put、get、delete、clear。put 时租户已满则先淘汰最久未使用的。get 命中时刷新访问时间。返回数据包含缓存年龄（距上次更新的秒数）。

租户管理：创建、删除租户（清空其所有缓存）。修改容量配额时，若新配额小于当前条目数，立即淘汰多余的。全局统计：合计命中率、总条目数、内存估算。单租户统计：命中率、条目数、淘汰次数。缓存值最大 1MB，超出拒绝写入。端口 PORT 环境变量。
