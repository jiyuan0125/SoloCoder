用 actix-web 写一个多租户缓存中间件。每个租户独立的命名空间和容量配额。

租户通过 API Key 标识。每个租户有独立的缓存空间，互不影响。租户创建时指定容量上限（最大条目数）。超出的条目按 LRU 淘汰。

缓存操作：put、get、delete、clear。put 时如果租户已满，先淘汰最久未使用的条目。get 命中时刷新访问时间。返回数据包含缓存年龄（距上次更新的秒数）。

租户管理：创建、删除租户。删除租户时清空其所有缓存。修改租户容量配额时，如果新配额小于当前缓存条目数，立即淘汰多余的。

全局统计：所有租户合计的命中率、总条目数、内存占用估算。单个租户的命中率、条目数、淘汰次数。缓存值最大支持 1MB，超过拒绝写入。端口 PORT 环境变量。
