axum 做一个 KV 配置存储。支持 Watch 机制监听 key 的变更。

存储层：key-value 持久化到本地文件（JSON 格式）。启动时从文件加载。写操作先写文件再更新内存。文件写入失败不更新内存。

Watch 机制：客户端注册对某个 key 或前缀的监听。变更时通过 HTTP 回调通知客户端。客户端注册时提供回调 URL。回调失败重试 3 次后取消监听。

配置分组：支持按前缀查询。比如查询 /database/* 返回所有数据库相关的配置。

三个模块分开：存储层、Watch 管理、HTTP 接口层。存储层不依赖 HTTP 层。Watch 管理依赖存储层的事件。端口 PORT 环境变量。
