Spring Boot 写一个配置中心，侧重配置回滚和多环境对比。配置项以 key-value 存储，归属到应用名和环境（dev/staging/prod）。每次修改产生历史版本，版本号自增。可查看任意历史版本内容。

回滚：选择某历史版本一键回滚，回滚操作本身也产生新版本，回滚后推送通知给订阅客户端。多环境对比：传入两个环境名返回差异列表，只在一侧存在的 key 标注"缺失"，值不同标注"不同"。支持把一个环境的配置同步到另一个环境。

配置导入导出：按应用名和环境导出所有配置为 JSON。导入时校验格式，覆盖已有 key，新增缺失的 key。导入记录审计日志（操作人、时间、变更 key 数量）。端口 PORT 环境变量。
