Spring Boot 写一个配置中心，侧重配置回滚和多环境对比。

配置项以 key-value 形式存储，归属到应用名和环境（dev/staging/prod）。每次修改产生历史版本，版本号自增。可以查看任意历史版本的配置内容。

回滚：选择某个历史版本一键回滚。回滚操作本身也产生一个新版本。回滚后推送通知给订阅的客户端。

多环境对比：接口传入两个环境名，返回配置差异列表。只在一侧存在的 key 标注为"缺失"，两侧值不同的标注为"不同"。支持把一个环境的配置项同步到另一个环境。

配置导入导出：按应用名和环境导出所有配置为 JSON。导入时校验格式，覆盖已有 key，新增缺失的 key。导入操作记录审计日志（操作人、时间、变更的 key 数量）。端口 PORT 环境变量。
