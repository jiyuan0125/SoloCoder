axum 写一个带 fencing token 的分布式锁。每次获取锁递增 fencing token。

fencing token 机制：获取锁时返回递增的 token。客户端用这个 token 访问受保护的资源。资源服务只接受比上次更大的 token。

锁获取时指定 key、超时。获取成功返回 token 和锁 ID。续期时也返回新的 token（递增）。这样续期后即使旧的锁因为网络问题被其他人获取，旧客户端的 token 已经失效。

锁释放：正常释放或超时自动释放。释放后 fencing token 不重置，继续递增。

客户端可能在锁超时后仍然尝试操作（网络延迟），这种情况下 token 已过期。资源端要能正确拒绝。token 可能非常大（长时间运行后）。端口 PORT 环境变量。
