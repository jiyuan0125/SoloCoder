Spring Boot 写一个日志处理管道。日志经过收集、过滤、格式化、分发四个阶段。

收集阶段：通过 HTTP 接口接收日志。日志格式支持 plain text 和 JSON。plain text 自动解析出时间、级别、消息。

过滤阶段：按级别过滤（低于阈值的丢弃）、按关键字过滤（包含指定关键字的保留或丢弃）。过滤规则按服务配置。

格式化阶段：统一输出为 JSON 格式。可以添加额外字段（服务名、主机名、处理时间戳）。

分发阶段：输出到文件、HTTP 推送、或者两者同时。推送失败时本地暂存，定时重试。四个阶段用责任链模式连接，每个阶段是独立的 Spring Bean。端口 PORT 环境变量。
