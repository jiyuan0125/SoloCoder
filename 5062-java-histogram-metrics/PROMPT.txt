Spring Boot 写一个 Histogram 指标服务。记录请求延迟分布。

Histogram 配置：名称、桶边界（如 10ms, 50ms, 100ms, 500ms, 1s, 5s）、最大保留时间。每次写入一个观测值，自动落入对应的桶。

分位数计算：P50、P90、P95、P99。基于桶数据估算，不存储原始值。精度要求在 1% 以内。

时间窗口：只保留最近 N 分钟的数据。过期的桶数据自动清理。清理不影响正在写入的桶。

多维度标签：每个指标可以有多个标签（如 HTTP 方法、路径、状态码）。标签组合形成独立的时间序列。查询时可以按标签过滤和分组。

同一个指标可能同时有大量写入。桶的更新需要线程安全。端口 PORT 环境变量。
