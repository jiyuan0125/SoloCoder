Spring Boot 写一个探针管理器。管理 HTTP 和 TCP 两种类型的健康探针。

探针状态：创建 → 启用 → 检查中 → 健康/不健康 → 禁用。探针创建后默认启用。启用后开始定时检查。检查结果决定健康状态。

检查失败处理：连续失败次数达到阈值标记不健康。单次失败不改变状态（抖动容忍）。连续成功次数达到恢复阈值后从 unhealthy 变为 healthy。

探针可以分组。组内的探针状态聚合：全部健康则组健康，任一不健康则组不健康。组的聚合结果影响依赖该组的服务。

探针配置可以动态修改（检查间隔、超时、阈值）。修改后用新参数执行下次检查。正在执行中的检查不受影响。端口 PORT 环境变量。
