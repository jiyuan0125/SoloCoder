Spring Boot 写一个定时探针调度器。管理大量定时健康检查任务，每个任务有独立的 cron 表达式和探针配置。

探针任务：每个任务包含名称、目标地址、探针类型（HTTP/TCP）、cron 表达式、超时。到执行时间时发起检查，记录结果（成功/失败/超时）和响应时间。

执行历史：每次检查的结果存储，保留最近 7 天。支持按任务名和时间范围查询历史。统计接口返回每个任务的成功率和平均响应时间。

任务管理：创建、修改、暂停、恢复、删除任务。修改 cron 表达式后下次执行用新时间。暂停的任务不执行但保留配置。

并发控制：同时最多执行 20 个检查任务。超出的排队。任务执行超时（可配）自动取消并记录为超时结果。同一个任务的上一次还没执行完时跳过本次触发。端口 PORT 环境变量。
