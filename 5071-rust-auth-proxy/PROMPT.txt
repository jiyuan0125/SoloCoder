axum 做一个认证代理网关。请求先经过认证模块，认证通过后转发到上游服务。

认证方式：API Key 和 HMAC 签名两种。API Key 在 header 中传递，服务端维护有效的 key 列表。HMAC 签名：请求中包含签名，用共享密钥和时间戳验证。

签名验证：检查时间戳在正负 5 分钟范围内。签名内容包含请求方法、路径、请求体哈希。签名不匹配返回 401。

API Key 管理：通过接口创建、吊销、查询。Key 有描述和创建时间。吊销后的 Key 立即失效。Key 列表可能很大（上万个），验证要快。

请求转发：认证通过后，在 header 中注入认证信息（用户ID、认证方式），转发到上游。上游不可达返回 502。端口 PORT 环境变量。
