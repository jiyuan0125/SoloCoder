FastAPI 写一个 Token 管理网关。管理 Access Token 和 Refresh Token 的生命周期。

Token 状态：活跃 → 即将过期 → 已过期 → 已吊销。即将过期的定义：剩余有效期不到 20%。

Access Token 有效期 30 分钟。Refresh Token 有效期 7 天。用 Refresh Token 换新的 Access Token 时，如果 Refresh Token 也即将过期，同时刷新 Refresh Token。

Token 使用记录：每次使用 Token 时记录请求路径、时间、客户端 IP。记录用于审计，保留 30 天。

异常检测：同一个 Token 在短时间内从不同 IP 使用，标记为可疑。可疑 Token 需要额外验证（如二次确认接口）。连续 5 次验证失败自动吊销。端口 PORT 环境变量。
