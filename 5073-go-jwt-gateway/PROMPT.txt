Gin 写一个 JWT 认证网关。请求进来后验证 JWT Token，解析出用户信息再转发到后端服务。

Token 验证：检查签名（HMAC-SHA256）、过期时间、签发者。验证失败返回 401。验证成功后将用户信息（用户ID、角色）注入到请求 header 中转发。

Token 刷新：客户端可以用未过期的 Token 换新 Token。新 Token 的过期时间重新计算。旧 Token 在刷新后仍然有效直到自然过期（不立即作废）。

Token 黑名单：管理员可以强制让某个用户的 Token 失效。黑名单存储在内存中，重启后清空。黑名单检查在验证签名之后。

路径白名单：部分路径不需要认证（如 /login、/health）。白名单支持精确匹配和前缀匹配。端口 PORT 环境变量。
