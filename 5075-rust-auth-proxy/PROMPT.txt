用 axum 做一个 RBAC 认证网关。请求经过角色校验后才转发到上游。

用户管理：创建用户时指定用户名、密码哈希（SHA-256）、角色列表。角色管理：创建角色，绑定一组 API 路径的访问权限（允许/拒绝）。比如 admin 角色可以访问 /api/*，guest 只能访问 /api/public/*。

请求认证流程：从请求头取 Token，查到对应用户和角色。检查请求路径是否匹配该角色允许的路径模式。匹配成功则转发，否则返回 403。Token 有过期时间，过期后需要重新获取。

登录接口：用户名+密码验证通过后返回 Token。Token 有效期可配。同一个用户可以有多个有效 Token（多设备登录）。Token 过期或用户被禁用后立即失效。

权限变更实时生效：修改角色的权限配置后，该角色所有用户的后续请求立即用新规则。用户被禁用后所有 Token 失效。端口 PORT 环境变量。
