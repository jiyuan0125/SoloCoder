Gin 写一个 JSON 和 Protobuf 协议转换网关。外部服务用 JSON 调用，内部服务用 Protobuf。

转换规则：通过 Protobuf 的 proto 文件定义消息结构。网关启动时加载 proto 文件。请求进来后根据路径匹配到对应的 proto 消息类型，JSON 解码后编码为 Protobuf 二进制转发到内部服务。

内部服务的响应（Protobuf 二进制）再解码回 JSON 返回。字段映射：proto 字段名用 snake_case，JSON 用 camelCase。嵌套消息和 repeated 字段都要正确处理。

proto 文件可以通过接口更新。更新后新的请求用新定义，旧请求不受影响。

转换失败的请求返回 400 和错误详情。内部服务不可达返回 502。JSON 字段类型与 proto 定义不匹配时给出具体的错误位置。端口 PORT 环境变量。
