Gin 写一个 WebSocket 到 HTTP 的桥接网关。客户端用 WebSocket 连接，消息转为 HTTP 请求发到内部服务。每条消息是 JSON，包含目标路径（path）、方法（method）、请求体（body）。网关根据 path 路由到对应的内部 HTTP 服务。

响应回传：内部服务响应通过同一条 WebSocket 连接返回，每条响应通过请求中的 id 字段匹配。并发消息的响应可能乱序返回。连接认证：WebSocket 握手时验证 header 中的 Token，无效拒绝连接。Token 中用户信息注入上游 header。

内部不可达时通过 WebSocket 发错误消息。支持多客户端同时连接，每个独立处理。管理接口查看活跃连接数和消息吞吐量。端口 PORT 环境变量。
