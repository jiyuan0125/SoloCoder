Gin 写一个 WebSocket 到 HTTP 的桥接网关。客户端用 WebSocket 连接，消息被转换为 HTTP 请求发到内部服务。

连接管理：客户端建立 WebSocket 连接后，每条消息是一个 JSON，包含目标路径（path）、HTTP 方法（method）、请求体（body）。网关根据 path 路由到对应的内部 HTTP 服务。

响应回传：内部 HTTP 服务的响应通过同一条 WebSocket 连接返回给客户端。每条响应关联到对应的请求（通过请求中的 id 字段匹配）。并发消息的响应可能乱序返回。

连接认证：WebSocket 握手时验证 header 中的 Token。无效 Token 拒绝连接。Token 中携带用户信息，转发 HTTP 请求时注入到上游 header。

内部服务不可达时通过 WebSocket 发送错误消息。支持多个客户端同时连接，每个连接独立处理消息。管理接口查看当前活跃连接数和消息吞吐量。端口 PORT 环境变量。
