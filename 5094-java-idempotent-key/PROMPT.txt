Spring Boot 写一个幂等性保障服务。基于幂等键防止重复操作。

幂等键管理：客户端在请求中传入幂等键（Idempotency-Key header）。服务端检查该键是否已经处理过。如果处理过，返回上次的处理结果。

处理结果缓存：幂等键对应处理结果（状态码、响应体）。缓存保留 24 小时。缓存存储在本地文件中，服务重启后恢复。

并发处理：同一个幂等键的多个请求同时到达。第一个请求处理中，其他请求等待。第一个完成后所有等待者返回相同结果。

过期清理：后台任务定时清理过期的幂等键。清理时不能影响正常的键查询和写入。清理过程可能很长（百万级键），分批执行。

接口可以查询幂等键的状态和处理结果。端口 PORT 环境变量。
