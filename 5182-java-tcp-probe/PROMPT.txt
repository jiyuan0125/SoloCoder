Spring Boot 做一个多协议健康检查编排器。支持 HTTP、TCP、gRPC 三种探针，探针可以编排成检查流程。

检查流程由多个探针步骤组成，步骤之间可以串行或并行。串行步骤前一个失败则跳过后续。并行步骤全部完成后汇总结果，任一失败则流程标记为不健康。每个步骤可以设置超时和重试。

探针模板：预定义常用的探针配置（如"数据库连接检查"、"Redis Ping"、"HTTP 首页探测"）。模板可以复用到多个流程中。

定时执行：流程绑定 cron 表达式，定时触发。执行结果存入历史记录，保留 7 天。最近一次的检查结果缓存，查询时直接返回。缓存 TTL 可配。

告警联动：流程标记不健康时调用配置的 Webhook 通知。Webhook 调用失败重试 2 次。同一个流程连续不健康时不重复告警（静默期可配）。端口 PORT 环境变量。
