tokio 写一个通用重试引擎。任务执行失败后按配置的退避策略自动重试。

通过 API 提交任务：POST /tasks，body 包含回调 URL、payload、重试配置。重试配置包括：初始间隔秒数、退避策略（fixed/exponential）、最大重试次数（默认 5）、最大间隔上限。任务提交后引擎立即调用回调 URL（POST），如果回调返回非 2xx 或超时（10 秒），记为失败并加入重试队列。

退避策略：fixed 模式每次间隔相同秒数；exponential 模式每次间隔翻倍，但不超过配置的最大间隔上限。每条任务有个重试计数器，记录当前已重试次数。达到最大重试次数后任务标记为 exhausted，不再重试。

任务状态：pending → running → completed/exhausted。exhausted 的任务可以通过 API 手动重新触发。所有状态变更和时间戳都记录下来。管理接口展示各状态的任务数量、平均重试次数、exhausted 任务列表。端口 PORT 环境变量。
