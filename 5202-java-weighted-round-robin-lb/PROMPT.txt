Spring Boot 做加权轮询负载均衡器。后端实例注册时每个带一个权重值，权重越大分到的请求越多。

注册时传入 address 和 weight（正整数）。权重为 0 的实例保留但不参与负载——"暂停但不删除"，后续可以调回来。

加权轮询用平滑算法（Nginx 那种）：每个实例维护 current_weight，选择时 current_weight += effective_weight，选最大的，选中后 current_weight -= total_weight。权重比 5:3:2 的三台机器，请求分配比就是 5:3:2，不会连续打到同一台。

健康检查用 TCP 连接探测，每 15 秒一次。连续 2 次失败标记 unhealthy 移出负载池。恢复后自动加回，权重不变——之前是 5 加回来还是 5。

端口 server.port 配置，Maven 构建。
