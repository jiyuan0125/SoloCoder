axum 实现滑动窗口限流器。按客户端 IP（从 X-Real-IP 或 X-Forwarded-For 取）或者 API Key（X-Api-Key 头）做限流维度——带了 API Key 按 Key 限流，没带按 IP。

窗口配置按路径分组。比如 /api/login 每个 IP 每分钟最多 5 次，/api/search 每个 Key 每秒 20 次。没专门配的路径走默认规则（每分钟 100 次）。

滑动窗口秒级精度——维护时间戳到计数的 map，请求进来时先清理窗口外的老数据，再统计当前窗口内请求数。超过阈值返回 429，响应头带 Retry-After。被限流的请求不计入统计——防止恶意刷量把计数器撑爆。

端口 PORT 环境变量，cargo build 能过。数据存内存。
