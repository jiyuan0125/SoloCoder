Go 标准库做 API 网关，请求经过一条插件链处理后转发到后端。不同路径可以配不同的插件组合和顺序。

插件四种：auth（校验 API Key）、rate_limit（按路径+IP 限流 QPS）、logging（记录请求响应）、request_rewrite（修改 Header 或 Body）。每个插件就是一个函数，输出放行/拒绝/修改后放行。插件按配置的顺序依次执行——先认证再限流再日志。某个插件拒绝请求时短路返回，后面不跑了。

路由配置通过接口管理，支持前缀匹配（/api/*）和精确匹配（/api/login），精确优先。每条路由配 upstream_url 和插件链。

端口 PORT 环境变量，go build 能过。
