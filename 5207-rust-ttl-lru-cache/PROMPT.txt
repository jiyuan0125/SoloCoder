axum 做一个缓存中间件——带 TTL 过期和 LRU 淘汰的内存 KV 缓存。给内部服务用，替代 Redis 做临时数据缓存。

容量上限通过环境变量 CACHE_MAX_KEYS 配置，默认 10000。达到上限淘汰最久未使用的 Key。TTL 在 set 时指定，0 表示永不过期。后台每秒扫描过期 Key 清理——不用每次 get 都判断过期，减少热路径开销。但 get 也要检查，防止还没来得及清理的过期数据被返回。

接口：set/get/delete/keys（列出未过期 key，分页）。统计接口返回命中率（hit/(hit+miss)）、淘汰次数、过期清理次数。

并发安全。端口 PORT 环境变量，cargo build 能过。
