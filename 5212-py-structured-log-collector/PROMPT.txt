FastAPI 做结构化日志收集。日志是 JSON 格式的，每条有固定的结构字段加可扩展的自定义字段。

上报接口接收 JSON 数组，每条日志包含 timestamp、source、level、message、fields（扩展 KV）。一次最多 500 条。

查询支持按 source、level、时间范围、keyword（在 message 和 fields 里模糊匹配）组合过滤。结果按时间倒序分页。

日志按天归档到文件（data/logs/{source}/{date}.jsonl）。写入用缓冲——满 100 条或距上次超 1 秒就刷盘。超过保留天数（可配，默认 7 天）的文件自动删除。

端口 PORT 环境变量，能正常跑起来。
