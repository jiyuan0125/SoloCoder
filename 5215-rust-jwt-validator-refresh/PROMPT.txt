axum 做 JWT 验证和自动刷新的网关。请求带 JWT 进来，验签名和过期时间，合法就放行并把用户信息注入 Header 转发后端。

签名算法 HMAC-SHA256，密钥通过管理接口管理。Token payload 包含 sub（用户ID）、role、exp、iat。验签失败或过期返回 401。

自动续期：Token 剩余有效期不到 5 分钟时，响应头附加 X-New-Token（用相同 payload 更新 exp 重新签名）。客户端下次用新 Token 就行。

换全新 Token 需要 Refresh Token。POST /auth/refresh 传入 refresh_token 验证后返回新 access_token 和新 refresh_token（轮换）。Refresh Token 可撤销，撤销列表存内存。

端口 PORT 环境变量，cargo build 能过。
