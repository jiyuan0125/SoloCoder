axum 做 OAuth2 Token 中继网关。后端服务不想处理 OAuth2 的授权码交换、Token 刷新这些杂事，全交给网关。

工作流程：客户端拿 OAuth2 授权码发给网关，网关用授权码向 Provider 换 Access Token 和 Refresh Token，缓存到内存。后续请求带 Bearer Token，网关验证后把用户信息（user_id、email、roles）注入 Header 转发后端。

Token 自动刷新：Access Token 剩余不到 5 分钟时用 Refresh Token 刷新，新 Token 通过响应头返回。Refresh Token 也过期就返回 401。

支持多 Provider（GitHub、Google 等），通过接口配置各 Provider 的 token_url、client_id、client_secret。

端口 PORT 环境变量，cargo build 能过。
