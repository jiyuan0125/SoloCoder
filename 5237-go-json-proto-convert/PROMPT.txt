Go 标准库做 JSON-Protobuf 转换网关。微服务内部用 Protobuf 效率高，但前端只会调 JSON。网关负责两种格式互转。

Proto Schema 通过接口上传，解析出 message 定义（支持嵌套和 enum）。每个 message 映射到 HTTP 路径 POST /convert/{package}.{message_name}。客户端发 JSON，网关按 proto 编码为 Protobuf 二进制转发后端，后端返回 Protobuf 再解码回 JSON。

类型校验：JSON 值类型要和 proto 定义匹配——int32 字段不能传字符串，repeated 必须是数组。错误信息要具体到哪个字段、期望什么类型。

端口 PORT 环境变量，go build 能过。
