Go 标准库做请求体改写代理。前后端字段名不一致、要脱敏、要过滤敏感字段——在代理层统一处理。

改写规则按路径前缀配置，支持三种操作：rename（改字段名）、remove（删字段如 password/credit_card）、convert（类型转换如 string→int）。支持嵌套字段路径（user.phone）。

请求流程：按最长前缀匹配找到改写规则，对请求体 JSON 做改写后转发后端。改写后注入 X-Transformed: true。JSON 格式错误返回 400 附具体位置。超过 1MB 返回 413。

响应也能改写——比如把后端的 Java stacktrace 过滤成简短错误码。规则通过接口管理。

端口 PORT 环境变量，go build 能过。
