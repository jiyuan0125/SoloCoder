Go 标准库做认证注入网关。后端不想各自实现认证——请求先过网关验身份，验完把用户信息塞 Header 转发后端。

认证用 API Key：请求头带 X-API-Key。Key 存内存，通过管理接口增删。创建 Key 时传入 user_id 和 role，返回 32 位随机 hex。Key 可以设过期时间。

认证流程：没有 X-API-Key 返回 401。Key 无效（不存在、过期、已吊销）返回 401。有效则注入 X-User-Id 和 X-User-Role 转发。

白名单路径跳过认证。后端地址从 UPSTREAM_URL 环境变量读。端口 PORT 环境变量，go build 能过。
