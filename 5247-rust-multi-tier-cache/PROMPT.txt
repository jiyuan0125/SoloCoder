axum 做多级缓存——L1 内存缓存（快但小），L2 文件缓存（慢但大）。读时先查 L1，没有查 L2，都没有就是 miss。

L1 用 HashMap + LRU 淘汰，容量上限可配（默认 10000）。L2 用本地目录 data/cache/，文件名是 Key 的 SHA-256，TTL 淘汰（默认 1 小时），容量上限默认 100MB。

写时同时写 L1 和 L2。L2 写失败不影响 L1（降级为只有 L1）。L1 满了按 LRU 淘汰，L2 满了按文件修改时间淘汰最旧的。

读时 L1 miss 查 L2，L2 命中后回填 L1。删除同时删两级。支持按前缀批量清除。

端口 PORT 环境变量，cargo build 能过。
