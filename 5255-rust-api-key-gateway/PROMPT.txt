axum 实现 API Key 网关。每个调用方发一个 Key，绑定权限和限流。Key 管理：POST /admin/keys 创建——name、scopes（如 ["read:users","write:orders"]）、rate_limit（每秒请求数默认 100）、expires_at。返回 sk_live_/sk_test_ 前缀+随机串。GET 列出，DELETE 吊销。

请求验证：X-API-Key header。查有效→查权限（路径匹配 scope）→查限流（令牌桶，超限 429 带 Retry-After）。无效 401，无权限 403。

使用记录：每次请求记 Key、路径、方法、状态码、时间戳，追加 data/usage.jsonl。GET /admin/keys/{key}/usage 最近 100 条。GET /admin/keys/{key}/stats 返回总调用、今日调用、被限流次数、最常调 Top 5。端口 PORT 环境变量，cargo build 能过。
