Go 标准库做 WebSocket-HTTP 桥接网关。前端 WebSocket 长连接，后端只有 HTTP REST，网关做协议转换。客户端连 ws://gateway:{PORT}/ws，每条消息是 JSON 含 path、method、headers（可选）、body（可选）和 request_id。网关转 HTTP 请求到 UPSTREAM_URL，响应封装回 WebSocket 消息。

连接管理：MAX_CONNECTIONS 环境变量（默认 1000），idle 超时 120 秒，消息大小限制 64KB。GET /admin/connections 返回活跃连接数和空闲时间。后端超时 10 秒，超时返回 {error: "upstream timeout", request_id}。

GET /admin/stats 返回历史总连接数、活跃数、已处理消息数、后端成功/失败数。端口 PORT 环境变量，go build 能过。
