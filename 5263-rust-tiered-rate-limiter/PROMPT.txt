axum 做多级限流。请求同时过三道关卡：IP 级别、用户级别、接口级别，任一道被拦返回 429。IP 按 X-Real-IP/X-Forwarded-For，用户按 X-Api-Key，接口按请求路径。没 API Key 跳过用户级别。白名单 Key（POST /admin/whitelist）不限流。

每级独立配置：POST /admin/rules 创建规则——level（ip/user/path）、target（具体值，* 表示默认）、window_seconds、max_requests。GET 列出规则，DELETE 删除立即生效。

响应头带各级别剩余配额（X-RateLimit-Remaining-IP/User/Path）。被限流时 body 说明被哪个级别拦了。固定窗口实现。GET /admin/usage 查看各级别当前计数。端口 PORT 环境变量，cargo build 能过。
