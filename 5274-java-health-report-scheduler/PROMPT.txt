Spring Boot 做定时健康报告服务。每小时自动生成报告，汇总所有注册服务健康状态并和上份报告对比。报告三块内容：所有服务健康快照、新增不健康服务列表、从不健康恢复的服务列表。

报告持久化到本地 JSON 文件（文件名带时间戳），保留最近 100 份超期删最老。查询：GET /reports/latest 最新报告，GET /reports 列表（支持时间范围过滤），GET /reports/{id} 单份完整报告。

服务通过 POST /services 注册（带健康检查地址和方式），报告生成时主动探测。端口 server.port 配置，Maven 构建。数据存内存和文件，不依赖外部数据库。
