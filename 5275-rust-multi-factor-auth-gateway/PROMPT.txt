axum 写多因子认证网关，请求过两道关。第一关 API Key 验证：X-API-Key header 查本地 Key 列表，无效或禁用返回 401（"API Key 无效或已禁用"）。第二关 JWT 验证：Authorization: Bearer xxx 校验签名和过期时间，不对返回 401（"Token 无效或已过期"）。JWT payload 含 role 字段。

两关通过后，JWT 角色和 API Key 权限做交集，空则 403（"权限不足"），非空放行转发后端。

验证流程：API Key→JWT→角色权限交集→放行。API Key 增删改通过管理接口。JWT 签名密钥配置文件指定。端口 PORT 环境变量，cargo build 能过。
