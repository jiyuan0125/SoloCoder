axum 做带标签的缓存服务。写入时给 key 指定一组标签（如 user:123、region:east）。标签和 key 多对多。失效时按标签一次性清除所有关联 key——如某地区数据源更新，按 region:east 标签一次搞定。

接口：POST /cache/set 写入值和标签列表。GET /cache/{key} 读取。DELETE /cache/tags/{tag} 按标签批量失效。GET /cache/tags/{tag}/keys 查看标签下有哪些 key。GET /stats 返回缓存条目总数、标签总数和各标签 key 数量。

端口 PORT 环境变量，cargo build 能过。数据存内存，TTL 可选。
