Spring Boot 做依赖健康树服务。服务间调用依赖建成树，一目了然看故障传播到哪。服务注册时上报依赖的下游，系统构建完整依赖树。每个节点有健康状态（healthy/degraded/unhealthy），子节点不健康时父节点自动 degraded。

GET /tree/{service} 返回完整依赖子树，含节点名称、状态、层级。支持剪枝查询 unhealthy_only=true 只返回不健康分支。树深度无限制。注册时检测循环依赖，发现拒绝报错。

健康状态 POST /services/{name}/status 上报更新，也可配检查地址由系统主动探测。状态变化触发事件通知。端口 server.port 配置，Maven 构建。数据存内存。
