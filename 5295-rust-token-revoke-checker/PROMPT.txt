axum 做 Token 吊销检查网关。JWT 泄露了没法立刻作废——这个服务即使 Token 没过期也能立即吊销。吊销列表用 HashSet 按 JWT 的 jti 索引。请求进来先解析 jti 查吊销列表，在列表返回 401（"该 Token 已被吊销"），不在则放行。后台定期清已过期的条目。

管理：POST /revocations 吊销（jti、过期时间、可选原因如"用户登出"）。DELETE /revocations/{jti} 恢复误吊销。GET /revocations 列出所有被吊销 Token 及原因和时间。

GET /stats 返回吊销列表大小和最近清理时间。端口 PORT 环境变量，cargo build 能过。数据存内存。
