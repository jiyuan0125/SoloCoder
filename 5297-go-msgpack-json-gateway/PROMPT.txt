Go 标准库做 MessagePack-JSON 双向网关。客户端用任意格式发请求，网关自动转换。请求进来判断 Content-Type：msgpack 格式反序列化后转 JSON 转发后端，后端 JSON 再转回 msgpack 返回客户端。JSON 格式直接透传。客户端也可通过 Accept 头指定响应格式。

转换出错：msgpack 反序列化失败返回 400 指出字节位置，JSON 序列化失败同样 400，后端返回非 JSON 返回 502。

GET /stats/conversion 按方向统计转换次数和失败数。POST /config 设置是否开启某方向转换或强制格式。端口 PORT 环境变量，go build 能过。
