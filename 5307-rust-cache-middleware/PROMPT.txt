Rust/axum 写缓存中间件，减轻后端压力控制内存占用。两个维度淘汰同时生效：TTL 过期——到期首次访问触发异步刷新，刷新期间返回旧值不阻塞。LRU 淘汰——容量达上限（默认 10000 可配）淘汰最久未使用的。内存超阈值也触发淘汰。

缓存击穿防护：同 key 大量并发访问时只让第一个去加载，其他等待共享结果。加载失败旧缓存不删，TTL 自动延长 5 分钟给源恢复时间。

POST /cache/{key} 写入（JSON 含 value 和 ttl_seconds）。GET 读取 miss 返回 404。DELETE 手动删除。POST /cache/warm 批量预热。GET /cache/stats 命中率、条目数、容量百分比、内存估算。端口 PORT 环境变量，cargo build 能过。数据存内存。
