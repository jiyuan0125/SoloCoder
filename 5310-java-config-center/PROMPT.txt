Spring Boot 配置中心，所有应用配置集中管理，改一次到处生效。配置按应用和环境分组，KV 格式值支持字符串、数字、布尔和 JSON 对象。同 key 不同环境可有不同值，查询须指定应用名和环境名。

配置变更后推送到订阅的实例（HTTP POST 回调），失败重试 3 次间隔 5 秒。实例超 10 秒没 ACK 标记推送失败记日志。配置有完整版本历史，可回滚到任意版本，回滚也触发推送。

POST /configs 设置。GET /configs?app=xxx&env=xxx 查询。GET /configs/history/{key} 变更历史。POST /configs/rollback 回滚。GET /configs/push-status 推送状态。端口 PORT 环境变量，Maven 构建。数据存内存。
