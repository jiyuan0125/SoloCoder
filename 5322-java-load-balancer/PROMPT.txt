Spring Boot 负载均衡器。按权重分配流量到各实例，处理能力强的多分。权重 0 不接收流量但保留方便恢复。HTTP 探测每 10 秒一次，连续 3 次失败标记不可用，恢复需连续 2 次成功防抖动。

会话粘性：同客户端 IP 5 分钟内打到同一后端，过期重新按权重分配不绑死。权重动态调整 PUT 改完立即生效。

POST /instances 注册（IP、端口、权重）。DELETE 注销。PUT /instances/{id}/weight 调权重。GET /instances 查所有实例状态、权重和累计分发数。GET /stats 各实例分发统计和健康检查历史。端口 PORT 环境变量，Maven 构建。数据存内存。
