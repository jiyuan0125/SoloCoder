Spring Boot 配置中心，集中管理所有应用配置。按应用和环境两维度组织，开发/测试/生产完全隔离。值支持字符串、数字、布尔和 JSON 对象。敏感配置（密码、API Key）存储传输加密，查询返回脱敏值。

配置变更后 HTTP 回调主动推送订阅实例。实例超 10 秒没 ACK 标记推送失败。失败重试 3 次。完整版本历史，每次修改记一条，可回滚到任意版本，回滚也触发推送。

POST /configs 创建（应用、环境、key、value、类型）。GET /configs?app=xxx&env=xxx 查询。PUT /configs/{id} 修改。GET /configs/{id}/history 变更历史。POST /configs/rollback 回滚。GET /push/status 推送状态。端口 PORT 环境变量，Maven 构建。数据存内存。
