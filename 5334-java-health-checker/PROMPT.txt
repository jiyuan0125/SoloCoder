Spring Boot 做健康检查中心，主动探测注册服务健康状态异常第一时间通知。注册检查目标配探测方式（HTTP/TCP）和间隔。HTTP 探测关注状态码和响应时间，TCP 关注能否连通。连续失败若干次（默认 3）才标记不健康防误报，恢复也连续成功若干次。

状态变化触发 Webhook 通知，POST 到回调含目标名、旧/新状态和变化时间，支持多渠道。

GET /health/overview 所有目标总览——多少健康/不健康/降级。GET /health/{name} 单目标探测历史。POST /targets 注册。PUT /targets/{name} 改配置。DELETE 移除。GET /targets 列出。端口 PORT 环境变量，Maven 构建。
