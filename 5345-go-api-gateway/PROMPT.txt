Go 标准库实现对怪异输入安全处理的 API 网关。路径可能多斜杠、URL 编码特殊字符（%2F%2F）、超长路径。先规范化再匹配保留原始路径传后端。请求体可能是二进制、空或畸形 JSON——只转发不校验。

后端可能慢或不返回，超时控制连接 5 秒读 30 秒。路由表可能几万条，匹配不能 O(n)。路由动态变更有并发读写不能读半写状态。

中间件链顺序执行：认证→限流→日志→转发，各独立可开关。认证 API Key，限流按 IP 滑动窗口，日志记录方法路径状态码耗时。GET /routes 查路由表。POST 添加。GET /middleware/status 状态。GET /stats 统计。端口 PORT 环境变量，数据存内存。
