Spring Boot 消息队列，把边界条件都考虑到位。生产者可能发空消息、超长消息（10MB）、乱码。消息大小限制默认 1MB，超限返回 413 记日志。消费者可能不在线或极慢，消息积压不能内存溢出——超水位线的只留磁盘。

磁盘满或文件被删写入失败不丢消息，先放重试队列等恢复再写。重新投递可能再失败不能无限循环——重试上限默认 5 次超限进死信。

POST /topics 创建。POST /topics/{name}/messages 发消息。POST /topics/{name}/subscribe 订阅。GET /topics/{name}/stats 堆积量、消费速度、各分区状态。GET /topics/{name}/deadletter 死信。端口 PORT 环境变量，Maven 构建。数据存内存加本地文件。
