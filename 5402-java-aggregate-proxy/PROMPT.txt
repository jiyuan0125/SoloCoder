Spring Boot 写一个微服务聚合代理。业务场景是前端需要同时调用订单、库存、用户三个服务的数据，想通过一个接口拿到聚合结果。

路由规则按 URL 前缀匹配，匹配到的请求转发到对应后端。转发前要给请求加上内部认证 header（X-Internal-Token），token 值从配置里读。后端响应时间超过 3 秒就返回降级数据（空对象），不能让前端一直等着。

聚合接口的路径是 /api/aggregate，它需要并行调用多个后端然后合并结果返回。后端服务列表可以通过管理接口增删改。如果某个后端连续失败 5 次，标记为不可用，30 秒后自动重试一次。端口通过 application.properties 的 server.port 指定。
