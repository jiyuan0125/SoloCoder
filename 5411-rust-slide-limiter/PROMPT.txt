Rust/actix-web 做一个滑动窗口限流器。业务场景是开放 API 平台，按用户限流，每个用户每分钟最多调 N 次，N 由用户的套餐等级决定（免费 60、基础 300、专业 1000）。

滑动窗口精度到秒，用 Redis 有序集合实现（先实现内存版本，接口兼容就行）。同一个用户的请求，窗口内计数超过配额就返回 429，响应头带上 X-RateLimit-Remaining 表示剩余次数和 X-RateLimit-Reset 表示窗口重置时间。套餐等级通过管理接口配置，改了立即生效。

用户可以从免费升级到基础或专业，升级后新窗口立即按新配额计算。降级时当前窗口不立即生效，等窗口过期后用新配额。管理接口可以查看所有用户的当前用量、手动重置某个用户的计数。
