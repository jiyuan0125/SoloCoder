Spring Boot 做三级限流：IP → 用户 → 接口。场景是开放平台，先按 IP 限（防止同一 IP 大量请求），再按用户限（按用户等级），最后按接口限（保护后端）。三级是串行检查的关系，任何一级被拦就返回 429。

IP 限流默认每分钟 1000 次，用户限流按等级（免费 100、付费 1000、企业 5000），接口限流按接口配置。三级的配置都可以通过管理接口修改。限流算法用固定窗口就行，窗口大小 1 分钟。IP 从 X-Forwarded-For 或 RemoteAddr 取，用户 ID 从请求头 X-User-Id 取。

429 响应要告诉客户端是哪一级被限、当前限制值和剩余次数。统计接口按级别汇总数据：每个 IP 的请求数、每个用户的请求数、每个接口的请求数。
