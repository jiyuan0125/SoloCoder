Rust/actix-web 做 LRU 缓存中间件。场景是配置中心的缓存层，配置数据读多写少，热点配置需要快速响应。

缓存支持 GET/SET/DELETE 操作，容量上限可配置（默认 10000 条）。达到上限时淘汰最久未访问的数据。每个缓存条目可以设置 TTL，过期自动删除。GET 请求命中过期数据时返回 miss 并删除该条目。SET 操作如果 key 已存在，更新值并重置 TTL。

统计接口返回命中率（命中次数/总查询次数）、当前缓存条目数、总 GET 次数、总 SET 次数。缓存数据通过 HTTP 接口访问，key 和 value 都是字符串。管理接口可以批量导入缓存（用于预热）、清空缓存、查看某个 key 是否存在及其剩余 TTL。
