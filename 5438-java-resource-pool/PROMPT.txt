Spring Boot 写一个通用资源池。场景是视频转码服务，每个转码任务需要占用一个转码引擎实例（用模拟对象代替，不需要真实引擎）。引擎实例创建成本高，需要池化复用。

池的配置包括：最小空闲数、最大总数、创建超时、借出超时。池启动时预创建最小空闲数个实例。借出时池里有可用的直接给，没有就新建（未超上限），满了就等（超时抛异常）。归还时检查实例是否健康（调用 isValid 方法），不健康的丢弃。池里保持最小空闲数，不够了后台线程自动补。

管理接口可以查看池的当前状态（活跃数、空闲数、等待数）、调整配置、手动驱逐所有空闲实例（触发重建）。实例的借出和归还都要记录时间戳，用于统计平均使用时长。
