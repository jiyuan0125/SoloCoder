Spring Boot 做 Histogram 指标采集。场景是统计 API 响应时间的分布，不是看平均值而是看 P50/P90/P99。

Histogram 通过配置桶边界实现（比如 10ms、50ms、100ms、500ms、1000ms、5000ms）。每个请求的上报值落在某个桶里。查询时根据桶计数计算分位数。桶边界可以自定义，默认用上面的配置。指标可以带标签（比如接口路径），按标签分组统计。

上报接口接收指标名、值、标签。查询接口返回指定指标的分位数（P50、P90、P95、P99）、平均值、最大值、最小值。时间窗口：默认统计最近 10 分钟的数据，超过窗口的自动丢弃。管理接口可以配置桶边界、查看所有已注册的指标。
