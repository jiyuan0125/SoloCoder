Rust/axum 做 JWT 认证网关。所有请求先过网关验证 JWT，验证通过后转发到后端服务，验证失败返回 401。

JWT 的签发密钥通过配置指定（HS256 对称密钥）。token payload 包含 user_id、role、exp。验证逻辑：签名正确、未过期、user_id 非空。过期时间判断允许 30 秒的时钟偏移。角色校验：每个路由可以配置允许访问的角色列表，不在列表里的返回 403。

网关维护一个 token 黑名单（用于主动登出），黑名单里的 token 即使未过期也返回 401。黑名单条目有过期时间（等于 token 的剩余有效期），过期自动清理。管理接口查看黑名单大小、手动加入黑名单。端口 PORT 环境变量。
