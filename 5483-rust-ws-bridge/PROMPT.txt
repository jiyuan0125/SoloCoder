Rust/tokio 做 WebSocket↔HTTP 桥接。场景是浏览器用 WebSocket 连接，但后端只有 REST API，需要中间有个转换层。

WebSocket 消息格式约定：JSON 包含 method（GET/POST/PUT/DELETE）、path、headers、body。桥接层把 WebSocket 消息转为 HTTP 请求发给后端，拿到响应后以 WebSocket 消息返回。每个 WebSocket 消息有一个 request_id，响应原样带回，方便客户端匹配。

连接管理：WebSocket 客户端断开时清理资源。后端 HTTP 调用超时 5 秒，超时返回错误响应。消息序号校验：request_id 在同一个连接内必须递增，重复或跳号的返回错误。管理接口查看当前活跃连接数、已转发请求总数。端口 PORT 环境变量。
