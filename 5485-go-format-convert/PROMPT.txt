Go 标准库做请求格式自动转换。场景是老系统只接受 XML，新系统只接受 JSON，客户端两种都有，网关做双向转换。

路由规则配置：每个后端服务的期望格式（JSON 或 XML）。客户端请求的 Content-Type 和后端期望不一致时，网关自动转换请求体。响应同理：后端返回的格式和客户端 Accept 不一致时，转换响应体。XML 和 JSON 的转换规则：XML 标签名做 key，属性忽略或加 @ 前缀。

数组处理：XML 里重复的标签转换为 JSON 数组。转换失败的请求返回 400，包含转换错误的位置信息。管理接口查看每个后端的格式配置、转换次数统计。端口 PORT 环境变量。
