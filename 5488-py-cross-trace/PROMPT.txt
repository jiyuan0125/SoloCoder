FastAPI 做跨服务追踪和采样。场景是高并发环境下不可能记录每条 Trace，需要采样策略只记录一部分，但错误 Trace 全部记录。

采样策略：头部采样（入口决定是否采样，采样率可配置，默认 10%）。但错误 Trace 不受采样率限制，全部记录。Trace 的完整生命周期：入口 Span 创建 → 多个子 Span 上报 → Trace 完成（入口 Span 上报结束时间）。如果只有子 Span 没有入口 Span，Trace 标记为"不完整"。

查询接口支持：按 TraceID 精确查、按服务名查最近 N 条 Trace、按操作名查耗时最长的 N 条。每条 Trace 返回调用链和总耗时。管理接口配置采样率、查看采样统计（总 Trace 数、采样数、错误 Trace 数）。
