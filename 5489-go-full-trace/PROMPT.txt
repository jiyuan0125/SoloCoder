Go 标准库做全链路追踪和瓶颈定位。场景是定位 API 响应变慢的原因，需要看到请求在每一层的耗时。

Span 数据通过 HTTP 上报，每个 Span 包含：TraceID、SpanID、ParentSpanID、服务名、操作名、开始时间、结束时间、标签、日志事件列表。日志事件是 Span 内部的时间点记录（比如"开始查数据库"、"数据库返回"、"开始调缓存"），用于更细粒度定位。

瓶颈分析接口：给定 TraceID，返回调用链 + 耗时分布 + 瓶颈点标记。瓶颈判定：某个 Span 耗时超过整条链路总耗时的 50%，或者某个 Span 的耗时比同操作的历史平均耗时高 3 倍。历史平均耗时按（服务名+操作名）聚合。端口 PORT 环境变量。
