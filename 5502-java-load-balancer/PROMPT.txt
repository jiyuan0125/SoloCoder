用 Spring Boot 做一个基于一致性哈希的负载均衡器。请求按某个 key（可配置为 IP、Header 值或请求体中的字段）做哈希，映射到上游实例。实例增减时只影响相邻的 key，已有的映射尽量不变。

虚拟节点数默认 150 个/实例，可以通过管理接口调整。新增实例时记录迁移的 key 数量，方便排查。健康检查走 TCP 握手，每 5 秒一次，超时 2 秒算失败。失败的实例从哈希环临时摘除，恢复后自动加回。

如果哈希环上没有可用实例，返回 503 并记录告警日志。管理接口支持查看当前环状态、各实例的 key 分布情况。端口 PORT 环境变量指定，mvn spring-boot:run 能跑起来。
