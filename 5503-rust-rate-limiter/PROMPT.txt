用 actix-web 写一个分层限流器。每个 API 路径有独立的全局限流配额（如 /api/query 每秒 100 次），同时每个客户端 IP 对每个路径也有独立配额（如每秒 10 次）。两层都通过才放行。

限流用滑动窗口实现，窗口大小可配（1s/5s/60s）。超限请求返回 429，响应头里带 Retry-After 告诉客户端多久后重试。配额用完一半时在响应头里加 Warning 标记。

限流规则通过管理接口动态配置，修改后立即生效。每个路径可以配置是否启用 IP 级别限流。统计信息接口可以查询各路径的当前 QPS、被限流次数、活跃 IP 数。端口环境变量指定，cargo run 能跑。
