用 Go 标准库 net/http 做一个带请求聚合的 API 网关。某些前端页面需要调多个后端接口，网关支持在一次请求中批量调用多个后端，结果聚合后一次性返回。

聚合规则通过配置定义，比如 /api/dashboard 聚合了 /api/users、/api/orders、/api/stats 三个接口的结果，分别放在 users、orders、stats 字段里。聚合请求中如果某个子接口失败，其他子接口的结果正常返回，失败字段标 error。

子接口可以配置超时和缓存。缓存的子接口结果 30 秒内不重复请求后端。路由匹配支持精确路径和前缀匹配，前缀匹配时 /api/v1/ 优先于 /api/。端口 PORT 环境变量指定，编译后能直接运行。
