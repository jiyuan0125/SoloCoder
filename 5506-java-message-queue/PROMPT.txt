用 Spring Boot 做一个简易消息队列。支持 Topic 和 Queue 两种模式。Topic 模式下消息广播给所有订阅者，Queue 模式下每条消息只投递给一个消费者。

消息投递失败（消费者返回 nack 或超时 30 秒）重试 3 次，间隔递增（5s、15s、45s）。3 次都失败的消息进死信队列，死信队列的消息可以通过管理接口重新投递或丢弃。

消费者通过心跳保活，30 秒没心跳认为掉线，掉线消费者的未确认消息重新入队。消息持久化到文件，重启后恢复。管理接口支持创建 Topic/Queue、查看积压量、消费者列表。端口 PORT 环境变量指定，mvn spring-boot:run 能跑起来。
