用 actix-web 写一个带 TTL 的多级缓存。支持两级：L1 内存缓存（LRU 淘汰）和 L2 文件缓存。查询时先查 L1，miss 了查 L2，再 miss 返回空。L2 命中时顺便回填 L1。

每个 key 有独立的 TTL，默认 300 秒。写入时同时写 L1 和 L2。L1 满了（最大 key 数可配）按 LRU 淘汰，L2 满了按文件修改时间淘汰最旧的。

TTL 过期的 key 在读取时惰性删除。另外每 60 秒做一次主动扫描，清理所有过期 key。支持 tag 功能——写入时打标签，按标签批量失效。管理接口可以查看 L1/L2 命中率、key 数量。端口环境变量指定，cargo run 能跑。
