用 Spring Boot 做一个带版本管理的配置中心。配置按 namespace + key 组织，每次修改生成新版本。可以查看任意 key 的修改历史，支持回滚到指定版本。

配置变更后主动推送给订阅了该 namespace 的客户端。推送用长连接，客户端断线重连后自动拉取断线期间的增量变更。推送失败时记录重试，最多重试 3 次。

配置支持文本、数字、布尔、JSON 四种类型。JSON 类型的配置支持部分更新——只改 JSON 中的一个字段而不是整个覆盖。管理接口展示各 namespace 的配置数量、订阅者数量、最近变更记录。端口 PORT 环境变量指定，mvn spring-boot:run 能跑起来。
