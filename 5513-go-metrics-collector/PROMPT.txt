用 Go 标准库 net/http 做一个指标采集服务。支持三种指标类型：Counter（只增不减的计数器）、Gauge（可增可减的仪表盘）、Histogram（分布直方图）。客户端通过 HTTP 接口上报指标数据。

Histogram 上报时传一个值，服务端自动维护分布桶（<10ms、<50ms、<100ms、<500ms、<1s、>=1s）。查询时返回各桶的数量和百分位数（P50、P90、P99）。

指标按 namespace + name 组织，支持标签（如 method=GET, path=/api/users）。同一指标名不同标签独立统计。数据保留最近 1 小时的分钟级精度，更早的按小时聚合。管理接口展示所有指标列表和实时值。端口 PORT 环境变量指定，编译后能直接运行。
