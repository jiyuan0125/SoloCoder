用 Go 标准库 net/http 做一个带认证注入的 API 网关。外部请求进来先过认证层，认证通过后网关把用户信息注入请求头转发到后端微服务。认证支持 API Key 和 JWT 两种方式。

API Key 校验查本地缓存，缓存 5 分钟刷新一次。JWT 校验包括签名验证和过期检查。Token 过期返回 401，无效返回 403。认证通过后在请求头加 X-User-Id 和 X-User-Roles。

路由配置支持路径参数，/api/users/:id 的 :id 部分提取后注入到转发请求的 header。后端有多个实例时做轮询负载。请求和响应日志异步写入，包含耗时和状态码。端口 PORT 环境变量指定，编译后能直接运行。
