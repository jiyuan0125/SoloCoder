用 Spring Boot 做一个带优先级的消息队列。消息有 3 个优先级（高、中、低），高优先级消息优先投递。同一优先级内按 FIFO 顺序。每个队列独立管理，队列可以配置最大长度，满了之后低优先级消息被丢弃为新消息腾空间。

消费者按组管理，同一组的消费者竞争消费同一队列。消费者可以订阅多个队列，每个队列的消费进度独立跟踪。消费者断开后，其未确认的消息在 10 秒后重新投递给同组其他消费者。

消息确认有超时机制——消费者取走消息后 60 秒内必须确认，否则自动重投。管理接口可以查看各队列深度、消费者状态、各优先级消息占比。端口 PORT 环境变量指定，mvn spring-boot:run 能跑起来。
