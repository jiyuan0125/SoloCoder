Authorization Code 流程——客户端跳转到网关授权页面，用户登录后网关拿到 code 换取 access token 和 refresh token。actix-web 实现。access token 存网关端（不暴露给浏览器），浏览器拿到 session ID，后续请求带 session ID，网关查到对应 access token 再转发到后端。session 有效期 2 小时，过期后用 refresh token 自动续期。

refresh token 也过期了就重定向到登录页。支持多个 OAuth2 Provider，入口路径区分。接口展示活跃 session 数。

端口环境变量指定，cargo run 能跑。
