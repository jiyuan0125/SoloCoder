用 Spring Boot 做一个带区域感知的负载均衡器。后端实例注册时带上区域标签（如 us-east、cn-north），请求进来时优先路由到同区域的实例。同区域没有可用实例时，按延迟排序跨区域路由。

每个区域的实例独立做轮询分配。区域间的延迟通过定期探测维护，每分钟测一次，记录最近 5 次的均值。延迟超过 500ms 的区域降级为备选。

管理接口可以查看各区域的实例列表、健康状态、平均延迟。新增实例时指定区域，删除实例后该区域计数实时更新。跨区域路由时在响应头里加一个 X-Cross-Region 标记。端口 PORT 环境变量指定，mvn spring-boot:run 能跑起来。
