用 Spring Boot 做一个带环境隔离的配置中心。支持多套环境（dev、staging、prod），同一份配置在不同环境可以有不同的值。管理接口切换环境时展示当前环境的所有配置。

新建配置时可以指定是否所有环境共用（如日志格式），还是每个环境独立（如数据库地址）。共用的配置修改一次全环境生效，独立的只改当前环境。

环境之间支持配置克隆——比如把 staging 的配置克隆一份到 prod。克隆后 prod 的配置变成独立的，修改 staging 不影响 prod。配置变更审计日志记录谁在什么时间改了什么。端口 PORT 环境变量指定，mvn spring-boot:run 能跑起来。
