用 Gin 写一个 WebSocket-HTTP 桥接器。把 WebSocket 消息转换成 HTTP 请求转发到后端，后端的 HTTP 响应转回 WebSocket 消息发给客户端。

WebSocket 消息格式定义为 JSON，包含 path、method、body 三个字段。桥接器根据 path 和 method 构造 HTTP 请求。

支持双向——后端也可以主动推送。后端调用桥接器的 HTTP 接口发消息，桥接器转发给对应的 WebSocket 客户端。客户端通过连接时的 query 参数指定一个 channel ID，后端按 channel ID 定位客户端。端口 PORT 环境变量指定，编译后能直接运行。
