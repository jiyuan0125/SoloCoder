用 tokio 写一个带 Token 交换的认证网关。内部服务之间的调用也需要认证，但不想每个服务自己管理密钥。网关提供 Token 交换接口——用服务 A 的 Token 换取一个 scope 限定为"以服务 A 身份访问服务 B"的短期 Token。

交换的 Token 有效期只有 60 秒，只能用于访问指定的目标服务。目标服务验证这个 Token 时需要回查网关确认 Token 仍然有效。

服务注册时获得一个长期 API Key，用这个 Key 换取本服务的 Token。API Key 可以通过管理接口轮换，轮换后旧 Key 有 24 小时过渡期。管理接口展示各服务的 Token 使用统计。端口环境变量指定，cargo run 能跑。
