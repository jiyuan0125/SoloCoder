业务方那边提了个需求，要负载均衡服务，用 Netty 实现裸 HTTP 服务，不用 Spring，Maven 构建。

在线教育直播流分发，按课程 ID 哈希到固定转码节点，GPU 节点处理高码率 CPU 处理低码率。同一课程始终路由同一节点（一致性哈希）。节点下线时该课程流迁移到新节点保持会话。节点列表通过接口动态增删。代理暴露 /stats 展示每个节点连接数。

用 Netty 实现裸 HTTP 服务，不用 Spring，Maven 构建。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
