B2B 开放平台管理合作伙伴 API 调用，Fiber 框架实现带认证和限流的网关。

每个合作伙伴分配 API Key，调用带 X-API-Key 头。Key 过期拒绝返回 401。不同等级速率限制：标准 100 次/分、专业 500 次/分、企业不限速。超限返回 429 带 Retry-After。

后端错误码统一转标准格式——JSON 含 code、message 和 request_id。调用日志按合作伙伴分组，记录方法、路径、状态码、耗时和 request_id。API Key 创建时指定等级和有效期，过期自动失效。

接口：POST /keys、DELETE /keys/{id}、GET /keys、GET /logs?partner=xxx、GET /stats。数据存内存。端口 PORT 环境变量指定，go run 能跑起来。
