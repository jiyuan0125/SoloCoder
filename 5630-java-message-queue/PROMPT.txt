现在用的方案不支持我们想要的特性，用 Netty 实现裸 HTTP 服务，不用 Spring，Maven 构建 自己写个消息队列服务。

跨服务事件广播，多服务同时订阅，新服务可订阅已有事件类型。事件有版本号（v1/v2），消费者兼容旧版本。事件状态：已发布→已投递→已消费/已失败。投递失败重试 3 次。存储最近 10000 条。消费者注册指定类型和版本。

用 Netty 实现裸 HTTP 服务，不用 Spring，Maven 构建。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
