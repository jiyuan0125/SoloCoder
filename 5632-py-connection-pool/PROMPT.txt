物联网设备接入网关，设备用 MQTT 和 CoAP 两种协议接入，网关转换成内部 HTTP 调用。Spring Boot 2.x。

MQTT 设备发 JSON 消息到 topic/devices/{device_id}/data，网关订阅 MQTT broker 解析后转发到后端 HTTP API。CoAP 设备发二进制数据，网关解码后转发。设备认证用预共享密钥，每个设备一个。密钥信息你自己设计存储格式。

设备上报的数据要包含设备 ID、时间戳、数据类型、值。网关要校验数据完整性（校验和或签名，具体用什么算法你来定）。批量上报支持一次最多 50 条数据。设备注册和密钥管理通过 API。端口环境变量。
