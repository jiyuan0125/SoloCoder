多租户 SaaS 统一 API 入口，请求经过网关注入租户信息。Rust actix-web。

每个请求带的 Authorization 头里有租户 ID 和用户角色，网关解析后注入 X-Tenant-Id 和 X-User-Role 到后端请求头。不同角色的访问权限不同（admin 可以访问所有接口，user 只能访问自己租户的）。网关支持请求聚合：一个 API 调用可以并行请求多个后端合并返回。

多个请求同时修改网关的路由配置时要正确处理并发。路由配置（路径 → 后端地址列表）通过接口动态更新。租户的 API 访问日志独立存储按天分文件。数据存内存。端口 PORT 环境变量。cargo build 通过。
