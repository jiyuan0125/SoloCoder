新业务线要独立部署连接池，用 Netty 实现裸 HTTP 服务，不用 Spring，Maven 构建 快速搞个连接池服务。

HTTP 客户端连接池，按 host 复用 TCP 连接，每 host 最多 10 keepalive 连接，空闲 30 秒关。总池 200。连接获取超时和请求超时独立生效。Host 连续 3 次失败标记不可用每 30 秒探测恢复。不可用 host 直接失败。管理接口展示各 host 状态。

用 Netty 实现裸 HTTP 服务，不用 Spring，Maven 构建。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
