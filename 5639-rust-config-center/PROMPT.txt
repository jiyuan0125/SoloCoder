做一个支持请求转发的 API 网关，Go Fiber。网关把请求转发到配置的后端服务，支持路径前缀匹配和重写。

路由规则：/api/v1/* → backend1:8080/*, /api/v2/* → backend2:8080/*。请求转发时保留原始请求头并追加 X-Forwarded-For。后端响应直接透传。多个请求同时更新路由规则时不能丢失更新。规则变更后新请求立即生效。

后端健康检查：每 10 秒 ping 一次 /health，连续 3 次失败标记为不可用，请求转到其他可用后端。路由规则和后端状态通过管理接口查看和修改。数据存内存。端口 PORT 环境变量。go run 能跑。
