帮我做一套分布式锁服务，用 Netty 实现裸 HTTP 服务，不用 Spring，Maven 构建 后端。

文件处理排他锁，多阶段进度追踪，同一文件只被一个 worker 处理。分下载→解析→入库多阶段，每阶段更新进度。失败释放锁其他可接续。锁含当前阶段和进度百分比。文件任务格式 file_id/status/stage/progress/holder。

用 Netty 实现裸 HTTP 服务，不用 Spring，Maven 构建。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
代码分至少三个源文件。
