API 响应缓存，GET 请求按 URL+查询参数做 key。Go Gin。

不同的 Content-Type（JSON/XML）分开缓存。带 Authorization 头的个性化请求不缓存。缓存容量满 LRU 淘汰。缓存响应带上 Age 头表示已缓存秒数。POST/PUT/DELETE 请求自动失效相关路径的 GET 缓存（前缀匹配失效）。

比如 PUT /api/users/123 失效 /api/users/123* 的所有缓存。缓存项包含：key、value、content-type、创建时间、过期时间。管理接口可以查看缓存大小和手动清理。端口 PORT 环境变量。go run 能跑。
