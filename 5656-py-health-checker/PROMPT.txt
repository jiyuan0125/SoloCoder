用 Netty 做一个独立的 TCP 缓存服务器（类似简化版 Redis）。Maven 不用 Spring。

支持 SET key value [EX seconds]、GET key、DEL key、EXISTS key 四个命令。文本协议，换行分隔。过期的 key 访问时自动删除。内存上限 100MB，超了按 LRU 淘汰。客户端通过 TCP 连接发送命令。

多个客户端同时操作同一个 key 时数据不能出错。SET 如果 key 已存在则覆盖。GET 不存在的 key 返回 nil。支持 SCAN 命令列出所有匹配前缀的 key。端口环境变量。mvn clean package 通过。
