日志分级过滤，线上只持久化 WARN 以上，DEBUG/INFO 存 ring buffer（10000 条），出错时 dump 最近 100 条。过滤规则运行时可修改。日志格式 level/service/message/timestamp/extra。规则含级别阈值、关键词白名单、service 过滤。管理接口改规则、dump buffer。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
