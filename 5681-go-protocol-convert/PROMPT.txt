gRPC 网关方案太重了我们只要核心转码功能，Fiber 框架写 HTTP 到 gRPC 协议转码网关。

客户端发 RESTful JSON，网关转 Protobuf 通过 gRPC 调后端，响应转回 JSON。URL 自动映射：/api/v1/users → users.UserService.List。JSON 字段自动映射 Protobuf 类型，基本类型自动转换。gRPC 状态码映射 HTTP：OK→200、NotFound→404、InvalidArgument→400、PermissionDenied→403、Unavailable→503。

路由映射通过接口配置，每条指定 HTTP method+path → gRPC service+method。支持路径参数提取。后端不需要真实 gRPC 可用模拟。

端口 PORT 环境变量，go run 跑起来。
