开源的那个功能太多但我们要的没做好，Spring Boot 2.x，Maven，JDK 17 从零写协议转换服务。

旧版 SOAP 到 REST 桥接，老系统 SOAP 接口，新服务调用需转换。REST 转 SOAP XML 解析 SOAP 响应返 JSON。SOAP 命名空间和复杂类型要正确处理。支持 WS-Security 认证转换。转换规则可配置。管理接口查看规则和测试转换。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
