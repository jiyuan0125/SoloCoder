试了三个方案都不满足需求，只能 用 tokio 做异步运行时，裸 TCP/HTTP 处理 自己写协议转换服务。

JSON 到 Protobuf 双向转换器，JSON→Protobuf 序列化和 Protobuf→JSON 反序列化。嵌套消息、repeated、map 字段正确转换。字段缺失用 Protobuf 默认值。提供 schema 注册接口。schema 格式 name/fields（name/type/repeated）。管理接口 CRUD schema。

用 tokio 做异步运行时，裸 TCP/HTTP 处理。数据存内存，用合适的集合类型。端口通过环境变量 PORT 指定。cargo build 能编译通过，cargo run 能跑起来。
