API 性能指标采集器。Rust actix-web。

收集每个接口的 QPS、P50/P95/P99 响应时间、错误率。数据按分钟粒度聚合，保留最近 7 天。查询接口返回指定时间段的指标。导出 Prometheus 格式通过 /metrics 端点。

接口注册格式：name、method、path。每次请求上报：interface_name、status_code、duration_ms、timestamp。聚合数据结构：interface、time_bucket（分钟）、request_count、error_count、durations（存所有用于计算百分位）。管理接口：注册接口、查询指标。数据存内存。PORT 环境变量。cargo build 通过。
