定时任务、消息消费等异步场景的链路追踪，异步任务生成独立 TraceID 通过消息 header 传下游。Spring Boot 2.x。

异步任务链路串联器，定时任务、消息消费等异步场景的链路追踪。异步任务生成独立 TraceID 通过消息 header 或任务参数传下游。一个触发源产生多个异步任务要关联。异步链路超时未完成标记告警。格式 parent_trace_id/child_traces[]/status/timeout。

Spring Boot 2.x + Maven + JDK 17，端口 PORT 环境变量，mvn clean package 编译 java -jar 跑。
