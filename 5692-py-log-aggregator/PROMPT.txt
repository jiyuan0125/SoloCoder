API Key 认证网关。Spring Boot 2.x Maven JDK 17。

第三方开发者通过 API Key 访问接口。Key 有权限范围（read/write/admin）和速率限制。Key 泄露可立即禁用并生成新 Key。所有调用记录关联到 Key，用于统计。Key 有使用统计（调用次数、错误率、平均响应时间）。

Key 格式：key_id（UUID）、secret（随机字符串）、partner_name、permission、rate_limit、status（active/revoked）、created_at。请求头 X-API-Key 携带。管理接口：创建/吊销/重新生成 Key、查看使用统计。数据 ConcurrentHashMap 存。端口环境变量。mvn package 通过。
