用 Rust 写一个表达式计算器，REPL 交互模式。支持四则运算、变量赋值、内置函数、比较和逻辑运算。

语法规则：
1. 一行一个表达式或赋值语句，赋值格式：变量名 = 表达式（不支持 let/var 关键字，直接写 x = 5）
2. 支持 + - * / % 和比较运算 == != < > <= >=，比较结果返回 1（true）或 0（false）
3. 支持 && || ! 逻辑运算，&& 和 || 必须短路求值：false && 右边不执行，true || 右边不执行
4. 支持 if-else 三元表达式：if (条件, 值1, 值2)，条件为真返回值1否则返回值2，值1和值2都会被求值（不是惰性的）
5. 内置函数：sqrt、abs、max（两个参数）、min（两个参数），参数是 double 类型，返回 double
6. 变量未定义时返回错误提示，变量名只支持字母开头、字母数字下划线

输出要求：
7. 每次输入表达式后输出计算结果，格式为 "= {值}"，整数显示为整数（5 而非 5.0），浮点数显示浮点（5.5）
8. 赋值语句不输出结果
9. 除以零返回 "Error: division by zero"，其他错误返回 "Error: {描述}"

代码分 tokenizer、parser、evaluator、内置函数几个模块，cargo build 能过。
