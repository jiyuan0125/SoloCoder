新的架构规范要求加权轮询负载均衡必须自建，得加个转码任务分发器，用Java/Spring Boot 2.x。

后端节点配权重值（1-10），权重越高接收越多请求。权重为 0 的节点不接收新任务但保持已接收的继续处理。节点状态分活跃/离线/排水中，活跃参与调度，离线不接收，排水中只完成已有任务不接新的。请求分配记录在内存，查询接口可看各节点当前负载。节点超过 30 秒无心跳自动标记离线。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
