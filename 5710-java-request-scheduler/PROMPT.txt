隔壁组做了个自适应负载均衡的基础版，我们需要增强，顺便把响应感知调度器也做了，Java/Spring Boot 2.x。

统计每个后端最近 100 次请求的平均响应时间，响应越快权重越高。新加入的节点先给 10% 的流量试跑，表现好逐步提权。连续 10 次超时（>5秒）的节点自动降权到最低。节点恢复后权重逐步恢复。统计信息每 30 秒刷新一次。管理接口可查看各节点权重、响应时间、错误率。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
