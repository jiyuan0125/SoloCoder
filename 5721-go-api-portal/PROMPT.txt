试了三个现成方案都不满足所有内部服务的API统一经过网关做鉴权和限流这个需求，只能Go/标准库 net/http自己写内部API网关。

请求进来先鉴权（API Key 校验），再限流（每Key每分钟100次），最后路由转发。路由表按路径前缀匹配，支持通配符。鉴权失败的返回 401，限流的返回 429，路由不到的返回 404。API Key 有权限范围，不同 Key 可访问不同路径前缀。后端转发时注入 X-User-Id 头。管理接口管理 API Key 和路由规则。所有请求记录访问日志。

鉴权模块、限流模块、路由模块、转发模块分开。

Go 标准库 net/http 实现，不用框架。数据存内存，用 map 或自定义结构体。端口通过环境变量 PORT 指定。go run 能跑起来。
