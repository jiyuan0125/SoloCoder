移动端一个页面要展示的数据来自多个后端服务，网关负责聚合，Java/Spring Boot 2.x后端。

定义聚合接口模板：一个聚合请求触发多个后端调用，结果合并后返回。后端调用之间有依赖关系的串行，无依赖的并行。并行调用总耗时取最慢的那个。某个后端失败时返回部分结果加失败标记，不阻塞整个聚合。聚合结果支持字段裁剪：客户端指定需要哪些字段。聚合模板通过 /templates 接口管理。

聚合模板引擎、并行调用调度、结果合并分模块。

Spring Boot 2.x + Maven + JDK 17，端口 PORT 环境变量，mvn clean package 编译 java -jar 跑。
