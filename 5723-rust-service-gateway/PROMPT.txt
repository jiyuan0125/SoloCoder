业务上遇到个问题：设备用MQTT协议上报数据，平台内部用HTTP，网关做协议转换。打算用Rust/tokio搞个IoT协议适配网关。

接收MQTT消息（模拟：HTTP接口接收原始格式）解析后转换成内部统一的JSON格式。不同设备型号的消息格式不同，转换规则按设备型号配置。转换失败的进死信队列待人工处理。转换成功后调用内部HTTP接口。内部接口响应码非200的重试3次。管理接口管理设备型号和转换规则。支持查看转换统计和死信队列。

消息解析、规则引擎、内部调用、死信队列分模块。

Rust tokio（裸 TCP/HTTP）。数据存内存，用合适的集合类型。端口通过环境变量 PORT 指定。cargo build 能编译通过，cargo run 能跑起来。
