线上的旧中间件太简陋了，重写一个支付消息可靠投递，Java/Spring Boot 2.x实现。

消息写入时先持久化到内存队列（WAL日志模式），确认持久化成功后返回写入成功。投递失败的标记为待重试。服务启动时扫描未投递和待重试的消息重新处理。消息状态：待投递→投递中→已确认→已完成。投递中的消息重启后回到待投递重新投递。支持按时间范围查询消息投递状态。管理接口可手动重新投递指定消息。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
