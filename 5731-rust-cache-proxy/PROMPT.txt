上个月线上出了个中间件故障，影响了整个服务链路。现在要上商品信息缓存服务，用Rust/tokio。

按商品ID缓存商品详情，TTL 可配置默认 10 分钟。缓存命中直接返回，未命中回源查询并存入缓存。支持手动失效：商品更新时调 /cache/invalidate/{id} 清除。支持批量预加载：活动前批量预热缓存。缓存满时按 LRU 淘汰。统计接口返回命中率、当前缓存数、淘汰次数。支持前缀扫描：按类目ID前缀清除该类目所有商品缓存。

Rust tokio（裸 TCP/HTTP）。数据存内存，用合适的集合类型。端口通过环境变量 PORT 指定。cargo build 能编译通过，cargo run 能跑起来。
