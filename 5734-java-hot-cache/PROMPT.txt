下周要给老板演示双层缓存这块，先出个能跑的配置双层缓存服务，Java/Netty。

L1 本地缓存（容量小速度快）+ L2 远程缓存（模拟为另一个缓存层）。查询先查 L1，未命中查 L2，都未命中回源。L2 命中后回填 L1。更新时同时写 L1 和 L2。L1 TTL 比 L2 短（L1: 1分钟，L2: 10分钟）。失效时 L1 和 L2 同时失效。支持按前缀批量失效。L1 容量满了按 LRU 淘汰。统计接口返回各层命中率和回源率。

Java Netty 实现，Maven，JDK 17。数据用内存存储。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，运行主类能启动。
