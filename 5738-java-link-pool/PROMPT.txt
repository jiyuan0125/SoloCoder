有个老模块是硬编码写的，维护不动了，用Java/Spring Boot 2.x重写连接健康守护器。

每 10 秒对空闲连接做一轮健康检查。检查方式：发送心跳包并等待响应，超时 3 秒视为不健康。不健康的连接立即销毁并在需要时重建。连续 3 次创建连接失败的Host标记为不可用，不再尝试创建。不可用的Host每 60 秒尝试恢复一次。管理接口可查看各Host的健康检查历史。支持手动触发全量健康检查。检查结果记录统计：总检查次数、失败次数、当前不可用Host。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
