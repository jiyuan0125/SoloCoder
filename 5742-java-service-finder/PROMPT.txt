试了三个现成方案都不满足dev/staging/prod 环境的服务实例互相隔离这个需求，只能Java/Spring Boot 2.x自己写环境化服务注册中心。

服务注册时必须指定环境标签（dev/staging/prod）。查询服务列表时按环境过滤，不同环境的实例不互通。同一服务在不同环境可以有不同配置。环境内支持分组：如 dev 环境下按项目组分组。跨环境查询需要特殊权限标记。环境下的实例超过 100 个时自动分页。管理接口可管理环境配置和查看各环境实例数量。支持一键清理某个环境的所有实例。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
