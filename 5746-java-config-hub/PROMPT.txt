想用Java/Spring Boot 2.x练手中间件这块，做个配置版本管理服务。

配置以 KV 形式存储，支持嵌套结构（如 app.db.host = localhost）。每次修改创建新版本，版本号自增。查询时默认返回最新版本，可指定版本号查询历史。支持回滚到指定版本，回滚也产生新版本。配置变更记录操作人和时间。配置支持加密存储（标记为 secret 的值存密文，返回时脱敏）。管理接口管理配置的增删改查和版本。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
