市面上的中间件要么太重要么太贵，我们只需要各服务输出JSON格式日志，统一收集、存储、查询，Python/aiohttp写一个。

接收 JSON 格式日志，必须包含 level、timestamp、message 字段。支持自定义字段。日志按服务名和时间建索引。查询接口支持按 level、时间范围、关键字过滤。关键字搜索支持模糊匹配。日志保留 7 天自动清理。写入接口批量接收：一次请求可提交多条日志。查询结果支持分页。统计接口返回各 level 的日志数量和趋势。

Python aiohttp 全异步。数据存内存，用字典或列表。端口通过环境变量 PORT 指定。pip install 装好依赖后能跑起来。
