业务上遇到个问题：高并发日志写入走批量缓冲，定时刷盘。打算用Java/Spring Boot 2.x搞个日志批量写入器。

日志先写入内存缓冲区，缓冲区满（1000条）或超时（5秒）时批量刷盘。刷盘失败的重试 3 次，全部失败则丢弃并记录告警。缓冲区满了的新日志走降级策略：丢弃最旧的或拒绝新写入（可配置）。写入接口非阻塞：提交后立即返回不等待刷盘。查询时可查到已刷盘的数据，缓冲区中未刷盘的数据不参与查询。管理接口查看缓冲区水位和刷盘统计。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
