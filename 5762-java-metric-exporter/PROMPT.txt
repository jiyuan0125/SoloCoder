季度末了，中间件这块还是手动管的，赶紧搞个资源水位监控服务，Java/Spring Boot 2.x。

Gauge 可增可减，反映当前值。set 接口设置值，increment/decrement 接口调整。支持按标签维度（如 host=server1, type=cpu）。变化历史记录最近 100 个数据点。告警规则：超过阈值触发告警（如 CPU > 90%）。告警冷却时间可配置，同一指标 5 分钟内不重复告警。导出 Prometheus 格式。管理接口查看所有 gauge 和告警状态。

Gauge引擎、告警检测、历史记录分模块。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
