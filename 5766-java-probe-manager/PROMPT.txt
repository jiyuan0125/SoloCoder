上个月线上出了个中间件故障，影响了整个服务链路。现在要上HTTP探针管理器，用Java/Spring Boot 2.x。

探针配置：目标URL、检查间隔（默认10秒）、超时（默认5秒）、健康阈值（连续几次成功算健康）、不健康阈值（连续几次失败算不健康）。状态变化时触发通知（记录到内存列表可查询）。通知内容包括目标、旧状态、新状态、触发时间。探针支持暂停和恢复。管理接口管理探针配置和查看状态历史。超过 100 条状态历史自动清理最旧的。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
