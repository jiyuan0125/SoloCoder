现在用的开源方案只能看死活，不满足需求——响应时间、错误率这些维度都得综合评分。Java/Spring Boot 2.x 写个服务健康评分器。

评分维度：响应时间（P99 < 500ms 满分）、错误率（< 1% 满分）、可用性（检查成功率 100% 满分）。各维度权重可配默认各 1/3。综合评分 0-100，90+ 健康，70-89 警告，<70 不健康。评分每 30 秒更新一次，历史保留 24 小时。SLA 报告：统计指定时间段内的平均评分和各等级占比。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储。端口 PORT 环境变量。mvn clean package 能编译通过，java -jar 能跑起来。
