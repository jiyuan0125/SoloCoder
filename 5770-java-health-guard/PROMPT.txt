现在用的开源方案不支持不只看死活，还要看响应时间、错误率等多个维度综合评分，自己加太麻烦，不如用Java/Spring Boot 2.x写个服务健康评分器。

评分维度：响应时间（P99 < 500ms 满分）、错误率（< 1% 满分）、可用性（检查成功率 100% 满分）。各维度权重可配默认各 1/3。综合评分 0-100。90+ 为健康，70-89 为警告，<70 为不健康。评分每 30 秒更新一次。评分历史记录最近 24 小时。SLA 报告：统计指定时间段内的平均评分和各等级占比。管理接口查看评分和SLA报告。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
