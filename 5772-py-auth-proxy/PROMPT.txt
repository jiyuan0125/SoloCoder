第三方开发者用API Key调用接口，按Key限流和鉴权。所以想做一个API Key网关，Python/aiohttp。

API Key 格式：ak_{随机字符串}。请求带 X-API-Key 头。Key 绑定：开发者ID、权限范围（允许的路径前缀列表）、限流配额、过期时间。Key 过期返回 401。权限不足返回 403。限流超额返回 429。支持 Key 轮换：生成新 Key 后旧 Key 在宽限期（24小时）内仍可用。管理接口管理 Key 的创建、吊销、权限配置。Key 使用统计：调用量、错误量、最后使用时间。

Python aiohttp 全异步。数据存内存，用字典或列表。端口通过环境变量 PORT 指定。pip install 装好依赖后能跑起来。
