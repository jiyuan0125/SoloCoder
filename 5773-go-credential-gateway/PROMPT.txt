有个老模块是硬编码写的，维护不动了，用Go/标准库 net/http重写RBAC鉴权网关。

角色定义：admin/operator/viewer。权限绑定：每个角色允许的 HTTP 方法 + 路径前缀组合。admin 全部允许，viewer 只允许 GET，operator 允许 GET 和 POST。用户可以有多个角色，权限取并集。请求进来先验证Token获取用户角色，再判断是否有权限。无权限返回 403。角色和权限配置可通过管理接口调整。操作审计日志记录所有请求的鉴权结果。

Go 标准库 net/http 实现，不用框架。数据存内存，用 map 或自定义结构体。端口通过环境变量 PORT 指定。go run 能跑起来。
