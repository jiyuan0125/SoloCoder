隔壁组做了个租户特征标签路由的基础版，我们需要增强，顺便把租户染色路由器也做了，Python/FastAPI。

租户等级：vip/standard/free。VIP 租户请求带 X-Tenant-Level: vip 头路由到专属后端。Standard 走共享后端但带宽有保障。Free 走共享后端且有额外限流。租户等级变更后下次请求生效。VIP 后端挂了降级到共享后端但标记降级状态。降级期间 VIP 租户的限流配额提高到和 standard 一样（防止共享后端被打爆）。管理接口管理租户等级和路由规则。

FastAPI 全异步。数据存内存，用字典或列表。端口通过环境变量 PORT 指定。pip install 装好依赖后能跑起来。
