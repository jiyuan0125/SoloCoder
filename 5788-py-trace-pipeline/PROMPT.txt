之前用其他方案做中间件，这次换Python/aiohttp试试调用链可视化服务。

根据 Span 的 parent 关系构建调用树。树节点包含服务名、操作名、耗时、状态。支持展开/折叠查看子调用。调用链中错误节点高亮标记。同一层级的子节点按开始时间排序。耗时占比计算：每个节点占整个trace总耗时的百分比。查询接口返回树形 JSON 结构。支持搜索节点：按服务名或操作名模糊搜索。管理接口查看最近的trace列表。

树构建、节点查询、错误标记分模块。

Python aiohttp 全异步。数据存内存，用字典或列表。端口通过环境变量 PORT 指定。pip install 装好依赖后能跑起来。
