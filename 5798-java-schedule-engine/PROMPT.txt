市面上的中间件要么太重要么太贵，我们只需要每隔N分钟执行一次数据同步任务，Java/Spring Boot 2.x写一个。

任务配置：名称、执行间隔（分钟）、回调URL。任务状态：运行中、暂停、已完成（一次性任务）。任务执行时间超过间隔时跳过下一次不排队。任务执行记录包含：开始时间、结束时间、耗时、状态、错误信息。连续 3 次执行失败自动暂停任务并告警。告警信息可查询。管理接口管理任务和查看执行历史。支持手动立即执行一次（不影响调度周期）。

Spring Boot 2.x，Maven，JDK 17。数据用内存存储（ConcurrentHashMap 之类）。端口通过环境变量 PORT 指定。mvn clean package 能编译通过，java -jar 能跑起来。
