线上的网关每次改路由要重启，业务受不了。用 Spring Boot 写一个热更新的 API 网关。

路由配置存在内存里，通过 API 接口 CRUD。每个路由项包括：路径模式、后端地址、超时毫秒、重试次数、是否启用认证。路径模式支持路径参数，比如 /users/{id}/orders。

请求进来后按路径匹配路由，提取路径参数注入到转发的 Header 里。后端返回后如果状态码是 5xx 且重试次数 > 0，换一个同组后端重试。

认证目前先做 API Key 验证，Key 从 Header 的 X-API-Key 读。Key 和权限的映射关系通过管理接口维护。

Maven 构建，端口 server.port。
