有个场景需要缓存二进制数据（图片缩略图）。用 Go/Gin 写。

缓存 value 支持 string 和 binary 两种类型。string 类型存 UTF-8 文本，binary 类型存 base64 编码的二进制。get 时返回 Content-Type 标明类型。

key 有最长长度限制（256 字节），value 有最大大小限制（可配，默认 1MB）。超限拒绝存储。

缓存分层：热数据放内存，冷数据溢出到磁盘文件。内存和磁盘的阈值可配。读取冷数据时自动加载回内存。

提供接口查看缓存使用量（内存、磁盘）、命中率、各类型的 key 数量统计。

端口 PORT 环境变量，go build 能过。
