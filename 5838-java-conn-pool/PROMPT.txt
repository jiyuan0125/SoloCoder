高并发场景下连接池性能很关键。用 Go 标准库 net/http 写。

连接池用 channel 实现——带缓冲的 channel 存空闲连接。获取从 channel 读，归还往 channel 写。channel 满了说明已达上限，归还时直接关闭连接。

支持连接预热：启动时按最小连接数预先创建。连接最大存活时间可配，超时的连接归还时不再放回 channel，而是关闭。

获取连接时支持 context 取消——等待过程中如果 context 被取消，从等待队列中移除。

统计接口返回池的利用率（使用中/最大连接数）、每秒获取请求数、等待超时次数。
