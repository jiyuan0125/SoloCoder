之前那个配置中心不支持灰度发布配置。用 Java/Spring Boot 写。

配置发布分两种模式：全量发布（所有客户端立刻生效）和灰度发布（先推给指定 IP 列表的客户端）。灰度发布后可以观察一段时间，确认没问题再全量推。

配置加密：标记为加密的 key，存储时 AES 加密，返回给客户端时解密。加密密钥通过环境变量注入，不硬编码。

客户端除了长轮询，还要提供 SDK 模拟接口——拉取全量配置。服务启动时拉一次全量，后续走 watch 增量。

配置导入导出：把一个 namespace 的所有配置导出为 JSON 文件，导入到另一个 namespace。

Maven 构建，端口 server.port。
