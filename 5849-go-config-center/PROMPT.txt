配置中心要支持多环境（dev/staging/prod）。用 Go 标准库 net/http 写。

同一份配置 key 在不同环境下可以有不同的 value。环境是顶级分组。查询时必须指定环境，不提供跨环境查询。

环境之间可以继承：staging 继承 dev 的配置（staging 没配的 key 从 dev 继承），prod 继承 staging。继承关系可配。

配置变更只影响指定环境。继承的 key 如果被子环境覆盖，子环境的值优先。删除子环境的 key 后回退到父环境的值。

管理接口可以对比两个环境的配置差异（哪些 key 不同、哪些 key 只在一个环境存在）。

端口 PORT 环境变量，go build 能过。
