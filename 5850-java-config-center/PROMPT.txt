有个场景需要配置的变更联动——改一个 key 自动触发其他 key 的更新。用 Go/Gin 写。

配置规则支持引用：value 里可以用 ${other.key} 引用其他配置的值。引用在读取时解析。被引用的 key 变更后，引用它的 key 下次读取时拿到新值。

触发器机制：某个 key 变更后自动执行预定义的动作。目前支持的动作类型：HTTP 回调（POST 到指定地址）和级联更新（自动修改其他 key 的值）。

触发器执行失败重试 3 次，间隔递增（1s、3s、5s）。全部失败后标记触发器异常，管理接口能看到。

配置格式校验：标记为 JSON 格式的 key，保存时校验是否合法 JSON。不合法拒绝保存。

端口 PORT 环境变量，go build 能过。
