日志要按 trace_id 串联起来才能看完整链路。用 FastAPI 写。

日志上报接口接收单条或批量日志。每条日志必须有 trace_id，可选 span_id 和 parent_span_id。有 span 信息的日志会被组织成树形结构。

按 trace_id 查询时返回完整的调用树，按时间排序。可以展示每个 span 的开始时间、结束时间、耗时。

日志告警：配置规则，当某个服务在 N 分钟内 ERROR 级别日志数超过 M 条时触发告警。告警记录到 SQLite，同时回调通知。

统计接口返回每个 trace 的总耗时和 span 数量，用于发现慢请求。

端口 PORT 环境变量。
