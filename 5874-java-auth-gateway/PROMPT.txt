需要一个多租户的认证网关。用 Go 标准库 net/http 写。

每个租户独立的用户体系和认证配置。请求先通过域名或 Header 中的 X-Tenant-ID 识别租户。

支持三种认证方式（按租户配置）：JWT、API Key、Basic Auth。同一个租户只能启用一种。

用户管理接口：创建用户、删除用户、修改密码。密码用 bcrypt 哈希存储。用户信息包括：用户名、密码哈希、角色（admin/member）、状态（启用/禁用）。

权限校验：admin 角色可以访问所有接口，member 角色只能访问非管理接口。权限不满足返回 403。

端口 PORT 环境变量，go build 能过。
