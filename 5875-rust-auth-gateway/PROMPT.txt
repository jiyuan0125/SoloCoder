认证网关要支持 SSO（单点登录）。用 Go/Gin 写。

登录接口：用户提交用户名密码，验证通过后生成 session_id，返回 Set-Cookie。Session 存内存，有 TTL（可配，默认 2 小时）。

SSO 机制：各子系统重定向到网关的 /sso/login?redirect=xxx。如果用户已登录（session 有效），直接重定向回子系统并带上临时 code。子系统用 code 换 token。

Session 管理接口：查看所有活跃 session、强制下线某个 session、查看某个用户的登录历史。

登录失败保护：同一用户名连续 5 次登录失败后锁定 15 分钟。锁定记录存内存。

端口 PORT 环境变量，go build 能过。
