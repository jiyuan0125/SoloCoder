需要按请求内容动态染色。用 FastAPI 写。

染色策略支持三种：基于 Header 匹配、基于 URL 路径匹配、基于请求 body 字段值匹配。body 匹配只支持 JSON 格式的请求。

匹配到的请求会注入一组自定义 Header（可配）。比如匹配到测试用户的请求注入 X-Env: staging 和 X-Debug: true。

染色标签有 TTL，同一个客户端第一次匹配后缓存染色结果 N 秒。缓存期内不重新匹配，直接用缓存的标签。客户端用 IP + User-Agent 做缓存 key。

管理接口配置染色策略和查看实时命中统计。策略有优先级，编号小的优先匹配。

端口 PORT 环境变量。
