gRPC 和 REST 之间需要互相调用。用 Go 标准库 net/http 写协议转换代理。

REST → gRPC 方向：接收 JSON 请求，根据路径映射找到对应的 gRPC 方法，把 JSON 转成 protobuf 消息调用后端 gRPC 服务，再把 protobuf 响应转回 JSON。先用 JSON 手动映射模拟，不用真的依赖 gRPC 库。

gRPC → REST 方向：gRPC 服务调用 REST 接口，代理接收 gRPC 请求转成 HTTP 调用。

映射配置：REST 路径 + HTTP 方法 → gRPC service + method。请求和响应的字段映射规则。通过接口配置。

支持 streaming 模拟：gRPC server streaming 转成 HTTP chunked response。

端口 PORT 环境变量，go build 能过。
