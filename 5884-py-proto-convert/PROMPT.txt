需要把 CSV 格式的数据批量转成 JSON，还有反向转换。用 Java/Netty 写。

CSV → JSON：解析 CSV（自动检测分隔符和编码），第一行作为字段名，每行数据生成一个 JSON 对象，整体返回 JSON 数组。字段类型自动推断（数字、布尔值、字符串）。

JSON → CSV：接收 JSON 数组，所有对象的 key 并集作为 CSV 列。对象中缺少某个 key 的填空字符串。嵌套 JSON 对象拍平（parent.child 格式）。

批量转换接口：上传文件或传 body，返回转换结果。大文件（超过 10MB）流式处理，不全加载到内存。

转换选项：指定分隔符、编码、是否包含 header、日期格式。

端口 PORT 环境变量，Maven 构建。
