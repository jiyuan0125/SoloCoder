异步任务的链路断了——请求触发一个任务，任务又产生子任务，排查时完全串不起来。Go/Gin 写个异步链路追踪。

异步任务场景：请求触发一个任务，任务异步执行，执行过程中可能产生子任务。每个任务有自己的 span，parent 指向触发它的请求或父任务。

任务上报接口：上报任务创建、任务开始、任务完成/失败事件。每个事件带 trace_id、task_id、parent_task_id、时间戳。

按 trace_id 查询返回完整的任务树，包括每个任务的状态、耗时。支持查看失败的异步任务及其错误信息。

任务超时检测：任务超过 N 分钟未完成标记为超时。超时任务在查询结果中标注。

端口 PORT 环境变量，go build 能过。
