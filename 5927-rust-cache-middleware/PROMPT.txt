缓存命中率从 95% 掉到 60%，热点 key 过期后没有及时刷新。Rust/actix-web 写个带热点探测和自动预热的缓存。

基础操作：get/set/delete，set 时指定 TTL。支持 batch 操作。

热点检测：统计每个 key 的访问频率，超过阈值（可配）自动标记为热点。热点 key 的 TTL 到期后不立即删除，而是后台异步刷新（重新从数据源加载）。

缓存预热：服务启动时可以指定一批 key 和加载函数。后台并行加载这些 key 到缓存。

统计接口返回 key 数量、命中率、热点 key 列表、当前内存占用估算。

Cargo build 能过，端口 PORT 环境变量。
