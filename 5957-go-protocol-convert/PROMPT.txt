前端团队只愿意写 HTTP 接口，后端全是 gRPC 服务，两边都不肯让步。Go/Gin 写个 HTTP-gRPC 桥接。

转换配置：HTTP 路径 + 方法 → gRPC 服务名 + 方法名。请求 body（JSON）映射到 gRPC 请求的 protobuf 字段。映射规则通过配置文件定义。

gRPC 响应转 JSON 返回。嵌套的 protobuf 字段映射为嵌套 JSON。

支持流式 gRPC：HTTP 用 SSE 返回。客户端可以中断 SSE 连接，服务端取消 gRPC 流。

转换统计：每个规则的调用量、成功率、平均延迟。管理接口 CRUD 规则。

端口 PORT 环境变量，go build 能过。
