API Key 管理现在是写在配置文件里的，增删 Key 要重启服务。Rust/tokio 写个带 Key 管理和权限分级的认证网关。

API Key 管理：创建 Key 时指定名称、权限级别（只读/读写/管理员）、速率限制、过期时间。Key 创建后不可修改但可以吊销。

请求认证：从 header 取 X-API-Key，查库验证。过期或吊销的 Key 返回 401。权限不足返回 403。

权限规则：每个 API 路径定义最低权限级别。比如 /api/data 只需要只读，/api/admin/* 需要管理员。

统计接口：每个 Key 的调用量、错误率、最近调用时间。

Cargo build 能过，端口 PORT 环境变量。
