前端用 WebSocket 连接，后端遗留系统只认 TCP 原始套接字，协议对不上。Go 标准库 net/http 写一个双向协议转换网关。

客户端 WebSocket 连接的 URL 路径决定路由到哪个 TCP 后端——/ws/service-a 到 service-a 的 TCP 地址。路由规则通过管理接口动态配置。网关收到 WebSocket 帧后提取载荷通过 TCP 原样转发，TCP 返回数据封装成 WebSocket 帧发回，不做内容解析。

连接生命周期：WebSocket 断开时关闭对应 TCP 连接，TCP 断开时关闭 WebSocket。异常断开记录日志（持续时间、传输字节数）。GET /connections 返回活跃连接数和各后端统计。

Go 标准库 net/http。数据存内存。端口 PORT 环境变量，go build 能过。
