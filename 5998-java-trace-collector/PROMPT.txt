每条错误链路都要人工分析根因在哪，太耗时了。Spring Boot 写个带错误链路分析和根因推断的追踪服务。

Span 采集如前。新增：每个 Span 如果是 ERROR 状态，记录错误类型和错误消息。

错误链路查询：找出包含 ERROR Span 的 Trace。按错误类型统计（超时、连接失败、业务错误）。按服务统计错误分布。

根因分析：对单条错误 Trace，自动推断最可能的根因——最深层的 ERROR Span 且其下游 Span 都是因为它失败的。

告警：某个服务的 ERROR Span 数量在 1 分钟内超过阈值时触发告警。

Maven 构建，端口 server.port。
