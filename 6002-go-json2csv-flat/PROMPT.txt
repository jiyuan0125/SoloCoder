下游系统只认 CSV，但我们 API 返回的全是嵌套 JSON。产品问能不能把 address.city 这种深层字段拉平成一列导出，手工搞了几次发现列数对不上——嵌套层级深浅不一，很容易错位。

1. 命令格式 `json2csv -i data.json -o out.csv [-fields "name,age,address.city,address.zip"]`，不指定 -fields 时自动提取所有叶节点路径作为列，列名按字母排序。
2. 嵌套对象用点号路径展平，比如 {"a":{"b":1}} 变成列 a.b 值 1。数组按索引展开，items[0].name 变成列名 items.0.name。
3. 空值和缺失字段输出空字符串。值为 null 时 CSV 写空，字段不存在也写空。
4. 输入不是合法 JSON 时 stderr 输出 "invalid JSON" 并 exit 1。-o 指定路径不可写时 exit 2。
5. 输出 CSV 第一行是表头，UTF-8 编码，含逗号或换行的字段用双引号包裹，内部双引号转义为两个双引号。
6. 输入是 JSON 数组时逐条展平，输入是单个对象时展平为一行。

处理完每条记录后触发统计更新，统计也读原始记录，维护 in-memory 计数器记录 processed 和 skipped 行数，最终打印到 stderr。纯标准库实现，go run . 能跑。
