TOML 的日期时间类型和嵌套表映射到 JSON 时很容易搞错吗？上回用在线工具转了一次，日期变成了时间戳数字，下游解析直接炸了。自己写一个类型映射完全可控。

Go 命令行工具做 TOML 转 JSON。命令 `toml2json -i config.toml -o output.json`，不传 -i 读 stdin，不传 -o 写 stdout。TOML 的数组表 [[array]] 映射成 JSON 数组，嵌套表 [a.b] 映射成嵌套对象。日期时间类型转 ISO 8601 字符串，纯日期 "2024-01-15"、带时间 "2024-01-15T10:30:00+08:00"、不含时区 "2024-01-15T10:30:00" 三种格式都要区分。内联表转成普通对象，多行字符串保留换行符 \n。TOML 的整数和浮点数分别映射为 JSON 的 int 和 float64，无穷大和 NaN 输出为字符串 "Infinity"/"NaN"。

TOML 的布尔值 true/false 映射为 JSON 布尔。字符串值保持原样不加额外引号。TOML 的点号键（如 a.b = 1）等价于嵌套表 [a] b = 1，输出 {"a":{"b":1}}。输入文件不存在时 stderr 输出 "file not found: <path>" 并 exit 1。TOML 语法错误时 stderr 输出 "parse error: <details>" 并 exit 1。输出文件不可写 exit 2。纯标准库实现，go run . 能跑。数据有录入→清洗→校验→发布四个阶段，校验不过退回清洗。
