客服系统要对接一个用 TOML 做配置的第三方服务，我们的配置全是 JSON。TOML 对类型支持有限制，嵌套数组遇到混合类型就头疼。
Go CLI 做 JSON 转 TOML。JSON 数组映射到 TOML 数组表。混合类型数组保留原样。遇到 TOML 不支持的类型给个提示。
输入文件通过 -i 指定，输出用 -o 指定，不指定输出就打印到 stdout。格式错误不要 panic，给出行号和原因。
大文件（超过 100MB）流式处理，不能全读到内存里。每次读一行或一个数据块，转换后立刻写入输出。
日期字段要能识别常见格式，ISO8601、RFC3339、yyyy/MM/dd 等，转换后统一输出为 RFC3339。
转换结果写到文件后，再检查一遍输出能不能正常解析，不通过就报错。
如果输入有多段数据（多文档 YAML 或者多个根元素），每段独立转换，不要混在一起。
同步分为：准备→扫描→传输→验证→完成。验证失败重试传输。
代码组织上，主逻辑和辅助函数分开文件写，常量和类型定义单独放，入口 main.go 清爽一点。go build 编译通过。
