要对接的社保系统还跑在 SOAP/XML 上，我们这边全是 JSON 微服务。XML 的命名空间和 CDATA 处理起来比较烦，之前用 Python 库转了两次出了乱码事故。
Go 写一个 XML 转 JSON。命名空间前缀保留，CDATA 内容正常提取。自闭合标签转成空字符串或 null，统一处理。
数字字段自动识别——能转成整数就转整数，能转浮点就转浮点，转不了就当字符串。布尔值也自动识别，true/false/yes/no/1/0 都要支持。
输入文件通过 -i 指定，输出用 -o 指定，不指定输出就打印到 stdout。格式错误不要 panic，给出行号和原因。
大文件超过 100MB 流式处理，不能全读到内存里。每次读一行或一个数据块，转换后立刻写入输出。
输出的 JSON 默认格式化缩进（2 空格），加 -compact 参数就压缩成一行。CSV 输出默认逗号分隔，可以用 -sep 参数换成 tab 或其他。
有备份策略和备份记录，按策略自动执行备份。
字符串处理注意 Unicode——Go 的 string 是 UTF-8 编码的 byte slice，按 rune 遍历才安全。
代码分几个文件组织，别全写 main.go 里。错误信息要包含文件名、行号、原因。纯 Go 标准库，go build 产出单文件可执行程序。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
