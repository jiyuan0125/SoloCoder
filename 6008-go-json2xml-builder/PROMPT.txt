银行那边的接口只认 XML 报文，我们系统内部全用 JSON。转过去的 XML 还得过他们的 schema 校验，特殊字符转义搞错一次就被打回来。上个月因为一个 & 符号没转义，整批交易被拒了。
Go CLI 做 JSON 转 XML。根节点名称可以通过参数指定，默认 root。数组元素用相同的标签名包裹。特殊字符要正确转义（&, <, > 等）。
日期字段要能识别常见格式，ISO8601、RFC3339、yyyy/MM/dd 等，转换后统一输出为 RFC3339。
输出的 JSON 默认格式化缩进两个空格，加 -compact 参数就压缩成一行。CSV 输出默认逗号分隔，可以用 -sep 参数换成 tab 或其他。
转换结果写到文件后，再检查一遍输出能不能正常解析，相当于写完做个自检。
如果输入有多段数据（多文档 YAML 或者多个根元素），每段独立转换。
编码处理要考虑 UTF-8 和 GBK 两种，输入是 GBK 的时候自动检测并转换，也可以用 -enc 参数强制指定。
合并完成后自动删除源文件，保留模式不删除。
纯 Go 标准库，go build 编译。10MB 以下全量读取没问题，超过的话用 bufio.Scanner 逐行处理。
字符串处理注意 Unicode——Go 的 string 是 UTF-8 编码的 byte slice，按 rune 遍历才安全。
