月度报表的数据源是 YAML 格式的监控采集结果，财务要 CSV 才能进他们的系统。线上那套 shell 脚本跑一版报表要二十分钟，还老出错——上周因为 YAML 里的布尔值没被识别，整列数据全偏了一位。
Go 实现 YAML 转 CSV。只有数组类型的 YAML 才能转，对象的值如果是数组也支持展平。
数字字段自动识别——能转成整数就转整数，能转浮点就转浮点，转不了就当字符串。布尔值也自动识别，true/false/yes/no/1/0 都要支持。
指定输出编码，默认 UTF-8。编码处理要考虑 UTF-8 和 GBK，输入是 GBK 的时候自动检测并转换，可以用 -enc 参数强制指定。
大文件超过 100MB 流式处理，不能全读到内存里。每次读一行或一个数据块，转换后立刻写入输出。
输出的 JSON 默认格式化缩进（2 空格），加 -compact 参数就压缩成一行。CSV 输出默认逗号分隔，可以用 -sep 参数换成 tab 或其他。
支持多种操作模式：convert csv json、convert yaml toml、validate json、diff json。
如果输入文件有多段数据（多文档 YAML 或者多个根元素），每段独立转换。
错误信息要包含文件名、行号、原因。go build 编译，不引第三方包，能跑就行。
代码按模块拆分，不要把所有逻辑写在一个文件里。解析、转换、输出分开组织。
