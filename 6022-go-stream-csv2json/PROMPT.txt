日志导出的 CSV 文件动辄几个 GB，全量加载内存直接 OOM。想做一个流式处理——每处理一行输出一条 JSON 对象，最终用数组包裹。支持从管道读输入。

命令 `streamcsv2json [-i data.csv] [-o output.json] [--batch-size 1000] [--pretty]`，不传 -i 从 stdin 读取（支持管道 `cat huge.csv | streamcsv2json`），不传 -o 写 stdout。流式逐行读取用 bufio.Scanner，内存中同时只保持当前行和输出缓冲区，峰值内存不超过 10MB。--batch-size 控制每 N 行刷新一次输出缓冲区（调用 os.File.Write 或 bufio.Writer.Flush），默认 1000。

输出格式：起始 `[` 换行，每行一条 JSON 对象后跟逗号，最后一行无逗号，结尾 `]` 换行。加 --pretty 时每条对象 json.MarshalIndent 缩进 2 空格。空行跳过不计入行数。行内字段数与表头不匹配时 stderr 输出 "line N: column count mismatch (expected M, got K)"，K > M 时截断多余字段，K < M 时缺失字段填 null，该行跳过但计入 skipped 计数。表头有重复列名时后者覆盖前者并 stderr 警告。

stdin EOF 后正常结束 exit 0，stderr 打印 "processed: N rows, skipped: M rows"。-i 指定文件不存在时 stderr 输出 "file not found: <path>" 并 exit 1。go build 能编译通过，不依赖第三方库，主逻辑和辅助函数分文件写。
