难道没有好用的 YAML 路径查询工具吗？DBA 团队每周要在几十个 YAML 配置文件里找某个键在哪个文件的哪个位置，手动翻太痛苦了。Go 标准库写一个吧。

支持三种路径语法：`/key` 精确匹配顶层键、`/array[0]` 按索引取数组元素、`/key/subkey` 多级嵌套。用法：`yq --path /database/connections[0]/host --dir ./configs/`，扫描目录下所有 `.yaml` 和 `.yml` 文件。匹配结果输出 JSON 数组到 stdout：`[{"file": "db.yaml", "path": "/database/connections[0]/host", "value": "10.0.0.1", "line": 42}]`。多个文件匹配同一路径全部返回。无匹配输出空数组 `[]`，退出码 0。

加 `--sensitive` 标志时，值包含 `password`、`secret`、`token`、`key`（不区分大小写）的匹配项在输出中加 `"warning": "potential sensitive value"` 字段，且 `value` 替换为 `"***REDACTED***"`。

文件为空或不是合法 YAML 跳过，stderr 输出 `skipped: <filename> (<原因>)`。`--output-file` 参数指定输出路径，省略则 stdout。`--depth` 限制匹配嵌套层数（默认无限制）。目录不存在退出码 2。

子命令：`scan --dir <path>` 仅扫描统计不输出详细结果，stdout 返回 `matched: N files, M paths`。不用第三方包，`go build` 通过就行。
