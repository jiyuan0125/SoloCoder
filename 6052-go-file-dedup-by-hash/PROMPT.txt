文件服务器磁盘快满了——排查发现重复文件占了不少空间，同名不同内容、不同名同内容都有。Go 写一个基于哈希的文件去重工具。

去重分两步：先按文件大小分组，同大小的文件再算哈希比对（避免全量计算哈希）。命令：`dedup --dir /data --algorithm sha256 --output dupes.txt --confirm-delete`。`--algorithm` 支持 `md5` 和 `sha256`（默认）。结果输出到文件，每行一组：`<hash> <size> <path1>|<path2>|<path3>`，同组重复用 `|` 分隔路径。`--json` 参数改为 JSON 输出：`{"groups": [{"hash": "abc...", "size": 1024, "files": ["path1", "path2"]}]}`。

加 `--confirm-delete` 时交互式列出每组重复文件，用户输入 `y` 确认删除，每组保留第一个文件。不加只输出列表不删除。空文件（0 字节）单独归为一组，hash 标记 `EMPTY`。`--min-size` 跳过小于指定字节的文件（默认 0 不跳过）。`--max-size` 跳过大于指定字节的文件。

符号链接跟随目标文件计算哈希，循环链接检测到后 stderr 输出 `symlink cycle: <path>` 并跳过。无法读取的文件 stderr 输出 `read error: <path> (<原因>)`，标记为 error 但不中断。结果中各组按重复文件数降序排列，组内路径按字母序。

扫描状态机：初始化→扫描中→分析中→报告生成。`go build` 能编译通过，不依赖第三方库。目录不存在退出码 2，无重复文件退出码 0。
