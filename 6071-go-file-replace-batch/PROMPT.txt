批量替换配置文件里的旧域名，涉及几百个文件不能一个个改，改漏一个就出故障。Go 做批量文本替换，支持纯文本和正则两种模式。

用法：`replacebatch --dir <目录> --old <旧文本> --new <新文本> [--regex] [--include "*.yaml,*.json"] [--exclude "*.bak"] [--dry-run] [--backup]`。

`--regex` 开启正则模式，`--old` 当正则编译，捕获组可在 `--new` 中用 `$1` `$2` 引用。正则编译失败 stderr 输出 `ERROR: invalid regex: <信息>` 退出码 2。

`--dry-run` 只显示 diff 不实际修改，diff 格式 `--- <文件>\n+++ <文件>\n- 旧内容\n+ 新内容`。非 dry-run 模式 `--backup` 会把原文件复制到 `.replace-bak/` 目录下。

`--include` 和 `--exclude` 支持 glob 模式，逗号分隔。不指定 include 则匹配所有文件。跳过二进制文件（检测前 512 字节含 NULL）。

构建流程：解析参数 → 编译正则 → 遍历文件 → 替换。替换结果写入后执行测试命令 `--test "go test ./..."` ，测试失败不继续，stderr 输出 `ERROR: test failed, rollback` 退出码 4。

纯标准库实现，go run . 能跑。
不要写单文件，核心逻辑、CLI 入口、辅助工具各放一个文件。
