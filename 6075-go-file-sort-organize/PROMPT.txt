下载目录里堆了几千个文件，按时间排序找不到大的，按大小排序又看不到最新的，每次找个文件跟考古一样。Go 做文件排序整理工具，用法 `filesort <dir> --by time|size|name --order asc|desc --prefix --dry-run --output report.json`。按修改时间排序时精确到秒，按大小排序用字节数比较，按名排序区分大小写。加 `--prefix` 给文件名加序号前缀，格式 001_filename.ext，位数按文件总数自动补零（100 个文件用 3 位，1000 个用 4 位）。`--dry-run` 只输出计划不实际移动，stdout 每行 "原路径 -> 新路径"。`--output` 写 JSON 报告，包含 total_files、sorted_by、renamed_count、skipped_count、duration_ms。目标文件已存在时 stderr 输出 "error: file already exists: <path>" 跳过不覆盖，继续处理其余文件。空目录处理后 stdout 输出 "info: empty directory, nothing to sort" 退出码 0。排序中遇到无法读取的文件 stderr 输出 "warning: cannot read file info: <path>" 跳过。校验完成后自动生成排序报告，报告内容包含总文件数、排序耗时、跳过数量，报告也要查询校验数据生成。不用第三方包，go build 通过就行。
不要写成一个 main.go 搞定所有事情。按职责拆文件：入口、解析、处理、输出分开。
