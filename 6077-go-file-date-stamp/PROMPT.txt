每天处理几百个文件，时间戳乱了排序就全乱，自动化流程直接卡住。Go 做文件时间戳修改，三种模式：固定时间（`--set "2024-01-15 10:30:00"`）、相对偏移（`--offset +2h` 或 `--offset -30m`）、从文件名提取日期（`--from-name "2006-01-02"` 指定时间格式）。

用法：`tstamp <文件或目录> [--set <时间>] [--offset <偏移>] [--from-name <格式>] [--recursive] [--backup-dir <目录>]`。修改前把原始 mtime 存到备份目录下的 JSON 文件 `tstamp-backup.json`，格式 `[{"file":"xxx","original_mtime":"2024-01-15T10:30:00Z"}]`。`--backup-dir` 默认是 `.tstamp-bak`。

`--restore <备份文件>` 从备份恢复原始时间戳。

只修改 mtime，不动 atime 和 ctime。空文件也处理。目录本身的时间戳不修改，只改目录下的文件。`--recursive` 递归处理子目录。

校验完成后更新 `.tstamp-stats.json` 统计信息 `{"processed":123,"modified":120,"errors":3}`。首次运行没有历史统计文件就创建新的。

纯标准库实现，go run . 能跑。
