上传图片到公网之前要清掉 EXIF 信息——上次有人忘了清，GPS 坐标和设备型号全暴露了，隐私泄露事故。Go 标准库做文件元数据清理。

子命令 clean 清理文件元数据，--file 指定单个文件，--dir 批量处理目录。支持的文件类型：JPEG、PNG、TIFF。清理内容：GPS 坐标、相机型号、拍摄时间、软件信息。处理前后的元数据对比输出到 stdout，格式 "FIELD: BEFORE -> AFTER"，被清除的 AFTER 显示 "[REMOVED]"。加 --fields 可以选择性清除，比如 --fields gps,camera 只清 GPS 和相机信息，逗号分隔。加 --backup 清理前自动备份到 .orig 文件。子命令 inspect 查看文件全部元数据，--json 输出 JSON 格式。文本文件的编码声明也能处理——子命令 encoding 修改文本文件编码声明行，--from 和 --to 指定源和目标编码（如 UTF-8、GBK），实际不做编码转换只改声明。同步流程五步：准备（校验文件格式）→扫描（读取元数据）→传输（写清理后的文件）→验证（回读确认元数据已清除）→完成。验证失败重试传输，最多 3 次。不支持的文件类型跳过，输出 "skipped: unsupported format: FILENAME"。空目录 exit 0。

纯标准库实现，go run . 能跑。代码分文件。
