你跟我说两台服务器文件一样，那到底一不一样？rsync --dry-run 的输出看得人眼花。上次迁移完发现目标比源少了 47 个文件，排查了两天。我需要一个目录对比工具——清晰地列出两边差异，再决定同步方向。Go 写，纯标准库。

对比逻辑：遍历 A 和 B 两个目录，按相对路径对比。对每个文件先用 size 快速判断，大小一致时再计算 SHA-256 做内容比对（size 不同直接标记 DIFF，不浪费时间算哈希）。输出三列状态：A_ONLY（只在 A 存在）、B_ONLY（只在 B 存在）、DIFF（两边都有但内容不同），每行格式 `<状态> <相对路径> <A大小> <A时间> <B大小> <B时间>`，大小和时间的对齐用 tab 分隔。

同步功能可选方向：--sync a-to-b 把 A 的内容同步到 B（B 多余的删、缺少的补、不同的覆盖），--sync b-to-a 反过来。同步前必须 --dry-run 先预览，不加 --dry-run 直接同步时每个操作输出一行 `COPY <src> → <dst>` 或 `DELETE <路径>`。

符号链接跟随一次后按常规文件比较。权限不可读的文件标记 `PERMISSION_ERROR: <路径>` 并跳过。--output report.json 导出对比结果为 JSON 数组，每条记录含 path、status（A_ONLY/B_ONLY/DIFF/SAME）、size_a、size_b、mtime_a、mtime_b。A 或 B 目录不存在退出码 1。退出码 0 全部一致或同步成功，8 存在差异或部分失败。不用第三方包，go build 通过就行。
