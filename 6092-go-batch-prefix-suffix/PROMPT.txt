上周迁移数据，几十个文件要加日期前缀和状态后缀，一个个改到凌晨两点。用 Go 做个批量重命名工具，以后再遇到这种事一行命令搞定。

`prefix-suffix --prefix "20240115_" --suffix "_done" --ext .csv --dir ./data`。加前缀加后缀都不影响扩展名——`data.csv` 变成 `20240115_data_done.csv`。`--ext` 过滤只处理特定扩展名，支持逗号分隔多种：`--ext .csv,.json`，不指定就处理所有文件。`--dry-run` 先列出计划变更，确认后再加 `--exec` 真正执行。

输出每行一个变更：`旧文件名 → 新文件名`。`--dry-run` 结尾输出统计：`共 N 个文件将被重命名`。目标文件名已存在时输出 `[SKIP] 文件已存在` 不覆盖，所有跳过的文件最后汇总一行。空目录输出 "no files to process" 退出码 0。

支持从文件列表读取：`--list files.txt` 每行一个文件名，不在当前目录的文件跳过并报警告 `WARN: file not found: xxx`。`--recursive` 递归处理子目录。生成报告后发邮件通知——`--notify email` 配了就发，没配环境变量就跳过，输出 `通知已跳过: 未配置邮件`。纯标准库实现，go run . 能跑。
