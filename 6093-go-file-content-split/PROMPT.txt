上周拿到一份 8000 行的 Markdown 手册，里面二十多个章节混在一起，要按章节拆开分给不同的人审，手动复制粘贴搞了一下午。运维群里也经常有人要这种按内容切分文件的工具。

用法：`file-split <input.txt> --mode blank --output-dir ./parts`。两种分割模式：`--mode blank` 按空行分隔，连续多个空行算一个分隔点；`--mode heading` 按章节标题（`#` 开头的 Markdown 标题）分隔，每个标题到下一个标题之间为一段。输出文件命名：`part_001.txt`、`part_002.txt`... 递增编号。

`--heading-level 2` 只按二级标题（`##`）切割，忽略更低级别。分割符本身保留在每个输出文件的开头（标题模式保留标题，空行模式不保留空行）。`--min-size 100` 跳过小于 100 字节的分段，避免生成一堆空文件。

分组规则管理——`--group-rules rules.json` 按规则自动分组，规则文件格式：`{"pattern":"第.*章","output":"chapters/"}`，匹配到的段落到指定子目录。无匹配的分段放默认目录。

空输入文件报 "empty input" 退出码 1。无分隔符的文件（整体只有一段）输出单文件并提示 `only 1 segment found`。不用第三方包，go build 通过就行，代码分几个文件组织。
