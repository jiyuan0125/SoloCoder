生成的那批数据里重复行太多了——10 万行将近 30% 是重复的，分析结果全是错的。Go 写个去重工具，支持灵活策略，大文件也不能 OOM。

命令：`dedup <输入文件> --output <输出文件> --strategy first|last --key full|field:N --report report.json`。--strategy first 保留每组第一条，last 保留最后一条，默认 first。--key full 整行作 key（trim 空格后比较），--field N 按第 N 列（逗号分隔，从 1 开始），支持多列 --field 1,3 拼接。输入输出都是 CSV，首行为表头不参与去重。

去重逻辑——按 key 分组，同 key 按 strategy 保留一条。文件 > 500MB（os.Stat 预判）自动切外部排序：按 key 分片写入 os.TempDir() 临时文件，归并去重后清理临时文件。

report.json 含 total_lines、unique_lines、duplicate_lines、duplicate_rate（如 "28.5%"）、top_duplicates（top 10，每条含 key 和 count）。stdout 输出 `dedup result: N total, M unique, K duplicates removed (R%)`。--skip-empty 控制空行是否参与去重（默认跳过）。--incremental 读上次 report 累加统计。输入不存在退出码 1，输出不可写退出码 1，正常退出码 0。go build 编译通过，不依赖第三方库。
