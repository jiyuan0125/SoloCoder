配置文件改来改去经常搞错环境，出过两次生产事故了。用正则从文本里批量提取字段，命名捕获组直接当字段名，不用手动指定列名映射。

用法：`extract --pattern <正则> --input <文件> [--output <输出文件>] [--format csv|json] [--delim <分隔符>]`。正则里有 `(?P<name>...)` 命名组时，name 就是列名。没命名组时列名是 group_0、group_1...。

输入从 stdin 或 `--input` 指定文件读取，支持逐行匹配。CSV 格式输出首行是列名，后续每行一个匹配结果。JSON 格式输出数组 `[{"field1":"val1","field2":"val2"},...]`。`--delim` 指定 CSV 分隔符，默认逗号。

没匹配到任何内容时 stderr 输出 `WARN: no matches found`，退出码 0 但输出文件为空。正则编译失败 stderr 输出 `ERROR: invalid regex: <错误信息>` 退出码 2。输入文件不存在退出码 2 stderr `ERROR: file not found: <路径>`。

`--max-match N` 限制最大匹配数，超过 N 停止处理。

删除记录后清理关联索引——索引文件 `.extract-index.json` 存行号到文件偏移的映射，删除时遍历剩余记录重建索引，保证索引和实际数据一致。

go build 能编译通过，不依赖第三方库。
项目结构要分模块：主入口、核心处理逻辑、工具函数分文件组织，方便测试和维护。
