运营给了一份用户数据 Excel，数字列的格式五花八门——千分位 12,345、中文「一万二千三百」、百分号 45%、带单位 3.5K。直接导入数据库全变成字符串，下游分析全废了。

用法：numparse --input data.csv --column amount --output parsed.csv。工具逐行读取指定列，尝试多种模式解析：先试千分位（逗号分隔的三位数字），再试中文数字（零一二三四五六七八九十百千万亿），再试百分号（去掉%除以100），再试 K/M/B 后缀（乘以相应倍数）。

解析成功的在输出 CSV 里新增 parsed_<column> 列写数值（float64 字符串），解析失败的保留原文、parsed 列写空字符串。加上 --summary 标志在 stderr 打印：总行数、成功解析数、失败数、失败样例前 5 条。

支持批量：--column 可以逗号分隔指定多列。--format json 改输出为 JSON 数组。输入文件不存在的 exit code 1，列名不存在的 exit code 1 并打印 ERROR: column 'xxx' not found。

中文数字解析要处理组合：一千二百三十四 = 1234。亿级别也要支持。输入支持从 stdin 读取（--input -），输出也支持 stdout。go build 能编译通过，不依赖第三方库。主逻辑和各解析模式分文件写。
