数据同步那回配置推错了环境，排查时发现搜不了配置文件内容，只好一个一个 vim 打开看，浪费了一整个下午。Go 做高级文本搜索，速度要快功能要全，以后排查问题不用再手翻文件。

`agrep --pattern "error" --path ./config/ --mode regex`。mode 支持 regex、fixed（固定字符串不做正则转义）、multi（多模式任一匹配逗号分隔）。默认输出每行 `file.txt:15: error connecting to db`。`--group` 按文件分组文件名只显示一次。`--context 3` 显示上下各 3 行，多组匹配间用 `--` 分隔。

过滤：`--include "*.go"` 只搜特定后缀，`--exclude-dir ".git,node_modules,vendor"` 排除目录，`--case-insensitive` 或 `-i` 忽略大小写。`--max-count 10` 每文件最多 10 条匹配。`--count-only` 只输出每文件匹配数 `file.txt: 5`。

搜索完成 stderr 输出 "searched: N files, matched: M files, time: Xs"。`--workers 4` 控制并发数默认 CPU 核数。退出码 0 有匹配，1 无匹配，2 参数错误。纯标准库，go build 能编译通过。
