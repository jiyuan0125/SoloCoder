先定义提取模板告诉工具去哪找数据，再批量跑模板提取所有文件，最后汇总输出——三步搞定。

模板文件格式（JSON）：`{ "name": "report", "fields": [{ "name": "patient_id", "pattern": "编号[：:]\s*(\w+)" }, { "name": "date", "pattern": "日期[：:]\s*(\d{4}-\d{2}-\d{2})" }] }`。每个 field 有 name 和 pattern（Go 正则），编译失败输出 `error: invalid pattern for field <name>: <错误>` 退出码 1。

命令行：`extract -template tmpl.json -input-dir ./reports -output result.csv -format csv`。目录下 .txt 和 .md 逐个处理，字段没匹配填 `N/A`，多次匹配取第一次。

输出：JSON 是数组 `[{ "file": "r1.txt", "patient_id": "P001", "date": "2024-01-15" }]`，CSV 首行列头 file + 字段名。空目录输出 `warning: no input files found in <dir>` 退出码 0。

Go 标准库，go build 能编译通过，不依赖第三方库。主逻辑和辅助函数分文件写。
