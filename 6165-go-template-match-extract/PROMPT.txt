上周客服传来一批用户反馈，格式都是「姓名：张三，年龄：28，城市：北京」这种固定模板，手动抄字段抄到眼花。Go CLI 工具，给模板和文本就能批量抽出字段——这种重复劳动不该让人做。

模板里 `{{字段名}}` 当占位符，如「姓名：{{name}}，年龄：{{age}}」匹配后输出 `{"name":"张三","age":"28"}`。占位符名只允许字母数字下划线，`{{}}` 空占位符报错 "empty placeholder in template" 退出码 2。模板语法错误 stderr 输出具体位置和原因。

`tmplx extract --template '姓名：{{name}}，年龄：{{age}}' --file data.txt --output result.json`。多条模板：`--template-file templates.txt` 每行一个模板自动尝试直到命中，命中后停止。输出格式：`--format json`（默认 JSON 数组）、`--format csv`（列名即占位符名，含表头行）、`--format table`（终端对齐表格，用 | 和 - 绘制边框）。

匹配失败的行 stderr 输出 "line 12: no match"。全部失败退出码 1，至少一条成功退出码 0。空文件输入 stderr 输出 "empty input file" 退出码 1。`--strict` 模式下任何一行匹配失败就退出码 1。不用第三方包，go build 通过就行。
