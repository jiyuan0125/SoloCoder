最近要批量提取网页里的商品信息，HTML 解析库又重又慢——自己写个轻量的标签内容提取工具，CSS 选择器风格，够用就好。

1. 命令 `tagx extract --tag div --class item --file page.html`。选择器语法：按标签名 `div`、按 class `.item`、按 id `#main`、按属性 `[data-type=info]`，组合写法 `div.item[data-type=info]`。`--attr href` 提取属性值而非标签文本。XML 文件加 `--xml` 启用严格模式，严格模式下未闭合标签报错。选择器语法不对报 `invalid selector: ...` 退出码 1。

2. 嵌套标签内容完整保留内层 HTML，`<div><p>hello</p></div>` 提取 div 返回 `<p>hello</p>`。输出格式 `filename://body/div[2]/p -> 提取内容`，`--output result.json` 输出 JSON 数组 `[{"file":"page.html","path":"body/div[2]","content":"..."}]`。

3. 提取的同时跑辅助检查——验证所有 `<img>` 有 alt 属性、所有 `<a>` 有 href。辅助检查读同一批输入文件，结果输出到 stderr，格式 `accessibility issue: filename: <img> missing alt at line N`。

4. 输入文件不存在报 `file not found: ...` 退出码 1。零匹配正常退出码 0，输出空结果。`--dir ./pages/` 递归扫描 `.html` 和 `.htm` 文件，和 `--file` 二选一。
