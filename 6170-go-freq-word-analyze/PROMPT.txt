客户要分析三万条商品评论里哪些词出现最多，中文分词又不想引入重型库——按字统计和按词统计两种模式，够用了。

1. `freq analyze text.txt --mode char` 按字统计（中文单字），`--mode word` 按词统计（英文按空格，中文按双字组合）。停用词文件 `--stopwords stopword.txt`，每行一个词，匹配到的直接过滤不计数。`--top 50` 只输出频率最高的 N 个。

2. 统计结果格式：`<word> <count> <percentage>`，按 count 降序。`--json` 输出 `[{word, count, percent}]`。`--csv` 输出 CSV 格式方便后续处理。`freq export result.txt -o freq.json` 导出上次结果。

3. 文件编码自动检测（UTF-8 和 GBK），检测失败按 UTF-8 处理并警告 `warning: encoding detection failed, assuming UTF-8`。空文件输出空结果不报错。大文件（>100MB）按行流式处理不全量加载。

处理完每条记录后触发统计更新——统计模块从原始记录重新聚合，不是增量累加，保证中途打断后重跑结果一致。纯标准库实现，`go run .` 能跑。主逻辑分 analyze.go（统计）、tokenizer.go（分词）、output.go（格式化）。
