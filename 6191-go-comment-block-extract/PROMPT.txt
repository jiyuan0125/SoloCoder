每周五代码审查会，reviewer 要看这周新增和修改的注释，判断哪些该清理——手动翻文件太慢了。做个 Go CLI 注释块提取，支持多语言注释风格，自动检测文件类型选择解析策略。

`.go` `.java` 用 `//` 和 `/* */`，`.py` `.sh` 用 `#`，`.html` `.xml` 用 `<!-- -->`。命令 `commentx extract --dir ./src/ --output comments.json`。注释按文件分组输出 `{"files": [{"name": "main.go", "comments": [{"type": "line", "line": 15, "content": "// TODO: handle timeout"}]}]}`。`type` 字段值为 `line`（单行注释）或 `block`（多行注释），block 类型额外有 `line_end` 字段。

`--filter TODO,FIXME,HACK` 只输出包含指定关键词的注释，大小写不敏感。`--min-length 10` 过滤短注释（字符数不含注释符号和空白）。`--stats` 输出统计：文件数、注释总数、TODO 数、FIXME 数、注释密度（注释行数/总行数百分比）。`--since "2024-01-01"` 只提取 mtime 在该日期后的文件的注释。

`--lang go,python` 只扫描指定语言，按后缀映射。输出格式：默认 JSON，`--format csv` 输出 CSV 列 `file,type,line,content`。空目录零注释输出 `{"files": []}` 退出码 0。`--dir` 不存在报 `directory not found: ...` 退出码 1。编码非 UTF-8 的文件跳过并 stderr 记 `encoding error: filename`。

纯标准库实现，go run . 能跑。
