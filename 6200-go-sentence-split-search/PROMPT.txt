NLP 项目要拿句子做情感分析，结果发现分句这一步就卡住了——英文按句号切还算靠谱，中文的。？！…混着用，还有 Mr. 这种缩写陷阱。先把分句做好再做句子级别搜索，两步搞定。

分句：`split --input article.txt` 加载文本，按以下规则切句子：英文按 .!? 后跟空格或行尾；中文按 。，！？；…后面跟非引号字符也切；换行符也作为分隔。缩写（如 Mr. U.S.A. i.e.）不误切。输出 sentences.json：{"count": 42, "sentences": [{"index": 0, "text": "...", "start": 0, "end": 25}]}。

搜索：`split search --input article.txt --query "关键词"` 在分好的句子里搜索，返回包含关键词的完整句子。支持多关键词 AND/OR：--query "Go AND 并发" 或 --query "性能 OR 优化"。输出 search_result.json：{"query": "关键词", "matches": [{"sentence_index": 5, "text": "...", "highlight": "..."}]}，highlight 里关键词位置用 **标记。

空文件输出空数组。搜索无结果输出空 matches，exit code 0。删除记录后要清理关联索引——索引存在内存 map 里，删除句子时遍历剩余记录更新倒排索引。纯标准库实现，go run . 能跑。
