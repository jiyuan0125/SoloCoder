拿到两个固件二进制，想知道到底哪里不一样——用 hex editor 手动对位偏移效率约等于零。Go 实现一个二进制文件对比，差异段用十六进制显示并标注偏移量，跑完就知道改了什么。

1. 命令 `bindiff compare --file-a firmware_v1.bin --file-b firmware_v2.bin --output diff_report.txt`。逐字节对比，找到差异段输出：偏移范围、A 的十六进制、B 的十六进制，每段最多 16 字节差异。`--context 8` 差异段前后各扩展 N 字节上下文，默认 4 字节。

2. 汇总统计输出到 stdout：`{"total_bytes": 1048576, "diff_bytes": 234, "diff_percent": "0.02%", "diff_regions": 5}`。`--threshold 1` 合并相邻小于 N 字节的差异段。`--format json` 完整 JSON 报告含每个差异段详情，`--format hex` 纯十六进制 dump 风格。`--limit 100` 最多输出前 N 个差异段，超出记 `... N more regions truncated`。

3. 文件大小不一致时超出部分标 `appended data`，长度差计入统计。两个文件完全相同输出 `files are identical` 退出码 0。空文件报 `empty file: filename` 退出码 1。`--file-a` 或 `--file-b` 不存在报 `file not found: ...` 退出码 1。输入是文本文件（非二进制）仍正常处理，不报错。

4. 跑完对比自动生成摘要报告到 stderr，含差异字节数、百分比、区域数。大文件（超过 100MB）用缓冲区流式读取不全部加载。

纯标准库，go run . 能跑。
