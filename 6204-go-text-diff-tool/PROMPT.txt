为什么每次对比配置文件都要翻 diff 手册？参数记不住，输出格式也不够直观。Go CLI 文本差异工具，输出跟 unified diff 差不多，但要加两个实用开关过滤噪音。

到底哪变了？命令 `txdiff diff --file-a config_v1.yaml --file-b config_v2.yaml --output patch.diff`。默认输出 unified diff 格式 `--- a/config_v1.yaml` `+++ b/config_v2.yaml` `@@ -3,5 +3,6 @@` 行级对比。`--ignore-whitespace` 忽略空行和缩进变化，`--ignore-case` 忽略大小写——两个开关过滤噪音只看实质变化。`--context 3` 控制上下文行数默认 3。

`--stat` 只输出统计 `{"added": 5, "removed": 3, "modified": 2, "unchanged": 120}`。`--side-by-side` 并排对比输出，终端宽度自动适配超长行截断加 `...`。`--word-diff` 单词级差异标注（用 `[add]{removed}` 格式标记变化的部分）。

完全相同的文件输出 `files are identical` 退出码 0。二进制文件报 `binary file detected, use bindiff instead` 退出码 1。编码不一致尝试 UTF-8 和 GBK 两种解码，都失败报 `encoding error: filename` 退出码 2。`--file-a` 或 `--file-b` 不存在报 `file not found: ...` 退出码 1。`--output` 指定的目录不存在自动创建。

不用第三方包，go build 通过。
