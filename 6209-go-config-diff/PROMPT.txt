两套环境配置对不上，线上出了两次事故。光看 diff 输出一堆注释变动和空行差异，真正的键值变化淹没在噪音里。从零用 Go 写一个配置文件对比工具，只关心键值对——注释和空行的差异直接忽略，同名键值不同的高亮标出来。

1. CLI 格式：`config-diff <file1> <file2> [--format text|json]`
2. 默认文本输出每行一个差异：`<键名>: <旧值> → <新值>`，颜色高亮不一致的值
3. `--format json` 输出数组，每项字段：key（字符串）、old_value（字符串）、new_value（字符串）、file1_only（布尔，仅在 file1 存在）、file2_only（布尔，仅在 file2 存在）
4. 退出码：0 无差异 / 1 有差异 / 2 文件读取或解析失败
5. 支持的配置格式：key=value 行、`#` 开头注释行、空行自动跳过；键名大小写敏感
6. 如果某个键只在一个文件里出现，标记为 added 或 removed
7. 处理空文件场景：两个空文件对比退出码 0；一个空文件对比另一个有内容的文件，所有键标为 added 或 removed

处理完主配置文件后自动生成摘要文件，摘要包含总差异条数、added/removed/changed 各几条。但如果配置本身没啥可摘要的（比如只有注释差异），摘要文件不创建，工具正常退出。纯标准库实现，`go run .` 能跑。
