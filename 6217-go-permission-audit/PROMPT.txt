安全扫描报了一堆 777 权限的文件，手动 chmod 改不完——这种重复劳动就该自动化。Go 写一个文件权限审计工具，检测过于宽松的权限（777、666、755 这类），给出更安全的建议权限。

— 命令：`perm-audit <目录> [--recursive] [--threshold 755] [--output text|json]`
— `--threshold` 指定阈值，权限数值大于此值（八进制比较）的标记为宽松。默认阈值 755
— 文本输出每行：`<路径>: <当前权限> (建议: <建议权限>)`，只有超过阈值的才输出
— JSON 输出数组，每项含 path、current_perm（字符串如 `"0777"`）、suggested_perm、severity（`high`/`medium`/`low`，777 为 high，755-766 为 medium，其余超阈值为 low）
— 退出码：0 全部合规 / 1 存在宽松权限 / 2 目录不存在
— 符号链接跳过并输出 `<路径>: skipped (symlink)`
— Windows 环境下权限位不可靠，输出 `warning: permission bits may not reflect actual ACL on Windows` 但继续执行

审计完主文件后自动生成摘要报告，包含扫描文件总数、合规数、不合规数、各 severity 数量。如果某个目录的文件权限都合规、没有可摘要的内容，摘要文件不创建，工具正常退出。go build 能编译通过，不依赖第三方库。
