配置文件改了十几个版本，不知道哪次改坏的——这种事在运维日常中太常见了。Go 做文件版本对比，按版本号排序，相邻版本之间的差异一目了然，还能直接回滚到任意版本。

能做得多好？CLI 命令组设计为多级结构：`file version list <目录>` 列出所有版本（版本号、时间戳、文件大小），按版本号升序排列；`file version diff <目录> --from V1 --to V2` 比较两个版本的差异，输出统一 diff 格式（`<` 开头为旧版本行，`>` 开头为新版本行，中间用 `---` 分隔）；`file version rollback <目录> --to V3` 回滚到指定版本，回滚前自动创建当前版本的快照。`--output json` 时 diff 输出结构化数组，每项含 line、type（`added`/`removed`/`changed`）、content。退出码：0 无差异或操作成功 / 1 有差异 / 2 版本不存在 / 3 目录不存在。版本存储在 `.versions/` 子目录中，每个版本一个文件。版本号格式为 `v001`、`v002` 递增，自动生成。不指定 `--from` 时默认与前一个版本比较，不指定 `--to` 时默认到最新版本。

命令组还包括 `file convert`、`file check`、`file merge`，每组下面有具体操作。go build 能编译通过，不依赖第三方库。
不要写成一个 main.go 搞定所有事情。按职责拆文件：入口、解析、处理、输出分开。
