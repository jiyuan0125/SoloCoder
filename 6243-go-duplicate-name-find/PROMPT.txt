先扫描同名文件，再比较内容是否一致——两步走。项目里同名文件散落在不同目录，引用的时候不知道用的是哪个版本，出了 bug 排查半天才发现引用了错的那个。Go 写同名文件查找工具，找到后比较内容，结果按文件名分组。

1. 命令：`dupname scan <目录> [--recursive] [--compare-content] [--output text|json]`
2. 不加 `--compare-content` 时只按文件名分组列出路径；加上后对同名文件两两比较内容（逐字节或哈希），标记是否内容一致
3. 文本输出按文件名分组，每组内列出路径和一致性标记：`<文件名>: <路径1> <路径2> [IDENTICAL]` 或 `[DIFFERENT]`
4. JSON 输出数组，每项含 name、paths（字符串数组）、content_match（布尔值，需加 `--compare-content` 才有值，否则 null）
5. 退出码：0 无同名文件 / 1 存在同名文件 / 2 目录不存在
6. 符号链接解析到实际路径后参与比较
7. 隐藏文件（`.` 开头）默认跳过，加 `--include-hidden` 才纳入

CLI 分几个命令组：`file convert`、`file check`、`file merge`，每组下有具体操作。不用第三方包，go build 通过就行。
