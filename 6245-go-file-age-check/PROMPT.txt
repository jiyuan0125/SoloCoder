上个月 /tmp 撑爆了磁盘，排查发现有些临时文件躺了半年没人管。得用 Go 写个文件过期检查工具，能按天数算文件年龄，超过阈值的列出来。不同目录设不同阈值——日志目录保留 30 天，临时目录只留 7 天。

CLI 用法：`file-age check --dir /var/log --days 30 --dir /tmp --days 7`，多个 `--dir` 和 `--days` 成对出现。输出表格包含列：文件路径、大小（人类可读 KB/MB）、最后修改时间（YYYY-MM-DD HH:mm:ss）、超过天数。退出码 0 表示有过期文件并正常输出，1 表示参数错误或目录不存在，2 表示扫描出错（权限不足等）。

统计信息写入 `.file-age-stats.json`，结构 `{"lastScan":"RFC3339","totalFiles":N,"expiredFiles":N,"directories":N}`。首次运行没有这个文件就创建，不要报错。`--dry-run` 参数只输出列表不删除；加 `--delete` 才实际删除过期文件，删除前逐个打印 "deleting: <路径>" 并等待用户输入 y 确认。加 `--sort size|time|name` 指定输出排序方式（默认按时间倒序）。`--limit 50` 限制最多输出 N 条结果。空目录扫描时输出 "0 files scanned" 然后退出码 0。符号链接默认跳过，加 `--follow-symlinks` 才跟踪。权限不足的目录输出 "permission denied: <路径>" 跳过继续扫描其他目录。纯标准库实现，`go run .` 能跑。
