Docker 容器启动要传 30 多个环境变量，手动 export 一个个写 Dockerfile 里 ENV 谁维护得了。Go 做配置导出环境变量工具，从 JSON/YAML/TOML 配置文件读取，自动把嵌套结构拍平——db.host 变成 DB_HOST，app.server.port 变成 APP_SERVER_PORT，层级用下划线连接，key 全部大写。值中的换行符转义成 \n，双引号转义成 \"，shell 特殊字符（$ ` !）前面加反斜杠。

子命令结构：
- `env-export generate config.yaml --format shell` — 输出 export KEY="VALUE" 格式，一行一个，可以直接 source 加载
- `env-export generate config.yaml --format docker` — 输出 Docker ENV KEY=VALUE 格式，可以直接粘贴到 Dockerfile
- `env-export generate config.yaml --format json` — 输出 {"KEY":"VALUE"} 格式，方便程序读取
- `env-export preview config.yaml` — 预览将要导出的键值对表格，不实际导出，输出格式 KEY | VALUE 两列

数组类型导出时用逗号连接：hosts: ["a","b","c"] 变成 HOSTS="a,b,c"。布尔值导出为小写 true/false。空配置文件导出为空（不输出任何内容），退出码 0。纯标准库实现，go run . 能跑。
