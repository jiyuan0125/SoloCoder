TOML/YAML 有类型，.env 全是字符串，合在一起 "3306" 和 3306 对不上。Go 做配置类型推断——自动推断字符串值的实际类型，让不同格式的类型统一。

推断规则："3306"→int，"3.14"→float，"true"/"false"→bool，"null"→null，其余 string。--strict 模式下 "123abc" 不推断保持 string。

- `typeinfer process --file config.env --output config.json` 推断转换输出 JSON
- `typeinfer check --file config.env` 统计类型 "string:15 int:8 float:2 bool:3"
- `typeinfer diff --file-a config.env --file-b config.yaml` 类型差异对比 "key server.port: env=string, yaml=int"
- `typeinfer cast --file config.env --key "server.port" --type int` 强制类型，失败报 "cannot cast 'abc' to int"

--infer-list 开关启用逗号分隔值推断为数组 "a,b,c"→["a","b","c"]。处理每条记录后触发统计更新。go build 编译通过，不依赖第三方库。
至少拆成两个包或三个文件以上，不要单文件一把梭。
