用 Rust 写一个栈式字节码虚拟机。从二进制文件加载字节码并执行。

指令集：
1. ICONST n：常量入栈
2. ADD / SUB / MUL / DIV / MOD：弹出栈顶两个值运算，结果入栈。整数除法除以零返回错误不 panic
3. LOAD var_idx / STORE var_idx：从局部变量加载/存储，局部变量空间在 CALL 时分配
4. JMP addr / JZ addr / JNZ addr：跳转。JZ 弹出栈顶，为 0 则跳转；JNZ 同理不为 0 则跳转
5. CALL addr：把当前 PC+1 压入调用栈，跳转到 addr。每个 CALL 分配独立的局部变量空间（256 个槽位，初始为 0）
6. RET：从调用栈弹出返回地址并跳转，同时释放当前局部变量空间
7. PRINT：弹出栈顶并打印
8. HALT：停止 VM

字节码格式：每条指令 1 字节操作码 + 0 或 4 字节操作数（小端序）。

要求：
9. JMP/CALL/JZ/JNZ 的目标地址如果在字节码范围之外返回错误
10. CALL 栈深度超过 64 层返回栈溢出错误
11. 执行结束后打印栈中剩余元素数量（应该为 0 表示正常结束）

代码分 VM 核心、指令解码、调用栈管理、字节码加载几个模块，cargo build 能过。
