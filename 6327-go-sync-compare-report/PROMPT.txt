上次同步 5000 个文件到生产环境，同事问哪些变了，答不上来。`syncreport --source <dir> --target <dir> --output report.md --checksum sha256 --ignore .git,tmp` 对比两个目录，输出 Markdown 报告。`--ignore` 指定跳过的目录名，逗号分隔。扫描时按相对路径逐一比对：源有目标没有记为 "added"，目标有源没有记为 "deleted"，都存在但内容不同（用 sha256 比较文件内容）记为 "modified"，内容和大小完全相同记为 "unchanged"。报告开头是汇总行：新增 X 个，删除 Y 个，修改 Z 个，相同 W 个，总耗时 T（毫秒）。后面跟四个 Markdown 表格，每张表列 columns：序号、相对路径、源端大小（字节）、目标端大小（字节）。处理完每个目录后更新进度到 stderr："[scanning] processed N files..."。空目录跳过处理但进度计数器照常更新。比较过程中遇到符号链接跳过，stderr 输出 "warning: symlink skipped: <path>"。`--checksum` 可选 sha256 或 size-only，size-only 只比文件大小不读内容。source 或 target 目录不存在时 stderr 输出 "error: directory not found: <path>" 退出码 1。编译 go build，不用第三方库。
