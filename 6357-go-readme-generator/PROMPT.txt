新同事 clone 项目不知道怎么跑，README 写得乱七八糟。`readmegen <project-dir> --output README.md --template custom.tmpl` 自动生成 README。不加 `--template` 用内置模板，加了就加载自定义 Go template 文件，模板变量有 ProjectName、DirectoryTree、ExportedFunctions、Usage。提取三类信息：目录树用 filepath.Walk 遍历，忽略 .git 和 vendor 目录，输出缩进层级结构，每层缩进两个空格；导出函数列表用 Go AST 解析 .go 文件，提取首字母大写的函数名、参数类型列表和返回值类型列表，表格展示；使用说明从 main.go 的注释（// Usage: 开头的行）和 flag.String/flag.Bool 定义中提取 flag 名称和默认值。生成内容分三段：Project Structure、Exported Functions、Usage。目录为空时输出 "warning: empty project directory" 并生成只含标题的 README。首次运行没有历史统计，直接生成。重复运行覆盖已有 README.md，旧内容不保留。校验完成后自动更新统计信息到 `.readmegen/stats.json`，记录 last_generated（RFC3339）、file_count、func_count。编译 go build 通过就行，不用第三方包。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
