PR 里的 Markdown 表格在 GitHub 上对不齐——review 的时候表格列歪了，数字和文字混在一起根本看不清。

1. 自动对齐列宽命令 `fmt table --input <file> [--output <file>]`，不指定 output 则就地修改。规则：每列宽度对齐到该列最宽单元格的长度加两侧空格，数字列（内容全部匹配 `^-?\d+(,\d{3})*(\.\d+)?$`）右对齐，其他列左对齐。表格内部连续空行分隔视为两个独立表格。非表格行原样保留。输出格式变更统计：`{"tables_processed": 3, "cells_aligned": 45, "numeric_columns": 2}`。

2. 子命令结构：`fmt table` 格式化表格，`fmt list --input <file> --style dash|asterisk` 格式化列表，`fmt status --file <path>` 显示文件中表格数量和格式状态。

3. 处理完主文件后自动生成摘要文件 `<basename>.summary.md`，内容包括表格数量、总行数、总列数。文件中无表格时不生成摘要文件。

4. 分隔行 `|---|---|` 中不足的列自动补齐（加 `---|`），多出的列截断。空表格（只有表头没有数据行）原样保留不修改。`go build` 出来就跑，标准库实现。退出码 0=成功，1=文件读取失败，2=格式错误。
