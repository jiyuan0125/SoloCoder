技术文档里几十个代码示例散落在各处，review 的时候翻得头疼。按语言分类提取出来，方便批量检查和执行。

CLI：`mdextract extract --input docs.md --output ./code-blocks/ --by-lang`。扫描 Markdown 文件中的围栏代码块（```标记），按语言分类保存。输出目录结构：`./code-blocks/go/1-hello-world.go`、`./code-blocks/python/2-data-model.py`。文件名优先取代码块上方的 `### 标题` 或代码块首行注释，取不到则用递增序号。`--by-lang` 按语言分子目录，不加则全部平铺到输出目录。

`mdextract list --input docs.md` 只列出代码块信息不提取：输出表格含序号、语言、起始行号、行数、标题（如有）。`mdextract stats --input docs.md` 输出统计 JSON：`{"total_blocks": 25, "languages": {"go": 15, "python": 8, "bash": 2}, "total_lines": 340}`。

输入文件不存在退出码 1。文件中无代码块时输出 `no code blocks found` 退出码 0。代码块未标注语言时归入 `unknown` 类别。子命令 `db migrate`/`db rollback`/`db status`/`db seed` 管理提取记录的本地 SQLite 存储（`--store extract.db`），避免重复提取。`go build` 通过就行，不用第三方包。
项目结构要分模块：主入口、核心处理逻辑、工具函数分文件组织，方便测试和维护。
