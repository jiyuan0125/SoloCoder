先说场景：内部文档全中文标题，生成的 HTML 锚点全是乱码。这个工具做的事情分几步——第一步扫描 Markdown 文件提取所有标题，第二步把中文标题转成合法锚点（拼音或编号），第三步扫描文档中所有 `[text](#anchor)` 格式的内部链接，把锚点更新成新生成的值。

命令行用法：`anchor-gen <文件或目录>`，`--mode pinyin` 用拼音（需要内嵌常用汉字拼音映射表），`--mode number` 用 `section-1-2-3` 格式编号，默认 pinyin 模式。`--dry-run` 只输出变更计划不修改文件。输出格式：每行一个变更，`行号: 旧锚点 → 新锚点`。支持递归处理目录：`anchor-gen ./docs/` 会遍历所有 `.md` 文件。

重复标题自动加后缀：第二次出现的"概述"变成"概述-2"，第三次变成"概述-3"。代码块（```围栏）内的内容跳过不处理，行内代码（`code`）也跳过。空文件或无标题文件直接输出 "no headings found" 退出码 0。导入数据后自动做一致性检查——验证修改后的文档所有内部链接都有对应标题，断裂链接输出 `[BROKEN] 行号: #xxx not found` 警告，不退出。

`--suffix .bak` 修改前备份原文件，默认不备份。go build 过了就完事，全标准库，主逻辑分文件写。
