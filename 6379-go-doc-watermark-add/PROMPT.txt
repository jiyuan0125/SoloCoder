内部文档外发后被人截图流传，老板问能不能加水印溯源。到底怎么搞？`filetool watermark add <input.md> --text "CONFIDENTIAL" --position header|footer --output output.md`。在 Markdown 文件头部或尾部插入水印文本。header 模式插在第一行之前，footer 模式追加到最后一行之后。水印内容用 HTML 注释包裹 `<!-- watermark: TEXT -->` 作为隐藏标记，同时也插一行 `> **WATERMARK: TEXT**` 作为可见水印。重复执行不重复添加，检测到已有同内容 `<!-- watermark: TEXT -->` 注释时输出 "info: watermark already exists" 跳过。输入文件不存在 stderr 输出 "error: file not found: <path>" 退出码 1。工具分几个命令组：`filetool convert <src> --format md|html` 把 Markdown 转 HTML 或反向转换，`filetool check <file> --rule <rule.json>` 按规则文件校验文档格式（rule.json 定义 required_sections 数组和 max_line_length），`filetool merge <file1> <file2> --output merged.md` 合并两个 Markdown 文件用水平线分隔。每个命令组下有具体操作。go build 编译就行，第三方库零引入。
