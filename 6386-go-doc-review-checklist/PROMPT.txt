文档审阅全靠人工，格式错误经常漏检——上次 API 路径写错审了三遍没人发现。

1. `review check --dir <dir> [--rules <rules.json>]` 三项检查：完整性（标题/作者/日期缺失 `MISSING_FIELD: <file> field=<name>`），准确性（代码示例格式校验 `INVALID_EXAMPLE: <file> line=<n> type=<json|yaml>`），格式（标题跳级 `HEADING_SKIP: <file> line=<n> from=h1 to=h3`）。

2. `review report --dir <dir> --output <f> --format text|json`。JSON：`{"file": "p", "score": 85, "issues": [{"type": "...", "severity": "error", "detail": "..."}]}`，error 扣 10 分 warning 扣 3 分。

3. 操作模式：`convert csv json`、`convert yaml toml`、`validate json --file <p>`、`diff json --left <f> --right <f>`。

空目录 `NO_DOCS: <dir>`。无问题 `CLEAN: <file>`。标准库，`go run .` 跑起来就行。
