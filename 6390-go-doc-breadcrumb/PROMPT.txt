文档站有五层目录深度，用户反馈打开一篇文档完全不知道自己在哪个层级。做一个自动生成面包屑导航的工具，把路径层级嵌入到文档顶部。

第一步，`breadcrumb generate -dir ./docs`。扫描目录下所有 `.md` 文件，根据文件所在目录层级生成面包屑。比如 `docs/api/auth/login.md` 的面包屑是 `首页 > API > 认证 > 登录`。第二步，在每个 Markdown 文件的头部（第一个 `---` front matter 之后，或文件开头）插入一行注释格式的面包屑 `<!-- breadcrumb: 首页 > API > 认证 > 登录 -->`。第三步，如果文件已有面包屑注释，替换旧内容而不是重复插入。

生成后自动记录操作日志。日志结构：`{"file": "...", "breadcrumb": "...", "level": 4, "timestamp": "..."}`。数据库不可用（如 SQLite 文件写锁）时回退写本地文件 `breadcrumb.log`，格式每行一条 JSON。

配置文件 `breadcrumb.yaml` 可自定义：`home_label`（首页显示名称，默认"首页"）、`separator`（分隔符，默认 " > "）、`max_depth`（最大显示层级，超过则省略中间层用 "..." 表示）。dir 不存在 exit 1 并打印路径。零 md 文件输出 "no markdown files found" exit 0。go build 过了就完事，不用第三方包。
