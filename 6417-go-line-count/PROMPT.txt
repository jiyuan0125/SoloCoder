每周五领导要看代码量报告，手动跑 cloc 再粘贴到表格里太折腾了。需要个工具自动统计，按周对比，一眼看出这周写了多少、改了多少、注释比例有没有下降、哪个包变更最多、谁贡献了多少代码量。

统计维度分三层：代码行（非空行非注释行）、注释行（以 // 或 /* 或 * 开头）、空行。按包和文件两层分组汇总，先按包汇总再展开到文件级别。支持指定时间范围，line-count -dir ./src -since 2024-01-01 -until 2024-01-07，根据 git log 的提交时间筛选该周变更过的文件并统计行数变化。输出一张按周分组的对比表，列名：周起始日期、新增代码行、删除代码行、净增、注释占比、文件变更数。-format json 输出完整结构化数据，weeks 数组每项有 date、added、deleted、net、comment_ratio、files_changed 六个字段。

空目录输出 "no Go files found" 退出码 0。文件编码统一按 UTF-8，遇到非法字符跳过该行并计入 skipped_lines。没有 git 仓库时降级为纯文件统计，只统计总量不按周分组。-top 5 只显示变更量最大的前 5 个文件。-by-author 按提交者分组统计各人贡献量，输出每位作者的新增行、删除行和净增行数。单文件行数超过 5000 行的在结果中标记 LARGE 提醒关注拆分。不用第三方包，go build 通过就行。
