1. 问题出在哪？并发程序调了三天，最后发现 channel 方向搞反了——goroutine 往一个只读 channel 里写数据。

2. 分析 Go 源码里 channel 使用，覆盖三类检查：
   - 缓冲与非缓冲 channel 混用（make(chan T) vs make(chan T, N)）
   - 方向标注与实际读写匹配（chan<- T 只写，<-chan T 只读）
   - goroutine 泄漏：channel 未关闭且无消费者

3. 嵌套子命令：
   - `project create --name <名> --path <目录>` 创建分析配置
   - `project build` 编译目标
   - `project test run [--verbose]` 运行测试收集数据
   - `project test coverage [--threshold 80]` 覆盖率报告

4. 输出：终端表格显示文件、行号、channel、问题、级别（warn/error）。`--json` 输出数组含 file/line/channel/issue/severity。error 级退出码 2，warn 退出码 0。

5. 路径不存在 "path does not exist: <path>" 退出码 1。--threshold 默认 80，低于阈值退出码 3 打印 "coverage X% below threshold Y%"。

纯标准库，`go run .` 就能跑。
