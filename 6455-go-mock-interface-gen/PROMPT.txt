单元测试的 mock 结构体手写太烦，接口改了一个方法，三个 mock 文件要同步改，漏一个编译就挂。做一个代码生成器，从 Go 接口定义自动生成 mock 实现，每个方法都可以独立配置返回值。

命令 `mockgen -iface ./service.go -name UserService -output ./mocks/user_service_mock.go`。解析源文件找到指定接口，为每个方法生成 mock 函数。生成的 mock struct 包含一个 `Calls` 字段记录调用历史（参数列表），和一个 `Returns` map 设置每个方法的返回值。示例生成代码模式：`func (m *MockUserService) GetUser(ctx context.Context, id int) (*User, error) { m.Calls = append(m.Calls, Call{Method: "GetUser", Args: []interface{}{ctx, id}}); return m.Returns["GetUser"].(*User), nil }`。

构建流程四步：解析（parse 接口定义）→编译（验证生成的代码能通过 `go vet`）→测试（生成基本测试文件验证 mock 可用）→打包（输出到目标路径）。测试失败则不生成最终文件，打印 "generated code failed validation: <error>" exit 1。

接口名在文件中不存在报 "interface not found: <name>" exit 1。源文件不存在 exit 1。输出目录不存在自动创建。标准库搞定，`go run .` 跑起来。
