新开一个 Go 项目要手动建目录、写 go.mod、搭 main.go 骨架、放 placeholder 防空目录——每次都干同样的事还是会漏步骤。

命令 `modinit generate <项目名> --module <路径>` 一步搞定：创建 cmd/、internal/、pkg/ 目录，加 --with-api 额外建 api/。go.mod 自动填模块路径和当前 Go 版本。cmd/<项目名>/main.go 包含 package main 和空 func main()。internal/placeholder.go 和 pkg/placeholder.go 防空目录被 git 忽略。--with-readme 生成 README.md 写项目名和模块路径。最后提示 go mod tidy（不自动执行）。

子命令用法——`sync local <目录>` 基于已有代码重建 go.mod、`sync remote <git-url>` 克隆后分析依赖、`sync status` 显示上次初始化的记录。处理完成后自动在项目根目录写 .modinit-meta.json 记录项目名、模块路径、生成时间。

参数不传 --module 报错 "module path is required" 退出码 1。目录已存在且非空 "directory not empty: <path>" 退出码 1。Go 版本检测失败 "cannot determine Go version" 退出码 1。

模块路径格式校验——至少包含一个 `/`，如 github.com/user/project。不合法时 "invalid module path: <path>" 退出码 1。

纯标准库，`go run .` 跑起来。
