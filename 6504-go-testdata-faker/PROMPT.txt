产品经理说测试数据不够真实，每次手动编 JSON 编到怀疑人生。从 Go struct 定义文件里提取字段名和类型，按规则自动生成测试数据，email 出邮箱格式、phone 出手机号、枚举列随机选值——这些都能自动搞定。

主命令 `fakegen`，`fakegen generate --file model.go --count 20 --output fake_data.json`。解析 .go 文件中的 `type Xxx struct` 定义，提取每个字段的名字、类型（string/int/float64/bool/time.Time）和 tag（json/yaml 标签名）。字段名包含 email 或 mail 就生成 `user<number>@example.com` 格式；包含 phone 或 mobile 就生成 `1[3-9]xxxxxxxxx`；tag 里有枚举值（如 `enum:"active|inactive|pending"`）就从中随机选。自定义规则通过 `--rules rules.json` 覆盖，格式为 `{"FieldName":"pattern:<template>"}` 或 `{"FieldName":"enum:a|b|c"}`。`--count` 控制生成条数，默认 10。`--format json|yaml` 控制输出格式。struct 里嵌套的匿名 struct 也要展开到输出里。文件解析失败输出 "parse error: <file>: <detail>" exit 1。找不到 struct 定义输出 "no struct definition found in <file>" exit 2。`--seed` 固定随机种子保证可复现。Go 标准库，命令行参数用 flag 包，`go build` 直接跑。
