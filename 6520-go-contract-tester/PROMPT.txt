契约测试框架要钱，Pact 那一套在 Go 里跑起来太重。自己定义接口契约（请求格式和响应格式），对运行中的服务发起请求验证响应是否合规，JSON Schema 校验就够了。

API 契约测试工具。定义接口契约（请求格式和响应格式），然后对运行中的服务发起请求验证响应是否符合契约。支持 JSON Schema 校验。
项目拆成至少 3 个 Go 源文件：主入口、核心逻辑、数据模型分开。
扫描时锁住结果集，但发现重复项需要回查结果集做去重校验。
CLI 用子命令组织：`tool group command subcommand`，支持三级。

用 Go 标准库写，go run . 或 go build 都行。
