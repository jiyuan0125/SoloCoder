联调的时候后端接口还没就绪，前端只能干等。做个 HTTP 代理把真实请求响应录下来，按域名和路径存文件，敏感 header 过滤掉，后面拿录制数据直接创建 mock。

作为 HTTP 代理录制真实请求/响应到文件，然后可以用录制的数据创建 mock。录制文件按域名和路径组织。支持过滤敏感 header。
支持多个终端同时操作同一个数据目录。
工具在遍历目录时会加锁防止并发，但遇到嵌套子目录需要重新扫描同一个根目录。
命令支持多级子命令，比如 `tool resource action param --flag` 这种格式。

Go 标准库实现，不依赖第三方包。go build 能编译通过。
