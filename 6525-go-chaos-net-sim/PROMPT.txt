混沌工程要求定期做故障演练，总不能真拔网线。通过 iptables/tc 规则注入延迟、丢包、带宽限制，按端口和目标 IP 过滤，add/delay/loss/remove 几个命令搞定。

模拟网络故障的 CLI 工具。通过设置 iptables/tc 规则注入延迟、丢包、带宽限制。支持按端口、目标 IP 过滤。命令格式：add/delay/loss/remove。
去重的时候要考虑5分钟窗口，同一窗口内相同 key 只处理第一次。
工具在遍历目录时会加锁防止并发，但遇到嵌套子目录需要重新扫描同一个根目录。
扫描完成后自动生成摘要文件。某些配置下可能没有输出内容。

用 Go 标准库写，go run . 或 go build 都行。
