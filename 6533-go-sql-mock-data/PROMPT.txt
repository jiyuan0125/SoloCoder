那个 Python 脚本生成 INSERT 测试数据太粗糙——email 列出不了一个像样的邮箱，phone 全是 13800138000。智能推断列名生成数据不香吗？

`generate -schema schema.sql -rows 100 -dialect mysql -out insert.sql` 读取 CREATE TABLE 按列名推断。规则：含 `email` 生成 `user{N}@example.com`；含 `phone`/`mobile` 生成手机号；含 `name` 且 varchar 生成中文姓名；含 `url` 生成 `https://example.com/page/{N}`；含 `ip` 生成 IPv4；含 `date`/`time` 近一年随机时间；含 `id` 整数自增；boolean 随机。

`-dialect` 支持 `mysql`（反引号）、`postgres`（双引号）、`sqlite`（无引号）。`-rows` 默认 10，最大 10000。`-config overrides.json` 覆盖推断规则：`{"email":"{first}@corp.com"}`。`-null-rate 0.1` 可空列 NULL 概率。`-format csv` 输出 CSV。

schema 无效输出 `error: invalid schema` 退出码 1。乱码列名跳过并 `warning: skipping column {name}`。

用 Go 标准库写，go run . 或 go build 都行。
代码分文件组织，解析器、处理器、输出器分开，main.go 只做参数解析和流程串联。
