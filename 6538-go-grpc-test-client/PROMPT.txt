每次排查 gRPC 接口问题都得新建一个 Go 文件、写 client 代码、编译、运行——验证一个字段改了之后返回值对不对，这么简单的事要折腾十分钟。有没有那种直接传 JSON 就能调 gRPC 方法的通用客户端？服务端开了 reflection 的话应该能做到。

`call -endpoint localhost:50051 -service UserService -method GetUser -request '{"id":"123"}'` 通过 server reflection 发送一元调用，输出响应 JSON 到 stdout。

`stream-server -endpoint localhost:50051 -service LogService -method StreamLogs -request '{"level":"error"}' -timeout 10s` 接收服务端流，每条消息一行 JSON。`stream-client` 从 JSONL 文件逐行读取发送客户端流。`stream-bidi` 双向流。

`list -endpoint localhost:50051` 列出服务和方法：`SERVICE | METHOD | TYPE`，TYPE 为 `unary|server_stream|client_stream|bidi_stream`。

`-metadata 'authorization:Bearer token123'` 传递 metadata。连接失败输出 `error: failed to connect to {endpoint}: {reason}` 退出码 1。reflection 不可用输出 `error: server reflection not supported` 退出码 2。请求 JSON 格式错误输出具体解析错误。

用 Go 标准库 + `google.golang.org/grpc` 实现。go build 能编译通过。
