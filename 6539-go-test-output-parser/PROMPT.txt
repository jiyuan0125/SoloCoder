monorepo 里 Go 服务、Python 脚本、Java 工具都有，CI 跑完测试报告格式五花八门——Go 的 `go test -v` 输出、Python 的 pytest stdout、Java 的 JUnit XML，想汇总一个总通过率都做不到。统一解析这三种格式，输出标准化 JSON，再生成一个 HTML 汇总页面一目了然。

`parse -format gotest|pytest|junit|auto -file output.txt` 解析测试输出。统一输出 JSON：`{"framework":"","test_suites":[{"name":"","tests":[{"name":"","status":"pass|fail|skip","duration_ms":0,"error_message":""}]}],"summary":{"total":0,"passed":0,"failed":0,"skipped":0,"duration_ms":0}}`。

`report -files a.log,b.txt,c.xml -out summary.html` 解析多文件生成 HTML 汇总。顶部通过/失败/跳过彩色计数，按文件分组，失败用例红色背景可展开查看错误信息。

`diff -base baseline.json -current current.json` 对比两次结果，输出新增失败、已修复、持续失败的用例。

空文件输出 `warning: empty input, no results` 退出码 0。无法识别格式输出 `error: unrecognized format` 退出码 1。

用 Go 标准库写，go run . 或 go build 都行。
