time.Now() 在测试里不可控，mock 掉它才能测过期、超时、定时触发这些场景。

`generate -pkg mocktime -out ./mocktime/` 生成 Go 包。接口：`type Clock interface { Now() time.Time; Since(t time.Time) time.Duration; Sleep(d time.Duration) }`。实现 `MockClock`：`NewMockClock(fixed time.Time)`、`Set(t time.Time)` 设时间、`Advance(d time.Duration)` 前进、`Freeze()`/`Resume()` 暂停恢复。

`-speed 2x` 生成加速时钟，`Now()` 按倍速前进。`-ticker` 额外生成 `MockTicker` 支持 `Tick()` 和 `Stop()`，`Advance` 时自动触发 channel。

生成文件头注释 `// Code generated by mock-time-provider; DO NOT EDIT`。已有目录需 `-force` 覆盖否则 `error: directory exists, use -force to overwrite` 退出码 1。生成代码 `go build` 和 `go vet` 无错误。

Go 标准库实现。go build 能编译通过。
