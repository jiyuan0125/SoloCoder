先看现状——`git branch -a` 输出 200 多行，大部分早就合进 main 了，但没人敢删怕删错。然后做清理——扫描所有本地分支，判断是否已合并到 main/master（自动检测默认分支名），把已合并的列出来让你确认再批量删。

命令 `branch-cleaner [flags]`，先列出候选删除列表。`-exclude "main,master,dev,release-*"` 排除保护分支（支持 glob 通配）。`-merged-only` 只显示已合并的。`-older-than 30d` 过滤超过 30 天没提交的（单位支持 d/w/m）。`-dry-run` 只输出不执行删除。不加 `-dry-run` 时逐个提示 `Delete branch feature/xxx? [y/n/a/q]`（a=全部 yes，q=退出）。

输出表格：列包括分支名、最后提交日期、是否已合并、作者。已合并的标绿色 ✓，未合并标红色 ✗。没有本地分支时输出 `no local branches found`。主分支检测失败时（既没有 main 也没有 master）输出 `error: cannot detect default branch, use -target to specify` 退出码 1。分支名匹配 exclude 规则时跳过不在列表中显示。

纯 Go 标准库，编译后单二进制可以直接跑，退出码 0 正常 1 错误。
项目结构要分模块：主入口、核心处理逻辑、工具函数分文件组织，方便测试和维护。
