做代码审计的时候想看每个模块到底是谁写的，结果 `git blame` 只能单文件看，几十个文件逐个 blame 眼睛都花了。把 blame 结果按作者和文件汇总一下，一眼就能看出模块归属和贡献度。

`blame-stats -repo ./project -path src/` 扫描指定路径下所有文件（递归），对每个文件执行 `git blame --porcelain`，解析输出提取每行的 commit hash、作者名、作者邮箱、时间戳。第一步汇总：按文件×作者统计行数，输出表格列——文件路径、作者、行数、占比百分比（保留一位小数）。第二步：`-by-period month` 按月统计每个作者的贡献趋势。`-top 5` 只显示占比最高的 5 个作者，其余归入 `<others>`。`-author "zhangsan"` 过滤指定作者。`-since/-until` 限定时间范围，只统计该时间段内 last-modified 的行。遇到文件被删除（`git blame` 报错）时跳过并在 stderr 输出 `skipping deleted file: xxx`。重命名文件（blame 输出中有 `previous-file` 行）按当前路径统计。

输出 `blame-stats -format json` 时 JSON 结构为 `{"files":[{"path","authors":[{"name","lines","percentage"}]}],"summary":{"total_files","total_lines","top_contributors":[]}}`。作者同名不同邮箱的行数合并显示，用第一个出现的邮箱。

项目拆成至少 3 个 Go 源文件：主入口 main.go、核心逻辑 blame.go、数据模型 types.go。Go 标准库实现，`go build` 编译通过。
