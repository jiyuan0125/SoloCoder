git bisect 原理简单但操作繁琐，50 个 commit 要交互 6 次，每次手动跑测试再标记 good/bad。给个起止 commit 和测试命令让它自己跑完。

`bisect-run -good v1.0.0 -bad v2.0.0 -test "go test ./..." -repo ./project` 自动化整个流程：`git bisect start`，标记 good/bad，循环 checkout 中间 commit、执行测试、根据退出码自动标记（0=good，非 0=bad），输出 `First bad commit: {hash} {subject}`。

`-test-timeout 120s` 单次测试超时（默认 120s），超时视为 bad。`-max-steps 20` 防无限循环。`-script check.sh` 自定义脚本（退出码 0=good）。结束后自动 `git bisect reset`，中断也先 reset。commit 不存在报错 `error: commit xxx not found` 退出码 1。命令执行失败输出 `error: test command failed: {stderr}` 退出码 2。`-verbose` 输出每步详情。

项目拆成至少 3 个 Go 源文件：main.go、bisect.go、types.go。Go 标准库，`go build` 编译通过。
