上周安全审计发现有人把 GitHub token 明文写进了 .gitconfig 的 remote URL 里。不扫一遍不知道还有没有。

命令行：`credential-audit -path /path/to/repo` 扫描仓库和全局配置。`-global` 只检查 `~/.gitconfig`。`-output report.json` 输出 JSON，默认 text。

检查项：
- 远程 URL 泄露：正则匹配 `https?://[^@]+@` 或含 `token=`/`key=`/`secret=` 的 URL，匹配到输出 "LEAK: remote '%s' contains credentials"
- credential helper：未设置输出 "WARN: no credential.helper configured"；值为 `store` 输出 "RISK: credential.helper=store stores plaintext"
- .gitconfig 敏感字段：扫描 `[user]` 段 token、`[github]` 段 oauth token

text 模式按行输出 `[LEAK|RISK|WARN|OK] xxx`。json 模式：`{"findings": [{"severity":"leak","rule":"cred_in_url","message":"...","file":".git/config","line":5}]}`。

退出码：0 = 无泄露，1 = 有 leak。路径不存在退出码 1。Go 标准库，`go build -o credential-audit .`。
