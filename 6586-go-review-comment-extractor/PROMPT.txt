Gerrit 的 review 评论嵌在 commit message 里，格式还不统一。手动一个个整理成表格，这活没人愿意干。

命令行：`review-extractor -repo /path/to/repo -format table`。`-since 2024-01-01` 过滤日期。`-reviewer john@example.com` 过滤 reviewer。`-output review.csv` 输出到 CSV。

解析 Gerrit 格式提取字段：Reviewer 从 `Reviewed-by: Name <email>` 提取，File 从 `Comments-on: path` 提取，Comment 从 `Comment: xxx` 提取，Score 从 `Code-Review: +1/+2/-1/-2` 提取。

输出格式：table 为 `| COMMIT | FILE | REVIEWER | COMMENT | SCORE |` 对齐表格；csv 表头 `commit,file,reviewer,comment,score`；json 为 `[{"commit":"abc123","file":"main.go","reviewer":"John","comment":"nit","score":"+1"}]`。

无 review 评论退出码 0 打印 "no review comments found"。不是 git 仓库退出码 1。解析失败的单条跳过打 stderr warning。Go 标准库，`go build -o review-extractor .`。
项目要用多文件结构，入口文件、业务逻辑、数据模型分开放，别揉在一个文件里。
