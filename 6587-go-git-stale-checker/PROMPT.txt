80 多个过期分支堆着，有些一年没碰了，手动排查效率为零。

命令行：`stale-checker -days 90` 标记 90 天以上无活动分支。`-exclude "main,master,release/*"` 排除保护分支，逗号分隔 glob。`-format text`（默认）或 `-format json`。`-delete` 自动删除过期分支（不加只列出）。

text 模式输出：`STALE BRANCHES (>90 days):` 下每行 `feature/login | 186 days | last: 2023-12-01 | author: alice@dev.com`，末尾 `Total: 2 stale, 1 protected`。json 模式：`{"stale":[{"name":"feature/login","days_inactive":186,"last_commit":"...","author":"..."}],"protected":[...]}`。

`-delete` 逐个删除打印 "deleted: %s"，`-dry-run` 打印 "would delete: %s"。不是 git 仓库退出码 1。无过期分支退出码 0 打印 "no stale branches found"。

需 regexp.Regexp 处理 glob。纯 Go 标准库，`go build -o stale-checker .`。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
