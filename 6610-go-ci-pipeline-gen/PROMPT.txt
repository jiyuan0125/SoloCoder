团队每接一个新项目就要手写 CI 配置文件，Go 项目一套、Java 一套、Python 又一套，复制粘贴改漏变量是常有的事。先搞定最常用的几种模板，后面再扩展。

工具流程是这样的：第一步 `ci-gen init` 交互式选择项目类型（go/java/python）和 CI 平台（github/gitlab），第二步读取项目目录结构自动检测已有的测试框架和构建工具，第三步 `ci-gen generate --type go --platform github --stages "lint,test,build,docker" --output .github/workflows/ci.yml` 生成配置文件。Go 项目模板包含：`go vet`、`go test -v -race -coverprofile=coverage.out ./...`、`go build -o bin/app`三个阶段。Java 模板用 Maven：`mvn verify`。Python 模板用 `pytest --cov`。`--stages` 不指定则生成全部阶段。生成的 YAML 缩进 2 空格，包含触发条件 `on: push: branches: [main]`。`--docker` 标志追加 docker build & push 阶段，镜像 tag 用 `github.sha` 短 hash。输出目录不存在时自动创建。已有同名文件时提示 `file exists, use --force to overwrite` 并退出码 3。项目拆成至少 3 个 Go 源文件：主入口、核心逻辑、数据模型分开。纯 Go 标准库实现，`go build` 能编译通过。
