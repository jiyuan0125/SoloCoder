三个 namespace 的资源配额要对齐，每次对比都要跑 kubectl 再手动整理到表格里，Python 脚本做了但执行太慢。Go 重写后一次对比秒出结果。

三个核心子命令。`nslist --namespace prod --format table` 列出指定 namespace 下的资源使用情况，输出 CPU/内存的 request 和 limit、Pod 数量、配额上限，从 `kubectl get resourcequota -o json` 的输出解析。`nsdiff --ns1 staging --ns2 prod` 对比两个 namespace 的资源配额差异，逐项列出 `资源类型 | ns1 值 | ns2 值 | 差异`，差异为 0 的行标注 `MATCH`，否则标注 `DIFF` 并显示差值。`nscheck --namespace prod --rules quota-rules.yaml` 检查配额是否符合规则文件定义的阈值，规则格式 `limits: cpu: max: "4" memory: max: "8Gi" requests: cpu: min: "100m"`。所有子命令支持 `--format json` 切换输出为结构化 JSON。`--kubeconfig` 指定 kubeconfig 路径，默认用 `$HOME/.kube/config`。kubectl 不可用或连不上集群时输出错误退出码 1。namespace 不存在时输出 `namespace not found: <name>` 退出码 2。项目拆成至少 3 个 Go 源文件：主入口、核心逻辑、数据模型分开。纯 Go 标准库，`go build` 能编译通过。
