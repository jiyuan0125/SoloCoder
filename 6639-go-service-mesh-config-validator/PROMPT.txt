先看怎么用：`mesh-validator check config.yaml` 校验单文件，`mesh-validator check ./manifests/ --recursive` 扫描目录。校验规则覆盖三类——路由规则检查 destination host 非空且 subset 在 DestinationRule 中有定义；超时设置检查 timeout 为合法 duration（如 `3s`、`500ms`）且不超过 `300s`；重试策略检查 attempts ≥ 1 且 perTryTimeout > 0。

接着看具体校验项：VirtualService 的 gateway 字段不能为空，regex match 的正则语法必须合法，weight 总和必须等于 100（有显式 weight 时）。DestinationRule 的 trafficPolicy 中 connectionPool 要有合理的 maxConnections。

输出格式：通过输出 `✓ config.yaml: 3 virtualservices, 2 destinationrules - all valid`，失败逐条列出 `✗ config.yaml: vs "my-svc" - route[1].subset "v3" not defined`。JSON 输出用 `--json`：`{file, errors: [{line, rule, message}], warnings: [...]}`。

YAML 解析失败 `error: invalid yaml: <path>: <line>` exit 2。无 Istio 资源 `warning: no Istio resources found` exit 0。Go 标准库实现，`go build` 编译通过，交叉编译友好。
