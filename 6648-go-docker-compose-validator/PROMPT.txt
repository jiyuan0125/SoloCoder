docker-compose.yml 端口冲突导致服务起不来排查了两小时，之后又出过 volume 挂载路径不存在和环境变量引用未定义变量的问题。团队要求提交 compose 文件前必须过一遍检查。

工具扫描 docker-compose.yml（支持 v2/v3），检查四类问题。命令行 `compose-check verify --file docker-compose.yml --strict`。(1) 端口冲突：多 service 绑定同一宿主机端口报 error `port conflict: host port <port> used by <svc1> and <svc2>`；(2) volume 挂载：bind mount 宿主机路径不存在（绝对路径）报 warning `bind mount source does not exist: <path>`；(3) 环境变量：`${VAR}` 或 `$VAR` 在 environment 块和 .env 文件中找不到定义报 warning `undefined variable: <VAR> in service <name>`；(4) depends_on 引用不存在的 service 报 error `depends_on references non-existent service: <name>`。`--strict` 下 warning 也算失败。输出每行一条 `[ERROR/WARNING] <service>: <message>`，最后汇总 `N errors, M warnings`。通过退出码 0，有问题非零。YAML 解析失败退出码 2。项目拆成至少 3 个 Go 源文件：主入口、核心逻辑、数据模型分开。纯 Go 标准库，`go run .` 或 `go build` 都行。
