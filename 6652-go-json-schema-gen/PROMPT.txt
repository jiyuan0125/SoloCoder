前端团队要 JSON Schema 做表单校验，后端懒得手写——几十个接口每个 schema 都几百行，手动维护跟代码同步几乎不可能。下周演示用，先出个能用的原型。

两种输入模式。`schema-gen from-json --sample data.json --output schema.json` 从 JSON 样本推断：字符串字段推断为 `{"type":"string"}`，数字推断为 `{"type":"number"}`（整数用 `"type":"integer"`），布尔推断为 `{"type":"boolean"}`，数组根据第一个元素推断 `items`，null 或混合类型推断为多类型 `"type":["string","null"]`。所有字段默认标记 `"required": false`，用 `--required-fields name,email,age` 指定必填。`schema-gen from-struct --file model.go --struct User --output schema.json` 从 Go 源码解析 struct tag `json:"name"` 生成字段名，类型映射：`string→string`、`int/int64→integer`、`float64→number`、`bool→boolean`、`[]T→array`。输出 JSON Schema draft-07 格式，固定包含 `$schema: "http://json-schema.org/draft-07/schema#"` 和 `$ref` 根引用。Go 源码解析失败时输出具体错误位置和原因，退出码 1。输入文件不存在退出码 2。输出目录不存在自动创建。Go 标准库，命令行参数用 flag 包解析。
