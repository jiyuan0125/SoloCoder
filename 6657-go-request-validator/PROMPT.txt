你有没有试过用一个 200MB 依赖的 JSON Schema 校验库？或者用按调用量收费的 SaaS 验证 API？太重了也不划算。Go 标准库完全能搞定 JSON Schema 验证，就看你愿不愿意写。

从文件读 JSON Schema 和待校验数据，命令行 `jsonvalidate --schema schema.json --data data.json --strict`。支持 JSON Schema draft-07 子集校验：`type`（string/number/integer/boolean/array/object/null）、`required`（检查必填字段列表）、`minimum`/`maximum`（数值范围）、`minLength`/`maxLength`（字符串长度）、`enum`（值是否在枚举列表中）、`items`（数组元素校验，递归应用 schema）、`properties`（嵌套对象校验，递归）。`--strict` 模式下额外校验数据中存在但 schema 未定义的字段，输出 warning `unknown field: <path>`。校验失败时逐条输出错误：`VALIDATION ERROR at <jsonpath>: expected <type>, got <actual>`。jsonpath 用点分隔表示嵌套路径如 `user.address.city`。全部通过输出 `Validation passed` 退出码 0。Schema 文件本身格式错误退出码 2。项目拆成至少 3 个 Go 源文件：主入口、核心逻辑、数据模型分开。Go 标准库，命令行参数用 flag 包解析。
