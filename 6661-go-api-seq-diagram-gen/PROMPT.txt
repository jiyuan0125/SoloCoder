排查接口时序问题要从几百行日志里手动拼请求顺序，上次出了个 bug 花了一下午才理清哪个请求在哪个响应之前。如果有工具自动把请求响应按时序排出来画成图，能省不少时间。

从 HTTP 日志或 HAR 文件提取请求响应，按时序排序后输出时序图。命令行 `seqgen parse --input access.log --format mermaid --output seq.mmd`。日志格式兼容 nginx combined log（按行解析，提取时间戳、method、path、状态码）和 HAR 文件（JSON 格式，从 `entries[].startedDateTime` 提取时间戳、`request.method`、`request.url`、`response.status`）。客户端和服务端通过日志中的 IP 或 HAR 中的 `serverIPAddress` 区分角色。输出 Mermaid sequenceDiagram 格式：`sequenceDiagram participant Client participant Server Client->>Server: GET /api/users [200] 12ms Server-->>Client: 200 OK`。请求响应配对逻辑：同一 IP 的请求和响应按时间戳相邻配对，超过 5 秒未配到的请求标注 `[timeout]`。`--filter` 按 URL 路径前缀过滤，只输出匹配的请求。`--format` 支持 `mermaid` 和 `plantuml` 两种。文件格式无法识别时输出 `unsupported log format` 退出码 1。纯 Go 标准库，`go build` 能编译通过。
