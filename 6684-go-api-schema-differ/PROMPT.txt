1. JSON Schema v2 发给前端了，对方说接口对不上——字段名改了、类型从 string 变成了 integer、required 里多了三个字段。手动对两个 schema 文件太容易漏了。Go 写个结构化对比工具：`schema-diff <old.json> <new.json>` 输出差异报告。

差异分五类输出，每类带标记：`[ADD]` 新增字段、`[DEL]` 删除字段、`[TYPE]` 类型变化、`[CONST]` 约束变化（minimum/maximum/pattern/enum/maxLength 等）、`[REQ]` required 变化。每个差异一行：`类型 路径 旧值→新值`。`--format json` 输出 JSON 数组，每条 `{"type":"ADD","path":"properties.age","old":null,"new":{"type":"integer"}}`。

嵌套的 `$ref` 引用需要展开再对比，不能只看 ref 路径变了没有。`--breakdown` 按路径前缀分组输出统计。`--depth N` 限制嵌套展开深度，默认 10。空 schema 或非 JSON 输入报错退出码 1，错误信息 `"invalid JSON: <filename>"`。两个文件完全一致输出 "no differences" 退出码 0。
