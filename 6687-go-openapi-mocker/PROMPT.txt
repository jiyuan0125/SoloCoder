先干这个：前端联调需要 mock 数据，但 OpenAPI spec 里 examples 字段基本没人填，手动造 JSON 又慢又不一致。写个工具从 spec 自动生成 mock 响应。

第一步，解析 OpenAPI 3.0 的 JSON/YAML 文件。对每个 GET/POST endpoint 的 200 响应 schema 生成 mock 数据。策略：schema 中有 `example` 或 `examples` 字段，优先用；没有则按类型生成——string 用 `lorem ipsum`，integer 用随机数（1-1000），boolean 随机 true/false，array 生成 1-3 个元素，object 递归处理。

1. 命令：`apimock generate --spec api.yaml --endpoint GET:/api/users --count 10 --output mock-users.json`。
2. `--count` 控制生成条数，默认 5。`--endpoint` 不指定则为所有 GET endpoint 生成。
3. `--seed 42` 固定随机种子，保证可复现。
4. 输出 JSON 数组，每个元素符合 schema 结构。

`apimock validate api.yaml` 校验 spec 文件格式，解析失败输出具体错误位置和原因，退出码 1。spec 中无 paths 定义时输出 `no endpoints found` 退出码 0。必填字段（required）在 mock 中必须出现，可选字段有 50% 概率包含。用 Go 标准库写，`go run .` 或 `go build` 都行。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
