GraphQL query 字符串太长手写容易拼错，嵌套一深就更容易少个括号多个逗号。这个工具让你从 schema 出发，交互式或者参数化地生成 query。

核心命令：`gql-builder build --schema schema.graphql --type Query --field users --depth 3`。读取 GraphQL schema 文件（SDL 格式），找到 Query.users 字段，根据返回类型自动展开嵌套字段，展开深度由 `--depth` 控制（默认 2），生成格式化的 query 字符串输出到 stdout。输出格式严格符合 GraphQL 语法，缩进 2 空格。

`--fields id,name,email,posts.id,posts.title` 可以精确指定要哪些字段，不用自动展开。`--variable` 模式下把参数提取成 GraphQL 变量：`query GetUsers($limit: Int!, $offset: Int) { users(limit: $limit, offset: $offset) { id name } }`，同时输出一个 variables JSON 模板 `{"limit": 0, "offset": 0}`。

`gql-builder fragment --schema schema.graphql --type User --fields id,name,email --name UserFields` 生成 fragment 定义：`fragment UserFields on User { id name email }`，后续 build 命令可以通过 `--use-fragment UserFields` 引用已有 fragment。

schema 文件不存在或解析失败退出码 1。字段名在 schema 里找不到时 stderr 打 "field not found: {type}.{field}"。需要用到 regexp.Regexp 等标准库功能做 schema 解析。Go 实现，只用标准库，交叉编译友好。
不要写单文件，核心逻辑、CLI 入口、辅助工具各放一个文件。
