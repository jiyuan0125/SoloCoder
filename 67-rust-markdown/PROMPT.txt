用 Rust 写一个 Markdown 转 HTML 渲染器。命令行工具，输入 .md 文件，输出 .html 文件。

支持的 Markdown 语法：
1. 标题：# 到 ######（不支持 ###### 以上的标题，超过 6 个 # 的行当作普通文本）
2. 列表：无序列表（- 或 * 开头）和有序列表（1. 开头），嵌套最多 3 层，缩进 2 空格表示一层
3. 代码块：三个反引号围起来的内容不进行任何 HTML 转义和 Markdown 渲染，原样输出到 &lt;pre&gt;&lt;code&gt; 标签中
4. 行内元素：`行内代码`、**粗体**、*斜体*、[链接](url)、![图片](url)
5. 表格：| 分隔的表格，第一行为表头，第二行为分隔行（|-|-|-），后续为数据行。单元格内的 | 字符不需要转义
6. 水平线：--- 或 *** 单独一行

HTML 转义：
7. 在非代码块和非行内代码的文本中，< > & 要分别转义为 &lt; &gt; &amp;
8. 代码块和行内代码中的 < > & 不转义

要求：
9. 解析错误不要 panic，尽可能渲染能渲染的部分，未闭合的格式当作普通文本
10. 输出完整 HTML 文档（包含 &lt;html&gt;&lt;body&gt;...&lt;/body&gt;&lt;/html&gt;），不是 HTML 片段

代码分 block parser、inline parser、HTML 生成几个模块，cargo build 能过。
