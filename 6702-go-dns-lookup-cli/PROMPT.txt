运营那边换了 DNS 服务商之后邮箱收不到验证邮件，怀疑是 MX 记录没迁过来。查 DNS 这事经常遇到，得有个顺手的好工具。

先说命令行：`dns-lookup --domain example.com --type MX --server 8.8.8.8:53 --format json`。`--type` 支持 A、AAAA、CNAME、MX、TXT、NS、SOA、SRV，不传默认查 A。`--server` 指定 DNS 服务器地址（IP:端口格式），不传用系统默认。`--format` 可选 json 或 table。

输出 JSON 结构要完整：`{ "domain": "example.com", "query_type": "MX", "dns_server": "8.8.8.8:53", "answers": [{ "name": "example.com", "type": "MX", "ttl": 3600, "priority": 10, "value": "mail.example.com.", "class": "IN" }], "authority": [...], "additional": [...], "rcode": "NOERROR", "authoritative": true, "query_time_ms": 12 }`。authority 和 additional 段也要输出，不能丢。TTL 单位秒，MX 记录的 priority 单独字段。

`dns-lookup --domain example.com --type ALL` 一次查所有支持的记录类型，结果按 type 分组。table 格式输出用 tabwriter，列是 NAME/TYPE/TTL/VALUE，MX 多一列 PRIORITY。

域名不存在返回 NXDOMAIN 时，answers 为空数组，rcode 字段为 "NXDOMAIN"，不要报错退出码 0。DNS 服务器连不上退出码 1，stderr 打 "dns server unreachable: {address}"。查到 CNAME 链要跟踪解析到底，每一跳都列出来。项目拆成至少 3 个 Go 源文件：主入口、核心逻辑、数据模型分开。Go 标准库，命令行参数用 flag 包解析。
