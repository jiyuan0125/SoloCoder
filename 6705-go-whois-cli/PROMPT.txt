手上有三十几个域名要续费管理——每次登注册商后台查过期时间，三十几个域名要点三十几次，眼睛都花了。还有时候需要查一段 IP 的归属信息。做个 WHOIS 查询工具，批量搞定。

命令行：域名查询 `whoisctl domain example.com` 或批量 `whoisctl domain --file domains.txt`。IP 查询 `whoisctl ip 8.8.8.8` 或 `whoisctl ip --range 192.168.1.0/24`。批量文件每行一个域名或 IP，支持注释行（# 开头）。

输出格式：每个查询结果输出 registrar（注册商）、creation_date、expiration_date、name_servers（逗号分隔）、status。加 `--json` 输出结构化 [{query, type, registrar, created, expires, nameservers[], status, error}]。过期时间在 30 天内的标红并打印 "⚠ EXPIRING SOON"。

查询超时 `--timeout` 默认 10 秒。查询失败不中断批量任务，在结果中 error 字段记录原因。文件不存在退出码 1。所有查询失败退出码 2。部分失败退出码 0 但 stderr 打印失败数。

Go 实现，只用标准库，交叉编译友好。
不要写成一个 main.go 搞定所有事情。按职责拆文件：入口、解析、处理、输出分开。
