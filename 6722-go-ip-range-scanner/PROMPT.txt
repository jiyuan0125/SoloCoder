上个月内网安全扫描，运维手动 ping 了三个小时才扫完一个 C 段，效率太低了。需要一个能快速扫大段网络的工具。

输入 CIDR（如 10.0.0.0/8）或 IP 范围（如 192.168.1.1-192.168.1.254），用 `-cidr` 或 `-range` flag 指定。`-concurrency` 控制并发数，默认 100。每个 IP 发 ICMP 或 TCP SYN 探测（`-mode icmp|tcp`，tcp 模式用 `-port` 指定端口，默认 80），记录响应时间。

结果输出到 stdout，格式为表格：IP 地址、状态（alive/dead）、响应时间（ms）。用 `-o result.json` 输出 JSON 数组，每项 `{"ip":"...","alive":true,"latency_ms":12}`。同时自动生成 `scan_report.txt` 摘要文件，包含扫描起止时间、总 IP 数、存活数、平均/最大/最小响应时间。如果没扫到任何存活主机，报告里写 "0 hosts alive" 而不是空文件。

空输入或非法 CIDR 打印 "invalid input: <reason>" 并 exit 1。`-timeout` 单个探测超时默认 1 秒。扫描进度实时显示 "scanning: 1024/65536 (1.6%), alive: 23"。Go 标准库实现，交叉编译友好，`go build -o scanner` 出单二进制。
