排查网络问题最烦的就是看路由表——`route -n` 输出的列对不齐、网段掩码混在一起，macOS 的 `netstat -rn` 格式又不一样。两个系统来回切换简直折磨。

`routeread` —— Go CLI 跨平台路由表解析工具。`routeread show` 读取系统路由表，格式化输出表格：`DESTINATION  GATEWAY  INTERFACE  METRIC  FLAGS`。Linux 从 `/proc/net/route` 和 `ip route` 解析，macOS 从 `netstat -rn` 输出解析。加 `--json` 输出 JSON：`[{"dest":"0.0.0.0/0","gw":"192.168.1.1","iface":"eth0","metric":100,"flags":"UG"}]`。

`routeread lookup -d 10.0.1.5` 模拟路由查找，输出匹配的路由条目和出口接口。`routeread diff --old routes.json --new routes.json` 对比两次路由快照差异，显示新增/删除/修改的路由。

默认路由（`0.0.0.0/0` 或 `::/0`）高亮标黄。没有默认路由时输出 `[WARN] no default route found`。IPv6 路由同样支持，自动检测。接口不存在（路由指向已删除的网卡）标红 `[STALE] iface=<name> not found`。

`routeread monitor --interval 5s` 每 5 秒刷新一次路由表，变化时输出 diff。Ctrl+C 优雅退出。

Go 实现，只用标准库，交叉编译友好。`go build` 生成单二进制。退出码 0 成功，1 路由表读取失败，2 参数错误。
拆成至少三个 Go 文件：main.go 做入口和参数解析，核心处理逻辑独立一个文件，工具函数单独放。
