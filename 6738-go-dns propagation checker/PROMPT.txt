域名 DNS 记录改了之后，全球生效要多久心里没数，用户已经在投诉了。这个工具查询一批分布在各地的公共 DNS 服务器（默认 10 个：8.8.8.8、1.1.1.1、8.8.4.4、9.9.9.9、208.67.222.222 等），对比它们返回的记录是否跟预期值一致，算出传播百分比。

用法：`dnscheck <域名> <记录类型> <期望值> [--servers <文件>] [--timeout 5s] [--json]`。记录类型支持 A、AAAA、CNAME、MX、TXT。`--servers` 指定自定义 DNS 服务器列表文件，每行一个 IP:PORT，不指定用内置列表。

输出格式：表格，每行 `DNS服务器  返回值  是否匹配  响应时间`。最后汇总 `传播进度: X/Y (Z%)  平均响应: Nms`。`--json` 输出 JSON `{"domain":"...","type":"A","expected":"1.2.3.4","total":10,"matched":8,"percentage":80,"servers":[{"ip":"8.8.8.8","result":"1.2.3.4","match":true,"rtt_ms":12}]}`。

全部匹配退出码 0，部分匹配退出码 1，全部不匹配退出码 2，DNS 查询超时退出码 3。超时时间通过 `--timeout` 设置，默认 5 秒。

查询超时的服务器在表格里标记 `TIMEOUT`，不算入匹配统计。域名格式不合法时 stderr 输出 `ERROR: invalid domain: <域名>` 退出码 4。

用 Go 标准库写，go run . 或 go build 都行。
至少拆成两个包或三个文件以上，不要单文件一把梭。
