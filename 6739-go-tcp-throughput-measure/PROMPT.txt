新拉的专线标称 1Gbps，实际能跑多少得自己测。TCP 吞吐量测试工具，一个二进制包揽 client 和 server，多连接并行聚合吞吐。

远端起服务端：`tcp-throughput --mode server --port 5201`，客户端打流量：`tcp-throughput --mode client --host remote:5201 --duration 10s --buffer-size 64KB --connections 4`。`--buffer-size` 从 4KB 到 1MB 可调，小缓冲测延迟影响，大缓冲测带宽上限。

客户端输出分三个阶段：预热阶段（前 2 秒不计入统计）、稳定测量阶段（每秒输出当前吞吐量 `1.2 Gbits/s`）、总结阶段。总结包括：平均吞吐量、峰值吞吐量、最低吞吐量、总传输字节数、重传次数（如果系统支持读取）。`--unit mb` 指定输出单位（kb/mb/gb），默认 mb。

`--csv throughput.csv` 每秒一条记录导出时间序列数据，字段：`timestamp,bytes_sent,throughput,connections_active`。服务端没收到数据超过 5 秒自动退出。

客户端连不上服务端 3 秒超时报 "connection refused" 退出码 1。`--mode` 不指定也报错 "must specify --mode server or client"。纯 Go 标准库，编译后单二进制可以直接跑。
