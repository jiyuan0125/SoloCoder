测试环境要验证重试逻辑在弱网下表现如何，但真实丢包不可控。需要一个能按指定概率丢包的工具，用完还能恢复——这东西肯定要 root 权限，操作 tc 命令没权限就别想了。

命令用法分三个子命令。inject：pkt-loss inject -iface eth0 -rate 0.1 -duration 60s，-iface 指定网卡名，-rate 丢包率 0.0 到 1.0，-duration 持续时间到后自动恢复。restore：pkt-loss restore -iface eth0，手动移除丢包规则。status：pkt-loss status -iface eth0，显示当前网卡上的丢包规则详情。底层用 tc netem 命令实现，丢包规则挂在该网卡的 root qdisc 上。执行前先检查 tc 命令是否可用，不可用输出 "tc command not found" 退出码 1。

inject 时先把当前 qdisc 配置保存到临时文件 /tmp/pkt-loss-<iface>.bak，恢复时从备份还原。程序收到 SIGINT 或 SIGTERM 信号时自动执行恢复逻辑，防止丢包规则残留。支持过滤条件：-src-port 8080 只对目标端口丢包，-protocol tcp 只对 TCP 生效，可组合使用。status 输出包含：丢包率、过滤条件、已持续时间和剩余时间。非 root 执行时输出 "permission denied, require root" 退出码 1。

Go 标准库，命令行参数用 flag 包解析。
代码分文件组织，解析器、处理器、输出器分开，main.go 只做参数解析和流程串联。
