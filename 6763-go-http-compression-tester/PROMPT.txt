页面加载突然变慢，抓包一看响应全是明文——压缩根本没开。这个工具发带 Accept-Encoding 的请求，验证服务端压没压缩，算出压缩效率。

用法：`comptest -url https://example.com/api/data -encodings gzip,br,deflate`。`-url` 必填，`-encodings` 用逗号分隔要测试的编码方式，默认 `gzip`。支持 `-H "Authorization: Bearer xxx"` 传自定义请求头。

输出 JSON：`{"url":"...","results":[{"encoding":"gzip","compressed":true,"original_size":20480,"compressed_size":5120,"ratio":0.75,"content_type":"application/json"}]}`。ratio 是节省比例（0-1），compressed 为 false 时 compressed_size 等于 original_size，ratio 为 0。

`-verbose` 时额外打印请求头和响应头到 stderr。没加 `-url` 时输出 usage 并 exit 1。URL 无法连接时 stderr 输出 `error: connection failed: {url}` 并 exit 1。非 2xx 时 exit 2 并输出状态码。成功 exit 0。超时默认 10 秒，`-timeout` 可调。

纯 Go 标准库，`go build -o comptest .` 编译后单二进制直接跑。
代码分文件组织，解析器、处理器、输出器分开，main.go 只做参数解析和流程串联。
