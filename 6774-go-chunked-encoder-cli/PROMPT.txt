调了半天流式上传接口，服务端说收到的 chunked 数据格式不对，但肉眼看二进制根本看不出哪截多了一位少了一位。得有个工具把数据编解码来回转，编码时按指定 chunk size 切分，解码时逐块校验，格式错了精确定位到字节偏移。

两个子命令：`encode` 把 stdin 转成 chunked 格式输出到 stdout，`decode` 反过来。`echo "hello world" | ./chunked encode` 输出 `b\r\nhello world\r\n0\r\n\r\n`。`./chunked decode < chunked_input.txt` 还原原始内容。

chunk 大小用 `-chunk-size 1024` 指定，默认 8192 字节。也支持从文件读取：`./chunked encode -i body.txt -o body_chunked.txt`。管道模式友好——可以 `cat data.bin | ./chunked encode | curl -X POST --data-binary @- http://localhost/upload`。

decode 遇到格式错误的 chunked 流打印 "invalid chunked encoding at byte offset <n>: <reason>" 并 exit 1。encode 输入为空直接输出终止标记 `0\r\n\r\n`。大文件处理用流式读写，内存占用不超过 chunk-size。

用 filepath.Walk 批量处理目录下所有文件：`./chunked encode -dir ./raw/ -outdir ./chunked/`，保留原文件名加 `.chunked` 后缀。

Go 标准库，交叉编译友好。
