你有没有遇到过 CI 流水线跑一半挂了，查了半天发现是下载的依赖包损坏了？这种问题隐蔽得很，文件大小看着对但内容不完整，hash 对不上。与其每次手动 sha256sum，不如让下载和校验一步到位。

工具的用法：`dlcheck -url https://example.com/file.tar.gz -hash abc123def456 -algo sha256`。-url 是下载地址，-hash 是预期的哈希值，-algo 支持 md5、sha1、sha256，默认 sha256。三个参数至少要有 -url 和 -hash，-algo 可以不填。

下载流程：先下载文件到临时文件（URL 最后一段作为文件名，取不到就叫 `download`），下载过程中打印进度 `downloading... <已下载字节数>/<总字节数>`（总字节数从 Content-Length 获取，取不到就不显示分母）。下载完成后计算哈希，和预期值对比。校验通过输出 `OK: <文件名> <算法> matched` 退出码 0，校验失败输出 `MISMATCH: expected <预期值> got <实际值>` 然后删掉已下载文件，退出码 1。

网络错误输出 `error: download failed: <具体错误>` 退出码 1。URL 格式不对输出 `error: invalid URL` 退出码 1。下载超时 60 秒可配置 `-timeout`。

用 Go 标准库写，go run . 或 go build 都行。代码拆成至少两个文件：下载逻辑和哈希校验分开。
