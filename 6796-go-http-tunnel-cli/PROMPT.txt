上周的故障排查了三小时才定位到——HTTP 隧道的认证配置有误，但没人知道连接到底走没走代理。如果有详细的连接日志，五分钟就能查完。

写个 HTTP CONNECT 隧道工具 `htunnel`。用法：`htunnel --listen :8080 --proxy http://proxy.corp.com:3128 --user admin --pass secret --target internal.db:3306`。它通过 HTTP CONNECT 方法建立隧道，将本地 TCP 连接转发到远程。支持代理认证（Basic Auth），通过 `--user` 和 `--pass` 指定。连接日志格式：`[2024-01-15 14:30:00] CONNECT internal.db:3306 via proxy.corp.com:3128 status=200`，认证失败记 `status=407`，代理不可达记 `status=ERR`。日志写到 stderr，加 `--log-file tunnel.log` 同时写文件。代理认证失败退出码 1 输出 `error: proxy authentication failed (407)`。目标不可达退出码 1 输出 `error: tunnel establishment failed: <status>`。用 Go 标准库写，`go run .` 或 `go build` 都行。
项目要用多文件结构，入口文件、业务逻辑、数据模型分开放，别揉在一个文件里。
