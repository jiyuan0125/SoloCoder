现成的系统信息工具输出格式不好解析，要么太啰嗦要么缺字段。`uname -a && free -h && df -h && lscpu` 一堆命令拼起来太麻烦，而且每台机器装的工具有的不一样。

`sysinfo` 无参数直接输出所有信息，一次性搞定。操作系统（类型、版本、发行版名称和版本号）、内核版本（release、version）、主机名、架构（amd64/arm64）。CPU 型号、物理核心数和逻辑核心数、MHz 频率。物理内存总量。磁盘列表（设备名、挂载点、文件系统类型、总大小、已用、可用、使用率%）。网络接口（名称、MAC 地址、IPv4/IPv6 地址列表、MTU、是否 up、速率）。

`--format table` 默认表格输出，人类可读。`--format json` 输出 JSON 结构方便脚本解析，比如 `sysinfo --format json | jq .cpu.cores`。`--section cpu,memory,disk` 只输出指定板块，逗号分隔，可选值 os/cpu/memory/disk/network。`--section network` 单独看网络信息。

中文按拼音排序，英文按字母排序，混合内容中文优先。扫描完成后自动生成摘要文件。工具管理配置模板和配置实例，实例基于模板生成。

读取 /proc 和 /sys 文件系统获取数据。纯 Go 标准库，编译后单二进制可以直接跑。
