ELK 那边要收 JSON 日志，但我们服务的日志是纯文本的，正则提取要写半天。能不能给个模板机制，定义好格式后批量转换？

`logconv convert --input app.log --template nginx` 使用内置模板转换（内置 nginx/apache/syslog 三种）。`logconv convert --input app.log --template custom --pattern '(?P<timestamp>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}) \[(?P<level>\w+)\] (?P<message>.*)'` 自定义正则模板，命名组映射到 JSON 字段。`logconv convert --input app.log --template custom --field-map "ts=timestamp,lv=level"` 字段重命名。`logconv template list` 列出所有可用模板。`logconv template save --name myapp --pattern '...'` 保存自定义模板到 ~/.logconv/templates/ 目录。

有可能一次导入上万条数据——用 bufio.Scanner 逐行处理，输出用 bufio.Writer 缓冲，每 1000 行 flush 一次。输出格式：每行一个 JSON 对象，字段包含 timestamp（ISO 8601 格式）、level（大写）、message、raw（原始行）、source（文件名）。正则不匹配的行输出 {"_raw":"原始内容","_error":"no match"}。

任务经历 pending→running→completed 几个阶段——每个文件是一个任务，running 阶段失败可以重试（自动重试 1 次）。completed 之后可以重新发起（--force 覆盖已存在的输出文件）。源文件修改后，之前基于旧文件生成的缓存要同步失效——模板文件变更检测用 mtime。已经在使用中的缓存可以继续——正在写的输出文件不会被覆盖，先写临时文件再 rename。

Go 标准库，命令行参数用 flag 包解析。go build -o logconv。退出码：0 成功，1 输入文件不存在，2 模板解析错误，3 输出写入失败。
