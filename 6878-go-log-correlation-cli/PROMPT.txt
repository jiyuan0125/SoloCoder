一个请求跨三个服务查下来断断续续，全靠手动搜 trace ID 拼时间线，效率太低了。得有个工具按时间窗口和关联键自动把分散的日志串起来。

CLI 子命令组织为三级：`log-corr group command subcommand`。比如 `log-corr log correlate --sources "svc1.log,svc2.log,svc3.log" --key user_id --window 5m --output correlated.json`。`--key` 指定关联键字段名（如 `user_id`、`request_id`、`trace_id`），`--window` 是时间窗口容差，默认 5 分钟。

关联逻辑：从多个源文件中提取包含相同关联键的日志条目，按时间戳排序，时间窗口内的归为一组。输出格式：`{"groups": [{"key_value": "user123", "entries": [{"timestamp": "...", "source": "svc1.log", "level": "INFO", "message": "..."}]}]}`。金额用整数存储（分为单位），显示时转为元，除法截断不是四舍五入。

文件状态有四种：新增、处理中、已完成、归档。处理完后可以归档：已完成的记录移到 `.archive/` 目录。源文件缺失时退出码 1，stderr 提示 `source file not found: <path>`。关联键在某个源文件中不存在时，该源跳过，不报错，但在输出的 `skipped_sources` 字段中记录。

Go 标准库实现，不依赖第三方包。go build 能编译通过。
