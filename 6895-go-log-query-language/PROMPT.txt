每次要统计日志都得写一段 Go 脚本——同一个需求不同人写了三遍。要是能直接对着日志文件跑 `SELECT count(*), level FROM log WHERE level='ERROR' GROUP BY hour` 这种 SQL 就好了。

1. 语法规则：SELECT 支持的字段有 count、sum、avg、min、max、distinct 及原始字段名。WHERE 支持 =、!=、>、<、LIKE、IN 操作符，用 AND/OR/NOT 连接。GROUP BY 支持 hour、minute、day 三个时间粒度和任意字段。ORDER BY 支持 ASC/DESC。LIMIT 限制返回行数。

2. 查询流程：先 `tool query --input log.txt --sql "SELECT ..."` 读入文件，解析 SQL，扫描匹配行，执行聚合，输出结果。也可以用 `tool explain --sql "SELECT ..."` 只显示解析后的执行计划不实际查询。`--output` 指定输出文件名，默认 stdout。

3. 任务状态机：查询进入队列后经历 waiting → running → success/failed/cancelled 五种状态。失败的查询用 `tool retry --id <query_id>` 重试，重试时保留原始 SQL。结果为零行时输出空表头不报错。

4. 错误处理：SQL 语法错误时 stderr 输出错误位置（行号、列号）和具体原因，退出码 2。字段不存在时提示 "unknown column: xxx"。不支持的操作符直接报 "unsupported operator"。

Go 标准库实现，go run . 或 go build 都行。
