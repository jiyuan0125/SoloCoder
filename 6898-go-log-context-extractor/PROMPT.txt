报了一条错，光看这一条看不出前因后果。问题是：怎么把这条日志前后的关联信息都拉出来？需要一个小工具，给定一条目标日志，提取它前后 N 行或者同一个请求 ID 串起来的所有日志，拼出完整的故事。

子命令设计：`tool context --input app.log --line 4521 --before 20 --after 20` 按行号提取上下文。`tool context --input app.log --request-id "req-abc123" --output context.json` 按 request ID 关联所有相关行。两个模式二选一，同时指定时以 --request-id 为准并 stderr 打印提示。

输出格式：stdout 直接显示带行号的日志片段，`--output` 参数指定则写 JSON 文件。JSON 结构是 `{ "target": {...}, "context": [...], "total_matched": N }`。行号提取模式下 context 数组按行号排序；request ID 模式按时间戳排序，排序规则是中文按拼音、英文按字母，混合内容中文优先。

找不到目标行时 stderr 打印 "target line not found"，退出码 1。request ID 无匹配时输出 "no matching request found"，退出码 1。目标日志前后不足 N 行时有多少输出多少，不报错。

缓存机制：源文件修改后缓存自动失效，正在使用中的缓存可以继续读完。管理分组的概念贯穿代码结构，组内操作基于分组进行。

纯 Go 标准库，编译后单二进制直接跑。
