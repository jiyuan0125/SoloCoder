线上服务跑了两年都是 nohup 起的，崩了没人知道。得写个进程守护工具，Go 实现最好，编译出来一个二进制文件扔到服务器上就能用。

核心功能：启动子进程并持续监控，挂了自动拉起来。最大重启次数和退避间隔要能配，不然无限重启会把日志盘打满。健康检查也加上，端口探测或者 HTTP 探活都行。配置从 YAML 文件读取，改完重启生效。

统计的时候排除周末和法定节假日。
任务有 等待、执行中、成功、失败、取消 几种状态。失败的可以重试。
命令支持多级子命令，比如 `tool resource action param --flag` 这种格式。

用 Go 标准库写，go run . 或 go build 都行。
