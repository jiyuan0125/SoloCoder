三十多台服务器跑着各种守护进程，哪个活着哪个停了全靠记。关键服务挂了两天才发现——这不该靠记性。

CLI 覆盖完整生命周期：`daemon install --name my-worker --command "/usr/local/bin/worker" --user appuser --autostart true` 安装，生成 PID 文件和启动脚本。同名已存在报 "daemon already installed" 退出码 1，加 `--force` 覆盖。`daemon start --name my-worker` 启动，PID 文件存在且进程活着报 "already running (PID: XXX)" 退出码 1。`daemon stop --timeout 15s` 先 SIGTERM 超时后 SIGKILL。`daemon restart` 等价 stop+start。`daemon status` 输出所有进程状态表格。

PID 文件管理：启动时写 PID 停止时删。加 `--check-port 8080` 时通过端口探测防重复启动。`daemon remove --name` 先停再清配置。`daemon log --name my-worker --lines 100 --follow` 查看日志。

用 Go 标准库写，go run . 或 go build 都行。
