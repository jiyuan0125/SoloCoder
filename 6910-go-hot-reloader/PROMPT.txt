每次改完代码手动重启太浪费时间。写个文件变更自动重启工具，监控目录文件一改就触发进程重启。

`hotreload start --watch ./src --command "go run ." --ignore ".git,vendor,node_modules" --debounce 500ms`。`--watch` 可多次指定。`--debounce` 防抖间隔默认 300ms。旧进程先 SIGTERM，`--kill-timeout 5s` 后 SIGKILL。`--health-check "http://localhost:8080/health"` 可选探活，连续失败 3 次 stderr 输出 "health check failed after restart"。

排除规则：`--ignore` 支持目录名和 glob（`*.swp`）。隐藏文件默认不触发。`--ext .go,.html` 只监控指定扩展名。`hotreload status` 显示监控目录、上次重启时间和重启次数。`hotreload log --last 20` 显示最近 20 次重启记录（timestamp/trigger_file/duration_ms/exit_code）。

已在运行再次 start 不报错先停旧再启新。Ctrl+C 停监控并杀子进程。路径不存在报 "watch path does not exist" 退出码 1。

纯 Go 标准库，编译后单二进制直接跑。
