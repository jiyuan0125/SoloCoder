每个月月初要批量跑 200 多个数据对账脚本，现在是一个人坐在那挨个执行、等结果、记状态。写个批量执行作业的工具，从文件读取作业列表，按顺序或并行执行，每个作业的状态和输出都记下来。执行完一看汇总就知道哪些成功了哪些失败了。

作业定义文件用 JSON 格式，每个作业包含 name、command、timeout（秒，默认 60）、retry（重试次数，默认 0）四个字段。CLI 用法：`batch-runner -f jobs.json -mode parallel -workers 4`，-mode 支持 sequential 和 parallel，parallel 模式下 -workers 控制并发数，默认 4。每个作业的超时到达后发 SIGKILL 终止，状态标记为 timeout。退出码非 0 标记为 failed，0 标记为 success，超时重试次数用尽仍失败标 timeout。运行结束后输出汇总 JSON 到 stdout，包含 total、success、failed、timeout 的计数，以及每个作业的 name、status、exit_code、duration_ms、output（截断到前 512 字符）。汇总中 failed 或 timeout 大于 0 时工具自身退出码为 1，全部成功退出码 0。作业列表文件不存在或 JSON 格式错误时输出 "invalid job file" 并退出码 2。

Go 实现，只用标准库，交叉编译友好。
至少拆成两个包或三个文件以上，不要单文件一把梭。
