测试和生产数据库结构不一样——发版漏了字段变更线上直接报错。`sqldiff -source dev.db -target prod.db` 输出三类差异。

纯文本按表分组：新增表 `[+] TABLE order_items`、删除表 `[-] TABLE legacy_logs`、修改的表 `[~] TABLE users\n    [+] column: email TEXT\n    [-] column: middle_name\n    [~] column: age INTEGER→BIGINT\n    [~] constraint: 无→UNIQUE(email)`。包含类型变化、约束变化（NOT NULL/DEFAULT/UNIQUE/PK）。

`-format json` 输出 JSON：`{"added_tables":[...],"modified_tables":[{"name":"users","added_columns":[...],"modified_columns":[{"name":"age","source_type":"INTEGER","target_type":"BIGINT"}]}]}`。`-output diff.txt` 写入文件。

数据库不存在输出 "database not found: XXX" 退出码 1。完全相同输出 "schemas are identical" 退出码 0。不支持非 SQLite。

需要用到 filepath.Walk 等标准库功能。Go 标准库实现，不依赖第三方包。go build 能编译通过。
