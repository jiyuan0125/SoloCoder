初始化数据库要插入 10 万条测试数据，一条一条 INSERT 跑了 20 分钟。写个批量数据插入工具，读 CSV/JSON 数据生成批量 INSERT SQL。batch size 要能配，一条 SQL 里放 1000 条还是 5000 条看数据库承受能力。去重也加上，重复的主键跳过不报错。

支持多个终端同时操作同一个数据目录。
任务经历 pending → running → completed 几个阶段。running 阶段失败可以重试。completed 之后可以重新发起。
子命令结构：`tool namespace resource action`，比如 `tool db table export`。

Go 标准库实现，不依赖第三方包。go build 能编译通过。
