先从两个 CSV 读销售数据，再从 JSON 拿产品信息，最后还得查 SQLite 里的用户表——四个数据源合成一份统一的数据集。字段名还不统一，这边叫 user_id 那边叫 uid，含义一样得映射到同一列。

CLI：`merger -config merge_config.json -output unified.csv`。配置文件格式：`{"sources":[{"path":"sales1.csv","type":"csv"},{"path":"products.json","type":"json"},{"path":"users.db","type":"sqlite","query":"SELECT * FROM users"}],"mapping":{"user_id":["uid","user_id","id"],"product_name":["name","product","pname"]},"output_format":"csv"}`。

mapping 里 key 是统一后的列名，value 数组是各来源对应的原始列名，按顺序匹配。统一 schema 后行数据按来源顺序拼接，加 `-dedup key_col` 可按指定列去重。

来源文件不存在时 stderr 报错 "error: source 'xxx' not found" 并 exit 1。SQLite 查询失败时 stderr 输出具体错误，exit 3。列名找不到时该列填空值。输出格式支持 csv 和 json。

文件可能很大，超过内存要能处理——用流式读写，不在内存中全量加载。

用 Go 标准库写，go run . 或 go build 都行。
