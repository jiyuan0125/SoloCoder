YAML 配置文件越来越多，类型错误靠肉眼根本看不出来。上周部署因为端口写成了字符串，排查了三小时。写个 Go 命令行工具：YAML 类型校验覆盖日期、时间、IP、URL，锚点引用解析要能检测循环引用，配置合并后检查 schema 合规性。顺带把数据完整性也校了——行数列数校验和都要算。证书续签后依赖该证书的 TLS 配置要同步更新。go build 能过，命令行工具能正常运行。

CLI：yamval check --schema types.yaml --data config.yaml --output report.json。schema 定义字段类型（date/time/ip/url/port/integer/float/string）和约束（range/pattern/enum）。

类型校验：date 匹配 YYYY-MM-DD 或 RFC3339，IP 用 net.ParseIP，URL 用 url.Parse 需含 scheme。失败报 "error: $.server.port expected integer, got string '8080'"。

锚点循环引用：遍历 anchor/alias 建图做拓扑排序，环报 "circular reference: anchor 'db' -> 'prod' -> 'db'"。

配置合并：--overrides prod.yaml 后者覆盖前者再过 schema。完整性校验对 CSV 算行数列数一致性、CRC32，--baseline 对比上次。

退出码：0=通过，1=失败，2=输入错误。空文件 {"valid":true,"warnings":["empty file"]}。
