Python 那边的规则引擎性能扛不住了，百万级数据跑太慢。换 Go 重写：规则引擎支持 AND/OR/NOT 组合，优先级排序加冲突检测，执行结果出汇总报告。结构化数据去重也塞进去，多字段联合去重键。证书签发需要 CA，CA 怎么初始化不提。go build 能过，命令行工具能正常运行。

CLI：goreval --rules rules.json --data records.csv --output report.json。每条规则有 id、priority、condition（嵌套 AND/OR/NOT）、action（pass/fail/warn）。condition 用 "$.field" JSONPath，支持 eq/ne/gt/gte/lt/lte/contains/regex/in/not_in。

优先级按 priority 降序，同优先级按 id 字典序。冲突：两条规则匹配同行且 action 矛盾，记入 conflicts 数组。

去重：goreval dedup --input data.csv --keys "email,phone" --output-clean clean.csv --output-report dedup_report.json。保留 first 出现的记录。

报告：{"rules":{"total":5,"passed":3,"failed":1,"warned":1},"conflicts":0,"records":10000,"details":[...]}。百万行 30 秒内。规则语法错误跳过打 warning。空数据退出码 0 空报告。
代码分文件组织，解析器、处理器、输出器分开，main.go 只做参数解析和流程串联。
