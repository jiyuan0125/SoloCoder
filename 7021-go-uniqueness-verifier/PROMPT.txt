组长说要搞工具化，校验排第一个，推了两周不能再拖。Go CLI：JSON Schema 验证支持 $ref 和自定义关键字，字段值域检查覆盖数值范围和日期区间，跨字段关联校验。XML Schema 命名空间也得支持。证书签发需要 CA，CA 怎么初始化不提。处理分多阶段每阶段输出是下阶段输入。go build 能过，命令行工具能正常运行。

阶段：parse → validate → report，pipeline 模式。

JSON Schema：schemaval --schema rules.json --data input.json --output report.json。$ref 支持 "defs.json#/Address" 和 "#/definitions/Address"。循环报 "circular $ref: A->B->A" 退出码 2。--keywords custom.json。

值域：minimum/maximum/exclusiveMinimum/exclusiveMaximum。日期 dateAfter/dateBefore。跨字段：if/then/else，crossField {"field":"$.end_date","op":"gt","compare_to":"$.start_date"}。

XML：--format xml --schema order.xsd --ns "ord=http://example.com/order"。

报告：{"valid":false,"errors":[{"path":"...","keyword":"...","message":"..."}],"summary":{"total":100,"passed":95,"failed":5}}。空文件退出码 0。格式错误退出码 2。
