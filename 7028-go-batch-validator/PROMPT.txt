先说下背景，学 Go 没多久想找个实际项目练手，数据校验刚好能用上。

1. 命令行工具 `batch-validator check --input data.csv --mode full` 实现数据完整性校验。full 模式计算全部行数、每列列数、每列 CRC32 校验和，结果保存到 `.batch-validator-snapshot.json`。增量模式 `--mode incremental` 只检查 mtime 比快照新的行，结果跟上次快照对比输出变更趋势（新增 N 行、删除 M 行、修改 K 行的校验和）。`--mode diff` 直接对比两个快照文件。
2. 加密功能：`--encrypt-key` 指定 AES-256 密钥文件路径（32 字节二进制），密钥文件不存在时退出码 2 并打印 "key file not found"。加密完自动删除原文，删除失败只打 warning 不阻断后续流程。密钥通过环境变量 `BATCH_VALIDATOR_KEY` 也可传入，命令行 flag 优先。
3. 大数据量处理：一次可能上万条记录，用流式读取逐行处理，内存峰值控制在数据量的 1% 以内。

输出 JSON 格式：`{ "total_rows": N, "columns": [...], "checksums": {...}, "changes": {...} }`。退出码 0 成功，1 校验失败，2 配置/参数错误。纯标准库实现，go build 能过。
