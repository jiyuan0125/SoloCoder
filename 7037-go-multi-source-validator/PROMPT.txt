Go 重写 `multi-source-validator` 命令行工具，分三个处理阶段顺序执行。阶段一 `profile`：分布统计输出 min/max/mean/median/stddev，TopN 计算 `--top-n 10` 每列高频值，基数估算用 HyperLogLog。阶段二 `compare`：`--expected baseline.json` 对标偏差，`--tolerance 0.15` 超过 15% 标记异常。阶段三 `cross-check`：`--primary master.csv --secondary detail.csv --foreign-key id` 多文件交叉校验。前一步失败不继续后续阶段。

证书签发场景保留但不展开——命令行预留 `--ca-cert` 和 `--ca-key` 参数占位。处理分多个阶段，每阶段输出 JSON 数组作为下阶段输入，管道式串联。大文件流式处理，内存峰值不超 150MB。

CLI 用法：`multi-source-validator run --input data.csv --expected baseline.json --cross-source detail.csv --foreign-key id`。输出 JSON 包含三个阶段结果：`{ "profile": {...}, "comparison": {...}, "cross_check": {...} }`。退出码 0 成功 1 数据异常 2 输入错误。纯标准库实现，go build 能过。
