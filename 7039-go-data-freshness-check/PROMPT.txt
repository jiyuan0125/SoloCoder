群里运营同学天天问有没有自动校验工具，手动改规则太容易出错——上周有人手滑把正则写反了，一整天数据没拦住。

Go 命令行工具 `data-freshness-check` 实现校验规则版本管理。子命令 `rules init --dir ./rules` 创建规则仓库，规则文件为 YAML 格式含 name、version、expression、priority。`rules diff --old v3 --new v4 --sample 200` 变更前用 200 条样本数据评估影响范围，输出 affected_count 和每条差异。`rules rollback --version v3` 从 `.freshness-history/` 恢复指定版本。灰度校验 `check --rules ./rules --data input.csv --range 0-50` 只取前 50 行试水，通过后再跑全量。CSV 列类型自动推断采样前 100 行判断 int/float/string/date。

令牌管理：令牌状态机 created → active → refreshed → expired → revoked，`--token-file` 指定持久化路径。字段值遇到奇怪格式不崩溃，记录到 parsing_errors 数组含行号、列名、原始值。

输出 JSON：`{ "rules_version": "...", "result": {...}, "parsing_errors": [...], "range_test": {...} }`。退出码 0 成功 1 校验失败 2 配置错误。纯标准库实现，go build 能过。
