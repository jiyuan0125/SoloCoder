`mutation-detector check --schema schema.yaml --data config.yaml --base baseline.yaml` 把 YAML 类型校验、锚点循环检测、配置合并验证和数据完整性一股脑全做了。类型校验覆盖日期（RFC3339）、时间（HH:MM:SS）、IP（v4/v6）、URL（带 scheme）。锚点引用解析检测循环并输出引用链，配置合并后验证 schema 合规性。完整性这边算行数、列数、每列 CRC32，结果跟 baseline.yaml 快照对比，变更项标明 field、old_value、new_value。

密钥路径 `keys/{algorithm}/{key_id}/versions/{ver}`，algorithm 支持 AES/RSA/ECDSA，ver 整数版本号，列出时按 version 降序。批量校验并发执行 `--workers 4`（默认 runtime.NumCPU()），结果按输入文件顺序汇总，乱码行跳过不阻塞。

输出 JSON：`{ "type_errors": [...], "anchor_errors": [...], "integrity": { "rows": N, "checksums": {...}, "changes": [...] } }`。退出码 0 通过 1 校验失败 2 配置错误。纯标准库实现，go build 能过。
