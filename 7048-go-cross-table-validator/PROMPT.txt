新项目数据完整性是硬性要求，不过校验不能上线。

Go 命令行 `cross-table-validator` 三种模式搞定完整性校验。`check --input data.csv --mode full` 算行数、每列列数、CRC32 校验和，结果存到 `.cross-table-snapshot.json`。`--mode incremental` 只检查 mtime 比快照新的行，输出 changes 含 added_rows、deleted_rows、modified_checksums。`--mode diff --snapshot-old a.json --snapshot-new b.json` 对比两个快照。审计日志按 `audits/{year}/{month}/{day}/{id}.json` 自动写入，记 timestamp、input_file、result。日志目录不存在自动创建，写入失败打 warning 不中断。`--archive output.zip` 把报告打包成 zip，内含 report.json + checksums.json，用 archive/zip 读写。

输出 JSON：`{ "total_rows": N, "columns": [...], "checksums": {...}, "changes": {...} }`。退出码 0 成功 1 校验失败（增量模式下有变更）2 配置错误。纯标准库实现，go build 能过。
至少拆成两个包或三个文件以上，不要单文件一把梭。
