CTO 上周刚定下来，数据平台第一步先把增量计算搞定。Go CLI 实现两块：对比两个数据集的差异，变更类型标记新增/修改/删除，差异合并策略；分组聚合做 sum/avg/count/max/min。扫描有排队→扫描中→分析中→报告生成→完成五个状态。

增量对比：`merge-datasets diff --old baseline.csv --new latest.csv --key id --output diff.json`，输出 JSON 数组，每条格式 `{"key":"xxx","type":"added","old":null,"new":{...}}`，type 精确为 added/modified/deleted，modified 逐字段对比值不同才算。合并：`merge --diff diff.json --strategy apply --output merged.csv`，strategy 选 apply（全部应用）或 selective（`--types added,modified` 选择性应用）。聚合：`aggregate --input data.csv --group-by region --metric sum:amount,avg:price --output agg.json`。

输入 CSV/JSON 均支持，diff 输出固定 JSON。`--key` 列不存在报 `error: key column not found` 退出码 1。两个数据集 key 列有重复值时报 `error: duplicate key: xxx` 退出码 1。空数据集 diff 结果全为 added 或 deleted。聚合空值填 null。输入常见格式都支持。go build 能过，纯标准库。
代码要模块化：主流程、具体功能实现、辅助函数分开存放，主文件只做调度。
