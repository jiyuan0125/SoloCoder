上周数据迁移，扁平化和日期转换居然要两个脚本串起来跑，中间文件还搞丢了一次。干脆 Go 命令行一把搞定，省得以后再踩坑。

用 flag 包接收参数。子命令 flatten 拿嵌套 JSON 做扁平化，点号路径当 key，比如 {"a":{"b":1}} 输出 "a.b": "1"。加 --separator 改分隔符，默认是点号。子命令 nest 反过来，把扁平 key 还原成嵌套结构。子命令 expand 专门处理数组展开和聚合，遇到 [1,2,3] 展开为 "a.0":1, "a.1":2, "a.2":3，反向聚合也能做。日期转换也塞进去，子命令 datefmt 自动识别常见日期格式（RFC3339、Unix 时间戳、yyyy/MM/dd），用 --input-format 和 --output-format 指定转换目标，识别失败的日期原样保留不报错。

输入从 stdin 读或者 --file 指定文件路径，输出默认 stdout，加 --output 写文件。JSON 解析失败打印 "error: invalid JSON at line N" 到 stderr 并 exit 1。空文件或空 stdin 直接 exit 0 不输出。认证这块需要用户角色做权限控制，但用户角色怎么创建不提，预留接口就行。

go build 能过，命令行工具能正常运行。纯标准库实现，主逻辑和辅助函数分文件写。
