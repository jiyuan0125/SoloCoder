新来的同事问"订单表的 amount 字段对应接口里哪个字段"，没人能说清楚。字段映射规则全靠口口相传，得有个工具统一管理映射关系。

这个 CLI 工具管理字段映射配置：源字段到目标字段的对应关系、类型转换（string→int、string→float64、string→time.Time RFC3339、string→bool，`"true"/"yes"/"1"` 为真，其余为假）、默认值填充（源字段缺失时用 `--default "field:value"` 指定的默认值）。

命令：`xmlmapper map --config mapping.yaml --input data.json --output result.json`。配置文件 YAML 格式：每个映射项含 `source`（源字段路径，支持 `a.b.c` 点号嵌套）、`target`（目标字段名）、`type`（目标类型，不填则原样复制）、`default`（可选默认值）、`required`（布尔，为 true 时源缺失则报错）。

`xmlmapper validate mapping.yaml` 校验配置文件格式和类型转换是否合法。`xmlmapper diff --config mapping.yaml --input sample.json` 对比一条样本数据的映射前后差异。

转换完自动写入目标文件，目标路径不可写时输出 `warning: cannot write to target, result printed to stdout`，不报错退出码仍为 0。输入 JSON 解析失败退出码 1，输出具体解析错误位置。`go build` 能过，命令行工具正常运行。
