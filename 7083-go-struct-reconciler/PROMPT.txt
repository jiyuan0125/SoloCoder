旧的数据转换工具扁平化之后丢了嵌套信息，下游系统解析不了，出了两次线上事故才下定决心重写。

现在要做一个 Go CLI 叫 `structrecon`，解决 JSON 结构互转的问题。子命令 `flatten` 把嵌套 JSON 用点号路径展开成扁平键值对——比如 `{"a":{"b":1}}` 变成 `{"a.b":1}`，嵌套数组用 `a.0.b` 的方式索引。`nest` 反过来，把点号路径的扁平数据重建回嵌套结构。`expand` 专门处理数组展开聚合，把同前缀的键合并成数组。三个子命令都支持 `--input file.json` 和 `--output result.json`，不指定就 stdin/stdout。遇到类型冲突（同一个路径既是数字又是对象）输出警告到 stderr 并跳过该字段。日期格式自动识别转换——`2024-01-15`、`2024/01/15`、`Jan 15, 2024` 这几种常见格式要能互相转换，用 `--date-format` 指定目标格式。消息格式升级后旧的消费者要能兼容处理，遇到新增字段不报错直接透传。处理分多个阶段，每个阶段输出是下个阶段输入，阶段之间用管道衔接。纯标准库实现，go build 能过，命令行工具能正常运行，退出码 0 成功 1 参数错误 2 数据处理失败。空 JSON 数组输入输出空数组不报错，深层嵌套超过 20 层给警告但继续处理。
