死锁一周出了三次，DBA 说查不到哪个事务占了锁不放，日志里全是 Lock Wait Timeout。再加上审计新规要求加合规检查，双管齐下赶紧搞。 ——— 子命令 import 把 CSV 导入 SQLite，--csv 指定输入文件，--db 指定数据库路径，已存在的表用 --mode 冲突处理：skip 跳过重复行，upsert 覆盖更新，abort 遇到冲突直接退出并 exit 2。导入过程中每 1000 行打印进度 "imported N rows..." 到 stderr。子命令 analyze 分析锁等待，输出按等待时间降序排列，列包括 session_id/lock_type/wait_seconds/blocking_query，默认 top 20，--limit 可调。 ——— 合规检查用子命令 audit，扫描长事务（超过 --threshold 秒，默认 60）和未提交事务，结果输出到 --report 指定的文件。报告模板用 --template 指定路径，模板文件不存在就跳过模板渲染，直接输出纯文本。字段值格式容错：时间列解析失败标 "INVALID_DATE"，数值列解析失败标 "PARSE_ERROR"，不要直接 panic。空 CSV 输出 "warning: empty input" 到 stderr 并 exit 0。 Go 命令行工具，go build 能过就行，纯标准库实现。
