这个工具关注数据库索引健康和备份安全。命令 `reindex-tool`，子命令：`analyze`、`backup`、`restore`、`check`。`analyze --db app.db` 扫描所有索引，输出每个索引的碎片率、叶子页数、深度，格式为表格。加 `--json` 切换为 JSON 输出 `{"indexes": [{"name": "idx_orders_date", "table": "orders", "fragmentation": 0.72, "leaf_pages": 150, "depth": 3}]}`，碎片率超过 `--threshold 50`（默认 50%）的标红并建议 REINDEX。

`backup --db app.db --output backup.sql --mode full`：full 模式做完整 SQL dump，`--mode incremental --since backup.sql` 做增量备份（对比上次备份后的变更）。`restore --input backup.sql --db restored.db --verify` 恢复并自动验证（对比原库和恢复库的表数量与行数）。`check` 子命令做 SQL 静态分析：未使用索引、SELECT *、缺失 WHERE。

任务状态：registered → queued → executing → success / failed → retrying。每个状态变更输出一行日志 `[STATE] task_id=xxx old=xxx new=xxx`。备份文件写入失败（磁盘满）exit code=2，SQL 语法错误 exit code=3。支持 CSV 和 JSON 输入。go build 能过就行。
