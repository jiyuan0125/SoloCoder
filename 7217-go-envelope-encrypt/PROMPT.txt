密钥分片逻辑散在五个 Python 文件里，改一处坏三处。Go 重写，Shamir Secret Sharing、门限恢复、分片验证、密码哈希（bcrypt/scrypt）。

Shamir 分片：`env-enc split --input master.key --threshold 3 --shares 5`。GF(256) 拉格朗日插值，每个字节独立构造多项式。输出 5 个 JSON 文件 `share_N.json`：`{index, data(base64), threshold, total}`。随机系数 `crypto/rand` 生成。

门限恢复：`env-enc recover --shares "share_1.json,share_3.json,share_5.json"` 拉格朗日插值。分片数不足阈值报错退出码 1。结果十六进制输出到 stdout。

分片验证：`env-enc verify share_2.json` 检查 JSON 结构完整性——index 范围、base64 合法性、threshold ≤ total。输出 `{valid, index, threshold}`。

密码哈希：`env-enc hash-password --password "xxx" --algo bcrypt` 输出标准模块字符串。bcrypt cost 默认 12，scrypt 用标准参数。

数据转换需要映射模板？本工具只处理密钥和分片，不做通用数据转换。`go build` 能过，命令行工具能正常运行。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
