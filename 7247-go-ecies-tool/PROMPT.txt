密钥分片逻辑散在五个 Python 模块里，互相依赖搞不清。Go 重写，Shamir Secret Sharing 密钥分片、门限恢复、分片验证。

Shamir 分片：`ecies split --input master.key --threshold 3 --shares 5`。GF(256) 上构造随机多项式，常数项是密钥的每个字节。输出 5 个 JSON 文件 `share_N.json`，每个包含 `index`（1-5）、`data`（base64）、`threshold`、`total`。随机系数用 `crypto/rand`。

门限恢复：`ecies recover --shares "share_1.json,share_3.json,share_5.json"`。拉格朗日插值恢复密钥。分片数 < threshold 直接报错退出码 1。恢复结果十六进制输出到 stdout。

分片验证：`ecies verify share_2.json`。检查 JSON 结构完整性：index 范围、base64 合法性、threshold ≤ total。输出 `{"valid": true, "index": 2, "threshold": 3}`。

认证通过后自动记录日志？本工具不做认证。但操作记录可以写到 `~/.ecies/audit.log`，每行记录时间戳、操作类型、分片索引（如果适用）。日志写入失败不影响主流程。输出格式默认 JSON。

`go build` 能过，命令行工具能正常运行。
