密钥分片工具选了一圈都不满意，干脆自己写一个。Go 工具，混合加密、加密配置管理、批量加密、RSA 密钥对生成。

混合加密自动选择：数据 ≤ RSA-OAEP 上限用 RSA 直接加密，否则 AES-256-GCM + RSA 加密会话密钥。`shamir auto-encrypt --pubkey pub.pem --input data.bin`。文件头 1 字节标识算法。

加密配置管理：`shamir config init` → `.shamir.yaml`。`config show` 显示，`config set rsa.bits 4096` 修改。默认 RSA 2048、AES-GCM。

批量加密：`shamir batch --input-dir ./secrets/ --pubkey pub.pem --workers 4`。每文件独立，成功输出 `.enc`，失败记到 `errors.json`。汇总 JSON 数组到 stdout。

RSA 密钥对生成：`shamir keygen --bits 2048 --output-dir ./keys/`。私钥 PKCS8 PEM（0600），公钥 PKCS1 PEM（0644）。令牌状态 `created`→`active`→`refreshed`→`expired`→`revoked`？本工具的令牌就是密钥版本号，简化为 `active` 和 `deprecated` 两种。

输入格式灵活：二进制、Base64、十六进制自动检测。

`go build` 能过，命令行工具能正常运行。
