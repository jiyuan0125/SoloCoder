Java 服务和 Go 服务用的密钥格式不统一，跨语言调用经常报 key format error。做个密钥格式转换工具，PKCS12/PKCS8、PEM/DER、密钥格式标准化。Go CLI。

PKCS12：`keylog from-p12 --input client.p12 --password "xxx" --output-dir ./out/`。`keylog to-p12 --cert c.pem --key k.pem --ca ca.pem --output client.p12`。

PEM↔DER：`keylog pem-to-der --input cert.pem --output cert.der`。`keylog der-to-pem --input cert.der --type certificate --output cert.pem`。

标准化：`keylog normalize --input key.pem --output standard.pem`。统一 PKCS8 PEM。

校验三阶段：格式校验（文件格式是否合法）→ 规则校验（密钥长度是否达标）→ 关联校验（密钥是否在库中注册）。前一步通过才做下一步。扫描多个目录并行处理。

`go build` 能过，命令行工具能正常运行。
拆成至少三个 Go 文件：main.go 做入口和参数解析，核心处理逻辑独立一个文件，工具函数单独放。
