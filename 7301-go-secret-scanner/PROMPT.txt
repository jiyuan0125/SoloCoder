上个月代码审查的时候，有个同事不小心把 AWS Secret Key 提交到了公开仓库，幸亏安全团队发现得早，不然这事儿就大了。从那以后我们就想做一个自动化的敏感信息扫描工具，用 Go 标准库写，命令行直接跑。

扫描能力要覆盖常见的敏感信息类型，包括 API Key、密码明文、各种 Token（OAuth、JWT、Refresh Token）。检测方法上不能只靠正则，因为有些 Key 格式不固定，所以还得加上熵值分析——高熵字符串大概率是密钥类内容。两种方法结合起来，正则负责已知的格式模式，熵值负责兜底捕捉那些格式不规律的敏感字符串。误报率要控制在合理范围内，扫描结果要区分高、中、低三个置信等级，让使用者能快速定位真正的问题。

配置审计这块也需要覆盖，主要查硬编码密码和不安全的默认值。比如配置文件里写死了 admin/admin 这种默认账号，或者数据库连接串里明文带着密码，都应该识别出来。扫描结果以 JSON 格式输出，每条结果包含文件路径、行号、匹配到的内容片段和置信等级。

有个注意点：证书续签之后，所有依赖该证书的 TLS 配置项需要同步更新，扫描器要能识别出这种过期的证书引用。扫描的时候支持递归目录遍历，可以用 --depth 控制递归深度，--exclude 排除不需要扫描的目录（比如 vendor、node_modules）。go build 能过，命令行工具能正常运行。
