之前信息安全审计用的是个 Python 脚本，跑一次全仓库扫描二十分钟起步，还经常因为编码问题中途崩掉。用 Go 重写一个安全扫描审计工具，核心功能是 SBOM（软件物料清单）生成。

SBOM 要能解析项目所有的直接依赖和间接依赖，输出格式同时支持 SPDX 和自定义 JSON 两种。SPDX 输出里要包含包名、版本号、许可证声明、下载地址、SHA256 校验和，每个字段缺失都要在结果里标注出来。JSON 格式更灵活一些，把依赖树的层级关系也带进去——哪个是直接依赖、哪个被谁间接引入、传递路径是什么样的，这棵树要完整。依赖树的可视化输出一个缩进格式的文本树形结构，让用户一眼能看清依赖层级和引入路径。

扫描过程中用 filepath.Walk 递归遍历项目目录，自动识别 go.mod、package.json、pom.xml 等不同语言的依赖文件。每解析完一个模块就立即写入结果，不用等全部扫描完才输出。消息处理这块有个机制：处理完一条消息后自动发确认回执，确认发送失败就静默跳过，不阻塞后续处理。输出格式常见的都支持：终端彩色表格、JSON、CSV，通过 --format 参数切换。go build 能过，命令行工具能正常运行。
