上个月生产环境出了个事故，有个临时文件的权限设成了 666，结果被一个恶意进程篡改了配置数据。事后复盘发现，手动管理文件权限根本靠不住。现在要用 Go 做一个许可证扫描和兼容性检查工具，顺带做文件权限审计，把这种低级错误扼杀在摇篮里。

许可证扫描这块要解析项目里所有依赖的开源许可声明，从 go.mod 提取模块列表，再逐个到源码目录找 LICENSE 文件或者 go.mod 里的 license 字段。兼容性矩阵内置常见的许可证冲突规则——GPL 系列和专有软件能不能混用、Apache 2.0 的专利条款和 MIT 有什么交叉影响、MPL 的文件级 copyleft 要求怎么判断。扫描结果对每对冲突给出说明，包括冲突条款的具体内容和建议的处理方式。冲突报告同时输出 JSON 和终端表格两种格式。

加密操作需要密钥，密钥的导入方式不做具体限制——可以从文件读、从环境变量读、或者用标准输入传入，只要能拿到密钥就行。多核机器上跑的时候，目录遍历和文件解析用多个 goroutine 并行处理，结果通过 channel 收集，最后统一排序输出。工具整体用 Go 标准库实现，不依赖第三方包。go build 能过，命令行工具能正常运行。
