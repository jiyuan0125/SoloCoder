脚本方案扛不住了——每次安全审计都靠一堆 Bash 脚本到处复制粘贴，改一个地方另外三个忘了改，而且脚本跑一次二十分钟。用 Go 重写一个覆盖面更广的安全扫描审计工具。

工具要解决两个层面的问题。第一个层面是 SBOM 生成——解析项目依赖树，输出 SPDX 和 JSON 两种格式的软件物料清单。SPDX 输出包含包名、版本、许可证、下载地址、校验和。JSON 格式额外包含依赖层级关系和传递路径。依赖树用缩进文本格式可视化输出，一眼能看出谁依赖了谁。第二个层面是漏洞优先级评估——对发现的每个漏洞计算综合优先级，依据 CVSS 评分、环境相关性和修复可用性三个维度。

消息系统这块，topic 支持多层通配符，格式是 a.b.c.# 这种点分层级加通配符，可以匹配 a.b.c.d.e 之类的深层路径。消息路由根据通配符规则做模式匹配。代码按功能分文件组织：SBOM 生成逻辑一个文件、漏洞评估逻辑一个文件、公共的 IO 和工具函数一个文件、命令行入口一个文件。go build 能过，命令行工具能正常运行。

扫描结果同时输出终端表格和 JSON 格式。JSON 报告里包含扫描时间戳、总耗时、依赖总数、发现的漏洞数量和按严重等级的分布统计。终端表格用颜色区分不同严重等级——红色 Critical、黄色 High、蓝色 Medium、灰色 Low。
