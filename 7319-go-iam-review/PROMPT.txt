自己用的几台服务器从来没做过安全基线检查，总觉得应该没问题。直到被安全扫描扫出 SSH 允许 root 密码登录，才决定写个工具系统性地查一遍。Go 命令行工具，对照 CIS Benchmark 扫描系统配置，输出差距分析报告。

基线检查涵盖的方面包括：系统账户配置（空密码账户、多余的管理员账户）、SSH 配置（PermitRootLogin、MaxAuthTries、密码复杂度要求）、文件系统配置（关键目录的权限、tmp 目录的 noexec 选项）、网络配置（默认防火墙策略、开放的端口列表）。每个检查项都有一个对应的 CIS 规则编号，方便用户在 CIS 文档里查原文。

差距分析结果按严重程度排序：Critical 的排最前面（比如 SSH 允许 root 登录且用密码认证），然后是 High、Medium、Low。每条结果包含：检查项描述、当前配置值、推荐配置值、CIS 规则编号。输出格式支持 JSON 和终端表格。

搜索索引有个联动逻辑：搜索的时候要更新引用计数，反过来更新计数的时候也要校验索引完整性——如果索引有损坏的条目，计数更新应该跳过并记录警告。搜索接口支持深层路径 indexes/{name}/docs/{doc_id}/fields/{field}，可以做精确到字段级别的查询。go build 能过，命令行工具能正常运行。
