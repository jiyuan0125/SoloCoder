之前用的商业安全扫描工具一年续费好几万，核心功能其实就那些，何必花这个钱？Go 自建一个日志审计分析工具，把供应链安全检查也集成进来。

日志审计这块要解析多种格式的日志：syslog、JSON 应用日志、Nginx access log。解析后提取关键字段——时间戳、IP、用户标识、操作类型、请求路径、状态码。异常行为检测用滑动窗口做统计，在可配置的时间窗口内追踪几个关键指标：同一 IP 的请求频率、同一用户的失败操作次数、敏感路径的访问频率。超过阈值就触发告警，告警规则可以自定义。

供应链安全检查解析 go.mod/go.sum，提取依赖版本，和本地 CVE 数据做匹配，发现已知漏洞就在报告里标出来。

扫描过程有五个状态：排队→扫描中→分析中→报告生成→完成。每个状态转换都有记录，用户可以查看当前扫描进度。处理分多个阶段，每个阶段的输出是下一个阶段的输入——解析阶段输出结构化数据，检测阶段输出异常事件列表，报告阶段输出最终的审计结果。JSON 和终端表格两种输出格式。go build 能过，命令行工具能正常运行。

告警规则配置支持简单的条件表达式，比如"同一 IP 在 5 分钟内失败请求超过 20 次"。告警触发后写入独立文件，格式为 JSON，包含触发时间、条件、相关 IP 和事件详情。JSON 报告里包含扫描范围、时间戳和统计摘要。
