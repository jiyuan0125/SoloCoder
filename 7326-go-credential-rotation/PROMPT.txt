之前用过一个开源的许可证检查工具，规则是硬编码的，想加一条自定义检测得 fork 项目改源码再编译，太折腾了。从零用 Go 写一个许可证扫描工具，把自定义规则的能力做好。

许可证扫描要覆盖项目所有依赖的开源许可声明。解析 go.mod 提取模块列表，到每个模块的源码目录找 LICENSE 文件或 README 里的许可声明。兼容性矩阵内置常见的冲突规则：GPL 和专有软件不能混用、AGPL 通过网络使用也触发 copyleft、LGPL 静态链接和动态链接要求不同、Apache 2.0 的专利授权条款和其他许可证的交互。扫描结果对每对冲突组合给出具体说明——哪两个依赖冲突、各自什么许可证、哪条条款冲突、建议怎么处理。

冲突报告同时输出 JSON 格式（供其他工具消费）和终端表格格式（给人看）。一个重要的联动逻辑：扫描规则如果更新了（比如某个许可证被新认定为有风险），历史扫描结果里涉及该许可证的条目的严重级别要自动重新评估，不能让用户手动重新跑一遍。go build 能过，命令行工具能正常运行。

扫描结果汇总包含总依赖数、有许可证声明的数量、冲突数量和按严重等级的分布。终端表格输出用颜色区分不同冲突等级。规则更新后自动触发增量扫描，只重新评估受影响的部分，不用全量重跑。
