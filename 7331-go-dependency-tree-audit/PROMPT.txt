去年年底有一次代码审查，发现一个实习生把私钥提交到了代码仓库，虽然当天就删了但 Git 历史里还有。从那以后我们就觉得需要一个自动化的敏感信息扫描工具。Go 标准库实现，命令行直接跑。

扫描引擎要做两种检测。正则检测匹配已知的敏感信息格式——AWS Key（AKIA 开头）、GitHub Token（ghp_ 开头）、私钥文件头（BEGIN RSA/EC PRIVATE KEY）、数据库连接串中的密码。正则规则写在配置文件里，用户可以自己加规则。熵值检测对每一行代码计算 Shannon 熵值，高熵字符串大概率是加密密钥或者随机生成的 Token，即使不匹配任何已知格式也要标记出来。两种检测做交叉验证，都命中的是高置信度。

误报率控制靠两个手段：白名单（用户指定安全文件或安全模式，扫描跳过）和上下文分析（检查匹配项周围有没有测试标记、示例注释之类的线索，有的话降低置信度）。

密钥生命周期管理有五个状态：生成→激活→轮换→归档→销毁。每个状态转换都有审计记录。消息 topic 支持多层通配符 a.b.c.# 的模式匹配，可以路由到深层路径。数据序列化用 encoding/xml 的 Marshal/Unmarshal。扫描结果以 JSON 格式输出。go build 能过，命令行工具能正常运行。
不要写单文件，核心逻辑、CLI 入口、辅助工具各放一个文件。
