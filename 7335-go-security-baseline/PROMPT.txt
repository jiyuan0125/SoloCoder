日志散落在十几个服务器上，每台格式还不一样，出问题要排查的时候根本找不到关键信息。做一个日志审计分析工具把这件事自动化，Go 实现。

工具要做的第一件事是日志解析——支持 syslog（BSD 和 RFC5424）、JSON 应用日志、Nginx/Apache access log、自定义文本格式。解析后提取关键字段：时间戳、来源 IP、用户标识、HTTP 方法和路径、状态码、响应耗时。时间戳格式做归一化处理，统一转成 RFC3339。

异常行为检测用滑动窗口统计，在可配置的时间窗口内追踪几个关键指标：同一 IP 的请求频率和失败率、同一用户的异常操作模式、敏感路径的访问频率、非工作时段的活动。超过阈值触发告警，告警规则由用户自定义。告警触发后记录到独立的告警文件。

认证这块需要用户角色来控制谁能看什么级别的审计数据，用户角色怎么创建和管理不做具体限制。输出支持 JSON 和终端表格两种格式，JSON 报告包含时间范围、异常事件列表、告警记录和统计摘要。go build 能过，命令行工具能正常运行。

扫描结果汇总包含时间范围、解析的日志总行数、检测到的异常事件数和触发的告警数。终端表格输出用颜色区分告警等级。支持 --time-range 参数指定分析的时间范围，不指定就分析全部数据。
不要写成一个 main.go 搞定所有事情。按职责拆文件：入口、解析、处理、输出分开。
