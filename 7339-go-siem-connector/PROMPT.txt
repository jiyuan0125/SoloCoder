系统安全基线检查一直拖着没做，因为 CIS Benchmark 的检查项太多了，手动逐条对照根本不现实。Go 命令行工具自动化这件事——扫描系统配置项对照 CIS Benchmark 推荐值，输出差距分析报告。

基线检查覆盖系统账户、SSH 配置、文件系统权限、网络和防火墙。系统账户要查空密码用户、UID 0 的非 root 账户、密码过期的账户。SSH 配置检查 PermitRootLogin（应该设 no）、PasswordAuthentication（应该设 no）、MaxAuthTries（建议不超过 4）、允许的认证方式（只允许公钥）。文件系统看关键文件权限（/etc/shadow 应该 600）、tmp 目录是否设置 noexec 和 nosuid。网络检查默认防火墙策略、不必要的开放端口。每个检查项带 CIS 规则编号方便查原文。

差距分析结果按严重程度排序输出——Critical 排前面（SSH 允许 root 密码登录这种），然后是 High、Medium、Low。每条结果包含检查项描述、当前配置值、推荐配置值、CIS 编号和修复建议。

消息处理完成后自动发确认回执，发送失败静默跳过不阻塞。字段值可能有各种奇怪格式——大小写混乱、多余的空格、非标准的时间格式，解析的时候要做归一化和容错处理。输出格式支持 JSON 和终端表格两种。go build 能过，命令行工具能正常运行。
