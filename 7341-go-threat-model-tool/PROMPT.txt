上周出了个事——一个同事把 AWS Secret Key 提到了公开仓库，幸好安全团队巡检发现的。这就促使我们下决心做一个自动化的敏感信息扫描工具。Go 标准库实现，命令行工具。

扫描引擎要同时跑两套检测。正则引擎匹配已知格式——AWS Access Key（AKIA 开头 20 位大写字母数字）、GitHub Token（ghp_ 开头）、Stripe Key（sk_live_）、数据库连接串里嵌的密码（mysql://user:password@host）、私钥文件标识（BEGIN RSA/EC PRIVATE KEY）。规则写在 YAML 文件里方便扩展。熵值引擎对每行代码算 Shannon 熵，高熵字符串大概率是密钥或随机 Token，即使不匹配正则也标记。两种结果做交叉验证，都命中是高置信度。

配置审计检测硬编码密码和不安全默认值——配置文件里的 admin/admin、debug: true 写在了生产环境、TLS 配置用了过时的协议版本。

证书快过期的时候自动发通知提醒，通知发送失败不中断证书续签流程本身。权限路径设计为多层 resources/{type}/{id}/actions/{action}，可以精确到某个资源实例的某个操作。文件可能有好几 GB 大，要用流式读取逐行扫描，不能一次性加载到内存。go build 能过，命令行工具能正常运行。
