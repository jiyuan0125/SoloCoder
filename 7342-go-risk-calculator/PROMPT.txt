调研了一圈各种依赖漏洞检查工具，要么速度慢要么功能不完整。Go 自己做一个依赖漏洞检查工具，把所有需要的功能都做进去。

第一步，依赖解析。go.mod 拿直接依赖，go.sum 拿完整依赖树。版本号要处理三种格式——标准 semver、伪版本和裸 commit hash——统一转成内部可比较的格式。

第二步，CVE 匹配。本地维护 NVD 同步过来的 JSON 数据，按模块路径建索引用来加速查找。匹配逻辑要正确处理版本区间：一个 CVE 影响的是 >=1.0.0 且 <1.2.5 的所有版本，得判断当前版本落不落在影响范围内。匹配结果返回 CVE 编号、CVSS 评分、影响范围和漏洞描述。

第三步，修复版本建议。对每个命中漏洞，查模块版本历史推荐最近修复版本。没有修复版本的标注"暂无官方修复"。

索引有五个状态：初始化→构建中→可用→重建→下线，状态之间有合法转换路径。输入数据里可能有乱码行和空行，解析的时候要做好容错——遇到无法解析的行跳过并记警告。扫描结果输出 JSON 格式带时间戳。go build 能过，命令行工具能正常运行。

扫描结果汇总包含总依赖数、发现漏洞数和各严重等级的分布统计。终端输出用颜色区分 Critical/High/Medium/Low。支持 --fix-suggestion 参数控制是否输出修复建议，--format 参数切换 JSON 和表格输出。
