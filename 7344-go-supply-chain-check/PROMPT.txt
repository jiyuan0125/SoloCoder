朋友开了个小公司要做安全合规，市面上的工具不是太贵就是太重。帮他做一个轻量的配置审计工具——扫描 .yaml、.json、.toml、.env、.ini 里的硬编码密码和不安全默认值，跑一轮 OWASP 和 CIS 合规基线，然后输出报告。Go CLI 实现。

配置审计要覆盖 .yaml、.json、.toml、.env、.ini 这些格式。检测项：密码明文（password、secret、api_key 键名对应的值是直接字符串而非环境变量引用）、不安全默认值（admin/admin、空密码、localhost 配合默认端口）、调试开关在生产配置中打开（debug: true、verbose: true）。每个问题输出文件路径、行号和具体不安全值。

合规基线内置 OWASP 和 CIS 相关规则，按严重等级分级。用户可通过 YAML 文件扩展规则。

证书管理有完整的状态流转：申请→签发→生效→过期→续签。状态转换有合法路径，不能跳步。代码按三个文件组织：配置解析和检测逻辑、报告生成和 IO 处理、命令行入口。扫描结果输出 JSON 格式，每条包含规则编号、严重等级、当前值和建议值。go build 能过，命令行工具能正常运行。

扫描结果汇总包含扫描的配置文件总数、检测项总数、通过数和失败数。报告末尾附带修复建议汇总，按严重等级列出最常见的几类问题和建议的修复步骤。支持 --rules 参数指定自定义规则文件扩展基线。
拆成至少三个 Go 文件：main.go 做入口和参数解析，核心处理逻辑独立一个文件，工具函数单独放。
