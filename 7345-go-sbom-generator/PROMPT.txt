季度末审计报告要交了，日志审计和供应链安全检查两块还空着。赶紧用 Go 做一个工具，把这两个功能都覆盖了。

日志审计方面要解析多种格式：syslog、JSON 应用日志、Nginx/Apache access log。提取时间戳、来源 IP、用户标识、HTTP 方法路径、状态码、响应时间。异常行为检测用滑动窗口统计——在可配置时间窗口内追踪同 IP 请求频率、同用户失败操作次数、敏感路径访问频率。超过阈值触发告警，告警规则用户自定义。

供应链安全检查解析 go.mod/go.sum，提取依赖版本，和本地 CVE 数据做匹配。

字段映射如果发生变更（比如某个字段的含义改了），之前已经跑完的转换任务结果要标记为"过时"。文件操作要注意权限检查——写入报告文件之前先确认目标目录有写权限，没有就输出错误提示而不是直接崩溃。输出格式支持 JSON 和终端表格。go build 能过，命令行工具能正常运行。

告警规则配置支持自定义阈值和触发条件。扫描结果按严重等级排序输出，汇总统计包含分析的日志总行数、异常事件数、告警数和供应链漏洞数。JSON 报告带时间戳，终端表格用颜色区分不同严重等级。
不要写成一个 main.go 搞定所有事情。按职责拆文件：入口、解析、处理、输出分开。
