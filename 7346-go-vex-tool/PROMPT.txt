上次安全事故之后，安全团队要求所有项目都要上许可证扫描工具。Go 来做一个，覆盖兼容性检查和冲突报告。

扫描引擎解析 go.mod 提取模块列表，逐个到源码目录找 LICENSE 文件或 go.mod 里的 license 声明。兼容性矩阵内置规则覆盖常见场景：GPL 系列和专有软件冲突、AGPL 网络使用触发 copyleft、LGPL 静态链接 vs 动态链接、Apache 2.0 专利条款。冲突结果对每对组合给出说明——哪两个依赖冲突、各自什么许可证、冲突条款原文和建议处理方式。冲突报告同时支持 JSON 和终端表格两种输出格式。

表结构如果发生了变更（比如许可证兼容性规则更新了），依赖该表的查询和自动生成的报告要标记为需要重新执行，不能用过期的数据。任务执行有四个状态：等待→运行→成功→失败，失败的任务记录错误原因和时间戳。输出 JSON 格式的报告，带扫描时间、耗时和命中统计。go build 能过，命令行工具能正常运行。

扫描结果汇总包含总依赖数、各许可证类型的分布和冲突总数。终端表格用颜色区分冲突等级——红色表示法律风险高的组合，黄色表示需要关注的兼容性问题。JSON 报告带时间戳和扫描统计。
