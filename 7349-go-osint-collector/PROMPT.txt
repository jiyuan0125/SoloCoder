系统安全基线和依赖漏洞是安全审计里最容易漏的两块——前者检查项太多手动查不完，后者间接依赖太多手动查不过来。Go CLI 工具把这两件事自动化：对照 CIS Benchmark 检查系统配置，解析 go.sum/go.mod 匹配 CVE 漏洞，输出差距分析报告。

安全基线检查覆盖系统账户（空密码、多余管理员）、SSH 配置（PermitRootLogin 应该 no、PasswordAuthentication 应该 no）、文件系统（关键目录权限、tmp 的 noexec）、网络（防火墙默认策略、开放端口）。每个检查项带 CIS 规则编号。

依赖漏洞检查解析 go.mod 直接依赖和 go.sum 完整依赖树，版本号和本地 CVE 数据做版本区间匹配。发现漏洞按 CVSS 评分排序。

审计日志按多层路径 audits/{year}/{month}/{day}/{id} 组织，方便按时间范围查询。证书快过期的时候自动发通知提醒运维，通知发送失败不中断证书续签本身。差距分析结果按 Critical/High/Medium/Low 排序，每条包含检查项描述、当前值、推荐值和修复建议。输出 JSON 和终端表格两种格式。go build 能过，命令行工具能正常运行。

输出报告包含扫描范围、时间戳和统计摘要。终端表格用颜色区分不同严重等级的差距项。支持 --format 参数切换 JSON 和表格输出。JSON 报告带每条检查的详细信息，方便和 CI/CD 流水线集成做自动化的基线检查。
