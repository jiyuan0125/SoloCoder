团队最近在搞 JWT 认证的迁移，涉及好几个服务，手动检查每个 Token 的签名和过期时间太费事了。做一个 JWT 工具，Go CLI 实现，能把解码、签名验证和权限检查串起来。

JWT 解码要能解析 Token 的三段结构（header.payload.signature），Base64URL 解码后显示 alg、typ、kid 这些 header 字段和所有 claims。常见的 claims 都要能识别：iss（签发者）、sub（主体）、aud（受众）、exp（过期时间）、nbf（生效时间）、iat（签发时间）、jti（唯一标识）。过期时间检查要精确到秒，和当前系统时间比对，同时允许配置一个时钟偏移容忍度（比如 ±30 秒），防止因为服务器时钟不完全同步导致的误判。

签名算法检查要支持 HS256、HS384、HS512、RS256、RS384、RS512、ES256、ES384、ES512。要能检测出 alg: none 这种无签名攻击，以及 RS/HS 算法混淆攻击的迹象。密钥可以从文件、环境变量或命令行参数传入。

RBAC 权限检查基于 JWT claims 里的 roles 字段，验证当前用户是否拥有指定角色。角色怎么创建和管理不做具体限制。搜索索引有联动：搜索时更新引用计数，反过来更新计数时也要查索引完整性。go build 能过，命令行工具能正常运行。
不要写单文件，核心逻辑、CLI 入口、辅助工具各放一个文件。
