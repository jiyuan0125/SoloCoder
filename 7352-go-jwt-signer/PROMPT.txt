现有的 JWT 签发工具只支持 HS256，想换成 RS256 和 ES256 还得改代码。Go 自己写一个支持多算法的 JWT 签名生成工具。

签名生成要覆盖三种算法族。HMAC 系列（HS256/HS384/HS512）用共享密钥，密钥长度要满足最低要求——HS256 至少 256 位，HS384 至少 384 位，HS512 至少 512 位，不够的要在生成时发出警告。RSA 系列（RS256/RS384/RS512）用 RSA 私钥签名，密钥格式支持 PEM 编码的 PKCS1 和 PKCS8。ECDSA 系列（ES256/ES384/ES512）用椭圆曲线私钥签名，ES256 对应 P-256 曲线，ES384 对应 P-384，ES512 对应 P-521。

Claims 支持自定义——用户可以通过 JSON 文件或者命令行参数传入任意 claims，工具自动合并标准 claims（iat、jti）和用户自定义 claims。生成的 Token 输出到标准输出或者指定文件。

规则校验涉及规则组，规则组的来源和管理方式不做限制。消息 topic 支持多层通配符 a.b.c.# 的匹配模式。代码按三个文件组织：签名算法实现、claims 处理和 Token 编码、命令行入口。go build 能过，命令行工具能正常运行。
