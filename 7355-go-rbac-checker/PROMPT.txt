之前用的那个商业权限管理工具太贵了，而且 ACL 规则只能通过它的 Web 界面配置，没法批量导入导出。Go 自建一个 ACL 管理工具，把 Token 内省也集成进去。

ACL 规则管理要支持批量操作——从 JSON 或 YAML 文件导入规则，导出为 JSON 格式。每条规则包含：主体（用户或组）、资源路径、操作（读/写/执行/删除）、效果（允许或拒绝）。规则冲突检测要覆盖这些场景：同一主体对同一资源有允许和拒绝两条规则，这时候按"显式拒绝优先"原则处理；通配符规则（resource: *）和具体规则冲突；规则优先级相同时的行为要明确。

效果模拟评估让用户在不实际执行的情况下测试某条规则的影响——给定主体和资源，模拟返回允许还是拒绝，以及是哪些规则在起作用。

Token 内省（RFC 7662）检查 Token 的活跃状态——发给授权服务器查询 token 是否有效、是否过期、关联的 scope 和 client_id。任务执行有状态机：注册→排队→执行→成功/失败→失败可重试，重试次数可配。扫描多个目录时用 goroutine 并行处理。go build 能过，命令行工具能正常运行。
