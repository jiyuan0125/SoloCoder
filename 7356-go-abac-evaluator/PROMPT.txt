之前试过一个开源的策略引擎，自定义规则的能力太弱了，只能做简单的 RBAC。从零用 Go 写一个支持条件组合的策略引擎。

策略由条件和动作组成。条件支持几种类型：属性匹配（用户部门 = "engineering"）、数值比较（请求次数 < 100）、时间窗口（工作日 9:00-18:00）、IP 范围匹配。条件之间可以用 AND、OR、NOT 组合，支持嵌套。动作包括允许、拒绝、需要二次认证、记录审计日志。多条策略按优先级排序执行，命中第一条就返回结果（类似于防火墙的 first-match 语义）。

策略组合支持策略集的概念——把相关的策略编成一组，整组启用或禁用。决策日志记录每一次策略评估的完整过程：输入的条件值、匹配了哪些策略、最终决策和依据。

加密操作需要密钥，密钥的来源不做具体限制——可以从文件、环境变量或标准输入获取。任务有四个状态：等待→运行→成功→失败，失败的任务记录错误原因。策略和决策日志以 JSON 格式存储。go build 能过，命令行工具能正常运行。

策略文件用 JSON 格式定义，每条策略包含 id、优先级、条件和动作。默认策略集作为示例随工具提供。决策日志持久化到文件，带时间戳和唯一 ID，方便事后审计和问题追溯。输出 JSON 格式的决策结果。
