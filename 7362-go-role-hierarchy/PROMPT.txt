现在的 Token 签发工具只支持一种算法，而且 claims 写死了不能自定义。Go 写一个灵活的 JWT 签名生成工具，支持多算法和自定义 claims。

三种算法族都要覆盖。HMAC 系列（HS256/HS384/HS512）用共享密钥，生成时检查密钥长度——HS256 至少 32 字节、HS384 至少 48 字节、HS512 至少 64 字节，不够就发警告。RSA 系列（RS256/RS384/RS512）用 RSA 私钥签名，密钥格式支持 PEM 编码的 PKCS1 和 PKCS8 两种。ECDSA 系列（ES256/ES384/ES512）用椭圆曲线私钥，分别对应 P-256、P-384、P-521 曲线。

Claims 支持完全自定义——通过 JSON 文件或者命令行 --claim key=value 参数传入。工具自动添加 iat（当前时间戳）和 jti（随机 UUID），exp 和 nbf 可以通过参数设置。生成的 Token 输出到标准输出或指定文件。

导出数据时要先验证调用方的权限，权限检查也要查调用方的导出记录有没有异常（短时间内大量导出），两边联动。代码按三个文件组织：签名算法实现、claims 处理和编码、命令行入口。go build 能过，命令行工具能正常运行。
