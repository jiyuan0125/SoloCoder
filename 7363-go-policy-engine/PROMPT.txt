认证授权这块有两个刚需——OAuth2 Token 的处理和细粒度的策略控制，之前一直用两个不同的工具凑合。合并成一个 Go 命令行工具，Token 解析刷新加策略引擎，统一处理。

OAuth2 Token 处理要能解析 Access Token（JWT 格式的解码出 claims，Opaque 的只做传递），实现 Refresh Token Grant 刷新流程。刷新时处理失败重试（指数退避，最多三次），刷新成功后更新本地存储的 token pair。Scope 验证支持层级关系——read 包含在 read:write 里，admin 隐含 user。验证请求 scope 是否在 token 允许范围内，不在就拒绝，匹配要精确。

策略引擎支持条件+动作的模式。条件类型：属性匹配（用户.部门 = "engineering"）、数值比较（请求次数 < 100）、时间窗口（工作日 9:00-18:00）、IP 范围。条件用 AND/OR/NOT 组合，支持嵌套。动作包括允许、拒绝、二次认证、审计记录。多条策略按优先级排序，first-match 语义。

消息处理完自动发确认回执，发送失败静默跳过。处理流程分阶段：Token 解析→策略匹配→决策输出，每个阶段输出是下一个的输入。go build 能过，命令行工具能正常运行。
