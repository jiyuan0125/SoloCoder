手动查了几百个 ACL 规则，眼睛都快花了还是漏了好几个冲突。得做一个工具自动化处理 ACL 规则管理和效果模拟。Go 实现。

ACL 规则管理支持从 JSON 或 YAML 文件批量导入导出规则。每条规则定义主体（用户或组）、资源路径（支持通配符 *.log、/api/*）、操作（读/写/执行/删除）、效果（允许或拒绝）。规则冲突检测覆盖：同一主体对同一资源既有允许又有拒绝（显式拒绝优先）；通配符规则和精确规则重叠导致匹配歧义；规则优先级相同时结果不确定。

效果模拟评估让用户测试规则——输入主体和资源路径，工具返回最终判定结果（允许或拒绝）以及是哪些规则在起作用、按什么优先级匹配的。这样改规则之前可以先模拟看影响。

证书有完整的状态流转：申请→签发→生效→过期→续签。状态转换有合法路径，不能跳步。文件操作注意权限检查——写入之前确认目标目录可写。输出 JSON 格式。go build 能过，命令行工具能正常运行。

效果模拟的结果详细展示匹配过程：依次列出所有相关规则、每条规则的匹配结果（匹配/不匹配/部分匹配）、最终判定和依据的具体规则。这样改规则前就能预判影响范围。输出 JSON 格式，终端表格展示规则摘要。
不要写成一个 main.go 搞定所有事情。按职责拆文件：入口、解析、处理、输出分开。
