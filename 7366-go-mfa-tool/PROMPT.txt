上周 Excel 公式写错了，权限策略配置表全废了，花了一整天才恢复过来。手动管理策略太不可靠了，用 Go 做一个策略引擎工具把这件事自动化。

策略引擎要支持条件+动作的组合。条件类型覆盖：字符串匹配（用户.部门 = "engineering"）、数值比较（请求频率 < 100/分钟）、时间条件（工作日 9:00-18:00）、IP 范围匹配（192.168.1.0/24）。条件可以用 AND、OR、NOT 逻辑组合，支持任意深度的嵌套。动作类型：允许、拒绝、触发二次认证、记录审计日志、发送告警。多条策略按优先级排序，命中第一条就返回决策结果。

策略组合支持策略集——把相关策略编组，整组启用或禁用。决策日志记录每次评估的完整过程：输入条件值、匹配的策略、最终决策和判断依据。

扫描完自动提交报告到指定位置，提交失败只记日志不中断。扫描规则更新后历史结果的严重级别要重新评估。校验分三阶段：语法检查→语义检查→引用检查。go build 能过，命令行工具能正常运行。

策略文件用 JSON 格式定义，每条包含 id、优先级、条件表达式和动作。决策日志持久化到文件，每条记录带时间戳、唯一 ID 和完整的评估上下文，方便审计和问题排查。输出 JSON 格式。
