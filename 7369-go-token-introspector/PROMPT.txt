API Key 散落在各个服务的配置文件里，没人知道一共有多少个、哪些已经过期了、哪些还在用。Go CLI 做一个 Key 全生命周期管理工具——生成（自定义前缀 + Base62 编码）、轮换（带宽限期）、吊销（立即生效）、使用统计和过期预警。

API Key 生成支持自定义前缀（比如 prod_、staging_ 区分环境），主体用 crypto/rand 生成随机字节再 Base62 编码，长度可配默认 32 字节。Key 存储用 SHA256 摘要，验证时对传入 Key 算摘要比对，不能明文存储。

轮换流程分步：生成新 Key → 更新配置 → 设置旧 Key 的宽限期（默认 7 天，新旧都有效） → 宽限期后旧 Key 自动失效。吊销立即生效，被吊销的 Key 加入黑名单。

使用统计记录每个 Key 的调用次数、最后使用时间、来源 IP 分布，统计粒度按小时或天。过期预警在到期前 7 天、3 天、1 天各发一次通知。

数据转换需要映射模板来定义 Key 元数据到存储结构的映射，模板格式不做限制。加密用 crypto 包的对称加密（AES-GCM）。输出 JSON 格式。go build 能过，命令行工具能正常运行。

统计结果按 Key 分组展示日调用趋势和来源分布。过期预警写入独立的通知文件。Key 的元数据（创建时间、最后轮换时间、关联服务）也以 JSON 格式存储。终端输出用颜色区分不同状态的 Key。
