之前用 Python 处理 OAuth2 Token 刷新，异常处理不到位导致 Token 泄露了一次。换 Go 重写一个 OAuth2 Token 工具，把刷新和 Scope 验证都做好。

Token 处理支持 JWT 格式的 Access Token 解码（提取 scope、exp、client_id），Opaque Token 只做传递。刷新流程实现标准的 Refresh Token Grant——拿 refresh_token 调 token endpoint 换新的 access_token。刷新失败用指数退避重试，最多三次，每次间隔翻倍。刷新成功自动更新本地 token 存储。

Scope 验证支持层级：read 包含在 read:write 里，admin 隐含 user。验证请求 scope 是否在 token 允许范围内，不在就拒绝。Scope 匹配要精确，前缀匹配不算。

证书签发需要 CA，CA 怎么初始化不做限制。消息 topic 支持多层通配符 a.b.c.# 的匹配，可以路由深层路径。扫描多个目录时用 goroutine 并行处理。输出支持 JSON 格式。go build 能过，命令行工具能正常运行。
