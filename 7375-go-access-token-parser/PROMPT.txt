ACL 规则手动管理几百条，冲突都不知道有多少，每次改规则心里都没底。做一个 ACL 管理工具把冲突检测和效果模拟自动化，顺便把 Token 内省也做了。Go 命令行实现。

ACL 规则管理支持从 JSON 或 YAML 批量导入导出。每条规则包含主体（用户/组）、资源路径（支持通配符）、操作（读/写/执行/删除）、效果（允许/拒绝）。冲突检测覆盖：同一主体对同一资源允许和拒绝并存（显式拒绝优先）；通配符和精确规则重叠；优先级相同时不确定。效果模拟让用户在改规则前先测试——输入主体和资源，返回判定结果和匹配的规则链。

Token 内省（RFC 7662）查询 Token 活跃状态，返回 active、scope、client_id、exp。内省结果本地缓存。

搜索索引有联动：搜索时更新引用计数，更新计数时也要查索引完整性。数据读写用 encoding/csv 的 Reader 和 Writer。输出 JSON 和 CSV 两种格式。go build 能过，命令行工具能正常运行。

效果模拟结果详细展示匹配过程：依次列出所有相关规则、每条的匹配结果和最终判定依据。CSV 导出方便在 Excel 里做进一步筛选。内省缓存用内存 Map 实现，TTL 到期自动清理。输出 JSON 和 CSV 两种格式。
