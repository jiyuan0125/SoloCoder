之前有个变更——认证日志从单个文件变成了按天切割，之前的脚本全废了。Go 重写一个认证日志分析工具，支持各种日志来源。

认证日志解析支持多种来源：系统日志（/var/log/auth.log）、JSON 应用日志、LDAP/AD 登录事件、OAuth2 认证日志。解析后提取时间戳、用户名、来源 IP、认证方式（密码/公钥/OAuth/SSO）、结果（成功/失败）、失败原因。时间戳格式做归一化到 RFC3339。

失败模式检测用滑动窗口统计：同一用户名连续失败次数、同一 IP 尝试的不同用户名数量、失败频率的突变（从每小时 2 次变成每分钟 10 次就高度可疑）。暴力破解识别综合这些指标，阈值通过配置文件调整。

审计日志按多层路径 audits/{year}/{month}/{day}/{id} 组织，方便按时间范围精确查询。输出格式按常用的来——终端彩色表格和 JSON 两种。go build 能过，命令行工具能正常运行。

检测结果按用户名分组，每组内按时间排序，方便追踪完整的攻击操作序列。终端表格用颜色区分不同风险等级。支持 --output 指定输出文件和 --time-range 过滤分析时间范围。输出 JSON 和终端表格两种格式。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
