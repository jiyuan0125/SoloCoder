Token 过期了没人发现、吊销了还能用、刷新轮换从来没正确执行过——这三个问题反复出现，必须工具化了。Go 命令行做一个 Token 生命周期管理工具，覆盖内省（RFC 7662）、吊销列表和刷新轮换。

Token 内省（RFC 7662）发送 token 到授权服务器查询状态，返回 active、scope、client_id、username、exp。Token 不存在或过期返回 active: false。内省结果要本地缓存，缓存 TTL 不超过 token 剩余有效期的四分之一。

吊销列表在本地维护。Token 被吊销后加入列表，内省时先查本地列表再查远程。列表持久化到文件，重启后自动加载。条目有过期清理机制——自然过期的 token 对应条目定期清理。

刷新 Token 轮换：每次刷新后旧 refresh_token 立即失效。如果已失效的 refresh_token 被使用（疑似被盗），自动吊销关联的全部 token，这是个安全事件要记录。

数据库查询需要连接配置，连接配置怎么做不做具体限制。输出 JSON 格式，包含每个操作的结果和时间戳。go build 能过，命令行工具能正常运行。

工具用 Go 标准库实现，不依赖第三方包。Token 缓存用内存 Map 存储，TTL 到期自动清理。吊销列表的过期清理在每次查询时顺带执行，不额外启动定时任务。输出 JSON 格式，包含每个操作的结果、时间戳和状态。
至少拆成两个包或三个文件以上，不要单文件一把梭。
