闲着没事想用 Go 写点东西，那就做一个 API Key 管理工具吧。生成支持自定义前缀，轮换有宽限期，吊销立即生效，再配上使用统计和过期预警。顺手把 JWT 签名生成也做进去，HS256 和 RS256 都支持。Go CLI 实现。

API Key 生成支持自定义前缀（prod_、dev_ 区分环境），主体用 crypto/rand 生成随机字节再 Base62 编码，默认 32 字节长度可配。存储用 SHA256 摘要，验证时算摘要比对，不存明文。轮换流程：生成新 Key → 更新配置 → 旧 Key 设 7 天宽限期 → 宽限期后自动失效。吊销立即生效加入黑名单。

使用统计记录每个 Key 的调用次数、最后使用时间、来源 IP。统计粒度按天。过期预警在到期前 7 天、3 天、1 天各通知一次。JWT 签名支持 HS256 和 RS256，Claims 自定义传入。

消息发送需要 topic，topic 创建不做具体要求。消息处理后自动发确认，确认失败静默跳过。输入格式支持 JSON、YAML 等常见格式。输出 JSON。go build 能过，命令行工具能正常运行。

Key 的完整元数据（创建时间、轮换历史、关联服务、状态）以 JSON 格式存储。统计结果按 Key 分组展示日调用趋势。输出包含 Key 列表、统计数据和预警记录。支持 --key-file 参数从文件读取 Key 配置。
代码要模块化：主流程、具体功能实现、辅助函数分开存放，主文件只做调度。
