线上有个 Token 签名验证的 bug——某些 ES256 签名的 Token 总是验证失败，查了半天发现是曲线参数不对。趁排查的机会把 JWT 解码验证工具做完整，Go 标准库写命令行。

JWT 解码解析三段式 header.payload.signature，Base64URL 解码后展示完整的 header（alg、typ、kid）和所有 claims。标准 claims 要能识别：iss（签发者）、sub（主体）、aud（受众）、exp（过期时间）、nbf（生效时间）、iat（签发时间）、jti（唯一标识）。过期检查精确到秒，和系统时间比对，允许配置 ±30 秒的时钟偏移容忍度，防止服务器时钟不完全同步导致的误判。

签名算法检查支持 HS256/HS384/HS512、RS256/RS384/RS512、ES256/ES384/ES512。检测 alg: none 无签名攻击，检测 RS/HS 算法混淆。密钥从文件或环境变量读取。

证书签发需要 CA，CA 怎么初始化不做具体限制。输出格式按常用的来——终端彩色表格和 JSON 两种，JSON 里包含解码结果、签名验证状态和过期判断。go build 能过，命令行工具能正常运行。
