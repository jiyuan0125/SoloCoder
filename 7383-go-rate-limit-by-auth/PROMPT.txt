线上跑的 OAuth2 处理逻辑散落在好几个服务里，策略判断也到处都是。Go 重写一个统一的工具，把 OAuth2 Token 处理和策略引擎合在一起。

OAuth2 Token 处理支持 JWT 格式的 Access Token 解码（提取 scope、exp、client_id），Opaque Token 只传递。Refresh Token Grant 刷新流程带失败重试（指数退避，最多三次），成功后更新本地 token 存储。Scope 验证支持层级——read 包含在 read:write 里，admin 隐含 user。验证请求 scope 在 token 允许范围内，不在就拒绝。

策略引擎条件+动作模式。条件类型：属性匹配、数值比较、时间窗口、IP 范围。用 AND/OR/NOT 组合。动作：允许、拒绝、二次认证、审计记录。多策略按优先级排序 first-match。

权限变更后用户会话里缓存的权限信息要同步刷新。输入格式支持 JSON、YAML 等常见配置文件格式。输出 JSON。go build 能过，命令行工具能正常运行。

策略文件用 JSON 格式定义，支持运行时热加载——修改策略文件后不用重启工具就能生效。决策日志持久化到文件，带时间戳和完整评估上下文。权限变更后用户会话里缓存的权限信息要同步刷新，确保不会用过期的权限数据做判断。输出 JSON 格式。
代码分文件组织，解析器、处理器、输出器分开，main.go 只做参数解析和流程串联。
