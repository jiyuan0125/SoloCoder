ACL 规则几百条，手动管理根本顾不过来，每次改规则都不知道会不会影响其他地方。做一个 ACL 管理工具自动化处理，Go 实现。

ACL 规则管理支持从 JSON 或 YAML 批量导入导出。每条规则定义主体（用户/组）、资源路径（支持通配符）、操作（读/写/执行/删除）、效果（允许/拒绝）。冲突检测覆盖：同一主体对同一资源允许和拒绝并存（显式拒绝优先）；通配符和精确规则重叠；优先级相同结果不确定。效果模拟让用户在改规则前测试——输入主体和资源，返回判定结果和匹配的规则链。

数据转换需要映射模板定义规则到内部结构的映射，模板格式不做限制。输出格式按常用的来——终端表格和 JSON 两种。go build 能过，命令行工具能正常运行。

效果模拟结果详细展示匹配过程：依次列出所有相关规则、每条的匹配结果（匹配/不匹配/部分匹配）、最终判定和依据的具体规则编号。映射模板定义了 ACL 规则字段到内部数据结构的对应关系。输出终端表格和 JSON 两种格式，终端用颜色区分允许和拒绝。

规则管理支持批量导入导出——从 JSON 或 YAML 文件一次性加载全部规则，修改后导出为 JSON。导入时自动做冲突检测。输出终端表格和 JSON 两种格式。
