之前有个项目策略配置全写在代码里，改一条规则要重新编译部署，效率太低。Go 做一个策略引擎工具，把策略从代码里抽出来，支持运行时加载和修改。

策略引擎核心是条件+动作组合。条件类型覆盖：属性匹配（user.role = "admin"）、数值比较（request.count < rate_limit）、时间条件（工作日 9:00-18:00 才允许）、IP 范围匹配（10.0.0.0/8 内网放行）。条件用 AND/OR/NOT 逻辑组合，支持多层嵌套——比如 (role = admin OR (department = engineering AND level > 5)) AND time = workday。动作类型：允许、拒绝、要求二次认证、写审计日志、发告警通知。多条策略按优先级排序，first-match 语义。

策略组合支持策略集概念——相关策略编成一组，整组启用或禁用。决策日志记录每次评估的完整过程：输入参数、匹配的策略列表、最终决策和判断依据。

数据库查询需要连接配置，连接配置怎么做不做具体限制。数据库操作用 database/sql 的预处理语句防止 SQL 注入。输出 JSON 格式的决策结果。go build 能过，命令行工具能正常运行。
项目要用多文件结构，入口文件、业务逻辑、数据模型分开放，别揉在一个文件里。
