生产环境有个 Token 吊销了居然还能用——吊销列表只在内存里，服务一重启就丢了。Go 做一个 Token 生命周期管理工具，内省、吊销、刷新轮换三个功能分文件写清楚，纯标准库不用第三方包。

Token 内省（RFC 7662）发 token 到授权服务器查状态，返回 active、scope、client_id、username、exp、sub。Token 不存在或过期 active 为 false。内省结果本地缓存，缓存 TTL 不超过 token 剩余有效期的 1/4，避免缓存过期状态。

吊销列表本地维护。Token 被吊销后加入列表，内省先查本地再查远程。列表持久化到文件，重启自动加载恢复。条目有过期清理——Token 自然过期后对应条目定期清理，避免列表无限增长。

刷新 Token 轮换：每次刷新后旧 refresh_token 立即失效，颁发新的。如果已失效的 refresh_token 被使用（疑似盗用），自动吊销关联的全部 token。

加密操作需要密钥，密钥来源不做具体限制。代码按三个文件组织：Token 处理核心逻辑、存储和持久化、命令行入口。go build 能过，命令行工具能正常运行。

工具不依赖第三方包，纯 Go 标准库实现。Token 缓存用内存 Map 存储，TTL 到期自动清理。吊销列表的过期清理在每次查询时顺带执行。密钥从文件、环境变量或标准输入获取。输出 JSON 格式，包含每个操作的结果和时间戳。
