上次轮换 API Key 的时候忘了设宽限期，旧 Key 一失效调用方全报错，紧急回滚折腾了一个小时。Go CLI 做一个完整的 Key 生命周期管理工具——生成（自定义前缀 + Base62）、轮换（带宽限期）、吊销（立即生效）、使用统计和过期预警，把这种低级失误自动化掉。

API Key 生成支持自定义前缀区分环境和用途（prod_api_、staging_），主体用 crypto/rand 生成随机字节再 Base62 编码。默认 32 字节，长度可配。存储用 SHA256 摘要，验证时对传入 Key 算摘要比对，不存明文。轮换流程：生成新 Key → 更新配置 → 旧 Key 设宽限期（默认 7 天新旧都有效）→ 宽限期后旧 Key 自动失效。吊销立即生效加入黑名单。

使用统计记录每个 Key 的调用次数、最后使用时间、来源 IP。过期预警在到期前 7 天、3 天、1 天各通知一次。

扫描发现异常要生成报告，报告生成也要扫描关联配置文件。数据序列化用 encoding/xml 的 Marshal/Unmarshal。输出 JSON 格式。go build 能过，命令行工具能正常运行。

Key 的完整元数据（创建时间、轮换历史、状态）用 encoding/xml 序列化存储。统计结果按 Key 分组展示日调用趋势。过期预警在到期前 7 天、3 天、1 天各通知一次。输出 JSON 格式，包含 Key 列表、统计数据和预警记录。
代码要模块化：主流程、具体功能实现、辅助函数分开存放，主文件只做调度。
