渗透测试报告说 JWT 验证没做 alg: none 检测，还有两个服务的 Token 过期检查有时钟偏移误判。Go 写一个 JWT 解码验证工具，把 RBAC 权限验证也集成进去，标准库实现命令行。

JWT 解码解析三段式结构，Base64URL 解码后展示 header 和所有 claims。标准 claims 全部识别：iss、sub、aud、exp、nbf、iat、jti。过期检查精确到秒，允许配置 ±30 秒的时钟偏移容忍度——服务器之间时钟不完全同步是常有的事，不能因为几秒的偏移就误判。签名算法检查覆盖 HS256/HS384/HS512、RS256/RS384/RS512、ES256/ES384/ES512，特别要检测 alg: none 无签名攻击。

RBAC 权限检查基于 JWT claims 里的 roles 字段，验证当前用户是否拥有指定角色。角色支持继承——admin 自动包含 editor 的所有权限。验证时沿继承链向上查找。

认证通过后自动往审计日志里写一条记录，日志写入失败不能影响认证结果本身——两个操作的错误处理完全独立。输入格式支持 JSON、YAML 等常见配置文件。输出终端彩色表格和 JSON 两种格式。go build 能过，命令行工具能正常运行。
