JWT 签发工具只支持 HS256 已经满足不了需求了——移动端要用 RS256，IoT 设备用 ES256。Go 写一个多算法 JWT 签名工具，Claims 完全自定义。

三种算法族全覆盖。HMAC 系列（HS256/HS384/HS512）用共享密钥签名，生成时检查密钥长度——HS256 至少 32 字节、HS384 至少 48、HS512 至少 64，不够就警告。RSA 系列（RS256/RS384/RS512）用 RSA 私钥，密钥格式支持 PEM 编码的 PKCS1 和 PKCS8。ECDSA 系列（ES256/ES384/ES512）分别对应 P-256、P-384、P-521 椭圆曲线。

Claims 通过 JSON 文件或命令行 --claim key=value 传入。自动添加 iat（签发时间戳）和 jti（随机 UUID），exp 和 nbf 可配置。Token 输出到标准输出或指定文件。

校验时需要查关联表的规则，查关联表时也要校验触发方的状态——两个操作互相依赖。任务有等待→运行→成功→失败四个状态。输出 JSON 格式。go build 能过，命令行工具能正常运行。
