微服务拆分之后 ACL 规则跟着拆到了各个服务里，改一条规则要改三个地方，还经常改漏。做一个 ACL 管理工具把冲突检测和效果模拟自动化，Token 内省也集成进去。Go 实现。

ACL 规则管理支持从 JSON 或 YAML 批量导入导出。每条规则包含主体、资源路径（支持通配符）、操作、效果。冲突检测：同一主体对同一资源允许和拒绝并存（显式拒绝优先）；通配符和精确规则重叠；优先级相同。效果模拟——输入主体和资源，返回判定结果和匹配的规则链，改规则之前先模拟。

Token 内省（RFC 7662）查 Token 活跃状态，返回 active、scope、exp。内省结果本地缓存。消息处理完自动发确认，确认失败静默跳过。文件操作注意权限检查——写入之前确认目标目录可写。输出 JSON 格式。go build 能过，命令行工具能正常运行。

效果模拟详细展示匹配过程：依次列出相关规则、每条匹配结果和最终判定依据。批量导入导出支持 JSON 和 YAML。内省缓存 TTL 不超过 token 有效期的 1/4。冲突结果按严重程度排序附带建议。输出 JSON 和终端表格两种格式。
 文件操作注意权限检查。工具纯 Go 标准库实现不依赖第三方包。
