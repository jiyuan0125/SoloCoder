那个认证日志分析脚本是用 Python 写的，依赖一堆库环境都搭不起来。Go 重写一个，性能也更好。

认证日志解析支持多种来源：系统日志 /var/log/auth.log、JSON 应用日志、LDAP/AD 登录事件、OAuth2 认证日志。提取关键字段：时间戳、用户名、来源 IP、认证方式（密码/公钥/OAuth/SSO）、结果（成功/失败）、失败原因。时间戳归一化到 RFC3339，支持各种输入格式。

失败模式检测用滑动窗口——在可配置时间窗口内追踪：同一用户名连续失败次数、同一 IP 尝试的不同用户名数量、失败频率变化趋势。暴力破解识别综合这些指标，阈值通过配置文件调整。检测结果按风险等级排序输出。

证书续签后依赖该证书的 TLS 配置要同步更新。代码按三个文件组织：日志解析和字段提取、异常检测和模式分析、命令行入口。输出终端表格和 JSON 两种格式。go build 能过，命令行工具能正常运行。

检测结果按用户名分组，每组内按时间排序，方便追踪完整攻击操作序列。终端表格用颜色区分不同风险等级的检测事件。支持 --output 指定输出文件和 --time-range 过滤时间范围。输出 JSON 和终端表格两种格式。
