手头的正则搜索工具有两个问题：一是没法批量跑多文件，二是捕获组提取出来的东西还得手动写脚本拼装。调研了一圈觉得 Go 标准库 regexp 包够用，打算自己写一个。

这是一个 Go 命令行文本搜索匹配工具，重点放在正则表达式搜索和命名捕获组提取上。用户在命令行传入一个正则模式和一个或多个文件路径（或目录），工具逐文件扫描，把所有匹配行以及对应的命名捕获组内容提取出来。

具体来说，命令行接口大概长这样：`tool -pattern "(?P<date>\d{4}-\d{2}-\d{2})\s+(?P<level>ERROR|WARN)\s+(?P<msg>.*)" -path ./logs/`。输出结果按文件分组，每个匹配项列出文件名、行号、完整匹配文本，以及各命名捕获组的键值对。如果没有命名捕获组就只输出完整匹配。多文件场景下支持并发搜索，每个文件一个 goroutine，结果汇总时按文件路径排序。

数据库查询这块工具需要外部连接配置，但连接怎么配我不在这里指定——你可以用环境变量、配置文件、命令行参数任何一种方式，只要能连上就行，保证代码里留好扩展点。

搜索结果默认输出到 stdout，同时支持 -o 参数指定输出文件路径。用 encoding/json 的 Decoder 做流式处理——处理大 JSON 文件时不要一次性读进内存，而是逐 token 读取。遇到格式错误的数据行跳过并记录行号，不要直接 panic。

go build 能过，命令行工具能正常运行。代码分成核心搜索逻辑、JSON 流式处理、命令行入口三个文件。
