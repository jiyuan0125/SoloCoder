之前用 Python 写了个全文搜索脚本，数据量一上去就慢得离谱。这次直接换 Go 来做，性能应该能好不少——写一个命令行全文索引和搜索工具。

倒排索引是核心——对输入文档集合做分词后建立倒排表，每个词项指向包含它的文档 ID 列表和位置信息。索引构建完持久化到本地 JSON 文件，启动时如果已有索引文件就直接加载，不用从头构建。增量更新也要支持：新文档进来后，解析完合并到现有索引里，而不是每次全量重建。

查询方面支持布尔查询——AND（所有关键词都出现）、OR（任一关键词出现）、NOT（排除含某关键词的文档），用户可以用简单表达式组合查询，比如 "golang AND（并发 NOT channel）"。解析查询表达式时如果语法有误，返回具体的错误位置和原因，不要只扔一个 "invalid query"。

这个工具里还有一块令牌管理的逻辑——令牌有创建→活跃→刷新→过期→吊销五种状态。创建后进入活跃态，活跃令牌可以刷新（延长有效期），过期或被主动吊销后不能再刷新。状态转换必须单向流转，不允许从吊销回退到活跃。

加密方面用 crypto 包做对称加密，密钥从配置文件读取。索引数据在写入磁盘前可以选择加密存储，读取时解密。密钥文件不存在时给出明确提示，不要静默跳过。

go build 能过，命令行工具能正常运行。
