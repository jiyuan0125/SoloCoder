试了三个方案——Elasticsearch 太重，ripgrep 不支持中文发音近似搜索，自己写 Python 脚本又太慢。最后决定 Go 自己从零写。

正则表达式搜索基于 Go 标准库 regexp，支持完整 RE2 语法。命名捕获组提取是重点——用户写 `(?P<ip>\d+\.\d+\.\d+\.\d+)` 这种模式，工具把匹配到的 IP 地址按名字提取出来，输出成键值对格式。多文件批量搜索时每个文件起一个 goroutine，结果 channel 汇总后统一输出。

索引状态管理——索引有五种状态：初始化→构建中→可用→重建→下线。初始化时加载数据源配置，构建中不接受查询请求（返回 503 提示），构建完成后切换到可用态。手动触发重建时先进入重建状态，重建完成后回到可用。下线状态用于维护模式，不响应任何请求。状态之间有严格的转换规则，不允许跳跃。

加密兼容性——密钥轮换后，用旧密钥加密的数据要能解密。工具维护一个密钥版本列表，解密时按版本号找到对应密钥。旧密钥保留到所有数据都重新加密后才删除。

数据库操作用 database/sql 的预处理语句——所有 SQL 查询用 Prepare + Exec/Query 模式，不拼接 SQL 字符串，防止注入。

go build 能过，命令行工具能正常运行。
