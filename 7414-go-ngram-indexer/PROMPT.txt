新规下来要求对线上日志做合规检索，现有的工具不支持模糊搜索和相似度计算，得加一个。Go 实现。

N-gram 索引构建——文本按 n=2 或 n=3 切分（用户可配置），每个 n-gram 映射到包含它的文档 ID 列表。索引数据用 Go 的 map 在内存中维护，持久化到 JSON 文件。启动时如果 JSON 文件存在就直接加载，否则触发构建。

模糊匹配加速流程——用户输入查询词，先切 n-gram，然后拿这些 n-gram 去索引里查候选文档集。候选集通常远小于全量文档，接着对候选集做精确的相似度计算。相似度支持两种：编辑距离和余弦相似度（基于 n-gram 向量）。用户通过 -similarity edit|cosine 参数选择。

证书状态管理——证书有五种状态：申请→签发→生效→过期→续签。申请提交后进入签发等待，签发成功进入生效状态，到期后进入过期状态。续签操作只在生效期和过期后 30 天内允许。状态流转是单向的，不允许回退。

任务状态管理——任务有等待、运行、成功、失败四个状态。等待中的任务被 worker 取走后进入运行状态，完成后标记成功或失败。失败任务不自动重试，需要用户手动重新提交。同一时间一个任务只能处于一种状态。

go build 能过，命令行工具能正常运行。
