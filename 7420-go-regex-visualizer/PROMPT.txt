V2 版本月底要上线，搜索能力是核心功能之一，先把这块做了。Go 命令行。

搜索索引持久化——索引数据（包括倒排表、文档元数据、索引统计信息）全部序列化到 JSON 文件。文件里带版本号字段，启动时版本不匹配自动触发重建。索引文件路径通过 -index-dir 参数指定，默认是当前目录下的 .index/。

索引重建——全量扫描文档集，重新分词建索引，写 JSON 文件。重建过程中旧索引仍然可用（读写分离），重建完成后原子替换索引文件。可以设一个 -rebuild 命令手动触发。

索引合并——两个索引文件可以合并，用于多批次文档的场景。合并时按文档 ID 去重，相同的文档取最新版本。合并完成后生成新索引文件。

证书签名验证——签名时需要验证证书状态（是否过期、是否被吊销），验证时也要检查签名链（中间 CA → 根 CA 的信任链）。签名链断裂时返回明确错误。

加密操作完成后自动删除原文文件，删除失败不中断后续流程，只记 warn 日志。

扫描多个目录要并行处理——每个目录一个 goroutine，结果通过 channel 汇总。并行度默认等于 CPU 核数。

go build 能过，命令行工具能正常运行。
