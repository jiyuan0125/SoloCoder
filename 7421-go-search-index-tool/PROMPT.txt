我们组最近在做日志审计系统，需要一个能模糊搜索和索引的工具。用 Go 标准库写个命令行工具，不引入第三方包。

模糊搜索基于 Levenshtein 编辑距离——用户传一个查询词和最大距离阈值，工具返回所有编辑距离在阈值内的匹配项。搜索结果按距离从小到大排序输出，距离相同的按匹配文本的字典序排列。命中部分用 ANSI 颜色高亮，终端里一眼能看到哪里匹配了。

N-gram 索引用来加速模糊搜索。把文档集合中的文本按 2-gram 切分，每个 n-gram 对应一个文档 ID 集合。搜索时先拿查询词的 n-gram 去索引里查候选集，再对候选集做精确编辑距离计算。索引构建完存 JSON 文件，支持增量更新——新文档进来追加到现有索引。

证书状态流转——证书有申请→签发→生效→过期→续签五种状态。签发需要审核，生效期可以手动触发续签，过期后 30 天内仍可续签。状态只允许正向流转。

输入数据格式自动检测——支持纯文本、JSON Lines、CSV。JSON Lines 按 \n 分行，每行一个 JSON 对象；CSV 按第一行表头解析，后续行按列匹配。格式检测基于文件扩展名和内容前几行的特征。

go build 能过，命令行工具能正常运行。
