业务那边有几百个配置文件要定期搜关键词，让我做一个 N-gram 搜索工具。Go CLI 实现。

N-gram 索引构建——文本按 2-gram 或 3-gram 切分（默认 2-gram），每个 n-gram 建立到文档和位置的映射。索引存 JSON 文件，支持加载已有索引继续增量构建。索引构建时支持并发——多个文件同时构建各自的 n-gram 表，最后合并到全局索引。

模糊匹配加速——用户输入查询词，先切 n-gram 拿候选文档集，再对候选集做精确编辑距离计算。相似度计算支持两种指标：Jaccard 系数（基于 n-gram 集合交集）和余弦相似度（基于 n-gram 频率向量），用户通过参数选择。

令牌状态管理——令牌有创建→活跃→刷新→过期→吊销五种状态。创建时分配令牌 ID 和有效期，激活后可用于鉴权。刷新延长有效期，但只能刷新活跃状态的令牌。过期或吊销后不可恢复。令牌状态变更时记录审计日志。

搜索结果输出支持 JSON 格式，包含匹配文档路径、行号、相似度分数、匹配片段。可以通过管道传给其他工具做二次处理。

go build 能过，命令行工具能正常运行。
