朋友开的小公司有一批地址数据要做模糊匹配和相似度计算，让我帮忙写个工具。Go CLI。

N-gram 索引构建——文本按 2-gram 切分，每个 n-gram 映射到包含它的记录 ID 列表。索引存 JSON 文件。增量更新支持——新记录追加到现有索引，相同 ID 先删旧数据再插新数据。

模糊匹配加速——用户输入查询文本，先切 n-gram 查候选集，再对候选集计算精确相似度。相似度支持两种：编辑距离和 Jaccard 系数，用户通过参数选择。结果按相似度降序输出，默认返回 top 10。

表结构变更传播——如果搜索依赖的配置表结构变了，依赖该表的查询模板和报告配置需要更新。字段改名自动映射，字段删除标记为不可用，新增字段忽略。变更时记录变更日志，方便回溯。

导出数据时验证权限——导出前检查用户是否有该数据集的导出权限，同时查导出记录（限制每用户每天导出次数和总量）。权限检查和导出记录查询有双向依赖，用缓存避免循环查询：首次查询后缓存结果，后续请求直接用缓存。

go build 能过，命令行工具能正常运行。
