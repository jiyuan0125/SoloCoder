季度末了要出一份日志分析报告，需要一个能做后缀数组搜索和时间范围过滤的工具。Go 命令行。

后缀数组构建——对输入文本生成所有后缀并排序，用倍增算法实现。有了后缀数组，子串查找 O(m log n) 定位所有匹配位置。重复子串检测基于 LCP 数组——LCP 值超过阈值的就是重复出现的模式，按长度降序输出。构建结果持久化到 JSON 文件，避免重复计算。

消息格式兼容——消息格式升级后（比如 v2 新增了字段），旧格式的消费者要能兼容处理。实现方式：解析时忽略未知字段，缺失字段用默认值填充。版本号通过消息头部的 version 字段标识。

输入文件编码不确定——常见编码都要支持：UTF-8（直接处理）、GBK（用 golang.org/x/text/encoding/simplifiedchinese 转换）、Latin-1（直接按字节读）。编码检测基于文件头 BOM 和内容统计（中文高频字节特征）。检测失败默认按 UTF-8 处理，解析出错再尝试 GBK。

搜索结果按时间范围过滤——用户通过 -from 和 -to 参数指定时间范围，工具只返回文件修改时间在该范围内的匹配结果。时间格式支持 YYYY-MM-DD 和 RFC3339 两种。

go build 能过，命令行工具能正常运行。
