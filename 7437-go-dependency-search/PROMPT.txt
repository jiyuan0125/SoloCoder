之前用脚本手动做搜索结果汇总太耗时了——每次格式不一样，对比分析完全靠肉眼。这回用 Go 写一个带聚合统计和索引持久化的搜索工具。

搜索结果聚合——用户搜一批文件，工具返回匹配行的同时做聚合：按文件统计命中数、按关键词统计命中数、按文件类型分面统计。聚合结果输出 JSON 结构，包含 total、by_file、by_keyword、by_ext 四个维度。

分面统计和结果排序——用户指定分面维度，工具在搜索时同时计算分面数据。结果排序支持相关度（TF-IDF）和时间（文件修改时间），通过 -sort 参数切换。

索引持久化——搜索索引序列化到 JSON 文件，包含版本号和构建时间。启动时版本不匹配自动重建。支持索引合并——多个索引文件按文档 ID 去重后合并。

证书签发——证书签发需要 CA，但 CA 怎么初始化不在这里指定。你可以用自签名证书、内置 CA 配置、或从文件加载。关键是签发流程和搜索流程解耦，搜索工具只需校验证书有效性（未过期、未被吊销）。

代码分成：搜索引擎核心、索引 IO、命令行入口三个文件。

go build 能过，命令行工具能正常运行。
