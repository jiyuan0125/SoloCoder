组长上周说要搞工具化建设，搜索是第一个要统一的。Go CLI，支持模糊搜索和 N-gram 索引。

模糊搜索基于 Levenshtein 编辑距离——用户传查询词和阈值，返回所有编辑距离在阈值内的匹配。搜索结果按距离排序输出，距离相同按文本位置排序。命中部分用 ANSI 颜色高亮，红色标记匹配字符。

N-gram 索引加速——文本按 2-gram 切分建立倒排表。搜索时先拿查询词的 n-gram 查候选集，再对候选集精确计算。索引数据存 JSON 文件，支持增量追加。

权限规则支持多层级路径——比如 rules/{group}/{name}/{version}，rules/security/sql-injection/v2。搜索时匹配最具体的规则，没有具体规则再向上回退到分组级别。规则路径解析后缓存，避免重复解析。

多目录并行扫描——用户传多个目录时，每个目录起一个 goroutine 并行扫描。目录间互不依赖，结果通过 channel 汇总。并行度默认 CPU 核数。单个目录内的文件也支持并行（worker pool 模式）。

go build 能过，命令行工具能正常运行。
