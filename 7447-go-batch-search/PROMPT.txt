隔壁组刚做完数据同步工具，我们搜索聚合能力也得跟上。Go 实现。

搜索结果聚合统计——用户搜关键词，返回匹配行的同时做聚合分析。按文件维度统计每个文件的命中数，按关键词维度统计每个关键词的命中数。聚合结果输出 JSON 格式，包含 total_matches（总命中数）、by_file（按文件统计）、by_keyword（按关键词统计）三个维度。JSON 结构清晰方便下游工具消费。

分面统计——用户指定分面维度（文件类型 .go/.java/.py、目录层级、文件修改时间区间如最近7天/30天/更早），工具在每个分面桶内统计命中数量。分面结果和搜索结果一起输出。

结果排序——支持相关度排序（简化版 TF-IDF 打分）和时间排序（文件修改时间），通过 -sort relevance|time 参数切换。默认相关度排序。

认证和日志——认证通过后自动记录访问日志，日志内容包含用户 ID、搜索关键词、命中文档数、查询耗时。日志写入失败不影响搜索结果返回。日志用 append 模式写入文件，写失败只打 warn 日志。

go build 能过，命令行工具能正常运行。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
