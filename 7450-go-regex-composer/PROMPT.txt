V2 版本月底上线，搜索索引管理是基础能力，先把这块做了。Go 命令行。

索引持久化——搜索索引（倒排表、文档列表、统计信息）全部序列化到 JSON 文件。文件包含版本号和构建时间戳。启动时版本不匹配自动重建。索引路径通过 -index-dir 指定，默认 .index/。

索引重建——全量扫描文档集，重写 JSON 文件。重建期间旧索引可用（读写分离），写完后 rename 原子替换。

索引合并——两个索引文件按文档 ID 去重合并，相同 ID 保留最新版本。合并完生成新索引文件。

表结构变更传播——搜索依赖的配置表结构变更后（字段改名、新增、删除），依赖该表的查询模板和报告配置要更新。字段改名自动映射，删除标记为不可用，新增忽略。变更记录审计日志。

日志脱敏——日志里绝对不打印密钥、密码、token 等敏感信息。打印前做脱敏处理（保留前 4 位和后 4 位，中间用 *** 替代）。对已知敏感字段名（password、secret、token、key）自动检测脱敏。

go build 能过，命令行工具能正常运行。
