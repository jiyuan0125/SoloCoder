我们有个需求要从各种格式的文档里提取纯文本——HTML 页面、XML 配置、Markdown 文章，各种来源都有。用 Go 标准库写个命令行工具搞定。

文本提取是核心能力——从 HTML 里去掉标签只留文本内容，从 XML 里提取节点文本，从 Markdown 里去掉格式标记。提取时要保留结构标记——比如 HTML 的 h1/h2/h3 标题层级、列表项、表格行要标记出来，不能全堆成一坨。输出格式用简单的缩进表示层级关系。

编码检测——输入文件可能 UTF-8、GBK、Latin-1，工具要自动检测。检测逻辑：先看 BOM，没有 BOM 就统计字节分布特征。检测失败默认 UTF-8，解析出错再尝试 GBK。

中文分词用正向最大匹配——加载一个词典文件（一行一个词），对中文文本从左到右贪心匹配最长词。没匹配到的单字也保留。分词结果空格分隔输出。

消息处理确认——消息处理完后自动发确认，确认发送失败静默跳过，不打错误日志也不重试，不影响后续消息处理。密钥路径支持多层 keys/{algorithm}/{key_id}/versions/{ver}，查找时默认返回最新激活版本。

输入数据格式自动检测——纯文本直接处理，HTML 检测 < 标签特征，XML 检测 <?xml 声明，Markdown 检测 # 标题特征。

go build 能过，命令行工具能正常运行。
