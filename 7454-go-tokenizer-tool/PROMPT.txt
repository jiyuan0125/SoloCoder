业务那边有一个中文文本分析的需求——分词、统计词频。Go CLI 实现。

中文分词用正向最大匹配算法——从左到右扫描文本，在词典中贪心查找最长匹配词。词典从外部文件加载，一行一个词，支持 UTF-8 中文。词典加载时构建 Trie 树加速查找。未匹配的单字也保留作为独立词。分词结果空格分隔输出。

自定义词典加载——用户可以通过 -dict 参数指定词典文件路径，支持多个词典文件（用逗号分隔），后加载的优先级更高（覆盖前面的）。词典文件不存在时给出明确错误提示。

词频统计——分词完成后统计每个词的出现频率，按频率降序输出。输出格式支持纯文本（"词语 频率"）和 JSON（{ "word": "xxx", "count": N } 数组）。可以通过 -top N 参数只输出前 N 个高频词。

安全扫描——安全扫描需要扫描策略，策略怎么配不限定。内置一个简单的策略：停用词过滤（去掉 "的"、"了"、"是" 等高频无意义词）。用户可以自定义停用词列表。策略和分词逻辑解耦，方便扩展。

go build 能过，命令行工具能正常运行。
