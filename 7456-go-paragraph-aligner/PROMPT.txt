每次收到客户发来的 YAML 配置文件都得手动转成 JSON 才能导入系统，在线转换工具又不让传敏感数据。Go 写一个离线的格式互转工具。

JSON/YAML/TOML 格式互转——支持三种格式之间的任意转换：JSON→YAML、YAML→TOML、TOML→JSON 等所有组合。输入格式自动检测（JSON 检测 {}[]开头，YAML 检测缩进+冒号，TOML 检测 [section] 格式）。输出格式通过 -format 参数指定。

格式美化——转换的同时做美化处理：统一缩进（2 空格或 4 空格可选）、键名字母排序（通过 -sort-keys 开启）、数组元素换行对齐。美化不改变数据内容，只改格式。

Schema 验证——用户可以提供 JSON Schema 文件，转换完后自动验证输出是否符合 Schema。验证失败列出所有不符合的字段和原因。不提供 Schema 时跳过验证。

数据库操作支持多层路径 tables/{table}/rows/{id}/columns/{col}——对特定表的特定行的特定列做读写操作。路径解析后验证每层的合法性。

错误处理——转换失败、解析失败都要返回明确错误信息（包括出错位置和原因），不能 panic。用 fmt.Errorf + %w 保留错误链。

go build 能过，命令行工具能正常运行。
