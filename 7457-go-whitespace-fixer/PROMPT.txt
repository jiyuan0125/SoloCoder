有个老 Python 脚本做文本去重，但只能精确匹配——完全一样的行才算重复，模糊去重完全不行。Go 重写一个，加上相似度检测。

文本去重两种模式——精确去重：对文本行做哈希（SHA256），哈希相同认为重复，保留第一行删除后续重复行。模糊去重：计算行间相似度，支持两种算法——Jaccard 系数（基于 n-gram 集合交集/并集）和编辑距离（Levenshtein）。用户通过 -algorithm jaccard|edit-distance 选择。相似度阈值通过 -threshold 参数配置，默认 0.8。

去重报告——处理完成后输出统计信息：总行数、唯一行数、重复行数（精确+模糊分别统计）。报告支持 JSON 格式输出。去重后的文本输出到 stdout 或指定文件（-o 参数）。

消息 topic 通配符匹配——topic 支持 "a.b.c.#" 格式的多层通配符。* 匹配单层（如 order.*.paid），# 匹配零或多层。匹配用 Trie 数据结构实现。

路径安全——用户输入的文件路径要做安全检查，防止目录遍历（路径中不允许出现 ".."），解析后绝对路径必须在允许的工作目录范围内。越界路径拒绝并报错。

go build 能过，命令行工具能正常运行。
