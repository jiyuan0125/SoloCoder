每次发版都要手动对比配置文件差异，三个环境改来改去经常遗漏。需要一个本地 Diff 加合并工具，顺带支持模板渲染。Go 实现。

Diff 生成——比较两个文本文件，输出差异。用最长公共子序列（LCS）算法实现。输出格式支持 unified diff（就是 git diff 那种格式，带 + 和 - 标记）。Diff 结果用 ANSI 颜色高亮：删除行红色，新增行绿色。

Diff 应用——拿一个 patch 文件应用到原始文件。patch 格式就是上面生成的 unified diff 格式。应用前先检查 patch 是否能干净地应用（所有上下文行都匹配），有冲突就报错不强行应用。

三路合并——给定 base、branch-a、branch-b 三个文件版本，做三路合并。两边改了不同位置自动合并，两边改了同一位置标记冲突（用 <<<<<<< ======= >>>>>>> 标记）。

模板渲染——用 Go 标准库 text/template 做文本模板渲染。加载模板文件和数据文件（JSON），渲染后输出。支持自定义函数。

搜索路径支持多层 indexes/{name}/docs/{doc_id}/fields/{field}，逐级查找定位到具体字段。

go build 能过，命令行工具能正常运行。
