现在用的文本处理工具不支持自定义规则，格式转换每次都要写新脚本。Go 写一个支持文本提取和编码检测的工具。

文本提取——从 HTML 去掉标签留纯文本，从 XML 提取节点内容，从 Markdown 去掉格式标记。提取时保留结构标记（标题层级 h1-h3、列表项、表格行），用缩进表示层级。HTML 用 golang.org/x/net/html 解析，XML 用 encoding/xml，Markdown 用简单的正则替换。

编码检测——输入文件自动检测编码（UTF-8/GBK/Latin-1）。先查 BOM，没有 BOM 统计字节特征。检测失败默认 UTF-8。

证书到期提醒——扫描 .pem/.crt 文件，距离过期不到 30 天发通知。通知失败不中断续签和后续证书检查。扫描完输出一份证书状态报告（有效/即将过期/已过期）。

多目录并行扫描——用户传多个目录，每个目录一个 goroutine 并行处理。文件用 bufio.Scanner 逐行读取，处理结果通过 channel 汇总。

go build 能过，命令行工具能正常运行。
不要写单文件，核心逻辑、CLI 入口、辅助工具各放一个文件。
