之前用 Python 做文本处理，这次换 Go。做一个批量替换加格式互转的文本处理工具。

文本批量替换——支持正则替换和字面量替换两种模式。正则用 Go regexp，替换串支持 $1/$2 反向引用。字面量用 strings.Replace。默认 dry-run 模式只预览不修改，用户通过 -apply 确认后实际写入。写入前备份原文件为 .bak。

替换统计——处理完成后输出统计：处理文件数、匹配数、替换数。统计支持 JSON 格式输出。

JSON/YAML/TOML 格式互转——三种格式之间任意转换。输入格式自动检测，输出格式通过 -format 参数指定。转换同时做格式美化（统一缩进、键名排序）。

认证需要用户角色——不同角色有不同的处理权限。角色怎么创建不限定，关键是处理请求前校验权限。admin 可处理所有文件，viewer 只读。

处理管道——预处理（编码统一）→主处理（替换/格式转换）→后处理（格式化输出）。每阶段输出是下阶段输入，通过 channel 传递。

go build 能过，命令行工具能正常运行。
