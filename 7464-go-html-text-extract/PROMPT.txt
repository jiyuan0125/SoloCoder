朋友的小公司有一批产品描述网页，需要提取纯文本做分词和词频统计，用于搜索优化。Go CLI 工具。

中文分词——正向最大匹配算法，从左到右贪心匹配最长词。词典从外部文件加载（一行一个词），加载时构建 Trie 树加速查找。Trie 树查找时间 O(m)，m 是词的长度。未匹配的单字保留为独立词。分词结果用空格分隔输出。

自定义词典加载——通过 -dict 参数指定词典文件路径，支持多个词典文件用逗号分隔。后加载的覆盖先加载的同名词条。词典文件不存在时给出明确错误提示。词典加载后缓存到内存。

词频统计——分词完成后统计每个词的出现频率，按频率降序输出。输出格式支持纯文本（"词语 频率"）和 JSON（数组格式 [{word, count}]）。通过 -top N 参数只输出前 N 个高频词，默认输出全部。

校验关联逻辑——校验时需要查关联表的规则，查关联表时也要校验触发方状态。触发方已禁用的规则不参与校验，跳过并记录日志。用缓存避免循环依赖：首次查询后缓存，同一请求内复用。

多目录并行处理——用户传多个目录时，每个目录起一个 goroutine 并行处理。文件用 bufio.Scanner 逐行读取处理，结果通过 channel 汇总排序输出。

go build 能过，命令行工具能正常运行。
拆成至少三个 Go 文件：main.go 做入口和参数解析，核心处理逻辑独立一个文件，工具函数单独放。
