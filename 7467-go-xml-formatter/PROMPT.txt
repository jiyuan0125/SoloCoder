之前用脚本对账经常出错——数据重复没检测出来，格式还不统一。换 Go 写一个去重加分类的文本处理工具。

文本去重——精确去重：对文本行做 SHA256 哈希比较，哈希值相同认为重复，保留第一行删除后续重复行。模糊去重：计算行间相似度（Jaccard 系数，基于字符 2-gram 集合），超过阈值（默认 0.8，-threshold 可配）认为近似重复。去重报告输出统计：总行数、唯一行数、精确去重数、模糊去重数，支持 JSON 格式输出方便脚本消费。

文本分类——基于规则分类。用户定义匹配规则（正则或关键词）和分类标签，文本逐条匹配命中打标签。一条文本可以匹配多个规则产生多标签，不匹配标记"未分类"。分类结果和去重结果合并输出。

消息发送——消息发送需要 topic，topic 怎么创建不限定。内存队列或文件系统都行，关键是统一发送接口。发送失败重试 3 次后跳过，不阻塞主流程。

输入容错——可能有乱码行和空行。乱码行跳过记录行号，空行直接跳过，都不影响正常行处理。

go build 能过，命令行工具能正常运行。
