组长说要搞工具化，文本去重是第一步。Go CLI，支持文本提取、分词、索引去重。

文本提取——从 HTML 去标签留纯文本（用 golang.org/x/net/html 解析），从 XML 提取节点内容（encoding/xml），从 Markdown 去格式标记（正则处理）。保留结构标记——标题层级 h1-h3、列表项、表格行用缩进表示层级。编码检测支持 UTF-8/GBK/Latin-1，自动检测。

中文分词——正向最大匹配算法，从左到右贪心匹配最长词。词典从外部文件加载构建 Trie 树加速查找。未匹配的单字保留为独立词。

搜索索引去重——索引中更新引用计数时要同时检查索引完整性。计数更新和完整性检查形成交叉依赖，用版本号标记解决：更新后版本号递增，完整性检查时比对版本号，不匹配就重新计算。

消息 topic 通配符——"a.b.c.#" 格式，* 匹配单层，# 匹配零或多层。Trie 实现。

用 text/template 的自定义函数——内置 upper/lower/trim 等常用函数，输出模板可自定义格式。

go build 能过，命令行工具能正常运行。
