线上老工具的文本替换功能太简陋了——不支持 dry-run，每次替换完发现改错了只能手动恢复。Go 重写一个正经的批量替换工具。

文本批量替换——正则替换（Go regexp 标准库，替换串支持 $1/$2 反向引用）和字面量替换（strings.Replace），通过 -mode regex|literal 参数切换模式。默认 dry-run 模式只预览不修改文件——输出用 ANSI 颜色区分原文本（红色）和替换后文本（绿色），左右对比显示。用户确认替换内容无误后通过 -apply 参数触发实际写入。写入前自动备份原文件为 .bak。

替换统计——处理完成后输出统计报告：扫描了多少文件、找到多少处匹配、实际替换多少处。统计支持 JSON 格式输出方便脚本消费。

数据转换映射——数据转换需要映射模板，模板怎么定义不限定。Go template 语法或简单占位符都行，关键是替换操作能按模板格式化输出。

用 encoding/xml 的 Marshal/Unmarshal——搜索结果支持 XML 格式导出，字段用 XML tag 标注。读取 XML 配置文件时 Unmarshal 到结构体，解析失败返回明确错误信息。

go build 能过，命令行工具能正常运行。
