开源文本工具的自定义转换规则写得一塌糊涂，没法扩展。Go 从零写一个格式互转加 Schema 验证工具。

JSON/YAML/TOML 格式互转——三种格式之间任意方向转换。输入格式自动检测：JSON 检测 {}或[]开头，YAML 检测缩进+冒号格式，TOML 检测 [section] 声明。输出格式通过 -format json|yaml|toml 参数指定。转换过程：源格式反序列化到 map[string]interface{} →目标格式序列化输出。中间结构体兼容三种格式所有数据类型。

格式美化——统一缩进（2 或 4 空格，通过 -indent-size 参数配置），键名按字母排序（-sort-keys 开启），数组元素逐个换行对齐。美化只改变格式不改变数据内容。

Schema 验证——用户可以提供 JSON Schema 文件，转换完成后自动验证输出是否符合 Schema。验证失败列出所有不符合的字段名、期望值和实际值。不提供 Schema 时跳过验证步骤。

密钥轮换兼容——密钥轮换后，用旧密钥加密的数据要能解密。维护一个密钥版本列表，加密数据头标记密钥版本号，解密时按版本号找到对应密钥。旧密钥设置保留期，保留期内不删除。

go build 能过，命令行工具能正常运行。
项目要用多文件结构，入口文件、业务逻辑、数据模型分开放，别揉在一个文件里。
