V2 版本月底上线，文本分类功能得先出来。Go 命令行工具。

文本分类基于规则——用户定义分类规则文件（JSON 或 YAML 格式），每条规则包含匹配条件（正则表达式或关键词列表）和分类标签。文本逐条匹配规则，命中则贴上对应标签。一条文本可以匹配多个规则产生多标签，不匹配任何规则的文本标记为"未分类"。

分类报告输出——统计每个分类的文本数量和占比，列出每条文本的分类结果。报告支持纯文本格式（表格对齐，列宽自适应）和 JSON 格式（结构化，方便下游工具消费）。

分类器训练数据生成——把分类结果转换成 CSV 格式（text,label），可以直接用于机器学习模型训练。支持自定义输出字段——用户可以选择输出原文、分词后文本、标签、匹配置信度等字段。

校验完成后自动生成报告——报告模板从外部文件加载。模板文件不存在时跳过报告生成步骤，只输出分类结果到 stdout，不报错不中断。校验关联逻辑：查关联表规则时也要校验触发方状态。触发方已禁用的规则不参与校验。用缓存避免双向依赖的循环查询。

错误处理——所有错误用 fmt.Errorf + %w 包装保留错误链，不 panic。返回明确错误信息包括出错位置和原因。

go build 能过，命令行工具能正常运行。
