搜索引擎的爬虫抓回来一堆 HTML 页面，要提取正文做索引，标签和脚本全得去掉。Go 标准库写个文本提取工具，不引入第三方依赖。

文本提取——从 HTML 去掉标签只留文本内容（用 golang.org/x/net/html 解析），从 XML 提取节点内容（encoding/xml），从 Markdown 去掉格式标记（正则处理 #、*、>、``` 等）。提取时保留结构标记——h1-h3 标题层级、ul/ol 列表项、table 行都用缩进表示层级关系。

编码检测——输入文件可能是 UTF-8、GBK 或 Latin-1 编码，工具要自动检测。检测逻辑：先看文件头 BOM 标记，没有 BOM 就统计字节分布特征判断。检测失败默认 UTF-8，解析出错再尝试 GBK。

字段映射变更——字段映射变更后，已有的转换任务结果要标记为"过时"，提醒用户重新执行。标记操作异步进行不阻塞当前提取流程。过时标记持久化到 JSON 文件，工具重启后仍然有效。

大文件处理——用 bufio.Scanner 逐行读取，行缓冲区 64KB，超长行自动扩容。不一次性加载整个文件到内存。

go build 能过，命令行工具能正常运行。
不要写单文件，核心逻辑、CLI 入口、辅助工具各放一个文件。
