数据库迁移要把一批 SQL 文件里的表名前缀从 old_ 全换成 new_，还得把配置文件从 YAML 转成 JSON。Go CLI 一个工具搞定。

文本批量替换——正则替换（Go regexp 标准库，替换串支持 $1/$2 反向引用）和字面量替换（strings.Replace），通过 -mode regex|literal 切换。默认 dry-run 模式只预览不修改文件，输出用 ANSI 颜色区分原文本和替换文本。用户确认后通过 -apply 参数触发实际写入，写入前自动备份原文件为 .bak。替换统计输出：处理文件数、匹配数、替换数。

JSON/YAML/TOML 格式互转——三种格式之间任意方向转换。输入格式自动检测，输出格式通过 -format 指定。转换流程：源格式反序列化→map[string]interface{}→目标格式序列化。

消息格式兼容——消息格式升级后（比如 v2 新增字段），旧格式的消费者要能兼容处理。解析时忽略未知字段，缺失字段用默认值填充。版本号通过消息头 version 字段标识。

消息发送——需要 topic，topic 怎么创建不限定。内存队列或文件系统都行，关键是统一发送接口。发送失败重试 3 次，每次间隔递增 1s/2s/4s，超过次数跳过。

go build 能过，命令行工具能正常运行。
代码分文件组织，解析器、处理器、输出器分开，main.go 只做参数解析和流程串联。
