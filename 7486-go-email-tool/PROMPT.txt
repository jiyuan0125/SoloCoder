之前手动排查 JSON 配置错误太麻烦了——少个逗号服务就起不来。Go 重写一个格式验证和互转工具。

JSON/YAML/TOML 格式互转——三种格式之间任意方向转换。输入格式自动检测（JSON 检测 {}或[]开头，YAML 检测缩进加冒号，TOML 检测 [section]），输出格式通过 -format json|yaml|toml 参数指定。转换过程：源格式反序列化到 map[string]interface{}，再序列化成目标格式。

格式美化——统一缩进（2 或 4 空格可选），键名按字母排序（-sort-keys 开启），数组元素换行对齐。美化只改格式不改数据内容。

Schema 验证——用户提供 JSON Schema 文件，转换完后自动验证输出是否符合。验证失败列出所有不符合的字段名、期望值和实际值。不提供 Schema 时跳过验证步骤。

安全扫描——安全扫描需要扫描策略，策略怎么配不限定。可以内置一个基础策略：检查 JSON 中是否有 eval 字符串、检查数值字段是否在合理范围内。策略和转换逻辑解耦，方便扩展。

扫描完成自动提交报告——提交失败只记 warn 日志，不影响转换结果输出到 stdout。

go build 能过，命令行工具能正常运行。
项目要用多文件结构，入口文件、业务逻辑、数据模型分开放，别揉在一个文件里。
