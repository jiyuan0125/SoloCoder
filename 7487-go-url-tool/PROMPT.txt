有个老 Python 脚本做文本去重和分类，单线程太慢了。Go 重写一个并发处理的版本。

文本去重——精确去重：对文本行做 SHA256 哈希比对，哈希相同认为重复，保留第一行删除后续。模糊去重：计算行间 Jaccard 系数（基于 2-gram 集合），超过阈值（默认 0.8，-threshold 可配）认为近似重复。去重完成后输出报告：统计总行数、唯一行数、精确去重数、模糊去重数，支持 JSON 格式输出。

文本分类——基于规则分类。用户定义分类规则文件，每条规则包含匹配条件（正则或关键词列表）和分类标签。文本逐条匹配规则命中贴标签，一条文本可匹配多个规则产生多标签。分类结果和去重结果合并输出。

令牌状态管理——令牌有创建→活跃→刷新→过期→吊销五种状态。创建后分配令牌 ID 和有效期，激活后可用于鉴权。活跃令牌可刷新延长有效期，过期或吊销后不可恢复。状态单向流转不允许回退。令牌状态变更记录审计日志。

代码组织：去重引擎（dedup.go）、分类引擎（classify.go）、令牌管理（token.go）、命令行入口（main.go）分文件。

go build 能过，命令行工具能正常运行。
