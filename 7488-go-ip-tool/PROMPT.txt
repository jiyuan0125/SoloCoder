客户发来的数据包全是 zip 压缩的文本文件，解压再统计太麻烦。Go 写个直接从 zip 包读取的文本统计工具，自动分析字数和关键词。

文本统计——字数统计区分中英文：中文按字计数，英文按空格分词后按单词计数。行数统计包括总行数、空行数、非空行数。字符分布统计中文、英文、数字、空白、标点各多少个及其百分比。统计结果用表格格式输出，列对齐方便阅读。

可读性评分——中文文本基于平均句长（句号之间的平均字数）和长句占比打分，英文文本用 Flesch-Kincaid 公式。分数 0-100，越高越容易阅读。同时输出评分和简短的难度等级说明。

关键词提取——TF-IDF 算法。需要先加载一个参考语料库的文档频率表（从 JSON 文件读取），然后对当前文本做分词，计算每个词的 TF-IDF 分数，按分数降序输出 top N 关键词。N 通过 -top 参数配置默认 10。支持批量处理 zip 包内的所有文本文件。

规则校验——规则校验需要规则组，规则组怎么来的不限定。关键是校验逻辑和统计逻辑解耦。

任务状态——任务有等待、运行、成功、失败四个状态。等待中被 worker 取走变运行，完成标记成功或失败。不自动重试。

go build 能过，命令行工具能正常运行。
至少拆成两个包或三个文件以上，不要单文件一把梭。
