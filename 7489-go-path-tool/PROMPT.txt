群里有人说缺一个好用的 Diff 合并工具，Go 搞一个。

Diff 生成——比较两个文本文件，用最长公共子序列（LCS）算法找差异。输出 unified diff 格式（+/- 标记），ANSI 颜色高亮：删除行红色背景，新增行绿色背景。支持逐行和逐词两种粒度，通过 -granularity line|word 参数选择。逐词模式对每行内部做词级对比，精确到单词变化。

Diff 应用——拿 patch 文件应用到原始文件。patch 格式就是 unified diff。应用前先检查所有上下文行是否完全匹配，任何一行对不上就不应用，返回错误信息和出错行号。不能强行应用导致数据损坏。

三路合并——给定 base、branch-a、branch-b 三个文件版本。两边改了不同位置自动合并，两边改了同一位置标记冲突（<<<<<< branch-a / ======= / >>>>>>> branch-b）。合并完成后输出统计：自动合并数和冲突数。

转换结果写入——转换完后自动写入目标路径，目标不可用时不报错，只打 warning 日志。结果同时输出到 stdout 兜底。

文件操作权限检查——读写文件前检查权限（os.FileMode），无权限返回明确错误。目录不存在时自动创建（os.MkdirAll 模式）。

go build 能过，命令行工具能正常运行。
