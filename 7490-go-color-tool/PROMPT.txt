下周要演示文本分类能力，先出个能跑的版本。Go CLI 工具。

文本分类基于规则——用户定义分类规则文件（JSON 格式），每条规则包含匹配条件（正则表达式或关键词列表）和分类标签。工具对文本逐条匹配规则，命中则贴上对应标签。一条文本可以匹配多个规则产生多标签，不匹配任何规则的文本标记为"未分类"。默认按规则定义顺序匹配，先命中的优先级更高。

分类报告输出——统计每个分类的文本数量和占比，列出每条文本的分类结果。报告支持纯文本格式（表格对齐，列宽自适应）和 JSON 格式（结构化数据，方便下游工具消费）。纯文本格式用 ANSI 颜色区分不同分类标签。

训练数据生成——把分类结果转换成 CSV 格式（text,label），可以直接用于机器学习模型训练。支持自定义输出字段——用户可以选择输出原文、分词后文本、标签等，通过 -fields 参数指定。

导出权限——导出数据时验证用户权限，同时查导出记录（限制每用户每天导出次数和总量）。权限检查和导出记录查询有双向依赖，用缓存避免循环：首次查询后缓存结果，同一请求内复用。

用 archive/zip 的 Reader/Writer——支持从 zip 包直接读取文本文件进行分类，分类结果也可以打包输出为 zip。

go build 能过，命令行工具能正常运行。
代码按模块拆分，不要把所有逻辑写在一个文件里。解析、转换、输出分开组织。
