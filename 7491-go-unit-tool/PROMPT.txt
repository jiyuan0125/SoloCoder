现在用的文本提取工具不支持自定义规则，格式转换每次都要写新脚本。Go 写一个文本提取加分词工具，命令行。

文本提取——从 HTML 去掉标签只留纯文本内容，从 XML 提取节点文本，从 Markdown 去掉格式标记（#、*、>、``` 等）。提取时要保留结构标记——比如 HTML 的 h1-h3 标题层级、ul/ol 列表项、table 行要标记出来，用缩进表示层级关系。HTML 解析用 golang.org/x/net/html，XML 用 encoding/xml，Markdown 用简单正则处理。

编码检测——输入文件可能是 UTF-8、GBK 或 Latin-1 编码，工具要自动检测。检测逻辑：先看 BOM 标记，没有 BOM 就统计字节分布特征判断。检测失败默认 UTF-8，解析出错再尝试 GBK。

中文分词——正向最大匹配算法。从左到右扫描文本，在词典中贪心查找最长匹配词。词典从外部文件加载（一行一个词），加载时构建 Trie 树加速查找。未匹配的单字保留为独立词。分词结果用空格分隔输出。

证书状态流转——证书有申请→签发→生效→过期→续签五种状态。签发需要审核通过，生效期间可手动触发续签，过期后 30 天内仍允许续签一次。状态只能正向流转，不允许回退。每次状态变更都记录审计日志（变更时间、旧状态、新状态）。

go build 能过，命令行工具能正常运行。
不要写单文件，核心逻辑、CLI 入口、辅助工具各放一个文件。
