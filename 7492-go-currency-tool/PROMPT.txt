调研了一圈模板方案，Go 标准库 text/template 就够了——语法简洁、执行安全、不需要额外依赖。做一个模板渲染工具。

模板渲染——Go text/template 标准库。加载模板文件和数据文件（JSON），渲染后输出到 stdout 或指定文件（-o 参数）。支持完整模板语法：{{.Field}} 变量、{{range .Items}} 循环、{{if .Condition}} 条件、{{with .Context}} 上下文切换、管道操作。

自定义函数注册——内置常用函数：upper/lower/trim/replace/split/join/date/now。用户可通过 plugin 包加载外部 .so 扩展函数（编译时注册或运行时动态加载）。

模板继承——子模板 extends 基础模板，覆盖指定 block。基础模板定义骨架和 block 默认内容，子模板只覆盖需要定制的部分。未覆盖的 block 用默认内容渲染。

加密密钥——加密需要密钥，密钥怎么导入不限定（文件、环境变量、配置）。

消息 topic 通配符——"a.b.c.#" 格式，* 匹配单层，# 匹配零或多层。Trie 实现匹配。

批量操作并发执行——多个模板渲染任务并行处理，goroutine 数默认 CPU 核数。结果按原始任务顺序汇总输出。

go build 能过，命令行工具能正常运行。
项目结构要分模块：主入口、核心处理逻辑、工具函数分文件组织，方便测试和维护。
