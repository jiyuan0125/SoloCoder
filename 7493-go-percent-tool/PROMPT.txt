之前用 Python 做文本替换太慢了——几十个文件正则替换要跑好几分钟。换 Go 重写，批量替换工具。

文本批量替换——支持正则替换和字面量替换两种模式。正则模式用 Go regexp 标准库，替换串支持 $1/$2 反向引用，方便提取和重组。字面量模式用 strings.Replace 做精确替换。用户通过 -mode regex|literal 参数选择模式。

替换预览——默认 dry-run 模式，只展示将要替换的内容不实际修改文件。输出用 ANSI 颜色区分：原文本红色，替换后文本绿色，左右对比显示。用户确认替换内容无误后，通过 -apply 参数触发实际写入。写入前自动备份原文件为 .bak 文件。

替换统计——处理完成后输出统计报告：扫描了多少个文件、找到了多少处匹配、实际替换了多少处。统计结果支持 JSON 格式输出，方便被其他脚本消费。

扫描状态管理——扫描有五个状态：排队→扫描中→分析中→报告生成→完成。排队等待空闲 worker 取任务，扫描中逐文件处理做匹配，分析中汇总统计，报告生成阶段格式化输出，完成释放资源。状态单向流转，完成后不自动重置，用户需通过 -rerun 参数重新触发。状态变更持久化到 JSON 文件，工具重启后可恢复。

go build 能过，命令行工具能正常运行。
代码分文件组织，解析器、处理器、输出器分开，main.go 只做参数解析和流程串联。
