上次出事故——手动改 YAML 配置缩进错了，服务起不来排查了两个小时。需要一个格式验证和互转工具。Go 实现。

JSON/YAML/TOML 格式互转——三种格式之间任意方向转换。输入格式自动检测（JSON 检测 {}或[]开头，YAML 检测缩进加冒号，TOML 检测 [section]），输出格式通过 -format json|yaml|toml 参数指定。转换过程：源格式→map[string]interface{}→目标格式序列化。

格式美化——统一缩进（2 或 4 空格可选，-indent-size 配置），键名按字母排序（-sort-keys 开启），数组元素逐个换行对齐。美化只改格式不改数据内容。

Schema 验证——用户提供 JSON Schema 文件，转换完自动验证。验证失败列出不符合的字段和原因。无 Schema 跳过验证。

索引状态——索引有初始化→构建中→可用→重建→下线五种状态。构建中不响应查询，可用正常工作。不允许跳跃状态转换。

审计日志——按多层路径 audits/{year}/{month}/{day}/{id} 组织。每次转换操作记录审计日志。目录不存在自动创建。

go build 能过，命令行工具能正常运行。
