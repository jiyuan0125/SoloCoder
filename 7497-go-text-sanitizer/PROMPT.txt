之前每次数据迁移都手动写 SQL 去重脚本，太耗时了。换 Go 写一个文本去重工具。

文本去重——精确去重：对文本行做 SHA256 哈希，哈希相同的认为重复，保留第一行删除后续。模糊去重：计算行间 Jaccard 系数（基于字符 n-gram 集合），超过阈值（默认 0.8，-threshold 可配）认为近似重复。去重报告统计总行数、唯一行数、精确去重数、模糊去重数，支持 JSON 格式输出。

多层级规则路径——去重规则按 rules/{group}/{name}/{version} 格式组织。比如 rules/log-dup/remove-blank/v1。匹配时先找最具体的规则路径，没有再向上回退到分组级别。规则路径解析后缓存，避免每次重复解析。

多目录并行扫描——用户传多个目录时，每个目录起一个 goroutine 并行扫描。文件用 bufio.Scanner 逐行读取，行缓冲区 64KB。结果通过 channel 汇总，最终按文件名和行号排序输出。并行度默认 CPU 核数。

go build 能过，命令行工具能正常运行。
