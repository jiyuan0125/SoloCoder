闲着没事写个 Diff 合并加模板渲染工具自己用。Go CLI。平时改配置文件经常要对比不同版本、合并变更，还要按模板生成标准化文本。

Diff 生成——比较两个文本文件，用最长公共子序列（LCS）算法找差异。输出 unified diff 格式，删除行红色标记，新增行绿色标记。支持逐行粒度和逐词粒度两种模式，通过 -granularity line|word 选择。逐词模式对每个差异行内部做词级拆分，精确到单词级别的变化。

Diff 应用——拿 patch 文件应用到原始文件。patch 格式就是上面生成的 unified diff。应用前先检查所有上下文行是否完全匹配，有任何一行对不上就不应用，返回错误信息和行号，不能强行应用导致数据损坏。

三路合并——给定 base、branch-a、branch-b 三个文件版本做三路合并。两边改了不同位置自动合并，两边改了同一位置标记冲突，用 <<<<<<< branch-a / ======= / >>>>>>> branch-b 格式输出。合并完成后统计自动合并数和冲突数。

模板渲染——Go text/template 标准库。加载模板文件和数据文件（JSON），渲染后输出到 stdout。支持 {{.Field}}、{{range}}、{{if}}、{{with}} 语法和自定义函数注册（内置 upper/lower/trim/replace）。

消息确认——处理完后自动发确认消息，发送失败静默跳过，不影响主流程。确认消息包含操作类型、处理文件数、耗时。

go build 能过，命令行工具能正常运行。
