朋友那边需要文本分类和训练数据生成工具。Go 命令行。

文本分类基于规则——用户定义分类规则文件，每条规则含匹配条件（正则或关键词）和分类标签。文本逐条匹配，命中贴标签。多标签支持，不匹配任何规则标记"未分类"。分类报告统计各分类数量和占比，支持纯文本和 JSON 两种输出格式。纯文本表格对齐，JSON 结构化方便程序处理。

训练数据生成——把分类结果转成 CSV 格式（text,label），可直接用于机器学习模型训练。支持指定输出字段——原文、分词后文本、标签等，通过 -fields 参数选择。

加密后清理——加密操作完成后自动删除原文文件（os.Remove），删除失败不中断后续流程继续执行，只记 warn 日志。删除前确认文件存在且可写。

密钥轮换兼容——旧密钥加密的数据要能解密。维护密钥版本列表，数据文件头标记加密使用的密钥版本号，解密时按版本号查对应密钥。旧密钥设保留期，保留期内仍可用于解密。

用 encoding/json 的 Decoder 流式处理——大 JSON 文件逐 token 读取不全量加载内存。遇到格式错误跳过该 token 记录位置继续。

go build 能过，命令行工具能正常运行。
