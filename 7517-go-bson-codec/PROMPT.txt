MongoDB 迁移数据的时候碰到 BSON 格式的 dump 文件，想看看里面有什么内容但手头没工具。BSON 和 JSON 结构类似，但多了些扩展类型——日期时间、二进制数据、正则表达式、ObjectId，这些在 JSON 里没有直接对应。

写个 `bson-tool`，子命令 `to-json` 和 `from-json`。`bson-tool to-json` 读 BSON 二进制数据（从文件或 stdin），转成人类可读的 JSON。BSON 的扩展类型用特殊标记：ObjectId 变成 `{"$oid": "..."}`, 日期变成 `{"$date": "..."}`, 二进制变成 `{"$binary": {"base64": "...", "subType": "..."}}`。`bson-tool from-json` 反过来，把带扩展标记的 JSON 转成 BSON 二进制。

处理完成后自动归档——如果输入是文件，可以加 `--archive-dir` 指定归档目录，处理完的文件移过去并加时间戳。

工具支持多种输入输出格式：`--input-format` 可以是 `bson`（原始二进制）或 `bsondump`（MongoDB 的 bsondump 文本格式），`--output-format` 可以是 `json` 或 `extended-json`。字段映射通过 `--rename` 支持，格式 `old=new`。

转换过程中保留 `_id` 字段和文档顺序（BSON 是有序的）。遇到损坏的 BSON 文档报告偏移位置，尝试恢复后续文档。

Go 标准库，`go build`。
