数据分析那边每天要处理几百个 CSV 报表，入库之前得转成 JSON。手工一个个转显然不行，得自动化。而且 CSV 的列头和 JSON 的嵌套结构之间映射关系有时候不直接——第一行是列名，后面的行怎么变成 JSON 对象，需要灵活配置。

用 Go 写个 `csv2json-tool`。命令结构分两步：先解析 CSV 拿到列头和数据行，再把每行数据映射成 JSON 对象。输入支持文件路径（`--input`）和 stdin 管道。默认模式是每行变一个 JSON 对象，整体输出一个 JSON 数组。`--lines` 模式改为每行输出一个 JSON 对象（JSONL 格式），适合流式处理。

映射规则：CSV 列名默认直接做 JSON 键名。支持 `--mapping` 参数传入 JSON 文件指定复杂映射，比如把 `user_name` 列映射成 `{"user": {"name": "..."}}` 嵌套结构。`--separator` 指定 CSV 分隔符（默认逗号），`--quote` 指定引号字符。

Round-trip 验证：`--verify` 模式下，转完 JSON 后再试着按反向映射转回 CSV，和原始数据对比。对不上的地方输出差异报告。错误收集：不 panic，把所有行的错误（类型不匹配、缺列、多列）收集到列表，最后统一输出，每个错误标注行号和列名。

Go 标准库实现，`encoding/csv` 和 `encoding/json`。`go build`。
至少拆成两个包或三个文件以上，不要单文件一把梭。
