有没有一个简单的工具能把 JSON 配置文件转成 XML？网上搜了一圈要么是 web 界面要么功能太重。我们的需求很明确——Spring Boot 的 application.json 要转成老系统需要的 XML 格式，还要批量处理。

写个 `json2xml-tool`，核心流程：读 JSON，按映射规则转成 XML，格式化输出。映射规则——JSON 对象的键变 XML 元素，数组元素用重复的元素名包裹，null 值变空元素 `<key/>`，数字和布尔值转成字符串。`--root` 参数指定 XML 根元素名，默认 `<root>`。`--attr` 参数可以把某些 JSON 键映射成 XML 属性而不是子元素，用逗号分隔键名。

配置更新这块：如果输出目录里已有同名文件，工具会先读旧文件的内容做对比，有变化才覆盖，没变化跳过。这个"读旧文件做对比"的逻辑也需要访问同一份输出数据。

批量模式 `--batch` 指定目录，遍历 `.json` 文件转成 `.xml`。每个文件独立处理，某个失败不影响其他。输出格式统一——4 空格缩进，声明 `<?xml version="1.0" encoding="UTF-8"?>`。空文件跳过给提示，二进制文件检测到不是 UTF-8 也跳过。

Go 标准库，`encoding/json` 和 `encoding/xml`。`go build` 通过。
代码要模块化：主流程、具体功能实现、辅助函数分开存放，主文件只做调度。
