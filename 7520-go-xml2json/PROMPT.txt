把老系统的 Spring XML 配置迁移到 Spring Boot 的 JSON 格式，两百多个文件，手工转了三天发现进度才 10%。XML 的属性、命名空间、CDATA 这些概念 JSON 里没有直接对应，盲目转换会丢信息——得有个能自定义映射规则的工具。

`xml2json-tool` 先做解析再转换。第一步，用 `encoding/xml` 把 XML 解析成内存树。属性怎么处理？默认变 `$attr` 前缀的键，比如 `<item id="1">` 变成 `{"item": {"$attr-id": "1", "#text": "content"}}`。这个映射规则通过 `--mapping` 参数自定义，传入一个 JSON 文件描述属性名和元素名的对应关系。

转换时碰到混合内容（元素里既有文本又有子元素），文本部分放 `#text` 键，子元素正常嵌套。CDATA 区域的内容原样保留。命名空间前缀保留为键名的一部分，`--strip-ns` 可以去掉。注释默认丢弃，`--keep-comments` 模式下变成 `<!-- ... -->` 键。

第二步，把转换好的结构用 `encoding/json` MarshalIndent 输出，2 空格缩进。round-trip 验证用 `--verify`——转完 JSON 后再按反向规则转回 XML，对比结构和内容差异。错误收集不 panic，所有问题最后统一输出。

输入支持文件路径和管道。Go 标准库实现，`go build`。
