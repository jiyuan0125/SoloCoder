二进制协议解析——听起来就很底层，但在 IoT 和游戏开发里天天遇到。传感器数据包、自定义 RPC 协议，字节级别的拆包是家常便饭。问题是每次手写解析代码都容易出错，位操作一个不小心就对不上。

`bin-tool` 做两件事：按模板解析二进制数据，和把结构化数据序列化成二进制。模板用 JSON 描述格式定义，比如 `[{"name": "magic", "type": "uint32"}, {"name": "length", "type": "uint16"}, {"name": "payload", "type": "bytes", "length_field": "length"}]`。支持的类型：int8/16/32/64、uint 系列、float32/64、bytes、string（带长度前缀或 null 终止）、嵌套结构、数组。

输入从文件或管道读取，输出 JSON 格式。Round-trip 是硬要求——解析出来的 JSON 再序列化回去，字节序列必须和原始输入完全一致。所以模板里得能描述变长字段和条件分支（比如 magic 值为 `0xABCD` 时 payload 是一种格式，`0xEF01` 时是另一种）。

错误不 panic，用 error slice 收集：某个字段解析出问题就记录"字段 `payload` 偏移 12：剩余字节数不足"，继续尝试后面的字段（如果还能定位的话）。输入支持文件路径和管道两种方式。

Go 标准库实现。`go build`。
