同事那边提了个需求：项目里几十个 `.json5` 配置文件要转成标准 JSON，因为 CI 流水线里的 JSON 校验工具不认注释和尾逗号。Go 的 `encoding/json` 也不认。手动一个个改太蠢了，几十个文件批量转才靠谱。

`json5-tool`，子命令 `parse`、`convert`、`format`。`json5-tool parse` 读 JSON5 文件，用自定义的解析器（支持注释、尾逗号、无引号键名、多行字符串），输出标准 JSON。`json5-tool convert` 批量转换：`--recursive` 递归扫描目录，找 `.json5` 文件转成 `.json`。`json5-tool format` 美化 JSON5 文件——统一缩进、对齐注释、规范化键名引号。

两级命令结构：`json5-tool` 是根命令，每个子命令有自己的参数。递归处理时，碰到权限错误跳过并记录（stderr 输出路径和错误）。文件名保持不变只改扩展名：`.json5` → `.json`。

JSON5 特有的语法要正确处理：单引号字符串、十六进制数字、正负无穷大、NaN 这些在标准 JSON 里没有的概念，parse 时转成最接近的标准 JSON 表示（字符串或 null）。注释在 parse 时丢弃，或者 `--keep-comments` 模式下保留为 `// ...` 格式的特殊字段。

Go 标准库。`go build`。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
