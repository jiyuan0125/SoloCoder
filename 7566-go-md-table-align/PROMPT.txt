Markdown 文档里的表格经常是手写的，时间一长列宽就对不齐了——特别是改了某个单元格的内容之后，分隔线没有同步更新。线上好几个项目的 README 里都有这种问题，看着很不专业。写个工具自动标准化表格对齐。

`md-table-tool`，子命令 `align`、`check`、`convert`。`md-table-tool align` 读 Markdown 文件，找到所有表格，重新计算列宽并重新生成对齐的分隔线。列宽按内容自适应——每列取所有行（包括表头）的最大宽度，然后所有行填充到这个宽度。支持 Unicode 字符：中文字符算两个宽度，组合字符算零宽度，ANSI 转义序列不计入宽度。表头和数据列严格对齐。

`md-table-tool check` 检查表格格式是否规范——分隔线的长度是否和列数匹配、对齐方式是否一致（`:---`、`:---:`、`---:`）。`md-table-tool convert` 在 Markdown 表格和 CSV 之间互转。

属性变更影响计算结果——比如某个单元格内容改长了，列宽就得重新算。管道输入支持，处理速度要快。

Go 标准库。`go build`。
项目要用多文件结构，入口文件、业务逻辑、数据模型分开放，别揉在一个文件里。
