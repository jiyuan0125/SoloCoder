文档里引用了 `./images/foo.png`，排版一折行路径就从中间断了——相对路径废了，图片加载不出来。排版不只是对齐那么简单，断词、间距、缩进、资源路径，哪个处理不好文档就废了。

`text-layout`，子命令 `reformat`、`indent`、`toc`。`text-layout reformat` 重新排版文本段落——按 `--width`（默认 80）折行，支持 Markdown 格式：代码块（` ``` ` 包裹）里的内容不处理，列表项正确缩进，链接和引用保持正确解析不被截断。`text-layout indent` 调整缩进——统一用空格或 Tab（`--char` 参数），支持嵌套层级的缩进。`text-layout toc` 从 Markdown 文档生成目录——提取所有标题（`#` 到 `######`），输出目录列表，带锚点链接。

嵌套资源路径的处理：`--base-dir` 指定文档根目录，文档里的相对路径引用（图片、链接）在重新排版后要保持正确。

输入输出都支持 Markdown 格式。Go 标准库。`go build`。
