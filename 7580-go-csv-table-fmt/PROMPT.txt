Markdown 文档里嵌了个 CSV 表格，数据一更新列宽全乱——手工重新对齐太痛苦了，几十列几百行根本调不过来。删除行或列后索引也要跟着更新，不然表格结构不对。

`csv-table-fmt`，子命令 `render`、`align`、`check`。`csv-table-fmt render` 读 CSV 数据，渲染成终端对齐的表格或 Markdown 表格（`--format md`）。解析器要能处理嵌套列表（CSV 字段里带逗号的引号包裹值）、表格（本身的数据）和代码块（如果 CSV 数据来自 Markdown 文件里的代码块）。`csv-table-fmt align` 重新对齐已有表格——读 Markdown 文件里的表格，重新计算列宽并格式化。`csv-table-fmt check` 检查表格格式是否规范。

输出保持语义等价但格式标准化——原始数据的值不变，只是展示格式统一。列宽计算考虑 Unicode 字符——中文占两列，组合字符占零列，ANSI 转义不计宽。

Markdown 代码块里的 CSV 自动检测并处理，代码块外的内容保持不变。嵌套列表在表格单元格内正确处理。

Go 标准库实现。`go build`。
代码按模块拆分，不要把所有逻辑写在一个文件里。解析、转换、输出分开组织。
