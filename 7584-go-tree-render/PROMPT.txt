第一步，解析树形数据。第二步，计算节点宽度和缩进。第三步，渲染输出。终端里树形结构渲染对不齐的问题很烦——不同层级的缩进线 `│` `├` `└` 对不齐，节点名称的宽度计算又受到 Unicode 字符影响。

`tree-render`，子命令 `render`、`from-json`、`check`。`tree-render render` 读缩进文本（每行一个节点，缩进用空格或 Tab 表示层级），渲染成树形图。连接线用 box-drawing 字符：`├── ` 最后一个子节点用 `└── `，中间的层级用 `│   `。`tree-render from-json` 从 JSON 结构生成树——JSON 的对象嵌套直接映射成树的层级。`tree-render check` 检查已有树形图的格式——连接线是否对齐、缩进是否一致。

多个关联实体——节点之间有父子关系，渲染时父节点的宽度会影响子节点的对齐位置。表格列宽按内容自适应：节点文本的显示宽度要考虑 Unicode 字符（中文 2 列，组合字符 0 列），连接线 `│` 的位置要和上方父节点的字符对齐。ANSI 转义序列在节点文本中不影响宽度计算。

Go 标准库。`go build`。
