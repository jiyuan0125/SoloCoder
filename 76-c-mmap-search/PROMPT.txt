用 C 写一个大文件搜索工具，基于 mmap 多线程并行搜索。

核心功能：
1. 从命令行接收搜索字符串和文件路径，支持多个文件
2. 大文件（>1MB）用 mmap 映射到内存，按固定块大小（4MB）分块交给线程池并行搜索
3. 小文件（<=1MB）直接 read 全部内容搜索，不走 mmap
4. 分块边界处理：如果块边界正好在行中间，前一块要读到下一个 \n 为止，确保不漏掉跨块匹配行。下一个块的起始位置相应调整

搜索行为：
5. 如果 mmap 的文件内容包含 NUL 字节（\0），视为二进制文件跳过不搜索，打印 "{filename}: binary file skipped" 到 stderr
6. 搜索结果输出格式：{filename}:{line_number}:{line_content}，行号从 1 开始
7. 支持选项：-i 忽略大小写、-l 只输出文件名、-c 只输出匹配行数、-n 显示行号（默认显示）

进度和统计：
8. 搜索过程中每处理完一块打印进度（百分比）到 stderr："\rProcessing {filename}: {percent}%"
9. 全部完成后打印统计："\n{总文件数} files, {匹配文件数} matched, {总匹配行数} matches\n"

线程管理：
10. 线程数默认等于 CPU 核心数，可通过 -t 参数指定
11. 搜索全部完成后才退出，所有工作线程正确 join

代码分 mmap_search.c、thread_pool.c、main.c 几个文件，gcc -lpthread 编译能过。
