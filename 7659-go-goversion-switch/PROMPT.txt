三个项目三个 Go 版本——1.19、1.21、1.22——来回切换全靠手动 export PATH 和 GOROOT。上周切到 1.22 跑测试，忘了 GOFLAGS 里还留着 1.19 的构建标签，测试全挂了。版本切换这事得工具化，把每个版本的完整环境配置管起来。

GoVersion 实体有版本号、安装路径、GOROOT、状态（installed/available/default）。VersionConfig 有嵌套结构——路径为 `version/<version>/config`，包含 PATH 追加项、环境变量覆盖、构建标签。`show version/1.21/config` 显示该版本的完整配置。`edit version/1.21/config --set GOROOT=/opt/go1.21` 修改配置。

工具支持模板渲染——`template render --version <v>` 把版本配置模板（包含 {{.Version}}、{{.GOROOT}} 等占位符）渲染成实际配置文件。公共变量（如 GOPROXY、GONOSUMCHECK）只维护一份，所有版本共享。

敏感信息处理——GOFLAGS 里可能包含私有仓库地址，支持从环境变量注入（`inject --version <v> --from-env GOPRIVATE`），不从模板硬编码。

- `version add <v> --path <dir> --goroot <dir>`
- `version list`：已安装和可用的版本
- `version default <v>`：设置默认版本
- `show version/<v>/config`：查看版本配置
- `edit version/<v>/config --set <key>=<value>`
- `template render --version <v> --output <file>`
- `inject --version <v> --from-env <var-name>`
- `switch <v>`：切换当前版本，输出变更的环境变量

Go 标准库实现，go build 通过。
