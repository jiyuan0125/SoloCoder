~/.ssh/config 文件改来改去，上周加了跳板机配置，这周又删了。到底哪些 host 还在用、哪些是半年前测试留下的？没人说得清。更糟糕的是有人手动改了 SSH 配置，其他人完全不知道。

HostConfig 实体有 ID、别名、HostName、User、Port、IdentityFile、ProxyJump（跳板机）、ForwardAgent、状态（active/disabled）。`host add --alias <name> --hostname <addr> --user <name> [--port <n>] [--identity <file>] [--proxy <jump>]` 添加配置。`host list` 显示所有 host 和状态。

锁定当前配置——`snapshot create` 把当前所有 active 的 host 配置生成快照文件，包含每个配置的 SHA256 校验。后续如果有人手动改了 ~/.ssh/config，`snapshot verify` 对比差异并输出变更内容。主流程完成后（snapshot verify 通过），自动生成一条 AuditLog 记录，内容包括操作时间、配置哈希、变更摘要。

`host diff <alias1> <alias2>` 对比两个 host 的配置差异。`host export` 导出 SSH config 格式到 stdout。`host test <alias>` 尝试 SSH 连接验证配置有效性。

- `host add --alias <name> --hostname <addr> --user <name> [--port <n>]`
- `host list [--status active|disabled]`
- `host disable <alias>` / `host enable <alias>`
- `snapshot create` / `snapshot verify`
- `host diff <alias1> <alias2>`
- `host export`：输出 SSH config 格式
- `host test <alias>`

Go 标准库实现。
