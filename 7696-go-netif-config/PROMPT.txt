网络接口配置写了三套——/etc/network/interfaces 有一套，netplan YAML 有一套，NetworkManager 还有自己的一套。改了 interfaces 里的静态 IP，netplan 那边还是旧的，networkctl 重启之后地址又变回去了。

InterfaceConfig 实体有 ID、接口名（eth0、wlan0 等）、IP 地址（静态/DHCP）、子网掩码、网关、DNS 服务器列表、MTU、状态（up/down）、配置来源（interfaces/netplan/NetworkManager）。`iface add --name <text> --method static|dhcp [--address <ip>] [--gateway <ip>]` 添加接口配置。

子命令分组：`iface`（接口管理）、`dns`（DNS 配置）、`route`（路由管理）、`bond`（链路聚合）。`iface list` 显示所有接口。`iface show <name>` 完整信息。

合并功能——`merge --source <file1> --source <file2> --output <file>` 合并多个配置源。同名接口后者覆盖前者，DNS 列表用追加模式（去重），路由表深度合并。

`export --format interfaces|netplan|nmcli` 按格式输出配置。`check` 对比工具管理的配置和系统实际状态。

- `iface add --name <text> --method static|dhcp [--address <ip>] [--gateway <ip>] [--dns <servers>]`
- `iface list` / `iface show <name>`
- `dns add <iface> --server <ip>` / `dns list <iface>`
- `route add <iface> --dest <cidr> --via <ip>`
- `merge --source <file> --source <file> --output <file>`
- `export --format interfaces|netplan|nmcli`
