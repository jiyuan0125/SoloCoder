你有没有这种经历——浏览器书签栏塞了几百个链接，找的时候翻半天也翻不到？与其依赖浏览器的书签管理，不如自己做一个命令行版本，检索快，还能加自定义标签和描述。

bookmark-mgr 管理技术书签，每条书签记录包含 URL、标题、描述、标签数组、创建时间、最后访问时间。数据存本地 JSON 文件，`~/.bookmark-mgr/bookmarks.json`，单个文件读写，用 flock 互斥。Go 标准库实现，`go build -o bookmark-mgr ./cmd/bookmark-mgr` 编译。

从代码注释提取文档这个思路也集成进来了——如果书签指向的是本地代码仓库，工具能自动扫描注释生成摘要。支持 `//`、`/* */`、`///` 多种注释格式。书签变更时，如果关联的是本地代码文件，会标记需要更新摘要。

核心操作：`add --url <url> --title <title>` 新增，`--tags` 打标签；`search <keyword>` 全文搜索标题和描述；`tag <tagname>` 按标签过滤；`open <id>` 调用系统浏览器打开 URL 并更新访问时间；`export` 输出 Markdown 格式的书签列表，方便分享。`list` 命令默认按最近访问排序，`--sort created` 按创建时间。删除书签前检查是否有其他书签引用同一标签，给出影响提示。
