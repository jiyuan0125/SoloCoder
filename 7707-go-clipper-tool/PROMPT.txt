读技术博客的时候经常想摘一段存下来，手动复制粘贴到笔记里再排版太麻烦了。于是想搞个剪藏工具，从网页或文件里提取技术内容，自动清理格式存到本地知识库。

clipper-tool 纯 Go 标准库实现，`go build -o clipper ./cmd/clipper` 出二进制。它处理 HTML 和纯文本两种输入源，从 stdin 读取或用 `--file` 指定文件路径。剪藏记录包含标题、原文摘录、来源 URL 或文件路径、标签、创建时间，数据存在 `~/.clipper/notes/` 目录下，每条一个 JSON 文件。

比较有意思的是标签提取和交叉引用。保存时工具自动从标题和正文中提取关键词作为候选标签，用户确认后才正式打标。新剪藏进来后，工具会算它和已有记录的相似度，超过阈值自动建立引用。删除记录时反向检查——如果被别的记录引用了就直接拒绝，并列出引用方。引用关系变更后自动同步被引用方的关联列表。

子命令：`clip` 从 stdin 读取内容剪藏；`list` 列出所有记录支持 `--tag` 过滤；`search <keyword>` 搜索标题和正文；`link <id>` 显示某条记录的所有引用关系。空库时 `search` 和 `link` 直接提示无数据。`go test ./...` 跑测试。
