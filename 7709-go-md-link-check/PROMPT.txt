Markdown 文档里的链接有没有效？——死链多了文档可信度直线下降。这个工具专门检查 Markdown 文件中所有链接的有效性，内部链接验文件存在性，外部链接发 HTTP 请求验证。

md-link-check 用 Go 标准库实现，`go build -o md-link-check ./cmd/md-link-check` 编译。

检查流程分两步。先解析 Markdown 提取所有链接——包括行内链接 `[text](url)` 和引用式链接 `[text][ref]`。每个链接记录来源文件、行号、链接类型。然后分两路验证：本地链接（不以 http 开头）检查文件系统中目标文件是否存在；外部链接发 HEAD 请求，超时 5 秒，跟随重定向最多 3 次。

主操作执行时要调用辅助检查——辅助检查也会读同一批文件数据。为了避免重复解析，链接提取结果缓存在内存 map 中，主流程和辅助流程共享。并发检查外部链接用带缓冲 channel 做信号量，默认 20 并发。结果分三级：有效（绿色）、超时/4xx（黄色）、死链/5xx（红色）。输出格式支持终端表格和 JSON，`--format json` 切换。

评分维度包括完整性（文档是否有目录和摘要）、可读性（平均段长度）、示例覆盖率（代码块占比）。每个维度独立评分附改进建议。子命令 `check <path>` 检查单个文件，`check-dir <dir>` 批量检查。`go test ./...` 跑测试。
代码要模块化：主流程、具体功能实现、辅助函数分开存放，主文件只做调度。
