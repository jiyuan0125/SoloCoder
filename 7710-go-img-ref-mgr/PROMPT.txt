写技术文档离不开图片，但图片和文档的引用关系经常搞乱——删了文档忘了删图片，或者图片挪了位置文档里就红叉。先整理引用关系，再统一管理图片资源。

img-ref-mgr 用 Go 标准库实现，`go build -o img-ref-mgr ./cmd/img-ref-mgr` 编译。它遍历指定目录下所有 Markdown 文件，正则匹配 `![alt](path)` 和 `<img src="path">` 两种格式提取图片引用，同时扫描图片目录记录实际位置和大小，结果存在 `img-refs.json` 里。

扫描完就能对比出两类问题：被引用但不存在的图片（悬空引用，报 error）和存在但没被任何文档引用的图片（孤立图片，报 warning）。发现问题的图片先标记为待审核，用户确认后才执行操作——`move <img> <new-path>` 移动图片并自动更新所有引用它的文档，`clean` 删除孤立图片（需 `--confirm`），`report` 输出 JSON 格式的引用关系图。引用格式统一标准化为相对路径。

子命令还有 `list` 显示所有图片及引用数，`orphans` 只列孤立图片。数据持久化用本地 JSON，文件写入原子操作。`go test ./...` 跑测试，`go build` 编译通过。
