写代码时经常想找以前写过的某段实现，但翻遍项目也找不到——代码片段散落在各处，没有统一管理的地方。与其每次重新写，不如把常用片段集中存起来。

snippet-mgr 管理代码片段，每条记录有标题、代码内容、语言标签（可多个）、描述、创建时间。标签支持层级，比如 `go` 下面可以有 `go/concurrency`。Go 标准库实现，`go build -o snippet-mgr ./cmd/snippet-mgr` 编译。

主记录依赖配置数据——配置文件在 `~/.snippet-mgr/config.json`，定义默认语言、存储路径、编辑器命令。片段数据存在 `~/.snippet-mgr/snippets/` 目录下，每条一个 JSON 文件。标签层级关系存在 `~/.snippet-mgr/tags.json`。

操作上，`add` 新增片段，交互式输入标题和描述，代码内容从 stdin 读或 `--file` 指定文件。`search <keyword>` 搜标题、描述和代码内容。`tag <tag-name>` 按标签过滤，支持 `tag/subtag` 层级路径。`list` 默认按创建时间倒序，`--lang go` 按语言过滤。`export <id>` 输出指定片段为 Markdown 格式到 stdout，`--dir` 批量导出整个标签树。`--tags` 给片段打多个标签，一个条目可以属于多个分类。按标签聚合显示时，子标签缩进在父标签下面。零依赖纯 Go 标准库，`go test ./...` 跑测试。
