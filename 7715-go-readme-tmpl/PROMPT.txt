新项目总要写 README，格式大同小异但每次都要从头来。先用模板把常见结构固定下来，再根据项目类型填充内容，省得每次都忘了该写什么。

readme-tmpl 用 Go 标准库实现，`go build -o readme-tmpl ./cmd/readme-tmpl` 编译。

先定义模板。内置几套模板：通用项目模板（标题、描述、安装、使用、贡献指南）、Go 库模板（多了 godoc 链接和 Go 版本要求）、CLI 工具模板（多了子命令说明和配置参数表）。模板用 Go 标准库 `text/template` 引擎渲染，变量用双花括号标记。

再填充变量。从项目目录自动探测：`go.mod` 提取模块名和 Go 版本，`Makefile` 提取 build 命令，git 远程仓库提取 URL。探测不到的变量交互式提示用户输入。用户也可以自定义模板文件，`--template my-readme.tmpl` 指定。

比较两个版本时高亮差异——模板变量替换后和现有 README 对比，新增绿色标注，删除红色标注，修改黄色标注。并排格式输出，方便审查改了什么。修改主体内容后关联的目录和链接也同步更新。

子命令：`init` 选择模板生成 README；`diff` 对比当前 README 和模板生成的版本；`update` 用最新探测结果刷新 README 中可自动填充的部分。输出到 stdout 或 `--output` 指定文件。`go test ./...` 跑测试，`go build` 编译通过。
