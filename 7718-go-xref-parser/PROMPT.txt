文档之间互相引用很常见，但引用关系没人维护——删了一篇文档，引用它的地方全变成死链。需要一个交叉引用解析工具，把文档间的引用关系理清楚。

xref-parser 用 Go 标准库实现，`go build -o xref-parser ./cmd/xref-parser` 编译。

解析 Markdown 文件中的所有交叉引用：`[text](./relative-path.md)` 内部链接、`[text](../other/doc.md)` 相对路径引用、`[[wiki-link]]` 风格双向链接。每条引用记录包含源文件路径、目标文件路径、引用文本、行号。解析完成后构建引用图——每个文档是节点，引用关系是边。

调整引用后相关的汇总也要更新——引用计数、入度出度、孤立节点列表都会重新计算。汇总数据缓存在 `.xrefs/summary.json`，某篇文档变更时只刷新该文档相关的引用边和全局统计。

评分功能从三个维度评估文档集：完整性看是否所有被引用的文档都存在，可读性看引用密度是否合理（太密影响阅读），示例覆盖率看引用的文档内容质量。每个维度独立评分附改进建议。

子命令：`parse <dir>` 解析整个目录；`graph <file>` 显示某文档的引用关系图；`orphans` 列出无入度的文档；`broken` 列出指向不存在文件的引用。输出支持终端表格和 Mermaid 格式。`go test ./...` 跑测试。
至少拆成两个包或三个文件以上，不要单文件一把梭。
