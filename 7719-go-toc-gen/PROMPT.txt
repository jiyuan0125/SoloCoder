长文档没有目录，读者找不到想要的内容——手动维护目录又容易和实际标题对不上。这个工具自动从 Markdown 标题生成目录，文档改了目录跟着变。

toc-gen 用 Go 标准库实现，`go build -o toc-gen ./cmd/toc-gen` 编译。

解析 Markdown 文件的所有标题行（`#` 到 `######`），提取标题文本和层级。生成目录时每个标题转成锚点链接——标题文本转小写、空格变连字符、去除标点。目录插入到文档中 `<!-- TOC -->` 和 `<!-- /TOC -->` 标记之间。如果没有标记就在文件开头插入。已存在的目录自动替换，不会重复插入。

多个关联实体——标题、锚点、目录条目、子目录。多级标题自动形成嵌套结构，用缩进表示层级。标题层级跳跃（比如 H1 直接接 H3）会发出 warning 但不阻止生成。

从代码注释提取文档这个能力也集成了——工具能扫描 Go 源码的 doc comment，转换成 Markdown 段落加入文档。支持多种注释格式。代码变更时标记需要更新的文档段落，用 `<!-- STALE -->` 注释包裹。变更通知下游——目录更新后，如果文档被其他文档引用，自动在引用方的缓存中标记过期。

子命令：`gen <file>` 生成单个文件目录；`gen-dir <dir>` 批量处理目录下所有 Markdown 文件；`check <file>` 检查目录是否和实际标题一致。输出 Markdown 格式。`go test ./...` 跑测试。
代码要模块化：主流程、具体功能实现、辅助函数分开存放，主文件只做调度。
