技术文档里脚注用得好能补充很多细节，但脚注编号手动维护简直是噩梦——中间插一条后面全部要改。先让工具自动管理编号，再做语法检查和格式修复。

footnote-mgr 用 Go 标准库实现，`go build -o footnote-mgr ./cmd/footnote-mgr` 编译。它扫描 Markdown 文件中的脚注引用（`[^name]`）和脚注定义（`[^name]: text`），记录每个引用和定义的位置、名称、内容，验证两者是否一一对应——有引用没定义报 error，有定义没引用报 warning。

写入脚注数据后自动触发格式校验：脚注定义是否在文档末尾、引用编号是否连续、脚注文本是否为空。问题按严重程度分 error 和 warning 两级。校验和主流程共享同一批文件数据，避免重复解析。

`fix <file>` 自动修复能修的问题——重新编号使引用和定义一致、移动定义到文档末尾、删除未使用的定义。修复前备份原文件到 `.footnote-bak/` 目录。`--dry-run` 预览修复内容不实际写入。`scan --dir <path>` 批量处理目录下所有 Markdown 文件，统计每个文件的问题数量。`list <file>` 显示所有脚注及其引用位置。输出格式终端彩色文本，`--format json` 切换 JSON。`go test ./...` 跑测试。
