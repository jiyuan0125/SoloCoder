技术文档里写数学公式，要么拍张图贴上去，要么手写 LaTeX 再想办法渲染——这两种方案都不理想。图片不能搜索不能复制，LaTeX 渲染又依赖外部工具。能不能纯 Go 搞定？

math-render 就是干这个的。Go 标准库实现，`go build -o math-render ./cmd/math-render` 编译。它把 LaTeX 数学公式转换成终端可显示的 Unicode 近似渲染，或者输出为 SVG 片段嵌入 HTML。

支持管道和重定向——`echo 'E=mc^2' | math-render` 从 stdin 读公式直接渲染输出。也支持 `--file <path>` 从 Markdown 文件中提取所有 `$...$` 和 `$$...$$` 包裹的公式批量处理。每个公式有编号，输出时标注来源行号。

公式解析器手写递归下降，支持常见结构：上标下标、分数 `\frac{}{}`、根号 `\sqrt{}`、求和 `\sum`、积分 `\int`、矩阵 `\begin{pmatrix}`。解析失败的公式原样输出并标注错误位置。终端渲染模式用 Unicode 字符近似——上标用 Unicode 上标数字，分数用水平线分割，矩阵用方括号。

标签系统：每条公式可以有多个标签，按标签聚合显示。标签支持父子层级关系，比如 `physics > relativity`。`tag list` 显示标签树。数据存本地 JSON 文件 `~/.math-render/formulas.json`，记录渲染过的公式和标签。`go test ./...` 跑测试。
