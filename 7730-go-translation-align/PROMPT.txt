文档翻译最怕上下不对齐——原文改了中文没同步，或者翻译漏了一段没人发现。先解析两份文档的段落结构，再自动对齐对比，翻译遗漏和不同步的地方一目了然。

translation-align 用 Go 标准库实现，`go build -o translation-align ./cmd/translation-align` 编译。

先解析。加载原文和译文两个 Markdown 文件，按段落拆分。段落划分规则：空行分隔、标题独立成段、代码块整体作为一段。每个段落计算哈希值用于快速比较。

再对齐。用动态规划算法找最优段落匹配序列。匹配维度包括：段落位置相近度、结构相似度（都有代码块或都有列表）、关键词对应（英文段落中频繁出现的词在中文段落中有对应翻译）。对齐结果分三类：匹配的段落对、原文多出的段落（翻译遗漏）、译文多出的段落（多翻译的部分）。

最后报告。变更时自动通知——原文文件修改时间变化就重新对齐，输出和上次对齐的差异。从代码注释提取 API 文档的功能也集成了——如果原文是代码注释格式，先转成 Markdown 再对齐。支持多种注释格式。输出为 Markdown 格式，三列表格：原文段落、译文段落、状态（对齐/遗漏/多余）。

子命令：`align <en.md> <zh.md>` 对齐两个文件；`batch <dir>` 批量处理目录下所有对应文件对；`stats` 输出对齐率统计。`go test ./...` 跑测试。
