团队文档散落在各个仓库的 `docs/` 目录里，没有统一入口。新人入职找文档找半天，问来问去效率太低。搞个工具把所有文档聚合成一个静态网站，一键生成全团队的知识库。

docsite-gen 用 Go 标准库实现，`go build -o docsite-gen ./cmd/docsite-gen` 编译。

它扫描指定根目录下所有 Markdown 文件，按目录结构建立页面树。每个页面有标题、正文、标签、分类、父页面、子页面列表。Markdown 转 HTML 用内置渲染器，应用内置 CSS 模板，模板支持自定义——放在 `~/.docsite-gen/template/` 目录覆盖默认样式。渲染的同时按标签和分类建交叉索引页，生成全局搜索用的 JSON 索引文件（简单的倒排索引，中文按字切分英文按空格，搜索结果高亮匹配词）。最终输出 `index.html`、各页面 HTML、`search.json` 到指定输出目录。

导航自动从目录结构生成面包屑和侧边栏。支持多级标题，新增文档自动纳入下次生成。`--watch` 模式监听文件变更自动重新生成变更的页面。笔记支持标签和分类，搜索支持全文检索和按标签筛选。

子命令：`gen <src-dir> -o <out-dir>` 生成站点；`serve <out-dir>` 启动本地预览服务器；`search <keyword>` 测试搜索功能。数据存本地 JSON 文件。`go test ./...` 跑测试，`go build` 通过。
