技术博客或文档更新后没有通知机制——读者不知道什么时候出了新内容，只能自己时不时来看。RSS 是标准解决方案，但手动维护 RSS XML 太痛苦了，需要自动从文档目录生成。

rss-gen 用 Go 标准库实现，`go build -o rss-gen ./cmd/rss-gen` 编译。

生成逻辑：扫描指定目录下所有 Markdown 文件，按修改时间排序，取最近 N 篇（默认 20）作为 RSS 条目。每个条目包含标题（从 H1 或 frontmatter 提取）、摘要（正文前 200 字）、链接（相对路径转成配置的基础 URL）、发布时间（文件修改时间或 frontmatter 中的 date 字段）、作者。

属性变更影响计算结果——文档标题改了、摘要内容变了、排序位置移动了，都会反映在 RSS 输出中。增量生成只重新处理修改时间大于上次生成时间的文件。上次生成时间戳存在 `.rss-gen/last-run` 文件中。

输出标准 RSS 2.0 XML 格式，包含 channel 元素（标题、描述、链接、语言）和 item 列表。验证 XML 格式正确性——标签闭合、特殊字符转义、日期格式 RFC 822。

笔记支持标签和分类，RSS 条目也包含 category 字段。全文检索用标签过滤——`--tag go` 只输出标记为 Go 分类的文档。子命令：`gen <dir>` 生成 RSS；`validate <file>` 验证 XML 格式。配置文件 `.rss-gen.json` 设置基础 URL、条目数量、摘要长度。`go test ./...` 跑测试，`go build` 通过。
至少拆成两个包或三个文件以上，不要单文件一把梭。
