SEO 检查目前全靠经验，没人系统性地逐项检查——meta 标签有没有、标题层级对不对、图片 alt 有没有、关键词密度如何。先建一套检查规则，再批量扫描文档目录自动出报告。

seo-check 用 Go 标准库实现，`go build -o seo-check ./cmd/seo-check` 编译。

第一步解析。扫描指定目录下所有 Markdown 和 HTML 文件，提取 SEO 相关元素。Markdown 文件转成 HTML 后统一分析。提取内容包括：title 标签、meta description、H1-H6 标题层级、图片及 alt 属性、链接、关键词密度。

第二步检查。规则集引用了其他数据源——比如术语表（检查关键词是否用了标准术语）、站点地图（检查内部链接是否在 sitemap 中）。检查项按类别分组：内容检查（标题长度 20-60 字、描述 120-160 字、H1 唯一）、技术检查（图片必须有 alt、链接不能有死链、canonical 正确）、结构检查（标题层级不跳跃、面包屑完整）。

第三步报告。每个问题记录文件路径、规则名、严重程度、当前值和期望值。工具自动扫描文档目录，新增文件自动加入检查范围。多级标题在报告中按层级展示。

子命令：`check <dir>` 扫描检查；`report` 输出汇总报告；`fix <file>` 自动修复能修的问题（补 alt 文本、修标题层级）。配置文件 `.seorc.json` 自定义规则。`go test ./...` 跑测试。
代码按模块拆分，不要把所有逻辑写在一个文件里。解析、转换、输出分开组织。
