文档重构后 URL 全变了，老链接全变成 404。迁移上线那天，搜索引擎收录的页面、别人博客里的引用全挂了。如果有重定向管理工具，维护一张映射表，Nginx 配置都不用手写。

redirect-mgr 用 Go 标准库实现，`go build -o redirect-mgr ./cmd/redirect-mgr` 编译。

映射模型：每条记录包含源路径、目标路径、状态码（301 永久 / 302 临时）、创建时间、备注。源路径必须以 `/` 开头且不能重复——添加时检查唯一性。目标路径可以是内部路径也可以是外部 URL。

笔记模型支持标签和分类。映射记录也按标签组织——比如"v1→v2迁移"、"文档重构"。搜索支持全文检索和按标签筛选。数据存本地 JSON 文件 `~/.redirect-mgr/redirects.json`，主记录依赖配置数据（`~/.redirect-mgr/config.json` 定义站点根路径和默认状态码）。

验证功能：`validate` 检查映射表中有没有循环重定向（A→B→C→A）、链式重定向超过 3 层、目标路径本身也是重定向源。检测到问题标红报 error。

子命令：`add /old-path /new-path` 新增映射；`list` 展示所有映射，支持 `--tag` 过滤；`search <keyword>` 搜路径和备注；`remove <source-path>` 删除（需 `--confirm`）；`export` 输出为 Nginx rewrite 格式或 JSON；`validate` 检查映射合法性。文件读写用 flock 互斥。`go test ./...` 跑测试，`go build` 通过。
