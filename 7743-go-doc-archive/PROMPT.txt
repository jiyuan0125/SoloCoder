过时文档堆积如山——没人看也没人删，搜索时还老跳出来干扰。需要一个归档工具，把过期文档按规则自动归档，保持活跃文档区的清爽。

doc-archive 用 Go 标准库实现，`go build -o doc-archive ./cmd/doc-archive` 编译。

归档策略基于时间阈值——超过 N 天未修改的文档标记为待归档（默认 180 天）。但不是所有老文档都该归档——被其他活跃文档引用的老文档保留，标记为"长期维护"的文档保留。归档前检查引用关系，有引用就跳过并报告。

达到阈值时自动触发告警——待归档文件列表输出到 stdout，支持 `--notify` 参数输出 JSON 格式给外部告警系统。归档动作是把文件从源目录移到归档目录 `archived/YYYY-MM/` 下，并在源目录生成一个 stub 文件指向归档位置，这样老链接不会直接 404。

评分维度用于判断文档质量——完整性、可读性、示例覆盖率各独立评分。质量分高的文档即使时间到了也建议保留，归档报告里会标注。

子命令：`scan <dir>` 扫描并列出待归档文件；`archive <dir>` 执行归档操作；`restore <file>` 从归档恢复文件到原位；`report` 输出归档统计。配置文件 `.archiverc.json` 设置阈值和排除规则。数据存本地 JSON 文件记录归档历史。`go test ./...` 跑测试。
