条件内容渲染——同一份文档根据环境不同显示不同内容，比如开发环境显示调试信息，生产环境隐藏。手动维护两份文档太蠢了，得在文档里用条件标记。

conditional-render 用 Go 标准库实现，`go build -o cond-render ./cmd/cond-render` 编译。

语法设计：条件块用 `{{if ENV==production}}...{{else}}...{{end}}` 包裹。支持的判断条件：环境变量值比较、特性开关状态、目标平台（linux/darwin/windows）、文档版本。条件可以嵌套，最多 3 层。嵌套太深发出 warning。条件块内可以包含任何 Markdown 内容，包括代码块和表格。

从代码注释提取文档的功能也集成——源码中的条件编译标签（Go 的 `//go:build`）自动映射到文档条件块。支持多种注释格式。代码变更时标记需要更新的条件内容。输出为 Markdown，根据指定环境变量值过滤后只剩满足条件的内容。

多种子命令处理不同操作：`render <file> --env production` 按环境渲染；`check <file>` 检查条件语法是否正确；`diff <file> --env dev --env prod` 对比两个环境下的输出差异；`list-conditions <file>` 列出文档中所有条件块及其判断条件。数据存本地 JSON。`go test ./...` 跑测试。
