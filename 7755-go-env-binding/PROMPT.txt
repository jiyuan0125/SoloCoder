每次写 CLI 工具都要处理配置来源的问题——开发时用本地配置文件，部署时用环境变量覆盖，调试时命令行参数再覆盖一层。三种来源的优先级和合并逻辑到处重复，不如统一做个绑定组件。

env-binding 用 Go 标准库实现，`go build -o env-binding-demo ./cmd/env-binding` 编译。用结构体 tag 标注每个字段的环境变量名和默认值，比如 `Port int \`env:"PORT" default:"8080"\``。支持的数据类型：string、int、bool、float64、[]string（逗号分隔）。

加载优先级：命令行参数 > 环境变量 > 配置文件 > 默认值。命令行参数用 `--port 9090` 覆盖环境变量 `PORT`。配置文件支持 JSON 和简单 key=value 格式。找不到值时使用默认值，没有默认值且字段标记为 required 则报错退出。`load` 加载并输出配置，`validate` 校验所有 required 字段是否有值。

工具自动记录每个配置项的值来源（命令行/环境变量/文件/默认），`stats` 子命令输出统计报告。如果配置项涉及异步加载（比如从远程读取），内置简单的任务队列支持最大并发数限制，任务失败自动重试，次数可配，所有加载任务完成后才返回最终配置。`export` 导出为环境变量格式方便写启动脚本。`go test ./...` 跑测试。
