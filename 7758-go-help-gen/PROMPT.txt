帮助信息格式混乱——有的命令帮助写得很详细，有的就一行；有的对齐整齐，有的参差不齐。帮助文本散落在各个 handler 里，维护起来到处改。需要一个统一的帮助信息生成组件。

help-gen 用 Go 标准库实现，`go build -o help-gen-demo ./cmd/help-gen` 编译。

生成模型：每个命令/选项定义为结构体，包含名称、短名、类型、描述、默认值、是否必填。帮助信息从这些结构化数据自动渲染。输出格式支持三种——JSON（程序可解析）、YAML（配置可读）、表格（人类友好）。格式通过参数 `--format` 切换。数据驱动设计，传入结构体自动渲染，不需要手写帮助文本。

嵌套的资源路径——命令可以多级嵌套。`app service restart` 的帮助要展示每一级的说明。自动生成树状帮助：根命令概览、子命令列表、每个子命令的详细帮助。嵌套深度不限，但超过 3 层发出 warning 提示可能过于复杂。

宽度自适应：终端宽度通过 `ioctl` 获取（兼容不支持的情况默认 80）。描述列自动换行对齐。长描述截断并加省略号。

用法行自动生成：`Usage: app [OPTIONS] COMMAND [ARGS]...`，根据参数定义动态拼出正确的用法模板。示例文本可以通过 `Example` 字段手动指定。

API：`helpGen := New()`、`helpGen.AddCommand(cmd)`、`helpGen.AddOption(opt)`、`helpGen.Render()`。零依赖纯标准库。`go test ./...` 跑测试。
