多个任务同时跑的时候，终端上就一行进度条根本看不清哪个任务跑到哪了。能不能同时显示多个进度条，每个任务一行，互不干扰？

multi-progress 用 Go 标准库实现，`go build -o multi-progress-demo ./cmd/multi-progress` 编译。它处理多任务并发时的进度展示。

每条进度条独立管理：总任务数、已完成数、描述文本、颜色。多条进度条在终端中纵向排列，每条占一行。刷新时用 ANSI 转义序列移动光标到对应行更新，不影响其他行。任务完成时该行显示勾号和耗时，新任务动态插入不破坏布局。

文件操作场景：比如批量转换文件，每个文件一个进度条。文件写入用原子操作（先写临时文件再 rename），每个文件的写入进度独立展示。支持文件变更监听——输入目录有新文件时自动添加新进度条。并发安全。

调整后相关的汇总也要更新——所有任务完成后自动显示汇总：总任务数、成功/失败数、总耗时、平均速度。汇总信息替换进度条区域，不用滚动翻找。

API 设计：`mp := multi.New()`、`bar1 := mp.AddBar(100, "Task A")`、`bar1.Inc()`、`mp.Wait()`。最多同时显示 20 条进度条，超出折叠显示。输出到 stderr。终端宽度不足时自动缩短描述文本。`go test ./...` 跑测试。
