让用户从一堆选项里挑一个，总不能让人手动输入完整名称吧？带序号的选择列表，上下键或输入数字选，体验好多了。

interactive-select 用 Go 标准库实现，`go build -o select-demo ./cmd/select` 编译。它给命令行工具加交互式选择能力。选项模型：每个选项有显示文本、值（可以和显示文本不同）、描述（可选，选中后显示在底部）。选项数量不限制，超过终端高度自动分页，用方向键翻页。

交互流程：显示选项列表，当前选中项高亮（反色），按上下键移动，回车确认，ESC 取消。也支持数字快捷键——输入数字直接跳到对应选项。搜索过滤：输入字符自动过滤匹配的选项，缩小选择范围。`--default 3` 预选第 3 项。`--input 2` 跳过交互直接选第 2 项。

日志能力集成——选择过程的操作日志分级输出到 stderr（DEBUG/INFO/WARN/ERROR），支持结构化字段。文件输出支持轮转，当天写到 `select.log`，超过阈值触发轮转。不依赖第三方库。写入数据后自动触发校验——选择结果校验（是否在选项范围内、是否为空），校验也需要访问同一份选项数据。

API：`sel := select.New("Choose:", options...)`、`choice, err := sel.Run()`。返回选中的值。`go test ./...` 跑测试。
