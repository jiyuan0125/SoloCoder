密码输入——在终端输入密码时字符回显到屏幕上太危险了，旁边人一眼就能看到。Go 标准库没有直接关闭回显的跨平台方案，每次都要处理平台差异。

password-input 用 Go 标准库实现，`go build -o password-input-demo ./cmd/password-input` 编译。它处理密码输入时的安全回显。

核心功能：读取用户输入时不回显字符，终端只显示 `*` 或完全不显示（可配置）。输入完成后恢复回显。数据有生命周期——密码只在内存中保留到使用完毕，用完立即用零值覆盖 `[]byte`，避免残留在内存中。

文件操作相关：密码可以保存到加密的本地文件中（用 AES-GCM，密钥从系统密钥链或环境变量获取）。文件写入用原子操作。支持文件变更监听——密码文件被外部修改时通知调用方重新输入。并发安全——多个 goroutine 不会同时操作终端。

交互细节：支持退格删除，Ctrl+U 清空整行，Ctrl+C 取消退出。最小长度和最大长度可配置——`MinLength(8)`、`MaxLength(128)`。复杂度检查：必须包含大小写字母、数字、特殊字符中的几种，不满足时给出具体提示。

确认模式：`Confirm(true)` 要求输入两次，不一致提示重新输入。API：`pwd, err := password.Read("Enter password:")`、`password.ReadConfirm("Password:", "Confirm:")`。`go test ./...` 跑测试。
