输入几个字符就提示完整的命令或文件名，这是好用的 CLI 工具的基本功。补全引擎做得好，操作效率翻倍。

autocomplete-engine 用 Go 标准库实现，`go build -o autocomplete-demo ./cmd/autocomplete` 编译。补全源有三类：静态词表（命令名、选项名）、动态数据（文件系统路径、历史命令）、上下文补全（根据前一个参数决定下一个参数的候选值）。比如 `git checkout <tab>` 补全分支名，`--file <tab>` 补全文件路径。

匹配算法：前缀匹配为基础，加上模糊匹配（允许跳过中间字符，`gts` 匹配 `go test ./...`）。匹配结果按相关度排序——前缀匹配优先，然后按使用频率。处理完成后自动归档补全结果到缓存，常用补全项权重提升，下次排序靠前。文件系统扫描等慢操作用 worker pool 并发，最大并发数限制，失败自动重试，次数可配。

子命令：`complete <input>` 测试补全效果；`index <dir>` 为目录建文件名索引；`history` 管理历史命令记录。交互模式下 Tab 键触发补全，有多个候选时显示列表让用户选。所有候选计算完成后按权重排序输出。数据存本地 JSON。`go test ./...` 跑测试。
代码要模块化：主流程、具体功能实现、辅助函数分开存放，主文件只做调度。
