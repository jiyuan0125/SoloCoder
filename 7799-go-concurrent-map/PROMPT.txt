并发安全 Map——Go 的 map 不是并发安全的，多个 goroutine 同时读写会 panic。`sync.Map` 虽然安全但 API 不好用，还没有泛型支持。自己封装一个带泛型风格的并发安全 map。

concurrent-map 用 Go 标准库实现，`go build -o cmap-demo ./cmd/cmap` 编译。它处理文件操作场景下的并发安全键值存储。

内部实现：分片锁（默认 32 个分片），每个分片一把 `sync.RWMutex`。key 通过哈希函数映射到分片，不同分片可以并行读写。比全局单锁性能高得多。支持管道和重定向——`Get`、`Set`、`Delete` 操作返回的结果可以链式传递。

文件操作集成：Map 可以持久化到 JSON 文件，文件写入用原子操作（临时文件+rename）。支持文件变更监听——外部修改持久化文件后自动重新加载。并发安全——加载过程中读写操作不阻塞，用 double-buffering 策略。

操作 API：`Set(key, value)`、`Get(key) (value, ok)`、`Delete(key)`、`Has(key) bool`、`Len() int`、`Keys() []string`、`Range(fn)` 遍历。`Range` 遍历时快照数据，遍历期间 map 可以继续修改。`GetOrSet(key, defaultFn)` 原子性的获取或初始化。

子命令：`put <key> <value>` 写入；`get <key>` 读取；`delete <key>` 删除；`list` 列出所有键值对；`dump` 导出为 JSON；`load <file>` 从文件加载。API 简洁。`go test ./...` 跑测试。
