样本量估算在实验设计阶段就必须做——做完了才发现样本量不够，时间和钱都白花了。这个工具提供几种常见场景的样本量计算。场景一：估计均值。公式 n = (Z_α/2 × σ / E)²，E是允许的误差范围。场景二：估计比例。公式 n = Z_α/2² × p(1-p) / E²。场景三：两个均值比较。场景四：两个比例比较。场景五：方差分析。场景六：相关性检验。每个场景需要输入：效应量或预期差异、显著性水平、功效、是否双尾。输出：所需样本量（每组）、总样本量、实际功效（可能略高于目标）。如果不知道效应量，工具提供Cohen's标准作为参考（小=0.2、中=0.5、大=0.8，针对t检验）。还支持不等分组——比如实验组与对照组2:1分配时需要的样本量。数据从JSON或CSV读取。聚类分析另外包含：每簇统计摘要，簇数量可配或自动选择。支持管道和重定向。Go 标准库实现，go build 通过。

进阶能力：样本量的分组计算每组需要多少以及总样本量。不等分组的比例可配比如实验组和对照组二比一分配。Cohen效应量标准内置作为参考小零点二中等零点五大零点八。如果用户不确定效应量工具提供基于文献常见值的推荐。聚类分析作为附加功能簇数量可配。
代码要模块化：主流程、具体功能实现、辅助函数分开存放，主文件只做调度。
