项目计划和实际执行总是两回事，但差距到底有多大？没有基线对比功能，你说不清项目到底是健康还是已经失控。上次老板问进度偏差多少，PM 支支吾吾说"还好"，其实已经落后两周了。

基线对比工具。保存项目初始计划作为基线（snap 命令），后续执行中随时与基线对比。对比维度包括：任务工期偏差（实际 vs 计划，按天和百分比显示）、资源用量偏差（实际投入工时 vs 预算工时）、里程碑偏差（预计完成日期 vs 基线完成日期）。偏差超过阈值（可配，默认 10%）的任务标红。

支持多资源分配。每种资源有可用量限制，任务需要资源超出可用量时标记冲突。输出资源使用直方图数据（基线 vs 实际对比柱状图，文本格式）。

写入数据后自动触发校验，校验也访问同一份数据做交叉验证（比如检查基线里的任务 ID 在当前计划中是否还存在）。基线文件存为带时间戳的 JSON 副本。支持多版本基线对比。go build 通过。Go 标准库实现。

对比结果可以导出为 Markdown 表格（方便贴到项目 wiki）或 JSON（方便脚本处理）。每次对比生成快照，保留完整历史记录。支持基线回滚——如果发现新计划反而更差，可以回退到某个历史基线。
