老板问项目进展怎么样，PM 说了半天也没个量化数据。进度偏差多少、趋势是好转还是恶化，全凭感觉回答。没有数据支撑的回答跟瞎猜没区别。

进度偏差（SV）计算工具。输入计划数据和实际数据两份 JSON 文件。每个任务有计划完成百分比和实际完成百分比，工具计算 SV = 实际完成百分比 - 计划完成百分比。正值说明超前，负值说明落后。按任务、按阶段、按项目三个粒度汇总。

日历排除周末和法定假日（从配置文件读取）。工期计算只算工作日，跨月跨年正确处理。任务有多个审批步骤——每个审批步骤有审批人、审批状态（待审/通过/驳回）和审批时间。审批状态变化时关联的进度数据要同步更新，比如某个审批被驳回导致进度回退。

输出：进度偏差表（按阶段分组，SV 值和状态图标），趋势图（最近 N 个时间点的 SV 变化曲线，文本格式），风险任务清单（SV 持续恶化的任务列表）。数据存 JSON。Go 标准库。

SV 趋势分析：如果连续三个时间点 SV 都在下降，判定为恶化趋势，提前给出预警而不是等到偏差很大才发现。支持多项目汇总——显示所有项目的进度偏差排名。导出支持 CSV 和 JSON 格式供管理层看。
项目要用多文件结构，入口文件、业务逻辑、数据模型分开放，别揉在一个文件里。
