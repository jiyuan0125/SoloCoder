挣值管理（EVM）是项目管理的经典方法，但手动算 PV/EV/AC/SV/CV/SPI/CPI 太繁琐了。每次出报表都要在 Excel 里拉半天公式，还容易拉错。

EVM 工具。输入三个数据：项目总预算（BAC）、计划完成百分比序列（按时间点的计划进度）、实际完成百分比和实际成本序列。工具自动计算挣值（EV = BAC × 实际完成%）、计划值（PV = BAC × 计划完成%）、进度偏差（SV = EV - PV）、成本偏差（CV = EV - AC）、进度绩效指数（SPI = EV/PV）、成本绩效指数（CPI = EV/AC）。

日历排除周末和法定假日（从配置文件读取），工期计算只算工作日，跨月跨年正确处理。

预测指标：完工估算 EAC = BAC / CPI，完工偏差 VAC = BAC - EAC，尚需估算 ETC = EAC - AC。这些数据让你一眼看出项目最终会超支多少、延期多久。

输出 EVM 仪表盘：SPI/CPI 双轴趋势图（文本格式）、预测完工日期和成本、风险等级评定（绿 SPI>1 且 CPI>1 / 黄 接近1 / 红 <0.9）。Go 标准库。

数据存 JSON 文件。所有操作有完整审计日志。工具不依赖外部服务，单二进制分发。
至少拆成两个包或三个文件以上，不要单文件一把梭。
