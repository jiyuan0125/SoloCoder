每周项目周报都是手动写 Markdown 表格，数据从各处汇总。有时候表格格式不统一，有时候漏了某个项目的数据。团队想统一报表格式但没人愿意手动维护模板。

Markdown 报表工具。支持多维度的下钻分析——先看全量汇总，再按某个维度展开，每一层独立计算统计量（计数、求和、平均、最大最小）。结果以缩进树形结构输出为 Markdown 格式，可以直接贴到 wiki。多种子命令处理不同操作：`md-report summary data.json` 汇总，`md-report drilldown data.json --by department` 下钻。

模板系统：报表模板从文件读取（Markdown 格式，用 {{变量}} 占位），数据从 CSV 或 JSON 读取。模板支持条件逻辑（如果某列超阈值则标红）。同一模板可用于不同数据源。

输出：带格式的 Markdown 表格（支持对齐方式、合计行、条件高亮）。go build 通过。Go 标准库实现。支持多 sheet 输出到同一 Markdown 文件。
