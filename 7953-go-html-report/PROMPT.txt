上次给领导发 Excel 版的数据质量报表，他手机上打开全是乱码，要求改成 HTML 网页能直接在浏览器里看。手动做 HTML 报表？一次要检查 20 多个字段的空值率、重复率、格式合规，做到半夜都做不完。

HTML 报表工具，专门做数据质量检查。输入 CSV 或 JSON 数据文件。检查维度四个：完整性（必填字段空值率）、唯一性（主键重复率）、格式合规（正则校验通过率）、范围合规（数值在合理范围内的比率）。每个维度独立评分（0-100），总评分加权计算，权重可配。

数据有生命周期——每次检查生成带时间戳的报告，超过保留期限的自动归档。历史报告可以对比，看数据质量趋势是改善还是恶化。评分下降的字段自动标为退化。支持定义质量基线，低于基线触发告警。检查规则支持自定义正则表达式（比如手机号格式校验）。

输出 HTML 格式，包含检查结果表格（每行一个字段，列出各维度得分和总评分）、饼图数据（合格/不合格比例）和趋势曲线数据。CSS 内联，不依赖外部样式表。

命令：`html-report check data.csv --output report.html`。Go 标准库实现。
