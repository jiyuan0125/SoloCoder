这个月的数据和上个月差在哪？两个版本的配置文件有什么不同？每次对比都写 diff 脚本太浪费时间了。

JSON 报表工具。对比两个时间段的数据，高亮异常变化。输入两份数据文件（JSON 或 CSV，结构一致）和时间标签。工具逐行逐字段对比，计算变化量和变化率。变化超过阈值（可配，默认 20%）的字段标为异常。输出 JSON 格式的差异报表。

差异类型：新增行（只存在于新数据）、删除行（只存在于旧数据）、变更行（两份数据都有但字段值不同）。每类差异独立统计数量和占比。

输出为彩色终端表格或 JSON（--format json），方便脚本处理。JSON 报表结构：`{ "summary": {...}, "details": [...], "anomalies": [...] }`。go build 通过。Go 标准库实现。

差异报表支持嵌套结构对比（JSON 对象深度比较）。数组元素对比支持按主键匹配而非下标匹配。输出包含变更摘要和详细 diff 两个层级。

差异报表支持忽略字段配置（某些字段变化不需要报告，如更新时间戳）。JSON diff 支持数组顺序无关比较（按内容而非位置）。
拆成至少三个 Go 文件：main.go 做入口和参数解析，核心处理逻辑独立一个文件，工具函数单独放。
