运营那边要个分组统计工具——按部门看人数、按月份看收入、按地区看用户量。每次都是临时写 SQL 或 Python 脚本，写完用完就扔，下次又重新写。调整后相关的汇总也要更新。

分组统计工具。支持环比和同比计算——环比是和上一个周期比，同比是和去年同周期比。计算周期可配（日、周、月、季、年）。缺失周期用前值填充（上一个有数据的值）或插值。输出为 Markdown 表格，可以直接贴到报告里。

分组维度支持多级：先按大区分组，大区内按城市分组，城市内按门店分组。每级独立计算统计量。调整某个分组后，上级汇总自动重算。

数据从 CSV 读取，支持 --filter 参数过滤行（如 `--filter "region=华东"`）和 --select 参数选择列。输出按指定列排序。

输出：Markdown 表格 + 环比同比变化率列。支持 JSON 格式导出。Go 标准库实现。图表数据输出支持折线图 JSON 格式、累计值计算（年初至今/月初至今）和移动平均环比平滑。
