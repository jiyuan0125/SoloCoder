老板问"最近三个月趋势怎么样"，分析师打开 Excel 拉了半天数据。其实趋势就是按时间排序的数值变化，一眼就能看出来的东西。

趋势报表工具。从 CSV 或 JSON 读取时间序列数据，按指定时间字段排序，计算趋势指标：变化量（最新值 - 最早值）、变化率、线性趋势斜率（用最小二乘法拟合）。属性变更影响计算结果——改了数据后趋势要重算。

报表模板从文件读取（JSON 格式），数据从 CSV 读取。模板支持变量替换和条件逻辑（比如变化率超过 20% 标红）。同一模板可用于不同数据源。

趋势判断：斜率 > 0 上升趋势（绿色），斜率 ≈ 0 平稳（黄色），斜率 < 0 下降趋势（红色）。阈值可配。支持移动平均线（N 日 SMA）平滑数据。

输出：时间序列表格 + 趋势指标摘要。终端彩色显示或 Markdown 导出。Go 标准库。

趋势报表支持多系列对比（比如三条产品线的趋势叠加显示）。异常点检测：偏离趋势线超过 2 倍标准差的点标为异常并给出可能原因提示。支持简单线性预测未来走势（基于历史斜率外推）。
代码按模块拆分，不要把所有逻辑写在一个文件里。解析、转换、输出分开组织。
