运营要一份用户消费金额分布报表——多少人消费在 0-100、100-500、500-1000、1000 以上。每次都是临时写 SQL 的 CASE WHEN，改一个分桶边界就要重写。

分布报表工具。从 CSV 或 JSON 读取数据，按指定数值字段计算分布。支持等宽分桶（每个桶宽度相同）、等频分桶（每个桶数据量相同）和自定义分桶（手动指定边界）。每个桶输出：数据条数、占比、累计占比。多种子命令：`dist equal-width data.csv --field amount --bins 10`，`dist custom data.csv --field amount --boundaries 0,100,500,1000`。

支持多种图表类型的数据格式输出。数据聚合粒度可调（按天/周/月聚合后看分布变化）。输出为 JSON 格式方便前端渲染。

分布统计量：均值、中位数、众数、标准差、偏度、峰度、四分位数。异常值检测（超过 Q3+1.5*IQR 的标为异常）。

支持输出为直方图 ASCII 字符画。大数据量流式处理不占内存。Go 标准库实现。

工具单二进制分发，不依赖外部服务。数据存 JSON 文件。所有操作有审计日志。
不要写单文件，核心逻辑、CLI 入口、辅助工具各放一个文件。
