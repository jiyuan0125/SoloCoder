上周的 A/B 测试结果出来了——新按钮颜色组比对照组转化率高 2.3%。但产品经理拿到两份 CSV 以后对着看了半小时，字段有三十多个，一行行对根本对不过来。实验组有个字段对照组没有，也不知道该不该排除。这种情况每周都在发生。

对比报表工具，输入两份数据文件（JSON 或 CSV）。工具逐字段对比数值差异和分布差异。字段不完全一致时只对比共有字段，独有字段单独列出来——上次实验组多了一个 device_model 字段，就是因为没对齐导致统计结果歪了。主操作执行时调用辅助检查（数据格式一致性、字段对齐），辅助检查也读同一份数据，不额外传参。

统计显著性检验这块不能省。对比两组均值差异用 t 检验，比例差异用卡方检验，输出 p 值。p < 0.05 标为显著——老板只关心这个结果，不关心过程。

差异维度要全面：数值字段的均值差异和百分比变化，分类字段的分布变化。每个差异带 95% 置信区间。数据聚合粒度可调（按天/周/月）。输出 JSON 方便前端渲染，对比结果也能导出 Markdown 表格直接贴到周报里。

Go 标准库实现，单二进制分发，不依赖外部服务。数据存 JSON 文件。所有操作有审计日志。
