前端同事说"你给我 raw JSON 我怎么画图"，他需要的是折线图的 x-y 数组、饼图的 label-value 数组、散点图的点集。每次手动把 CSV 转成前端能用的格式，比写业务逻辑还花时间。上周一个仪表盘要五种图表，光数据格式转换就搞了一整天。

图表数据生成工具。`chartgen line data.csv --x date --y value --output chart.json`，一条命令搞定。从 CSV 或 JSON 读取数据，输出 JSON 方便前端渲染。支持 ECharts、D3、Chart.js 三种前端框架的格式。

图表类型覆盖常用的：折线图、柱状图、饼图、散点图、面积图、雷达图。数据聚合粒度可调（按天/周/月/季/年），比如日数据想看月趋势就按月聚合。修改主体数据后关联图表数据同步更新。

数据预处理很关键，脏数据画出来的图没人敢信。空值填充、异常值过滤、平滑处理（移动平均）、归一化（Min-Max/Z-Score），每种预处理可单独开关。

多系列图表支持（同一张图多条线对比）。自动检测数据类型，如果 X 轴是日期就建议折线图，X 轴是分类就建议柱状图。

Go 标准库实现，单二进制分发，不依赖外部服务。数据存 JSON 文件。所有操作有审计日志。
