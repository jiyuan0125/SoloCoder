每周五下午项目周会，PM 要在 PPT 里贴一张各项目工时消耗的柱状图。流程是：打开 Jira → 导出 CSV → 手动整理格式 → 导入 Excel → 生成图表 → 截图。六个步骤，每周重复，一个小时就过去了。该自动化了。

柱状图数据工具。输入 CSV 或 JSON 数据，按分类字段分组，对数值字段聚合（sum/avg/count/max/min），直接输出柱状图 JSON——每个分类一个柱子，丢给 ECharts 就能渲染。

堆叠柱状图是刚需：主分类按项目，子分类按人员或模块，一个柱子里面分色显示。横向纵向柱状图切换——项目名称太长的时候横向显示更清晰。柱子排序支持按值排序（最大的在最前面）或按标签排序（字母序）。

上周还加了需求：按部门分组后，每个部门下面按项目堆叠，这样老板一眼就能看到哪个部门工时超标。

输出 ECharts option 格式 JSON，前端直接 `setOption(data)` 就行。Go 标准库实现，单二进制分发，不依赖外部服务。数据存 JSON 文件。所有操作有审计日志。
