每月初要出 KPI 月度趋势图：目标是一条线，实际是一条线，两条线的差距就是完成情况。从数据库导出 CSV 后还要手动整理成前端图表格式，每月重复。上个月导出的数据缺了三个周末的日期，折线图直接断开了，老板以为是系统挂了。

折线图数据工具。输入 CSV 时间序列数据（日期 + 若干数值列），输出折线图 JSON。命令：`linegen data.csv --x date --y target,actual --output trend.json`。

KPI 场景的折线图有特殊需求：目标值和实际值各一条线，达标区域标绿色，未达标区域标红色，接近达标的标黄色。多 KPI 汇总看板里每个 KPI 一张小折线图。数据变更时自动通知下游——KPI 值更新了，依赖它的图表数据也要刷新。

多线叠加：目标线 + 实际线 + 上期线，三线对比看进步还是退步。数据插值处理缺失日期：自动补点，用前值或线性插值。Y 轴范围自适应或手动指定（KPI 图表 Y 轴一般从 0 到 120% 才合理）。

趋势标注：自动标注最高点和最低点，附具体数值。数据点过多时自动降采样（一年 365 个点终端显示不了，降到 52 个周点）。支持面积填充。输出 JSON 支持 ECharts 和 Chart.js 两种格式。

Go 标准库实现，单二进制分发，不依赖外部服务。数据存 JSON 文件。所有操作有审计日志。
代码分文件组织，解析器、处理器、输出器分开，main.go 只做参数解析和流程串联。
