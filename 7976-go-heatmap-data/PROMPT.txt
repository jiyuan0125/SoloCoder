50 台机器 × 24 小时的 CPU 使用率数据，要画成热力图看哪台机器在哪个时段负载高。数据从 Prometheus API 拉出来是时间序列格式，但热力图要的是二维矩阵：行是机器名，列是时间点，值是 CPU 百分比。格式转换每次都手动搞，50 台机器的数据量手动转一次要半小时。

热力图数据工具。输入 CSV 或 JSON（行标签、列标签、值），输出热力图 JSON：二维矩阵 + 行列标签 + 颜色映射范围。前端拿到就能直接渲染。

颜色映射不是简单线性就够的。CPU 使用率 0-50% 是正常区间颜色变化不大，50-80% 要开始变黄，80% 以上变红。所以颜色映射函数可配：线性、对数（适合数值跨度大的场景）、分位数（突出分布差异）。阈值标记：超过设定阈值的格子用特殊颜色高亮。

矩阵支持不对称——行数和列数可以不一样，30 台机器 × 48 个半小时点完全没问题。大数据量自动分块处理，不会内存溢出。还能导出 CSV 矩阵格式丢给 Excel 做条件格式。

Go 标准库实现，单二进制分发，不依赖外部服务。数据存 JSON 文件。所有操作有审计日志。
