运营总监想看用户在站内的流向——从首页进来，有多少去了搜索，有多少去了推荐，各自又去了哪里，最终在哪一步流失。桑基图是最佳选择，但数据整理成桑基图格式（节点列表 + 链接列表）非常繁琐。上个月让实习生整理了一个下午，格式还是不对，前端说 source 和 target 的名称不一致导致节点重复。

桑基图数据工具。输入用户行为日志（JSON：用户 ID、来源页面、目标页面、时间戳），自动统计每对源到目标的流量，输出桑基图 JSON：节点列表（去重）+ 链接列表（source、target、value）。修改主体数据后关联图表数据同步更新。

流量太碎的节点要合并。占比低于阈值（比如 1%）的流量合并为"其他"节点，不然图表上全是细线看不清。循环检测也必须做——桑基图不支持循环流（A→B→C→A），检测到循环自动截断。

层级自动识别：按流量汇聚点分层，不用手动指定哪一层放什么节点。按时间范围过滤数据。节点颜色可配置，不同层级用不同色系。

输出 JSON 支持 ECharts 和 D3 两种格式。Go 标准库实现，单二进制分发，不依赖外部服务。数据存 JSON 文件。所有操作有审计日志。
