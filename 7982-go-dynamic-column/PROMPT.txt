运营要的报表每次都加新花样。上周要"月环比增长率"，这周要"季度累计金额"，下周估计要"同比增速"。这些列都不在原始数据里，得从其他列算出来。每加一个新列就改一次代码或者写个临时 Python 脚本，数据团队已经攒了 20 多个脚本了，没人敢删也没人知道哪个还在用。

动态列工具，新列需求不改代码。动态列定义从 JSON 配置文件读取，每个列有名称、计算公式和输出格式。公式支持：四则运算、聚合函数（sum/avg/count/max/min）、时间函数（同比/环比/累计）、条件函数（if-then-else）。

四种动态列类型：计算列（从其他列派生，比如"金额 = 单价 × 数量"）、排名列（按某字段排名）、分组列（按条件分桶，比如"金额 > 1000 为高价值"）、标志列（满足条件为 1 否则为 0）。

环比和同比是高频需求——环比是和上一个周期比，同比是和去年同周期比。计算周期可配（日、周、月、季）。缺失周期用前值填充，不会因为缺了一天数据就报错。输出 Markdown 表格。

最终输出是原始数据 + 动态列的合并表格。加 `--only-dynamic` 参数只输出动态列，适合粘贴到已有报表里。

Go 标准库实现，单二进制分发，不依赖外部服务。数据存 JSON 文件。所有操作有审计日志。
