数据团队花了一整天清洗用户表——补了 3000 个空手机号、去重了 500 条记录、修正了 200 个日期格式。但清洗完拿给业务方看，对方问"质量提升了多少"，没人答得上来。清洗前和清洗后的数据质量到底差多少，得有量化的指标说话。

数据质量报表工具，给数据质量打分。输入 CSV 或 JSON 数据文件，五个维度各打 0-100 分：完整性（必填字段空值率）、唯一性（主键重复率）、时效性（数据是否过期）、准确性（数值是否在合理范围）、一致性（关联字段是否匹配）。总评分加权计算，权重可配。`quality report data.csv --output report.html` 一条命令出报表。

多个关联实体之间的质量评分要关联展示。比如用户表质量 85 分但订单表只有 60 分，关联起来看就知道订单数据是短板。

质量趋势是关键价值。保存每次的历史评分，生成趋势曲线。上周完整性 92 分这周掉到 78 分，标记为"退化"——可能是新接入的数据源质量有问题。聚合粒度可调，输出 JSON 供前端渲染。

输出 HTML 报表（含评分表格、雷达图数据、趋势数据）或纯 JSON。Go 标准库实现，不引第三方包，单二进制分发。数据存 JSON 文件，操作带审计日志。
代码组织要清晰：CLI 参数处理一个文件，核心业务逻辑一个文件，公共工具函数一个文件。
