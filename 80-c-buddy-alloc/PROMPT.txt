用 C 写一个伙伴系统内存分配器。预分配一大块内存，按伙伴系统管理分配和释放。

分配规则：
1. 最小分配单元 64 字节，最大分配 4MB。预分配 64MB 内存
2. alloc(size)：将 size 向上取整到最近的 2 的幂（如 100 → 128，200 → 256），如果 size 为 0 返回 NULL
3. free(ptr)：释放内存。如果 ptr 的 buddy 也是空闲的则合并（递归向上合并），释放的块大小必须和分配时一致
4. split 操作只能将一个块平分成两个等大的 buddy

数据结构：
5. 用数组维护空闲块列表，按块大小分级（64, 128, 256, ..., 4MB 共 16 级）
6. 每个空闲块记录：大小、是否空闲、buddy 位置（用于合并时查找）

碎片统计：
7. 碎片率 = (已分配块数 × 最小块大小 64) / 总内存 64MB。实际分配越分散（小碎片越多）碎片率越高。不是 1 - 最大连续块/总空闲
8. 提供 buddy_stats() 打印：总内存、已用内存、空闲内存、碎片率百分比、各级大小的空闲块数

要求：
9. free 时如果 ptr 不在预分配范围内或者地址没有对齐到对应块大小的边界，返回错误不释放
10. buddy_init() 返回分配器指针，buddy_destroy() 释放预分配的大块内存

代码分 buddy_alloc.c、buddy_alloc.h 两个文件，gcc 编译能过。
