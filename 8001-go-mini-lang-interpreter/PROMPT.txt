上周末参加了一场编程语言工作坊，回来手痒想自己造一个玩具语言。帮我用 Go 写一个小型编程语言解释器，就叫它 mini 好了。

这门语言需要支持这些基本能力：整数和浮点数变量赋值（用 = 赋值，变量名支持字母数字下划线）、四则运算（加减乘除，注意除零要报错）、括号改变优先级、if/else 分支和 while 循环做控制流、print 语句输出结果。运算符优先级按常规来，乘除高于加减，括号最优先。比较运算符 == != > < >= <= 返回布尔值，布尔类型支持 && || ! 逻辑运算。

代码从 .mini 文件读取或者 stdin 传入，经过词法分析拆成 token，再解析成 AST，最后树遍历逐节点执行。语法错误要报出具体的行号列号和出错原因，比如第 3 行少了个右括号这种。运行时错误同理，除零或者对未定义变量的引用都得有清晰提示。

解释器内部维护一个环境 map 做变量绑定，作用域用链表结构，if/while 的块内定义的变量出了块不能访问。变量查找沿作用域链向上搜索。

go build 能编译通过就行，不用搞太复杂，标准库足够。命令行用法：mini run hello.mini 或者 cat hello.mini | mini run。
