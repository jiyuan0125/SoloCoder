先说一下场景：我们微服务配置分开发、测试、预发、生产四套环境，现在用 JSON 配置，不同环境只能复制一份改几个值，维护成本很高。

用 Go 实现一个配置 DSL 解析器来解决这个痛点。DSL 核心能力：支持嵌套块（用大括号分层，像 JSON 但不用写引号和逗号）、变量引用（${var} 语法，可以从环境变量也可以是前面定义的变量）、环境变量替换（${env.HOST} 直接读系统环境变量）、还有条件判断语句 if(env == "prod") { ... } else { ... }，根据环境变量值选择性包含配置块。

解析后输出为标准 JSON 格式，方便现有服务直接读取。引用不存在的变量要报错，循环引用（A 引用 B，B 又引用 A）也要检测出来。变量替换支持默认值语法 ${DB_PORT:-3306}，冒号减号后面跟默认值。

注释用 # 号开头，解析时跳过。key = value 是基本赋值，value 可以是字符串、数字、布尔、null。同一个 key 重复定义时后面的覆盖前面的。include "other.cfg" 可以引入其他配置文件，引入内容在当前位置展开。

解析错误时报告行号和具体错误位置，比如 "line 12: undefined variable ${UNKNOWN}"。

纯标准库，go build 能编译。命令行：cfg-dsl config.dsl -o config.json。
