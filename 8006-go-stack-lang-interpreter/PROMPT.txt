你玩过 Forth 吗？那种把操作数都往栈上扔的语言，写起来特别有极客感。想自己搞一个。

实现一个 Go 版的栈式编程语言，类似 Forth 那种风格。支持整数和浮点数操作（自动做类型提升，整数和浮点运算时整数转浮点）、基本算术（+ - * / mod）、栈操作（dup 复制栈顶、swap 交换栈顶两个、drop 丢弃栈顶、over 复制次栈顶到栈顶）。

控制流方面：条件分支用 if ... then 或 if ... else ... then，循环用 begin ... until（直到条件为真退出）和 begin ... while ... repeat（条件为真时继续）。这些控制结构通过编译到跳转指令实现。

用户定义新词（word）用冒号语法：`: square dup * ;` 定义一个 square 词。词定义可以嵌套引用其他自定义词。递归定义也支持，但要有最大递归深度限制。

解释器维护一个数据栈和一个返回栈（调用词时保存位置），用户输入代码字符串，逐步执行。错误要有意义——栈下溢（空栈时执行 dup）、除零、未定义的词都要报出来，附带当前栈状态方便调试。

标准库，go build 通过。交互模式逐行执行，也支持从文件加载执行。
