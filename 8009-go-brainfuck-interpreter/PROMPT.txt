Brainfuck 只有 8 个指令却能算任何可计算的东西，图灵完备的最小实现之一。想自己写个解释器感受一下它的力量。

用 Go 写个 Brainfuck 语言解释器。先加载 BF 代码，验证括号配对合法性（每个 [ 必须有对应的 ]），然后预计算跳转表——把每对匹配的方括号位置记录下来，执行时 O(1) 查找。

8 个指令：> 移动数据指针向右、< 向左、+ 当前单元格加一、- 减一、. 输出当前单元格的 ASCII 字符、, 从 stdin 读一个字节存入当前单元格、[ 如果当前值为 0 则跳到匹配的 ] 后面、] 如果当前值非 0 则跳回匹配的 [ 后面。

内存带至少 30000 个单元格，初始全零，每个单元格是 uint8（0-255 溢出回绕，255+1 变 0，0-1 变 255）。指针可以双向移动，超出初始范围的部分动态扩展（按需分配新单元格，不设上限）。

忽略 8 个指令以外的所有字符（当作注释），逗号指令从 stdin 读一个字节（EOF 时存 0），点号输出到 stdout。支持传入命令行参数指定内存带初始大小和单元格位宽（8/16/32 位可选）。

执行完后可选打印数据指针位置和非零单元格的内容，方便调试。go build 通过，标准库就好。
