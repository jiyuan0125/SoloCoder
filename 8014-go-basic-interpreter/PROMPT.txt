先搞清楚需求：我们要实现一个经典 BASIC 解释器。BASIC 的行号机制让它跟现代语言很不一样——代码按行号排序存储，GOTO 和 GOSUB 通过行号跳转。

写个 BASIC 语言解释器，Go 实现。源码从文本文件加载，每行以行号开头（如 "10 PRINT ""HELLO"""），程序按行号从小到大排序后执行。

语句类型覆盖这些：LET 变量赋值（支持整数和字符串，变量名后缀 $ 表示字符串类型）、PRINT 输出（支持多个表达式用分号或逗号分隔）、IF THEN 条件（THEN 后面跟行号就是 GOTO，跟语句就是执行）、GOTO 行号跳转、FOR NEXT 循环（支持 STEP 步长）、GOSUB RETURN 子程序调用（用栈维护返回地址）、INPUT 从终端读取用户输入、END 终止程序。

内置数学函数：ABS 取绝对值、INT 取整、RND 生成 0-1 随机数、SQR 平方根。表达式支持四则运算和括号，字符串只支持拼接（+）和比较（= <>）。

语法错误报告行号，运行时错误也报告出错的源码行。一个简单的猜数字游戏就能验证整个流程是否跑得通。

标准库，go build 能编译就行。
