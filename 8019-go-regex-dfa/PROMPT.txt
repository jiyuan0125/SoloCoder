第一步把正则转成 NFA，第二步用子集构造法把 NFA 转成 DFA，第三步把 DFA 最小化——完整的正则到 DFA 管线走一遍，比看教科书管用多了。

Go 实现 DFA 版的正则匹配。正则先经过词法分析和语法分析生成 AST，再用 Thompson 构造转 NFA，接着子集构造法把 NFA 的每个可达状态集合映射为 DFA 的一个状态。最后用 Hopcroft 算法最小化 DFA——不断细化等价类直到不能再分。

支持基本正则语法：字面字符、选择(|)、连接、闭包(*+?)、字符类([])、括号分组。展示从正则到 NFA 到 DFA 到最小化 DFA 的完整转换过程——打印每一步的状态数量变化，比如 "regex -> NFA(12 states) -> DFA(8 states) -> minDFA(5 states)"。

DFA 匹配的时间复杂度和输入串长度线性相关，这是 DFA 相对回溯引擎最大的优势，不会出现指数爆炸。匹配过程可以开启 verbose 模式：每读一个字符，显示当前 DFA 状态编号和转移。

Match(pattern, text) 和 FindAll(pattern, text) 两个接口都要提供。正则语法错误在编译阶段就要报出来。

标准库，go build 编译通过。
