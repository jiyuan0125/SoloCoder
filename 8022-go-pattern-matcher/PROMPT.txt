日志系统里需要对每条消息做模式匹配，有的按前缀匹配，有的要正则，有的用通配符——分散处理太乱了。

用 Go 写一个统一的多模式匹配引擎。支持多种匹配模式：精确匹配（字符串完全相等）、前缀匹配（strings.HasPrefix）、后缀匹配（strings.HasSuffix）、通配符匹配（支持 * 和 ?）、正则匹配（regexp.Compile 后匹配）。

用户定义一组 pattern 和对应动作（用一个 JSON 配置文件描述规则列表），输入字符串后引擎依次检查所有规则，返回所有匹配到的 pattern 及其动作。匹配顺序支持优先级排序——优先级数值越小越先匹配，也可以配置为最长模式优先（更具体的规则优先于模糊的规则）。

性能优化：精确匹配用 hash map O(1) 查找、前缀匹配用 Trie 树、正则匹配预编译缓存。对大量规则的场景，先过一遍快速匹配器（精确和前缀），命中不了的再走慢速的通配符和正则。

命令行工具从配置文件加载规则，从 stdin 逐行读取输入，每行输出匹配结果。API 层面提供 AddRule、Match、MatchAll 三个方法。

go build 通过，标准库。
