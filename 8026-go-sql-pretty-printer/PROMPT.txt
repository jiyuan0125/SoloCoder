代码 review 的时候看到同事写了一行 500 字符的 SQL，瞬间不想看了。格式化工具必须安排上。

写个 SQL 格式化工具，Go 实现。输入一段压缩的 SQL 字符串，输出格式化后的版本。格式化规则：关键字全部大写、SELECT/FROM/WHERE/GROUP BY/ORDER BY/LIMIT 各占一行且缩进相同层级、JOIN 各占一行、子查询缩进一层（用两个空格或四个空格可配置）、长 WHERE 条件按 AND/OR 断行（AND/OR 在行首，对齐缩进）。

逗号后面加空格、运算符两边加空格。函数调用内部不断行，参数之间逗号后加空格。字符串字面量和数字原样保留。IN (...) 里的值超过 5 个就每个值一行。CASE WHEN ... THEN ... ELSE ... END 每个分支一行。

支持配置选项：缩进用空格还是 tab、缩进宽度、每行最大长度（超过则自动断行）、关键字大写还是小写、逗号前置还是后置。配置用命令行参数传入。
命令行工具，从 stdin 或文件读取 SQL，输出格式化后的 SQL 到 stdout。标准库，go build 编译通过。
注意处理空输入、超长输入等边界情况，函数遇到异常输入应该返回有意义的错误而不是静默失败。
