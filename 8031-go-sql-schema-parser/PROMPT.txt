做数据库迁移工具，第一步就是要把 CREATE TABLE 语句解析出来，搞清楚每张表长什么样。手动抄字段定义太蠢了。

写个 SQL Schema 解析器，Go 实现。解析 CREATE TABLE 语句，提取表名、列定义（名称、数据类型如 INT/VARCHAR(255)/BOOLEAN/DATE/TIMESTAMP/DECIMAL(10,2)、约束如 NOT NULL/PRIMARY KEY/UNIQUE/DEFAULT value/AUTO_INCREMENT/REFERENCES）、外键关系（FOREIGN KEY (col) REFERENCES other_table(col)）、索引定义（CREATE INDEX idx_name ON table(col)）。

解析结果可以序列化为 JSON 输出，JSON 结构包含表名、列数组（每个列有 name/type/constraints）、主键列名、外键列表、索引列表。支持多个表的 schema 文件一起解析，多个 CREATE TABLE 语句用分号分隔。

数据类型解析要够细致：VARCHAR(255) 要提取出长度参数，DECIMAL(10,2) 要提取精度和小数位，TIMESTAMP 要支持 WITH TIME ZONE 后缀。DEFAULT 值的解析——字符串要带引号、数字直接写、CURRENT_TIMESTAMP 这种表达式也要识别。

命令行工具从 SQL 文件读取 DDL，输出 JSON schema。go build 能编译，纯标准库。
