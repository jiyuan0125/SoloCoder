Web 开发里模板引擎是标配——把数据塞进 HTML 模板里输出。Go 自带的 text/template 不错，但想自己实现一个更灵活的版本。

用 Go 写一个通用模板引擎。支持这些模板语法：变量插值 {{.name}}（点号路径访问嵌套字段，比如 {{.user.profile.age}}）、条件判断 {{if .logged_in}}...{{else}}...{{end}}、循环 {{range .items}}...{{end}}（循环体内 {{.}} 引用当前元素）、自定义函数调用 {{.name | upper | truncate 20}}。

模板从文件加载（支持模板目录，按文件名查找），和数据合并后输出渲染结果。数据用 map[string]interface{} 或 struct 传入，通过反射读取字段值。

模板编译阶段要检查语法正确性——未闭合的 {{if}}、{{range}} 都要报出来，报告具体哪行出错。运行时数据缺失不崩溃，默认输出空字符串（可配置为报错）。

支持模板嵌套 {{template "header" .}} 引用其他模板文件，支持 {{define "name"}}...{{end}} 定义子模板。支持注册自定义函数（传入函数名和 func(...string) string 类型的函数）。

标准库，go build 通过。
