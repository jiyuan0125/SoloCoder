YAML 是配置文件界的"看起来简单实际全是坑"——缩进语义、多种数据类型表示、锚点别名、多文档流。要正确解析它，真得认真对待每一个细节，不能心存侥幸。

实现一个 YAML 解析器，Go 语言。支持 YAML 1.2 核心子集——标量类型（字符串单双引号和无引号、整数十进制/十六进制/八进制/二进制、浮点数含 .inf 和 .nan、布尔 true/false、null/~ 和空值）、序列（- item 短横线加空格，支持嵌套）、映射（key: value 冒号后加空格）。

高级特性：多文档流（--- 分隔，... 结束）、锚点和别名（&anchor 定义，*alias 引用，包括合并键 <<: *alias 合并映射内容）、折叠标量（> 折叠换行为空格，| 保留换行）、块序列和块映射的任意嵌套、行内序列 [a, b] 和行内映射 {k: v}。

解析成通用的树结构——Node 类型有 Scalar、Sequence、Mapping、Alias 四种，不依赖 gopkg.in/yaml.v3。解析错误要报告行号和具体原因。

这个工具在日常开发中能省不少重复劳动。
go build 编译通过，标准库。
