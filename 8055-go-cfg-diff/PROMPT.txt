配置改了之后服务行为不一样了，到底改了啥？人工对比两份 JSON 文件太痛苦了，特别是嵌套很深、字段上百个的时候，肉眼根本看不过来。

用 Go 写个配置差异比较工具。输入两个 JSON 或 YAML 文件，输出详细的 diff 结果。不做文本层面的 diff，而是做语义层面的结构化比较——精确到每个字段的变化。

比较规则：对象按 key 逐一比较——新增的 key 标记为 added（显示新增的值）、删除的 key 标记为 removed（显示被删的值）、值变化的 key 标记为 modified（同时显示旧值和新值）、值不变的跳过不显示。嵌套对象递归比较，路径用点号表示（如 database.connection.pool_size: 10 -> 20）。数组按索引逐项对比——每项显示是 added/removed/modified，并标注数组索引。

输出格式要人类可读——终端模式下用颜色区分增删改（绿色 added、红色 removed、黄色 modified）。也支持 --json 输出结构化 diff report。支持 --quiet 模式只输出有没有差异（退出码 0=相同 1=不同，方便 CI）。
