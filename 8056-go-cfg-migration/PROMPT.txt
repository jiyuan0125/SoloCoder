我们的配置格式要从 v1 升级到 v2，十几个微服务的配置文件都得迁移。字段名变了、结构从扁平改成嵌套了、有些默认值也变了。手动改太慢还容易出错。

用 Go 写个配置迁移工具。定义好 v1 到 v2 的迁移规则，批处理所有配置文件。迁移规则支持的操作：字段重命名（database_host -> database.host，从扁平变成嵌套）、类型转换（字符串端口号 -> 整数、"true"/"false" -> 布尔值）、结构调整（把 server.host 和 server.port 合并为 server.address = "host:port"）、默认值填充（v2 新增的必填字段自动填默认值）、字段删除（v2 废弃的字段移除并记录到日志）。

迁移规则用一个迁移定义文件描述（JSON 格式），包含一系列迁移步骤。每个步骤定义源路径、目标路径、转换函数（rename/typeConvert/merge/split/default/remove）。

迁移完输出两样东西：迁移后的 v2 格式配置文件、迁移报告（列出每个文件做了哪些变更——哪些字段重命名了、哪些新增了、哪些删除了）。

命令行工具，go build 能编。
