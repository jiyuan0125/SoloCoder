告警系统要判断一堆指标条件是否触发——CPU 使用率超过 80% 或者内存超过 90% 且磁盘超过 85%。条件可以嵌套组合，该怎么设计一个灵活的条件评估引擎？

Go 实现条件评估引擎。支持组合条件：any（任一子条件满足即 true，等价于 OR）、all（所有子条件都满足才 true，等价于 AND）、not（取反）。阈值比较：> >= < <= == !=，支持数字和字符串类型。时间窗口判断：within("5m") 表示最近 5 分钟内。

条件用 JSON 格式定义——可以嵌套任意深度，比如 {"any": [{"all": [{"field": "cpu", "op": ">", "value": 80}, {"field": "mem", "op": ">", "value": 90}]}, {"field": "disk", "op": ">", "value": 95}]}。评估的时候传入指标数据 map[string]interface{}，返回三个信息：是否触发（triggered bool）、匹配了哪些条件（matched []string，条件的路径描述）、不满足哪些条件（unmatched []string）。

评估结果以 JSON 输出，方便下游系统消费。条件定义文件可以有多个条件组，按优先级排序评估。
