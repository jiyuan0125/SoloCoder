栈式虚拟机的指令太多太碎——一个加法要三个指令（PUSH a, PUSH b, ADD）。寄存器式设计直接用寄存器编号操作，理论上指令数更少、执行更快。想对比一下两者。

Go 实现一个基于寄存器的虚拟机，指令的操作数用寄存器编号而不是栈顶。至少支持 16 个通用寄存器（R0-R15）。

指令集：MOV Rd, Rs/Rd, imm 寄存器间传送或加载立即数。ADD/SUB/MUL/DIV Rd, Rn, Rm 三操作数算术（Rd = Rn op Rm）。LOAD Rd, [Rs + offset] 从内存加载到寄存器。STORE Rs, [Rd + offset] 寄存器值存入内存。CMP Rn, Rm 比较两个寄存器设置条件标志。JMP/JZ/JNZ/JG/JL label 条件跳转。CALL label / RET 函数调用和返回（保存恢复寄存器现场）。PRINT Rd 输出寄存器值。

写个简单的汇编器，汇编语法支持标签定义和注释。虚拟机执行后打印所有非零寄存器状态和程序计数器值。内存模型用 []byte（64KB），内存查看命令 dump start length。

支持 --trace 模式打印每条指令执行后的寄存器快照变化。

go build 能编。
