手上有字节码二进制文件但看不到具体干了啥——编译器输出的中间产物，或者需要逆向分析的字节码。一个反汇编器是理解字节码内容的第一步。

Go 实现字节码反汇编器。把二进制字节码文件反汇编成可读的汇编指令文本。核心处理步骤：

指令边界识别——从起始位置逐字节解析操作码（opcode），根据操作码查表确定指令长度（不同指令的操作数数量不同），正确切分每条指令不能错位。操作码解码——操作码映射到可读指令名（0x01 -> PUSH, 0x02 -> ADD, 0x10 -> JMP 等）。操作数解码——根据指令格式解码（整数用小端序读取、地址用十六进制表示、寄存器编号映射到名字 R0-R15）。标注函数入口点——识别 CALL 指令的目标地址标记为函数入口，给个标签名 func_0010。标记跳转目标——JMP/JZ 等指令的目标地址标注为 L_0010 格式的标签。

如果指令集不是固定的，用一个 JSON 配置文件描述指令编码格式——每条指令的操作码、名称、操作数类型列表。这样反汇编器可以适配不同的自定义指令集。

输出格式：地址 + 十六进制原始字节 + 汇编文本。go build 通过。
