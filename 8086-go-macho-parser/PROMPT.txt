分析 macOS 上的二进制文件需要理解 Mach-O 格式——和 Linux 的 ELF 完全不同的二进制布局，但同样承载着代码、数据和元信息。不用 debug/macho 包，手动按规范解析二进制字节。

Go 实现 Mach-O 文件解析器。Mach-O 文件以 magic number 开头（0xFEEDFACE 是 32 位，0xFEEDFACF 是 64 位），紧接着是 header：

Header 字段——CPU 类型（CPU_TYPE_X86_64/ARM64 等）、文件类型（MH_OBJECT/MH_EXECUTE/MH_DYLIB 等）、load command 数量、sizeofcmds。Load Commands——每个 load command 描述文件的一个方面：LC_SEGMENT_64（段定义，包含节列表）、LC_SYMTAB（符号表和字符串表偏移）、LC_DYSYMTAB（动态符号表）、LC_LOAD_DYLIB（依赖的动态库路径）、LC_MAIN（入口点）。Sections——属于某个 Segment，包含节名（如 __text、__data）、虚拟地址、文件偏移和大小。

解析输出：文件类型描述、CPU 架构、所有 Segment 及其 Section 列表（名称、地址、大小、属性）、导出符号列表、依赖的动态库列表。
