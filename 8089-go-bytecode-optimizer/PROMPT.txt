自己做的字节码编译器生成的代码太冗余了——加载一个常量马上存到局部变量又加载出来、跳转到下一条指令、永远执行不到的死代码。这些冗余指令白白浪费执行时间。

Go 实现一个字节码优化器。对自定义字节码做几类优化 pass，每个 pass 可以独立运行也可以组合：

常量折叠（Constant Folding）——编译期可计算的表达式直接算出结果，比如 PUSH 1, PUSH 2, ADD 替换为 PUSH 3。死代码消除（Dead Code Elimination）——不可达的指令删除，比如 JMP 后面紧跟的指令（如果不是跳转目标）、无条件跳转后面的指令。常量传播（Constant Propagation）——跟踪常量值的流动，LOAD x（已知 x=5）后续用到 x 的地方直接用 5。冗余加载存储消除（Redundant Load/Store Elimination）——STORE x, LOAD x 序列简化为 DUP, STORE x（值已经在栈上了）。

输入未优化的字节码文件，输出优化后的字节码文件。打印优化统计——每类优化消除了多少条指令、总指令数从 N 减少到 M（减少百分比）。支持 -O1 到 -O3 优化级别。

go build 编译通过。
