调试编译器的时候最痛苦的就是看不到 AST 的结构——脑子里想象一棵树，但实际长什么样只能猜。一个清晰的 AST 可视化工具能省掉大量 printf 调试。

Go 写一个 AST 打印器，把抽象语法树以人类可读的形式输出。支持三种输出格式：

纯文本缩进——层级关系用缩进表示（2 空格或 4 空格可配置），每个节点一行，显示节点类型和关键字段。比如 "BinaryOp(+) ├── Num(1) └── Num(2)" 这种树形图。S-表达式——类 Lisp 格式输出 (BinaryOp + (Num 1) (Num 2))，紧凑适合程序处理。JSON——标准 JSON 序列化，每个节点是 {"type":"BinaryOp","op":"+","left":{...},"right":{...}} 结构，可以用 jq 等工具后续处理。

功能选项：控制打印深度（--depth N 超过 N 层的子树用 ... 省略）、显示 token 位置信息（每个节点标注源码行号列号）、自定义节点显示格式（注册格式化函数控制不同节点类型显示哪些字段）。

输入一个简单语言（算术表达式或 mini SQL）的 AST。先实现解析器，再打印 AST。也支持从 JSON 文件加载外部 AST。

go build 编译通过。
