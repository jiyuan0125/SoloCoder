做代码审查工具需要对比两份代码的 AST 差异。纯文本 diff 的问题太多了——变量名从 x 改成 count，文本 diff 只显示"删了 x 加了 count"，但语义上是重命名。只有 AST 级别的 diff 才能精确反映代码的逻辑变化。

Go 实现 AST 差异比较工具。解析两个源文件生成 AST，然后比较两棵树的差异。使用 Zhang-Shasha 树编辑距离算法找出最少的编辑操作序列，把旧 AST 变换成新 AST。

支持四种编辑操作：插入（新版本新增的节点，比如新增了一个 else 分支）、删除（旧版本被删除的节点，比如删了一个冗余的括号）、修改（节点类型相同但属性变了，比如数字字面量从 1 变成 2、运算符从 + 变成 -、函数名从 foo 变成 bar）、移动（节点从一棵子树移到另一棵位置，比如表达式从 if 条件移到了赋值右边）。

输出差异报告——按变更类型分组，标注每个变更在源码中的位置（文件名、行号、列号），用颜色区分增删改（终端模式）。忽略空格和注释的变化。支持输出 unified diff 格式。

先支持简单的表达式语言（算术表达式 + 变量赋值 + if/while 语句）。go build 通过。
