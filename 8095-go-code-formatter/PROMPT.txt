想做一个迷你代码格式化工具，类似 gofmt 但是针对自定义的简单语言。团队不用再争论缩进用 tab 还是空格、花括号放哪、行宽多少——格式化工具统一风格，所有人都接受。

Go 实现代码格式化器。解析源码生成 AST（或 token 流），然后按照可配置的格式化规则重新输出代码。格式化规则覆盖这些方面：

缩进——统一用 2 空格或 4 空格或 tab（--indent 参数配置），每增加一层嵌套（函数体、if/else/while/for 块、类定义）多一级缩进。空格——二元运算符两边加空格（a + b 不是 a+b）、逗号后面加空格、关键字后加空格（if (cond) 不是 if(cond)）、函数名和括号之间不加空格。花括号——K&R 风格（{ 跟在行尾）或 Allman 风格（{ 独占一行），--brace-style 参数选择。行宽——--max-width 80 或 120，超长行自动在合适位置断行（函数参数在逗号处断、长条件表达式在逻辑运算符处断）。对齐——连续的赋值语句自动对齐等号位置。

先支持类 C 语法的简单语言（变量声明、if/else、while/for、函数定义、表达式）。go build 通过。
