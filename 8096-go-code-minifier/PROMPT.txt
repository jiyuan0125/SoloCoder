前端构建的时候需要把 JS 代码压缩到最小体积——减少传输大小、加快页面加载。虽然 terser 和 Closure Compiler 已经很成熟了，但自己实现一遍能深刻理解代码压缩的各种策略。

Go 实现一个代码压缩器，针对类 JS 的简单语言。压缩策略按节省字节从多到少排列：

删除空白——删掉所有不必要的空格、换行、缩进。保留关键字和标识符之间的最少空格（var x 不能变成 varx），但关键字前后只留一个空格。缩短变量名——把局部变量重命名为 a, b, c, ... aa, ab, ... 使用作用域分析确保不同作用域的变量可以重名不冲突。全局变量和对象属性名不动（避免破坏外部引用）。删除注释——单行 // 和多行 /* */ 全部移除。删除不可达代码——if(false){...} 整个删除、return 后面的语句删除、永远为真的条件简化。合并字符串常量——"hello" + " world" 变成 "hello world"。

输入源码文件，输出压缩后代码。打印压缩统计——原始字节数、压缩后字节数、压缩率百分比、每种策略各节省多少。

go build 编译通过。
