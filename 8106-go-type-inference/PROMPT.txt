Go 的 := 短变量声明让类型推导无处不在——x := 42 编译器知道 x 是 int，y := x + 1.5 推导出 y 是 float64。想自己实现一个类似的局部类型推导引擎，理解编译器是怎么做到的。

输入一段简化的 Go 代码（var 声明、:= 短声明、赋值、函数调用、运算表达式），自动推导出每个变量的类型。推导规则：

字面量类型推导——整数推导为 int、浮点数推导为 float64、字符串推导为 string、布尔值推导为 bool。运算类型推导——同类型运算结果不变、int 和 float64 运算结果为 float64、字符串 + 字符串结果为 string。赋值类型推导——右值类型推导完成后赋给左值变量。函数调用推导——根据函数签名推导参数和返回值类型。复合类型——[]int 切片、map[string]int 字典、*int 指针。

命令行交互模式——逐行输入代码，实时输出每个新声明变量的推导类型。输入 "x := 42" 输出 "x: int"，输入 "y := x + 1.5" 输出 "y: float64"。

Go 标准库实现，go build 编译通过。
