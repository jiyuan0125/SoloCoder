做一个简易的源码到源码转换器框架——输入一种语言的代码，输出另一种语言的等价代码。这在编程语言迁移、代码现代化场景里很有用。

先实现一个示例转换器：把简化的 Pascal 代码转成 Go 代码。需要支持的映射关系：

变量声明——Pascal 的 var x: integer 映射到 Go 的 var x int。for/while 循环——Pascal 的 for i := 1 to 10 do 映射到 Go 的 for i := 1; i <= 10; i++，while cond do 映射到 for cond {}。if-else 结构——Pascal 的 if cond then ... else ... 映射到 Go 的 if cond { ... } else { ... }，注意 Pascal 不用花括号而用 begin/end。函数定义——Pascal 的 function name(params): returnType 映射到 Go 的 func name(params) returnType。赋值——Pascal 用 := Go 用 =（反过来），Pascal 用 = 比较而 Go 用 ==。

用法：transpiler -from pascal -to go input.pas。输出转换后的 Go 源码。转换不了的地方加 // TODO: manual conversion needed 注释标记。Go 标准库实现，go build 能编。
