PEG 和 CFG 的核心区别是选择操作有序——从左到右尝试，第一个成功就采用。这让 PEG 天然无歧义，不像 CFG 还要做歧义消解。

实现一个 PEG（解析表达式文法）解析器。PEG 跟 CFG 的关键区别是——PEG 的选择是有序的（/ 运算符从左到右尝试，第一个成功的就采用），而 CFG 的选择是无序的。这让 PEG 没有歧义问题，但也带来了一些不同的设计考量。

支持 PEG 的核心操作：顺序（a b，先匹配 a 再匹配 b）、选择（a / b，先尝试 a，失败则尝试 b）、零或多个（a*，重复匹配 a 直到失败）、一或多个（a+，至少匹配一次 a）、可选（a?，匹配零或一次 a）、否定预判（!a，如果 a 匹配成功则整体失败，不消费输入）、肯定预判（&a，如果 a 匹配成功则继续但不消费输入）。

定义格式用文本文件：
Expr <- Term (('+' / '-') Term)*
Term <- Factor (('*' / '/') Factor)*
Factor <- Number / '(' Expr ')'
Number <- [0-9]+

从文件读 PEG 规则，构建解析器，然后对输入文本做解析，输出匹配结果（成功/失败、匹配的文本范围、匹配树）。

Go 标准库，go build 编译通过。
