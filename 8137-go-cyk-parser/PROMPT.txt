CYK 是用动态规划解 CFG 解析的经典算法——虽然要求文法转成 CNF 格式有点麻烦，但算法本身简单到可以在面试白板上写出来。

做一个 CYK（Cocke-Younger-Kasami）解析器。CYK 是经典的动态规划解析算法——虽然要求文法必须是 CNF（Chomsky 范式），但算法本身简单清晰，适合教学和理解。

工作流程：先自动把普通 CFG 转换成 CNF——消除 ε 产生式、消除单位产生式（A -> B 形式）、把长产生式拆成二元产生式（A -> B C D 变成 A -> B X, X -> C D）、把终结符替换为新生成的非终结符。然后执行 CYK 算法——用三角矩阵 table[i][j] 表示子串 input[i:j] 可以推导出的非终结符集合，自底向上填表。

用三角矩阵展示解析过程——每格显示对应的非终结符集合。最终 table[0][n] 如果包含起始符号则输入合法。
用法：cyk-parser grammar.cfg "a b c"。输出是否接受，以及所有可能的解析路径。Go 标准库，go build 通过。
