Python 的缩进语法初看很清爽，但实现词法分析的时候头就大了——缩进级别变化要生成 INDENT/DEDENT token，混用空格和 tab 还会报错。这个需求比想象中复杂。

实现一个缩进敏感的词法分析器——类似 Python 那种靠缩进决定代码块结构的方式。缩进语言的好处是不用写花括号，代码看起来干净；坏处是词法分析器要自己处理缩进级别。

跟踪每一行的缩进级别——用空格数表示。遇到缩进增加时生成 INDENT token，缩进减少时生成 DEDENT token，每行末尾生成 NEWLINE token。

处理混合 tab/空格——默认报错（Python 3 的行为），可配置为统一转换（tab 按 4 空格计算）。支持悬挂缩进——if (很长的条件 and 另一个条件): 这种跨行的条件语句，括号内的内容不受缩进影响。续行（行尾反斜杠）——当前行和下一行视为同一行，不生成 NEWLINE。

括号内忽略缩进变化——()、[]、{} 内部换行时不生成 INDENT/DEDENT，用嵌套深度计数器跟踪。
用法：indent-lexer input.py。输出 token 序列，包含自动生成的 INDENT/DEDENT/NEWLINE token。Go 标准库，go build 编译通过。
