做代码统计报告的时候不想把注释行算进去、做文本 diff 的时候不想看注释变化——需要一个工具把注释剥离干净。

写一个注释剥离工具。有时候需要去掉代码里的注释——做代码统计的时候不想算注释行、做代码比对的时候不关心注释变化、做代码压缩的时候注释是多余的。

能智能地去除源代码中的注释，但保留字符串字面量里的注释文本（比如 console.log("// 这不是注释") 里的 // 不能被误删）。

支持多种语言的注释风格：Go 和 C/Java（// 单行和 /* */ 多行注释）、Python（# 单行和三引号 ''' """ 多行注释/文档字符串）、Shell（# 注释）、HTML（<!-- --> 注释）、CSS（/* */ 注释）。

两种模式：剥离模式（-strip）删除所有注释，保留代码和字符串。提取模式（-extract）反过来——把所有注释单独提取出来，标注来源文件名和行号，方便做文档生成或注释质量分析。
用法：comment-stripper -lang go -strip input.go 或 comment-stripper -lang go -extract input.go。Go 标准库实现，go build 能编。
