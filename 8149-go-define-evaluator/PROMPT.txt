实现一个 #define 常量表达式求值器。C 预处理器里的 #if 和 #elif 后面跟的表达式不是 C 代码而是预处理表达式——它的求值规则和普通 C 表达式略有不同。

解析预处理器中的条件表达式并求值。支持的操作：整数运算——加减乘除取模（+ - * / %）、位运算（& | ^ ~ << >>）、逻辑运算（&& || !）。宏值替换——表达式中的标识符如果是在 -D 参数中定义的宏，替换为对应的值。defined() 检查——defined(NAME) 返回 1（已定义）或 0（未定义）。比较运算（== != < > <= >=）。三元运算符（cond ? a : b）。

能处理嵌套宏和宏引用其他宏的情况——先展开所有宏引用，再求值。未定义的宏在表达式中视为 0（C 预处理器规范的行为）。

这个工具在日常开发中能省不少重复劳动。
用法：define-eval -D VERSION=3 -D DEBUG=1 -expr "VERSION > 2 && defined(DEBUG)"。输出求值结果 true/false 和展开后的表达式。

Go 标准库实现，go build 通过。
