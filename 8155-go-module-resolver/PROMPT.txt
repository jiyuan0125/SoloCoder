写个工具分析 Go module 依赖关系。Go module 是 Go 1.11 以后的标准依赖管理方案——go.mod 文件定义了模块的直接依赖，但间接依赖链和版本冲突经常让人头疼。

读取 go.mod 文件，解析以下指令：module 路径（模块标识）、go 版本（最低 Go 版本要求）、require 指令（直接依赖列表，含版本号和 //indirect 标记）、replace 指令（替换依赖源，本地开发时常用）、exclude 指令（排除特定版本）。

然后递归分析整个模块里所有包的依赖链——扫描所有 .go 文件的 import，结合 go.mod 的 require 列表，计算出完整的间接依赖图和最小依赖集。

检测版本冲突——同一个模块被间接引用了不同版本（比如 A 依赖 logrus v1.4、B 依赖 logrus v1.6），给出冲突报告。MVS（Minimal Version Selection）算法的模拟——展示 Go 选出的最终版本。
命令行用法：输入模块根目录，输出依赖树和冲突检测报告。纯 Go 标准库，go build 编译通过。
