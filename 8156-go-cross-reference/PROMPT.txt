帮我实现一个 Go 源码交叉引用生成器。做代码审查时经常想知道一个函数到底在哪些地方被调用了、一个类型被哪些 struct 嵌入了、一个常量在哪里使用——交叉引用就是干这个的。

这个工具读入一个 Go 包目录，解析后生成完整的交叉引用索引。对每个定义（definition），列出所有引用它的位置（references）；对每个引用，标注它指向的定义。

覆盖的场景：函数调用——直接调用、方法调用（值和指针接收者）、函数变量赋值。变量读写——读取变量值和给变量赋值的位置分别列出。类型使用——类型定义的位置和所有声明该类型变量的位置。接口实现——哪些 struct 满足了哪些接口。结构体嵌入——哪些 struct 嵌入了哪些类型。

输出 JSON 格式方便后续处理——格式为 { "definitions": [{ "name": "Foo", "file": "a.go", "line": 10, "references": [{ "file": "b.go", "line": 42 }] }] }。

这个工具在日常开发中能省不少重复劳动。
