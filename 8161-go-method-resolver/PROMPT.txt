值接收者和指针接收者的区别坑了无数 Go 新人——T 的方法集不包含 *T 的方法，但 *T 的方法集包含 T 的方法。搞错这个接口就满足不了。

写一个 Go 方法解析器，搞定方法集的分析。Go 的方法集（method set）是接口满足判断的基础——搞错了值接收者和指针接收者的区别就会遇到编译错误。

输入 Go 源码，解析出所有绑定到命名类型上的方法。对每个方法记录：接收者类型（值接收者还是指针接收者）、方法名、参数列表、返回值列表。

正确计算每个类型的方法集：对指针类型 *T，方法集包含 T 的所有方法（值接收者和指针接收者都算）。对值类型 T，方法集只包含值接收者的方法。这是 Go 规范明确规定的区别——因为指针接收者方法可能修改接收者，通过值调用无法保证。

还要处理结构体嵌入带来的方法提升——被嵌入类型的方法自动提升到外层类型。如果两个嵌入类型有同名方法，会产生冲突（编译错误），要检测出来。
输出每个类型的完整方法集表格，标注方法来源（自身定义还是嵌入提升）和接收者类型（value/pointer）。Go 标准库，go build 编译过。
单元测试覆盖正常路径和异常路径，go test / cargo test 能全部通过。
