工具解析 Go 源码中的所有匿名函数和函数字面量（go func() { ... }() 和 var f = func() { ... } 形式）。分析每个闭包捕获了哪些外部变量——在闭包体内使用但在闭包参数和体内未定义的变量就是被捕获的。

区分捕获方式：按引用捕获——Go 里闭包捕获的都是变量的引用（地址），闭包内修改会影响外部。被捕获的变量在闭包创建后还被修改过——这是最常见的 bug 来源（循环变量问题），标注为 "capture risk: variable 'i' modified after capture at line 10"。
