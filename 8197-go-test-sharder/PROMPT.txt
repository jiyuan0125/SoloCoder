CI 集群有多台机器，想把测试分片到不同机器上并行跑——这是缩短 CI 时间最有效的方式。需要一个分片工具把测试列表均匀分配到 N 台机器。

工具读入 Go 测试列表（通过 go test -list 获取），把测试均匀分成 N 个分片。分片策略支持三种：

按数量平均分——每片大约 total/N 个测试。按预估耗时加权分——根据历史数据（上一次运行的耗时记录），把慢的测试分散到不同分片，让每片总耗时大致相等。按包维度分——同一个包的测试放同一片，减少编译次数（因为 go test 按包编译）。

输出每个分片的测试列表（JSON 格式），或者直接运行指定分片——命令行参数：--total-shards 4 --shard-index 0（表示总共 4 片，当前执行第 0 片）。

支持缓存上次分片结果，增量更新——只有新增或删除的测试需要重新分配。
Go 标准库，go build 通过。
