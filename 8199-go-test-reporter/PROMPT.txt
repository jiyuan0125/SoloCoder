Jenkins 要 JUnit XML 格式的测试报告、团队想要 HTML 格式的可视化报告——go test 原始输出两种都不支持，需要一个转换工具。

帮我实现一个 Go 测试报告生成器。go test 的原始输出是文本流，CI 工具需要结构化的报告格式（JUnit XML 给 Jenkins、HTML 给人看）。

收集 go test 的 JSON 输出（go test -json），解析后生成格式化的测试报告。支持这些输出格式：

终端彩色表格——按包分组，每个测试一行（名称、状态、耗时），失败的测试展开显示错误信息和堆栈。HTML 页面——完整的测试报告页面（可以在浏览器里看），包含汇总图表（饼图显示通过/失败/跳过比例）、按包展开的详细结果、失败测试的完整错误输出。JUnit XML——标准格式，方便 Jenkins/GitLab CI 集成，包含 testsuite/testcase 结构。JSON——结构化数据，方便后续处理。

报告内容包括：每个包/测试函数的通过/失败/跳过状态、耗时、失败原因和堆栈、覆盖率数据（如果有）。

命令行工具：go test -json ./... | test-reporter --format html -o report.html。支持管道输入。Go 标准库，go build 通过。
