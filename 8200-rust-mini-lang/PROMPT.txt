最近想深入理解编译器原理，看完龙书觉得纸上得来终觉浅——必须动手写一个才算真的理解。帮我用 Rust 写一个迷你编程语言，从词法分析到解释执行完整走一遍。

语言不需要太复杂，支持这些特性就行：整数和布尔类型（i32 和 bool）、变量声明和赋值（let x = 42;）、算术运算和比较运算、if-else 条件分支、while 循环、函数定义和调用（支持递归）、println 输出。
Rust 社区对这类工具有很大需求。

实现三个阶段：词法分析器（lexer）——把源码拆成 token 流（关键字、标识符、数字、运算符、分隔符）。递归下降语法分析器（parser）——从 token 流构建 AST，处理运算符优先级（乘除高于加减、比较低于算术）。树遍历解释器（tree-walking interpreter）——递归遍历 AST 节点执行，维护环境（HashMap 存变量绑定）和调用栈。
对语法错误和运行时错误要有清晰的报错信息——标注出错的文件名、行号、列号和具体原因。用 Rust 实现，cargo build 通过，cargo run 可以执行 .mini 源文件。
内存数据结构考虑序列化和反序列化，方便保存和加载。
