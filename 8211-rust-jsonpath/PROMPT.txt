后端微服务之间的 API 调用越来越频繁，返回的 JSON 数据动辄几百 KB，嵌套层级深得让人头疼。每次只需要提取几个关键字段用于监控面板或日志聚合，手工写代码遍历 JSON 树既麻烦又容易写错路径，一旦上游 API 的结构调整还得逐行排查代码。团队决定引入 JSONPath 查询语法来做数据提取——一条表达式就能精确定位到目标节点，类似 XPath 之于 XML。现在需要用 Rust 实现一个 JSONPath 查询引擎，嵌入到内部的数据管道工具链里，处理每秒数千次的查询请求。

用 Rust 实现 JSONPath 查询引擎：
- 支持 $ 表示根节点，. 表示子节点，.. 表示递归下降
- 支持 [*] 数组通配符和 [0:3] 切片语法
- 支持 [?(@.price < 10)] 过滤表达式
- 支持多个路径用 | 连接，合并结果
- 不合法的 JSONPath 要报错说明原因
CLI：jsonpath "$.store.book[*].author" data.json，输出匹配到的值。cargo build 编译通过。
