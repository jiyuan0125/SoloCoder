Rust 生态里的 toml crate 虽然功能完备，但作为想深入理解解析技术的开发者，直接调用第三方库总感觉隔了一层，看不到里面的实现细节。TOML 作为 Rust 项目的标配配置格式——Cargo.toml 每天都在打交道——自己手写一个解析器来理解整个解析过程，是最直接也最有效的学习方式。很多人觉得解析器是黑魔法，其实只要把词法分析和语法分析拆开，按规范一步步处理 token 流，并没有想象中那么复杂。目标是覆盖 TOML v1.0 规范的主要特性，解析后输出 JSON 格式方便和官方工具的结果做对比验证。
Rust 社区对这类工具有很大需求。

用 Rust 从零写一个 TOML 解析器：
- 支持基本类型：字符串、整数、浮点数、布尔、日期时间
- 支持数组 [1, 2, 3] 和内联表 { x = 1 }
- 支持表 [section] 和数组表 [[array_section]]
- 支持多行字符串和转义字符
- 解析后输出为 JSON 格式，方便对比验证

这个工具在日常开发中能省不少重复劳动。
CLI：toml-parser config.toml，输出对应的 JSON。cargo build 通过。
