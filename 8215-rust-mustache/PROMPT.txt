前端项目用了 Mustache 模板做页面渲染，现在要把渲染逻辑从浏览器端挪到 Rust 后端做服务端渲染（SSR），首屏加载速度能快不少，SEO 也能正常抓取页面内容。Mustache 的设计理念是"无逻辑模板"——只有变量插值、区块展开和列表迭代，没有 if/else 条件分支、没有循环计数器、更没有自定义函数调用，简单到几乎不会出渲染 bug。这种极简风格正好适合服务端批量渲染的场景，模板文件交给非技术人员维护也不会搞出什么花样。能不能在 Rust 里实现一套兼容 spec 的引擎？

用 Rust 实现一个 Mustache 模板引擎：
- 支持 {{name}} 无转义和 {{{name}}} 原始输出
- 支持 {{#section}} ... {{/section}} 区块渲染
- 支持 {{^inverted}} 反向区块
- 支持 {{.}} 迭代当前项（列表内）
- 支持 {{>partial}} 局部模板
- 兼容 Mustache spec 的基本测试用例

CLI：mustache template.mustache --data data.json，输出渲染结果。cargo build 通过。
