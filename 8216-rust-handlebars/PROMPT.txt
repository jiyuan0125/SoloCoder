Rust 后端服务需要 HTML 模板引擎来做页面渲染，团队之前用 Handlebars 比较多，语法直观，前端同事也能很快上手。{{variable}} 插值、{{#if}} 条件、{{#each}} 循环这些基本操作覆盖了 90% 的场景。后端服务要渲染邮件模板、报表页面、错误页面等，不想引入重量级的模板框架，自己实现一个 Handlebars 兼容引擎就够了。关键是支持自定义 helper 注册，这样遇到特殊的格式化需求可以灵活扩展，不用改模板引擎本身的代码。

用 Rust 实现 Handlebars 模板引擎：
- 支持 {{variable}} 和 {{{raw}}} 输出
- 支持 {{#if}} {{else}} {{/if}} 和 {{#each}} {{/each}}
- 支持 {{#with context}} 临时切换上下文
- 支持 {{helper arg1 arg2}} 自定义 helper 注册
- 支持 {{#block name}} {{/block}} 和 {{> partial}} 模板继承
- 内置 helper：eq、ne、gt、lt、and、or

CLI：handlebars render template.hbs data.json，输出 HTML。cargo build 编译通过。
