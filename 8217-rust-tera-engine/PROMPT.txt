Python 里的 Jinja2 模板引擎太好用了——模板继承、过滤器链、循环变量一应俱全，写起 HTML 模板来又快又舒服。但迁移到 Rust 后端后，找不到一个用起来同样顺手的模板方案。Tera 虽然存在，但依赖链太长，编译时间也跟着拉长。其实只需要 Jinja2 的核心功能子集就够了：变量插值、过滤器、条件分支、循环加上模板继承。自己实现一个 Tera 风格的小型引擎，既解决眼前的问题，也能深入理解模板引擎的设计思路。

用 Rust 实现 Tera 风格的模板引擎：
- 支持 {{ variable }} 和 {{ value | filter }} 过滤器链
- 支持 {% extends "base.html" %} 和 {% block content %} 模板继承
- 支持 {% for item in items %} 循环，带 loop.index、loop.first 等变量
- 支持 {% if %} {% elif %} {% else %} {% endif %}
- 内置过滤器：length、join、sort、reverse、truncate
- 支持从目录批量加载模板文件

CLI：tera-engine render --template-dir templates/ --data data.json --template index.html，输出结果。cargo build 通过。
