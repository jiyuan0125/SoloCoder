学习编译原理的时候，光看书上的状态转换图和公式推导总觉得抽象——指令怎么编码成字节序列、运行时栈帧怎么布局、函数调用时寄存器怎么保存恢复，这些关键细节只有自己动手实现一遍才能真正吃透。决定从零开始做一个基于字节码的虚拟机来串联整个知识链路：先把简单的表达式语言编译成字节码指令序列，再写一个虚拟机逐条解释执行这些指令。整个过程涵盖编译器前端和后端的核心环节，从词法分析到语法树构建，再到字节码生成和虚拟机执行，完整走一遍"源码→AST→字节码→执行"的编译流水线。
用 Rust 实现一个字节码虚拟机：
- 定义一套字节码指令集（LOAD、STORE、ADD、SUB、JMP、CALL、RET 等）
- 实现字节码编译器，能把简单表达式编译成字节码序列
- 实现虚拟机执行字节码，维护操作数栈和调用栈
- 支持函数定义和调用，支持局部变量
- 可以 dump 字节码查看指令序列
CLI：bytecode-vm run program.bc 或 bytecode-vm compile program.src，编译执行。cargo build 通过。
注意处理空输入、超长输入等边界情况，函数遇到异常输入应该返回有意义的错误而不是静默失败。
