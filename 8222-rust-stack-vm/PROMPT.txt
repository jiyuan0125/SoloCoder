栈式虚拟机的指令密度一直是个让人头疼的问题——做一次加法要三条指令：PUSH a、PUSH b、ADD，编译同样一段逻辑出来的字节码比寄存器式长不少。但栈式设计也有明显优势：指令不需要编码操作数地址，每条指令更短更紧凑；编译器不用做寄存器分配，前端实现简单很多。这也是为什么 JVM、CPython、WebAssembly 这些主流运行时都选择栈式设计。想自己实现一个完整的栈式虚拟机来理解它的优缺点，看看在什么场景下栈式比寄存器式更合适，同时搞清楚 operand stack 和调用栈的关系。

用 Rust 实现栈式虚拟机：
- 基于 operand stack 的设计，PUSH/POP/DUP/SWAP 等栈操作
- 算术指令在栈顶取操作数，结果压回栈（如 ADD 弹出两个、压入一个）
- 支持条件跳转和循环（IF、ELSE、ENDIF、WHILE）
- 支持函数调用，有独立的返回栈和局部变量
- 输出每一步执行的栈状态（debug 模式）
CLI：stack-vm run program.svm --debug，显示执行过程。cargo build 编译通过。
对无效输入做好校验和错误返回，日志里记录关键操作方便排查问题。
