栈式虚拟机指令条数太多，性能受限于频繁的 PUSH/POP 操作。换成寄存器式设计后，指令直接携带寄存器编号作为操作数，执行阶段不需要额外的栈操作，运行效率理论上更高。Lua 5.0 之后从栈式切换到寄存器式，就是为了减少指令条数、提高解释执行速度。当然代价也有——编译器需要做寄存器分配，确定哪些变量放在哪个寄存器里，增加了编译阶段的复杂度。用 Rust 实现一个 16 寄存器的虚拟机，重点关注指令解码和执行的效率，对比栈式虚拟机看看实际性能差距有多大。
Rust 的类型系统能帮上不少忙。

用 Rust 实现一个寄存器式虚拟机：
- 固定数量的寄存器（R0-R15），指令带寄存器编号
- 支持 MOV、ADD、SUB、MUL、DIV 等算术指令
- 支持 LOAD/STORE 访问内存
- 支持条件比较 CMP 和条件跳转 JZ、JNZ、JMP
- 支持函数调用 CALL/RET，保存恢复寄存器现场
- 执行时可以打印寄存器快照
CLI：register-vm run program.rvm，执行并输出结果。cargo build 通过。
