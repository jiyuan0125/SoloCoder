有了词法分析器还不够，解析器才是编译器前端的硬骨头。手写递归下降解析器对简单语法还行，但遇到复杂语法就容易出 bug——左递归没处理、优先级搞错、冲突没发现。Yacc/Bison 这类工具已经证明了解析器生成器的价值：用户只写语法规则，工具自动计算 FIRST/FOLLOW 集合、构建解析表、检测冲突，然后生成可直接使用的 parser 代码。想在 Rust 里也做这样一个工具，输入 BNF 风格的语法规则，输出完整的 Rust parser 实现，让编译器开发者专注于语法设计而不是解析算法的细节。

用 Rust 实现解析器生成器：
- 用户用 BNF 风格定义语法规则（expr := term (+ term)*）
- 自动计算 FIRST/FOLLOW 集合
- 生成 LALR(1) 或 LR(1) 解析表的 action/goto 表
- 冲突检测和报告（shift/reduce、reduce/reduce）
- 生成可独立使用的 Rust parser 代码

CLI：parser-gen grammar.pg --output parser.rs，生成 Parser 代码。cargo build 编译通过。
