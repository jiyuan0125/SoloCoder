LR 解析算法是编译原理课程里的重头戏——项集族的构建、closure 和 goto 操作、action 表和 goto 表的填充，光看教材上的步骤演示总觉得隔了一层。想自己实现一个完整的 LR 解析器，把 LR(1) 的每一步算法都跑一遍：从文法规则出发构建 LR 状态机，填充 action/goto 表，然后用这张表驱动 token 序列的解析，在规约时创建 AST 节点。遇到 shift/reduce 冲突时默认选择 shift 并给出警告，用 operator precedence 来处理表达式优先级问题。实现一遍之后，LR 解析的整个流程就不再是抽象的概念了。

用 Rust 实现一个 LR 解析器：
- 输入文法规则（LR(1) items），自动构建 LR 状态机
- 构建 action 表和 goto 表
- 解析输入 token 序列，构建 AST（规约时创建节点）
- 处理 shift/reduce 冲突：默认 shift 并给出警告
- 支持 operator precedence 解决表达式优先级
- 输出解析过程的状态转换序列

CLI：lr-parser --grammar grammar.lr --input tokens.txt，输出 AST。cargo build 通过。
