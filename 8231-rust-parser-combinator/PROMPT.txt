函数式语言里的解析器组合子是一种很优雅的设计——不用写复杂的语法规则文件，直接用代码组合小解析器构建出大解析器。一个解析字符的组合子、一个解析字符串的组合子，通过 seq、alt、many 这些组合操作拼在一起，就能处理相当复杂的语法。这个思路在 Haskell 和 Scala 社区非常流行，想在 Rust 里也实现一套。关键是处理好所有权和借用——解析器组合子天然涉及大量闭包和递归，在 Rust 的借用检查器面前需要仔细设计类型签名。附一个算术表达式解析器作为完整示例，验证这套组合子库确实能跑起来。

用 Rust 写一个解析器组合子库：
- 提供基础组合子：char、string、regex、any
- 提供组合操作：seq（顺序）、alt（选择）、many（零或多）、many1（一或多）、optional
- 支持 map 转换解析结果，支持 flatMap 做上下文相关解析
- 支持 left recursion 处理（用 lazy/fix）
- 解析失败返回带有位置信息的错误
- 附带一个示例：用它解析简单的算术表达式

CLI：parser-combinator parse "3 * (4 + 5)"，输出解析结果。cargo build 编译通过。
