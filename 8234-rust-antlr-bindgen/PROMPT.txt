项目里有一套 ANTLR 定义的语法规则，Java 和 Python 端都直接用 ANTLR 生成的解析器，但 Rust 端没有官方的 ANTLR 运行时支持。需要做一个中间工具：读取 ANTLR 的 .g4 语法文件，解析其中的 lexer 规则和 parser 规则，然后自动生成对应的 Rust 代码——包括表示 AST 节点的结构体、visitor/trait 的骨架实现、以及 token 定义的常量。生成流程是：解析 .g4 文件 → 提取规则定义 → 生成 AST 类型的 Rust struct/enum → 生成 visitor trait → 输出到指定目录。对 fragment、mode 等 ANTLR 的 lexer 特性也做基本支持，不支持的特性给出明确的警告提示。

用 Rust 写一个 ANTLR 到 Rust 的绑定生成器：
- 读取 ANTLR .g4 语法文件
- 解析 lexer 规则和 parser 规则
- 生成 Rust 结构体表示 AST 节点
- 生成 visitor/trait 的骨架代码，方便用户实现 visitor 模式
- 支持 ANTLR 的 fragment、mode 等 lexer 特性
- 对不支持的特性给出警告

CLI：antlr-bindgen MyGrammar.g4 --output src/generated/，生成 Rust 代码。cargo build 通过。
