代码迁移和重构场景下，需要对 AST 做批量改写——把所有 for 循环改成 while 循环、统一重命名某个函数、把回调模式改写成 async/await。纯文本的查找替换太粗糙，容易误改注释和字符串里的同名内容。AST 级别的转换才能精确地只改代码结构、不影响字符串字面量和注释。需要实现一套 AST 转换工具：支持按模式匹配节点并替换为新节点、支持在指定位置插入或删除子节点、支持全局重命名、以及用 DSL 定义自定义转换规则（match pattern → replace pattern）。转换前后输出 diff 对比，确保改动符合预期。

用 Rust 实现 AST 转换工具：
- 支持节点替换：匹配特定模式，替换为新节点
- 支持节点插入和删除（在指定位置增删子节点）
- 支持重命名（变量、函数、类型名的全局替换）
- 支持自定义转换规则的 DSL（match pattern -> replace pattern）
- 转换前后输出 diff 对比
- 保持转换后的 AST 仍然合法

CLI：ast-transform ast.json --rules rename.rules --diff，显示转换结果。cargo build 通过。
