代码重构之后需要确认改动是否正确，纯文本的 diff 输出不够直观——把一行代码拆成两行、调整参数顺序、或者提取变量这种重构，在文本 diff 里看起来改动很多，但语义上可能完全等价。AST 级别的 diff 能更准确地反映代码的真实变化。实现流程是：解析重构前后的代码得到两棵 AST → 递归对比每层节点 → 找出增删改的节点 → 检测代码块的移动（同一段逻辑被挪到了别的函数里）→ 用颜色标记差异输出报告。支持 unified diff 格式输出，方便集成到代码审查工具中。
用 Rust 实现 AST diff 工具：
- 对比两份 AST，找出结构差异（增删改的节点）
- 输出语义级别的 diff：函数新增、参数变化、语句修改
- 支持 move 检测（代码块被移动到其他位置）
- 用颜色区分新增（绿）、删除（红）、修改（黄）的节点
- 支持输出为 unified diff 格式
- 处理大文件时性能不能太差
CLI：ast-diff old.ast new.ast，输出差异报告。cargo build 编译通过。
提供 --verbose 选项输出详细过程信息，方便调试。
重要操作加上日志，排查问题不用抓瞎。
