团队协作开发时，代码风格不统一是个老问题——有人花括号换行有人不换、有人 tab 缩进有人用空格、import 顺序也是各写各的。每次 code review 都要花时间纠结格式问题，浪费精力。虽然 rustfmt 能格式化 Rust 代码，但它不支持自定义规则，团队有一些特殊的格式偏好它覆盖不了。想做一个可配置的代码格式化工具：解析源码得到 AST 和 token 流，按配置文件里定义的规则重新排版——缩进几格、空格还是 tab、import 怎么排序分组、长行在什么位置折行。格式化前后做 diff 确保只改了排版、没改语义。

用 Rust 实现代码格式化器：
- 解析 Rust 源码得到 AST/Token 流
- 按规则重新排版：缩进、空格、换行、对齐
- 处理 import 排序和分组
- 处理长行自动折行（函数参数、match arm 等）
- 支持配置文件 .formatter.toml 自定义风格
- 不改变代码语义，只改排版
- 对格式化前后的文本做 diff 检查

CLI：code-formatter src/main.rs --check（检查）或 --write（原地修改）。cargo build 通过。
