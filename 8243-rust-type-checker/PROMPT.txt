编译器前端最关键的一步是类型检查——确保程序里的每个表达式类型正确，函数调用的参数和返回值对得上，结构体字段访问的类型没搞错。类型系统不需要太复杂，先实现一套基本的静态类型检查器：支持 int、float、bool、string、void 这些基本类型，支持函数类型的签名检查（参数个数、类型、返回类型都要匹配），支持结构体/record 类型的字段访问检查，支持数组类型的下标访问检查。类型不匹配时报告期望类型和实际类型的差异。同时支持 int 到 float 的隐式类型转换，这是最常见的隐式转换场景。

用 Rust 实现一个类型检查器：
- 支持基本类型：int、float、bool、string、void
- 支持函数类型和类型签名检查（参数类型、返回类型）
- 支持结构体/record 类型，检查字段访问
- 支持数组类型，检查下标访问
- 类型不匹配时报告期望类型和实际类型
- 支持隐式类型转换规则（int -> float）

这个工具在日常开发中能省不少重复劳动。
CLI：type-checker source.tc，输出类型检查结果或错误列表。cargo build 通过。
