类型推导让程序员不用显式标注每个变量的类型，编译器自动从上下文推断出来。Hindley-Milner 算法是经典的多态类型推导方法，ML 系语言和 Haskell 都在用它。实现流程是：遍历 AST 为每个表达式分配一个类型变量 → 收集类型约束（比如函数调用的参数类型必须和形参一致）→ 用合一（unification）算法求解所有约束 → 把类型变量替换为具体类型。还要处理 let 多态：同一个 let 绑定在不同使用位置可以实例化为不同的类型。推导失败时报告具体的类型冲突位置，方便定位问题。

用 Rust 实现 Hindley-Milner 类型推导：
- 实现合一（unification）算法，处理类型变量
- 支持基本类型和多态类型（泛型）
- 支持函数类型推导：从函数体推导参数和返回类型
- 支持 let 多态（let-polymorphism）
- 支持 if/else 分支的类型一致性检查
- 推导失败时报告具体的类型冲突
CLI：type-inference source.ti，输出每个表达式的推导类型。cargo build 编译通过。
考虑到并发安全的场景，多线程同时操作时不会出现数据竞争。
