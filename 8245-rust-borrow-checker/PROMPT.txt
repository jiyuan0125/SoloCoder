Rust 最独特也最让人头疼的就是借用检查器——move 之后再使用变量会报错，同时持有可变借用和不可变借用也会报错，初学者经常被搞得很崩溃。但借用检查的逻辑其实可以拆解成几个明确的分析步骤：追踪变量的所有权转移情况、检查 use-after-move、检查 &mut 和 & 的冲突、用作用域近似判断引用是否悬垂。想自己实现一个简化版的借用检查器来理解 Rust 编译器是怎么做这些检查的。错误信息要说明具体哪行发生了借用、哪行产生了冲突，让使用者能快速定位问题。
Rust 的类型系统能帮上不少忙。

用 Rust 实现一个简化版借用检查器：
- 分析变量的所有权转移（move）情况
- 检查是否在 move 之后使用了变量（use-after-move）
- 检查可变借用和不可变借用的冲突（同时存在 &mut 和 &）
- 检查悬垂引用（引用生命周期超出被引用值）
- 用作用域来近似判断生命周期
- 错误信息说明具体哪行借用了、哪行冲突了

这个工具在日常开发中能省不少重复劳动。
CLI：borrow-checker source.bc，输出借用检查结果。cargo build 通过。
