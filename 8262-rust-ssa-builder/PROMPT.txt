手写的 IR 生成器产出的是三地址码，变量可以重复赋值，但这不是 SSA 形式，后面做优化 pass 很不方便。需要把普通三地址码转换成 SSA。Rust 实现。

转换算法分两大步。第一步：插入 phi 函数。对每个全局变量（跨基本块赋值的变量），计算它的 iterated dominance frontier（IDF）。IDF 的计算依赖支配树——先构建支配树，然后对每个变量的定义块集合，求它们的支配边界的迭代闭包。在 IDF 中的每个基本块头部，为该变量插入一个 phi 节点，操作数个数等于前驱数量。

第二步：变量重命名。从支配树根节点开始 DFS，维护每个变量的当前版本栈。遇到变量定义就 push 新版本，遇到使用就 peek 栈顶版本。到 phi 节点时，为每个前驱分支填充对应的操作数版本。支配树的子节点处理完后 pop 版本栈恢复状态。

IR 数据结构需要能表示 Phi 指令：Phi { dest: Value, incoming: Vec<(BasicBlock, Value)> }。给几个有意义的测试用例——if-else 分支里各赋值然后汇合、循环里变量在迭代间传递、嵌套分支。验证转换后每个 Value 只定义一次，所有使用都有对应的定义。cargo test 全绿。
