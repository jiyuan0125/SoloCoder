优化 pass 的第一步总是要搞清楚控制流长什么样，手动画太麻烦了。用 Rust 构建一个控制流图（CFG）数据结构和可视化工具。

CFG 的基本元素是 BasicBlock——持有一组有序指令，一个前驱列表和一个后继列表。图的入口块和出口块要显式标记。构建 CFG 的输入是一组基本块定义，每块的末尾指令隐含了后继关系：Jump 指令 → 一个后继，Branch 指令 → 两个后继（true/false），Return → 无后继，Switch → 多个后继。

构建过程中自动计算前驱列表（遍历后继反向填充）。额外提供几个分析方法：检测不可达块（从入口做 BFS/DFS，访问不到的块标记出来）、计算自然循环（配合支配信息）、统计图的复杂度（节点数、边数、分支密度）。

导出 Graphviz dot 格式是刚需——每个块一个节点，块内显示指令摘要，跳转关系用带标签的边表示。cargo run 读入一个示例函数的 IR，输出 .dot 文件，用 dot 命令渲染成图。cargo build 通过。
配置项尽量通过环境变量或命令行参数传入，不要硬编码路径和端口。
输入输出格式统一，JSON 或者结构化文本。
