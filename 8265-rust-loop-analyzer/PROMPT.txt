循环是编译器优化最核心的对象——循环不变量外提、强度消减、向量化，全都要先识别出循环。用 Rust 写一个循环分析器，从 CFG 和支配树信息出发识别自然循环。

自然循环的定义：CFG 中一条回边（从节点 n 到其支配者 d 的边）确定一个自然循环，循环体是 d 到 n 之间所有能到达 n 但不经过 d 的节点。如果 d == n，循环体就是单独一个节点（自循环）。

分析器的输入是 CFG 和对应的支配树。输出每个循环的详细信息：入口块（header）、回边来源（latch）、循环体包含的所有基本块、循环深度（嵌套层级，外层为 1）、出口块（循环体内有边指向循环外的块）。多个循环之间可能存在嵌套关系，用树结构表示。

特殊场景要处理：一个 header 可能对应多条回边（多个 latch），此时循环体是所有回边对应的循环体的并集。break 语句会产生一条从循环体直接跳到循环外的边。continue 语句会产生一条跳回 header 的边。

cargo test 用几个典型的 CFG 验证：简单的 while 循环、嵌套两层 for 循环、带 break 的循环、带 continue 的循环。cargo build 通过。
