编译器 IR 经过几轮变换后往往会留下不少废代码——算出来了但没人用的值、条件永远为假的分支。死代码消除 pass 就是清理这些。Rust 实现，在 SSA IR 上工作。

第一轮扫描：遍历所有指令，标记哪些 Value 被其他指令的 use 列表引用了（包括 phi 的 incoming 值、分支的条件操作数、store 的地址和值）。没有被引用的指令就是直接死代码。但要注意副作用——Call、Store、Jump/Branch/Return 这些指令即使返回值没人用也不能删，它们有副作用。

删除直接死代码后，可能出现新的死代码（原来被死指令使用的值现在也没人用了）。所以需要迭代执行直到收敛：每轮扫描标记、删除、检查是否有变化。

也可以用逆序标记法更高效：从根指令（有副作用的指令和函数返回值）开始，沿着 use-def 链反向标记所有可达的指令，未标记的就是死代码，一轮搞定。

输入 SSA 形式的 IR，输出消除后的 IR，打印删掉了多少条指令。cargo test 用几个有冗余计算的 IR 片段验证——比如 a=1+2; b=a*3; 只用 b 不用 a，看 a=1+2 是否被保留。cargo build 通过。
