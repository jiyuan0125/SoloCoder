常量折叠是最早也是最安全的优化之一——在编译期就算出来，省得运行时再算。用 Rust 实现一个常量折叠 pass，在 SSA IR 上工作。

遍历 IR 中所有指令，逐条检查操作数是否全部是常量值（Constant 类型的 Value）。如果都是，直接计算结果并替换整条指令为常量定义。支持的运算：

整数算术：Add(i+i)、Sub(i-i)、Mul(i*i)、Div(i/i)——注意除零不折叠，保留原指令。位运算：And、Or、Xor、Shl、Shr。比较：Eq、Ne、Lt、Le、Gt、Ge，折叠结果是 0 或 1。

嵌套常量表达式也要能一路折叠：比如 a=2+3, b=4-1, c=a*b，第一轮把 a 折成 5、b 折成 3，第二轮 c 就能折成 15。所以需要迭代多轮直到没有新的折叠发生。

额外的优化：常量条件的分支折叠。如果 Branch 指令的条件是常量 1，直接替换为 Jump 到 true 目标，false 分支变成不可达代码。后续死代码消除 pass 会清理掉。

cargo test 验证各种场景：纯算术、嵌套表达式、除零保护、分支折叠。cargo build 通过。
