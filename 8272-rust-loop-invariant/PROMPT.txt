编译器优化的经典 pass 之一，循环不变量外提（LICM）。循环体内有些计算跟循环变量完全无关——每次迭代都在算一样的值，白白浪费 CPU。把它们挪到循环外面只算一次。Rust 实现。

判断一条指令是否循环不变量：所有操作数要么是常量，要么定义在循环体外，要么本身就是已经判定为循环不变量的指令。而且该指令没有副作用（纯计算）。满足这些条件就可以移动。

移动的目标位置是循环前置节点（preheader）——一个在循环入口前、只被循环入口块的前驱连接的块。如果没有 preheader，先插入一个。移动后要保证语义不变，特别需要注意：
- 指令不能移动到它没有被定义就被使用的位置（def 必须在所有 use 之前）
- 如果循环可能一次都不执行（while 循环条件可能初始就为 false），把计算挪出去不会增加执行次数（无副作用所以 OK）
- 如果指令可能抛异常（除零等），移动到循环前可能改变异常抛出的时机——这种保守处理不移动

cargo test 验证：循环内常量计算的外提、嵌套循环的内层不变量外提到外层。cargo build 通过。
