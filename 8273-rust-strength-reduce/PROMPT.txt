乘法比加法慢、除法比位移慢——在热循环里这些差异会被放大几千倍。强度消减 pass 就是把高代价运算替换成等价的低代价运算。用 Rust 在 IR 层面做变换。

常见替换规则：
1. 乘以 2 的幂（x * 2^n）→ 左移（x << n），包括 x * 1 → x（恒等），x * 0 → 0
2. 除以 2 的幂（x / 2^n）→ 算术右移（x >> n），但要注意负数的向下取整问题——除以 2^n 对负数要先加 2^n-1 再右移
3. 取模 2 的幂（x % 2^n）→ 位与（x & (2^n - 1)），取模非 2 的幂不能替换
4. 乘以常数用加法和移位的组合：x * 3 = (x << 1) + x，x * 5 = (x << 2) + x，x * 10 = (x << 3) + (x << 1)
5. 循环归纳变量：for (i=0; i<N; i++) 里访问 a[i*4]，可以维护一个变量 j 初始 0 每次加 4 代替乘法

替换时要验证等价性：带符号和无符号的除法/右移语义不同，不能混淆。cargo test 覆盖每种替换规则的正负数边界。cargo build 通过。
