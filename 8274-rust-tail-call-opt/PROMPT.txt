函数式编程风格喜欢用递归，但递归太深会栈溢出。尾调用优化的原理是——如果函数的最后一个动作是调用另一个函数并直接返回其结果，那当前函数的栈帧就没用了，可以复用。用 Rust 实现这个 pass。

检测尾调用模式：遍历函数的每个基本块，找到末尾是 Return 指令且返回值来自一条 Call 指令的情况。进一步确认 Call 和 Return 之间没有其他有副作用的指令。满足条件时，把 Call+Ret 替换成 Jump（跳到被调用函数的入口块）。

参数适配：如果调用者和被调用者的参数数量和类型完全一致，直接跳转。如果不一致（比如参数多了或少了），需要调整——在被调用函数入口前插入参数搬移指令。自身递归（调用自己）是最简单的 case，不需要参数搬移。

相互递归也要支持：A 尾调用 B，B 尾调用 A，两个函数的栈帧都可以复用。不过需要注意避免形成无限跳转环，至少确认参数在某维度上是递减的。

cargo test 用阶乘尾递归版本、斐波那契尾递归版本、非尾递归函数（不应被优化）验证。cargo build 通过。
