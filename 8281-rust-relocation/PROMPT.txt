链接器把多个目标文件合并后，里面的地址引用都还是相对的，需要根据最终的内存布局修正——这就是重定位。上次合并完 section 发现符号地址全乱了，就是重定位没做。用 Rust 实现常见的 x86_64 重定位类型处理。

重定位条目包含：重定位的偏移（在被修改的 section 中的位置）、重定位类型、引用的符号索引或加数（addend）。处理时先从符号表查到符号的最终地址 S，然后根据重定位类型计算 patch 值 P，写到 section 数据的对应偏移处。

x86_64 常见重定位类型的计算公式：
- R_X86_64_64：S + A（64 位绝对地址），直接写入符号地址 + 加数
- R_X86_64_PC32：S + A - P（32 位 PC 相对偏移），算出符号相对于 patch 点的偏移，用于 call/jmp 的相对跳转
- R_X86_64_32：S + A（截断到 32 位的绝对地址），用于小模式代码
- R_X86_64_PLT32：和 PC32 一样计算，但通过 PLT 表间接跳转

A 是 addend（内联在指令中的常量部分），P 是被 patch 的位置在最终二进制中的虚拟地址。处理溢出检查——PC32 和 32 位类型的结果必须在 i32 范围内。

cargo test 构造包含重定位条目的二进制数据，验证每种类型的计算结果。cargo build 通过。
