从固件或闭源二进制里提取可读字符串是逆向工程的第一步。binutils 的 strings 就是干这个的，但有时需要嵌入到自己的工具链里。用 Rust 写一个 strings 工具。

核心逻辑：扫描二进制文件，找连续的可打印 ASCII 字符序列。可打印的定义是字节值在 0x20-0x7E 之间。默认最小长度 4 个字符（可以通过 -n 参数调整）。输出每个找到的字符串及其在文件中的偏移地址。

扫描策略：顺序读取文件，维护一个当前字符串缓冲区。遇到可打印字符就追加，遇到不可打印的就检查缓冲区长度——够长就输出，不够就清空。整个文件都要扫，不只是加载段（加 -a 参数明确）。

编码支持：默认 ASCII，-e l 标 UTF-16LE（每两个字节一个字符，按小端序解读 UTF-16 码点），-e b 标 UTF-16BE。UTF-16 模式下最小字符数按 UTF-16 码点计算，不是字节数。

大文件处理用流式读取——固定 8KB 的缓冲区逐块读取，注意字符串可能跨越两个缓冲区的边界（最后保留几个字节和下一块拼接）。cargo run -- /bin/ls 看看效果。cargo build 通过。
