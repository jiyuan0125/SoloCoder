readelf 是分析 ELF 文件最全面的工具，能看所有内部结构。但它的源码太复杂了，我只需要几个核心功能。用 Rust 写一个精简版 readelf。

支持的选项和对应的输出：

-h（ELF header）：打印魔数、class（ELF32/64）、data（大端/小端）、OS/ABI、类型（ET_EXEC/ET_DYN/...）、机器架构、入口地址、program header 和 section header 的数量和偏移。

-l（program headers）：遍历所有 program header，打印类型（PT_LOAD/PT_INTERP/...）、offset、virtaddr、physaddr、filesiz、memsz、flags（R/W/X）、align。

-S（section headers）：遍历所有 section，打印编号、名字、类型、地址、offset、size、entsize、flags（A/W/X/M）、link 和 info。

-s（symbol table）：解析 .symtab 和 .dynsym，打印每个符号的编号、地址、size、类型（NOTYPE/OBJECT/FUNC/SECTION/FILE）、绑定（LOCAL/GLOBAL/WEAK）、可见性、section 索引、名字。

-r（relocations）：解析 .rela.dyn 和 .rela.plt，打印偏移、类型、符号值、符号名、加数。

选项可以组合使用：cargo run -- -hS /bin/ls。cargo build 通过。
