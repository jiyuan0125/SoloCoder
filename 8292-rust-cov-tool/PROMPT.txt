测试覆盖率是衡量测试质量最直接的指标——跑了 1000 个测试用例，但只覆盖了 30% 的代码行，那说明测试写得不够好。用 Rust 写一个代码覆盖率分析工具。

采用源码插桩的方式：在每行可执行代码前插入一个原子计数器（AtomicU64）。插桩在 AST 级别做——解析源码得到 AST，遍历 AST 在每个表达式语句、if/else 分支、循环体、match 分支前插入 counter++ 语句。插桩后的代码编译执行，结束时把所有计数器的值写到 .covdata 文件。

计数器数据收集完后，和源码逐行对照生成报告。每行源码标注执行次数——0 次标红（未覆盖）、1 次以上标绿（已覆盖）。统计总行数、可执行行数、已覆盖行数，算出覆盖率百分比。

输出格式：终端彩色文本 + 可选的 HTML 报告。HTML 报告里每行源码有背景色，点击能看到执行次数。

先支持 Rust 代码的覆盖率分析。cargo run -- source.rs -- test-command "cargo test"。cargo build 通过。
