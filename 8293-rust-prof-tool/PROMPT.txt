服务响应变慢了，火焰图太高层看不清具体哪个函数在吃 CPU。需要一个工具把 profiling 采样数据按函数维度聚合，找出热点。Rust 实现。

输入是简单的采样数据文件——每行一个十六进制地址（程序计数器的采样值），可能几十万行。配合一个带符号表的二进制文件，把地址翻译成函数名。

处理流程：
1. 读取所有采样地址，建立频率直方图 HashMap<u64, usize>
2. 解析二进制的符号表，建立地址范围到函数名的映射
3. 对每个采样地址查对应的函数名（在区间列表中二分查找）
4. 按函数名聚合采样次数，算出每个函数占总采样的百分比

输出按采样次数降序排列的热点函数列表。加一个 caller-callee 统计——如果采样数据带了栈帧信息（每行是一个栈帧序列），就统计每个函数被谁调用、又调用了谁。

输入也可以用简单文本格式：每行一个地址或 "caller -> callee" 对。cargo run -- profile-data.txt --binary /path/to/binary 输出报告。cargo build 通过。
