测试覆盖率 80% 看起来不错，但可能只是执行了代码没做真正的断言。Mutation testing 通过故意往代码里注入 bug 来检验测试是否能发现。变异杀死率高才说明测试真的有效。Rust 实现。

工作流程：
1. 解析源代码得到 AST
2. 遍历 AST 找到可变异的位置，生成变异版本
3. 对每个变异版本重新编译并运行测试套件
4. 测试失败 → 变异被杀死（好），测试通过 → 变异存活（测试没覆盖到这个 case）

支持的变异操作：
- 比较运算符翻转：== ↔ !=、< ↔ >=、> ↔ <=
- 算术运算符替换：+ ↔ -、* ↔ /、% ↔ *
- 逻辑运算符替换：&& ↔ ||、! 删除/插入
- 常量替换：整数常量 ±1、布尔取反、字符串清空
- 语句删除：删除一条语句（用 {} 替代）
- 返回值修改：true/false 互换、0 ↔ 1

AST 级别的文本替换——不需要完整的类型系统分析，找到匹配的模式就替换。输出报告：变异总数、杀死数、存活数、变异杀死率（百分比）。存活的变异要列出源码位置和变异内容，方便开发者补充测试。
