正则表达式用了这么多年，但底层是怎么把模式串匹配到目标字符串上的？NFA 到底怎么构建的？想从零手写一个正则引擎来彻底搞懂。Python 实现。

支持的语法：普通字符匹配、.（匹配任意单个字符）、*（前一项零次或多次）、+（一次或多次）、?（零次或一次）、[abc]（字符集）、[a-z]（范围）、[^abc]（取反）、()（分组捕获）、|（或）、\d \w \s（预定义字符类）、^ $（行首行尾）。

实现方案——Thompson NFA 构造法。先把正则表达式解析成 AST（Concat、Alt、Star、Plus、Question、CharClass、Group），然后从 AST 构建 NFA：每个 AST 节点转换成一组状态和转移边。NFA 的状态用整数 ID，转移用邻接表（字符转移和 ε 转移）。ε-closure 用 BFS 计算。

匹配过程：从起始状态的 ε-closure 开始，逐个读入目标字符串的字符，计算每一步的状态集合。到达终点时如果当前状态集合包含接受状态就匹配成功。捕获分组通过给子 NFA 的入口和出口状态打标记来追踪。

提供 CLI 工具：python3 regex.py "a(b|c)*d" "abcbd" 输出匹配成功和捕获分组内容。也支持找所有匹配（findall）。纯 Python 标准库。
