每次用 PyYAML 都觉得 YAML 的解析挺神奇的——靠缩进来表达嵌套关系、多行字符串有好几种写法、锚点引用还能"复制粘贴"节点。想自己实现一遍来理解细节。Python 手写 YAML 解析器。

支持的 YAML 特性：
- 键值对：key: value（冒号后必须有空格）
- 嵌套：通过缩进表达（空格缩进，不支持 Tab）
- 列表：- item（减号加空格）
- 多文档：--- 分隔，... 结束
- 字符串：双引号/单引号/无引号，无引号字符串 trim 首尾空格
- 数字和布尔：自动类型推断（true/false → bool，123 → int，1.5 → float）
- 行内注释：key: value # 这是注释
- 多行字符串：| 保留换行（literal block），> 折叠换行（folded block）
- 锚点和引用：&anchor 标记节点，*anchor 引用节点（alias）
- null 值：~ 或 null 或空值

解析策略分两步：先做行的缩进分析和预处理，产出缩进级别和内容 token。然后用递归下降处理每个缩进级别的内容——遇到键值对就递归解析下一缩进级别的值，遇到 - 就解析列表元素。

错误处理：缩进不一致（同一级别缩进量不同）报行号，非法字符和格式错误也要报。循环引用（锚点引用链形成环）要检测。

python3 yaml_parser.py config.yaml 输出 Python repr 或 JSON。纯手写，不用 PyYAML。
