手上有一个自定义字节码文件，不知道里面的指令做了什么。需要一个通用的反汇编器框架——不绑定特定指令集，而是通过描述文件来定义指令格式，然后对任意字节码做反汇编。Python 实现。

指令集描述文件格式（JSON 或自定义文本）：每条指令包含操作码（opcode）、助记符名称、操作数列表。每个操作数有类型（imm8/imm16/imm32 寄存器名 地址偏移）和显示格式。示例：
```
[
  {"opcode": "0x01", "name": "PUSH", "operands": [{"type": "imm32", "label": "value"}]},
  {"opcode": "0x10", "name": "ADD", "operands": []},
  {"opcode": "0x20", "name": "JMP", "operands": [{"type": "addr16", "label": "target"}]}
]
```

反汇编过程：从字节码起始位置开始，读一个字节查操作码表，匹配到指令后按操作数定义读取后续字节。地址偏移类型的操作数显示为标签（自动在目标位置生成 label_N）。变长指令靠操作数定义的长度自然处理。

内置一个 20 条左右的示例指令集（栈操作 + 算术 + 跳转 + 函数调用）。非法操作码显示为 ??? 并跳过该字节继续。

python3 disasm.py --isa isa.json code.bin。纯 Python 实现。
