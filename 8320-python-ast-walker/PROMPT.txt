团队代码规范检查工具需要遍历 Python AST 做各种分析，但每次都手写 ast.NodeVisitor 太繁琐。写一个声明式的 AST 遍历框架，用装饰器注册处理器，自动匹配节点类型调用。Python 实现。

框架的核心用法：定义一个分析器类，用 @visit("FunctionDef") 装饰器标记处理函数定义节点的方法，用 @visit("Call") 标记处理函数调用的方法。框架遍历 AST 时自动把匹配类型的节点分发给对应的处理器。支持多个处理器处理同一类型节点——按注册顺序依次调用。

处理器可以返回一个结果对象（方便收集分析数据），也可以返回 None。框架还提供 @enter 和 @exit 钩子在遍历进入和离开节点时调用。遍历策略可选深度优先（默认）或广度优先。

内置三个实用分析器示例：函数复杂度统计器（计算每个函数的分支数和嵌套深度）、未使用 import 检测器（记录所有 import 和后续引用）、长函数检测器（函数体超过 N 行的标黄）。这三个分析器可以同时注册到一次遍历中。

命令行：python3 ast_walker.py source.py --checks complexity,unused_imports,long_functions。纯 Python 标准库（用 ast 模块）。
