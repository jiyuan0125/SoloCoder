项目越来越大，模块间的依赖关系越来越混乱——改一个模块不知道会影响哪些其他模块。需要一张清晰的依赖图来辅助决策。Python 写一个依赖图生成工具。

扫描指定目录下所有 .py 文件，用 ast 模块解析每个文件的顶层 import 语句，建立模块间的有向依赖关系。模块粒度按文件来——foo/bar.py 模块名为 foo.bar。

图的构建：节点是模块名，边是 import 关系。A import B 则有一条 A→B 的边。同一个文件内的 import 去重（多次 import 同一模块只算一条边）。

分析能力：循环依赖检测（在有向图上做 DFS 找环，输出环上所有模块名）、依赖层级计算（被依赖最多的是底层基础设施，依赖最多的是上层业务代码）、孤立模块检测（没有 import 也没有被 import 的模块可能是废代码）、影响范围分析（给定一个模块，找出所有依赖它的上游模块）。

输出两种格式：文本形式输出拓扑排序后的依赖列表（从底层到上层），循环依赖用红色标注。DOT 格式输出可以用 dot -Tpng 渲染成图，节点按层级分层排列。python3 dep_graph.py project_dir/。纯 Python 实现。
