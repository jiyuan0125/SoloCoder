性能优化要知道热点函数被谁调用了、调用链有多深，才能有针对性地优化。静态调用图分析不依赖运行时采样，能覆盖所有可能的调用路径。Python 实现。

通过 AST 静态分析提取函数间的调用关系。分析粒度：每个函数/方法定义是一个节点，函数体中的 Call 表达式是边。处理几种调用模式——直接函数调用 func()、方法调用 obj.method()（推断 obj 的类型需要类型注解，推断不出就记录为 obj.method）、嵌套调用 outer(inner())、递归调用（函数调自己）。

入口函数指定：从指定的入口函数（比如 main）出发，BFS 追踪调用链。也支持反向查找——给定一个函数名，找到所有调用它的函数（在所有定义中搜索包含该函数 Call 的函数体）。

输出：正向调用树（从入口出发的树形结构，标注每层调用的行号）、反向调用链（谁调了这个函数、谁调了调用者...一直追溯到入口）、最长调用链深度、递归调用检测。

python3 call_graph.py src/ --entry main。纯 Python 实现，基于 ast 模块。
