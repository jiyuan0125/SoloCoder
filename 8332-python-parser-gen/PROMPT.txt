手写解析器是编译原理实验最痛苦的环节，一遍又一遍改产生式调 bug。做一个解析器生成器，输入文法定义自动生成解析器代码。Python 实现。

文法定义格式（BNF 风格）：
```
Expr    = Expr "+" Term | Expr "-" Term | Term
Term    = Term "*" Factor | Term "/" Factor | Factor
Factor  = "(" Expr ")" | NUMBER
```

支持的特性：产生式用 | 分隔多个选择、终结符用大写或引号包围、非终结符用小写、空产生式用 epsilon。生成器会计算 First 集和 Follow 集，检测左递归（报告哪些非终结符有直接或间接左递归），检测不可达产生式。

生成递归下降解析器时自动消除直接左递归（A = Aα | β → A = β A', A' = α A' | ε）。如果文法不是 LL(1) 的，报告冲突——哪些 token 在哪个状态下既可移进又可归约。

生成的解析器是 Python 代码，接受 token 流输入，构建 AST。AST 节点类型对应非终结符名，子节点对应产生式右部的元素。

附带一个计算器文法示例：支持四则运算、括号和负号。python3 parser_gen.py grammar.bnf --test "2*(3+4)"。纯 Python 实现。
