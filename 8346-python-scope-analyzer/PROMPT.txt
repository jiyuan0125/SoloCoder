代码审查时发现有人在函数里用了全局变量名一样的局部变量，遮蔽了外部变量导致 bug。手动检查太麻烦了，写个工具自动分析作用域。Python 实现。

解析 Python 源文件为 AST，遍历 AST 构建作用域树。作用域类型：Module（全局作用域）、FunctionDef/AsyncFunctionDef（函数作用域）、ClassDef（类作用域）、Lambda（匿名作用域）、Comprehension（列表推导有独立作用域）。

每个作用域维护：定义的变量名集合（包括参数、赋值、import、for 循环变量）、引用的变量名集合（读取使用但不在本作用域定义的）、子作用域列表、父作用域引用。

分析报告：
- 未定义就使用的变量：引用了一个在当前作用域和所有祖先作用域中都没有定义的名字
- 变量遮蔽（shadowing）：内层作用域定义了和外层同名的变量，标出两层的定义位置
- global/nonlocal 一致性：声明了 global 但没有在外层找到定义，或者 nonlocal 指向的变量不在外层函数中
- 未使用的变量：定义了但整个作用域（含子作用域）都没有引用

输出每个作用域的变量表（定义位置、引用位置列表）和检测到的问题列表。python3 scope_analyzer.py source.py。纯 Python 用 ast 模块。
