Python 闭包是面试高频题，实际开发中也是性能陷阱——不小心捕获了一个大对象就内存泄漏了。写一个闭包分析器来可视化和检测这些问题。Python 实现。

分析 Python 源码中的闭包形成条件：
1. 找到嵌套函数定义（FunctionDef 嵌套在另一个 FunctionDef 内）
2. 分析内层函数引用了哪些外层函数的变量（free variables）
3. 这些被引用的变量就是 cell variables（被内层捕获的变量）
4. 如果内层函数又定义了嵌套函数，形成多层闭包链

可视化输出闭包的变量捕获图——外层函数列出它定义的所有变量，标出哪些被内层函数捕获（用 → 箭头连接到内层函数的 free variable 列表）。

检测性能陷阱：
- 捕获了大对象：如果外层函数定义了大容器（list/dict）或大对象，且被内层捕获，警告"大对象捕获"
- 不必要的捕获：外层函数的某个变量只在创建闭包时使用，但闭包执行时不需要——这种可以改成默认参数传递
- 循环中的闭包：for 循环内创建的 lambda/闭包捕获了循环变量，所有闭包都引用同一个变量的最终值（经典 bug）
