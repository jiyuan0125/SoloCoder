Python 推导式一行代码能干十行循环的事，但嵌套多了可读性急剧下降，还容易踩性能坑——嵌套三层列表推导就变成 O(n³) 了。写一个推导式分析器，帮开发者理解和优化推导式代码。Python 实现。

解析能力：用 ast 模块分析源码中的 ListComp、DictComp、SetComp、GeneratorExp 节点。提取每个推导式的结构——迭代变量名、可迭代对象、条件过滤器（if 子句）、嵌套层级。嵌套推导式如 [x for sub in matrix for x in sub if x > 0] 解析为两层循环加一个过滤器。

分析维度：
- 嵌套深度：推导式里有几个 for 子句。深度超过 3 建议改写为普通循环
- 时间复杂度推导：单层遍历是 O(n)，两层嵌套是 O(n²)，加上 if 过滤不影响阶数但影响常数因子
- 变量作用域分析：迭代变量在推导式内部的作用范围，外部同名变量是否被遮蔽
- 副作用检测：推导式内部调用了有副作用的函数（比如修改了外部变量、做了 I/O 操作）——推导式不应该有副作用
- 内存使用：列表推导会一次性生成全部结果，如果数据量大建议改用生成器表达式

输出格式：每个推导式的位置（文件:行号）、结构摘要、嵌套深度、估计复杂度、发现的问题和建议。python3 comprehension_analyzer.py source.py。纯 Python 用 ast 模块。
