日志分析时经常要匹配特定格式的文本——提取 IP 地址、匹配 URL 路径、找特定前缀的消息。正则太强大了反而容易过度复杂。写一个轻量的模式匹配引擎，用更简单的通配符语法。Python 实现。

支持的匹配语法：
- *：匹配零个或多个任意字符（贪婪）
- ?：匹配恰好一个任意字符
- [abc]：匹配字符集中的任意一个字符
- [a-z]：匹配范围内的任意一个字符
- [!abc]：匹配不在字符集中的任意一个字符
- {n,m}：前一个元素重复 n 到 m 次
- (pattern)：捕获分组，记录匹配到的内容
- \：转义特殊字符

匹配算法用回溯法——维护一个 (文本位置, 模式位置) 的状态，遇到 * 时尝试不同长度的匹配（从长到短贪婪），匹配失败就回溯。分组用栈记录每对括号的匹配起始和结束位置。

用户可以定义多个模式模板组成规则集。输入文本逐行匹配，返回所有命中的行号、匹配片段和捕获分组内容。支持大小写不敏感模式。

命令行：python3 matcher.py --pattern "hello*world" input.txt。也支持交互模式：python3 matcher.py 进入后输入模式和文本即时测试。纯 Python 3 标准库，不依赖 re 模块。
