用 Python 写一个通用的二进制文件解析工具，能根据用户提供的格式描述解析任意二进制数据。

做逆向分析经常要解析各种二进制协议和文件格式，需要一个声明式的解析框架。用户通过 YAML 或 JSON 描述字段名、偏移量、长度、字节序、类型（整数、浮点、字符串、位域等），工具读入二进制文件后按描述提取所有字段，支持计算偏移和指针引用。输出结构化的 JSON 结果。

纯 Python 3，不依赖第三方库。命令行：`python binary_parser.py --spec format.yaml input.bin`，打印解析出的字段列表。规格文件里有错误（比如偏移越界）要能报告出来。`python binary_parser.py` 能跑。
