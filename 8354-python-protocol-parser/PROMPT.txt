网络故障排查第一步就是看报文里到底传了什么。Wireshark 太重量级了，有时只想快速看几个关键字段。写一个轻量的协议解析器，从原始字节流中逐层提取信息。Python 实现。

支持的协议层：
- Ethernet II 帧：目标 MAC（6 字节）→ 源 MAC（6 字节）→ EtherType（2 字节，0x0800=IPv4, 0x86DD=IPv6, 0x0800=ARP）
- IPv4 头：版本+IHL（1 字节）、DSCP+ECN（1 字节）、总长度（2 字节）、标识+标志+片偏移（4 字节）、TTL（1 字节）、协议（1 字节，6=TCP, 17=UDP, 1=ICMP）、头部校验和（2 字节）、源 IP（4 字节）、目的 IP（4 字节）。IHL > 5 时还有选项字段
- TCP 头：源端口（2 字节）、目的端口（2 字节）、序列号（4 字节）、确认号（4 字节）、数据偏移+标志（2 字节）、窗口大小（2 字节）、校验和（2 字节）、紧急指针（2 字节）。标志位展开：URG/ACK/PSH/RST/SYN/FIN
- UDP 头：源端口、目的端口、长度、校验和（各 2 字节）

输入是原始字节流（从 pcap 文件或 socket 抓包得到）。工具逐层解析：先读 Ethernet 头，根据 EtherType 决定下一层是 IPv4 还是 ARP，再根据 IPv4 的协议字段决定是 TCP 还是 UDP。每一层解析完后把有效载荷传给下一层。

输出树状结构：每层缩进展示字段名和值。MAC 地址用冒号分隔十六进制，IP 用点分十进制。遇到未识别的协议类型输出原始字节警告但不崩溃。

python3 proto_parser.py capture.bin。纯 Python 3 标准库。
