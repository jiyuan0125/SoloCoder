Git 三路合并的核心算法不复杂——找共同祖先，对比两个分支的改动，能自动合并的就合，改了同一段的就冲突。但手写一遍才能真正理解冲突检测的边界情况。Python 实现三路合并工具。

输入三个文件：base（共同祖先）、ours（我们的修改）、theirs（他们的修改）。对三个文件按行做差异分析，找出各自的改动区域。

合并策略：
- 只有一方改了某段 → 采用改动方的内容
- 两方改了同一段但改动完全相同 → 采用任意一方
- 两方改了同一段但改动不同 → 标记为冲突

实现方法：先把三个文件切成"差异区域"——用 diff3 算法找到三个版本之间的变更块。对每个变更块判断是一方修改还是双方修改。一方修改的直接采用，双方修改的检查是否完全相同。不同则标记冲突。

冲突标记格式：<<<<<<< ours ... ======= ... >>>>>>> theirs，中间是两个分支各自的内容。输出合并后的文本和冲突数量。

特殊处理：新增行（一方加了行另一方没动）要正确插入到位置上。删除行（一方删了行另一方没动）要正确移除。一方加了一行另一方也加了同一行 → 不算冲突。

CLI：python3 merge_tool.py --base base.txt --ours ours.txt --theirs theirs.txt -o merged.txt。返回 0 表示无冲突，1 表示有冲突。纯 Python 3 标准库。
