实现一个 Python 的合并冲突自动解决器，能处理 Git 风格的冲突标记。

有时候合并产生的冲突其实是可以自动解决的——比如一边只改了格式，另一边改了内容。工具读取包含 `<<<<<<<` / `=======` / `>>>>>>>` 冲突标记的文件，对每个冲突块应用策略：选 ours、选 theirs、合并两边（如果修改的是不同行）、交互式选择。支持配置默认策略，对无法自动解决的冲突保留标记。

Python 3 实现。CLI：`python resolver.py --strategy auto conflicted_file.py -o resolved.py`。能统计自动解决了多少冲突、剩余多少需要人工处理。`python resolver.py` 能直接跑。
