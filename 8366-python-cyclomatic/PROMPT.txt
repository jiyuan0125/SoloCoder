代码审查时需要一个客观的复杂度指标来判断函数是否需要重构。McCabe 圈复杂度是最经典的——它度量的是程序中独立执行路径的数量。Python 实现圈复杂度计算工具。

计算规则：圈复杂度 = 1 + 决策点数量。Python 中的决策点包括：if、elif、for、while、and、or、except、with、assert、列表推导式中的 if 条件。三元表达式（x if cond else y）也是一个决策点。elif 不同于 if——每个 elif 算一个额外的决策点，但不算嵌套。

解析流程：用 ast 模块解析源文件，遍历 AST 找到所有 FunctionDef 和 AsyncFunctionDef 节点。对每个函数体遍历子节点，统计决策点出现次数。lambda 表达式也单独计算。类方法分别计算（不把类本身当作一个计算单元）。

输出每个函数的复杂度值和评级：
- 1-5：简单，风险低
- 6-10：中等，可以接受
- 11-20：复杂，建议重构
- 21+：高风险，必须重构

额外统计：总函数数、平均复杂度、超过阈值的函数列表、复杂度分布直方图。

CLI：python3 cyclomatic.py source.py。支持 --threshold 10 过滤只显示超过阈值的函数。也支持扫描整个目录。纯 Python 3 用 ast 模块。
