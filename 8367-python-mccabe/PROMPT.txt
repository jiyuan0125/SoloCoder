帮我实现一个 McCabe 复杂度分析器，对 Python 代码做静态分析。

McCabe 复杂度和圈复杂度本质上一样，但这个工具要更贴近 McCabe 原始论文的定义，并且输出更友好的报告。解析 Python AST，计算每个函数/方法的决策点数量。额外功能：按模块汇总、生成阈值报警（比如 >5 建议重构、>10 必须重构）、支持忽略特定装饰器的函数（如 `@property`）。

Python 3 标准库，基于 ast 模块。用法：`python mccabe.py --threshold 5 myproject/`，只显示超过阈值的函数。输出包含函数全限定名、起止行号、复杂度值。`python mccabe.py` 能运行。
