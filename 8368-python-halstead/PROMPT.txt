圈复杂度只度量控制流，不度量代码的"信息量"。Halstead 度量从操作符和操作数的数量来量化代码的词汇复杂度——函数用了多少种不同的运算符、多少种不同的操作数。Python 实现 Halstead 复杂度计算器。

操作符和操作数的分类（Python 特化）：
- 操作符：算术运算符(+ - * / // % **)、比较运算符(== != < > <= >=)、赋值(= += -=)、逻辑运算符(and or not)、关键字(if elif else for while def class return yield with try except raise)、点号访问(.)、下标([])、调用(())、lambda
- 操作数：变量名、常量（整数、浮点、字符串、布尔、None）

统计量：
- n1 = 不同操作符数量，N1 = 操作符总出现次数
- n2 = 不同操作数数量，N2 = 操作数总出现次数

派生指标（按 Halstead 公式）：
- 程序长度 N = N1 + N2
- 词汇量 n = n1 + n2
- 程序体积 V = N × log2(n)
- 难度 D = (n1/2) × (N2/n2)
- 工作量 E = D × V
- 预计错误数 B = E^(2/3) / 3000
