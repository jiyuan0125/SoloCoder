微服务拆分时需要量化模块间的耦合程度——高耦合的模块不适合分到不同的服务。写一个 Python 耦合度分析工具，基于 import 关系量化模块间依赖。Python 实现。

数据收集：扫描目录下所有 .py 文件，用 ast 模块解析 import 语句。构建模块依赖图——节点是模块，边是 import 关系。边有权重（import 的数量）。

指标计算：
- 扇入（Fan-In）：有多少其他模块依赖此模块。高扇入的模块是基础设施，改动要谨慎
- 扇出（Fan-Out）：此模块依赖多少其他模块。高扇出的模块是胶水代码，受上游影响大
- 不稳定度（Instability）：I = Fan-Out / (Fan-In + Fan-Out)，范围 0-1。0 表示最稳定（被依赖多但不依赖别人），1 表示最不稳定
- 抽象度（Afferent Coupling）：Ca = Fan-In
- 传递依赖：A→B→C，A 间接依赖 C。用 BFS 计算每个模块的传递扇出

依赖矩阵：N×N 矩阵（N 是模块数），格子值是 import 数量。高密度区域说明耦合严重。

循环依赖检测：DFS 找有向图中的环。报告所有环路径。

输出格式：终端表格 + 可选 DOT 格式依赖图。python3 coupling.py src/。纯 Python 3 用 ast 模块。
