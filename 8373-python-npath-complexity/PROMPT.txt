圈复杂度 10 看起来还好，但如果是一个包含 5 个 if-else 链的函数，实际执行路径是 2^5 = 32 条。NPath 复杂度统计的就是这种路径组合爆炸。Python 实现分析器。

计算规则（基于 AST 结构递归计算）：
- 顺序语句：NPath = max(1, NPath(s1) × NPath(s2) × ...)——顺序执行的路径数相乘
- if-else：NPath = NPath(condition) + NPath(then_branch) + NPath(else_branch)。没有 else 时 else_branch 的 NPath = 1
- if-elif-else 链：每个分支的 NPath 相加
- for/while 循环：NPath = 1 + NPath(body)（循环体可能执行 0 次或多次，简化为 2 条路径）
- try-except：NPath = NPath(try_body) + Σ NPath(except_clause)。每条 except 分支是一条独立路径
- 函数调用：NPath = 1（除非是递归）
- 其他语句：NPath = 1

递归计算每个函数的 NPath 值。阈值建议：200 以下可接受（来源于原始论文的建议）。

输出每个函数的 NPath 值和路径数（科学计数法显示，因为数字可能很大）。找出 NPath 最高的函数。

python3 npath.py source.py。纯 Python 3 用 ast 模块。
