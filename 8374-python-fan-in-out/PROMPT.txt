影响分析的核心问题——改了某个模块会影响多少其他模块？扇入扇出是最基础的度量。Python 实现扇入扇出分析工具。

数据收集：扫描 Python 项目的所有 .py 文件，用 ast 模块解析 import 语句。构建有向依赖图：A import B → A 到 B 有一条边。

直接依赖指标：
- 扇出（Fan-Out / Ce，Efferent Coupling）：模块直接依赖的其他模块数量（出度）
- 扇入（Fan-In / Ca，Afferent Coupling）：直接依赖此模块的其他模块数量（入度）

传递依赖指标：
- 传递扇出：通过传递闭包计算，A 依赖 B，B 依赖 C → A 传递依赖 C。用 BFS/DFS 从每个模块出发计算可达的其他模块总数
- 传递扇入：反向图的传递扇出——有多少模块直接或间接依赖此模块
- 依赖距离：两个模块之间的最短依赖路径长度。同模块=0，直接依赖=1，间接传递=2+

可视化输出：依赖热力图——模块为行和列的矩阵，格子的颜色深浅表示依赖强度（直接依赖深色，传递依赖浅色）。也输出文本格式的依赖拓扑（按扇出从低到高排列）。

python3 fan_in_out.py src/。纯 Python 3 用 ast 模块。
