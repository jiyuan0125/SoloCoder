项目代码库里有大量重复代码——类似的函数在不同文件里复制粘贴，改了一个忘了改另一个。手动找不现实，写一个自动化的重复代码检测器。Python 实现。

检测方法：使用基于 token 序列的匹配。先用 tokenize 模块把 Python 源码转成 token 序列（忽略空白、注释和缩进 token），然后对 token 序列做滑动窗口匹配。

算法步骤：
1. 收集所有源文件的 token 序列
2. 按固定窗口大小（默认 30 个 token，约 5-8 行代码）切分
3. 对每个窗口计算哈希值（把 token 类型序列哈希）
4. 哈希值相同的窗口对就是候选重复
5. 对候选对做扩展匹配——向前后延伸直到不匹配为止，得到完整的重复片段

过滤误报：纯 import 语句的重复不算、只有一个 return 语句的函数不算、getter/setter 不算。

输出每组重复的：涉及的文件和行号范围、重复的 token 数量和行数、相似度百分比（完全相同 = 100%）。按重复程度排序，最大的重复排在前面。汇总统计：总重复行数、重复率（重复行 / 总代码行）。

python3 duplication_detector.py src/ --min-tokens 30。纯 Python 3 标准库。
