代码克隆（Code Clone）比简单的复制粘贴更隐蔽——有时候是结构相同但变量名不同，有时候是整体重构了但核心逻辑没变。按类型检测不同层次的克隆。Python 实现。

克隆类型定义：
- Type 1（精确克隆）：完全相同的代码，只有空白和注释不同
- Type 2（结构克隆）：结构上相同的代码，变量名和函数名不同但语法结构一样
- Type 3（语义克隆）：功能相同但实现方式不同（这个最难检测，可以用简单启发式）

检测方法：
- Type 1：用 tokenize 转 token 序列，去空白和注释后做子串匹配。对 token 序列算 Rabin-Karp 滚动哈希，找长度 ≥ 50 token 的完全匹配段
- Type 2：在 Type 1 的基础上，把所有标识符替换为占位符（IDENTIFIER），字面量也替换（NUMBER/STRING），然后做相同的哈希匹配
- Type 3：提取函数的 AST 结构指纹（节点类型序列），相似度超过阈值的函数对标记为候选

输出每对克隆的类型、两个文件的位置和行号范围、克隆代码片段预览。Type 1 和 2 按出现频率排序，最频繁的克隆排在前面。

python3 clone_detector.py src/ --min-length 50。纯 Python 3 用 ast 和 tokenize 模块。
