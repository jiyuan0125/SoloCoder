代码分析工具发现了各种问题，但只报问题不给解决方案让人很无助。写一个工具不仅检测代码问题，还给出具体的重构建议。Python 实现。

检测和建议对照：
- 长函数（>40行）→ 建议按职责拆分为多个小函数，每个函数做一件事。自动识别函数内的代码块边界（连续的注释行或空行暗示了逻辑分段）
- 长参数列表（>5个）→ 建议用参数对象（dataclass 或 TypedDict）封装相关参数
- 深层嵌套（>3层）→ 建议用 guard clause（早返回）减少嵌套层级
- 重复代码 → 建议提取公共函数，自动生成提取后的代码骨架
- 大类（>300行）→ 建议按 LCOM 分析结果拆分，给出推荐的方法分组
- 复杂条件表达式 → 建议提取为命名的布尔变量或辅助函数
- 魔法数字 → 建议提取为命名常量
- 过长的三元表达式 → 建议改写为 if-else

每个建议包含：原代码片段（带行号）、问题说明、重构后的代码示例（自动生成骨架，不一定完全正确但给出方向）、预期改善的度量变化（复杂度从 X 降到 Y）。

输出 Markdown 格式的重构报告，可以集成到 PR review 中。python3 refactor_suggest.py source.py。纯 Python 3 用 ast 模块。
