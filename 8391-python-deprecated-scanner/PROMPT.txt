Python 版本升级后有些 API 被 deprecated 了——collections.Mapping 要改成 collections.abc.Mapping，asyncore 模块整个删了。如果代码库很大手动查根本找不过来。Python 实现废弃 API 扫描器。

维护一个废弃 API 数据库（JSON 格式），按 Python 版本分类：
- 3.9 废弃：random.randrange(non-int) 等
- 3.10 废弃：distutils 整个模块、importlib.resources.path 等
- 3.11 废弃：asyncore、asynchat、imghdr、locale.resetlocale 等
- 3.12 移除：asyncore、asynchat、imp、optparse（建议迁移到 argparse）

扫描流程：用 ast 模块解析源文件，提取所有 import 语句和属性访问（ast.Attribute）。对比废弃数据库，匹配到废弃 API 就报告。

每个匹配报告：文件名:行号、废弃的 API 名称、废弃版本、替代方案、是否已完全移除。按严重程度排序——已移除的优先（会导致 ImportError/AttributeError），然后是已废弃的。

也检测标准库以外的废弃 API——通过读取包的 __deprecated__ 属性或 CHANGELOG（启发式，不保证完整）。

支持指定目标 Python 版本：--target 3.12 只报告 3.12 及之前版本废弃的 API。python3 deprecated_scanner.py src/ --target 3.12。纯 Python 3 用 ast 模块。
