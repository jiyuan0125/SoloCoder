实现一个 Python 的漏洞扫描器，检测代码中的常见安全问题。

不是扫描依赖漏洞，而是扫描源代码本身的安全隐患。检测：SQL 注入（字符串拼接 SQL）、命令注入（os.system / subprocess 用了用户输入）、硬编码密码和密钥、不安全的反序列化（pickle.loads 处理外部输入）、不安全的随机数（random 而非 secrets）、路径遍历（未过滤的文件路径）、弱哈希（md5/sha1 用于密码）。

Python 3，ast 模块 + 正则。CLI：`python vuln_scanner.py src/`，输出每个漏洞的类型、严重度（高/中/低）、位置和修复建议。`python vuln_scanner.py` 能直接运行。
