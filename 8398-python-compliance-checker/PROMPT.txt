帮我实现一个 Python 的合规性检查工具，验证代码是否符合安全编码规范。

参考 OWASP 和 CERT 编码标准，检查 Python 代码是否遵循安全最佳实践。检查项包括：异常处理是否完整（不能吞掉异常不记录）、日志中是否包含敏感信息、是否有输入验证、密码存储是否用了合适的哈希算法、是否有安全的会话管理、CORS 配置是否过于宽松。每条检查有对应的规范编号。

Python 3，ast 模块。命令行：`python compliance.py --standard owasp src/`，输出每条检查的通过/失败状态和具体代码位置。`python compliance.py` 能直接运行。
