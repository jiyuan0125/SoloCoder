数据库索引底层就是 B-Tree，理解它对优化查询很重要。用 Go 实现一个 B-Tree，支持基本的增删查操作。

B-Tree 的核心性质：每个节点最多 M 个 key（M 是阶数，默认设为 3 即 2-3 树方便测试），最少 ⌈M/2⌉-1 个 key。所有叶子节点在同一层。节点内的 key 有序排列，子节点指针夹在 key 之间。搜索时在节点内二分查找定位子树。

操作实现：
- Search(key)：从根节点开始，每个节点内二分查找。找到就返回值，找不到就去对应的子节点继续。时间 O(log n)
- Insert(key, value)：先找到应该插入的叶子节点，插入后如果 key 数超过 M-1 就分裂——中间 key 上提到父节点，两边分裂成两个新节点。分裂可能向上传播到根，根分裂时树高加 1
- Delete(key)：找到 key 所在节点删除。删除后如果 key 数少于下限，先尝试从兄弟节点借一个 key（旋转），借不了就和兄弟合并。合并也可能向上传播
- 遍历：中序遍历产出所有 key 的有序序列

写个 main 做基准测试：插入 10000 个随机 key，验证中序遍历结果有序，搜索每个 key 都能找到。然后删掉一半再验证。go build 通过。
