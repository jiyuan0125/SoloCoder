B+ Tree 和 B-Tree 的关键区别是——所有数据都在叶子节点，内部节点只存 key 做索引。叶子节点之间用链表串起来，范围查询特别快。数据库索引几乎都用 B+ Tree。Go 实现。

节点结构：内部节点存 keys 和 children 指针（子节点数量 = keys 数量 + 1）。叶子节点存 keys、values 和一个 next 指针指向右边的兄弟叶子。所有叶子通过 next 指针形成有序链表。

操作：
- Search(key)：和 B-Tree 类似向下搜索，但最终一定在叶子节点找到数据
- RangeSearch(start, end)：先搜索到 start 所在的叶子节点，然后沿 next 指针遍历直到 key > end。这是 B+ Tree 最大的优势——范围查询不需要回溯内部节点
- Insert(key, value)：插入到叶子节点，满了就分裂。分裂时中间 key 复制一份上提到父节点（不是移动，因为叶子也要保留这个 key 作为分隔）
- Delete(key)：从叶子删除，不够就从兄弟借或合并
