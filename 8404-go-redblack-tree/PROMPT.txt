AVL 树的平衡太严格导致旋转频繁，红黑树放松了平衡条件但仍然保证 O(log n)。Java 的 TreeMap 和 C++ 的 map 都用红黑树。Go 实现。

红黑树的五条性质：1) 每个节点是红色或黑色。2) 根节点是黑色。3) 叶子节点（nil）是黑色。4) 红色节点的两个子节点都是黑色。5) 从任一节点到其所有叶子的路径包含相同数量的黑色节点。

插入后的修复（Fixup）：新插入的节点是红色的。如果父节点也是红色（违反性质 4），需要根据叔节点的颜色决定操作——叔节点红色就变色（父和叔变黑，祖父变红），叔节点黑色就做旋转（根据父节点是左子还是右子以及新节点是左子还是右子选择 LL/RR/LR/RL 旋转）。

删除后的修复更复杂——删除黑色节点可能导致黑色节点数量不平衡。用 Sentinel nil 节点简化实现（所有叶子都指向同一个 nil 节点）。

操作：Insert、Delete、Search、Min、Max。写个 main 顺序插入 100 万个整数，验证 Search 和 Delete 都正确。统计树的黑高度验证性质 5。go build 通过。
