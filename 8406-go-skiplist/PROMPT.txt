Redis 的有序集合底层用跳表实现——比红黑树简单得多，还支持 O(log n) 的范围查询。Go 实现一个跳表。

跳表在有序链表的基础上加多层索引。底层是完整的有序链表，上面的每一层是下一层的稀疏子集。查找时从最高层开始，每层向右走到不能走了就下降一层，最终到底层找到目标。每个节点随机决定自己的层数（抛硬币，概率 0.5 每次成功层数加 1，最大层高限制 16 或 32）。

操作：
- Search(key)：从最高层头节点开始，每层向右比较 key，大于目标就下降。O(log n) 期望
- Insert(key, value)：先像 Search 一样找到插入位置，同时记录每层的"前驱节点"。新节点随机生成层数，在涉及的每一层都插入。更新每层前驱节点的 next 指针
- Delete(key)：类似 Insert，找到位置后从所有包含该节点的层中移除
- Range(start, end)：找到 start 节点，沿底层链表遍历到 end

并发安全加分项（可选）：用细粒度锁（每个节点一个 mutex）实现并发读写。

写个 main：插入 10 万个随机 key，验证 Search 和 Range 正确。统计平均层数是否接近预期（1/(1-p) = 2）。go build 通过。
