AA Tree 是红黑树的简化版——只用右旋和一个"层级"字段就实现了平衡，代码特别简洁。对理解自平衡 BST 的本质很有帮助。Go 实现。

AA Tree 的规则：1) 只有右子节点可以是红色（用 level 表示，红色节点 level = 父节点 level）。2) 叶子节点 level = 1。3) 左子节点的 level 比父节点少 1。

插入和删除后只需两个操作恢复平衡——skew（右旋处理左红色链接）和 split（左旋处理连续的右红色链接）。skew 把左红链接转成右链接，split 处理两个连续的右红链接。两个操作都是常数时间，最多调用 O(log n) 次。

代码特别简洁：插入用递归 BST 插入，然后对路径上的每个节点做 skew + split。删除也是递归删除后做 rebalance（先降低过高的节点，然后做三次 skew + 两次 split）。

和红黑树对比：AA Tree 的代码量大约是红黑树的一半，性能相当。很多教材推荐用 AA Tree 代替红黑树教学。
