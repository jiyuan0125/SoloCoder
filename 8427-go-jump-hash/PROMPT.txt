Google 的 Jump Consistent Hash 是一个零内存的一致性哈希算法——不需要环、不需要虚拟节点、甚至不需要存储任何状态。给定 key 和桶数 N，纯计算就能决定 key 属于哪个桶。Go 实现。

算法只有几行代码：从 b=1（初始第一个桶）开始，用伪随机数生成器（以 key 为种子）反复"跳"到更大的桶号。第 j 轮以 1/(j+1) 的概率跳到桶 j（否则留在当前桶）。最终 b 就是 key 的归属桶。数学证明保证：当桶数从 N 变成 N+1 时，恰好 1/(N+1) 的 key 需要迁移。

优势：零内存（不需要环数据结构）、均匀分布（比虚拟节点更均匀）、快速 O(ln N)。局限：桶必须从 0 连续编号（不支持带权重的场景）、桶的增删必须是尾部操作。

操作接口：Hash(key uint64, numBuckets int32) → int32。只需这一个函数。

扩展示例：如果要支持桶的删除（中间空出一个位置），维护一个已删除桶号的 sorted list，跳跃时跳过已删除的桶。

写个 main 做 benchmark：100 万个 key 分配到 100 个桶，统计均匀性。然后桶数从 100 变到 101，验证迁移比例接近 1/101。go build 通过。
