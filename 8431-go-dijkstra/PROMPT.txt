写一个 Dijkstra 最短路径算法的 Go 实现，用来做城市之间的路线规划。

输入是带权有向图，用邻接表表示。图的存储结构：type Graph struct { nodes map[int][]Edge }，Edge 包含 to 和 weight 字段。支持从文件读取图的边数据，格式每行：from to weight（空格分隔）。

算法实现：从源点 src 出发，维护一个 dist 数组（到每个节点的最短距离，初始无穷大）和 prev 数组（前驱节点，用于重建路径）。用优先队列（container/heap 实现最小堆）存储 (distance, node) 对。每次弹出距离最小的节点，对其所有邻居做松弛操作：如果 dist[current] + edge.weight < dist[neighbor]，更新 dist 和 prev。

时间复杂度 O((V+E)log V)。处理不连通的情况——不可达节点的 dist 保持无穷大（用 math.MaxInt64 表示）。负权边不是 Dijkstra 的适用场景，遇到负权输出警告。

路径重建：从目标节点沿 prev 数组回溯到源点，反转得到完整路径。输出格式："0 → 3 → 7 → 12, distance: 42"。

写个 main 读入一个有 1000 个节点 5000 条边的随机图，查几条最短路径并打印（包含路径和距离）。也测试一个不连通的图验证无穷大输出。go build 编译通过。
