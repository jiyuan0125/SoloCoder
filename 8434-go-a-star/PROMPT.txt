做一个 A* 寻路算法，用在二维网格地图上找从起点到终点的最短路径。Go 实现。

A* 是 Dijkstra 的启发式版本——用一个估计函数 h(n) 引导搜索方向，比 Dijkstra 快很多。核心公式 f(n) = g(n) + h(n)，g 是从起点到 n 的实际距离，h 是从 n 到终点的估计距离。h 必须是可容许的（不高估实际距离），A* 才能保证最优。

网格地图的表示：二维数组，0 表示可通行，1 表示障碍。支持从文本文件读入（# 表示障碍，. 表示空地）。支持两种移动模式：四方向（上下左右，曼哈顿距离作为启发函数）和八方向（含对角线，用切比雪夫距离或欧氏距离作为启发函数）。

实现用优先队列（按 f 值排序），每个状态包含 (x, y, g, f, parent)。closed set 记录已访问的格子防止重复。如果终点不可达（被障碍包围），明确报告无解。

输出路径：在原始地图上用 * 标出路径格子，打印完整的地图。同时输出路径长度和搜索过的节点数（和 Dijkstra 对比搜索效率）。

写个 main 读一个 50x50 的地图，找一条路径并打印。go build 通过。
