编译器里要根据模块依赖关系确定编译顺序，不能有循环依赖。用 Go 实现拓扑排序。

两种实现方式：
1. Kahn 算法（BFS）：先计算所有节点的入度。把入度为 0 的节点加入队列，依次弹出并减少其邻居的入度，邻居入度变 0 就加入队列。弹出的顺序就是拓扑序。如果弹出的节点数 < 总节点数，说明有环
2. DFS 方式：对每个未访问的节点做 DFS，回溯时把节点加入结果列表（最终反转）。用三色标记（白/灰/黑）——遇到灰色节点说明有环

图用邻接表表示。支持从文件读取依赖关系，格式：A B 表示 A 依赖 B（B 是 A 的前置）。

检测到环时，不只是报告"有循环依赖"，还要输出环上的节点——DFS 方式中遇到灰色节点时，从当前递归栈中提取环路径。

命令行工具：读取依赖文件后输出编译顺序。测试两组数据：一组无环的正常依赖（5 个模块互相依赖），一组有循环依赖（A→B→C→A）。go build 通过。
