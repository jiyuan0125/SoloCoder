哥尼斯堡七桥问题就是欧拉路径的起源。用 Go 实现欧拉路径和欧拉回路的判断和求解。

欧拉路径的判定条件：无向图中恰好 0 个或 2 个奇数度的节点。0 个奇数度节点 → 存在欧拉回路（起点终点相同），2 个奇数度节点 → 存在欧拉路径（从一端出发到另一端）。有向图中：所有节点入度等于出度 → 欧拉回路；恰好一个节点出度比入度多 1（起点）和一个节点入度比出度多 1（终点）→ 欧拉路径。

求解算法——Hierholzer：从起点开始 DFS，每次走一条未使用的边。DFS 回溯时把节点加入路径。最终路径反转就是欧拉路径。

实现关键：每条边只能走一次。用邻接表存储，同时维护每条边是否已使用的标记（或者直接从邻接表中删除已走的边）。DFS 的过程中动态删除边避免重复走。

输出：路径序列 v0 → v1 → v2 → ... → vk。如果不存在欧拉路径/回路，说明原因（奇数度节点的数量和位置）。

写个 main：构造几个图测试——一个有欧拉回路的（所有度数为偶数）、一个只有欧拉路径的（两个奇数度节点）、一个都没有的（四个奇数度节点）。打印路径序列。go build 编译通过。
