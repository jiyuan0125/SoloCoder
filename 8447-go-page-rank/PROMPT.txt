Google 搜索的核心算法之一就是 PageRank，用来给网页排序。基本思想：一个网页的重要性取决于有多少重要的网页链接到它。用 Go 实现一个 PageRank 算法。

模型：每个网页是一个节点，超链接是有向边。PageRank 值 PR(v) = (1-d)/N + d × Σ_{u→v} PR(u)/out_degree(u)。d 是阻尼系数（默认 0.85，表示用户 85% 概率点击链接，15% 概率随机跳转）。N 是总节点数。

幂迭代法实现：初始所有节点 PR = 1/N。每轮迭代按公式更新所有 PR 值。当所有 PR 值的变化量之和 < ε（默认 1e-6）时停止，说明收敛。

Dangling node 问题：没有出链的节点（out_degree=0）会导致 PR "泄漏"。处理方式——dangling node 的 PR 值平均分配给所有节点（相当于随机跳转到任意页面）。

输入有向图的邻接表。输出每个节点的 PageRank 值（排序后）。

写个 main：构建一个 100 个网页的随机链接图（每个页面随机链接 3-5 个其他页面），运行 PageRank 算法，输出 Top 10 最重要的网页及其分数。go build 通过。
