通用分段 LRU 缓存——不是固定两个段，而是允许用户自定义多个优先级段。比如 hot/warm/cold 三级，每段有独立的容量和 LRU 链表。应用可以主动指定 key 放进哪个段，也可以配置自动晋升规则。Go 实现。

段管理：
- RegisterSegment(name string, capacity int) 注册一个新段。至少支持 3 个段
- Put(key, value, segmentName) 指定段名插入。段不存在报错
- Get(key) 跨段查找——遍历所有段的 map 找到后返回值。可选的自动晋升：如果 key 被访问 N 次（可配置），从低优先级段提升到高优先级段

段内的淘汰：每个段独立按 LRU 淘汰自己超出的部分。淘汰时不降级到其他段（和 SLRU 不同），直接丢弃。段间的容量分配完全由用户决定。

统计：每段独立统计命中率（hit/miss/evict）。GetRate(segmentName) 返回该段的命中率。总命中率 = 所有段的命中数 / 总访问数。

Go 标准库实现，go build 通过。段数量不限但至少支持 3 个。写个 main 演示三段（hot 容量100/warm 容量500/cold 容量1000）的使用场景。
