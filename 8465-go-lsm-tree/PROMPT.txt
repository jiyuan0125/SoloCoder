用 Go 实现一个简化版的 LSM-Tree 存储引擎。

LSM-Tree 是写密集型数据库的核心数据结构，LevelDB 和 RocksDB 都基于它。写入先到 Memtable（内存），满了刷成 SSTable 文件，后台做 compaction 合并文件。

核心功能：
- 写入路径：WAL → Memtable → Immutable Memtable → Flush SSTable
- 读取路径：Memtable → Immutable Memtable → Level-0 SSTables → Level-1...
- 多层 SSTable 文件管理，每层容量递增
- Get/Put/Delete/Scan 基本接口
- 简单的 size-tiered compaction

Go 标准库，go build 能编译通过。先不做并发 compaction，把基本流程跑通就行。注意 Delete 是写入一个 tombstone 标记。
