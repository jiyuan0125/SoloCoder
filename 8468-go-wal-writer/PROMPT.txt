数据库最怕什么？写到一半断电。WAL（Write-Ahead Log）就是保险绳——每次写操作先追加日志文件再更新内存，crash 后重放日志就能恢复。LevelDB 的 .log 文件就是这么干的。Go 写一个 WAL 写入器。

记录格式参考 LevelDB：每条记录 CRC32 校验（4字节）+ 长度（2字节）+ 类型（1字节）+ payload。因为 block 按 32KB 对齐，大记录跨 block 时拆成 first/middle/last 三种类型拼接，单 block 内放得下的用 full。block 末尾不够 7 字节 header 就填零补齐。

Write(key, value, opType) 接口，opType 区分 PUT 和 DELETE。每次 Write 后可选 fsync——关键路径同步刷盘保安全，批量导入异步写保性能。文件写满自动滚动到新文件，文件名带递增序号方便按序恢复。

CRC32 用标准库 hash/crc32（IEEE 多项式）。go build 通过。
