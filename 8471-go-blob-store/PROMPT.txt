Go 实现一个简单的 Blob 存储服务。

存储大文件（图片、视频、日志归档等），类似 S3 的简化版。每个 blob 用 SHA256 哈希做 content-addressable key 实现天然去重——相同内容只存一份。存在本地文件系统的分桶目录中，适合单机部署场景。

功能要求：
- Put(blob io.Reader) 返回 SHA256 哈希作为 ID，相同内容不重复存储（引用计数 +1）
- Get(id) 读取 blob 内容，返回 io.ReadCloser 流式读取，大文件不一次性加载到内存
- Delete(id) 删除 blob，引用计数减 1，到 0 才真正删文件
- List 支持按前缀和创建时间筛选，分页返回结果
- 分桶目录：用 hash 前两位分 256 个子目录（00/、01/...ff/），避免单目录文件太多
- 元数据（引用计数、大小、创建时间）单独存储在 JSON 文件中

Go 标准库，go build 通过。并发安全，Put/Get/Delete 需要加锁。流式读写用 io.Copy + bufio。
