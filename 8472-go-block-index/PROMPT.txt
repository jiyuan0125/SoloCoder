没有索引的 SSTable 就像没有目录的字典——找一个 key 要从第一页翻到最后一页。Block Index 就是那个目录：记录每个 data block 的起始偏移、长度和最大 key，查找时先在索引里二分定位 block，再去磁盘读那一小块。Go 实现这个索引结构。

索引条目包含 block offset（uint64）+ block size（uint64）+ separator key（分隔键，变长字节）。分隔键不是简单地取块的最大 key，而是取当前块最大 key 和下一块最小 key 之间的一个短字符串——找两个 key 的最长公共前缀，取前缀加上下一个 key 前缀后的第一个字符就行，这样索引本身更紧凑。

查找逻辑：给定 key，在 separator key 列表中二分找 key ≤ separator 的最后一个条目，就是目标 block。支持序列化到字节流写入 SSTable，以及从文件加载到内存（打开 SSTable 时一次读入，常驻内存）。编码用小端序。
