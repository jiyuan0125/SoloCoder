帮我用 Go 实现 SSTable 的 Block Index 结构。

Block Index 是 SSTable 文件中用来快速定位数据块的索引，记录每个数据块的起始 offset、长度和最大 key。读操作先在索引中二分查找定位 block，再去读对应的数据块——没有索引就只能线性扫描整个文件。

需要：
- 索引条目：block offset（uint64）+ block size（uint64）+ separator key（分隔键，变长字节）
- 构建索引：遍历数据块时记录每个块的元信息，选择分隔键（取当前块最大 key 和下一块最小 key 之间的短字符串）
- 查找：给定 key，二分查找找到可能包含该 key 的 block（key ≤ separator 的最后一个条目）
- 支持索引块本身的序列化（写入 SSTable）和反序列化（从文件加载到内存）
- 分隔键选择算法：找两个 key 的最长公共前缀，取前缀 + 下一 key 前缀后的第一个字符

Go 标准库，go build 编译通过。索引可以常驻内存，打开 SSTable 时一次读入。编码用小端序。
