SSTable 里的 key 有个有趣的特征——相邻 key 往往共享很长的前缀，比如 "user:1001:name" 和 "user:1001:email"。LevelDB 利用这一点做前缀压缩：每个 entry 只存和前一个 key 不同的后缀部分，默认每 16 个 entry 插一个 restart point 存完整 key，兼顾压缩率和二分查找效率。Go 实现这个 block 格式。

BlockBuilder 按 key 有序写入 entry，entry 格式是三个 varint（shared prefix length、unshared key length、value length）+ key suffix + value。每 16 个 entry 设一个 restart point（存完整 key），restart point 数组放在 block 末尾（uint32 数组 + num_restarts），支持二分查找跳转。block 满 4KB 就 finish 当前块开始新块。

BlockReader 从字节流重建 block，基于 restart point 做二分查找定位 entry，也支持顺序迭代遍历。key 必须有序写入，编码用小端序。
