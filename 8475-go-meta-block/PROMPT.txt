Go 实现 SSTable 的 Meta Block 管理。

SSTable 文件中除了数据块和索引块，还有元数据块（meta block），存储 bloom filter、统计信息、压缩字典等附加数据。需要统一的读写接口来管理这些不同类型的 meta block，扩展时不用改 SSTable 的核心格式。

要做的：
- Meta Block 的通用容器格式：type tag（变长字符串）+ data length（uint32）+ data payload
- 支持注册不同类型的 meta block（"bloom"、"stats"、"properties"、"compression_dict" 等）
- 写入时按 type tag 字母序追加到 SSTable 文件的 meta 区域
- 读取时按 type tag 索引，快速定位和加载特定 meta block（通过 meta index block 做映射）
- Footer 中记录 meta index block 的 offset + length，meta index block 内部格式同 data block
- 提供迭代器遍历所有 meta block

Go 标准库，go build 编译通过。参考 LevelDB 的 table format 设计，meta index 也是有序 KV 结构。
