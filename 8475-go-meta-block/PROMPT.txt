SSTable 不只有数据和索引——bloom filter 是一个 meta block，压缩字典是另一个，统计信息又是一个。这些附加数据类型会随着版本迭代增加，不能每加一种就改文件格式。做一个通用的 meta block 容器，Go 实现。

容器格式很简单：type tag（变长字符串，如 "bloom"、"stats"、"properties"）+ data length（uint32）+ payload。写入时按 type tag 字母序追加到 SSTable 的 meta 区域。读取时通过 meta index block 做 type → offset 映射，O(1) 定位。

Footer 里记录 meta index block 的 offset + length。meta index block 本身也是有序 KV 结构（key 是 type tag，value 是 meta block 的位置）。提供迭代器遍历所有 meta block，支持注册新类型——加个 "compression_dict" 不用改任何已有代码。

参考 LevelDB 的 table format。go build 通过。
