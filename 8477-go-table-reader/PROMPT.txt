Builder 把 SSTable 写到磁盘了，Reader 负责读回来。打开文件先读尾部 48 字节的 footer，拿到 index block 和 meta index block 的位置，后续所有查找都从 footer 出发。Go 实现。

Get(key) 的查找路径：index block 二分定位 data block → 读入 data block → block 内二分找 key → 返回 value。Bloom filter 先过一遍——miss 的 key 直接跳过磁盘读取。NewIterator(start, end) 提供范围迭代器，正向遍历（Seek → Next → Valid），跨 block 自动加载。

读过的 data block 可以缓存在 LRU 里避免重复 I/O。文件句柄打开后保持 fd，关闭时释放。文件 I/O 用 os.File + bufio.Reader，mmap 可选。

go build 通过。
