帮我写一个 Go 的 SSTable Table Reader。

从磁盘读取 SSTable 文件，解析 footer 定位 index block，然后支持按 key 查询和范围迭代。和 Table Builder 是一对读写组合——Builder 写出来的文件由 Reader 来消费。

功能点：
- Open(path) 打开文件后先读尾部 footer（最后 48 字节），拿到 index block 和 meta index block 的位置
- Get(key)：先在 index block 二分定位 data block → 读入 data block → block 内二分查找 key → 返回 value
- NewIterator(start, end)：范围迭代器，支持正向遍历（Seek → Next → Valid），跨 block 自动加载
- 利用 bloom filter 块提前过滤不存在的 key——bloom miss 直接跳过 block 读取
- Block 缓存可选：读过的 data block 可以缓存在内存中（LRU），避免重复磁盘 I/O
- 文件句柄管理：打开后保持 fd，关闭时释放资源

Go 标准库，go build 编译通过。文件 I/O 用 os.File + bufio.Reader，mmap 可选不必须。
