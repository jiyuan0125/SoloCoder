帮我用 Go 实现 LSM-Tree 的 Level Manager。

管理 LSM-Tree 中多个层级的 SSTable 文件，跟踪每层的文件列表、key range 和总大小。负责文件的创建、删除和层间移动。Level Manager 是 compaction 和读取操作的基础设施——每层有哪些文件、key 怎么分布，都从这里查。

功能：
- 维护 L0-Ln 的层级结构，每层一个有序文件列表
- 添加新 SSTable 到指定层（flush 输出加到 L0，compaction 输出加到目标层）
- 查询某层中和指定 key range 有重叠的文件（PickFiles(level, start, end)）
- 文件层级移动：compaction 后从源层删除参与文件、在目标层添加输出文件（原子操作）
- 统计每层文件数量和总大小，提供总数据量查询
- L0 文件 key range 可以重叠，L1+ 文件按 key range 有序且不重叠

Go 标准库，go build 编译通过。L1+ 的 key range 重叠检测要高效，可以用按 smallestKey 排序 + 二分查找。
