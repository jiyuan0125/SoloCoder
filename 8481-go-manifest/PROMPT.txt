Go 实现 LSM-Tree 的 Manifest 文件管理。

Manifest 记录 LSM-Tree 的状态变更历史：哪个 SSTable 被创建、删除，compaction 完成了哪些文件。相当于"数据库的数据库"——crash recovery 时靠它重建 level state，决定哪些文件属于哪层。没有 manifest 就不知道磁盘上那些 SSTable 怎么组织。

要做：
- Manifest 记录格式：record type（ADD/DELETE/NEW_CURRENT）+ level + file metadata（id, size, smallest/largest key）
- 追加写入：每次状态变更（flush 完成、compaction 完成、文件删除）追加一条记录到 manifest 文件
- Checkpoint：定期把当前完整状态快照写入新 manifest 文件（全量快照），加速恢复
- 恢复流程：读取最新 checkpoint manifest → 从 checkpoint 开始重放增量记录 → 重建完整层级状态
- 文件滚动：manifest 文件太大时创建新文件，旧文件保留做备份
- 每条记录带 CRC32 校验，损坏记录跳过并报警

Go 标准库，go build 通过。记录格式参考 LevelDB 的 log format。
