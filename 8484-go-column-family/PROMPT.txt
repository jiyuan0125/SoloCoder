帮我用 Go 实现 LSM-Tree 的 Column Family 支持。

Column Family 类似数据库的表，多个 Column Family 共享 WAL 但各自独立的 Memtable 和 SSTable 文件。RocksDB 用这种方式在同一个实例里隔离不同类型的数据。

要实现：
- ColumnFamily 管理：创建、删除、列出所有 CF
- 每个 CF 独立的 Memtable 和 SSTable 文件集合、独立 compaction
- 共享 WAL：写操作记录 CF ID + key + value 到同一个 WAL
- 恢复时按 CF ID 分发 WAL 记录到对应 CF 的 Memtable
- 全局操作：FlushAll、CloseAll（优雅关闭所有 CF）

Go 标准库，go build 通过。默认有个 "default" CF，新建的 CF 需要显式创建。
