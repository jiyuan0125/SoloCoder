LSM-Tree 读一个 key 要查 Memtable + Immutable Memtable + L0 的好几个 SSTable + L1 的 SSTable...十几个有序数据源，怎么合成一个全局有序的结果？答案是最小堆归并——跟归并排序一个原理，每次从所有子迭代器里弹出 key 最小的那个。Go 实现。

包装多个子 Iterator（memtable iter + 多个 sstable iter），对外统一接口。内部用 container/heap 维护，每次弹出所有子 iter 中当前最小的 key。同一个 key 有多个版本时返回 sequence number 最大的（Memtable 优先于 SSTable），旧版本跳过。遇到 tombstone 的 key 也不输出给上层，内部直接 Next 跳过。

支持 Seek(key) 定位到 ≥ key 的第一条记录、Next() 前进、Valid() 检查有效性。子迭代器接口统一：Seek/Next/Key/Value/Valid。

go build 通过。
命令行工具支持 --help 输出用法说明，错误输入时返回非零退出码。
输出要有结构，别一股脑全打印出来，分个类排个序。
