Go 实现 Huffman 编码器。

Huffman 编码是经典的无损压缩算法，根据字符频率构建最优前缀编码树，频率高的字符用短码，频率低的用长码。平均编码长度接近信息熵下界，是很多压缩格式（deflate、JPEG、PNG 过滤）的组成部分。

要求：
- 统计输入数据的字节频率分布（256 个可能值，统计每个出现次数）
- 构建 Huffman 树：最小堆每次取两个最小频率节点合并为新节点，直到只剩一棵树
- 生成编码表：从树根到叶子节点的路径（左 0 右 1）就是该字符的变长编码
- 编码：把输入字节流按编码表转换为 bit 流，最后一个字节记录有效 padding 位数
- 编码后的数据要自包含：输出 = 频率表（256 个 uint32）+ 原始数据 bit 长度（uint64）+ 压缩 bit 流
- 处理边界情况：只有一个唯一字符（编码为单个 0 bit）、空输入直接返回空
- 支持 canonical Huffman code：编码表按符号值排序分配，存储更紧凑

Go 标准库，go build 通过。bit 操作用 byte 数组模拟，最小堆用 container/heap。
