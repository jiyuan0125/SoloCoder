用 Go 写一个 Huffman 解码器。

配合 Huffman 编码器使用，从压缩数据中还原原始内容。解码过程需要用编码时生成的 Huffman 树（或频率表），逐 bit 遍历树进行解码。

功能：
- 从编码数据中解析头部信息（频率表或树结构）
- 重建 Huffman 树
- 逐 bit 读取压缩数据，从树根走到叶子输出字符
- 支持两种编码存储格式：频率表 + 压缩数据，或 canonical code + 符号列表
- 处理最后一个字节的不完整 bit（记录有效 bit 数）

Go 标准库，go build 编译通过。canonical Huffman code 可以更紧凑地存储编码表。解码性能很重要，可以考虑查表加速。
