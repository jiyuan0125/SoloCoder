编码器把 "hello world" 压成了 40 个字节，怎么还原？从压缩数据头部读出频率表重建 Huffman 树，然后逐 bit 遍历——从根出发，0 走左子树，1 走右子树，走到叶子就输出一个字符。Go 写解码器。

头部格式支持两种：频率表重建树（256×uint32 + 原始 bit 长度 uint64，简单直观），或 canonical code + 符号列表（只存位宽分布，更紧凑）。最后一个字节可能有不完整的 padding bit，头部记录了有效 bit 数，尾部忽略。

性能优化：预建 8-bit 查找表（256 项），一次查表解码 1+ 个符号，不用每个 bit 都走一遍树。退化情况也要处理——只有 1-2 种字符时树只有一条链。

canonical code 按位宽排序分配编码，解码时用位宽还原。go build 通过。
