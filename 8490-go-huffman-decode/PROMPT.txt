用 Go 写一个 Huffman 解码器。

配合 Huffman 编码器使用，从压缩数据中还原原始内容。解码过程需要用编码时生成的 Huffman 树（或频率表），逐 bit 遍历树进行解码——从根开始，0 走左子树，1 走右子树，走到叶子就输出一个字符。

功能：
- 从编码数据中解析头部信息（频率表 256×uint32 + 原始 bit 长度 uint64），重建 Huffman 树
- 逐 bit 读取压缩数据，从树根走到叶子输出字符，循环直到消耗完所有有效 bit
- 支持两种头部格式：频率表重建树（简单直观），或 canonical code + 符号列表（只存位宽分布，更紧凑）
- 处理最后一个字节的不完整 bit（头部记录了有效 bit 数，尾部 padding 忽略）
- 解码性能优化：预建 8-bit 查找表（256 项），一次查表解码 1+ 个符号，减少逐 bit 遍历次数
- 正确处理只有 1-2 种字符的特殊 Huffman 树退化情况

Go 标准库，go build 编译通过。canonical code 按位宽排序分配编码，解码时用位宽还原。
