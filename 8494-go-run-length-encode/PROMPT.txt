Go 实现 Run-Length Encoding（游程编码）。

RLE 是最简单的压缩算法之一，连续相同的字节用 (值, 重复次数) 对代替。对有大量连续重复的数据（位图、简单图形、稀疏矩阵零行）效果很好，是很多复杂压缩算法的基础组件。

要求：
- 编码：扫描输入，连续相同字节合并为 (value, count) 对，每组最多 255 次重复
- 解码：展开 (value, count) 为连续 count 个相同字节
- 处理 count 很大的情况：分块编码，超过 255 次就拆成多个 (value, 255) + 余数组
- 处理单个不重复字节：count=1 的组 worst case 膨胀 2x（可接受）
- 支持字节流式处理，不需要一次加载全部数据——输入 io.Reader，输出 io.Writer
- 编码格式简洁：每两个字节一组 (value, count)，特殊标记 value=0 count=0 作为流结束符

Go 标准库，go build 编译通过。处理全零和全相同字节等边界情况。流式用 bufio.Reader/Writer 做缓冲。
