一张 800x600 的黑白位图背景全白——600 行每行 100 字节全是 0xFF。RLE 一句话搞定：用 value 加 count 对代替 100 个重复字节。对位图、简单图形、稀疏矩阵零行这种大量连续重复的数据，RLE 是最简单也最有效的压缩方法。Go 实现编码器和解码器。

编码扫描输入字节流，连续相同的字节合并为一个 value 加 count 对。每组最多记录 255 次重复，超过 255 就拆成多个组比如 value 加 255 再加 value 加余数。解码反过来展开为连续 count 个相同字节写入输出流。单字节不重复的情况 worst case 会膨胀 2 倍每个字节变成两个字节输出，这是可接受的代价。

格式保持简洁：每两个字节一组第一个是 value 第二个是 count，value 等于 0 且 count 等于 0 作为流结束标记。流式处理输入 io.Reader 输出 io.Writer，bufio 做缓冲提升 I/O 性能。全零输入、全相同字节、单字节交替变化等边界情况都要正确处理不丢数据。go build 通过。
写好单元测试，覆盖正常流程和边界情况。测试数据要包含各种典型场景。
