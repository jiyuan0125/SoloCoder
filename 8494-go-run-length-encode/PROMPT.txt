Go 实现 Run-Length Encoding（游程编码）。

RLE 是最简单的压缩算法之一，连续相同的字节用 (值, 重复次数) 代替。对有大量连续重复的数据（如位图、简单图形）效果很好。

要求：
- 编码：扫描输入，连续相同字节合并为 (value, count)
- 解码：展开 (value, count) 为连续字节
- 处理 count 很大的情况（分块编码，每块最多 255 次）
- 处理单个不重复字节的情况（count=1 不会膨胀太多）
- 支持字节流式处理，不需要一次加载全部数据

Go 标准库，go build 编译通过。编码格式简洁：每两个字节一组 (value, count)。处理全零和全相同字节的边界情况。
