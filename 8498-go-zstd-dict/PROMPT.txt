Go 实现 Zstandard 的字典压缩预处理模块。

Zstd 支持用预训练字典加速小数据的压缩。字典从训练数据中提取高频子串，压缩时优先匹配字典中的内容，小消息也能获得不错的压缩率。

需要：
- 字典构建：从一组训练数据中提取高频 N-gram/子串
- 字典格式：头部 magic number + dictionary ID + 词表内容
- 压缩时用字典内容初始化滑动窗口的虚拟前缀
- 解压时同样需要加载字典
- 支持字典的序列化和加载

Go 标准库，go build 编译通过。不需要实现完整的 zstd 格式，重点做字典的构建和使用流程。高频子串可以用 suffix array 或者简单统计。
