Go 实现 Zstandard 的字典压缩预处理模块。

Zstd 支持用预训练字典加速小数据的压缩。字典从训练数据中提取高频子串，压缩时优先匹配字典中的内容，小消息（几百字节的 RPC payload）也能获得不错的压缩率。没有字典的话，小数据的压缩窗口太小，LZ77 几乎找不到匹配。

做以下功能：
- 字典构建：从一组训练样本（建议 ≥ 100 条）中提取高频子串（用 N-gram 统计或 suffix array），选出最有区分度的固定大小内容（默认 32KB）
- 字典格式：头部 magic number (0x37A4ED11) + dictionary ID (uint32) + histogram 数据 + 词表内容
- 压缩时用字典内容初始化滑动窗口的虚拟前缀——把字典当作"之前已经见过的数据"
- 解压时同样需要加载对应字典（通过 dictionary ID 匹配），否则解不出来
- 支持字典的序列化（保存到 []byte）和加载（从 []byte 解析），多字典 ID 管理

Go 标准库，go build 编译通过。不需要实现完整的 zstd 压缩格式，重点做字典的构建和序列化流程。
