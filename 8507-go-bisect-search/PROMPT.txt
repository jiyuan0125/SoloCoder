Go 标准库的 sort.Search 确实能用，但返回值语义单一（找到插入点），很多时候我需要知道更多——第一个等于目标的位置、最后一个等于的位置、第一个大于等于的位置。手写二分的 bug 又特别多，边界条件稍不注意就死循环或者越界。

1. 基础搜索函数。在有序切片中查找目标值，返回位置索引。不存在时返回插入点（和 sort.Search 一致）。内部用闭区间 [lo, hi] 写法，循环不变量要清晰。

2. 变体搜索。LowerBound：找第一个大于等于目标的位置。UpperBound：找第一个大于目标的位置。EqualRange：返回 [lower_bound, upper_bound) 区间，表示所有等于目标值的元素范围。FirstEqual：第一个等于目标的位置。LastEqual：最后一个等于目标的位置。

3. 泛型支持。用 Go 泛型写，约束为 cmp.Ordered 或接受自定义比较函数。这样字符串、浮点数、结构体字段都能搜索，不限于数字。

4. 边界测试。空切片返回 0 作为插入点、单元素切片、全相同元素的切片、目标比所有元素都小或都大。时间复杂度严格 O(log n)，别写出退化为线性的版本——每一步都必须把搜索范围砍半。

Go 标准库，go build 编译通过。测试用例要覆盖上述所有变体和边界情况。
