数据库索引课上老师说了一个挺反直觉的事：如果数据是均匀分布的，插值搜索比二分搜索快得多。原理也不复杂——二分搜索每次无脑取中点，插值搜索会根据当前查找值在区间中的比例来估算位置，类似字典里翻到 "apple" 不会翻到中间而是翻前面。理想情况下 O(log log n)，不过最坏也能退化到 O(n)。

用 Go 实现一个完整的插值搜索工具。

核心公式——在有序数组 arr[lo..hi] 中找 target，估算位置 pos = lo + (target - arr[lo]) * (hi - lo) / (arr[hi] - arr[lo])。然后跟二分搜索一样比较 arr[pos] 和 target，缩小范围。

要支持的类型：整数数组（int64、uint64）和浮点数数组（float64）。整数版本要注意除法截断问题，浮点版本要注意精度。提供一个搜索次数统计的功能——记录每次搜索经过了几次比较，方便和二分搜索做对比实验。

边界防护很关键：arr[lo] == arr[hi] 时直接做线性搜索或者二分搜索（防止除零）；pos 计算出来超出 [lo, hi] 范围要钳位；数据不均匀分布时（比如 [1, 2, 3, ..., 999, 1000000000] 这种长尾），要能检测到退化并切换到普通二分，别死循环。空数组和单元素数组单独处理。

Go 标准库，go build 通过。
