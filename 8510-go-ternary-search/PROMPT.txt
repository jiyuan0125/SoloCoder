凸函数上的极值怎么找？三分搜索就是干这个的。它和二分搜索的区别在于每次把区间分成三段而不是两段，然后比较两个分界点的函数值，淘汰掉不可能包含极值的那一段。当然它也能当普通搜索用——在有序数组里找目标值，每次排除三分之二的搜索空间。

那具体怎么实现呢？先说函数极值搜索。给定一个单峰函数 f(x) 和搜索区间 [lo, hi]，选两个分界点 m1 = lo + (hi-lo)/3 和 m2 = hi - (hi-lo)/3。如果 f(m1) < f(m2)，极值在 [m1, hi] 里，lo = m1；否则极值在 [lo, m2] 里，hi = m2。循环到 |hi - lo| < epsilon 就停。找最大值和最小值的区别只在比较方向上。

精度方面，epsilon 要能由调用方指定，默认取 1e-9。浮点精度别出幺蛾子——用 math.Abs 做差值比较。收敛次数是 O(log₃(range/epsilon))，理论上比二分搜索的区间收缩更快。

数组搜索方面，把三分搜索用在有序切片上找目标值，不过实际效率不如二分搜索（每次比较次数更多），所以这个变体主要是教学用途。

特殊函数的处理：常函数 f(x) = c 不会收敛到极值点，要在循环里加个检测——如果 f(m1) 和 f(m2) 足够接近就直接返回中点。平坦区间（一段都是极值值）的情况也要处理。纯 Go 标准库，go build 通过。
