面试经常问一个问题：怎么在 O(n) 时间内排序？桶排序在特定条件下能做到——数据均匀分布时每个桶里元素很少，桶内排序接近常数时间，n 个桶并行处理就是线性的。当然前提是分布真的均匀，否则某个桶可能装了大部分元素直接退化成 O(n²)。

用 Go 实现一个通用的桶排序。

浮点数场景是经典用法——假设所有值在 [0, 1) 之间均匀分布，开 n 个桶，第 i 个桶装 [i/n, (i+1)/n) 范围的值。遍历输入数组把每个值放进对应的桶。桶内用插入排序（数据量小的时候插入排序最快，常数因子小）。最后把所有桶按顺序拼接起来。

整数场景——自动计算 min 和 max，桶的个数取 √n 或自定义。每个桶覆盖的范围 = (max - min) / bucket_count。非均匀分布的防御：如果某个桶的元素超过总数的 50%，对这个桶递归做桶排序或者直接切换到快排，避免最坏情况。

桶内排序用插入排序——实现一个简洁的 insertion sort，对小于 16 个元素的切片效率最高。桶排序的稳定性取决于桶内排序的稳定性，用插入排序就是稳定的。

API 设计：BucketSortFloats(data []float64) 和 BucketSortInts(data []int, bucketCount int)。从文件或命令行读数据也支持。空切片和单元素直接返回。

Go 标准库，go build 通过。
