插入排序的时间复杂度 O(n²) 看着不行，但它有个特点——元素离最终位置越近，插入排序越快。Shell Sort 就是利用这一点，先用大间隔把远处的元素快速搬到位，再逐步缩小间隔做精细调整。

实现流程——

第一步，选择间隔序列。提供三种经典序列可选：Shell 原始序列（n/2, n/4, ..., 1），最简单但不是最优；Hibbard 序列（1, 3, 7, 15, ..., 2^k-1），最坏 O(n^1.5)；Knuth 序列（1, 4, 13, 40, ..., (3^k-1)/2），实际表现很好。默认用 Knuth 序列，其他通过参数选择。

第二步，排序过程。从最大的间隔 gap 开始，对数组中所有间隔为 gap 的元素子序列分别做插入排序。然后 gap 缩小到序列中的下一个值，重复。最后 gap=1 时就是一次标准插入排序，但此时数组已经基本有序，这次插入排序接近 O(n)。

第三步，性能对比。实现一个 benchmark 函数，对同一组数据分别用三种间隔序列排序，记录比较次数和耗时。数据模式要覆盖：随机数据、已排序、逆序、90% 相同值。

也支持用户传入自定义间隔序列。间隔序列必须是递减的，最后必须是 1。空切片和单元素直接返回。Go 标准库，go build 编译通过。
