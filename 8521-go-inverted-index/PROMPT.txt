团队内部有个需求：给文档库加个关键词搜索功能。文档量不大，几千篇，用 Elasticsearch 太重了，自己写一个简单的倒排索引就够用。倒排索引的原理其实很直白——建一张表，记录每个词出现在哪些文档里，查询的时候直接查表就行。

用 Go 实现一个倒排索引系统。

文档管理方面——每篇文档有唯一 ID（uint32）和文本内容（string）。提供 AddDocument(docID, text) 方法添加文档。内部对文本做分词：按空格和常见标点（逗号、句号、感叹号等）切分，转小写，去掉空 token。文档 ID 列表要排重且保持有序。

索引构建方面——分词后对每个 token 建立映射：token → []docID。同一个 token 在同一篇文档里出现多次只记一次 docID。也记录每个 token 的文档频率（出现在多少篇文档里），后面算 TF-IDF 会用到。

查询接口——Query(keyword string) 返回包含该关键词的所有文档 ID，有序去重。QueryAnd(keywords []string) 返回同时包含所有关键词的文档，用多路归并求交集。QueryOr(keywords []string) 返回包含任一关键词的文档，用归并求并集。

持久化——把索引序列化到文件（JSON 或者二进制格式都行），也能从文件加载。启动时不用每次重建索引。

Go 标准库，go build 通过。查询效率要比遍历所有文档快得多，这是索引的基本要求。
