搜索引擎有个底层组件容易被忽略——Term Dictionary（词项字典）。它管理索引里出现过的所有词项，记录每个词项对应的倒排列表在文件中的偏移量。看起来就是 map[string]int64，但词典可能有几百万甚至上千万个词项，纯 map 内存占用很大，而且要支持前缀查找和有序遍历。

用 Go 实现一个高效的词项字典。

底层存储用前缀树（Trie）或 FST（Finite State Transducer）。前缀树方案：每个节点存一个字符和子节点 map，叶子节点存倒排列表偏移量。公共前缀共享节点，省内存。FST 方案更省但实现更复杂，用前缀树就行。

查找操作——精确查找：给定一个词，遍历前缀树字符路径，走到末尾的节点就是结果，返回偏移量。前缀查找：给定前缀 "go"，先走到 'g'→'o' 的节点，然后 DFS 收集所有子孙节点对应的词项。结果按字典序排列。

有序遍历——对前缀树做中序遍历（DFS 按字符顺序访问子节点），输出所有词项和偏移量，天然就是字典序。

序列化——把前缀树序列化成二进制格式写入文件。节点序列化：字符 + 子节点数量 + 子节点偏移量列表 + 是否有值的标记 + 值。加载时从文件读入反序列化。序列化后的文件要明显比 JSON 小。

Go 标准库，go build 通过。内存占用要比 map[string]int64 小至少 30%，前缀查找的时间复杂度 O(k + m)，k 是前缀长度，m 是匹配词项数。
