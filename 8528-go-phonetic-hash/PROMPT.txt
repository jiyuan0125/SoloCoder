用户注册时填的姓名五花八门——"Smith"、"Smythe"、"Smyth" 其实是同一个姓，但数据库里存了三条记录。语音哈希（Phonetic Hash）就是把发音相似的词映射到同一个编码，用来做模糊去重和匹配。

用 Go 实现两种语音哈希算法——

Soundex 算法（1900 年代的经典，超级简单）。规则：保留首字母；B/F/P/V 编码为 1，C/G/J/K/Q/S/X/Z 编码为 2，D/T 编码为 3，L 编码为 4，M/N 编码为 5，R 编码为 6；去掉 A/E/I/O/U/H/W/Y；相邻相同编码去重；补零或截断到 4 个字符。比如 "Robert" → "R163"，"Rupert" → "R163"。

Metaphone 算法（Soundex 的改进版，区分度更高）。规则更细致：处理了更多英语发音的特例，比如 "gn" 开头的 g 不发音、"ck" 的 c 不发音、th 编码为 0 等等。输出是字母组成的编码（不是数字）。比 Soundex 更精确但实现也更复杂。

功能：输入一个单词，输出 Soundex 编码和 Metaphone 编码。也支持批量编码——输入一个词列表，输出每个词的两种编码。查找发音相似的词——给定一个目标词和候选列表，返回编码相同的所有候选词。

只处理英文字母，非字母字符跳过或报错。大写小写都能处理，内部统一转大写。Go 标准库，go build 通过。
