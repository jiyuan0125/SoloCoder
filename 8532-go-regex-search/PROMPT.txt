文档库里做全文检索，有时候关键词搜索不够用——用户想搜 "版本号是 v2.x.x 的记录"，这种模式得用正则。但正则匹配很慢，拿正则去扫百万篇文档不现实。解决方案是先从正则表达式里提取出必须出现的字面量子串，用字面量去倒排索引里快速过滤出候选文档，只对候选文档做完整正则匹配。

1. 正则表达式解析。把正则解析成 AST。支持的基本语法：字面量字符、.（任意字符）、*（零次或多次）、+（一次或多次）、?（零次或一次）、[]（字符类）、()（分组）、|（选择）。不需要支持反向引用和环视这些高级特性。用递归下降或者直接用 regexp 包的 syntax 子包解析。

2. 字面量提取。遍历正则 AST，收集所有必须出现的字面量子串。比如 "hello.*world" 提取出 "hello" 和 "world"。选择分支 (foo|bar) 各自独立提取。字符类 [abc] 没有固定字面量，跳过。提取结果是一组字面量列表，列表中的每个字面量都必须在文档中出现。

3. 候选过滤。用提取出的字面量去倒排索引中查，对所有字面量的倒排列表求交集，得到候选文档集合。

4. 完整匹配。对候选文档逐个用 Go 的 regexp 包做完整正则匹配，确认匹配并返回结果。

Go 标准库（regexp 包做最终匹配），go build 通过。字面量预过滤要显著减少需要完整正则匹配的文档数量。
