搜索引擎要支持组合查询，比如用户输入 "golang AND (web OR api) NOT python"，系统要解析这个表达式，在倒排索引上执行对应的集合运算，返回匹配的文档。

实现流程——

第一步，查询解析。把查询字符串解析成 AST（抽象语法树）。支持的操作符：AND（交集）、OR（并集）、NOT（差集）。支持括号嵌套改变优先级。也支持简写：+ 表示 MUST（等同于 AND）、- 表示 MUST_NOT（等同于 NOT 后取差集）。操作符优先级：NOT > AND > OR，括号最高。

第二步，AST 求值。对 AST 递归求值——叶节点是单个关键词，去倒排索引查对应的文档 ID 集合；AND 节点对左右子树的结果求交集；OR 节点求并集；NOT 节点比较特殊，有 NOT A AND B 这种情况时，NOT A 取全文档集合减去 A 的结果。

第三步，集合运算实现。交集用双指针归并（两边都是有序的 docID 列表）；并集类似归并取两边所有元素；差集从左边去掉右边有的元素。如果实现了 Posting List 的迭代器接口，集合运算可以流式进行，不需要把所有文档 ID 加载到内存。

第四步，结果处理。返回匹配的文档 ID 集合，有序去重。也返回每个文档匹配了哪些查询词（高亮用）。

Go 标准库，go build 通过。解析器要处理空白符和操作符的各种组合，比如 "a AND b" 和 "a b"（隐式 AND）。
