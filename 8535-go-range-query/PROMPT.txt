商品搜索里用户经常要按价格范围筛选——"100 到 500 之间"、"大于 200"、"2024 年之后上架的"。纯文本搜索处理不了这种需求，得在倒排索引旁边额外维护一份数值字段的有序索引，做范围过滤的时候用二分查找快速定位。

用 Go 实现范围查询模块。

先说数值范围过滤。给文档增加数值字段（比如 price、date）。维护一个按字段值排序的索引：FieldIndex = []struct{ Value float64; DocID uint32 }。范围查询时在 FieldIndex 上做二分查找，找到 [lower, upper] 区间内的所有 docID。支持开区间和闭区间：>、>=、<、<=、[lower, upper]、(lower, upper)。

日期范围过滤——日期字段存为时间戳（int64）或标准格式字符串（"2024-01-15"）。支持常见的日期格式：YYYY-MM-DD、YYYY/MM/DD、带时间的 YYYY-MM-DD HH:mm:ss。日期范围查询先转成时间戳再做数值比较。

和文本搜索的结合——先做文本查询得到候选文档集合，再做范围过滤缩小结果。范围过滤不能全表扫描，必须利用 FieldIndex 的有序性做二分查找，时间 O(log n + k)。

字段值缺失的文档——可以当作不匹配（排除），也可以由调用方决定怎么处理。提供一个 MissingValueAction 选项。

Go 标准库，go build 通过。
