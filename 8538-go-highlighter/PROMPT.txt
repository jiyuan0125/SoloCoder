搜索结果里光返回文档 ID 不够直观，用户想看到关键词在文档的什么位置出现。类似 Google 搜索结果里那段带粗体的摘要——从长文档里截取最相关的一段话，把匹配词加粗显示。这个功能叫高亮（Highlighting）。

用 Go 实现搜索结果高亮器。

位置标记——给定文档原文和查询词列表，扫描原文找到每个查询词的出现位置。记录 (start, end) 字节偏移。同一个词出现多次都要记录。大小写不敏感匹配。

HTML 高亮——把每个匹配位置的原文用 <em> 标签（或 <b>，可配置）包裹。注意 HTML 转义——原文中的 < > & 等特殊字符要先转义（&lt; &gt; &amp;），然后再插入高亮标签，不能搞乱顺序。比如原文 "a < b & c" 搜索 "b" 应该输出 "a &lt; <em>b</em> &amp; c"。

智能摘要（Snippet）——如果文档超过指定长度（默认 200 字符），只截取包含最多匹配词的片段。算法：用滑动窗口在匹配位置上扫描，找匹配密度最高的窗口。匹配密度 = 窗口内的匹配词数 / 窗口长度。窗口边界尽量在句子断点（句号、空格）处截断。摘要前后加 "..." 表示截断。

短语高亮——如果查询是短语（连续的多个词），匹配位置相邻的词整体用一个标签包裹，不要每个词单独包裹。

Go 标准库，go build 通过。摘要算法不能简单截取前 N 个字符，要按匹配密度选择最佳片段。
