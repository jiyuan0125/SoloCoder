搜索引擎排序最基础的方法就是 TF-IDF——词在文档里出现次数越多、在整个文档集里越罕见，就越重要。虽然现在有 BM25 等更好的算法，但 TF-IDF 依然是理解搜索排序的起点。

实现步骤——

第一步，TF（词频）计算。一个词在文档中出现的频率 TF = count(word, doc) / total_words(doc)。也支持多种 TF 变体：原始频次 count(word)、对数 TF（1 + log(count)）、增强 TF（0.5 + 0.5 × count / max_count）。默认用增强 TF。

第二步，IDF（逆文档频率）计算。IDF = log(N / df)，N 是总文档数，df 是包含该词的文档数（文档频率）。词越罕见 IDF 越高。如果词在所有文档中都没出现过（df=0），IDF 的计算要避免除零——返回 0 或者一个极大值。

第三步，TF-IDF 评分。TF-IDF = TF × IDF。对给定查询和文档集合，先对查询分词，然后对每篇文档计算查询中每个词的 TF-IDF 并求和，得到文档的总分。按总分降序排列返回结果。

第四步，关键词提取。TF-IDF 也可以反过来用——对单篇文档，计算所有词的 TF-IDF 分数，分数最高的就是这篇文档的关键词。提供 Top-K 关键词提取功能。

Go 标准库，go build 通过。IDF 需要遍历整个文档集计算，可以预计算缓存。
