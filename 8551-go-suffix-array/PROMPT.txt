之前在做一个文本索引系统，需要快速定位子串在文本中的所有出现位置。暴力搜索是 O(n×m)，后缀数组可以做到 O(m log n)——先把所有后缀排序，然后用二分搜索找子串。构造后缀数组是重点，简单的 O(n log²n) 倍增法够用了，如果想追求极致可以用 SA-IS 做 O(n)。

用 Go 实现后缀数组的构造和查询。

倍增法构造——第一步，对每个字符计算初始排名（就是字符本身的序号）。第二步，每次把比较长度翻倍：第 k 轮比较的是 s[i..i+2^k) 和 s[j..j+2^k) 的字典序，用上一轮的两个排名 (rank[i], rank[i+2^(k-1)]) 作为排序键做基数排序。重复 log n 轮直到所有排名互不相同。时间 O(n log²n)，空间 O(n)。

二分搜索查询——给定子串 pattern，在后缀数组上做二分查找。比较时取 suffix[sa[mid]] 和 pattern 做字典序比较。找到第一个大于等于 pattern 的位置（lower_bound），然后从该位置开始线性扫描，找到所有以 pattern 为前缀的后缀。输出这些后缀在原文中的起始位置。

也实现 LCP 数组的构造——Kasai 算法，O(n) 时间。LCP[i] = suffix[sa[i]] 和 suffix[sa[i-1]] 的最长公共前缀长度。LCP 数组可以用来加速查询（不用逐字符比较）和找最长重复子串。

输入从文件或 stdin 读入文本字符串。边界：空串返回空数组，单字符返回 [0]。Go 标准库，go build 编译通过。
