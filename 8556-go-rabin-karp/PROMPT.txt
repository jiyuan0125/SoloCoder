文档去重系统需要快速判断一段文本是不是抄袭了另一段。暴力做法是对每两个文档算编辑距离，O(n²×m²) 完全不可行。Rabin-Karp 的滚动哈希能快速计算文本窗口的哈希值，滑动窗口时 O(1) 更新，非常适合做文档指纹和去重。

用 Go 实现一个完整的 Rabin-Karp 字符串搜索工具。

滚动哈希——用多项式哈希：H = c₀×base^(m-1) + c₁×base^(m-2) + ... + c_{m-1}，base 选一个质数（如 101 或 256），对一个大质数取模（如 10^9+7）。窗口滑动时：H_new = (H_old - c_out × base^(m-1)) × base + c_in。减去离开字符的贡献，乘以 base 左移一位，加上新进入的字符。每步 O(1)。

单模式串搜索——先算模式串的哈希值，然后在主串上用相同长度的滑动窗口计算哈希。哈希相等时做逐字符验证（防止碰撞）。找到所有匹配位置并输出。

多模式串搜索——扩展到同时搜索多个模式串。对每个模式串算哈希，存在一个 map[uint64][]patternIndex 里。滑动窗口时查 map，命中后验证具体是哪个模式串匹配。

哈希碰撞处理——哈希相等不代表字符串相等，必须做逐字符验证。碰撞率取决于模数的大小——用 uint64 的自然溢出（不取模，让乘法自动溢出）碰撞率极低而且更快。

超长文本——哈希值用 uint64 不会溢出（自然溢出就是取模 2^64）。base 和 mod 要可配置。Go 标准库，go build 通过。
