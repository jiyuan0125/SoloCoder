Z 算法算 Z 函数的代码非常简洁，但它能解决很多字符串问题——子串搜索、字符串周期检测、最长公共前缀等。核心思想是：给定一个字符串 s，Z[i] 表示 s[i:] 和 s 的最长公共前缀长度。算出 Z 数组后很多问题迎刃而解。

用 Go 实现 Z 算法及其应用。

Z 数组计算——维护一个 Z-box [l, r]，表示当前已知的最右端以 l 开头且与 s 前缀匹配的区间。对每个位置 i：如果 i <= r，可以利用已经计算过的 Z[i-l] 来加速（因为 s[i..r] 和 s[i-l..r-l] 相同）。如果 Z[i-l] < r-i+1，直接 Z[i] = Z[i-l]。否则从 r+1 开始逐字符扩展。如果 i > r，从 i 开始逐字符和前缀比较。整个算法 O(n) 时间。

子串搜索——把模式串 pattern 和主串 text 用特殊字符（如 '#'）拼接成 pattern + '#' + text，计算 Z 数组。Z[i] == len(pattern) 的位置就是匹配的起始点（偏移要减去 pattern 长度 +1）。

字符串周期——一个字符串的最小周期 T 满足 s[i] == s[i+T] 对所有 i 成立。判断方法：如果 len(s) - Z[T] == T（T 整除 len(s)），则 T 是一个周期。找最小周期就找满足条件的最小 T。

空串返回空数组。O(n) 时间搞定。Go 标准库，go build 能编译通过。
