拼写检查器的核心就是编辑距离——两个字符串之间最少需要几次单字符操作（插入、删除、替换）才能互相转换。这个值直接反映拼写相似度。不过只算出距离值不够，还需要回溯出具体的操作序列——告诉用户 "把第 3 个字符从 a 改成 b"。

实现步骤——

第一步，DP 表构建。建一个 (m+1)×(n+1) 的二维表 dp，m 和 n 分别是两个字符串的长度。初始化：dp[0][j] = j（空串变成长度 j 的串需要 j 次插入），dp[i][0] = i。递推：dp[i][j] = min(dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1]+cost)。cost = 0 如果 s[i-1]==t[j-1]，否则 cost = 1。结果 dp[m][n] 就是最小编辑距离。

第二步，操作序列回溯。从 dp[m][n] 开始反向追踪。如果 dp[i][j] 来自 dp[i-1][j]+1，说明做了一次删除（删掉 s[i-1]）。如果来自 dp[i][j-1]+1，说明做了一次插入（插入 t[j-1]）。如果来自 dp[i-1][j-1]+cost，cost=0 说明字符相同不需要操作，cost=1 说明做了一次替换。按从右到左的顺序记录操作，最后反转为从左到右。

第三步，输出格式。每步操作格式："位置 X: 插入 'c'"、"位置 X: 删除 'c'"、"位置 X: 将 'a' 替换为 'b'"。也输出一个类似 diff 的对齐视图，上下两行展示字符串的对齐关系，用 | 表示匹配、+ 表示插入、- 表示删除、^ 表示替换。
