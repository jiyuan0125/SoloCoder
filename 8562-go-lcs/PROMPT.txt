版本对比系统底层需要找两个序列的最长公共子序列（LCS）。注意子序列和子串不一样——子序列不要求连续，只要保持原始顺序就行。比如 "ABCBDAB" 和 "BDCAB" 的 LCS 是 "BCAB"，长度 4。

1. 经典 DP 解法。建一个 (m+1)×(n+1) 的二维表 dp。dp[i][j] = s[:i] 和 t[:j] 的 LCS 长度。递推：如果 s[i-1]==t[j-1]，dp[i][j] = dp[i-1][j-1]+1；否则 dp[i][j] = max(dp[i-1][j], dp[i][j-1])。时间 O(mn)，空间 O(mn)。

2. LCS 内容回溯。从 dp[m][n] 开始反向追踪。如果 s[i-1]==t[j-1]，这个字符属于 LCS，加入结果然后 i--, j--。否则往 dp 值更大的方向走（dp[i-1][j] 或 dp[i][j-1]）。追踪完后反转为正序。结果就是具体的 LCS 内容。

3. 空间优化。如果只需要长度不需要具体内容，dp 表只需要两行（当前行和上一行），空间降到 O(min(m,n))。提供一个只返回长度的函数 LCSLength(s, t) int。

4. 通用序列支持。不只是字符串，也支持任意类型数组的 LCS。用 Go 泛型或者接受 reflect.DeepEqual 做比较。

能把 DP 表打印出来方便理解过程——用 fmt.Printf 输出一个对齐的数字矩阵。空输入的边界：空串和任何串的 LCS 长度都是 0。Go 标准库，go build 编译通过。
