想做一个简单的 diff 工具来比较两段文本的差异——类似 git diff 的效果。底层原理很简单：先把两个文本按行切成行数组，然后用 LCS 找出公共行，剩下的行就是差异。

用 Go 实现基于 LCS 的文本差异比较。

输入处理——读入两个文件，按换行符切分成行数组 lines1 和 lines2。每行保留原始内容（包括空行），行号从 1 开始。

LCS 求差异——对 lines1 和 lines2 求 LCS。LCS 中的行是两个文件共有的（标记为 " "，不变）。只在 lines1 中的行是删除的（标记为 "-"）。只在 lines2 中的行是新增的（标记为 "+"）。

输出格式——类似 unified diff 的格式。对差异的行组输出上下文（前后各 3 行不变的行）。每组差异前面加一行 "@@ -start,count +start,count @@" 标记位置范围。删除行前面加 "-"，新增行前面加 "+"，不变行前面加 " "。

处理特殊情况——两个空文件完全相同，输出 "文件相同"。一个文件为空另一个不为空，所有行都是新增或删除。行数很多的大文件别爆内存——如果超过 10000 行可以只显示差异部分不显示全部内容。

Go 标准库，go build 能编译通过。输出要人能看懂，方便代码审查。
