推荐系统的首页展示要从几百个候选内容中按权重随机选几个——热门内容权重高更容易被选中，但小众内容也要有机会。加权随机抽样和均匀抽样不一样：每个元素有不同的权重，选中概率和权重成正比。

用 Go 实现加权随机抽样。

两种模式——可放回抽样：每次抽完放回去，同一个元素可以被多次选中。用前缀和 + 二分搜索实现。先算权重的前缀和 prefix[i] = w[0]+w[1]+...+w[i]，然后生成一个 [0, total_weight) 的随机数，在前缀和数组上二分查找确定落在哪个区间。每次抽样 O(log n)。不可放回抽样：抽完不放回，每个元素最多选一次。

Alias Method 优化——多次可放回抽样用 Alias Method 可以把每次抽样降到 O(1)。预处理阶段：把权重归一化，构建两个数组——prob[i] 和 alias[i]。prob[i] 是第 i 个桶的原概率，alias[i] 是溢出到哪个桶。预处理 O(n)，每次抽样 O(1)。对需要从同一组候选中反复抽样的场景特别高效。

边界处理——权重为 0 的项永远不被选中。所有权重都是 0 的输入返回空结果。k 大于元素数量时（不可放回模式）返回所有元素。权重为负数报错。

API 设计——WeightedSample(items []T, weights []float64, k int, replace bool) []T。也提供命令行工具。Go 标准库，go build 通过。
