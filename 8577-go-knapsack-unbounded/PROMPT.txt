零钱兑换其实就是完全背包——每种硬币数量无限，要用最少的硬币凑出指定金额。或者换个角度：每种物品可以选多次，在容量限制内让价值最大。完全背包和 0-1 背包的 DP 表长得很像，唯一的区别在于内层循环的方向。

1. 完全背包 DP。dp[i][w] = max(dp[i-1][w], dp[i][w-weight[i]] + value[i])。注意第二个不是 dp[i-1] 而是 dp[i]——因为选了第 i 件之后，第 i 件还可以再选。体现在一维数组上就是内层循环正向遍历（从 weight[i] 到 W），而不是 0-1 背包的倒向遍历。

2. 求解方案。除了最大价值，还要输出每种物品选了几个。用一个额外的 count 数组记录每个容量对应的物品选择数量。回溯时根据 count 还原选择方案。

3. 零钱兑换应用。给定硬币面额列表 coins 和目标金额 amount，求最少硬币数。dp[w] = min(dp[w], dp[w-coin]+1)。如果 dp[amount] 仍然是初始值（无穷大）说明凑不出来，明确提示。

4. 空间优化版本。展示一维数组的写法，只用 O(W) 空间。两种写法都要提供，方便对比理解。

物品数量为 0 返回 0 价值。容量为 0 返回 0。Go 标准库，go build 编译通过。
