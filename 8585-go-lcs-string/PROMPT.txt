代码查重系统要比较两个文件的相似度——最长的公共代码片段有多长？注意这次是最长公共子串（substring），要求连续，和最长公共子序列（subsequence）不一样。暴力做法 O(n²×m) 每个起始位置逐字符比较，太慢了。后缀数组或后缀自动机可以做到 O(n+m)。

用 Go 实现最长公共子串查找。

后缀数组方法——把两个字符串用特殊字符（ASCII 0 或 '#'）拼接，然后构建后缀数组。在后缀数组上找相邻两个来自不同字符串的后缀，计算它们的 LCP（最长公共前缀）。LCP 的最大值就是最长公共子串的长度，对应的子串就是答案。时间 O((n+m) log(n+m)) 用于构建后缀数组，加上 O(n+m) 用于 LCP 计算。

DP 方法作为对照——建一个 (m+1)×(n+1) 的二维表 dp。dp[i][j] = 以 s1[i-1] 和 s2[j-1] 结尾的最长公共子串长度。如果 s1[i-1]==s2[j-1]，dp[i][j] = dp[i-1][j-1]+1。否则 dp[i][j] = 0。扫描整个表找最大值。时间 O(mn)，空间 O(min(m,n))。

也支持找所有长度 >= L 的公共子串——不只找一个最长的，找所有达到指定长度的公共子串。结果去重（相同的子串只出现一次）。

空串返回空结果。没有公共子串（两个字符串完全不同字符集）也正确处理。Go 标准库，go build 通过。
