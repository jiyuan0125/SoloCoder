扑克牌的 patience sorting 玩法——把牌一张张放到最左边的可以放的牌堆上（牌堆顶部值比当前牌小），找不到就新开一堆。最后牌堆的数量就是最长递增子序列的长度。这个直觉可以转化为一个 O(n log n) 的 LIS 算法。

1. O(n log n) 二分搜索版本。维护一个 tails 数组，tails[i] 表示长度为 i+1 的递增子序列的末尾元素的最小值。遍历输入数组，对每个元素 x 在 tails 中用二分查找找到第一个 >= x 的位置并替换。如果 x 比所有 tails 都大就追加。最终 tails 的长度就是 LIS 长度。用 sort.SearchInts 做二分查找。

2. 回溯具体序列。光知道长度不够，还要输出一个具体的 LIS。用一个 prev 数组记录每个元素的前驱索引。回溯时从最长子序列的末尾开始反向追踪。最终反转得到 LIS。注意可能存在多个等长 LIS，输出其中一个即可。

3. O(n²) DP 版本。dp[i] 表示以第 i 个元素结尾的 LIS 长度。dp[i] = 1 + max(dp[j]) 对所有 j<i 且 arr[j]<arr[i]。这个版本更直观但更慢，作为对照实现。

4. 严格与非严格递增。严格递增（<）和非严格递增（<=）两种模式都支持。通过参数选择。

空序列返回长度 0。全相同元素的序列严格递增 LIS 长度为 1，非严格 LIS 长度为 n。从文件或命令行读数据。Go 标准库，go build 通过。
