中文分词的后处理阶段有个问题——给定一个字符串和一个词表，怎么判断这个字符串能不能被完全切分成词表中的词？更进一步，如果能切分，有几种切法？比如 "catsanddog" 用词表 {cat, cats, and, sand, dog} 可以切成 "cats and dog" 和 "cat sand dog" 两种。

用 Go 实现 Word Break 问题。

可行性判断——dp[i] 表示 s[:i] 能否被切分。dp[0] = true（空串可以被切分）。对每个位置 i 从 1 到 n，遍历所有 j < i，如果 dp[j] 为 true 且 s[j:i] 在词表中，dp[i] = true。时间 O(n²)。词表用 map[string]bool 存储，查找 O(1)。

所有切分方案——先 DP 判断可行性，如果可行再用回溯找出所有方案。DFS(s, start, path)：如果 start == len(s)，找到一个方案，把 path 加入结果。否则遍历所有可能的 end，如果 s[start:end] 在词表中就递归搜索 end 位置。用 DP 结果剪枝——如果 dp[end] 为 false 就不用继续了。

词典加载——从文件按行读取，每行一个词。也支持从命令行参数直接传入。空串返回一个空方案 [[]]。空词典（没有可用词）返回空结果 []。

结果输出——每种切分方案用空格连接词，每行输出一种方案。总方案数也打印。Go 标准库，go build 通过。
