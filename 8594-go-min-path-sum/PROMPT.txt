机器人从网格左上角走到右下角，每个格子有个通过代价，只能往右或往下走，找总代价最小的路径。这是动态规划的经典入门题，也是很多路径规划问题的简化版本。

实现步骤——

第一步，DP 求解。dp[i][j] 表示从 (0,0) 到 (i,j) 的最小代价路径。递推：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])。第一行只有从左边来一种选择：dp[0][j] = dp[0][j-1] + grid[0][j]。第一列只有从上面来：dp[i][0] = dp[i-1][0] + grid[i][0]。

第二步，路径回溯。从终点 (m-1, n-1) 反向追踪——每步看是从上方来还是左方来（哪个 dp 值小），记录方向。追踪到起点后反转为正向路径。输出路径坐标列表，比如 [(0,0), (0,1), (1,1), (2,1), (2,2)]。

第三步，空间优化。dp 表只需要当前行和上一行（因为 dp[i][j] 只依赖 dp[i-1][j] 和 dp[i][j-1]），空间从 O(mn) 降到 O(n)。如果需要回溯路径则保留完整的 dp 表。

第四步，输入和输出。从文件读取网格数据（CSV 或空格分隔），每行一行数字。输出最小代价和具体路径。单行或单列的矩阵直接累加。

网格大小可以到 1000×1000，空间优化版本要注意。Go 标准库，go build 通过。
