分析股票收益序列，想找一段连续区间使得收益之和最大。这就是最大子数组问题（Kadane 算法）——听起来简单，但面试和竞赛里都是高频考点。算法本身只要一遍扫描 O(n)，但要正确处理全负数的情况。

用 Go 实现最大子数组问题。

Kadane 算法——维护两个变量：currentSum（以当前位置结尾的最大子数组和）和 maxSum（全局最大）。遍历数组，每步 currentSum = max(arr[i], currentSum + arr[i])——要么从当前位置重新开始，要么延续之前的子数组。maxSum = max(maxSum, currentSum)。一遍扫描完成。

同时记录起止位置——维护 currentStart 变量。当 currentSum 从 arr[i] 重新开始时，currentStart = i。当 maxSum 更新时，记录 bestStart = currentStart, bestEnd = i。输出最大和以及子数组 [bestStart, bestEnd]。

全负数的情况——数组里全是负数时，最大子数组就是最大的那个负数（绝对值最小的）。比如 [-3, -1, -2] 的最大子数组是 [-1]，和为 -1。Kadane 算法天然能处理这种情况（因为 currentSum 会从 arr[i] 重新开始而不是加上一个更小的负数）。

分治版本——O(n log n) 的分治解法：最大子数组要么在左半边、要么在右半边、要么跨中点。跨中点的情况从中点向两边扩展找最大和。虽然更慢但提供了不同的思路。也实现一下做对比。

空数组返回 0。Go 标准库，go build 通过。
