钢材批发业务有个优化问题——一根长 L 的钢管，可以切成不同长度出售，不同长度价格不一样。长度 1 卖 1 元、长度 2 卖 5 元、长度 3 卖 8 元...问题是：一根长 8 的钢管怎么切最赚钱？也许不切整根卖更贵，也许切成 2+2+2+2 利润更高。

用 Go 实现钢条切割问题。

DP 解法——price[i] 表示长度 i 的售价。dp[n] 表示长度为 n 的钢管的最大收益。递推：dp[n] = max(price[i] + dp[n-i]) 对所有 1 ≤ i ≤ n。意思是：第一刀切下长度 i，卖 price[i]，剩下的 n-i 继续切获得 dp[n-i]。也包括 i=n 的情况（不切整根卖）。自底向上计算，从 dp[0]=0 开始填到 dp[n]。时间 O(n²)。

回溯切割方案——用一个 choice 数组记录 dp[n] 取最大值时的 i（第一刀切下多长）。从 n 开始：切下 choice[n] 长度，然后 n -= choice[n]，继续切直到 n=0。输出切割方案：比如 "切成 2+2+2+2，总收益 20"。

扩展版本——每次切割有固定成本 c。比如每切一刀成本 2 元。递推变成 dp[n] = max(price[n], max(price[i] + dp[n-i] - c)) 对所有 1 ≤ i < n。只有实际切了一刀才扣成本，整根卖不扣。

输入价格表和总长度，输出最大收益和最优切割方案。长度为 0 收益为 0。Go 标准库，go build 编译通过。
