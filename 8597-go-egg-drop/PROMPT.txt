LeetCode hard 题里的常客：k 个鸡蛋、n 层楼，最少抛几次能确定鸡蛋从哪层开始会碎？如果只有 1 个鸡蛋，只能从 1 楼开始逐层试，最坏 n 次。如果鸡蛋无限，二分搜索 log₂n 次。k 个鸡蛋的情况介于两者之间，需要 DP 来优化。

1. 基础 DP。dp[k][n] 表示 k 个鸡蛋 n 层楼的最少抛掷次数。dp[k][n] = 1 + min(max(dp[k-1][i-1], dp[k][n-i])) 对所有 1 ≤ i ≤ n。含义：在第 i 层抛一次，碎了就剩 k-1 个鸡蛋、i-1 层楼要试；没碎就剩 k 个鸡蛋、n-i 层楼要试。取最坏情况，然后在所有 i 中取最优。时间 O(k×n²)。

2. 二分优化。内层的 min(max(...)) 关于 i 是个谷形函数（左半 dp[k-1][i-1] 递增、右半 dp[k][n-i] 递减），可以用二分搜索代替线性枚举，时间降到 O(k×n×log n)。

3. 反向思路。把问题转换成：k 个鸡蛋、最多抛 m 次，最多能测多少层楼？dp[k][m] = dp[k-1][m-1] + dp[k][m-1] + 1（碎了测下面 dp[k-1][m-1] 层，没碎测上面 dp[k][m-1] 层）。找到最小的 m 使 dp[k][m] >= n。这个方法避免了大 n 导致的超时问题。

4. 边界。k=1 答案是 n。n=0 答案是 0。n=1 答案是 1。Go 标准库，go build 通过。
