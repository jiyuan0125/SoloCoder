爬楼梯问题人人都会——每次走 1 或 2 步，到第 n 阶有几种走法？答案就是斐波那契数列。但面试官不会这么简单就放过你，他们会加各种限制：某些台阶是坏的不能踩、每次可以走 1 到 k 步、结果要对 10^9+7 取模。

用 Go 实现爬楼梯问题并支持各种扩展。

基础版——dp[n] = dp[n-1] + dp[n-2]，dp[0]=1, dp[1]=1。结果就是 Fib(n+1)。用迭代不用递归避免栈溢出。

自定义步长——每次可以走 steps 集合中的步数（比如 {1, 2, 3}）。dp[n] = Σ dp[n-s] 对所有 s 在 steps 中且 s ≤ n。通用化斐波那契。

坏台阶——某些台阶不能踩（用 bool 数组 broken 标记）。dp[n] = 0 如果第 n 阶是坏的。否则 dp[n] = Σ dp[n-s]（和上面一样，但跳过坏台阶）。如果第 0 阶也是坏的，直接返回 0。

取模输出——n 很大时结果可能超过 int64。加一个 mod 参数（默认 10^9+7），每步加法后取模。这样 dp 值始终在范围内。

边界——n=0 返回 1（原地不动也算一种走法）。n<0 返回 0。steps 为空返回 0。所有台阶都是坏的返回 0。

用迭代不用递归，数组大小 O(n)。Go 标准库，go build 通过。
