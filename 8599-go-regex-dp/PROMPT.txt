正则表达式引擎的实现方式有两种：NFA/DFA 自动机和 DP。这里用 DP 来实现一个简化版的正则匹配——只支持 .（匹配任意单个字符）和 *（匹配前一个字符零次或多次）。虽然功能简单，但 DP 的思路和完整正则引擎是相通的。

实现步骤——

第一步，定义状态。dp[i][j] 表示文本 s[:i] 和模式 p[:j] 是否匹配。布尔值。dp[0][0] = true（空文本匹配空模式）。

第二步，初始化。dp[0][j] 的处理：如果 p[j-1] 是 '*'，那它可以消掉前一个字符，dp[0][j] = dp[0][j-2]（跳过 x* 两个字符）。否则 dp[0][j] = false。比如模式 "a*b*" 可以匹配空文本。

第三步，状态转移。如果 p[j-1] 是普通字符或 '.'：dp[i][j] = dp[i-1][j-1] && (s[i-1]==p[j-1] || p[j-1]=='.')。字符匹配或者 '.' 匹配任意字符，同时前面部分也要匹配。

如果 p[j-1] 是 '*'：两种可能——不用这个 x*（匹配零次）：dp[i][j] = dp[i][j-2]。用这个 x*（匹配一次或多次）：dp[i][j] = dp[i-1][j] && (s[i-1]==p[j-2] || p[j-2]=='.')。只要当前字符和 * 前面的字符匹配就行。

第四步，空间优化。dp 表只需要当前行和上一行，空间 O(m)。

空文本和非空模式的匹配：模式 "a*b*c*" 可以匹配空文本。非空文本和空模式不匹配。Go 标准库，go build 通过。
