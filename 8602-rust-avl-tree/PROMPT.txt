后端服务的内存索引需要保证最坏情况也是 O(log n)，普通 BST 在数据有序时会退化成链表。AVL 树是严格平衡的二叉搜索树——任何节点的左右子树高度差不超过 1，通过旋转来维持这个不变量。

1. 旋转操作。四种旋转：LL（左孩子的左子树过高）→ 右旋；RR（右孩子的右子树过高）→ 左旋；LR（左孩子的右子树过高）→ 先左旋左孩子再右旋当前节点；RL（右孩子的左子树过高）→ 先右旋右孩子再左旋当前节点。每次旋转后要更新相关节点的高度值。

2. 插入。标准 BST 插入，然后从插入点沿着 parent 指针往上回溯，更新高度并检查平衡因子。平衡因子 = 左子树高度 - 右子树高度。如果绝对值超过 1 就做对应的旋转。选择哪种旋转取决于不平衡的方向和插入发生在哪一侧。

3. 删除。标准 BST 删除（叶节点直接删、一个孩子的用孩子替代、两个孩子的用中序后继替代），然后同样从删除点往上回溯调整平衡。删除可能需要多次旋转（不像插入最多旋转一次）。

4. 查找和遍历。search 按标准 BST 查找。中序遍历输出有序序列。节点存 int key + 泛型 value，用 Box<Node> 持有子节点。

重复 key 的插入——用策略决定：忽略、替换旧值、或者用链表存多个值。边界：删空节点、删除不存在的 key。cargo build && cargo run 能看到测试结果。
