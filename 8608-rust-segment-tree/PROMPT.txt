数组区间查询的利器——线段树。想象一个场景：有一个长度几万的数组，经常要做"查区间 [3, 17] 的最大值"或者"查 [5, 10] 的和"这类操作，还要支持"把第 8 个位置的值改成 42"。朴素方法每次查询 O(n) 不行，线段树能做到查询 O(log n)、更新 O(log n)。

用 Rust 实现线段树。

构建——给定一个数组，递归自底向上建树。每个叶节点对应数组的一个元素，每个内部节点维护它所代表区间的聚合值（最大值/最小值/求和，选一种或都支持）。用数组存树（下标 i 的左孩子 2i+1，右孩子 2i+2）。build 时间 O(n)。

查询——query(l, r) 查询区间 [l, r] 的聚合值。从根开始递归：如果当前区间完全在 [l, r] 内，直接返回节点值。如果完全不重叠，返回单位元（max 的单位元是 -∞，sum 的是 0）。否则递归查询左右子树，合并结果。

更新——update(index, value) 把第 index 个位置改成 value。从根递归到对应的叶节点，更新叶节点值，然后沿着回溯路径更新所有祖先节点。

用泛型和 trait 实现聚合操作——定义 trait Monoid { fn unit() -> Self; fn combine(&self, other: &Self) -> Self; }。这样最大值、最小值、求和只要做不同的 Monoid。

数据量几万到几十万的级别。main 函数构造一个数组，建树后跑几组查询和更新，打印结果验证正确性。cargo run 能跑出来。
