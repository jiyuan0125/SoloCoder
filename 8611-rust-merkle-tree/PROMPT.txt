区块链和 Git 都用了同一个数据结构来验证数据完整性——Merkle Tree（默克尔树）。原理是：把数据块做哈希，两两组合再做哈希，层层往上直到只剩一个根哈希。任何一块数据被篡改，根哈希就会变，而且不需要全部数据就能验证某一块是否被改过——只需要那条路径上的哈希值（Merkle proof）。

用 Rust 实现一棵 Merkle Tree。

构建树——输入一组数据块（Vec<Vec<u8>> 或 Vec<&str>）。每个数据块用 SHA-256 哈希，得到叶节点的哈希值。然后两两配对，把两个哈希拼接后再 SHA-256 得到父节点的哈希。重复直到只剩一个根哈希。如果某一层有奇数个节点，最后一个直接提升到上一层（或者复制一份配对）。

获取根哈希——root_hash() 返回根节点的 [u8; 32]。任何数据块的变化都会导致根哈希不同。

生成 Merkle proof——给某个叶节点的索引，生成从该叶节点到根路径上所有兄弟节点的哈希值。proof 是一个 Vec<(bool, [u8; 32])>，bool 表示兄弟在左边还是右边。验证方不需要整棵树，只需要数据和 proof 就能算出根哈希。

验证 proof——给定数据块、proof 和声称的根哈希。从数据块的哈希开始，按 proof 里的方向依次和兄弟哈希组合再哈希，最后比较结果是否等于根哈希。

用 sha2 crate 或者手写一个简单的哈希函数（不追求安全性的话用简单的哈希也行，只要能演示原理）。main 里跑个 demo：构建树、获取 proof、验证、修改一个数据块后验证失败。cargo run 能看到结果。
