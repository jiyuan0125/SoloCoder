布隆过滤器有个致命缺点——不能删除元素。一旦插入就不能移除，因为一个 bit 位置可能被多个元素共享。布谷鸟过滤器解决了这个问题——每个元素存一个短指纹（fingerprint），删除时只需要去掉对应的指纹。空间效率也不比布隆过滤器差。

用 Rust 实现布谷鸟过滤器。

数据结构——一个固定大小的桶数组，每个桶存几个指纹（比如 4 个，每个指纹 8 bit）。总容量 = 桶数 × 每桶指纹数。两个哈希函数确定一个元素的候选桶：h1 = hash(x)，h2 = h1 XOR hash(fingerprint(x))。这样只要知道一个桶和指纹，就能算出另一个桶。

插入——计算指纹 fp 和两个候选桶 i1、i2。如果任一桶有空位，放入 fp。如果都满了，随机选一个桶踢出一个指纹，被踢的指纹找它的另一个桶放入。如果另一个桶也满了，继续踢。设置最大踢出次数（比如 500），超过就报错"过滤器满了"。

查找——计算 fp 和两个候选桶。检查两个桶中是否有 fp。有则返回 true（可能存在），没有则返回 false（一定不存在）。

删除——和查找类似，找到 fp 后从桶中移除。注意：删除后如果再查同一个元素应该返回 false。

Demo 对比布隆过滤器——同样的容量下对比空间占用和误判率。布谷鸟过滤器的优势是可以删除，劣势是实现更复杂。cargo build 通过，cargo run 打印对比结果。
