城市间的路线规划——给定一张有向带权图，从北京出发到所有其他城市的最短距离分别是多少？Dijkstra 算法是解决单源最短路径的经典方法，用优先队列优化后时间复杂度 O((V+E) log V)。

用 Rust 实现 Dijkstra 最短路径算法。

实现步骤——

第一步，图的表示。用邻接表存图：HashMap 或 Vec<Vec<(usize, f64)>>，每个节点的邻居列表存 (目标节点, 边权重)。从文件或硬编码读入图数据。

第二步，算法实现。初始化：dist[source] = 0，其他 dist[v] = f64::INFINITY。把 (0, source) 放入最小堆。循环：每次从堆中取出距离最小的节点 u。如果 dist[u] < 取出的距离说明是过期条目跳过。对 u 的每个邻居 v，如果 dist[u] + weight(u,v) < dist[v]，更新 dist[v]，记录 predecessor[v] = u，把 (dist[v], v) 放入堆。堆空时结束。

第三步，路径回溯。从目标节点沿 predecessor 数组反向追踪到源点，得到最短路径的节点序列。

第四步，负权检测。如果遇到负权边，Dijkstra 的贪心策略不保证正确——检测到负权时报错。不支持负权边。

输出从指定起点到所有可达节点的最短距离和路径。不可达的节点距离保持无穷大。cargo run 能打印最短路径结果。
