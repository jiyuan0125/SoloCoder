Dijkstra 不支持负权边——如果图里有负权边，它的贪心策略可能给出错误结果。Bellman-Ford 不挑食，负权边照样能算最短路径，还能检测负权环（如果一个图里有负权环，某些节点对之间的最短路径可以无限小）。

用 Rust 实现 Bellman-Ford 最短路径算法。

算法流程——初始化：dist[source] = 0，其他无穷大。进行 V-1 轮松弛：每轮遍历所有边 (u, v, weight)，如果 dist[u] + weight < dist[v]，更新 dist[v] = dist[u] + weight，记录 predecessor[v] = u。V-1 轮后最短路径一定收敛（因为最短路径最多经过 V-1 条边）。

负权环检测——做完 V-1 轮后再做一轮额外松弛。如果还有边能松弛（dist[u] + weight < dist[v]），说明存在负权环——可以通过这个环无限降低路径权重。检测到负权环就报错提示。

输入格式——从文件或命令行读入图的边列表，格式 "起点 终点 权重"。用 Vec<(usize, usize, f64)> 存边列表。

输出——如果无负权环，输出从源点到各点的最短距离和路径。如果有负权环，报告哪些节点受影响（在负权环可达范围内的节点没有最短路径）。

测试用例——包含有负权边但无负权环的图（算法正常工作），和有负权环的图（算法检测到并报告）。cargo run 能看到正确输出。
