网络延迟分析有个需求——知道任意两个服务器之间的最短延迟。Dijkstra 和 Bellman-Ford 都是单源最短路径（一个起点到其他所有点），要算所有点对就得跑 N 次。Floyd-Warshall 直接一次搞定全源最短路径，虽然 O(V³) 但代码超级简单——三重循环。

用 Rust 实现 Floyd-Warshall。

输入——一个有向带权图的邻接矩阵。dist[i][j] = 直接边的权重，没有边就设为 f64::INFINITY，dist[i][i] = 0。节点数几百个以内（太大就太慢了）。

三重循环——外层循环 k 从 0 到 V-1（中间节点），内层双重循环 i, j：dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])。每一轮 k 都尝试通过 k 作为中转来缩短 i 到 j 的路径。V 轮结束后 dist[i][j] 就是最短距离。

负权环检测——算法结束后检查 dist[i][i] 是否有负值。如果有，说明从 i 出发经过一个负权环可以回到 i 且总权重为负，即存在负权环。

前驱矩阵——如果需要输出具体路径，维护一个 next[i][j]：从 i 到 j 最短路径的下一个节点。初始化 next[i][j] = j（如果有直接边）。更新时如果通过 k 中转更短，next[i][j] = next[i][k]。路径重建：从 i 开始，沿 next 走到 j。

输出完整的距离矩阵。写个 demo 读入一个示例图，打印所有节点对的最短距离。cargo run 能输出矩阵。
