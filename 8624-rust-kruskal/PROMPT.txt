网络布线要把所有办公室连通，但线路有成本。怎么选线才能让所有办公室连通且总成本最低？这就是最小生成树问题——在连通无向图中选 n-1 条边连通所有节点，使总权重最小。Kruskal 算法用贪心策略解决。

用 Rust 实现 Kruskal 最小生成树算法。

实现步骤——

第一步，边排序。把所有边按权重从小到大排序。

第二步，并查集初始化。每个节点初始时自成一个集合。实现 find（带路径压缩）和 union（按秩合并）操作。

第三步，贪心选边。从最小权重的边开始，对每条边 (u, v, w)：如果 find(u) != find(v)（u 和 v 不在同一个连通分量），就选这条边加入生成树，然后 union(u, v)。如果已经在同一分量就跳过（加入会形成环）。

第四步，终止条件。选够 n-1 条边就停止（n 个节点的最小生成树恰好有 n-1 条边）。

图的输入——从文件或硬编码，格式每行 "节点1 节点2 权重"。输出选中的所有边和总权重。

验证：选出的边数 = 节点数 - 1。用并查集检查所有选出的边确实把所有节点连通了。

写个 demo 在一个 10 节点左右的图上跑，打印选出的边和总代价。cargo build 通过，cargo run 有结果。
