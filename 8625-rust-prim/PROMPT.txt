Kruskal 从边出发贪心选，Prim 从一个点出发逐步扩展。两种方法结果一样（同一棵最小生成树）但思路不同。Prim 用优先队列优化后时间 O(E log V)，适合稠密图。

用 Rust 实现 Prim 最小生成树算法。

从一个任意起点开始，维护一个候选边集合（优先队列）。每步从候选边中取权重最小的，如果这条边连接了一个还没加入生成树的新节点，就把它加入生成树，同时把新节点的所有出边加入候选集。重复直到所有节点都被覆盖。

优先队列用 BinaryHeap（Rust 标准库）实现，存 (weight, from, to)。注意 Rust 的 BinaryHeap 是最大堆，要包装成 Reverse 来做最小堆。

图不连通的处理——如果算法结束后加入生成树的节点数 < 总节点数，说明图不连通，无法生成完整 MST。给出提示。

输出构成最小生成树的所有边和总权重。和 Kruskal 结果对照应该一致（总权重相同，但具体选的边可能不同）。

从文件读取图的边数据（邻接表格式）。打印最小生成树。cargo run 能看到生成树的边和权重。

测试——10000 个随机读写操作序列，验证 B+ 树中序遍历有序。插入后删除再插入，验证结构正确不丢失数据。和标准库排序结果对比。
