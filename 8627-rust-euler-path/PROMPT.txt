哥尼斯堡七桥问题——能不能每座桥恰好走一次？这就是欧拉路径问题：在一个图中，能不能找到一条恰好经过每条边一次的路径？如果起点和终点相同就是欧拉回路。

1. 判断条件。无向图：连通的前提下，奇数度节点为 0 个 → 存在欧拉回路（从任意点出发）；奇数度节点为 2 个 → 存在欧拉路径（从一个奇数度节点出发到另一个）；其他情况不存在。有向图：所有节点入度等于出度 → 欧拉回路；恰好一个节点出度-入度=1（起点）和一个入度-出度=1（终点）→ 欧拉路径。

2. Hierholzer 算法构造路径。从起点开始 DFS，每走一条边就删掉这条边（或标记为已用）。当某个节点没有未用的边时，把它加入路径。DFS 回溯时路径自然就拼好了。最后反转路径得到正确顺序。

3. 输出。对几个测试图分别运行：一个有欧拉回路的图（比如一个环上加点），输出回路。一个只有欧拉路径的图，输出路径。一个不存在欧拉路径的图，提示不存在并说明原因。

4. 边的表示。用邻接表，删除边可以用 drain 或者标记 visited。注意 Hierholzer 算法要在没有未访问边的时候才把节点加入路径，不是在访问的时候。
