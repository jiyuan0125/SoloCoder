网络带宽分配场景：数据中心的链路有容量上限，要从源服务器传数据到目标服务器，最大能传多少？最大流问题。Ford-Fulkerson 方法用增广路径不断往网络里"灌水"，直到灌不进去为止。

用 Rust 实现网络最大流算法。

Edmonds-Karp 实现——Ford-Fulkerson 方法配合 BFS 找增广路径。BFS 保证找到的增广路径是最短的（边数最少），时间复杂度 O(V×E²)。

残留图——每条边有容量 capacity 和当前流量 flow。正向残留容量 = capacity - flow，反向残留容量 = flow（用于"退回"流量）。BFS 在残留图上找从源点到汇点的路径，路径上的最小残留容量就是这轮能增加的流量。

主循环——不断用 BFS 在残留图上找增广路径。找到后计算路径瓶颈（最小残留容量），沿路径更新正向边的流量增加、反向边的流量减少。找不到增广路径时结束，当前的总流量就是最大流。

输出——最大流量值，以及每条边上的实际流量。验证：源点出发的总流量 = 到达汇点的总流量 = 最大流。中间节点的流入 = 流出。流量不超过容量。

写个 demo 跑一个经典示例图（6-8 个节点），验证结果正确。cargo run 能打印最大流值和边的流量分配。
