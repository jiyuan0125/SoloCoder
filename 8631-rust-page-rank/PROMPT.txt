搜索结果的排名到底怎么算？Google 用 PageRank 给网页按重要性排序——被很多重要网页链接的网页自己也重要。这是一种"你被谁引用了"的传递模型：每个网页把一部分分数（rank）均分给出链指向的页面，迭代到收敛。

用 Rust 实现 PageRank 算法。

输入一组网页和它们之间的链接关系（有向图），用邻接表表示。每条边 u→v 表示网页 u 有一条链接指向 v。

幂迭代法——初始化每个节点的 PageRank = 1/N。每轮迭代：PR(v) = (1-d)/N + d × Σ(PR(u)/out_degree(u))，对每个有链接指向 v 的节点 u 求和。d 是阻尼系数取 0.85（表示用户有 85% 概率点击链接继续浏览，15% 概率随机跳转到任意页面）。

收敛条件——连续两轮所有节点 PR 值的变化量之和 < epsilon（默认 1e-6），或者达到最大迭代次数（默认 100）。支持从文件读入图数据，格式每行一个链接 "from to"。

输出所有节点的 PageRank 值，按分数从高到低排序。总和应该约等于 1.0。写个 demo 跑一个小型网页图（10 个节点，20 条边），验证迭代收敛。cargo run 能看到排序结果。
