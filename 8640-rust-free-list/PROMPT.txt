通用内存分配器（malloc/free）在大量小对象频繁分配释放时容易产生碎片——空闲内存总量够但都是零散的小块，分配稍大的请求就失败。Free List 分配器维护一个空闲块链表，分配时找到够大的块，释放时和相邻的空闲块合并（coalescing），减少碎片。

用 Rust 写一个 Free List 内存分配器。

空闲链表——维护一个 Vec<FreeBlock> 或链表，每个 FreeBlock 记录起始地址和大小。分配请求到来时，从链表中找第一个够大的块（First Fit）或者最合适的块（Best Fit）。

First Fit——从头遍历链表找第一个 size >= request_size 的块。找到后从块中切出 request_size，剩余部分作为新的空闲块留在链表中。

Best Fit——遍历所有块找 size 最接近 request_size 的。碎片更少但遍历更慢。

释放和合并——释放一个块时把它插回链表。然后检查是否有相邻的空闲块（地址连续），如果有就合并成一个更大的块。合并是减少碎片的关键。分配单位是字节。

用 unsafe 指针操作模拟真实内存管理，或者用 Vec<u8> 模拟一个内存池。写个 demo 分配不同大小的块，释放几个，验证合并逻辑正确。cargo build 编译通过，cargo run 有输出。
