Linux 内核的伙伴系统（Buddy System）是经典内存管理算法——把内存按 2 的幂次分割和合并。分配时找最小的满足需求的块，没有就分裂更大的块。释放时检查"伙伴"（相邻的同等大小的块）是否也空闲，空闲就合并成更大的块。

用 Rust 实现伙伴内存分配器。

数据结构——维护不同大小等级（order）的空闲链表。order k 的块大小是 2^k × min_block_size。比如 min_block_size=64 字节，order 0 = 64B，order 1 = 128B，order 10 = 64KB。用一个数组 free_lists[MAX_ORDER] 存每个等级的空闲块链表。

分配——alloc(size)：计算需要的 order（向上取整到最近的 2 的幂）。在 free_lists[order] 中找空闲块。如果有就直接返回。如果没有，从更高的 order 找空闲块，不断对半分裂（每次 order--）直到目标 order。每次分裂产生两个"伙伴"，一个用于分配，另一个放入对应 order 的空闲链表。

释放——free(ptr, size)：计算 order。检查伙伴是否空闲（用位运算：buddy_addr = block_addr XOR block_size）。如果伙伴空闲就从对应链表中移除伙伴，合并成更大的块（order++），递归检查新块的伙伴。如果伙伴不空闲就当前块放入 free_list[order]。

最小块大小和总内存大小可配置。写个 demo 展示分配、释放、伙伴合并的过程，打印每次操作后的内存状态。cargo run 能看到分配日志。
