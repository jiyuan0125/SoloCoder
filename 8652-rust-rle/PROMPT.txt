有一批 BMP 图片和简单色块图，很多行是连续的同一颜色。RLE（Run-Length Encoding）压缩超级简单——连续重复的字节用 (计数, 字节) 表示。对简单图形效果好，对复杂图片可能反而变大。

用 Rust 写 RLE 编解码工具。

编码——遍历输入字节流，统计连续重复的字节。遇到相同的字节就一直计数，直到不同或者达到 255（一个计数器最大值）。输出 (count, byte) 对。比如 "AAABBBCC" 编码为 (3,A)(3,B)(2,C)。

处理不重复的数据——连续不重复的字节不能简单编码为 (1,A)(1,B)(1,C)，这样反而更长了。实现一个混合方案：遇到连续重复用 RLE，遇到不重复的用标记 + 原样拷贝。比如用一个特殊标记区分"后面跟着 RLE 数据"和"后面跟着原始数据"。

解码——读 (count, byte) 对，展开为 count 个 byte。遇到原始数据标记就直接拷贝指定长度的字节。

CLI 用法：rle encode in.raw out.rle / rle decode out.rle restored.raw。支持文件读写。边界情况：空文件（编码后也是空）、全是重复字节（最高压缩比）、全是不重复字节（可能略大于原文件）。

cargo build 编译通过，压缩再解压后文件内容完全一致。
