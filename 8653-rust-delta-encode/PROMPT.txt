时序传感器数据有个特点——相邻两个采样点的值变化很小。温度可能从 25.3℃ 变到 25.4℃，下一个还是 25.4℃。直接存原始值浪费空间，Delta 编码只存差值，差值通常很小可以用更少的 bit 表示。

用 Rust 写 Delta 编码工具。

编码——输入一个整数序列。第一个值存原始值（基准），后续每个值存与前一个值的差值。比如 [100, 102, 105, 103, 100] 编码为 [100, +2, +3, -2, -3]。

解码——第一个值直接还原。后续每个值 = 前一个值 + 差值。所以 [100, +2, +3, -2, -3] 还原为 [100, 102, 105, 103, 100]。

有符号整数支持——差值可以是负数（值下降了）。用 zigzag 编码把有符号整数转成无符号：zigzag(n) = (n << 1) ^ (n >> 31)。这样 -1 变成 1，1 变成 2，-2 变成 3...然后可以用 varint 编码。

提供 encode 和 decode 两个子命令。从标准输入读取数据（每行一个整数），输出到标准输出。也支持二进制格式（用 bincode 或者自定义序列化）。

编码前后数据精度不能有损失——整数 Delta 编码是精确的。如果值域是有界且差值很小，可以进一步用 bit-packing 压缩差值。cargo build 通过。
