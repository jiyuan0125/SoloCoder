微服务间传输大量格式相似的 JSON 消息（比如日志事件、用户行为数据）。单个消息才几百字节，普通压缩算法需要积累足够数据量才有效果。Zstd 的字典模式就是为这种场景设计的——用一批训练样本构建字典，之后每条消息都可以单独压缩，压缩率比无字典模式好很多。

用 Rust 实现基于字典的压缩工具。

三个操作——train：从一批训练样本（文件）生成压缩字典。读入多个训练文件，分析它们共同的字节模式，构建一个字典文件。字典大小可配置（默认 32KB）。compress：加载字典后压缩单个文件。decompress：加载字典后解压文件。

字典构建——简化版：把训练样本拼在一起，找出高频的子串作为字典内容。或者更简单：用前 N 个训练样本的字节作为字典（效果也不错）。字典保存为一个独立的 .dict 文件。

压缩——加载字典后，用 LZ77 风格的匹配在字典中搜索重复片段。匹配到的用 (offset, length) 引用字典内容。没匹配到的 literal 原样输出。

解压——加载同一个字典，遇到字典引用时从字典中取出对应的内容还原。

cargo build 编译通过。对格式相似的小文件（比如 10 条 JSON 日志），字典模式的压缩率应该明显优于无字典模式（对比展示）。
