传感器数据每个采样点只需 12 bit（精度 0-4095），但 u16 要 16 bit，4 bit 白白浪费了。一百万个采样点浪费 500KB。Bit-packing 把 N 个只需要 B bit 的整数紧密打包到字节数组，不留间隙。

用 Rust 实现通用的 bit-packing 工具。

打包——把 N 个 B-bit 整数紧密写入字节数组。支持 1-32 位宽度的任意打包。关键难点是跨字节边界的情况——比如 12-bit 整数，第一个占字节 0 的全部 8 bit 和字节 1 的低 4 bit，第二个从字节 1 的高 4 bit 开始。用位运算（移位和掩码）处理不对齐的读写。

解包——从打包的字节数组中还原所有整数。pack 和 unpack 必须互为逆操作——打包后再解包，所有数据必须和原始输入完全一致。

API——pack(values: &[u64], bits: u8) -> Vec<u8> 和 unpack(data: &[u8], bits: u8, count: usize) -> Vec<u64>。count 是原始整数个数（解包时需要知道）。

CLI 工具——从文件读取整数列表（每行一个），指定 bit 宽度，打包后输出，或者解包。示例：把 1000 个 12-bit 值打包，占 1000×12/8 = 1500 字节，比 1000×2 = 2000 字节的 u16 数组省 25%。
