Prometheus 兼容的时序数据库需要压缩存储大量时间戳和计数值。Simple8b 是一种整数压缩编码——用一个 64 bit 字的低 60 bit 存多个整数，高 4 bit 选择编码模式。适合时序数据中小值居多的场景。

用 Rust 实现 Simple8b 编码算法。

编码模式——高 4 bit 是 selector（0-15），决定低 60 bit 怎么划分。selector=0: 1 个 60-bit 值。selector=1: 2 个 30-bit 值。selector=2: 3 个 20-bit 值...selector=15: 240 个 0-bit 值（全零值）。编码时从最大的 selector（存最多值）开始试，看当前这批数字的最大值是否能装进对应的位数。不行就降级。

编码——遍历输入数组，每次尝试用当前最优的 selector 编码一批值。成功就写入一个 u64，继续处理下一批。一批数字可能跨多个 u64。

解码——读一个 u64，取高 4 bit selector，知道后面 60 bit 怎么拆。按 selector 对应的位数逐个提取值。速度很快。

编码后要能正确解码出原始序列。对监控场景的小整数（0-1000 范围的时间戳差值）应该有好的压缩比。cargo build 通过。
