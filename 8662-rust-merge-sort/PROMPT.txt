Rust 标准库的 sort 是稳定的但有时候不够定制——需要自定义比较逻辑、统计比较次数、或者排序自定义结构体。手写一个归并排序作为通用工具，保证稳定性和可控性。

用 Rust 写一个通用的归并排序库。

经典实现——自顶向下递归：把数组从中间分成两半，分别排序，然后合并。合并时用临时缓冲区，双指针归并。自底向上迭代：先合并长度 1 的子数组，再合并长度 2 的，再 4...直到全部排好。两种都实现，通过参数选择。

稳定性——合并时如果两个元素相等，取左边那一半的元素优先。这样相同元素的原始相对顺序保持不变。

泛型接口——sort_by(data: &mut [T], cmp: F) where F: Fn(&T, &T) -> Ordering。调用者可以传自定义比较函数。也提供 sort(data) 用默认的 Ord 比较。

统计信息——可选地记录比较次数和交换（移动）次数，方便分析排序行为。用 RefCell<usize> 或者返回一个 Stats 结构体。

CLI 工具——对文本文件的行做排序。cargo build 编译通过。
测试——随机生成 10000 个整数，验证排序结果和标准库 sort 一致。对已排序数组、逆序数组、全相同元素的三种边界情况验证稳定性和正确性。也实现一个 benchmark 模式，和 Vec::sort() 对比不同规模（100, 1000, 10000, 100000）的耗时。
