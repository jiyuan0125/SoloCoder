想做个简单的全文搜索引擎，第一步是建倒排索引。倒排索引是搜索引擎的核心——把"哪些文档包含哪些词"这个信息提前算好，查询时直接查表，不用遍历所有文档。

用 Rust 实现一个倒排索引构建和查询工具。

文档管理——读取一组文本文件（指定目录路径），每个文件是一篇文档。文件名就是文档 ID。对每个文件的内容做分词：英文按空格和标点切分，中文按字符切分（最简单的方案）。全部转小写，去掉空 token。

索引构建——对每个 token，建立到文档 ID 列表的映射。token → BTreeSet<DocId>（有序去重）。也统计每个 token 的文档频率（出现在多少篇文档里）。整个索引用 BTreeMap<String, BTreeSet<String>> 存储。

查询——支持多词 AND 查询：输入多个关键词，取所有关键词对应文档集合的交集。返回同时包含所有查询词的文档列表，按文档名排序。

持久化——索引序列化到磁盘（bincode 或者 JSON 格式），下次启动直接加载不用重建。

要能正确处理中文和英文文本。CLI：indexer build ./docs 建索引，indexer search "关键词" 查询。cargo build 通过。
