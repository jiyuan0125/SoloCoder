做个类似 fzf 的模糊搜索工具——在命令行输入几个字符就能从大量候选项中找到匹配的。不需要精确匹配，字符按顺序出现在候选中就算匹配，连续的额外加分。

用 Rust 实现模糊搜索引擎。

匹配算法——给定查询 Q 和候选字符串 S，检查 Q 的每个字符是否按顺序出现在 S 中。如果字符按顺序出现但连续，加分（连续匹配更相关）。首字符匹配加分（如果 Q 的第一个字符是 S 的首字符）。记录每个匹配字符的位置用于高亮。

评分函数——基础分 = 匹配字符数 / 候选长度。连续匹配加分 = 连续匹配组数 × bonus。首字符匹配加分。最终分数 = 基础分 + 加分。

结果排序——所有候选按分数降序排列，返回 Top-N。用最小堆只维护前 N 个。

性能——一万条候选项的搜索应该在毫秒级完成。避免对每个候选做完整匹配后排序——先用长度过滤（候选长度 < 查询长度的一定比例直接跳过），再做精确匹配和评分。

CLI：fuzzy-search "ml" < candidates.txt。cargo build 通过。
测试——[-2,1,-3,4,-1,2,1,-5,4] 最大子数组和应为 6，区间 [3,6]。全负数 [-3,-1,-2] 结果为 -1。分治版本结果应和 Kadane 一致。跑 1000 次随机测试。
