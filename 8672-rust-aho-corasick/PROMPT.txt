内容审核系统要同时检测几百个敏感词——暴力、色情、政治等各类关键词。一个一个匹配是 O(k×n)，k 个模式串每个都要扫一遍文本。Aho-Corasick 算法建好自动机之后一次扫描就能找到所有模式串，时间 O(n+m+z)，z 是匹配数。

用 Rust 实现 Aho-Corasick 多模式匹配。

构建阶段——先把所有模式串插入 Trie 树。每个节点有转移 map（字符→子节点）和 fail 指针。模式串末尾节点标记为输出，记录是哪个模式串。

计算 fail 指针——BFS 层序遍历 Trie。根节点的 fail 指向自己。对节点 u 的每个字符 c 的子节点 v：从 u.fail 开始沿 fail 链找到有 c 转移的节点 w，v.fail = w 通过 c 转移到的节点。如果一直找不到就回溯到根节点。同时把 fail 节点的输出合并到当前节点的输出列表（输出链接）。

匹配扫描——从根节点出发，逐字符扫描输入文本。当前节点有 c 的转移就走下去，没有就沿 fail 链跳转直到找到有 c 转移的节点或回到根。每次到达一个节点检查它和 fail 链上的所有输出，记录匹配。

报告每个模式串在文本中的所有出现位置（起始和结束索引）。支持重叠匹配。模式串从文件按行读取。空模式串跳过。cargo build 通过。
