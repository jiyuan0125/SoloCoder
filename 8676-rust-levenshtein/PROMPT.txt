地址清洗系统每天要处理上万条地址记录——"北京市朝阳区建国路 88 号" 和 "北京朝阳区建国门外大街" 到底是不是同一个地方？人工判断太慢，用 Levenshtein 距离量化差异：距离越小越可能是同一地址。但距离是绝对值，"北京" 和 "北京市" 差 1 和 "北京市朝阳区" 和 "北京市海淀區" 差 1 意义完全不同。需要归一化到 [0,1] 区间。

用 Rust 实现 Levenshtein 距离计算，带归一化和阈值优化。

标准 DP 部分——插入、删除、替换三种操作，每步代价 1。按 rune 处理 Unicode 字符，不能按字节。归一化相似度 = 1 - distance / max(len(s), len(t))。

阈值优化——加一个 maxDist 参数。很多场景只需要知道"距离是否超过阈值"，不需要精确值。优化方式：每行只计算 [max(0, i-maxDist), min(n, i+maxDist)] 范围内的格子。如果当前行最小值已经超过 maxDist，直接返回。

距离为 0 时短路返回，跳过整个 DP 计算。CLI：levenshtein "北京朝阳区" "北京市朝阳区"，输出距离和相似度百分比。cargo build 通过。
