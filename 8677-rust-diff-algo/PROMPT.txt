版本控制系统每天要对比成千上万次代码变更——哪个函数改了、哪行删了、哪行新增的。手工作对比不现实，需要一个自动化的文本 diff 工具。

问题 1：如何找出两段文本的差异？按行分割两个文件，用 LCS（最长公共子序列）找出两个文件中都出现的行——这些是"不变"的行。只在旧文件中出现的标记为"删除"（-），只在新文件中的标记为"新增"（+）。

问题 2：输出格式怎么做？类似 unified diff 格式——差异部分前后各展示 3 行上下文，每组差异前面加 @@ 标记行列位置。让用户一眼就能定位改动。

问题 3：边界怎么处理？两个空文件输出"内容相同"。完全不同的文件全部标红/绿。行数很多的大文件要注意内存，别一次性全加载。

用 Rust 实现。CLI：text-diff old.txt new.txt，输出 diff 结果。cargo build 通过。
额外要求：支持颜色输出——删除行红色，新增行绿色，不变行默认色。通过 ANSI escape code 实现，加一个 --color 参数控制。也支持输出到文件（无颜色模式）。处理文件不存在、权限不足的错误情况。
支持忽略空白差异（--ignore-whitespace）和忽略大小写（--ignore-case）的选项。行号从 1 开始编号，输出中标注。
