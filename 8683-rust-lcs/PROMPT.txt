代码查重系统要对比两份提交的相似度——不是逐字符比较，而是找最长公共子序列（LCS）。"ABCBDAB" 和 "BDCAB" 的 LCS 是 "BCAB"，长度 4。LCS 越长，两份代码越可能抄袭。DNA 序列比对也用 LCS 找保守区段。

用 Rust 实现 LCS。

标准 DP 解法——(m+1)×(n+1) 二维表。dp[i][j]：如果 s[i-1]==t[j-1] 则 dp[i][j]=dp[i-1][j-1]+1，否则取 max(dp[i-1][j], dp[i][j-1])。dp[m][n] 就是 LCS 长度。

- 回溯具体内容：从右下角往回追，相等时往左上走并记录字符，不等时往 dp 值更大的方向走
- 只求长度？空间优化到 O(min(m,n))——两行交替即可
- Unicode 处理按 char，不要按 u8

CLI：lcs "ABCDGH" "AEDFHR" 返回 "ADH"。同时输出长度和子序列内容。cargo build 通过。
验证几组："ABCBDAB" vs "BDCAB" 应返回 LCS "BCAB" 长度 4。完全相同的字符串 LCS 就是自身，完全不同的返回空。长字符串（5000 字符）用空间优化版本只测长度，确认时间可接受。
