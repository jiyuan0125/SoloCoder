量化交易系统分析股票价格走势——[10, 9, 2, 5, 3, 7, 101, 18] 中最长上升子序列是 [2, 3, 7, 101]，长度 4。找上升趋势帮助判断买入卖出时机。朴素 DP 是 O(n²)，数据量大时太慢。二分搜索版本能做到 O(n log n)。

用 Rust 实现最长递增子序列（LIS）。

第一步，O(n log n) 二分搜索版本。维护一个 tails 数组——tails[i] 表示长度为 i+1 的上升子序列的最小末尾元素。遍历每个元素 x：如果 x 大于 tails 最后一个元素，直接追加；否则用二分搜索找到第一个 >= x 的位置替换。tails 的长度就是 LIS 长度。

第二步，回溯具体序列。额外维护一个 parent 数组记录每个元素的前驱位置。最后从最长子序列的末尾往回追。

支持两种模式：严格递增（<）和非严格递增（<=）。全降序序列的 LIS 长度为 1。CLI：lis "10 9 2 5 3 7 101 18"，输出长度和具体序列。cargo build 通过。
[10, 9, 2, 5, 3, 7, 101, 18] 应返回长度 4、序列 [2, 3, 7, 101]。全降序 [5,4,3,2,1] 长度 1，全升序 [1,2,3,4,5] 长度 5。随机灌 10000 个元素验证 O(n log n) 版本的性能。
