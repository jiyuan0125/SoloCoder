搜索引擎处理中文查询"北京大学计算机"——需要判断能不能用词典完全切分，以及有哪些切分方式。"北京大学/计算机"、"北京/大学/计算机"、"北京/大学/计算/机"……词典里有的才算有效切分。分词后处理、拼写检查、以及自然语言的词法分析都依赖这个能力。

用 Rust 实现 word break 问题。

DP 判断可行性——dp[i] 表示 s[0..i] 能否被词典完全切分。dp[0]=true（空串可切分）。对每个位置 i，检查所有 j < i：如果 dp[j]=true 且 s[j..i] 在词典中，则 dp[i]=true。最后 dp[n] 就是答案。

回溯所有切分方案——用 DFS 回溯。从位置 0 开始，尝试每个可能的切分点，如果 s[pos..i] 在词典中就递归处理 s[i..]。收集所有路径。

输入字符串和词典。CLI：word-break "catsanddog" --dict "cat,cats,and,sand,dog"，输出能否切分以及所有切分方案。cargo build 通过。
测试——"catsanddog" 词典 {cat, cats, and, sand, dog} 应返回两种切分：cat/sand/dog 和 cats/and/dog。空字符串直接返回 true（空切分）。词典为空时任何非空字符串都返回 false。测试性能：50 字符字符串 + 100 词典条目。
