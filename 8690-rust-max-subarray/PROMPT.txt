股票收益分析——给你一组价格变动 [-2, 1, -3, 4, -1, 2, 1, -5, 4]，哪个区间的累计收益最大？[4, -1, 2, 1] 这个区间和为 6，是所有连续子数组里最大的。这就是最大子数组和问题，Kadane 算法一遍扫描 O(n) 搞定。

用 Rust 实现最大子数组和。

Kadane 怎么做？维护两个变量——current_sum 是以当前位置结尾的最大子数组和，best_sum 是全局最优。遍历每个元素：current_sum = max(x, current_sum + x)——要么把 x 接到前面的子数组后面，要么从 x 重新开始。best_sum 随时更新。

光知道最大和不够——还得知道是哪个区间。记录 current_sum 重置时的起始位置，以及 best_sum 更新时的起止位置。

全负数怎么办？比如 [-3, -1, -2]，最大子数组是 [-1]，和为 -1。不能返回 0，那是"不选任何元素"的结果。

也实现一个分治版本做对比——O(n log n)，左半最大、右半最大、跨越中点的最大三者取 max。CLI：max-subarray "-2,1,-3,4,-1,2,1,-5,4"。cargo build 通过。
