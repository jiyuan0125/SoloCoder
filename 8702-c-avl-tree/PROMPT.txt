内存里的有序字典——频繁插入删除后普通 BST 会退化成链表，查找从 O(log n) 退化到 O(n)。AVL 树是最早发明的自平衡 BST，任何时刻左右子树高度差不超过 1，保证最坏情况也是 O(log n)。

问题 1：旋转怎么写？四种情况——LL（左孩子的左子树高了，右旋）、RR（右孩子的右子树高了，左旋）、LR（左孩子的右子树高了，先左旋左孩子再右旋根）、RL（右孩子的左子树高了，先右旋右孩子再左旋根）。每种旋转后更新高度。

问题 2：插入和删除怎么维护平衡？插入后从插入点往上更新高度，发现不平衡就旋转。删除更复杂——删完可能要一路旋转到根。

问题 3：接口怎么设计？节点存 int key 和 void* value。支持自定义比较函数。操作：insert、delete、search、inorder traversal（输出排序结果）。重复 key 的插入可以选择更新 value 或者忽略。

C 语言实现，gcc 编译。main 函数插入随机数据后中序遍历，验证有序性。
测试——插入 1000 个随机数，中序遍历验证严格递增。删除 500 个后再遍历验证有序。测量树高，验证大致 1.44×log2(n)。
