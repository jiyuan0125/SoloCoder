有序场景下需要替代平衡树——AVL 和红黑树的旋转逻辑写起来头疼，调试更头疼。Skip List 用概率代替旋转来维持平衡，代码量少一半以上。Redis 的 sorted set、LevelDB 的 memtable 都用了它。查找、插入、删除都是 O(log n) 期望值，最坏 O(n) 但概率极低。

用 C 语言实现 Skip List。

怎么建多层索引？每个节点随机决定自己的层数——抛硬币，正面层数加 1，反面停止。最大层数用宏控制（比如 32），概率取 1/2。这样第 k 层大约有 n/2^k 个节点，形成一棵"概率性平衡树"。

查找怎么做？从最高层的头节点开始，向右走——如果右边的 key 小于目标就继续走，大于目标就往下跳一层。一层层往下直到第 0 层，找到或者确认不存在。

范围查询怎么做？先定位到起始 key 的位置，然后沿着第 0 层链表往后遍历 N 个元素。
