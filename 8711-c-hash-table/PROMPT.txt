编译器的符号表——每遇到一个变量名就要查它是不是已经声明过、是什么类型、在哪个作用域。一个源文件几千个符号，查一次不能扫一遍。哈希表用链地址法解决冲突：每个桶挂一个链表，哈希到同一个桶的元素串在一起。查找、插入、删除平均 O(1)，最坏 O(n) 但好哈希函数能让冲突极低。

用 C 语言实现链地址法哈希表。

数据结构——一个指针数组（桶），每个桶指向一个链表节点。节点存 key（字符串）、value（void* 通用指针）、next。表容量初始给 16，负载因子超过 0.75 就扩容。

哈希函数——字符串 key 用 djb2 或者 FNV-1a 这种简单高效的哈希。hash(key) % capacity 得到桶号。扩容时容量翻倍，所有元素重新哈希到新桶里（rehash）。

操作接口——put(key, value)：如果 key 已存在就更新 value，不存在就新建节点。get(key)：找到返回 value，没找到返回 NULL。delete(key)：找到并删除，返回是否成功。遍历：callback 函数遍历所有键值对。
