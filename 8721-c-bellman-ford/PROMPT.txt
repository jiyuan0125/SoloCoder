金融系统里货币汇率构成一个图——美元→欧元汇率 0.85，欧元→英镑 0.88，英镑→美元 1.35。如果 0.85×0.88×1.35 > 1，存在套利机会。把汇率取负对数后，套利就是负权环。Dijkstra 处理不了负权边，Bellman-Ford 可以——对每条边做 V-1 轮松弛，然后额外做一轮检测负权环。

用 C 语言实现 Bellman-Ford 单源最短路径。

算法流程——初始化 dist[source]=0，其余无穷大。外层循环 V-1 轮，每轮遍历所有边 (u,v,w)，如果 dist[u]+w < dist[v] 就更新 dist[v]=dist[u]+w。V-1 轮后所有最短路径确定。

负权环检测——再做一轮遍历。如果还有边能松弛（dist[u]+w < dist[v]），说明存在负权环。报告哪些节点受影响（从可松弛的边出发 DFS 标记）。

存储——边列表比邻接表更合适，因为算法要遍历所有边而不是按节点访问。结构：struct Edge { int u, v; double w; }。

路径回溯——prev 数组记录前驱。负权环上的节点路径无意义。

gcc 编译。测试：一个正常有负权边的图（有最短路），一个有负权环的图（能检测出来）。
