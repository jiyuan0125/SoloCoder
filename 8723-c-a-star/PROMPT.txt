游戏里的 NPC 要从地图左上角走到右下角，路上有墙壁和障碍。BFS 会无脑扫全图，Dijkstra 不用因为每步代价相同。A* 加上启发函数引导搜索方向——像用指南针一样优先朝着终点走，大部分情况只探索一小片区域就找到路了。

用 C 语言实现 A* 寻路算法。

核心公式——f(n) = g(n) + h(n)。g(n) 是起点到 n 的实际代价，h(n) 是 n 到终点的估计代价（启发函数）。优先队列按 f 值排序，每次取 f 最小的节点扩展。

- 启发函数：曼哈顿距离（四方向移动，h=|x1-x2|+|y1-y2|）或欧几里得距离（八方向）。可配置选择
- 四方向 / 八方向移动：通过方向数组控制
- 优先队列：用最小堆，支持 decrease_key
- 障碍物：网格上有标记不可通过的格子

路径不存在时要正确报告。输出路径在地图上标出——用字符表示起点、终点、路径和障碍。

20×20 网格地图，放几个障碍物，演示从左上到右下的路径。gcc 编译。
测试——20×20 网格，随机放 30% 障碍物。验证路径是最短的（和 BFS 对比）。无路径时正确报告。对比曼哈顿和欧几里得启发函数的探索节点数。
