大学排课系统——"数据结构"依赖"C 语言程序设计"，"算法设计"依赖"数据结构"。几百门课的依赖关系图，排课顺序必须满足所有前置条件。拓扑排序把 DAG 的节点排成线性序列，保证每条边的起点排在终点前面。编译器的 make 依赖、CI/CD 流水线、任务编排都用它。

用 C 语言实现拓扑排序。

第一步，用 Kahn 算法（BFS 版本）。统计每个节点的入度。入度为 0 的节点入队。循环：从队列取一个节点，加入结果序列，把它所有邻居的入度减 1，减到 0 的入队。直到队列空。

第二步，环检测。如果结果序列的长度小于节点总数，说明图中有环——存在循环依赖，不可能拓扑排序。报告"图中有环，无法排序"。

第三步，也实现 DFS 版本。从每个未访问节点开始 DFS，递归完成后把节点压栈。最后栈里从顶到底就是拓扑序列。DFS 时遇到灰色节点（正在访问中）说明有环。

用邻接表存图。gcc 编译。示例：模拟课程依赖关系，输出选课顺序。
测试——10 门课的依赖关系图，输出拓扑序列后验证每条边的起点在终点前面。包含环的图（如 A→B→C→A）应报告无法排序。
两种算法的输出可以不同但都必须合法。也支持输出所有可能的拓扑序列中的一个即可。
