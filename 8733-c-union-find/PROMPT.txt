社交网络的"你可能认识"功能——两个人有没有共同好友？在线动态判断两个元素是否属于同一个集合。并查集（Union-Find / Disjoint Set Union）专门干这个：MakeSet 创建单元素集合，Find 查代表元，Union 合并两个集合。加上路径压缩和按秩合并，均摊几乎 O(1)。

用 C 语言实现并查集。

数据结构——parent[i] 存第 i 个元素的父节点（根的 parent 指向自己）。rank[i] 存以 i 为根的树的高度上界。

- MakeSet(i)：parent[i]=i, rank[i]=0
- Find(i)：沿 parent 向上找根。路径压缩——找到根后把沿途所有节点直接连到根上。递归或迭代都行
- Union(i, j)：找两个根，按秩合并——矮树挂到高树下面。秩相同时任选一个当根，根的秩加 1

初始化 N 个独立集合，然后处理一系列 merge 和 connected 操作。演示：给一个无向图的边列表，用并查集判断图是否有环——每条边的两个端点如果已经在同一集合就有环。gcc 编译。
性能测试——100 万次 union 和 find 操作，验证均摊耗时接近 O(1)。路径压缩前后深度对比：压缩前可能很深，压缩后大部分节点直接连到根。
