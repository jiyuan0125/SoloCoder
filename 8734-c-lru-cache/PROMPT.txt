浏览器缓存有限，不可能把所有访问过的页面都存着。LRU（Least Recently Used）策略淘汰最久没用的——刚好和直觉一致：最近看过的可能还要看，很久没看的可以删了。HashMap 加双向链表实现 O(1) 的 get 和 put。

用 C 语言实现 LRU Cache。

第一步，数据结构。HashMap 存 key 到链表节点的映射。双向链表按访问时间排序——最近访问的在头部，最久没访问的在尾部。链表有 dummy head 和 dummy tail 方便操作。

第二步，get 操作。HashMap 查 key，找不到返回 -1。找到了就把对应节点从链表当前位置摘出来，移到头部，返回 value。移动是 O(1)。

第三步，put 操作。如果 key 已存在，更新 value 并移到头部。如果 key 不存在：新建节点，插入 HashMap 和链表头部。如果超过容量，删掉链表尾部的节点（最久没用的），同时从 HashMap 里删除对应 key。

容量为 0 时任何 put 都直接淘汰。gcc 编译。容量 3，连续操作验证淘汰顺序。
测试——容量 3，put(1,10), put(2,20), put(3,30)（满），get(1)（命中），put(4,40)（淘汰 2），get(2) 返回 -1。完整操作序列验证淘汰正确。
