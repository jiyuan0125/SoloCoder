Web 服务器每秒要处理上千个请求，每个请求都要分配 HTTP 头结构体、连接对象、缓冲区。malloc/free 太慢——每次都要在堆里找合适大小的块，还要处理碎片。Slab 分配器为固定大小的对象预分配内存，分配和释放都是摘链表节点，O(1)。Linux 内核就是这么管理小对象的。

用 C 语言实现 Slab 分配器。

Slab 的结构——每种对象大小对应一组 slab。每个 slab 是一块连续内存（比如一页 4KB），里面分成若干个等大的 object。空闲 object 用链表串起来。

分配流程——slab_alloc(size)：找到对应大小的 slab 组，从空闲链表取一个 object。链表空了就 malloc 一块新 slab，切成 object 挂到链表上。

释放流程——slab_free(ptr)：根据指针算出它属于哪个 slab，把 object 挂回空闲链表。一个 slab 的 object 全部空闲了可以释放给系统（可选）。

支持多种大小——比如 32B、64B、128B、256B 几种 slab。请求 50 字节就用 64B 的 slab。

底层用 malloc 申请大块内存。gcc 编译。反复分配释放验证无泄漏。
