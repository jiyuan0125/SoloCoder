音频播放器一边从文件读数据、一边往声卡送数据——两个操作速度不同，中间需要一个缓冲。环形缓冲区（Ring Buffer）读写指针独立前进，满了不能再写，空了不能再读。不需要移动数据，两个指针绕着圈跑就行。串口通信、网络收发包、日志轮转都是这个模型。

用 C 语言实现 Ring Buffer。

读写指针怎么管理？固定大小数组，head 指向下一个读位置，tail 指向下一个写位置。前进时对 size 取模实现循环。区分满和空——用一个 count 变量记录元素数量，或者牺牲一个 slot（满的条件是 (tail+1)%size == head）。

ring_write(buf, data, len)——写入 len 字节，返回实际写入量。如果剩余空间不够就只写能写的部分。ring_read(buf, data, len)——读取 len 字节，返回实际读取量。空了就返回 0。

能存的最大数据量 = size - 1（区分满和空）。线程安全先不管，但接口设计上要方便加锁。gcc 编译。测试写满、读一半、再写，验证数据正确。
测试——容量 8，写 A B C D E F G H（满，实际写 7 个），读 3 个得 A B C，再写 X Y Z，读全部验证数据不丢不错。
