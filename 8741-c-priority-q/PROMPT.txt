医院急诊室来了病人——不能按先来后到，得按病情严重程度排序。优先队列就是干这个的：每次 pop 出来的是优先级最高的元素（不是最先加的）。二叉最小堆用数组实现，push 和 pop 都是 O(log n)，peek 看堆顶 O(1)。操作系统的任务调度、网络数据包排队、A* 的 open set 都用它。

用 C 语言实现基于二叉最小堆的优先队列。

数组表示——节点 i 的左孩子在 2i+1，右孩子在 2i+2，父节点在 (i-1)/2。堆性质：每个节点 <= 子节点。

push(value, priority)——新元素加到数组末尾，然后上浮（sift up）：和父节点比较，如果更小就交换，直到满足堆性质。pop()——堆顶和末尾交换，弹出末尾（原堆顶），新堆顶下沉（sift down）到正确位置。peek()——直接返回数组第一个元素。

初始容量固定，满了可以选择报错或扩容（realloc 翻倍）。空堆 pop/peek 返回错误。

gcc 编译。插入一堆带优先级的任务，pop 出来验证按优先级从小到大。
测试——push (task1, 3), (task2, 1), (task3, 5), (task4, 2)。连续 pop 应得到 task2(1), task4(2), task1(3), task3(5)——按优先级升序。
