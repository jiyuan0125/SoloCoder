社交网络分析——给 100 万个用户和他们的好友关系，最终形成多少个朋友圈？每个圈子里都有谁？普通的 union-find 只能判断两个元素是否在同一集合，这里还需要遍历集合的所有成员。在 union-find 基础上加链表枚举功能。

用 C 语言实现带枚举功能的不相交集合。

基础 union-find——路径压缩的 find，按秩合并的 union。每个元素有 parent 和 rank。

额外的链表——每个集合的代表元素维护一个成员链表头。合并时把一个链表拼到另一个后面。这样遍历集合就是顺着链表走一遍。

- make_set(i)：parent[i]=i, rank[i]=0, head[i]=i, next[i]=-1
- find(i)：带路径压缩
- union(i, j)：按秩合并，拼接成员链表
- print_set(representative)：遍历链表输出所有成员

也实现 count_sets() 返回当前集合总数。gcc 编译。演示一系列合并操作后输出所有集合。
测试——10 个元素，union(0,1), union(2,3), union(1,3) 后 {0,1,2,3} 是一个集合。print_set 输出所有成员。count_sets 返回正确数量。
