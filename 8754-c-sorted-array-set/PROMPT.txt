先说下场景。有些嵌入式设备内存只有几十 KB，跑不了红黑树和跳表那些重量级结构。但如果数据量在几百到几千这个级别，一个排好序的数组配合二分查找就够用了——查找 O(logn)，插入和删除虽然要移动元素（memmove），但数据量小的时候完全可以接受。

用 C 写一个基于有序数组的集合。内部维护一个动态数组，元素按升序排列。数组初始容量可配，满了之后按 2 倍扩容。每个元素是一个整数或者字符串（先用整数版本）。

接口：add(value) 插入元素并保持有序——先用二分查找确定插入位置，再用 memmove 腾出空间。remove(value) 删除元素，同样先二分定位再 memmove 覆盖。contains(value) 二分查找判断元素是否存在，O(logn)。iter() 遍历所有元素（有序），size() 返回元素个数。toArray() 导出为普通数组供外部使用。

重点注意几个边界情况：往空集合插入第一个元素、插入重复元素时返回错误或忽略（不能破坏集合的互异性）、删除一个不存在的元素时该怎么处理——这些都要考虑清楚，不要让程序崩溃。

写个测试程序覆盖这些场景：空集操作、大量随机插入后验证有序性和互异性、交替插入删除后检查一致性。gcc 编译通过，只依赖标准库和 stdlib。
