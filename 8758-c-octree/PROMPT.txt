3D 引擎里碰撞检测是性能瓶颈之一——场景里可能同时存在几十万个物体，两两检测碰撞是 O(n²) 完全不可行。八叉树把三维空间递归切成八个子立方体，只对同一个子空间内的物体做碰撞检测，直接把复杂度降到 O(n log n)。

用 C 实现一个八叉树（Octree），管理三维空间中的点或对象。每个节点存一个轴对齐包围盒（AABB）和最多 capacity 个元素。超出容量后沿 x/y/z 三个轴的中点分裂成八个子立方体——前左上、前右上、前左下、前右下、后左上、后右上、后左下、后右下。

提供这些操作：insert(x, y, z, id) 插入一个 3D 坐标点并关联一个 ID；remove(id) 根据 ID 删除点（需要维护一个 id 到节点的映射表来加速定位）；query_sphere(cx, cy, cz, r) 查询球心 (cx,cy,cz) 半径 r 的球体内所有点；query_box(min_x, min_y, min_z, max_x, max_y, max_z) 查询轴对齐包围盒内的所有点。

query_sphere 的剪枝策略：先判断球体和节点的 AABB 是否相交，不相交直接跳过整个子树。

提供命令行测试程序：插入 50000 个随机 3D 坐标点，做 100 次随机球形范围查询，输出每次查询命中的点数和查询耗时。再和暴力遍历做对比。gcc 或 make 编译，纯标准库。
