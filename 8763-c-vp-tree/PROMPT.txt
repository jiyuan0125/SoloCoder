VP-Tree 和 kd-tree 最大的不同在于它不依赖坐标——只需要一个距离函数。这意味着你可以拿它做字符串近邻搜索（用编辑距离）、做分子结构相似性检索（用自定义的距离度量），任何满足三角不等式的度量空间都行。

用 C 实现一棵 VP-Tree（Vantage Point Tree）。建树过程很简单：从当前点集中随机选一个点作为 vantage point，计算所有其他点到它的距离，取中位数作为阈值。距离小于等于中位数的放进"近半"（left），大于中位数的放进"远半"（right）。递归对两半分别建树。

每个节点存储：vantage point 的坐标（或数据指针）、距离阈值（中位数）、左子树指针、右子树指针。

knn(query, k) 查询的实现——维护一个最大堆存放当前 k 个最近邻。搜索时先算查询点到当前节点 vantage point 的距离 d。如果 d ≤ 阈值就先搜左子树（近半），否则先搜右子树（远半）。搜完一边后检查另一边是否需要搜索——如果 |d - 阈值| < 堆顶距离，说明另一边可能有更近的点，也要搜。

demo 里用欧氏距离做 2D 点搜索验证正确性。随机生成 10000 个二维点建树，做 100 次 knn(k=5) 查询，结果和暴力搜索逐条比对，确保完全一致。

gcc 能编译通过就行，纯标准库。
