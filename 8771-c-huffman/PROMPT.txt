压缩算法里哈夫曼编码是最经典的入门案例，原理简单到一句话就能说清——频率高的字符用短编码，频率低的用长编码。但真要实现一个完整的压缩/解压工具，细节还是挺多的：位流怎么读写、最后一字节不满 8 位怎么办、编码表怎么存到压缩文件里。

用纯 C 实现哈夫曼编码的压缩和解压。压缩流程：先扫描一遍输入文件统计每个字节值的出现频率（256 个槽位的计数数组），用频率构建最小堆，不断取出堆顶两个节点合并成新节点再放回去，最终得到哈夫曼树。从树根到每个叶子的路径就是该字节的编码（左 0 右 1）。然后用编码表把输入文件的每个字节翻译成 bit 流输出。

解压流程：从压缩文件中读取编码表（或者直接存树结构），重建哈夫曼树。然后逐 bit 读取压缩数据，沿着树从根往下走——遇到 0 走左，遇到 1 走右，到达叶子就输出对应字节并回到树根。

压缩文件格式：魔数（2 字节标识这是哈夫曼压缩文件）→ 编码表（或者树的序列化，比如 256 个条目，每条是"字节值 + 编码长度 + 编码位"）→ 原始文件长度（8 字节）→ 压缩后的 bit 流数据。解压时用原始文件长度知道什么时候停。

最后一个字节不满 8 位的情况用 padding 补齐，在文件头里记录有效的 bit 位数。

命令行：huffman compress input.bin output.huf、huffman decompress output.huf restored.bin。解压后的文件要和原文件字节一致。gcc 编译。
