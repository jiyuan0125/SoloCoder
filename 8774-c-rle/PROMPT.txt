RLE 是最简单的压缩算法，简单到很多人觉得不值得单独实现。但实际上它的应用场景比想象中广——BMP 位图、传真编码、某些 PNG 的过滤模式，底层都是 RLE 或者它的变体。不过最朴素的 RLE 有个致命问题：对不重复的数据反而会膨胀（每个字节前面都要加个计数 1），所以实用版本要区分"重复序列"和"不重复序列"两种模式。

用 C 实现 RLE 编解码，支持两种模式。模式一：对连续重复字节做 count-byte 编码——遇到 3 个以上连续相同的字节，输出 (count, byte)，count 最大 255。模式二（关键）：对不重复的数据段，输出一个特殊的标记字节（比如 count 的最高位设 1 表示后面跟的是不重复数据），然后跟上原始字节，不压缩也不膨胀。

编码流程：扫描输入数据，统计连续重复字节的长度。如果重复次数 ≥ 3 就输出压缩格式 (count, byte)；如果重复次数 < 3 或者不重复，就把连续的不重复字节攒起来，攒够一批后输出不重复标记 + 长度 + 原始字节。

解码流程：读取每个 token 的第一个字节作为控制字节。最高位为 0 表示后面跟的是要重复的字节（重复次数 = 控制字节的值），最高位为 1 表示后面跟的是不重复的原始字节（数量 = 控制字节 & 0x7F）。

文件格式：文件头 4 字节（魔数 + 原始数据长度），然后是 RLE 编码后的数据。

命令行：rle encode input.raw output.rle、rle decode output.rle restored.raw。验证编解压一致性。用位图数据和随机数据分别测试压缩率。gcc 编译。
