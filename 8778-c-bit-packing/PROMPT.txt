列式存储引擎（比如 Parquet、ORC）里有一个很基础但很重要的优化——bit packing。原理很简单：如果一列数据的所有值都在 [0, 63] 范围内，那每个值只需要 6 个 bit 存，不需要用完整的 32 位 int。32 个 int 原来要 128 字节，bit packing 后只要 24 字节，节省 81%。

用 C 实现 Bit Packing 算法。输入一个 int32 数组和一个 bits 参数（每个值用多少 bit 表示，范围 1~32），把数组紧凑地打包成字节数组。输出字节数组的长度是 ceil(len * bits / 8)。

打包函数 pack(input, len, bits, output)：按顺序把每个值的低 bits 位追加到输出 bit 流中。每个值占 bits 个 bit，跨字节边界时要拆分——当前字节剩余空间不够就填满当前字节，剩余的位放到下一个字节的高位。比如 bits=5，第一个值占第 0 字节的 bit 0~4，第二个值占第 0 字节的 bit 5~7 加上第 1 字节的 bit 0~1。

解包函数 unpack(packed, len, bits, output)：逆向操作，从紧凑的 bit 流中逐个提取 bits 位的值还原为 int32。

跨字节对齐的处理要特别注意——用位运算（移位 + 掩码）而不是逐 bit 操作，性能好得多。可以先处理完整的字节，再处理剩余的 bit。

接口还要支持 SIMD 友好的批量版本（一次处理 32 个值）就更完美了，不过简单版本先保证正确性。
