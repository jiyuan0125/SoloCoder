归并排序应该是每个程序员都写过的排序算法了，但大部分实现只做了内存排序。真正有意思的部分是外部归并排序——给一个放不进内存的大文件做排序，分块排序加多路归并。这个思路不仅适用于排序本身，LSM 存储引擎的 compaction、大文件去重、分布式排序的 reduce 阶段都用到了同样的模式。

用 C 实现归并排序，要求同时支持内部排序和外部排序两种模式。内部排序就排内存里的数组，标准递归版或者自底向上版都行，注意用临时数组做合并时不要反复 malloc/free，一次性分配好复用。

外部排序是重点。输入是一个大文件（每行一个记录），内存只能放 buffer_size 大小的数据。流程：第一阶段分块读取文件，每块在内存里排序后写成一个临时文件（run file）。第二阶段用 k-way merge 把所有 run file 归并成最终的有序文件。

k-way merge 用最小堆实现：堆里维护每个 run file 当前读到的最小值和文件句柄。每次从堆顶取出最小元素写入输出，然后从对应的 run file 补充下一个元素到堆里。k 的值和每个 run file 的缓冲区大小都可以通过命令行参数配置。k 越大归并轮数越少但每轮内存开销也越大。

临时文件的管理要干净——归并完成后自动删除所有 run file。

命令行：mergesort --input=data.txt --output=sorted.txt --buffer=64M --k=16。验证排完后文件确实有序（每行和前一行比较）。gcc 编译。
