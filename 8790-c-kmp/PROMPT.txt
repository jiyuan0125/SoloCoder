字符串匹配能不能做到主串指针不回退？KMP 算法说可以——关键在于预处理模式串的时候算出一个 next 数组（也叫部分匹配表），告诉你失配后应该跳到模式串的哪个位置继续比较，而不是从头开始。这个预处理本身也是个精巧的自匹配过程。

用 C 写 KMP 字符串匹配算法。先实现 next 数组的计算：next[0] = -1（或 0，取决于约定），next[i] 表示 pattern[0..i-1] 这个前缀中，最长的真前缀同时也是真后缀的长度。计算过程：设两个指针 i=1、j=0，如果 pattern[i] == pattern[j] 则 next[i+1] = j+1，i++ j++；否则 j 回退到 next[j]，如果 j == -1 了就 next[i+1] = 0，i++ j=0。

有了 next 数组后，匹配过程就很简单了：i 指主串，j 指模式串，逐字符比较。相等则 i++ j++，j 到了模式串末尾就找到一个匹配，记录位置后 j 回退到 next[j] 继续找下一个匹配。不等则 j 回退到 next[j]，如果 j == -1 就 i++ j=0。

要求实现三个功能：kmp_first(pattern, text) 返回第一次匹配的位置（-1 表示没找到）；kmp_all(pattern, text) 返回所有匹配的起始位置数组；lcs_string(str_a, str_b) 找两个字符串的最长公共子串——用 KMP 的思路或者滑动窗口的方式都行。

命令行：kmp_search pattern text，输出所有匹配的起始位置（0-indexed）。gcc 编译。
