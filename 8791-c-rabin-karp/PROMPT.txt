Rabin-Karp 的妙处在于用哈希来做字符串匹配——算出模式串的哈希值，然后在主串上用一个滑动窗口 O(1) 更新哈希，哈希值一样了再逐字符确认。多模式匹配的时候尤其好用，多个模式串长度相同的话同一个窗口就能同时检查所有模式。

用 C 实现 Rabin-Karp 字符串匹配算法。哈希函数用多项式滚动哈希：H(s[0..n-1]) = s[0]*d^(n-1) + s[1]*d^(n-2) + ... + s[n-1]，d 是基数（选一个质数，比如 257 或 1013）。滑到下一个位置时：new_hash = (old_hash - s[i]*d^(n-1)) * d + s[i+n]。取模避免溢出，模数选个大质数（比如 2^61-1 用快速乘法，或者直接用 unsigned long long 自然溢出取模 2^64）。

支持两种模式：单模式匹配 rk_search(pattern, text) 输出所有匹配起始位置；多模式匹配 rk_multi_search(patterns[], count, text) 对多个等长模式串做匹配——所有模式串的哈希值预计算好存到哈希表里，每次窗口更新后在哈希表里查，命中则逐个确认是哪个模式。

哈希碰撞处理：哈希值匹配后做一次完整的字符串比较确认是真匹配。实际上选好参数后碰撞概率极低，但确认步骤不能省。

命令行：rk_search pattern text，输出所有匹配起始位置。也支持 rk_search -f patterns.txt text 从文件加载多个模式。gcc 编译通过。
