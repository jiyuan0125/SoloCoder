LCS（最长公共子序列）和最长公共子串不一样——子序列不要求连续，只要保持原来的相对顺序就行。比如 "ABCBDAB" 和 "BDCAB" 的 LCS 是 "BCAB"，长度 4。版本控制系统的 diff 算法、生物学里的序列比对，底层都是 LCS 或它的变体。

用 C 实现 LCS 算法。标准 DP：dp[i][j] = dp[i-1][j-1]+1（如果 A[i-1]==B[j-1]），否则 max(dp[i-1][j], dp[i][j-1])。时间和空间 O(mn)。m 和 n 分别是两个字符串的长度。

空间优化版：dp 只依赖上一行，所以只需要两行。但如果只需要 LCS 长度不需要具体序列，这个优化就够了。如果需要回溯输出具体的子序列内容，就得保留完整的 dp 矩阵（或者用 Hirschberg 算法做 O(min(m,n)) 空间版本，不过实现复杂度高）。

回溯输出 LCS 序列：从 dp[m][n] 出发，如果 A[i-1]==B[j-1] 且 dp[i][j]==dp[i-1][j-1]+1，说明这个字符在 LCS 里，加入结果并往左上角移动；否则往 dp 值更大的方向移动。

再加一个 LCS 距离的计算：dist = m + n - 2 * lcs_length。这个距离满足度量空间的三角不等式。

命令行：lcs "ABCBDAB" "BDCAB"，输出 LCS 长度、具体子序列内容、LCS 距离。也支持从文件读取两个字符串。gcc 编译。
