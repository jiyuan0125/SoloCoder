写一个类似 git diff 的文本比较工具——比较两个文件，找出增删改的地方，输出 unified diff 格式的结果。听起来简单，但要做好其实涉及不少细节：按行做 LCS 找公共行、处理相邻变更的合并、上下文的展示。

用 C 写一个 Diff 算法。输入是两个文本文件（old.txt 和 new.txt），输出 unified diff 格式。核心步骤：

第一步按行做 LCS：把两个文件的每一行作为元素，用 LCS 算法找最长的公共行序列。LCS 里的行是"没变的"，LCS 之外的行就是增删。

第二步标记变更：遍历两个文件，根据 LCS 结果标记每行是"不变"、"删除"（只在 old 里有）还是"新增"（只在 new 里有）。连续的删除和新增组成一个变更块（hunk）。

第三步生成输出：对每个 hunk，输出头部的 @@ -old_start,old_count +new_start,new_count @@，然后输出上下文行（变更前后各 3 行）和变更行（+ 开头表示新增，- 开头表示删除，空格开头表示上下文）。

如果想做得更好，可以在变更块内部做行内 diff——对被删除的旧行和被新增的新行（如果它们相邻的话）用编辑距离找最小编辑方案，在行级别标注具体哪个字符变了。

命令行：diff_tool old.txt new.txt，把 diff 结果输出到 stdout。gcc 编译。
