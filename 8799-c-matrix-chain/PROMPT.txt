矩阵乘法满足结合律——A*B*C 可以算成 (A*B)*C 也可以算成 A*(B*C)，数学结果一样但乘法次数差别巨大。如果 A 是 10x100、B 是 100x5、C 是 5x50，(AB)C 要 10*100*5 + 10*5*50 = 7500 次，A(BC) 要 100*5*50 + 10*100*50 = 75000 次，差了 10 倍。矩阵链乘法就是找到加括号的最优方式使总乘法次数最少。

用 C 实现矩阵链乘法的最优括号化。DP 求解：m[i][j] = 矩阵链 A_i...A_j 的最少乘法次数。转移方程 m[i][j] = min(m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j])，对 k 从 i 到 j-1 枚举所有可能的断点。p 数组是维度序列——A_1 是 p[0]*p[1]，A_2 是 p[1]*p[2]，等等。同时用 s[i][j] 记录最优断点 k，用来还原括号位置。

DP 的填表顺序：按链长 len 从 2 到 n 递增，对每个 len 枚举起始位置 i，j = i + len - 1。

括号化输出：递归函数 print_parens(s, i, j)——如果 i == j 直接输出 "A_i"，否则输出 "(" + print_parens(s, i, s[i][j]) + print_parens(s, s[i][j]+1, j) + ")"。

命令行：输入维度序列（从命令行参数或文件，比如 "10 100 5 50" 表示三个矩阵），输出最少乘法次数和最优括号化方案。gcc 编译。
