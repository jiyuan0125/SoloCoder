帮我写一个 SQL 注入检测工具，用 Go 实现。

背景：公司有个内部代码审计平台，需要静态扫描 Go 代码里的 SQL 拼接问题。

功能要求：
- 递归扫描指定目录下所有 .go 文件，找出字符串拼接构造 SQL 语句的地方（fmt.Sprintf + "SELECT/INSERT/UPDATE/DELETE" 这种模式）
- 能识别常见的危险写法：字符串拼接、fmt.Sprintf、字符串 + 运算符拼接 SQL
- 输出检测结果时标注文件名、行号和匹配到的危险代码片段
- 支持通过命令行参数指定扫描目录，比如 `./sqli-detector ./src`

只用 Go 标准库，go build 能编译通过就行。
