写一个 SSRF 防护工具，Go 实现。

背景：我们的服务有个 URL 预览功能，用户填一个 URL 服务端去抓取内容，结果被安全团队打了个 SSRF 漏洞。

功能需求：
- URL 校验：解析用户输入的 URL，检查 scheme（只允许 http/https）、检查 host 格式
- DNS 解析后检查 IP：防止通过域名指向内网 IP（127.0.0.1、10.x、172.16-31.x、192.168.x、0.0.0.0 等）
- 支持 IP 黑名单和网段配置
- 包装 http.Client 的 CheckRedirect，防止通过 302 跳转到内网地址

只用 Go 标准库，go build 能通过。
