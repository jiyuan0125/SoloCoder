系统需要对接 GitHub 和 Google 的 OAuth2 登录，不想引大而全的第三方库。自己写一个轻量客户端，把 Authorization Code 流程从头到尾实现一遍，包括 PKCE 安全扩展。

用 Go 写一个 OAuth2 客户端。Authorization Code 流程：生成授权 URL（拼装 authorize endpoint + client_id + redirect_uri + scope + state 参数），在浏览器中打开让用户授权。启动一个临时 HTTP 服务器监听 redirect_uri 等待回调，接收授权码 code。用 code 调用 token endpoint 换 access_token 和 refresh_token。

PKCE 扩展：自动生成 code_verifier（43~128 个字符的随机字符串，Base64URL 编码）和 code_challenge（SHA256(code_verifier) 的 Base64URL 编码，S256 方式）。授权请求带上 code_challenge 和 code_challenge_method=S256，token 请求带上 code_verifier。这样即使授权码被截获也无法使用。

Token 管理：access_token 过期后自动用 refresh_token 刷新，新的 response 会返回新的 refresh_token。token 安全存储到本地文件（文件权限 0600），加密可选项。

CLI 示例：启动本地 HTTP 服务器接收回调，完成完整的 OAuth2 登录流程后打印用户信息（调用 userinfo endpoint）。

Go 标准库，go build 编译通过。
