写一个 API Key 管理工具，Go 实现。

微服务架构下各个服务之间用 API Key 做认证，现在 key 都是 Excel 管的，太乱了。

功能需求：
- 生成安全的 API Key：随机 32 字节 Base62 编码，支持自定义前缀（如 svc_a_xxx）
- Key 状态管理：创建、激活、停用、吊销，每个 key 关联服务名和权限范围
- Key 校验：验证 key 格式、查询状态、检查是否过期和权限范围
- 本地文件存储（JSON 格式），支持导入导出
- 命令行：`./apikey create --service=user-svc --scope=read,write`、`./apikey verify --key=xxx`

Go 标准库，go build 能通过。
