帮我实现一个 Token 吊销管理工具，Go 写的。

JWT 是无状态的，一旦签发就没法直接撤回，需要一套吊销机制来处理 token 泄露和用户登出场景。

要实现：
- Token 黑名单：记录被吊销的 token ID（jti）或整个 token 的哈希值
- 支持两种吊销模式：精确吊销（单个 token）和批量吊销（按用户 ID 吊销该用户所有 token）
- 黑名单存储用本地文件，加载到内存做快速查询
- 自动清理过期的黑名单条目，避免无限增长
- HTTP 接口：POST /revoke 吊销、GET /check?token=xxx 查询吊销状态

Go 标准库，go build 编译通过。
