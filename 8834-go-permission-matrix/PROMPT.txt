后台有十几个模块、几十个角色，权限配置散落在各处，谁也说不清楚某个角色到底能干什么。需要用一个统一的权限矩阵来管理——行是资源和操作，列是角色，单元格是允许或禁止。一目了然。

用 Go 写一个权限矩阵管理工具。矩阵定义：行标识是 "资源:操作"（如 article:read、article:write、user:delete），列标识是角色名（如 admin、editor、viewer）。每个单元格的值是 true（允许）或 false（禁止）。

矩阵操作：Set(resource, action, role string, allow bool) 设置单个单元格。Get(resource, action, role string) bool 查询单个权限。批量设置 SetRow(resource, action string, roles map[string]bool) 为一个操作设所有角色的权限。

矩阵运算：MergeRoles(roleA, roleB string) map[string]bool 取两个角色权限的并集——某个操作任一角色允许就允许。IntersectRoles(roleA, roleB string) map[string]bool 取交集——两个角色都允许才允许。ConflictDetect() []Conflict 检测矩阵中的矛盾——同一操作在不同角色间的权限差距过大（比如 viewer 比 editor 权限还多）。

导出功能：ExportCSV() 输出 CSV 格式的矩阵表（第一行是角色名，第一列是资源操作）。ExportJSON() 输出结构化 JSON。方便审计和文档化。

命令行：matrix check --role=editor --resource=article --action=delete，matrix export --format=csv --output=permissions.csv，matrix load permissions.json。

Go 标准库，go build 编译通过。
