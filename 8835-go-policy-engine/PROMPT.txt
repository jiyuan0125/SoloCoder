帮我实现一个通用策略引擎，Go 写的。

像 OPA 那样的策略引擎太重了，我想要一个轻量的内嵌式策略判断引擎，能在代码里直接用。

功能需求：
- 策略定义语言：简单的 DSL，支持条件表达式（==、!=、>、<、in、contains）和逻辑运算（AND、OR、NOT）
- 策略评估：输入一组属性（JSON），根据策略规则计算 allow 或 deny
- 支持多条策略的优先级排序和冲突解决（deny 优先 或 按优先级）
- 内置函数：time_range（时间范围）、ip_in_cidr（IP 网段判断）、regex_match
- 策略热加载：从 JSON 文件加载，支持运行时更新

Go 标准库，go build 能通过。
