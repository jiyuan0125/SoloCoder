公司要过等保（等级保护）认证，需要自动检查代码和配置的合规性。靠人工逐条对照检查清单太慢了，一个项目几百个检查点，完全看不过来。

用 Go 写一个合规性检查工具。检查规则用 JSON 配置文件定义，每条规则包含：rule_id（规则编号）、name（检查项名称）、category（分类：密码策略、日志配置、传输安全、敏感信息等）、severity（严重程度：critical/high/medium/low）、check_type（检查方式：file_pattern 文件内容匹配、file_exists 文件存在性检查、config_value 配置值检查）、pattern（匹配模式，正则表达式）、fix_suggestion（修复建议）。

内置常见检查规则：密码策略——检查密码最小长度、是否要求复杂度、是否有弱密码列表。日志配置——检查是否启用了访问日志、日志是否包含必要字段。HTTPS 强制——检查是否有 HTTP 重定向到 HTTPS 的配置。敏感信息硬编码——检查源码中是否有硬编码的密钥、密码、token。

扫描流程：加载规则文件，递归遍历指定目录，对每个文件按规则逐条检查。匹配到问题后记录文件路径、行号、匹配内容和触发的规则。

报告生成：输出 JSON 格式的合规报告——通过/未通过统计、按严重程度分布、每个问题的详情和修复建议。也支持输出简洁的终端表格。

命令行：compliance-checker scan ./project --rules=rules.json --output=report.json。

Go 标准库，go build 能通过。
