日志里不小心打印了用户手机号和身份证号，被安全审计发现后紧急修复。但这种问题靠 code review 很难完全避免——总有人写 log.Infof("user info: %v", userInfo) 不小心把整个 struct 打出来。需要写个工具定期扫描日志文件检测敏感信息泄露。

用 Go 写一个 PII（个人身份信息）检测工具。内置检测规则（正则表达式）：中国大陆手机号（1[3-9]\d{9}，前后不是数字）、身份证号（18位或15位格式，简单校验位验证）、邮箱地址（标准 email 格式）、银行卡号（16-19位数字，Luhn 校验）、IP 地址（IPv4 格式）、信用卡号（Visa/Mastercard/UnionPay 格式）。支持通过 JSON 配置文件添加自定义检测规则——规则名、正则表达式、严重程度、掩码方式。

扫描功能：ScanFile(filePath string) []PIIFinding——逐行读取文件，对每行应用所有检测规则，记录匹配到的 PII 类型、行号列号、原始内容。输出时对原始内容做部分掩码（如 138****1234、3201**********5X）。

命令行模式：pii-detector scan /var/log/app/ --rules=custom.json 递归扫描目录下所有文本文件。也支持从 stdin 管道输入实时检测。输出报告包含按 PII 类型分类的统计（每种类型出现了多少次），以及详细的发现列表。支持 JSON 格式输出。

Go 标准库，go build 能编译。
