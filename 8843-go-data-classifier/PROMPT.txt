数据安全治理第一步是搞清楚有哪些数据、分别是什么敏感级别。新来的安全负责人问"我们有哪些敏感数据存在哪"，没一个人能说清楚。需要一个工具自动扫描数据字段做分类。

用 Go 写一个数据分类工具。分类级别四级：公开（Public）——不包含任何个人信息或商业秘密；内部（Internal）——仅限公司内部使用；敏感（Sensitive）——包含个人信息或需要访问控制的数据；机密（Confidential）——高度敏感数据如密码、密钥、财务数据。

自动扫描支持两种数据源：结构化数据文件——解析 CSV（第一行为字段名）、JSON（键值对）的字段名和内容样本。Go 源码——扫描 struct tag（json、db、yaml 标签）和变量定义。

分类规则：基于字段名关键词——含 password/secret/key/token → 机密；含 email/phone/address/name → 敏感；含 id/type/status/count → 内部；其余 → 公开。基于内容模式——字段名 + 内容样本双重判断，减少误报。比如字段名含 email 但内容不是邮箱格式就降为内部。

支持自定义规则：通过 JSON 配置文件定义"字段名关键词 + 内容模式 → 分类级别"的映射。规则优先级：自定义规则 > 内置规则。

输出分类报告：每个字段的分类结果、判定依据（匹配了哪条规则）、数据样本（脱敏后的前几条数据）。

Go 标准库，go build 通过。
