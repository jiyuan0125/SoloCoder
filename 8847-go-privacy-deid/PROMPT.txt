测试环境需要脱敏数据，但不能简单地把所有敏感字段替换成 "REDACTED"——那样数据特征全丢了，测试出来的性能和行为跟生产完全不一样。需要保持数据格式和分布特征的脱敏。

用 Go 写一个隐私数据去标识化工具。支持四种去标识化方法：

掩码（Masking）：保留部分原始字符，其余用 * 替换。手机号 13812345678 → 138****5678（保留前 3 后 4）。身份证 320123199001011234 → 3201**********1234。自定义保留的前后位数。

替换（Substitution）：用同格式的随机数据替换原始值。邮箱 zhang@example.com → liu52@example.net（随机用户名 + 随机域名）。姓名 张三 → 王五（从内置的姓/名列表随机组合）。地址 上海市浦东新区XX路 → 广州市天河区YY路（保持地址格式）。替换表持久化保证同一输入同一输出（可确定性随机）。

泛化（Generalization）：降低数据精度。年龄 28 → 25-30（5 岁区间）。邮编 200001 → 200***（只保留前 3 位）。时间 2024-01-15 14:32 → 2024-01（只保留月份）。

哈希（Pseudonymization）：SHA-256 哈希后截取前 16 字符。不可逆但可关联——同一输入始终产生同一伪名。

按字段配置去标识化规则（JSON 文件），支持批量处理 JSON 和 CSV 格式的数据文件。

命令行：privacy-deid process data.json --rules=deid-rules.json --output=deid-data.json。Go 标准库，go build 编译通过。
