Argon2 是 2015 年密码哈希竞赛的冠军，Password Hashing Competition 的推荐方案。它同时抗 GPU 和 ASIC 攻击，可配置内存消耗、时间消耗和并行度。现在是 OWASP 推荐首选的密码哈希算法。

用 Go 写一个 Argon2id 密码哈希 CLI 工具（用 Go 扩展库 golang.org/x/crypto/argon2）。Argon2id 是 Argon2 的混合模式——前半段用 Argon2i（抗侧信道），后半段用 Argon2d（抗 GPU），兼顾安全性和性能。

hash 子命令：调用 argon2.IDKey(password, salt, time, memory, threads, keyLen)。参数：time=1（迭代次数）、memory=65536（内存 64MB）、threads=1（并行线程数）、keyLen=32。生成随机 16 字节 salt。输出 PHC 格式字符串：$argon2id$v=19$m=65536,t=1,p=1$base64_salt$base64_hash。PHC 格式是密码哈希的标准存储格式，可以直接存数据库。

verify 子命令：解析 PHC 格式字符串提取参数。用相同的参数和 salt 对输入密码重新计算 Argon2id。恒定时间比较哈希值。

参数配置：-memory KB 数（默认 65536 即 64MB）；-time 迭代次数（默认 1）；-threads 并行线程数（默认 1）。推荐参数参考 OWASP：memory=65536, time=1, threads=4 对于普通 Web 应用足够。

命令：argon2-tool hash -pass "mypass"、argon2-tool hash -pass "mypass" -memory 131072 -time 3 -threads 4、argon2-tool verify -pass "mypass" -hash "$argon2id$v=19$..."。

Go 的 golang.org/x/crypto/argon2，go build 能编译。
