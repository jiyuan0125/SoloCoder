Passkey 底层就是 WebAuthn，但有些用户数据和流程需要额外处理——比如生成注册和认证的挑战、验证响应流程是否完整。需要一个能覆盖完整 Passkey 流程的工具。

用 Go 写一个 Passkey 数据处理工具。challenge 子命令：生成随机 challenge（32 字节，Base64URL 编码）用于注册或认证请求。输出 JSON 格式的 PublicKeyCredentialCreationOptions 或 PublicKeyCredentialRequestOptions 的结构（包含 rp、user、challenge、pubKeyCredParams 等）。

verify-registration 子命令：输入 challenge（Base64URL）和注册响应 JSON。验证流程——clientDataJSON 的 type 是否 "webauthn.create"。challenge 是否和之前生成的一致。origin 是否匹配预期值。authenticatorData 的 flags 中 UP（用户在场）位是否为 1。解析 COSE 公钥提取 credential 公钥。

verify-auth 子命令：输入 challenge、认证响应 JSON 和已存储的 credential 公钥。验证——clientDataJSON 的 type 是 "webauthn.get"。challenge 匹配。签名计数器没有回退（防克隆）。用存储的公钥验证签名。

命令：passkey-handler challenge -rp "example.com" -user "testuser"、passkey-handler verify-registration -challenge <base64> -response <json-file>、passkey-handler verify-auth -challenge <base64> -response <json-file> -credential <base64-pubkey>。

Go 标准库实现，go build 能编译通过。
