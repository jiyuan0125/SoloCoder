普通 TCP connect 扫描会留下完整的连接日志，目标服务器的应用层会记录这次连接。SYN 半开扫描只发 SYN 包不完成三次握手，服务端只会记一条内核层的 SYN 日志，应用层无感知。当然这是用于授权的安全测试。

用 Go 写一个 SYN 半开扫描工具。核心流程：构造原始 TCP SYN 包——IP header（版本=4、协议=TCP、源 IP 和目的 IP）+ TCP header（SYN 标志、源端口随机、目的端口、序列号随机）。发送原始包。监听响应——收到 SYN-ACK 说明端口开放（回一个 RST 防止对方继续等待）；收到 RST 说明端口关闭；超时无响应标记为 filtered。

实现方式：用标准库 net.ListenPacket("ip4:tcp", "0.0.0.0") 创建原始套接字收包。发包需要构造 IP+TCP 的字节序列，TCP 校验和需要计算（含伪首部）。

端口范围和并发控制：支持端口范围（-ports 22,80,443 或 -ports 1-1024）和并发数（-workers 200）。每个端口一个 goroutine 发包，共享一个 listener 收响应并做匹配（根据源端口+序列号关联请求和响应）。

超时和重试：单端口超时默认 3 秒。无响应的端口重试一次。

命令：syn-scanner scan -target 192.168.1.1 -ports 22,80,443、syn-scanner scan -target 10.0.0.1 -ports 1-1024 -workers 200。

需要 root 权限运行（原始套接字）。Go 标准库 net 包加 syscall，go build 通过。
