有些重要的服务跑在 UDP 上——DNS(53)、SNMP(161)、mDNS(5353)、NTP(123)、TFTP(69)。TCP 扫描扫不到它们。UDP 扫描的原理不同：发一个 UDP 包到目标端口，如果收到回复说明端口 open，如果收到 ICMP Port Unreachable 说明 closed，超时无响应可能是 open|filtered。

用 Go 写一个 UDP 端口扫描工具。核心逻辑：构造 UDP 探测包发送到目标端口。同时监听 ICMP 响应（需要 raw socket）和 UDP 回复。解析结果——收到 UDP 回复→open，收到 ICMP Type 3 Code 3（Port Unreachable）→closed，超时→open|filtered。

服务识别辅助：对常见 UDP 服务发送特定 payload 提高识别率——DNS 端口发一个标准 DNS 查询（A 记录查询 example.com），SNMP 端口发 SNMPv1 GET 请求（community public，OID 1.3.6.1.2.1.1.1.0），NTP 端口发 NTP 版本请求。收到对应格式的回复就能确认服务类型。

扫描配置：-ports 指定端口列表、-timeout 单端口超时（默认 3 秒，UDP 比 TCP 需要更长超时）、-retries 无响应时重试次数（默认 2 次）。

命令：udp-scanner scan -host 192.168.1.1 -ports 53,123,161,5353、udp-scanner scan -host 10.0.0.1 -ports 1-1024 -timeout 3s。

Go 标准库 net 包，go build 通过。
