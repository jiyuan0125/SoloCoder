等保测评扫出来一堆 SSH 弱算法——还在用 diffie-hellman-group1-sha1 做密钥交换、ssh-rsa 签名、3des-cbc 加密。几十台服务器逐个手动排查根本来不及，写个工具自动连上去把 ServerHello 里的算法列表全拽出来，和弱算法黑名单比对。

用 Go 写一个 SSH 服务审计工具。audit 子命令：用 crypto/ssh 连接目标 SSH 服务器（只做密钥交换不实际登录），从 ServerHello 中获取支持的算法列表——密钥交换算法（kex）、服务器密钥算法（host key）、加密算法（cipher）、MAC 算法、压缩算法。

安全检查：弱密钥交换——diffie-hellman-group1-sha1、diffie-hellman-group14-sha1（SHA-1 不安全）。弱加密——aes128-cbc、aes256-cbc、3des-cbc（CBC 模式有 padding oracle 问题）。弱 MAC——hmac-md5、hmac-sha1（太短）。弱密钥类型——ssh-rsa（SHA-1 签名）、ssh-dss（DSA 密钥太短）。检查服务器密钥长度——RSA 密钥是否 >= 2048 位、ECDSA 是否 >= P-256。

输出格式：按类别列出所有支持的算法，标记弱算法。给出安全建议——推荐禁用哪些算法、推荐添加哪些算法。支持 JSON 输出。

命令：ssh-audit audit -host 192.168.1.1 -port 22、ssh-audit audit -host 192.168.1.1 -json。

Go 标准库 crypto/ssh，go build 能编译通过。
