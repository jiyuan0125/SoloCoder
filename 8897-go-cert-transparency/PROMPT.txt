写个证书透明度（Certificate Transparency）日志查询工具，Go 实现。

CT 日志里记录了所有公开信任的 TLS 证书签发记录，可以用来监控有没有人为你的域名签发了未授权的证书。

功能：查询指定域名在 CT 日志中的所有证书记录；展示证书签发时间、颁发者、是否过期；检测可疑证书（非预期的颁发者）；支持按时间范围过滤。

命令：cert-transparency search -domain example.com、cert-transparency search -domain example.com -issuer "Let's Encrypt" -json、cert-transparency search -domain example.com -after 2024-01-01
通过公开 CT API 查询，Go 标准库 net/http，go build 通过。
