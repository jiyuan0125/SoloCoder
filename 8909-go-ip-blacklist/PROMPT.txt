运维同事需要维护一个 IP 黑名单来封禁恶意访问。目前黑名单散落在各个 iptables 规则和 Nginx 配置里，管理混乱，添加删除都要手动改配置重载服务。需要一个集中的黑名单管理工具。

用 Go 写一个 IP 黑名单管理 CLI。数据存储：黑名单存在本地 JSON 文件中，每条记录包含 IP 或 CIDR、添加时间、添加原因备注、操作者。支持三种 IP 格式——单 IP（192.168.1.100）、CIDR 网段（10.0.0.0/24）、IP 范围（192.168.1.1-192.168.1.100）。

CRUD 操作：add --ip 192.168.1.100 --reason "暴力破解" 添加条目。remove --ip 192.168.1.100 删除条目。list 列出所有黑名单条目（表格显示）。check --ip 192.168.1.100 判断某个 IP 是否在黑名单中（支持 CIDR 匹配）。

导入功能：import --file threats.txt 从外部威胁情报列表导入（每行一个 IP 或 CIDR 的纯文本文件）。导入时自动去重。也支持导出——export --format=plain 输出纯 IP 列表供 iptables 或 Nginx 使用。

统计：黑名单总条目数、单 IP 和 CIDR 各多少、最近添加的 10 条。

Go 标准库实现，go build 能编译通过。
