有些 IP 一看就知道不怀好意——频繁扫描、暴力破解、发恶意请求。但单个事件可能不够封禁，需要一个累积的信誉评分系统，根据历史行为给 IP 打分，分数低的自动标记为可疑。

用 Go 实现一个 IP 信誉评估工具。本地数据库（JSON 或 SQLite）记录每个 IP 的历史行为事件。事件类型和扣分规则：端口扫描（-10 分/次）、暴力破解尝试（-20 分/次）、WAF 规则触发（-15 分/次，按严重程度加权）、恶意 User-Agent（-5 分/次）、异常高频请求（-8 分/次）。

信誉分计算：初始分 100（满分，表示可信）。每次事件按规则扣分，最低 0 分。分数区间：0-20 极度可疑、21-40 高度可疑、41-60 中度可疑、61-80 轻度可疑、81-100 可信。时间衰减：30 天前的事件权重减半，90 天前的权重为 0.1。防止一次小事件永久影响信誉。

命令行：ip-rep check --ip 192.168.1.100 查询单个 IP 的信誉详情（当前分数、历史事件列表、风险等级）。ip-rep import --file events.json 批量导入事件日志更新评分。ip-rep top --limit 10 查看信誉最低的 Top N 个 IP。ip-rep report 生成信誉分布报告。
