服务只想让特定国家/地区的用户访问，需要根据 IP 判断地理位置然后决定放行或拒绝。商用 GeoIP 数据库要花钱，但可以用免费的 GeoLite 数据集或者自己维护一个简化版的 IP 段归属表。

用 Go 写一个地域屏蔽工具。内置一个简化版 GeoIP 数据库——用 CSV 或 JSON 格式存储主要国家的 IP 段（不需要覆盖全部 IP，常见的 A/B/C 类段够用就行）。每条记录包含起始 IP、结束 IP、国家代码（ISO 3166-1 alpha-2）、国家名称。数据量大概几千条就能覆盖主要的 IP 段。

查询功能：lookup --ip 8.8.8.8 返回该 IP 的国家代码和国家名。判断逻辑：读取配置的策略——allow-list（允许的国家列表）或 deny-list（禁止的国家列表）。输入 IP 判断是否应该放行。

批量检测：batch --file ips.txt --policy allow --countries US,GB,DE 从文件读取 IP 列表批量检测。输出放行和拒绝的统计，以及每个 IP 的查询结果。

配置管理：允许从配置文件加载国家策略，支持运行时更新。

Go 标准库实现（IP 比较用 net.ParseIP + 字节比较），go build 通过。
