API 接口被爬虫疯狂刷，需要识别出机器人流量。不是所有自动化访问都是恶意的（搜索引擎爬虫是合法的），需要区分"好机器人"和"坏机器人"。

用 Go 写一个请求特征分析工具。从访问日志（JSON Lines 格式）中提取特征并分析：

User-Agent 分析：已知爬虫列表（Googlebot、Bingbot、Baiduspider 等）标记为合法爬虫。空 UA 或可疑 UA（python-requests、Go-http-client、curl/、Java/ 等）标记为疑似机器人。

访问频率分析：统计同一 IP 在指定时间窗口内的请求数——超过阈值（如 100 次/分钟）标记为高频访问。请求间隔分布——机器人的间隔通常很均匀（标准差小），人类访问的间隔更随机。

路径模式分析：访问路径是否有规律——递增的 ID（/api/user/1, /api/user/2, ...）、全量遍历、固定路径重复访问。

输出可疑 IP 列表和判断理由——哪些特征触发了判断。支持配置阈值参数。Go 标准库实现，go build 通过。
