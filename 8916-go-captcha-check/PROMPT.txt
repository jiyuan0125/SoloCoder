登录接口需要验证码服务——生成验证码、存储、验证、过期清理。不用 Redis，内存 map 就够。

用 Go 实现一个验证码服务。生成：generateCode(length int) string 生成随机数字验证码（默认 4 位，可配 6 位）。存储到内存 map 中——key 是 session ID，value 是 {code, expires_at, attempts}。设置过期时间（默认 5 分钟）。

验证接口：verifyCode(sessionID, userInput string) VerifyResult——查询 sessionID 对应的验证码。比对用户输入和存储的验证码（默认大小写不敏感，可配置）。验证后立即删除该条记录（一次性使用，防重放）。返回验证结果和失败原因。

防暴力破解：每条验证码最多验证 5 次，超过次数自动作废。同一 sessionID 频繁请求验证时加入冷却时间。

HTTP 接口：POST /captcha/generate 生成验证码，返回 session_id 和验证码值（实际生产中应该发短信/邮件，这里直接返回方便测试）。POST /captcha/verify 验证，body: {session_id, code}。GET /captcha/stats 统计信息（活跃验证码数量、今日生成/验证次数）。

配置参数：验证码长度、过期时间、最大验证次数、是否大小写不敏感。用 net/http 提供 REST 接口。go build 编译通过。
