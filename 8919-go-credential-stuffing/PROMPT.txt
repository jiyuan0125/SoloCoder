攻击者拿到泄露的账号密码数据库来撞库——不是暴力猜密码，而是用已知的"账号-密码"对逐个尝试。特征是同一个 IP 在短时间内尝试多个不同的账号，每个账号只试一次（因为密码大概率是正确的）。

用 Go 写一个撞库检测工具。从 JSON 格式的访问日志中分析登录行为。检测逻辑：统计每个 IP 在时间窗口内（默认 1 分钟）尝试的不同账号数量。阈值规则——同一 IP 在窗口内尝试超过 N 个不同账号（默认 5）就标记为撞库。同一账号被不同 IP 尝试也标记为可疑（可能是针对该账号的撞库）。

触发告警后输出详细报告：源 IP、时间窗口、尝试的账号列表、每个账号的登录结果（成功/失败）。区分两种情况——撞库失败（所有尝试都失败）和撞库成功（部分账号登录成功，需要立即处理这些账号）。

也支持实时监控模式：tail -f 访问日志，实时分析新的登录请求。Go 标准库，go build 编译通过。
