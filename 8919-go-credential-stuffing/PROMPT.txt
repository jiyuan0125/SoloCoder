攻击者拿到泄露的账号密码数据库来撞库——不是暴力猜密码而是用已知的账号密码对逐个尝试登录。特征很明显：同一个 IP 在短时间内尝试多个不同的账号，每个账号只试一次因为密码大概率已经在泄露库里了。跟暴力破解的区别在于每次尝试的密码都不同但命中率极高，这是目前最主流的账户接管攻击方式。

用 Go 写一个撞库检测工具。从 JSON 格式的访问日志中分析登录行为模式。检测逻辑分两层：统计每个 IP 在滑动时间窗口内默认 1 分钟尝试的不同账号数量，超过阈值默认 5 个就标记为撞库攻击源。反向检测同一个账号被多个不同 IP 尝试登录也标记为可疑可能是针对特定账号的定向撞库攻击。

触发告警后输出详细报告：源 IP 地址、时间窗口起止时间、尝试的账号列表以及每个账号的登录结果成功或失败。区分两种严重程度：撞库失败所有尝试都失败说明攻击被防御住了只需要记录事件。撞库成功部分账号登录成功这是紧急安全事件需要立即处理这些被泄露的账号强制重置密码并通知受影响用户。也支持实时监控模式持续 tail 读取新增日志实时分析并输出告警。Go 标准库，go build 通过。
命令行参数解析用标准库就行，不需要第三方包。确保在主流操作系统上能编译运行。
