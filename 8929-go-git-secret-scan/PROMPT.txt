Git 仓库历史里可能藏着泄露的密钥——当前代码里已经删除了但历史 commit 里还有。光扫描当前工作目录文件不够，必须扫描整个 git 历史所有 commit 的 diff 内容。

Go 写一个 Git 历史秘密扫描工具。扫描流程：执行 git log 获取所有 commit hash 列表。对每个 commit 执行 git diff 获取变更内容。在每个 diff 中用正则表达式搜索敏感信息模式——AWS Access Key 以 AKIA 开头、GitHub Token 以 ghp_ 开头、私钥块 BEGIN RSA PRIVATE KEY、JWT 格式 eyJ 开头、数据库连接串包含密码字段等常见模式。

输出格式：每次泄露包含 commit hash 截断到前 8 位方便查看、文件路径、行号、泄露的内容片段掩码后只显示前后几个字符。支持按作者筛选 --author、按时间范围筛选 --since 和 --until。统计汇总：总扫描了多少个 commit、发现多少次泄露、涉及哪些作者和哪些敏感类型。

git 命令调用用 os/exec 包不需要第三方 Git 库。go build 通过。
