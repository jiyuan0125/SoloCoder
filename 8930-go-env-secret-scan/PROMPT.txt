.env 文件经常被误提交到仓库里。.env 文件里有数据库密码、API Key、加密密钥这些最高价值的敏感信息，一旦泄露后果最严重。

用 Go 写一个专门的 .env 泄露扫描器。扫描范围：指定目录下的 .env、.env.local、.env.production、.env.staging、.env.development、.env.test 等所有环境变量文件。也扫描 git 历史（执行 git log --all --full-history -- "*.env*" 找出所有曾经存在的 .env 文件）。

识别高价值敏感变量名——DATABASE_URL、SECRET_KEY、API_KEY、PASSWORD、TOKEN、PRIVATE_KEY、AWS_SECRET_ACCESS_KEY、SMTP_PASSWORD、ENCRYPTION_KEY、JWT_SECRET。每个变量名按风险分级——高（密码、密钥、token）、中（连接串、URL 含凭据）、低（配置项但不含敏感值）。

输出扫描结果按风险等级排序。支持忽略 .env.example 和 .env.template 这类模板文件（只有占位符没有真实值）。go build 编译通过。
