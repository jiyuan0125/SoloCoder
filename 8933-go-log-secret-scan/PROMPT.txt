应用日志里有时会不小心打印出用户密码或 Token。这种泄露在日志管理平台、日志文件传输、甚至日志归档到 S3 的过程中都可能被利用。

用 Go 写一个日志文件敏感信息扫描工具。支持两种格式：纯文本日志（逐行扫描）和 JSON 格式日志（解析 JSON 后扫描每个字段的值）。

检测规则：信用卡号——用 Luhn 校验算法验证，匹配 Visa（4 开头 16 位）、Mastercard（5 开头 16 位）、UnionPay（62 开头）。手机号——中国大陆手机号模式。身份证号——18 位模式，校验位验证。邮箱地址——标准 email 格式。JWT Token——eyJ 开头。API Key 格式——AKIA 开头（AWS）等各种服务商前缀。

匹配到的内容自动脱敏显示——只显示前 3 后 4 个字符，中间用 * 代替。比如 138****1234、abcd****wxyz。

输出统计：哪些类型的敏感信息出现了多少次、分布在哪些行。支持递归扫描目录。Go 标准库，go build 通过。
