上周五发版差点出事——一个 Docker 镜像里不知道谁把 .env 文件塞进去了，里面全是数据库密码，直接推到了公网仓库。事后复盘发现，镜像构建流程里根本没有安全检查环节，全靠人工review。

用 Go 写一个容器镜像安全分析工具。核心要求是不依赖 Docker daemon，直接解析镜像 tar 包。具体来说，程序先读取本地保存的 .tar 格式镜像文件，解析 manifest.json 找到配置信息和层列表，然后逐层解压，扫描每一层里的文件路径和内容。

扫描维度要覆盖这几点：第一，检查是否有敏感文件被复制进镜像，比如 /etc/shadow、.env、*.pem、*.key、id_rsa 这些；第二，提取基础镜像信息，确认 FROM 指令指向的是哪个 base image；第三，统计镜像层数和每层大小，算出总大小；第四，检查镜像内是否安装了高危软件包（通过解析包管理器元数据），比如 telnetd、openssh-server 这类不该出现在应用镜像里的东西。

输出一份结构化的安全报告，按风险等级排序——Critical 是私钥泄露这类，High 是 shadow 文件、敏感配置，Medium 是基础镜像用了 latest、层数过多等。报告同时输出到终端和 JSON 文件。

工具做成 CLI 形式，接受镜像 tar 路径作为参数，也支持指定目录批量扫描。用 Go 标准库的 archive/tar、encoding/json、compress/gzip 来解析，不需要额外依赖。go build 编译通过就行。
