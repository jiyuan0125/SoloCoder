写一个 IaC 配置扫描工具，Go 实现，扫描 Terraform 和 Docker Compose 文件里的安全隐患。

程序的工作流程很简单：用户指定一个目录或单个文件路径，工具自动识别文件类型（.tf 走 Terraform 解析，.yml/.yaml 走 Compose 解析），提取关键配置项，逐条匹配安全规则，最后输出按文件分组的检查结果。

Terraform 侧重点检查这些问题：安全组或防火墙入站规则写了 0.0.0.0/0（等于对外全开）、RDS 或 ElasticCache 没有启用加密、S3 Bucket 没有开版本控制或日志、IAM policy 使用了通配符 * 的资源授权、明文写进了数据库密码（应该用变量引用）。Docker Compose 侧重点检查：容器配置了 privileged: true 特权模式、端口直接映射到宿主机高位端口、环境变量里硬编码了密码、挂载了 Docker socket 或宿主机根目录、使用了 latest 镜像标签。

解析策略用正则加字符串匹配，不需要完整的 HCL parser——识别 resource 类型名和关键属性值就够了。Compose 文件用标准库的 encoding/json 或简单的 YAML 解析（手写一个轻量解析器）。

每条结果输出文件路径、行号（如果定位得到）、风险等级、问题描述、修复建议。支持 --format json 参数切换输出格式。Go 标准库搞定，go build 编译通过。
