写一个 Go 的访问控制代理服务，实现基于属性的访问控制（ABAC）。

系统里有大量资源，每个资源有分类和敏感度标签，不同用户根据部门、职级、地域等因素拥有不同的访问权限。需要一个集中的访问决策点来统一处理鉴权请求。

工具的核心是一个 HTTP API 服务。接口接收鉴权请求，请求体里包含三个部分：主体属性（用户 ID、部门、职级、所在地区）、资源属性（资源 ID、资源分类、敏感度等级）、环境属性（当前时间、请求来源 IP、设备类型）。服务收到请求后，加载预定义的权限策略（JSON 文件），逐条评估是否匹配，返回三种结果之一——允许（allow）、拒绝（deny）、需要审批（需要上级确认）。

策略定义示例：如果用户部门是财务部 AND 资源分类是财务报表 AND 时间在工作时间内，则允许；如果资源敏感度是机密 AND 用户职级低于总监，则需要审批；如果来源 IP 不在可信网段列表内，则拒绝。策略之间有优先级，按配置顺序匹配。

API 返回 JSON 格式的响应，包含决策结果、匹配的策略 ID 和原因说明。策略文件通过 --policy 参数指定路径。Go 标准库实现，go build 能过就行。
