生产环境临时提权的流程是这样的：运维人员发现问题需要高级权限来排查，先在群里发消息申请，领导看到了回复同意，然后运维手动修改 IAM 角色或者 sudoers 配置，排查完经常忘记回收权限——这中间每一步都容易出纰漏。

写一个 Go 的 JIT（Just-In-Time）权限管理工具来规范化这个过程。把临时提权的申请、审批、执行、回收全部自动化。

工作流程：第一步，运维人员用 CLI 提交提权申请，指定要申请的角色（如 admin、dba）、持续时间（如 2 小时）、申请理由。系统生成一个申请记录，状态为 pending。第二步，审批人通过 CLI 查看待审批列表，approve 或 reject 指定的申请。审批通过后，系统自动给申请人授予对应角色的权限。第三步，计时器到时间后自动回收权限，状态变为 expired。也可以手动提前回收。第四步，所有操作（申请、审批、授权、回收）都记录审计日志，包含时间、操作人、角色、理由。

数据存储用本地 JSON 文件，结构简单——一个申请记录文件，一个审计日志文件。CLI 的子命令设计：jit request 提交申请、jit list 查看申请列表、jit approve/reject 审批、jit revoke 手动回收。Go 标准库实现，go build 通过。
