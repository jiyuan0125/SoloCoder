Go CLI 工具，威胁情报聚合和查询。从多个本地数据源读取威胁情报，做去重关联，然后支持快速查询。

工具维护一个本地的威胁情报库，数据来源是各种格式的本地文件——JSON 格式的 IP 黑名单、CSV 格式的恶意域名列表、纯文本的文件哈希列表。导入时自动识别格式，提取出 IOC 指标（IP 地址、域名、文件哈希、URL），统一存入内部数据结构。相同指标如果在多个来源中出现，合并记录并保留所有来源标注和置信度信息。

查询功能支持三种方式。按值查询：输入一个 IP、域名或哈希，查它是否在情报库中，如果命中则显示所有关联的来源、威胁类型和置信度。按类型浏览：列出所有 IP 类型的 IOC、所有域名类型的 IOC 等。按标签过滤：如果情报数据带有标签（如 ransomware、apt29、phishing），可以按标签筛选。

数据持久化用本地 JSON 文件——一个存 IOC 记录，一个存来源元数据。支持增量导入，不会重复添加已有的指标。CLI 子命令：import 导入数据文件、query 查询指标、list 列出统计信息、export 导出合并后的数据。Go 标准库实现，go build 通过。
