想搞清楚 NIDS 到底是怎么工作的——数据包进来之后引擎怎么处理、规则怎么匹配、告警怎么生成？与其看文档不如自己写一个，哪怕功能简单也能把原理搞透。

用 Go 写一个简单的网络入侵检测引擎。核心流程是：从 pcap 文件里逐包读取网络数据，解析 IP header 和 TCP/UDP header 提取五元组（源 IP、源端口、目标 IP、目标端口、协议），然后拿每一包的数据载荷去逐条匹配检测规则，命中就生成告警。

检测规则用自定义的简化格式（类似精简版 Snort），每条规则包含：匹配方向（源到目标或双向）、协议类型、源和目标的地址端口条件、匹配内容（支持字符串搜索和正则表达式两种模式）、规则描述。规则文件用简单的文本格式定义，一行一条。

匹配到规则后，输出告警信息：时间戳（从 pcap 包头提取）、源 IP:端口 → 目标 IP:端口、匹配的规则描述、匹配到的具体内容片段。对于 TCP 流量，支持基本的会话重组——把属于同一个 TCP 连接的数据包按序列号排序后再做内容匹配（简单实现即可，不需要处理分片和乱序的复杂情况）。

用 Go 标准库解析 pcap 文件格式（pcap 的文件头和包头结构很规范，手写解析完全可行）和 IP/TCP header。go build 编译通过。
