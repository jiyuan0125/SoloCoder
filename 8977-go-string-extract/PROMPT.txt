二进制文件里的字符串藏着大量信息——恶意软件的 C2 地址、硬编码的凭证、注册表路径、文件路径——但是系统自带的 strings 命令功能太弱，不能识别 UTF-16 编码的字符串，不能按类型分类，更不能标注特殊字符串。做逆向分析的时候很不方便。

用 Go 写一个增强版的 strings 工具。从任意二进制文件中提取可打印字符串，功能比系统 strings 命令强得多。

基础提取功能：扫描文件的每个字节，找到连续的可打印字符序列，最小长度可配置（默认 4 个字符）。支持三种编码：ASCII/Latin-1（单字节）、UTF-16LE（Windows 二进制常见）、UTF-16BE。对每种编码分别提取，标记来源编码。

智能分类：对提取出的字符串自动识别类型并打标签。URL（http://、https://、ftp:// 开头的链接）、IP 地址、邮箱地址（包含 @ 的合法邮箱格式）、文件路径（/开头或 \ 开头的路径）、Windows 注册表路径（HKEY_ 开头的）、Base64 编码字符串（长度是 4 的倍数且字符集匹配）。按类型分组显示，方便快速定位感兴趣的内容。

输出格式：每条字符串附带其在文件中的偏移地址（十六进制）和所属的节区名称（如果能从 ELF/PE header 推断出来的话）。支持输出为纯文本或 JSON 格式。CLI 工具，Go 标准库实现，go build 通过。
