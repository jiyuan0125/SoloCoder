Go 程序在线上跑着跑着 CPU 飙到 100%，运维用 go tool pprof 看了一下，但是 pprof 的交互式终端界面在大规模数据下不太直观，而且很多时候只想快速看到热点函数排名和调用路径。

写一个 Go 的 pprof profile 分析工具。输入是 pprof 的 CPU profile 文件（protobuf 格式），工具解析后输出文本格式的分析报告。

解析 pprof 的 protobuf 数据：提取 Profile 对象里的 Sample 序列，每个 Sample 包含一组 Location（调用栈帧），每个 Location 关联一个 Function（函数名、源文件名、行号），Sample 还带有 value 数组表示采样次数和累计时间。

分析功能：计算每个函数的 CPU 占用——累计时间除以总采样时间得到百分比。列出 Top N 热点函数（N 默认 20，可配置），显示函数名、自身耗时（不包括子函数）和总耗时（包括子函数）。找出最热的调用路径——从根函数到叶子函数的完整调用链，每条路径显示累计采样数。

生成简化的火焰图数据：每行是一条调用栈（用分号分隔函数名）加一个采样值，这种格式可以直接导入到火焰图可视化工具里。输入是 pprof 文件路径，输出分析报告到终端或文件。Go 标准库实现，go build 通过。
