手头有个 2GB 的 pcap 抓包，要从中筛出所有 TCP 80 端口含 "GET /admin" 的请求喂给检测引擎。tshark 的过滤语法写了两层就套不动了，干脆自己解析 pcap 文件头和包记录，按协议和端口做简单过滤。

Go 写一个 pcap 文件读取工具。支持两种格式：传统的 pcap 格式（magic number 0xa1b2c3d4 或 0xd4c3b2a1）和下一代 pcapng 格式。

pcap 格式的解析：先读 24 字节的文件全局头——magic number 确认格式和字节序、major/minor 版本号、snaplen（最大捕获长度）、链路类型（Ethernet、Loopback 等）。然后逐个读数据包记录：16 字节的包头包含时间戳（秒和微秒）、捕获长度、原始长度，后面跟着捕获的数据内容。

pcapng 格式的基本支持：识别 Section Header Block 和 Interface Description Block，解析 Enhanced Packet Block 提取数据包。

过滤功能：实现简化版的 BPF 风格过滤。支持按协议类型（tcp、udp、icmp）、端口号、源/目的 IP 地址过滤。不要做完整的 BPF 虚拟机，用简单的条件判断组合就行。输出包摘要信息：包编号、时间戳、长度、识别出的协议类型。CLI 工具，Go 标准库实现，go build 通过。
