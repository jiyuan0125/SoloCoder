分析网络流量的时候，TCP 包是碎片化的——一个 HTTP 请求可能被拆成了十几个包，每个包只携带一小段数据。要做应用层分析就必须先把 TCP 流还原出来，不然看到的只是一堆不完整的片段。

Go 实现 TCP 流重组工具。从 pcap 文件中读取 TCP 数据包，按照四元组（源 IP、源端口、目的 IP、目的端口）分组，每条 TCP 流独立重组。

重组逻辑：首先按四元组把包分到不同的流里。对于每条流，根据 TCP header 里的序列号（Sequence Number）对数据包排序。然后按序拼接 payload——序列号 1000 的包接在 999 后面，序列号 1050 的包接在 1049 后面。如果中间有间隔（比如序列号从 1000 直接跳到 1020，缺了 1000-1020 的数据），记录为间隙并标注。重传包（相同序列号的包出现多次）只保留最新的。

支持双向流的识别——A→B 和 B→A 的包属于同一条 TCP 连接的两个方向，分别重组。输出时客户端到服务端的数据和服务端到客户端的数据分开存。

工具读取 pcap 文件后，把每条重组完成的流写入单独的文件（按五元组命名），并输出摘要信息：总共识别了多少条流、每条流的持续时间和数据量。Go 标准库实现，go build 通过。
