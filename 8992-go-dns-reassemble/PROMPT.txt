DNS 解析出问题的时候排障特别头疼——客户端说访问不了某个域名，但你不知道是 DNS 查询没发出去、还是服务器返回了错误的 IP、还是被中间人篡改了响应。拿 tcpdump 抓了一堆 DNS 包，对着十六进制数据看格式太痛苦。

Go 实现一个 DNS 协议解析器，专门从 pcap 文件中提取和分析 DNS 查询与响应。

DNS 报文格式的解析：首先是 12 字节的 Header——事务 ID（用来匹配请求和响应）、标志位（QR 区分查询/响应、Opcode、AA 权威应答、TC 截断、RD 递归请求、RA 递归可用、RCODE 响应码）、问题数、回答数、授权数、附加数。然后是 Question 段——查询的域名（DNS 自己的标签长度编码格式，需要正确解码）、查询类型（A=1、AAAA=28、CNAME=5、MX=15、NS=2、TXT=16、SOA=6）、查询类（IN=1）。

Answer 段解析各类资源记录：A 记录提取 IPv4 地址、AAAA 记录提取 IPv6 地址、CNAME 记录提取别名、MX 记录提取优先级和邮件服务器、TXT 记录提取文本内容。域名压缩指针（指针值以 0xC0 开头，指向报文内的偏移位置）要正确处理，不然会解析出乱码。

工具从 pcap 文件中过滤 UDP 53 端口的数据包，解析所有 DNS 报文，输出查询统计（哪些域名被查了最多、哪些返回了 NXDOMAIN、响应时间分布）和完整域名列表。Go 标准库，go build 通过。
