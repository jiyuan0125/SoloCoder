帮朋友写一个 SQL 注入检测工具。场景是这样的：他有个内部系统经常被安全扫描扫出问题，想自己先跑一遍检测，赶在安全团队出报告之前把明显的漏洞堵上。

要求用 Python 写，能分析输入字符串判断是否包含 SQL 注入攻击模式。需要检测常见的注入手法，比如联合查询注入（UNION SELECT）、布尔盲注（AND 1=1）、时间盲注（SLEEP/BENCHMARK）、堆叠查询（分号拼接）、报错注入（EXTRACTVALUE/UPDATEXML）。每种类型的匹配要用正则和关键词组合判断，不能只靠单条规则，因为攻击者会用大小写混合、注释分割（SEL/**/ECT）这些绕过手段。

输出要标明检测到的注入类型和风险等级（高/中/低），高风险比如联合查询和堆叠查询，中风险是盲注类，低风险是可疑但不确定的模式。检测结果以 JSON 格式输出，包含 input、detected、type、risk、matches 字段，方便后续对接自动化流水线。

支持从文件批量读取输入（每行一条），也支持管道传入单条检测。遇到超长输入（超过 64KB）要截断并给出警告，避免正则回溯导致性能问题。python3 能跑就行，别搞太重的框架，标准库 re + json + sys 就够了。
