文件操作这块的安全检查一直是个体力活。我们的 Web 服务允许用户通过参数指定要读取的资源路径，之前出过一次 ../ 绕过的事故导致配置文件被读，现在想把检测逻辑抽出来做成独立工具，以后新项目直接引入。

Python 实现，核心功能是判断用户输入的路径是否试图逃出指定的基础目录。要检测的攻击向量包括：多级 ../ 跳转、URL 编码绕过（%2e%2e%2f、..%252f 双重编码）、Windows 风格（..\\、C:\）、空字节截断（file.txt%00.php）、符号链接跟随、点号变体（….// 这种嵌套构造）。还要考虑大小写混合在 Windows 上的绕过。

检测流程：先对输入做多层 URL 解码直到稳定，再用 os.path.normpath 归一化，最后用 os.path.realpath 解析符号链接后判断是否在基础目录下。每一步的中间结果都要记录，方便排查误报。

命令行接口：传入 --base 目录和 --path 用户输入，输出安全/危险判定、归一化后的路径、匹配到的攻击类型。批量模式从文件读取路径列表逐个检测，汇总输出安全/危险数量和详细报告。python3，不依赖外部库。
