公司有个老旧系统会把用户输入拼到 shell 命令里执行，出过一次事故，运维半夜被叫起来擦屁股。现在想先写个检测工具，把所有用到用户输入拼命令的地方扫一遍，排查完再统一用 subprocess + 参数列表的方式加固。

用 Python 写一个命令注入检测器。要能识别这些常见手法：管道符注入（|malicious_cmd）、反引号执行（`whoami`）、$() 命令替换、换行符注入（%0a 或 \n 后接新命令）、环境变量篡改（$IFS、$PATH）、通配符滥用、反斜杠转义绕过、分号分割（; rm -rf /）、井号注释截断（; cat /etc/passwd #）。给每个检测结果标注危险等级——命令替换和管道符是高危，环境变量和通配符是中危，可疑字符是低危。

检测策略上，先做输入归一化（URL 解码、HTML 实体解码、Unicode 归一化到 NFC），然后逐条规则匹配。每条匹配结果要输出：注入类型名称、匹配到的原始片段、在输入中的起止位置、攻击原理一句话说明。

两种使用方式：交互式逐条输入检测，匹配到的片段用 ANSI 颜色高亮；从文件批量扫描（每行一条输入），最后输出统计摘要（总数、高危数、中危数、低危数）。python3 标准库为主，别装太多依赖。
