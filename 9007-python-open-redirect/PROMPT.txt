项目登录页的跳转参数是用户可控的，安全问题拖了几个月没修，这次干脆写个独立工具把所有开放重定向的入口都扫一遍。

Python 实现开放重定向检测器，判断一个 URL 是否可能被用来做钓鱼跳转。检测这些绕过手法：
- @ 符号欺骗（https://trusted.com@evil.com 实际访问 evil.com）
- 多斜杠（https://trusted.com///evil.com）
- 反斜杠替代（https://trusted.com\\@evil.com）
- URL 编码绕过（%2f、%5c 混合使用）
- 子域名钓鱼（https://trusted.com.evil.com）
- 协议降级（https 跳到 http）
- javascript: 和 data: 协议替换

输入一个可信域名和待测 URL，工具先用 urllib.parse 解析，再做多层归一化（URL 解码、斜杠统一、协议提取），最后跟可信域名做精确匹配——不但要匹配域名本身，还要防止子域名钓鱼。

命令行输出：SAFE 或 UNSAFE，如果不安全要说明命中的绕过手法。批量检测模式从文件读取 URL 列表。python3 直接运行。
