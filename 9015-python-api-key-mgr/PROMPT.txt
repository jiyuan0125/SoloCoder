我管着好几个内部服务的 API Key，现在都记在备忘录里，上次不小心把备忘录同步到了公共盘，吓出一身冷汗。做个命令行管理工具，把密钥安全地管起来。

用 Python 写一个 API Key 管理工具。存储安全是第一位的：所有 key 用 AES-256-GCM 加密后存储，主密钥从用户设定的主密码通过 PBKDF2 派生（迭代 10 万次，盐值随机生成），主密码本身不落盘。加密数据存储在 ~/.api_keys/vault.dat，目录权限 700，文件权限 600。

每个 key 记录包含：key 值、服务名称（如 aws、github、internal-api）、环境标记（dev/staging/prod）、标签列表（方便按用途分类）、创建时间、过期时间、备注。操作支持：生成随机 key（可指定前缀如 ak_live_ 和长度）、添加和删除 key、按标签或服务名筛选列表、模糊搜索。

过期提醒：启动时检查是否有 key 在 7 天内过期并给出警告。轮换功能：生成新 key 的同时将旧 key 标记为待废弃状态。查询时 key 值默认只显示前 8 位，完整值需要加 --show-full 参数。所有写操作记录审计日志。python3 运行，别搞服务端。
