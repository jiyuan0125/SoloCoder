需要一个安全的会话存储组件。起因是之前的项目把会话数据直接 pickle 序列化丢到文件里，没有任何加密和完整性校验，一旦文件被改就能伪造任意会话。

Python 实现一个服务端会话存储引擎。会话创建时分配 256 位的随机 session ID（secrets.token_urlsafe 生成），数据序列化后用 AES-256-GCM 加密存储，每个会话有独立的 nonce 防止重放。加密密钥在初始化时指定，可以是从环境变量读取的主密钥。

生命周期管理：创建会话时可设置过期时间（默认 30 分钟不活跃过期），每次读取自动续期。过期会话的清理支持两种策略——被动清理（每次操作时顺带检查）和主动清理（后台线程定期扫描，间隔可配置）。

存储后端支持两种：FileBackend（每个会话一个文件，存在指定目录下，适合单进程部署）和 MemoryBackend（用字典 + TTL 管理，适合开发调试）。接口统一：create(data, ttl=None) 返回 session_id、get(session_id) 返回数据或 None、update(session_id, data) 更新数据、destroy(session_id) 删除会话。

python3 import 即用，不依赖第三方库。
