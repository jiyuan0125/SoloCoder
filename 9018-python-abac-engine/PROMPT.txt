我们系统的权限规则比较复杂，光靠角色不够用。比如"只有工作日的 9 点到 18 点，部门经理可以审批金额不超过 5 万的报销单"这种规则，RBAC 完全表达不了。

用 Python 写一个 ABAC（基于属性的访问控制）引擎。先定义策略：每条策略包含一组条件和一个决策（allow 或 deny）。条件可以引用四类属性——主体属性（用户的部门、职级）、资源属性（文档的密级、金额）、动作属性（读/写/删除）、环境属性（当前时间、请求来源 IP）。

条件表达式支持的操作符：等于、不等于、包含、前缀匹配、正则匹配、数值大于/小于/区间、时间范围（支持工作日判断）。多个条件用 AND/OR 组合，支持嵌套。策略组合方式两种：deny-override（任何一条 deny 都优先）和 permit-override（有 permit 就放行）。

策略用 JSON 格式定义，支持从文件加载。核心接口 evaluate(subject, action, resource, environment) → (decision: bool, matched_policies: list)，返回决策结果和匹配到的策略列表方便审计。python3 库形式。
