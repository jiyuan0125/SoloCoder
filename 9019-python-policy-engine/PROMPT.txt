想把公司内部的权限规则统一管理起来。现在每个系统各自写一套权限判断逻辑，有的用数据库存，有的硬编码，改一个权限规则要三个团队协调一周。能不能用一个通用的策略引擎把规则集中起来？

写一个通用的策略引擎，Python 实现。策略用 JSON 定义，格式是：一条规则包含 condition（条件表达式）和 effect（allow 或 deny）。条件表达式支持 AND/OR/NOT 逻辑组合、数值比较（>、<、>=、<=、==、!=）、字符串匹配（精确、前缀、正则）、集合操作（in、not in、contains）、时间范围判断（工作日/周末、小时区间）。

输入一个上下文字典（比如 {"user": "alice", "department": "engineering", "action": "deploy", "resource": "prod-server-01"}），引擎按优先级顺序评估所有匹配的规则，返回最终的 allow/deny 决策。冲突策略可配置：deny-override 严格模式（一条 deny 就拒绝）或 permit-override 宽松模式。

命令行能测试单条策略——输入规则文件和上下文 JSON，输出匹配过程和最终决策。也提供 evaluate() API 接口供代码调用。python3 实现。
