合规审计要求记录系统里所有关键操作，但现在的日志东一块西一块，格式也不统一，审计的人看了直摇头。写一个通用的审计日志组件，把所有操作记录统一到一个地方。

Python 实现一个审计日志引擎。每条日志记录包含标准字段：who（用户 ID 或服务账号）、what（操作类型如 create/update/delete/login）、target（操作对象如 order:12345）、when（ISO 8601 格式的精确时间戳，含时区）、result（success/failure，失败时附带错误码）、source（来源 IP 和 User-Agent）。扩展字段用 key-value 形式存储，不限制内容。

防篡改机制：每条记录计算 HMAC-SHA256 签名（包含所有字段 + 前一条记录的签名哈希），形成链式结构。验证时从头开始逐条校验，任何篡改都会导致后续所有记录的签名验证失败。签名密钥在初始化时指定。

查询支持：按时间范围（起始-结束）、用户 ID、操作类型过滤，返回匹配的记录列表。存储后端用本地文件（追加写入，每行一条 JSON）或 SQLite。提供写入和查询接口，python3。
