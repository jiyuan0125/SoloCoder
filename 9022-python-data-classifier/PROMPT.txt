数据分级分类的活儿一直拖着没做，现在合规催得紧，要求月底前把所有数据表的敏感级别标清楚。手动看几百个字段不现实，写个工具自动判断。

Python 写一个数据分类工具，自动判断文本或字段内容属于哪个敏感级别——公开（Public）、内部（Internal）、机密（Confidential）、绝密（Top Secret）。判断依据综合三方面信号：字段名关键词匹配（password、secret、token 映射为机密，phone、email 映射为内部）、内容模式识别（11 位数字且通过号段校验可能是手机号→机密，18 位含 X 且校验位正确是身份证→绝密）、数据分布特征分析（唯一值比例超过 90% 可能是 ID 列→内部，分布高度均匀可能是 token→机密）。

自定义规则通过 YAML 配置文件扩展：添加关键词→级别映射和自定义正则模式，用户规则优先级高于内置规则。当多个信号冲突时取最高敏感级别，宁可过度保护。

输入从 CSV 或 JSON 文件读取，对每个字段输出：推荐敏感级别、判断依据（命中哪条内置或自定义规则）、前 5 条样本数据（脱敏显示，手机号中间四位打星号）。python3 实现，不依赖数据分析框架。
