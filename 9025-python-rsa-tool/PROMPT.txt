RSA 加密解密在开发和测试中用得挺频繁。每次都要翻 openssl 命令的文档，参数还老记混（是 -inkey 还是 -keyinfile？），不如写个 Python 工具把常用操作包进去。

Python 实现一个完整的 RSA 工具。密钥管理：生成 RSA 密钥对（可选 1024/2048/4096 位，默认 2048），密钥导出为 PEM 格式，公钥和私钥分别保存为 .pub.pem 和 .priv.pem。从 PEM 文件导入已有密钥时自动识别是公钥还是私钥。

加密解密：用公钥加密、私钥解密，支持 PKCS#1 v1.5 和 OAEP 两种填充模式。OAEP 模式用 SHA-256 做 hash 函数。对于超过密钥长度减去填充开销的明文，自动分段加密（每段大小根据密钥长度和填充模式计算），解密时按分界符自动拼接还原。

签名验签：用私钥签名、公钥验签，支持 PKCS#1 v1.5 签名和 PSS 签名（PSS 盐值长度等于哈希输出长度）。签名前对消息做 SHA-256 哈希。验签时输出"签名有效"或"签名无效：消息可能被篡改或密钥不匹配"。

密文和签名输出为 Base64 编码，命令行指定操作和参数。python3 实现，用 cryptography 库。
