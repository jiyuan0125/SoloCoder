想做一个 Ed25519 签名工具，给文件和消息做签名用的。Ed25519 不依赖随机数生成器（确定性签名），比 ECDSA 安全性更好理解，不容易出实现上的漏洞。

Python 实现一个 Ed25519 签名工具。密钥管理：生成 Ed25519 密钥对，公钥 32 字节，私钥 64 字节（实际是种子 32 字节扩展而来）。密钥导出支持 OpenSSH 格式（ssh-ed25519 AAAA... 开头，可以直接放到 authorized_keys 里）和原始字节十六进制格式。

签名操作：对消息直接签名（Ed25519 不需要预哈希，但提供一个预哈希模式选项用 SHA-512 先哈希再签，适配大文件场景）。签名结果 64 字节，输出为 Base64 或十六进制。文件签名模式：读取文件全部内容，计算签名后把签名和文件名写入一个 .sig 伴随文件。

验证操作：输入消息（或文件路径）、签名和公钥，输出"签名有效"或"签名无效：消息可能被篡改或密钥不匹配"。批量验证模式：扫描目录下所有 .sig 文件，逐个验证对应的源文件。python3，用 cryptography 或 nacl 库。
