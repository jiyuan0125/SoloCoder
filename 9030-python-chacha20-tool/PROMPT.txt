想试用一下 ChaCha20-Poly1305 加密算法。据说在没有 AES-NI 硬件加速的环境下（比如某些 ARM 设备）性能比 AES-GCM 好很多，而且实现更简单不容易出侧信道漏洞。

Python 写一个 ChaCha20-Poly1305 加密工具。加密时自动生成随机 12 字节 nonce，解密时验证 16 字节 Poly1305 认证标签——如果密文或附加数据被篡改，解密直接失败并明确提示"认证失败：数据可能被篡改"。

密钥支持两种来源：直接输入 32 字节十六进制密钥，或从密码通过 HKDF-SHA256 派生（输入密码和随机盐值，输出 32 字节密钥，盐值和密文一起保存）。也支持纯 ChaCha20 流加密模式（不带 Poly1305 认证标签），用于对性能要求极高但不需要认证的场景，但使用时要给出安全警告。

附加数据（AAD）支持：加密时可以传入不需要加密但需要认证保护的额外数据（比如文件名、元数据），解密时传入相同的 AAD 才能成功。加密文件输出格式：盐值（如果用密码派生）+ nonce + AAD 长度 + AAD + 密文 + 认证标签。命令行使用，python3 运行。
