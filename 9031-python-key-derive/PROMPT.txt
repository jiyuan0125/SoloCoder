需要一个密钥派生工具。不同加密模块都要从用户密码派生出固定长度的密钥，但各自用不同算法还容易搞错参数，统一用一个工具来生成靠谱些。

Python 实现，支持四种密钥派生函数。PBKDF2：输入密码和盐值，可配置迭代次数（默认 60 万次，按 OWASP 2023 推荐值），输出指定长度的密钥，底层用 HMAC-SHA256。HKDF：输入密钥材料和可选的 info 参数，两步流程（提取+扩展），适合从已有密钥材料派生子密钥而不是从密码派生。scrypt：可配置 N（CPU/内存代价参数，默认 2^14）、r（块大小，默认 8）、p（并行度，默认 1），抗 GPU/ASIC 破解能力强于 PBKDF2。Argon2id：三种模式都支持——Argon2d（抗 GPU）、Argon2i（抗侧信道）、Argon2id（混合，推荐），可配置时间成本、内存成本、并行度。

所有函数都支持随机盐值生成（默认 16 字节，输出为十六进制），参数和盐值可以导出为 JSON 供后续复现。验证模式：给定密码、盐值和参数，判断能否派生出与之前相同的密钥——用于校验用户输入密码是否正确而不存储明文密码。

每种 KDF 输出参数对照表（推荐的安全参数值），命令行 --help 可以查看。命令行工具，python3 运行。
