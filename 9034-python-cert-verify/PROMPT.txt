线上服务要用证书做 mTLS，证书量不少，手动检查哪张快过期了很麻烦。之前出过一次证书过期导致服务中断的事故，现在想定期批量检查，把有问题的提前揪出来。

Python 实现一个证书验证工具，做这些检查：有效期——证书是否在当前时间的有效窗口内，剩余天数少于 30 天的标为"即将过期"（黄色警告），少于 7 天的标为"紧急"（红色）。签名验证——用签发者证书的公钥验证目标证书的签名是否正确，自签名证书单独标注"自签名，跳过签名验证"。

密钥用途匹配：检查证书的 Key Usage 和 Extended Key Usage 扩展是否与预期用途匹配。比如 TLS 服务端证书应包含 Server Auth，mTLS 客户端证书应包含 Client Auth，代码签名应包含 Code Signing。用途不匹配给出具体警告。

吊销状态检查：如果证书包含 CRL 分发点或 OCSP 响应器 URL，尝试在线查询是否被吊销（网络不可达时跳过并标注"无法验证"）。证书链验证：检查从终端证书到根证书的每一步签发关系。

批量模式：读入证书目录（.pem 和 .crt 文件），输出验证结果表格——文件名、使用者 CN、剩余天数、签名状态、用途匹配、吊销状态。python3 命令行工具。
