想写个 CRL（证书吊销列表）解析查看工具。上次排查一个 mTLS 握手失败的问题，折腾半天才发现是客户端证书被 CA 吊销了但没人注意到，如果有工具能直接查 CRL 就不会浪费时间了。

Python 实现 CRL 解析器。支持 DER 和 PEM 两种格式的 CRL 文件输入，也支持直接从 HTTP URL 下载 CRL（URL 从证书的 CRL Distribution Points 扩展中提取）。解析后展示这些信息：签发者 DN、本次更新时间、下次更新时间（如果已过期给出警告）、签名算法。

被吊销证书列表是重点——逐条展示每个被吊销证书的序列号（十六进制）、吊销日期、吊销原因（unspecified、keyCompromise、cAffiliationChanged、superseded、cessationOfOperation 等，映射为中文说明）。如果吊销条目包含无效日期（证书失效日期），也一并展示。

对比功能：输入一个证书文件和一个 CRL，检查该证书的序列号是否出现在吊销列表中，输出"未被吊销"或"已吊销"及吊销原因。批量对比：输入证书目录和 CRL，输出所有被吊销的证书清单。命令行工具，python3 运行。
