证书在线状态查询用 OCSP 比查 CRL 更及时。上次一个证书被 CA 紧急吊销了，但我们的服务还在用本地的 CRL 缓存，过了两天才发现。写个 OCSP 客户端，实时查证书状态。

Python 实现一个 OCSP 客户端。流程：从待查证书的 AIA（Authority Information Access）扩展中提取 OCSP 响应器 URL，从待查证书中提取序列号，从签发者证书中获取公钥和名称哈希，按 RFC 6960 构造 OCSP 请求，用 HTTP POST 发送到响应器。

解析 OCSP 响应：展示证书状态——good（正常有效）、revoked（已吊销，附吊销时间和原因）、unknown（响应器不知道这个证书）。响应签名验证：检查 OCSP 响应的签名是否由可信方签署（可能是 CA 本身或授权的 OCSP 响应器签名证书）。

异常处理：OCSP 响应器不可达（超时默认 5 秒）、HTTP 非 200 状态码、响应格式不正确——每种情况给出明确的错误提示而不是抛异常。支持批量查询：从文件读取证书列表，逐个查询并汇总结果。命令行使用，python3 实现，用 cryptography 库构造和解析 OCSP 消息。
