管理好几台 Linux 服务器的 SSH 密钥，密钥文件越积越多，有些不知道是哪个服务在用不敢删，有些是老项目留下的 RSA 1024 位弱密钥需要更换。写个工具整理一下。

Python 实现 SSH 密钥管理工具。第一步解析密钥文件：支持 OpenSSH 格式（ssh-rsa AAAA...、ecdsa-sha2-nistp256、ssh-ed25519）和 PEM 格式（RSA PRIVATE KEY、EC PRIVATE KEY），自动识别密钥类型和格式。

第二步展示密钥信息：密钥类型（RSA/ECDSA/Ed25519/DSA）、密钥长度（RSA 的位数、ECDSA 的曲线名）、公钥指纹（SHA256 格式和 MD5 格式，SHA256 为默认）、注释（通常是 user@host）。

第三步安全检查：RSA 密钥小于 2048 位的标为"不安全，建议替换"，DSA 密钥标为"已废弃，不应使用"。检查私钥文件权限是否为 600 或 400，权限过宽的给出警告。

批量扫描：扫描指定目录（默认 ~/.ssh/）下所有密钥文件，列出摘要表格——文件名、类型、长度、指纹、注释、安全评价。python3 命令行工具。
