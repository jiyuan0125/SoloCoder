需要一个端口扫描工具。做安全检查的时候要快速看看目标开了哪些端口，nmap 虽然强但有时候不想装那么大的东西，尤其在容器或受限环境里，一个 Python 脚本就够了。

Python 实现一个端口扫描器。扫描方式用 TCP 全连接扫描（完整三次握手，结果准确）。支持指定端口范围（如 1-1024）、离散端口列表（80,443,8080,8443）、常见服务端口快速扫描（内置 Top 100 端口列表）和 1-65535 全端口扫描。

并发控制：用 ThreadPoolExecutor 管理并发扫描线程，默认 100 个，可配置。每个端口的连接超时默认 2 秒，超时视为关闭或被防火墙过滤。扫描速率限制：每秒最多发起指定数量的连接，避免触发目标 IDS/IPS 规则。

输出结果包含：端口号、状态（open/closed/filtered）、推测的服务名称（根据 /etc/services 或内置映射，如 22=SSH、3306=MySQL）、响应时间（毫秒）。输出格式支持文本表格、JSON 和 CSV，JSON 格式方便对接后续自动化处理流水线。扫描完成后显示统计摘要——开放端口数、关闭数、过滤数、总耗时。python3 实现，命令行工具。
