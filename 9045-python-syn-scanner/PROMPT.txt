做一个 SYN 半开扫描工具。全连接扫描会在目标服务的访问日志里留下完整记录，SYN 扫描只发 SYN 不完成三次握手，大部分服务不会记录这种未完成的连接尝试，相对更隐蔽，安全评估时更不容易被发现。

Python 实现需要构造原始 TCP SYN 数据包。用 scapy 库构造 IP 头（设置源地址和目标地址、TTL 默认 64）和 TCP 头（flags 设为 SYN 即 0x02，源端口随机选 49152-65535 高位端口，seq 号随机生成），目标端口逐个扫描。收到 SYN-ACK（flags=0x12）说明端口开放——此时工具自动回一个 RST 断开，不完成完整握手。收到 RST（flags=0x14）说明端口关闭，超时无响应视为被防火墙过滤。

权限要求：发送原始数据包需要 root 权限，启动时检测权限不足则提示并自动降级为 TCP connect 全连接扫描模式。发送间隔可配置（默认 0.1 秒避免触发速率限制），并发扫描线程数可调。

输出结果：端口号、状态（open/closed/filtered）、响应 TTL 值（不同操作系统的初始 TTL 不同，可辅助判断目标系统类型，如 Linux=64、Windows=128）。支持端口范围指定、离散端口列表和从文件读取目标主机列表批量扫描。python3 实现，依赖 scapy。
