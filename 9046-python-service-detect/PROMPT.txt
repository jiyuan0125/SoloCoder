扫到开放端口后要知道上面跑的是什么服务。有些服务跑在非标准端口上（比如 SSH 跑在 2222），光看端口号猜不准，得主动探测。

写个服务识别工具，Python 实现。探测方式：先尝试 TCP 连接，等待服务端主动发送 banner（很多服务连接后会先发一行欢迎信息，比如 SSH-2.0-OpenSSH_8.9）。如果没有 banner，则发送一组探测报文——HTTP GET 请求（探测 HTTP 服务）、SSL/TLS ClientHello（探测 HTTPS）、空的换行（触发 SMTP/FTP 的响应）——根据响应内容判断服务类型。

识别特征库：内置常见服务的 banner 正则匹配规则。比如 SSH 以 SSH- 开头、HTTP 响应以 HTTP/ 开头、FTP 以 220 开头、SMTP 以 220 开头但包含 ESMTP、MySQL 以特定长度的二进制包开头、Redis 返回 -NOAUTH 或 +PONG。

输出结果：端口号、识别到的服务名称、版本号（如果能从 banner 中提取）、置信度（高/中/低，banner 明确匹配为高，靠端口号推测为低）。python3 命令行工具，输入 IP 和端口列表，输出服务识别报告。
