写一个 Banner 抓取工具，快速收集目标服务的版本信息。渗透测试前期信息收集阶段，知道目标服务版本是制定攻击策略的基础——比如 OpenSSH 7.6 之前的版本有用户名枚举漏洞。

Python 实现流程分三步。第一步连接：TCP 连接到目标主机指定端口，设置超时（默认 5 秒）。第二步等待 banner：很多服务会在连接建立后主动发送 banner 文本——SSH-2.0-OpenSSH_8.9p1、220 mail.example.com ESMTP Postfix、220 ProFTPD 1.3.6 Server ready。连接后等待 3 秒接收数据，超时无数据则进入主动探测。

第三步主动探测：如果服务不主动发 banner（HTTP 服务就是典型），发送特定的探测请求。HTTP 发 GET / HTTP/1.0 加 Host 头，HTTPS 先做 TLS 握手再发 HTTP 请求。其他协议发空数据或协议特定握手包触发响应。

批量模式：从文件读取 IP:端口 列表（每行一个），并发抓取（默认 50 线程），超时的目标单独标注。结果输出表格——地址、端口、banner 内容（前 200 字符）、服务类型推测。也支持 JSON 格式输出方便后续工具处理。python3 实现，不依赖 scapy。
