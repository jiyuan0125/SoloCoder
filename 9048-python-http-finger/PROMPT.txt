想做个 Web 服务器指纹识别工具。做安全评估的时候光知道目标开了 80 端口不够，得知道后端用的什么技术栈才能针对性地测试。

根据 HTTP 响应的特征来判断技术栈。采集这些信号：Server 头（nginx/1.18.0、Apache/2.4.41 直接暴露服务器类型和版本）、X-Powered-By 头（PHP/7.4.3、Express 暴露运行时）、响应头顺序（不同服务器响应头的排列顺序不同，Apache 先 Date 再 Server，Nginx 相反）、默认错误页面（404 页面的 HTML 结构差异）、Cookie 名称（PHPSESSID、JSESSIONID、connect.sid 分别指向 PHP/Java/Node.js）。

TLS 证书信息也要看：证书的 Subject Organization、Issuer、SAN 列表中的域名。证书透明度日志中的签发时间也能侧面反映系统更新频率。

探测方式：发送精心构造的 HTTP 请求（正常 GET、故意错误的 HTTP 方法、超长 URL），收集所有响应特征综合判断。输出识别结果：服务器软件、版本号（如果暴露）、后端语言、框架（如果能推断）、操作系统线索，以及每条判断的依据和置信度。python3 实现。
