想写个操作系统指纹识别工具，通过网络探测判断目标机器的操作系统。知道 OS 类型对后续渗透和安全加固都很关键，但不想依赖 nmap 的 OS 指纹库。

Python 实现，综合多种探测信号做判断。TTL 初始值：发送 ICMP echo 或 TCP SYN，看响应包的 TTL 值——Linux 默认 64、Windows 默认 128、某些网络设备 255，考虑网络跳数衰减后推断。TCP 窗口大小：不同 OS 的初始窗口大小不同，Linux 通常是 5840 或 29200，Windows 是 8192 或 65535，FreeBSD 是 65535。

TCP 选项：SYN-ACK 响应中 TCP 选项的排列顺序和类型因 OS 而异——MSS、窗口缩放、SACK、时间戳这些选项的组合形成特征。ICMP 响应行为：某些 OS 对特定类型的 ICMP 请求会回复，某些不会。

综合判断：多个信号交叉验证，输出每个 OS 的匹配概率（如 Linux 4.x 85%、Windows 10 10%、Unknown 5%），附上各信号的具体值和判断依据。python3 实现，需要 scapy 构造和解析原始数据包。
