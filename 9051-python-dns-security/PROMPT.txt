最近在排查一个 DNS 劫持的问题，用户的域名在某些网络环境下解析到了错误的 IP，怀疑是中间人攻击或者 DNS 污染。需要写个工具系统性地检测 DNS 安全问题。

Python 做一个 DNS 安全检查工具，对输入域名做三项检测。DNS 劫持检测：同时向多个可信上游 DNS（Google 8.8.8.8、Cloudflare 1.1.1.1、本地配置的 DNS）发送查询请求，对比解析结果是否一致——如果不同 DNS 返回的 IP 不同，可能存在劫持或污染。DNSSEC 验证：查询域名的 DS 记录和 DNSKEY 记录，检查域名是否启用了 DNSSEC 签名。如果启用则尝试验证签名链的完整性。

开放递归解析检测：向目标 DNS 服务器发送外部域名的递归查询请求，如果服务器响应了答案说明允许开放递归，这是一个安全风险（可能被用于 DNS 放大攻击）。

输入一个域名列表（文件或命令行参数），输出每个域名的安全评估——劫持风险（各 DNS 解析结果对比表）、DNSSEC 状态（已签名/未签名/验证失败）、递归开放状态。风险等级标注为高/中/低。纯 Python 标准库实现，用 socket 构造 DNS 查询包。
