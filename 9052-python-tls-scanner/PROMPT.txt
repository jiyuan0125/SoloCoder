帮写一个 TLS 安全扫描器。线上有几十个对外服务的域名，每个都要检查 TLS 配置是否安全，手动一个个用 openssl s_client 测太痛苦了。

Python 实现。第一步连接目标：给定主机名和端口（默认 443），用 ssl 模块创建 SSL 连接并完成握手。第二步证书检查：证书有效期（剩余天数少于 30 天标为"即将过期"）、是否自签名（CN 和 Issuer 相同）、SAN 扩展是否覆盖了访问的域名、证书链是否完整。

第三步协议版本检查：尝试分别用 TLS 1.0、1.1、1.2、1.3 连接，记录目标实际支持的版本。TLS 1.0 和 1.1 已废弃应该禁用，只允许 1.2 和 1.3。第四步弱密码套件检测：枚举服务端支持的密码套件（通过 ssl.SSLSocket.shared_ciphers()），标记包含 RC4、DES、3DES、NULL、EXPORT 的不安全套件。

输出一份安全报告：证书信息摘要、支持的协议版本（标注不安全的）、弱密码套件列表（附安全替代建议）、综合评分（A/B/C/D/F）。python3 实现，用标准库 ssl 和 socket。
