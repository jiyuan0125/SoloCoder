需要给一个小型 Web 服务加上 WAF 防护。市面上的 WAF 产品太重了，我们的服务就几个 API 接口，只需要检测常见的恶意请求然后拦截或告警就够了。

用 Python 写一个轻量级 WAF 引擎核心。规则匹配引擎：接收 HTTP 请求对象（包含方法、路径、查询参数、请求头、请求体），遍历已加载的规则对请求各部分做正则匹配。命中后立即返回拦截决定，附带命中的规则 ID、攻击类型和匹配到的原文片段。

内置检测规则覆盖常见攻击：SQL 注入（UNION SELECT、OR 1=1、SLEEP/BENCHMARK、注释分割 SEL/**/ECT）、XSS（script 标签及变体、事件处理器 onXXX=、javascript: 协议、SVG/IMG 标签内嵌代码）、路径穿越（../ 及各种编码绕过 %2e%2e）、命令注入（管道符 |、反引号、$()、分号）、SSRF（内网 IP 段 10.x/172.16-31.x/192.168.x、169.254.169.254）。

引擎设计要可插拔——规则加载和匹配逻辑解耦。规则格式为 JSON，包含规则 ID、攻击类型、正则表达式、检查目标（url/body/header/all）、严重等级（high/medium/low）。支持自定义规则文件加载和热更新。纯 Python 实现，命令行输入请求数据即可测试。
