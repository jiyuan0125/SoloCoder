服务器老被恶意 IP 骚扰，扫描、爆破、爬虫什么都有。需要一个 IP 黑名单管理工具，把威胁情报里的恶意 IP 收集起来，查询的时候能快速判断一个 IP 是否在黑名单里。

Python 实现黑名单管理。数据加载：支持从多个来源导入黑名单——纯文本文件（每行一个 IP 或 CIDR 段）、STIX/TAXII 格式的威胁情报（简化解析）、手动添加单个 IP。导入时自动去重、合并重叠的 CIDR 网段（比如 192.168.1.0/24 和 192.168.1.0/25 合并为 192.168.1.0/24）。

查询接口：输入一个 IP 地址，遍历所有黑名单条目做匹配——支持精确 IP 匹配和 CIDR 段包含判断（用 ipaddress 模块的 overlap 方法）。返回匹配结果和匹配到的具体条目（包含来源、添加时间、备注）。

管理操作：add 添加、remove 删除（支持按 IP 或 CIDR）、list 列出所有条目、stats 统计信息（总条目数、各来源的条目数）。过期管理：每条目可设置 TTL，过期后自动清理。用 pytricia 或手动实现前缀树加速 CIDR 匹配。命令行操作，纯 Python 标准库。
