服务只需要面向国内用户，海外流量基本是扫描和攻击。想按地理位置封禁境外流量，但又不能误伤使用 VPN 的正常用户，需要一个灵活的判断工具而不是一刀切。

Python 写一个基于 IP 的地理位置封锁工具。第一步加载 GeoIP 数据：支持 MaxMind GeoLite2 的 mmdb 格式（用 maxminddb 库读取）或纯文本 IP 段对照表（每行一条：CIDR + 国家代码，用 ipaddress 模块解析）。加载时构建内存索引，启动后常驻内存快速查询。

第二步策略配置：通过 YAML 文件定义封锁策略——白名单模式（只允许指定国家的 IP）或黑名单模式（禁止指定国家的 IP）。每条规则指定国家代码（CN、US、JP 等）、动作（allow/block）、备注说明。

第三步查询判断：输入 IP 查询其所属国家，按策略判断放行或封禁。批量模式从文件读取 IP 列表逐个判断。用 LRU 缓存（默认 10000 条）加速重复 IP 查询。

边界处理：查不到归属的 IP 默认按黑名单处理（可配置），私有 IP 段（10.x/172.16-31.x/192.168.x）和回环地址自动放行。输出判断结果、匹配到的国家代码、策略匹配详情。python3 命令行工具。
