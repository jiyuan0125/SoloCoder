SSH 和 Web 登录经常被暴力破解。上次一个测试环境的 SSH 被跑了一晚上字典进去装了挖矿程序，幸亏发现得早。写个工具从日志里自动分析暴力破解行为，及时封禁。

用 Python 分析认证日志。日志解析：支持标准 syslog 格式的 SSH 日志（/var/log/auth.log 或 journalctl 输出）和 nginx/apache 的访问日志。从 SSH 日志中提取 Failed password 和 Accepted password 事件，从 Web 日志中提取 HTTP POST /login 的 401/403 响应。

统计分析：对每个 IP 地址，在滑动时间窗口（默认 5 分钟）内统计失败登录次数，超过阈值（默认 10 次）标记为暴力破解攻击。分析攻击时间线——攻击开始时间、持续时间、尝试次数、使用的用户名列表（区分字典攻击和针对性攻击）。

输出攻击报告：每个被标记的 IP 列出攻击时间跨度、失败次数、尝试的用户名、是否最终成功登录（成功说明密码已泄露，需要紧急处理）。自动生成 IP 封禁建议——iptables 命令或 nginx deny 配置片段。汇总统计：攻击 IP 数量、最活跃的攻击 IP、被攻击最多的用户名。纯 Python 标准库。
