写一个密码强度评估工具。用户注册时前端虽然也有密码强度提示，但后端必须再做一次校验，防止绕过前端直接调 API 注册弱密码账号。

Python 实现密码强度检测器。检测维度包括：长度（低于 8 位弱、8-12 位中、12 以上强）、字符组成（纯数字/纯字母最弱，大小写混合+数字较强，加上特殊字符最强）、常见弱密码比对（内置 top 10000 常见密码列表，如 123456、password、qwerty、admin123 ——命中直接判定为极弱）、键盘序列检测（qwerty、asdfgh、123456 这种连续键位）、重复模式检测（aaaa、ababab）、个人信息相关（可选传入用户名和邮箱，检测密码中是否包含这些信息）。

强度评级：极弱（命中常见密码列表或长度不足 6）、弱（只满足部分条件）、中等（长度 8+ 且包含两类字符）、强（长度 12+ 且包含四类字符且无明显模式）。给出具体改进建议——"建议增加特殊字符"、"避免使用连续数字"、"不要包含用户名"。

提供 API 接口 check_strength(password, username=None, email=None) → dict。也提供命令行模式。python3。
