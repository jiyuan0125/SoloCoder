项目的依赖越来越多，哪些有漏洞、哪些许可证不兼容，手动查根本查不过来。需要写个工具扫描项目依赖树，把有问题的依赖揪出来。

Python 写一个依赖安全扫描器。先解析项目的依赖声明文件——Python 的 requirements.txt（逐行解析包名和版本，支持 >=、==、~= 等版本操作符）、Pipfile/Pipfile.lock、pyproject.toml 的 dependencies 段。构建完整的依赖树（直接依赖 + 传递依赖）。

漏洞检查：将每个包的名称和版本号与本地 CVE 数据库比对（从 NVD 或 OSV 下载的 JSON 漏洞数据）。匹配到漏洞的包列出：包名、当前版本、漏洞编号（CVE-YYYY-NNNNN）、漏洞描述摘要、CVSS 评分和严重等级、修复版本号。

许可证扫描：通过包名在 PyPI 元数据中查找许可证类型，对比许可证兼容性矩阵——GPL 系列与商业项目冲突、AGPL 要求网络服务也要开源、LGPL 可以动态链接。输出许可证不兼容的警告。

结果输出：按严重等级排序的漏洞列表、许可证兼容性报告。支持 JSON 输出格式对接 CI/CD。python3 命令行工具，能扫描当前目录下的 Python 项目。
