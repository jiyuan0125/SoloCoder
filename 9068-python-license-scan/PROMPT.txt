公司合规要求所有项目的第三方依赖许可证都要审查。有些开源许可证（比如 AGPL）用在不合适的地方会有法律风险，写个工具自动扫描。

Python 实现许可证扫描工具。扫描范围：Python 包（从 site-packages 或 pkg_resources 获取安装包列表及元数据）、npm 包（解析 node_modules 目录下的 package.json）、Go 模块（解析 go.sum 和 go.mod）。从每个包的元数据或 LICENSE 文件中提取许可证标识。

许可证分类：宽松型（MIT、BSD-2/3-Clause、Apache-2.0、ISC）基本可以随便用。弱 copyleft（LGPL-2.1/3.0、MPL-2.0）允许动态链接但有限制。强 copyleft（GPL-2.0/3.0、AGPL-3.0）要求衍生作品也开源，AGPL 还要求网络服务也要开源。未知/自定义许可证标记为需要人工审查。

输出许可证清单：包名、版本、许可证类型、分类标签（宽松/弱copyleft/强copyleft/未知/商业）、风险说明。汇总统计各类许可证的依赖数量。也输出一个兼容性矩阵——当前项目的许可证与各依赖许可证是否兼容。python3 命令行工具。
