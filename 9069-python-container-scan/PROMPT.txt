容器安全问题不只是镜像漏洞，还有运行时配置——容器是不是用 root 跑的、有没有暴露不必要的端口、挂载了哪些敏感目录。写个工具对容器做全面安全扫描。

Python 实现容器安全扫描器。静态分析（扫描镜像或 Dockerfile）：基础镜像版本是否过时、是否有已知 CVE（复用 CVE 数据库查询）；Dockerfile 里是否用了最新标签（FROM ubuntu:latest 不确定性高）、是否 COPY 了敏感文件、EXPOSE 了哪些端口、USER 指令是否存在（没有 USER 意味着默认 root 运行）。

配置检查：解析 docker inspect 输出或 docker-compose.yml——Privileged 模式是否开启（非常危险）、是否挂载了 docker.sock（等于给容器宿主机 root 权限）、是否挂载了敏感目录（/etc、/var/run、宿主机根目录）、网络模式是否为 host（绕过网络隔离）、资源限制是否设置（没有 limit 可能导致资源耗尽）。

运行时检查（可选）：连接 Docker daemon 获取正在运行的容器列表，对每个容器检查上述配置项。输出按严重程度排序的安全问题清单，每个问题附带修复建议。python3 命令行工具。
