基础设施即代码的安全检查一直没做，Terraform 配置里可能存在安全组开得太宽、S3 bucket 公开之类的问题。等到云上被扫出来就晚了，写个工具在提交代码前就检查一遍。

Python 写一个 IaC 安全扫描器。支持扫描 Terraform 的 .tf 文件（HCL 格式）和 CloudFormation 的 .yaml/.json 文件。解析配置文件后对资源配置做规则检查。

检查规则覆盖这些场景：安全组和网络 ACL 规则是否过于宽松（0.0.0.0/0 入站规则、开放了 SSH 22 和 RDP 3389 端口到公网）、S3 bucket 是否设置了 public access block、是否启用了加密（SSE-S3 或 SSE-KMS）、IAM 策略是否使用了 *:* 这种完全权限（应该遵循最小权限原则）、数据库实例是否允许公网访问、是否启用了存储加密、密钥管理服务密钥是否设置了自动轮换。

每条规则包含：规则 ID、严重等级（critical/high/medium/low）、资源类型和名称、问题描述、修复建议。支持自定义规则文件扩展。输出扫描报告——按严重等级排序的问题列表，附修复建议。也支持输出 SARIF 格式对接 GitHub Security。python3 命令行工具。
