安全运营需要对接多个威胁情报源，AbuseIPDB、VirusTotal、AlienVault OTX 这些，手动一个个查太慢了。写个工具统一查询，把多个情报源的结果聚合到一起，提高运营效率。

Python 写一个威胁情报聚合查询工具。支持对接多个情报源（每个源实现统一的查询接口）：AbuseIPDB（查询 IP 的滥用报告次数、置信度和 abuse 类别）、VirusTotal（查询 IP/域名/文件哈希在多少个引擎中被标记为恶意）、AlienVault OTX（查询关联的 threat pulse 和恶意活动指标）。API Key 通过配置文件统一管理，支持配置多个 Key 轮换避免触发速率限制。

查询接口：输入一个指标（IP 地址、域名、文件 SHA-256 哈希、URL），工具并行查询所有已配置的情报源，等待全部返回后聚合。聚合策略：综合各源判定结果，输出威胁评分（0-100，各源按可靠性设权重加权平均）和最终判定（恶意/可疑/安全/未知）。

缓存机制：查询过的指标结果缓存到本地 SQLite 数据库，TTL 默认 24 小时，避免重复查询浪费 API 配额。输出格式支持终端表格和 JSON。python3 命令行工具。
