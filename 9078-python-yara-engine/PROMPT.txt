YARA 规则是恶意软件分析和文件分类的事实标准，但 Python 调用 yara-python 库有时候编译安装有问题。写个纯 Python 的简易 YARA 规则引擎，支持核心语法但不依赖 yara C 库。

Python 实现一个轻量 YARA 规则引擎。支持的核心语法：字符串匹配（字符串字面量 $s1 = "malware_sig"）、十六进制字符串 $h1 = { E2 34 ?? 56 }（?? 是通配符）、正则表达式 $r1 = /cmd\.exe.*\/c/。条件表达式支持：and、or、not 逻辑组合，any of ($s*) 和 all of ($s*) 集合操作，uint16/uint32 读取文件偏移处的整数，filesize 文件大小判断。

匹配流程：加载规则文件（解析 rule、meta、strings、condition 四个段），对目标文件逐规则扫描。每条规则独立执行，命中的字符串记录偏移位置。元数据段（meta）中的作者、描述、严重等级等信息一并输出。

命令行接口：输入目标文件或目录和 YARA 规则文件，输出匹配到的规则名称、命中的字符串和位置、规则元数据。支持递归扫描目录。python3 纯实现。
