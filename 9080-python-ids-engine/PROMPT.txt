需要一个轻量级入侵检测引擎，不需要部署 Snort/Suricata 那么重的东西。我们的场景是分析导出的 pcap 文件或者实时读取网络流量，检测可疑行为。

Python 实现一个基于规则的 IDS 引擎。规则定义：每条规则包含匹配条件（协议类型 TCP/UDP/ICMP、源/目标端口、负载内容匹配）和响应动作（alert/log）。内容匹配支持字符串字面量和十六进制模式（|XX XX| 格式），支持大小写不敏感选项。

检测引擎：从 pcap 文件读取数据包（用 scapy 或 dpkt 库解析），对每个数据包逐条规则匹配。匹配维度：IP 层（源/目标地址是否在监控列表中）、传输层（端口号是否匹配规则、TCP flags 是否为特定组合如 SYN-only）、应用层（负载中是否包含特定字符串或字节序列）。

告警机制：匹配到规则后生成告警记录——时间戳、源/目标 IP 和端口、匹配到的规则 ID 和描述、数据包摘要（前 64 字节 hex dump）。告警输出到标准输出和 JSON 文件。统计面板：每秒数据包处理速率、各规则触发次数排行、严重等级分布。python3 命令行工具。
