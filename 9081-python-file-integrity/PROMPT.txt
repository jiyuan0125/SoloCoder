服务器上的关键配置文件需要做完整性监控，防止被入侵者篡改。之前用 tripwire 但配置太复杂了，写个轻量级的文件完整性检查工具自己用。

Python 实现文件完整性监控系统。第一步建立基线：扫描指定目录下所有文件（递归遍历），对每个文件计算 SHA-256 哈希值，记录文件大小、权限模式（八进制表示）、修改时间（精确到秒）、所有者 UID/GID。基线数据保存到本地 JSON 文件，文件用 HMAC-SHA256 签名防篡改——如果基线文件被篡改，检查时会报告签名验证失败。

第二步检查变更：重新扫描同一目录，逐文件对比当前状态和基线记录。检测到的变更类型——内容修改（哈希值变化）、权限变化（mode 变化）、所有者变化（uid/gid 变化）、文件被删除（基线中有但当前不存在）、文件被新增（当前有但基线中没有）。符号链接先解析到实际文件再做哈希计算。

第三步报告：输出变更列表，包含文件路径、变更类型、旧值和新值。严重等级判断——系统关键目录（/etc、/bin、/usr/bin、/sbin）的变更标为高危，用户数据目录的变更标为低危。支持 glob 模式排除频繁变化的文件（日志、临时文件、pid 文件）。python3 命令行工具。
