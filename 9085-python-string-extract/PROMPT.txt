分析可疑二进制文件时第一步通常是提取里面的可读字符串——IP 地址、URL、命令、注册表路径这些线索都能从字符串中找到。写个比 strings 命令更智能的字符串提取工具。

Python 实现增强版字符串提取器。基础提取：扫描二进制文件，提取连续可打印 ASCII 字符序列（默认最小长度 4 字符）。同时支持 Unicode 字符串（UTF-8 和 UTF-16LE 编码，Windows 二进制常用 UTF-16LE）。

增强功能——自动分类提取到的字符串：URL（http:// 或 https:// 开头的链接）、IP 地址（IPv4 格式）、文件路径（Windows 的 C:\ 路径和 Linux 的 / 路径）、注册表键值（HKEY_ 开头）、邮箱地址、域名（点分隔的域名格式）、命令行参数（- 或 -- 开头的标志）。

过滤和排序：支持按字符串类型筛选（只要 URL 和 IP），按出现频率排序（出现多次的字符串可能更重要），按文件偏移量排序。每条结果输出：偏移量（十六进制）、字符串类型标签、字符串内容。

也支持从内存 dump 文件和 pcap 包含的 payload 中提取字符串。python3 命令行工具。
