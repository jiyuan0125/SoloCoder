分析可疑二进制文件的时候需要快速查看关键函数的汇编代码，不想开 IDA 这么重的工具。写个轻量级的反汇编查看器，命令行直接用。

Python 实现一个简单的反汇编工具。支持两种架构：x86-64（最常见的桌面和服务器架构）和 ARM（嵌入式和移动设备常见）。反汇编引擎用 capstone 库，它支持多种架构且 Python 绑定稳定。

功能：输入一个二进制文件和起始偏移量，从该位置开始反汇编指定数量的指令（默认 100 条）。输出每条指令的地址（十六进制偏移）、字节码（hex dump）和反汇编结果（助记符 + 操作数）。支持指定架构和模式（32 位或 64 位）。

高级功能：函数识别——扫描二进制中常见的函数序言模式（x86 的 push rbp; mov rbp,rsp、ARM 的 stmdb sp!, {fp,lr}）标记可能的函数入口。字符串引用——查找指令中引用的地址，如果该地址在文件的 .rodata 或 .rdata 区域，尝试提取对应的字符串。交叉引用查找——查找哪些地方引用了指定地址。

输出格式：终端彩色显示（地址蓝色、助记符绿色、操作数白色），也支持纯文本输出。python3 命令行工具。
