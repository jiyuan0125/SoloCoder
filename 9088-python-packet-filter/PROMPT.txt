写一个数据包过滤器，类似 tcpdump 的简化版。从 pcap 文件或实时网卡抓包中过滤出符合条件的流量，用来快速定位感兴趣的通信。

Python 实现一个 BPF（Berkeley Packet Filter）风格的包过滤引擎。过滤器语法支持：按协议过滤（tcp、udp、icmp）、按 IP 地址过滤（host 192.168.1.1、src host、dst host）、按端口过滤（port 80、src port 443、dst port 3306）、逻辑组合（and、or、not）。比如 "tcp and dst port 80 and host 10.0.0.1" 表示目标端口 80 且涉及 10.0.0.1 的 TCP 流量。

过滤流程：读取 pcap 文件中的数据包，对每个包按协议层次解析（先以太网头 → IP 头 → TCP/UDP 头），提取过滤需要的字段，然后评估过滤表达式。匹配的包保留，不匹配的跳过。

输出选项：只显示包头摘要（源/目标 IP:端口、协议、长度、TCP flags）、导出匹配的包到新的 pcap 文件、统计匹配包的数量和字节数。也支持从网络接口实时抓包（需要 root 权限，用 raw socket）。python3 实现。
