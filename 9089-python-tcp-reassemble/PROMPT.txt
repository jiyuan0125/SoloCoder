分析 pcap 中的 TCP 流量不能只看单个包，TCP 是面向流的协议，应用层数据分散在多个包里。需要把属于同一个连接的包重组起来，还原完整的应用层会话内容。

Python 实现 TCP 流重组器。第一步识别连接：从 pcap 中提取所有 TCP 包，按四元组（源 IP + 源端口 + 目标 IP + 目标端口）分组。每个唯一的四元组代表一个 TCP 连接，通过 SYN 包标记连接开始，FIN 或 RST 包标记结束。

第二步重组数据流：对每个连接的 TCP 包按序列号排序——处理乱序到达（缓存后按序拼接）、重传数据（检测重复序列号只保留最新）、TCP 分片（一个应用层消息跨多个包的载荷拼接在一起）。区分客户端到服务端和服务端到客户端两个方向的数据流，分别独立重组。

第三步处理边界情况：连接未正常关闭（没有 FIN/RST 包，通过超时或新 SYN 来判断旧连接结束）、零窗口探测、选择性确认（SACK）。

输出每个连接的重组结果：连接元数据（四元组、时间跨度、包数、字节总数）、两个方向各自的完整载荷内容（可导出为二进制文件方便后续分析，或在终端以 hex dump 显示）。python3 纯二进制解析，不依赖 scapy。
