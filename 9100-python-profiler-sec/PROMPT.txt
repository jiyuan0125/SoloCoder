从安全角度分析程序运行时的行为——它打开了哪些文件、连接了哪些网络地址、调用了哪些系统调用。跟性能分析器不同，这里关注的是安全相关的行为模式。

Python 实现一个安全行为分析器。数据采集：通过 strace（Linux）或 dtrace（macOS）的输出作为输入源——先运行 strace -f -o trace.log ./target_program，然后用本工具分析 trace.log。也支持解析 /proc/PID/maps 和 /proc/PID/fd 的快照。

分析维度——文件访问：打开的文件路径（关注 /etc/passwd、/etc/shadow、~/.ssh/、/tmp/ 下的可执行文件）、创建的文件、修改权限的操作。网络行为：连接的目标 IP 和端口（关注外连到非常规端口的连接、反向 shell 常用的端口如 4444、5555）。进程操作：fork/exec 调用链（追踪子进程）、ptrace 调用（调试其他进程）。权限操作：setuid/setgid 调用、capability 操作。

风险评分：基于行为模式计算风险分（0-100），有外连行为加分、访问敏感文件加分、创建可执行文件加分。输出行为摘要和风险评分。python3 命令行工具。
