CORS 配置搞错了就是个安全漏洞——Access-Control-Allow-Origin 设成 * 或者反射请求的 Origin 头，等于白名单形同虚设。写个工具自动检查目标网站的 CORS 配置。

Python 实现 CORS 配置检查器。第一步发送正常请求：用 requests 库请求目标 URL，检查响应头中的 Access-Control-Allow-Origin、Access-Control-Allow-Methods、Access-Control-Allow-Headers、Access-Control-Allow-Credentials 值。

第二步发送恶意 Origin：分别用不同的 Origin 值发送请求——随机的 https://evil.com、null（某些配置会允许 null origin）、子域名 https://evil.target.com。如果响应的 ACAO 头反射了我们传入的 Origin 值，说明存在 CORS 配置漏洞——攻击者可以从任意域读取目标网站的响应。

第三步检查 credentials：如果 ACAC 设为 true 且 ACAO 允许任意 origin（或反射 origin），这就是高危漏洞——攻击者可以带 cookie 跨域请求，等于窃取用户会话。
