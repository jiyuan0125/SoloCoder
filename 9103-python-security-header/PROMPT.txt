Web 应用上线前做安全检查，HTTP 安全头是基本项。但安全头有好几个，每个都有不同配置选项，手动一个个 curl 检查很烦。写个工具一次性检查所有安全相关的 HTTP 响应头。

Python 实现一个 HTTP 安全头检查器。对目标 URL 发送 HTTPS 请求，收集响应头后逐项检查：Strict-Transport-Security（HSTS，检查 max-age 和 includeSubDomains）、Content-Security-Policy（CSP，是否配置、有没有 unsafe-inline/unsafe-eval）、X-Content-Type-Options（应该是 nosniff）、X-Frame-Options（应该是 DENY 或 SAMEORIGIN）、X-XSS-Protection（应该是 1; mode=block，虽然已废弃但某些旧浏览器需要）、Referrer-Policy（推荐 strict-origin-when-cross-origin 或 no-referrer）、Permissions-Policy（限制浏览器 API 如 camera、microphone、geolocation）。

每项检查输出：是否存在、配置值是什么、是否符合安全推荐、改进建议。缺少的头标红，配置不当的标黄，配置正确的标绿。

最后计算一个安全头评分（A-F 级别），根据配置完整性和正确性打分。也检查 HTTP 响应头中是否泄露了敏感信息（Server 版本号、X-Powered-By）。python3 命令行工具。
