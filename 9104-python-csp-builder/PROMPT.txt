CSP（Content Security Policy）是防 XSS 的最后一道防线，但手写 CSP 策略很容易出错——directive 名字拼错、值写法不对、漏了哪个指令。写个工具帮助生成正确的 CSP 策略。

Python 实现一个 CSP 策略构建工具。交互式构建：逐步引导用户配置每个 CSP directive——default-src（默认策略）、script-src（JS 来源，处理 unsafe-inline 和 unsafe-eval 的安全影响）、style-src（CSS 来源）、img-src（图片来源）、connect-src（AJAX/WebSocket 来源）、font-src、media-src、frame-src、object-src（应该设为 none 防止 Flash/Java 插件）。

每个 directive 支持的值类型：'none'（完全禁止）、'self'（同源）、域名列表（如 https://cdn.example.com）、nonce 格式（'nonce-{随机值}'，配合服务端生成）、hash 格式（'sha256-{base64}'，针对固定的内联脚本）。自动生成 nonce 和 hash 值。

验证功能：构建完成后自动检查策略的合理性——default-src 没设则警告、script-src 包含 unsafe-inline 则警告 XSS 风险、object-src 不是 none 则提醒。输出完整的 CSP 头字符串，可直接用于 Nginx/Apache 配置。python3 命令行工具。
