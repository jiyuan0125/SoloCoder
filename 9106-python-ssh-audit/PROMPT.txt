SSH 服务安全审计，类似 ssh-audit 的简化版。我们内网有几十台服务器，SSH 配置参差不齐，想批量扫一遍把不安全的揪出来。

Python 实现。连接阶段：连上目标 SSH 服务器（默认 22 端口），获取 banner 信息（如 SSH-2.0-OpenSSH_8.9p1 Ubuntu-3）。密钥交换：发送 SSH_MSG_KEXINIT 获取服务端支持的算法列表——密钥交换算法（如 curve25519-sha256、diffie-hellman-group14-sha256、diffie-hellman-group-exchange-sha256）、主机密钥算法（如 ssh-ed25519、rsa-sha2-256、ssh-rsa）、加密算法、MAC 算法、压缩算法。

安全评估：对每个算法类别，标记不安全的算法。密钥交换中 diffie-hellman-group1-sha1 已废弃（SHA-1）、diffie-hellman-modp512 太弱。加密算法中 3des-cbc、blowfish-cbc 已不安全。MAC 中 hmac-md5、hmac-sha1 有碰撞风险。主机密钥中 ssh-dss（DSA）密钥太短。

输出分三列：算法类型、当前支持的算法列表、安全评价——好（绿色，现代安全算法）、警告（黄色，可用但有更好选择）、危险（红色，应立即禁用），附替换建议。也检查服务端 banner 是否暴露了具体版本和操作系统。python3 实现，用 socket 直接做 SSH 握手。
