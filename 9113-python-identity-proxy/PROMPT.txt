内部应用要对接外部身份提供商（IdP），但每个应用自己实现 OIDC/SAML 协议对接太复杂了。做一个身份代理，应用只需要跟代理交互，代理负责跟 IdP 打交道。

Python 实现一个身份认证代理。代理充当应用和 IdP 之间的中间层。应用将未认证的请求重定向到代理，代理引导用户到 IdP 登录（支持 OIDC Authorization Code Flow），用户在 IdP 完成认证后回调到代理，代理用授权码换取 id_token 和 access_token，验证 token 有效性后生成自己的内部 session token 返回给应用。

Token 管理：代理签发的内部 session token 包含用户 ID、角色、过期时间，用 HMAC-SHA256 签名。应用拿到这个 token 后只需验证签名就能确认用户身份，不需要处理 OIDC 协议细节。支持多个 IdP 配置——不同应用可以对接不同的 IdP。

会话管理：维护活跃会话列表，支持单点登出（代理通知 IdP 吊销 token）。健康检查端点返回代理状态和已配置的 IdP 连接状态。python3 实现，启动一个 HTTP 代理服务。
