安全告警每天几百条，大部分是误报——扫描器触发的、正常业务行为触发的、规则配置太敏感触发的。真正有威胁的可能就两三条，但找出来像大海捞针。写个告警分诊工具自动过滤和排序，让分析师只关注最重要的。

Python 实现告警分诊工具。告警输入：从 JSON 文件读取告警列表（兼容 Splunk/QRadar/Elastic SIEM 的导出格式），每条包含时间戳、源/目标 IP、告警类型、描述文本、原始严重等级。

分诊规则——去重：相同源 IP + 相同告警类型 + 5 分钟时间窗口内的告警合并为一条，记录原始告警数量。白名单过滤：已知良性活动源（内部扫描器 IP 列表、定期备份任务的 IP）自动标记为误报。严重度提升策略：同一 IP 短时间内触发三种以上不同类型的告警（比如端口扫描+SQL 注入+暴力破解），说明攻击正在进行，整体提升为 P1 高优先级。

上下文丰富：查询告警中 IP 对应的资产信息（从 CMDB 配置文件加载——生产/测试/开发、负责人、运行的服务类型）。威胁情报比对：IP 是否在本地恶意 IP 库中，域名是否匹配 DGA 检测规则。

输出按优先级排序的告警列表，每条附带上下文、分诊依据和处置建议。python3 命令行工具。
