磁盘上的敏感文件——数据库备份、配置文件、密钥文件——应该加密存储。之前有个开发把包含 AWS Secret Key 的配置文件直接放在了 NFS 共享目录上，被扫出来了。写个文件加密工具避免这种事再发生。

Python 实现文件静态加密。加密流程：读入原始文件内容 → 用户输入密码 → 用 os.urandom 生成 16 字节随机 salt → PBKDF2-HMAC-SHA256 从密码和 salt 派生 32 字节 AES 密钥（迭代 60 万次）→ 用 os.urandom 生成 12 字节 nonce → AES-256-GCM 加密 → 输出 .enc 文件（格式：magic bytes + salt + nonce + 密文 + 16 字节 auth tag）。

解密流程：读取 .enc 文件 → 解析 salt 和 nonce → 用户输入密码 → 派生密钥 → AES-GCM 解密并验证 auth tag → tag 验证失败则报"密码错误或文件被篡改" → 恢复原始文件。

CLI：python encrypt.py lock secret.txt（交互式输入密码，密码不回显）生成 secret.txt.enc 并可选删除原文件。python encrypt.py unlock secret.txt.enc 恢复。支持批量加密整个目录。python3 用 cryptography 库。
