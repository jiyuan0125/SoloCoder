配置文件中的密钥泄露是个老大难问题。开发者在 .env 文件里写 AWS Secret Key，在 config.yaml 里写数据库密码，然后一不小心就提交到 Git 了。写个工具在 pre-commit 阶段扫描配置文件，把敏感信息拦在仓库外面。

Python 实现。第一步扫描目标：指定目录或文件路径，识别配置文件类型（.env、*.yaml、*.yml、*.json、*.conf、*.ini、*.toml、*.properties）。

第二步正则匹配：扫描常见密钥格式——AWS Access Key（AKIA 开头 20 字符）、AWS Secret Key（40 字符 Base64）、GitHub Token（ghp_/gho_ 前缀）、Slack Token（xoxb-/xoxp- 前缀）、私钥内容（BEGIN RSA/EC PRIVATE KEY）、数据库连接串（mysql://user:pass@host 这种格式）、通用 key/secret/token 变量赋值模式。

第三步熵值检测：对配置文件中的字符串值计算 Shannon 熵，高熵值（>4.5 bits/character）的字符串可能是随机生成的密码或 token，标记为可疑。

输出：文件名、行号、匹配到的密钥类型、原文片段（值部分用 *** 遮蔽）。能生成 .gitignore 建议条目和 pre-commit hook 脚本。python3 标准库。
