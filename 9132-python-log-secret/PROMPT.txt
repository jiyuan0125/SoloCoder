Python 实现两种使用方式。集成模式：提供 SanitizingHandler 类，集成到标准 logging 模块——logger 添加这个 handler 后，所有经过的日志消息自动脱敏再输出到最终目标文件或终端。CLI 模式：处理已有的日志文件，读入后逐行脱敏输出到新文件。

脱敏规则通过 YAML 配置文件定义——手机号：保留前三位后四位，中间用 **** 替换（138****5678）。身份证号：保留前三位后两位。邮箱：保留首字母和域名（z***@example.com）。IP 地址：可选保留前两段。信用卡号：保留后四位。通用正则匹配：支持自定义正则和替换格式。

规则优先级：自定义规则优先于内置规则。多规则匹配取最长匹配。脱敏后保持日志可读性，不能整行变星号。python3 标准库 + PyYAML。
