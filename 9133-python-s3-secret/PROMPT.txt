S3 bucket 里经常被人放了不该放的东西——.env 文件、数据库备份、带密钥的配置文件。之前有个 bucket 被扫出来里面有个 production.env 文件，里面有数据库密码和 API Key。写个工具定期扫描 S3 bucket 里的敏感数据。

Python 实现 S3 敏感数据扫描器。扫描方式：列出指定 bucket 的所有对象（支持指定前缀过滤），对每个对象判断是否需要扫描——跳过二进制文件（图片、视频、压缩包）和超大文件（超过 10MB 默认跳过，可配置）。对小文本文件下载全部内容扫描，对中等大小的文件只读前 4KB。

检查项：正则匹配 AWS Key、GitHub Token、私钥文件内容、数据库连接串、.env 格式的变量赋值（PASSWORD=xxx、SECRET_KEY=xxx）。文件名检查：.env、*.pem、*.key、id_rsa、credentials.json、backup.sql 这些文件名本身就很可疑。PII 检测：CSV 和 JSON 文件中是否包含大量手机号或身份证号。

也支持本地目录模式（不连 S3，用文件系统路径代替 bucket）。输出报告列出有风险的对象和具体发现。python3，S3 模式用 boto3。
