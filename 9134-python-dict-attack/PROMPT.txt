安全团队做渗透测试的时候，密码强度验证是必备环节——拿一份字典文件对着目标服务的登录接口批量跑，几万条密码靠手动试不现实。这是授权测试用的内部工具，不是攻击工具。

Python 实现。加载密码字典文件（每行一个密码，支持 # 开头的注释行和空行跳过），对目标服务逐个尝试认证。支持三种协议——HTTP Basic Auth（用 requests 发送带 Authorization 头的请求，检查 401/200 状态码判断成功）、SSH（用 paramiko 连接尝试密码认证，捕获 AuthenticationException 判断失败）、FTP（用 ftplib 登录，检查 530 Login incorrect / 230 Login successful 响应码）。

速率控制：可配置请求间隔（默认 1 秒）和每秒最大请求数，避免触发目标的速率限制和 IP 封禁。断点续传：记录已尝试到字典的第几行到文件，中断后可继续。

实时显示进度（已尝试/总数/百分比/当前密码），找到正确密码时高亮显示。结束后统计——总尝试次数、成功次数、成功率、总耗时。也输出安全建议。python3 命令行工具。

多线程支持：HTTP 模式下可以用 ThreadPoolExecutor 并发请求（线程数可配置，默认 5），SSH 模式因为是长连接建议单线程。结果同时输出终端和 JSON 文件（包含所有尝试记录）。python3 命令行工具。
