攻击者对着你的登录接口不断试密码，这种行为跟正常用户的登录模式完全不同——频率异常高、大量不同用户名、失败率几乎 100%。安全团队需要从日志里自动揪出这种暴力破解行为。

Python 实现认证暴力破解检测器。第一步日志解析：支持 nginx access.log（匹配 POST /login 的 401 响应）、syslog auth.log（匹配 Failed password 行）、自定义 JSON 格式（包含 timestamp、username、ip、success 字段）。统一提取为内部事件格式。

第二步统计分析：对每个 IP 地址，在滑动时间窗口（默认 5 分钟）内统计失败次数。检测规则——高频失败：单 IP 每分钟超过 10 次失败登录。破解成功信号：大量失败后突然出现一次成功（说明密码被试出来了，需要紧急通知用户改密码）。用户名枚举：同一 IP 尝试了大量不同用户名（admin、root、test、user1...）。

输出可疑 IP 列表：每个 IP 附带攻击时间窗口、失败次数、尝试的用户名列表、是否最终成功。自动生成封禁建议——iptables -A INPUT -s IP -j DROP 命令。python3 标准库。
