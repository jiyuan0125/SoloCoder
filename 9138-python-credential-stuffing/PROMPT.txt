凭证填充攻击是拿泄露的用户名密码对去批量试登录。这种攻击比传统暴力破解更危险——因为密码是真实泄露的，成功率远高于随机猜测。我们的登录系统需要检测这种行为并自动告警。

Python 实现凭证填充检测器。输入：登录事件流（JSON Lines 格式，每行包含 timestamp、username、ip、success 布尔值）。支持两种处理模式——实时模式从 stdin 逐行读取事件流即时检测，批量模式读取完整的 JSON Lines 文件做回溯分析。

检测模式——单 IP 多账号：同一 IP 在短时间内（默认 1 小时窗口）尝试大量不同用户名（阈值默认 50 个），正常用户不会这样。分布式填充：同一组凭证从多个不同 IP 尝试，攻击者用代理池规避 IP 封禁。异常成功率：总成功率极低（<1%）说明在批量盲试。突发流量：登录请求量比基线高出 N 倍。

输出告警事件：攻击类型、涉及 IP 列表、尝试账号数、时间窗口、如果有成功登录的账号标为紧急需重置密码。python3 标准库。

告警去重：同一种攻击模式的告警在 5 分钟内不重复触发。支持配置白名单（内部安全扫描器的 IP、负载均衡器的健康检查）排除已知合法来源。python3 标准库。
