企业安全策略要求敏感操作只能在办公网络进行，但总有员工通过 VPN 绕过这个限制——合规审计发现好几次了。得从流量特征入手，把 VPN 访问识别出来。

Python 实现多维度 VPN 检测。维度一——IP 信誉库匹配：加载公开的 VPN 提供商 IP 范围数据（从开源的 VPN 供应商 IP 列表或 IP2Location 的 proxy 类型数据库加载），对目标 IP 做精确匹配和 CIDR 范围匹配。维度二——TLS 指纹分析：用 JA3 指纹方法分析客户端 TLS 握手特征，VPN 客户端的 cipher suite 组合跟正常浏览器明显不同（比如缺少浏览器特有的扩展）。维度三——地理位置异常：用 MaxMind GeoLite2 数据库做 IP 定位，检测同一用户短时间内从不同地理位置登录（10 分钟前北京现在纽约，物理上不可能）。

综合判断：每条线索独立评分 0-10，加权平均后映射为高/中/低 VPN 概率。输出每个 IP 的检测结果、触发规则和证据详情。支持单 IP 查询和日志批量分析。python3 命令行工具。

缓存策略：已查询过的 IP 结果缓存到 SQLite（TTL 24 小时），避免重复查询浪费资源。白名单支持——企业自有 VPN 的 IP 段可以排除不检测。python3 命令行工具。
