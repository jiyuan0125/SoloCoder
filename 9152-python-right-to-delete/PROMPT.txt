"被遗忘权"执行工具。GDPR 和个人信息保护法要求，当用户申请删除账号时，企业必须在各个系统里找到并清除该用户的个人数据。之前这类请求是产品经理手动在各个后台操作的，漏删了几次后被合规点名了。写个工具把流程自动化。

Python 实现。配置文件（YAML）定义数据源列表——每个数据源包含名称、类型（database/file/api）、连接信息或路径、包含用户 ID 的字段名、要脱敏的字段列表。

执行流程：输入用户 ID → 遍历所有配置的数据源 → 在每个数据源中搜索该用户的记录 → 对找到的记录执行脱敏处理（姓名替换为"已删除用户"、邮箱替换为 SHA-256 哈希值的前 8 位+@deleted.com、手机号清空为空字符串、其他 PII 字段设为 null）→ 生成删除执行报告。

报告内容：每个数据源处理了多少条记录、哪些字段被脱敏、是否有数据源连接失败。整个操作记录审计日志——谁在什么时候对哪个用户执行了删除、影响了哪些系统。跑起来就行，不用接真实数据库，用模拟数据演示。python3 命令行工具。

配置文件示例：两个 SQLite 数据库（users 表和 orders 表）加一个日志目录。报告输出 JSON 和人类可读的文本两种格式。python3 命令行工具。
