用户同意管理工具，用于记录和查询用户对各项数据处理活动的授权状态。

场景是这样的：我们的应用需要收集用户同意才能使用 Cookie、发送营销邮件、共享数据给第三方，而且用户随时可以撤回。

用 Python 写一个命令行工具：
- 记录用户对某一处理目的的同意或拒绝（用户ID、目的、时间戳、来源渠道）
- 查询某用户当前对所有目的的同意状态，以表格形式输出
- 支持撤回操作，撤回后标记历史记录状态变更

数据存在本地 JSON 文件就行。命令示例：python consent_mgr.py grant user_001 marketing_email --source web_form
能跑起来，不依赖外部服务。
