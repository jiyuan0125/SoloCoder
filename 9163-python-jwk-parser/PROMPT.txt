JWK（JSON Web Key）解析工具。OAuth2 和 OpenID Connect 的 JWKS 端点返回的就是 JWK 格式的密钥——JSON 格式描述公钥的参数，比 PEM 格式更适合 Web API 传递。写个工具解析和操作 JWK。

Python 实现 JWK 解析器。支持的密钥类型——RSA（kty=RSA，参数 n/e/d/p/q/dp/dq/qi，从 Base64url 编码的大整数解析为实际的模数和指数）、EC（kty=EC，参数 crv/x/y/d，支持 P-256/P-384/P-521 曲线）、oct（kty=oct，对称密钥，Base64url 编码的字节串）、OKP（kty=OKP，Ed25519/X25519，参数 crv/x/d）。

功能：从 JWK JSON 解析出密钥对象，提取公钥和私钥，转换为 PEM 格式（方便给 openssl 和 cryptography 库使用），从 PEM 格式生成 JWK。JWKS（密钥集合）解析：从 JWKS 端点（如 https://example.com/.well-known/jwks.json）获取 JSON，按 kid（Key ID）查找特定密钥。

密钥用途检查：解析 use 字段（sig 签名/enc 加密）和 key_ops 字段，验证密钥是否用于预期用途。命令行：parse（解析 JWK JSON）、convert（JWK↔PEM 互转）、fetch（从 JWKS URL 获取密钥集）。python3。
