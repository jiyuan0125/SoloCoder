访问日志分析工具，从 Web 服务器访问日志中提取安全相关的信息。

运维每天产生几万条 Nginx 访问日志，人工看不过来。需要一个工具自动找出可疑的访问模式。

Python 命令行工具：
- 解析 Nginx/Apache Combined Log Format 日志
- 统计 IP 访问频率，标记超过阈值的 IP（疑似爬虫或暴力破解）
- 检测路径扫描行为（大量 404 响应、访问敏感路径如 /admin、/.env）
- 按时间段统计请求量和状态码分布
- 输出分析报告，包含 Top10 高频 IP、可疑请求列表、异常时间段

用法：python access_log.py analyze access.log --threshold 100 --output report.txt
支持日志文件和 stdin 输入，能处理百万行级别的日志。
