漏洞扫描报告聚合工具，把多个安全扫描器的输出合并成一份统一报告。

现在安全流水线里跑了 Trivy、Bandit、Snyk 三个扫描器，每个输出格式都不一样，安全工程师看不过来。需要统一格式汇总。

Python 实现：
- 解析 Trivy JSON、Bandit JSON、Snyk JSON 三种扫描报告格式
- 按统一的漏洞模型转换：CVE ID、严重级别、影响包、版本范围、修复建议
- 去重：同一个 CVE 被多个扫描器报出只保留一条，标记来源
- 按严重级别排序输出，支持 JSON 和 Markdown 两种格式

用法：python scan_reporter.py merge trivy.json bandit.json snyk.json --output report.md
能正确处理各扫描器的输出格式。
