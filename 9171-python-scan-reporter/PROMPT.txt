漏洞扫描报告聚合工具。安全团队用了好几个扫描器——Trivy 扫容器、Bandit 扫 Python 代码、npm audit 扫前端依赖、自定义脚本扫配置。每次扫描完输出格式都不一样，汇总成一份数据给老板看要花半天。写个工具自动合并。

Python 实现扫描报告聚合器。输入解析：支持多种扫描器输出格式——Trivy JSON、Bandit JSON、npm audit JSON、SARIF 格式、自定义 CSV。每个解析器将原始输出转换为统一的内部格式——漏洞 ID、严重等级、受影响组件、描述、来源扫描器名称。

去重和合并：不同扫描器可能报告同一个漏洞（比如 Trivy 和 npm audit 都发现了同一个 CVE），用 CVE 编号 + 组件名做去重键，合并时保留所有来源信息。如果没有 CVE 编号，用描述的相似度（简单文本匹配）去重。

报告生成：输出统一的 JSON 和 HTML 报告。HTML 报告包含——执行摘要（总漏洞数、按严重等级分布的饼图数据、各扫描器的发现数量）、详细列表（按严重等级排序，每条漏洞显示组件、描述、来源、修复建议）。python3 命令行工具。

趋势对比：支持对比两次扫描报告的差异——新增了多少漏洞、修复了多少、哪些恶化了。python3 命令行工具。
