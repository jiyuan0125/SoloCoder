漏洞关联分析工具。单个漏洞的危害有限，但如果攻击者能组合利用多个漏洞形成攻击链，危害就大多了。比如一个文件读取漏洞 + 一个 SSRF 漏洞可以读取内网元数据获取凭证。写个工具自动分析漏洞间的关联关系。

Python 实现漏洞关联分析器。输入：一组漏洞列表（JSON 格式，每个漏洞包含 CVE 编号、漏洞类型、影响组件、攻击前提条件、可获得的权限或信息）。关联规则——前置条件匹配：漏洞 A 的后果（如"获取本地文件读取能力"）满足漏洞 B 的前提条件（如"需要读取配置文件"），则 A→B 可链接。组件依赖：漏洞在同一个组件或依赖链上，利用一个可以为利用另一个创造条件。

攻击链生成：从已有漏洞出发，用广度优先搜索找到可达的攻击目标（如"获取 root 权限"、"访问数据库"）。输出每条攻击链的漏洞序列、每步获得的权限提升、整体风险等级（链越长但能到达高价值目标的风险越高）。

也支持跟 MITRE ATT&CK 技术的映射——每个漏洞对应哪些攻击技术，攻击链对应怎样的攻击路径。python3 命令行工具。

可视化输出：文本形式的攻击路径图（节点是漏洞、边是关联关系），高亮标注最高风险的路径。也支持导出 DOT 格式给 Graphviz 画图。python3 命令行工具。
