NVD（国家漏洞数据库）数据客户端。直接调 NVD API 有限速（每 30 秒 5 次请求没有 API Key，有 Key 可以 50 次），而且响应比较慢。写个带缓存和限速的客户端库，方便其他工具使用。

Python 实现一个 NVD API 客户端。API 封装：查询 CVE 信息（GET /rest/api/cves/2.0?cveId=CVE-YYYY-NNNNN）、按关键词搜索、按 CPE 名称查询、按时间范围查询。每个请求自动处理分页（resultsPerPage 参数和 startIndex）。

限速控制：用令牌桶算法控制请求频率——无 API Key 时每 6 秒一个请求，有 API Key 时每 0.6 秒一个。请求之间的间隔自动管理，调用方无需关心。API Key 从环境变量 NVD_API_KEY 读取。

缓存层：查询过的 CVE 结果缓存到本地 SQLite（TTL 默认 24 小时），相同查询直接命中缓存不调 API。缓存命中时自动延长 TTL。离线模式：如果网络不可用，降级为只查缓存并给出提示。

响应解析：从 API 返回的 JSON 中提取 CVE ID、描述（英文）、CVSS v3.1 评分、弱点（CWE）、CPE 匹配配置、参考链接。提供 get_cve(cve_id) → dict 和 search(keyword) → list 接口。python3 库形式。
