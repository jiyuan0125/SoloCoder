SBOM（软件物料清单）生成工具，扫描项目依赖生成标准化 SBOM 文件。

客户要求我们交付软件时附带 SBOM，说明里面用了哪些第三方组件。需要自动从项目依赖中提取并生成标准格式。

Python 实现：
- 扫描 Python（requirements.txt、Pipfile、pyproject.toml）和 Node.js（package.json）项目文件
- 提取依赖名称、版本、来源信息
- 生成 CycloneDX JSON 格式的 SBOM（包含组件列表、版本、哈希）
- 支持添加自定义元数据（供应商名称、构建时间等）

用法：python sbom_generator.py scan ./my-project --format cyclonedx --output sbom.json
能解析常见依赖文件格式，输出的 SBOM 结构要合规。
