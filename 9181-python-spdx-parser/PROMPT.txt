SPDX（Software Package Data Exchange）许可证清单文件解析器。SPDX 是另一种 SBOM 标准格式，有些工具生成的 SBOM 是 SPDX 格式。写个工具解析 SPDX JSON 和 tag-value 两种格式。

Python 实现 SPDX 解析器。格式支持：SPDX JSON 格式（解析 Document、Packages、Relationships 顶层对象）和 tag-value 格式（每行 key: value 对，如 PackageName: openssl）。解析 Packages 列表——每个包的 SPDXID、name、versionInfo、supplier、licenseConcluded、licenseDeclared、copyrightText、downloadLocation。

关系解析：解析 Relationships 段构建依赖图（SPDXRef-PROJECT DEPENDS_ON SPDXRef-openssl）。许可证汇总：提取所有包的 licenseConcluded 和 licenseDeclared，统计许可证分布——MIT 多少个、Apache 多少个、GPL 多少个、Unknown 多少个。

交叉引用：将 SPDX 的包名和版本转换为 purl（Package URL）格式，方便跟 CycloneDX SBOM 互相对比。命令行：parse（展示包列表）、license-summary（许可证汇总）、deps（依赖树）、compare（对比两个 SPDX 文件的差异）。python3。
