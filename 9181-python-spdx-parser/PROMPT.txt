SPDX 许可证清单文件解析器，处理 SPDX 格式的软件物料清单。

SPDX 是 Linux 基金会推的 SBOM 标准，和 CycloneDX 齐名。有些客户要求 SPDX 格式，需要能解析处理。

Python 实现：
- 解析 SPDX JSON 格式文件（tag-value 格式可选）
- 提取包信息：包名、版本、SPDX ID、许可证声明、版权声明、文件列表
- 检查许可证合规性：标记非标准许可证、未知许可证、无许可证的组件
- 统计许可证使用分布，高亮有法律风险的许可证（如 GPL 系列用于闭源项目）
- 导出为简洁的许可证报告

用法：python spdx_parser.py parse spdx.json --check-licenses
python spdx_parser.py report spdx.json --format markdown
重点是许可证识别要准确，SPDX License Identifier 要支持常见的。
