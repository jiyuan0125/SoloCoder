pip 依赖安全审计工具，检查 Python requirements 文件中的已知漏洞。

Python 项目的依赖经常有安全问题，手动一个一个查 CVE 太费劲。需要一个工具自动扫描。

Python 命令行工具：
- 解析 requirements.txt、requirements-dev.txt、Pipfile.lock 格式
- 对每个依赖包及版本，查询本地漏洞数据库（JSON 文件，包含包名、受影响版本范围、CVE ID、修复版本）
- 版本范围匹配要支持 >=、<=、==、~=、!= 等操作符
- 按严重度排序输出，标红有已知漏洞的包
- 给出升级建议：当前版本 → 安全版本

示例：python pip_audit.py check requirements.txt --db vuln_db.json
数据库内置几十条常见包的漏洞记录就行，关键是版本比较逻辑要对。
