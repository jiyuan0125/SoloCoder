NPM 依赖安全审计工具。Node.js 项目的 package-lock.json 里面可能有几百个依赖，其中不乏有漏洞的老版本。npm audit 命令有时候网络不好用不了，写个离线审计工具。

Python 实现。第一步解析 package-lock.json：读取 JSON 文件，递归遍历 dependencies 对象，提取每个包的名称、版本号和 resolved URL。区分直接依赖（在顶层的）和传递依赖（嵌套在其他包里的）。

第二步漏洞查询：对每个包用 name@version 调用 OSV API 或查本地漏洞数据库。OSV 的查询格式为 {"package": {"name": "lodash", "ecosystem": "npm"}, "version": "4.17.15"}。解析返回的漏洞列表，提取 CVE 编号、严重等级、受影响版本范围和修复版本。

第三步结果展示：按严重等级排序的漏洞列表——包名、当前版本、漏洞编号、CVSS 评分、修复版本。汇总统计——总依赖数、有漏洞的依赖数、按严重等级分布。也支持输出 SARIF 格式对接 GitHub Security tab。

命令行：python npm_audit.py ./package-lock.json --format table。也支持只扫描 production 依赖（排除 devDependencies）。python3 命令行工具。
