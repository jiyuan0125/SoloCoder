Rust Cargo 依赖安全审计，扫描 Cargo.lock 检查 crates 的已知漏洞。

Rust 生态的 cargo audit 工具挺好，但我们需要在 Python 轨道里统一处理所有语言的依赖审计。

Python 实现：
- 解析 Cargo.lock（v2/v3 格式）提取所有 crate 名称、版本、来源
- 对比本地漏洞数据库，检查已知安全问题
- 解析 Cargo.toml 提取直接依赖和 features 信息
- 检测 yanked 版本（已被作者撤回的版本）
- 输出按严重度排序的审计结果

示例：python cargo_audit.py check Cargo.lock --db rust_vulns.json
python cargo_audit.py check --toml Cargo.toml
Cargo.lock 的 TOML 格式解析要正确，注意 v3 格式用 [[package]] 数组。
