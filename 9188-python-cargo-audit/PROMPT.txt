Rust Cargo 依赖安全审计。Rust 生态有 RustSec Advisory Database 记录已知漏洞，cargo audit 命令可以查但我们要在 CI 中自定义逻辑，写个 Python 版本。

Python 实现。第一步解析 Cargo.lock：读取 TOML 格式的锁文件，提取 [[package]] 段的每个 crate——name、version、source（区分 crates.io 和 git 源）、checksum。也支持解析 Cargo.toml 的 [dependencies] 段获取直接依赖列表。

第二步漏洞查询：从 RustSec Advisory Database 下载 advisories 目录（每条建议是一个 TOML 文件，包含漏洞影响的 crate 名和版本范围）。本地匹配：对每个 crate，查找对应 name 的 advisory 文件，检查版本号是否落在 affected 版本范围内（用 semver 版本比较）。也支持调 OSV API（ecosystem=crates.io）在线查询。

第三步结果展示：有漏洞的 crate 列表——名称、当前版本、advisory ID（如 RUSTSEC-2024-XXXX）、严重等级（根据 CVSS 或 RustSec 的分类）、描述摘要、修复版本。无漏洞的 crate 不显示，保持输出简洁。汇总统计。python3 命令行工具，用 tomllib 解析 TOML。
