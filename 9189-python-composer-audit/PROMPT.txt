PHP Composer 依赖安全审计。PHP 项目的 composer.lock 文件记录了所有安装的包和精确版本。写个工具扫描这些依赖是否有已知漏洞。

Python 实现。第一步解析 composer.lock：读取 JSON 格式的锁文件，提取 packages 数组（生产依赖）和 packages-dev 数组（开发依赖）。每个包的信息——name（vendor/package 格式）、version（如 v2.14.1）、source/dist URL。

第二步漏洞查询：PHP 包的漏洞数据来源——Packagist 的 Security Advisories API 或 GitHub Advisory Database。用包名和版本号查询 OSV（ecosystem=Packagist）。解析返回的漏洞列表——漏洞 ID、CVE 编号、影响版本范围、修复版本、描述。

第三步结果展示：默认只扫描生产依赖（packages），加 --include-dev 也扫描开发依赖。终端表格输出——包名、当前版本、漏洞编号、CVSS 评分、修复版本。传递依赖标注来源。汇总——总包数、有漏洞包数、按严重等级分布。

也支持输出 JSON 格式对接 CI 流水线，有高危漏洞时返回非零退出码。python3 命令行工具。
