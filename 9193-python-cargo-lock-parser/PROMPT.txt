Cargo.lock 解析器，解析 Rust 项目的锁文件提取依赖信息。

Cargo.lock 是 TOML 格式，记录了 Rust 项目的精确依赖版本。需要能解析它来获取完整的依赖列表。

Python 实现：
- 解析 Cargo.lock TOML 格式，提取 [[package]] 中的 name、version、source、checksum
- 识别依赖来源：crates.io（registry）、git 仓库、本地路径
- 构建依赖关系图（根据 dependencies 字段）
- 查询功能：按包名搜索、按来源类型过滤、查找某个包的所有依赖者
- 输出依赖树或依赖列表

用法：python cargo_lock_parser.py parse Cargo.lock
python cargo_lock_parser.py deps Cargo.lock --package serde
TOML 解析可以用标准库或 toml 包。source 字段格式是 "registry+https://github.com/..."。
