go.sum 文件里每行一个模块+版本+哈希，看着简单但信息量不少——哪些是正式版本、哪些是伪版本（没打 tag 的 commit）、模块都来自哪些域名。做安全审计和 SBOM 之前得先把这些信息结构化提取出来。

Python 实现。go.sum 文件格式：每行包含三个字段——module_path（如 github.com/gin-gonic/gin）、version（如 v1.9.0 或 v1.9.0/go.mod）、hash（h1:开头的 SHA-256 校验和 Base64 编码值）。同一个模块可能有多行——模块本身和它的 go.mod 文件各一行。

解析功能：逐行解析提取模块路径、版本号和哈希值。版本号中可以区分伪版本（v0.0.0-20230101120000-abcd1234abcd，来自没有打 tag 的 commit）和正式版本（v1.2.3，来自 git tag）。模块路径中提取域名（如 github.com、golang.org、google.golang.org）做来源统计。

分析功能：统计依赖总数、按域名分组（github.com 多少个、golang.org 多少个）、检测重复模块（不同版本号的同一个模块路径）、校验和验证（可选下载模块重新计算哈希对比）。输出依赖列表和统计报告，也支持 JSON 格式导出。python3 命令行工具。
