Conan 锁文件解析器，解析 C++ 包管理器 Conan 的锁文件。

Conan 2.0 的锁文件记录了 C++ 项目的精确依赖版本和构建配置。我们的 C++ 项目需要做依赖审计。

Python 实现：
- 解析 Conan lockfile（JSON 格式），提取包引用、版本、recipe hash、package ID
- 提取构建配置信息：编译器、OS、架构
- 解析依赖图（depends_on 字段），构建依赖树
- 查询功能：按包名搜索、按版本过滤、查找某个包的依赖链
- 输出依赖清单和配置矩阵

示例：python conan_lock_parser.py parse conan.lock
python conan_lock_parser.py deps conan.lock --package fmt
Conan lockfile 是 JSON 格式，包引用格式是 name/version@user/channel。
