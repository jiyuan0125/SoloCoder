C++ 的依赖管理一直是团糟，Conan 算是比较成熟的方案了。conan.lock 里记录了每个包的版本、构建选项和依赖关系，做 SBOM 和安全审计得先把这些信息提取出来。

Python 实现。conan.lock 文件是 JSON 格式。解析 graph 字段中的 nodes 对象——每个节点包含 ref（包引用，格式为 pkg/version@user/channel，如 fmt/9.1.1//@）、package_id（二进制包 ID，跟平台和编译器相关）、prev（包修订版本）、options（构建选项如 shared=True）、path（依赖链路径）。

从 nodes 构建 dependency graph——每个节点的 depends 字段记录了它直接依赖的其他节点 ID。从图结构可以推导出完整的依赖树。

分析功能：统计所有唯一的包（按 name 去重后）、按版本号排序、检测同一个包的不同版本（可能需要统一版本）。输出依赖列表（包名、版本、用户/通道）、依赖树（文本形式展示层级关系）、JSON 导出。也支持提取 Conan recipe 中的许可证信息（如果有）。python3 命令行工具。
