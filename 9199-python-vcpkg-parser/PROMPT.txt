vcpkg 装了几十个包，但项目里到底依赖了什么、每个包什么版本、ABI 兼容性如何——这些信息散在 vcpkg.json 和 vcpkg-lock.json 两个文件里。SBOM 生成工具需要把这些信息统一起来。

Python 实现。解析 vcpkg.json（项目配置文件）的 dependencies 数组——每个依赖可以是字符串（包名如 "fmt"）或对象（包含 name 和 version>= 等约束）。解析 vcpkg-lock.json（锁文件，类似 npm 的 package-lock.json），提取每个已安装包的 name、version、abi（二进制兼容性标识）。

也支持解析 vcpkg 的 installed 目录（vcpkg_installed/vcpkg/info/ 下的 .list 文件），从每个包的安装清单中提取包名、版本和安装的文件列表。

分析功能：统计已安装的包数量、按版本排序、构建依赖图（从 vcpkg-lock.json 的 dependencies 字段）。检测问题——同一个基础库有多个版本、缺少版本约束的依赖（应该锁定版本）。输出依赖列表、统计信息和 JSON 格式的 SBOM。python3 命令行工具。
