最近在折腾无损音乐，手上有不少 FLAC 文件，来源各异——有从 CD 抓轨的、有网上下载的、还有自己用 ffmpeg 转的——想看看每个文件的编码参数和元数据情况，确认质量是不是真无损。

写个 FLAC 解析器，能读取 FLAC 文件头的 'fLaC' magic number，然后按顺序解析 metadata block chain。STREAMINFO block 是核心——16 字节里塞了最小/最大块大小、帧大小范围、采样率（20 bit）、总采样数（36 bit）、声道数减一、位深度减一、以及 MD5 校验值，从这些信息推算出总时长和比特率。接着遍历 VORBIS_COMMENT block，里面的 tag 列表（vendor string 后面跟着一组 key=value 对，title、artist、album、tracknumber 之类的）全部打印出来。如果文件里嵌了封面图（PICTURE block），报告图片 MIME 类型、尺寸和色深，不用解码图片本身。CUESHEET 和 SEEKTABLE block 如果存在也解析出来。遇到大文件不要一口气读进内存，用 io.SectionReader 按 seek 偏移量读取。

Go 写，纯手写二进制解析，encoding/binary 配合 bufio。不依赖第三方 FLAC 库。go build 编译通过。
