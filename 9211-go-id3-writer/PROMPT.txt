给音乐文件批量修改标签：往 MP3 文件里写入 ID3v2 标签。整理音乐库的时候，有大量文件缺少标签或者标签信息有误，需要一个命令行工具批量处理——比如从目录结构推导艺术家和专辑名，再写回文件。

能通过命令行参数设置标题（TIT2）、艺术家（TPE1）、专辑（TALB）、年份（TDRC）、曲目号（TRCK）、流派（TCON）这些基本文本帧，也要能嵌入封面图片（APIC 帧，指定图片文件路径和 MIME 类型）。写入时要正确构造 ID3v2.4 tag header——版本号、flag、同步安全整数编码的标签大小。帧数据里文本帧用 UTF-8 编码（编码标记字节 0x03），APIC 帧按规范拼 MIME type + null byte + 描述文本 + null byte + 图片二进制数据。如果文件已经有 ID3v2 标签，先读出旧的解析成帧列表，更新指定字段，其余帧原样保留；如果没有标签就在文件头部插入新的。padding 留 1KB 左右方便后续追加。边界情况处理好：空字段不写空帧，标签大小计算要把 padding 包含进去，音频数据的起始偏移要算准。

Go 标准库，二进制读写用 bytes.Buffer + encoding/binary，不用第三方库。go build 通过。
