Ogg Vorbis 和 FLAC 文件里的 Vorbis Comment 标签跟 ID3 完全是两套体系——键值对格式、小端序长度前缀编码、key 大小写不敏感——想单独搞个工具来读写。

读取功能：解析 Ogg Vorbis 文件里的 Vorbis Comment block。先读 vendor string（4 字节小端长度前缀 + UTF-8 文本），然后读 user comment 列表的总数，逐条解析（每条也是 4 字节长度前缀 + "KEY=VALUE" 格式的 UTF-8 文本）。常见的 key 有 TITLE、ARTIST、ALBUM、TRACKNUMBER、DATE、GENRE、DESCRIPTION、PERFORMER、COMPOSER 这些。输出成 JSON 格式，key 统一转大写方便对比。写入功能也要有——能通过 -set "ARTIST=张三" 这样的参数设置指定字段，重建整个 comment block 写回文件。写入时保留原有不冲突的字段，只更新指定的 key（大小写不敏感匹配）。comment 值里带中文 UTF-8 不能乱码。Ogg 文件的页面 CRC32 要重新计算。

Go 实现，encoding/binary 读小端序的长度前缀。go build 编译通过。
