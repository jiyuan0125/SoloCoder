做音频可视化需要把波形数据预先提取出来。网页上做音频播放器的时候，缩略波形图能让用户一眼看到整首歌的响度变化——哪里安静、哪里高潮，比光秃秃的进度条直观多了。SoundCloud 那种波形条就是这个原理。

从 WAV 或原始 PCM 音频中采样生成波形数据。先读文件头获取采样率、位深、声道数和总数据量，据此算出总时长和总采样数。然后按照用户指定的目标分辨率（比如 800 个数据点对应 800px 宽的图，命令行 -width 参数控制）计算降采样步长 = 总采样数 / 目标点数。大文件不能一口气加载到内存——用 bufio.Reader 逐块读取 PCM 数据（每块几十 KB），每个块内的采样取最大值和最小值，这就是 min-max 下采样法，比取平均值更能保留波形的峰峰值和动态范围信息（平均值会让安静的段落和响亮的段落看起来差不多，丢失细节）。输出三种格式可选：JSON（{ "samples": [ { "min": -0.8, "max": 0.9 }, ... ] }，前端 JS 直接用），CSV（序号,min,max 三列，适合 gnuplot / matplotlib），或者 ASCII 文本波形图（终端 80 列宽度，用 █ ▀ ▄ 和空格拼出来，横向是时间纵向是振幅，能直观看出哪里响哪里静）。支持单声道和立体声，立体声取两个声道的 max/min 包络。

Go 写，纯标准库，bufio 分块读取不爆内存。go build 通过。
