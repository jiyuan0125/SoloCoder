做播客片头片尾需要淡入淡出效果——片头音乐从静音慢慢变响，片尾渐渐消失。简单处理就行，不需要打开专业 DAW 调一堆参数。

给 WAV 音频添加淡入（fade in）和淡出（fade out）效果。通过 -in 和 -out 参数分别指定淡入淡出时长（毫秒，默认 1000ms）。两种曲线类型通过 -curve 参数切换：linear（gain = t / T，从 0 线性增长到 1，简单直接）和 exponential（gain = (t / T)²，开始变化慢后面加速，听感更平滑，默认选项）。淡入区域：前 T_in 毫秒的每个采样值乘以 fade_curve(t / T_in)；淡出区域：最后 T_out 毫秒的每个采样值乘以 (1 - fade_curve(t / T_out))；中间区域原样保留不变。处理后输出新的 WAV 文件，RIFF 头完全重建。边界处理：fade 时长超过文件总时长的话自动截短到文件长度的一半。16/24/32 bit PCM 以及 32 bit IEEE Float 都能正确处理——浮点格式直接乘，整数格式注意类型转换不溢出。
