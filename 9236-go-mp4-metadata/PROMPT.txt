视频文件的信息经常散落在不同的 box 里——时长在 mvhd、编码在 stsd、分辨率在 tkhd、标签在 udta——每次用 ffprobe 看一堆输出眼睛都花了，想一个工具把重要元数据都提取出来整理成清晰的 JSON。

专门读取 MP4 文件的元数据信息。解析 moov box 下的所有子 box：mvhd 拿创建时间（Mac epoch 转人类可读）、修改时间、timescale + duration 算总时长（秒）、速率；每个 trak 下的 tkhd 拿 track ID、时长、宽高；mdhd 拿轨道的 timescale 和 duration；hdlr 拿 handler type 区分视频/音频/字幕；stsd（采样描述）拿编码格式名（avc1=H.264、hev1=HEVC、mp4a=AAC、Opus）、音频的采样率和声道数。bitr（码率）box 如果存在也读取。udta/meta box 里的 iTunes 风格标签：©nam 标题、©ART 艺术家、©alb 专辑、©gen 流派、trkn 曲目号、©day 年份。全部整合输出为一个结构清晰的 JSON 对象。

Go 标准库，输出 JSON 格式，go build 通过。
