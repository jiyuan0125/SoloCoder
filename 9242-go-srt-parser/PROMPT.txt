字幕文件最常见的 SRT 格式，想写个解析器提取文本做翻译——批量翻译字幕的时候需要一个靠谱的解析器先把文本拆出来，翻译完再按时间轴拼回去。

解析 SRT 字幕文件（SubRip 格式）。每个字幕条目由三部分组成：序号（纯数字一行）、时间轴（起始 --> 结束，格式 HH:MM:SS,mmm --> HH:MM:SS,mmm）、文本内容（一行或多行，直到遇到空行）。时间轴解析要严格验证：小时 0-23、分钟 0-59、秒 0-59、毫秒 0-999，分隔符必须是逗号不能是点号（有些文件的毫秒分隔符写成了点号要能容错处理），箭头 " --> " 前后有空格。文本内容支持多行，保留原始换行。同时处理 Windows 的 \r\n 和 Unix 的 \n 换行符，不要因为换行符不同就解析失败。空行分隔条目——连续多个空行也要正确处理，不要丢条目。输出 JSON 数组，每个条目包含 index、start_time（秒，浮点数）、end_time（秒）、lines（文本行数组）。文件开头的 UTF-8 BOM（0xEF 0xBB 0xBF）要自动跳过。还能统计总条目数和总时长。

Go 标准库，go build 编译通过。
