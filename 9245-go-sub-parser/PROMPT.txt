字幕文件格式太多——SRT、ASS、SSA、VTT、SUB/IDX——每次都要想"这个文件该用什么工具打开"。想写一个通用解析器自动识别格式然后统一输出，省得每次都要判断。

通用字幕解析器，能自动检测文件格式并用对应解析器处理。格式检测策略：先看文件扩展名（.srt .ass .ssa .vtt .sub），再看文件内容双重确认——SRT 特征是数字行后跟时间轴 "-->" 行，ASS/SSA 特征是 "[Script Info]" 或 "[V4+ Styles]" 段落标记，VTT 特征是文件开头 "WEBVTT"，SUB 是 MicroDVD 格式（{起始帧号}{结束帧号}文本内容）。所有格式统一输出为相同结构的 JSON 数组：{ index, start_seconds, end_seconds, text, style? }。SRT 解析按标准 SubRip 格式；ASS 提取 Dialogue 行的 Start/End/Text 并去掉花括号覆写标签只留纯文本；VTT 提取 cue 的时间轴和文本内容（去掉 HTML 标签）；SUB 将帧号换算成秒数（需要 --fps 参数指定帧率，默认 23.976）。格式检测失败时给出明确提示，说明文件内容的前几行长什么样。

Go 原生实现，纯标准库处理多种字幕格式。go build 能过。
