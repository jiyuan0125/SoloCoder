PID 分配是 TS 封装的起手式。PAT 固定 PID 0x0000，PMT 分配一个 PID（比如 0x1000），视频分配一个 PID（0x1001），音频分配一个 PID（0x1002）。PCR 时钟绑定在视频 PID 上。

第二步，构建 PAT 和 PMT 表。PAT 内容：表 ID 0x00，传输流 ID 任选一个，里面有一个条目——节目号 1，PMT PID。PMT 内容：表 ID 0x02，节目号 1，PCR PID 设为视频 PID，两个流描述——视频流类型 0x1B（H.264）+ 视频 PID，音频流类型 0x0F（AAC）+ 音频 PID。PAT 和 PMT 的插入间隔默认每 100ms 一次。

第三步，封装视频。读取 H.264 裸流的 NAL 单元（起始码 0x000001 或 0x00000001 分隔），把 SPS 和 PPS 单独作为一个 PES 包先发出去（用来初始化解码器），后续的 IDR 和非 IDR 帧各自封装成 PES 包。PES 包头加上 PTS（和 DTS 如果是 B 帧的情况）。PES 数据按 184 字节（188 - 4 字节头）切分成 TS 包，不足的用自适应字段填充。

第四步，封装音频。读取 AAC 帧（ADTS 头或裸帧），同样封装成 PES 再切成 TS 包。音频只有 PTS 没有 DTS。输出标准 .ts 文件。用法 ts-mux -video input.h264 -audio input.aac -output output.ts。Go 标准库，go build 编译通过。
