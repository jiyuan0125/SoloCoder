我想分析音频的频谱特征，需要一个工具对 WAV 音频做频谱分析并输出结果。

要做的事：
- 读取 WAV PCM 数据，将音频切成短时帧（frame size 可配置，如 1024 或 2048 采样点）
- 对每帧做 FFT 变换，计算各频率 bin 的幅度值（magnitude）
- 输出每帧的频谱数据，标注对应的频率范围（根据采样率计算实际 Hz 值）
- 支持汉宁窗（Hanning window）减少频谱泄漏

Rust 项目，cargo build 编译通过。`spectrum analyze audio.wav --frame-size 2048 > spectrum.json`。
