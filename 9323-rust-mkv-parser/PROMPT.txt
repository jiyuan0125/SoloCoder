做一个 MKV（Matroska）容器格式的解析工具，解析 MKV 文件的 EBML 结构。

功能：
- 解析 EBML 头部（EBML version、read version、max ID/size length）
- 递归解析 Matroska Segment 下的关键 Element：Info（Duration、TimecodeScale）、Tracks（TrackEntry、CodecID）、Cues
- 读取 TrackEntry 中的轨道类型（video/audio/subtitle）、编码格式、采样率等属性
- 正确处理 EBML 的变长整数编码（VINT）和不定长 Element 的 size

Rust 实现，cargo build 编译通过。`mkv-parser info movie.mkv` 输出文件结构和轨道信息。
