有时候不需要完整解析视频——只要快速提取几个关键元数据字段：编码格式、分辨率、帧率、码率、时长。特别是批量处理的时候，几千个文件每个都要解析一遍 moov box 太慢了，需要优化只读必要的字段。Rust 实现。

元数据分布在不同 box 里。视频信息：从 moov/trak[video]/mdia/minf/stbl/stsd 读编码格式（avc1/hev1/vp09）。从 stsd 的 sample entry 读分辨率 width/height。从 moov/trak[video]/mdia/minf/stbl/stts 计算帧率——stts 是 (count, delta) 对列表，总帧数 = Σ count，总时长 = Σ(count × delta)，帧率 = 总帧数 / (总时长 / timescale)。码率从 stsz 计算——Σ size × 8 / (总时长 / timescale) / 1000 得到 kbps。

音频信息：stsd 的 mp4a sample entry 里有编码对象类型、采样率（从 AudioSampleEntry 的 samplingRate 或 esds 里的 AudioSpecificConfig 获取）、声道数。容器信息：moov/mvhd 的 creation_time 和 modification_time（Mac epoch，1904 年 1 月 1 日以来的秒数）、duration/timescale 算出总时长。

封面图提取——检查 moov/udta/meta/ilst 是否有 covr（cover art）条目。如果有，提取出来保存为文件（通常是 JPEG 或 PNG 格式）。用法 mp4-meta info video.mp4。Rust 实现，cargo build 通过。
