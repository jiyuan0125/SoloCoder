字幕文件解析这种基础工具写一次用无数次。SRT 是最简单的字幕格式——但"简单"只是说规范简单，实际文件的格式问题千奇百怪：BOM 头、\r\n 混用、序号缺失、时间轴格式不规范、空行数量不一致。一个健壮的解析器得把这些都处理好。Rust 实现。

标准 SRT 格式：空行分隔的字幕块，每块包含序号（整数）、时间轴（HH:MM:SS,mmm --> HH:MM:SS,mmm）和文本（可能多行）。但实际文件可能偏离规范。序号可以是任意数字甚至缺失——缺失时不影响解析（自己编号）。时间轴的逗号可能是点号，小时位可能只有一位，分隔符两侧可能有多余空格。

时间解析——用正则或手动解析提取时间分量：时（0-99）、分（0-59）、秒（0-59）、毫秒（0-999）。转成毫秒：total_ms = h×3600000 + m×60000 + s×1000 + ms。BOM 头（0xEF 0xBB 0xBF）要在文件开头检测并跳过。文本内容保留原始格式，包括换行。

解析后输出为 JSON 数组——每个元素包含 index（整数）、start_ms（毫秒）、end_ms（毫秒）、text（字符串，内部换行用 \n 表示）。加 --json 参数输出 JSON，默认输出可读格式。用法 srt-parser parse subtitles.srt --json。Rust 实现，cargo build 通过。
