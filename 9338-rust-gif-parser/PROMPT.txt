做一个 GIF 图片文件解析工具，能解析 GIF 动图的结构和帧信息。

解析内容：
- 验证 GIF 签名（GIF87a 或 GIF89a），读取逻辑屏幕描述符（宽高、全局颜色表大小、背景色索引）
- 解析全局颜色表（GCT）和每帧的局部颜色表（LCT）
- 解析图形控制扩展（GCE）： disposal method、用户输入标志、透明色索引、延迟时间
- 读取每帧的图像描述符（左/上偏移、宽高）和 LZW 压缩的像素索引数据（不解压，只报告大小）
- 统计总帧数、动画总时长、循环次数（从 NETSCAPE 扩展读取）

Rust 实现，cargo build 通过。`gif-parser info animation.gif`。
