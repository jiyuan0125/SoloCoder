做一个 TIFF 图片文件格式解析工具，能处理 TIFF 的 IFD 结构。

解析要求：
- 验证字节序标记（II 小端 / MM 大端），读取魔数 42 和第一个 IFD 偏移
- 遍历 IFD（Image File Directory）中的标签条目，解析 tag ID、类型、数量、值/偏移
- 识别关键标签：ImageWidth、ImageLength、BitsPerSample、Compression、PhotometricInterpretation、StripOffsets、StripByteCounts
- 支持链式 IFD（一个 TIFF 文件可能包含多页，通过 NextIFDOffset 链接）
- 处理大端小端的正确字节序转换

用 Rust 写，cargo build 通过。`tiff-parser info scan.tiff` 输出 IFD 标签列表。
