码率分析——流媒体调优的基础操作。容器元数据声明的码率经常不准，必须通过实际数据量来计算真实码率。视频平台的转码质量评估也依赖精确的码率统计。Rust 实现。

总码率最简单的算法——文件大小 × 8 / 时长秒数 / 1000 = kbps。但这个值包含了容器开销，不能精确反映视频流本身的码率。分轨道码率才是关键——MP4 从 stsz 表统计各 track 的总字节数，除以各自的时长。MKV 从 Cluster 的 Block 按 track number 区分统计。TS 按 PID 分类统计各 PID 的总字节数。

VBR 检测——按时间段（每秒或每 10 秒）统计码率变化曲线。如果所有时间段的码率都在均值的 ±5% 以内，判定为 CBR（恒定码率）。标准差越大越可能是 VBR。同时记录峰值码率（所有时间段的最高值）——这对带宽规划很重要，直播流的峰值码率不能超过上行带宽。输出视频码率、音频码率、总码率，单位 kbps 和 Mbps，标注 CBR/VBR 估算和峰值码率。加 --timeline 输出逐秒码率数据。用法 bitrate-calc video.mp4。Rust 实现，cargo build 通过。
