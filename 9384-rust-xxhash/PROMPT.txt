xxHash 不是加密哈希——它是超高速的非加密哈希函数，设计目标是极致速度。在数据校验、哈希表、布隆过滤器场景下比 CRC32 和 MD5 快得多。Rust 实现 xxHash32 和 xxHash64。

xxHash32 的算法流程。初始化：根据 seed 值计算四个累加器 v1-v4 = seed + prime1 + prime2、seed + prime2、seed、seed - prime1。每轮处理 16 字节（4 × 4）：每个累加器 += 输入字 × prime2，然后左旋 13 位，再乘以 prime1。最后把四个累加器合并：累加结果 ^= 右旋17(累加结果 × prime1)，一系列 merge 操作。

剩余字节处理——4 字节一组：acc += 输入字 × prime3，acc = rotl(acc, 17) × prime4。1 字节一组：acc += 输入字节 × prime5，acc = rotl(acc, 11) * prime1。最后混合作：acc ^= acc >> 15，acc *= prime2，acc ^= acc >> 13，acc *= prime3，acc ^= acc >> 16。

xxHash64 类似但用 64 位运算和不同的常量。Streaming 模式——对大文件分块计算，维护中间状态。输出十六进制哈希值和计算耗时（微秒）。用法 xxhash file.bin --algo xxh64 --seed 0。Rust 实现，cargo build 通过。
