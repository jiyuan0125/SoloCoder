文件签名验证——确保文件没被篡改。完整的数字签名需要 RSA/ECC 非对称加密，但简化版可以用 HMAC-SHA256 实现类似的效果。Rust 实现。

签名生成流程：读取密钥文件（任意二进制数据）和输入文件，计算 HMAC-SHA256（密钥 + 文件内容），把结果写入 .sig 文件（32 字节二进制 + 可选的元数据如文件名和时间戳）。签名文件格式：8 字节 magic（"FHSIG001"）+ 4 字节版本 + 4 字节签名长度 + 签名数据 + 8 字节原始文件长度 + 原始文件路径（零终止字符串）。

验证流程：读取签名文件，提取原始签名和元数据。重新计算文件的 HMAC-SHA256，与存储的签名对比。匹配输出 VERIFIED，不匹配输出 TAMPERED 并显示文件名和预期/实际签名值。

密钥管理——密钥从文件读取（--key secret.key），不硬编码。生成随机密钥用 --gen-key 参数输出 32 字节随机数据到指定文件。也支持用密码派生密钥——PBKDF2 算法用密码 + 盐值派生 32 字节密钥。用法 file-sig sign --key secret.key --input data.tar 和 file-sig verify --key secret.key --input data.tar --sig data.tar.sig。Rust 实现，cargo build 通过。
