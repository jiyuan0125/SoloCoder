MP3 文件标签信息散在两个地方——ID3v1 在文件末尾 128 字节，ID3v2 在文件开头。v1 简单但信息少，v2 信息丰富但格式复杂。写个 Python 工具同时读取两种格式。

ID3v1 解析——读文件最后 128 字节，前 3 字节 "TAG"，然后标题（30B）、艺术家（30B）、专辑（30B）、年份（4B）、注释（30B）、流派（1B 查表映射）。注释第 30 字节非零就是曲目号（v1.1 扩展）。文本 ASCII 编码空格填充。

ID3v2 解析——10 字节标签头：3 字节 "ID3"、2 字节版本号（2.3 或 2.4）、1 字节标志位、4 字节大小（syncsafe integer 编码——每字节只用低 7 位共 28 位）。帧结构：4 字节帧 ID（TIT2、TPE1、TALB、TRCK、TDRC 等）+ 4 字节大小 + 2 字节标志 + 数据。文本帧首字节编码标识：0=ISO-8859-1、1=UTF-16 BOM、2=UTF-16BE、3=UTF-8。APIC 帧包含封面图二进制数据。

v2.3 和 v2.4 的区别主要在帧大小编码——v2.3 用普通整数，v2.4 用 syncsafe integer。不认识的帧跳过。用法 python mp3_tag.py info song.mp3，Python 3 实现。
