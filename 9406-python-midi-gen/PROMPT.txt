需要用代码自动生成测试用的 MIDI 文件——音阶、和弦进行、简单旋律之类的。Python 写一个 MIDI 文件构建器。

MIDI 文件的二进制结构。文件头 MThd：格式 0（单轨）或格式 1（多轨）、轨道数、PPQN（如 480 ticks per quarter note）。每个 MTrk 轨道：delta-time（变长整数编码）+ 事件。速度事件（meta 0x51）：3 字节微秒/四分音符（如 120BPM = 500000μs = 0x07A120）。拍号（meta 0x58）：4 字节（如 4/4 = 04 02 18 08）。

音符事件的写入。Note On：0x9n + 音高(0-127) + 力度(1-127)。Note Off：0x8n + 音高 + 0。delta-time 是当前事件和上一个事件之间的 tick 数。构建时要维护一个"当前时间"指针，每次添加事件计算 delta = event_time - current_time。

功能：设置拍号和速度、添加音符（音高、开始时间、持续时长、力度、通道）、添加休止符、多轨道支持。生成的文件符合 MIDI 标准格式能被常见播放器打开。用法 python midi_gen.py --bpm 120 --output scale.mid。Python 3 直接运行。
