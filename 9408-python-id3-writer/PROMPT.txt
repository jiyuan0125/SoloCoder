往 MP3 文件里写 ID3 标签分两种场景——文件已有 ID3v2 的就读出原有帧，修改目标帧后重新编码覆盖；没有 ID3v2 的就在 MPEG 帧之前插入新的 ID3v2 标签。

第二步构造 ID3v2.4 帧结构。帧 ID（4 字节 ASCII）+ 大小（4 字节 syncsafe）+ 标志（2 字节全 0）+ 数据。文本帧统一用 UTF-8 编码（首字节 0x03）。TIT2="标题" 编码后：0x03 + UTF-8 bytes。TPE1、TALB、TRCK、TDRC 类似。帧大小计算包含编码标识字节。

第三步组装标签体。所有帧按 ID 升序排列后拼接。标签头：3 字节 "ID3" + 2 字节版本 4.0 + 1 字节标志 + 4 字节标签体大小（syncsafe）。在标签体末尾加 padding（若干 0x00 字节），为将来修改留空间。

第四步写回文件。如果原有 ID3v2 标签，新标签覆盖原位置（如果新标签更大则后续数据后移）。原有音频数据（MPEG 帧）不能损坏，写完后文件还能正常播放。用法 python id3_writer.py write song.mp3 --artist "周杰伦" --title "晴天"。Python 3 实现。
