想在网页上展示音频波形图——后端生成波形摘要数据，前端渲染。Python 写一个波形数据生成工具。

波形数据计算——把音频按固定时间窗口分段（比如每秒 100 个采样点）。每段计算峰值 max、峰值 min 和 RMS。16bit PCM 的 max/min 范围 -32768~32767。立体声先合并为单声道（左右取平均）。支持 16bit/24bit/32bit 整数和 32bit 浮点格式。

输出 JSON 格式：{ "sample_rate": 44100, "channels": 2, "samples": 960000, "points_per_second": 100, "max": [...], "min": [...], "rms": [...] }。max/min/rms 数组长度 = 时长秒数 × points_per_second。大文件流式处理——按窗口读取计算后丢弃原始数据。

也能生成 ASCII 字符画形式的波形在终端直接看——用字符高度表示振幅（8 级：█▇▆▅▄▃▂▁ ）。用法 python waveform.py gen audio.wav --samples-per-second 100 > wave.json，python waveform.py ascii audio.wav。Python 3 实现，不依赖重型框架。
