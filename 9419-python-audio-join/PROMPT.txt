手里有一堆音频片段要拼成一个完整文件——录播课按章节分的段落、采访按问题分的录音、播客的广告位和正片。手动在剪辑软件里拖来拖去太慢了，命令行直接拼才是正事。

拼接之前先做参数校验。所有输入文件的采样率、位深、声道数必须完全一致，不一致直接报错退出并告诉用户哪个文件的哪个参数不匹配。这一点不能含糊——采样率不同的文件拼在一起播放会变调变速，声道数不同的文件更没法处理，强行拼出来的东西没法听。

拼接处做可选的交叉淡入淡出。前一个文件末尾 N 毫秒线性渐弱（采样值乘以从 1 递减到 0 的系数），后一个文件开头 N 毫秒线性渐强（从 0 递增到 1），两段叠加。淡入淡出的重叠区域能避免拼接处出现"咔嗒"声。默认不淡入淡出，用户用 --crossfade 指定毫秒数开启。文件之间可插入静音间隔，--gap 控制。

写入过程：先写占位 WAV 文件头，依次从每个输入文件读 PCM 数据写入，中间插入静音。全部写完回填实际数据大小。用法：python3 audio_join.py a.wav b.wav c.wav --gap 500 --crossfade 50 -o merged.wav
