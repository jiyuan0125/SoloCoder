手头有一批 MP4 文件想快速了解每个文件的视频参数和元数据——编码格式、分辨率、帧率、比特率、还有 moov/udta 里存的歌曲标题、艺术家、描述之类的标签信息。打开播放器一个个看太慢了，命令行一条搞定才对。

解析流程：先找到 moov box——它是所有元数据的根容器。从 mvhd 里读时间刻度和时长，算出总时长（秒 = duration/timescale）。从 trak → mdia → minf → stbl → stsd 里读编码参数。stsd 里面视频轨存了编码类型（avc1 是 H.264、hev1 是 H.265）、宽高；音频轨存了采样率、声道数。esds box 里有详细的编码器配置——Profile/Level、配置描述符等。元数据在 moov → udta 里面——©nam 是标题、©ART 是艺术家、©des 是描述，都是 iTunes 格式的标签。

输出整理成易读的文本格式，每个参数一行标清楚。关键参数包括：视频编码/分辨率/帧率/比特率、音频编码/采样率/声道数、所有元数据标签。用法：python3 mp4_metadata.py show video.mp4
