1. 感知哈希（pHash）的核心思路：把图片缩小到 32×32，转灰度，做 DCT 变换取左上角 8×8 的低频系数（这些系数反映了图片的整体轮廓），然后算均值，大于均值的位设为 1、小于的设为 0，得到 64 位哈希。两张图片的 pHash 汉明距离越小表示视觉上越相似。

2. 差异哈希（dHash）更简单：把图片缩小到 9×8（注意是 9 列 8 行），转灰度，每行的 9 个像素两两比较——左边比右边亮就是 1，否则 0。每行 8 个比较结果，8 行共 64 位哈希。dHash 对缩放和轻微裁剪有很好的鲁棒性，计算速度也比 pHash 快。

3. 比较功能：输入两张图片的路径，分别计算哈希后求汉明距离（两个等长二进制串有几个位不同）。距离为 0 表示完全一样，1-5 基本上是同一张图（可能经过压缩或微调），10 以上是不同的图。

4. 支持常见格式 JPG、PNG、BMP。纯 Python 实现，缩放和灰度转换用基本的像素操作。用法：python3 image_hash.py hash image.png 或 python3 image_hash.py compare img1.jpg img2.jpg
