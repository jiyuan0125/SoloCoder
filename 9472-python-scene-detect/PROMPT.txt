一批教学视频要做章节标记，手动看一遍再标记太慢了。场景切换检测能自动找到画面突变的切点——切镜、转场、PPT 翻页这些动作在帧间差异上都有明显特征。通过比较相邻帧的像素或直方图差异来判断场景切换位置，不需要人工干预。

检测算法。对每帧计算灰度直方图（256 个 bin，统计每个亮度级别的像素数量），然后和前一帧的直方图做差异比较。差异度量用卡方距离：D = Σ(h1[i] - h2[i])² / max(h2[i], 1)。差异值超过阈值（默认 30，可调）就标记为一个场景切换点。直方图比较比逐像素比较速度快得多，而且对微小的镜头抖动不敏感——画面整体亮度稍微变化不会触发误检，但切镜这种大面积像素变化一定会被捕获到。

灵敏度参数很关键。阈值低检测灵敏但可能误报（光照变化、快速运镜都会触发），阈值高只抓硬切但可能漏掉渐变转场。用户根据视频类型自行调整合适的阈值。输出每个切换点的时间戳和差异值，可选 JSON 或 CSV 格式方便后续脚本处理。用法：python3 scene_detect.py detect video.mp4 --threshold 30 --format json
