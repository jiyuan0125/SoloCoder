调试微服务的时候经常收到一堆 protobuf 二进制数据，没有对应的 .proto 文件根本看不懂内容。需要一个工具能在没有 schema 的情况下解析 protobuf 的 wire format——通过字段编号和 wire type 来推断数据的基本结构。

Protobuf wire format 的核心概念。每个字段由 field number（变长整数 varint）和 wire type（3 位）组成，合成一个 tag。Wire type 决定后续数据的读取方式：0=Varint（变长整数，每个字节的最高位是连续标志），1=64-bit（固定 8 字节，double 或 fixed64），2=Length-delimited（先读 varint 得到长度，再读对应字节数，可能是 string、embedded message 或 packed repeated），5=32-bit（固定 4 字节，float 或 fixed32）。

解码策略。遇到 wire type 0 读 varint 按整数输出。遇到 wire type 2 读出字节数后，先尝试当 UTF-8 字符串解码，如果失败就尝试递归当嵌套消息解码（重新从字节头开始读 tag），都失败就输出十六进制。最终输出 JSON 格式。用法：python3 protobuf_decode.py decode --input data.bin --output data.json
