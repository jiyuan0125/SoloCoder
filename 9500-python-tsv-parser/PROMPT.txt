Tab 分隔值文件在生物信息学和日志分析领域非常常见——基因表达数据、测序结果、服务器访问日志经常用 TSV 格式存储。和 CSV 相比 TSV 的分隔符固定是 Tab，不需要处理引号转义的复杂情况，但仍有自己的陷阱需要处理。

解析规则。以 Tab（\t）作为字段分隔符，每行一条记录。行尾符可能是 LF（Unix）或 CRLF（Windows），都要支持。字段内如果包含 Tab 或换行（理论上不应该但实际会出现），需要双引号包裹。空行跳过。第一行可能是表头（字段名），通过 --header 参数控制是否把第一行当表头。

提供的操作。列提取：--columns 1,3,5 或 --columns name,age,score 只输出指定列。行筛选：--where "col2=hello" 按条件过滤行，支持等于和不等于。行数统计：--count 输出总行数。格式转换：--to csv 输出成 CSV 格式（字段加引号）、--to json 输出成 JSON 数组（每行一个对象）。大文件流式处理，逐行读写不把整个文件加载到内存。用法：python3 tsv_parser.py parse data.tsv --columns 1,3,5 --where "col2=hello" --to csv --output out.csv
