上周有个同事拿了一百多篇论文 PDF 过来，要做文献综述，需要把正文全部导出来做关键词分析。手动复制粘贴显然不现实，得写个脚本批量处理。

Python 3 命令行工具，输入 PDF 路径提取文本内容。支持普通文字型 PDF（底层有文本层）和扫描版 PDF——如果嵌了 OCR 层也能把隐藏文字提出来。命令行指定文件路径后文本输出到 stdout 或写入指定文件。

保留基本段落结构很关键，不同页之间用 [Page N] 分隔符隔开，方便后续定位引用。碰到表格尽量按行输出，把每个单元格内容用 | 分隔，别把数据搅成一团。PDF 里常见的多栏排版也要处理，按照阅读顺序拼接而不是位置顺序。加密或损坏的文件给出清晰错误提示——是密码保护还是文件不完整，别直接抛 traceback 让用户一脸懵。

支持目录批量处理：python main.py ./papers/*.pdf --output ./texts/。每篇 PDF 对应一个同名 .txt 文件，处理进度要实时打印。用 pypdf 或 pdfplumber 就够了，python main.py 能直接跑起来。

输出文本用 UTF-8 编码，遇到 PDF 内部的非标准编码要做映射。处理速度也有要求——单个 PDF 别超过 5 秒，大文件给个 --fast 模式只提纯文本跳过复杂表格。
