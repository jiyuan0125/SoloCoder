每个月要发几十份合同和申请表，格式一样但数据不同。复制粘贴填表再导出 PDF 重复到想吐，能不能让程序自动干？

Python 工具往 PDF 表单模板里批量填数据然后导出新文件。数据来源是 CSV 或 JSON，每行对应一份表单。先有个 list 命令读模板 PDF 列出所有可填写字段——字段名和类型（文本框、复选框、下拉选择），方便对照着准备数据 CSV。

填写时处理几种控件：文本框直接填字符串，复选框根据布尔值勾选，下拉选择匹配选项值。日期字段支持 "2024-01-15" 自动转成 PDF 表单日期格式。填完输出新 PDF，文件名基于 CSV 某列值自定义，比如用合同编号命名。

错误处理要到位——字段值类型不对、必填字段为空、模板不存在这些情况都给出明确报错信息。输出目录自动创建，处理完打印汇总：成功多少份、失败多少份、哪些行出了问题。Python 3 命令行工具。

模板 PDF 如果带数字签名，填充后签名会失效，这个要在输出时提醒用户。支持 --dry-run 模式预览填充结果不实际写文件。

对于没有表单字段的纯 PDF（比如扫描件），给出提示说该文件没有可填写字段，跳过不报错。填充完的 PDF 可以加水印标记已处理状态。
