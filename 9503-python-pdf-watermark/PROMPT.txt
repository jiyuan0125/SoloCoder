给 PDF 加水印这事儿听起来简单，但批量处理几百份合同的时候手动搞真能搞死人。

Python 命令行工具给 PDF 加文字或图片水印。文字水印支持自定义内容、字体大小、颜色、透明度（0 到 1 的 alpha 值）、旋转角度——斜着铺满的那种 30-45 度是标准做法。图片水印则指定一张 PNG 路径，调位置和透明度，适合放公司 logo。

两种铺放模式：铺满整页（每隔一定间距重复形成网格水印）和指定位置（右下角盖章、居中大字）。铺满模式的水印间距也要能调，太密了遮挡内容太稀了防护效果差。

批量处理是刚需——给个目录路径递归扫描所有 PDF 文件逐个加水印输出到指定目录。文件多时打印处理进度。单文件：python watermark.py report.pdf --text "CONFIDENTIAL" --opacity 0.3 --angle 45。不能破坏原 PDF 的超链接和书签，输出大小不能膨胀太多。Python 3 实现。

水印加完后可以自动打开 PDF 预览效果，也可以 --check 模式对比加水印前后的文件大小差异。

命令行参数要全面：--text 指定文字水印，--image 指定图片水印，--position 选择位置，--tile 模式铺满，--opacity 调透明度。缺省情况下给个合理默认值让用户最少参数就能跑。
