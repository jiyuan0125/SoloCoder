手上有一批 EPUB 电子书需要做语料整理和全文检索。流程分几步：先读 OPF 元数据拿到书名、作者、语言和目录结构，然后按 spine 顺序遍历所有章节把 XHTML 转成纯文本，最后把嵌入的图片和 CSS 资源也导出来。

输出 JSON 格式结构化数据，字段包括 title、author、language、chapters（每章标题加正文文本）、resources（图片列表及路径）。目录从 NCX 或 nav 文件解析保留层级——第一章下面有 1.1、1.2 这种嵌套要体现出来，不然目录就成扁平列表了。

XHTML 里的特殊标签（脚注、边栏、代码块、链接）转纯文本时要处理干净，别留一堆 HTML 标签。碰到 DRM 加密的 EPUB 给个提示说无法解析，别直接崩溃。

支持命令行指定单个文件或扫描目录批量处理，每个 EPUB 输出一份 JSON。Python 3 实现，用 ebooklib 或者 zipfile 直接解压——EPUB 本质就是 zip 包。python parse_epub.py book.epub -o output.json。

EPUB 里的 CSS 样式信息也可以选择保留一份，方便后续做格式还原。如果某个章节的 XHTML 解析出错，跳过该章节继续处理，不要影响其他正常章节。
