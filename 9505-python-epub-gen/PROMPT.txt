写了一系列技术博客想打包成电子书放 Kindle 上看，手动排版太折腾——能不能直接从 Markdown 自动生成 EPUB？

输入一组 Markdown 文件（每个文件一个章节），按顺序组装成 EPUB 电子书。Markdown 转 XHTML 时正确处理加粗、链接、代码块、图片引用这些常见语法。章节标题从文件名或一级标题自动提取，生成目录（TOC）。

书的元信息可配置：书名、作者、语言、ISBN，用 JSON 配置文件或命令行参数都行。图片处理比较关键——Markdown 里引用的图片路径要正确映射到 EPUB 内部路径，图片文件必须打包进去，不然在阅读器上显示不出来。

CSS 样式可以自定义，默认提供一套干净的排版样式（合理的行高、段间距、代码块高亮）。生成的 EPUB 要能在 Kindle、Apple Books、Calibre 上正常打开。能通过 epubcheck 校验就更完美了。

Python 3 命令行工具。python epub_gen.py --title "我的书" --author "张三" chapter1.md chapter2.md -o mybook.epub。
