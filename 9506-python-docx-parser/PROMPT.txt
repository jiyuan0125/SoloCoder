公司积累了上千份 Word 格式的方案文档，最近要做知识库建设需要批量提取结构化内容建索引。手动打开看不可能，得写个解析工具自动处理。

Python 3 解析 .docx 文件，提取段落结构、表格数据、嵌入图片和文档属性。段落识别标题层级（Heading 1/2/3）和正文，重建文档大纲时保留层级关系。有些文档目录结构混乱——标题样式不规范或者用加粗大字冒充标题，这种情况尽量兼容处理。

表格数据转成二维列表，也可以直接导出 CSV 格式。合并单元格要做展开处理，每个格子里填上正确的值。文档中嵌入的图片导出为独立文件按出现顺序编号命名。

文档属性也要读取——作者、创建时间、修改时间、修订次数这些元数据放在输出 JSON 的 metadata 字段里。解析结果以 JSON 格式输出。碰到损坏的 .docx 或者实际是 .doc 格式的文件优雅处理给提示。python parse_docx.py document.docx -o result.json。

有些 .docx 文件内嵌宏或者 VBA 脚本，这种情况给个提示。输出 JSON 文件过大时可以按章节拆分成多个小文件。

输出 JSON 支持 --pretty 格式化（带缩进换行）和 --compact 紧凑格式。大批量处理时给个进度条和预计剩余时间。
