每周五要出项目周报，格式固定但数据不同——手动粘贴太费时间了，经常漏改日期搞错表格数据。用代码自动生成 Word 文档才是正道。

Python 程序通过代码调用生成 .docx 文件，不用装 Word 软件。文档内容支持多级标题、正文段落、有序无序列表。表格是重点功能——指定行列数和内容，支持合并单元格（横跨所有列的表头），可设背景色和对齐方式。

格式控制够用：字体（中文字体如宋体微软雅黑也要支持）、字号、颜色、加粗斜体下划线。页面设置包括纸张大小 A4、页边距、页眉页脚。页眉放公司 logo 图片，页脚放页码。往文档里插图片要能指定路径和尺寸，自动等比缩放。

提供模板函数，输入 Python 字典（项目名、本周进展、下周计划、风险项等）自动填充到周报模板生成完整 docx。样式可基于已有 docx 模板文件继承，公司 CI 规范不用硬编码。python gen_report.py --data this_week.json -o 周报.docx。

如果数据里的某个字段值为空或者 None，对应位置留空不填，别填个 None 字符串进去。支持 --preview 模式只生成不保存，打印文档大纲让用户确认。
