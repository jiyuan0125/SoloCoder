读 Excel 文件——听着简单，实际上同事发来的表各种奇葩：合并单元格满天飞、公式嵌了好几层、表头不在第一行、一个文件里十几个 sheet。每次手动处理都要骂人。

Python 3 工具读取 .xlsx 提取结构化数据。指定工作表按行列输出，遇到合并单元格可选择处理策略：展开填充值让每个格都有内容，或者标记合并区域边界。单元格类型要正确识别——数字、日期（别把日期读成浮点数）、布尔值、公式和纯文本。公式单元格能取到计算后的值而不是公式字符串本身。

有些 Excel 里嵌了图表，至少能读出标题、数据范围、图表类型。支持列出所有 sheet 名称，批量导出多个 sheet 为独立 CSV 文件——一个 sheet 一个 CSV。

大文件分批读取，支持指定行范围或流式逐行读取，别一口气把几万行全塞内存。损坏的 sheet 要有降级处理。python read_xlsx.py data.xlsx --sheet "销售数据" --range A1:D100。

如果 sheet 名称包含中文或特殊字符，输出 CSV 时要做文件名安全处理。支持 --format 参数选择输出格式：JSON、CSV 或者 Python dict。
