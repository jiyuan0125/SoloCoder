自动化报表流程：先从数据库或 CSV 拿原始数据，然后按固定模板写入 Excel 加样式和公式，最后发给领导。整个过程用代码来干不用打开 Excel。

Python 3 生成 .xlsx 文件。创建多工作表各有独立名称和标签颜色。写入数据时数字格式可设置——货币（¥1,234.56）、百分比（85.5%）、千分位分隔。日期字段写入后要被 Excel 正确识别为日期类型而不是一串数字。

样式是区分"能用"和"好看"的关键：字体名称和大小、文字颜色、边框（四个边独立设粗细颜色）、对齐方式、背景填充色。合并单元格做表头、自动调整列宽让长内容不被截断。内置 SUM、AVERAGE、COUNT、VLOOKUP 等常用函数的快捷写入方法。冻结首行或首列方便滚动时表头不丢。

条件格式也支持——大于某值的单元格自动标红。python gen_xlsx.py --template config.json --data sales.csv -o 月报.xlsx。

如果配置文件里的模板引用了不存在的列名，启动时就要报错别等到写 Excel 的时候才发现。支持 --dry-run 验证配置不实际生成文件。
