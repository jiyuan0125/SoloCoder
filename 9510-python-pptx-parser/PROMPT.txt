老板说把过去一年培训 PPT 全部审查一遍，看有没有过时内容或敏感信息泄露。几百个文件手动打开看谁有那闲工夫？

Python 解析器提取 .pptx 里文本和媒体内容。遍历每页幻灯片，提取标题、正文文本框内容、备注页文字。文本记录格式信息——字号、颜色、是否加粗、位置坐标，方便做关键词搜索时按重要性排序。形状里的文字也要覆盖到，有些人把内容放在矩形框或者箭头旁边。

媒体文件：嵌入的图片按幻灯片编号保存为独立文件，音频视频资源一并导出到 assets/ 目录。表格和 SmartArt 里的文字不能遗漏，图表要能读出数据系列和类别名称。

解析结果以 JSON 输出按幻灯片编号组织，每页包含 texts、images、tables、notes 字段。支持批量扫描目录下所有 pptx 文件。Python 3 实现，python-pptx 库。python parse_pptx.py training.pptx -o result.json。

对于 PPT 里嵌的 OLE 对象（比如 Excel 表格链接），给出提示说明无法提取。版本兼容性也要处理——.ppt 格式（老版 PowerPoint）和 .pptx 区分开。
