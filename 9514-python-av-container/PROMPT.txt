整理视频归档第一步得搞清楚每个文件的底细——什么编码、多长时间、多少分辨率。几百个文件手动右键看属性太原始了。

Python 3 音视频容器格式解析工具。先读文件头识别容器类型（MP4、MKV、AVI 三种主流格式），然后逐层解析容器结构提取信息。视频流包括编码格式（H.264/H.265/VP9）、分辨率（宽×高）、帧率（fps）、码率（bps）。音频流包括编码格式（AAC/MP3/Opus）、采样率、声道数、码率。

容器级别的元数据也要提取：总时长（秒）、创建时间、标题标签。MP4 的 moov box 里有章节标记和字幕轨道信息，MKV 的 SegmentInfo 也类似。多音轨和多字幕轨道要全部列出来——有些视频文件带国语粤语两条音轨加中英两条字幕。

解析结果以 JSON 格式输出完整媒体信息报告。不需要依赖 ffmpeg 命令行，纯 Python 解析二进制文件头。python probe.py movie.mp4 -o info.json。

碰到加密的媒体文件或者 DRM 保护的，给出提示。对于不支持的容器格式（比如 FLV、WMV），友好提示而不是报错退出。

碰到无法识别的容器格式给友好提示而不是崩溃。支持管道模式从 stdin 读取文件路径批量处理，输出汇总 JSON。
