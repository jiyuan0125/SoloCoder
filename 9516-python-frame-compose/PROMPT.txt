上次拍了延时摄影素材——每隔 5 秒拍一张连续拍了三小时攒了上千张照片。后期需要把这些照片按顺序合成一个流畅的视频。做深度学习时也有类似需求——模型生成的帧序列要导出 MP4 看效果。

Python 3 图片帧合成视频工具。输入一组按序号排列的图片文件（支持 PNG、JPEG、BMP），程序按文件名排序后逐帧读取合成视频。输出编码格式优先 H.264，帧率可配（常见的 24/25/30/60fps），分辨率可以指定或者自动取第一张图的尺寸。输入图片尺寸不一致时自动统一缩放到最小公共尺寸。

可以给每帧叠加信息——左下角显示时间戳或者自定义的文字水印（字体大小和颜色可调）。还能添加一条背景音乐音轨，指定一个音频文件路径，视频时长自动对齐到音频长度或帧序列长度。

处理过程中输出编码进度百分比和预估剩余时间。python compose.py frames/ --fps 30 --codec h264 -o timelapse.mp4。

如果图片文件名没有序号而是时间戳格式，也要能正确排序。支持 --reverse 选项倒序合成。帧率为 0 时输出 GIF 格式作为备选。

如果图片总量很大（上万张），合成前要估算最终视频文件大小和耗时，超过阈值给警告让用户确认。合成完成后打印视频总时长和文件大小。
