做图像处理实验最烦每次都要写一遍"读取图片→转成数组→操作像素→保存"的样板代码。这些准备工作可以封装成一个通用的像素操作工具，以后不管做颜色反转、灰度化还是自定义变换都能直接用。

Python 3 实现像素级操作库。核心能力：读取常见图片格式（JPEG、PNG、BMP、TIFF、WebP），内部用 numpy 二维数组表示（高度×宽度×通道数）。像素读写支持获取/设置单个像素值、批量设置矩形区域的所有像素。提供逐像素映射函数——传入 lambda 或函数对象对每个像素做变换，比如反转颜色 lambda r,g,b: (255-r,255-g,255-b)。

像素统计功能：每个通道的最大值、最小值、均值、中位数、标准差，整体亮度的直方图数据。大图（超过 100MB）支持分块处理——把图片切成固定大小的块逐块操作后拼接回去避免内存溢出。

操作完保存回图片文件，格式根据输出后缀自动判断。命令行 python pixel.py input.jpg --map invert -o output.jpg，也可以作为 Python 库被其他脚本 import 使用。

操作历史要记录——对图片做了什么变换、参数是什么，方便回溯和复现。支持链式操作：python pixel.py input.jpg --map invert --then grayscale -o output.jpg。
