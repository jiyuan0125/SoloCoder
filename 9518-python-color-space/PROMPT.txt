颜色空间转换——RGB 不是万能的。做颜色分割用 HSV，做亮度处理用 YUV，做印刷用 CMYK，做特征提取转灰度。每次手写转换公式要么抄错要么精度不够，搞个靠谱的工具一劳永逸。

支持这些颜色空间互相转换：RGB、HSV、HSL、灰度、YUV/YCbCr、CMYK。两两之间都要能转，不是只支持转到某个中心格式。单个像素值转换（输入 RGB 三元组输出 HSV 三元组）和整张图片批量转换都支持。批量转换时用 numpy 向量化运算，别用 for 循环逐像素搞。

转换精度不能马虎——8 位色深（0-255）和 16 位色深（0-65535）都要支持，浮点运算中间结果不能截断只在最终输出时 clamp 到合法范围。RGB→灰度的系数不能用简单平均，得用 ITU-R BT.601 标准加权公式（0.299R + 0.587G + 0.114B）。HSV 的 H 通道要注意输出是 0-360 还是 0-179。

python colorspace.py photo.jpg --to HSV -o output.jpg。Python 3 实现。

如果目标空间不支持某个通道（比如 CMYK 没有 Alpha），转换时自动丢弃并给出警告。也可以作为 Python 库 from colorspace import convert 直接调用。
