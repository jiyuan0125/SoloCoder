之前做文档扫描项目，手机拍的纸质文档光照不均——有的地方亮有的地方暗，直接丢给 OCR 引擎识别率惨不忍睹。第一步必须把图片转成干净的黑底白字二值图，这就离不开阈值化处理。

Python 3 实现多种图像阈值化方法。全局阈值最简单手动指定一个值（0-255），大于的变白小于的变黑。Otsu 自动阈值算法自动计算最佳分割点不用手动调参。自适应阈值更灵活把图片分成小块每块独立算阈值，适合处理光照渐变的情况。

二值化和截断阈值两种模式都要支持：二值化是非黑即白，截断是超过阈值保持不变没超过的变零。输入彩色图片时自动先转灰度再处理。批量处理模式可以把当前使用的阈值参数保存到 JSON 文件下次复用。

默认用 Otsu 算法加自动阈值省去手动调参。结果输出包含对比图：原图灰度、Otsu 结果、自适应结果并排展示。python threshold.py doc_scan.jpg --method adaptive -o binary.jpg。

另外要注意，参数合理范围要有校验——核大小必须是奇数、sigma 不能为负、阈值在 0-255 之间。如果参数超出范围给出建议值而不是默默接受。处理前后可以做 PSNR 或 SSIM 对比量化效果变化。支持 --preview 模式只在窗口显示不保存文件。
