之前做文档扫描项目，手机拍的纸质文档光照不均——有的地方亮有的地方暗，直接丢给 OCR 引擎识别率惨不忍睹。第一步必须把图片转成干净的黑底白字二值图，这就离不开阈值化处理。不同场景要用不同的阈值策略，一个工具得全支持。

Python 3 实现多种图像阈值化方法。全局阈值最简单手动指定一个固定值 0-255，大于阈值的像素变白小于的变黑。Otsu 自动阈值算法通过最大化类间方差自动计算最佳分割点不用手动调参，对双峰直方图的图片效果最好。自适应阈值把图片分成小块每块独立算阈值适合处理光照渐变的情况，块大小和偏移量可调。

二值化和截断阈值两种输出模式都要支持：二值化是非黑即白，截断是超过阈值保持不变没超过的变为零。输入彩色图片时自动先转灰度再处理不需要手动预处理。批量处理模式可以把当前使用的阈值参数保存到 JSON 文件下次直接复用同样的参数。

默认用 Otsu 算法自动阈值省去手动调参的麻烦。结果输出包含对比图：原图灰度、Otsu 结果、自适应结果并排展示方便比较效果。python threshold.py doc_scan.jpg --method adaptive -o binary.jpg
