图片去噪、模糊、锐化这些操作底层全是滤波。不同噪声要用不同滤波器——椒盐噪声用中值滤波效果最好，高斯噪声用高斯滤波，保边去噪用双边滤波。每次都要翻资料选滤波器太麻烦了。

Python 3 实现常用空域滤波器：均值滤波（简单取邻域平均）、高斯滤波（距离加权平均核大小和 sigma 可调）、中值滤波（取邻域中位数对椒盐噪声有奇效）、双边滤波（同时考虑空间距离和像素值差异保边去噪）、Unsharp Mask 锐化（先模糊再用原图减去模糊图得到细节叠加回去增强边缘）。

还支持自定义卷积核——输入一个矩阵直接做卷积运算。逐通道独立滤波或三通道合并处理都可以。可视化滤波前后的差异图直观展示滤波器去掉或增强了什么。

滤波核参数保存为 JSON 配置文件方便复现。python filter.py noisy.jpg --type bilateral --sigma 10 -o denoised.jpg。Python 3 numpy 手写滤波逻辑。

还有一个实际问题：参数合理范围要有校验——核大小必须是奇数、sigma 不能为负、阈值在 0-255 之间。如果参数超出范围给出建议值而不是默默接受。处理前后可以做 PSNR 或 SSIM 对比量化效果变化。支持 --preview 模式只在窗口显示不保存文件。
