工厂流水线上摄像头拍产品照片后要在上面定位特定标记的位置——比如找到每个零件上的定位孔确认孔位偏差在允许范围内。PCB 板检测也要找焊盘位置。模板匹配的核心思想就是在每个位置滑动模板计算和大图对应区域的相似度。

Python 3 实现图像模板匹配工具。在大图中搜索小图模板的位置，支持三种相似度度量方法：NCC 归一化互相关对亮度变化有鲁棒性是最常用的方法、SAD 绝对差值之和计算速度最快适合实时场景、SSD 平方差之和对大误差更敏感。匹配置信度阈值可设置低于阈值的候选结果直接丢弃。

多尺度匹配必须支持——模板和目标大小不一致时自动在多个缩放比例的图片上搜索找到最佳匹配尺度。多目标检测：同一模板出现多次全部找出来然后用非极大值抑制 NMS 去掉重叠的检测结果保留置信度最高的。
