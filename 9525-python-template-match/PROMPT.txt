工厂流水线上摄像头拍产品照片后要在上面定位特定标记的位置——比如找到每个零件上的定位孔确认孔位偏差在允许范围内。PCB 板检测也要找焊盘位置。这就是模板匹配的典型场景。

Python 3 实现图像模板匹配工具。在大图中搜索小图模板的位置，支持 NCC（归一化互相关对亮度变化鲁棒）、SAD（绝对差值之和计算快）、SSD（平方差之和）。匹配置信度阈值可设低于阈值的丢弃。

多尺度匹配必须支持——模板和目标大小不一致时自动在缩放后的图片上搜索。多目标检测：同一模板出现多次全部找出来用非极大值抑制去掉重叠的检测结果。

输出每个匹配位置的坐标和相似度分数。结果图上用矩形框标出所有匹配位置框颜色根据分数高低渐变。python match.py product.jpg --template hole.png --threshold 0.8 -o result.jpg。
