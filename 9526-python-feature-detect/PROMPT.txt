帮我做个图像特征点检测工具，实现几种经典的特征提取算法。

做全景图拼接和 3D 重建的前置步骤就是特征点检测。想比较一下不同算法的速度和准确度。

实现以下特征检测器：
- Harris 角点检测
- SIFT 特征（Scale-Invariant Feature Transform）
- ORB 特征（Oriented FAST and Rotated BRIEF）
- FAST 角点检测

功能要求：
- 可视化检测到的特征点，在图上用圆圈或十字标出
- 比较不同算法的特征点数量和分布
- 输出特征点的坐标、尺度、方向等描述信息
- 两张图片之间做特征匹配，画出匹配连线

Python 3 实现。
