做全景图拼接和 3D 重建的前置步骤就是特征点检测。不同算法的速度和准确度差很多，想拿真实图片对比看看。

Python 3 实现几种经典特征检测器：Harris 角点检测（简单快速适合纹理丰富的场景）、SIFT 特征（尺度不变特征变换对缩放旋转都有鲁棒性）、ORB 特征（Oriented FAST and Rotated BRIEF 速度快且免费）、FAST 角点检测（极致速度适合实时场景）。

可视化检测到的特征点——在图上用圆圈或十字标出位置。比较不同算法在同一张图上检测到的特征点数量和分布差异。输出特征点的坐标、尺度、方向等描述信息。

最实用的是两张图片之间的特征匹配——找出两张图中的对应点画出匹配连线，这样就能直观判断匹配质量。python feature.py img1.jpg img2.jpg --method sift --match -o match_result.jpg。

另外要注意，处理异常情况也很重要——输入文件不存在或者格式完全不对（比如把 PNG 当 CSV 传），要给出友好的错误提示而不是 traceback。如果文件特别大（超过 100MB），需要分块或者流式处理避免内存爆炸。输出结果可以同时支持终端打印和 JSON 文件导出两种方式。
