做全景图拼接和 3D 重建的前置步骤就是特征点检测——在两张图片里找到对应的特征点然后算出变换矩阵。不同算法的速度和准确度差很多，想拿真实图片对比看看哪个更适合当前场景的实际需求。

Python 3 实现几种经典特征检测器：Harris 角点检测简单快速适合纹理丰富的场景对旋转不变但对尺度变化敏感。SIFT 尺度不变特征变换对缩放旋转都有鲁棒性是质量最高的但速度较慢。ORB 特征速度快且没有专利限制是实时应用的首选方案。FAST 角点检测极致速度适合对延迟敏感的实时场景。

可视化检测到的特征点——在图上用圆圈标出位置圆的大小反映尺度方向用短线表示。比较不同算法在同一张图上检测到的特征点数量和空间分布差异输出对比报告。每个特征点输出坐标、尺度、方向和描述子维度等完整信息。

最实用的功能是两张图片之间的特征匹配——找出两图中的对应点画出匹配连线用不同颜色区分好匹配和坏匹配，直观判断匹配质量。python feature.py img1.jpg img2.jpg --method sift --match -o match_result.jpg
性能上注意避免不必要的内存分配和拷贝。关键路径上的操作要高效。
