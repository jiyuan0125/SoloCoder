仓库管理的扫码系统需要对接，但有些旧的条形码照片质量不太好——模糊、倾斜、光照不均、条码部分被标签遮挡，商用扫码枪对这些图片无能为力只能人工补录。需要一个容错性强一点的软件识别方案能处理各种质量退化的情况。

Python 3 条形码读取工具从图片中识别各种条形码格式。支持 EAN-13、EAN-8 常见于商品包装的条码、Code 128 和 Code 39 工业编码覆盖物流和仓储场景、UPC-A 和 UPC-E 北美商品条码、ITF 交叉 25 码常用于物流箱贴标。这些格式覆盖了零售和工业场景的大多数识别需求。

从图片文件中定位并读取条形码——先用梯度检测找到条码的大致区域做初步定位，然后对候选区域做解码尝试。支持一张图里有多个条形码全部识别出来返回完整列表。输出每个条码的内容字符串、编码类型以及位置坐标矩形框。

识别失败时给出原因分析——是图片模糊导致条空宽度无法区分、条码被遮挡超过容错范围、还是角度倾斜太严重导致投影失真。这样用户知道该重新拍照还是调整预处理参数。python barcode_reader.py product.jpg
