仓库管理的扫码系统需要对接，但有些旧的条形码照片质量不太好——模糊、倾斜、光照不均，需要容错性强一点的识别方案。

Python 3 条形码读取工具从图片中识别各种条形码格式。支持 EAN-13、EAN-8（商品条码）、Code 128 和 Code 39（工业编码）、UPC-A 和 UPC-E、ITF（交叉 25 码）。这些格式覆盖了零售和工业场景的大多数需求。

从图片文件中定位并读取条形码——先用梯度检测找到条码的大致区域，然后解码。支持一张图里有多个条形码全部识别出来。输出每个条码的内容和类型以及位置坐标。

识别失败时给出原因分析——是图片模糊、条码被遮挡、还是角度倾斜太严重。这样用户知道该重新拍照还是调整参数。python barcode_reader.py product.jpg。
