商品标签、快递面单、库存标牌都需要生成条形码。不同场景用不同的码制——商品用 EAN-13、物流用 Code 128、工业用 Code 39。需要一个能生成多种格式条形码并输出高清图片的工具，生成的图片要能直接用于打印不模糊。

Python 3 条形码生成工具。支持生成 EAN-13、Code 128、Code 39、UPC-A、ITF 等常用格式。输入数字或文本程序自动选择合适的编码方式——EAN-13 必须是 12-13 位数字最后一位是校验位自动计算、Code 128 可以编码任意 ASCII 字符最适合混合内容。

可设置条形码尺寸参数包括整体宽度和高度、前景色和背景色支持自定义、边距大小控制留白。支持在条形码下方显示对应的文本内容方便人工核对。输出 PNG 用于直接打印或 SVG 用于高质量排版不模糊。

批量模式从 CSV 文件读取数据一次生成多个条形码图片文件名用编号或内容摘要命名避免重名。格式不合法的数据跳过并在最后打印警告汇总。python barcode_gen.py --data items.csv --format code128 --output barcodes/
