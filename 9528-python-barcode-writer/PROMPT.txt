商品标签、快递面单、库存标牌都需要生成条形码。需要支持多种码制输出高清图片可以直接打印。

Python 3 条形码生成工具。支持生成 EAN-13、Code 128、Code 39、UPC-A、ITF 等格式。输入数字或文本程序自动选择合适的编码方式——EAN-13 必须是 12-13 位数字、Code 128 可以编码任意 ASCII 字符。

可设置条形码尺寸（宽度和高度）、前景色和背景色、边距大小。支持在条形码下方显示对应的文本内容方便人工核对。输出 PNG 或 SVG 格式——PNG 用于直接打印，SVG 用于高质量排版。

批量模式从 CSV 文件读取数据一次生成多个条形码图片，文件名用编号或内容摘要命名。python barcode_gen.py --data items.csv --format code128 --output barcodes/。

补充几个关键点：输出的文件要能在标准工具里正常打开和显示。如果输入参数有冲突（比如指定的尺寸不合法或者数据格式不匹配），在开始处理前就要报错别等到生成一半才发现。处理完打印输出文件的路径和大小方便确认。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。
