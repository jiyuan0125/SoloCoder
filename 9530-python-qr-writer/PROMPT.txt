活动推广要生成大量带不同链接的二维码，手动搞太慢了。需要一个脚本丢进去一堆 URL 自动生成二维码图片。

Python 3 二维码生成器。输入文本或 URL 生成标准 QR Code 图片。可调整二维码像素尺寸（默认 300×300 足够手机扫描）和纠错等级（L 低 / M 中 / Q 较高 / H 最高）——纠错等级越高二维码越复杂但容错能力越强。

支持自定义前景色和背景色（默认黑白）。批量模式从 CSV 或文本文件读取内容每行生成一个二维码，文件名自动编号（001.png、002.png...）。

生成的二维码要能用手机摄像头正常扫出来。如果内容太长（超过 QR Code 的容量上限）给出提示而不是生成一个扫不出来的码。python qr_gen.py --data urls.txt --size 400 --error-level M -o qrcodes/。

对了，还有个细节——输出的文件要能在标准工具里正常打开和显示。如果输入参数有冲突（比如指定的尺寸不合法或者数据格式不匹配），在开始处理前就要报错别等到生成一半才发现。处理完打印输出文件的路径和大小方便确认。如果处理过程中出现什么问题，错误信息要具体到是哪个步骤哪条数据出的问题。
