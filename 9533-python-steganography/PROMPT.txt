想在一个 PNG 图片里藏一段秘密文本信息，表面上看起来图片完全正常，但用对应的解码工具能把隐藏的信息提取出来。LSB 隐写就行不需要太复杂。

Python 3 图片隐写工具。编码模式：读取载体图片把文本信息藏进像素最低有效位（LSB），输出新图片。解码模式：读取含隐藏信息的图片把文本提取出来。两个功能做成子命令 encode 和 decode。

支持设置密码对文本做简单加密（XOR 即可），没密码的话提取出来是乱码。文本长度先编码到图片头部几个像素里，解码时先读长度再提取对应位数的数据。

自动检查文本长度是否超出图片容量——一张 1000×1000 的 RGB 图片大概能藏 375KB 的文本。超出容量时报错提示换张更大的图。编码前后图片肉眼完全看不出差别。python stego.py encode carrier.png --message "秘密信息" --key mypass -o output.png。
