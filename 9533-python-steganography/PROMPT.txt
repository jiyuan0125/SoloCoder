想在一个 PNG 图片里藏一段秘密文本信息，表面上看起来图片完全正常，但用对应的解码工具能把隐藏的信息提取出来。LSB 隐写是最经典的做法——修改像素最低有效位对视觉影响可以忽略不计。

Python 3 图片隐写工具。编码模式 encode：读取载体图片把文本信息藏进像素 RGB 通道的最低有效位每个通道藏 1 bit 三个通道共 3 bit 每像素，输出新图片文件。解码模式 decode：读取含隐藏信息的图片从 LSB 中提取出原始文本。两个功能做成子命令。

支持设置密码对文本做简单加密 XOR 即可，没密码提取出来是乱码无法阅读增加了安全性。文本长度先编码到图片头部几个像素的前 32 bit 存储字节数，解码时先读长度再提取对应位数的数据避免多读或少读。

自动检查文本长度是否超出图片容量——一张 1000x1000 的 RGB 图片每个像素藏 3 bit 大概能藏 375KB 的文本。超出容量时报错提示换张更大的图或者缩短文本。编码前后图片肉眼完全看不出差别 PSNR 应该在 50dB 以上。python stego.py encode carrier.png --message "秘密信息" --key mypass -o output.png
