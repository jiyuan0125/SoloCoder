做安全审计的时候要检查用户上传的图片里有没有用 LSB 隐写藏东西。不需要解码出具体内容只要能判断"这张图大概率被隐写修改过"就行，标记出来交给安全团队深入分析处理。

Python 3 隐写检测工具。对 PNG 和 BMP 图片做 LSB 最低有效位分析统计其分布特征。正常图片的 LSB 应该接近随机分布 0 和 1 各约 50% 没有明显规律，如果被 LSB 隐写过会出现异常的统计模式——比如某些区域连续出现 0 或 1 明显偏离随机分布呈现出被嵌入信息的结构特征。

输出分析报告包含卡方检验分数、自由度和疑似隐写的概率百分比。支持批量扫描一个目录下的所有图片按可疑程度从高到低排序输出方便安全团队优先处理最可疑的文件。检测结果要合理控制误报率——正常照片的误报率不应超过 5%，真正用 LSB 隐写过的图片检出率应在 90% 以上。

可以用已知的干净图片和用各种隐写工具处理过的图片做对比测试验证检测准确率和阈值设置是否合理。python stego_detect.py ./uploads/ --threshold 0.7
处理异常情况时给出有意义的提示信息，不要直接 panic 或忽略错误。
