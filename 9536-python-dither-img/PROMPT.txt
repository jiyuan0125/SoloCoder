在电子墨水屏或打印机上只能显示黑白两色，要把灰度图或彩色图转成二值图还能保持视觉层次感，就得用抖动（Dithering）算法。

Python 3 实现经典抖动算法。Floyd-Steinberg 误差扩散抖动是最常用的——把当前像素量化误差按比例分散到周围未处理像素上，这样相邻像素的误差会互相补偿产生自然的灰度过渡。Ordered Dithering 用 Bayer 矩阵做阈值矩阵，速度快有规律纹理。Atkinson 抖动是苹果早期用的方案对比度比较好。

还有 Random Dithering（随机噪声最简单但效果粗糙）和蓝噪声抖动（视觉效果最自然但计算量大）。

输入彩色或灰度图片输出抖动后的二值图。可以同时跑多个算法输出对比图。输出 1-bit 黑白图片文件体积要小。python dither.py photo.jpg --method floyd-steinberg -o dithered.png。

另外要注意，生成的结果需要验证——二维码要能被手机扫描、水印要能被提取、隐写信息要能被解码。提供验证命令或者在生成后自动做一轮验证。如果输入参数导致生成的结果无效（比如二维码内容太长），提前报错给建议。
