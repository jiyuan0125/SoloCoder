在电子墨水屏或打印机上只能显示黑白两色，要把灰度图或彩色图转成二值图还能保持视觉层次感就得用抖动 Dithering 算法。简单的阈值二值化会丢失大量灰度信息，抖动通过误差扩散模拟出连续灰度的视觉效果。

Python 3 实现多种经典抖动算法。Floyd-Steinberg 误差扩散是最常用的——把当前像素量化误差按 7/16、3/16、5/16、1/16 的比例分散到右方和下方三个相邻像素上，相邻像素的误差会互相补偿产生自然的灰度过渡效果。Ordered Dithering 用 Bayer 矩阵做阈值矩阵速度快会产生有规律的交叉纹理。Atkinson 抖动是苹果早期方案只分散 6/8 的误差对比度比较好。

还有 Random Dithering 随机噪声最简单但效果粗糙、蓝噪声抖动视觉效果最自然纹理分布最均匀但计算量大。

输入彩色或灰度图片输出抖动后的纯黑白二值图。可以同时跑多个算法输出对比图直观比较效果差异。输出 1-bit 黑白图片文件体积要小适合打印机或电子墨水屏使用。python dither.py photo.jpg --method floyd-steinberg -o dithered.png
