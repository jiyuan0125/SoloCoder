做 UI 设计的时候经常需要从品牌 Logo 或参考照片中提取主色调。手动用取色器一个个点效率太低了。

Python 3 从图片中提取调色板的工具。使用 K-Means 或中位切分算法做颜色聚类，从图片中提取 N 个主色（N 可配置默认 5 个）。聚类后排除太接近的颜色确保提取出来的色值有足够区分度——两个颜色的欧氏距离小于阈值就合并。

输出每个颜色的 HEX 值、RGB 值和 HSL 值。生成一个调色板预览图——色块并排展示每个色块下方标注色值。支持排除白色和黑色背景的干扰（比如产品照片的白底不想出现在调色板里）。

对于颜色丰富的图片可以增加到 8-10 个主色。采样时先缩小图片尺寸加速计算，大图不用逐像素聚类。python palette.py brand_logo.png --colors 6 -o palette.png。

还有一个实际问题：对于批量操作场景，支持通配符匹配或者目录扫描。处理进度实时打印——已经处理了多少个文件、当前在处理哪个、预计还要多久。如果某个文件处理失败跳过它继续处理下一个，最后汇总报告哪些失败了及原因。命令行参数要设计合理——有默认值让最少参数就能跑，也有高级选项给需要调优的用户。
