要把彩色照片转成 GIF 或者做像素风格的艺术效果，需要把图片中的颜色数量从几百万减少到指定的几个。

Python 3 色彩量化工具。把图片颜色量化到指定的颜色数（比如 8 色、16 色、256 色）。支持两种算法：均匀量化（简单把每个通道均匀分成 N 段速度快但效果差）和中位切分（递归把颜色空间按中位数切分效果好）。

量化后用调色板中最近的颜色替换每个像素。输出量化后的图片同时打印调色板信息——每个颜色的 RGB 值和占像素总数的百分比。

量化后图片颜色要合理不能出现大色块断裂的情况。如果指定颜色数太少（比如 4 色），某些区域会丢失细节但这正是想要的效果。支持输出 GIF 格式（天然支持 256 色调色板）。python quantize.py photo.jpg --colors 16 -o output.png。

补充几个关键点：生成的结果需要验证——二维码要能被手机扫描、水印要能被提取、隐写信息要能被解码。提供验证命令或者在生成后自动做一轮验证。如果输入参数导致生成的结果无效（比如二维码内容太长），提前报错给建议。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。
