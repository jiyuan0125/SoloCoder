要把彩色照片转成 GIF 格式或者做像素风格的艺术效果，需要把图片中的颜色数量从几百万减少到指定的几种或几十种。量化算法的选择直接影响视觉效果——好的算法能保留关键颜色减少色块断裂。

Python 3 色彩量化工具。把图片颜色量化到指定的颜色数比如 8 色、16 色、256 色等。支持两种算法：均匀量化简单把 RGB 每个通道均匀分成 N 段速度快但效果差容易出现色带。中位切分 Median Cut 递归把颜色空间按中位数切分每次沿方差最大的通道切效果好颜色过渡自然。

量化后用调色板中最近的颜色替换每个像素采用欧氏距离计算 RGB 空间距离。输出量化后的图片同时打印调色板详细信息——每个颜色的 RGB 值、十六进制色值和占像素总数的百分比方便分析颜色分布。

量化后图片颜色要合理不能出现大面积色块断裂的情况。如果指定颜色数太少比如 4 色某些区域会丢失细节但这正是像素艺术的预期效果。支持输出 GIF 格式天然支持 256 色调色板文件体积也小。python quantize.py photo.jpg --colors 16 -o output.png
输出结果要格式清晰可读，方便人工检查和后续处理。错误信息要包含具体上下文。
