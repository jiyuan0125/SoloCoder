做 UI 开发经常需要把带透明通道的前景图叠到不同背景色上，手动一个个搞太麻烦想自动化这个过程。

Python 3 Alpha 合成工具。读取带 Alpha 通道的 PNG 前景图，支持指定纯色背景（输入 HEX 颜色值如 #FFFFFF）或另一张背景图。按 Alpha 通道做正确的前景背景合成：out = fg * α + bg * (1-α)，用 numpy 手写这个公式。

合成结果边缘过渡要自然——半透明像素不能出现锯齿或色晕。输出不带 Alpha 的合成图片（JPEG 或 PNG 都行）。

批量模式可以对同一张前景图分别合成到多种背景色上生成多张结果图。也支持对一个目录下所有 PNG 批量合成到指定背景。python alpha_compose.py foreground.png --bg-color FFFFFF -o result.jpg。

最后一步别忘了，对于批量操作场景，支持通配符匹配或者目录扫描。处理进度实时打印——已经处理了多少个文件、当前在处理哪个、预计还要多久。如果某个文件处理失败跳过它继续处理下一个，最后汇总报告哪些失败了及原因。使用说明打印 --help 要清晰，每个参数的作用和默认值都要写明。
