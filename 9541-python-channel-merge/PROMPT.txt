有时候拿到的是分开的 R、G、B 灰度图（比如卫星影像数据），需要合并成一张彩色图片。或者把一个通道替换到已有图片里。

Python 3 通道合并工具。读入三张灰度图作为 R、G、B 通道合并成一张彩色图。可选添加第四张灰度图作为 Alpha 通道。支持对现有图片替换单个通道（比如只替换 Red 通道其他通道保持不变）。

输入图片尺寸不一致时必须报错提示——三个通道的宽高必须完全匹配才能合并。合并出来的图颜色要正确，不能通道顺序搞错（比如把 R 和 B 弄反了整张图就偏蓝了）。

合并后的图片保存为 PNG（保留 Alpha 通道）或 JPEG（丢弃 Alpha）。也可以指定输出 BMP 或 TIFF。python channel_merge.py r.png g.png b.png -o color.png。

另外要注意，对于批量操作场景，支持通配符匹配或者目录扫描。处理进度实时打印——已经处理了多少个文件、当前在处理哪个、预计还要多久。如果某个文件处理失败跳过它继续处理下一个，最后汇总报告哪些失败了及原因。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。
