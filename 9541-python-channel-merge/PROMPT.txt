有时候拿到的是分开的 R、G、B 三张灰度图比如卫星影像数据的多光谱波段需要合并成一张彩色图片才能正确显示。或者需要对已有图片替换单个通道比如用一张高分辨率的灰度图替换低质量的红通道做局部增强。

Python 3 通道合并工具。读入三张灰度图作为 R、G、B 通道合并成一张彩色图片。可选添加第四张灰度图作为 Alpha 透明通道输出带透明度的 PNG。支持对现有图片替换单个通道比如 --replace-red new_r.png 只替换 Red 通道其他通道保持原值不变。

输入图片尺寸不一致时必须报错提示三个通道的宽高必须完全匹配才能合并不能自动缩放因为缩放会引入插值误差。合并出来的图颜色要正确通道顺序不能搞错——比如把 R 和 B 弄反了整张图就偏蓝完全不对需要验证。合并后可以输出每个通道的直方图验证数据分布是否合理。

合并后的图片保存为 PNG 保留 Alpha 通道或者 JPEG 自动丢弃 Alpha 通道。也可以指定输出 BMP 或 TIFF 格式适配不同工作流。python channel_merge.py r.png g.png b.png -o color.png
