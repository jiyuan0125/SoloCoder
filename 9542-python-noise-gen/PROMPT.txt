做图像算法测试需要带噪声的测试图，手动加太慢了。要一个能批量给干净图片加各种噪声的脚本。

Python 3 图像噪声生成工具。支持多种噪声类型：高斯噪声（可调均值和标准差模拟传感器噪声）、椒盐噪声（可调密度随机把像素变白或变黑）、泊松噪声（模拟光子计数噪声在暗光照片里常见）、均匀随机噪声（可调范围最简单的噪声模型）。

每种噪声可以单独加也可以叠加——先加高斯噪声再加椒盐噪声模拟真实拍摄场景。噪声参数通过命令行或 JSON 配置文件指定方便复现同样的噪声模式。

加噪声前后图片视觉差异要明显。支持批量处理：对一个目录下的所有图片加相同参数的噪声。python noise_gen.py clean.jpg --type gaussian --mean 0 --stddev 30 -o noisy.jpg。

还有一个实际问题：输出的文件要能在标准工具里正常打开和显示。如果输入参数有冲突（比如指定的尺寸不合法或者数据格式不匹配），在开始处理前就要报错别等到生成一半才发现。处理完打印输出文件的路径和大小方便确认。命令行参数要设计合理——有默认值让最少参数就能跑，也有高级选项给需要调优的用户。
