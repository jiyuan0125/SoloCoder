手机夜景照片噪点特别多想用 Python 做个简单的降噪处理。不用追求 SOTA 效果比中值滤波好点就行。

Python 3 图像降噪工具。实现多种滤波降噪方法：中值滤波（椒盐噪声克星原理是取邻域中位数）、均值滤波（简单取平均）、高斯滤波（加权平均远处的像素权重低）、双边滤波（保边降噪核心思想是像素值相近的权重高）、非局部均值降噪（NLM 在整张图里找相似块做平均效果最好但慢）。

每个滤波器的核大小和强度参数可通过命令行调整。处理前后可以做 PSNR 对比看看降噪效果。

大图要分块处理避免内存问题。支持指定只处理图片的某个区域（ROI）。python denoise.py noisy_night.jpg --method bilateral --sigma 15 -o clean.jpg。

补充几个关键点：参数合理范围要有校验——核大小必须是奇数、sigma 不能为负、阈值在 0-255 之间。如果参数超出范围给出建议值而不是默默接受。处理前后可以做 PSNR 或 SSIM 对比量化效果变化。支持 --preview 模式只在窗口显示不保存文件。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。
