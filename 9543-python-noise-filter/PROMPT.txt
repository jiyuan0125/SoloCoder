手机夜景照片噪点特别多想用 Python 做个降噪处理。不用追求深度学习的 SOTA 效果比简单的中值滤波好点就行，重点是实现多种经典滤波方法并比较它们在真实噪点照片上的实际效果差异帮助选择最合适的降噪方案。

Python 3 图像降噪工具。实现五种滤波降噪方法：中值滤波取邻域中值对椒盐噪声效果最好能去除散点噪声同时保持边缘。均值滤波简单取平均速度最快但会模糊边缘细节丢失高频信息。高斯滤波按距离加权平均远处像素权重低是基础降噪方案。双边滤波保边降噪核心是同时考虑空间距离和像素值相似度在平滑噪声的同时保持边缘。非局部均值 NLM 在整张图里找相似块做平均效果最好但计算量最大适合离线处理高质量需求。

每个滤波器的核大小和强度参数可通过命令行调整适配不同程度的噪声污染。处理前后可以做 PSNR 和 SSIM 对比客观衡量降噪效果选择最佳参数。
