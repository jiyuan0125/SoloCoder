拍出来的照片有时候不够清晰边缘有点模糊。想用 Python 做锐化处理让图片看起来更清楚。

Python 3 图片锐化工具。实现拉普拉斯锐化（用二阶导数增强边缘简单粗暴容易过锐）和 Unsharp Mask 锐化（先模糊原图再用原图减去模糊图得到高频细节叠加回去增强边缘效果更自然）。Unsharp Mask 可调半径（决定增强多宽的边缘）和强度（增强多少倍）。

命令行指定输入图片、锐化方法、强度参数和输出路径。支持多次锐化叠加但要有过锐警告——锐化太多次会出现白色光晕伪影和噪声放大。

锐化后图片要看起来更清晰但不能出现明显的光晕伪影。默认参数要给个安全值别让用户一跑就过锐。python sharpen.py blurry.jpg --method unsharp --radius 2 --amount 1.5 -o sharp.jpg。

最后一步别忘了，参数合理范围要有校验——核大小必须是奇数、sigma 不能为负、阈值在 0-255 之间。如果参数超出范围给出建议值而不是默默接受。处理前后可以做 PSNR 或 SSIM 对比量化效果变化。支持 --preview 模式只在窗口显示不保存文件。
