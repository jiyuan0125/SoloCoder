想给照片加个浮雕的艺术效果——就是那种看起来像石板雕刻的立体感。实现不难用方向性卷积核就行。

Python 3 图片浮雕效果工具。实现基本浮雕效果用浮雕卷积核做卷积运算。支持八个方向的浮雕效果——上下左右和四个对角线方向不同方向的光影效果不同。

浮雕深度可调通过修改卷积核的权重值控制立体感的强弱。输出灰度浮雕图和彩色浮雕图两种模式——灰度模式只有明暗变化更经典，彩色模式保留原始颜色同时叠加浮雕纹理。

处理后的图片要有明显的立体浮雕感，不同方向的效果要有区别能看出光影来自不同方向。参数可以保存为预设方便下次直接用。python emboss.py photo.jpg --direction northeast --depth 3 -o embossed.jpg。
