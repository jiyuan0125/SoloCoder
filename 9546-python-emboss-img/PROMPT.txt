想给照片加个浮雕的艺术效果——就是那种看起来像石板雕刻的立体感。原理不复杂用方向性卷积核做卷积运算就能实现，不同方向的卷积核模拟不同角度的光源照射产生的明暗分布效果。

Python 3 图片浮雕效果工具。用浮雕卷积核对图片做 2D 卷积运算。支持八个方向的浮雕效果——上、下、左、右和四个对角线方向共八种选择，不同方向意味着光源来自不同角度产生的明暗阴影也完全不同效果差异明显。

浮雕深度可调通过修改卷积核中心权重值和周围权重的比值来控制立体感的强弱，权重差越大浮雕凸起越明显。输出灰度浮雕图和彩色浮雕图两种模式——灰度模式只有明暗变化更像传统石板浮雕视觉效果经典，彩色模式在保留原始颜色的基础上叠加浮雕纹理同时保持色彩和增加立体感。
