做一些创意图片效果需要把照片做各种扭曲变形——像哈哈镜那样的效果。不用特别精确视觉上好玩就行。

Python 3 图像扭曲变形工具。波浪扭曲：沿水平或垂直方向做正弦波变形可调振幅和频率控制波浪大小和密度。漩涡扭曲：从中心向外做旋转变形可调旋转角度和影响范围，角度越大旋转越厉害。

球面化扭曲：模拟球面镜效果从中心向外膨胀或收缩可调半径和强度。每种效果可以指定作用中心点和范围——不一定要以图片中心为圆心可以偏移。

变形效果要流畅自然不能有明显的锯齿或断裂。用反向映射加双线性插值保证输出质量。python distort.py photo.jpg --type swirl --angle 180 --radius 200 -o distorted.jpg。

还有一个实际问题：变换参数可以保存到 JSON 文件方便复用同一套变换应用到多张图片上。支持逆变换——给定变换后的坐标算出原图坐标。输出图片的元数据（尺寸、色彩空间）要正确设置别让后续程序读到错误信息。命令行参数要设计合理——有默认值让最少参数就能跑，也有高级选项给需要调优的用户。

性能方面要注意——单个文件处理不能太慢（别超过 10 秒），批量处理时可以并行加速。内存占用也要控制，处理大文件时别超过 500MB。日志输出要分级：正常模式只打印摘要，verbose 模式打印每一步的细节。
