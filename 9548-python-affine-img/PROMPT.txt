做图像配准和拼接的时候需要对图片做旋转、平移、缩放这些基本的仿射变换。手动算变换矩阵太容易出错了需要一个能精确控制每个参数的工具方便快速迭代调试不同的变换组合效果。

Python 3 仿射变换工具。支持四种基本变换：旋转指定角度和中心点默认绕图片中心旋转角度单位为度支持正负值。平移指定 x 和 y 方向的偏移量单位为像素正方向为右和下。缩放 x 和 y 方向独立缩放支持不等比缩放可以做拉伸效果。剪切变换模拟平行四边形变形。可以组合多个变换通过矩阵乘法合并成一个 3x3 仿射变换矩阵一次性应用避免多次插值导致图像质量逐次损失。

用 numpy 手写仿射变换矩阵和双线性插值——变换后的像素坐标如果是小数就用周围四个像素按距离加权平均计算输出值。变换后图片不能有空洞即有些输出位置没有被源图映射到用反向映射解决。

命令行传入变换参数输出变换后的图片支持输出黑色或白色两种背景色。python affine.py photo.jpg --rotate 30 --scale 1.2 -o transformed.jpg
