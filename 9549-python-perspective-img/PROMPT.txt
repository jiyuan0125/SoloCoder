拍黑板或白板的时候角度歪了想校正成正视图。经典用法就是点四个角把梯形变成矩形。

Python 3 透视变换工具。用户指定原图四个点的坐标和目标四个点的坐标，程序计算 3×3 透视变换矩阵然后用变换矩阵做图像重映射。用双线性插值填充输出图片的每个像素。

也可以简化模式：输入图片尺寸和目标矩形比例四角自动对齐到图片四个角附近。比如拍了一张 A4 纸照片四个角坐标大概在 (100,80)、(780,60)、(820,1100)、(80,1120)，目标矩形就是 (0,0)、(794,0)、(794,1123)、(0,1123)。

校正后的图片边缘要平直不能有波浪状扭曲。python perspective.py photo.jpg --src "100,80 780,60 820,1100 80,1120" --dst "0,0 794,0 794,1123 0,1123" -o corrected.jpg。

最后一步别忘了，变换参数可以保存到 JSON 文件方便复用同一套变换应用到多张图片上。支持逆变换——给定变换后的坐标算出原图坐标。输出图片的元数据（尺寸、色彩空间）要正确设置别让后续程序读到错误信息。
