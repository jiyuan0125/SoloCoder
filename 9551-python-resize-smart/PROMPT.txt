平时手动改图片大小要么拉伸变形要么裁剪丢内容挺烦的。想用 Python 做一个根据图片内容智能选择缩放策略的工具。

检测图片中的人脸或主体区域（可以用简单的显著性检测或者边缘密度分析），缩放时优先保留这些区域不变形，边缘部分可以适当裁切或拉伸。支持指定目标宽高也支持按比例缩放。

如果检测不到明显的主体区域就退化成常规的等比缩放加裁剪模式——先等比缩放到目标尺寸能包含的最大尺寸然后居中裁剪。输出保存为新文件不覆盖原图。

Python 3 实现用 Pillow 就够了。python resize_smart.py input.jpg -o output.jpg --width 800 --height 600。

另外要注意，变换参数可以保存到 JSON 文件方便复用同一套变换应用到多张图片上。支持逆变换——给定变换后的坐标算出原图坐标。输出图片的元数据（尺寸、色彩空间）要正确设置别让后续程序读到错误信息。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。
