手头有好多张局部截图想拼成一张完整的。比如把多张雷达图拼成对比大图、把截长图的结果合并、把多张证件照排列成版面。需要一个灵活的图片拼接工具按网格排列合并成一张大图。

Python 3 图片拼接工具。读取多张图片按照行列网格排列拼接成一张大图。支持自动计算行列数根据图片数量开平方取整选择最接近的矩形排列，也支持手动指定 --rows 和 --cols 精确控制布局。图片大小不一致时有两种对齐策略——可以选择取最大宽高做黑色背景居中放置保持原始尺寸，或者统一缩放到相同尺寸再拼接保持整齐美观。

间距 gap 像素数和背景色可配置默认无间距白色背景。输出一张合并后的 PNG 图片文件。如果图片太多拼接出来文件特别大比如超过 50MB 给个文件大小警告让用户确认。

Python 3 加 Pillow 做图像处理就够了。python stitch.py img1.png img2.png img3.png -o merged.png --cols 2
输出结果要格式清晰可读，方便人工检查和后续处理。错误信息要包含具体上下文。
构建产物要足够轻量，不要引入不必要的依赖。编译或打包后可以直接在命令行运行。
