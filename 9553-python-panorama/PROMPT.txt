出去玩拍了好多张风景照想合成一张全景图。能不能自动拼接？

Python 3 全景图合成工具。输入一组有重叠区域的相邻照片，程序自动检测特征点匹配估算变换矩阵把多张图融合拼接成一张全景大图。至少支持 3-5 张图片的水平拼接。

特征匹配用 SIFT 或 ORB，变换矩阵估算用 RANSAC 去除外点。图像融合时重叠区域要做渐变过渡（线性混合或拉普拉斯金字塔融合）避免出现明显的拼接缝。

输出保存为 JPEG。如果输入图片之间没有足够的重叠区域或者场景变化太大无法匹配给出提示。python panorama.py photo1.jpg photo2.jpg photo3.jpg -o pano.jpg。

补充几个关键点：对于批量处理场景支持目录扫描和通配符匹配。处理进度实时显示已完成数量和总数量。如果某个文件处理出错跳过继续下一个最后汇总报告。输出结果要包含处理参数的记录方便追溯和复现。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。

错误恢复机制也要考虑——如果程序崩溃了，重启后能从断点继续而不是从头开始。配置参数可以保存到文件下次直接 --config file.json 加载。支持管道输入输出方便和其他命令行工具组合使用。
