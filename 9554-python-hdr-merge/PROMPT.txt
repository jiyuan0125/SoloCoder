同一个场景拍了好几张不同曝光的照片想合成一张高动态范围的 HDR 图像——亮部不过曝暗部不欠曝所有细节都能看到。手机相机的自动 HDR 就是干这个的但现在要用 Python 手动实现完整的合成流程。

Python 3 HDR 合成工具。读取多张不同曝光参数的同一场景照片至少 3 张欠曝正常和过曝各一张，用曝光融合算法合并成一张高动态范围图像。能处理不同 EV 值的图片——从照片 EXIF 信息里读取曝光时间自动计算 EV 差值或者让用户手动 --ev 参数指定每张的曝光补偿值。

合成时对每个像素根据曝光情况取最优值——欠曝图片取亮部细节因为亮部没有被截断保留了高光信息，过曝图片取暗部细节因为暗部有足够的信号不会混入噪声。输出的图片在亮部和暗部都有合理的细节层次不出现纯白或纯黑的死区。

批量操作支持目录扫描自动按 EXIF 时间戳分组处理。处理进度实时打印。单个文件失败跳过继续最后汇总报告。python hdr_merge.py dark.jpg normal.jpg bright.jpg -o hdr.jpg
性能上注意避免不必要的内存分配和拷贝。关键路径上的操作要高效。
配置参数通过命令行参数或配置文件传入，不要在代码里硬编码。支持合理的默认值。
