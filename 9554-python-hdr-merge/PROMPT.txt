同一个场景拍了好几张不同曝光的照片想合成一张高动态范围的 HDR 图像。

Python 3 HDR 合成工具。读取多张不同曝光参数的同一场景照片（至少 3 张），用曝光融合算法合并成一张 HDR 图像。能处理不同 EV 值的图片——需要从照片 EXIF 里读取曝光时间信息或者手动指定 EV 值。

合成时对每个像素根据曝光情况取最优值——欠曝图片取亮部细节过曝图片取暗部细节。输出的图片在亮部和暗部都有合理的细节层次不出现纯白或纯黑的死区。

Python 3 实现。python hdr_merge.py dark.jpg normal.jpg bright.jpg -o hdr.jpg。

最后一步别忘了，对于批量操作场景，支持通配符匹配或者目录扫描。处理进度实时打印——已经处理了多少个文件、当前在处理哪个、预计还要多久。如果某个文件处理失败跳过它继续处理下一个，最后汇总报告哪些失败了及原因。使用说明打印 --help 要清晰，每个参数的作用和默认值都要写明。
