有了 HDR 图但普通显示器看不了——HDR 的亮度范围远超 sRGB 显示器的能力，直接查看要么全白要么全黑。色调映射 Tone Mapping 就是把高动态范围的亮度压缩到显示器能正常显示的标准范围同时尽量保留视觉细节。

Python 3 色调映射工具。输入高动态范围图像或者多张不同曝光的普通照片先合成 HDR，然后通过色调映射算子压缩亮度范围。实现至少两种映射算法：Reinhard 算法最简单效果好公式 L_out = L_in / (1 + L_in) 自然压缩高亮区域。Mantiuk 算法保留对比度细节更丰富适合需要精细控制的场景。

支持调节映射强度参数控制压缩程度和 gamma 校正值调整整体亮度。映射后暗部不能全黑亮部不能全白，中间调细节层次要保留不能出现色带或色块。

输出标准 LDR 的 JPEG 或 PNG 文件方便在普通设备上查看和分享。python tonemap.py input.exr -o output.jpg --method reinhard --gamma 2.2
处理异常情况时给出有意义的提示信息，不要直接 panic 或忽略错误。
