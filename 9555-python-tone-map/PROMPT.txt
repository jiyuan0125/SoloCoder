有了 HDR 图但显示器看不了需要做色调映射把亮度范围压缩到普通显示器能正常显示的级别。

Python 3 色调映射工具。输入高动态范围图像或者多张不同曝光的普通图，通过色调映射算子压缩亮度范围。实现至少一种映射算法——Reinhard 算法（简单效果好：L_out = L_in / (1 + L_in)）或者 Mantiuk 算法（保留对比度细节更丰富）。

支持调节映射强度参数和 gamma 校正值。映射后暗部不能全黑亮部不能全白，细节层次要保留。

输出 LDR 的 JPEG 或 PNG。python tonemap.py input.exr -o output.jpg --method reinhard --gamma 2.2。
