经常遇到拍的照片要么太暗要么太亮。写个自动曝光修正的小工具。

Python 3 分析图片的亮度直方图判断是过曝还是欠曝。过曝的特征是直方图偏右（大量像素在高亮度区域堆积），欠曝偏左。然后自动调整 gamma 或亮度曲线——太暗的提亮太亮的压暗中间调尽量不动。

修正幅度要控制——不能一次调整太猛导致另一种方向的失真。可以分多步逐步修正。支持批量处理一个目录下所有图片。

保留原图片的 EXIF 信息。python exposure_fix.py photo.jpg -o fixed.jpg。批量模式 python exposure_fix.py ./photos/ --batch。

另外要注意，对于批量处理场景支持目录扫描和通配符匹配。处理进度实时显示已完成数量和总数量。如果某个文件处理出错跳过继续下一个最后汇总报告。输出结果要包含处理参数的记录方便追溯和复现。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。
