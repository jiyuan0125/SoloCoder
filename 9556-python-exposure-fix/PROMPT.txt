经常遇到拍的照片要么太暗要么太亮。手机自动曝光有时不准特别是逆光和高对比度场景容易出问题。写个自动曝光修正工具能根据直方图分析自动判断问题并调整亮度。

Python 3 分析图片的亮度直方图判断是过曝还是欠曝。过曝的特征是直方图偏右大量像素集中在高亮度区域甚至碰到 255 右边界被截断。欠曝偏左大量像素堆积在低亮度区域甚至碰到 0 左边界。然后自动调整 gamma 值或亮度曲线——太暗的提亮降低 gamma 值、太亮的压暗升高 gamma 值、中间调尽量保持不变只调整两端的映射。

修正幅度要控制——不能一次调整太猛导致从欠曝变成过曝。可以分多步逐步修正每步检查直方图分布直到亮暗分布合理。支持批量处理一个目录下所有图片统一修正。

保留原图片的 EXIF 信息不丢失拍摄参数和设备信息。python exposure_fix.py photo.jpg -o fixed.jpg。批量 python exposure_fix.py ./photos/ --batch -o fixed/
命令行参数解析用标准库就行，不需要第三方包。确保在主流操作系统上能编译运行。
如果涉及并发操作，注意共享数据的同步问题。尽量使用语言标准库提供的并发原语。
