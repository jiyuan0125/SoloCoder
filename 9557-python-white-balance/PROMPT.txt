室内灯光下拍的照片总是偏黄，阴天拍的偏蓝。写个白平衡校正工具。

Python 3 白平衡校正工具。自动检测图片的色温偏移——用灰度世界假设（整张图的 R/G/B 均值应该相等），如果不相等就按比例调整各通道增益。也支持手动指定色温值或者点选图片上的中性灰参考点来校正。

校正后白色区域应该真正显示白色，整体色调不偏暖也不偏冷。可以调节色温（开尔文值）和色调（green-magenta 偏移）两个维度。

Python 3 + Pillow 或 OpenCV。python wb.py photo.jpg -o corrected.jpg。手动色温 python wb.py photo.jpg --temp 5500 --tint +5。

还有一个实际问题：对于批量处理场景支持目录扫描和通配符匹配。处理进度实时显示已完成数量和总数量。如果某个文件处理出错跳过继续下一个最后汇总报告。输出结果要包含处理参数的记录方便追溯和复现。命令行参数要设计合理——有默认值让最少参数就能跑，也有高级选项给需要调优的用户。

性能方面要注意——单个文件处理不能太慢（别超过 10 秒），批量处理时可以并行加速。内存占用也要控制，处理大文件时别超过 500MB。日志输出要分级：正常模式只打印摘要，verbose 模式打印每一步的细节。
