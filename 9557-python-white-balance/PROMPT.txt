室内灯光下拍的照片总是偏黄，阴天拍的偏蓝。白平衡没调好整张照片色调都不对看着不自然。后期处理的第一步通常就是校正白平衡把偏色修复回来。

Python 3 白平衡校正工具提供三种校正方式。自动模式用灰度世界假设整张图的 R/G/B 均值应该大致相等，如果不相等就按比例调整各通道的增益系数自动校正偏色。参考点模式让用户点选图片上一个应该是灰色或白色的区域以此为基准计算色温偏移并校正。手动模式直接指定色温开尔文值和色调 green-magenta 偏移量两个参数。

校正后白色区域应该真正显示白色，整体色调不偏暖也不偏冷看着自然。可以调节色温从 3000K 暖光到 8000K 冷光和色调两个维度精细控制。

Python 3 用 Pillow 或 OpenCV 做像素级图像处理。python wb.py photo.jpg -o corrected.jpg。手动色温 python wb.py photo.jpg --temp 5500 --tint +5
大文件或边界情况要考虑周全：空输入、超大输入、格式异常都要能正确处理。
构建产物要足够轻量，不要引入不必要的依赖。编译或打包后可以直接在命令行运行。
