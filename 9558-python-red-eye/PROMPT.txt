闪光灯拍的红眼照片太难看了，写个去红眼工具。

Python 3 自动检测图片中的红眼区域——在暗色圆形区域中找到高饱和度的红色像素。检测到后把红色替换成自然的深色瞳孔颜色（深棕色），同时保持眼睛周围皮肤和其他细节不变。

检测算法：先做人脸检测缩小搜索范围，然后在眼睛区域找红眼特征。自动模式识别不准的情况下支持手动模式——用户指定红眼中心坐标和半径。

去红眼后的瞳孔颜色要自然不能变成纯黑色。处理前后对比可以看出红色被正确替换了。python redeye.py flash.jpg -o fixed.jpg。手动 python redeye.py flash.jpg --center 320,240 --radius 15。
