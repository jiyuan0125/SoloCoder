做证件照时有好多规矩——头要占照片面积的几分之几、眼睛要在什么位置范围内、背景要纯色不能有杂物。照相馆手动检查效率低还容易漏检，需要一个工具自动检测照片是否符合各类证件的标准要求。

Python 3 证件照规则检查工具。检测人脸位置和大小在照片中的占比，计算头部面积占照片总面积的比例是否在规定范围内。眼睛位置是否在规定区域内比如眼睛要在照片上半 1/3 处偏高或偏低都不合格。检查背景是否足够纯净单色——采样照片边缘区域的像素计算颜色方差如果方差小说明背景纯色符合要求。

也要检查脸部亮度是否均匀左右脸亮度差不能太大否则照片不合格。支持不同证件标准：id-card 身份照、passport 护照照片、visa 签证照片，每种标准有不同的尺寸比例和位置要求预设参数。

输出一份结构化的检查报告列出所有检查项通过或未通过的状态以及具体偏差数值方便用户针对性调整。python face_check.py photo.jpg --type id-card
输出结果要格式清晰可读，方便人工检查和后续处理。错误信息要包含具体上下文。
配置参数通过命令行参数或配置文件传入，不要在代码里硬编码。支持合理的默认值。
