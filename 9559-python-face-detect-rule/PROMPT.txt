做证件照时有好多规矩——头要占几分之几、眼睛要在什么位置、背景要纯色。想写个工具自动检查照片是否符合证件照规则。

Python 3 证件照规则检查工具。检测人脸位置和大小，计算头部占照片面积的比例、眼睛位置是否在规定范围内（比如眼睛要在照片上半 1/3 处）。检查背景是否足够纯净单色——采样照片边缘区域的颜色如果方差小说明背景纯。

也要检查亮度是否均匀（脸部左右亮度差不能太大）。支持不同证件标准：id-card（身份证）、passport（护照）、visa（签证），每种标准有不同的尺寸和位置要求。

输出一份检查报告告诉用户哪些规则没通过。python face_check.py photo.jpg --type id-card。
