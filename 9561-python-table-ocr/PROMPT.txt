经常要把纸质的表格录入电子档，太费时间了。能不能写个表格 OCR 工具？
输入一张表格图片，自动检测表格的网格线结构，识别出行列关系，然后把每个单元格里的文字识别出来。最终输出 CSV 或者 Markdown 格式的表格。要能处理有合并单元格的情况就更好了。
Python 3，可以用 OpenCV 做图像处理。命令行：python table_ocr.py table_photo.jpg -o output.csv --format csv

另外要注意，检测结果的置信度或分数要一起输出方便后续筛选。支持设置最低置信度阈值低于阈值的自动过滤。批量处理时结果输出到 CSV 包含文件名、检测结果、置信度和位置坐标。处理速度也要关注——单张图片别超过 5 秒。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。

如果运行环境缺少某些依赖库，启动时要给出清晰的安装指引而不是 import 报错。命令行帮助信息要完整每个参数都有说明和默认值。处理完成后打印简要统计——处理了几个输入、耗时多少、输出在哪里。
