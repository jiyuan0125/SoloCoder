文档图片的版面分析工具。扫描了一堆纸质文档想自动判断每页里哪些区域是标题、正文段落、图片、表格、页眉页脚，方便后续对不同类型的内容做针对性的 OCR 处理提升识别准确率。

对输入图片做区域检测和分类把页面划分成不同的逻辑块。标题通常是字号最大的文字区域面积相对较小。正文段落是密集的文字区域像素密度高且分布均匀。图片区域是连续的非文字像素块纹理特征和文字明显不同。表格区域有规律的网格线结构。页眉页脚在页面的顶部和底部位置固定面积小。

用连通域分析找到所有内容区域然后根据每个区域的特征面积、宽高比、像素密度、纹理复杂度、位置等进行自动分类。输出 JSON 格式的版面描述包含每个区域的坐标边界框、类型标签和置信度分数方便下游处理。

Python 3 用 Pillow 或 OpenCV 做图像处理连通域分析。命令行：python layout.py doc_scan.jpg -o layout.json
命令行参数解析用标准库就行，不需要第三方包。确保在主流操作系统上能编译运行。
日志和调试信息要分级输出，方便排查问题。生产环境下只输出必要的信息。
输入数据可能有各种异常格式，工具需要正确处理而不会崩溃。对于二进制文件解析，要注意大小端字节序的问题。
