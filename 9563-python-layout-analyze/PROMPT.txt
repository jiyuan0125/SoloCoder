文档图片的版面分析工具。想自动判断一张文档扫描图里哪些区域是标题、正文、图片、表格。
对输入图片做区域检测和分类，把页面划分成不同的逻辑块（标题、段落、图片区域、表格区域、页眉页脚），输出每个区域的坐标和类型。可以用连通域分析或者边缘检测之类的方法。
Python 3，Pillow/OpenCV 都行。输出 JSON 格式的版面描述，命令行：python layout.py doc_scan.jpg -o layout.json

补充几个关键点：对于批量处理场景支持目录扫描和通配符匹配。处理进度实时显示已完成数量和总数量。如果某个文件处理出错跳过继续下一个最后汇总报告。输出结果要包含处理参数的记录方便追溯和复现。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。

错误恢复机制也要考虑——如果程序崩溃了，重启后能从断点继续而不是从头开始。配置参数可以保存到文件下次直接 --config file.json 加载。支持管道输入输出方便和其他命令行工具组合使用。

参数校验要在处理开始前完成——如果参数不合法立即报错退出不要等到处理到一半才发现。支持 --version 查看版本号。配置文件可以用 YAML 或 JSON 格式。程序要有信号处理优雅关闭不要留下半成品。
