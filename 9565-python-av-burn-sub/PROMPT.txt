看外语视频没字幕不行，想把 SRT 字幕烧录到视频画面上。
读取 SRT 格式字幕文件，把字幕文字按照时间轴烧录到对应视频帧上。支持自定义字体大小、颜色、描边、位置。中文字幕要能正常显示（需要处理字体路径）。
Python 3 实现，用 ffmpeg 的字幕滤镜。命令行：python burn_sub.py video.mp4 -s subs.srt -o output.mp4 --font-size 24 --color white --outline black

对了，还有个细节——音频质量不能因为处理明显下降——处理前后可以做频谱对比确认没有引入额外噪声。支持常见的采样率（44100、48000、96000）和位深（16-bit、24-bit）。批量处理时如果某个文件格式不支持跳过并记录到日志里。如果处理过程中出现什么问题，错误信息要具体到是哪个步骤哪条数据出的问题。

代码结构要清晰——核心逻辑和 CLI 入口分离，核心功能可以被其他脚本 import 使用。依赖尽量少只用标准库或者一两个常用第三方库。README 写清楚安装依赖和基本用法。

所有 goroutine 的生命周期要管理好不能有泄漏。channel 要正确关闭避免死锁。错误处理不能吞掉所有 error 都要处理或者向上传播。日志输出要包含时间戳和 goroutine ID 方便并发调试。go test 要能通过。
