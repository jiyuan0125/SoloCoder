需要给视频加水印 logo。帮我写个工具把图片 logo 叠加到视频上。
读取一个 PNG logo 文件（带透明通道），叠加到视频的指定位置（左上、右上、左下、右下、居中，或者自定义坐标）。支持调节 logo 的透明度和缩放比例。输出新视频文件。
Python 3，用 ffmpeg 滤镜实现。python burn_logo.py video.mp4 --logo watermark.png --position bottom-right --opacity 0.5 --scale 0.2 -o output.mp4

另外要注意，音频质量不能因为处理明显下降——处理前后可以做频谱对比确认没有引入额外噪声。支持常见的采样率（44100、48000、96000）和位深（16-bit、24-bit）。批量处理时如果某个文件格式不支持跳过并记录到日志里。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。
