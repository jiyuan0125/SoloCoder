拍了好几段视频想拼成一个完整的。写个视频拼接工具。
把多个视频文件按顺序拼接成一个。需要处理不同视频分辨率/编码格式不一致的情况（先统一转码再拼接，或者直接拼接相同格式的）。支持列出拼接顺序的文件列表。
Python 3，ffmpeg concat demuxer 或 filter。python concat.py clip1.mp4 clip2.mp4 clip3.mp4 -o merged.mp4，或 python concat.py --list filelist.txt -o merged.mp4

最后一步别忘了，音频质量不能因为处理明显下降——处理前后可以做频谱对比确认没有引入额外噪声。支持常见的采样率（44100、48000、96000）和位深（16-bit、24-bit）。批量处理时如果某个文件格式不支持跳过并记录到日志里。使用说明打印 --help 要清晰，每个参数的作用和默认值都要写明。

测试用例要覆盖边界情况——空文件、超大文件、格式不对的文件、编码异常的文件。每个具体来说都要有对应的测试。用 Python 的 unittest 或 pytest 都行，python -m pytest tests/ 能跑通。
