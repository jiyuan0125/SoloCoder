想把一个大视频按时长切分成多个小片段。比如把一个 1 小时的录像切成每 5 分钟一段。
按固定时长切分视频，也可以按指定的切割点列表来切。切割时不重新编码，直接按关键帧切。输出多段编号命名的文件。也要支持按文件大小来切（每段不超过指定大小）。
Python 3 + ffmpeg。python split.py video.mp4 --every 300 -o clips/，或 python split.py video.mp4 --at 120,300,600 -o clips/

对了，还有个细节——对于批量操作场景，支持通配符匹配或者目录扫描。处理进度实时打印——已经处理了多少个文件、当前在处理哪个、预计还要多久。如果某个文件处理失败跳过它继续处理下一个，最后汇总报告哪些失败了及原因。如果处理过程中出现什么问题，错误信息要具体到是哪个步骤哪条数据出的问题。
命令行参数解析用标准库就行，不需要第三方包。确保在主流操作系统上能编译运行。
对工具的输入输出格式要有明确的定义和文档说明。代码注释要清晰，方便后续维护和功能扩展。
输入数据可能有各种异常格式，工具需要正确处理而不会崩溃。对于二进制文件解析，要注意大小端字节序的问题。
