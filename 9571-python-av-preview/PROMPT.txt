视频预览图生成器。想在网页上放个视频缩略图，鼠标悬停就能预览效果那种。
从视频中均匀采样若干帧，生成一张雪碧图（sprite sheet），同时生成一个 WebVTT 文件记录每帧的时间戳和坐标。也支持只输出几张关键帧截图。采样帧数可配置。
Python 3 + ffmpeg。python preview.py video.mp4 -o sprites.jpg --frames 100 --width 160 --columns 10，同时输出 sprites.vtt

另外要注意，音频质量不能因为处理明显下降——处理前后可以做频谱对比确认没有引入额外噪声。支持常见的采样率（44100、48000、96000）和位深（16-bit、24-bit）。批量处理时如果某个文件格式不支持跳过并记录到日志里。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。

如果运行环境缺少某些依赖库，启动时要给出清晰的安装指引而不是 import 报错。命令行帮助信息要完整每个参数都有说明和默认值。处理完成后打印简要统计——处理了几个输入、耗时多少、输出在哪里。
