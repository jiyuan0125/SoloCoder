音频波形可视化。想看看一段音频的波形图长什么样。
读取音频文件，生成波形图（waveform）。横轴是时间，纵轴是振幅。支持生成整段音频的波形，也支持指定时间范围。波形颜色、背景色、图片尺寸可配置。输出 PNG 图片。
Python 3，用 ffmpeg 或 wave 模块读取 PCM 数据，用 Pillow 或 matplotlib 画图。
python waveform.py audio.mp3 -o waveform.png --color blue --width 1200 --height 200

补充几个关键点：音频质量不能因为处理明显下降——处理前后可以做频谱对比确认没有引入额外噪声。支持常见的采样率（44100、48000、96000）和位深（16-bit、24-bit）。批量处理时如果某个文件格式不支持跳过并记录到日志里。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。

错误恢复机制也要考虑——如果程序崩溃了，重启后能从断点继续而不是从头开始。配置参数可以保存到文件下次直接 --config file.json 加载。支持管道输入输出方便和其他命令行工具组合使用。
