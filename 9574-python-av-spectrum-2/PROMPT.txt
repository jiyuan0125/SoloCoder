音频频谱分析工具。做音乐分析或噪声诊断的时候想看看各个频率分量的分布和随时间的变化情况。波形图只能看到时域振幅变化频谱图能看到完整的频率成分信息。

读取音频文件做 FFT 快速傅里叶变换频谱分析生成频谱图。支持生成静态频谱快照显示某一时刻的频率分布柱状图，也支持生成随时间变化的频谱瀑布图 spectrogram 横轴时间纵轴频率颜色深浅表示能量强度能直观看到频率随时间的演变。频率范围 --freq-max 最高到多少 Hz 可调默认 20000Hz，频率分辨率取决于 FFT 窗口大小 --window-size 默认 2048 参数越大分辨率越高但时间精度越低。

输出 PNG 图片频谱图的配色方案可配置热力图、灰度等。Python 3 用 scipy 或 numpy 做 FFT 计算用 matplotlib 画图。

python spectrum.py song.wav -o spectrum.png --type spectrogram --freq-max 20000
