音量标准化工具。不同来源的音频文件音量差别很大，想统一到一个水平。
分析音频的响度，然后自动调整增益让所有文件达到目标响度（默认 -14 LUFS）。支持单个文件处理和批量处理目录下所有音频。不要只做简单的 peak normalization，要用 LUFS 标准。
保留原音频格式和质量。Python 3 + ffmpeg loudnorm 滤镜。
python normalize.py music/ --target -14 -o normalized/，或 python normalize.py song.mp3 -o song_norm.mp3

另外要注意，音频质量不能因为处理明显下降——处理前后可以做频谱对比确认没有引入额外噪声。支持常见的采样率（44100、48000、96000）和位深（16-bit、24-bit）。批量处理时如果某个文件格式不支持跳过并记录到日志里。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。
