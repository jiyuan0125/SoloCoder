音频淡入淡出工具。剪出来的音频片段开头结尾太突然了，需要加个渐变。
给音频文件的开头加淡入效果，结尾加淡出效果。淡入淡出时长可配置（比如 2 秒淡入、3 秒淡出）。也支持只加淡入或只加淡出。处理后音质不能下降。
Python 3 + ffmpeg afade 滤镜。python fade.py intro.wav --fade-in 2 --fade-out 3 -o intro_faded.wav

补充几个关键点：音频质量不能因为处理明显下降——处理前后可以做频谱对比确认没有引入额外噪声。支持常见的采样率（44100、48000、96000）和位深（16-bit、24-bit）。批量处理时如果某个文件格式不支持跳过并记录到日志里。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。

错误恢复机制也要考虑——如果程序崩溃了，重启后能从断点继续而不是从头开始。配置参数可以保存到文件下次直接 --config file.json 加载。支持管道输入输出方便和其他命令行工具组合使用。

参数校验要在处理开始前完成——如果参数不合法立即报错退出不要等到处理到一半才发现。支持 --version 查看版本号。配置文件可以用 YAML 或 JSON 格式。程序要有信号处理优雅关闭不要留下半成品。
