有一批音频文件采样率不统一有 44100 的也有 48000 的还有 22050 的某些播放器只支持特定采样率需要统一重采样。不想装 ffmpeg 那么重的东西用纯 Python 标准库搞定。

支持读取 WAV 和 FLAC 音频格式按指定目标采样率做重采样。保持原始通道数单声道或立体声和位深 16bit 或 24bit 不变。重采样算法用线性插值就行不需要太复杂的多项式拟合对音频质量要求不是特别高的场景够用。

命令行指定输入文件和目标采样率输出新文件到指定路径。处理前验证输入文件的格式信息采样率、通道数、位深并打印出来让用户确认参数正确。输出文件格式和输入保持一致。

Python 3 纯标准库加 struct 模块处理二进制 WAV 头部不依赖 ffmpeg 或任何第三方音频库手动解析 RIFF chunk。python resample.py input.wav 48000 -o output.wav
输出结果要格式清晰可读，方便人工检查和后续处理。错误信息要包含具体上下文。
对工具的输入输出格式要有明确的定义和文档说明。代码注释要清晰，方便后续维护和功能扩展。
输入数据可能有各种异常格式，工具需要正确处理而不会崩溃。对于二进制文件解析，要注意大小端字节序的问题。
