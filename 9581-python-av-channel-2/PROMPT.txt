音频声道处理工具。有些文件是立体声有些是单声道，需要互相转换。
支持立体声转单声道（左右混合或只取一个声道），单声道转立体声（复制到两个声道）。也支持提取单独的左声道或右声道，以及调换左右声道。处理 WAV 和 MP3 格式。
Python 3 + ffmpeg。python channel.py stereo.wav --mono -o mono.wav，或 python channel.py mono.wav --stereo -o stereo.wav，或 python channel.py audio.wav --swap -o swapped.wav

另外要注意，音频质量不能因为处理明显下降——处理前后可以做频谱对比确认没有引入额外噪声。支持常见的采样率（44100、48000、96000）和位深（16-bit、24-bit）。批量处理时如果某个文件格式不支持跳过并记录到日志里。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。
