音频标签（metadata）读写工具。音乐文件的标题、艺术家、专辑信息有时候是乱码或缺失的。
读取和修改音频文件的元数据标签。支持 ID3v1/v2（MP3）、Vorbis Comment（OGG/FLAC）、iTunes tags（M4A）。能查看所有标签字段，也能批量设置标题、艺术家、专辑、年份、封面图。
Python 3，可以用 mutagen 库。python audiotag.py song.mp3 show，或 python audiotag.py song.mp3 set --title "歌名" --artist "歌手" --album "专辑" --cover cover.jpg
