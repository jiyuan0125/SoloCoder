歌词同步校正工具。下载的歌词和音频对不上，有的提前有的滞后。
读取 LRC 歌词文件，支持整体时间偏移调整（所有时间标签加或减一个固定偏移量）。也支持倍速调整（比如歌词是正常速度但音频是 1.05 倍速录的）。处理完保存为新的 LRC 文件，保留原文不变。
Python 3 纯标准库。python lrc_sync.py lyrics.lrc --offset -2.5 -o synced.lrc，或 python lrc_sync.py lyrics.lrc --speed 1.05 -o synced.lrc

最后一步别忘了，对于批量处理场景支持目录扫描和通配符匹配。处理进度实时显示已完成数量和总数量。如果某个文件处理出错跳过继续下一个最后汇总报告。输出结果要包含处理参数的记录方便追溯和复现。使用说明打印 --help 要清晰，每个参数的作用和默认值都要写明。

测试用例要覆盖边界情况——空文件、超大文件、格式不对的文件、编码异常的文件。每个需要做的都要有对应的测试。用 Python 的 unittest 或 pytest 都行，python -m pytest tests/ 能跑通。
