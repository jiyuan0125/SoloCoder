歌词同步校正工具。下载的歌词和音频对不上有的提前有的滞后逐行手动调太麻烦需要一个批量校正工具快速修正时间偏移。

读取 LRC 歌词文件支持整体时间偏移调整 --offset 参数所有时间标签统一加或减一个固定偏移量秒为单位支持小数比如 -2.5 表示所有歌词行提前 2.5 秒。也支持倍速调整 --speed 参数比如歌词是正常速度但音频是 1.05 倍速播放录制的就需要把歌词时间轴也相应拉伸 1.05 倍。

处理完保存为新的 LRC 文件 --output 保留原文内容不变只调整时间标签。验证功能：输出前几行的时间戳调整前后对比让用户确认偏移方向和幅度是否合理再保存。

Python 3 纯标准库实现不需要第三方库。python lrc_sync.py lyrics.lrc --offset -2.5 -o synced.lrc，或 python lrc_sync.py lyrics.lrc --speed 1.05 -o synced.lrc
命令行参数解析用标准库就行，不需要第三方包。确保在主流操作系统上能编译运行。
配置参数通过命令行参数或配置文件传入，不要在代码里硬编码。支持合理的默认值。
