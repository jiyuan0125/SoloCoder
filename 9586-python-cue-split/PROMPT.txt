用 CUE 文件切分整轨音频。一张 CD 抓出来是一个大的 WAV 或 FLAC 文件加上一个 CUE 索引文件想按曲目切成独立的歌曲文件方便单独播放和管理。

读取 CUE 文件获取每首歌的曲名、表演者和起始时间信息，从整轨音频文件中按时间点精确切出每首歌的独立文件。支持 WAV 和 FLAC 格式输入，输出单独的 WAV 或 FLAC 文件通过 --format 参数指定。输出文件名用曲目编号加标题命名比如 01 - Song Name.flac 格式规范整洁。

切分精度要准确到 CUE 文件中 INDEX 01 指定的帧级别不能有间隙或重叠。同时把 CUE 中的曲目元数据标题和表演者写入输出文件的标签中。

Python 3 用 ffmpeg 按时间区间切分。python cue_split.py album.flac album.cue -o tracks/ --format flac
写好单元测试，覆盖正常流程和边界情况。测试数据要包含各种典型场景。
如果涉及并发操作，注意共享数据的同步问题。尽量使用语言标准库提供的并发原语。
输入数据可能有各种异常格式，工具需要正确处理而不会崩溃。对于二进制文件解析，要注意大小端字节序的问题。
