用 CUE 文件切分整轨音频。一张 CD 抓出来是一个大 WAV/FLAC 加一个 CUE 文件，想按曲目切成独立的文件。
读取 CUE 文件获取每首歌的时间点，从整轨音频中按时间切出每首歌的独立文件。支持 WAV 和 FLAC 输入，输出单独的 WAV/FLAC 文件，文件名用曲目编号和标题命名。
Python 3 + ffmpeg。python cue_split.py album.flac album.cue -o tracks/ --format flac，输出 tracks/01 - Song Name.flac 等。

另外要注意，对于批量操作场景，支持通配符匹配或者目录扫描。处理进度实时打印——已经处理了多少个文件、当前在处理哪个、预计还要多久。如果某个文件处理失败跳过它继续处理下一个，最后汇总报告哪些失败了及原因。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。
