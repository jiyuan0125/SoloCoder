通用播放列表解析器。想统一处理各种播放列表格式。
能自动识别播放列表文件格式，解析出里面所有的音轨路径或 URL。支持的格式越多越好：M3U/M3U8、PLS、XSPF、ASX、WPL 等。输出统一的 JSON 格式（每条记录包含文件路径、标题、时长等可用信息）。
Python 3 纯标准库。python playlist.py music.m3u --json -o tracks.json，或 python playlist.py playlist.pls show

还有一个实际问题：处理异常情况也很重要——输入文件不存在或者格式完全不对（比如把 PNG 当 CSV 传），要给出友好的错误提示而不是 traceback。如果文件特别大（超过 100MB），需要分块或者流式处理避免内存爆炸。输出结果可以同时支持终端打印和 JSON 文件导出两种方式。命令行参数要设计合理——有默认值让最少参数就能跑，也有高级选项给需要调优的用户。

性能方面要注意——单个文件处理不能太慢（别超过 10 秒），批量处理时可以并行加速。内存占用也要控制，处理大文件时别超过 500MB。日志输出要分级：正常模式只打印摘要，verbose 模式打印每一步的细节。
