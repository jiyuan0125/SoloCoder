M3U 播放列表解析器。手里有好多 M3U 文件想提取里面的歌单。
解析 M3U 和 M3U8（Extended M3U）格式文件。提取 EXTINF 标签中的信息（时长、艺术家、标题）和实际的文件路径。支持相对路径和绝对路径，支持 URL 类型的条目。能把解析结果导出为 CSV 或 JSON。
Python 3 纯标准库。python m3u_parser.py playlist.m3u show，或 python m3u_parser.py playlist.m3u --export csv -o songs.csv

补充几个关键点：处理异常情况也很重要——输入文件不存在或者格式完全不对（比如把 PNG 当 CSV 传），要给出友好的错误提示而不是 traceback。如果文件特别大（超过 100MB），需要分块或者流式处理避免内存爆炸。输出结果可以同时支持终端打印和 JSON 文件导出两种方式。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。

错误恢复机制也要考虑——如果程序崩溃了，重启后能从断点继续而不是从头开始。配置参数可以保存到文件下次直接 --config file.json 加载。支持管道输入输出方便和其他命令行工具组合使用。
