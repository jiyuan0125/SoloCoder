ASX 播放列表解析器。Windows Media Player 的 ASX 格式也需要支持。
解析 ASX（Advanced Stream Redirector）XML 格式的播放列表。提取每个 entry 的 title、author、ref href（媒体路径）、copyright 等信息。ASX 有多种版本和写法，要尽量兼容。输出到终端或导出 JSON。
Python 3 标准库 xml.etree.ElementTree。python asx_parser.py playlist.asx show，或 python asx_parser.py playlist.asx --json -o tracks.json
