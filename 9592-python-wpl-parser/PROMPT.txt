WPL 播放列表解析器。Windows Media Player 默认保存为 WPL 格式。
解析 WPL（Windows Media Player Playlist）SMIL 格式的播放列表。提取 body → seq → media 节点中的 src、tid、title 等属性。也要读取 head 中的 meta 信息（比如 totalDuration）。输出 JSON 或 CSV。
Python 3 标准库 xml.etree.ElementTree。python wpl_parser.py playlist.wpl show，或 python wpl_parser.py playlist.wpl --csv -o songs.csv
