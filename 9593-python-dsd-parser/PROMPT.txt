最近在折腾 DSD 音频格式，发现手上有 .dff 和 .dsf 两种文件，想快速看一下它们的采样率和元数据信息，但找不到命令行下好用的查看工具。

DSD 音频有两种主流容器格式——DFF（Philips DSDIFF）和 DSF（Sony DSD Stream File）。这个工具先做通用解析：打开文件后先读文件头的 magic bytes 判断是 DFF 还是 DSF，然后按各自的格式规范读取结构。要提取的信息包括采样率（通常是 2.8224MHz 或 5.6448MHz）、位深（1-bit DSD）、声道数（单声道或立体声）、播放时长、艺术家和标题等 ID3 元数据（DSF 文件末尾会带 ID3v2 标签）。不涉及音频解码播放，纯粹做文件结构分析。

命令行用法：python dsd_parser.py track.dff info，输出文件格式类型、采样率、声道数、时长、元数据等信息。也支持传入 .dsf 文件，自动识别格式。遇到无法识别的文件要给出明确的错误提示而不是直接崩溃。

Python 3 纯标准库，直接用 open() + struct 模块读二进制。不依赖任何第三方音频处理库。
