上次做了个通用 DSD 解析器，现在想深入一下 DSF 的文件结构。DSF 是 DSD 音频最常用的容器格式，索尼搞的，市面上大部分 DSD 文件都是这种封装。

DSF 文件由三块组成，每块都有自己的 chunk header。DSD 块在最前面，包含格式版本号和指向后面各块的偏移指针；fmt 块记录音频格式详情，包括格式 ID（区分原生 DSD 和 DST 压缩）、声道数、采样率（常见的是 2822400 或 5644800 Hz）、每 sample 的 bit 数、总采样数，通过这些可以算出播放时长；data 块是实际的音频数据区域，大小可能上百 MB。文件末尾往往附带了 ID3v2 元数据标签，里面有艺术家、专辑、曲目名、年份这些常见字段。解析器要逐块读取，把每个块的偏移量和内容都解析清楚。

命令行用法：python dsf_parser.py music.dsf info，输出完整的文件结构——各块的位置和大小、音频参数、时长、ID3 元数据。加个 --verbose 参数可以看到更详细的块级偏移信息。没有 ID3 标签的文件不要报错，跳过就好。

Python 3 纯标准库，struct 模块做二进制解析。文件头都是大端序，读的时候注意字节序。
