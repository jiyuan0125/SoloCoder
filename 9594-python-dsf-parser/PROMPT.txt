DSF 文件解析器。DSF 是 DSD 音频的常用容器格式，想深入了解它的结构。
解析 DSF（DSD Stream File）格式的音频文件。DSF 文件由三块组成：DSD 块（文件头）、fmt 块（格式信息）、data 块（音频数据）。读取并解析这些块的内容，提取版本、格式 ID、声道数、采样率、位深、总采样数等信息。也读取 ID3v2 元数据标签。
Python 3 纯标准库二进制解析。python dsf_parser.py music.dsf info，输出完整的文件结构信息。

最后一步别忘了，处理异常情况也很重要——输入文件不存在或者格式完全不对（比如把 PNG 当 CSV 传），要给出友好的错误提示而不是 traceback。如果文件特别大（超过 100MB），需要分块或者流式处理避免内存爆炸。输出结果可以同时支持终端打印和 JSON 文件导出两种方式。使用说明打印 --help 要清晰，每个参数的作用和默认值都要写明。

测试用例要覆盖边界情况——空文件、超大文件、格式不对的文件、编码异常的文件。每个大概这些都要有对应的测试。用 Python 的 unittest 或 pytest 都行，python -m pytest tests/ 能跑通。
