DFF 是 Philips 搞的 DSDIFF 格式，和 DSF 是同一类东西但封装方式完全不同。它用的是类似 IFF/AIFF 的嵌套块结构：最外层是 FRM8 容器块，里面套着 FVER（格式版本）、PROP（属性块，记录采样率和声道数）、DSD（实际音频数据）这些子块。PROP 块里面还有进一步的嵌套，得递归地解析才行。

解析器要做的：逐块扫描文件，遇到 FRM8 就进到下一层，遇到 FVER 读版本号，遇到 PROP 就继续深入读采样率和声道配置，遇到 DSD 块记录数据区域的位置和大小。有些 DFF 文件用了 DST 压缩（无损压缩），碰到 DST 块也要识别出来并标注。最终输出文件格式版本、采样率、声道数、压缩方式、估算时长这些关键信息。

命令行：python dff_parser.py audio.dff info，打印块结构和音频参数。加 --tree 参数可以输出完整的块嵌套树，方便调试。文件特别大的时候不能全部读入内存，得用 seek 按需读取。

Python 3 纯标准库二进制解析，struct.unpack 读固定宽度的块头。DFF 的 chunk ID 是 4 字节 ASCII，大小是 big-endian 64 位整数。
