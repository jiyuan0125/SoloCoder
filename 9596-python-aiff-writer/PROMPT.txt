音频处理流水线到最后一步需要把 PCM 数据保存成 AIFF 格式，主要是给 Mac 上的音频工具用。FFmpeg 虽然能转但不够灵活，尤其是要精确控制位深和元数据的时候。

AIFF 文件结构是这样的：最外层 FORM 容器，里面嵌套 COMM 块（记录声道数、采样率、位深等格式信息）和 SSND 块（实际的 PCM 音频数据，前面还有 8 字节的 offset 和 blockSize）。另外可以加一个 ID3 块写入基本标签信息。写入时要注意 AIFF 的整数都是 big-endian，和 WAV 的 little-endian 相反。支持 16-bit 和 24-bit 位深，单声道和立体声，自定义采样率（44100、48000、96000 等）。

输入可以是 raw PCM 字节流，也可以是 numpy 数组（如果有 numpy 的话）。命令行用法：python aiff_writer.py --input pcm.raw --output audio.aiff --sample-rate 44100 --channels 2 --bit-depth 24。必须指定采样率、声道数和位深，因为没有文件头可以推断。24-bit 的写入要用到 3 字节打包，struct 模块原生不支持，得手动处理。

Python 3 纯标准库 struct 模块写入二进制，不依赖第三方音频库。文件大小限制不用管，处理几十 MB 的音频文件就行。
