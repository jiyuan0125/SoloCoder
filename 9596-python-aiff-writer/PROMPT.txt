AIFF 文件写入器。音频处理完了想保存为 AIFF 格式给 Mac 上的工具用。
把 PCM 音频数据（numpy 数组或者原始字节）写入 AIFF 文件格式。支持 16-bit 和 24-bit 位深，单声道和立体声，自定义采样率。正确写入 AIFF 文件头（FORM、COMM、SSND 块），也支持写入基本的 ID3 标签。
Python 3 纯标准库 struct 模块写入二进制。python aiff_writer.py --input pcm.raw --output audio.aiff --sample-rate 44100 --channels 2 --bit-depth 24

另外要注意，输出的文件要能在标准工具里正常打开和显示。如果输入参数有冲突（比如指定的尺寸不合法或者数据格式不匹配），在开始处理前就要报错别等到生成一半才发现。处理完打印输出文件的路径和大小方便确认。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。
