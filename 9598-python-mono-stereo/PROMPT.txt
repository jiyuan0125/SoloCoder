单声道立体声互转工具。有些音频处理需要固定声道数。
支持把单声道音频复制成双声道立体声（左右声道相同），也支持把立体声混合成单声道（取平均值，或只取左/右声道）。多声道（5.1 之类）也能降混成立体声或单声道。输入输出支持 WAV 和 FLAC。
Python 3 + ffmpeg 或用 wave 模块直接处理 PCM。python mono_stereo.py input.wav --to-stereo -o stereo.wav，或 python mono_stereo.py stereo.wav --to-mono --method avg -o mono.wav

补充几个关键点：对于批量处理场景支持目录扫描和通配符匹配。处理进度实时显示已完成数量和总数量。如果某个文件处理出错跳过继续下一个最后汇总报告。输出结果要包含处理参数的记录方便追溯和复现。性能方面也要考虑——单次处理不能太慢，如果需要可以加个 --fast 模式牺牲精度换速度。

错误恢复机制也要考虑——如果程序崩溃了，重启后能从断点继续而不是从头开始。配置参数可以保存到文件下次直接 --config file.json 加载。支持管道输入输出方便和其他命令行工具组合使用。
