音频位深转换工具。24-bit 的音频想转成 16-bit 给老的播放器用，或者反过来提升精度。
在不同采样位深之间转换音频：8-bit ↔ 16-bit ↔ 24-bit ↔ 32-bit。转换时要正确处理量化和抖动（dithering），避免截断噪声。支持有符号整数和无符号整数格式，也支持浮点 PCM（32-bit float）。
Python 3 + numpy 或 struct。python bitdepth.py input.wav --to 16 --dither triangular -o output.wav，输入输出都是 WAV 格式。

最后一步别忘了，变换参数可以保存到 JSON 文件方便复用同一套变换应用到多张图片上。支持逆变换——给定变换后的坐标算出原图坐标。输出图片的元数据（尺寸、色彩空间）要正确设置别让后续程序读到错误信息。使用说明打印 --help 要清晰，每个参数的作用和默认值都要写明。

测试用例要覆盖边界情况——空文件、超大文件、格式不对的文件、编码异常的文件。每个需要做的都要有对应的测试。用 Python 的 unittest 或 pytest 都行，python -m pytest tests/ 能跑通。
