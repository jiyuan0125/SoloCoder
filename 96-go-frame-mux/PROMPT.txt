用 Go 写一个连接多路复用框架。在一条 TCP 连接上复用多个逻辑流（类似 HTTP/2 stream）。

帧格式：
1. 4 字节 stream ID（大端序）
2. 1 字节 flags：bit 0=SYN（新流）, bit 1=FIN（半关闭发送端）, bit 2=ACK, bit 3=RST（强制关闭）
3. 4 字节 payload 长度（大端序）
4. 后跟 payload 数据

流管理：
3. 客户端开的流 ID 用奇数（1, 3, 5...），服务端用偶数（2, 4, 6...）。流 ID 不能为 0
4. SYN 标志：新建流时设置。RST 标志：强制关闭流，丢弃该流所有缓冲数据
5. 半关闭（FIN）：发送 FIN 后不能再发数据，但还可以继续收数据。双方都 FIN 了才可以关闭流

流量控制（滑动窗口）：
6. 每个流有独立的发送窗口和接收窗口，窗口大小为 64KB
7. 发送端维护可用窗口大小，发送数据后减少可用窗口
8. 接收端读取数据后发送窗口更新帧（flags=ACK，payload 为该流的当前可用接收窗口大小）
9. 窗口为 0 时不能发送数据，必须等待窗口更新

API：
10. mux.OpenStream() (Stream, error)：创建新流
11. mux.AcceptStream() (Stream, error)：接收对端创建的流（阻塞等待）
12. stream.Write(data) / stream.Read() 读写数据
13. stream.Close() 发送 FIN

代码分 mux.go、stream.go、frame.go 几个 package，go build 能过。
