采样率转换工具。有一批 48kHz 的音频要转成 44.1kHz 才能刻 CD。
将音频文件的采样率从一种转换到另一种。支持常见采样率互转（44100、48000、96000、192000、22050、8000 等）。转换质量要高，使用合适的重采样算法（线性插值或更好的），不能有明显失真。支持 WAV 和 FLAC 格式。
Python 3 + scipy.signal.resample 或 ffmpeg。python sr_convert.py input.wav --from 48000 --to 44100 -o output.wav

对了，还有个细节——变换参数可以保存到 JSON 文件方便复用同一套变换应用到多张图片上。支持逆变换——给定变换后的坐标算出原图坐标。输出图片的元数据（尺寸、色彩空间）要正确设置别让后续程序读到错误信息。如果处理过程中出现什么问题，错误信息要具体到是哪个步骤哪条数据出的问题。

代码结构要清晰——核心逻辑和 CLI 入口分离，核心功能可以被其他脚本 import 使用。依赖尽量少只用标准库或者一两个常用第三方库。README 写清楚安装依赖和基本用法。
