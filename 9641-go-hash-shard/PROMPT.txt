帮我用 Go 做一个哈希分片模块。把 key 做哈希后取模，决定数据存在哪个节点，这是最简单也最常用的分片方式。

实现内容：哈希函数的选择（支持多种哈希：MurmurHash、FNV、CRC32）、取模分片（hash(key) % N）、一致性映射（节点数变化时尽量少迁移）。预分片策略：预先划分固定数量的虚拟分片（比如 256 个），再映射到实际节点，加节点只需重新映射虚拟分片。

写个 benchmark：分别用不同哈希函数对 100 万个 key 做分片，打印每个节点的数据量和分布标准差。go build 通过。

另外要注意，对于批量处理场景支持目录扫描和通配符匹配。参数可以保存为配置文件方便复用。处理出错时给出具体原因和修复建议而不是一个笼统的 error。输出结果要清晰易读方便人工确认或者被其他程序调用。最终输出要包含处理摘要：成功多少个、失败多少个、跳过多少个。

接口设计要考虑易用性——新手看一眼 help 就能跑起来，高级用户有足够的参数可以调。输出格式统一用 JSON 方便后续脚本处理。如果处理过程中被中断（Ctrl+C），要把已处理的结果保存下来不要全部丢掉。

如果运行环境缺少某些依赖库，启动时要给出清晰的安装指引而不是 import 报错。命令行帮助信息要完整每个参数都有说明和默认值。处理完成后打印简要统计——处理了几个输入、耗时多少、输出在哪里。
