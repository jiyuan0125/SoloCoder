分布式 KV 经常需要按前缀查询——比如查所有 user: 开头的条目（用户数据）、log:2024-01: 开头的条目（某月日志）、session: 开头的条目（活跃会话）。不需要知道具体的 key，给个前缀就能把匹配的全捞出来。

前缀扫描的实现思路：给定期望的前缀字符串（比如 "user:"），遍历有序 KV 存储中所有 key，返回前缀匹配的 key-value 对。因为底层是有序结构（sorted map / skip list），可以利用前缀的范围特性做优化——前缀 "user:" 对应的 key 范围是 ["user:", "user;"）（分号是冒号的下一个 ASCII 字符），在这个范围内做有序遍历比全量扫描快得多。分页支持：返回结果可能很多，支持 limit + offset 或者 cursor 参数做分页——每页返回 N 条，附带下一页的 cursor（最后一个 key）。分布式场景下还要处理多分片合并：如果 key 按 hash 分片到不同节点，前缀扫描需要向所有分片并发发起查询，然后合并结果排序返回。

模拟多分片场景：3 个分片节点，数据按 key hash 分布。写入 50 条 user: 开头、30 条 order: 开头、20 条 product: 开头的数据。前缀查询 "user:" 时，向 3 个分片并发查询，合并结果后返回所有 50 条 user: 前缀的记录。分页查询（每页 10 条），验证分页 cursor 正确。
