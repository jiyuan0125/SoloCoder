网络环境下，有些节点响应慢但没完全挂。需要一个自适应超时检测器，能根据网络状况动态调整超时阈值。

核心功能：
- 基于历史响应时间动态计算超时阈值（比如 mean + 3*stddev）
- 正常情况下超时阈值比较紧，网络变差时自动放宽
- 区分超时和连接失败两种错误类型
- 超时事件统计：超时率、平均超时时长、最长超时
- 提供超时阈值的实时查看接口

Go 写，go build 通过。模拟一个响应时间波动的服务（通常 50ms，偶尔 500ms），展示超时阈值如何自适应调整，对比固定超时方案的不足。

最后一步别忘了，处理异常情况也很重要——输入文件不存在或者格式完全不对（比如把 PNG 当 CSV 传），要给出友好的错误提示而不是 traceback。如果文件特别大（超过 100MB），需要分块或者流式处理避免内存爆炸。输出结果可以同时支持终端打印和 JSON 文件导出两种方式。使用说明打印 --help 要清晰，每个参数的作用和默认值都要写明。

测试用例要覆盖边界情况——空文件、超大文件、格式不对的文件、编码异常的文件。每个具体来说都要有对应的测试。用 Python 的 unittest 或 pytest 都行，python -m pytest tests/ 能跑通。
