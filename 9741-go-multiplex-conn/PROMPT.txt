一台机器上要同时跟多个对端通信，不能每个连接一个线程太浪费。需要实现多路复用连接（类似 HTTP/2 的多路复用）。

功能：
- 在一条 TCP 连接上同时承载多个逻辑流（stream），每个 stream 有独立 ID
- 发送方把不同 stream 的数据帧交织发送，接收方按 stream ID 分发
- 支持流的创建、数据传输、流关闭（半关闭和全关闭）
- 流量控制：每个 stream 有独立的窗口大小，防止某个流占满整个连接
- 一条物理连接断开后，所有 stream 都感知到

Go 实现，go build 通过。在一条模拟连接上同时跑 3 个 stream 传输不同内容，展示数据帧的交织传输和按 stream 正确重组。
