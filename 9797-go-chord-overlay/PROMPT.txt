Chord 是最经典的分布式哈希表（DHT）算法之一。它把所有节点和 key 都映射到一个环上，每个节点负责环上一段区间的 key。查找的时候不用遍历所有节点，通过 Finger Table 跳跃 O(log N) 次就能定位到目标。用 Go 把 Chord 的核心路由逻辑实现出来。

哈希环的构建：用 SHA-1（或者简单用 CRC32 也行）把节点 ID 和 key 映射到一个 0 ~ 2^m-1 的环上。m 可以设小一点（比如 8，环大小 256），方便调试和可视化。节点在环上按顺时针排列，每个节点负责从它的前驱节点（不含）到自己的区间内的所有 key。

Finger Table 的结构：每个节点维护 m 个表项，第 i 项指向 successor(node_id + 2^i) 的节点。查找 key 时从最高位开始，如果 finger[i] 比自己离 key 更近，就跳到 finger[i] 继续找。每跳至少翻倍当前进度，所以 O(log N) 跳就能到达。

需要实现的功能：创建环并添加节点（更新所有受影响节点的 finger table）、查找 key 的负责节点、添加和移除节点（重新分配 key）。模拟 16 个节点，插入 100 个 key，打印几次查找的路径："lookup key=x hash=142 → node-5 hash=50 → node-11 hash=130 → node-13 hash=142 ✓ (2 hops)"。

Go 标准库实现，go build 编译通过。
