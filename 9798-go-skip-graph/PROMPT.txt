Skip Graph 是一种跳表的分布式变体——每个 key 是一个节点，有多层的 membership vector（随机二进制串），每一层形成一个有序链表。查找时从最高层开始，逐层下降缩小范围，O(log N) 复杂度。和 Skip List 不同的是 Skip Graph 的节点可以分布在不同机器上。用 Go 实现它。

数据结构设计：每个元素有一个 key（用于排序）和一个 membership vector（随机生成的二进制串，比如 8 位）。每个元素在多层链表中出现——第 0 层包含所有元素（完全排序的链表），第 k 层只包含 membership vector 前 k 位为某个特定值的元素。

查找过程：从最高层开始，在当前层找到最大的不大于 target 的节点。如果这个节点的 key 等于 target，查找成功。否则下降一层，在更密集的链表里继续找。逐层下降直到第 0 层，最终找到精确位置或确认不存在。

需要实现四种操作：Insert(key) 生成 membership vector 后在每一层插入正确位置、Delete(key) 从所有层移除、Find(key) 精确查找、Range(min, max) 范围查询（先找到 min，然后沿第 0 层遍历到 max）。

构造 100 个随机 key 的 Skip Graph，打印结构概览（每层有多少节点），演示查找和范围查询的路径。
