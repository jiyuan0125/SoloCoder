实现哈希分片（Hash Sharding），用 Rust。

把 key 通过哈希函数映射到固定的分片数量上，每个分片由不同的节点负责。优点是分布均匀，缺点是范围查询不友好。适合随机读写的场景。

核心功能：
- 配置总 shard 数量（如 64、128），key 哈希后取模确定分片
- 维护 shard → 节点的映射表
- 支持动态修改 shard → 节点映射（不改变 shard 数量，只改节点分配）
- 查询某个 key 落在哪个分片和节点上
- 统计各分片的 key 数量验证均匀性

cargo build 通过，用 10000 个随机 key 测试各分片数量偏差不超过 10%。
