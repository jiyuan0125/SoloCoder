用 Rust 实现 Kademlia 的 K-Bucket 数据结构。

K-Bucket 是 Kademlia DHT 路由表的核心：每个桶覆盖一个距离范围，最多存 k 个节点（通常 k=20）。桶内节点按最近活跃时间排序，新节点优先替换最不活跃的。

要做的：
- 每个桶维护一个有序列表（最近活跃的在尾部）
- 插入节点：桶未满直接加，满了就 ping 最老的节点——如果还活着就忽略新节点，否则替换
- 支持按 node ID 确定属于哪个桶（计算公共前缀长度）
- 定期刷新：对长时间没通信的桶执行查找刷新
- 线程安全的桶操作

cargo build 通过，测试桶满时的替换策略和并发安全性。
