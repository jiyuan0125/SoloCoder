先理解混合逻辑时钟（HLC）要解决的问题，再实现它。物理时钟不靠谱（NTP 有偏移），逻辑时钟不直观（counter 不对应真实时间）。HLC 把两者结合——使用物理时间戳作为主体，逻辑 counter 处理同一物理时间内的多次事件。用 Rust 实现 HLC，对比普通 Lamport 时钟。

HLC 的数据结构：HybridClock { physical_time: u64, logical_counter: u16 }。physical_time 是当前的物理时间戳（毫秒级），logical_counter 是逻辑计数器（同一毫秒内的事件用 counter 区分）。

事件处理的三个规则。本地事件或发送消息时：如果 now() > physical_time，更新 physical_time = now()，counter = 0。否则 counter++。接收消息时：取 max(physical_time, msg.physical_time, now()) 作为新的 physical_time。如果三者相等，counter = max(counter, msg.counter) + 1。如果 physical_time 是 max，counter = max(counter, msg.counter) + 1。如果 now() 是 max，counter = 0。

HLC 的性质：和 Lamport 时钟一样保证因果有序（如果 A before B，则 HLC(A) < HLC(B)）。同时，HLC 的 physical_time 部分接近真实时间，最大偏差只有消息延迟。比纯 Lamport 时钟更容易理解事件的真实发生时间。
