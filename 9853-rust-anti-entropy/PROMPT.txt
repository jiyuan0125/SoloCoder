Anti-entropy（反熵）是 Dynamo 和 Cassandra 用来保证副本最终一致的后台修复机制。和读修复（读时触发）不同，anti-entropy 是后台定期运行的，用 Merkle Tree 高效地找出副本间的差异。用 Rust 实现一个基于 Merkle Tree 的 anti-entropy 同步器。

Merkle Tree 的构建：把 key 空间按范围分成固定大小的桶（比如 256 个桶），每个桶计算一个哈希值（桶内所有 key-value 的哈希）。桶的哈希两两组合生成父节点哈希，逐层向上直到树根。比较两棵 Merkle Tree 时，如果根哈希相同，说明数据完全一致。如果不同，逐层向下比较，找到差异的叶子桶。

同步流程：节点 A 向节点 B 发送自己的 Merkle Tree 根哈希。B 比较根哈希，如果不同，请求 A 发送下一层。逐层比较直到找到差异的叶子桶。然后 A 把差异桶中的数据发给 B，B 用较新版本覆盖。

增量更新：数据变更后只更新受影响的桶和其祖先路径，不用重建整棵树。每次写入操作后，找到 key 对应的叶子桶，重新计算该桶和所有祖先的哈希。

模拟 2 个节点各 1000 个 key。故意让节点 B 缺少 50 个 key、20 个 key 版本过旧。构建 Merkle Tree 并运行 anti-entropy，打印找到的差异和修复过程。
