分布式 KV 存储是分布式系统的"Hello World"——几乎所有概念都能在它上面体现：副本、一致性、分区容忍、故障恢复。用 Rust 把一个简单的分布式 KV 实现出来，集成之前做过的多个模块。

架构：N 个节点（默认 3 个），每个节点存储一部分 key（一致性哈希分片），每个 key 有 R 个副本（默认 3，即全量副本）。节点间通过 channel 模拟网络通信。

客户端接口：put(key, value, consistency: W) 写入、get(key, consistency: R) 读取。W 和 R 可配置——W=1 快但不可靠，W=3 强一致但慢。如果 W+R > N，保证读到最新写入的数据（quorum 读写的交集性质）。

内部实现：put 操作由协调者节点负责——找到 key 的所有副本节点，并行发送写入请求，等 W 个确认后返回。get 操作同样找副本节点，取版本最高的返回。如果部分副本不可达，尝试使用 hinted handoff（把写入暂存到可用节点）。

命令行交互：启动时指定节点数和副本数。支持 put key value、get key、stats（打印各节点的数据量和状态）、down node_id（模拟节点下线）、up node_id（恢复节点）。

cargo build 通过。
