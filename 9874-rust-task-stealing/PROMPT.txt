先说清楚 work stealing 要解决什么问题——多个 worker 各有自己的任务队列，如果某个 worker 空了但它邻居还有很多任务，可以从邻居那里"偷"一些过来。这样比中心化调度更去中心化，延迟更低。用 Rust 实现 work stealing 的调度策略。

数据结构：每个 Worker 有一个本地 deque（双端队列）。Worker 自己从队列尾部取任务执行（LIFO，利用局部性）。其他空闲 Worker 从队列头部偷任务（FIFO，偷最旧的任务，减少竞争）。

Work stealing 的流程：Worker 循环执行——如果本地队列有任务，从尾部取一个执行。如果本地队列空了，随机选一个其他 Worker，从它的队列头部偷一个任务。如果偷到了就执行，偷不到（别人也空了）就 sleep 一小段时间再试。

偷取的策略：Random steal（随机选一个 Worker 偷）简单但可能偷到空队列。Steal-best-of-k（随机选 k 个 Worker，从任务最多的那个偷）更高效但开销稍大。程序实现两种策略，对比偷取成功率。

负载均衡的效果：初始时所有任务都放在 Worker-0 的队列里。运行后观察任务如何通过 stealing 逐渐分布到所有 Worker 上。打印每个 Worker 的本地队列大小随时间的变化。

实现用 crossbeam-deque 或自己用 Mutex<VecDeque> 简单实现。cargo build 通过。
