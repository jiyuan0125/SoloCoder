帮我用 Rust 实现任务窃取（Work Stealing）调度器。

在多线程/多 worker 场景下，每个 worker 有自己的本地任务队列。如果某个 worker 空了，可以从其他 worker 的队列末尾"偷"任务来执行，实现负载均衡。

要做：
- 实现多个 worker，每个 worker 有自己的 deque（双端队列）
- worker 从自己队列头部取任务执行，没有任务时从其他 worker 的队列尾部偷
- 偷任务时要处理好并发竞争（两个 worker 不能偷到同一个任务）
- 统计每个 worker 自己完成的任务数和偷来的任务数
- 能输出最终的任务分布情况，验证确实实现了负载均衡

cargo run 能看到窃取过程。
