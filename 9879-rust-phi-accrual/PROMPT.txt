写个 Rust 程序实现 Phi Accrual 故障检测器。

和传统的心跳检测不同，Phi Accrual 不是简单的"超时就判定挂了"，而是根据历史心跳间隔算出一个"疑似故障程度"（phi 值）。phi 越高说明越可能挂了，可以灵活设置阈值。

核心功能：
- 记录最近 N 次心跳到达的时间间隔，计算均值和标准差
- 根据当前时间距上次心跳的间隔，计算 phi 值（参考 Cassandra 的论文公式）
- phi 值超过可配置阈值（默认 8.0）时判定为故障
- 提供命令行接口：可以模拟发送心跳、查看 phi 值变化曲线、触发故障告警
- 网络抖动场景下不会误判（偶尔回来一个心跳 phi 就降下去了）

cargo build 通过。
