用 Rust 实现集群成员管理（Cluster Membership）。

就是管理"集群里有哪些节点活着"这件事。节点可以加入、离开、或者故障被踢掉，所有节点最终要对成员列表达成一致。

功能：
- 每个节点维护一个成员列表，记录节点 ID、地址、状态（alive / suspect / dead / left）
- 使用 gossip 协议传播成员变更：定期随机选一个节点，同步彼此的成员信息
- 新节点加入时通过 seed 节点发现集群，逐步获取完整成员列表
- 节点优雅退出（主动 leave）和故障退出（心跳超时被标记 dead）的处理不同
- 能展示 gossip 传播过程中各节点成员列表的收敛过程

cargo run 能演示，内存模拟多个节点。
