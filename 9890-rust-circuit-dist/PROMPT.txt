用 Rust 实现分布式场景下的熔断器（Circuit Breaker）。

调用下游服务时，如果失败率太高，就暂时停止调用，等下游恢复后再试。避免故障级联。

要做的：
- 三种状态：closed（正常调用）→ open（熔断，直接拒绝）→ half-open（试探性放少量请求）
- 记录最近 N 次调用的成功/失败，失败率超过阈值（比如 50%）就切换到 open
- open 状态持续一段时间后自动进入 half-open，放少量请求试探
- half-open 中如果成功率恢复，切换到 closed；还是失败就回到 open
- 能输出状态转换日志和调用统计

cargo run 能演示熔断过程。模拟调用成功/失败。
