用 Rust 实现快照应用（Snapshot Apply）机制。

节点从快照恢复状态时，需要把快照数据加载并应用到状态机。还有另一种场景：leader 给落后太多的 follower 发快照而不是逐条发日志。

核心功能：
- 状态机维护一个 key-value 状态，通过日志条目的 apply 来更新
- 支持生成快照：把状态机当前状态和 last_applied_index 序列化
- 从快照恢复：清空当前状态，加载快照数据，然后从快照之后的 index 继续应用日志
- 模拟一个落后节点的恢复场景：先加载快照跳到 index 100，然后逐步应用 101 之后的日志
- 验证最终状态和一直从头 apply 日志的结果一致

cargo build 通过，标准库实现。
