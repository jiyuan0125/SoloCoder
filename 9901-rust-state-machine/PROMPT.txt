帮我用 Rust 实现一个通用的有限状态机引擎。

场景是这样的：我需要在一个嵌入式通信协议里管理连接生命周期，比如 CLOSED→CONNECTING→CONNECTED→DISCONNECTING→CLOSED 这种状态流转。希望能定义状态和转移规则，然后驱动事件去触发状态变化。

功能要求：
- 可以定义状态集合、事件集合、以及合法的转移规则（from_state + event → to_state）
- 支持守卫条件（guard），转移前可以检查一个闭包返回 true 才允许执行
- 每次状态变化触发 on_enter 和 on_exit 回调
- 提供当前状态查询和转移历史记录

用纯 Rust 标准库，cargo build 能编译通过就行。
