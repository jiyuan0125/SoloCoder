我需要一个副本提升（promotion）模块，用 Rust 实现。

场景是这样的：分布式系统里主节点挂了，需要把一个从节点提升为新主节点。这个过程不能随便来，得选延迟最小、数据最完整的从节点，而且切换过程中要保证数据不丢。

要做的事情：
- 维护一个候选从节点列表，记录每个从节点的同步进度（已应用 LSN）和健康状态
- 选举逻辑：优先选同步进度最高（LSN 最大）且健康的从节点
- 提升流程：标记旧主为 down→通知选中的从节点停止同步→切换角色为新主→通知其他从节点改为从新主同步
- 如果同时有多个从节点 LSN 相同，用节点 ID 做确定性排序打破平局
- 提升完成后拒绝来自旧主节点的写入

纯 Rust，cargo build 通过。
