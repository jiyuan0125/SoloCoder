用 Rust 写一个 Quorum 读写控制模块。

分布式系统里经常用 quorum 来保证读写一致性——比如 3 个副本，写的时候至少 2 个确认成功才算写完，读的时候也至少从 2 个读才能返回。这个工具就是来管理 quorum 逻辑的。

功能：
- 配置集群大小 N 和 quorum 数 W/R（write quorum / read quorum）
- 写入操作：向所有 N 个副本发送写入请求，收到 W 个确认后返回成功，超时的副本记录为待修复
- 读取操作：向所有 N 个副本发送读取请求，收集 R 个响应后，返回最新的那个版本
- 支持 N=1 的退化模式（单节点，无需 quorum）
- 提供查询接口，看当前有多少副本在线、多少在恢复中

模拟节点间通信就行，不走真正网络。Rust 标准库，cargo build 通过。
