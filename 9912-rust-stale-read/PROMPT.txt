用 Rust 写一个过期读（stale read）检测和处理工具。

问题：分布式系统里从节点可能延迟，读从节点时可能拿到旧数据。很多时候业务能接受一定程度的旧，但需要知道数据到底有多旧。这个工具就是来量化和管理这个问题的。

功能：
- 每条数据写入时记录一个时间戳（write_ts）
- 读取时可以配置可接受的过期阈值（stale_threshold）
- 如果读到的数据 write_ts 距离当前时间超过阈值，标记为 stale read
- 统计接口：返回最近 N 次读取中有多少次是 stale read、平均延迟多少
- 支持一个模式：遇到 stale read 时自动从主节点重新读取并返回最新值（read repair）
- 可以按 key 查看各副本上该 key 的时间戳差异

Rust 标准库，cargo build 编译通过。
