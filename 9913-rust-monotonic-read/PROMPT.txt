前两天用户群里有人反馈"我刚看到的订单状态是已发货，刷新一下怎么变回待发货了？"查了一下，是负载均衡把他导到了不同的从节点，两个节点数据版本不一样。单调读保证的就是这件事：同一个客户端连续读同一个 key，不应该看到时间倒退。

用 Rust 实现单调读模块。客户端侧维护一个 session token，记录已观察到的最新版本号，每次读取时把 session token 传给存储层，存储层保证返回的数据版本不低于 session token。如果当前副本没有足够新的数据，等待同步完成或从更快的副本读取。支持模拟多客户端，每个客户端独立维护自己的单调读保证。

这个保证的核心成本在客户端——服务端不用改什么，客户端记住之前看到过的最高版本号就够了，实现简单但效果很直接。

Rust 标准库，cargo build 通过。
