帮我实现单调读（monotonic read）保证模块，用 Rust。

场景：用户连续发两次读请求，如果第二次读到了比第一次更旧的数据，体验会很糟糕。比如第一次看到了一条新消息，第二次刷新反而没了。单调读保证：一旦读到了某个值，后续的读不会回退到更旧的值。

实现：
- 在客户端侧维护一个 session token，记录该客户端已观察到的最新时间戳或版本号
- 每次读取时，把 session token 传给存储层
- 存储层保证返回的数据版本不低于 session token
- 如果当前副本没有足够新的数据，等待同步完成或从更快的副本读取
- 支持模拟多客户端，每个客户端独立维护自己的单调读保证

Rust 标准库，cargo build 通过。
