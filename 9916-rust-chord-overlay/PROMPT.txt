Chord 算法最漂亮的地方在于：N 个节点的集群里定位一个 key 只需要 O(log N) 跳。它把所有节点和数据都映射到一个环上，每个节点只维护 m 个 finger table 条目就能完成路由。听起来像数学魔术，但实现出来其实很直观——用 Rust 在内存里模拟一个完整的 Chord DHT。

要做的东西：
- 实现 Chord 环：节点 ID 通过 SHA-1 哈希映射到环上
- Finger table：每个节点维护 m 个 finger entry，第 i 个指向 ID 后面 2^(i-1) 位置的节点
- 查找操作：给定一个 key，沿 finger table 在 O(log N) 跳内找到负责该 key 的节点
- 节点加入：新节点通过已知节点查找自己的后继，插入环中，更新 finger table
- 稳定化（stabilize）：定期运行，修正后继指针和 finger table
- 数据操作：put(key, value) 放到负责节点上，get(key) 通过查找定位到节点并返回

纯 Rust，内存模拟，cargo build 通过。
