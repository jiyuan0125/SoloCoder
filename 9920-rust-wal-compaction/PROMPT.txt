用 Rust 实现一个 WAL 日志压缩（compaction）模块。

问题：WAL 里会累积大量已经被上层应用的旧日志，白白占空间。需要定期压缩——把已经应用过的日志记录合并或删除，只保留必要的部分。

功能需求：
- WAL 中每条日志记录带一个 applied 标记
- 压缩时扫描所有段，找到连续的已应用记录
- 对于已应用的记录，如果对应的数据已经被 checkpoint 持久化，可以安全删除
- 压缩后生成新段替换旧段，对外提供连续的 LSN 不受影响
- 支持后台增量压缩：不阻塞正常写入，先在副本上压缩，完成后原子切换
- 提供统计：压缩前后的段数量和总大小对比

Rust 标准库，cargo build 通过。

这个工具的核心价值在于把wal compaction的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

压缩过程中的新写入是个挑战——常见方案是压缩产生新文件，完成后原子切换（rename），不影响正在写入的当前活跃 segment。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。
