磁盘空间不够了——WAL 里有上万条旧日志，其中 90% 已经被上层 apply 过了但还是占着空间。同一个 key 被 put 了 100 次，只有最后一次的值是有意义的。WAL 压缩就是把这些被覆盖的旧操作清理掉，用 Rust 把这套压缩流程实现出来。

功能需求：
- WAL 中每条日志记录带一个 applied 标记
- 压缩时扫描所有段，找到连续的已应用记录
- 对于已应用的记录，如果对应的数据已经被 checkpoint 持久化，可以安全删除
- 压缩后生成新段替换旧段，对外提供连续的 LSN 不受影响
- 支持后台增量压缩：不阻塞正常写入，先在副本上压缩，完成后原子切换
- 提供统计：压缩前后的段数量和总大小对比

Rust 标准库，cargo build 通过。

压缩过程中的新写入是个挑战——常见方案是压缩产生新文件，完成后原子切换（rename），不影响正在写入的当前活跃 segment。
