帮我实现一个 WAL 日志重放（replay）模块，用 Rust 写。

场景：数据库崩溃重启后，需要从最近一次 checkpoint 开始重放 WAL 日志，把未持久化的数据重新应用一遍，恢复到崩溃前的状态。

要做的：
- 模拟一个简单的存储引擎（内存 KV），维护一个 checkpoint
- 写入操作同时写 WAL，定期做 checkpoint（记录当前 LSN 和数据快照）
- 模拟崩溃：丢弃内存数据，只保留 WAL 和最近 checkpoint
- 重放：从 checkpoint 的 LSN 开始，顺序读取 WAL 记录，逐条应用到空存储
- 处理幂等性：同一条日志重放多次结果要一样（put 操作天然幂等）
- 重放完成后存储状态应该和崩溃前一致
- 提供 verify 接口：对比重放后的数据与崩溃前的数据

纯 Rust，cargo build 通过。

这个工具的核心价值在于把wal replay的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

回放的正确性依赖于幂等性——如果某条操作被重复 apply 了两次，结果必须和 apply 一次相同。这要求状态机的操作是幂等的或者从准确的 checkpoint 开始回放。
