日志不可能无限增长，磁盘放不下重启回放也慢。定期给状态机拍个快照，把当前状态序列化保存，然后就能放心地截断旧日志了。用 Rust 实现快照创建的完整流程——序列化状态机、记录 lastIncludedIndex、截断旧日志。

背景：Raft 日志不能无限增长。当日志积累到一定量后，需要把当前状态机做成快照，截断已包含在快照中的旧日志。这个工具负责快照的创建和管理。

要做：
- 状态机（简单 KV 存储）提供快照接口：dump 当前所有 key-value
- 快照格式：包含 last_included_index、last_included_term、以及 KV 数据
- 创建快照后，last_included_index 之前的日志可以安全截断
- 快照持久化：保存到文件或内存（模拟持久存储）
- 支持多个快照版本，但只保留最新的
- 提供 snapshot_info 接口：返回快照的元信息（大小、包含的 index 范围、创建时间）

Rust 标准库，cargo build 通过。

快照创建的实践细节：不能在持有状态机锁时做序列化（会阻塞读写）。通常先拷贝一份浅拷贝，然后在不持有锁的情况下序列化。
