帮我用 Rust 实现写跟随读（write-follows-read）一致性。

场景：用户先读到了某个版本的数据，之后基于这个数据做写入。写跟随读保证：写入必须发生在之前读取的数据所在的节点或更新的节点上，不会写回旧节点覆盖掉更新的值。

功能：
- 客户端读取时，存储返回一个版本令牌（version token）
- 客户端写入时带上这个令牌
- 存储节点收到写入后，检查自己的版本不低于令牌中的版本
- 如果自己的版本更旧，触发同步把数据拉到最新，再执行写入
- 如果令牌的版本比自己的还旧（不应该发生），拒绝写入
- 支持追踪：可以看到每次写入触发了几次同步

Rust 标准库，cargo build 通过。
