帮我用 Rust 实现一个 Skip Graph 数据结构。

Skip Graph 是一种分布式概率数据结构，类似于跳表但更适合 P2P 网络。每个节点属于多个层级，查找时从最高层开始逐步缩小范围，实现 O(log N) 查找。

要实现：
- 节点有 key 和 membership vector（一个随机 bit 向量决定层级归属）
- 插入：根据 membership vector 确定节点参与哪些层级，在每层中维护有序链表
- 查找：从最高层开始，在每层内找到不超过目标 key 的最大节点，然后下降到下一层
- 删除：从所有参与的层级中移除节点
- 范围查询：找到范围内第一个节点后，沿最底层链表遍历
- 支持 dump 功能：打印各层的链表结构，方便验证正确性

纯 Rust 标准库，cargo build 通过。
