用 Rust 实现一个 Pastry 覆盖网络。

Pastry 是经典的 P2P 覆盖网络协议。每个节点有一个 128-bit 的 nodeId，消息路由时每一步 nodeId 和目标 key 的共同前缀长度至少增加一位，实现 O(log N) 跳的路由。

需要做：
- nodeId 空间：用 16 进制表示，比如 "1A2B3C..."
- 路由表：每个节点维护一个路由表，第 i 行存储与该节点前 i 位相同、第 i+1 位取不同值的节点
- 叶子集：维护 nodeId 最近的 L 个节点（左右各 L/2），用于最后几跳
- 路由算法：消息目标 key 与当前节点比较，找共同前缀最长的下一跳
- 节点加入：通过已有节点路由到最近的节点，沿途更新路由表
- 消息路由：给定目标 key，模拟逐跳路由过程，记录路径

Rust 标准库，cargo build 通过。

这个工具的核心价值在于把pastry overlay的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。
