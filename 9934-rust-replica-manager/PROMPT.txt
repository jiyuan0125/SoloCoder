集群里 3 个副本放在同一台机器上，那台机器挂了数据就全丢了——这种事真发生过。副本管理器负责确保副本分散到不同节点，检测副本不足的分片，自动补副本。用 Rust 实现这套管理逻辑。

背景：分布式存储系统里需要管理数据的多副本——一个数据分片（shard）有几个副本、分别放在哪些节点上、副本的健康状态如何、需要做迁移还是补副本。这个模块就是来做这些事的。

要做：
- 集群有一组节点，数据按 key range 分成多个 shard
- 每个 shard 配置一个副本因子（replication factor），比如 3
- 副本放置策略：尽量分散到不同节点，避免单节点故障导致数据丢失
- 健康监控：标记节点上线/下线，检测副本不足的 shard
- 副本补全：当某个 shard 的副本数低于配置值时，自动选择新节点创建副本
- 副本迁移：支持把副本从一个节点移到另一个节点（rebalance）
- 查询接口：给定 key，返回它属于哪个 shard、该 shard 的副本在哪些节点上

Rust 标准库，cargo build 通过。
