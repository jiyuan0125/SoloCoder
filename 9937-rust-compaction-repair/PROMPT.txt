帮我用 Rust 写一个压缩修复（compaction-repair）模块。

场景：分布式存储引擎里，LSM-Tree 式的存储会不断做 compaction（合并排序）。在合并过程中如果发现某些 key 的数据有损坏或不一致（比如多个副本的版本冲突），需要趁机修复。这个模块把 compaction 和数据修复结合起来。

要做：
- 模拟一个简单的 LSM 存储：写入先到 memtable，flush 到 SSTable，多层级合并
- 合并时检查数据完整性：每个 key-value 对带 CRC 校验码
- 发现校验失败时，从副本拉取正确数据进行修复
- 发现版本冲突时（同一个 key 有多个版本号不同但都 valid 的值），保留最新版本
- 合并完成后输出统计：合并了多少条、修复了多少条、清理了多少重复
- 支持增量合并：不阻塞读写，只合并部分层级

Rust 标准库，cargo build 通过。

这个工具的核心价值在于把compaction repair的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。
