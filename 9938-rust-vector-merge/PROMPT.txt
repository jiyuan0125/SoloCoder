用 Rust 实现一个向量时钟合并（vector clock merge）工具。

背景：在分布式系统里，不同节点对同一个 key 的并发修改会产生多个版本。每个版本带一个向量时钟。读取时需要合并这些版本——如果它们有因果关系，保留更新的；如果并发，保留两者让用户解决冲突。

要做的：
- 实现向量时钟数据结构：每个节点 ID 对应一个递增计数器
- 实现向量时钟比较：before/after/concurrent 三种关系
- 版本合并：给定同一个 key 的多个版本（带向量时钟），判断哪些有因果序、哪些并发
- 有因果序时自动保留更新的版本
- 并发版本保留为一个版本列表（conflict set），等待外部解决
- 外部可以提交解决结果（指定一个值作为最终值），生成新的向量时钟（合并所有输入的时钟并递增）
- 提供 debug 接口：可视化版本演变图

Rust 标准库，cargo build 通过。
