MVCC 引擎跑了两个月，每个 key 积了上千个旧版本，内存快撑不住了。问题是不能随便删——还有活跃事务可能需要读旧版本。版本修剪（version prune）就是清理那些已经没有事务需要的旧版本。用 Rust 把修剪的规则和时机实现出来。

背景：MVCC（多版本并发控制）存储引擎里，每次更新都会产生一个新版本。旧版本需要保留一段时间供正在读的事务使用，但不能无限保留。版本修剪就是清理不再需要的旧版本。

功能：
- 每个 key 保留多个版本，每个版本有 create_ts 和 delete_ts
- 活跃事务列表：记录当前正在运行的事务的 start_ts
- 修剪规则：如果某个版本的 delete_ts < min(所有活跃事务的 start_ts)，说明没有事务还需要它，可以安全删除
- 如果没有活跃事务，只保留每个 key 的最新版本
- 修剪后返回释放了多少条版本记录
- 支持配置最大保留版本数（即使有活跃事务，也不保留超过 N 个版本）

Rust 标准库，cargo build 通过。

版本裁剪删除没有引用的历史版本以回收空间。裁剪的前提是确保没有节点还依赖这些版本——通常通过检查所有副本的同步进度来判断。
