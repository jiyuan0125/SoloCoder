帮我用 Rust 实现一个服务发现中的解析器服务（resolver service）。

场景：微服务架构里，服务消费者需要知道服务提供者的地址。Resolver 就是一个简单的服务发现组件——服务启动时注册自己的地址，消费方通过服务名查询可用实例列表。

要实现：
- 服务注册：实例启动时发送 (service_name, instance_id, address, metadata) 注册到 resolver
- 心跳保活：实例定期发心跳，超时未心跳的实例标记为不可用
- 服务发现：通过 service_name 查询所有可用实例
- 支持实例权重和标签过滤（比如只查带 "zone=east" 标签的实例）
- 健康检查：resolver 主动探测注册的实例是否可达（模拟 TCP ping）
- 变更通知：当某个服务的实例列表发生变化时，通知订阅者

Rust 标准库，内存模拟，cargo build 通过。
