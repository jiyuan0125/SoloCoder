用 Rust 写一个请求路由服务（router service）。

背景：微服务网关里，外部请求进来后需要根据 URL 路径、请求头、参数等条件路由到不同的后端服务。这个路由服务处理请求的匹配和分发逻辑。

功能：
- 配置路由规则表：每条规则包含匹配条件（路径前缀/精确匹配/正则、HTTP 方法、请求头条件）和目标后端地址
- 请求匹配：按优先级（精确 > 前缀 > 正则）和规则顺序匹配请求
- 支持路径参数提取：比如 /users/:id 匹配 /users/123 并提取 id=123
- 负载均衡：如果一条规则配了多个后端实例，用轮询策略选择
- 默认路由：没有匹配到任何规则时走默认后端或返回 404
- 路由表热更新：不重启就能添加/删除规则

Rust 标准库，cargo build 通过。

这个工具的核心价值在于把router service的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

路由服务在服务网格中扮演数据面角色——实际请求转发。需要高性能（不能成为瓶颈）和低延迟，通常用连接池和长连接优化。
