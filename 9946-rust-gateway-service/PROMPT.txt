用 Rust 写一个 API 网关服务（gateway service）。

网关是微服务对外的统一入口，除了路由和代理，还要做认证、限流、日志等横切关注点。这个工具实现一个轻量级的 API 网关核心功能。

功能：
- 路由：根据请求路径和方法匹配后端服务（类似 router service）
- 认证中间件：支持 API Key 和 JWT 两种认证方式，无效请求返回 401
- 限流：基于 IP 或 API Key 的滑动窗口限流（比如每分钟 100 次），超限返回 429
- 请求日志：记录每个请求的方法、路径、状态码、耗时
- 聚合指标：统计 QPS、平均延迟、错误率
- 支持中间件链式调用：认证→限流→路由→代理，任一环节失败直接短路返回

Rust 标准库，cargo build 通过。
