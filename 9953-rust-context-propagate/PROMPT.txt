用 Rust 实现一个跨服务的上下文传播机制。

背景：微服务之间调用时需要把追踪上下文（trace_id、span_id、baggage 等）传给下游服务。实现一个 Context Propagator，支持将上下文信息序列化注入到 HTTP header（比如用 "X-Trace-Id"、"X-Span-Id" 这样的 header），以及从 HTTP header 中提取还原上下文。支持 baggage 机制——自定义的 key-value 对也可以在服务间传递。要处理编码转义，比如值里含有特殊字符的情况。

纯 Rust 实现，cargo build 能过，写个小例子演示注入和提取的过程。
