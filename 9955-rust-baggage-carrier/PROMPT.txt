帮我用 Rust 写一个 baggage carrier，用于分布式追踪中的元数据传递。

Baggage 就是在分布式追踪里随请求一路传递的自定义键值对，比如用户 ID、实验分组这些业务信息。实现一个 BaggageCarrier：支持添加、获取、删除 baggage 项；能把 baggage 序列化成字符串放到 HTTP header（类似 W3C baggage header 格式，逗号分隔，key=value）；能从 header 字符串反序列化回来；处理特殊字符的转义和 URL 编码；设置最大条目数限制防止滥用。

纯 Rust，cargo build 通过，带个 demo 展示序列化和反序列化。
