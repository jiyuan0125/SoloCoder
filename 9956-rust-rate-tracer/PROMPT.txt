用 Rust 做一个速率追踪器，统计分布式系统中的请求速率。

需求：我们需要实时监控各个接口的 QPS，能按秒、分钟、分钟级别聚合。实现一个 RateTracer，支持按接口名称记录请求次数，实时计算每秒/每分钟/每小时的平均请求速率。用滑动窗口实现，避免内存无限增长。能输出当前速率和峰值速率，支持重置统计。可以考虑用环形缓冲区来存储时间窗口内的计数。

Rust 标准库，cargo build 能编译，cargo run 演示几个接口的速率统计输出。

这个工具的核心价值在于把rate tracer的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

速率追踪器监控操作的调用频率——QPS 或错误率。速率突变时自动告警，帮助及时发现异常。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。

速率追踪器的底层是用滑动窗口计数器——维护最近 N 秒的操作计数。每秒统计一次，窗口大小可配置（默认 60 秒）。速率 = 窗口内总数 / 窗口大小。突变检测用简单的阈值——当前速率超过历史平均的 k 倍就告警。
