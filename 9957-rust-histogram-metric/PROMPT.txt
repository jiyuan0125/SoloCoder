写一个 Rust 的直方图指标库，用于监控系统的延迟分布。

实际场景：我们需要统计 API 响应时间的分布情况，比如 P50、P90、P99 延迟。实现一个 Histogram 结构体，支持配置桶的边界（比如 1ms、5ms、10ms、50ms、100ms、500ms、1s），记录观测值到对应的桶中，计算百分位数（percentile），输出平均值、最小值、最大值。支持合并两个直方图（分布式场景下多个节点各自统计后聚合）。桶的计数要精确，不能有浮点误差。

Rust 实现，cargo build 通过，能跑个模拟 API 延迟的 demo。

这个工具的核心价值在于把histogram metric的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

直方图比平均值更有用——平均值会掩盖尾部延迟。99% 请求 10ms 但 1% 要 10 秒的系统，平均值看着正常但实际影响用户体验。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。
