用 Rust 实现一个 Gauge 指标类型，用来跟踪可增可减的实时数值。

场景是这样的：我们想监控当前活跃连接数、内存使用量、队列长度这类会上下波动的指标。Gauge 和 Counter 不一样——它可以直接设置值，也可以增减。支持设置当前值（set）、增加（inc）、减少（dec）、增减指定量（inc_by / dec_by）。记录历史变化趋势，能输出当前值、最小值、最大值。支持回调式的 Gauge——每次读取时自动调用一个函数获取最新值（适合监控实时系统指标）。

纯 Rust，cargo build 通过，演示线程安全的 Gauge 使用。

这个工具的核心价值在于把gauge metric的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

Gauge 表示某一时刻的测量值——内存使用量、活跃连接数、队列深度。和 Counter 不同，Gauge 可以上下波动，反映实时状态。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。
