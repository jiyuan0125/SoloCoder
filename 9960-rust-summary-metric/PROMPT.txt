用 Rust 实现一个 Summary 指标，用于统计数据的分位数分布。

Summary 和 Histogram 的区别在于它不需要预定义桶边界，而是用采样算法在客户端计算分位数。实现一个 Summary：接受观测值，内部维护一个可配置大小的样本窗口（比如最近 500000 个值），支持计算 configurable 的分位数（φ-quantile，比如 0.5、0.9、0.99），输出这些分位数的值。支持设置最大过期时间窗口，太久的数据会被淘汰。注意处理样本量不足时的边界情况。

纯 Rust 实现，cargo build 通过，模拟一些延迟数据演示分位数计算。

这个工具的核心价值在于把summary metric的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

Summary 提供分位数信息——P50、P90、P99 延迟。在客户端计算分位数，不需要预定义桶，但不可跨实例聚合。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。
