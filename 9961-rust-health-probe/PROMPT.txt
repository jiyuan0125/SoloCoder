写一个 Rust 的健康检查探针（health probe）服务。

背景：Kubernetes 里每个服务都要提供 /healthz 端点，告诉集群自己是不是健康的。实现一个简单的 HTTP 健康检查服务：监听指定端口（默认 8080），提供 /healthz 端点返回 200 或 503。支持注册多个健康检查项（比如检查数据库连接、检查磁盘空间、检查依赖服务可达性），每个检查项有自己的超时时间。所有检查项通过才返回健康，任何一个失败就返回不健康。检查结果以 JSON 格式返回，包含每个检查项的状态和耗时。

用 Rust 写，cargo build 能过，cargo run 后可以用 curl 测试。
