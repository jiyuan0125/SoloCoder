Kubernetes 里每个 Pod 都要暴露 /healthz 端点，告诉集群自己是不是还活着。但光检查进程是否存活不够——数据库连不上了、磁盘满了、依赖的服务挂了，进程还活着但已经不能正常服务了。需要一个综合健康检查服务，把多个检查项汇总成一个整体状态。

用 Rust 实现综合健康检查服务（标准库 TCP listener）。监听指定端口（环境变量 PORT，默认 8080），提供 /healthz 端点。收到请求后遍历所有检查项并行执行（每项独立超时，默认 3 秒）。全部通过返回 200 + JSON，任一失败返回 503。

检查项注册：add_check(name, check_fn)，check_fn 返回 Result<(), Error>。内置检查：check_tcp_connectivity(host, port)、check_disk_space(path, min_bytes)、check_memory(min_percent)。检查结果缓存 5 秒，避免高频探测打满系统。

Rust 标准库实现，cargo build 通过，cargo run 后可以用 curl 测试。注册 3 个模拟检查项（2 个通过、1 个模拟磁盘空间不足），展示不健康的 JSON 响应。
