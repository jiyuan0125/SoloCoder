用 Rust 实现连接排空（connection draining）机制。

问题是这样的：服务要下线时不能直接断开所有客户端连接，需要等正在进行的请求完成，这就是 drain。实现一个 Drainer：支持注册连接（带唯一 ID），标记连接为"活跃"或"空闲"，收到排空信号后关闭所有空闲连接，等待活跃连接完成（可配置超时），超时后强制关闭剩余连接。用一个简单的 HTTP 服务模拟场景——几个请求正在处理中，触发 drain，观察等待和关闭过程。打印每个连接的状态变化。

纯 Rust，cargo build 通过，cargo run 能演示完整的排空流程。

这个工具的核心价值在于把drain conn的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

连接排空是优雅关闭的关键步骤——不再接受新连接，已有连接上的请求继续处理。超时时间取决于请求处理时间。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。
