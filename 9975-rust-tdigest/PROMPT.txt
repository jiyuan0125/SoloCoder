帮我用 Rust 实现 t-digest 数据结构。

t-digest 是 Ted Dunning 提出的一种用于在线估计分位数的数据结构，在尾部（极端分位数如 P99、P999）的精度特别好。实现 t-digest 的核心算法：用一组质心（centroid）来压缩数据，每个质心有一个均值和权重（代表覆盖了多少个数据点）。质心在尾部更密集（精度更高），在中间更稀疏（精度低但省空间）。支持合并两个 t-digest。支持查询任意分位数。实现 merging 或 sorting 变体都可以。

Rust 标准库实现，cargo build 通过，用正态分布随机数据验证分位数精度。

这个工具的核心价值在于把tdigest的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

t-digest 在分布尾部（P99、P999 附近）保持高精度，中间部分粗略近似。这正好符合监控场景的需求。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。
