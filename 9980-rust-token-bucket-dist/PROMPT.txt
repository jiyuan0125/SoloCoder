用 Rust 实现分布式令牌桶限流器。

普通令牌桶是单机的，分布式场景下多个节点需要共享限流配额。实现一个分布式令牌桶：模拟多个节点和一个中央存储（可以用简单的 HashMap 模拟 Redis），每个节点从中央存储获取令牌。处理并发竞争——多个节点同时请求令牌时不能超发。支持配置桶容量和填充速率，支持预取（一次取多个令牌减少网络开销），处理令牌不足时的等待或拒绝策略。节点间通信用简单的消息传递模拟。

Rust 实现，cargo build 通过，模拟 3 个节点同时请求令牌的场景。

这个工具的核心价值在于把token bucket dist的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

令牌桶是分布式限流的经典算法——以固定速率生成令牌，请求消耗令牌，桶空了就拒绝。允许突发同时限制平均速率。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。

分布式令牌桶的挑战在于——令牌需要在多个节点之间共享或协调。这个程序实现一个中心化的令牌桶服务——所有请求到一个中心节点获取令牌。支持配置生成速率（tokens/sec）和桶容量（最大突发量）。提供 acquire(n) 和 try_acquire(n) 两个接口。
