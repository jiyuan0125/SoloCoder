写一个 Rust 的漏桶限流器实现。

漏桶（leaky bucket）和令牌桶不同：它以固定速率"漏水"，请求进来后排队，桶满了就直接拒绝。实现一个 LeakyBucket：配置桶容量和漏水速率（比如每秒漏 10 个），请求到来时如果桶没满就加入队列（返回 true），桶满了就拒绝（返回 false）。后台以固定速率从桶中取出请求处理。支持突发——桶为空时可以瞬间接纳 capacity 个请求。用通道或队列模拟请求排队。提供当前桶水位和等待时间估算。

纯 Rust，cargo build 通过，模拟突发流量演示限流效果。

这个工具的核心价值在于把leaky bucket的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

漏桶以固定速率处理请求，不允许突发。比令牌桶更平滑但可能降低峰值吞吐。适合需要严格匀速的场景。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。

漏桶算法把请求比作水滴——以固定速率从桶底漏出。如果桶满了（请求太多），新的请求被丢弃。和令牌桶不同，漏桶严格匀速处理请求，不允许任何突发。适合需要精确控制处理速率的场景，比如调用外部 API 限速。
