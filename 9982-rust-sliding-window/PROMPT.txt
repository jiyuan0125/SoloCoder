用 Rust 实现滑动窗口限流器。

滑动窗口比固定窗口更精确——它不会在窗口边界处出现两倍流量的突刺。实现两种滑动窗口：基于时间的滑动窗口（记录每个请求的时间戳，查询时只统计最近 N 秒内的请求数）和基于数量的滑动窗口（类似 Ring Buffer，维护固定数量的计数槽位）。支持配置窗口大小和限流阈值。内存效率要合理——基于时间的版本可以用有序列表加定期清理，不能让内存无限增长。支持多 key 限流（不同接口独立限流）。

Rust 标准库，cargo build 通过，对比滑动窗口和固定窗口在边界处的行为差异。

这个工具的核心价值在于把sliding window的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

滑动窗口限流比固定窗口更精确——固定窗口在边界处可能有双倍流量。滑动窗口在任何时刻看过去 N 秒都不会超限。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。

滑动窗口限流比固定窗口更精确——在任何时刻回头看过去 N 秒，请求数都不超过限制。这个程序用时间片数组实现——把窗口分成多个小时间片（比如 100ms 一个），每个片记录该时间段的请求数。查询时累加最近 N 个片的计数。
