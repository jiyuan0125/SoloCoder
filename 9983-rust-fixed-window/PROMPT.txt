帮我用 Rust 实现固定窗口限流器。

固定窗口是最简单的限流算法：把时间划分为固定长度的窗口（比如每分钟一个窗口），每个窗口内允许的最大请求数固定。实现一个 FixedWindowRateLimiter：支持配置窗口大小（秒）和窗口内最大请求数。请求到来时检查当前窗口内的计数，没超限就放行并计数+1，超限就拒绝。窗口到期自动重置计数。支持多个独立的限流 key。注意处理并发安全。打印每次请求的通过/拒绝结果和当前窗口剩余配额。

Rust 实现，cargo build 通过，演示限流和窗口重置的过程。

这个工具的核心价值在于把fixed window的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

固定窗口最简单但不精确——限制每分钟 100 次，但在窗口边界 2 秒内可能来 200 次。实际生产中通常用滑动窗口替代。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。

固定窗口限流的实现最简单——用 (当前时间 / 窗口大小) 作为窗口 key，每个 key 维护一个计数器。窗口结束时自动切换到新 key。缺点是窗口边界可能有双倍流量（两个窗口各来一波），优点是实现简单、内存占用小。
