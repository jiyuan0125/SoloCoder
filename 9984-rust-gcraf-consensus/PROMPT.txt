用 Rust 实现 Gossip/CRAFT 风格的共识协议模拟。

Gossip 协议在分布式系统中用于成员管理和信息传播——每个节点定期随机选几个节点交换信息，最终所有节点收敛到一致状态。实现一个模拟器：创建 N 个模拟节点（比如 10 个），每个节点维护一个 key-value 存储和成员列表。节点之间通过消息传递（可以用 channel 模拟网络）进行 gossip 交换。实现 push-pull 模式：每轮每个节点随机选一个对端，互相交换各自知道的最新数据。跟踪收敛过程——需要多少轮才能让所有节点数据一致。支持节点动态加入和离开。

Rust 写，cargo build 通过，可视化每轮的收敛进度。

这个工具的核心价值在于把gcraf consensus的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

Gossip/CRAFT 风格共识把 Paxos 精确性和 Gossip 可扩展性结合——不需要所有节点参与每轮共识，只需要最终收敛。适合大规模集群的配置管理。
