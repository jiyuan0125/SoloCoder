写一个 Rust 的 Gossip 广播协议模拟器。

Gossip 协议（也叫 epidemic protocol）像病毒传播一样在集群中扩散消息。实现一个 Gossip 广播模拟器：N 个节点组成集群，每个节点维护一个消息列表。每轮每个节点随机选 fanout 个（比如 3 个）邻居，把自己的新消息同步过去。实现 push 模式：节点定期把新消息推送给随机邻居。跟踪消息传播过程——某条消息从节点 A 发出，需要几轮才能传遍全网。支持节点故障——某些节点随机掉线不影响消息最终传播。打印每轮每个节点的已知消息数。

Rust 实现，cargo build 通过，展示一条消息从 1 个节点扩散到 100 个节点的过程。

这个工具的核心价值在于把gp bcast的关键细节都暴露出来——不是藏在框架的抽象层后面，而是让你能直接看到每个操作的效果。用Rust实现，利用类型系统在编译期捕获状态转换的错误。cargo build 通过。

Genuine Predicate broadcast 根据消息谓词选择性地广播——只有谓词匹配的节点才接收。大规模系统中可以大幅减少消息量。

程序要打印关键操作的详细信息，让使用者清楚看到每一步的效果。Rust 标准库实现，cargo build 通过。
